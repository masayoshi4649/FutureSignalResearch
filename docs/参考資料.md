## 5. 個別調査と組み合わせの追加資料

個別教科書の追加時に12項目をそれぞれ調べ直し、各ページ末尾に資料が支える定義・用法と、立証しない心理・収益を対応させた。[指標別の目次](technical-analysis/指標/README.md)から各資料表へ進める。

追加の提供元は、TradingViewの指標別公式仕様、Fidelity、マネックス証券、SMBC日興証券、CQG、IBKR等。すべてを一つの式へ無条件に統一せず、平均方式、同値、平滑、入力価格、描画シフトの差を記録している。

組み合わせの根拠として追加確認した本文は次の通り。

## 6. 市場心理・行動の根拠

以下は2026-10-30に要旨と関係する説明を確認した原論文・研究概要である。理論・対象市場の実証・NK225/TOPIXへの仮説を区別し、[市場心理の各ページ](technical-analysis/市場心理/README.md)へ対応を示した。

| 資料 | 支える背景と限界 |
| --- | --- |
| Kahneman・Tversky（1979）[プロスペクト理論](https://web.mit.edu/curhan/www/docs/Articles/15341_Readings/Behavioral_Decision_Theory/Kahneman_Tversky_1979_Prospect_theory.pdf) | 参照点に対する利得・損失の評価。特定の支持抵抗や指標の利益は実証しない |
| Odean（1998）[利益・損失の実現行動](https://faculty.haas.berkeley.edu/odean/Papers%20current%20versions/AreInvestorsReluctant.pdf) | 対象証券口座のディスポジション効果。先物全参加者への外挿は仮説 |
| Bikhchandani・Hirshleifer・Welch（1992）[情報カスケード](https://snap.stanford.edu/class/cs224w-readings/bikhchandani92fads.pdf) | 先行者の行動へ追随する仕組みの理論。チャートから模倣を識別する証拠ではない |
| Osler（2001）[利確・損切り注文と価格帯](https://www.newyorkfed.org/research/staff_reports/sr125.html) | 為替の注文配置に基づく説明。先物で同じ配置とは限らない |
