# チャートの読み方と仮説化

閲覧・整理日：2026-10-30。対象は NK225先物・TOPIX先物のセッション内売買。

チャートは観測済みの価格や数量を要約した図である。「上昇してきた」という観測と、「ここからも上昇する」という予測を分ける。本章では基本用語を押さえたうえで、目視の説明を、利用可能時刻が明確な条件へ置き換える。

出典の一般的な説明を基礎にしているが、以下の**研究用定義例・閾値・検証方法は本リポジトリの提案**であり、出典サイトがその戦略の有効性を保証しているわけではない。実データによる優位性は未検証である。指標の詳細な式は [指標の計算とシグナル](02_指標の計算とシグナル.md) を参照する。

## 1. 何を観測しているか

同じ価格系列から作った指標は、別々の情報源とは限らない。移動平均、MACD、移動平均乖離率を同時に使っても、価格変化を異なる方法で加工した情報が重なりやすい。追加条件の価値は、条件を加えた前後の成績で確かめる。

| 観測したい性質 | 主な表現 | 観測から直ちには分からないこと |
| --- | --- | --- |
| 方向 | 高値・安値の推移、移動平均の傾き | 今後も同方向へ進むか |
| 勢い | MACD、RSI、変化率 | 勢いが弱まっただけで反転するか |
| 変動の大きさ | 値幅、ATR、ボリンジャーバンド幅 | 次の変動の方向 |
| 取引の活発さ | 約定出来高、売買代金 | 注文者の意図、買い手と売り手の真の動機 |
| 注文の状態 | 売買気配、気配数量、スプレッド | 表示注文が残るか、自分が約定するか |
| 価格の位置 | 前セッション高安、VWAPからの距離 | その価格へ必ず回帰するか |

「トレンド系」「オシレーター系」「順張り」「逆張り」は整理のための言葉であり、分類は資料によって異なる。分類名よりも、**何を入力し、何を測り、どの条件で使うか**を記述する。例えばボリンジャーバンドは、中心線への回帰にも、拡大方向への追随にも使える。

出典：[三菱UFJ eスマート証券・第1回 指標の体系](https://kabu.com/investment/guide/technical/01.html)、[SBI証券・テクニカル分析の仕方](https://www.sbisec.co.jp/ETGate/WPLETmgR001Control?OutSide=on&getFlg=on&burl=search_op&cat1=op&cat2=guide&dir=guide&file=op_guide_08.html)（閲覧日：2026-10-30）。

## 2. ローソク足は四つの価格の圧縮表現

ある集計区間について、始値を `O`、高値を `H`、安値を `L`、終値を `C` とする。約定価格から作る足なら、区間内の最初・最大・最小・最後の約定価格に対応する。`C > O` が陽線、`C < O` が陰線であり、表示色はソフトごとの設定で変わる。

| 要素 | 計算 | 見えること |
| --- | --- | --- |
| 値幅 | `H − L` | 区間内で到達した価格の広がり |
| 実体 | `abs(C − O)` | 始値と終値の隔たり |
| 上ひげ | `H − max(O, C)` | 高値から実体上端までの隔たり |
| 下ひげ | `min(O, C) − L` | 実体下端から安値までの隔たり |
| 終値の位置 | `(C − L) / (H − L)` | 値幅内で最後の価格が位置する場所 |

値幅がゼロなら終値の位置を計算できない。その足を除外するか中立値を与えるかを事前に固定する。

同じ `O・H・L・C` でも、高値と安値に到達した順番は複数あり得る。足の途中で利確価格と損切り価格の両方に触れた場合、四本値だけでは先に成立した注文を決められない。長い下ひげも、その場にどれだけの買い注文が存在したかを直接示すものではない。

目視で使う「長い」「ほぼ同じ」は数値にする。例えば、同時線の候補を `実体 / 値幅 ≤ 0.1`、長い下ひげの候補を `下ひげ / 値幅 ≥ 0.6` と定義できる。ただし、この数値は説明用の未検証例である。形状だけで売買せず、直前の変化、支持抵抗との距離、コストを条件にする価値を個別に調べる。

出典：[三菱UFJ eスマート証券・第2回 ローソク足](https://kabu.com/investment/guide/technical/02.html)、[CME・チャートの種類](https://www.cmegroup.com/education/courses/technical-analysis/chart-types-candlestick-line-bar)（閲覧日：2026-10-30）。数値比率は独自の研究用定義例。

## 3. 足の時間幅と情報の利用可能時刻

5分足の20本平均は、欠損や休止時間を除けば約100分の価格を平滑化する。日足の20日平均と同じ現象を表すとは限らない。「一般に使われる20だから」という理由だけで足種をまたいで採用しない。

足を使う条件は、少なくとも次の四点を固定する。

1. 価格の種類：約定価格、買い気配、売り気配、仲値のどれか。
2. 区間の境界：例として `08:45:00以上、08:50:00未満` のデータを集計する。
3. 確定条件：区間終了と受信遅延の扱い。遅れて届いたデータで過去の判断を差し替えない。
4. 無取引・欠損の扱い：無取引と受信障害を区別し、前値補完した足なら識別できるようにする。

`08:45～08:50` の高値を利用する判断は、その足が確定してからである。5分足で判断し、15分足を方向条件に使う場合も、15分足は最後に確定したものだけを参照する。`09:07` に `09:00～09:15` 足の最終値は分からない。

持ち越さないことと、指標の計算をセッションごとに初期化することは別の設計である。過去セッションを指標の準備期間に使う方式も、当該セッションのみで計算する方式も比較対象になる。どちらでも、取引する限月と、休止時間・ギャップをまたぐ計算方法を固定する。

出典：[CME・チャートの種類](https://www.cmegroup.com/education/courses/technical-analysis/chart-types-candlestick-line-bar)（閲覧日：2026-10-30）。境界・確定・欠損処理は本研究に向けた設計要件。

## 4. トレンドとレンジを定義する

### 4.1 高値・安値の更新で見る

ダウ理論の学習では、複数の時間幅のトレンドや出来高による確認が論じられる。本研究ではまず、高値と安値の切り上げ・切り下げを、直近の構造を記録する一つの方法として使う。日中足へ適用した条件は、本来の長期的な理論全体とは区別する。

研究用定義例として、ある足 `i` の高値が前後それぞれ `r` 本の高値をすべて上回るとき、`i` を山とする。谷は安値について反対に定義する。同値をどう扱うか、連続する山・谷をどう整理するかも固定する。

ここで重要なのは、山の位置は `i` でも、**山だと確認できるのは `i+r` の足が確定した時点**ということである。後から描いた山のマークを、その位置で既に知っていたシグナルとして扱わない。

| 状態の候補 | 確認済みの直近二つの山・谷に対する条件 |
| --- | --- |
| 上昇構造 | 山と谷の両方が切り上がる |
| 下降構造 | 山と谷の両方が切り下がる |
| 未分類 | 上記以外、または必要な山・谷が足りない |

未分類をすべてレンジと呼ぶ必要はない。急変直後や転換途中も含まれるため、見送り状態として保持できる。

出典：[Zerodha・ダウ理論の解説](https://zerodha.com/varsity/chapter/dow-theory-part-1/)、[CME・反転形状](https://www.cmegroup.com/education/courses/technical-analysis/technical-patterns-reversals)（閲覧日：2026-10-30）。山谷の抽出条件と三状態分類は独自の研究用定義例。

### 4.2 平滑線や回帰線で見る

価格と移動平均の位置関係、移動平均の傾き、短長期線の交差も方向を表す候補になる。線が短ければ変化を捉えやすい一方で細かな反転が増え、長ければ反応が遅れる。短期間に交差が繰り返される局面では、取引コストが積み上がりやすい。

回帰を用いるなら、時点 `t` までの直近 `N` 本の終値について、`C_j = a + b × j + 誤差_j` の**残差平方和を最小化**する直線を計算する。傾き `b` を価格単位のまま比較せず、例えば `b / ATR` のように直近の変動幅で割れば、異なる水準の価格を比較しやすい。ただし、正規化に使うATRもその時点までに計算できる値に限る。

チャート全体を一本の回帰線で近似し、過去時点の売買判断にその線を使うと、後半の価格が混入する。ローリング計算では、各時点の推定値を保存して評価する。

出典：[三菱UFJ eスマート証券・第3回 移動平均](https://kabu.com/investment/guide/technical/03.html)、[同・第23回 回帰トレンド](https://kabu.com/investment/guide/technical/23.html)（閲覧日：2026-10-30）。回帰の最小化対象と利用時点を本章で明示した。

### 4.3 レンジは事後の見た目で決めない

「今日はレンジだった」とセッション全体から分類して、その日の序盤へ分類を適用すると先読みになる。使用するなら、例えば過去 `N` 本の高安差、方向性、帯幅などの時点情報で定義する。学習期間から決めた閾値を評価期間へ固定し、次のように検証する。

- レンジ条件内で反発狙いの期待損益が改善するか。
- 条件を加えると取引件数が減りすぎないか。
- レンジ判定の直後にブレイクする損失を含めて残るか。

状態の分類精度だけでなく、条件を使った売買の費用控除後の結果を評価する。

## 5. 支持線・抵抗線を「帯」として扱う

支持・抵抗は、価格が止まりやすいと想定する候補領域である。過去の高安、移動平均、節目などが使われ、突破後に役割が逆になる見方もある。一本の線に必ず反応すると仮定せず、価格の刻みと変動幅を考慮した帯として定義できる。

| 候補 | 利用可能になる時点 | 機械化で固定すること |
| --- | --- | --- |
| 前セッション高値・安値 | 前セッション終了後 | 同じ限月か、デイ・ナイトのどちらを参照するか |
| 当セッション序盤の高安 | 事前に決めた集計時間の終了後 | 例えば開始後15分。終了前には完成値を使わない |
| 直近 `N` 本の高安 | 対象となる足の確定後 | 現在足を含めるか、除外するか |
| 確認済みの山・谷 | 山谷の確認条件成立後 | 確認遅延、同値処理、有効期限 |
| 刻みの大きい節目 | 価格水準から事前に決定可能 | 節目の間隔と、帯の幅 |

研究用定義例として、時点 `t` の足を除外した直前 `N` 本の最高値を `R_t` とし、帯を `[R_t−ε, R_t+ε]` とする。`ε` は事前に決めたティック数、または判断直前のATRに一定係数を掛けた値にできる。

「上抜け」を `C_t > R_t+ε` とするのか、「一度上抜けてから帯へ戻り、再度上昇」を待つのかでは別戦略になる。次の判断時点で過去最高値や帯幅を更新すると条件も変わるため、突破時の基準を固定するか追随させるかを決める。

突破を観測できることと、その価格で買えることも別である。約定可能性は、判断後の売り気配、数量、遅延、実際に注文する商品の板で検証する。

出典：[CME・支持線と抵抗線](https://www.cmegroup.com/education/courses/technical-analysis/support-and-resistance)、[Fidelity・支持と抵抗](https://www.fidelity.com/learning-center/trading-investing/technical-analysis/support-and-resistance?print=true-0)（閲覧日：2026-10-30）。帯幅・突破条件は独自の研究用定義例。

## 6. チャート形状を条件の組に分解する

代表的な形状は、継続候補と反転候補に整理できる。ただし、完成した図の形と、途中で利用できた情報を混同しない。以下は名前を実装へつなぐための例であり、各形状の唯一の定義ではない。

| 形状 | 狙う現象 | 研究用定義で必要な条件 |
| --- | --- | --- |
| 長方形・持ち合い | 狭い価格帯からの離脱 | 過去区間の幅、上下への接触回数、突破幅、期限 |
| 三角持ち合い | 高安の収束後の離脱 | 確認済み山谷で引いた二線の傾き、幅の縮小率、突破条件 |
| 旗・ペナント | 大きな動きの後の一時休止と再開 | 先行する値動きの大きさ、調整の値幅・本数、再開条件 |
| 二番天井・二番底 | 同じ領域への再挑戦の失敗 | 二つの山谷の距離、価格差の許容幅、中間の谷山の突破 |
| 三尊・逆三尊 | 山谷の並びの変化 | 三つの山谷、中央の突出量、左右差、ネックラインの突破 |

例えば二番天井を研究する場合、二つの確認済みの山が許容幅内にあり、その間の谷を終値が下抜けた時点を候補にできる。二つ目の山そのもので売った記録にすると、山の確定を待たない別の戦略になる。

形状検出には、候補の保存規則も必要である。途中で崩れた候補、時間切れ、重複候補を残す。「きれいな形だけ」選んだ成績では、実運用で検出される失敗候補が消えてしまう。測定幅を利用する目標価格も、形状の幅をそのまま将来の到達保証として扱わず、決済候補として比較する。

出典：[CME・継続形状](https://www.cmegroup.com/education/courses/technical-analysis/trend-and-continuation-patterns)、[CME・反転形状](https://www.cmegroup.com/education/courses/technical-analysis/technical-patterns-reversals)（閲覧日：2026-10-30）。機械化条件は本章の研究案。

## 7. 出来高・気配数量・VWAPを混同しない

### 7.1 出来高は成立した取引の量

価格上昇と出来高増加を組み合わせて勢いを確認する見方がある。ただし、出来高には必ず買い手と売り手が存在する。出来高増加だけから「買い注文だけが増えた」と結論しない。逆ウォッチ曲線のように価格と数量の関係を観察する手法もあるが、典型図どおりに循環するかは別途の仮説である。

研究では、次の区別が必要になる。

- **約定出来高**：成立した枚数。区間値と累積値を区別する。
- **気配数量**：ある時点の表示注文数量。取り消しや価格変更で増減し、約定を伴わない。
- **建玉残高**：未決済契約の残高。出来高とは異なり、公表頻度と利用可能時刻の確認が必要。

累積出来高から区間出来高を作るなら差分を使うが、累積値の初期化をまたぐ負の差分を売買の減少とは解釈しない。また、ラージの出来高はラージ市場の活発さであり、mini・microの出来高や約定余力そのものではない。

出来高の比較は、銘柄・限月・デイとナイト・セッション開始からの経過時間を合わせる方法を検討する。同じ日の終了後の平均出来高をその日序盤の判断へ使わない。

出典：[三菱UFJ eスマート証券・第17回 逆ウォッチ曲線](https://kabu.com/investment/guide/technical/17.html)、[CME・建玉残高](https://www.cmegroup.com/education/lessons/open-interest)（閲覧日：2026-10-30）。データ変換と比較条件は本研究の設計要件。

### 7.2 VWAPは選んだ区間の数量加重平均

VWAPは、価格を取引量で重み付けした平均価格である。始点をセッション開始とするなら、その開始から現在までの取引を集計する。ローソク足の代表価格に出来高を掛ける近似と、全約定の価格・数量から求める値は区別する。

研究上の使い方には、価格がVWAPより上にある間の買い追随、VWAPから離れた後の回帰狙い、VWAPに接近したときの決済などがある。いずれもVWAPの定義から利益が導かれるものではない。開始直後と終了間際では累積したデータ量が異なり、反応の速さも変わる。

ナイトは日付をまたぐため、午前0時の機械的な日付変更でVWAPを初期化しない。基準をセッション開始・取引日・任意時刻のどれにするかを保存する。ラージで作ったVWAPを他の商品へ使うなら、分析の基準値と実際の発注・決済価格を分けて記録する。

出典：[TradingView公式・VWAP](https://www.tradingview.com/support/solutions/43000502018-volume-weighted-average-price-vwap/)（閲覧日：2026-10-30）。適用候補とセッション処理は本研究の設計案。

## 8. ダイバージェンスは勢いと価格の不一致

価格が高値を更新する一方で指標の高値が下がる場合を、弱気のダイバージェンス候補と呼ぶ。価格の安値更新に対して指標の安値が上がる場合は、強気の候補になる。これは価格と指標の関係の変化であり、直後の反転や反転価格を確定させるものではない。

機械化では、価格と指標のどの山谷を対応させるかが中心になる。本章の研究用定義例では、確認済みの二つの価格の山 `p1・p2` に対し、その同じ足の指標値を比較する。

- 価格：`H_p2 > H_p1 + 価格差の最小幅`。
- 指標：`指標_p2 < 指標_p1 − 指標差の最小幅`。
- 時間：二つの山の間隔が事前に決めた範囲内。
- 判断時点：二つ目の山の確認後。

指標自身の山を別に探す方式にするなら、対応を許す時間差を固定する。図を見た後で都合のよい山だけを結ばない。強いトレンドでは不一致が続いても価格が進むことがあるため、単独エントリー、既存建玉の縮小、利確条件への利用を分けて比較する。

出典：[Fidelity公式・価格と指標の不一致の説明](https://www.fidelity.com/learning-center/trading-investing/technical-analysis/technical-indicator-guide/apo)（閲覧日：2026-10-30）。山の対応方法と閾値は独自の研究用定義例。

## 9. 後から書き換わる表示を売買判断に使うとき

過去の線やマークが後の価格で変わる表示を、ここではリペイントと呼ぶ。全ての描き直しが誤りではないが、当時の判断を再現するには、そのとき見えていた値が必要である。

| 例 | 研究で必要な処理 |
| --- | --- |
| 未確定足の高安・終値 | 確定足だけ使うか、足内の逐次状態を保存する |
| 左右の足を使う山谷検出 | 山谷の位置と確認時刻を別に記録する |
| 後から最適な二点を選ぶトレンドライン | 点の選択規則と、その点が既知になった時刻を固定する |
| 全期間で引き直す回帰線 | 各時点までの入力だけで再計算する |
| 将来・過去へずらして表示する指標 | 描画位置と計算できた時刻を分離する |
| 修正・遅延データで更新された過去足 | 修正前の判断と修正後の分析を識別する |

例えば一目均衡表の先行・遅行という表示位置は、未来を知っていることを意味しない。過去へ描画した遅行線を、その過去時点で既知の入力として使わない。非時系列の足も、完成条件に達する前の形を完成後の形で置き換えない。

## 10. 仮説へ変えるための記入欄

チャートを見て気づいた現象は、次の項目まで書いてから検証へ進める。複数の見方を一度に足すより、一つの追加条件が何を変えたかを追えるようにする。

| 項目 | 記入する内容 |
| --- | --- |
| 観測 | どの商品・限月・時間帯で、どんな値動きがあったか |
| 仮説 | どの条件の後に、どの期間の値動きが変わると考えるか |
| 入力 | 価格系列、数量、足幅、指標の準備期間 |
| 条件 | 全ての期間・閾値・同値処理・確認遅延 |
| 実行 | 条件成立後の発注時刻、発注商品、注文種別 |
| 決済 | 利確・分析上の撤退・保護用逆指値・時間切れの優先順 |
| 比較 | 同じ期間・同じコストで比較する基準戦略 |
| 棄却 | どの結果なら仮説を採用しないか |

「反発した場面がある」から始めてもよい。ただし、反発しなかった場面、見送った場面、注文できなかった場面も同じ規則で集める。この記録が、チャートの印象を、次の試行で検証できる仮説へ変える。
