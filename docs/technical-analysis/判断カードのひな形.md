# 判断カードのひな形

作成日：2026-10-30。[指標](指標/README.md) / [組み合わせ](組み合わせ/README.md) / [市場心理](市場心理/README.md)

教科書の一部を試行へ再利用するときは、下表をコピーし、観測できる条件と説明の仮説を分けて記入する。これは研究記録用の形式であり、注文APIやViewerの入力スキーマではない。

| 項目 | 記入内容 |
| --- | --- |
| カード名・識別子 | 一つの現象が分かる名前。教科書ならC01等、試行固有の改変には別名 |
| 参照 | 指標ページ、組み合わせカード、使用した心理仮説P01〜P06と資料 |
| 観測事実 | 時点までに分かる価格・量・指標の関係 |
| 一般的な解釈 | どの資料がその解釈を紹介しているか |
| 心理・行動の仮説 | 誰が何を理由に売買すると考えるか。直接の証拠の有無 |
| 代替説明 | 同じ観測を生む別の原因 |
| 役割 | 環境、位置、入口、確認、通常撤退、保護のどれか |
| 入力と式 | 観測商品・限月、価格系列、足、期間、初期値、平滑、欠損と同値 |
| 環境条件 | その手法が想定する相場。判断前の情報だけで定義 |
| 発動条件 | 状態と交差、不等号、確認本数、発動時刻、有効期限 |
| 取消・無効化 | 前提の崩れ、時間切れ、品質不良、候補の破棄と再挑戦 |
| 発注 | 実行商品、呼値、数量、遅延、約定モデル、未約定の扱い |
| 通常決済 | 利確・損切り・時間による撤退の条件と優先順位 |
| 独立した保護 | 発動の観測価格、監視場所、発動後注文、更新・拒否の扱い |
| 終了 | 新規停止、全返済、確認期限、残建玉・未約定の監査 |
| 重複情報 | 同じ価格加工や同値の確認を何度も数えていないか |
| 比較 | 条件なし、単純手法、追加なしの元手法 |
| 反証と評価 | 何が起これば採用しないか、費用後の主評価値と未使用期間 |
| 状態 | 資料にある例 / 本研究の応用 / 教材例 / 実行済み。対象と適用範囲 |

## 教科書から実試行へ移す例

「C01、RSIを追加する案B、心理の説明候補はP03とP04」のように指定できる。次に、未指定の執行商品・期間・費用・初期化・終了条件を埋め、[試行記録テンプレート](../試行記録テンプレート.md)へリンクする。

教科書のカードを使っただけでは、実行可能な手法の仕様がすべて確定したことにはならない。心理を使う場合も、「P04らしい気がする」のような裁量条件を追加せず、実際に観測する突破・本数・数量等に置き換える。

## 更新時の扱い

一般解説の誤りや新しい根拠は教科書へ反映し、更新日と出典を残す。試行済みの条件は元の試行に保存し、教科書の変更で過去の計算条件をすり替えない。新しい入口・出口や条件の追加は別の候補として比較する。
