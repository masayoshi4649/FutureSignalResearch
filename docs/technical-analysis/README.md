# 先物自動売買研究のためのテクニカル分析教科書

初版・個別編の追加日：2026-10-30。対象はNK225先物・TOPIX先物のセッション内取引。

この教科書は、指定の証券会社3サイトを出発点に、取引所、指標開発者、ツール提供元、研究論文を補足して作成した。記事や図の転載ではなく、基本概念を独自に整理し、計算式と機械化の条件を説明する。各章に直接の出典を付け、全体の読み分けを [参考資料](../参考資料.md) にまとめた。

## 読み分ける三つの内容

- **資料で確認した説明・制度**：各節の一次資料へ戻れるようにしている。市場制度は確認日以降に変わり得る。
- **計算上の定義と実装仕様**：同名の指標でも式・入力・初期値で値が異なる。研究では一つの仕様を固定する。
- **本研究用の仮説・数値例**：売買候補やパラメータは未検証。利益や実約定を示すものではない。

指定資料でも、例えば移動平均乖離の基準値、RSIの平滑化、ボリンジャーバンドの入力価格、ストキャスの平均本数が異なる。一般的な名称やチャートの見た目だけで同じ実装と判断しない。

## 本研究への適用

分析にはラージのデータを用い、mini・microを取引する構成を想定する。指数と限月が同じでも商品の板・呼値・費用が異なるため、ラージ価格による代理評価と実行商品の約定評価を区別する。

各セッションの終了時には建玉と未約定を残さないことを要求する。デイ15:45・ナイト翌06:00まで全時間がザラバではないため、新規停止・返済・確認の期限を別に定める。

現存原板には価格時計と受信時刻の区別、欠測、同時計の更新など、検証前に確認する点がある。[データと閲覧形式](../データと閲覧形式.md)を先に確認し、仮定で補った結果を観測事実と混ぜない。

実試行を始めるときは [研究運用](../研究運用.md) と [試行記録テンプレート](../試行記録テンプレート.md) を使用する。[共通知見の目次](../README.md)へ戻る。
