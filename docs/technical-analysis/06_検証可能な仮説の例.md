## 1. 共通条件を先に固定する

| 項目 | 教材例の共通仕様 |
| --- | --- |
| 分析対象 | NK225ラージとTOPIXラージを別々に評価。同じ限月の既知過去データだけを利用 |
| 執行対象 | ラージ・mini・microは別の資源として記録。対象商品の板がなければラージ価格による代理損益と明記 |
| 足 | 確定5分足のLast。時計・足生成の制約はデータ文書の確認事項を解決してから確定 |
| 指標 | 02章の式から実装仕様を一つ選択。EMA・RMAの初期化と必要本数を固定 |
| 準備期間 | 同一限月の観測済み過去足を利用可。足数不足なら見送り、休場時間は架空足で埋めない |
| 数量 | 最初の比較は対象商品1枚固定、増玉・両建てなし |
| 判断 | 確定足で条件判定し、その後の利用可能な観測で発注。保護価格は足中も別に判定 |
| 通常の売買 | 買いはAsk、売りはBidを起点とする近似。欠損・数量不足は成功約定にしない |
| 終了 | 新規停止と全返済の時刻を先に固定。期限返済を全手法に優先 |
| 共通保護 | シグナル足確定時のATR14を固定し、実約定価格から買いは下へ・売りは上へ2ATR。商品別の刻みに丸め、返済約定は発動後の価格で評価 |
| 再エントリー | 建玉ゼロ・未約定ゼロを確認した後の新しい条件成立だけ。返済足での即時ドテンなし |
| 費用 | 商品別の往復手数料と約定モデルを試行前に指定。通常ケースと厳しいケースを両方比較 |

ATR14は02章のTRとRMAで計算し、前終値がない最初のTRは未定義とする。ATRが未定義なら新規を見送る。指標を固定する時点はシグナル足の確定、価格の基準はその後の実約定価格であり、シグナル終値を建値として代用しない。

共通保護の2ATR幅より先に通常の損切りが発生してもよい。どちらも同じ建玉の返済を競合させず、実際に成立した数量だけ減らす。現在の原板の時計で判定できない順序は、不明または明示した保守仮定として残す。

## 2. 仮説A：方向を限定したMACDの追随

**考え方**：上位の方向に沿った勢いの再加速は、方向を問わないMACD交差より費用後損益が良いか。

| 条件 | 買いの例 | 売りの例 |
| --- | --- | --- |
| 方向 | `C_t > EMA60_t` かつ `EMA60_t > EMA60_(t−1)` | 不等号を反転 |
| 入口 | MACD(12,26,9)で `MACD_(t−1) ≤ signal_(t−1)` かつ `MACD_t > signal_t` | 下向き交差 |
| 通常決済 | MACDがシグナルを下向きに交差、または `C_t < EMA60_t` | 上向き交差、または `C_t > EMA60_t` |
| 保護・期限 | 共通条件に従う | 共通条件に従う |

すべて同じ足の確定後に判断する。条件が継続して真であるだけでは新しい交差とはしない。反対側へ交差しても、まず返済を完了させる。

最初の比較は、方向条件なしのMACDとの比較とする。その後の別候補として、買いにRSI(14)が50超、売りに50未満という条件を追加できる。同じ価格から作る指標なので、追加情報ではなく単なる絞り込みになっていないかを確認する。

棄却・保留の観点は、交差が頻発する時間帯の費用、遅れて入ることによる逆行、EMAの準備不足、少数の大きなトレンドだけへの利益集中である。

## 3. 仮説B：バンド内へ戻った後の回帰

**考え方**：価格が帯の外側から内側へ戻った後に中心へ向かう傾向は、費用と損切りを加えても残るか。

この教材例では、終値20本のSMA、同じ20本の母標準偏差、上下2σを使う。楽天のTPを用いる例とは別の仕様である。RSIは14本のWilder型平滑を選んだ例とする。

| 条件 | 買いの例 | 売りの例 |
| --- | --- | --- |
| 前足の状態 | `C_(t−1) < 下帯_(t−1)` かつ `RSI_(t−1) < 30` | `C_(t−1) > 上帯_(t−1)` かつ `RSI_(t−1) > 70` |
| 入口 | `C_t ≥ 下帯_t` かつ `RSI_t ≥ 30` | `C_t ≤ 上帯_t` かつ `RSI_t ≤ 70` |
| 条件の整合 | `C_t < 中心線_t` を追加し、利確候補を既に通過した場合は見送り | `C_t > 中心線_t` |
| 通常利確 | 確定足で `C_t ≥ 中心線_t` | 確定足で `C_t ≤ 中心線_t` |
| 通常損切り | 再び確定終値が下帯を割る | 再び確定終値が上帯を超える |
| 保護・期限 | 共通条件に従う | 共通条件に従う |

中心線は動くため、入口時の値で固定する方式とは別手法である。最初は上記の時点ごとの中心線を使用し、足中に中心線へ触れただけでは通常利確しない。保護注文の発動は別扱いとする。

比較はバンドだけの条件、RSI追加の順で行う。さらに相場状態を絞るなら、過去情報のADXや帯幅の条件を一つ追加し、その変更を新しい候補として記録する。セッション終了後の見た目で「レンジの日」だけ選ばない。

棄却・保留の観点は、強いトレンドで損切りが重なること、中心までの距離がスプレッドと費用に近いこと、同足順序の仮定だけで利益が出ることである。バンド接触から反転の確率を固定値で仮定しない。

## 4. 仮説C：序盤の価格帯からの離脱

**考え方**：セッション開始後の価格帯を離れる動きは、単純な方向予測として有効か。

開始後15分の確定足だけから最高値 `R` と最安値 `S` を計算し、セッション中は固定する。通常時の範囲はデイ `[08:45,09:00)`、ナイト `[17:00,17:15)`。欠損がある場合はこの候補を無効にする。序盤区間が完成する前には発注しない。

| 条件 | 買いの例 | 売りの例 |
| --- | --- | --- |
| 入口 | 初めて確定終値が `R + 分析商品の1ティック` を上回る | 初めて `S − 分析商品の1ティック` を下回る |
| 通常損切り | 確定終値が `R` 以下へ戻る | 確定終値が `S` 以上へ戻る |
| 通常利確 | 共通保護と同じ固定ATR14を使い、実約定価格より2ATR上を目標とする。確定終値が到達した後に返済 | 実約定価格より2ATR下 |
| 保護・期限 | 共通条件に従う | 共通条件に従う |
| 再挑戦 | 最初の比較はセッション内で入口1回まで | 買い・売り合わせて1回まで |

分析商品のティックを用いた条件と、実行商品の注文の刻みは別である。将来、同じ絶対幅やATR正規化した突破幅を比較する場合も変更を記録する。

利益を伸ばす別候補として固定利確を追尾型の出口に交換できるが、元の結果と混ぜない。序盤の幅、時間帯、費用で分解し、板偏りの条件を加える前に価格だけの基準を残す。

棄却・保留の観点は、上抜け直後の逆行、開始時の不正気配や未設定Last、初回15分の欠損、残り時間の不足、通常の値動きと区別できない突破である。

## 5. 板データからの改善を混ぜすぎない

板の情報には入口の絞り込み、発注の見送り、約定の再現という異なる用途がある。

| 追加候補 | 問うこと | 必要な確認 |
| --- | --- | --- |
| スプレッド上限 | 高費用状態を避けるだけで改善するか | 商品別刻み、時間帯、判断時点の気配 |
| 気配数量の偏り | 同じチャート条件でも短期の順行に差があるか | 正常板、数量欠損、同時計更新、取消の影響 |
| 出来高増 | 価格帯離脱の継続性に差があるか | 累積値の起算、差分、時間帯の基準 |
| 不正・古い板の除外 | 評価不能区間を正しく識別できるか | 時計の意味と品質規則。損益を見た後に除外しない |

例えば板フィルターを加えた後の利益が増えても、取引数が激減し、少数の偶然の取引しか残っていないかもしれない。除外された取引も同じ基準で評価し、追加条件の効果を別期間で確認する。

データが支えない受信遅延や待ち行列を細かく作り込むことは、証拠の増加ではない。まず何が観測事実で、何がモデルの仮定かを明記する。

## 6. 次の実試行へ進むとき

候補を一つ選び、[試行記録テンプレート](../試行記録テンプレート.md)に入力期間・費用・約定・終了条件を埋める。未使用期間と比較対象を固定し、[データと閲覧形式](../データと閲覧形式.md)の未確認点を解消または仮定として記録した後に採番する。

実行後は成功例だけでなく、損失・無取引・欠損・期限返済の例をViewerで点検する。改善案は同じ試行の過去結果を書き換えず、次の番号へ引き継ぐ。
