# 市場心理を判断へつなげる

確認日：2026-10-30。[教科書の目次](../README.md) / [組み合わせ](../組み合わせ/README.md)

チャートの形を覚えるときは、「その価格で、誰が、なぜ売買する可能性があるか」を考えると理解しやすい。ただし、価格から参加者の頭の中を直接読むことはできない。本フォルダでは、心理を値動きの説明候補として整理し、別の原因と見分けるための観測までセットにする。

## 1. 三段階で読む

例えば、価格が100から95へ下がり、再び100に近づいた場面を考える。

| 段階 | 言えることの例 |
| --- | --- |
| 観測事実 | 前の高値近辺へ戻り、終値の上昇幅が小さくなった |
| 一般的な解釈 | 過去の高値が抵抗帯として意識されている可能性がある |
| 心理・行動の仮説 | 100で買って含み損だった人が、建値付近で売りたいのかもしれない |

三つ目を確かめるには保有者の取得価格や注文目的の情報が必要になる。新しい売り、ヘッジ、裁定、ニュースへの反応、買い注文の減少でも似た形は起こる。「建値売りが原因」と断定せず、その説明から予測できる反応を調べる。

## 2. 再利用する心理・行動の仮説

| 識別子 | 概念 | 指標との主な接点 | 詳細 |
| --- | --- | --- | --- |
| P01 | 参照価格を基準に損益を感じる | 支持抵抗、過去高安、MA・VWAPの解釈 | [参照価格と損失回避](参照価格と損失回避.md) |
| P02 | 利益確定と損失確定の非対称 | 利確、戻った価格での売り、反転候補 | [参照価格と損失回避](参照価格と損失回避.md) |
| P03 | 他者の行動を手がかりに追随する | トレンド、MACD、価格帯突破 | [追随と買い戻し](追随と買い戻し.md) |
| P04 | 損切り・買い戻しが同方向の注文になる | ブレイク、急伸、逆指値、SAR | [追随と買い戻し](追随と買い戻し.md) |
| P05 | 注文の集中と流動性の不足 | 板、スプレッド、出来高、ATR | [需給と流動性](需給と流動性.md) |

P01〜P06は本教科書の参照用識別子であり、確立した六分類という意味ではない。試行では「P04を説明候補とした」「注文目的は観測できない」のように使用する。

## 3. 根拠の種類を混ぜない

| 種類 | 何を裏付けるか | 何までは言えないか |
| --- | --- | --- |
| 指標の数式 | 入力価格や数量のどの関係を測っているか | その値を生んだ参加者の動機 |
| 証券会社・作者の教育資料 | その解釈・使い方が紹介されていること | 利用者全体の実態や、費用後の優位性 |
| 心理の選択実験・理論 | 一定の状況で起こり得る判断の仕組み | 今日のNK225でその仕組みが作動したこと |
| 口座・注文データの実証 | 調査した市場・期間・参加者の行動 | 別市場・別時代・別時間幅で同じ効果があること |
| 本研究の検証 | 指定データと条件での関係・損益 | 実行商品での約定、未来の収益、心理の因果関係の自動的な立証 |

心理の物語が分かりやすくても、逆方向の物語も同じくらい作れてしまうことがある。説明を選ぶ前に、上昇・下落・継続・失敗のすべてを同じルールで集める。[バックテストと改善](../05_バックテストと改善.md)

## 4. 心理を使って仮説を作る順序

```mermaid
flowchart LR
  A[観測した価格・数量] --> B[行動の説明候補]
  B --> C[別の原因も列挙]
  C --> D[次に何が起こるかを条件化]
  D --> E[反例と費用を含めて検証]
```

例えば「突破価格には損切りの買いが集中する」というP04を考えるなら、突破後の一定本数の順行幅、逆行幅、出来高、スプレッドを測る。何もない価格帯の突破とも比較する。価格だけが順行した結果から、損切り注文だったと逆算することはできない。

本研究の原板には、独立した受信時計や注文目的が確認できていない。出来高差分は欠落・リセットの影響を受け、板数量の変化には約定以外に取消・変更の影響がある。[データと閲覧形式](../../データと閲覧形式.md)の制約に合わせ、心理の説明を売買利益の根拠と混同しない。
