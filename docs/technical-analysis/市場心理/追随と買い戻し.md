# 追随と買い戻し

確認日：2026-10-30。参照用識別子：P03・P04。[市場心理の目次](README.md)

## 1. 上がる価格に買いが続く理由は一つではない

価格100、101、103と上がる場面を考える。新たな情報で価値を高く評価した買い、他者の行動を手がかりにした買い、機会を逃したくない買い、売り建玉の損切りによる買い戻しが、同じ方向の注文になり得る。

チャートではいずれも上昇に見える。MAの上向きやMACDの上昇はこの価格の推移を要約するが、どの理由の買いかは区別しない。

## 2. P03：他者の行動から学ぶ追随

Bikhchandani・Hirshleifer・Welchの情報カスケード理論では、先行する人の行動を観察した後、自分の情報より先行者の行動に従う状況を扱う。追随は必ずしも無思考な熱狂だけではなく、他者が情報を持っていると推測する行動としても考えられる。ただし、行動が揃っても新たな情報を集約できず、集団の行動が脆くなる場合がある。[原論文・要旨と基本モデル](https://snap.stanford.edu/class/cs224w-readings/bikhchandani92fads.pdf)

この考え方をチャートへ当てはめれば、「突破したので他の参加者も買うと考えて追随する」という説明候補になる。しかし、価格だけでは、皆が他者を真似たのか、それぞれ同じニュースへ合理的に反応したのかを見分けられない。

## 3. P04：売り建玉の損切りも買いになる

売り建玉を持つ人は、価格上昇が続くと損失を抑えるために買い戻すことがある。以前の高値の上に返済の買い条件が集まっていれば、高値突破後に買い注文が増えるという説明になる。買い建玉の損切りが売りになる場合も対称である。

これは「気持ちが強気になった買い」と異なる。価格の見通しを変えなくても、証拠金、損失上限、ヘッジ比率や自動注文の規則で返済することがある。感情を仮定せず説明できる部分も大きい。

Oslerの為替研究は、損切り注文が集まる水準付近での急な値動きや、注文の連鎖と整合的な証拠を報告している。NK225・TOPIXのラージ板に同じ集中があるかは、別に確認する必要がある。[ニューヨーク連銀・損切り注文の研究、要旨](https://www.newyorkfed.org/medialibrary/media/research/staff_reports/sr150.pdf)

## 4. 指標にどう現れると考えるか

| 観測 | 説明候補 | 同じ形になる別の原因 |
| --- | --- | --- |
| 上向きMAの上でMACDが再上昇 | 小休止後に追随する注文が再開 | ニュース、裁定、少量の取引でも起こる |
| 高値突破で値幅が拡大 | 新規の追随と損切り買い戻しが重なる | 売り気配の取消だけでも価格は動きやすくなる |
| RSIが高水準に留まる | 同方向の取引が継続 | 計算窓・平滑の影響で高い値が残る場合もある |
| 価格は高値更新、MACDの山は低下 | 上昇の勢いが相対的に弱まる | 上昇速度の変化だけで反転せず続くこともある |

RSIやMACDが示すのは価格変化の配分や平滑差である。「買い手の人数が増えた」「買い戻しが終わった」という直接の観測ではない。[MACD](../指標/MACD.md) / [RSI](../指標/RSI.md)

## 5. なぜ追随が失敗するか

高値を超えた直後に買い戻しが一巡し、新規の買いが続かなければ価格が戻るかもしれない。逆に、情報の変化が持続すれば、短期的な過熱指標が高いまま価格が進む可能性もある。

そのため、同じ「高値突破」について、順行幅、突破水準への戻り、継続時間、費用を調べる。成功した突破だけを見てP03、失敗した突破だけを見て「買い戻しの一巡」と説明しても予測にはならない。

## 6. 再利用する判断カード

| 項目 | P03・P04の使い方 |
| --- | --- |
| 対象 | 事前に定義した高安や価格帯の突破、トレンド内の再加速 |
| 観測 | 突破の確定、一定期間後の価格、MFE/MAE、出来高、正常な気配 |
| 発動候補 | 突破だけ、突破後の定着、戻り後の再上昇を別手法として定義 |
| 無効化候補 | 突破帯の内側へ戻る、指定本数で進まない、方向条件の崩れ |
| 心理の検証限界 | 新規と返済、情報反応と模倣の区別には追加データが必要 |
| 比較 | 方向条件なし、通常水準の突破、追加条件なしの同一手法 |

注文が集中するなら発動後に不利な価格で成立する場合もある。連鎖を利益の説明に使いながら、自分の損切りだけは常に発動価格で約定させる計算にしない。[先物と執行](../03_先物と執行の制約.md)
