# 参照価格と損失回避

確認日：2026-10-30。参照用識別子：P01・P02。[市場心理の目次](README.md)

## 1. 同じ価格でも、持っている人の感じ方は違う

価格100のとき、90で買った人には利益、110で買った人には損失となる。価格そのものが同じでも、どこを基準にするかで「もう売りたい」「戻るまで待ちたい」という判断が変わる可能性がある。

P01は、このように参照点に対する変化として損益を捉える説明である。Kahneman・Tverskyのプロスペクト理論は、リスク下の選択を最終的な資産額だけでなく利得・損失の評価として扱う。この理論は、チャートの支持線で必ず反発するという法則ではない。[原論文・要旨と価値関数の節](https://web.mit.edu/curhan/www/docs/Articles/15341_Readings/Behavioral_Decision_Theory/Kahneman_Tversky_1979_Prospect_theory.pdf)

「損を嫌う」は「必ずすぐ損切りする」と同じではない。損失を確定したくなくて保有を続ける場合も、早く損切りする場合もあり、リスク制約や運用目的によって変わる。

## 2. 利益を売り、損失を残す行動

P02では、含み益を早く確定し、含み損の確定を遅らせる行動を説明候補にする。これはディスポジション効果と呼ばれる。Odeanは大手割引証券会社の1万口座の取引記録を分析し、利益を実現する傾向が損失を実現する傾向より強いことを報告した。これは対象口座の実証であり、日本の先物参加者すべての行動を示さない。[著者公開論文・要旨とデータ分析](https://faculty.haas.berkeley.edu/odean/Papers%20current%20versions/AreInvestorsReluctant.pdf)

プロスペクト理論とディスポジション効果は関係づけて論じられるが、一方の言葉だけで他方の原因を一意に証明できるわけではない。税制、資金需要、リバランス、将来価格の見通しも売却に影響し得る。

## 3. 支持抵抗とどう結び付くか

次は説明用の架空の場面である。

1. 価格100付近で買った参加者がいる。
2. 価格が95へ下がり、その参加者は損失を抱えたまま待つ。
3. 価格が100付近へ戻ると、「同値で逃げられる」と売却を選ぶかもしれない。
4. その売りが直ちに買いたい注文を上回る程度に集中すれば、上昇が止まる可能性がある。

一方で、新しい情報を得た買い手がその売りを吸収すれば上へ進む。以前100で買った人がすでに全員退出している場合もある。過去の約定価格だけでは現在の保有者と取得価格を追えないため、上の流れは**本研究に適用する心理仮説**である。

支持抵抗の注文配置に関しては、Oslerが大手為替銀行の利確・損切り注文を分析し、節目付近の注文集中と価格反応を論じている。この注文データの証拠と、損失回避そのものの証拠は区別する。[ニューヨーク連銀・研究概要](https://www.newyorkfed.org/research/staff_reports/sr125.html)

## 4. MA・VWAPを「皆の建値」と読まない

| 基準 | 実際に計算しているもの | 心理と結び付けるときの限界 |
| --- | --- | --- |
| 移動平均線 | 選んだ足の価格の平均・平滑値 | その価格で取引した数量や、今の保有者を表さない |
| VWAP | 選んだ区間の約定量で加重した価格 | 売買両側と転売を含み、残っている建玉の平均建値ではない |
| 過去の高安 | 選んだ区間で観測された極値 | その価格の注文が現在も残るとは限らない |

「平均付近を参照して売買する人がいるかもしれない」は仮説として使える。「平均線で全員が損益ゼロになる」へ置き換えない。[移動平均線](../指標/移動平均線.md) / [VWAP](../指標/VWAP.md)

## 5. 再利用する観測と反証

| 項目 | P01・P02から作れる研究案 |
| --- | --- |
| 観測 | 事前に固定した過去高値・帯へ再接近した後の順行・逆行、接近回数、出来高 |
| 予測候補 | 初回の再接近で価格が止まりやすい、または突破後に動きが加速する |
| 代替説明 | ニュース、裁定、ヘッジ、単なる低流動性、価格の丸い刻み |
| 比較 | 同じ時間帯・変動幅で、参照帯のない水準や別の帯と比べる |
| 反証・保留 | 帯の後付け選択だけで差が出る、費用後の差がない、注文目的を識別できない |

この検証で価格反応の差があっても、個人の損失回避が原因とまでは言えない。売買の役に立つ条件と、心理の因果的な説明を別々に評価する。
