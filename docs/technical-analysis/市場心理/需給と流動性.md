# 需給と流動性

確認日：2026-10-30。参照用識別子：P05・P06。[市場心理の目次](README.md)

## 1. 「買う人が多い」の中身を分ける

成立した取引には必ず買い側と売り側がいる。「買いが多いから上がった」という説明は、参加人数よりも、すぐに買いたい注文と、その値段で売る注文の関係として考えると具体的になる。

例えば売り板に100で2枚、101で4枚があり、その表示が残っているときに、3枚を直ちに買う注文が到着したとする。単純な約定例では100で2枚、101で1枚が成立し、最後の約定価格は101になる。買いと売りの約定数量は同じ3枚でも、売り板を消費する注文により価格が変わる。

実際は価格優先・時間優先、注文の執行条件、到着前の取消や変更が関係する。これは板の仕組みを説明する架空例であり、スナップショットからの確実な再現を意味しない。[JPX・取引方法](https://www.jpx.co.jp/derivatives/rules/trading-methods/index.html)

## 2. P05：同じ数量でも動き方が違う

相手側の気配が薄ければ小さな注文でも複数の価格を消費し、厚ければ同じ数量で動かないことがある。気配の取消で、約定を伴わず最良気配が変わる場合もある。

したがって、価格の急変は「強い確信を持つ人が大量に参加した」以外にも説明できる。日中とナイト、寄付きと通常時で、同じ値幅や出来高の意味が変わり得る。

| 観測するもの | 分かること | 分からないこと |
| --- | --- | --- |
| スプレッド | 最良の売買気配の隔たり | 到着時まで気配が残るか |
| 表示数量 | その観測で表示された注文量 | 非表示の注文、全参加者の意図、取消予定 |
| 出来高 | 成立した数量 | 買い手が強気か、売り手が損切りか |
| ATR・帯幅 | 価格の変動の大きさ | 注文者の感情、今後の方向 |

P05は厳密には心理そのものより、注文と価格の関係である。心理が行動に影響しても、実際に価格へ影響する段階では流動性との組み合わせになる。[ATR](../指標/ATR.md) / [板の特徴量](../03_先物と執行の制約.md)

## 3. P06：VWAPを参照する売買の説明

VWAPは、選んだ期間の約定量で価格を加重した平均である。執行価格の比較基準という説明は[IBKRの用語集](https://www.interactivebrokers.com/campus/glossary-terms/volume-weighted-average-price-vwap/)、日中の価格位置を判断する説明は[TradingViewの仕様](https://www.tradingview.com/support/solutions/43000502018-volume-weighted-average-price-vwap/)で確認できる。

例えば基準に対して有利な価格で買いたい運用者が、VWAP付近または下を待つという説明は考えられる。一方で、急いで必要数量を確保する運用者はVWAPより上でも買い得る。執行目的を持つ参加者が必ず基準線を守るわけではない。

「VWAPを意識した注文が反発に寄与した」は、本研究で確認が必要な仮説である。線の上で反発した事実だけでは、その注文目的は分からない。ラージのVWAPを見てmini・microの参加者まで同じ行動を取ったと判断しない。

## 4. 心理の説明を約定仮定へ転用しない

「支持帯に買い需要がある」と考えても、自分の買い指値が約定したとは限らない。帯の手前で反発すれば買えないし、同値で後ろに並んでいれば順番が来ない。逆に帯を大きく割るときだけ自分が約定する場合もある。

指標条件に続く価格の傾向と、その傾向を取引できるかを分けて調べる。スプレッド上限や数量条件は執行の条件であり、必ずしも将来方向を当てる情報ではない。[バックテストと改善](../05_バックテストと改善.md)

## 5. 再利用する検証の問い

| 識別子 | 問い | 必要な注意 |
| --- | --- | --- |
| P05 | 同じ入口条件でも、スプレッドや表示数量によって純損益が変わるか | 待ち行列・取消・観測時計を仮定と区別 |
| P05 | 出来高増と値幅拡大を組み合わせると、その後の順行に差があるか | 累積量を全行加算せず、時間帯の基準を合わせる |
| P06 | VWAP再接近後の反応は、無関係な基準線より安定しているか | 起算時点を先に決め、都合のよいアンカーを後から選ばない |
| P06 | 基準への接近と基準の移動のどちらで距離が縮むか | 「価格が平均へ戻る」だけを想定しない |

現在の原板から、全約定、受信間隔、執行主体の目的は復元できない。[データの確認結果](../../データと閲覧形式.md)に従い、再現できる範囲を明示する。
