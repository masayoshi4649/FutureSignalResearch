# 指数差と注文圧力の時間尺度

確認日：2026-11-17。[両指数の継続探索方針](../../議論/両指数の入口探索を継続し相違の原因を比較する.md)の調査資料。以下では公式仕様、外部研究、心理の仮説、本研究で必要な検証を分ける。

## 指数が違うと、同じ市場材料への反応が違う可能性がある

日経平均は225銘柄を使う株価平均型、TOPIXは浮動株時価総額加重型である。指数算出方法の違いは公式に確認できる。[日経平均の指数概要](https://indexes.nikkei.co.jp/nkave/index/profile?idx=nk225)、[JPX・TOPIX概要](https://www.jpx.co.jp/markets/indices/topix/index.html)。

ここから立てる仮説は、同じニュースでも影響の大きい銘柄群や指数への寄与が違い、トレンドの持続・押戻しの形・指数間の強弱が異なり得る、というもの。ただし、これだけで「日経は順張り、TOPIXは逆張り」と決めることはできない。今回のデータには各現物銘柄の寄与が揃っていないため、構成銘柄起因という説明は未確認である。

まず同じ足・指標・値幅の正規化・約定方式を使い、それでも同じ局面の条件付き成績が違うかを見る。局面の出現割合が違うだけなら、別の売買原理より局面の配分を変える方が説明に合う場合がある。共通対照の結果が出る前に市場の性格を断定しない。

## 強い注文圧力でも、予測できる時間幅は同じではない

TakahashiのS&P500 E-mini先物の研究は、1秒系列を15分区間ごとに分析し、経済指標発表や日中の流動性で価格と注文フローの関係が変わることを報告した。推定したショックの応答は非常に短い。[Returns and Order Flow Imbalances, v4](https://arxiv.org/abs/2508.06788v4)（2025、プレプリント）。

Hu・ZhangのCSI300指数先物の研究も、注文フロー不均衡の記憶や予測との関係が、時間幅や局面によって異なると報告している。[Stochastic Price Dynamics in Response to Order Flow Imbalance, v1](https://arxiv.org/abs/2505.17388v1)（2025、プレプリント）。これはモデルによる分析であり、今回の日本先物で同じ売買利益が得られる証拠ではない。

研究への含意は、一瞬の方向一致を60分保持の優位へそのまま拡大しないこと。短い圧力は取得位置の確認に使い、背景の持続、価格水準の維持、複数時点の量を別に測る。逆に長期の方向一致だけで、その瞬間の不利な取得を許してよいとも限らない。

## トレンド研究の心理説明も時間幅を限定する

Moskowitz・Ooi・Pedersenは58の先物等で月単位の自己時系列モメンタムを調べ、初期の過小反応と後の過剰反応という説明と整合する結果を報告している。扱う持続は主として1～12か月である。[Time series momentum](https://w4.stern.nyu.edu/facdir/lpederse/papers/TimeSeriesMomentum.pdf)（2012）。

この説明は、情報への反応が段階的なら方向が続き得るという仮説の根拠になる。しかし日中の5/15/30分足、IFDの幅、費用後勝率へ直接移植できない。月次のトレンド実証を、短時間の全ての順張りが高確率で勝つ根拠にしない。

## 次の検証で記録するもの

|判断の問い|当時観測での候補|別の説明と注意|
|---|---|---|
|元方向の圧力が続いているか|異なる公開足でのDI優位・EMAの並びと拡散、価格進行、相対量の持続|同じ足を複数回数えない。価格由来の圧力は注文フローの直接観測ではない|
|反対側への変化が受け入れられたか|固定水準の反対側を一定実時間維持、途中の戻り、次の観測でも動力と量が同方向|一時的な買い戻し・利益確定だけの可能性を残す|
|市場の違いか取得の違いか|共通条件、ATR比、費用前後、同じ遅延とBBO代用、同じ可用性の場|スプレッド、欠測、原板更新の差でも異なる結果になる|

現データの価格時計はCurrentPriceTimeで、独立した受信時刻はない。累積出来高差分や板スナップショットから完全な注文フロー、取消、吸収、参加者の意図を復元したとは言わない。これらの観測候補の有効性は、金融計算前に条件を固定した試行で別に確かめる。
