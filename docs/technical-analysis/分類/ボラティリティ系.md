# ボラティリティ系：動く大きさを測る

調査日：2026-10-30。[分類の目次](README.md)

## 1. 何を知るための分類か

ボラティリティは、価格の変動の大きさを表す。上昇か下落かという向きと区別して、「普段はどれほど振れるか」「最近の値幅が広がっているか」を知るために使う。

同じ20の上昇でも、小さく動く市場では大きな変化かもしれず、普段から100動く市場では小さな変化かもしれない。市場の変動幅に照らして、保護価格や数量を考えるための尺度になる。これは本教科書の説明例であり、将来の値幅の上限を示さない。

## 2. 主な指標と、測っているものの違い

| 代表例 | 実際に測るもの | 注意点 |
| --- | --- | --- |
| [ATR](../指標/ATR.md) | 前終値との隔たりも含めたTRの平滑平均 | 価格と同じ単位。方向は分からない |
| 価格の標準偏差 | 選んだ窓の価格が平均の周りにどれほど散らばるか | 値幅やリターンの標準偏差と同じではない |
| [BBの帯幅](../指標/ボリンジャーバンド.md) | 平均に標準偏差を加減した帯の広さ | 中心線で割る幅の比率と、価格単位の幅を区別 |
| リターンの実現変動率等 | 観測された価格変化率の散らばり | 足、窓、取引休止、年率化の仕様が必要 |

ATRの公式解説は、方向を示さず変動の大きさを測る指標として説明している。BBについても、中心線・相対価格位置と幅の分析を分けて読む。[Fidelity・ATR](https://www.fidelity.com/learning-center/trading-investing/technical-analysis/technical-indicator-guide/atr)、[ボリンジャー本人の使用規則](https://www.bollingerbands.com/bollinger-band-rules)

## 3. トレンドやモメンタムとの違い

大きく上へ進むときも、大きく下へ進むときも、激しく往復するときも、変動が大きくなり得る。「高ボラティリティ＝上昇」「低ボラティリティ＝レンジ」とは決まらない。穏やかな一方向の動きも、狭い往復もあり得る。

また、価格水準の標準偏差は一方向に値が進むことでも大きくなる。その値を、方向を取り除いた純粋な不確実性の大きさと断定しない。どの変数の散らばりかを記録する。

## 4. 一般的な使い道

| 役割 | 考え方 | 検証が必要な点 |
| --- | --- | --- |
| 保護幅 | 普段の変動に対して狭すぎない値幅を考える | ATR何倍が適切か、急変時の滑り |
| 数量 | 許容する円損失に対して枚数を調整する | 倍率・呼値・費用、損失予算が上限保証でないこと |
| 環境 | 帯幅の収縮・拡大を区別する | 収縮後の方向は別の条件で判断 |
| 追尾決済 | 高安から変動幅を差し引いた線を使う | 更新時点、線を不利側へ広げるか、注文受付 |

これらは役割の整理であり、採用する倍数や値の水準を推奨するものではない。[ATRと追尾決済](../組み合わせ/ATRと追尾決済.md) / [決済とリスク管理](../04_決済とリスク管理.md)

## 5. 心理として説明するときの限界

急な値幅拡大を、驚き、損切りの集中、見通しの対立などで説明することはできる。一方、気配の薄さやヘッジ注文だけでも値幅は変わり得る。ATRや標準偏差に参加者の恐怖そのものは入力されていない。

ボラティリティ指標を「恐怖の強さ」へ一律に翻訳しない。オプションから算出する予想変動率を扱う場合も、今回の価格履歴によるATR等とは入力が違う。[市場心理の観測限界](../市場心理/README.md)
