# 種類ごとに何を知るために使うか

確認日：2026-10-30。[分類の目次](README.md) / [個別指標との対応](指標と戦略の対応.md)

テクニカル分析の種類を、**答えたい問い → 観測・計算する情報 → 判断への使い方**で整理する。売買用途は一般的な使い方を踏まえた研究上の候補であり、NK225・TOPIX先物で収益性を確認した規則ではない。

「分かること」は、指定した期間・時間足・入力の中で観測または計算できる状態を指す。そこから「この先も続く」「ここで反転する」と考える部分は仮説である。以下の種類は用途の整理であり、互いに重なる。

## 1. 基本四群は、それぞれ別の問いに答える

| 種類 | 知りたい問い | 観測・計算できること | 判断への使い方の候補 | 代表例 |
| --- | --- | --- | --- | --- |
| トレンド系 | **どちら向きに進んできたか。方向性はあるか** | 平均線の傾き・位置関係、高安の方向変化とその偏り | 買い・売りの方向を限定する、追随する環境を選ぶ、方向条件が崩れたら撤退する | 移動平均線、一目均衡表、DMI・ADX、SAR |
| モメンタム・オシレーター系 | **動き方が強まったか、弱まったか。どちら側へ偏っているか** | 短長期平均の差、上昇幅と下落幅の比、高安内の価格位置等 | 押し目からの回復や減速を捉える、入口・決済の発動条件にする | MACD、RSI、ROC、ストキャスティクス |
| ボラティリティ系 | **値動きはどれくらい大きいか。広がったか、縮んだか** | 過去の値幅、価格またはリターンの散らばり、帯幅の変化 | 保護幅・追尾距離・枚数を調整する、収縮・拡大の環境を分ける | ATR、標準偏差、ボリンジャーバンドの幅 |
| ボリューム系 | **どれだけ取引されたか。価格変化にどれほどの成立量を伴ったか** | 約定数量、平常時との数量比、価格変化と数量の対応 | 突破時の取引の活発さを確認する、価格だけの条件へ数量条件を加える | 出来高、相対出来高、OBV、MFI、VR |

四群という入口は[Fidelityの公式講義・15頁](https://www.fidelity.com/bin-public/060_www_fidelity_com/documents/learning-center/Transcript_Tech-analysis-ATP_v2.pdf)を参照する。個々の指標が何を測るかは、次節の資料で確認する。

### トレンド系：方向と方向性の強さを分けて知る

例えば「平均線が上向き」「価格が平均線より上」は、指定期間の上向きの状態を定義する材料になる。ただし、一時的に下がっても平均線が上向きのままのことはあり、足や期間を変えると結論も変わる。[Fidelity・移動平均線](https://www.fidelity.com/learning-center/trading-investing/technical-analysis/technical-indicator-guide/sma)

さらに、**方向と、その方向への偏りの強さは別の情報**である。DMIでは＋DIと－DIの関係から方向を読み、ADXで方向性の強さを見る。ADX上昇だけでは上昇相場か下落相場かを区別できない。[Fidelity・ADX](https://www.fidelity.com/viewpoints/active-investor/average-directional-index-ADX)

使い道の例は「上向きの条件を満たす間だけ買い候補を調べる」。それだけでは、今の価格が入りやすい位置か、次の値動きが上か、何円利益が出るかまでは分からない。[詳しい解説](トレンド系.md)

### モメンタム・オシレーター系：動き方の変化や偏りを知る

この群の「勢い」は一つの共通量ではない。同じような表示でも、指標ごとに知れる内容が違う。

| 知りたい内容 | 例 | 実際に見るもの |
| --- | --- | --- |
| 一定本数前からどれだけ変化したか | ROC | 期間の始点と終点の価格変化率。途中の経路や瞬間速度とは別 |
| 短期の動きと長期の動きの差は広がったか | MACD | 短期EMA－長期EMA。その値とシグナル線等の関係 |
| 上昇側と下落側の値幅はどちらへ偏ったか | RSI | 平滑化した上昇幅・下落幅から作る比率 |
| 直近の高値側・安値側のどこにいるか | ストキャスティクス | 一定期間の高安に対する終値の位置 |
| 過去の平均からどれだけ離れたか | 移動平均乖離率 | 指定した平均線と現在価格の相対距離 |

したがって「RSIが高い」と「上昇速度が速い」は同じではない。「買われすぎ」も反転確定の意味ではなく、強い方向性の中では高水準・低水準が続くことがある。[Fidelity・MACD](https://www.fidelity.com/learning-center/trading-investing/technical-analysis/technical-indicator-guide/macd)、[RSI](https://www.fidelity.com/learning-center/trading-investing/technical-analysis/technical-indicator-guide/rsi)、[ストキャスティクス](https://www.fidelity.com/learning-center/trading-investing/technical-analysis/technical-indicator-guide/fast-stochastic)

「勢いが強い」と記録するなら、ROCの変化率、MACDの平均差、RSIの値幅比率など、どの意味かを明記する。[Fidelity・ROC](https://www.fidelity.com/learning-center/trading-investing/technical-analysis/technical-indicator-guide/ROC)

使い道の例は「上向きの環境で、下落側への偏りから回復したら入口候補にする」「保有中に勢いの条件が崩れたら通常決済の候補にする」。オシレーターという表現だけでは、順張り・逆張りのどちらに使うかは決まらない。[詳しい解説](モメンタムとオシレーター.md)

### ボラティリティ系：値動きの大きさを知る

ATRは前足終値との隔たりを含む値幅を平均し、BB幅は帯の広がりを測る。どちらも最近の変動の状態を表すが、計算対象が違うため同じ値や同じ情報ではない。[Fidelity・ATR](https://www.fidelity.com/learning-center/trading-investing/technical-analysis/technical-indicator-guide/atr)、[BB幅](https://www.fidelity.com/learning-center/trading-investing/technical-analysis/technical-indicator-guide/bollinger-band-width)

使い道の例は「大きく動く環境では保護幅を広げ、同じ損失予算なら枚数を減らす」。保護幅の調整と枚数の調整は対で考える。また「収縮した後の突破を調べる」という環境条件にも使える。

ATR上昇から上昇方向は分からず、収縮から次の突破時刻も確定しない。過去の平均値幅は、次の足の上限、セッションの残り値幅、逆指値で確実に収まる最大損失ではない。[詳しい解説](ボラティリティ系.md)

また、小幅で一方向へ進む状態もあるため、低ボラティリティを横ばいと同一視しない。

### ボリューム系：成立した取引の活発さを知る

同じ価格上昇でも、約定数量が平常時より多いか少ないかを区別できる。OBV等では、数量を価格の上昇・下落に対応させて要約する。ただしOBVは足の終値変化でその足の出来高を加減する計算であり、買い主導約定を直接数えた値ではない。[Fidelity・OBV](https://www.fidelity.com/learning-center/trading-investing/technical-analysis/technical-indicator-guide/obv)

使い道の例は「高値突破のとき、同じ時間帯の平常時に対して数量も増えていたかを確認する」。時間帯や限月を揃えない比較では、日中・夜間の違いや乗換えの影響と混ざる。[詳しい解説](ボリューム系.md)

出来高が増えても、買い手の人数、新規の強気参加、損切りの量、将来の継続は特定できない。VWAPも数量を使うが、主に知るのは「数量加重の基準価格から見た現在位置」で、取引量の増加そのものではない。[VWAPの教科書](../指標/VWAP.md)

## 2. 四群以外は、位置・形・時間・市場の背景を補う

以下は分析方法や追加入力のまとまりであり、四群と重なる。例えば支持抵抗に移動平均線を使い、価格パターンに出来高を組み合わせることもある。

| 種類・観点 | 何を知るのに使うか | 判断への使い方の候補 | そこから確定できないこと | 根拠 |
| --- | --- | --- | --- | --- |
| 支持抵抗・価格位置 | **どこを判断の基準にするか**。過去高安、節目、平均線、VWAP等との距離や位置関係 | 入口を待つ価格帯、突破を判定する水準、目標・撤退条件を置く場所 | その価格に将来も注文が残ること、反発・突破の確実性 | [CME・支持抵抗](https://www.cmegroup.com/education/courses/technical-analysis/support-and-resistance) |
| ローソク足・価格パターン | **足の形と、複数足の高安・終値にどんな並びがあるか**。高安の切り上げ、収束、実体・ひげ等 | 継続・転換を調べる条件、入口の発動条件、形が崩れる撤退条件 | 足内の値動きの全経路、形に似ているだけでの未来予測、参加者の注文・動機 | [StockCharts・価格パターン](https://chartschool.stockcharts.com/table-of-contents/chart-analysis/chart-patterns) |
| 時間・周期・波動 | **いつ・何本経過したか、どんな順序や間隔で動いたか** | 時間帯別の条件、経過時間による撤退、周期仮説の検証 | 同じ周期の継続、次の転換時刻。時間帯統計と波動理論も同じ根拠ではない | [eスマート証券・一目の三理論](https://kabu.com/investment/guide/technical/05.html) |
| 市場内部・市場の広がり | **指数の動きが多数の銘柄に広がっているか**。騰落銘柄数、新高値・新安値数等 | 指数上昇・下落の広がりを環境条件にする、指数との不一致を調べる | 不一致からの反転時刻。一商品の先物価格だけでは算出できない | [StockCharts・ADライン](https://chartschool.stockcharts.com/table-of-contents/market-indicators/advance-decline-line) |
| 複数商品・市場間・相対分析 | **何と比べて強い・弱いか、どれほど一緒に動くか**。相対騰落、価格差、相関等 | NK225とTOPIXの相対状態を確認する、組み合わせ取引の仮説を立てる | 相関からの因果や先行関係、価格差の必然的な解消 | [StockCharts・市場間分析](https://chartschool.stockcharts.com/table-of-contents/market-analysis/intermarket-analysis) |
| センチメント | **調査回答・保有・オプション取引等にどんな偏りがあるか** | 極端な偏りを背景条件にする、追随・逆張りの仮説を比較する | 全参加者の心理、価格転換の時点。調査対象と取引目的の影響を受ける | [StockCharts・資料の種類](https://chartschool.stockcharts.com/table-of-contents/index-and-market-indicator-catalog/decisionpoint-sentiment-indicators)、[Cboe・取引目的による比率の歪み](https://www.cboe.com/insights/posts/how-early-exercise-order-flow-impacts-equity-option-put-call-ratios) |
| 板・流動性 | **今どの価格にどれだけ提示注文があり、どの気配で執行を検討できるか**。スプレッド、価格別数量、偏り | 注文方法・数量・価格の選択、約定費用の見積もり、執行を見送る条件 | 将来の板の維持、自分の約定・待ち順、取消や数量減少の理由 | [JPX・板](https://www.jpx.co.jp/glossary/a/13.html) |

時間帯による条件やNK225・TOPIXへの適用は、本研究でこれから検証する用途例である。出典がそのまま当該用途の利益を立証した意味ではない。

先物では、**市場の建玉残高（OI）**も別に見る価値がある。分かるのは未決済契約がどれだけ残り、増減したかであり、成立数量である出来高とも、未約定注文である板とも違う。OI増加だけから買い方向や新規買い手の強気を確定できない。[CME・建玉残高](https://www.cmegroup.com/education/lessons/open-interest)

## 3. 同時に起きても矛盾しない状態

| 同時に観測する状態の例 | 分けて理解する内容 |
| --- | --- |
| 平均線は上向きだが、正のMACDヒストグラムが0へ縮小 | 平均線で定義した方向と、平均差がシグナル線から離れる度合いは別。直ちに下落転換とは限らない |
| RSIは高いが、ATRは小さい | 上昇幅・下落幅の比が上昇側に偏っていても、絶対値幅は小さくなり得る |
| ADXが高く、価格は下落 | 方向性が強いことと上昇方向であることは別 |
| ATRが大きいが、価格は上下に往復 | 値幅が大きいことと、一方向に進むことは別 |
| 出来高は大きいが、価格はほぼ横ばい | 取引量が大きいことと、価格が大きく動くことは別。誰が何を吸収したかはこの二値だけで断定しない |
| 売り板が厚いが、表示数量が後に消える | 提示された注文の状態と、その後に成立した取引は別。取消等との識別には追加入力が要る |

これらは計算定義と観測対象の違いを示す説明例であり、今回データで発生頻度を測った結果ではない。

## 4. 自動売買では、問いを売買の役割へ割り当てる

本研究で再利用するなら、指標名を先に並べる前に、次の問いを決める。

| 売買の役割 | 答えたい問い | 関係する種類の例 |
| --- | --- | --- |
| 環境 | どの方向・状態で、この手法を使うか | トレンド、モメンタム、ボラティリティ、出来高、市場内部 |
| 位置 | どの価格帯まで待ち、どこから先は追わないか | 支持抵抗、MA・VWAPからの距離、高安内の位置 |
| 発動 | どの変化が起きたら注文を要求するか | モメンタムの回復、価格帯突破、価格パターン、数量変化 |
| 通常決済・保護 | 仮説が崩れたとする条件と、非常時の保護幅は何か | 方向・勢いの崩れ、価格構造、ATR、時間 |
| 数量・執行 | 何枚をどの注文で出すか。費用と執行条件は許容範囲か | ボラティリティ、損失予算、実行商品の板・呼値・費用 |
| 期限 | いつ新規を止め、いつ全返済・取消を終えるか | セッション時刻と注文管理。本研究では必須の運用条件 |

同じ種類が複数の役割を担うことも、一つの役割へ複数種類を使うこともできる。すべての種類を揃える必要はない。MA・MACD・RSIは異なる問いを立てられても、多くの場合同じ価格系列の加工であり、三つが一致したことを独立した三票と扱わない。

例えば「上向きの環境で、基準価格への接近を待ち、下落側の偏りからの回復で入る」という案なら、方向・位置・発動へそれぞれ役割がある。一方、「指標三つが買いだから入る」だけでは、何を確認して何を追加したかが曖昧になる。組み合わせの利益と追加情報の価値は、条件を固定した比較で確認する。[組み合わせの教科書](../組み合わせ/README.md)

## 5. 次の研究へ渡す記録

各手法の候補は、次の項目を[判断カード](../判断カードのひな形.md)へ記録する。

1. **知りたい問い**：例「直近の上昇幅・下落幅の偏りが回復したか」。
2. **測る値と入力**：指標、時間足、期間、平滑方式、数量等。
3. **分かる時点**：確定足、公表時刻、観測更新時刻等。未来の足で山谷を確定するなら、その後まで使わない。
4. **解釈・心理の仮説**：観測値からどういう説明を考えたか。実測と区別する。
5. **変える判断**：環境・位置・発動・決済・保護・数量・執行・期限のどれか。
6. **その値だけで分からないこと**：追加で必要な情報、成立条件、反例。
7. **追加する価値の比較**：同じ出口・費用・評価期間で、その条件の有無等を比較する。

現在の入力で使える範囲は[指標と戦略の対応・4節](指標と戦略の対応.md)を参照する。価格由来の計算、数量の完全性、実行商品の板、構成銘柄・OI・センチメント系列を区別する。今回の整理は共通知識の追加であり、新しい試行番号の採番や損益計算は行っていない。
