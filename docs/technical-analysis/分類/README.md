# テクニカル分析の分類

調査日：2026-10-30。[教科書の目次](../README.md) / [指標別の教科書](../指標/README.md)

テクニカル分析を大きな系統に分けて理解する考え方は有用である。ただし「トレンド」「オシレーター」「ボリューム」は、測る性質・表現・入力という異なる観点を含む。資料やツールで所属が違うので、一つの指標を一つの箱へ永久に固定するより、**何を知るための指標か**を中心に整理すると使いやすい。

用途から読むなら[種類ごとに何を知るために使うか](種類ごとに何を知るために使うか.md)を参照する。方向・動き方・値幅・成立量の違い、位置・形・時間・市場の背景、売買のどの判断へ使うかを対応させた。

## 1. まず押さえる四つの指標群

Fidelityの教育講義では、トレンド、モメンタム、ボリューム、ボラティリティの四群を挙げている。本教科書でも入口に採用する。これはすべての分析を漏れなく分ける統一規格ではない。[公式講義資料・15頁](https://www.fidelity.com/bin-public/060_www_fidelity_com/documents/learning-center/Transcript_Tech-analysis-ATP_v2.pdf)

| 群 | 主に知りたいこと | 代表例 | 見る場面の例 | それだけでは分からないこと |
| --- | --- | --- | --- | --- |
| [トレンド系](トレンド系.md) | どちらへ進んでいるか、方向性が続いているか | MA、一目、DMI/ADX、SAR | 方向の限定、追随する環境、方向条件の崩れ | 次の入口の適正価格、今後の継続保証 |
| [モメンタム・オシレーター系](モメンタムとオシレーター.md) | 動きの勢い、上昇下落の偏り、相対的な位置 | MACD、RSI、ストキャス、ROC、乖離率 | 勢いの変化、押し目からの回復、過度な偏り | 偏りがいつ解消するか、反転の確実性 |
| [ボラティリティ系](ボラティリティ系.md) | どれほど動くか、変動が拡大・縮小しているか | ATR、標準偏差、BBの幅 | 損切り幅、枚数、収縮・拡大の環境判定 | 上昇・下落の方向 |
| [ボリューム系](ボリューム系.md) | どれほど取引されたか、価格変化と数量がどう関係するか | 出来高、相対出来高、OBV、MFI、VR | 取引の活発さ、価格の動きへの数量面の確認 | 買い手の人数、注文者の動機、約定の保証 |

「モメンタム」と「オシレーター」は厳密な同義語ではない。上表では入門の案内として同じ行に置いたが、勢いを測る目的と、中心線・帯を参照する指標の形を分けて読む。乖離率やストキャスも、速度そのものを測るわけではない。

## 2. オシレーターはトレンドの反対ではない

日本の入門資料では、MAなどをトレンド系、RSI・ストキャスなどをオシレーター系として対比することが多い。一方、MACDはマネックス証券の一覧ではトレンド分析に入り、SBI証券の解説ではオシレーター系に置かれる。[マネックス証券](https://info.monex.co.jp/technical-analysis/indicators/)、[SBI証券](https://www.sbisec.co.jp/ETGate/WPLETmgR001Control?OutSide=on&getFlg=on&burl=search_op&cat1=op&cat2=guide&dir=guide&file=op_guide_08.html)

これは、MACDがトレンド追随に利用できる一方で、ゼロの上下を動く中心線型オシレーターでもあるため、分類の観点が異なると理解できる。RSIのような0〜100の固定範囲だけがオシレーターではなく、MACDには固定した上下限がない。[StockCharts・オシレーター入門](https://chartschool.stockcharts.com/table-of-contents/technical-indicators-and-overlays/introduction-to-technical-indicators-and-oscillators)

また、「オシレーターだから逆張り」「トレンド系だから入口も出口も順張り」とは決まらない。RSIの高水準継続を追随の確認に使う案も、MAへの接近を回帰目標にする案もある。指標の分類と売買戦略を分離する。

## 3. 数式指標だけがテクニカル分析ではない

| 分析のまとまり | 見る対象 | 例・注意 |
| --- | --- | --- |
| 価格位置・支持抵抗 | 基準や過去の価格帯との関係 | 前高安、節目、MA、VWAP。各指標群をまたぐ観点 |
| 価格形状・フォーメーション | 足や高安の並び | ローソク足、二番天井・底、三角持ち合い。形状を条件化する必要がある |
| 時間・サイクル | 周期、間隔、時刻による違い | 周期仮説、経過本数、時間帯。繰り返しは検証対象 |
| 市場内部・相対関係 | 多銘柄や別市場との関係 | 騰落数、騰落レシオ、相対強度。一本の先物価格以外の入力が必要 |
| センチメント | ポジションや調査等からみた偏り | 建玉関連、プット/コール比率等。心理の直接測定か代理尺度かを区別 |
| 板・流動性 | 未約定注文と取引の成立条件 | スプレッド、板数量、注文の取消・消費。約定出来高と別の情報 |

これは指標四群へ新しい同列の箱を継ぎ足す表ではなく、テクニカル分析を広く見渡すための補助地図である。価格位置と形状は分析方法、センチメント等は入力や解釈、板分析は執行も含む隣接領域で、相互に重なる。個別の根拠と境界は[価格形状とその他の分析](価格形状とその他の分析.md)を参照する。

## 4. 四つの観点で記録すると迷いにくい

| 観点 | 問い | MACDの例 | VWAPの例 |
| --- | --- | --- | --- |
| 測る性質 | 何を要約した値か | 短長期平均の差とその変化 | 選んだ期間の数量加重価格と現在の位置 |
| 入力 | 何のデータが必要か | 通常は価格 | 価格と約定数量 |
| 表現 | どの尺度・形で表示するか | ゼロ中心、固定上下限なし | 価格に重ねる基準線 |
| 戦略上の役割 | 何の判断へ使うか | 方向、入口、通常決済等 | 方向環境、位置、回帰目標、執行評価等 |

「価格に重ねるもの＝トレンド、別枠のもの＝オシレーター」という置き換えも厳密ではない。ATRやADX等の別枠表示にも、変動幅・方向偏りの強さを測るものがある。

既存12指標と先物データの対応は[指標と戦略の対応](指標と戦略の対応.md)へまとめた。BBは中心線・上下帯・帯幅で異なる性質を読み、VWAPは数量を入力しても取引量の増加そのものを測る指標ではない。

## 5. 資料ごとの分類をどう扱うか

| 資料 | 確認できた整理 | 本教科書での使い方 |
| --- | --- | --- |
| [Fidelity・公式講義15頁](https://www.fidelity.com/bin-public/060_www_fidelity_com/documents/learning-center/Transcript_Tech-analysis-ATP_v2.pdf) | 方向・勢い・量・変動幅の四群 | 何を測るかを考える入門の軸 |
| [マネックス証券・一覧](https://info.monex.co.jp/technical-analysis/indicators/) | トレンド、オシレーター、フォーメーション | 数式指標以外もあることと、MACDの所属例 |
| [SBI証券・先物の分析解説](https://www.sbisec.co.jp/ETGate/WPLETmgR001Control?OutSide=on&getFlg=on&burl=search_op&cat1=op&cat2=guide&dir=guide&file=op_guide_08.html) | 主にトレンドとオシレーターで紹介 | 国内での二分法と所属差の例 |
| [StockCharts・指標とオーバーレイ](https://chartschool.stockcharts.com/table-of-contents/technical-indicators-and-overlays) | 価格へ重ねる表示と、その他の指標を分ける | 表示と測定目的を混ぜないための例 |
| [TA-Lib・関数一覧](https://ta-lib.org/functions/) | Momentum、Overlap、Volume、Volatility等 | ライブラリの関数分類と分析目的の分類を同一視しない |
| [大和証券・量的指標](https://www.daiwa.jp/seminar/technical/10/) | 出来高・売買代金をエネルギー系と紹介 | ボリューム系の別の呼び名。物理的エネルギーや統計的独立性を意味しない |

各資料の分類自体が、その指標の利益や将来予測力を証明するわけではない。本フォルダは今後の議論に使う見取り図を作るもので、新しい売買ルールや追加バックテストは実行していない。

## 6. 次の議論で先に決めること

1. 方向、勢い、変動幅、数量、価格位置のうち、何を知りたいのか。
2. その情報は既存指標に含まれるか、新しい入力が必要か。
3. 環境判定・入口・決済・保護・執行のどこで使うのか。
4. 同じ価格の加工を増やしただけでないか、追加効果をどう比べるか。

四群から一つずつ選べば優位になる、という規則にはしない。分類は組み合わせの目的を明確にする道具であり、成績は別に検証する。
