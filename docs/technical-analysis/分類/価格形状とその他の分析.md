## 1. 指標の役割だけでは分析全体を覆えない

指標四分類のほかに、価格形状、市場全体への参加、市場間の関係を見る方法がある。分類を増やす前に、次の三軸を分ける。

| 軸 | 問うこと | 例 |
| --- | --- | --- |
| 分析目的 | 何を知りたいか | 方向、反転候補、活発さ、参加の広がり、執行しやすさ |
| 入力 | 何を観測するか | 単一商品の価格、約定量、注文、構成銘柄群、関連商品、調査回答 |
| 手法・表現 | どう整理するか | ローソク足、支持抵抗、形状認識、比率、相関、周期、平滑化 |

ローソク足は四本値の表現であり、方向にも反転にも使える。

## 2. 指標四分類の外側の見取り図

| 方法群 | 目的と主な入力 | 本研究で扱える範囲・未確認点 |
| --- | --- | --- |
| 支持抵抗・価格構造 | 過去高安・節目・帯から反発や突破の候補を見る | 原板から計算可。帯幅・山谷の確認時刻・突破条件は要定義 |
| ローソク足・価格パターン | 実体・ひげ・複数足から継続や転換を見る | 価格から研究可。完成した形を過去へ遡って使わない |
| 波動・時間・周期 | 山谷の並び・経過本数・繰り返しを見る | 足と価格時計はある。起点・数え方は未固定。日柄を分足へ移す有効性は未検証 |
| 市場内部・市場の広がり | 値上がり・値下がり、新高値・新安値の銘柄数を見る | 一商品の先物原板だけでは作れない。銘柄群・構成変更・集計時刻の追加入力が必要 |
| センチメント | 調査回答、運用者の保有比率、オプション売買比率等を見る | 収録範囲・公表時刻は未確認。価格由来のPSYと投資家調査を区別 |
| 複数商品・複数市場 | 指数、現先、異限月の相対変化・価格差を見る | NK225・TOPIXの価格あり。同期・倍率・限月を調整し、現物・金利・配当等は別途確認 |

この表は手法と入力の補助表である。支持抵抗は移動平均でも作れ、形状には出来高も併用できる。排他的な分類ではない。

## 3. 出来高・建玉・板は別の観測

- **出来高**：成立した取引の量。一定区間の活動を表す。
- **建玉残高（OI）**：未決済契約の残高。出来高を足し上げた値ではない。
- **板**：価格別・売買別に提示された注文。表示数量は成立した取引量ではない。

価格と出来高から残建玉を一意には復元できず、板の増減も取消等を含み得る。需給の分析でも入力項目と集計・公表時刻を分ける〔資料7〕。

ADラインは値上がり・値下がり銘柄数の差の累積〔資料4〕。名前の似た価格・出来高系の蓄積分配指標とは異なる。

## 4. 解釈と自動売買の条件を分ける

心理の代理値は直接測定とは限らない。Cboeは非方向性取引によるプット・コール比率の歪みを説明している〔資料5〕。高い比率を「全員が弱気」と読み替えない。

相関は共同変動の記述、裁定は関連商品の価格差を利用する売買の組成である。相関だけで価格差の解消を保証しない。JPXの現先・限月間・ラージとmini等の裁定〔資料6〕も、別入力と執行条件を伴う戦略として扱う。

入力・利用可能時刻・機械的な定義を確認してから検証する。今回は追加試行なし。
