# トレンド系：方向と継続の状態を見る

確認日：2026-10-30。[分類の目次](README.md)

## 何を問う分類か

トレンド系は、「どちらの方向へ進んできたか」「その方向への偏りがどの程度あるか」を整理する分類である。方向と偏りの強さは分けて考える。Fidelityの教材はMA・MACD・ADXを例として挙げている。[公式教材4頁][資料1]

過去の方向が分かっても、これから継続する保証にはならない。また、何本分の価格を見るかによって、長めでは上向き、短めでは下向きという状態は両立する。

## 実際に測っているもの

| 代表指標 | 計算・観測の中心 | 分かることと限界 |
| --- | --- | --- |
| [移動平均線](../指標/移動平均線.md) | 選んだ価格の平均・平滑値 | 傾きや価格との位置。全保有者の平均建値ではない |
| [一目均衡表](../指標/一目均衡表.md) | 複数期間の高安の中間値と描画位置 | 方向・位置関係。先へ描く線も過去の入力から作る |
| [パラボリックSAR](../指標/パラボリックSAR.md) | トレンド内の極値へ追随する水準 | 継続・撤退の候補。線の値での約定を保証しない |
| [MACD](../指標/MACD.md) | 短期平均と長期平均の差、その平滑値との差 | 方向と勢いの変化。モメンタム・オシレーターとも重なる |
| [DMI・ADX](../指標/DMIとADX.md) | 高安の方向変化と、その偏りの強さ | DIで方向、ADXで強さ。ADXだけで上下を決めない |

楽天証券もDMIをオシレーター系として紹介しながら、トレンド用途を説明している。一つの指標が複数の問いに使われる例である。[楽天証券・DMI][資料2]

## 使い道と不得手

取引を考える方向の整理、継続する動きへの追随、元の方向が崩れたかの確認に使える。ただし「トレンド系」という分類名だけでは、新規注文や決済の条件は決まらない。

平均等で細かな上下をならすため、変化の確認は価格に遅れやすい。横ばいでは交差や方向の切替えが繰り返され、取引費用が増える場合がある。急変後に追随すると、方向は合っていても残る値幅が小さいこともある。反応を速くすれば、この問題がすべて解決するわけではない。

## 他の分類と重なるところ

**測る性質と表示は別。** 価格と同じ尺度で重ねる線はオーバーレイと呼ばれる。MAはその代表だが、MACDやADXは通常別枠で表示する。価格上に重ねる指標だけをトレンド系とする分け方は適切でない。[StockCharts・表示による区別][資料3]

**入力と用途も別。** [VWAP](../指標/VWAP.md)は価格と出来高から基準価格を作る一方、その上下を日中の方向判断へ用いる説明もある。「出来高を使う」と「トレンドを確認する」は両立する。[TradingView公式・VWAP][資料4]

**BBは方向だけの道具ではない。** [ボリンジャーバンド](../指標/ボリンジャーバンド.md)には平均線と、価格の散らばりによる帯がある。国内ではトレンド分析、Fidelityの教材ではボラティリティ系に分類される。どの部分・用途に注目するかで所属が変わる。[楽天証券・BB][資料5]

## 一般的な心理説明の限界

追随する買い、売り建玉の買戻し、ヘッジ等が同じ方向の注文を生む、という説明は考えられる。しかし、線の傾きや交差から注文目的や参加人数は分からない。「上昇の要約」と「上昇の原因の特定」を区別する。[市場心理の整理](../市場心理/README.md)

分類の段階では、まず何を測るかを理解し、売買への使い方は[指標と戦略の対応](指標と戦略の対応.md)へ進める。
