# モメンタムとオシレーター：勢い・偏りと表し方を分ける

確認日：2026-10-30。[分類の目次](README.md)

## 何を問う分類か

モメンタム系は、価格変化の勢いや偏りを整理する道具の集まりである。ただし全指標が同じ「速度」を測るわけではない。平均同士の差、上昇幅と下落幅の配分、直近の値幅内での位置など、実際の入力と計算は異なる。

国内の入門資料では、方向を見るトレンド系に対し、相場の強弱を見るオシレーター系と説明する。一方、海外資料では、測る性質のモメンタムと、中心線や目安帯に対する振動としてのオシレーターを区別している。[三菱UFJ eスマート証券の分類例][資料1]、[StockChartsの解説][資料2]

両者は重なるが、常に同義でも、トレンド系と相互排他的でもない。

## 固定上下限がある指標だけではない

StockChartsは、中心線型と目安帯型のオシレーターを説明する。**振動する基準があることと、値の絶対的な上限・下限があることは別**である。

| 形・代表例 | 実際に測るもの | 範囲の読み方 |
| --- | --- | --- |
| 中心線型：[MACD](../指標/MACD.md) | 短期平均と長期平均の差 | 0の上下で見る。固定の上限・下限はない |
| 範囲が定まる例：[RSI](../指標/RSI.md) | 平滑化した上昇幅と下落幅の配分 | 計算が定義できる場合は0〜100。判定用目安線はこの範囲とは別 |
| 範囲が定まる例：[ストキャスティクス](../指標/ストキャスティクス.md) | 直近高安に対する終値位置 | 通常の定義では0〜100。上端付近の継続も起こる |
| 目安帯型としてのCCI | 平均からの価格の離れ方を規格化 | ±100は判定の目安であり、絶対的な上限・下限ではない |

StockChartsはCCIを、目安帯を利用してもRSIのような0〜100の固定範囲には収まらない例として挙げている。中心線型・目安帯型を、そのまま「無界・有界」の二分法に置き換えない。[中心線型と目安帯型の説明][資料2]

## 別枠に表示する指標がすべてオシレーターではない

Fidelityの一覧は、測定上の種類と系列の分類を別列にする。MACDはトレンド／オシレーター、ADXはトレンド／指数として掲載される。別枠に描かれることだけを理由に、オシレーターと決めない。[Fidelity・種類と分類の一覧][資料3]

また、TA-LibはMACD・RSI・ADXをモメンタムの関数群へまとめる。これは全関数が同じ現象を測るという意味ではない。[TA-Lib公式関数一覧][資料4]

## 使い道と限界

勢いの改善・鈍化を確認する、平均からの偏りが緩んだかを見る、価格の高安と指標の高安が食い違うかを調べる、といった用途がある。トレンド方向に沿う調整後の回復にも、往復相場の反転候補にも使える。

したがって、**オシレーター系だから逆張り専用ではない**。高いRSIや上端付近のストキャスは、強い上昇の継続とも両立する。MACDの交差は平均関係の変化であり、売られ過ぎ・買われ過ぎの一定水準を直接示すものでもない。[TradingView公式・MACD][資料5]

期間や平滑化が違えば反応も変わる。指標の鈍化と価格の反転は同義ではなく、複数の価格由来指標が同じ方向でも独立な証拠が増えたとは限らない。

## 心理の解釈を測定値と混ぜない

「買われ過ぎ」という名前から、買い手の人数、資金の枯渇、次に下がる確率まで読み取ることはできない。例えばRSIは値幅の配分であり、参加者への質問結果ではない。利確や買戻しによる勢いの変化は説明候補として置き、注文目的の観測と区別する。[市場心理](../市場心理/README.md)

実際の売買への用途は、分類から自動的には決まらない。[指標と戦略の対応](指標と戦略の対応.md)で役割を分けて整理する。
