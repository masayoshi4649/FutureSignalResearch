# ボリューム系：取引量を価格と照らし合わせる

調査日：2026-10-30。[分類の目次](README.md)

## 1. 価格だけでは分からない、成立した量を見る

価格が上がったという事実に対し、「どれほどの量が取引されながら上がったか」を加えて調べる分類である。出来高・売買代金に注目する手法を、大和証券はエネルギー系・量的指標とも紹介している。ここでいうエネルギーは比喩であり、蓄積すれば必ず価格が動くという物理法則ではない。[大和証券・量的指標](https://www.daiwa.jp/seminar/technical/10/)

新しい入力が増えることと、統計的に独立した証拠が増えることは同じではない。価格と数量が互いに関係する可能性も含め、追加する価値を比較する。

## 2. 代表例と目的

| 代表例 | 入力と考え方 | 直接は分からないこと |
| --- | --- | --- |
| 出来高・相対出来高 | 区間の約定数量、過去や同時間帯との比 | 投資家の人数、売買の目的 |
| OBV | 終値の上昇・下落に応じて出来高を加減し累積 | 本当に買い手主導だった約定量、資金の純流入 |
| MFI | 典型価格と出来高を組み合わせ、価格変化の側へ量を分類 | 口座間の資金移動そのもの |
| VR | 上昇・下落等の区間へ出来高を分類して比を見る | 過熱が終わる時点、式違いによらない共通閾値 |
| [CMF](../指標/CMF.md) | 足内終値位置を数量で重み付けした期間平均 | 真の資金流入額、積極売買数量、前終値からのギャップ |
| VWAP | 数量で加重した平均価格 | 取引量の増減や残存建玉の平均建値 |

OBVとMFIは公式資料で価格と出来高を用いる指標として説明される。OBVは出来高を価格変化に応じて加減し、MFIは典型価格×出来高を典型価格の前足比に応じて正負へ分類する。これらの計算と、実際の入出金記録は区別する。[Fidelity・OBV](https://www.fidelity.com/learning-center/trading-investing/technical-analysis/technical-indicator-guide/obv)、[Fidelity・MFI](https://www.fidelity.com/learning-center/trading-investing/technical-analysis/technical-indicator-guide/mfi)

[VWAP](../指標/VWAP.md)は数量を使うため、入力の分類ではボリューム系に含められる。一方、役割は価格位置・基準価格・執行評価が中心で、「出来高が増えたか」を表す尺度ではない。

## 3. 先物で特に区別する三つの量

| 種類 | 何を数えるか | 状態 |
| --- | --- | --- |
| 出来高 | 指定区間で成立した契約数量 | 過去に成立した取引 |
| 建玉残高・OI | 未決済の契約残高 | その時点で残る契約 |
| 板数量 | 表示される売買注文の量 | まだ約定していない注文 |

出来高は売買の両側を持つ取引数量で、買い手が売り手より多い人数を意味しない。OIも一つの未決済契約に買いと売りが対応する残高で、方向そのものではない。CMEも出来高と未決済の残高を区別して説明している。[CME・建玉残高](https://www.cmegroup.com/education/lessons/open-interest)

板数量は取消・訂正でも変化する。板の減少をすべて約定とし、出来高へ加えることはできない。板・流動性の研究は関連するが、約定出来高の分析と同じ計算ではない。

## 4. 一般的な見方と心理の説明候補

価格帯の突破に出来高の増加を伴うか、価格とOBV等の推移が同方向かを見る使い方が紹介される。取引への関与が活発になったという説明の手がかりにはなるが、「新しい強気の投資家が参加した」とまでは確認できない。

新規売買、利益確定、損切り、ヘッジ、限月の乗換えでも数量は増える。大量の取引を薄い板で処理した場面と、厚い板で吸収された場面も区別する。量の多さだけから今後の上昇・下落を確定させない。[需給と流動性](../市場心理/需給と流動性.md)

## 5. 現在のデータへ使う前の確認

原板にはTradingVolume等があるが、累積の起算、欠落・リセット、既存CSVのvolume_completeの意味は確認事項が残る。累積値を各行で合計せず、差分を作る場合も境界を検査する。表示板のQtyを約定数量に代用しない。

ラージの出来高を分析へ使うことと、mini・microで同じ数量が取引できることは別である。比較対象は同じ指数・限月・時間帯を揃え、必要なデータが足りるかを先に判断する。[データの確認結果](../../データと閲覧形式.md) / [分類と戦略の対応](指標と戦略の対応.md)
