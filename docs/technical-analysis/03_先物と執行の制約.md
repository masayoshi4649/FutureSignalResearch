# 第3章 先物と執行の制約

確認日：2026-10-30。制度はJPXの現行一次資料を優先した。本章の売買シミュレーション上の取り決めは研究用の設計案であり、取引所・証券会社の仕様とは区別する。

## 1. 同じ指数でも取引する商品は別

ラージを観測して方向を判断し、mini・microで枚数を調整する構成を研究対象とする。限月・対象指数を一致させることに加え、商品ごとの倍率と呼値を分離する。

| 商品 | 本研究の原板 | 1価格単位・1枚の倍率 | 通常の立会呼値 | 1呼値・1枚の損益変動 |
| --- | --- | ---: | ---: | ---: |
| 日経225先物（ラージ） | `NK225` | 1,000円 | 10円 | 10,000円 |
| 日経225mini | ラージを判断に利用 | 100円 | 5円 | 500円 |
| 日経225マイクロ先物 | ラージを判断に利用 | 10円 | 5円 | 50円 |
| TOPIX先物（ラージ） | `TOPIX` | 10,000円 | 0.5ポイント | 5,000円 |
| ミニTOPIX先物 | ラージを判断に利用 | 1,000円 | 0.25ポイント | 250円 |

商品別の出典：[日経225先物](https://www.jpx.co.jp/derivatives/products/domestic/225futures/01.html)、[日経225mini](https://www.jpx.co.jp/derivatives/products/domestic/225mini/01.html)、[日経225マイクロ先物](https://www.jpx.co.jp/derivatives/products/domestic/225micro-futures/01.html)、[TOPIX先物](https://www.jpx.co.jp/derivatives/products/domestic/topix-futures/01.html)、[ミニTOPIX先物](https://www.jpx.co.jp/derivatives/products/domestic/mini-topix-futures/01.html)。すべて2026-10-30閲覧。

表の最終列は倍率と呼値からの計算。J-NET取引やストラテジー取引の刻みとは分ける。本研究では、確認できた上記商品だけを対象として定義し、TOPIXにもmicroがあるとは仮定しない。

「価格が基本的に同じ」は、方向予測を共有するための仮説として扱う。各商品には別の板・呼値・流動性があり、同時刻に同価格で約定できるとは限らない。小口商品の成績をラージの価格差に倍率だけ掛けて出す場合は、**ラージ価格を代理利用した仮定損益**と明記する。

例えば、ラージの終値が100円上昇していても、microの買付と返済の両時点で同じ価格差を取れることまでは示さない。実運用に近づける段階では、対象商品の同限月の最良気配・約定・受信時刻を照合する。

## 2. セッションの端までザラバではない

現行の対象商品の時間を次のように分ける。セッション終了時刻とザラバ終了時刻を別項目として持つ。

| 区分 | 日中 | 夜間 |
| --- | --- | --- |
| 開始の板寄せ | 08:45 | 17:00 |
| ザラバ | 08:45〜15:40 | 17:00〜翌05:55 |
| 終了の板寄せ | 15:45 | 翌06:00 |

出典：[JPX・立会時間](https://www.jpx.co.jp/derivatives/rules/trading-hours/index.html)（2026-10-30閲覧）。

本研究のセッション識別子は、`2026-09-21_Night` なら9月21日17:00〜9月22日06:00という開始日基準を用いる。取引所・証券会社の「取引日」とカレンダー上の開始日が同じとは限らないため、別フィールドにできる設計とする。Viewer も開始日基準でこの時間範囲を扱う。[Viewer の範囲定義](../../../SessionTradeViewer/config.go)

「終了時刻になったら成行で必ず返済」は再現可能な規則にならない。研究の初期案として、次をパラメータで指定する。

- **新規停止時刻**：以降は新しい建玉を作らない。
- **決済開始時刻**：通常シグナルの有無にかかわらず返済を開始する。
- **返済確認期限**：ザラバ終了より前に余裕を持って置き、残数量を再照合する。
- **セッション終端**：全建玉・全注文が0か監査する。

時刻の数値は今後検証して決める。板寄せを用いる戦略を試す場合は、ザラバの最良気配を用いた約定モデルと分け、板寄せ参加条件と未成立時の扱いまで規定する。取引停止・注文拒否・通信断で期限内に返済できなければ、0枚に見せる処理をせず、持ち越し条件に違反した試行として残す。

2024-11-05から現物市場の時間延伸に合わせてデリバティブの時間も変更された。古い解説資料の15:15終了・16:30開始等を、そのまま2026年のデータへ適用しない。過去期間を広げる場合は制度の適用日別に時間表を持つ。[JPX・2024年の変更告知](https://www.jpx.co.jp/corporate/news/news-releases/0060/20241009-01.html)（2026-10-30閲覧）

## 3. 売買判断、注文、約定を分ける

自動売買は、少なくとも次の順序で進む。

```text
観測を受信 → 足を確定 → 指標を更新 → 売買判断
→ 注文送信 → 受付確認 → 一部または全部の約定
→ 建玉・保護注文を照合 → 決済 → 終了監査
```

買いシグナルの時刻が、そのまま買い約定時刻になるわけではない。確定足の終値で判断した注文を同じ終値で必ず成立させると、価格形成後の情報で過去の約定を選ぶことになる。基本の検証では、判断後に利用できる観測と明示した遅延仮定を用いる。

既存原板は `CurrentPriceTime` を価格時計として持つが、受信時刻・全イベント連番は確認できていない。1秒内の板更新、Lastの更新がない区間、注文の往復遅延には不確実性が残る。検証で使う時計と行順、約定に使える最初の行を明記する。[原板の確認結果](../データと閲覧形式.md)

## 4. 成行・指値のモデル

JPX の取引は価格優先・時間優先が原則。ザラバと板寄せで価格の決まり方は異なる。[JPX・取引方法](https://www.jpx.co.jp/derivatives/rules/trading-methods/index.html)（2026-10-30閲覧）

### 成行または直ちに約定を狙う注文

通常の正常板に対する最小モデルでは、買いは売気配、売りは買気配を出発点とする。Last や Mid はその価格で売買できることを示さない。注文数量が最良気配数量を超える場合は、利用できる板段数に応じた消費や追加スリッページをモデル化する。表示数量全量が実際の注文到着まで残る保証はない。

JPXの成行注文は未執行数量を板に残せない。FAK は一部約定後の残数量を失効させ、FOK は直ちに全数量が成立しなければ失効する条件である。証券会社・APIで利用できる条件は別に確認する。[JPX・注文の種類等](https://www.jpx.co.jp/derivatives/rules/order-types/index.html)（2026-10-30閲覧）

したがって、返済注文を送っただけで建玉0へ進めず、約定数量と残数量を管理する。取消要求中にも約定が起こりうるため、取消受付と取消完了も区別する。

### 指値注文

指値に価格が触れたことと、待ち行列を経て自分が約定したことは別。板数量の減少は約定だけでなく取消でも起こる。現存のスナップショットから自分より前の注文数や全約定を復元できない場合、指値の正確な成立率は分からない。

研究では、少なくとも次を分けて比較する。

| 仮定 | 調べること | 限界 |
| --- | --- | --- |
| 接触で約定 | 楽観的な成績の感度 | 主結果に採用するには根拠が必要 |
| 指値を明確に通過した後のみ約定 | 成立判定を厳しくした感度 | 実際の待ち行列を再現したことにはならない |
| 到着後の気配と数量から判断 | データが支える範囲の執行 | 受信時刻・取消・対象商品不足が残る |
| 対象商品の約定・注文ログで照合 | 実運用に近い成立検証 | 追加データが必要 |

呼値への丸めは商品ごとに行い、売買に有利な丸めを選ばない。指値価格・逆指値の発動基準・発動後注文価格はそれぞれ別の値として管理する。

## 5. 板から研究できる特徴量

正常な最良買気配を `b`、最良売気配を `a`、最良買数量を `Qb`、最良売数量を `Qa` とすると、次の特徴量を定義できる。

```text
スプレッド = a − b
中央価格 = (a + b) / 2
最良気配数量の偏り = (Qb − Qa) / (Qb + Qa)
```

数量和が0または欠測なら偏りは不明とする。複数段版を作るなら採用する段数と重みを事前に固定する。これらは本研究で使える数学的定義であり、それ自体に収益性の主張はない。

板の厚みは表示時点の注文で、撤回されうる。「買い板が厚いから上がる」と即断せず、スプレッド・価格変化・時間帯と組み合わせて独立した追加効果を検証する。ラージの板偏りを micro の約定数量へ直接流用しない。

価格判断の改善と、約定モデルの楽観化は分けて評価する。損失区間を見て追加した板フィルターは、その区間では開発済みの条件となる。新しい期間で検証し、元の手法を基準として残す。

## 6. 限月、祝日、停止と費用

同じ指数でも異なる限月の価格差は存在する。ラージの観測限月と小口商品の執行限月を揃え、期近の切替規則を固定する。継ぎ足し系列で見つけたブレイクが、単なる限月切替の段差でないか確認する。セッション内で保有しなくても、前セッションから指標を継続する際にはロール調整が問題になる。

祝日取引日と祝日前後の注文有効期間は、通常のカレンダー判定だけで決めない。限月・取引最終日・SQ・証拠金等は各商品の制度を確認する。値幅制限、即時約定可能値幅、売買中断があるため、ストップの発動を決済完了と同一視しない。[JPX・注文の種類等](https://www.jpx.co.jp/derivatives/rules/order-types/index.html)、[JPX・日経225先物の制度](https://www.jpx.co.jp/derivatives/products/domestic/225futures/01.html)（2026-10-30閲覧）

損益計算では、商品倍率・実枚数・両側の手数料・売買スプレッド・滑りを分ける。手数料の最新料率や証拠金額はこの教科書に固定せず、試行時点の採用値と出典を記録する。証拠金額は建玉の損失上限ではない。

損切り、保護用逆指値、建玉上限、通信断対応、日中・夜間それぞれの全返済については、次章のリスク管理と一体で設計する。
