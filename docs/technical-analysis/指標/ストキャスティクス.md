## 1. 直感：最近の値幅の上側か、下側か

最近の高値と安値を物差しにして、いまの終値の位置を0～100で表す。0なら直近の最安値、100なら最高値である。値動きの上昇回数を数えるPSY、上昇幅と下落幅を比べるRSIとは、圧縮している情報が異なる。

「80」は買い手の80%が強気という意味でも、次に下落する確率が80%という意味でもない。現在の終値が、選んだ値幅の上側にあるという位置の尺度である。

## 2. 式と小さな検算

確定足 `t` を含む直近 `n` 本の最高値を `HH_n(t)`、最安値を `LL_n(t)` とする。02章と同じく、平滑化には単純平均を使う。

```text
生の%K_t = 100 × (C_t−LL_n(t)) / (HH_n(t)−LL_n(t))
Fast %K_t = 生の%K_t
Fast %D_t = SMA_m(生の%K)_t
Slow %K_t = Fast %D_t
Slow %D_t = SMA_d(Slow %K)_t
```

最高値110、最安値90、終値106なら、生の `%K=80`。生の%Kが順に20・50・80なら、3本平均のFast%Dは50になる。スローでは、この50をSlow%Kとして、さらに別の平均を取る。

`n・m・d` は正の整数で固定する。高安差が0なら生の%Kは未定義とし、0で代用して交差を作らない。欠損なしの `14・3・3` なら生の%Kは14本目、Slow%Kは16本目、Slow%Dは18本目から計算でき、両線の前足との交差は最速19本目となる。

「%K」の名称だけでは平滑化前後が分からない。楽天のノーマルの説明は%Dが5期間、TradingViewでは%K自体を平滑化する設定もある〔資料1・2〕。画面表示と照合する際は、三つの期間と平均方式を調べる。

## 3. 一般に紹介される判断

| 読み方 | 見る関係 | 注意 |
| --- | --- | --- |
| 高低の水準 | 20以下・80以上など | 楽天の指定記事は30・70。資料・設定で異なる |
| 交差 | 低い領域で%Kが%Dを上抜く等 | 上にある状態と、上抜いた瞬間を分ける |
| 領域からの復帰 | 20未満から20超へ戻る等 | 領域内で直ちに買う案とは別手法 |
| ダイバージェンス | 価格の安値更新に指標が追随しない等 | 山谷の対応と確認遅延が必要 |

これらは一般的な用法の整理であり、成功確率を与えるものではない〔資料1～3〕。下降中に低い値が続く場合、低水準を反転予告と決めつけない。

## 4. 市場心理として考えられる仮説

高値圏で終わる足が続く現象には、高い価格でも買う注文が続く、売り手が安値へ注文を下げない、といった説明を考えられる。上側から中央へ終値が移れば、その状態が弱まった可能性を調べられる。

ただし、指標は注文者を数えていない。買い手の積極化と売り手の後退は、同じ終値位置を作り得る。指標が下がったことから「投資家が怖がった」とは特定できない。資料の勢い・売買圧力という表現と、実際の心理測定を区別する。

## 5. 反例と不得手

高値更新が続く上昇では、100付近に長く滞在し得る。低い領域での小さな交差も、下落途中の一時的な変化かもしれない。平滑化は細かな交差を減らす一方、判断を遅らせる。

終値が動かなくても値は変わる。例えば高値110・安値90・終値100なら50だが、古い高値が窓から外れて最高値が102になれば、同じ終値100でも約83.3になる。これを終値の急上昇と解釈してはいけない。

## 6. 機械化で固定すること

交差は `K_(t−1)≤D_(t−1)` かつ `K_t>D_t` と定義する。どちらかの比較値が欠損なら判定しない。高低判定に使う線を生の%K・Slow%K・Slow%Dのいずれにするかも固定する。

ダイバージェンスは、確認済みの価格の谷に対応する指標値を比べるなどの規則が必要である。右側の足で谷を確認したなら、確認した時刻からしか使えない。日足の14期間を5分足へ移すと観測時間が変わり、有効性は別の検証になる。

| 項目 | 低い領域での上向き交差を調べる教材例 |

| 入力 | 確定5分足、`n=14,m=3,d=3`、上記のSlow%K・Slow%D |

| 比較 | 水準だけ、交差だけ、両方を使う案を同じ出口・費用で比較 |
