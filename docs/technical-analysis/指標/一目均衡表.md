## 1. 直感：複数期間の値幅の中心を比べる

短い期間と長い期間の高安の中間値を比べ、現在価格がどこにあるかを見る。二本の先行スパンに挟まれた領域を「雲」と呼ぶ。雲より上・下・中という位置関係が、方向や支持抵抗の候補として紹介される〔資料1・3〕。

高安の中間値は、全約定の平均でも、投資家の平均建値でもない。期間の最高値と最安値だけで中間値を作り、その間に何枚取引されたかは使わない。

## 2. 式と小さな検算

`HH_n(t)・LL_n(t)` は現在の確定足を含む直近n本の最高値・最安値。本章は02章と同じ配列表現で、描画のずらし幅を `q=26` 本と定義する。

```text
転換_t = (HH_9(t) + LL_9(t)) / 2
基準_t = (HH_26(t) + LL_26(t)) / 2
A_t = (転換_t + 基準_t) / 2
B_t = (HH_52(t) + LL_52(t)) / 2

先行スパン1の描画位置t+qの値 = A_t
先行スパン2の描画位置t+qの値 = B_t
遅行スパンの描画位置t−qの値 = C_t
```

9本の高安が112・100なら転換106、26本が120・90なら基準105、52本が130・80ならBは105。Aは105.5となり、A・Bを26本先へ描く。

100本目に計算した `A_100・B_100` は126本目の位置に描く。**100本目の価格と比較する雲は `A_74・B_74`** である。遅行線として74本目に描く `C_100` を、74本目の判断に使ってはいけない。値を知った時刻は100本目である〔資料2〕。

必要本数は転換9、基準とA26、B52。本章のqでは、現在位置の雲が二本とも揃うのは最速78本目となる。欠損があれば無効とする。26日を当日込みで数える慣行等により、ソフトの配列シフトが25の場合もあるため、表示と照合する。

## 3. 一般に紹介される判断

転換線が基準線を上抜く好転、価格の雲上抜け、遅行線が過去価格を上回る状態などが紹介される。複数を合わせた状態が三役好転であり、逆向きが三役逆転と呼ばれる〔資料1・3〕。

「遅行線が過去のローソク足を上回る」は、過去終値を越えるのか高値まで越えるのかで条件が変わる。雲の上抜けも、終値か足中の高値か、何本の確認を要するかを定義しなければ同じ手法にならない。

## 4. 市場心理として考えられる仮説

参加者が過去の価格帯を基準にするなら、その領域を越えた価格では含み損益や注文行動が変わる、という説明を考えられる。資料には、遅行線と過去価格を利益の出やすさへ結びつける解釈もある〔資料1〕。

ただし、その過去価格で買った人が現在も保有しているかは、指標から分からない。先物には買いと売りがあり、乗換え・返済もある。「価格が雲の上だから大半の投資家が含み益」とは言えない。雲の厚さも二つの計算値の差であり、板の注文量や実際の保有コストの厚みではない。

## 5. 反例と不得手

横ばいでは転換・基準の交差や雲の出入りが反復し、コストが積み上がる可能性がある。高安の更新がなくても、古い極値が窓から外れるだけで線が変化する。急変直後は、長期間の高安が残る線が現在の状態へ遅れる。

雲が未来へ描かれるのは表示上の移動であり、未来の価格を観測した結果ではない。雲のねじれもAとBの大小関係の変化であり、その位置で必ず反転する予言ではない。

## 6. 機械化で固定すること

期間・q・足幅に加え、計算時刻と描画位置を別の情報として保持する。日足の9・26・52を分足でも妥当とみなさない。セッションごとに初期化するなら、雲までの準備時間が長くなることを確認する。

雲上端は `max(A_(t−q),B_(t−q))`、下端は `min(...)` と定義できる。どちらのスパンが上端かを固定しない。遅行の確認を現在終値と過去高値の比較で実装するなら、`C_t>H_(t−q)` と書き、判定時刻を現在tにする。

## 7. 再利用用条件カード

| 項目 | 三つの上向き状態を調べる教材例 |
| --- | --- |
| 入力 | 確定5分足、9・26・52、配列シフトq=26 |
| 上向き状態 | `転換_t>基準_t`、`C_t>雲上端_t`、`C_t>H_(t−26)`が全成立 |
| 買い候補 | 前足・現在の全比較値が有効で、前足は上向き状態でなく、現在は上向き状態 |
| 通常決済候補 | 確定終値が基準線未満、または雲上端以下 |
| 無効 | 雲を含む必要本数不足、欠損、新規受付終了後 |
| 比較 | 転換・基準だけ、雲追加、過去高値比較追加を順に比較 |
| 別途必要 | 建玉・未約定管理、次の観測での執行、数量、保護注文、期限返済 |

このカードは前足の全比較値も有効であることを要求するため、雲が初めて揃う78本目ではなく、最速79本目から新規候補を判定できる。遅行比較に過去高値を選んだのは教材の定義であり、三役好転の唯一の実装ではない。複数条件も同じ価格から作るため、独立した三つの証拠とは数えない。
