# 移動平均線を理解する

調査・作成日：2026年10月30日。数値・条件カードは説明用の仮説であり、先物での有効性は未検証。

## 直感：細かな上下をならす

移動平均線は、直近の価格をまとめた基準線である。価格を毎回追うと上げ下げに目を奪われるが、平均すると、どの時間幅の価格が高くなっているかを比較しやすい。楽天証券は傾きと短長期線の交差を、TradingViewは過去に反応する指標としての性質を説明している。[楽天証券](https://www.rakuten-sec.co.jp/web/fop/special/technical_analysis/chart_guide01/)、[TradingView公式](https://www.tradingview.com/support/solutions/43000502589-moving-averages/)

線は設定した価格の平均であり、全参加者の平均建値ではない。終値だけの単純平均には各価格での売買数量、保有者、買い・売り建玉の分布が入っていない。

## 計算と数値例

`C_t` は確定足の終値、`n` は足の本数とする。

```text
SMA_n(t) = (C_t + … + C_(t−n+1)) / n
EMA_n(t) = α C_t + (1−α) EMA_n(t−1)
α = 2 / (n+1)
```

計算用の終値が `100, 101, 102, 103, 104` なら5本SMAは102。次が110なら最古の100を除いて104となる。初回EMAを102で初期化する仕様なら、次のEMAは `110/3 + 102×2/3 ≒ 104.67`。EMAは新しい値を大きく重み付けするが、古い情報も徐々に減衰しながら残る。

SMAには `SMA_n(t)−SMA_n(t−1)=(C_t−C_(t−n))/n` という関係がある。傾きの変化は新しい値だけでなく、計算窓から外れる古い値にも左右される。これは数式から分かる事実である。

## 一般に紹介される判断

| 見る対象 | 一般的な読み方 | 直接観測できる内容 |
| --- | --- | --- |
| 長めの線の上向き | 上昇方向の環境 | 選んだ平均値が前より高い |
| 価格が線より上 | 直近価格が強い | 価格がその平均を上回る |
| 短期線が長期線を上抜け | 買い候補のゴールデンクロス | 二つの過去平均の大小が逆転 |
| 上向きの線付近から反発 | 押し目候補 | 価格が基準付近へ来て再上昇 |

これらは解釈であり、次の上昇が式から導かれるわけではない。「線に近づいた」だけでは反発の定義にならず、距離と回復条件が必要になる。

## 市場心理として考えられる説明

**心理の推論。** 上昇後の一服で、買いそびれた参加者が基準線付近を待ち、既存の買い手が押し目と判断すれば買い需要が出るかもしれない。同じ線を参照する売買が重なれば反応が強まる可能性もある。

**検証上の区別。** 線付近で価格が戻った事実だけから、誰が何を考えたかは分からない。指数裁定・ヘッジ・材料への反応でも似た形は作られる。心理仮説を検討するなら、接近後の約定・板・時間帯を別に観測する。線を意識した参加者の存在や比率は、この計算だけでは立証できない。

## 崩れる場面

横ばいでは短期線が上下を往復し、交差のたびに売買すると費用が積み重なる。急な材料では価格が先に動き、線の変化を待つ間に値幅の多くが終わる場合もある。支持線と解釈した水準を割っても、「平均へ戻るはず」と保有を続ける根拠にはならない。

短い線ほど速く反応するが、速さだけで優劣は決まらない。遅い線は転換に遅れ、速い線は小さな往復を拾う。利益と費用を含む比較が必要になる。

## 機械化と先読みを防ぐ仕様

確定足の終値だけで更新し、交差を `短期_(t−1)≤長期_(t−1) かつ 短期_t>長期_t` と定義する。上にある状態を毎足の新規発注にしない。判断後の注文を同じ足の終値で必ず約定させない。

SMAは必要本数未満を欠損にする。EMAは初期値と助走期間を保存する。足の長さ、無約定足、欠測、セッション間の継続も固定する。5日線と5分足5本は別の対象を測っており、期間の数字だけを移植しない。

## 再利用する条件カード：方向を絞った交差

| 項目 | 買い側の研究用定義 |
| --- | --- |
| 役割 | 環境の絞込みと入口 |
| 環境 | 長期20本SMAが前足より高い。20本は仮置き |
| 発動 | 短期5本SMAが長期線を上抜け。建玉・未約定新規なし |
| 無効化 | 平均が欠損、新規停止時刻後、長期線の上向き条件が消失 |
| 出口候補 | 逆交差、固定した保護用逆指値、セッションの返済期限 |
| 重複情報 | MACDは平均同士の差、乖離率は価格と平均の距離。独立な確認とは数えない |
| 実装条件 | 確定足、交差の不等号、平均方式、初期化、発注遅延を固定 |

売り側を試す場合は対称条件を明文化する。複数の出口候補を後から選ばず、優先順位を試行開始前に決める。
