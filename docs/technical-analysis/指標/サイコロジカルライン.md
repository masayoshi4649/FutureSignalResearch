# サイコロジカルライン

確認日：2026-10-30。略称はPSY。数値例は検算用、条件カードは未検証の教材である。

## 1. 直感：値幅を捨てて、上昇した回数を数える

直近の終値比較で、上がった足が何割あったかを表す。大きな上昇も小さな上昇も1回である。値幅を使うRSIより単純な代わりに、どれだけ動いたかという情報を失う。

名称に「心理」が含まれていても、心理調査の集計ではない。PSY75は上昇した比較が75%という意味であり、強気の投資家が75%、買い注文が75%、次の下落確率が75%という意味ではない。

## 2. 式と小さな検算

本研究では02章と同じく、同値を上昇に含めない。

```text
上昇_i = 1（C_i > C_(i−1)）、それ以外は0
上昇回数_t = 直近n個の上昇_iの合計
PSY_n(t) = 100 × 上昇回数_t / n
```

`n=12` で9回上昇なら75、3回なら25。12回の比較には終値が13個必要である。計算に必要な終値が欠損していれば、比較を0に置き換えず、その窓を未定義とする。`n` は正の整数でなければならない。

同値の扱いは資料で異なる。三菱UFJ eスマート証券は、同値を「勝ち」とするケースも紹介している〔資料2〕。6回上昇・3回下落・3回同値なら、本研究の厳密上昇方式は50、同値を上昇側に含める方式は75となる。全て同値なら、それぞれ0と100である。どちらも実際の急落・急騰を意味しない。

## 3. 一般に紹介される判断

楽天は12期間と25・75付近を目安に、下落・上昇回数の偏りを見る使い方を紹介している〔資料1〕。低水準からの回復を買い候補にする方法も、低水準そのもので買う方法とは分けて考えられる。

| 観測 | 仮説の候補 | まだ分からないこと |
| --- | --- | --- |
| PSYが高い | 上昇の連続性、または反落の候補 | 継続と反転のどちらになるか |
| PSYが低い | 下落の連続性、または反発の候補 | 下げ止まった価格・時刻 |
| 低水準から回復 | 上昇回数が増え始めた | 値幅として上昇するか |

## 4. 市場心理として考えられる仮説

上昇が続くと、利益を確定したい人や、乗り遅れたくない人が増えるという説明は考えられる。前者なら反落、後者なら追随という異なる予測になる。PSYは、その二者の人数・建玉・注文を識別しない。

「何度も上がったから次は下がるはず」という考えには注意する。仮に各回が独立で上昇確率が常に1/2のモデルなら、直前の連騰だけで次の確率は変わらない。これは市場が独立だという主張ではなく、**過去の回数の偏りだけでは反転の根拠にならない**ことを示す例である。

## 5. 反例と不得手

1単位の上昇が9回、5単位の下落が3回なら、PSYは75でも合計変化はマイナス6となる。値幅を捨てた指標なので、計算上の矛盾ではない。

上昇・下落の順番も値に残らない。8回の上昇と4回の下落が混在した場合も、8連騰の後に4連落した場合も同じ値になり得る。資料2も経過の中身を見る必要を指摘している。

さらに12期間では値が約8.33刻みになる。「25以下」と「25未満」では対象の回数が変わる。価格が止まった薄商いでは同値処理の影響が大きく、PSYだけを「強い下落」と読むことはできない。

## 6. 機械化で固定すること

期間、足幅、同値処理、セッションをまたぐ比較、欠損処理を保存する。前の期間の終値を引き継ぐ場合、セッション最初の比較には休止中の価格変化も含まれる。セッション内だけで計算する方式とは別である。

百分率の丸めで判定を変えないよう、12期間の25以下を「上昇回数3以下」と表す方法も使える。前足と現在の有効値を比較し、閾値を越えた瞬間と、その領域にいる状態を分ける。日足の12日を、分足の12本でも有効と仮定しない。

## 7. 再利用用条件カード

| 項目 | 下方への偏りからの回復を調べる教材例 |
| --- | --- |
| 入力 | 確定5分足終値、12比較、同値は0 |
| 買い候補 | 前足の上昇回数が3以下、現在が4以上 |
| 通常決済候補 | 上昇回数が6以上に達する、または3以下へ再低下 |
| 無効 | 13終値不足、窓内欠損、新規受付終了後 |
| 比較 | PSYなしの基準、PSY追加、RSIによる別条件を同じ費用で比較 |
| 別途必要 | 建玉・未約定の管理、注文価格、数量、価格に基づく保護、期限返済 |

PSYは値幅を制限しないため、カードの決済条件を金額上の損失上限とみなさない。判断後の約定価格・費用を用いて、[検証方法](../05_バックテストと改善.md)に従う。
