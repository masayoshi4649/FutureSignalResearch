# MACDを理解する

調査・作成日：2026年10月30日。数値・条件カードは説明用で、NK225・TOPIX先物の有効性は未検証。

## 直感：速い平均と遅い平均の間隔を見る

MACDは、価格そのものより二つの平均の開き方に注目する。速く反応する線が遅い線を上回るか、その差が最近の差より大きくなったかを分けて見る。楽天証券は12・26・9期間の例、TradingViewはMACD・シグナル・ヒストグラムの三系列を説明している。[楽天証券](https://www.rakuten-sec.co.jp/web/fop/special/technical_analysis/chart_guide03/)、[TradingView公式](https://www.tradingview.com/support/solutions/43000502344-moving-average-convergence-divergence-macd-indicator/)

## 計算と数値例

`C_t` は確定足の終値。ここでは平均をすべてEMAとする。

```text
MACD_t = EMA_fast(C)_t − EMA_slow(C)_t
Signal_t = EMA_signal(MACD)_t
Histogram_t = MACD_t − Signal_t
EMA_n(X)_t = α X_t + (1−α) EMA_n(X)_(t−1)
α = 2 / (n+1)
```

初期化後に価格100が長く続き、二つのEMAが100、シグナルが0の状態を仮定する。計算を見やすくするため期間は3・5・3とする。一般的な12・26・9とは異なる説明用設定である。

| 時点 | 終値 | 短期EMA | 長期EMA | MACD | シグナル | ヒストグラム |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 初期 | 100 | 100 | 100 | 0 | 0 | 0 |
| 次 | 104 | 102 | 101.333 | 0.667 | 0.333 | 0.333 |
| さらに次 | 104 | 103 | 102.222 | 0.778 | 0.556 | 0.222 |

表示は小数第3位へ丸めた。最後の行では価格が変わらなくてもMACDは増え、ヒストグラムは縮む。これらは価格の上昇速度や加速度そのものではなく、平滑化した系列間の関係である。

## 一般に紹介される判断

| 観測 | 一般的な解釈 | 式から確実に言えること |
| --- | --- | --- |
| MACDが0より上 | 上向きの勢い | 短期平均が長期平均より高い |
| シグナル線を上抜け | 勢い改善の買い候補 | MACDがその平滑値を下から上へ横断 |
| 正のヒストグラムが縮小 | 上昇の勢いへの注意 | MACDとシグナルの正の差が縮小 |
| 価格が高値更新、MACDの山が低下 | ダイバージェンスによる警戒 | 指定した山同士の対応が異なる |

MACDが負の領域でシグナルを上抜ける場合もある。これは下落の弱まり候補で、上昇トレンドの確認とは別の条件である。

## 市場心理として考えられる説明

**心理の推論。** 最近の価格変化が過去より上向けば、追随する買い手が増えた、売り手の圧力が弱まった、売り建玉の買戻しが起きた、という説明が考えられる。交差を参照する注文が重なる可能性もある。

**観測との境界。** MACDには出来高、建玉、新規・返済の区別、参加者情報が入っていない。交差は新規資金流入や「買い手が売り手より多い」ことの証明にはならない。ヘッジ取引や一部の大口注文でも同じ価格列になり得る。心理説明は原因の候補であり、直接観測した事実とは分ける。

## 崩れる場面

狭い往復では交差が続き、確定を待つほど遅れて入る可能性がある。急騰後には価格が高いままでも平均間隔が落ち着き、決済サインが出ることがある。ダイバージェンスも反転時期を決めず、そのまま高値更新が続く場合を想定する。

MACDは価格差なので商品や価格水準が変われば値の尺度も変わる。NK225とTOPIXで同じ絶対閾値を使う根拠はなく、規格化する場合も別の仕様として検証する。

## 機械化・初期化・先読み

TradingView公式ではMACD側とシグナル側の平均をSMAまたはEMAから選べる。同じ「12・26・9」でも平均方式が違えば一致しない。入力価格、平均方式、初期値、出力開始、助走期間を記録する。

上抜けは `MACD_(t−1)≤Signal_(t−1) かつ MACD_t>Signal_t`。ヒストグラムの負から正への交差はこれと同じ事象なので、二つの確認として数えない。確定足で判断し、注文の時刻を分離する。

山谷を右側の足で確定するなら、その確定を待って初めてダイバージェンスを利用できる。山の位置へ過去にさかのぼってエントリー印を付けない。

## 再利用する条件カード：正の領域での改善

| 項目 | 買い側の研究用定義 |
| --- | --- |
| 役割 | 追随型手法の入口 |
| 環境 | MACDが0超。期間12・26・9、全平均EMAを仮置き |
| 発動 | シグナル線を上抜け。建玉・未約定新規なし |
| 無効化 | 初期化未完了、欠測、判定後に発注可能な正常板なし、新規停止時刻後 |
| 出口候補 | シグナル線の下抜け、保護用逆指値、セッション返済期限 |
| 重複情報 | 二本の移動平均との重複が大きい。ヒストグラム交差も同じ確認 |
| 実装条件 | 確定足、平均方式、交差不等号、初期化、発注遅延、出口優先順位を固定 |

このカードと「負の領域からの回復」を同じ手法へ混ぜず、それぞれの寄与を比較する。
