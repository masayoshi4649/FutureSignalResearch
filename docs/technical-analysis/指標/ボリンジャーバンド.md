## 1. 直感：最近の価格に対して、どこにいるか

移動平均の周囲に、価格の散らばりに応じた帯を描く。最近の価格がまとまっていれば狭く、散らばっていれば広くなる。上側の帯に近い価格は、選んだ過去期間に対して相対的に高い。企業価値に対して割高という意味ではない。

狭い帯は、過去の変動が小さかったことを示す。次に大きく動く方向や、動き始める時刻は示さない。帯の外に出た後に戻る仮説と、その方向へ進む仮説は区別する。

## 2. 式と小さな検算

確定終値を `C_t`、直近の本数を `n`、幅の係数を `k` とする。本章では02章に合わせ、終値と母標準偏差を使用する。

```text
中心_t = 直近n本の終値の単純平均
σ_t = sqrt(直近n本の (終値−中心_t)^2 の合計 / n)
上帯_t = 中心_t + k × σ_t
下帯_t = 中心_t − k × σ_t
%b_t = (C_t−下帯_t) / (上帯_t−下帯_t)
帯幅比_t = (上帯_t−下帯_t) / 中心_t
```

終値が `98, 99, 100, 101, 102` なら、`n=5` の中心は100、分散は2、標準偏差は約1.414。`k=2` の帯は約97.172～102.828となる。最後の終値102の `%b` は約0.854、帯幅比は約0.0566。百分率表示の帯幅なら約5.66%であり、0.0566%ではない。

`%b=0` は下帯、`1` は上帯で、外側なら0未満・1超にもなる。帯幅ゼロの `%b`、中心ゼロの帯幅比は未定義として新規判断を止める。期間不足も欠損とする。

楽天の記事は代表価格 `TP=(高値+安値+終値)/3` を用いる仕様であり、本章の終値入力とは別である〔資料1〕。標準偏差の分母を `n−1` にする設定も区別する。

## 3. 一般に紹介される判断

| 読み方 | 観測すること | 分けて検証する問い |
| --- | --- | --- |
| 回帰 | 下帯外から内側へ戻る | 中心へ向かう動きが費用後も残るか |
| 追随 | 上帯外へ終値が進む | 既存の上昇が継続するか |
| 収縮からの拡大 | 帯幅比が小さい状態から増える | 変動拡大の検出に役立つか。方向は別条件が必要か |

楽天は保ち合いでの逆張りを紹介する一方、作者は接触だけで売買せず、トレンド中の帯沿いの推移にも注意するよう説明している〔資料1・2〕。同じ上帯接触でも、相場状態によって反対の仮説になり得る。

**「±2σだから次の価格が95%で帯内へ戻る」とは言えない。** 正規分布の母数が既知の場合の区間確率と、短い過去窓から作った帯の将来予測は別である。作者も正規分布の確率をそのまま適用することを戒めている〔資料2〕。

## 4. 市場心理として考えられる仮説

過去の価格帯を参加者が基準にしていれば、帯からの乖離で利確や逆張りが増える、という回帰の説明を考えられる。他方、新情報による評価変更や損切り注文の連鎖なら、帯を越えて追随する動きも考えられる。

これは二つの**競合する心理仮説**である。終値と標準偏差だけから、どの参加者が何を考えたかは観測できない。帯沿いの上昇を「全員が強気」と断定しない。心理の真偽と、帯条件後の値動きの統計は別に扱う。

## 5. 反例と不得手

強い上昇では上帯接触が続き、接触のたびに売ると損失が重なる可能性がある。反対に、帯外へ出てもすぐ内側へ戻る局面では追随が失敗する。収縮後の最初の突破が、継続する方向とは限らない。

古い大きな値動きが計算窓から外れただけでも、帯幅は急に変わる。幅の変化を、参加者の不安が今突然変わった証拠とは扱わない。中心線も動くため、価格が上昇せず中心線が下がって「中心到達」になることもある。

## 6. 機械化で固定すること

入力価格、`n・k`、標準偏差の分母、帯幅の比率・百分率を保存する。日足で紹介された20・25等の期間を、そのまま分足の適正値とみなさない。確定足の帯と終値を比較し、発注は判定後の利用可能な板で評価する。

収縮を使うなら「過去100個の有効帯幅比の20%分位以下」などに定義できるが、分位点は判断前までの値から求める。評価期間全体の分位点を序盤へ適用しない。回帰と追随を切り替える場合も、切替条件を先に固定する。

## 7. 再利用用条件カード

| 項目 | 下帯からの復帰を調べる教材例 |
| --- | --- |
| 入力 | 確定5分足の終値、`n=20, k=2`、母標準偏差 |
| 買い候補 | `C_(t−1)<下帯_(t−1)`、`C_t≥下帯_t`、`C_t<中心_t` が全成立 |
| 通常決済候補 | 確定終値が中心以上、または再び下帯未満 |
| 無効 | 必要本数不足、欠損、帯幅ゼロ、新規受付終了後 |
| 比較 | 接触だけで入る案、内側への復帰を待つ案を同じ費用で比較 |
| 別途必要 | 建玉・未約定ゼロの確認、発注商品、数量、保護注文、期限返済 |

これは条件の部品であり、完成した運用手法ではない。[決済とリスク管理](../04_決済とリスク管理.md)を適用し、反対売買価格と費用を含めて検証する。
