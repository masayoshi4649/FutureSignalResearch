# CMF（チャイキン・マネー・フロー）

確認日：2026-11-05。数量系・足内終値位置の指標。一般的な説明、式の性質、本研究の仮説を区別する。

## 何を知るために使うか

各足の高安の中で終値が上側か下側かを測り、数量の大きい足ほど重くして、一定期間の偏りを読む。CMFが正なら量で重み付けした終値位置が足の中央より上、負なら下である。単に出来高が増えたか、前終値より上昇したかとは異なる。[Fidelityの公式教材](https://www.fidelity.com/learning-center/trading-investing/technical-analysis/technical-indicator-guide/cmf)は21日を代表期間とし、価格突破方向の確認等を紹介している（確認2026-11-05）。

作者側の教材も、価格と数量から計算するもので、機関投資家の注文フローを直接監視しているわけではないと説明している。本研究でもCMFを資金流入額、積極買い数量、投資家の人数と読み替えない。[Chaikin Analytics](https://help.chaikinanalytics.com/knowledge-center/chaikin-money-flow)（確認2026-11-05）

## 計算式と設定カード

```text
m_i = ((C_i−L_i)−(H_i−C_i))/(H_i−L_i)
    = (2C_i−H_i−L_i)/(H_i−L_i)
CMF_n(t) = Σ(i=t−n+1..t)(m_i*q_i) / Σ(i=t−n+1..t)q_i
```

H/L/Cは足の高値・安値・終値、qは足の数量。mはCLVと同じ式で、有効OHLC・H>Lなら−1〜1となる。CMFはその数量加重平均で、総q>0なら同じ範囲に入る。本研究は倍率1で保存する。百分率表示する資料やツールの±100とは100倍の違いがあり、表示倍率と閾値を揃える。

|固定する項目|確認内容|
|---|---|
|足と期間|日足21と3分21は異なる仮説。期間本数と足幅を別に記す|
|当足|確定公開した当足を含むか。形成中の足と混ぜない|
|数量|全約定量、累積差分の観測量等、何を合計したか|
|窓|場跨ぎ、欠枠、数量不完全、非公開足をどう扱うか|
|未定義|H=L、欠測q、総q=0の扱い|
|表示・比較|倍率、等号、精密値と表示丸め値の区別|

本研究の試行42では、当足含む同場21連続公開完全3分足の観測累積差分量を使う。全qの基準完全・有限非負、全足H>L、総q>0を必要とする。完全0qは有効だが総q=0は未定義。幅0は未定義として窓を切る。これらは研究の欠測規約であり、全ソフト共通のゼロ除算処理とは主張しない。価格の監視は数量不完全だけでは解除しない。

## 数値例と、他の量指標との違い

架空の二足で、共にH=110/L=100とする。一足目C=109/q=10ならm=0.8、二足目C=101/q=30ならm=−0.8。CMFは `(0.8*10−0.8*30)/40=−0.4`。両足の重みが等しければ0になる。大きい数量の足を重くする部分と、足内位置そのものの効果を分けて読める。

全qが等しい場合、CMFは複数足CLVの単純平均へ退化する。単足CLVとCMFを完全に独立した確認票にはしない。OBVやVRは前終値との変化方向で量を分類するが、CMFは当足高安内の終値位置で重みを付ける。CMFは累積ADLや、ADLの短長EMA差を取るChaikin Oscillatorとも異なる。

前C=120から、当足H=110/L=100/C=109へ下がった例でもmは正になる。CMFの式は前終値からのギャップを含まない。窓内の古い大数量足が落ちても値が変わるため、CMF上昇を当足の新しい買い増加だけへ帰属させない。これらは式からの反例であり、特定の相場で起きた損失を測ったものではない。

## 価格・勢いとどう組み合わせるか

|役割|使う情報|判断の候補|
|---|---|---|
|価格構造|先に認識した過去高安と、後続の再テスト終値|突破側を維持したか、旧範囲へ戻ったか|
|勢い|再テスト時点のMACDヒスト現前差|実際に入る方向の勢いと整合するか|
|量と位置の補助|同時点CMFの符号|数量加重の終値位置もその方向か|
|保護|新規要求時のATR、現在BBOの費用後含み益|固定した距離での追尾と注文が成立するか|

支持・抵抗の役割が突破後に入れ替わるという一般的な説明は[CMEの教材](https://www.cmegroup.com/education/courses/technical-analysis/support-and-resistance)にもある。ただし水準を厳密な一点として扱う本研究の規約、3分20本・6本寿命の収益を原典が証明したわけではない（確認2026-11-05）。

心理の仮説としては、既知の水準へ戻った際、終値位置と勢いと数量の配分が整えば、その側へ価格を保つ取引が続いている可能性を考える。ただし同じ価格・量はヘッジ、返済、薄商い等からも生じる。注文者の意図や吸収を確認した事実とはしない。

## 本研究の条件カードと限界

試行42では、最初の突破で水準を固定し、最初の対象足再テストで外側維持T、strict旧範囲内帰還R、その他待機を判定する。実方向のMACD差を要求する基準A0、CMF計算準備を追加するA1、実side×CMF>0を追加するA2を比較する。準備不成立や符号不一致を次の都合のよい足まで待たず、そのイベントを一回消費する。

売買は実side積の同じ式。価格鏡映H'=K−L/L'=K−H/C'=K−CでmとCMFは符号反転し、qと準備は不変となる。数値は各観測値をFractionへ写して比較し、表示丸めやepsilonを採否に使わない。全幅NPや欠枠を飛ばして窓を圧縮しない。

CMFが正でも将来上昇する確率はここから求められない。価格・MACD・CMFは互いに関係し、複数条件の一致が独立した証拠の数を意味しない。資料の一般用法と、この3分先物での効果を区別し、結果は[試行42](../../../study/00042_突破再テストと数量加重終値位置/README.md)へ記録する。カタログは[版4のV06](../../議論/手法と時間スケールの汎用表_版4.md)へ追加し、旧版を変更しない。
