# 確定スイングの突破

確認日2026-11-05。既に確認できた山谷の価格を水平水準にし、その後の終値が越える場面を入口候補にする。山谷の中心で入れたことにはせず、価格構造・DMI・Fastストキャスティクスを役割別に組み合わせる研究方法を整理する。

## 山谷の価格と、分かる時点を分ける

[MetaQuotesのFractals教材](https://www.metatrader5.com/en/terminal/help/indicators/bw_indicators/fractals)は、中心の高値/安値と左右2本からなる形を説明する。本研究は[試行15](../../../study/00015_RSIの山谷と価格構造/計画.md)の定義を再用し、左側2本は厳密、右側2本は同値を許す。同値の並びでは先頭側を選ぶ研究規約であり、原システムやAlligator併用を再現するものではない。

|極値|中心iの条件|初めて分かる時点|
|---|---|---|
|高値|H_iが左2本より高く、右2本以上|右2本目i+2の足が公開された時|
|安値|L_iが左2本より低く、右2本以下|同上|

中心iの価格をチャートへ描くことと、iで注文できることは異なる。中心・確認足・公開時計/原行を別に保存する。同じ中心が両極値なら、高値/安値の履歴へ両方記録する。

試行45では、現在足jの判断には**直前足pまでに確認できた極値だけ**を使う。jを右2本目として新しく確認する極値は、jの判断後に登録する。

```text
中心i → 右2本目で極値を確認 → 以後の足jで終値cross → 新規要求
```

最新確定高値R・最新確定安値Lに対して、買いはC_p≤R<C_j、売りはC_p≥L>C_jとする。等号に留まる現在終値は突破ではない。指値をR/Lへ置いた模型ではなく、j公開後の要求・最初正常BBOでの約定を評価する。

## 高安の構造を背景として使う

[Fidelityのトレンド教材](https://www.fidelity.com/learning-center/trading-investing/technical-analysis/basic-concepts-trend)は、高値と安値の切上げ/切下げで方向を整理する。ただし以下の「最新2組比較」は本研究の操作的定義で、交互に並ぶ波やダウ理論全体の再現ではない。

|前足時点の確定履歴|背景D|
|---|---:|
|最新高値>前高値、かつ最新安値>前安値|+1|
|最新高値<前高値、かつ最新安値<前安値|−1|
|同値・混在|0、待機|
|各側2点に足りない|未準備、0へ補完しない|

実際の突破方向をsとし、s=Dなら構造継続候補T、s=−Dなら構造破綻・転換候補Rと呼ぶ。下向き背景で確定戻り高値を上抜く買いはR、上向き背景で押し安値を下抜く売りもRになる。背景は確認済み履歴の記述であって、現在もその構造が維持されることや、将来の転換完了を保証しない。

同じ出口を使う同一新規について、T/Rの名称だけを変えても損益は変わらない。背景0/未準備での待機、価格発動、追加指標の選別を区別し、混合成績を「切替だけの効果」としない。

## 方向優勢と直近位置を合わせる

価格のcrossは発動、構造Dは背景、[DMI](DMIとADX.md)は高安変化の方向優勢、[Fastストキャス](ストキャスティクス.md)は直近範囲内の終値位置と平滑線の関係として使う。全て同じ価格の派生で、独立した三票ではない。

|段階|複合条件|比較する差|
|---|---|---|
|C0|価格cross＋準備済みの非零背景＋s×(+DI−−DI)>0|新しい複数手法の基準入口|
|C1|C0＋当場Fast14/3が準備済み|公開履歴・幅・平滑線の準備除外|
|C2|C1＋s×(K−Dfast)>0|同じ準備での直近位置の選別|

DMIは14差分のWilder平滑。最初の有効足を前HLCの種とし、14組のDM/TRの平均から初DIを作るため最速15足目となる。以後は(13×前平滑値+現値)/14というfloat演算を主模型の定義とする。平滑TR0はDI未定義、平滑状態を保持する。TR正かつ両DM0はDI0/0で準備済みだが、優勢条件は不成立。ADX20/25やADX低下を追加しない。

```text
K_j = 100*(C_j−LL14_j)/(HH14_j−LL14_j)
Dfast_j = (K_j + K_(j−1) + K_(j−2))/3
```

Fastは当足含む14本のrawKとSMA3。各足のH=Lは有効で、14本範囲の幅が0ならK未準備としK3窓だけを切る。公開連続窓の最速準備は16足。80/20、Kの上昇継続、交差の同時成立は要求しない。K>DfastはKが前足より上がったことと同義ではない。

価格を上抜いてもKの差は必ずしも正にならない。架空例としてR=100、前C=99、現H=200/L=90/C=101、14本の高安がこの範囲内なら現在K=10。前2Kが各30ならDfast=70/3、差は−40/3となる。上ヒゲや以前の高値等で、終値突破と範囲内の相対位置が食い違い得る。

## 取り直しと先読みを防ぐ規約

最初の適格crossは(方向,極値中心ID)ごとに一回消費する。指標・時間・構造未準備や保有のため不採用でも、後で条件が良くなった時へ取り直さない。価格が同じでも新しい極値IDなら別水準とし、古い有利な極値を探し直さない。

p/jは同場の隣接した公開完全3分足、j公開key>p公開key、j.end>p.confirmを要求する。後者が不成立ならcrossを判定・消費せず、履歴は進める。これは終値の端点比較であり、jの形成開始から全期間が水準公開後だった、という意味ではない。実際の最初の板上突破やヒゲtouchを再現したとはしない。

局所pivot・使用済みID・Fastは場替わり、契約変更、欠枠/不正/非公開で切る。番号・区間の飛越後に有効なmissing0当足があれば、新しい局所窓の種にできる。公開key後退/同keyや重複indexは入力拒否。DMI数値銀行の同限月carry・完全NP足の内部更新とは分ける。

## 心理の仮説と検証の限界

確認済みの押し安値/戻り高値を終値が越え、同方向の高安変化優勢と終値位置が伴うなら、従来の価格帯を受け入れる関係が変化した可能性を問える。ただし注文の集中、損切り、参加者の意図を直接測ったわけではない。Rは転換候補であり、次の250ptが確実に取れるという判断ではない。

[試行45](../../../study/00045_確定スイング突破と方向優勢/計画.md)では、新しい要求時刻・新規価格から125/250の先着を直接評価する。旧15の中心時刻、旧42のb/j、旧245入口のラベルを転用しない。純入口・仮約定・実単一建玉・利益回収・費用・品質は別分母とする。

利益追尾は固定33の現在費用後strict正起動を維持する。今回のmicro代理前提では現在返済BBOによる粗含み益円−122円>0で起動し、NK要求時ATR固定D・最低名目entry床・非緩和・セッション内完結を使う。名目床は費用後同値や遅延後の同値約定を保証しない。

DMIの正本値定義と独立生値を別に保存照合し、数値値だけの1e−10許容をDI優勢の符号・採否へ流用しない。Fastの差はFractionで計算し、表示丸めを採否に使わない。全66場は既使用の追加開発であり、支持・7割・費用条件の達成は実測するまで未確認である。
