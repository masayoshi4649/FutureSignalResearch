# CMFの変化と窓の入替え

確認日2026-11-05。[CMFの基本](CMF.md)に対する補足。数量加重の終値位置の水準と、その現前変化を区別し、機械判定に必要な窓・時点・欠測を整理する。旧教材と既存試行の固定条件は変更しない。

## 水準と変化は別の問い

CMFは高安内の終値位置を数量で重み付けした期間平均である。Fが正ならその加重位置は中央より上、ΔFが正なら前より上へ移ったことを示す。負のFが改善する場合も、正のFが低下する場合もある。価格の上昇・下落や真の注文フローは別に観測する。

[StockCharts公式教材](https://chartschool.stockcharts.com/table-of-contents/technical-indicators-and-overlays/technical-indicators/chaikin-money-flow-cmf)は水準・零線交差・価格との不一致を説明し、改善する負の値と正の値の区別、往復シグナルやギャップの注意を述べている。ただし以下の一足差と寄与分解は本研究の代数整理であり、その売買有効性を原典が証明したわけではない（確認2026-11-05）。

## 現前21期間には22本が必要

```text
m_i = (2C_i−H_i−L_i)/(H_i−L_i)
N_t = Σ(i=t−20..t)m_i*q_i
Q_t = Σ(i=t−20..t)q_i
F_t = N_t/Q_t
ΔF = F_t−F_(t−1)
```

現窓と前窓の和集合はt−21..tの22本。古い足o=t−21のqも必要で、現在21本だけから差を作らない。本研究では同場の公開完全3分足、全幅正、全q基準完全・有限非負、現前それぞれの総q正を必要とする。完全0qは有効。欠枠や数量不完全を飛ばして22本へ圧縮せず、古い正常値へfallbackしない。

現前は当場index−1と区間の隣接から特定し、両足の公開keyが現在の要求key以下であることを確認する。当足が公開されてから一回だけ判定し、後から改善する足へ時刻を取り直さない。

## 当足と、古い足が抜ける影響を分ける

前窓から最古oが抜け、当足tが入るので、

```text
N_t = N_prev + q_t*m_t − q_o*m_o
Q_t = Q_prev + q_t − q_o

ΔF = [q_t*(m_t−F_prev) − q_o*(m_o−F_prev)]/Q_t
I  = q_t*(m_t−F_prev)/Q_t
O  = −q_o*(m_o−F_prev)/Q_t
ΔF = I+O
```

Iは前CMFに対する当足の相対位置・量・分母の効果、Oは古い足の脱落の効果である。Iを新しい買い注文、Oを売り手の退出人数とは呼ばない。共通20本の総qが0でも現前のQが正ならこの式を使える。古い足を先に抜いた中間比は定義しなくてよい。

元H/L/C/qを各々Fractionへ写し、F現/前、差、I、Oを分数で保存する。差の符号は `N_t*Q_prev−N_prev*Q_t` と直接の分数差の両方で確認できる。表示floatを引いて0へ丸めたり、任意epsilonで採否を補正したりしない。

## 反例から読み方を決める

以下は人工の数学例であり、相場の収益ではない。

|例|前21本と当足|結果と読み方|
|---|---|---|
|脱落だけの改善|前q全1、最古m=−1、他20本m=0。当足m=0/q=0|F前=−1/21、F現=0、Δ=1/21、I=0、O=1/21。現在の方向付き量が増えなくても改善する|
|中立の当足|上と同じ前窓、当足m=0/q=1|I=1/441、O=20/441。Iが正でも当足mが正とは限らない|
|同じ位置の持続|現前の全mが1/2、各総qは正|量が変わってもF現=F前=1/2、Δ=0。差0から価格上昇の終了は推定できない|

前終値から下がっても当足の高安の上側で終わればmは正になり得る。CMFもΔFも、close-to-closeのギャップを直接含む式ではない。MACDや価格構造と組み合わせるときも、同じ価格の加工が重複する点を残す。

## 複数手法へ組み込む条件カード

試行43では固定42の価格登録・最初再テスト・T/R/WAIT・当時MACD差を保持する。T/Rが実際の方向を決め、実sideをdとする。

|案|条件|比較すること|
|---|---|---|
|D0|固定42A0の全純入口、識別子以外を保持|入口・時刻・出口が同じ完全対照|
|D1|D0かつ現前CMF21が共に準備済み|22本の価格/数量/幅・両総量の準備除外|
|D2|D1かつd×ΔF>0 strict|同じ準備での変化方向の選別|

現在水準dF>0、I>0、零線交差、後続確認待ちは同時に追加しない。I/Oと水準×変化の区分は診断へ留める。同じ現前準備へ揃える前の42A2全体との差を、水準対変化だけの効果としない。

心理の仮説としては、再テストで明示的に維持/帰還した価格に、その方向への量加重終値位置の変化が伴うかを問う。ただし改善の一部が窓落ちに由来し、観測量は真の全約定量でもない。注文者の意図や今後の継続確率を確認した事実とはしない。

売買は同じd積。価格をH'=K−L/L'=K−H/C'=K−Cへ鏡映するとm/F/Δ/I/Oは符号反転し、q・準備・dを掛けた採否は変わらない。逆向きCMFから自動反転せず、既存の価格分岐と待機を保持する。
