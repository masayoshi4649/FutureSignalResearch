# VWAP：観測した約定を、数量で重み付けした基準価格

資料閲覧日：2026-10-30。数値例と条件カードは説明・研究用で、損益実績ではない。

## 単純平均と何が違うか

100円で1枚、110円で9枚が売買されたとする。2つの価格を単純平均すると105円だが、数量を考慮した平均は109円になる。多く売買された価格へ重みを付けるのがVWAPである。

先物ツールCQGは、取引日またはセッションの出来高加重価格を説明し、集計開始点の設定も設けている。IBKRは執行価格を評価する比較基準としての用途も説明する。[CQG公式・先物VWAP](https://help.cqg.com/cqgic/25/Documents/volumeweightedaveragepricevwap.htm)、[IBKR公式・VWAP](https://www.interactivebrokers.com/campus/glossary-terms/volume-weighted-average-price-vwap/)

**VWAPは、現在保有している全参加者の平均建値ではない。** 同じ建玉が何度も売買された数量も含み、すでに返済した参加者や以前のセッションからの保有を識別していない。

## 厳密な式と、足から作る近似

集計の開始から現在までの各約定を `j`、価格を `p_j`、数量を `v_j` とする。

```text
約定ベースVWAP = Σ(p_j × v_j) / Σv_j

100円で1枚、110円で9枚なら
VWAP = (100×1 + 110×9) / 10 = 109円
```

次に90円で10枚売買されれば、累積値は `(1090+900)/20=99.5円` になる。新しい数量が、既存の累積数量に対してどれだけ大きいかで動き方が変わる。

1本の足について全約定が分からない場合、代表価格で近似できる。

```text
TP_t = (H_t + L_t + C_t) / 3
足近似VWAP = Σ(TP_t × V_t) / ΣV_t
```

TradingViewは典型価格と足出来高による構成、入力価格、開始点を説明している。これは個々の約定価格から作る値と必ず一致しない。足を1分から5分に変えると、代表価格による近似も変わりうる。[TradingView公式・VWAP](https://www.tradingview.com/support/solutions/43000502018-volume-weighted-average-price-vwap/)

累積の分子・分母を更新するため、セッション後半ほど過去の数量が多くなり、同じ新規出来高では線が動きにくくなる。固定本数の移動平均とはこの性質が異なる。

## 一般的な判断と心理・需給の仮説

価格がVWAPの上か下か、線の傾き、乖離後の復帰や再交差を、相場環境や売買の候補として使う解説がある。[TradingView・利用方法](https://www.tradingview.com/support/solutions/43000502018-volume-weighted-average-price-vwap/)

「その時間帯に多く取引された価格が比較基準になり、押し戻された際に注文が出る」「VWAPを執行評価に使う参加者が意識する」という説明は考えられる。IBKRの資料は比較基準としての利用を支えるが、**特定の先物でその価格に注文が集中することまでは立証しない**。支持・抵抗として働くという部分は本研究の検証対象である。

上にいる買い参加者が全員含み益、下にいる売り参加者が全員含み益、とは言えない。観測外の取得価格、ヘッジ、限月間取引、売買済みの玉がある。VWAPより高いことが、その商品を適正価値より割高と証明するわけでもない。[市場心理の扱い](../市場心理/README.md)

## 反例を理解する

- 強い上昇ではVWAPから離れたまま進み、線へ戻るまで待つ入口が生じないことがある。
- 横ばいでは再交差が多発し、スプレッドと手数料で損なわれうる。
- 寄付きの大量出来高が累積を支配すると、後の需給変化へ反応しにくい。
- セッション途中からの収録では、見かけのVWAPが本来の開始点からの値と異なる。

VWAPを決済目標にした平均回帰と、VWAPより上だけ買う追随は異なる仮説である。後から値動きを見て切り替えず、環境条件を先に固定する。[組み合わせ](../組み合わせ/README.md)

## 起算点・欠損・実データが核心になる

本研究の基本候補はデイ08:45、ナイト17:00で別リセットとする。ツールの「Session」がこの区分を指すとは限らない。取引日通算、暦日、各セッション、特定イベント開始では別の値になる。[CQG・開始点の設定](https://help.cqg.com/cqgic/25/Documents/volumeweightedaveragepricevwap.htm)

イベントを起点にするアンカー方式では、起点をいつ認識できたかを記録する。後から最安値を選んで起点を置き、その時点から利用できたとする検証は先読みになる。現在時点で過去の極値を起点に決めることと、過去時点で売買できたことは分ける。

原板には `VWAP`、`TradingVolume` があるが、今回、集計起点・リセット規則を確認できていない。提供値をそのまま「デイ開始からのVWAP」とは呼ばない。累積数量を全行で加算せず、差分・重複・リセット・欠測を検査する。差分数量と直近のLastだけでは、その間のすべての約定代金は復元できない。

CSVの `volume_complete=false` は出来高研究で確認すべき旗である。生成仕様が未確認の段階では、足近似を正式な約定VWAPとして扱わない。原板の板数量は約定数量の代わりにならない。ラージの集計値はmini・microの平均価格でもない。[原板とCSVの確認結果](../../データと閲覧形式.md)

数量合計0なら欠損にする。途中欠測後に再開する場合、欠けた数量・代金を復元できなければ完全な累積値に戻ったとは言えない。「欠測ありの参考値」と「完全な起点からの値」を区別する。確定足の近似を使う売買は、足が完成してから判断する。
