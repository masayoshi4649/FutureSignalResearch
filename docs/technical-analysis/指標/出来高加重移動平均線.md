# 出来高加重移動平均線（VWMA）

識別子：I16。確認日：2026-11-12。直近の有限区間について、数量の多い足の価格を重くした基準を測る。**VWMA20を1分HLC3・固定20分で作る案は未採用**。NK225での入口成立数・先着率・損益はまだ検証していない。

## 一般的な定義とVWAPとの違い

TradingViewは、SMAが各足の終値を等しく扱うのに対し、VWMAは足の数量で重みを変えると説明する。NinjaTraderも非累積型として区別し、periodを使用する足の本数として指定する。[TradingView：VWMA](https://www.tradingview.com/support/solutions/43000592293-volume-weighted-moving-average-vwma/)、[NinjaTrader：VWMA](https://static.ninjatrader.com/support/helpGuides/nt8/moving_average_-_volume_weight.htm)

```text
VWMA_n = Σ(P_i × V_i) / ΣV_i       # 選んだ直近n足だけ
HLC3_i = (High_i + Low_i + Close_i) / 3
```

|測定|重みと対象|区別する意味|
|---|---|---|
|SMA|各足を等加重|選んだ価格系列の平均|
|EMA|直近を重くする指数平滑|数量による加重ではない|
|VWMA|有限窓内の足量で加重|古い足が窓から外れる局所基準|
|セッションVWAP|場の起点から累積して量加重|起点と以降の全入力が必要な場内基準|

TradingViewのVWAPはanchorで累積区間を選び、代表価格の既定例にHLC3を使う。VWMAの同社説明はCloseを例示し、NinjaTraderは価格入力系列を指定できる。したがって**HLC3のVWMAは入力価格を明示した別設定**であり、公式VWMAの全実装が同じHLC3を使うとはしない。[TradingView：VWAP](https://www.tradingview.com/support/solutions/43000502018-volume-weighted-average-price-vwap/)、[NinjaTrader：入力系列](https://static.ninjatrader.com/support/helpGuides/nt8/moving_average_-_volume_weight.htm)

足代表価格×足量は約定ごとの価格×数量と同一ではない。HLC3へ替えても正確な全約定VWAPにはならず、VWMAをセッションVWAPへ改名しない。

## 本研究で検討する固定20分窓

最新の対象1分の市場EndをTとし、`[T−20分,T)`の**連続20個の1分区間**を使う。各区間の確定OHLC、数量の既知性・品質、公表/実配送Stampを確認してから現在で使用する。5分足20本、取得できた20行、正数量の足20本とは異なる。I16の**1分列**へ記録し、20分は計算窓の設定へ書く。

- 1分が欠けても古い観測を足して20本へ圧縮しない。それは20分より長い別窓となる。前値・0量で欠分を埋めない。
- 場/限月をまたがず、20区間の必要入力が揃うまでは未知。開始の不完全足も、その足が窓内にある間は影響する。一方、欠損が窓外へ出て新しい連続20区間が揃えば、局所窓は再び計算できる。これは起算不明のセッションVWAPが復元できた意味ではない。
- 既知のV=0は重み0で、足の時間位置は残す。全窓のΣV=0なら未知。数量未知/負値・欠足と0を混同しない。数学上はV=0が既知ならP不明でもその寄与を0と定義できるが、全区間OHLCV完備を求める品質規約とは別である。価格未知を0価格へ置換せず、必要OHLCの品質方針を固定する。
- `closed`と`volume_complete`は収集器の旗で、全受信の完全性を証明しない。採用する旗・重複・量reset・欠分の判定を入力仕様に残す。[時計と保存仕様](../../データと閲覧形式.md)
- 最新窓Tの選び方と鮮度上限を決め、古い最後の観測窓を現在の20分窓と呼ばない。例えば5分傾きは`VWMA(T)−VWMA(T−5分)`で、両窓の知得が必要。1分窓の5分おき参照と、5分HLC3からの再計算は別測定。

有限窓は場の初期欠損や累積平均の遅さを避ける別候補だが、欠測を治す機能ではない。窓内の大きな数量や窓落ちで急変し得るため、常にVWAPより速く有利になるとも言えない。全73場参加・平均頻度・70%を満たすかは新しい入力監査と試行が必要である。

## 計算から言えることと市場心理の仮説

架空の2足でP=(100,110)、V=(1,3)ならVWMA=107.5、SMA=105。高い価格の足に多い量が配られている。同一窓・同一Pなら`VWMA−SMA=Cov(P,V)/平均V`（Covは窓内母共分散）。差の符号は価格水準と量の配分を示し、買い注文の超過や次の上昇を直接測らない。量が全足同じならVWMA=SMAになる。

心理仮説は「最近量が伴った価格域の外で終値を保ち、再接近を止めて再加速するなら、直近の値決めより上/下を受け入れる動きかもしれない」。全参加者の平均建値・公正価格や、その線を機関が守る意図を観測したことにはならない。価格帯の受容は別足の価格構造で確認し、上位の方向/位相・値幅・現在Last/BBOの取得位置とは役割を分ける。

VWMAは既に価格と数量を使う。同じ足の価格位置・VWMA越え・相対量を「独立3票」と数えない。別足の再接近/再加速や同足量の確認を組み合わせる場合も、同じ入力の共有を記録する。窓落ちによる線の移動だけで価格が突破したように見える反例を分ける。売買は符号反転した同じ条件とし、VWMAだけで順行/反転を決めない。

## 再利用時に固定する項目

`I16 / 足1分 / P=HLC3 / 窓=固定20分`は候補定義の例。起点・対象区間・当足包含・場替わり、0/未知/数量品質、欠分での未知と回復、最新窓の鮮度、傾き差分、公表/配送/保持/取得期限、帯があればATR等との別定義を残す。20分や帯幅を成績から採用した結果ではない。

I01のSMA/EMAとは同じ平均系だが、数量入力の既知性と有限窓を明示的に追跡するためI16を独立行にした。I12 VWAPと重複計上せず、同じVWMAのClose/HLC3・期間違いはI16内の設定差とする。[汎用表・版7](../../議論/手法と時間スケールの汎用表_版7.md)、[記録方針](../../議論/手法と時間スケールの記録方針.md)。
