# 線形回帰と決定係数（OLS・R²）

確認日：2026-11-05。分類は方向・価格経路の形状。以下は計算の定義、資料の用法、本研究の仮説を分けた教材である。

## 何を知るために使うか

等間隔の確定終値に直線を当てはめ、傾きから上向きか下向きかを、R²からその直線で標本内の変動をどれだけ説明できるかを読む。例えば終値が毎足同じ幅だけ上がれば、傾きは正でR²は1になる。同じ始値・終値でも、途中で往復した経路や最後だけ急変した経路では当てはまりが変わる。

回帰トレンドは証券会社の教材にもある既知の分析方法である。同資料では平行帯も紹介されるが、本章の傾きとR²だけから帯の売買ルールまで実装したことにはしない。[三菱UFJ eスマート証券・回帰トレンド](https://kabu.com/investment/guide/technical/23.html)（確認2026-11-05）

## 式と、再利用時に固定する項目

古い順に `x_i=i, i=0..n−1`、`y_i=確定終値` とし、切片付きの `ŷ_i=a+b*x_i` を当てはめる。OLSは価格の縦方向の残差平方和を最小にする。直交距離や絶対誤差の最小化とは計算が異なる。数式の仕様には[NIST・最小二乗法](https://www.itl.nist.gov/div898/handbook/pmd/section4/pmd431.htm)を用いる（確認2026-11-05）。

```text
Sxx = Σ(x_i−平均x)²
Sxy = Σ(x_i−平均x)(y_i−平均y)
Syy = Σ(y_i−平均y)²
b = Sxy/Sxx
a = 平均y−b*平均x
SSE = Σ(y_i−ŷ_i)²
R² = 1−SSE/Syy = Sxy²/(Sxx*Syy)   （Syy>0）
```

全終値が同値なら傾きは0でR²は未定義とする。0や1で補完しない。正負の方向は傾きに残り、R²には方向がない。傾きの単位はpt/足で、3分足の傾きを15分足とそのまま同じ大きさとして比較しない。

再利用する設定カードには、足、期間、終値以外の入力を使うか、当足を含むか、切片の有無、欠枠とセッション跨ぎ、必要本数、公開時点、未定義の処理、傾きとR²の各閾値を記す。判定に表示用の丸め値を使わない。

20点なら `Dxx=20Σx²−(Σx)²=13300`、`Dxy=20Σxy−ΣxΣy`、`Dyy=20Σy²−(Σy)²` と置ける。`b=Dxy/Dxx`、`R²=Dxy²/(Dxx*Dyy)`。本研究の `R²≥1/2` は `Dyy>0` のもとで `2*Dxy²≥Dxx*Dyy` と比較する。これは代数的な書き換えであり、新しい指標ではない。

## ERや移動平均との違い

移動平均の前後差は平均水準の動き、OLSの傾きは窓全体への直線の傾きである。どちらも同じ価格の加工なので、組み合わせても独立した証拠が二つになるとは限らない。

KaufmanのERは、端点の変化の絶対値を、その間の隣接変化の絶対値の合計で割る。往復の少なさを表すが、一定の速度で進んだかを直接表す式ではない。[作者によるERの説明](https://kaufmansignals.com/matching-the-markets-to-the-strategy/)（確認2026-11-05）

数学上、20期間前から前足まで同値で、最後だけA>0上がればER20は1になる。一方、当足含む20点のOLSでは19点同値・最後だけ上昇となり、傾きはA/70、R²は1/7になる。一定刻みの直線ならR²は1である。この人工例は経路の違いを説明するもので、実際のスパイク損失や勝率を測った結果ではない。

## 複数手法でどう判断するか

|役割|観測の候補|判断する問い|
|---|---|---|
|位置・発動|当足を除く直前高安と確定終値|過去の価格帯を終値で抜けたか|
|方向|OLS傾きの符号|窓全体の進行も突破方向か|
|勢い|MACDヒストの現前差|その方向の勢いが増えているか|
|経路の選別|R²|直近の終値が直線的な進行に近いか|
|保護・執行|ATR、正常BBO、費用後含み益|固定した追尾幅と注文モデルで守れるか|

買いは `side=+1`、売りは `side=−1` とし、`side*b>0`、`side*δMACD>0` の同じ式を使える。方向不一致や欠測を、直ちに逆方向へ入る根拠にしない。反転への切替は別の価格復帰や勢い反転を定義し、待機と区別して検証する。

市場心理の仮説としては、終値の高安突破に窓全体の進行と勢いが伴えば、複数時点で追随する注文が続いている可能性を考えられる。ただし終値だけで注文の意図や参加者数は観測できない。高R²でも最後の買いが尽きる場合や、次足から反転する場合がある。これは検証する説明候補であり、心理を確認した事実ではない。

## 読み違えやすい点

R²は当てはめに使った標本の説明度であり、将来+250ptへ先着する確率ではない。高いR²だけでモデルの妥当性を判断できないことを[NISTのモデル検証](https://www.itl.nist.gov/div898/handbook/pmd/section4/pmd44.htm)も説明している（確認2026-11-05）。重なる窓、価格系列の依存、ヒゲの逆行、約定費用、将来の変化は別に扱う。R²≥0.5を有意水準や最適値とは呼ばない。

## 154：発動足から分離した回帰環境も、継続の保証にはならなかった

2026-11-12追記。[154](../../../study/00154_回帰で進行と往復を分けて短期回復から入る/README.md)は、発動1分足rを除いた先行30分の確定終値へOLSを当て、R²>=.5・傾きが売買側と同じ・実側EMA8距離[-1,1]を、短期実体回復・5分MACD/RSI増分・相対出来高と組み合わせた。41の当足含3分20点・終値突破への追加とは別の構成である。

この順行枝T30は118取得・36順/67逆/8未到達/7観測不足、実BBO/H60/同幅±125ptの到達済み先着率34.95%だった。費用後IFD代用は利益491,535円/損失999,621円、金額未知0。R²<.5の端復帰枝V30も8取得・3順/4逆/1未到達であり、低R²をそのまま有効な逆張り環境とする根拠にはならなかった。

したがって、高R²の同方向進行を確認したことと、今からその方向へ125pt先着する優位があることは区別する。MA・MACD・RSI・回帰は同じ価格経路を加工した部分を共有し、同向の数値が増えても独立した支持票が増えたとは限らない。失速・反転・取得位置が原因かは、当時の現在価格と構造、同じ取得時計の実反対BBOを別に診断して確かめる。
