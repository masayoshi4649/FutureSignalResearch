# ATR：方向を予想せず、値動きの大きさを測る

資料閲覧日：2026-10-30。数値例は説明用であり実績ではない。損切り幅や枚数の係数は未検証である。

## 最初に理解すること

同じ20円の損切り幅でも、1分に数円しか動かない相場と、何十円も往復する相場では意味が違う。ATRは最近の値幅を平均して、その違いを測るための尺度である。上昇・下落の方向を予想する値ではない。[TradingView公式・ATR](https://www.tradingview.com/support/solutions/43000501823-average-true-range-atr/)

足の高値から安値を引くだけだと、前の終値から飛んだ分を見落とす。ATRの材料であるTRは、その飛びも含めて測る。したがって、静かな足でも前値との隔たりが大きければTRは大きくなる。

## 計算と小さな例

`H_t,L_t` は確定足の高安、`C_(t−1)` は前の確定終値。まず3つの距離の最大値を取る。

```text
TR_t = max(H_t−L_t, |H_t−C_(t−1)|, |L_t−C_(t−1)|)

初回ATR = 最初のn個のTRの単純平均
ATR_t = (ATR_(t−1) × (n−1) + TR_t) / n
```

前終値100、今の高値106・安値102なら、足内の幅は4だがTRは `max(4,6,2)=6`。高値98・安値94でも `max(4,2,6)=6`。上へ離れても下へ離れても同じ値になる。これが方向を示さない理由である。

`n=3`、最初のTRが4・8・6なら初回ATRは6。次のTRが9なら、ATRは `(6×2+9)/3=7`。直近3本のSMAなら `(8+6+9)/3≈7.67` なので、平均方式が違えば結果も違う。

ここではワイルダー型平均を採る。TradingViewは既定RMAのほか別の平均方式も選べる。TA-Lib固定版では初回の単純平均と後続のワイルダー型更新を確認できる。[TradingView・計算仕様](https://www.tradingview.com/support/solutions/43000501823-average-true-range-atr/)、[TA-Lib v0.6.4・ATR実装](https://raw.githubusercontent.com/TA-Lib/ta-lib/v0.6.4/src/ta_func/ta_ATR.c)

## 一般的な利用と、その背景になる仮説

価格と同じ単位を持つため、損切り幅、追随決済の距離、取引枚数、過度に荒い時間の除外などに転用できる。商品間で比較するなら `ATR/価格` 等の比率も候補になる。NK225とTOPIXのATR数値を、そのまま大小比較しない。[TradingView・ATRの尺度](https://www.tradingview.com/support/solutions/43000501823-average-true-range-atr/)

「ニュースで評価が割れ、注文を出し直す参加者が増えると値幅が広がる」「流動性が薄く、少量の注文でも価格が動く」という説明は考えられる。ただし、**この段落は本研究の需給仮説**であり、ATRが高いだけで原因を特定できない。出来高が多い場合と少ない場合の両方で値幅は広がりうる。

リスク幅への利用も、「過去の値動きの大きさが、次の短期間の値動きにも一定程度残る」という仮説に立つ。ATRの計算式が、その持続性や最適な損切り倍率を証明するわけではない。[市場心理の扱い](../市場心理/README.md)

## 損切りと枚数へ変換するとき

買い建値を `E`、入口で確定していたATRを `A`、倍率を `k` とすると、初期損切り候補は `E−kA`。これは価格条件の候補であり、実際の注文受付や約定を表さない。

```text
1枚の想定損失 = 損切り距離 × 商品倍率 + 想定費用
候補枚数 = floor(許容損失額 / 1枚の想定損失)
```

例として `A=7,k=2`、micro倍率10円なら、価格差による損失は1枚140円。許容額1,000円なら費用を無視した枚数は7枚だが、手数料・滑りを入れれば減る。呼値へ丸めた後の実距離で計算し、上限枚数・証拠金・流動性の制限も別に適用する。

買いの追随線を `過去最高値−k×ATR` で毎回作り直すと、ATR急増時に損切り線が下がって損失許容を広げる場合がある。広げない設計なら `新線=max(旧線,新候補)` とする。どちらを採るかは別仮説として固定する。[組み合わせと役割分担](../組み合わせ/README.md)

## 反例を先に知る

- 小さなATRの直後に急変すると、過去の尺度による損切り幅を大きく飛び越える。
- 急変後に動きが静まっても、平均には大きな足が残る。
- 高いATRは上昇の根拠にも下落の根拠にもならない。
- ATRを大きくすれば損切り回数は減るかもしれないが、1回の損失や滞在時間は増えうる。

ATRは最大損失・次足の値幅・一定確率の信頼区間を意味しない。逆指値の不成立や滑りまでATRで抑えられるとは考えない。

## 初期化・欠損・実データ

前終値を別途与えない場合、初回のTRを計算するために前足が必要となる。本章の基礎仕様は前終値なしのTRを欠損とし、連続する `n` TRから初期化する。最初のTRを `H−L` にする実装とは開始点が違う。TA-Libとの一致では助走設定も確認する。[TA-Lib v0.6.4・ATR](https://raw.githubusercontent.com/TA-Lib/ta-lib/v0.6.4/src/ta_func/ta_ATR.c)

欠損を挟む場合、飛び越えて差分を作るか、状態をリセットするかを試行で定義する。初期化未完・欠損・ATR0で新規枚数を計算しない。無約定足へ前値を埋めるとTRを人工的に小さくする場合がある。

前セッションの終値を継ぐか、当セッション内だけで測るかを分ける。建玉を持ち越さなくても指標の履歴は継続できるが、夜間開始のギャップと限月切替を混同しない。ラージ由来の幅を小口商品へ利用するときは、その商品の倍率と呼値へ変換する。[データ仕様](../../データと閲覧形式.md)
