# ボリュームレシオ：価格方向へ分けた数量の配分

調査・出典確認日：2026-11-05。[指標の目次](README.md) / [ボリューム系](../分類/ボリューム系.md)。一般的な説明、数式上の性質、研究の仮説を区別する。

## 何を知るために使うか

一定期間の数量を、終値が上がった足・下がった足・同じ足へ分類し、その配分を見る。価格の値幅や、単なる数量増減とは別の問いである。[野村證券](https://www.nomura.co.jp/terms/japan/ho/A02732.html)は上昇/下降時の出来高による過熱判断として説明し、[フィリップ証券の先物用語集](https://www.phillip.co.jp/futures/ft_glossary/volume_ratio.php)も方向別数量の変化に着目する。

全ての約定には買いと売りが対応する。上昇足の数量を、積極的な買い約定量、買い手の人数、口座への純入金へ読み替えない。板の表示数量・未決済建玉とも異なる。[OBV](OBV.md)は方向別数量の累積、VRは選んだ有限窓の配分であり、起算と窓から落ちる足の影響が違う。

## 二つの式を混ぜない

[楽天証券のVR公式ヘルプ](https://www.rakuten-sec.co.jp/MarketSpeed/onLineHelp/msman2_5_2_7.html)では次の二式がある。期間内の上昇足量をU、下落足量をD、同値終値足量をFとする。

```text
VR1 = 100 × (U + F/2) / (D + F/2)
VR2 = 100 × (U + F/2) / (U + D + F)
B   = 2 × VR2/100 − 1 = (U − D) / (U + D + F)
```

VR1の均衡は100、VR2は50、中心化Bは0。VR1は分母0で未定義になり得る。VR2/Bは総量が正なら片側量0も計算でき、Bは−1〜1。総量0は情報がないので未定義であり、0や中立へ補完しない。全量が同値足ならB=0になる。

架空例U=600、D=300、F=100ならVR1=185.71%、VR2=65%、B=0.30。同じ窓を上下反射してU/Dを交換すると、VR2=35%、B=−0.30となる。VR1は100−VR1へはならず、正の両分母の範囲ではVR1同士の積が10000になる。

日足か分足か、期間、同値量の扱い、終値以外の価格を使うかで値は変わる。楽天の説明にある25日等の設定や日足の過熱目安を、NK225の3分足へそのまま移して有効性を確認したことにはしない。

## 水準と変化が表すもの

|見るもの|直接分かること|まだ分からないこと|
|---|---|---|
|B>0|窓内の上昇足量が下落足量より多い|価格が次に上がるか|
|Bが上昇|上昇側への配分が前の窓より増えた|当足に新しい買い手が増えたか|
|低いBから改善|下落側優勢が弱まる候補|底打ちの成立・反転の値幅|
|価格と非追随|価格と方向別量の配分が異なる|どちらが先に修正されるか|

上昇時の数量を関与の強さと読む心理説明は一つの仮説である。損切り、ヘッジ、限月乗換えでも量は増える。強いトレンドでは過熱が続き、Bが高いという理由だけの売り、低いという理由だけの買いは失敗し得る。

**Bの改善は古い足の窓落ちでも起きる。** 当足が小量でも、大きな下落足量が窓から外れるとBが上がる場合がある。各足qが全て同じなら、Bは上昇/下落回数の差を足数で割った値になり、数量特有の追加情報がなくなる。価格由来のRSI/MACD等との併用でも独立票の数を増やしたと考えない。

## 価格構造・勢いと合わせる研究カード

未検証例として、買いは「過去安値を更新しても旧BB内で終わる価格P」＋「MACDヒスト差が上向き」＋「Bの一足差が正」、売りは鏡像という組み合わせが考えられる。価格は失敗の位置、MACDは運動変化、Bは数量配分の変化を担当する。Bの絶対水準が既に正であることまでは必須にしない案である。

機械化では、元価格発動の時点で一回だけ評価する。数量の準備だけで消える事例と、Bの値で消える事例を別対照にする。不成立をそのまま反対方向注文へ変換せず、待機とし、順行再開には別の価格発動を要求する。[試行36の事前計画](../../../study/00036_価格失敗と量比の方向変化/計画.md)で具体化した。成果は試行の結果を参照し、この教材例を利益実績とはしない。

## 実装で固定する点

- C_iとC_{i−1}を比べ、当足q_iを分類する。n変化にはn+1終値、現前n変化の比較にはn+2終値とn+1個のqが必要。最古の基準終値のqを余分に要求しない。
- 数量欠測で量窓を切ることと、有効終値を次足の比較元にできることは別。価格欠枠や非公開足では価格基準も切る。
- 観測累積量を足ごとに重ねて加算せず、差分の起算・減少・数量時計・欠測を監査する。観測差分量と真の全約定量を区別する。
- BとΔBは比の交差積や有理数で比較できる。表示floatが同じでも真の差が0とは限らない。採否のために都合よいεを足さない。
- K−価格へ反射するとU/D交換、BとΔBが符号反転する。対して標準MFIは絶対TP×q重みが変わり、単純な100−MFIにはならない。この性質を同じものとして実装しない。[FidelityのMoney Flow](https://www.fidelity.com/learning-center/trading-investing/technical-analysis/technical-indicator-guide/money-flow)

出典は一般的な計算・用法を支える。特定期間、125/250の先着率、手数料後の収益、先物の安定性は個別の検証事項である。
