# CCI：窓の平均からどれだけ離れたか

確認日：2026-11-05。CCIは商品チャネル指数の略称。以下は教科書と未実行の研究候補であり、NK225の先着率・損益を示すものではない。

[教科書の目次](../README.md) / [共通の計算仕様](../02_指標の計算とシグナル.md) / [組み合わせ](../組み合わせ/README.md) / [市場心理](../市場心理/README.md)

## 何を知るために使うか

CCIは、現在の代表価格が直近の平均から離れた程度を、その窓の平均絶対偏差で尺度調整する。正なら平均より上、負なら下にある。傾向の発生、偏りからの復帰、価格との非追随を調べる用法が紹介されている。[Fidelity公式](https://www.fidelity.com/learning-center/trading-investing/technical-analysis/technical-indicator-guide/cci)

単なる騰落回数、将来の上昇確率、注文の偏り、価格の順行余地を直接測る指標ではない。高値・安値・終値を使う価格由来の指標なので、他の価格指標を足したときも情報の重複を確かめる。

## 式：全てを同じ現在窓の平均から測る

この章では入力をHLC3、期間をnとする。標準的な説明の一つはn=20であるが、日足20本と3分足20本は別の設定である。[TradingView公式の計算例](https://www.tradingview.com/support/solutions/43000502001-commodity-channel-index-cci/)

```text
TP_i = (H_i + L_i + C_i) / 3
μ_t  = (TP_(t−n+1) + … + TP_t) / n
MD_t = (|TP_(t−n+1)−μ_t| + … + |TP_t−μ_t|) / n
CCI_t = (TP_t−μ_t) / (0.015 × MD_t)
```

MDは平均絶対偏差であり、標準偏差ではない。**窓内の全TPから、同じ現在時点のμ_tを引く**。各足当時の移動平均μ_iから偏差してその絶対値を平滑した `SMA(|TP_i−μ_i|)` は別の式になる。MDに使う平均も分子に使う平均も、現在足を含む同じn本窓である。

MD=0なら窓内TPが全て同値で、分子も0になる。この章の機械化では**無効値**とし、CCI=0や前値へ置き換えない。n本不足・非有限値・不正なOHLCも無効とする。nは2以上の整数を指定する。n=1は常にMD=0である。

定数0.015は尺度を調整する係数で、±100がよく参照される水準となるよう設けられた。±100内の比率は系列や期間次第であり、「次の取引が一定確率で勝つ」「250ptへ先着する」という意味は持たない。

### 小さな数値例

検算を短くするためn=5とし、次の架空の確定足を使う。全行の偏差は、最後の時点で得た同じ平均100から計算する。

| 足 | 高値H | 安値L | 終値C | TP | 最後の平均100からの絶対偏差 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 1 | 99 | 97 | 98 | 98 | 2 |
| 2 | 100 | 98 | 99 | 99 | 1 |
| 3 | 101 | 99 | 100 | 100 | 0 |
| 4 | 102 | 100 | 101 | 101 | 1 |
| 5 | 103 | 101 | 102 | 102 | 2 |

平均は100、MDは6/5=1.2。最後のCCIは `2/(0.015×1.2)=1000/9≒111.11` となる。これは計算例であり、買い推奨や検証成績ではない。全足TP=100ならMD=0となり、値を表示しない。

### 入力Sourceを省略しない

上の式はHLC3である。一方、TradingViewの同じヘルプは計算例をHLC3としつつ、入力Source欄では既定値をCloseと説明している。**画面の初期設定がHLC3だと推定せず、実際のSourceを保存する**。Close入力なら、上式のTPを全てCloseに置き換えた系列として区別する。期間、Source、足の作成法が違えば、同じCCIという名前でも照合対象は変わる。[TradingView公式・入力欄](https://www.tradingview.com/support/solutions/43000502001-commodity-channel-index-cci/)

## 一般的な判断と、切り替えに必要な情報

| 用法 | 買い側の観測例 | 組み合わせる情報・残る問題 |
| --- | --- | --- |
| 順行 | +100を下から上へ抜ける | 上位足の方向や価格突破で確認する。高値追随の直後に戻る可能性は残る |
| 反転 | −100未満から−100を上へ回復する | 固定した支持帯への復帰、上位足の収束等を別に確認する。強い下落中の一時反発と区別する必要がある |
| 非追随 | 価格が安値更新、対応するCCIは安値を更新しない | 比較元の時点と価格復帰を固定する。反転時刻や到達幅は決まらない |

売り側は高安と符号を反転する。Fidelityは±100突破を新しい方向の候補として他手法で確認する用法と、極端な値が続く注意を示している。**高いから直ちに売る、低いから直ちに買うとは決めない**。[Fidelity公式・用法](https://www.fidelity.com/learning-center/trading-investing/technical-analysis/technical-indicator-guide/cci)

±100や±200は価格や損失額の上限ではない。一般資料では「上下限のないオシレーター」と呼ばれ、0〜100に固定されるRSI等と区別される。ここで重要なのは、±100を越えても高水準・低水準が続き得ることにある。[TradingView公式・水準と継続](https://www.tradingview.com/support/solutions/43000502001-commodity-channel-index-cci/)

式上の補足として、全TPを同じ現在窓平均から測る固定nの上式には `|CCI|≤n/0.03` という理論限界がある。偏差の合計が0なので、絶対偏差の総和は現在偏差の絶対値の2倍以上となるためである。n=20なら約666.67。この数学的な限界と、売買の目安±100・±200は別であり、「上下限なし」を任意の値へ無限に発散する意味には使わない。この補足は本章で式から導いたものである。

CCIの上昇は分子だけでなくMDの変化でも生じる。CCIが上がったことだけで価格上昇幅が拡大したとは限らない。MA・BB・CCIは平均からの距離という成分が重なるため、複数を使っても独立した票数として扱わない。

## 市場心理として考えられる仮説

平均より上へ離れる動きには、新しい価格帯を受け入れる追随注文が続くという仮説がある。一方、保有者の利確や新規参加者のためらいが強ければ平均側へ戻るという仮説も成り立つ。どちらが支配的かはCCIの大きさだけでは分からない。

上位足の方向、元の価格帯へ戻ったか、押し戻り後の高安構造等を併用するのは、この二つを区別するための研究案である。CCIは投資家の人数、建玉、成行売買、感情を観測していない。心理は解釈の仮説であり、価格から心理の因果を実証したという主張ではない。

## 売買の鏡像と機械化

価格を基準aで上下反射するなら、`H'=2a−L、L'=2a−H、C'=2a−C` とする。TPと平均は反射し、MDは同じでCCIだけが符号反転する。したがって、実方向sを買い+1・売り−1として `x_t=s×CCI_t` を使えば、買い売りを同一式にできる。これは式上の性質であり、実際の売買約定や費用まで対称になる保証ではない。

- 期間n、Source、足幅、OHLCの作成・公開時計、現在窓に現在足を含めることを固定する。
- n本の連続性、セッション・限月のまたぎ方、欠枠・不正値の解除と再準備を指定する。休止中を0価格や前値で埋めない。
- 上位足は判断時点で公開済みの足だけを参照し、形成途中や後から確定した山谷を混ぜない。非追随の比較元kと確認時刻を保存する。
- 「領域にいる状態」と「前値から越えた瞬間」、strict不等号と等号を分ける。丸め表示で閾値判定をしない。境界の誤差処理は実装仕様として事前固定する。
- 条件の比較では両案へ同じCCI準備を課し、準備不足による除外と値による選別を分ける。原価格候補、採用、未約定、実参加も別々に記録する。
- 順行と反転の切替条件、注文中・建玉中の優先順位、後足まで待つか同時点で比べるかを固定する。後から有利な価格へ取り直さない。

`x=s×CCI` なので、順行売りは−100の下抜け、反転売りは+100からの下向き回復になる。価格候補の窓・時点や「範囲内」のstrict境界も、試行計画で固定してから計算する。カードの収束閾値10%は説明用に置いた未検証の仮定である。

出口は別途固定する。CCIによる通常決済を試す場合も、価格の保護逆指値、利益後の最低同値トレーリング、約定遅延・費用、セッション期限返済を必須とする。先着ラベルと実損益を分け、学習・条件選択・固定後確認の結果を保存する。この章では原板からの先着やP&Lを計算していない。
