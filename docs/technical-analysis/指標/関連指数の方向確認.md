# 関連指数の方向確認

確認日2026-11-05。NK225を取引するとき、TOPIX先物も同じ方向を示すかを補助情報として使う考え方を整理する。複数指数を同時に売買すること、相関や倍率の歪みを売買することとは区別する。

## 何を知るために使うか

日経225は225銘柄の価格加重指数である。TOPIXは浮動株調整時価総額加重で、重み付けが異なる。同じ日本株市場を反映していても、各構成銘柄が指数へ与える影響は同一ではない。[日経公式の指数紹介](https://indexes.nikkei.co.jp/en/nkave/index/profile?cid=7&idx=nk225)、[JPXの指数FAQ](https://www.jpx.co.jp/english/faq/stock_price_index.html)（確認2026-11-05）。

NK225の価格構造で発動を決めた後、別の重み付けの指数先物にも方向が伴うかを問える。ただし二つの指数は構成が重なり、独立した確認票ではない。TOPIXが上がることも、構成銘柄の多数が上がっていることを直接意味しない。これは指数値による確認であり、騰落銘柄数の観測ではない。

|問い|使う観測|そこからは分からないこと|
|---|---|---|
|関連指数の基調が同方向か|公開済み終値の回帰傾き等|将来の勝率、恒常的な先行関係|
|直近の勢いも同方向か|関連指数自身のMACDヒスト変化等|別指標から独立した証拠かどうか|
|両者が食い違っているか|同じ判断時点で見えた両系列|どちらが誤りか、必ず収束するか|
|価格構造が継続/反転を示したか|取引対象自身の突破・再テスト・帰還|関連指数の逆向きだけによる反転根拠|

## 組み合わせるときの役割

試行44の仮説は、NK225の最初再テストによる順行/反転とNK225自身のMACD変化へ、TOPIXの回帰方向・MACD変化を合わせること。取引の向きdはNK225の明示的な価格分岐で決める。TOPIX不一致なら見送り、反対注文へ変換しない。

```text
基準：NKの価格構造 → 実方向d、NKの勢いも同方向
準備：その判断時点より前に公開されたTOPIXの対象足と履歴がある
確認：d×TOPIXのOLS傾き > 0、かつ d×TOPIXのヒスト変化 > 0
```

回帰は20終値、MACDは12/26/9という研究上の固定仮定である。3分足先物の最適期間を示す原典や実績ではない。傾きとヒストは同じTOPIX終値を加工するため、その複合条件全体の効果を比べる。回帰単独/MACD単独の効果とはしない。[回帰の教科書](線形回帰と決定係数.md)、[MACD](MACD.md)も参照する。

心理の仮説としては、NK225固有の価格変化だけでなく、異なる重み付けの日本株指数にも流れが及んでいるなら、その方向への参加が広がっている可能性を考える。ただし指数値から注文者の意図や実際の資金移動を観測したわけではない。逆方向のときも構成・業種・現先差・流動性・観測時刻などが関与し得て、「NK225が間違っている」とは判定できない。

## 方向の整合と、先行する商品の発見は別

吉田靖の[JPX掲載研究（2021年4月）](https://www.jpx.co.jp/derivatives/market-report/futures-options-report/archives/nlsgeu00000595vz-att/rerk2104.pdf)は、2019年10〜11月の日中のミリ秒単位の板情報からNK225ラージ・mini・TOPIXを分析し、明確な先行遅行を識別できなかったと報告した（本文2〜4ページ、確認2026-11-05）。

一方、同著者の[2026年4月研究](https://www.jpx.co.jp/derivatives/market-report/futures-options-report/archives/t13vrt000000ner2-att/rerk2604.pdf)は、2026年1〜2月の午前・ITCH由来の共通時刻とマイクロプライスを使い、マイクロ秒規模の差と、TOPIXがminiに先行する推定が多い傾向を報告した。ただし関係の不安定さも述べる。共通T6は配信経路の単一地点での打刻で、今回のAPI価格時計へ同じ精度を移せるものではない（本文3〜5・12ページ、確認2026-11-05。全図表の網羅照合はしていない）。

したがって2021年の識別限界を、先行関係が常に存在しないという結論にしない。逆に2026年の限定された高頻度推計も、恒常的なTOPIX先行や、本研究の3分足の収益を示すものではない。本研究が問うのは当時見えた方向の整合であり、相関の時間差を推定する戦略ではない。論文の先行時間や仮想損益を本研究の成績へ転記しない。

## 時計が違えば、同じ足でも同時に見えない

二つの商品が別ファイルに保存されていると、各ファイルの原行番号は共通連番にならない。同秒だから同時に受信したとも言えない。足終了時刻が一致するだけで、関連指数の確定値を使えるとはしない。

試行44では同一セッション・同じ3分終了時刻のTOPIX足だけを対象とし、**TOPIX確認価格時計 < NK要求価格時計**のstrict条件を置く。同秒は不明で見送る。該当足が未公開でも古い正常足へ代替せず、後で公開されるまでNK要求を延期しない。

さらに、当時見える集合だけを先に作る。その中に対象足がなければ「TOPIX同終了strict事前公開参照なし」とする。将来になって同秒/後公開/未収録と分かっても、当時の参照None・理由・採否を書き換えない。後から全入力を調べた時計診断は、別の欄に保存する。

価格時計は受信時計ではないため、strict事前条件でも実WebSocket受信の先行を証明しない。現実の可用性を示すには共通受信時刻や保存連番が必要になる。[価格時計と受信時計](../../議論/価格時計と受信時計を分ける.md)の制約を引き継ぐ。

## 再利用する計算条件

|項目|固定しておく内容|
|---|---|
|主系列と補助系列|NK225ラージの価格発動とTOPIXラージの補助値。NK225microの代理損益だけを作る|
|商品識別|コードの一致ではなく限月年月の整合。数量・価格刻み・倍率は商品別|
|局所履歴|同場の連続公開完全3分足20本でOLS。欠測・不正・未公開を飛ばさない|
|数値履歴|中心化MACDは同一TOPIX限月だけcarry。欠枠/不正/尾部/限月変更で解除|
|現前の定義|同場の隣接公開足。過去の任意の正常値へ代替しない|
|零値|傾き0・ヒスト差0は準備済み。方向確認段階で不成立とする|
|対称性|実sideとの積を使う。二系列を同時に鏡映すると符号が反転し採否は不変|
|効果の分離|基準、補助の準備、方向・勢いの値を段階比較。時計選別も数える|

JPX現行仕様ではTOPIXラージは1pt当たり10,000円、呼値0.5pt。NK225の250/125ptや損益倍率をTOPIXへそのまま移さない。TOPIXは今回符号の補助だけで、二商品の絶対ptや円損益を足さない。[JPX・TOPIX先物制度](https://www.jpx.co.jp/derivatives/products/domestic/topix-futures/01.html)（確認2026-11-05）。

## 検証で残すこと

[試行44](../../../study/00044_TOPIX方向とNK再テスト/計画.md)では、固定NK入口を完全対照とし、補助入力の予約・時計・限月監査を先行する。新しい同終了結合をしたから未使用データになった、とは扱わない。使用範囲は[版4・X01](../../議論/手法と時間スケールの汎用表_版4.md)の関連指数確認として記録し、相関係数やNT倍率を計算したことにはしない。

入口を減らすと建玉の占有が変わり、新たに参加できる後続入口も生じる。純入口subset・実参加・共通新規の出口・片側だけの参加を分ける。利益後の追尾、費用、期限、入力品質も従来どおり評価し、方向一致率を250pt先着率へ読み替えない。
