# OBV：終値方向で数量を加減する

調査日：2026-11-05。[指標の目次](README.md) / [ボリューム系](../分類/ボリューム系.md)。一般的な説明と研究独自の条件を区別する。

## 何を知るために使うか

OBVは、終値が上がった足の数量を足し、下がった足の数量を引いた累積系列である。価格と数量方向の追随・非追随を調べる一般的な用法がある。絶対値の大きさだけで銘柄や起算の異なる系列を比べず、同じ系列の変化を見る。[Fidelity公式](https://www.fidelity.com/learning-center/trading-investing/technical-analysis/technical-indicator-guide/obv)

```text
OBV(t) = OBV(t−1) + sign(C(t)−C(t−1)) × q(t)
sign(正)=+1、sign(負)=−1、sign(0)=0
```

同値終値では、その足に数量があってもOBVは変わらない。始点を0にすると次の架空例になる。始点に足す定数は、同一区間内の二時点の差には影響しない。

| 時点 | 終値 | 当足数量 | OBV |
| --- | ---: | ---: | ---: |
| 0 | 100 | 起算 | 0 |
| 1 | 102 | 20 | 20 |
| 2 | 101 | 30 | −10 |
| 3 | 101 | 40 | −10 |
| 4 | 103 | 10 | 0 |

## 価格・他の数量指標との組み合わせ

価格の高値・安値更新にOBVも追随するか、価格が新高値なのにOBVが以前の値を越えない等の非追随を見る。非追随を将来の反転候補として調べ、価格が実際に戻る条件などを併用する説明がある。[TradingView公式](https://www.tradingview.com/support/solutions/43000502593-on-balance-volume-obv/)

本研究の心理仮説は「価格を端へ押し出した動きが、以前と同じ数量方向には表れていない可能性がある」。OBVは終値の上下で足の全数量を分類するので、積極買い・売りの約定量、資金の純流入、投資家の人数を測ったものではない。同値足の大きな数量を捨てる性質や、一度の大数量の影響にも注意する。

RVOLは数量の多寡、OBVは終値方向で符号を付けた累積で、別の問いである。一方、同一窓のOBV差を総量で割った値は、上昇量U・下落量D・同値量Fから作る `(U−D)/(U+D+F)` に一致する。同値を半配分する0〜100型VRはこの値の線形変換なので、独立した追加票として重ねない。後半は式からの整理である。

## 分足先物で固定すること

足幅、終値系列、数量の意味、起算・欠測・限月・セッションを指定する。標準の日足OBVを分足へ移しただけで有効とはしない。

今回使える数量は原板の累積数量から得る**観測区間差分の代理**。数量時計が価格時計より先行する値はその時点で採らず、欠測・巻戻り・初回基準等を区別する。完全性の判定は入力規約上のもので、全約定を捕捉した保証ではない。[数量の入力監査](../../議論/入力と数量の監査.md)

0と欠測は別に扱う。有効な0量は加減0、欠測を0で埋めて非追随を作らない。区間が切れた前後のOBVを比較せず、各有効区間で起算し直す。価格の連続性と数量の連続性を別に記録する。

## 再利用する反転条件の研究例

[00029](../../../study/00029_BB内復帰とOBV非追随/README.md)では、次を固定して比較した。両案の入口支持は充足したが70%・費用資格は未達。結果と限界は[共通知見](../../議論/極値更新とOBV非追随の反転を比較する.md)へ分けて記録した。

- 現在安値が直前20足の最安値を更新し、終値が前足までのBB20・2σの内側なら買いの価格候補。売りは高値更新で鏡像。
- MACDヒストの一足変化が実方向であることを共通条件にする。
- 数量選別案だけ、価格極値の比較元kに対するOBVの差が実方向であることを足す。kは直前20足の極値を付けた最も新しい足。
- 両案に同じ数量準備を要求し、準備による除外と方向の効果を分ける。後で指標が一致するまで待って別価格へ取り直さない。

ここで比較するOBV(k)はk足の終値時点の値であり、k足中の安値・高値を付けた瞬間の値ではない。また「新極値＋終値が旧BB内」という定義だけでは、ヒゲがBB外へ出たことまでは保証しない。実装では名称より式を正本にする。
