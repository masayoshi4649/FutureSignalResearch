# SuperTrend：ATR帯と方向状態

確認日：2026-11-13。汎用表V8の識別子I20。[指標目次](README.md) / [ATR](ATR.md) / [SAR](パラボリックSAR.md)。

## 一般定義と式

[TradingView公式](https://www.tradingview.com/support/solutions/43000634738-supertrend/)はOlivier Sebanに由来するATR帯の状態指標を説明する。発明者の原著本文ではなく、提供元の計算仕様を確認した。

```text
mid_t = (H_t+L_t)/2
basicU_t = mid_t+k ATR_t
basicL_t = mid_t−k ATR_t
U_t = basicU_t < U_(t−1) または C_(t−1)>U_(t−1) なら basicU_t、他は U_(t−1)
L_t = basicL_t > L_(t−1) または C_(t−1)<L_(t−1) なら basicL_t、他は L_(t−1)
```

前が下降側ならClose>Uで上昇へ、前が上昇側ならClose<Lで下降へ移る。上昇状態の線はL、下降状態の線はU。例えばbasicL=94・前L=95・前Close=100ならL=95を保持する。

## 心理の仮説

通常揺れを含む帯の同じ側を維持できる間と、維持できなくなった時を分ける。ただし線横断は需給反転の実測ではなく、レンジ内の往復でも起きる。

## 本研究の派生

保有側で適格な帯の線を保護床へ合成し、状態反転だけでドテンしない。現在清算BBOの位置、Hist/DI、量の支持を別役割の確認にする。実線への接触と確定Closeによる状態切替は異なるイベントなので、どちらが退出発動か固定する。

## 限界

ATRの平均法・期間、初期方向、等号、前帯と当帯の処理順で差が出る。未準備ATRを便宜的な下降方向へ補完しない。新しい帯が不利へ移っても、本研究の既設床は緩めない。SAR/EMA/ATRを足した数を独立票とせず、いつ候補線が既知になり有効化したか残す。足の最終高安を足初めから使わない。
