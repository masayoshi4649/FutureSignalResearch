# 二足の実体包み

確認日2026-11-05。直前の反対色の実体を現在足の実体が包んで終わったことを、確定後の価格発動として扱う。形だけで買わず、勢いと平均価格からの位置・進行を組み合わせ、入口の先着と実際の回収を別々に検証する。

## 実体とヒゲを分ける

[TradingViewの公式説明](https://www.tradingview.com/support/solutions/43000583771-engulfing-bullish/)は、下降の後に陰線の実体を次の陽線実体が包む形を説明する。ヒゲ全体の包含は必要ない。一方、短い足でも頻出し、次の上昇が続かないことがあるとする。

[thinkorswimの公式仕様](https://toslc.thinkorswim.com/center/reference/Patterns/candlestick-patterns-library/bearish-and-bullish/Engulfing.html)は、二足以前の方向や実体の長さも扱い、始値の比較は厳密な外側を要求する。ソフト間で等号・先行方向・長さの扱いが違うため、「包み足」という名前だけでは再現できない。

本研究では次の二実体関係を操作的に定める。先行トレンドや大小比を含む標準パターン検出器の完全再現とはしない。pは前足、jは現在足、O/Cは始値/終値、sは買い+1・売り−1。

```text
s*(C_p−O_p) < 0       前足は逆色
s*(C_j−O_j) > 0       現足は実方向
s*(O_j−C_p) ≤ 0       始値は前終値と同じか外側
s*(C_j−O_p) > 0       終値は前始値の外側へ抜ける
```

買いは前足陰線・現足陽線・O_j≤C_p・C_j>O_p、売りは鏡像。始値側の等号は許し、終値側は厳密とする。ドジを含めず、高安の包み、実体比、終値のヒゲ内位置は要求しない。現実体は前実体を含むが、「二つの実体の長さの合計を超える」という条件ではない。

例えば前O=100/C=95、現O=95/C=101なら買い型である。現O=96なら前終値側を包まず、現C=100なら前始値を厳密に越えず不成立。前L=90/H=110のヒゲが現実体の外に残っても、この研究規約では成立し得る。数値例は架空である。

## 何が変わったと考えるのか

心理の仮説は、前足が進んだ価格帯を次の実体が打ち返し、反対方向へ終えたことにある。ただし、観測したのは二足の始値と終値の関係で、買い手/売り手の人数、成行注文量、損切り集中、参加者の意図を直接測ったわけではない。

短期の反対実体を打ち返す形は、流れに沿った押し戻り後の再開にも、強い流れの中の一時反発にもなり得る。「前足と反対」という意味の反転と、中長期トレンドの転換を区別する。大きな現実体では確認して入るまでに値幅が進み、逆行125pt前の順行250ptという目標に不利な遅い入口にもなり得る。

## 勢いと背景を別の役割にする

[FidelityのMACD教材](https://www.fidelity.com/learning-center/trading-investing/technical-analysis/technical-indicator-guide/macd)は、短長EMA差とシグナル線による勢い、往復局面で信号が増える限界を説明する。本研究の現在ヒストグラムH_jと前H_pの差は、その一般的な交差条件とは別の設定である。

二足の実体包みに対してs*(H_j−H_p)>0を要求し、形状と現在の勢いの変化を合わせる。H自体の正負、ゼロ突破、シグナル交差は追加しない。包みの条件からs*(C_j−C_p)>0は自動成立するため、終値の前足比上昇をさらに独立した確認と数えない。一方、ヒストの差は過去EMA状態も含み、包みだけから必ず成立するとはしない。

[FidelityのSMA教材](https://www.fidelity.com/learning-center/trading-investing/technical-analysis/technical-indicator-guide/sma)は、平均の向きや価格との関係を一般的な用途として説明する。以下の20本・前足までの二平均・T/R/WAITは本研究で事前に定義する比較であり、原典の利益実証ではない。

```text
M_p     = mean(C[j−20 .. j−1])
M_(p−1) = mean(C[j−21 .. j−2])
dM      = M_p−M_(p−1)
dP      = C_j−M_p
```

平均には現足jを入れず、過去21終値から現前の二平均を作る。位置dPは現在jの確定終値と前平均の差なので、「位置もp時点で既知」という意味ではない。SMA20は仮置きする初期設定で、最適値とは呼ばない。

|判別|実方向sに対する条件|問い|
|---|---|---|
|T・順行候補|s*dM>0かつs*dP>0|平均の進行側で逆実体を打ち返す再開か|
|R・反転候補|s*dM<0かつs*dP<0|平均の進行と逆に、まだ平均の逆側で反発を始めたか|
|WAIT|同値0・不一致・未準備|位置だけ/傾きだけで決め打ちしない|

実売買方向は二実体と勢いが示したsを維持する。条件不一致だから自動で反対注文にしない。T/Rは仮説上の背景分類で、役割名だけを変えて同じ新規・同じ出口の利益が増えることはない。

SMA進行にはdM=(C[j−1]−C[j−21])/20という関係がある。古い足の脱落も含むので、新しい一足の注文圧力だけを示すわけではない。ローソク・SMA・MACDは同じ価格由来であり、独立した三票や確率の積として扱わない。

## 確定後にしか注文しない

p/jは同場・同限月の隣接した完全180秒足、missing0・有効OHLC・公開済み、公開key=(確認価格時計,原行)のstrict増加を要求する。発動はjが確定公開された時計で、一足前の終値や現始値へ遡って約定させない。pをjの形成開始前から知っていたとは仮定せず、判断時点jで両足が利用可能かを検査する。

局所の二足・平均窓は場替わり/非公開/欠枠/不正/番号・区間の飛越で切る。飛越後の有効なmissing0当足は新窓の種にできる。未準備を0へ補完したり、古い有利な平均へ代替したりしない。MACD/ATRの同限月数値銀行の継続規約とは分ける。

Pは各jで記録し、指標や時間で不採用でも後で同じPを取り直さない。現在足を確定させる前の暫定実体、将来の次足確認、事後のトレンド日分類を使わない。未来の足を追加/削除しても過去P・採否が変わらないことを検査する。

## 研究要旨の適用範囲

2026-11-06補足。[Lu・Shiu・Liu（2012）の論文要旨](https://www.sciencedirect.com/science/article/pii/S1058330012000092)は、台湾Top50構成株の2002〜2008年の日足で、二日パターンから反対パターンまで保有する方法を調べ、一部の上昇反転型に肯定的な結果を報告している。3分先物・始値等号の本規約・125/250先着・場内追尾とは対象も出口も異なり、その利益を本仮説へ移せない。ここでは要旨の範囲だけを確認し、全文の費用や検定仕様を確認済みとはしない。

[Chen・Zhou・Wang（2017）の著者公開要旨](https://arxiv.org/abs/1710.07470)は、CSI300先物の2012〜2016年・15/30/60秒でMA/KDJ/BB由来の規則を検証し、費用を含めると試験の利益が消失したと報告する。本研究や日本先物で利益が不可能という証明ではない。市場・尺度・規則・保有・費用を明示して比較し、パターンの名前や費用前の成績だけを採用根拠にしない、という問いとして参照する。
