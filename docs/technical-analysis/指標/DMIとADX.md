# DMIとADX：方向と方向性の偏りを分ける

資料閲覧日：2026-10-30。数値例は説明用に作成したもので、NK225・TOPIXの実測値ではない。条件カードは今後検証する仮説である。

## 最初に理解すること

価格が大きく動くことと、一定の方向へ進むことは異なる。上下へ激しく往復する価格と、少しずつ上がり続ける価格を、値幅だけでは区別できない。

DMIは、前の足に比べて高値がどれだけ伸びたか、安値がどれだけ下がったかを見る。`+DI` と `−DI` は上向き・下向きの動きを表す。ADXはその2つの偏りを平滑にする。**ADXが高いだけでは、買いか売りかは決まらない。** 楽天証券も方向をDI、強弱をADXで読む構成を説明している。[楽天証券・DMI](https://www.rakuten-sec.co.jp/web/fop/special/technical_analysis/chart_guide08/)

## 計算を追う

`H,L,C` は確定足の高値・安値・終値、`t−1` は前の足。まず高安の外側への変化を比べる。

```text
u_t = H_t − H_(t−1)
d_t = L_(t−1) − L_t

+DM_t = u_t （u_t > d_t かつ u_t > 0）、それ以外は0
−DM_t = d_t （d_t > u_t かつ d_t > 0）、それ以外は0

TR_t = max(H_t−L_t, |H_t−C_(t−1)|, |L_t−C_(t−1)|)
```

同じ幅だけ高値・安値の両側へ拡大した場合、両DMを0にする。内側に収まった足も両DMが0になる。終値の前足比を数える指標ではない。

例えば、前足が高値110・安値100・終値108、今の足が高値113・安値102なら、`u=3,d=−2` なので `+DM=3,−DM=0`。TRは `max(11,5,6)=11` である。

`RMA_n` を最初の `n` 入力の単純平均で初期化し、以後 `前値×(n−1)/n + 新値/n` で更新する平均とする。

```text
+DI_t = 100 × RMA_n(+DM)_t / RMA_n(TR)_t
−DI_t = 100 × RMA_n(−DM)_t / RMA_n(TR)_t
DX_t = 100 × |+DI_t − (−DI_t)| / (+DI_t + (−DI_t))
ADX_t = RMA_n(DX)_t
```

平滑後のDMが上3・下1、TRが10なら、`+DI=30,−DI=10,DX=50`。上1・下3でもDXは50になる。ADXの方向を読み取れない理由は、この絶対値にある。`n=14`、前ADX20・今DX50なら、次のADXは `(20×13+50)/14 ≈22.14`。今のDXへ一瞬で一致せず、過去の状態を残す。

式と初期化・丸めには実装差がある。TA-Lib固定版のコードにはDMの比較、DX、初回ADX、平滑更新、出力開始位置が記載されている。[TA-Lib v0.6.4・ADX実装](https://raw.githubusercontent.com/TA-Lib/ta-lib/v0.6.4/src/ta_func/ta_ADX.c)

## 一般的な読み方と、その説明になる仮説

`+DI > −DI` は上方向の拡大が相対的に優位、逆なら下方向が優位という読み方である。ADX上昇を方向性の強まり、低下を弱まりとして組み合わせる解説がある。[楽天証券・DIとADX](https://www.rakuten-sec.co.jp/web/fop/special/technical_analysis/chart_guide08/)

ここから「高値を買い上がる注文が繰り返され、安値を切り下げる動きより継続している」という需給の説明を作れる。ただし、これは**本研究の推論**である。DMは価格結果を数値化したもので、誰が買ったか、注文が新規か返済かを観測していない。ADX上昇から機関投資家の買いを立証することはできない。

方向性が継続するなら、逆張りより追随条件を優先する価値があるかもしれない。その検証では、ADXを入口そのものにする案と、別の入口を許可する環境条件にする案を分ける。[市場心理の扱い](../市場心理/README.md)、[組み合わせ](../組み合わせ/README.md)へ接続する。

## 同じ形でも失敗する場合

- 急落後に反発すると、下落由来の高いADXが残ったまま上がり始める。
- 狭い範囲でも片側への小さな拡大が続けば、方向性は偏る。ADXの高さは円建ての利益幅ではない。
- DIが交差しても、その後すぐ再交差することがある。方向の切替と収益性は別問題である。
- 大きな足の後は平滑値が残り、現在の流動性やボラティリティとずれる。

ADXが下がったことだけで、価格の反転まで断定しない。上昇の勢いが弱まっても、価格は緩やかに上がり続けうる。

## 自動化で固定する仕様

本章の平均形式では、連続データ・前値欠損なしならDMに前足が必要で、ADXはDIの後にDXの平均も必要となる。`n=14` の初回ADXは28本の足を要する。TA-Libとの一致には、見かけの本数だけでなく最初に平滑化する範囲を照合する。初回の出力直後を安定した値と同一視しない。

TRの平滑値0、DIの和0は基礎仕様では欠損にする。欠損後の前値維持・再初期化は試行で固定し、比較不能な足で交差を発生させない。前セッションの高安・終値を継ぐかも設定項目にする。日足の14期間を14分へ変えた効果は未検証である。

原板から足を作るとき、価格時刻と受信時刻の違い、空の足、途中足、交差板の扱いを揃える。板の提示数量はDMIの計算入力ではない。ラージのDMIをmini・microへ利用しても、対象商品の約定を保証しない。[実データの制約](../../データと閲覧形式.md)
