# 足内値幅の中央値

識別子：I15。確認日：2026-11-09。本研究で利益保護へ追加する値幅尺度であり、一般的な最適売買ルールと主張するものではない。

## 何を測るか

確定足ごとの `高値−安値` を並べ、その中央の値を使う。中央値は順位に基づくため、少数の極端な値に平均ほど引かれない。[NIST：位置の尺度](https://itl.nist.gov/div898/handbook/eda/section3/eda351.htm)

```text
range_i = High_i − Low_i
V = max(商品の呼値, median(range_1,...,range_n))
```

次の保護候補は同じ場・限月の連続した確定3分足5本を使う。例えば値幅が20、25、30、35、400ptなら中央値は30pt、単純平均は102pt。これは計算例で、実データの成績ではない。

ATRは前終値との飛びを含むTRを平滑する。足内値幅の中央値は、その飛びを含めず、順位から代表値を作る別の尺度である。[Fidelity：ATRの定義](https://www.fidelity.com/learning-center/trading-investing/technical-analysis/technical-indicator-guide/atr)、[本研究のATR](ATR.md)

## 使う仮説と限界

大きい開始足を初期値にしたATRを取得時固定すると、起動額や追尾幅へその影響が残る。直近の足内値幅で距離を制限すれば、現在の小さい往復に合わせて利益を保護できるかを検証する。低い値が上昇・下降・反転を示すとは解釈しない。

本当に変動が拡大しても、5本中少数の大足だけでは中央値が変わりにくい。必要な損切り距離を過小評価する反例もある。ギャップや板飛びのリスクが消えるわけではなく、固定の最小幅、床の非緩和、Source返済、費用・遅延と実約定を別に確認する。

公表済みの連続5本が揃うまで未知とする。欠足・不良価格・場/限月の変更で窓を初期化し、前値や0で補完しない。量だけ未知で価格が正常な場合は、価格の窓を壊さず量の未知を別に記録する。3分足5本は15分足1本の高安幅と同一ではない。

## 再利用する設定

期間と足幅、呼値、当足を含むか、足内値幅かTRか、欠足/場切替、利用可能時刻、取得時固定か更新かを明記する。次案では新規時Vから起動額を固定し、起動後の幅には新しいVも使う。値幅増大だけで保護床を不利に戻さない。[起動・幅・床の分解](../組み合わせ/ATRと追尾決済.md)

NISTが支えるのは中央値の統計的性質、Fidelityが支えるのはATRの一般定義である。5本、3分、倍率、費用後起動額、NK225損益の改善は本研究の未検証仮説として分ける。
