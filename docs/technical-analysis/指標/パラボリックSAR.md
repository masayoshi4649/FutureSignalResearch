# パラボリックSAR：進行する相場へ追随線を近づける

資料閲覧日：2026-10-30。例は説明用。期間・加速因数と売買条件の有効性は未検証である。

## 点の位置から何を読むか

SARは価格の上下に描かれる追随水準である。トレンド内の極値へ少しずつ近づき、新高値・新安値の更新に応じて追随を速める。「有利な方向へ進んだ利益の一部を、反転で失いすぎないようにする」という使い方を考えやすい。

一般的な解説では、価格の下にSARがあれば上向き、上にあれば下向きと読み、横断を転換候補とする。楽天証券は加速因数の例とレンジでの弱点も説明している。[楽天証券・パラボリック](https://www.rakuten-sec.co.jp/web/fop/special/technical_analysis/chart_guide09/)

**チャートの点は、証券会社に発注済みの逆指値ではない。** 「SARに到達した」と「その価格で全量決済できた」を分ける。

## 式を小さく分解する

`S_t` を足 `t` に向けて事前計算した水準、`EP_t` を足 `t` までの現在方向の極値、`AF_t` を加速因数とする。方向が続く場合の基本は次の形になる。

```text
次足の暫定水準 = S_t + AF_t × (EP_t − S_t)

上昇局面のEP = その局面の最高値
下降局面のEP = その局面の最安値
```

上昇中に `S=100,EP=110,AF=0.02` なら、暫定水準は100.2。次に極値が112へ伸び、AFを0.04へ増やすなら、次の計算は `100.2+0.04×(112−100.2)=100.672`。価格と線の差だけでなく加速因数も変わる。

ただし、この漸化式だけではSARを実装できない。一般的な処理では次の要素を持つ。

- 直近の高安を越えて線が入り込まないよう、上昇なら直近安値側、下降なら直近高値側へ制約する。
- 価格が事前の水準を横断したら方向を反転し、EP・AF・SARを再設定する。
- 極値が更新されたときだけAFを増やし、上限を設ける。

初期値0.02・増分0.02・上限0.2は説明によく用いられる値で、分足先物の最適値ではない。TA-Lib固定版は初期方向や反転・高安制約の具体的実装を公開している。[TA-Lib v0.6.4・SAR実装](https://raw.githubusercontent.com/TA-Lib/ta-lib/v0.6.4/src/ta_func/ta_SAR.c)

## 一般的な判断と需給の説明

追随型の決済に使う場合、買いを保有中は下側の線を上へ引き上げ、横断を決済候補にする。SARの反転ごとに反対方向へ新規建てする案もあるが、決済だけに使う案と分ける。[楽天証券・売買サインと限界](https://www.rakuten-sec.co.jp/web/fop/special/technical_analysis/chart_guide09/)

「高値更新を追う参加者が増えて価格が伸びた後、更新が止まると利益確定や反対注文で押し戻される」という説明は考えられる。しかし、**これは本研究の心理・需給仮説**である。SARが観測するのは高安と経過で、参加者の利益確定注文を識別していない。

また、極値が更新されなくても、SARは基本式によって極値へ近づく。横断は反対売買圧力の急増だけでなく、「時間が経ち、線が近づいた」結果でも起こる。SAR反転を、新情報による需給転換と同一視しない。[市場心理の扱い](../市場心理/README.md)

## 反例と失敗しやすい場面

- 狭いレンジで線を何度も横断すると、ドテンを繰り返して費用が増える。
- 押し目で線に触れた直後、元の上昇が再開することがある。
- ギャップや板の薄い局面では、線を越えた最初の約定可能価格が遠い場合がある。
- 加速を強めると反応が速くなる一方、通常の揺れでも決済されやすくなる。

SARの上下だけで、トレンドの存続確率や期待損益は得られない。到達率・利益保持・取引回数・費用を同時に評価する。

## 自動化で最も混同しやすい時点

足 `t` の高安を使って作った次足の候補は、足 `t+1` から利用する。足 `t+1` の高安を確認して線を更新し、その線が足の開始時から有効だったとする計算は先読みになる。

さらに、TA-Libは反転した足の表示用SARを、反転後の側の値へ差し替える処理を持つ。最終チャートのその足の点と、横断前から有効だった水準は同じとは限らない。研究では「事前に有効な線」「観測後の方向」「表示用の線」を区別して保存または再現する。[TA-Lib・反転時の出力](https://raw.githubusercontent.com/TA-Lib/ta-lib/v0.6.4/src/ta_func/ta_SAR.c)

足内の順序が不明なら、高値更新による線の変更と安値到達のどちらが先だったか決められない。確定足方式では次足から更新し、途中更新方式は原板の順序と時刻の制約を明示して別研究とする。

初期方向の決定には実装差がある。固定版のTA-Libを使うなら最初の2足の方向判定と初期高安、AFの扱いまで合わせる。欠損やセッション境界で状態をどう引き継ぐか、ギャップ時にどの価格で成立扱いにするかも規定する。原板の価格時計では板の実到着時刻を完全には復元できない。[実データの制約](../../データと閲覧形式.md)

## 再利用する条件カード

| 項目 | 候補の定義 |
| --- | --- |
| 役割 | 別の追随入口に対する決済線 |
| 環境 | 方向条件が成立し、初期化と板の品質条件を満たす |
| 発動 | 前足までで有効化した線への到達。終値判定なら別条件 |
| 無効化 | 方向未確定・欠損・線と注文の対応不明 |
| 出口 | SAR到達の決済、独立の保護注文、時間決済 |
| 重複 | ATR追随線やMA割れと役割が重なる。出口を一つずつ比較 |
| 実装仕様 | 初期方向、AF初期・増分・上限、高安制約、反転、線の有効時刻 |

SAR決済後の逆向き新規は、このカードには含めない。組み合わせの全体規則で独立に定める。[組み合わせ](../組み合わせ/README.md)
