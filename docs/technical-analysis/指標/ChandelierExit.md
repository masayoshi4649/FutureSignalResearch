# Chandelier Exit：高安から変動幅を差し引く

確認日：2026-11-13。[指標目次](README.md) / [C06・ATRと追尾決済](../組み合わせ/ATRと追尾決済.md)。既存C06の派生を詳しくした教材で、新しい汎用表行は増やさない。

## 一般定義と式

[Bollinger公式提供元のstop説明](https://bollingerbands.us/help-stops.php)はLeBeauに由来する方式を紹介する。LeBeau本人の原著書籍ではない。取得後の期間から、買いは最高値−kATR、売りは最安値＋kATRを計算する。直近n足最高/最安を使う別の公開実装もあり、取得後高安と同じ集合ではない。

```text
買い計算線_t = HH_since_entry − k ATR_t
売り計算線_t = LL_since_entry ＋ k ATR_t
```

原典説明はATR拡大による線の後退を許す。そのままの計算線と、本研究の買いmax(旧床,計算線)/売りmin(旧床,計算線)は区別する。例えば買いの旧床103、HH110、ATR3、k3なら新計算線101だが、非緩和床は103を保つ。

## 心理の仮説

小さい利食いの押戻しには通常揺れの余裕を与え、それを超える逆行で撤退する。ATR幅に市場全体の損切りが集中しているという証拠ではなく、自分の許容を定義する方法である。

## 本研究の派生と限界

一定利益arm・最低床0の上で、方向/構造維持時の通常幅と、支持否定＋勢い/量の失速時の狭幅を比較する。初期SL・arm・幅・基準高安を同時に変えて指標単独の効果としない。取得前の当該足高値を取得後峰へ混入せず、確定足の線は公表後から使う。ATR未知は0幅にせず既設床/固定安全規則を維持する。原行順序/約定遅延/費用を含む実比較が必要で、床価格は約定保証ではない。
