# 指標別の教科書

個別調査日：2026-10-30。[教科書の目次](../README.md) / [組み合わせ](../組み合わせ/README.md) / [市場心理](../市場心理/README.md)

一つのファイルで、指標の意味、式と数値例、一般的な判断、その背景に考えられる心理、失敗場面、機械化、出典を読める構成にした。各指標について原則二つ以上の公式・一次資料を個別に確認している。数値例と条件カードは本教材の未検証例である。

## 1. 指標から探す

| 指標 | まず理解する問い | 主な利用場面 |
| --- | --- | --- |
| [移動平均線](移動平均線.md) | 平滑な方向と現在価格はどの関係か | 方向、支持抵抗、交差、決済 |
| [移動平均乖離率](移動平均乖離率.md) | 平均からどの程度離れているか | 相対的な位置、復帰の候補 |
| [MACD](MACD.md) | 速い平均と遅い平均の差はどう変わるか | 勢い、追随、調整からの回復 |
| [RSI](RSI.md) | 上昇・下落の値幅の配分はどうか | 勢い、偏りからの復帰、方向 |
| [ボリンジャーバンド](ボリンジャーバンド.md) | 最近の価格の散らばりの中でどこにいるか | 相対位置、収縮と拡大 |
| [サイコロジカルライン](サイコロジカルライン.md) | 上昇した比較は何割あるか | 回数の偏り。人数の心理調査ではない |
| [ストキャスティクス](ストキャスティクス.md) | 直近の高安の範囲で終値はどこか | 価格位置、勢い、復帰 |
| [DMIとADX](DMIとADX.md) | 方向と偏りの強さをどう分けるか | 追随する環境と方向の照合 |
| [ATR](ATR.md) | ギャップを含む通常の変動幅はどの程度か | 保護幅、枚数、追尾決済 |
| [パラボリックSAR](パラボリックSAR.md) | 高安の更新へ撤退候補をどう追随させるか | 追尾、反転候補、注文との区別 |
| [一目均衡表](一目均衡表.md) | 複数期間の中心値と雲のどこに価格があるか | 方向、位置、支持抵抗 |
| [VWAP](VWAP.md) | 選んだ区間の数量加重価格とどの関係か | 日中基準、位置、執行評価 |

「平均移動線」で探す場合は、一般的な名称の[移動平均線](移動平均線.md)を参照する。DMI・ADXは計算と解釈を共有する同じ体系なので一つの文書にまとめ、ATRは方向を表さない別の指標として独立させた。

## 2. 共通する読み方

各章の一般的な判断は、教育資料で紹介される使い方である。市場での普及率や利益の証明を意味しない。心理の節は、説明がどの観測と整合するかを考えるためのもので、参加者の意図を観測した記録ではない。

計算例は小さな架空の価格で検算できるようにした。実際のNK225・TOPIXの価格予測ではない。日足でよく使われる期間や30・70等の数値を、分足先物の適正値としない。
