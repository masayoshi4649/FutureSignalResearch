# RSIを理解する

調査・作成日：2026年10月30日。期間・閾値・条件カードは説明用で、先物での収益性は未検証。

## 直感：上向きと下向きの値幅を比べる

RSIは、終値の変化を上昇幅と下落幅へ分け、どちらへ偏ったかを0～100で示す。上昇した足の割合、買い人数の割合、将来上がる確率ではない。楽天証券は70・30の目安と強い一方向相場での難しさを説明し、TradingView公式は平滑化を含む式を示している。[楽天証券](https://www.rakuten-sec.co.jp/web/fop/special/technical_analysis/chart_guide04/)、[TradingView公式](https://www.tradingview.com/support/solutions/43000502338-relative-strength-index-rsi/)

## 計算と数値例

`C_t` は確定足の終値。本教材ではワイルダー型平滑平均を使う。

```text
Δ_t = C_t − C_(t−1)
U_t = max(Δ_t, 0)
D_t = max(−Δ_t, 0)
平均U_t = ((n−1)×平均U_(t−1) + U_t) / n
平均D_t = ((n−1)×平均D_(t−1) + D_t) / n
RSI_t = 100 × 平均U_t / (平均U_t + 平均D_t)
```

最初の平均U・平均Dは各 `n` 個の変化の単純平均とする説明用仕様。`n=4` とし、終値の変化が `+4, −2, +3, −1` なら、平均Uは `7/4=1.75`、平均Dは `3/4=0.75`、RSIは70。上昇した足は半分でも値幅の比率は70になる。

次に2下がると平均Uは1.3125、平均Dは1.0625、RSIは約55.26。毎回直近4個だけを単純平均し直す方式とは結果が違う。楽天証券の記事でもRSI1・RSI2の計算差を説明しているため、名称だけで値を一致させない。

平均Dだけ0なら100、平均Uだけ0なら0。両方0は比率を定義できないため、本教材の研究案では欠損として新規売買を停止する。実際のツールが返す値は導入時に照合する。

## 一般に紹介される判断

| 観測 | よくある解釈 | 読み過ぎないための区別 |
| --- | --- | --- |
| 70以上・30以下 | 買われ過ぎ・売られ過ぎ | 値幅の偏りであり、反転時刻ではない |
| 30以下から30超へ復帰 | 下向きの偏り緩和、買い候補 | 安値を付け終えた保証はない |
| 50より上 | 上向きの変化が優勢 | 比較期間内の平均値幅の関係に限る |
| 価格安値更新、RSI安値切上げ | 下落の勢いへの注意 | 下落継続中の小休止でも起こり得る |

50は平均Uと平均Dが等しいことを意味し、価格の横ばいを証明しない。価格の位置や値幅の大きさをRSIだけで判断することもできない。

## 市場心理として考えられる説明

**心理の推論。** 下落が続いた後、利確の買戻しや割安と考える買いが増えれば下向きの変化が減り、RSIが回復するかもしれない。上昇後に利確売りが増える場合も対称に説明できる。

**観測との境界。** 式で分かるのは終値変化の配分だけである。参加者が恐怖を感じた、買いたい人が買い尽くした、資金が尽きた、とまでは分からない。新規買いと売り建玉の買戻しも区別できない。心理仮説を主張するには約定や注文行動等の追加観測が要る。

## 崩れる場面

小さくても上昇だけが続けばRSIは100に近づく。高い値は継続する上昇と両立し、「70になったから売る」を繰り返すとトレンドに逆らうことになる。反対に下落中の30復帰も一時的な反発かもしれない。

RSIが下がっても、価格が元の水準まで戻るとは限らない。上昇速度が鈍る、何本か逆向きに動く、といった変化でも値は下がる。過熱という言葉を、客観的な割高・割安と同一視しない。

## 機械化・初期化・先読み

`n` 個の変化には `n+1` 個の終値が必要。期間14は代表例で、14日と分足14本に同じ性質を期待する根拠はない。平滑方法、初期値、助走期間、欠損、セッションでのリセットを固定する。

復帰は `RSI_(t−1)≤30 かつ RSI_t>30` とする。未確定足では行ったり来たりするため、基礎研究では確定後に一度だけ判定する。価格・RSIの山谷を右側の足で確定する方法では、その時刻まで待ち、過去の山谷時刻に発注を置かない。

## 再利用する条件カード：レンジ条件下の復帰

| 項目 | 買い側の研究用定義 |
| --- | --- |
| 役割 | 平均回帰手法の入口候補 |
| 環境 | 過去だけで判定するレンジ条件が成立。判定方法は組み合わせ側で固定 |
| 発動 | ワイルダー型RSI14本が30以下から30超へ復帰。建玉・未約定新規なし |
| 無効化 | レンジ条件の消失、指標欠損、新規停止時刻後 |
| 出口候補 | RSI50到達、分析上の下落再開、保護用逆指値、セッション返済期限 |
| 重複情報 | ストキャスティクス等と値動き情報が重なる。独立な証拠とは限らない |
