# 移動平均乖離率を理解する

調査・作成日：2026年10月30日。数値・条件カードは説明用で、先物での有効性は未検証。

## 直感：平均からどれだけ離れたか

乖離率は、今の価格と移動平均の距離を割合に直した値である。同じ400円の差でも基準が40,000か4,000かで意味が違うため、平均に対する比率を使う。マネックス証券は計算と逆張りでの利用、SMBC日興証券は材料や銘柄で経験則が崩れる点を説明する。[マネックス証券](https://info.monex.co.jp/technical-analysis/indicators/019.html)、[SMBC日興証券](https://www.smbcnikko.co.jp/terms/japan/ka/J0451.html)

## 計算と数値例

`C_t` は確定足の終値、`MA_t` は同じ時点までの指定した移動平均とする。

```text
乖離率_t = 100 × (C_t−MA_t) / MA_t          ［基準0%］
比率表示_t = 100 × C_t / MA_t              ［基準100%］
比率表示_t = 乖離率_t + 100
```

平均40,000・終値40,400なら、本教材の乖離率は+1%。楽天証券の指定記事の比率形式では101%となる。0基準の「+5%」を100基準の「105%」と混同しない。[楽天証券の表示形式](https://www.rakuten-sec.co.jp/web/fop/special/technical_analysis/chart_guide02/)

**平均が動く例。** 5本の終値が `39,900, 39,900, 39,900, 39,900, 40,400` なら平均40,000・乖離率+1%。次の4本も40,400なら平均は40,400へ上がり、乖離率は0になる。価格は下落していない。

したがって「乖離が解消した」と「逆張りした建玉が利益になった」は別である。移動平均は固定された決済目標ではなく、時間とともに動く基準である。

## 一般に紹介される判断

| 観測 | 一般的な解釈 | 確実に分かること |
| --- | --- | --- |
| 大きなプラス | 上方への行き過ぎ、売り候補 | 価格が平均を大きく上回る |
| 大きなマイナス | 下方への行き過ぎ、買い候補 | 価格が平均を大きく下回る |
| 極端な領域から中心へ復帰 | 偏りの緩和 | 価格と動く平均の比率が縮小 |
| 0より上の状態が継続 | 上向きの環境の候補 | 価格が平均を上回り続ける |

閾値は商品の値動き、足、平均期間で変わる。資料にある日足の経験的な水準を、NK225・TOPIX先物の分足へそのまま移す根拠はない。

## 市場心理として考えられる説明

**心理の推論。** 急伸後には利確したい買い手が増え、高い価格を追う買い手が減れば価格が戻るかもしれない。急落後には売りの利確による買戻しや、新規の買いが反発を支える可能性がある。

**観測との境界。** 平均から離れたことは観測できるが、誰が利確したいか、買い余力がどれだけ残るかは式に含まれない。資料の「引き戻される」という説明は、物理的な復元力や数学的な義務を意味しない。基準の平均自体も全参加者の平均建値ではない。

## 崩れる場面

新しい材料で妥当と考えられる価格帯が変われば、過去平均からの大きな乖離が続く場合がある。小幅な戻り後にさらに下落する場合もあり、「過去最大に近いから底」とは決められない。

ボラティリティが変わると同じ±1%でも珍しさが変わる。期間を短くすれば平均が価格を追いやすくなり、乖離率は縮みやすい。0へ戻っても、前述の例のように価格が逆行しないまま平均が追いついただけかもしれない。

## 機械化・初期化・先読み

平均方式と期間、0基準か100基準かを保存する。平均が0、欠損、必要本数不足なら計算しない。EMAを使う場合は初期値と助走期間も必要。確定足で判定し、その後の利用可能な観測から約定をモデル化する。

極端さを過去の分位点で定めるなら、閾値を求める窓は判定時点より前に限定する。全期間の最大・最小や分位点を使い、その期間の初日から既知だった扱いにしない。セッション終了後に「本日はトレンド日」と分類して入口を除くことも先読みになる。

## 再利用する条件カード：負の乖離からの復帰

| 項目 | 買い側の研究用定義 |
| --- | --- |
| 役割 | 平均回帰手法の入口候補 |
| 環境 | 過去だけで判定したレンジ条件。移動平均20本SMAを仮置き |
| 発動 | 乖離率が `前足≤−h、現足>−h`。`h>0` は開発期間で事前固定 |
| 無効化 | レンジ条件の消失、平均欠損、新規停止時刻後、既存建玉・未約定新規あり |
| 出口候補 | 乖離率0以上、固定した保護用逆指値、セッション返済期限 |
| 重複情報 | 移動平均に対する価格位置を再表現。RSI等とも価格変化が重なる |
| 実装条件 | 基準0、期間・方式、復帰不等号、閾値の決定窓、費用、出口優先順位を固定 |

`h` とレンジ判定が未定ならカードは戦略として未完成。反転を待たずに領域へ入った時点で買う案は、別の入口として比較する。基準へ戻るまで保有し続ける規則にはせず、保護・時間決済を併設する。
