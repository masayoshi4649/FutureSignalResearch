# 指標の計算とシグナル

作成・資料閲覧日：2026年10月30日。

本章は、テクニカル指標を「同じ入力から同じ判定を再現できる式」に直すための教科書である。各社の解説を短く整理し、研究用の計算仕様と失敗しやすい条件を補った。本文の売買条件・数値はすべて検証候補であり、NK225先物・TOPIX先物での収益性を確認した結果ではない。

指標を個別に学ぶ入口は[指標別の教科書](指標/README.md)へ移した。直感的な説明、検算できる数値例、市場心理、反例と出典対応表は各ページで読む。本章は共通の記号・初期化と数式の横断参照に使う。[組み合わせ](組み合わせ/README.md) / [心理の根拠](市場心理/README.md)

## 1. 式を読むための約束

### 入力と時刻

| 記号 | 意味 |
| --- | --- |
| `t` | 判定対象の確定済みの足。過去の足は `t−1`、`t−2` と表す |
| `O_t, H_t, L_t, C_t` | その足の始値・高値・安値・終値 |
| `V_t` | その足の約定数量。板の提示数量とは区別する |
| `n` | 計算に使う足の本数。日足なら日数、5分足なら5分足の本数 |
| `HH_n(t), LL_n(t)` | `t` を含む直近 `n` 本の高値の最大値、安値の最小値 |
| `SMA_n(X)_t` | 系列 `X` の直近 `n` 本の単純平均 |

足が確定する前の高値・安値・終値は変化する。基礎研究では確定足だけで指標を更新し、判定後の発注・約定を別の時刻として扱う。足の終値を読んでから、その終値で必ず約定したことにはできない。

同じ25期間でも、25日と25分では異なる現象を測る。日足の解説で見た期間や閾値を分足に移せる根拠はない。足の長さ、価格の種類、限月、セッションの境界、指標の初期化を試行ごとに保存する。

### 交差を厳密に定義する

上抜けを `A_(t−1) ≤ B_(t−1) かつ A_t > B_t`、下抜けを `A_(t−1) ≥ B_(t−1) かつ A_t < B_t` とする。「上にある」という状態と、「上に抜けた」という一回の事象は別である。前者をそのまま発注条件にすると毎足注文する実装になり得る。既存建玉・未約定注文・再エントリーの条件も必要になる。

閾値との交差では `B_t` を一定値に置き換える。欠損値や未初期化値との比較は偽とし、売買判定を行わない。連続する同値の扱いもこの不等号に従う。

### 平滑化と初期化

```text
SMA_n(X)_t = (X_t + X_(t−1) + … + X_(t−n+1)) / n

EMA_n(X)_t = α X_t + (1−α) EMA_n(X)_(t−1)
α = 2 / (n+1)

RMA_n(X)_t = X_t/n + (1−1/n) RMA_n(X)_(t−1)
```

本章の `RMA` はワイルダー型の平滑平均を意味する。`EMA` と `RMA` は係数が異なる。以下の研究用仕様では、初回の値を最初の `n` 個の連続した有効入力の単純平均とし、それ以前は欠損とする。欠損を無視して離れた入力同士を黙ってつながない。欠損後に前値を維持するか、必要本数から再初期化するかなど、更新・再開の規則を試行で固定する。ただし、ライブラリやチャートとの完全一致を求める場合には、当該実装の初期値と出力開始位置に合わせる。

初期値が違うと、同じ後続入力でも平滑値はしばらく異なる。EMAの初期誤差は、更新を `k` 回行うと `(1−α)^k` 倍に減る。この関係から助走期間を決められる。単に `n` 本揃ったことと、初期値の影響が小さくなったことは同義ではない。

### 最初に出力できる足

以下は欠損がなく、上記の単純平均による初期化を採る場合の最低本数である。ライブラリの出力開始位置や追加の助走期間とは区別する。

| 指標 | 初回値に必要な入力 | 交差判定の注意 |
| --- | --- | --- |
| SMA・EMAの `n` 期間 | 終値 `n` 個 | 前の有効値との比較にはさらに1本必要 |
| RSIの `n` 期間 | 変化量 `n` 個、すなわち終値 `n+1` 個 | 全横ばい等では比率が未定義のままになり得る |
| MACD(12,26,9) | MACDは終値26個、シグナルは34個 | 両線の連続した比較は最速で35本目 |
| DMI・ATRの `n` 期間 | 前足を必要とする差分方式なら足 `n+1` 本 | 最初のTRの扱いによって開始位置が変わる |
| ADXの `n` 期間 | 上記DMIの後にDXを `n` 個平均。最速で足 `2n` 本 | `n=14` なら28本。ゼロ分母があれば遅れる |

## 2. 指標を役割で選ぶ

| 指標 | 何を圧縮しているか | 研究での主な役割 | 苦手になりやすい条件 |
| --- | --- | --- | --- |
| 移動平均 | 価格水準の平均 | 方向判定、追随、手仕舞い | 平均の周囲を往復する相場 |
| 移動平均乖離率 | 平均に対する相対距離 | 過度な乖離の検出 | 乖離が拡大し続ける相場 |
| MACD | 速い平均と遅い平均の差 | 勢いの変化、追随 | 小さな往復、転換直後 |
| RSI | 上昇幅と下落幅の配分 | 勢い、反転候補 | 高値圏・安値圏への張り付き |
| ボリンジャーバンド | 平均と価格の散らばり | 収縮・拡大、相対的な位置 | 接触だけで逆張りする運用 |
| サイコロジカルライン | 上昇した足の割合 | 連騰・連落の偏り | 上下の値幅が非対称な相場 |
| ストキャスティクス | 直近の値幅内での終値位置 | 反転候補、勢い | 直近高値・安値の継続更新 |
| DMI・ADX | 高安の方向変化とその偏り | 方向・トレンドの強さの分離 | 平滑化による遅れ、急反転 |
| パラボリックSAR | 高安の更新に追随する水準 | 追随型の決済候補 | 狭いレンジの反復横断 |
| ATR | 前の終値も含めた値幅 | 損切り幅・数量の尺度 | 方向の判断には使えない |
| 一目均衡表 | 複数期間の高安の中間値 | 方向・位置関係 | 描画位置と利用可能時刻の混同 |
| VWAP | 約定数量で重み付けした価格 | セッション内の基準価格 | 約定数量が不正確な入力 |

この役割分けは本研究の整理である。同じ価格から作る指標を多数並べても独立した証拠が増えるとは限らない。例えば移動平均とMACD、RSIとストキャスティクスは情報が重なりやすい。指標を加える際は、単独の場合に対して未使用期間の成績がどう変わるかを調べる。

## 3. 移動平均線：価格の方向を平滑に見る

移動平均は短期の変動をならす。短い期間は反応が速く、長い期間は滑らかになる。短期線と長期線の交差は代表的な判定だが、横ばいでは交差を繰り返しやすい。[楽天証券・移動平均線](https://www.rakuten-sec.co.jp/web/fop/special/technical_analysis/chart_guide01/)

**計算。** 基本式は前節のSMA・EMAを使う。終値が `100, 101, 102, 103, 104` なら5期間SMAは `102`。次の終値が `105` になれば最古の `100` を除き、SMAは `103` になる。平均が上向きでも次の価格上昇は保証されない。

**研究用の条件例。** 短期5本・長期20本を説明用に仮置きし、短期線が長期線を上抜け、かつ長期線が前足より上向きなら買い候補とする。買い建玉は逆交差、終値の長期線下抜け、またはセッションの決済期限で手仕舞う。売りは対称条件を別途定義する。期間と傾きの条件は未検証である。

**機械化の論点。** 傾きを1本の差で測るか、複数本の回帰で測るかで別の手法になる。価格差の絶対値は商品間で比較しにくいため、価格比やATRで規格化する選択肢もある。短期線・長期線にSMAとEMAを混在させる場合も設定に明記する。

## 4. 移動平均乖離率：平均からの距離を測る

同じ名称で基準値が異なる点が重要である。楽天証券の指定記事の乖離線は、価格が移動平均と等しければ100%になる形式である。[楽天証券・移動平均乖離線](https://www.rakuten-sec.co.jp/web/fop/special/technical_analysis/chart_guide02/)

```text
本章の乖離率_t = 100 × (C_t / MA_t − 1)       ［基準は0%］
楽天記事の比率_t = 100 × C_t / MA_t          ［基準は100%］
楽天記事の比率_t = 本章の乖離率_t + 100
```

例えば平均40,000・終値40,400なら、本章では `+1%`、比率形式では `101%` である。閾値の取り違えは売買条件を根本から変えてしまう。

**研究用の条件例。** 過去だけで決めた負の乖離閾値を下回った後、その閾値を上抜けて復帰したときに買い候補とし、平均への接近で決済する。「下回っている間に買う」と「下回った後に戻ってから買う」は別の試行にする。閾値を商品・時間帯・ボラティリティごとに変えるなら、その規則も事前に固定する。

**限界。** 価格が平均へ戻らず、平均が価格へ近づく場合もある。大きな乖離を「必ず戻る」と解釈しない。平均が0なら比率を計算しない。元記事の日足の経験的水準を分足先物の閾値に採用する根拠は得られていない。

## 5. MACD：速い平均と遅い平均の差を見る

MACDは、異なる期間のEMAの差と、その差を平滑にした線を使う。指定記事では12・26・9期間が代表例として紹介され、交差とゼロ付近の位置が解説されている。[楽天証券・MACD](https://www.rakuten-sec.co.jp/web/fop/special/technical_analysis/chart_guide03/)

```text
MACD_t = EMA_fast(C)_t − EMA_slow(C)_t
Signal_t = EMA_signal(MACD)_t
Histogram_t = MACD_t − Signal_t
```

本章ではシグナル線をEMAと定義する。単純平均を使うソフトの結果とは一致しない。`fast < slow` を満たすよう入力を検証し、各EMAの初期化が済むまではシグナルを無効にする。

**読み方。** MACDが正なら短期EMAが長期EMAより高い。ヒストグラムが正ならMACDがシグナル線より高い。「正である」「増えている」「ゼロを上抜けた」はそれぞれ別の条件である。正の値が縮小していても価格は上がり得る。

**研究用の条件例。** MACDがシグナル線を上抜け、MACDが0を超えている場合だけ買い候補とする。下抜けで買いを決済する。別案としてゼロ交差を入口にする場合は、シグナル線交差と混ぜずに比較する。

**限界。** 横ばいでは交差が多くなり、急変時には追随が遅れる。MACDの数値は価格差なので、NK225とTOPIXの値を同じ閾値で比較しない。商品間の比較には価格やATRによる規格化を別途検討する。

## 6. RSI：上昇幅と下落幅の割合を見る

RSIは、値動きのうち上向きの変化が占める割合を0～100の尺度で表す。指定記事ではRSI1とRSI2で計算方法が異なることも説明されている。[楽天証券・RSI](https://www.rakuten-sec.co.jp/web/fop/special/technical_analysis/chart_guide04/)

```text
Δ_t = C_t − C_(t−1)
U_t = max(Δ_t, 0)
D_t = max(−Δ_t, 0)

平均上昇幅_t = RMA_n(U)_t
平均下落幅_t = RMA_n(D)_t
RSI_t = 100 × 平均上昇幅_t / (平均上昇幅_t + 平均下落幅_t)
```

**計算の選択。** 本章の基準はワイルダー型の平滑化。直近 `n` 個の上昇幅・下落幅を毎回SMAで平均する方式は別仕様として記録する。ワイルダー型の更新式と初期平均は、実装の一次資料でも確認できる。[TA-Lib v0.6.4・RSI実装](https://raw.githubusercontent.com/TA-Lib/ta-lib/v0.6.4/src/ta_func/ta_RSI.c)

平均上昇幅が3、平均下落幅が1ならRSIは75。下落幅が0で上昇幅だけが正なら100、逆なら0となる。両方0のときは数学的に比率が定まらない。本研究の基礎仕様では欠損として新規売買を行わない案を採る。50または0を返す実装とは結果が異なるため、利用するライブラリの版と挙動を必ず確認する。

**研究用の条件例。** 30を下回った後に30を上抜けて復帰したら買い候補、50への到達で決済候補とする。70・30は広く紹介される目安で、適正値が確認されたわけではない。順張りで使う場合は「上昇方向にあるときの押し目からの回復」など、前提を変えて別試行にする。

**限界。** 強い上昇で70以上、強い下落で30以下に居続けることがある。過熱の検出と転換時点の予測は同じではない。将来の山谷を見てからダイバージェンスを付ける実装は先読みになる。山谷の確定時刻も記録する。

## 7. ボリンジャーバンド：価格の散らばりを見る

バンドは中心となる平均に標準偏差の倍数を加減する。楽天証券の記事では典型価格 `TP=(H+L+C)/3` を入力にしているため、終値を使う設定と一致しない。[楽天証券・ボリンジャーバンド](https://www.rakuten-sec.co.jp/web/fop/special/technical_analysis/chart_guide05/)

```text
X_t = C_t                         ［本章の説明用入力］
Middle_t = SMA_n(X)_t
σ_t = sqrt(Σ_(i=0…n−1) (X_(t−i) − Middle_t)^2 / n)
Upper_t = Middle_t + k σ_t
Lower_t = Middle_t − k σ_t

%b_t = (X_t − Lower_t) / (Upper_t − Lower_t)
BandWidth_t = (Upper_t − Lower_t) / Middle_t
```

標準偏差の分母は本章では `n` とする。標本標準偏差の `n−1` を既定にするライブラリがあるので注意する。`%b` と `BandWidth` はここでは比率、百分率表示なら100倍する。バンド幅0の `%b`、中心値0の `BandWidth` は欠損とする。

**原著者の説明との照合。** ボリンジャー本人は、20期間・2σを既定例としつつ適切な値は市場によること、バンドへの接触だけでは売買判断にならないこと、強いトレンドではバンドに沿って進むこと、正規分布に基づく確率をそのまま想定しないことを明示している。[ボリンジャー本人・使用規則](https://www.bollingerbands.com/bollinger-band-rules)

したがって「±2σだから次の足も95%の確率で内側に戻る」という理解は採らない。これは、本章で分足先物へ適用するときの重要な解釈である。

**研究用の条件例。** 平均回帰案では、過去のデータだけで定義したレンジ条件下で下側バンド外から内側への復帰を買い候補とし、中心線で決済する。追随案では、直前までのバンド収縮後の上側突破を買い候補とし、中心線割れで決済する。この二案は逆方向の仮説なので、相場を後から見て都合よく切り替えない。収縮の判定閾値も過去の窓から計算する。

## 8. サイコロジカルライン：上昇回数の偏りを見る

値幅ではなく、比較した終値が上昇した回数を数える。指定記事では12期間が紹介されている。[楽天証券・サイコロジカルライン](https://www.rakuten-sec.co.jp/web/fop/special/technical_analysis/chart_guide06/)

```text
上昇_t = 1 （C_t > C_(t−1) の場合）、それ以外は0
PSY_n(t) = 100 × Σ_(i=0…n−1) 上昇_(t−i) / n
```

この仕様では同値は上昇に数えず、分母からも除かない。12個の比較が必要なので終値は13個要る。9回上昇なら75。小幅上昇9回と大幅下落3回でも75となり、総値幅が上向きとは限らない。PSY=0でも全期間が横ばいなら下落したことを意味しない。

**研究用の条件例。** 25以下から25超へ復帰したときの買いと、50付近での決済を候補にする。閾値や同値の扱いは未検証。価格変化の符号しか使わないため、RSI等と比べて失う情報が多く、追加する価値は未使用期間で比較する。

## 9. ストキャスティクス：直近の値幅の中での位置を見る

直近の高値・安値の範囲で終値がどこにあるかを測る。楽天証券の指定記事はノーマルの `%D` を5期間の平均として説明しており、平滑期間を3にした設定とは別物である。[楽天証券・ストキャスティクス](https://www.rakuten-sec.co.jp/web/fop/special/technical_analysis/chart_guide07/)

```text
Fast %K_t = 100 × (C_t − LL_n(t)) / (HH_n(t) − LL_n(t))
Fast %D_t = SMA_m(Fast %K)_t

Slow %K_t = Fast %D_t
Slow %D_t = SMA_d(Slow %K)_t
```

本章の式では各平滑化をSMAとする。`n, m, d` と平均方式を必ず保存する。高安の範囲が0なら欠損とし、新規売買を行わない。スローの計算では追加の平滑期間も揃うまで待つ。

**研究用の条件例。** `%D` が低い領域にあり、`%K` が `%D` を上抜けたら買い候補、逆交差または中間域への到達で決済候補とする。20・80や30・70の目安は資料によって違うため、名称だけで条件が同じと判断しない。

**限界。** 高値更新が続けば100付近に張り付く。高値が計算窓から外れただけで値が急変することもある。閾値を極端にすれば確実になるわけではなく、取引回数と選ばれる相場が変わる。

## 10. DMI・ADXとATR：方向、偏り、値幅を分ける

### DMI・ADXの計算

`+DI` と `−DI` は方向の偏り、ADXはその偏りの強さを測る。ADX上昇だけでは上昇相場か下落相場かは分からない。[楽天証券・DMI](https://www.rakuten-sec.co.jp/web/fop/special/technical_analysis/chart_guide08/)

```text
上方変化_t = H_t − H_(t−1)
下方変化_t = L_(t−1) − L_t

+DM_t = 上方変化_t （上方変化_t > 下方変化_t かつ 上方変化_t > 0）、それ以外は0
−DM_t = 下方変化_t （下方変化_t > 上方変化_t かつ 下方変化_t > 0）、それ以外は0

TR_t = max(H_t−L_t, abs(H_t−C_(t−1)), abs(L_t−C_(t−1)))
+DI_t = 100 × RMA_n(+DM)_t / RMA_n(TR)_t
−DI_t = 100 × RMA_n(−DM)_t / RMA_n(TR)_t
DX_t = 100 × abs(+DI_t−(−DI_t)) / (+DI_t+(−DI_t))
ADX_t = RMA_n(DX)_t
```

高値と安値の外側への動きが同じ大きさなら、両DMを0にする。ADXにはDM/TRの初期化後、さらにDXを平均する期間が必要になる。上の式は読みやすい平均形式であり、合計形式で平滑化して比率を取る表現もある。ライブラリとの完全一致には最初の集計範囲と丸めの照合が要る。[TA-Lib v0.6.4・ADX実装](https://raw.githubusercontent.com/TA-Lib/ta-lib/v0.6.4/src/ta_func/ta_ADX.c)

**研究用の条件例。** `+DI` が `−DI` を上抜け、ADXが指定閾値以上なら買い候補、逆交差で決済候補とする。ADXの水準だけでなく傾きや価格方向を使う場合は別条件として記録する。TRの平滑値が0、またはDIの和が0なら本章の研究用仕様では欠損にする。ライブラリの0埋め・前値維持とは一致しない場合がある。

**限界。** 平滑化で反応が遅れる。高いADXが過去の下落によって生じた直後に上昇へ反転する場合もある。「ADXが高いから直近方向が続く」という仮説を検証する必要がある。

### ATRの計算と用途

```text
ATR_n(t) = RMA_n(TR)_t
```

最初のATRを `n` 個のTRの単純平均とし、その後ワイルダー型で更新する方式を基準とする。[TA-Lib v0.6.4・ATR実装](https://raw.githubusercontent.com/TA-Lib/ta-lib/v0.6.4/src/ta_func/ta_ATR.c)

ATRは価格と同じ単位を持ち、方向を示さない。買い建値から `a×エントリー時ATR` 下に損切り基準を置く、過去の高値から `b×確定時ATR` 下の水準で追随する、といった決済幅の尺度になる。`a, b` は未検証。ATRの変動に応じて損切りを遠ざけるのか、買いでは上がる方向にしか更新しないのかを固定する。

最初の足に前の終値を与えるか、セッション内だけで計算するかで開始付近のTRが変わる。前終値がない最初の足ではTRを未定義とする方式と、`H−L` で開始する方式を区別する。本章の最低本数の表は前者を想定する。前セッションとのギャップを計測に含める方針と、建玉を持ち越さない方針は別に設定できる。

## 11. パラボリックSAR：高安の更新に追随する

SARはトレンド内の極値へ徐々に近づく水準を計算する。指定記事では加速因数の初期値・増加幅0.02、上限0.2が紹介されている。[楽天証券・パラボリック](https://www.rakuten-sec.co.jp/web/fop/special/technical_analysis/chart_guide09/)

```text
次の足の暫定SAR = 現在のSAR + AF × (EP − 現在のSAR)
EP = 現在のトレンド内の極値 （上昇方向なら最高値、下降方向なら最安値）
AF = 極値の更新に応じて増える加速因数
```

この漸化式だけでは完全な実装にならない。過去の高安による上限・下限、反転時のSAR・EP・AFの再設定、最初の方向の決め方が必要である。初期化の違いは実際のOSSの説明でも示されている。[TA-Lib v0.6.4・SAR実装](https://raw.githubusercontent.com/TA-Lib/ta-lib/v0.6.4/src/ta_func/ta_SAR.c)

**研究用の条件例。** 最初は新規注文の入口より、トレンド追随手法の決済線として比較する。確定足 `t` までで次の足に有効な水準を計算し、その後の価格で到達を判定する。足 `t+1` の高安を読んで更新したSARを、同じ足の初めから有効だった逆指値にしてはいけない。

**限界。** 横ばいでは反転が頻発する。SARの反転を即座のドテンに結び付ける必要はなく、「決済のみ」「逆方向の新規は別条件」を別々に検証できる。チャート上のSARの値は、その価格で注文が約定する保証でも、取引所・証券会社の逆指値そのものでもない。

## 12. 補足：一目均衡表とVWAP

### 一目均衡表

高値・安値の中間値を複数の期間で計算し、位置関係を見る。SBI証券の指定記事は転換線・基準線・雲・遅行スパンの組み合わせを説明する。[SBI証券・一目均衡表を含む解説](https://www.sbisec.co.jp/ETGate/WPLETmgR001Control?OutSide=on&getFlg=on&burl=search_op&cat1=op&cat2=guide&dir=guide&file=op_guide_08.html)

```text
転換_t = (HH_9(t) + LL_9(t)) / 2
基準_t = (HH_26(t) + LL_26(t)) / 2
A_t = (転換_t + 基準_t) / 2
B_t = (HH_52(t) + LL_52(t)) / 2

描画上の先行スパン1_(t+q) = A_t
描画上の先行スパン2_(t+q) = B_t
描画上の遅行スパン_(t−q) = C_t
```

`9, 26, 52` は代表的な説明用期間。`q` は描画のずらし幅で、本章の配列表現では26本と定義する。日数に当日を含めるなどの数え方によって、既存ソフトの配列シフトが25になる場合もあるため、実装時には表示例と照合する。先行・遅行の描画方法は公式ツールの解説でも確認できる。[TradingView・一目均衡表](https://www.tradingview.com/support/solutions/43000589152-ichimoku-cloud/)

時刻 `t` の価格と画面上の雲を比較するなら、対応するのは `A_(t−q), B_(t−q)` である。遅行スパンの配列をそのまま時刻 `t−q` の売買条件に使うと、時刻 `t` の終値を過去へ渡してしまう。現在の終値と `q` 本前の高安を比べるなら、その判定時刻は現在 `t` とする。未来に描かれることと、未来の価格情報を持つことは異なる。

### セッションVWAP

約定価格 `p_j` と約定数量 `v_j` が利用できる場合、セッション開始から判定時点までの約定に対して次を計算する。

```text
約定ベースVWAP = Σ(p_j × v_j) / Σv_j

足からの近似VWAP = Σ(TP_t × V_t) / ΣV_t
TP_t = (H_t + L_t + C_t) / 3
```

後者は足の代表価格による近似であり、個々の約定から計算した値と必ず一致するわけではない。足の典型価格と出来高による計算、計算開始点の設定は公式ツールの資料でも説明されている。[TradingView・VWAP](https://www.tradingview.com/support/solutions/43000502018-volume-weighted-average-price-vwap/)

本研究ではデイとナイトで別々にリセットする案を基本候補とする。VWAPより上か下か、VWAPからの乖離や再交差を環境・入口・決済の条件にできる。ただし、ラージのVWAPはラージの約定を集計した値であり、mini・microの平均約定価格を表していない。板の数量を約定数量の代わりに使わない。累積出来高の差分化、重複イベント、データ欠落を検証し、数量合計0なら計算しない。
