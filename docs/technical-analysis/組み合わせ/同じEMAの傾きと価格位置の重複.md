# 同じEMAの傾きと価格位置の重複

確認日：2026-11-10。複数条件を組む際に、同じ内容を別の言葉で確認していないかを点検するための補足。[移動平均線](../指標/移動平均線.md)、[複数指標の役割と情報の重複](../../議論/外部再調査/複数指標の役割と情報の重複.md)と併用する。

## 同じ確定足の終値で更新したEMA

終値C_t、更新後EMAをE_t、前のEMAをE_p、平滑化係数を0<α<1とすると、EMA更新は次の式になる。前EMAと現在価格を使う定義は[FidelityのEMA教材](https://www.fidelity.com/learning-center/trading-investing/technical-analysis/technical-indicator-guide/ema)で確認した。本研究の実装はα=2/(N+1)、初期SMA後にこの更新を行う。

```text
E_t = E_p + α(C_t − E_p)
ΔE = α(C_t − E_p)
C_t − E_t = (1−α)(C_t − E_p)

したがって ΔE = α/(1−α) × (C_t − E_t)
```

係数が正なので、**同じEMAの1本差が正**と**更新に使った終値がそのEMAより上**は、数学上同じ符号条件になる。買い/売り方向へ同じ符号を掛けても関係は変わらない。価格位置と平均線の傾きを別々の独立した確認票として数えない。

## 114の8本・21本EMAに当てはめると

114の変数G=s(EMA8−EMA21)、x8=s(Close−EMA8)、a8=sΔEMA8、a21=sΔEMA21に対し、既知の連続更新後では次の関係がある。

```text
a8  = (2/7) × x8
a21 = (x8+G) / 10
```

G>0かつx8>0ならa8>0とa21>0も含意する。Rのx8>0とa8>0も重複する。Rで前の価格位置が非正から正へ移る条件は、別の時点を参照する回復イベントとして残る。MACDヒストグラム条件はこの二式と同じではないが、同じ価格履歴から作る以上、統計的な独立性が保証されるわけでもない。

この導出を理由に114の固定条件や成績を書き換えない。114は元の全条件で再生・保存した研究として保持する。次の候補では、新しい情報の役割を増やすかを検討する。

## この同値がそのまま使えない場面

- 3本差等の傾き、回帰傾き、別時間軸の傾き。
- 確定EMAに対する現在の逐次価格。EMAを更新した終値とは時点が違う。
- HLC3等でEMAを更新し、Closeとの位置を比べる場合。
- 初期SMAの成立時点、必要な前値が未知の場合、欠足/resetを挟む場合。
- 有限桁の丸め。ゼロ付近では数学上の符号と機械の厳密比較を分ける。

5分・15分・30分の背景、複数本の進行、DMI/ADXの方向と強さ、価格構造や観測数量等は、この同じ1本更新の重複とは区別して比較する。指標名や条件数を増やしただけで確認精度が上がったとは扱わず、使用時点と実現収支を検証する。
