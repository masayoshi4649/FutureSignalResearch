# DMI・ADX：方向と強さを分けて使う

識別子：C04。確認日：2026-10-30。[組み合わせの目次と共通条件](README.md)

## 1. 一般に紹介される判断

`+DI` と `−DI` で方向の偏りを見て、ADXでその偏りの強さを確認する。ADXが高いだけでは買いか売りか決まらない。Fidelityは両DIを方向の判断に使い、ADXの状態に応じてMAや価格帯突破等の追随型サインの重みを変える考え方を紹介する。[公式教材・使い方](https://www.fidelity.com/viewpoints/active-investor/average-directional-index-ADX)

教育資料で紹介される20・25などは解釈の目安で、分足先物の最適閾値ではない。[DMIとADXの個別教科書](../指標/DMIとADX.md)で、計算と初期化を確認する。

## 2. 同じADXでも方向は反対になり得る

| 例 | 読み方 |
| --- | --- |
| `+DI > −DI`、ADXが高い | 高安の上向きの偏りが相対的に強い候補 |
| `−DI > +DI`、ADXが高い | 下向きの偏りが相対的に強い候補 |
| DIが頻繁に交差、ADXが低い | 方向を追う前提が弱い候補 |
| ADXが低下、価格は上昇 | 上昇自体と、その方向偏りの強さは別 |

最後の行から直ちに売りを決めない。ADXが低下しても、上昇速度が緩やかになったまま進む場合がある。

## 3. 心理の説明候補

同方向の高安更新が続く場面では、[P03の追随やP04の返済注文](../市場心理/追随と買い戻し.md)が継続しているのかもしれない。一方、DIは高安の変化から計算しており、注文量や強気な人の割合ではない。ADXも市場の自信を直接測る温度計ではない。

「方向を追う注文が続く」という説明を考えたときに、実際の価格構造がそれに合っているかを見る補助として使う。ADXを原因、価格上昇を結果とする因果関係に読み替えない。

## 4. 再利用する教材カード

| 項目 | 買いの基準例 |
| --- | --- |
| 入力 | 確定5分足、DMI14・ADX14は個別章のWilder型仕様 |
| 発動 | `+DI` が `−DI` を上抜け、同じ足のADXが25以上 |
| 通常撤退 | `+DI` が `−DI` を下抜けたことを足確定後に観測 |
| 比較 | DI交差のみ、ADX追加、ADXの上向きも要求する案を別々に比較 |
| 追加の方向確認 | MAまたは一目の価格位置を加える場合は、元カードを残す |
| 保護と期限 | 通常撤退とは独立した保護、セッション終了前の全返済 |
| 反証 | 横ばいで費用が重なる、平滑の遅れで入口が遅い、急転換を捉えない |

同じ交差を何本も有効にするなら、その有効期間と一度の交差当たりの入口回数を決める。このカードは交差足に限る例である。通常撤退までの含み損をADXの強さだけで許容しない。
