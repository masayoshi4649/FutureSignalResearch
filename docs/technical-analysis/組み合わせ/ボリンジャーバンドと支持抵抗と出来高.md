# ボリンジャーバンド・支持抵抗・出来高：収縮からの離脱

識別子：C03。確認日：2026-10-30。[組み合わせの目次と共通条件](README.md)

## 1. 一般に紹介される判断

BBの幅が狭まった状態をスクイーズと呼び、そこから帯を突破する動きを探す使い方がある。StockChartsは帯の突破を支持抵抗の突破で確認し、出来高由来の指標を補助にする考え方を紹介している。収縮そのものは上か下かを示さない。[スクイーズの公式教材](https://chartschool.stockcharts.com/table-of-contents/trading-strategies-and-models/trading-strategies/bollinger-band-squeeze)

ここで確かめたいのは、「小さく動いていた」から「価格帯を離れる」への変化である。売買方向は実際の離脱で判断する。[BB](../指標/ボリンジャーバンド.md)の幅、支持抵抗の[事前定義](../01_チャートの読み方と仮説化.md)、出来高の集計を別々に固定する。

## 2. 心理と注文の説明

狭い価格帯で売買していた参加者が、価格帯の外への動きを見て追随するかもしれない。反対側の建玉が返済されると同方向の注文になり、相手気配が薄ければ値幅が広がる可能性もある。[P03・P04](../市場心理/追随と買い戻し.md)、[P05](../市場心理/需給と流動性.md)が説明候補になる。

ただし「幅が狭い間にエネルギーが溜まり、必ず解放される」は比喩であり、物理法則ではない。取引が少ないだけの静かな期間、ニュース直前、板の取消でも似た形になる。出来高増も、どの動機の注文かまでは示さない。

## 3. 再利用する教材カード

| 項目 | 買いの具体化例 |
| --- | --- |
| 入力 | 確定5分足、終値BB(20,2)、母標準偏差、幅は中心線で割った比率 |
| 収縮の判定 | 前足の幅が、それ以前の有効120本の幅の下位10%以下 |
| 価格帯 | 今足を除く直前12本の最高値を `R_t` とする |
| 発動 | 前足終値は前足の上帯以下。今足終値が今足の上帯と `R_t` の両方を上回る |
| 通常撤退 | 発動時に保存した `R_t` 以下へ確定終値が戻る |
| 利益を伸ばす候補 | 固定利確とC06の追尾決済を別候補として比較 |
| 出来高の追加案 | 今足出来高が直前20本の平均を超える条件を追加し、条件なしと比較 |

幅の分位点は前足より前の120本だけで計算し、分位点の補間方式を固定する。窓を含めた必要本数を揃え、欠損があればこの例の候補を無効にする。帯の突破と価格帯の突破を別々の時刻で待つ方式は別のカードにする。

本カードの120・10%・12・20は独自の未検証例。原典の長い日足期間を、そのまま日中足の最適値としたものではない。原典に挙げられるOBV等と、上表の単純な区間出来高比較も別仕様である。

## 4. 失敗をどう理解するか

突破後すぐ戻る動きを、ここでは失敗した突破として記録する。「本物の突破だけ」を目視で選別しない。突破水準へ戻るまでの最大順行、戻った後の逆行、発注遅延と滑りを評価する。

出来高を加えると、ニュース直後の大きな滑りを伴う取引だけが残る場合もある。値幅が大きくても費用後損益は改善しないことがある。収縮時の平均線やオシレーターが平らなだけでは、将来方向の根拠にならない。
