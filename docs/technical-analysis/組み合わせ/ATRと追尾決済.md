# ATR・追尾決済：値幅に合わせて撤退を考える

識別子：C06。確認日：2026-10-30。[組み合わせの目次と共通条件](README.md)

## 1. 一般に紹介される判断

利益を伸ばす追随型の手法では、固定の利確価格で早く終える代わりに、直近の高値・安値から一定の変動幅を引いた線を撤退候補にする使い方がある。Chandelier Exitは、その幅へATRを利用する例である。[StockCharts・Chandelier Exit](https://chartschool.stockcharts.com/table-of-contents/technical-indicators-and-overlays/technical-overlays/chandelier-exit)

入口の指標と出口の指標に別の役割を与える。MACDやRSIで入っても、ATRは「次に上がるか」ではなく「どの程度の逆行を許容するか」に用いる。[ATR](../指標/ATR.md)

## 2. 原典の線と、保護注文に使う線を分ける

教材で紹介される代表例は、買い側が直近22本最高値からATR22の3倍を引く形、売り側が直近22本最安値へ同幅を加える形である。日足での説明用設定を、5分足の最適値とはしない。

```text
買いの計算線_t = HH_n(t) − k × ATR_n(t)
売りの計算線_t = LL_n(t) + k × ATR_n(t)
```

この計算線は、ATRの増加や高安の窓外れで不利な方向へ動くこともある。買いの損切りを引き下げない研究仕様を採るなら、別途 `保護線_t = max(保護線_(t−1), 計算線_t)` とする。売りは `min` とする。これを元の線と同一の実装と呼ばない。

## 3. 心理との関係

利益が出たら守りたい一方、小さな調整だけで退出したくないという考え方を、変動幅のルールへ置き換える。逆行を「弱気な心理が増えた」と解釈しなくても、許容幅を超えたので撤退する、と定義できる。

既存の利食い・損切り注文が価格に影響する説明候補はあるが、ATRの2倍や3倍に全参加者の注文が集まる証拠ではない。自分のリスク規則と、市場参加者の心理を分ける。[P02](../市場心理/参照価格と損失回避.md) / [P04](../市場心理/追随と買い戻し.md)

## 4. 再利用する教材カード

| 項目 | 本研究で比較する例 |

| 入口 | C01等の入口を固定し、出口だけ交換 |
| 初期保護 | シグナル足のATR14を固定、実約定価格から2ATRの不利側 |
| 追尾候補 | 建玉後の観測済み最高値から確定ATR14の2倍を引く。売りは反対 |

このカードは原典の直近22本の線とも、期間をずらしただけのものとも異なる。高値の集計を建玉後に限定し、保護線に片方向の制限を付けた研究案である。

## 5. 足の途中を先読みしない

一本の足で高値が大きく伸び、その後安値まで下がったとしても、OHLCだけでは順序が分からない。その足の高値で引き上げた保護線が、足の初めから存在したと扱わない。判定済みの旧線と新線の有効時点を保持する。

建玉した足の高値が約定前に付いた場合、その高値は「建玉後最高値」に含めない。原板順で判定できない場合、この教材例では次の完全な足から追尾を更新する。そこまでは初期保護を使い、売り側の最安値も対称に扱う。

強いトレンドなら固定利確より利益を伸ばす可能性がある一方、往復相場では得た利益を返しやすい。MFEに対する実現利益、MAE、費用、期限返済を併記する。高いMFEの地点で必ず売れたという計算はしない。
