# ATR・追尾決済：値幅に合わせて撤退を考える

識別子：C06。確認日：2026-11-09。[組み合わせの目次と共通条件](README.md)

## 1. 一般に紹介される判断

利益を伸ばす追随型の手法では、固定の利確価格で早く終える代わりに、直近の高値・安値から一定の変動幅を引いた線を撤退候補にする使い方がある。Chandelier Exitは、その幅へATRを利用する例である。[StockCharts・Chandelier Exit](https://chartschool.stockcharts.com/table-of-contents/technical-indicators-and-overlays/technical-overlays/chandelier-exit)

入口の指標と出口の指標に別の役割を与える。MACDやRSIで入っても、ATRは「次に上がるか」ではなく「どの程度の逆行を許容するか」に用いる。[ATR](../指標/ATR.md)

## 2. 原典の線と、保護注文に使う線を分ける

教材で紹介される代表例は、買い側が直近22本最高値からATR22の3倍を引く形、売り側が直近22本最安値へ同幅を加える形である。日足での説明用設定を、5分足の最適値とはしない。

```text
買いの計算線_t = HH_n(t) − k × ATR_n(t)
売りの計算線_t = LL_n(t) + k × ATR_n(t)
```

この計算線は、ATRの増加や高安の窓外れで不利な方向へ動くこともある。買いの損切りを引き下げない研究仕様を採るなら、別途 `保護線_t = max(保護線_(t−1), 計算線_t)` とする。売りは `min` とする。これを元の線と同一の実装と呼ばない。

## 3. 心理との関係

利益が出たら守りたい一方、小さな調整だけで退出したくないという考え方を、変動幅のルールへ置き換える。逆行を「弱気な心理が増えた」と解釈しなくても、許容幅を超えたので撤退する、と定義できる。

既存の利食い・損切り注文が価格に影響する説明候補はあるが、ATRの2倍や3倍に全参加者の注文が集まる証拠ではない。自分のリスク規則と、市場参加者の心理を分ける。[P02](../市場心理/参照価格と損失回避.md) / [P04](../市場心理/追随と買い戻し.md)

## 5. 足の途中を先読みしない

一本の足で高値が大きく伸び、その後安値まで下がったとしても、OHLCだけでは順序が分からない。その足の高値で引き上げた保護線が、足の初めから存在したと扱わない。判定済みの旧線と新線の有効時点を保持する。

建玉した足の高値が約定前に付いた場合、その高値は「建玉後最高値」に含めない。原板順で判定できない場合、この教材例では次の完全な足から追尾を更新する。そこまでは初期保護を使い、売り側の最安値も対称に扱う。

比較では実際の粗損益、費用後損益、保有中に費用後利益を観測した後の最終赤字、最大DD、期限返済を記録する。[最新の評価方針](../../議論/実現損益を中心に評価する方針.md)に従い、最大順行に対する回収率や退出後の仮想利益を機会損失として評価しない。

## 7. 起動・要求・約定を区別する

2026-11-08の一次資料再確認。CMEの追尾注文の説明は、有利な価格進行へ追随し、不利な進行では線を据え置く。注文種別の説明では、条件到達後に指値となる注文と、保護価格範囲で執行する注文を区別している。追尾線の到達とその価格での全量約定を同じ事象にしない。[CME・追尾注文](https://www.cmegroup.com/tools-information/webhelp/cme-direct/cme-direct-trader-broker/Content/Trailing-Stop-Orders.html)、[CME・先物注文種別](https://www.cmegroup.com/education/courses/futures-trading-mechanics-and-regulation/futures-order-types)

これはCMEの説明であり、OSEや利用証券会社が同じ注文機能を提供するという確認ではない。本研究の追尾は現在返済側BBOを使い、要求後の適格な後続原行で約定させる研究モデルである。CME資料の約定値追随と同一実装とは呼ばない。

Kaminski/Loの研究は、損失に応じてエクスポージャーを減らす規則の期待収益と変動性への影響を扱う。MIT掲載要旨の実証対象は指数先物の日次価格と保有戦略であり、長い観測間隔で一部の規則に改善を報告している。NK225の5分新規や、初回含み益での返済の有効性を証明する資料ではない。[著者所属MITの原稿・要旨](https://dspace.mit.edu/entities/publication/bb69ca4b-0cdc-487f-831d-63b2e84fafee)

研究上の推論として、出口を足したという事実と収益の改善を分け、同じ入口・費用で再生して確かめる。[試行96の実取引](../../議論/複合判定で残った建値費用と次の利益確定.md)では、名目建値へ返済しても手数料赤字が残った。[試行97の計画](../../../study/00097_初回費用後利益の全量確定/検証計画.md)は、初回費用後正益での返済要求をP0の対照と比較する。次気配での赤字化も実損失として記録する。

## 8. 可変追尾を再利用するときの分解

2026-11-09に[TradingView公式・Volatility Stop](https://www.tradingview.com/support/solutions/43000594676-volatility-stop/)の定義・計算・限界を確認した。同資料は変動の尺度、倍率、価格の基準を分けて説明し、過去の変動が将来も続くという前提の限界を挙げる。NK225の最適な倍率や、本研究の収束条件を検証した資料ではない。

以下は本研究で追加する設計の分解であり、教材の既定設定ではない。

| 要素 | 事前に固定する内容 | 混同しないこと |
| --- | --- | --- |
| 起動 | 現在の費用後含み益がどの水準へ達したら保護を始めるか | 一度でも利益が出た玉の数と、起動した玉の数は異なる |
| 値幅 | ATR等の期間、取得時固定か逐次更新か、倍率と刻み | 取得時ATR固定は現在のボラティリティへ追随する方式ではない |
| 基準価格 | 建玉後に観測した返済側気配の最高値／最安値等 | 約定前の高安や、後で確定する足の高安を使わない |
| 技術的な切替 | 収束、勢いの鈍化、既に公開された高安の否定をどこまで要求するか | 収束を反転確定と呼ばず、複数の価格加工を独立した票と数えない |
| 保護床 | 名目建値と前回床より不利に動かさない規則 | 幅の拡大やATR上昇が、既に確保した床を緩める理由にはならない |
| 執行 | 更新・発動・返済要求・実約定の順序、費用、部分約定 | 同値の床でも手数料・滑りによる赤字は残り得る |

心理的な説明は、小さな調整を許しつつ、元方向を支える価格反応が弱くなれば守りを強めたい、という仮説に留める。収束やMACDから注文主体の意図を観測したとはしない。実取引の比較では、起動前の利益後赤字と起動後の赤字を分け、同一の実入口に対する退出差と、後続の実取得が変化した差を別記する。

[試行106](../../../study/00106_収束失速で保護の起動と幅を切り替える/README.md)はこの分解を使う比較で、通常起動・収束と勢いによる狭幅化・価格構造も要求する狭幅化・早期起動を事前に分けた。追記時点は市場再生中で、可変幅や早期起動の改善を確認したという意味ではない。[候補の根拠と反証](../../議論/収束と失速を分ける可変追尾の候補.md)も参照する。

2026-11-09の[11月06日の実保有診断](../../議論/11月06日の赤字を入口と利益保護から診断する.md)では、1ATR起動に届かない利益後赤字と、起動しても2ATR幅が広く建値床しか残らない例を確認した。取得時固定ATRの初期化・先頭足の影響まで記録する必要がある。一定利益での必須起動と、技術的な収束・失速による幅変更を分ける次の仮説につながるが、幅を狭くした候補の日計が悪化した反例もあり、一律の改善策とはしない。
