# VWAP・支持抵抗：日中の基準と価格構造を照合する

識別子：C05。確認日：2026-10-30。[組み合わせの目次と共通条件](README.md)

## 1. 一般的な個別解釈をどう組み立てるか

VWAPより上か下かで日中の価格位置を読む使い方と、過去高安や突破水準を支持抵抗として読む使い方がある。[TradingView・VWAP](https://www.tradingview.com/support/solutions/43000502018-volume-weighted-average-price-vwap/)、[CME・支持抵抗](https://www.cmegroup.com/education/courses/technical-analysis/support-and-resistance)

この二つを「日中基準より上で、事前に決めた抵抗帯を突破した後の押しを探す」のようにつなぐことができる。本章の組み合わせと発動条件は**本研究の応用案**であり、両資料が同じ完成手法を提示しているという意味ではない。

## 2. 心理の説明候補

過去に売りが出た水準を超えた後、買い手がその近辺を参照して新規に買う、売り建玉が返済する、基準価格を意識する運用者が待っていた買いを出す、といった説明が考えられる。[P01・P02](../市場心理/参照価格と損失回避.md)、[P04](../市場心理/追随と買い戻し.md)、[P06](../市場心理/需給と流動性.md)

これらが重なることを想像できても、VWAPと支持帯が近いだけで注文の集中は立証できない。後から「反発した線」を支持帯に選び直すと、説明が常に当たるように見えてしまう。

## 3. 再利用する教材カード

| 項目 | 買いの例 |
| --- | --- |
| 基準 | セッション開始後15分の最高値 `R` を確定後に固定 |
| VWAP | セッション開始からの量加重平均。原提供値を使うなら起算の確認が必要 |
| 候補の保存 | 序盤15分の確定後、初めて確定終値が `R` を上回った足を `t0` とし、`t0+1`〜`t0+6` の6本を待機期間とする |
| 発動 | 待機中の足で安値が `[R−ε,R+ε]` 内、終値が `R+ε` より上かつVWAPより上 |
| 幅 | `ε` は分析商品の1ティックという説明用の例 |
| 通常撤退 | 確定終値が `R−ε` 以下へ戻る、または終値がVWAPを下抜ける |
| 待機の無効化 | 確定終値が `R−ε` 以下、有効なVWAPの欠損、新規停止時刻到達、または6本の待機終了で発動なし |
| 出口・比較 | 固定利確とC06を別々に採用。VWAP条件なし・ありを比較 |

安値が帯を突き抜けた足を許すかは別仕様である。上表は安値が帯内の足に限定し、帯の上まで回復したことを確定足で確認する。帯で指値約定したものと扱わず、その後の実行可能な価格で入口を評価する。

このカードは開始後の高値確定まで取引せず、待機時間切れや上表の無効化で候補を捨てる。同じ足で無効化と発動が重なれば無効化を優先する。最初の比較では候補の登録をセッション1回に限り、破棄後・返済後とも再挑戦しない。全て未検証の教材値で、必須の保護と期限返済は別に設定する。

## 4. VWAPの傾きと価格位置は違う

価格がVWAPより上でも、現在の価格は直前から下がっているかもしれない。VWAPが上昇していても、価格はVWAPへ接近中かもしれない。「上にある」「傾きが上」「上抜けた」を一つの条件にまとめない。

ナイトの途中の午前0時で、基準を黙ってリセットしない。日中足からの近似VWAPと全約定VWAPの違い、ラージと実行商品の違いも記録する。[VWAPの個別教科書](../指標/VWAP.md)
