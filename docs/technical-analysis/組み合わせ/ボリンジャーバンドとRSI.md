# ボリンジャーバンド・RSI：位置と勢いの復帰を見る

識別子：C02。確認日：2026-10-30。[組み合わせの目次と共通条件](README.md)

## 1. 単なる「下に来たから買う」から一段進める

BBは最近の価格の散らばりに対する位置、RSIは上昇・下落の値幅の配分を表す。下帯へ到達したことに加え、下向きの動きが弱まり始めたかを確認するという組み立てができる。

ボリンジャー本人は、帯への接触だけを売買サインにしないこと、勢い・出来高等を併用する考え方を示す。StockChartsにもBBと勢いの指標CCIの併用例がある。**本章のRSIによる復帰条件は、これらの考え方を本研究で具体化した教材例**であり、そのまま原典に掲載された手法ではない。[作者の使用規則](https://www.bollingerbands.com/bollinger-band-rules)、[StockCharts・BB](https://chartschool.stockcharts.com/table-of-contents/technical-indicators-and-overlays/technical-overlays/bollinger-bands)

## 2. 往復相場と強いトレンドで読みが変わる

| 状況 | 判断の候補 | 理由 |
| --- | --- | --- |
| 価格が帯を往復し、中心の傾きが小さい | 外側から戻る動きを回帰候補として見る | 方向が継続しないという前提 |
| 上昇して上帯沿い、RSIが高い | 強さの継続も候補にする | 極端値は反転時刻を指定しない |
| 下落して下帯沿い、RSIが低い | 逆張り買いの前提を疑う | 安値圏が続く可能性がある |

セッション終了後に「この日はレンジだった」と選ばない。環境条件を用いるなら、判定前の足だけで中心線の傾きやADX等を定義する。

## 3. 心理の説明と代替説明

短期の売却が一巡し、売りたい参加者の売りが減る、または安い価格を参照した買いが出ると、価格が戻る可能性がある。利益を得ていた売り建玉の返済も買いになる。これは[参照価格P01・利益確定P02](../市場心理/参照価格と損失回避.md)等を使った説明候補である。

ただし、帯やRSIから「売りたい人が全員売った」とは分からない。指数の材料が変わった、気配が薄かった、平均線が価格へ追いついたなどでも、帯への復帰や乖離縮小は起こる。

## 4. 再利用する教材カード

| 項目 | 買いの基準例 |
| --- | --- |
| 入力 | 確定5分足、終値20本SMAと母標準偏差の2σ、RSI14はWilder型 |
| 事前状態 | 前足で終値が下帯未満、かつRSIが30未満 |
| 発動 | 今足で終値が下帯以上、RSIが30以上、かつ終値は中心線未満 |
| 通常利確 | 確定終値がその時点の中心線以上へ到達後に返済 |
| 通常損切り | 確定終値が再び下帯未満となった後に返済 |
| 環境の追加案 | ADX等で往復条件を加えるなら、条件なしを基準として別に検証 |
| 比較と反証 | BB復帰のみ対RSI追加。強い下落、費用増、遅い入口でも残るか |

売りは上下を反転し、RSI70を説明用の境界とする。閾値や20本という期間は分足先物で確認済みの適正値ではない。通常決済とは別の保護と期限返済を付ける。

## 5. 他の指標へ交換するとき

[ストキャス](../指標/ストキャスティクス.md)なら、値幅の配分ではなく直近高安に対する位置を確認する。RSIと同じ数値だから同じ意味ではない。両方を追加すると価格位置の情報がさらに重なり、必ず改善するとは限らない。

「RSIもBBも売られすぎ」の二票より、「価格が帯へ復帰し、その後の下値更新が止まったか」のように確認したい現象を明確にする。後者を使う場合も、何本・どの価格で確認するかを先に決める。
