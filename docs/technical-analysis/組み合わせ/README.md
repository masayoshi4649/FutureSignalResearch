# 指標を組み合わせて判断する

確認日：2026-10-30。[指標別の目次](../指標/README.md) / [市場心理](../市場心理/README.md) / [教科書](../README.md)

組み合わせの基本は、似た売買サインを数えることより、異なる問いに役割を割り当てることである。「どちら向きの取引を考えるか」「どこで入るか」「前提が崩れたか」「いくらまで許容するか」を分けると、判断を再利用しやすくなる。

本フォルダの「一般的な判断」は、確認した作者・証券会社・ツール提供元の教育資料で紹介される考え方を指す。利用者全体の調査や、最適な組み合わせという意味ではない。**資料に掲載された組み合わせ、その考え方を応用した本研究の案、未検証の数値設定を各文書で区別する。**

## 1. 判断に役割を与える

| 役割 | 問うこと | 主な候補 |
| --- | --- | --- |
| 環境 | 上昇・下落・往復のどれを想定するか | 移動平均、高安構造、一目、ADX |
| 位置 | 平均や価格帯のどこにいるか | 支持抵抗、BB、VWAP、乖離率 |
| 発動 | 今この足で何が変わったか | MACD・RSI・ストキャスの交差、帯の突破 |
| 確認 | 価格以外の面から何が補えるか | 出来高、正常な板、執行商品のスプレッド |
| 撤退 | 元の仮説が何によって崩れるか | 反対交差、価格帯への復帰、方向条件の崩れ |
| 損失管理 | 変動幅と保有量をどう制限するか | ATR、価格構造、保護注文、期限返済 |

一つの指標が複数の役割を担ってもよい。ただし、役割を増やすたびに別の情報が増えたと考えない。

## 3. 指標が食い違ったとき

| 観測 | 両立し得る読み方 | 避けたい飛躍 |
| --- | --- | --- |
| MA上向き、MACD低下 | 長めの上昇の中で短期の勢いが弱まっている | 下降転換したと即断する |
| RSI70超、上帯沿い | 上昇が強く続く候補と、調整の候補が両方ある | 買われすぎを自動的な空売りへ変える |
| ADX上昇、MACDの山が低下 | 高安の方向偏りと平均差の変化が異なる | 一方が必ず誤っているとする |
| 日中VWAPより下、長期MAより上 | 集計始点・長さが違う | 線の多い方の多数決を採る |
| RSIとストキャスが同時に高い | 同じ価格上昇が二つの尺度に表れている | 独立な二票だから確度が倍とする |

食い違いは、測っている期間・入力・役割を確認するきっかけになる。矛盾を解消するために、その場で閾値を変えたり都合のよい足へ切り替えたりしない。

## 4. 似た指標を重ねすぎない

MA、MACD、乖離率は平均価格を共通の材料にする。RSI、ストキャス、PSYも、程度は異なっても同じ価格推移の加工である。PSYは上昇回数、RSIは値幅の配分、ストキャスは価格位置という違いがあるが、それだけで統計的な独立は保証されない。

ボリンジャー本人も、直接関連する指標を複数並べることより、異なる種類の情報を組み合わせる考え方を示している。[使用規則3〜4](https://www.bollingerbands.com/bollinger-band-rules)

出来高を加えると価格とは別の入力が増えるが、利益の改善は未確定である。追加条件なし・ありを同じ費用と期間で比較する。条件を増やして取引がほぼなくなる場合も、改善とは限らない。

## 5. 全カードに共通する利用条件

カード内の数値は未検証の教材例とする。確定足の `t` と、その一つ前の有効足 `t−1` を用い、足確定後の利用可能な観測から注文を評価する。初期化・欠損・時計品質を満たさなければ新規を見送る。

単純な比較では1商品1枚、増玉・両建てなし、建玉・新規未約定ゼロのときだけ新規を認める。入口から出口まで一つの手法として固定し、通常決済と独立した保護注文、新規停止・期限返済を組み込む。ラージ価格による判断とmini・microの実約定は分離する。[決済とリスク管理](../04_決済とリスク管理.md)

使うカードは[判断カードのひな形](../判断カードのひな形.md)へ写し、未指定の値、同時計・同足の順序、失敗時の扱いを埋めてから試行する。今回は教科書の整理であり、カードの損益検証は実施していない。
