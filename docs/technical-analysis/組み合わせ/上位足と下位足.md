# 上位足・下位足：大きめの方向と短い調整を分ける

識別子：C07。確認日：2026-10-30。[組み合わせの目次と共通条件](README.md)

## 1. 同じ時間に上昇と下落が両立する

15分足で数時間の上昇を示していても、1分足では数分の下落が見えることがある。大きな向きの中で小さな調整を探すと考えれば、食い違いではない。異なる時間幅を役割で分ける本章の条件は、本研究用に整理した応用案である。

移動平均が示す期間やMACDの短長期は、足の長さで変わる。[移動平均線](../指標/移動平均線.md) / [MACD](../指標/MACD.md)。上位足と下位足は元の取引を共有するため、独立した市場二つの確認ではない。

## 2. 心理の説明候補

長めの運用目的で買う参加者と、短期の利益を確定する参加者が同時にいると、一時的な下落の後に買いが再開する可能性がある。ただし、足の長さから参加者の保有期間や属性を直接割り当てることはできない。

15分足のMAを機関投資家、1分足のRSIを個人投資家の心理と決めつけない。どの参加者も複数の時間幅を見ているかもしれないし、自動執行の分割注文でも同じ価格推移が起こり得る。[P03](../市場心理/追随と買い戻し.md) / [P06](../市場心理/需給と流動性.md)

## 3. 再利用する教材カード

| 項目 | 買いの例 |
| --- | --- |
| 上位足 | 最後に確定した15分足で、終値がEMA20より上、EMA20が前足より上 |
| 下位足 | 確定1分足のRSI14が40以下から40超へ復帰 |
| 発動 | 上位足条件が有効で、下位足の復帰を確定した後 |
| 通常撤退 | 上位足の終値がEMA20を下回る、または下位足RSIが再び40以下 |
| 比較 | 下位足単独対上位足条件あり。同じ入口時刻の執行モデルで比較 |
| 追加仕様 | 足の境界・休場・欠損・ウォームアップ・有効な上位足の鮮度 |
| 保護と期限 | 通常撤退を待たない保護、セッション内の期限返済 |

数字と通常撤退は未検証の教材例である。上位足の一目均衡表で方向を見る場合は、雲の配列シフトと十分な準備期間を別に固定し、このEMA方式の結果と混ぜない。[一目均衡表](../指標/一目均衡表.md)

## 4. 利用できる時刻の例

| 判断する時刻 | 参照できる15分足 | 参照してはいけない値 |
| --- | --- | --- |
| 09:07 | 正常に確定を確認済みの `[08:45,09:00)` 足 | `[09:00,09:15)` 足の最終高安・終値 |
| 09:15以降 | `[09:00,09:15)` 足の確定を確認した後に更新 | 遅延や欠損を確認せず完成扱いした足 |

上位足の判定を、未来に完成した値で下位足全区間へ埋め戻さない。現在進行中の上位足を使う方式も作れるが、その時点の暫定値を再現する別手法として扱う。
