# CUSUMと根拠失効：小さい逆方向変化の継続を調べる

確認日：2026-11-13。汎用表V8の識別子M03。[組み合わせ目次](README.md) / [ER](../指標/効率比ER.md) / [MACD](../指標/MACD.md)。

## 一般的な定義

[NIST E-Handbook](https://www.itl.nist.gov/div898/handbook/pmc/section3/pmc323.htm)の公式工程管理教材を実読した。CUSUMは基準平均からの小さい偏りを累積して平均変化を検知する。原著研究そのものではなく、政府機関の統計仕様である。

```text
S_hi(i) = max(0, S_hi(i−1) + x_i − μ0 − k)
S_lo(i) = max(0, S_lo(i−1) + μ0 − k − x_i)
初期S_hi=S_lo=0、どちらかがhを超えれば警戒
```

kは無視する小さいずれ、hは累積警戒限界。単発の大足だけでなく、小さい同方向の偏りを捉える。教材のh/k例を、NK225の最適値や誤警報率としない。

## 本研究の複合案

買+1/売−1をsとし、配送済み確定足のx_i=s(C_i−C_(i−1))/ATR_(i−1)を測る案がある。基準μ0は0等を事前固定する。取得後S_lo>hに加え、当時の確認済み支持/抵抗の否定と、保有方向Histの減速が揃った時に退出要求する。構造は「どこが壊れたか」、Histは「勢い」、CUSUMは「弱化の継続」という別役割。

方向を逆にして同じ式を再計算する。新高値を付けたからという理由だけで都合よく累積を消さず、初期化・reset条件・足幅・nとk/hをbookへ固定する。正益arm・利益床・非緩和・期限は別の共通保護として残す。

## 心理の仮説

価格を一度に大きく戻す注文がなくても、保有方向を支える働きが少しずつ失われる可能性を調べる。平均変化の警報は参加者の意図や反対方向の利益を証明しない。警戒だけで新規反転しない。

## 既知性と限界

市場の自己相関/変動性変化は工程管理の独立正規測定と異なる。ATR0・足飛び・価格未知をx=0へ補完しない。欠測resetと売買失効を分け、未知期間の累積を捏造しない。確認を待つほど損失が増える場合もある。単純IFDと同caseで比較し、初回警戒・複合成立・要求・後原行fillを別に残す。現時点で、この組合せの自然損益を確認した教材ではない。
