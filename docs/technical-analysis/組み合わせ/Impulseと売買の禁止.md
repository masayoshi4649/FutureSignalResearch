# Impulseと売買の禁止を、価格発動から分ける

確認日：2026-11-06。[組み合わせの目次](README.md) / [移動平均線](../指標/移動平均線.md) / [MACD](../指標/MACD.md) / [Force Index](../指標/ForceIndex.md)。資料で確認した考え方、数式から導く性質、今回の研究仮説を分ける。NK225での収益性は本教材からは分からない。

## 何を知るために使うか

Impulseは、価格EMAの進行とMACDヒストグラムの進行を合わせ、特定方向への売買を控えるための状態を作る考え方である。作者配布のマニュアルはEMA13・MACD12/26/9を既定例にし、Impulseへ逆らう売買を避ける説明を置いている。二時間幅を結合する別項目Impulse Releaseもある。本研究の「15分の禁止状態＋3分の価格発動」は独自構成で、Impulse Releaseそのものの再現ではない。[作者公式ページ](https://www.elder.com/product-page/elder-disk-v3-for-metastock-v15-with-scanners-1)、[作者配布マニュアル・印刷14〜16頁](https://6e6fa188-f273-4932-86c0-66af721f16a8.usrfiles.com/ugd/6e6fa1_c70983b8ebfa4100945b4c05c5f76c40.pdf)

MTAの講演報告にも平均とヒスト進行の一致・混在による色分けがある。ただし、その講演例のMACDは11/25/8であり、上のマニュアルの既定例とは違う。これは会合主催者による一次報告で、作者自身の原稿ではない。同じ名称でも期間・初期値・足の確定条件を記録する必要がある。[MTA会報2004年5月・6頁](https://docs.cmtassociation.org/docs/MTA0405.pdf)

## 本研究で明示する計算

以下のゼロ値・欠測処理まで含む形式化は本研究の仕様であり、全プラットフォーム共通の仕様とはしない。

~~~text
M_u = EMA12(C)_u − EMA26(C)_u
H_u = M_u − EMA9(M)_u
D_u = sign(H_u − H_(u−1))
E_u = sign(EMA13(C)_u − EMA13(C)_(u−1))

I_u = +1  （E=D=+1）
      −1  （E=D=−1）
       0  （両者準備済みで、それ以外）
    None  （必要な値が未準備）
~~~

MACD線、シグナル線、ヒストの水準、ヒストの一足差は別の量である。MACDのゼロ線とシグナル交差も区別される。[Fidelity公式MACD](https://www.fidelity.com/learning-center/trading-investing/technical-analysis/technical-indicator-guide/macd)

|状態|当時の数値が表すこと|本研究の禁止解釈|それだけでは言えないこと|
|---|---|---|---|
|I=+1|EMA13とヒストがともに増加|売りを控える状態|この足の買いが成功する|
|I=−1|EMA13とヒストがともに減少|買いを控える状態|この足の売りが成功する|
|I=0|準備済みだが同じ非0方向にそろわない|上記の同方向禁止が無い|反転確定、安全、低変動|
|I=None|必要な情報が無い|判断を保留|中立なので許可できる|

「禁止されていない」と「入る理由がある」を分ける。中立だけを買い・売り信号にすると、本来必要な価格の発動条件を消してしまう。

## 上昇・失速・反転を混同しない

H>0でΔH<0なら、MACD線とシグナル線の正の差が縮小している。MACD線が負になった、価格が必ず下落する、という意味ではない。ΔH>0のまま増加幅が小さくなる場合、二階差は負でもDは正である。初回の比較では二階差を追加しない。

EMA上昇・ヒスト減少という混在は、長めの平均が上がりながら平均差の進行は弱くなる状況と両立する。市場心理としては、追随する買いが弱まった、利確が増えた、という説明候補を考えられる。しかし終値の加工だけでは、その注文動機や主体を特定できない。

その後に元の価格端が崩れ、さらに後続足が失敗方向へ進めば、価格構造の継続的な不成立を追加で観測したことになる。これも強制決済や損切りの連鎖を実測した証拠ではない。心理は仮説を作る助けとし、採否は当時の数値・価格・時計で決める。

## 同じkで比べる二つの問い

元方向s、反転する実方向r=−sとする。元方向の背景と短期Force逆行bを知り、元の逆端を終値が破る失敗fを観測した後、別足の終値が失敗足の反転方向極値を越す最初のkを待つ。これは研究独自の価格確認である。

|役割|上位反転を必須とする案|元方向禁止の不在を使う案|
|---|---|---|
|新kまでの価格・短期条件|明示的f→別足k、現在Forceがr、ATR・時間条件|左と同じ|
|上位準備|H/EMAの現前が有限、当時公開済み|左と同じ|
|上位の値|D=r|I≠s|
|確かめたいこと|反転方向へのヒスト進行まで待つ必要があるか|価格確認がある場合、元方向にそろう禁止が無ければよいか|

両案の同じ新母機械・同じkでは、D=rならI=sにならないので、前者の純反転集合は後者に含まれる。追加されるのはD=0や、D=sでもE≠sである混在等の群である。純集合の包含は、実一建玉の参加集合・収益の包含を意味しない。追加反転の保有中に、後の順行注文へ参加できなくなる場合がある。

bでI_b=sを要求しない場合、全件を「禁止が解除された遷移」と呼ばない。kでの禁止不在だけを確認する。fで元寿命を延ばす、後の成功端を選び直す、WAIT全体を反転へ変える、といった条件はこの比較に加えない。

## 重複と実装時の注意

- EMAの定常更新からΔEMA=α(C現−EMA前)を得る。EMA進行と前平均に対する価格位置は関連し、独立した二票ではない。
- EMA13とMACDも同じ終値の平滑である。異なる役割を与えても統計的独立は保証しない。
- Forceは終値差×観測数量の平滑であり、観測数量が真の全約定量・攻撃側フローとは限らない。同じ正数量なら価格差平滑の定数倍になる。
- EMAの種、α、演算順、欠枠/限月でのreset、同契約carry、非公開足の内部更新を固定する。中心化値は絶対価格EMAそのものと表示しない。
- 15分の終了と公開keyの両方が3分判断時点以前であることを確認する。最新の未準備足を古い良好な足へ取り替えない。
- 売り買いは価格反射と符号反転で同じ条件にする。ゼロ・等号・欠測でも対称性を確認する。

実際の設定・支持・費用・先着と回収は各試行へ保存する。複合条件の利益をEMA又はMACD単独の効果として記録しない。
