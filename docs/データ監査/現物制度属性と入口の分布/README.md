# 現物制度属性と固定入口の取得分布

2026-11-18。既使用全83場のうちデイ42場を、通常日の現物立会と現物休場日に分けた事後診断。入口・決済・参加条件を変更した検証ではない。[分類前固定](分類前固定.json)に区分、出典、入力、SourceのSHAを残し、[全期間別診断](既存取得の制度別診断.json)へ保存した。

制度上の通常日は現物寄付前08:45〜09:00、前場09:00〜11:30、昼休み11:30〜12:30、後場ザラバ12:30〜15:25、引け板寄せ受付15:25〜15:30。現物休場の2026-09-21/22/23、10-12、11-03は終日休場へ分け、通常日と混ぜない。[JPX立会](https://www.jpx.co.jp/equities/trading/domestic/01.html)・[現物引け方式](https://www.jpx.co.jp/english/systems/equities-trading/01.html)・[休業日](https://www.jpx.co.jp/corporate/about-jpx/calendar/index.html)・[先物祝日取引](https://www.jpx.co.jp/derivatives/rules/holidaytrading/index.html)。確認日2026-11-18。

同じ全83場でも、日経とTOPIXの既存入口には取得した制度属性の違いがある。日経は通常日の寄付前に同じ10取得があり、TOPIX D4にはその帯の取得がない。

各商品mini1枚・費用後の円。日経の寄付前は旧199_00/02/05で同じ10取得・10黒字だが、母体・IFD幅・保有期限・時間帯支持がTOPIXと異なる。10取得の結果を将来の全寄付前に一般化しない。日経199_05は他の各群も合計黒字であり、両指数の差をこの10件だけで説明することもできない。

この10件のうち9件は±400pt/SESSION、1件は±350pt/H60で、決済は全て現物寄付後。寄付前の値動きだけから得た利益ではない。TOPIXのH60中心の評価と比較する際、入口の時刻に加えて保有期限と約定代用の違いも残す。

TOPIX D4の全体収支は+47,609.6円、前場群以外の合計が赤字。ただし「前場だけ注文すればその合計になる」という口座結果ではない。取得を除けば枠が変わり、後続要求の取得が変わる。時間帯別の閾値や除外条件はこの診断では作っていない。

区分に使った時計は実取得時刻。新しい入口の判断に使う場合は、当時既知のq0で分類し直し、境界を跨ぐ約定遅延と全後続枠を再生する必要がある。正常BBOや技術特徴の準備率、当時のスプレッド、数量可用性、支持件数と期間差を合わせて比較する。これは市場制度属性と取得集合の記述で、指数固有の参加者心理を確定した結果ではない。

[分類コード](分類する.py)はPython標準ライブラリだけで実行できる。入力は[206に固定した5母体のうち4BASE](../../../study/00206_指数間の相対変化を複合入口へ加える/金融正本/)。原板・売買条件・金融正本を変更せず、SHA不変を確認する。既存の[制度と参加構造の調査](../../議論/外部再調査/日本先物の時間帯と参加構造.md)、[指数差の検証方針](../../議論/両指数の入口探索を継続し相違の原因を比較する.md)へ接続する。

[独立確認](独立確認/確認結果.json)では生産分類コードを呼ばず、全群/全期間1,036属性・表48属性と寄付前の全個票を照合。4BASE入力と分類Sourceは前後SHA同体だった。[別集計Source](独立確認/照合する.py)を保存した。
