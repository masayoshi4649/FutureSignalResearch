## 先頭Raw1行のキー/時計だけを確認する場合

既存134監査は2ファイル各先頭1行で受信時計らしいキーを認めなかったという限定証拠を保持している。元保存コードも独自時計を付加しない。ただし全期間に別形式が混入した可能性まで、この2行だけで否定しない。追加確認が必要なら以下に限定する。

- Rootが固定した73場台帳から対象pathを列挙し、script/計画/台帳SHAをF0へ固定する。任意globで原板全走査しない。
- 各`book.jsonl(.gz)`の論理先頭1物理行だけを読み、JSONキーの階層と時刻フィールドの値/型だけを射影する。価格・数量・Symbol等の値や元行本文は保存/表示しない。
- 圧縮器の読取バッファが後続bytesを先読みし得ることと、JSONとして採用する行数1を区別する。全ファイルSHA再計算は別の全走査になるため、この限定監査では行わない。既存台帳SHA、before/after stat、先頭行SHAを保存し、全SHAを実検算したとしない。
- 最初の行に時計が無いことを全行不在へ外挿せず、見つかった独立時計も意味・単位・起算・値の妥当性を未確認のまま採用しない。

以下は未実行の射影関数案。ファイルopen/対象の選択/F0検証は含めず、Rootがガード付き監査器へ組み込む前提である。

```python
def project_keys_and_clocks(document):
    """
    機能: キー階層と時刻候補の値/型だけを残す。
    引数: document(dict|list)は許可された先頭行のJSON。
    返り値: dictはキー一覧と時刻候補。価格・数量の値は返さない。
    """
    import re
    keys, clocks = [], []

    def walk(value, prefix):
        """
        機能: 時刻以外のスカラー値を複写せず階層をたどる。
        引数: value(object)、prefix(str)は走査対象と階層。
        返り値: None。
        """
        if isinstance(value, dict):
            for key, child in value.items():
                path = prefix + '/' + key.replace('~', '~0').replace('/', '~1')
                keys.append(path)
                if re.search(r'time|stamp|received|receive|recv', key, re.I):
                    if child is None or type(child) in (str, int, float, bool):
                        clocks.append({'path': path, 'type': type(child).__name__, 'value': child})
                walk(child, path)
        elif isinstance(value, list):
            for child in value:
                walk(child, prefix + '/*')

    walk(document, '')
    return {'key_paths': sorted(set(keys)), 'clock_candidates': clocks}
```
