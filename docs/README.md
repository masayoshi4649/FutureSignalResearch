## 判断を引き継ぐとき

教科書は指標の定義と心理仮説を扱い、研究知見には、実際に比べた条件、観測された効果、成立しなかった局面を記す。特定の手法を再現する際は `algorithm/` の固定仕様を使う。各試行の `study/` にある条件・元帳の再現手順と、`outputs/` の候補別CSVに戻れば、約定単位まで照合できる。

2026年11月23日時点で、日経デイの固定比較基準はRC20。出口を加えたX2も次の追加デイで並行評価する候補に残っている。これまでの45デイは条件探索にも使用した。TOPIX・ナイトについては、それぞれの入力・費用・支持場数で得た結果を参照する。[RC20とX2の比較](../study/00228_日別の損益偏りと十月八日の入口出口を検証する/README.md)・[両指数の候補と未確認事項](議論/両指数の有望入口を固定して追加検証へ渡す.md)
