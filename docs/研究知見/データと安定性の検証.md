# データと安定性の検証

同じ入口を再計算したと言えるのは、判断に使えたデータ、売買側の価格、受付・約定の順番、評価対象の集合を揃えたときである。期間の総利益、先着率、件数のいずれも、その再現の一部を確認する数値にすぎない。[データとViewerの仕様](../データと閲覧形式.md)・[研究運用](../研究運用.md)

## 成績の単位をそろえる

- **費用。** RC20など日経miniの検証では1pt当たり100円・片道手数料38.5円・片道5ptの想定滑り。往復では1,077円。すでにBid/Askを使った粗損益にスプレッドをもう一度足さない。費用を事後に引くIFDと、費用後正益で床を起動する方式では滑り感度の計算が異なる。後者は発動と後続取引を再生する。[費用と原行差](../../study/00093_元三手法のmini連続再現と費用/README.md)・[費用に応じた起動時刻](../../study/00100_費用後利益化の前後で保護を分ける/README.md)
- **利益・損失・純額。** 確定した建玉の費用後正額を合算したものが利益、負額の絶対値の合計が損失。収支は利益−損失、利益損失比（PF）は利益÷損失。最大含み益から減った額は別指標。建玉の売買別・枚数別とセッション別の両方で中央値を求め、無取引の場はセッション中央値に0円として残す。未確定決済には0円を代入せず、既知小計・未知件数・どこまで判定可能かを表示する。[両中央値と追加禁止](../../study/00173_追加建てを禁止し両中央値で入口を再探索する/README.md)・[利益後の経路と実際の損失](../議論/増玉と短期保護を調べて分かったこと.md)
- **含み損益の経路。** 建玉の開閉・保有中の高低・それぞれの到達日時と原行、費用後に初めて利益が乗った時点、床を起動した時点、決済理由を同じ基準で記録する。観測した清算側BBOでの最大順行・最大逆行は、欠測区間を含む真の極値までは示さない。含み益は事後診断に使い、実現収支には当該約定だけを計上する。[含み益の診断](../../study/00009_含み益の赤字化と決済時点の診断/README.md)・[初正益と取得後1分](../../study/00117_正益起動と取得後1分波の失敗で利益を守る/README.md)・[損失日の各到達時刻](../../study/00228_日別の損益偏りと十月八日の入口出口を検証する/README.md)
- **単一口座。** 同時点の複数候補、保有・未決予約中の新規棄却、返済後に空く枠を通して再計算する。同一取得で決済だけ変わったもの、見送りで消えたもの、枠が空いて新たに入ったものを分け、合計差額を照合する。実保有時間率には保護後の再開待ちや未約定予約を含めない。[入口と口座損益の相違](../../study/00183_単純IFDで両指数の入口と損失安定性を検証する/README.md)・[取得の入れ替わり](../../study/00217_デイの利益集中と入口条件を比較する/README.md)・[再参加と保有率](../../study/00224_利益保護後の再エントリーをシグナルで待つ/README.md)

## 安定性を判定する順番

1. **条件をいつ決めたか。** 固定前に参照した期間、事前の主案・副案、途中で見つけた群、条件を変えず初めて追加日に適用した結果を記録する。過去から未来へ順に学習しても、枠組み自体をその全期間で発案したなら、その履歴は未見評価として再利用できない。探索前提の変更で生まれた仮説は新試行にする。[時間順での再評価](../../study/00126_複合切替を時系列に分けて学習評価する/README.md)・[固定候補を追加七場へ](../../study/00167_固定した複合入口を追加七場へ適用する/README.md)・[週ごとの過去選択](../../study/00225_過去のデイだけで出口を選んだ場合を検証する/README.md)
2. **損失がどう続いたか。** 赤字セッション数、最大1件損失、連敗・連続赤字場、開始からの最低累計、日末最大ドローダウン（DD）と回復までの場数、保有中評価込みDDの定義を分ける。173前48J026のデイは前半・後半の中央値が黒字でも、最初の12場中10場で累計マイナス。11場目の開始来最低は−42,924円、日末最大DDは48,385円だった。[累計と回復の実例](../議論/安定性を累計経路と取引の広がりで評価する.md)
3. **どこで稼いだか。** 期間前後、週、方向、入口の種類、上位1日／3日除外、指定日除外、追加日を並べる。比較元と各候補の利益上位日は揃わないことがある。各候補自身の上位日を外す集計と、基準の上位日を全候補から外す集計は異なる問いになる。[商品別の利益集中](../../study/00217_デイの利益集中と入口条件を比較する/README.md)・[方向別の収支](../../study/00218_日経199デイの売買方向と建玉日時を検証する/README.md)
4. **あとから分かった要因で説明を閉じない。** その日が下落・小幅だったこと、将来の高安、元の損切りに達したことは事後分類に使う。新規判断に移すには、当時用意できた代理変数で他の日に何件の誤判定が生じるか、既存の黒字・赤字がどう入れ替わるかを検査する。[追加日の悪化](../../study/00180_固定179入口を十一月十六日デイへ適用する/README.md)・[寄り前仮説の翌日反例](../../study/00216_十一月二十日の固定入口と寄り前の反例を検証する/README.md)・[事後の相場形状と当時判別可能な値幅](../../study/00228_日別の損益偏りと十月八日の入口出口を検証する/README.md)

検証を追加するときは、使った手法・足幅・閾値・不使用・未知を汎用表に残し、同じ判断をしただけの枝や費用感度を独立サンプルと数えない。候補別・全セッションのCSVと同一日付の建玉明細を対応付け、元入力の指紋・実行手順を試行へ残す。[手法と時間スケールの汎用表・版8](../議論/手法と時間スケールの汎用表_版8.md)・[研究知見の目次](README.md)
