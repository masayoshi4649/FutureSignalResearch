# 時間帯と指数間の移植

時間帯を区切る理由は、デイの現物寄付きや米国現物開始で、取引に参加できる市場と値動きが変わるためである。区分は判断時に分かる時計で決める。米国開始はニューヨーク現地09:30を日本時間へ変換し、夏冬の差を扱う。注文が境界をまたいだ取引では、入口をどの帯へ帰属させたかと、そこで強制決済したかを別に記録する。[三時間帯の運用定義](../議論/入口をデイと米国前後で分けて検証する.md)

## 共通の入口を使うか、帯別に作るか

153 U15・152 U0を帯別に集計すると、全体の先着率や利益／損失比が米国前の弱さを隠していた。帯別の問題に気付くことと、帯別モデルで予測が改善することは別である。同じ73場・±125ptで共通、帯属性付き、帯ごとに学習を比較した161の事前主案は、到達済み先着率が順に60.68%、56.64%、51.62%。モデルの細分化によって各条件の支持日数・市場局面・決済の未知件数も変わった。[固定入口の帯別診断](../../study/00160_入口を三時間帯で診断する/README.md)・[215モデルの比較](../../study/00161_三時間帯の入口を共通属性分割で比較する/README.md)

ナイトにも一部有望な候補はあった。172の事後選択B05_11は40ナイト・150取得、米国前78.75%、米国後88.89%、金融未知8。主119件に初参加補完31件を含み、事前主案の米国後100%には到達が4場に限られる集中があった。これを実用上の安定収入と結論づけず、どの時計・商品・背景で何場から得た率かを添える。一方、11月20日ナイトでは元の日経199共通入口が−66,462円、TOPIX専用212_06が＋74,913.2円。単日の反例は夜間全体の採否を決めない。[米国前後の探索](../../study/00172_デイを固定しナイト米国前後の複合入口を探索する/README.md)・[追加セッションの固定適用](../../study/00216_十一月二十日の固定入口と寄り前の反例を検証する/README.md)

## 日経の条件をTOPIXへ移したとき、何が違ったか

移植には三つの試験がある。①TOPIXの価格・量から日経と同じ条件を計算する。②日経が選んだ同一時点・方向の経路を両指数の板で測る。③日経の通知でTOPIX自身の一枠口座が発注する。②の診断には独立した重複経路が入り得るため、③の口座収支には足せない。旧42デイで、199_02をTOPIX自身で計算し呼値数を合わせた条件は費用前−51,000円、費用後−129,786円。日経の取得通知を使った独立TOPIX口座は40/42場・127件、既知＋282,466.4円、未知1件だった。[三つの移植・経路比較](../../study/00213_日経デイ199の入口をTOPIXへ固定移植する/README.md)

同じ局面を拾えなかった一例が現物寄り前である。15分MACD変化がまだなく短期の方向・勢い・回復で取る旧42デイの条件は、日経23件で13順3逆7未到達、TOPIX25件で5順10逆10未到達。11月2日は両者が08:56に買ったが、TOPIXは09:01に損切り、日経は09:15に利確した。一方、11月19日には日経側の価格が伸びた状態でもTOPIX買いが利確し、11月20日のTOPIXの寄り前売りも損切りまで1ptから持ち直した。現物寄りの機械的な除外や「片方が伸びたら必ず逆張り」を支持する一貫した結果は得ていない。[価格位置と現物寄りの診断](../../study/00214_日経とTOPIXで入口の成績が分かれる理由/README.md)・[翌日の反例](../../study/00215_追加デイで日経とTOPIXの固定入口を再検証する/README.md)・[11月20日の固定適用](../../study/00216_十一月二十日の固定入口と寄り前の反例を検証する/README.md)

指数構成・価格水準に加え、呼値、1ptの円換算、費用の値幅比、正常な観測機会、量の取得時刻、同じ本数の足が覆う実時間が異なる。これらを段階的にそろえると「入口の判断が違う」のか「同じ方向・時刻でも値動きが違う」のかを検討できる。相手指数の過去向き結合では、81場の主条件の可用率がデイ98.03%、米国前93.26%、米国後87.48%。実際の配信順序や秒単位の先行性は別途必要である。相手指数の支持を常に要求した206の比較にも共通の損失改善は見られなかった。[両指数の共通条件](../../study/00187_両指数を同じ価格特徴とIFDで比較する/README.md)・[量と観測機会](../../study/00197_TOPIXの量と観測機会と方向尺度を分離する/README.md)・[指数間の相対変化](../../study/00206_指数間の相対変化を複合入口へ加える/README.md)・[時計と可用率](../議論/指数間の先行追随を価格時計で参照する前提.md)
