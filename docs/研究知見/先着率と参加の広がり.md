# 先着率と参加の広がり

先着率は「指定した値幅まで順逆どちらが先に動いたか」を測る。ユーザーが一旦達成とした入口目標は、日経ラージの実側気配、取得後60分、同幅±125ptで、全73場に最低1取得かつ到達済み先着率70%超だった。現在のRC20は別の対象・値幅・保有条件を使う。[当時の達成判断と候補一覧](../議論/入口目標の一旦達成と候補比較.md)

## 条件変更後の評価表の読み方

- **実際の頻度**は取得数÷対象時間。**場別参加率**は1回以上取得した場数÷対象場数。**保有時間率**は1枚以上を実保有した時間÷対象時間。定時枠基準の「新規＋継続保有」も別の量になる。除外する開始待機・場末時刻、予約・欠測をどう扱ったかは数値の隣に置く。[参加時間の定義](../議論/保有時間の参加率と終了十五分前決済で入口を評価する.md)
- 1場最低1件という目標は、時刻が来たという理由だけで例外注文を足す根拠にしない。主候補と、当日初参加を狙う補完候補それぞれで件数・損失・連敗を出す。保留中に別経路から未確認で注文が通った試行194～199では、見送りで生じた後続取得の差が結果を動かした。[保留中の補完](../../study/00195_保留中の補完入口を技術根拠で判別する/README.md)・[別経路による注文と介入の効果](../../study/00199_保留中の旧幹を確認済みの根拠で切り替える/README.md)
- 幅の広いIFDでは、H60を観測しきった取引のみ分類する旧方式と、欠測前に既に触れた側を確定する方式がある。後者でも未到達と観測不足を分け、条件間で同じ時計を使う。保有60分はこの研究段階で置いた観測期限で、セッションの両端のノーポジションと独立に指定する。[到達を確定する時計](../../study/00164_IFD最初到達の確定時計で入口と反転を比較する/README.md)・[期限を外した日経デイの対照](../../study/00222_セッション両端の建玉制限と期限なしIFDを照合する/README.md)・[研究知見の目次](README.md)
