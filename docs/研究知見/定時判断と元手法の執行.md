# 定時判断と元手法の執行

同じ手法名でも、シグナルが生まれた時点で建てる取引と、15分後にまだ保有中の参照玉を見て建てる取引には、別の建値と残存リスクがある。原通知時刻・実取得時刻・残数量・決済可能価格をそろえた比較から読む。[元手法の通知と取得の違い](../議論/元の連続新規で確認したminiの黒字と費用.md)

## 15分ごとの判断で分かったこと

## 「大きく張った途端に損切り」を分解する

枚数が増えれば同じ逆行幅でも金額損失は増える。元の配分で複数枚になったことと、当時のチャートが強かったことは別に記録する。各建玉の売買側、初期と追加の枚数・取得価格・時刻、1枚当たりの最大順行／逆行、到達順、最終費用後収支、出口の起動時刻までを追う。機会損失の推定や「ピークで売れた場合」の増益を集計に足さない。[参照玉と可変配分](../../study/00087_FAR参照玉と可変数量の比較/README.md)・[正益と取得後の経路](../../study/00117_正益起動と取得後1分波の失敗で利益を守る/README.md)

試行112のP100の1枚取得では、片道5pt追加条件で最終赤字173玉はすべて未起動。うち一度費用後正益だった93玉の90玉は、初正益から60秒以内に負へ戻った。一方、11月6日の売り7枚には起動済みでも幅1,030ptが残り、評価＋552,461円から実現＋13,461円になった例がある。前者に必要なのは初期損失・起動前の検証、後者には既に起動した床の変更と執行の検証である。[建玉単位の診断と出典](../議論/増玉と短期保護を調べて分かったこと.md)・[利益保護の比較](損切りと利益保護.md)・[研究知見の目次](README.md)
