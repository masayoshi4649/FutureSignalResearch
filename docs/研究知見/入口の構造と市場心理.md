# 入口の構造と市場心理

判断したいのは「この先上がるか」だけではない。上位足が示す方向に対し、現在の価格が押し戻されているのか、すでに回復したのか、反対側に定着したのかによって、同じ上向きの移動平均でも買う場所と売る場所が変わる。下表の心理は注文行動の仮説で、指標から参加者の意図や人数を特定したものではない。[指標の役割別分類](../technical-analysis/分類/README.md)・[市場心理の教科書](../technical-analysis/市場心理/README.md)

| 何を知りたいか | 当時のデータで観測できる例 | 解釈を疑う条件 |
| --- | --- | --- |
| 進む方向と持続 | 30分のEMAの傾き、15分のDI差・ADX水準と変化、5分の平均からの位置 | 上昇の履歴で平均が上を向いたまま、足元は下向きになり得る。ADXの水準だけでは売買方向は決まらない。 |
| いま動き始めたか | 5分MACDヒストグラムの符号と前足差、RSIの持続、短期高安・実体の回復 | 単発の大きな足は数期間指標に残る。RSIの高値・低値はその場での反転時刻を与えない。 |
| 値幅に余地があるか | ATRに対する取得価格の距離、BB幅の拡大・縮小、短期足の実体とヒゲ | 値幅の縮小は方向を指定せず、支持水準へ届いた時点では反発をまだ観測していない。 |
| その方向に取引が進んだか | 完結した足の相対出来高、一定の価格水準へ試した後の終値・次の足の保持 | 大きな出来高は逆側の注文による吸収とも両立する。薄商いの中の価格移動や単なる取消もある。 |
| 取れる位置か | 元の水準を固定し、候補の発生、再接触・回復、取得側気配を別々に記録 | 判断を遅らせた時は取得位置も動く。後から確認できた根拠を過去の好値に遡及させない。 |

## 順行・反転・待機を分けた試行

- **押戻しからの順行。** 先行する値動き、節目への戻り、失速、実方向への再開の順に見る。試行136は背景と押戻しを先に認識し、5分の勢い改善、別の1分足での構造回復と同足の量、その後の板での保持を要求した。実取得に至らない枝が出る。各段階で何件残り、どこで公表が間に合わなかったかを残すと、条件を緩める場所を絞れる。[押戻し後の回復](../../study/00136_押戻し後の回復入口を加えて頻度と先着を比較する/README.md)・[成立が減る段階](../議論/背景の支持と押戻しの減速を同時条件にしない.md)
- **失敗した突破からの反転。** 節目の外へ出た事実、内に戻った事実、元方向の勢いが弱まった事実を分ける。逆指値が連鎖すれば突破が伸び、反対側に吸収されれば節目の内へ戻るという仮説は、この二つの経路で検査できる。試行121は構造回復に30分ADXの低下を加えて6順1逆を得た。ただし先に見つけた7例で、全73場に同条件を適用した主評価60分・±100ptは6順3逆だった。出来高の条件を加えた案には先着5順1逆でも期限評価の平均が赤字の例がある。[失速と量](../../study/00121_失速と量で反転の入口を切り替える/README.md)・[全73場での固定検証](../../study/00122_E0固定条件を全セッションで検証する/README.md)・[外部研究とOSEでの観測範囲](../議論/価格線への試行と定着を分けて入口を考える.md)
- **待つ、または方向を変える。** 試行118では、元通知から200pt有利な指値を待つと、約定71・観測完了68件の±100pt先着は22順45逆1未到達、追加滑り込みの平均は−3,974.06円。新しく立てた技術的な確認条件と有利な価格制限の両方を要求した枝は取得0。試行124で全件の売買を逆にしても改善しなかった。「逆行しがち」を見つけたら、同時点の反対側気配で再取得し、逆方向が改善する局面を別期間で検査する。[200pt待機と取得価格](../../study/00118_指値待機と複数技法の取得確認で入口を比較する/README.md)・[売買の実側反転](../../study/00124_逆行の原因と売買反転を同じ入口で検証する/README.md)

## 何を足しても改善するわけではなかったか

- 初期の147候補では、3分の開始帯からの失敗復帰にADXを加えた固定候補が、学習27/71・選択18/47。これは「125pt逆行前に250pt順行」の全仮約定に対する割合。15分の方向を追加したときの効果は期間で反転する例があり、足幅を変えると欠測・準備・注文数も変わった。日経とTOPIXを異なる倍率のまま円で合算せず、各商品・費用で対照を置く。[四系統の要因比較](../../study/00002_複数時間足と四系統の要因比較/README.md)・[六手法・三尺度・四補助](../../study/00006_外部手法を1分3分5分で比較/README.md)・[費用を加えた一建玉の成績](../議論/外部手法の検証で得た知見.md)
- 一目の上位方向を伴う基準線復帰では全案が支持件数を満たしても目標に届かず、価格極値・BB内復帰にOBV非追随を足すと両期間の先着率と平均損益が悪化した。CCIの持続に上位BB幅を加えた比較では主先着率と、重なりを間引いた率・費用後平均の動きが揃わなかった。成立に必要な履歴が新たに揃った件数、元から成立し選別された件数、実口座で新たに取得できた件数を分ける。[一目](../../study/00028_基準線復帰と上位一目の方向/README.md)・[OBV](../../study/00029_BB内復帰とOBV非追随/README.md)・[CCIとBB](../../study/00031_CCI持続と上位BB幅/README.md)・[SAR・VR・CMF・回帰・Force等の個別条件と反例](../議論/テクニカル手法の検証範囲と次の複合候補.md)
- 参照価格には起算時刻がある。配信VWAPはデイ開始起算と一致しない場があり、現在価格との上下関係とVWAPの傾きには同じ価格・数量の寄与が入る。節目を試した時点で固定した価格へ戻ろうとしたか、保持したか、量が伴ったかを別々に観測する。[入力列の監査](../../study/00017_配信元VWAPと売買代金の入力監査/README.md)・[起算と価格構造](../../study/00204_VWAPと価格構造の両指数入口/README.md)・[順序と量支持](../../study/00207_VWAPと固定価格の時間順入口を量支持で比較する/README.md)
- 試行201は両指数166商品場、約2,674万行の板数量で25口座を比較した。同方向の板支持を必須にすると参加と両中央値を失った。日経で強い反対板を除くと損失・DDが減る場面があっても、TOPIXで同じ効果は続かなかった。短期の反対板は長期順行の途中の押戻しでも発生する。板数量の更新回数、約定価格の時計、足の尺度をそろえて読む。[板数量の追加比較](../../study/00201_板数量の更新尺度を複合入口へ加える/README.md)・[短期の符号と押戻し](../議論/板の短期符号と押戻しの位相を分ける.md)
