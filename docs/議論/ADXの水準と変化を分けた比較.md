# ADXの水準と変化を分けた比較

78では、同じ終値反応TからADX変化の非負条件だけを外した。選択24場のT限定S0は純候補が23から34へ増え、250pt先着は4/23から7/34になったが、実回収は−4,306円から−7,448円へ悪化した。T/R併用S1も−8,482円から−11,624円へ悪化し、入口・費用・全枠活動の同時目標を満たす新政策はなかった。候補を減らしていた条件であっても、解除すれば入口の質や利益が改善するとは言えない。

正本は[試行78の概要](../../study/00078_ADXの水準と変化を分ける/README.md)、[計画](../../study/00078_ADXの水準と変化を分ける/検証計画.md)、[結果JSON](../../study/00078_ADXの水準と変化を分ける/結果.json)、[設定と結果](../../study/00078_ADXの水準と変化を分ける/設定と結果.md)、[保存監査](../../study/00078_ADXの水準と変化を分ける/保存物確認.json)である。確認日は2026-11-07。全66場は既使用。「学習」は初20場の準備専用部分を除く時系列評価20場の保存区分名で、新しいfit・モデル・独立測定は0。後続2場も未使用期間ではない。

## ADXの強さと非減速を分ける

[77の早いT確認](../../docs/議論/押戻し再開の確認を早めた比較.md)をそのまま使い、TのF48>=0だけを入口の必須条件から外した。F47は公開15分足のADX/100、F48はADX現前差/100である。0は旧から許されており、「上昇必須」ではなく「非減速必須」の解除になる。F51=F52=1、F47>=.20、DI同方向、FastKの位置と増分、現在価格進行、当時Lastと新規BBOの前提線strict側は維持した。R資格も全文不変で、ADX低下だけを反転成立としない。

親、出生ATR_b、出生からの最初r/f、Tの最初の終値反応kとその直前出典、R、永久取消、公開時計、期限、場所診断は変更していない。全1,702枠、基礎準備1,468・局所準備1,465、親履歴延べ10,149観測の構造が一致した。10,149は各定時で繰り返し見た親数の延べ和で、固有親数ではない。出生ATRは76成功保存値を再用し、再計算も複写も0である。

[外部根拠の整理](../../docs/議論/外部再調査/ADXの水準と変化を入口で分ける.md)では、DIが方向、ADXが方向によらない強さを表す一般説明と、高いADXが過去の強さを残す可能性を確認した。ここから同方向調整を拾う問いは立てられるが、消耗や弱い波の流入も反例になる。「利確が増えた」「参加が続く」は心理の仮説で、ADXから実主体・意図・注文フローを測定した事実ではない。公式教材は本研究の3分/15分、250/125先着や費用後回収を実証していない。出典URLと確認日はリンク先に記録した。

E0/E1は77成功保存の参照で、再運用していない。S0はTのみ、S1は同じ親機械のT/Rである。ラージBBOをmicro代理1枚10円/ptへ使い、主費用は片道11円・滑り5pt、往復122円。250ptが125pt逆行より先かという旧55の独立先着と、一枚占有・連続保護を伴う実運用回収は別の分母である。

## 活動、費用、利益保護の未達

選択S0の利益旗24件中19件、S1は27件中22件が主費用後赤字だった。S0の内訳は同値8・有利費用負け9・不利2、S1は10・10・2である。現在費用後益strict正で旗を立て、その後は最低名目新規床を維持する規則でも、遅延と費用を含む最終黒字は保証しない。先着250に対応する実退出では、S0が6件、S1が9件で250到達前に退出した。

選択S0の滑り0/5/10pt感応は−4,048/−7,448/−10,848円、S1は−7,424/−11,624/−15,824円で、滑り5ptだけが赤字の理由ではない。後続の＋790円は共通5完結・既使用2場の結果である。

主待ち率/判定不能を含む保守上限は、選択S0が84.12/96.06%、S1が83.11/95.05%だった。時系列もS0が79.32/96.62%、S1が78.65/95.95%、後続は両者89.19/93.24%で、全3期とも全定時枠50%以下の活動条件を満たさない。保有継続は待ちに含めていない。新規増を活動目標達成へ読み替えず、未準備と判定不能も分母に残す。

## 次の未固定の問い

78で確認したのは、ADX減速だけに阻まれていた同じTを追加しても、今回の既使用期間では費用後回収と活動の目標へ届かなかったことだ。ADX減速が常に有害、又は高ADXなら減速を許してよいという単独指標の効果は証明していない。追加Tは他の全資格を満たすという限定された集合であり、複合評価の成績をADX単独へ帰属させない。

次は、現在有効な価格形、DIの役割、FastKの位置と増分、現在進行、定時での取得位置がどの順序で残るかを分けて問う。方向・勢い・値幅・価格構造・量の役割を既存手法一覧から組み合わせ、取得位置や保護幅まで同時に変更して改善を先取りしない。ADX水準の変更や未知条件の緩和を今回の結果へ後付けせず、新しい仮説は別試行として固定する。心理の説明と測定された価格/指標条件、既使用探索と未使用期検証を分ける。
