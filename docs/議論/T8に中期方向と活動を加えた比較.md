# T8に中期方向と活動を加えた比較

[130](../../study/00130_中期方向と活動で既存の複合切替を補正する/README.md)は、T8がB0を反転する場面で、B0向き15分EMA並び・傾きとRVOL5≥2が揃えばB0へ戻す主V2を検証した。全79固定取得/73場は維持したが、主H60±125ptは39順18逆未到達16・不足6、68.42%で70%未達。参加条件は固定Source上で満たし、自然新規注文の取得を再構築した意味ではない。

既知IFD76のC5利益494,381円/損失327,233円・差引+167,148円、未知3。固定T8の利益506,304円/損失313,156円・+193,148円に対し26,000円悪化した。副V1（RVOL≥1）は61.40%・+59,148円でT8比134,000円悪化。高量と中期整合を加えれば一律に良くなるとは確認できず、この補正を採用しない。

V2は前48場でT8比−52,000円、後25場で+26,000円。後半の率はT8の60%から65%へ改善したが、全体の主を超えていない。前48場V2の70.27%はその区分の数値達成として残す一方、良い期間へ主を交換しない。全73は既使用で、過去のB0/T8の選択偏りも継承する。

金融前に決めたV2の4方向変更を検算すると、09/30 Dayは双方−14,077円で差0、10/01 Nightと10/02 Dayは各−26,000円、10/30 Nightは+26,000円、合計−26,000円だった。正逆が同じ損失になる例もあるため、反転の勝率を単純な1−pで作らない。量は参加の大きさを表す仮説上の役割を持つが、継続・消耗・清算を単独で判別した証拠ではない。

固定O0/B0/T8の旧180条件は全て一致し、全5政策/BBO・Lastのentry/touch/endpointも価格時計上のザラバ終端前だった。新しい2分bufferやSource取得の削除で成績を変えず、位相と方向補正を分けた。受信/板更新時計がないため実miniの約定可能性を証明した検査ではない。

今回の知見は「中期方向＋強い量」という一般的な言い回しだけでは、既存の複合切替を改善できなかったこと。既知76例の正の差引と、未知3、先着70%未達、未知期の再現性を分けて残す。固定T8のさらなる位相診断と、採番前の独立出生案を別の母集団として継続する。
