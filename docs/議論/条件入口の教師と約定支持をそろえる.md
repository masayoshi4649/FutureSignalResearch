# 条件入口の教師と約定支持をそろえる

確認日：2026-11-06。[試行69](../../study/00069_条件入口に合わせて技法群の教師を作る/README.md)の保存結果から得た知見。新6木・24回帰fit・4,092独立方向・184実運用を実行し、458,900照合で差0。全66場は既使用であり、新しい未見検証ではない。

条件入口に正解データを合わせるだけでは、今回の売買候補は増えなかった。条件教師C0/C1は全期間で取引0。損失0を収益改善とせず、**細分化した技法群に十分な約定例が残らなかったこと**と、**例数が残った群でも候補先着率に達しなかったこと**を分ける。

## 比較したもの

15分定時の同60特徴、DI方向と対応する価格経路の有効状態による先頭分岐、子の学習形式・候補特徴・容量、将来の3分足高安突破を待つ入口、発動前取消、費用、連続追尾は共通とした。学習後の子の分岐・閾値はIとCで異なる。売買は同じ式の符号反転であり、利益後の最低名目新規床も維持した。

| 比較 | 変更と解釈 |
| --- | --- |
| 保存68のN→69のI | 即時入口の教師を使う点は共通。ただし共通可知集合と無取引の扱いも変わるため、教師の価格時計だけの比較ではない。 |
| I→C | 同じ可知枠・同じ特徴・同じ学習構造で、正解データを即時入口から条件入口へ変更。実運用は両者とも条件入口。 |
| 0→1 | 同じモデルで、過去の費用後回収総額が厳密に正という条件を追加。両側の適格性を先に判定するため、売買の部分集合とは限らない。 |

確定無取引は回収0として分岐学習へ入れ、250/125先着率・約定支持の分母へは入れない。観測不足や品質注意は未知であり0補完しない。全準備済み4,092方向の分類は、確定無取引2,767、確定約定1,289、未知36だった。

共通可知枠は最初20/30/40場で537/809/1,097枠。条件教師の約定行は320/498/686で、同じ集合の即時教師の約定行986/1,482/2,014より少ない。両方向の行を持つことと、両方向が約定することは違う。条件入口では最初の価格端への到達が一方の発動と他方の否定をもたらすためである。

## どこで取引がなくなったか

学習時の葉の支持条件は、約定例60枠・6日・10場。これは最終評価の70%目標とは別の最低例数である。候補の先着score条件も従来の1/3を維持し、結果を見て下げていない。

| C0モデル | 葉の数 | 支持を満たす葉 | scoreが1/3以上の葉 | 同時に満たす葉 |
| --- | ---: | ---: | ---: | ---: |
| W20 | 11 | 0 | 2 | 0 |
| W30 | 14 | 0 | 3 | 0 |
| F40 | 16 | 3 | 3 | 0 |

W20の各葉は約定10〜58枠、W30は13〜53枠で、すべて60枠未満。F40で支持を満たす3葉の先着率は14/68、23/80、21/69で、いずれも1/3未満だった。逆に1/3を満たす3葉は35/32/42枠で支持不足。全葉の複数技法条件は満たしており、単一指標だけで判断していたための不採用ではない。

回収0の未約定を含めて分岐するとき、回帰に使える例数と、その枝で実際に約定して先着率を確かめられる例数は違う。細かく分けた後に支持を検査する設計では、分岐が作れても使える葉が残らない。これを「条件教師は常に無効」「テクニカルに意味がない」という結論へ広げない。一方、支持不足を理由に合格とみなすこともしない。

条件選択24場の比較を示す。micro代理1枚、片道手数料11円＋滑り5pt、往復122円。入口は独立仮約定、損益は保有制約を守った実運用であり、分母が異なる。

選択N0とI0の共通85取引は新規・返済・保護・損益が同値で、−17,670円。I0の差額＋78円は追加1取引で生じ、滑り10ptならこの1件は−22円だった。共通入口での回収改善とはしない。C0ではI0の86取引がすべてなくなり、黒字16件も赤字70件も除外された。

I0の時系列20場は4/7で57.14%だが、7件では支持不足、実回収は−2,054円。既使用後続2場はI0が−1,410円、I1が＋134円だが、I1は3件で支持不足かつ滑り10ptの感応では−166円。部分期間や小標本だけから黒字化とはしない。

選択I0は利益旗54件のうち38件が費用後赤字。内訳は同値価格23、不利価格2、粗益は正でも費用赤字13。即時教師から条件教師へ変えれば、最低名目新規床での費用負けが解決するとは確認できなかった。先着250のラベルと、そこへ至る前に返済する建玉の損益を混ぜない。

## 次に区別する問い

まず、同じ方向・価格構造・勢い・量の組み合わせを、約定例数を保てる粒度で評価できるかを問う。支持条件を下げる代わりに、支持を失う細分化を採用しない案がある。ただし方向だけ・価格構造だけの粗い節へ戻すなら、複数手法の条件も改めて満たす必要がある。分岐の変更で成績が改善するかは未検証である。

その上で、強い方向と有利な取得位置を分ける。上位方向が同じでも、直近の伸びの末端へ入る場合と、押し戻し後に再開する場合とでは、現在の保護線へ戻る余地が違うという心理仮説である。[外部調査](外部再調査/継続の方向と取得位置と短期保護を分ける.md)を根拠に当時点で測れる価格位置を候補化し、量・勢い・構造と合わせたときに違いを判別できるかを検証する。過熱だけで逆張りへ切り替えず、逆側自身の価格確認も別に求める。

目標・売買鏡像・費用後正での利益旗・最低名目床・場内完結を維持する。新しい条件は別試行へ固定し、69の正本を書き換えない。旧資料の心理説明を、今回確認した統計結果や70%達成の証拠として数えない。
