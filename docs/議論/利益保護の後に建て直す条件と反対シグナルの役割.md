# 利益保護の後に建て直す条件と反対シグナルの役割

2026-11-22。日経199_02のデイで、元の±1Rの利確・損切を残して利益を守る方法を比較した。1Rは入口が決めた片幅。保有時間に上限を設けず、開始20分・30分待機と15:30までの全決済を守った。対象は既使用45日、ラージの正常気配によるmini 1枚の費用後試算。

1. **どの順行も保護すべきか。** 単純IFDで0.50R順行した後に費用後の建値に戻った32件のうち、17件はその後に元の利確を達成した。初めて費用後の含み益が出た時点で建値に保護床を置いた口座は、元利確76件中3件しか同じ価格・時刻まで残せず、20分待機で45日収支−622,795円だった。出来高を確認すると早過ぎる返済は減ったが、選んだ条件の後半21日は単純IFDに届かなかった。[223の順行・出来高・価格構造の比較](../../study/00223_保有期限なしの利益保護を順行幅と値動きで比較する/README.md)
2. **追尾が成功してから、いつ枠を使い直すか。** 元の取得と返済側を固定し、反対シグナル2回で狭く追うR02を使うと、総損失は96,231円減った。自由に新規を再開するとさらに8件が成立し、その8件の総損失78,308円が口座に戻った。RCは追尾返済した時点で無保有となり、元の建値±1Rのいずれかへの到達だけを観測してから再開する。未保有時間を保有率に加算せず、仮想の損益も計上しない。[224の同じ入口での検証](../../study/00224_利益保護後の再エントリーをシグナルで待つ/README.md)
3. **反対方向を確認する意味。** 同じシグナル時刻で方向を無視して2回数えた案とRC20は、両方とも単純IFDから総損失が96,231円減った。ただし、方向を問わない案は利益も削り、収支が85,000円悪化。反対方向の条件を置いた方は収支38,000円増だった。「反対の根拠が揃うまでは、元の利確達成前の押しを許す」という解釈に合う。参加者の心理を直接観測した結果ではない。[226の方向と公表時刻の対照](../../study/00226_反対シグナルの方向と時刻を対照して利益保護を検証する/README.md)
4. **日ごとに選び直した方がよいか。** 前週までの結果だけで翌週の出口を決めても、総損失の減少と収支の増加を両立できた評価週は1週だった。週ごとに入れ替える対照は損失を抑える候補から外し、追加日には単純IFDとRCを同じ入口で固定比較する。[225の週ごとの成績](../../study/00225_過去のデイだけで出口を選んだ場合を検証する/README.md)・[追加日への適用](../../study/00224_利益保護後の再エントリーをシグナルで待つ/追加日への適用.md)

RC20は建玉・日次の費用後中央値がともに黒字で45日全てに参加した。赤字日14→11、日末最大下落74,693→63,154円。単純IFDから収支が変化したのは7日だけで、10月14日を除く収支差は−5,000円。前24日では収支が5,000円減り、後21日は43,000円増えた。一方、どの1週を外しても損失減は55,154円以上残る。次のデイでも、損失の深さ・赤字日と、利確の途中で手放した利益を別々に数える。[週ごとの損失と収支](../../study/00224_利益保護後の再エントリーをシグナルで待つ/期間別のばらつき.md)
