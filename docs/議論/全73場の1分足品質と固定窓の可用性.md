# 全73場の1分足品質と有限窓の可用性

2026-11-12。F0固定後に実行済みの**非金融・完成CSV品質監査**を恒久保存した。対象は既知73場（37デイ/36ナイト）の1分CSV、ザラバ格子43,255分。新しい価格再読・原板・金融・出生・追加2場の解析を本保存作業では行っていない。

|確認項目|結果|
|---|---:|
|格子全体の価格/量共同完備|21/73場|
|価格だけの格子全体完備|26/73場|
|欠けた分|2,586分|
|価格既知|40,669分|
|量既知・共同既知|各40,622分|
|生成器の量不完全flag|47分、全てCSV先頭データ行|
|既知量0/未知量0|各0分|
|終端に既知連続区間あり|73場|

独立実装が全43,255分のmask辞書、73場要約、件数を正本と照合した。UTF-8・ヘッダ・列数・構文・時刻不正、対象格子内の重複/後退等は各0だった。先頭の量不完全や途中欠分を0/前値で補わず、session_startからの完備性と後続の連続既知区間を分けた。

これは収集器CSVの保守的な共同既知maskで、通信受信/全約定完全性の証明ではない。joint=falseを全ての数学的VWAPが不可能という意味にせず、既知量0/価格未知の寄与0等の別定義も区別する。今回はVWAP/VWMA値を計算していない。

セッション起算の平均を必須とする案は、この入力規約では全場参加が難しい。局所の[VWMA](../technical-analysis/指標/出来高加重移動平均線.md)は後の連続20分等から回復できる別測定だが、「73場にどこか正常区間がある」だけで全場のVWMA20/背景/取得まで成立したとは言えない。元VWAPを途中起算へ改名せず、新しい測定と試行を分ける。

完成fileの最終mask・将来の最長正常区間・後続のエラーで、オンラインの過去出生やanchorを選ばない。新入口では現在までに配送済みの1分格子と品質だけを使い、最新分が不良なら古い良い分へ戻らない。[受信/価格/研究公表時計](../データと閲覧形式.md)も参照。
