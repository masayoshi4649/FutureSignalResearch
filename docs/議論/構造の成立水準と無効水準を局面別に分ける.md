# 構造の成立水準と無効水準を局面別に分ける

## 同じ「回復を失った」へまとめない

過去の足で成立した形と、現在の価格でなお成立している状態を分ける。同時に、その水準が何のためのものかも分ける。

|役割|例|次に確認すること|
|---|---|---|
|監視する水準|既知高安、BBの端、EMA帯|到着しただけで注文理由にしない|
|成立を確認する水準|終値の高安突破、直前足始値の回復|当時足で何を確認したか、現在価格との距離|
|仮説が無効になる水準|突破端への復帰、反対側の極値等の候補|成立線と同じ水準か、別の構造が崩れた時かを事前に定義する|
|取得を評価する位置|q0のLast/Ask/Bid、別原行q1の実側価格|価格の追いかけ、確認後の戻り、実側費用を区別する|

例えば、レンジ下端で直前始値を回復したことは反発の確認材料になりうる。しかし、その始値まで戻ったことがレンジ下端の破壊を意味するとは限らない。一方、上側の端を突破した後、元の範囲へ復帰した場合は、突破の維持が崩れたという別の仮説を立てられる。どちらも反対側の注文が増えたという心理の仮説であり、参加者の意図を直接観測した事実ではない。

## q0だけで記録できる状態

方向をs、ATR5をA、既知1分終値をC、直前1分始値をO、q0LastをL、先行3本の方向側端をEとする。

|状態量|既存100特徴からの式|意味|
|---|---|---|
|直前始値に対する現在Last|`m1_body_reclaim_atr5_to_side + q0_last_minus_m1_close_atr5_to_side`|s(L−O)/A。正負は状態を記述するだけで、自動的な無効判定にしない|
|既知終値による端突破|`q0_last_minus_prior3_forward_edge_atr5_to_side − q0_last_minus_m1_close_atr5_to_side`|s(C−E)/A|
|現在Lastによる端突破|`q0_last_minus_prior3_forward_edge_atr5_to_side`|s(L−E)/A|

必要値の未知は未知のまま残す。q0の判別へq1価格や先着結果を加えない。売買は符号変換した同じ式で評価し、実逆の結果は同じq1の逆側BBOで観測する。1−pによる補数計算はしない。

## 次の検証

成立線・無効線・取得位置を局面ごとに固定した候補を作る。既に失敗した突破と、反発確認後の通常の戻りを分ける。旧指標の方向が維持されていても現在の構造状態が異なる場合に、順行・反転・待機を切り替えられるかを検証する。

上の少数群を全て統合しても、旧C1の87＋R2の92＋T4の26＋R3全59＝重複前264件が上限で約0.366件/時にすぎない。これだけの統合で頻度目標を達成したとはしない。母集団から独立に生む構造候補の成立数、又は過去場だけの技術局面判別を先に設計し、全73場min1・平均概ね1回/時・実BBO/H60/±125の70%を維持する。

OR8候補のq0は足Endから中央値63秒、取得は68秒だった。これは既存のEnd+60公表モデルを含む価格時計で、実受信遅延ではない。価格変化は両方向にあり、遅延だけを不振原因と断定しない。CSVの足ラベルを都合よく前倒しせず、時計を変えるなら別入力・別仕様として検証する。

## 外部の一般論と限界

確認日2026-11-12。[CMEの支持抵抗](https://www.cmegroup.com/education/courses/technical-analysis/support-and-resistance)は既知水準での反応や突破後の役割変化を説明し、[CMEの反転パターン](https://www.cmegroup.com/education/courses/technical-analysis/technical-patterns-reversals)は形の確認と量を材料にしている。これらは水準の役割を分ける一般的背景であり、今回の26件/25件/92件やNK225の125pt目標を保証する根拠ではない。
