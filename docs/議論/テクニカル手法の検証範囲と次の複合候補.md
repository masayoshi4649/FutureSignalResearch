### 候補1：一目均衡表の方向を同時刻の複合発動へ追加する

**実行前の主仮説（00028で検証済）**：上位足の高安中心が示す方向と同じ向きの下位復帰は、同じ復帰でも背景が異なるものより125/250先着・費用回収がよいか。第一巡では順行側の仮説に絞り、反転は候補2で別に扱う。

**固定案の価格・勢い条件**は次の通り。数値は教科書の代表値を起点にした仮説であり、NK225分足で妥当と確認された値ではない。

| 要素 | 買い | 売り |
| --- | --- | --- |
| 3分の基準線 | `J26(t−1)=(過去26本最高H+過去26本最低L)/2`。t−1までの値を固定 | 同式 |
| 価格発動 | `C(t−1)≤J26(t−1)<C(t)` | `C(t−1)≥J26(t−1)>C(t)` |
| 3分生K14 | `K(t)=100×(C(t)−LL14(t))/(HH14(t)−LL14(t))` | 同式 |
| Fast D3 | `D(t)=SMA3(K)(t)` | 同式 |
| 勢いの状態 | `K(t)>D(t)` | `K(t)<D(t)` |

価格発動の二つの終値を**同じ前足の固定線**と比較する。現在のJ26(t)へ線を更新したために発動したことにしない。高安差0のKは無効、K=Dは勢い不成立とする。名称は「生K14・Fast D3」と明記し、Slow K/Dとは混ぜない。D3が初めて揃うのは最短16本、前足のJ26が必要なので価格発動は最短27本である。

同値境界の丸めによる片側だけの採用を避けるため、00028の採否には元OHLCから作る正確な有理数Kと三本平均Dの差の符号を使う。例えば数学上同じKが三本でも、浮動小数点の加算でごく小さい正差が出る場合がある。表示用の生K/Fast Dと、採否用の厳密符号・差の分子/分母を分けて保存し、同値は符号0として扱う。これは先着・損益を見る前の実装規約である。

この案は**K/Dの当足クロスではなく、価格発動時の上下関係**を使う。クロスが後で出るまで待たず、後で別価格から発動を取り直さない。20復帰、50、20〜80の範囲制限は第一巡の採否に使わない。20/80近辺への張り付きは順行中にも起こるため、水準だけで除去せず診断へ残す。これらを後から追加するなら別試行である。

上位足は、発動の公開時点以前に利用可能だった**最後の確定15分足u**だけを使う。上位終値C15(u)と現在位置の雲を比べる。3分終値を過去15分雲へ当てて「15分終値の状態」とは呼ばない。

```text
転換9(u) = (HH9(u)+LL9(u))/2
基準26(u) = (HH26(u)+LL26(u))/2
A(u) = (転換9(u)+基準26(u))/2
B(u) = (HH52(u)+LL52(u))/2
q = 26
現在雲上端(u) = max(A(u−26), B(u−26))
現在雲下端(u) = min(A(u−26), B(u−26))
```

| 比較ID案 | 共通発動に追加する値条件 | 検証する差 |
| --- | --- | --- |
| B0 | 上記の3分価格発動＋K/D状態。一目全値の準備はB1/B2と共通に要求する | 共通準備の対照 |
| B1 | 買いC15(u)>現在雲上端(u)、売りC15(u)<現在雲下端(u) | 上位の雲外方向の選別 |
| B2 | B1に、買い転換9(u)>基準26(u)、売り転換9(u)<基準26(u) | 雲外だけに短中期中心の整列を足す差 |

00028ではB0/B1/B2の三案を実行前に指定する。全案で現在雲・転換・基準の有効性を同じように要求する。現在雲は同一有効区間の最短78本目から揃う。上位の前足状態を追加要求する案ではないので79本を暗黙に要求しない。

### 候補2：価格と数量の非追随を、失敗突破の反転へ使う

**実行前の主仮説（00029で検証済）**：価格が過去極値を更新したのに、終値方向で符号を付けた観測数量が前の極値時点へ追随せず、価格も帯内へ戻る場合は、戻りを伴わない突破より反転を狙う余地があるか。試行14のRVOLと異なり、数量の大小ではなく価格方向との非追随を調べる。

第一案は3分、BB20・2σ、MACD12・26・9を固定し、指標の全足準備・数量連続準備を対照と共通にする。BBはt−1までの終値20本から作り、**その固定した上下端**へ現在のH/L/Cを比較する。

- 反転買いの価格発動：現在L(t)が直前20本の最安値を厳密更新し、`旧BB下端<C(t)<旧BB上端` へ終値が戻る。売りは現在H(t)が直前20本の最高値を厳密更新して同じ帯内へ戻る。
- 基準案R0：その価格発動に、買い `ΔMACDヒストグラム>0`、売り `<0` を要求する。これは既知の複合を参照する対照である。
- 数量選別案R1：R0に、買い `OBV(t)>OBV(k)`、売り `<` を追加。kはt−1までの20本で買いなら最安L、売りなら最高Hの足。同値極値は最も新しい足を選び、未来の山谷確認は使わない。

OBVは `OBV(t)=OBV(t−1)+sign(C(t)−C(t−1))×q(t)`。qは時点整合を満たす**観測累積数量の区間差分**であり、真の全約定量と呼ばない。OBV(k)はk足終値時点の値で、足中の安値／高値を付けた瞬間の値とは主張しない。数量の欠落・巻戻り・基準不明では区間を切り、同じ連続有効区間内のkだけ参照する。欠落を0で補って非追随を作らない。

価格の新極値とBB内復帰はR0にも要求し、R1だけへ価格条件を増やさない。原発動を先に固定し、OBV不一致・時間外・保有中でもその発動を消費する。後でOBVが良くなった足へ取り直さない。追加方向条件をADX/SAR等でさらに重ねず、まずR0/R1だけを比較する。

**心理仮説**：一方向に価格を押し出した動きの継続が、以前ほど数量方向へ表れない可能性を調べる。ただしOBVは終値の上下で当該足の全qを一括分類する近似であり、積極買い／売りフロー、資金の純流入、買い手の人数ではない。価格とOBVの非追随は反転確定ではない。[FidelityのOBV公式説明](https://www.fidelity.com/learning-center/trading-investing/technical-analysis/technical-indicator-guide/obv)。

### 候補3：方向の頻度を、価格突破と幅拡大へ足す

**実行前の主仮説（00030で検証済）**：同じ高安突破・幅拡大でも、単発の大きな値動きで到達したものと、同方向の足が反復したものを分けると違いがあるか。PSYはRSIの別名ではなく、値幅を捨てて上昇／下落の回数を残す。収縮状態を先に必須化した案ではない。

3分の直前20本高安の終値突破とBB20・2σの帯幅増加を共通発動にする。高安は現在足を含めず、帯幅 `W(t)=上端(t)−下端(t)` は現在確定値で `W(t)>W(t−1)`。価格で割った幅は上下反射を壊すため初回は使わない。

PSYの直近12変化（13終値）をU=上昇回数、D=下落回数、F=同値回数に分ける。通常の上昇PSYは100U/12。鏡像に使う方向値は `Z=(U−D)/12` とする。

| 比較案 | 入口 |
| --- | --- |
| P0 | 過去高安の価格突破＋BB幅増加。PSY現前の準備は共通 |
| P1 | P0に買い `Z(t)>0かつZ(t−1)>0`、売り `Z(t)<0かつZ(t−1)<0` を追加 |

同値がある場合、下落PSYは100D/12であり、100−上昇PSYではない。Z=0は方向不成立。価格発動時の2状態を参照し、後続の確認足を待つ案ではない。75/25の過熱閾値は初回に使わない。極端なPSYを即反転とすると、強い方向の継続を誤って売買する可能性がある。

00030では、幅増加を同値境界で誤判定しないよう、原終値のFractionから現前の母分散差を厳密に比較した。また価格突破足では現在変化が必ず実方向なので、前のU−Dが実方向正なら現も自動的に正になる。両状態を独立した二つの確認とは数えない。P0→P1の先着率は学習27.26%→26.51%、選択26.78%→27.74%と改善が揃わず、両案費用後赤字。学習には品質注意があり、全体確定額はnullである。値幅集中・実参加と回収は[結果文書](価格突破へ方向頻度を加えた比較.md)へ分けた。

**心理仮説**：大きさに関わらず同方向に終わる足が続くことが、継続的な値付けの偏りと整合するかを調べる。回数は投資家の人数ではなく、一度の巨大変化を軽視する性質もある。したがって価格構造・幅と複合にし、単独PSYの勝率とは呼ばない。[楽天証券のサイコロジカル解説](https://www.rakuten-sec.co.jp/web/fop/special/technical_analysis/chart_guide06/)、[本リポジトリのPSY教科書](../technical-analysis/指標/サイコロジカルライン.md)。

### 候補4：CCIの高水準を順行の持続として読む

**実行前の主仮説（00031で検証済）**。CCIは「高いから売る」だけの指標ではなく、強い偏りの始動・持続を別の価格判断と併用する一般用法もある。個別教科書とカタログ版2のI13を追加し、下記の二案を固定・実行した。C0/C1の差は上位幅の追加であり、CCI単独の追加効果ではない。

3分、CCI20、直前20本高安の終値突破を起点とし、背景は最後に公開された15分BB20の価格幅の増加を使う。対照C0は価格突破＋買いCCI現前とも>100／売りとも<−100。C1だけに上位BB幅増加を足す。全案は15分BB幅現前の準備を共有する。

```text
TP(t)=(H(t)+L(t)+C(t))/3
平均(t)=直近20本TPのSMA
MD(t)=直近20本それぞれの |TP(i)−平均(t)| の平均
CCI(t)=(TP(t)−平均(t))/(0.015×MD(t))
```

MDは各足で別々に計算した偏差の移動平均ではない。MD=0は無効。既に持続している現前CCIを価格発動時に読むので、次足を待って元の価格へ入ったことにはしない。±200、期間10/30、足幅1/5等の格子探索は初回に行わない。

**心理仮説**：平均からの偏りが一時的な飛びでなく持続し、上位の値幅も動き始めているなら、単発の外れ値とは異なるか。ただしCCI・BB・突破は価格由来で重複する。条件追加で取引を減らしただけか、残した入口の平均も改善したかを分ける。[FidelityのCCI公式説明](https://www.fidelity.com/learning-center/trading-investing/technical-analysis/technical-indicator-guide/cci)、[TradingViewのCCI計算説明](https://www.tradingview.com/support/solutions/43000502001-commodity-channel-index-cci/)。

## 4. MFI・VR・関連系列を今すぐ全ANDにしない理由

### MFIの主題と鏡像上の注意

MFIは典型価格TPと数量qから、TP上昇側・下降側のTP×qを集計する。価格帯の端復帰や一目基準線復帰に、量で重みを付けた運動を足す候補にはなる。20/80到達だけを反転発動にはしない。[FidelityのMFI公式説明](https://www.fidelity.com/learning-center/trading-investing/technical-analysis/technical-indicator-guide/mfi)。

ただし標準MFIの **TP×qの価格水準重み** は、価格を `P'=K−P` へ上下反射しても、必ずMFI'=100−MFIになるとは限らない。正負の分類は入れ替わるが重みがK−TPへ変わるためである。「買いMFI>50、売りMFI<50」という同じ式の対称閾値と、入力全体の厳密反射同値を区別する。本研究の鏡像QAを維持したまま標準MFIを採否へ入れる仕様は、まだ解決していない。都合よく単価を外して計算し、それを標準MFIと呼ばない。

最初はMFIを診断へ保持し、数量そのものの方向比を使うVRとの違いを式から整理する。MFI単独教科書・欠損時の規約・鏡像保証の裁定を済ませるまで、採用案へ進めない。

### VRとOBVを独立票に数えない

同一窓の上昇数量U、下落数量D、同値数量Fについて、[楽天証券のVR2](https://www.rakuten-sec.co.jp/MarketSpeed/onLineHelp/msman2_5_2_7.html)は `100×(U+F/2)/(U+D+F)`。正規化した符号数量 `B=(U−D)/(U+D+F)` とは **VR2=50×(1+B)** の関係になる。同じ窓のOBV差を総数量で割った値もこのBであり、同じ情報を別名で三票にしてはいけない。

候補2は過去の価格極値時点kとのOBV累積差を使うので、任意の固定窓VRと常に同値ではない。ただし一般に情報は重なる。まず一つの数量表現を選び、期間や閾値の総当たりはしない。標準VR1は上昇／下落比で、上下反射時は補数ではなく逆数になる。VR1へ50/50の規約を流用しない。全数量0の窓は無効、欠落は0にしない。

### 関連市場・板・OI

NK225とTOPIXの同時点の方向確認、板の深さ、注文フロー、OIは未実測の役割を持ち得る。ただし別系列の利用可能時刻、限月、数量の意味を先に監査する。価格の似た動きだけから注文フローを推定せず、後から届いたTOPIX値をNKの過去判断に使わない。まず現在あるOHLC・監査済み観測数量の候補を優先し、関連系列は追加入力の試行へ分ける。
