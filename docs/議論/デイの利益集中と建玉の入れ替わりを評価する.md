# デイの利益集中と建玉の入れ替わり

2026-11-22。日経199_02は10月20日に17.5万円を得たが、利益上位3日を外しても66.9万円が残った。TOPIX専用212_06は10月20日が＋5,664.8円で、利益上位3日は別の日に生じ、除くと13.3万円の赤字になった。特定日の心配を調べるときは、指定日を外した収支と、各手法自身に有利な上位日を外した収支を両方出す。比較元の上位日を固定して外せば、同じ日付集合でも比べられる。[45日の比較](../../study/00217_デイの利益集中と入口条件を比較する/README.md)

単一建玉の口座では、見送りがその後の売買を変える。旧・新に共通の取引、旧にだけある取引、新たに枠を得た取引に分けて差額を照合する。日経通知03では、見送りによって外れた旧取引45件は計−4,762円で、空いた枠で建てた4件は＋46,415.6円だった。TOPIX専用T26でも、後から入れた69件の＋81,481.6円が収支差の大半を占めた。信号の予測力と、口座としての取引順の効果は別に記録する。[通知の建玉入替え](../../study/00217_デイの利益集中と入口条件を比較する/日経通知/README.md) ・ [TOPIX専用の建玉入替え](../../study/00217_デイの利益集中と入口条件を比較する/TOPIX専用/README.md)

損失総額が減った場合は、赤字取引件数と1件当たりの平均損失も記録する。今回の通知03は既知赤字が60件から40件に減り、赤字1件の平均損失は9,425円から9,571円となった。約定数の減少で節約した費用は23,927.6円。TOPIX専用T26は上位3日を除いて黒字になったものの、前24日の収支は5,230円、後21日が141,560.4円だった。上位日を除いても残ることと、複数期間で安定することを別々に確かめる。[期間別・週別CSV](../../outputs/00217_デイ入口の利益集中と安定性/README.md)
