# 押戻し回復の出生ゼロと段階別の原因

2026-11-12記録。[136](../../study/00136_押戻し後の回復入口を加えて頻度と先着を比較する/README.md)は、背景→押戻し接触→拒否1分のK/I固定→新5分の勢い改善→別1分の構造回復と同足量→Raw保持の順序でE1を追加した。主A0は旧C0全取得に全適格E1を加え、場ごとの回数capを設けない。

新E1の出生/取得は0だった。ただし既存入口は全73場79取得あり、主A0・C0・副S0の全取得と方向は同体。0取得の場はない。平均頻度は全ザラバ720時間55分に対し0.10958回/時のまま。新金融F1・先着/金額の再計算・CSVを作らず、旧対照の到達済み先着率68.42%、C5利益506,304円/損失313,156円・既知差引+193,148円を継承参照とした。今回の新成績とは呼ばない。

## 準備がなかったのか、確認の途中で止まったのか

保存lifecycle/statsは接触257→K固定145→新5分改善34→別1分回復3→出生0。これらは入口の準備段階で、未取得場や決済勝敗の数ではない。[原因短報と資料](../../study/00136_押戻し後の回復入口を加えて頻度と先着を比較する/根拠/原因資料.md)は保存Sourceだけを分析し、新Raw/CSV/金融を読んでいない。

実配送Dの後に始まる別1分と最低1秒保持を要求すると、理論最速の完了はfloor(D/60)×60+121。一方の期限はmin(接触+900,D+120)未満。34改善中15は時計だけで成立不能だった。分内0秒配送12件・1秒配送2件・episode残35秒1件である。120秒期限取消26件では11件が時計上不可能、15件は可能だった。5秒配送でも理想余地は4秒しかなく、実際の閉鎖遅れや価格更新間隔を含めた成立は保証しない。

回復3例は全て、その確認時Lastが固定capの外だった。回復後54/70/18採用行の差が各場の維持geometry不成立statsと一致し、有効な維持開始がなかった。途中各行でcapとriskのどちらが落ちたか等の内訳は未保存であり、そこまでは識別しない。回復した形を確認できたことと、現在位置から適格に新規取得できることは別である。

## 再利用する教訓と次の問い

複数手法の順次確認は、各確認の市場End・実配送・現在Last/BBO・失効時計を並べて、最後まで成立し得る時間が残るか先に確認する。心理として押戻しからの買い直し/売り直しを想定しても、確認を待つ間に固定Kから進み過ぎれば、同じ価格リスクの入口ではなくなる。今回この心理仮説の利益を実証したわけではない。

136の期限やcapを後付けで緩めない。137では市場End後の足が既に確定していれば実配送時点の現在Last/BBOで確認する案を別に準備中で、結果はまだない。改善時のK/cap/riskと時計が整った4件という事後数も、確認足・量・保持・将来約定を満たす実入口数ではない。

[136の結果と限界](../../study/00136_押戻し後の回復入口を加えて頻度と先着を比較する/結果と限界.md)、[再現](../../study/00136_押戻し後の回復入口を加えて頻度と先着を比較する/再現資料/再現手順.md)、[頻度の方針](先着率を保ちながら時間あたりの取得数を増やす方針.md)。全場min1を下限に、平均概ね1回/時と到達済み同幅先着70%を分けて評価し、各場一律の回数や毎時強制エントリーには置き換えない。
