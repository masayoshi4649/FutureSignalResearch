# 初回利益の返済要求で変わった損益と残った初期損失

2026-11-08。[試行97](../../study/00097_初回費用後利益の全量確定/README.md)は既使用54場で入口と費用を固定し、最低建値・2ATR追尾のP0と、初回費用後残玉正益で全量返済を要求するH0を比較した。全8比較で同じSourceと実新規時刻・物理行・価格・初期量が一致し、差は実現出口の差だった。未参加や退出後の仮想利益は評価していない。

主条件はmini1枚1片道38.5円税込、追加滑り0、要求とは別の最初の正常原行で約定するC0/D0。各側上限10枚の可変数量であり、毎回10枚の成績ではない。

G0では同じ253玉が保有中の費用後単価正益uを観測した。出口だけを変えると最終黒字玉は64から208へ増える。この黒字率を、テクニカルが順行250ptを予測した確率や、指標単独の予測精度とは扱わない。ABの6出生は旧96と同じ例で、費用・遅延・P0/H0を反復して標本数を増やさない。

## 建値で終わる費用赤字と、利益前の逆行を分ける

主G0の正益後赤字は、P0の189玉410枚もH0の45玉111枚も、全て粗額0で手数料だけの赤字だった。H0は保護を起動した原行で返済を要求するが、後続原行で建値へ戻ってから約定する場合がある。要求時点の含み益を、そのまま実現額へ移してはいない。AB/H0の赤字2玉も粗額0・手数料計154円だった。

一方、G0のu正益未観測49玉・88枚・実損失−693,776円はP0/H0で変わらない。H0は利益後の赤字額を−31,570円から−8,547円へ減らしたが、利益前の大きな損失を解決する仕組みではなかった。主G0の損失総額はなお702,323円で、正額403,428円を上回る。黒字玉の増加だけで採用しない。

## 費用と遅延でも同じ結果とは限らない

G0/C0/D1ではP0−242,818円に対しH0−253,818円。追加片道5ptを仮定するC5/D0は−507,895→−752,895円、C5/D1は−379,818→−775,818円と悪化した。ABの全4H0運転は正額だが、C5でP0より小さくなった実現額も記録する。これは両戦略の実取引収支比較で、退出後に持ち続けた仮想利益を採点したものではない。

C5とD1は起動・要求・約定が変わる別の動的再生であり、C0の金額から一定費用を引くだけではない。主条件の改善から、早期返済が全条件で有利との一般則を作らない。

## 次に分けて検証すること

入口では[方向・勢い・板の食い違い](平均方向と現在の勢いと板が食い違うとき.md)を、価格構造の保持／喪失／回復失敗と組み合わせる。EMA配置の同方向、MACDの増分、現在の表示数量は別の観測であり、どれか一つから反転や継続を確定しない。

退出では、Actualの実建値から利益前の否定を定義する候補を、初回利益の出口と別に比較する。[参照Sourceと実建値の差](../../study/00097_初回費用後利益の全量確定/参照Sourceと実建値の差.md)では、正常なSource返済通知48件のうち12件でSourceには建値・順行側でもActualには逆行側だった。一方、不利取得だけでは損失群を識別できなかった。元の建値に沿う通知を流用する意味と、新規取得した玉のリスクを分けて扱う理由になるが、初期否定で収支が改善することは未検証である。
