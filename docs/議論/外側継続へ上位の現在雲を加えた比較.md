# 外側継続へ上位の現在雲を加えた比較

確認日：2026-11-05。[試行38](../../study/00038_外側継続と上位の現在雲/README.md)の共通知見。正本は[計画](../../study/00038_外側継続と上位の現在雲/計画.md)、[設定と結果](../../study/00038_外側継続と上位の現在雲/設定と結果.md)、[対応診断](../../study/00038_外側継続と上位の現在雲/対応診断.json)。学習40場・条件選択24場・後続2場は全て既使用の追加開発で、未見検証ではない。

## 短期の突出へ、上位の位置を加える

[37](高安帰還と外側継続の同時点判別.md)では、旧高安の外に終値が残り、MACDヒスト差もその方向へ進むT1の先着率が相対的に高かった。ただし70%未達・費用後赤字で、継続として採用できる成績ではなかった。38はT1を固定し、15分の現在雲外方向が、一時的な突出と継続を分けるかを比較した。

一目の雲に対する価格位置を上位トレンドの説明に使い、他指標で短期との関係を考える用法は[TradingViewの一次教材](https://www.tradingview.com/support/solutions/43000589152-ichimoku-cloud/)にある。描画が先に延びることは未来を計算できることを意味しない。今回の3分/15分・T1との組合せ・250pt先着確率は同教材の実証結果ではなく、本研究の仮説である。

心理の仮説は、短期の突出が、より広い高安中心帯の同方向外にも位置するとき、上位方向へ戻る途中の一時的な逆流と区別できるかというもの。雲を投資家の平均建値や板の注文量とは解釈しない。価格P/BB、MACD差、数量M、ATR、上位一目という役割を分け、価格由来の指標を独立した証拠の票数にしない。

|入口|追加条件|測る差|
|---|---|---|
|H0|固定37T1を全保持|上位準備のない完全対照|
|H1|H0かつ当場最新公開15分の現在雲/転換9/基準26が有限で公開可|H0→H1は準備の除外|
|H2|H1かつ買は15分C>雲上端、売は15分C<雲下端|H1→H2は上位の位置による選別|

旧T1は3分の過去20高安更新＋旧BB内終値、元P数量M、外側方向の中心化MACD12/26/9差を保つ。実方向は元反転Pの反対。全案順行XFで、上位不一致を反転注文へ変えず待機する。転換/基準の整列は診断だけに留め、採否へ加えていない。

[28](基準線復帰へ上位一目を加えた比較.md)も上位雲を比較し、改善は一貫しなかった。28は3分の基準線cross＋Fast発動で、全案に上位準備を要求していた。38は別のT1発動と数量M・費用後起動を用い、準備だけの除外も分けた追試である。28の不調を無効にしたり、全体率差を一条件の因果効果としたりしない。

## 現在雲と公開時計を固定する

固定28と同じ9/26/52を使い、現在雲はA(u−26)/B(u−26)、最短78本。現在計算のA(u)/B(u)を現在雲に使わない。当場の公開15分のうち、end15≤end3と公開key15≤元T1要求keyの両方を満たす最新足uだけを使う。最新uが未準備なら古い正常足へ戻らず、前場の公開足で代用しない。

雲と比較する価格は15分u.closeで、発動した3分終値ではない。同end/同keyは可、境界の等号は雲外不成立。零雲幅自体は無効にしない。数値の同限月carryと当場の公開参照は別で、全幅末尾NPは内部数値にだけ使う。欠枠/不正/限月/尾部欠等の解除規約も固定28を保った。

主は固定37caseを即13列へ射影し、旧29の下位出典と旧28の上位数値を共有した。旧価格P/MACD/数量Mの再検算は37の証明へ接続し、38で新しく再計算したとは呼ばない。一方、38独立側は元8列から下位OHLC出典と全2,574上位足を別形成・高安窓別走査し、新しいasof/採否を検算した。純射影のATR原値も完全一致を要求した。

## 準備の除外は方向値の効果ではない

|入口|学習・250/全仮約定|選択・250/全仮約定|選択・30分間引き率|
|---|---|---|---|
|H0|34/94＝36.17%|25/67＝37.31%|34.69%|
|H1|34/90＝37.78%|25/67＝37.31%|34.69%|
|H2|30/67＝44.78%|14/40＝35.00%|33.33%|

H0→H1で除外したのは学習4登録/4仮約定で、250成功0、125先着1、観測不足3。選択・後続には除外がなかった。学習の率が上がったことを、まだ比較していない雲の方向値の効果とはしない。観測不足を分母から落として成功率を高く表示することもしない。

H1→H2の学習は、保持30/67＝44.78%に対して除外4/23＝17.39%。選択では保持14/40＝35.00%に対して除外11/27＝40.74%と逆転した。上位方向を揃える効果は両期間で揃わなかった。三案とも入口支持は満たしたが、主率・間引き率の支持付き70%は未達。

同じ元T1では要求key・実side・新規方式・ATRを変えておらず、共通の先着11ラベルも同値だった。今回は上位の確定を後から待った入口価格の比較ではなく、同時点の事例選別である。

## 総損失の縮小と一取引の改善を分ける

|---|---|---|---|---|
|H0_XF|79|−9,938円 / −125.80円|62|−21,864円 / −352.65円|
|H1_XF|76|−8,372円 / −110.16円|62|−21,864円 / −352.65円|
|H2_XF|56|−6,432円 / −114.86円|36|−12,892円 / −358.11円|

micro一枚・倍率10円/pt・片道手数料11円・追加片道5ptという仮定。全案・全期間で品質注意/未解消/EOF期限未達0だったが、学習・選択は追加0ptでも赤字。費用後資格・採用資格は0/3である。

準備追加で実除外した学習3取引の追加5pt損益は−1,566円、選択・後続は差0。方向値を加えたH1→H2では学習+1,940円、選択+8,972円と総額は改善しても、平均は−110.16→−114.86円、−352.65→−358.11円と両期悪化した。取引を減らして総損失が小さくなったことを、各取引の質が上がったことと同じに扱わない。

特に学習で除外した20取引は、追加0ptでは+60円、追加5ptでは−1,940円だった。追加片道5pt往復で20取引分の2,000円が変わるため、方向値追加による総額改善を、値選別の予測精度向上だけで説明しない。

H1→H2の厳密共通新規は学習56・選択36・後続8件で、出口属性・追加0/5/10ptの差は全て0。右側の実追加は0だった。この値選別では参加減少が全額差を作り、同じ建玉からの利益回収改善は起きていない。純subsetと実追加は本来別に調べる必要があり、今回0だったことを一般法則にしない。

## 仮250と、利益保護後の回収

H2選択36取引に対応する仮250成功12件は、全12件が仮250判定より前に返済され、実保有MFE250は0件。26取引で利益追尾が起動し、その後の基準費用後赤字は11件（名目同値10、不利返済1）だった。仮250は実際の返済後も追った経路であり、追尾を外せば同じ全運用で12勝になるという意味ではない。

指定のXFは、現在正常返済BBOの有利額×10−122円>0で起動する。12.2ptを丸めずstrictに超える判定で、以後は入口ATR固定D、MFE−D、最低名目新規床、非緩和を保つ。0/5/10ptは同じ約定への費用負荷で、起動参照5を変えない。**費用後正益で起動しても、最低名目同値床だけで費用後黒字や同値約定を保証するわけではない。** この床を勝手に費用同値へ変更していない。

## 次に残る判別

短期MACDが継続方向で、上位価格も現在雲の同方向外にある、という複合説明だけでは選択期間の改善を再現しなかった。雲外の位置と、現在の高安中心がその方向へ進み始めていることは同じではない。上位の転換/基準の関係や中心値の進行を、短期継続/待機の判別に使えるかを次の候補として残す。

今回のTJ集計は診断であり、良かった部分だけを事後に採用していない。具体的に次の条件を選ぶ際は28のB2等との重複を照らし、準備・値・除去した成功・支持・実参加と回収を再び分ける。指標を足せば改善するとは仮定せず、70%入口目標を小幅利確の勝率へ置き換えない。次条件の効果は未検証。
