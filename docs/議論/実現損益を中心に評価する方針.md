# 実現損益を中心に評価する方針

2026-11-08のユーザー指定：「手法の利益/損失は考えても、機会損失（取り逃がした利益）については考えなくて良い。」

以後は各手法で成立した取引の実現収支を中心に研究する。未参加だった値動きや、決済後に持ち続ければ得られた仮想利益を機会損失として採点・最適化しない。未来のピークを入口や再参加の正解へ戻さない。

| 評価するもの | 扱い |
| --- | --- |
| 実現損益 | 粗損益・指定手数料・仮定追加滑りを分離し、純額・正額・負額・PFを記録する |
| 利益保護 | 保有中に費用後利益を観測した玉の最終赤字件数/額、保護起動・床・返済要求・実約定を区別する |
| 損失と安定性 | 正益未観測の損失、時価DD、赤字セッション/開始日、取引数・実枚数と分母を記録する |
| 手法間比較 | 各手法で実際に成立した取引の収支を比較する。入口変更を出口単独の効果としない |
| 対象外 | 未取得の利益、決済後の最高値まで保有した仮想利益、理想的な全値幅回収率 |

利益化時の追尾義務、最低名目建値の床、売買対称、mini各側上限10枚、指定手数料、セッション内完結は維持する。費用後赤字が小さくても手法全体が赤字なら、その実現収支をそのまま記録する。機会損失を対象外とすることは、赤字手法を合格扱いする意味ではない。

94は旧評価表現を含む条件を固定して実行済みであるため、元計画・数値を改変しない。実行後の解釈と次試行から本方針を適用し、旧資料にある「失った順行」「取り逃がし」を現在の改善目標へ継承しない。[94の実現収支](../../study/00094_連続出生を固定した個別利益追尾/成果物/結果.md)、[miniと判断時計](mini片側10枚と5分判断への研究更新.md)を参照する。
