## 一般的な説明と心理仮説

RSIは強いトレンドの中で高値・安値圏に長く留まることがある。高いことだけでは反転を確定できない。[Fidelity公式RSI解説](https://www.fidelity.com/learning-center/trading-investing/technical-analysis/technical-indicator-guide/rsi)（確認2026-11-16）。

元方向のEMA傾き・DI・動力が複数時間軸で揃い、値幅と量を伴う突破が続く場合、押戻りを待つ追随者と反対側の損切りが元方向への動きを支える可能性がある。これは市場心理の仮説であり、今回の板から参加者の動機を直接確認した事実ではない。元方向の強さを「行き過ぎだから逆へ入る」理由に置き換えず、反転する実方向の価格回復と元圧力の変化を別に確認する。

ATRは方向を示さず、値動きの大きさを表す。保護幅を変動性に合わせる尺度として利用できる。[Fidelity公式ATR解説](https://www.fidelity.com/learning-center/trading-investing/technical-analysis/technical-indicator-guide/atr)（確認2026-11-16）。今回のATR2倍、起動75%、BB比0.9等は独自の研究閾値であり、同解説が収益性を保証する数値ではない。

## 次の検証でも維持する分離

1. **方向と回復**：背景の元方向、取得する実方向、回復確認の公表時点を分ける。EMA/DI/MACDは相関があり、独立した確率として票を掛け合わせない。量にも価格構造・動力と異なる役割を持たせる。
2. **入口と出口**：元入口＋IFD、新入口＋IFD、元入口＋新保護、両方を変えた案を残す。枠解放と後続取得まで口座を再生し、単独改善額を足して複合改善としない。
3. **保護価格と実返済**：一定の費用後利益で追尾を必ず起動し、床を不利に緩めない。接触後の遅延・気配飛びを実価格に残す。同値以上の床は実利益を保証する約定ではない。
4. **全体と集中**：利益・損失・収支、両中央値、0取引場、保有時間、黒字場、上位3黒字場除外後、DDを併記する。取引数の減少だけで損失が消えた結果を安定改善としない。
5. **未知と既知寄与**：出口が変わると後続取得も変わり、別の欠測へ入る場合がある。新しい未知を0円で埋めず、未知非増加条件と全件確定累計を維持する。

今回の04は損失軽減の比較候補、03は未知増加を伴う参考候補として固定する。新しい未使用データでの適用前に、これらの名前を都合よく入れ替えたり閾値を変えたりしない。[候補別CSV](../../outputs/00182_反転確認と値幅保護の比較/README.md)。
