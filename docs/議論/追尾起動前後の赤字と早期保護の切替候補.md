# 追尾起動前後の赤字と早期保護の切替候補

確認日：2026-11-09。[試行105](../../study/00105_固定SourceとLD10の四場追加確認/README.md)の固定後4セッションで確認した事実と、次に調べる仮説を分ける。**LD10は旧54場では黒字だったが、今回の4場では全費用感度で赤字だった。利益保護の改良と安定収益の達成は、まだ確認できていない。**

## 赤字がどの段階にあったか

uは**実保有している残玉1枚の費用後評価**。下表の「最終赤字」は、その玉の全返済後の実現純額が負だったことを指す。u正益経験とLD10起動は別条件で、LD10は `u >= 100円/pt × max(10pt, 固定native ATR12値)` で起動する。

[個別玉IDによる検算](../../study/00105_固定SourceとLD10の四場追加確認/検査/主金融全4場/追尾起動前後の赤字.json)で、LD起動済み赤字がu正益経験赤字の部分集合であることを確認した。集計値の引き算だけで同じ玉と仮定したものではない。

この固定履歴では、起動後の幅だけを変える仕組みは、未起動だった大半の赤字玉へ直接介入できない。そこで起動を早める判別も調べる必要がある。ただし幅変更が起動済み黒字玉や後続の実取得に影響する可能性はあり、上表を可変幅による総改善額の上限とはしない。未参加や決済後の値動き、取り逃がし、仮想利益は評価していない。

## どう判別して保護を切り替えるか

以下は**未採用・市場未検証の次候補**。[収束と失速の観測案](収束と失速を分ける可変追尾の候補.md)を使う。平均差の縮小Cだけで反転とせず、保有方向に対するMACDヒストグラムの鈍化M、以前から公表済みの局所安値/高値の終値否定Pを分ける。EMAとMACDを独立した二票とは数えない。

|状況|操作的な切替候補|検証する反証|
|---|---|---|
|正益が小さい、又はC/M/Pが未知|既存のSource管理とLD10を継続し、欠測を支持へ補完しない|保護が遅い問題が残る。まず未知の頻度と当時の公開値を記録する。|
|既存LD05水準 `u >= 100×max(10pt,0.5×ATR)` を満たし、CかつM|LD10到達を待たず保護を起動する案E1。警戒時の狭幅候補は約1ATR|通常の押戻しまで失速と見て、早過ぎる退出が増える可能性。|
|同じ一定利益に加えCかつMかつP|構造否定まで待って早期保護する案E2|確認が遅い、又はPが未公表で使えず、大きな返しを防げない可能性。|
|いずれも満たさずLD10へ到達|現行どおり必ず追尾を起動|従来の対照を残す。|

E1/E2では、起動後の最低床を名目建値とし、既存床を不利へ戻さず、Sourceの返済予約を優先する。売買は符号反転した同条件、利益保護は5分判断の間も継続する。床の設定と実約定は別で、費用や価格飛躍による赤字が必ずなくなるとはしない。

心理の仮説は、収束には利食い・様子見による通常の調整も含まれるため、元方向への勢いと価格構造の維持を合わせて見る、というもの。個々の参加者の意図を読めたとはしない。未起動だった21玉に当時これらの警戒が出ていたかは、現Scalar11では分からない。公開済み3分足・個別EMA・MACD・OHLC・pivot確認時刻を別の因果的な配送へ結び、後から完成したチャートを過去の判断へ使わない。

次の比較では、LD10固定幅、LD10起動後だけの可変幅、E1/E2の早期起動を分ける。早期起動の差を幅だけの効果とは呼ばない。入口の手法・数量・費用・時計は固定し、実現額、全損失額、二つの赤字集合、DD、実取得の差、参加率を併記する。今回の4場を見て立てた案なので、同じ4場で次の成績が良くても完全な未使用期間の確認とは表記しない。
