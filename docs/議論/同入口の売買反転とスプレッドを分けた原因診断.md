# 同じ入口の売買反転とspreadを分ける

2026-11-11。[124の全73場/79取得の比較](../../study/00124_逆行の原因と売買反転を同じ入口で検証する/結果と限界.md)を完了した。未達を理由に止めず、逆行過多が方向の問題か、取得側や位置・時計の問題かを分けた。

原向きの60分±125ptは26順31逆未16、45.61%。全て逆にしても26順38逆未9、40.63%で改善しなかった。買Ask/売Bid・清算は反対側なので勝率は1−pにならない。25ptは正逆両方が逆先着29例で、元BBO32.88%に対してLast方向56.16%。狭幅にはspread/価格側の影響が大きいが、125ptのLastも49.15%で、方向選択の弱さまでspreadだけでは説明できない。Lastを売買利益として扱わない。

通常trendだけ反転するR2はC5代用利益410,920円/損失424,772円、PF0.9674で、元の差引−147,852円から−13,852円へ改善した。しかし主125ptの到達済み51.79%で、平均差のsession bootstrap95%区間は0を含む。主T1は切替0件・O0同体であり、良い対照へ主を変更しない。

テクニカルの条件重複も原因の一つだった。元の勢い改善を要求した入口に、同じ時点で両増分悪化を全必須として重ねるT2は成立しない。複数手法の役割を分け、前段の過伸長、次段の失速/拒否、その後の構造回復と量を時系列で確認する独立出生を次の仮説にする。心理として追随買い/売りの消耗や失敗突破後の手仕舞いを考えられるが、注文者の意図や今回の負けの単独原因を確認したわけではない。[一般説明と一次資料](../../study/00124_逆行の原因と売買反転を同じ入口で検証する/根拠/外部資料と正逆比較の根拠.md)を参照する。

原因区分では、元向き5分実体/足値幅の[0.5,0.75)群20例・20場が元4順13逆未3に対し、実BBO逆12順5逆未3（70.59%/全20分母60%）。逆のC5代用利益143,076円/損失85,616円、差引+57,460円、PF1.6711だった。多数区分から見つけた探索内の候補で、未知期確認・統計的有意ではない。次試行125でこの群だけ逆・他は元向きを全79例へ適用し、参加を保った政策として実際に再評価する。124主条件や旧結果は書き換えない。
