# 方向と価格反応を先に分けた比較

確認日：2026-11-06。[試行54](../../study/00054_方向と局所帯を先に分岐/README.md)は、53で見つかった「採用資格を満たす経路がDI順行だけになる」構造を変更した。反転の採用と主待ち率は改善したが、先着70%・費用後収益の目標には届かなかった。

条件・全閾値・結果の正本は[設定と結果](../../study/00054_方向と局所帯を先に分岐/設定と結果.md)と[結果JSON](../../study/00054_方向と局所帯を先に分岐/結果.json)。全66場は既使用であり、未見検証ではない。

## 構造を変えた理由

[53の診断](局所帯の反応で分岐を固定した比較.md)では、F0_F40の適格葉が全てF01=s×(DI+−DI−)/100の正値を要求し、DI逆側の採用が不可能だった。これは市場に反転がなかったという事実ではなく、学習した木と採用資格の組合せの制約である。

54のD0はZで価格反応を分け、次にfloat32 F01≤0と>0を必ず分けた。4群それぞれの中で、DMIの強さ、FastK/変化、ATR、ローソク足・OR/局所帯の位置等17特徴による深さ2の子木を学習する。全体の深さ4、得点1/3、葉支持60枠/6日/10場、売買対称、現在費用後正で起動する連続追尾は維持した。

固定Zはprice、固定DIはtrendなので、複数family条件は構造上自動充足する。条件式を残しただけで53と同じ厳しさとはいえない。自由な分岐を一段減らし、学習する集団も4つへ分けるため、DMI単独の追加効果ではなく構造全体の比較である。

[外部資料の再確認](外部再調査/上位方向との逆向きと反転確認を分ける.md)では、DI方向・ADXの強弱・価格の反転確認を区別した。DIに逆らう候補を評価できることと、反転の始まりを検出したことは別である。今回はADXや新しい価格線を追加していない。

## 利益保護と次の問い

利益旗は現在の正常返済BBOの含み粗益から往復122円を引いて正になったときに立て、床は最低名目新規価格とする。D0選択では利益起動244件のうち194件が最終的に主費用後赤字だった。入口の方向を増やす構造変更だけでは、利益消失の問題も解消しなかった。

同期間の仮250成功は100件、実保有中の250到達は6件だが、この二つは約定・建玉集合・終点が違う。差の94件をそのまま利益取り逃しとはしない。

追加診断では同slot・方向・役割に加え、新規時刻・原行・価格の**型と値まで完全一致**した実完結だけを対応させた。F0全310完結・D0全775完結は全件一致し、結合除外0だった。そこから仮250成功に限ると次のようになる。

|---|---|---|---|---|---|
|F0・選択|44|12/32|41/29|1|+2,332|
|D0・時系列|104|22/82|74/52|5|−4,288|
|D0・選択|96|25/71|83/58|6|+11,588|

D0時系列の帰属も期間全体の品質注意を引き継ぎ、確定利益とはしない。選択の仮成功100件のうち実完結に対応した部分は96件であり、未参加4件を仮想的に実損益へ加えていない。

**同じ新規で250が125より先に来る例でも、現在の連続追尾では赤字で終わる場合が多い。** 仮先着の教師は実追尾後の利益そのものを表していない。D0選択のこの96件の合計は正でも、全382完結の−103,504円を覆していない。将来の先着成功を知って群を選べるわけではなく、この群だけ保有を延ばせば同じ金額を得るという計算でもない。

入口と利益保護を接続する次の問いは、費用後正益になった後に新規価格へ戻る経路と、戻らず伸びる経路を、入口時点の価格構造・勢い・値幅からどこまで区別できるかである。追尾幅が通常の押し戻りより狭いのか、最低同値床で退出すべき前提失敗なのか、要求後の約定で利益を失うのかを分ける。最低同値以上・費用後正で起動・損失側も連続追尾という条件は維持する。

次の判別候補は、局所帯の外へ出ただけの追随と、押し戻りを経ても外側を維持した再開の違い、帯内へ戻っただけの復帰と、戻り後の再突破が失敗した反転の違いである。上位方向との符号だけで名前を付けず、価格の順序と短期の勢いを組み合わせる。15分の確認待ちで動きが終わっていないか、固定250ptの余地と連続追尾に耐える経路が残っているかも分ける。

これは新しい成功条件の発見ではない。54の条件・結果は固定したまま、保存値の診断から次の少数仮説を別試行へ進める。主/非重複70%、費用後正、支持と活動の基準は引き下げない。
