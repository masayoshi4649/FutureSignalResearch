# 入口の評価時計と候補の出生を分ける

2026-11-10。ユーザーの「まずエントリーを大きく改善する」という方針に基づく。従来のSource・入口・数量・保護の固定試行は変更しない。

## 入口の優位性を保護の成績から推定しない

旧手法の保有期間だけの同幅先着には、損切りによって逆行の観測が先に終了する影響があった。大幅到達者の高率や、多数の小さな正益経験から、入口時点で費用を超える優位性があるとは判断しない。[117追加診断](../../study/00117_正益起動と取得後1分波の失敗で利益を守る/診断/入口と利益消失/README.md)。

新しい入口試験では、約定を仮定した時点から30分・60分を固定して観測し、先着と期限清算評価を別列にする。実運用の利益追尾を省く提案ではなく、入口の性質だけを調べる段階である。先着しても決済したことにはしない。期限に達した最初の正常Rawが清算評価の終端であり、同じ価格時計秒でもその後の物理行を含めない。

未約定は損失でも0円の取引でもない。場末・欠測・正常BBO不足は観測不足として残す。約定した新候補の評価であり、元の取引が退出した後に「取れたはずの利益」を計算するものではない。1枚の独立ケースが重複するため、その評価額を合計して片側10枚の口座収支としない。

## 価格待機とテクニカル確認は別の作用

[118](../../study/00118_指値待機と複数技法の取得確認で入口を比較する/README.md)では、元の全Source新規558を使い、通知時の既知気配から50/100/200pt有利な指値を比較した。60分・片道5pt滑りストレスでは、200pt待ちは71件約定代用・68件評価完了、±100pt順行22・逆行45、平均期限評価−3,974.06円/miniだった。待ち価格が改善しても、約定後に逆行しやすい標本を選ぶ可能性を分けて調べる。200pt固定が唯一の解とは確認していない。

同出生でM0とL200の両方を評価できた65組では、旧価格取得の平均−23,400.08円に対し、L200の差は＋19,169.23円だった。これは全候補での平均やL200自体の黒字とは異なる。「悪い取得を改善した」と「新規後に正の期待がある」を混同しない。

118の順行・反転・ORでは技術確認が3/8/11候補に成立したが、元候補より50pt以上有利という価格capが全てを拒否した。元通知の時刻・方向・価格を前提にしたまま複合条件を増やすだけでは、有効な新規を作れていない。

## 技術的な出生から順行と反転を分ける

2026-11-10の追加指定では、入口から同一幅の利確・損切り水準を置いた先着で70%以上を目指すことを優先する。200pt待つこと自体を主目的にしない。幅ごとの順行÷順逆合計と、未到達を含む全観測完了中の順行率を併記し、未約定・観測不足も件数として残す。先着率だけをIFD実約定の勝率や収支と同一視せず、注文遅延・気配・費用・期限退出を含む次段階の検証へ接続する。

理想的に±w ptで約定し未到達がない独立mini1枚なら、勝率pの平均額は `100×w×(2p−1)−往復費用`。往復77円だけでなく、追加往復10ptを置くC5では費用1,077円となる。p=70%でもw=25ptは平均−77円、50ptなら＋923円、100ptなら＋2,923円という計算になる。これは損切り飛越・実約定遅延・期限退出を省いた算術で、研究のIFD実績ではない。70%という率と、選んだ幅で費用後利益が残ることを両方確認する。

次はSource通知の時刻・方向から独立し、30分の背景・15分の価格帯・5分の構造/勢い/量による領域接触を候補の出生とする。順行と反転を別の枝とし、各枝の売買は符号対称。5分は指標公表の時間幅であり、5分ごとの定時新規を強制する時計ではない。原行で監視し、公表時計を超えて未来足を使わない。

同じ領域への接触から、領域時の取得、確認直後の取得、確認した5分構造への再試験指値を分ける。確認後に元Source価格より一定pt有利であることまでは要求しない。背景が既知の否定へ変われば未約定を取消し、未知なら執行を保留する。同じ領域が続く間の出生を重複させず、領域を離れた新5分公表を経て再接触を許す。

複数技法の役割分担であり、価格由来のMA・MACD・RSIを統計的に独立な票とは数えない。数量は観測区間量の品質と公表時刻を記録する。未知の検証期間を使用したことにはせず、既使用70場での探索と明記する。

入口候補が残った段階で、可変数量、片側上限10枚、必須利益追尾、Sourceへの実約定返送を含む実行可能な口座を別に検証する。入口単独の期限評価を、その口座の安定利益と呼ばない。

## 119で確認した遅れと120への変更

[119の結果](../../study/00119_技術領域の出生と確認後再試験で入口を比較する/結果と限界.md)では345領域出生・1,035候補を全70場で評価し、6政策×2期限×5幅すべて同幅先着70%に届かなかった。順行の確認38イベントは出生から中央値715.5秒、Lastが中央値100pt進んでいた。順行確認後の取得・60分±100ptは順9・逆19。同出生で双方完了した22組でも確認後取得の価格改善は平均−119.55ptだった。確認を増やせば入口が良くなるとは確認できていない。

[120](../../study/00120_1分構造と無効化距離で入口を作る/README.md)では、上位5/15/30分を背景に、確定1分の小構造回復を使う。閉鎖足の回復だけでなく出生Rawと取得評価Rawでも水準を維持しているかを要求し、追随価格上限と無効化までの距離を同時に検査する。上位順行の押戻し、失敗突破の反転、収縮後の放れを別の背景・構造で区別する。追加のMACD/RSI・量確認も比べるが、同じ価格から作る複数指標を独立した証拠数とはみなさない。

120の主評価は実行前に60分±100ptへ固定する。ほかの幅を副評価で全件保存し、よかった幅だけへ主評価をすり替えない。未約定や打切りを0円へ補完せず、単なる入口選別と実行可能なIFD損益を分ける。

120の反転候補を失速・量で分解して121で再生した結果は、[反転入口を失速と量で切り替えた結果](反転入口を失速と量で切り替えた結果.md)へまとめた。既知の少数例で70%を超える選別は残ったが、追加期間の反証と広帯候補の未達があり、安定70%・未知再現性は未確立のまま資料を確定して区切る。
