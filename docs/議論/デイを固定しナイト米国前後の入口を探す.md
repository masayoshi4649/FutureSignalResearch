# デイを固定しナイト米国前後の入口を探す

2026-11-15。ユーザーは171のデイを、参加時間の低さを先着率で補えるとして一旦承認した。171の記録と当時の停止判断を保持し、新しい[172](../../study/00172_デイを固定しナイト米国前後の複合入口を探索する/README.md)でナイトだけを再開する。

デイは40場・365取得、同幅到達済み先着率84.16%。主入口の参加は26/40場、初参加補完だけの場は14。保有時間の和集合は既知決済だけで22.80%、未知を場末まで保持する数量モデルでは25.89%。この低参加を隠したり、改善のためデイを変更したりしない。

171のナイトは米国前190取得・24順28逆・先着46.15%、既知利益1,116,686円／損失1,232,776円。米国後は89取得・36順21逆・先着63.16%、既知利益769,458円／損失561,541円で14/40ナイトに参加した。到達済み率と全取得の決済勝率、未到達と観測不足は別物である。

次は、旧1460複合条件の夜間診断と、新しい履歴を使う8群768条件を比較する。押戻し後の再加速、低方向性下の端からの回復、BB内への復帰、過去端逸脱後の実体回復、反対動力の失速、圧縮解放、上位順行の再加速、背景混在下のDI回復を区別する。価格構造・勢い・方向・量・値幅を組み合わせ、過熱だけで反転を決めない。

純主入口の独立一枚評価で絞り、買売各10枚・未決予約込みの再生で、幅と期限による枠解放まで再計算する。補完は171の幅200/H60を固定し、主の参加不足を補完の成績で隠さない。NY09:30の前後は夏冬時間を変換し、境界で強制返済しない。

全80場は既使用である。全期発見と前半だけからの選択、追加7場の参考適用を区別する。多数条件から選んだ高率を将来の保証とせず、各帯の支持数・場集中・未知・前後差・利益と損失・保有時間を残す。結果の正本は172へ置く。

## 172で得た知見

旧1460規則と新768履歴規則を12幅・四期限・正逆で比較し、各帯20の短表から441数量政策を再生した。全期主B05_01はPRE78.75%／POST100%だが、POSTは到達4Nightだけで34順のうち27件が1Nightに集中していた。到達済みの高率だけでは、未到達の期限決済損失や場集中を隠してしまう。

既存441から前後四セルの支持を調べ、事後安定性対照B05_11を別に固定した。PREの局所回復条件を逆向きに扱う400pt/場末と、POSTのBB幅・足実体・MACD/RSI動力・15/30分EMA/DI方向・相対量を合わせた150pt/H30。全40Night150取得、PRE78.75%／POST88.89%、既知利益2,842,530円・損失594,464円。POST到達は17Nightへ分散し、最大場集中16.67%となった。

全場参加には初参加補完31件を含み、その補完だけは赤字。平均0.290回/時、PRE主は追加4Nightで0件、未知8件を残す。一般的な「回復失敗確認」の手法と呼べるわけではなく、EX反転は後続失敗を確認しない実装である。心理仮説と実装の差を[条件と市場心理](../../study/00172_デイを固定しナイト米国前後の複合入口を探索する/条件と市場心理.md)へ記録した。

有望候補を得たため一旦停止。高率群を選ぶときは、取得した場数とF/Aまで到達した場数、全期と前後、主と補完、一般論と事後発見を分けて判断する。主案の入替えや、既使用期を新しい未見検証と呼ぶことはしない。
