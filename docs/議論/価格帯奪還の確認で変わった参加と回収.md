# 価格帯奪還の確認で変わった参加と回収

2026-11-08。[92](../../study/00092_価格帯奪還と保持後の独立再開/README.md)の共通知見。全66場は既使用で、安定利益は未確認。売買・費用・約定を変更せず、旧E1入口と現在E0＋独立した価格確認を比較した。

## 何を組み合わせたか

15分EMAの背景、3分価格と平均の位置、MACD/RSIの増分、ATR内の取得位置と同時スパイク警戒を現在E0として維持した。新しい価格確認は、押し前の方向側最大Close Hを奪還し、突破後の最高Close PからH上で調整し、Pを再び越えた最初のvである。足高安や標準図形の検出とは呼ばない。

新i/pは旧kと別に追跡し、vから900秒未満を定時の資格とする。元FAR参照の全原行運転・数量・方向とG1連続保護は共通。旧E1へ価格条件を追加した部分列ではなく、確認時計を独立させた別の入口である。[事前の外部調査と心理仮説](外部再調査/平均回復と価格帯奪還の確認時刻を分ける.md)と検証結果を区別する。

価格構造は92attempt完成したが、15分時点のE0と現在両気配のH維持まで満たすのは6方向、非closing同方向Sourceもあるのは3方向・延べ4IDだった。6方向はすべて旧E1=false。候補方向、供給ID、注文受理、実取得は別の分母である。

## 同じ出口で何が変わったか

両政策で要求時計・方向・実取得時計/価格/量/Index/物理Lineまで同じ入口は0。共通参照2件も取得が変わったため、利益保護の優劣を同入口で比べた結果ではない。

| 差額の要素 | 主円 | 1秒円 |
| --- | ---: | ---: |
| 同実入口の出口差 | 0 | 0 |
| 同ref2件の取得変更 | ＋22,400 | ＋21,800 |
| 旧のみ31件を除外した純額寄与 | ＋148,446 | ＋158,546 |
| 新のみ1件の参加 | −13,830 | −13,830 |

旧のみ31件には勝ちと負けが含まれる。上の寄与はその合計を参加しなかった差額であり、31件すべてを悪い入口と判別した意味ではない。条件を損益に合わせて選び直していない。

共通2refも同じ向きには改善しなかった。10/01 Nightは新案が30分早く入り、旧＋380円から新−7,220円へ変わった。10/19 Dayは新案が135分遅く入り、旧−29,328円から新＋672円へ変わった。主の差は−7,600＋30,000＝＋22,400円。早い/遅いだけでは分けられず、ATR由来の幅も50→60pt、110→60ptと変わる。これは取得後の結果比較で、旧側の将来損益を新案の判断へ使っていない。

## 利益前と利益後を分ける

新案の利益未観測2玉は両遅延とも計−21,050円。利益後の追尾だけでは、この損失は解消しない。残る24枚の1玉は主＋672円、1秒＋72円で、全玉正益後の赤字はどちらも0/1だった。分母1を改善の証明にはしない。

| 正益1玉の実返済 | 主円 | 1秒円 |
| --- | ---: | ---: |
| 18枚の部分利確 | ＋1,404 | −396 |
| 残6枚の追尾返済 | −732 | ＋468 |
| 全玉の費用後合計 | ＋672 | ＋72 |

1秒側は、正益時に要求した部分利確が赤字約定し、保護予算不足も記録された。残玉の返済要求後に気配が改善した影響を含む黒字であり、予定どおり資金化して保全できた例とは言えない。全原行の要求義務と最低建値床は監査済みでも、発注時の利益と約定後の利益は別である。[入口と回収の診断](../../study/00092_価格帯奪還と保持後の独立再開/入口と回収の診断.md)へ公開価格の出典と実現した内訳を分けて残す。

残玉要求時の全玉評価は−528円で、実返済時は＋72円だった。したがって、最終黒字という結果だけで、途中の費用後赤字化まで避けたと解釈しない。

## 方向の確認と、損切り位置の意味を揃える

以下は結果を見た後の診断で、新しい入口条件として検証したものではない。3件とも買いで、売りの実績を示す標本にはならない。コードの売買対称性は別の鏡像人工で検査している。

要求時点の取得側気配q、当時ATR、Hは保存済みであり、実取得価格を先取りせず比較できる。初期幅を`D=min(125,max(15,5×ceil(ATR/5)))`、Hの10pt逆側までの距離を`q−H+10`として読み直した。後者は構造の否定位置を考えるための候補で、92の退出へ設定した線ではない。

| --- | ---: | ---: | ---: | ---: | ---: | ---: |

損失2件では、Hを支持と読む一方で、ATR由来の線はHより手前にあった。価格帯を奪還したことと、その場所で構造否定まで耐えられることは別である。幅を広げれば改善するとは限らず、損失を増やす可能性もある。この3件だけから勝てる距離の閾値を決めない。

次の検証候補は、現在気配と構造・ATRを合わせて「確認済みでも追い掛ける位置か」「許容幅内で否定を置ける押戻しか」を判別すること。合わなければ待機又は近い再押しを待つ入口へ切り替える。反対売買は別の反転成立条件を要求する。確認前の早い奪還と、確認後の再開を、価格リスクと失う勝ちを含めて比較する必要がある。

## 次に区別すること

- 価格帯を奪還したこと、現在の勢いが続くこと、その場所で新規取得する採算は別。構造完成を増やすだけで利益になるとはしない。
- 元FARが今も保有していることと、元手法が当定時に新しく入りたいことは別。過去の取得価格・部分利確・追撃段階を持つ残量を、新口座の新規へ渡す意味を再検討する。
- 新規初回条件の再評価にも待機・解除等の状態があり、毎定時に参照器を作り直すだけで元手法を再現したとは呼べない。[公開APIと状態の読取設計](外部再調査/定時の新規条件と参照保有を分ける.md)で、準備を全原行で追うことと、15分で注文することの契約を分ける。
- 継続不成立を逆売買の許可にしない。反転は価格帯否定、回復失敗、逆方向の勢いと値幅・量の確認を別に定義する。元参照方向と実売買方向、返済通知の意味を偽らない。
- 出来高・VWAPは既存の入力監査と教科書を再用できるが、板表示量・元保有量とは分ける。今の92へ後から追加していない。
