# 高率の小群を広げるときに残す情報

2026-11-12。[149](../../study/00149_継続と反転を可読8局面で判定する/README.md)の事後小群から作った[150](../../study/00150_突破の現在状態と背景で順逆を切り替える/README.md)では、**元の小群は同じ成績を保ったが、広げた領域へ高い率を一般化できなかった**。旧試行の条件や数値は変更しない。

## 維持できたものと弱まったもの

150は、終値による短期端突破後の現在Last復帰を、量・実体・ADX背景と組み合わせた。弱い/減速背景では反転、強化方向では再試行、レンジ端では反発を候補にした。主U0は全73場・1,259件・平均1.75件/時を確保した一方、484順481逆151未到達143不足、到達済み50.16%で70%未達だった。

## 一つずつ戻すだけでも救済できなかった

元T4は端復帰だけでなく、実体の先行3足値幅に対する大きさ、相対量、5分EMA差/Hist増分、15分ADX状態、取得位置を束で要求していた。150ではその一部を外して出生を広げたため、同じ名称の形でも別の領域が多くなった。

- 実体/先行3足値幅≥0.5と量/先行3足平均≥1.25を両方要求したFA531件も、195順232逆・C5−1,204,501円だった。
- 注文側の正規化前の5/15/30分EMA21増分が全部正のFA316件も、141順124逆・C5−252,639円だった。ATR既知を追加条件にしない符号分類であり、方向整合の単独分類で70%とはならない。
- 後発の取得位置追補で、元T4のsignal側位置0.75～1.5を維持したFA920件も、354順401逆・到達済46.89%、C5−1,608,684円だった。位置だけ戻せば改善するとの説明も支持されない。

最後の位置は**元の突破signal側のq0実側価格**による先行3足内比率で、反転注文側のq0実側価格とはAsk/Bidが異なる。反対側を1−xで補完せず、q1価格で群を選び直さない。[後発追補の保存資料](根拠資料/150_取得位置の後発追補.zip)は150の正式保存完了後の資料として分離する。

## 次に使うときの記録

高い率の小群から「端へ戻った」「過熱した」等の一つの説明だけを取り出さず、背景・形状・勢い・値幅・量・取得位置と当時時計を残す。どの条件を外したか、その追加域の率/損益/未到達/不足を元の群と分ける。全期を見た良い群の抽出を、未知期で成功した条件と呼ばない。

次の候補は、これらの相互作用を可読な状態条件又は過去場だけの判別で検証する。学習を使う場合も、当場より前に両方向H60完了を知った教師だけを使い、ランダム行分割・現在場の結果・未来の品質を混ぜない。複数技法を使ったという事実だけでエッジを推定しない。

全場最低1・全時間平均概ね1回/時・実BBO/H60/±125の70%を維持する。高頻度場と1回の場を均等化しない。少数の良群を足しても頻度が届かない場合は、達成とせず候補の生まれ方と良否判別の両方を設計する。追加2場の価格は未読のまま残す。
