# 単純IFDで損失の出にくい入口を優先する

2026-11-16、182報告後のユーザー指示。「出口はまだ考えず、単純IFDの想定」「利益が伸びることではなく、損失を生まない安定性強化を優先」。本方針を今後の入口評価に優先する。今回は評価方針の更新であり、新しい入口・出口の検証は実行していない。

2026-11-17追補：判断材料はテクニカルを主軸としつつ限定せず、板情報を直接使うことも含め採用手法の選択を研究側へ任せる。デイ・米国前・米国後の区分は、合理的理由を明示すればさらに細分化できる。対象はNK225先物とTOPIX先物の両方。以下へ反映し、旧試行の対象・成績は変更しない。

## 「改善」の意味

目指すのは、十分な参加を維持しながら、費用後の損失が発生しにくく、大きく膨らまず、連続する期間でも崩れにくい入口である。総利益・累計収支の最大化を最優先にしない。利益が減っても、黒字を保ち、損失の頻度・深さ・連続性が改善するなら評価する。利益減少そのものを不採用理由にはしない。

一方、取引を大幅に減らすだけで損失総額が減った結果や、少数の大勝ちで赤字期間を回収した結果を安定性の改善とはしない。過去の損失ゼロと将来の損失ゼロは別であり、未使用期間での再現を区別する。

| 優先して確かめること | 記録する指標と分母 |
|---|---|
| 損失の発生が少ないか | 赤字セッション数・率、赤字取引数・率。全対象場・取得数・0取引場・未知件数を併記 |
| 損失が深くないか | 総損失、赤字場/赤字取引の損失額、最悪場、損失が大きい側の分布。件数減少と1件当たり悪化を分ける |
| 損失が続かないか | 最大連続赤字場数・連敗数、累計DD、初期赤字、回復までの時間。場末と建玉決済順、保有中時価を区別 |
| 期間や時間帯で崩れないか | 前半・後半・追加期間、デイ・米国前・米国後の損失経路。全期間合算の黒字で局所悪化を隠さない |
| 参加と黒字を維持しているか | 実保有時間率、取得数・取得場数、建玉ごと/全セッションの費用後収支中央値。利益・収支・利益損失比は採算確認として併記 |

上記は評価の優先軸であり、新しい点数の重みや数値の合格閾値を既使用結果に合わせて設定したものではない。採否の具体的な順序・閾値は次の試行で計算前に固定する。指標が食い違うときは「総損失だけ減少」「赤字場は増加」のように範囲を限定して述べ、一語の「改善」でまとめない。

## 単純IFDで入口を比べる

- 当面はトレーリング・利益保護・技術による途中決済の探索を行わず、固定の利確/損切り注文で入口を評価する。
- 入口の比較ごとにIFD幅・保有期限・費用・約定代用・終了前決済を同じにする。幅を比較する場合は別条件として分け、幅変更の効果を入口だけの効果としない。125ptや250ptへ一律固定する指定ではない。
- テクニカルを主軸とし、採用する手法・組み合わせは仮説と検証に基づいて選ぶ。複数の技術・情報で方向・構造回復・動力・量・値幅などの役割を分け、順行/反転/待機を判断する。板の厚み・偏り・スプレッド・更新などを直接判断へ使ってよく、既存テクニカル一覧だけに限定しない。売買は符号対称。後から分かった勝敗を当時の判断材料へ入れない。
- 開始一律待機なし、買売合計保有・未決予約1件、デイ15:30/ナイト05:45までの全決済を継承する。末尾15分を保有率の分母から除く。
- 保有時間率20%程度、各デイ/ナイト最低1取得という参加条件を維持し、未達と合理的な未参加理由を残す。保有率は対象時間で加重し、各場すべての保有率20%や米国前後それぞれの強制取得を新たな条件にはしない。建玉ごと・全セッション収支中央値の両方の黒字を維持し、0取引場を中央値から除かない。
- 金融未知は0損益・決済済みにせず、既知寄与と全件確定を分ける。未知非増加と同じ品質条件を維持する。無取引・欠測・率の分母変更によって見かけの安定性を作らない。未参加や決済後の仮想利益は機会損失として最適化しない。

## 判断区分と対象商品

デイ・ナイト米国前・米国後は基本の集計区分であり、判断条件を分ける区分の上限ではない。例えば取引開始からの経過、事前に分かる市場の節目、当時観測できる流動性・変動性・トレンド状態など、相場の性質が異なると考える理由があれば細分化できる。これらは分割候補の例であり、今回その効果を検証したものではない。

各分割について、理由・境界又は判定条件・利用可能時刻・支持件数を残し、分割しない条件とも比較する。既使用データの損益が良く見える区切りだけを合理的理由としない。小区分ごとに強制取得を課したり、不調な区分を全セッション集計から落としたりはしない。

対象はNK225先物・TOPIX先物。両方について入口と安定性を評価するが、同じ数値閾値や同じIFDのpt幅を一律に適用する指定ではない。価格単位・呼値・乗数・手数料・滑り・データ品質を商品別に定義し、ラージの板を分析に使う場合とmini等で損益換算する場合を区別する。これまでのNK225・mini1枚換算の成績をTOPIXの成績へ読み替えない。

商品別の成績と参加をまず示し、一方の損失を他方の利益で覆わない。複数商品の同時運用や数量配分を比較する場合は、保有・予約枠と資金条件を別途明記する。今回の対象追加を、既存の追加禁止を解除する指示とは解釈しない。

## 181/182の位置付け

前回答の「改善」は、主に182の04でデイの損失総額と場末DDが減ったことを指していた。しかし、デイ黒字場は31/41から27/41へ減り、夜間損失は増えたため、安定性全体が強化されたと結論するには不十分だった。利益額が減ったことと、損失の出方が悪化したことは別に評価する。

181/182で出口まで変更した結果は参考資料として保持する。今後の入口比較にはC0_IFDの対照を使い、追尾付き04の結果を単純IFDの入口改善の証拠にしない。閲覧用00・01・05などに加え、全28組正本のIFD条件も過去資料として参照できるが、新しい探索をこれらだけへ限定しない。

旧試行の数値・条件・選択順位・当時判断は変更しない。新しい入口を評価する際は別試行を採番する。[182正本](../../study/00182_反転の危険局面と値幅に応じた保護を組み合わせる/README.md)・[当時の候補別CSV](../../outputs/00182_反転確認と値幅保護の比較/README.md)・[既存の安定性評価](安定性を累計経路と取引の広がりで評価する.md)を参照。
