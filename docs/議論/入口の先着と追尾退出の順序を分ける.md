# 入口の先着と追尾退出の順序を分ける

確認日：2026-11-06。[54の保存結果](../../study/00054_方向と局所帯を先に分岐/README.md)に対する事後診断。元の条件・結果・監査は変更していない。[診断JSON](../../work/方向局面分岐/00054/利益回収経路の診断.json)と[再現コード](../../work/方向局面分岐/00054/利益回収経路の診断.py)はGit外の保存物に置く。

## 最も大きかったのは起動前の損失

選択24場のD0全382完結を、返済要求時の利益旗と保護線Lで分けた。Lは新規価格から実方向へのpt差であり、L=0は名目新規価格、L>0は利益側の線を表す。

|要求時状態|完結|粗損|粗同値|粗益は正だが122円未満|費用後黒字|主費用後円|
|---|---:|---:|---:|---:|---:|---:|
|利益旗前・負の保護線|138|138|0|0|0|−120,336|
|利益旗後・L=0|205|24|84|80|17|−15,710|
|利益旗後・L>0|39|1|3|2|33|+32,542|
|全体|382|163|87|82|50|−103,504|

粗益=122円の行は0。主費用はmicro1枚・10円/pt、往復手数料22円と追加滑り100円の計122円。この分類は将来の実回収による診断で、入口時点で分かる属性ではない。

利益後の名目床で費用後赤字になる問題は残る。一方、この期間の最大の損失源は、返済要求まで利益旗が立たなかった群だった。要求後は旗が凍結されるため、実約定まで正益が一度もなかったとまでは言わない。床をさらに利益側へ上げるだけでは、この起動前の損失は解消しない。入口の選別と回収の両方を調べる理由になる。

## 仮250成功の多くは実退出より後の出来事

同slot・方向・役割に加え、新規時刻・原行・価格まで型と値が一致する実完結だけを、独立の125/250先着と結合した。

|期間|同一新規の仮250成功|250到達後に実退出|実退出後に仮250到達|
|---|---:|---:|---:|
|時系列20場|104|5|99|
|選択24場|96|6|90|
|既使用後続2場|22|3|19|

要求と250到達が同keyの例、返済要求後から実返済までに250へ達した例はいずれも0だった。時系列期間は既存の品質注意を引き継ぎ、金額を確定利益へ格上げしない。

選択の96件中、順行61件は費用後+15,758円、反転35件は−4,170円。反転35件は全て250到達前の実退出で、実保有中250到達は0だった。これを「250の含み益を得てから赤字にした35件」と呼ぶのは誤りである。長く持てば利益になった可能性と、必須追尾を維持した実回収は違う。

将来250へ達した群だけを残せるわけではない。全382完結の結果をこの96件で置き換えず、入口の250/125目標と追尾後の純額を別の評価として残す。

## 要求時の気配は保存されていない

返済要求ログにはarm/L/h/Dと要求keyがあるが、その時のr/返済BBOは常に記録される仕様ではない。同keyの明示記録も今回の全775完結で存在しなかった。よって要求時rと、要求から約定までの価格変化は全件不明とした。

全件で算出できるL−実決済rは「保護線から実決済までの超過」であり、閾値を跨いだ時点の跳びと要求後変動等を含む。これを全て約定滑りと呼ばない。選択の中央値0pt、75%点5pt、最大115ptはこの線超過である。要求から約定までの価格時計差は中央値5秒で、モデルの最低遅延1秒と実際に次の正常気配が来る間隔を区別する。

初期D中央値は時系列60pt・選択75pt・後続120ptだった。単に「1ATRだから極端に狭い」と説明せず、初期逆行・正益化・床更新・返済という順序で見る。

## 並行した外部確認

2026-11-06に著者由来の公開抜粋も確認した。[Zamansky・Stendahlの入口/出口効率の論考](https://traders.com/Documentation/FEEDbk_docs/1997/10/Abstracts_new/Zamanski/Zam.html)（1997年10月）は、同じ利益でも入口と出口を分けて評価する考え方を示す。[MFE戦略の論考](https://traders.com/Documentation/FEEDbk_docs/1999/03/Abstracts_new/Stendahl/Stendahl9903.html)（1999年3月）は、含み益と最終利益の関係を調べ、増玉規則を含む手法全体を再評価する段階を説明する。無料公開部分を読んだ範囲であり、非公開本文の式や実績を確認したとはしない。後者の増玉は本研究の1枚条件へ採用しない。

入口と出口の分離は既存のMAE/MFE教材や[追尾の外部調査](外部再調査/追尾の距離と入口の押戻余地を分ける.md)と重複する。今回の診断へ加える注意は、最終MAE/MFEの2値だけでは逆行と順行の順序が決まらないこと。後から知った最良の入口へずらす仮定ではなく、当時の固定入口・固定追尾から初回到達と実退出の順を比較する。
