# 入口の全置換と、局面別の枝の追加を分ける

確認日：2026-11-16。[175](../../study/00175_局面別入口を累計経路と支持で探索する/README.md)・[176](../../study/00176_役割票と局面別構造で入口を広げる/README.md)・[177](../../study/00177_固定幹を保ち高ADXの入口を増分比較する/README.md)の研究である。旧固定条件・旧CSVは変更しない。

## 今回わかったこと

174の米国時間後が希少だった理由は、低ADX用の入口しかなく、追加4ナイトの高ADX状態に対応していなかったことだった。一方で、低ADXの条件を外すだけ、又は全入口を緩い多数決へ置き換えるだけでは、別の場へ有効性が広がるとは限らなかった。

175では方向・動力・構造・量などの全条件一致を要求したところ、指標が公表済みでも成立が少なかった。176では方向票・動力票・代替構造を使い成立を増やしたが、旧73の全期参考案はデイ35/37場までで、ナイト先着率61.36%。追加7のナイト既知収支も−156,771円だった。幅を広げた未到達返済が多く、前半で良かった方向条件の後半悪化も確認した。いずれも採用しない。

177では174の固定幹を保ち、ADX>20が既知の局面に限って新しい複合入口を加えた。新しい主入口は保有・予約枠も含めて再生する。枝の独立利益を、旧手法の利益へ足してはいけない。

全80の177全期主は米後85取得・37/40場・到達済先着75.00%で、174の16取得・9/40場という希少性を改善した。一方で、Nightの既知利益/損失比は旧174の約2.34から約1.80へ低下し、追加7のNightは3F/6A、既知−203,155円。全80Nightの場中央値も未知12件を含み下限−1,769.5円で保留だった。取引が広がり、合計先着率が70%を超えたことだけでは安定採用しない。平均取得頻度もDay約0.582回/時、Night約0.292回/時で、概ね1回/時には達していない。

この不足から178では新枝だけに、正逆変換**後**の実際の取得方向で15/30分のEMA・DI、5分の動力・DI、量の確認を比較した。全期主は米前の長期方向2票以上、米後は長期2票以上＋5分MACDヒストグラム変化/RSI変化双方正を使う。旧幹/デイ/Tを保持して情報の役割を切り分ける別試行であり、各指標単独の効果を証明したものではない。

178主の全80はDay161取得・40/40場・先着71.43%、Night122取得・40/40場・75.00%、両群の建玉/場中央値下限が正。米後は57取得・31/40場・22F/3A=88.00%（27N/5C）で、既知利益735,305円/損失226,309円だった。Night既知利益1,563,379円/損失733,234円、利益損失比約2.13。177より損失を減らした一方、旧174の約2.34を上回ったわけではない。

ただし追加7のNightは3F/4A・既知−126,924円。前48だけで選んだ案は後25不適合のままで、全期主も旧73のNight先着が前48の66.67%→後25の92.31%と偏る。Nightは平均3.05取得/場・0.236回/時。新探索は有望候補を得たため178で一旦止め、初期損失・頻度・未知・前後差・未見再現の未確認を次回へ引き継ぐ。現時点で将来の安定利益が証明されたとはしない。

## 再利用する比較手順

1. 取得しない原因を、指標未公表・技術不成立・保有/予約による棄却・取得代用失効に分ける。
2. 元の固定幹を同体再現する。追加なしで全取得・全損益が一致することを先に確認する。
3. 局面範囲と、当時判別できる複数技術の条件を固定する。ADXだけで方向を決めず、EMA/DIの方向、MACD/RSIの動力、価格構造・量・値幅を役割別に扱う。
4. 新枝単独、旧幹＋一枝、旧幹＋複数枝を分ける。元方向と逆方向の対照は同じ入口時点の実BBO側で再評価する。
5. 枠の占有が変わる全後続取引を再生し、建玉・全セッションの両中央値、先着、未到達、未知、支持の広がり、累計経路を比較する。
6. 全期で発見した案と、前半だけで選んだ案を交換しない。後半悪化を隠さず、追加期間も既使用なら未見検証と呼ばない。

177の優先順は旧主→新枝→旧初参加補完。新枝同士が逆方向なら待機し、同方向なら固定ID順で幅・期限を選ぶ。旧主に新枝の反対票が出ても、旧主を取り消さない設計である。これは今回の比較条件で、最適な競合解決を実証したものではない。

## 心理の説明と、実証した成績を区別する

押戻し後の再開は「元方向の参加が残る」、突破は「価格帯を越えても追随する」という仮説である。高ADXは強さの背景で、上昇・下落の証明ではない。混在状態の回復候補を逆向きに使う枝は、見かけの回復が持続しない局面を狙う仮説である。今回の成績だけから、売買主体の心理や各指標の因果効果を証明したとはしない。

MA・MACD・RSIなどには価格由来の重複がある。複数の一致を独立した確率として掛け合わせず、複合政策全体として評価する。全期で選んだ枝が前半・後半とも高率でも、それを過去だけで選べた証明にはならない。

また、先着率はF/(F+A)。Nの期限返済にも損失がある。先着率の改善と利益損失比、建玉中央値、場中央値は別に確認する。未知がある場合、既知寄与のDDを全件のDDと呼ばない。
