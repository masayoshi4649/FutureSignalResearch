# 収縮後の突破と、その失敗からの反転

確認日2026-11-04。状態：一次資料の確認と[00013の比較・独立監査](../../study/00013_収縮後の突破と失敗反転/README.md)が完了。[00013の計画](../../study/00013_収縮後の突破と失敗反転/計画.md)は実行前の版を固定して保持する。[議論の目次](README.md)

00012ではBB内復帰の次足確認と構造保護を比べた。5分の次足確認は件数と先着率が低下し、構造保護は負けを小さくする一方で後の大きな利益も失った。ここから、入口確認や損切りを一律に強くするのではなく、動きが始まる前の文脈を別に測る。

手引きの低ADX時の「反転」という分類を、帯外への買い合図をそのまま売りへ反転する命令と読み替えない。今回は価格が固定範囲へ戻ったという別の観測を必要にする。日足の125本参照を、セッション内の20本最小へ変更するため、原著と同等の成績も名称も主張しない。

## 役割を分ける

| 観測 | 知りたいこと | 説明候補となる市場心理 | 反例 |
| --- | --- | --- | --- |
| 過去に比べ帯幅が狭い | 短期変動が小さくなったか | 売買の均衡、材料待ちなどが考えられる | 参加者の注文や動機は直接観測していない。静かな状態は続き得る |
| 固定高安の外へ終値が出て帯幅も増加 | 収縮の後に方向が現れたか | 新規追随と逆側建玉の解消が続く可能性 | 動きの多くを既に消化し、入った後に戻り得る |
| 突破後に同じ固定範囲へ終値が復帰 | 最初の方向が維持されなかったか | 追随注文の不成立や手仕舞いの可能性 | 一時的な押し戻りの後、元の方向へ続き得る |
| 確定15分EMA20方向の一致 | より長い価格方向と合うか | 長短の参加者の注文が同じ方向かもしれない | 同じ価格の加工であり独立証拠ではない。遅れと参加減少も生じる |

収縮は準備、価格の範囲脱出は発動、15分EMAは補助という役割に分ける。収縮と方向を同じ条件で決めず、突破失敗後の反転も未来の成否を見てから分類しない。

## 次に比較すること

3分/5分×突破追随/突破失敗反転×補助なし/確定15分方向一致の8入口を固定する。出口はTP250/SL125・期限に揃え、まず入口の文脈を比較する。収縮設定からの状態遷移、参照高安、満了、使い切り、欠足でのリセットを明示する。帯の現在値を参照して過去の突破水準を移動しない。

既使用65場を再利用する追加探索であり、新しい未見確認ではない。125/250先着、費用、品質、活動頻度、30分間引きを並記し、8案のいずれも成立しなければ不成立の知見を残す。細かい閾値を結果に合わせて同じ試行内で追加しない。

## 00013で観測したこと

[数値正本](../../study/00013_収縮後の突破と失敗反転/結果.json)では入口70目標0/8、探索用費用資格0/8だった。以下は学習/条件選択の順に記す。全65場は既使用である。

- 3分突破追随・補助なしは33/156、25/107の順行先着。片道追加5pt後の観測純額は−59,252円/−32,514円。15分方向一致を加えても19/81、15/67で、純額は−15,074円/−30,986円。学習の損失は縮んだが、選択でも改善したとは言えない。
- 5分突破失敗反転・補助なしは12/40、6/21。基準観測純額＋5,842円/＋704円でも、片道追加5pt後は＋1,942円/−1,096円へ変わった。注意3場/1場があり、観測額を全体の確定収益としない。
- 5分突破失敗反転・15分方向一致は片道追加5pt後＋2円/＋2,290円だが、完結は9/5取引、活動8/5場で支持不足、選択に注意1場がある。追加10ptでは学習−898円。小額の黒字と取引の少なさを安定性と取り違えない。

[補助対応診断](../../study/00013_収縮後の突破と失敗反転/補助対応診断.json)では、方向一致入口は補助なし入口の当時方向一致部分へ完全に対応した。同じ仮約定・設定・突破など3,840項目が一致し、共通の実新規の純額差は全12群で0円。全運用の純額差は、除いた入口と、一建玉の参加経路が変わって入った別の入口の合計差だった。例えば3分追随の学習では＋39,278円改善したが、選択では−872円悪化した。上位方向のフィルタが全期間で入口を改善するとは結論しない。

帯幅拡大も、短い固定高安の外に終値が出ることも、250ptへ進む力を単独では確認しなかった。次の問いには、価格から計算した指標をさらに重ねる前に、[利用可能な観測差分量](数量台帳の追加集計.md)が発動時の参加増加の補助になるかを残す。全約定VWAPや方向別注文フローは、この数量監査で利用可能になったとはしない。

独立監査は主179,654項目・状態47,130項目が不一致0。後者は原価格から足と指標を別に計算し、全1,096発動の集合に漏れ・余分がないことも確認した。監査は売買手順との整合確認であり、将来の未見成績の標本ではない。次は[00014の計画](../../study/00014_反転入口と観測差分量/計画.md)へ進む。
