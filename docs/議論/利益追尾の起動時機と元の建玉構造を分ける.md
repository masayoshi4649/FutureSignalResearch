# 利益追尾の起動時機と元の建玉構造を分ける

確認日：2026-11-09。[試行103](../../study/00103_元の多玉と数量を保つ一定利益後の追尾/README.md)の既使用54セッションの検証結果。入力・費用・実行・数値の正本は試行側へ置く。未知期間の安定収益を確認した結果ではない。

## 今回分かったこと

元Sourceの複数建玉、可変数量、親と追加、比例返済を保ち、初回通知を次の5分判断枠で一度だけ取得するB5Qを使用した。開始30分を見送り、保護は定時外も連続で行う。入口の指標・時計・数量を変えず、追加の全玉追尾の起動だけを比較した。

| 起動 | 追加滑りなし・遅延なし | 同・価格時計1秒遅延 | 仮定5pt片道・遅延なし | 同・1秒遅延 |
| --- | ---: | ---: | ---: | ---: |
| 費用後利益が正（P0） | −414,895円 | −242,818円 | −507,895円 | −379,818円 |
| 固定ATRの0.5倍以上（LD05） | ＋1,132,105円 | ＋1,405,182円 | ＋1,254,105円 | ＋1,237,182円 |
| 固定ATRの1倍以上（LD10） | ＋2,291,105円 | ＋2,434,182円 | ＋1,637,105円 | ＋1,777,182円 |

手数料38.5円/枚/片道を全案に控除。ATR起動は、残枚数1枚当たりの費用後含み益が `100円×max(10pt, 係数×ATR)` 以上になった時。ATRは元の確定5分足12期間で、取得時または初めて既知になった時に固定する。後からその期間の高安を見て変えない。起動後は建値を最低保護価格とし、従来の約2ATR幅を維持して不利に緩めない。滑りと次気配約定があるため、建値の保護指示は費用後赤字0の保証ではない。

P0対LDの8比較は、全て同じ実入口301または302玉で、取得変更・片方だけの実参加は0。したがって、この比較内の差額は追尾起動変更に対応する。102の単一建玉・2/4/6枚・各枠投票とは構造も違うので、102との差全てをATRや指標の効果とはしない。

## 参加と利益保護は別に点検する

LD10の全体参加率は27.63〜28.27%で最低25%以上、目標50%未満。主分母は開始30分後から元の強制返済時刻前までの6,048枠。米国前後の静観162枠も分母へ残した。末尾30分を除く観測副表5,832枠を主時計へ置き換えていない。

通常条件の日中は937/2,052枠＝45.66%、夜間は734/3,996枠＝18.37%。全体最低条件の達成を、夜間単独も25%以上だったと説明しない。夜間の参加を増やすためだけに、保護や損切りを遅らせない。

通常LD10では、費用後含み益が一度でも正になった253玉のうち最終赤字は112玉、赤字額合計−1,383,939円。一方、一定利益に達して保護が起動した129玉のうち最終赤字は21玉、赤字額合計−3,079円。**起動後の保護と、起動前の小利益からの赤字化を分ける。** 小さい後者だけを提示して利益後赤字を解消したとは呼ばない。

通常条件の全赤字額は、即時起動P0の−725,346円からLD10の−2,077,715円へ拡大した。純額改善は正額も大きく増えた結果であり、即時保護に対して全ての損失指標が改善したわけではない。追加の全玉保護を付けないS0診断（元の返済管理は維持）と比べると、LD10は同じ実入口のまま全4感度で純額＋12,000〜＋50,000円、負額161,231〜176,307円、保存点連結DD15,000〜45,000円を軽減した。[同実入口の別照合](../../study/00103_元の多玉と数量を保つ一定利益後の追尾/検査/全54場/S0対LD10の同実入口.json)に残した事後診断であり、S0は保護義務を満たす採用候補ではない。

通常条件は開始日単位27日のうち黒字19・赤字8、最良1日を除いても＋1,892,185円。ただし、この54場は多くの過去探索で既使用である。正の日数や費用感度は標本内の診断で、将来の確率ではない。

## テクニカルと心理の解釈

ATRは方向や参加者の意図ではなく通常変動の尺度。微小な正益で即座に床を置くと、順行の途中の往復でも退出し得る。一段の進行を確認してから保護する設計は、背景の方向と、実際の推進が成立した時点を区別する。この説明は一般的な仮説であり、今回の個々の値動きの主体や心理を観測した証明ではない。

元の入口はEMAの複数尺度、価格帯・短秒進行、二市場と板数量の支持、親と追加の履歴を組み合わせている。今回の改善を「ATR一つだけで稼げた」と読み替えない。また、価格由来の指標を増やした数を、独立した証拠数や校正済みの確信度としない。[外部資料を踏まえた設計上の整理](元の入口構造と利益保護の外部再調査.md)も参照する。

外部教材も2026-11-09に追加確認した。CMEの[継続パターン](https://www.cmegroup.com/education/courses/technical-analysis/trend-and-continuation-patterns)は、狭い往復や収束から継続する場合を説明する。一方、[反転パターン](https://www.cmegroup.com/education/courses/technical-analysis/technical-patterns-reversals)は、再度の高安更新の失敗と、その間の安値／高値の突破による確認を区別している。ここから「幅の縮小だけでは反転退出を決めず、価格構造・勢い等を合わせる」という研究設計を推論した。教材のパターンがNK225の本条件で機能した証明ではない。

[TradingViewのATR解説](https://www.tradingview.com/support/solutions/43000501823-average-true-range-atr/)でも、ATRを方向ではなく変動幅の尺度としている。同資料の標準14期間・RMAを本試行へ導入したわけではなく、本試行の元5分12期間の実装と区別する。

## 次に切り分けるもの

1. 元Sourceに残る共有range_sideの買い・売り同時成立時の買い優先を、別版で同時成立なら待機へ変更する。元条件の対照と新条件の自然なSignal・Fillを比較し、外側の対称式だけで全体を対称と呼ばない。
2. 起動後の通常幅を維持する対照に、複数尺度の平均間隔の縮小と勢いの鈍化、または価格構造の否定を組み合わせる幅変更を加える。収束だけで反転を断定せず、保護価格は戻さない。
3. 同じ実入口の退出差と、その後に実際に成立した参加の差を分ける。未参加や退出後の仮想利益は計算しない。
4. 固定後に品質・使用歴を確認した期間で検証する。費用・遅延・夜間の参加も残す。

可変幅を比較した102では、同実入口内の改善と後続の実参加損失が併存した。[その分解](利益保護の改善と退出後の再参加を分ける.md)を無視して、狭い幅自体を無効とも有効とも断定しない。
