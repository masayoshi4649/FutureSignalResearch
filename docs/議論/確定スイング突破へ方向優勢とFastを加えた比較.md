# 確定スイング突破へ方向優勢とFastを加えた比較

確認日2026-11-05。[試行45](../../study/00045_確定スイング突破と方向優勢/README.md)・[設定と結果](../../study/00045_確定スイング突破と方向優勢/設定と結果.md)・[保存診断](../../study/00045_確定スイング突破と方向優勢/対応診断.json)に基づく。全NK225の66場は既使用の追加開発であり、未見期間の実証ではない。TOPIXは今回の判断に使わず、未予約11/5Dayの両商品の内容は開いていない。

## 価格発動そのものを変えた

旧再テストの245登録に条件を足す方法から離れ、確認済みの山谷を越える新しい終値crossを入口候補にした。[個別教科書](../technical-analysis/指標/確定スイングの突破.md)のとおり、中心iの極値は右2本目が公開されて初めて分かる。現在jの判断はpまでに確認した最新水準だけを使い、jで新しく分かる極値は判断の後に登録する。

買いは前終値C_p≤最新確定高値R<現在終値C_j、売りは鏡像。p/jの連続性、公開keyの前後、j.end>p.confirmを要求する。終点での突破を意味し、jの形成全体が水準公開後だった、あるいは板の最初のtouchで買えたとはしない。

当時の最新2高値・2安値がともに切上げなら背景D=+1、ともに切下げなら−1、混在/同値なら0、履歴不足なら未準備とする。実際の突破方向sとDが同じならT順行、反対ならR反転候補、0/未準備ならWAIT。この背景は過去の確認済み構造を表し、現在も維持されることや転換の完了を保証しない。

|案|固定した複合条件|純要求数・学習/選択/既使用後続|
|---|---|---:|
|C0|新cross＋非零の高安背景＋s×(+DI14−−DI14)>0|246 / 155 / 18|
|C1|C0＋当場のFast14/3準備|246 / 155 / 18|
|C2|C1＋s×(rawK−FastD)>0|231 / 139 / 18|

価格構造は発動と背景、DMIは高安変化の方向優勢、Fastは直近範囲の終値位置と平滑線の関係を担当する。全て同じ価格の派生で、独立票ではない。ATRは固定出口の距離に使い、入口の追加賛成票とは数えない。ADXの強さ、80/20、現在の交差、RSI、上位足、数量、関連指数は追加しなかった。

DMIは初足を前HLCの種にし、次の14差分で初期化する。**平滑TRが正で、平滑された両DM平均が0**ならDIは0/0で準備済みだが優勢はない。当足rawDMが両方0になっただけで、過去を含むDIが直ちに0へ戻る意味ではない。FastのK>DもKの前足比上昇を意味しない。

## 条件が整うまで同じcrossを取り直さない

最初の適格crossは(方向,極値ID)ごとに一回消費する。構造・指標・時間・実保有の都合で不採用でも、後で有利になった時計へ延期しない。最新水準を使い、古い有利なpivotを探し直さない。j.end≤p.confirmはcross判定/消費をしない時点対象外として履歴だけを進める。

|保存機械の分母|学習|選択|既使用後続|
|---|---:|---:|---:|
|原crossの初消費P|698|435|35|
|使用済みcrossの再発見・見送り|108|54|1|
|Pのうち構造WAIT|337|217|12|
|C0の純要求|246|155|18|

原Pからの技術条件/時間による見送りと、純要求を実一建玉機械へ渡した後の抑止は別である。Pの初消費数を実注文数にせず、抑止を後の空き時計へ戻さない。

## Fast追加は期間をまたぐ改善にならなかった

先着率は新要求j後の最初正常BBOから、逆行125pt以上より前に順行250pt以上へ届く割合。期限未達・観測不足を仮約定分母へ残し、未約定は別記する。実追尾で退出した後も続く仮経路であり、実取引の勝率とは異なる。

|---|---:|---:|---:|---:|
|C0/C1|58/223＝26.01%|37/146＝25.34%|48/182＝26.37%|29/118＝24.58%|

全3混合と6役割群は両期間の入口支持を満たしたが、70%・費用資格・採用資格は全3案とも0。C2順行は37/127＝29.13%・20/78＝25.64%、反転は19/83＝22.89%・12/52＝23.08%だった。順行/反転の分類をしただけで局面の識別に成功したとはいえない。

C0/C1は観測上、識別IDを正規化した全case・全実参加・損益が同値だった。Fast準備で一件も落ちなかったことは、この入力での観測であり、任意のデータで常に冗長という証明ではない。

C1からC2の値追加で除外した仮約定は、学習2/13＝15.38%成功、選択5/16＝31.25%成功。学習は低率群を除いたが、選択は保持群24.62%より高率の群を除いた。同じ方向の指標を増やせば一貫して良くなる、という仮説を支持しない。除外群が13/16件と小さいことも残す。

## 正益起動後にも、回収と費用の問題は残る

現行XFは、現在の正常返済BBOによる粗含み益円−122円>0で一度起動する。新規時ATRから固定したDでMFE−Dを追い、最低床を名目の新規価格にし、線を緩めない。返済pending後は凍結し、最初適格気配までの遅延を含める。名目床は費用後同値でも、同値約定保証でもない。

|C2の実完結との対応|学習|選択|既使用後続|
|---|---:|---:|---:|
|実参加した入口のうち仮250成功|55|31|7|
|その250判定より前に実返済|53|30|6|
|実保有中MFE250以上|2|1|1|
|追尾が起動した実取引|157|93|16|
|起動後の基準損益で赤字・追加0pt|71|45|6|
|うち名目同値返済|57|37|4|
|うち名目不利返済|14|8|2|

この赤字件数と内訳は、保存診断の基準損益、すなわち手数料のみ・追加滑り0ptによる。起動は参照滑り5ptを含む122円控除で判定するが、赤字件数の費用尺度とは区別する。この表から追加5ptでの赤字件数を代用しない。

入口の仮成功を、そのまま250pt回収と扱うことはできない。早い追尾が後の大きな利益より先に退出する例と、正益化しても名目同値/遅延返済で費用後赤字になる例が同時にある。後から見た峰を利益として計上せず、追尾を緩めれば損失も増え得るため、出口変更は同じ入口の別試行で比較する必要がある。

## 再利用する知見と次の問い

確認済み水準の突破は「皆が見ている水準で注文が動く」という心理を仮説にできるが、本入力から注文集中や参加者の意図を直接確認したわけではない。高安背景・DI優勢・Fast差がそろうことだけでは、125/250の有利な局面を十分に識別しなかった。

今回の再利用点は、中心と利用可能時点、初cross消費と実保有、準備と値、T/R分類と真の機会差、先着と回収を別に設計・記録することにある。全12,952足の数値、3,235極値、1,168原P、1,226新caseを別実装で検算した。生ATRは200足・最大2.84e−14、+DIは9,780足・最大4.26e−14、−DIは9,908足・最大4.97e−14の表現差がある。数値だけのabs1e−10許容と、全準備・DI優勢・採否の厳密差0、検算済み正本定義による全SHA一致を分離した。許容幅を採否へ足していない。

次は既存水準のAND追加だけでなく、二足の価格拒絶と当時の勢い、発動前の基準価格からの位置・進行等による別発動を事前に定義する候補へ進む。過去の損失群をそのまま反転注文にはせず、旧一足のCLV/強い足や既存復帰発動との重複を確認する。具体条件と効果は未検証である。
