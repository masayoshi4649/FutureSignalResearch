# 手法と時間スケールの記録方針

作成日：2026-11-01。

まず[現行の汎用表・版8](手法と時間スケールの汎用表_版8.md)を用意し、**各試行へコピーした `設定と結果.md` に、その試行の閾値・役割・結果を記録する。** 汎用表そのものへ、特定の試行の設定や成功率を書き込まない。仮説・実行条件・結果の正本は各試行に置く。版8は2026-11-13にER等を追加した63手法×9尺度。2026-11-09の版6はI15追加で56手法×9尺度、2026-11-12の版7はI16・出来高加重移動平均線（VWMA）を追加した57手法×9尺度だった。[版7](手法と時間スケールの汎用表_版7.md)以前の旧試行は当時の版を保持する。教材の追加は個別設定や売買ルールの採用を意味しない。

## 1. 行は手法、列は処理に使う時間スケール

基本の表は1手法1行とし、次の9列を持つ。

| 尺度 | この記録での意味 |
| --- | --- |
| 原板・逐次 | 原板の観測順に気配・数量・到達・保護等を更新する。時間足の1本や価格の1ティックとは異なる |
| 1分・3分・5分・15分・30分・60分 | それぞれの時間幅で形成した足。確定時点と端数区間の扱いを明記 |
| セッション足 | 一つのデイまたはナイトを1本にする足。進行中の場の最終高安・終値を先取りしない |
| 日足 | 1日を1本にする足。日付境界、ナイトの帰属、採用する入力系列を明記 |

**時間足、計算期間、起算点は別の項目**である。5分足のEMA20は5分列へ置き、20本を「20分」としない。相対数量の直前20本も、採用する足の列へ置く。セッション開始から積み上げるVWAPは、起算がセッションだからという理由だけでセッション足列へ置かない。原板から逐次更新するなら原板・逐次列、分足から計算するならその足の列を使い、起算は設定明細へ記す。

例えばATRを5分足で計算し、その保護線を正常板ごとに監視した場合、ATRの5分列と保護監視の原板・逐次列を使う。先着ラベルの判定も原板・逐次列で記録し、入口の発動が5分足だったことと混ぜない。

複数足の組み合わせC07は、実際に使った5・15・30分等の各セルへ設定参照を置く。「5分で発動し、15/30分を環境に使う」という関係と利用可能時刻は下段の明細に記す。

## 2. カタログで重複と不足を管理する

カタログの初期範囲は、[個別12指標](../technical-analysis/指標/README.md)、[C01〜C07](../technical-analysis/組み合わせ/README.md)、価格構造・発動候補、数量・OI、板、関連系列、研究コードで使う複合モデルと評価・保護の記録行である。版1は `scripts/レポート/手法カタログ.json`。2026-11-05の版2は `scripts/レポート/手法カタログ_版2.json` にI13・CCIを追加し、52手法×9尺度とした。既存51IDと9尺度の定義を保持し、版1と旧試行を再生成しない。新しい試行は使用版とSHA256を記録する。

- SMAとEMA、期間20と60、RSIの50と70は原則として同じ手法行の設定違い。計算式・期間・閾値は設定IDで区別する。
- VWMAは数量入力の既知性と有限窓を追跡するためI16へ分ける。Close/HLC3・窓長の違いはI16内の設定差。I12の起点累積VWAPへ改名せず、同じ入力を独立な価格票/数量票として二重計上しない。1分系列の固定20分窓は1分列へ置き、欠分を飛ばした20観測へ圧縮しない。
- DMI・ADXは個別教科書I08で一つの体系とし、C04は方向と強さを組み合わせる使い方の行とする。同じ結果を独立な二つの成功例と数えない。
- 価格構造の記述と具体的発動を区別する。支持抵抗を見ることと、固定水準の再テストで新規を発動することは同じ設定ではない。
- ATRによる収縮拡大と、BB・支持抵抗・出来高のC03を同じ実装としない。名称が似ているだけでカード全体を実行済みにしない。
- OBV・MFI・VR、OI、板数量、市場内部、センチメント等は、未実装でも候補一覧から消さない。VWAPを数量系へも載せる場合はI12を参照し、同じ手法の行を重複させない。
- 決定木やHGBTは複合条件を抽出するモデル、先着ラベルは評価手順、保護監視は運用規則として分類する。全てをテクニカル指標と呼ばない。

行の追加は新しいIDで行い、既存IDを別手法へ再利用しない。古い試行のコピーは、当時使ったカタログ版・内容ハッシュを残す。後から行が増えたことを、過去の試行で調査・検証済みだったことにしない。

## 3. 空欄でなく、状態を記す

汎用表の全セルは「未設定・未検証」から始める。試行へコピーした後は、その試行における状態を区別する。

| 表記 | 意味 |
| --- | --- |
| 未使用 | 今回の試行で、その手法・尺度を使わない。有効でないという結論ではない |
| 未検証 | 設定候補・計算例・実装はあっても、その設定の評価が未実行または未完了 |
| データ不足 | 必要な入力・履歴・利用可能時刻等を満たせない。足が足りない場合と系列自体がない場合を明細で区別 |
| 対象外 | 今回の目的や定義の対象から外す。理由を記す。未実装や入力未確認の言い換えにしない |
| 設定ID／複合評価ID | 実際に使う設定と、その設定を含む評価への参照。実行状態は明細・結果欄に記す |

たとえば、日次公表のOIしかないときに、1分ごとの新しいOI変動を捏造しない。一方、最後に公表された値を分足の補助入力へ使う設計まで一律に対象外とはしない。公表時刻、保持方式、使える期間を定義する。データを監査していない段階では「未検証・入力要確認」と記し、確認せずに有無を断定しない。[入力を区別する見取り図](../technical-analysis/分類/価格形状とその他の分析.md)

同じ足幅でも、長い指標の準備で候補が出ない場がある。セルを使用にしていても、実際の利用可能本数・対象場数・除外数は下段へ残す。原板があることだけで全時間足が検証済みとは扱わない。

## 4. セルは短い参照、条件と成績は下段へ

使用セルの基本形は `S01（EMA20・方向）／R01` とする。Sは設定、Rは複合評価を表し、IDは各試行内で一意にする。試行をまたぐ参照には `00004:R01` のように試行も併記する。

設定明細には最低限、次を残す。

| 項目 | 記載内容 |
| --- | --- |
| 対応 | 設定ID、手法ID、使う尺度、役割（環境・位置・発動・通常決済・保護・診断・評価） |
| 計算 | 入力価格・数量、足の起点、期間、本数、平均式、初期化、ゼロ分母、欠損、場またぎ |
| 判断 | 買い・売りの式、閾値、等号、交差の前値、過去窓への当足の包含、分かる時刻 |
| 関係 | 複数足の参照関係、他設定の参照、実装箇所・版・内容ハッシュ |
| 使用範囲 | 対象入力・対象期間・実際に準備できた本数や場数・実行状態 |

Rの結果欄には、構成する全設定、評価目的、分母、件数・日数・場数、期間別結果、費用・執行または先着観測の仮定、不明・未約定・未完了、限界、詳細資料へのリンクを書く。未実行のRを置く場合は「未検証」と明示し、数値を空欄のまま成功扱いしない。

金額損益を評価したRと、200/400ptや125/250ptの先着を評価したRは別である。後者の成功率をそのまま自動売買の勝率・利益へ置き換えない。30分間引きは評価上の感度検査であり、30分足へ手法を適用したという意味ではない。

## 5. 複合成績を指標単独の効果にしない

MA・RSI・数量・ATR・板条件を使った一つの候補の結果は、共通のRへ結び付ける。構成要素の各セルに同じRを参照してよいが、各指標が個別にその利益・成功率を生んだとは書かない。

追加条件の効果を述べる場合は、それ以外を固定したあり・なしの比較へ別の評価IDを与える。00002の八文脈の平均も同じ市場経路の記述であり、独立した八回の実証ではない。[組み合わせの考え方](../technical-analysis/組み合わせ/README.md)

00005のような複合モデルでは、入力特徴として供給したこと、学習済みモデルで実際に分岐等へ使われたこと、その特徴だけを取り除く比較を実施したことを区別する。「モデルへ渡した」だけで手法単独を検証済みにしない。モデルの学習期間、条件選択、固定、後続確認もRの明細へ記録する。

## 6. 既存試行へコピーするとき

00001〜00005の各 `設定と結果.md` は、既存のコード・条件・集計を参照して埋める。表を埋める目的で、実行していない足幅や指標の成績を追加しない。未使用セルも残し、何を試したかの範囲を見渡せるようにする。

旧レポートへの追記は実行条件の変更ではない。README、条件ファイル、実行情報、結果表を正本とし、食い違いを見つけた場合は原因と訂正内容を記す。旧60場や末尾の既使用三場を、新しい表へ写したことで未使用期間に戻さない。

表が大きくても、全手法・全時間足の総当たりを要求するものではない。仮説ごとに使うセルと役割を先に決め、採用した設定、試した候補数、変更理由を後から追える記録にする。
