# 順行と反転の取得確認を保護から分離する

2026-11-10更新。[114の全70結果](順行と反転の入口を分けた実現収支.md)を公開した。固定F2の全70場・12条件・840会計の金融、独立入口/会計検算、正式保存、CSV再読、Viewer840一覧ID・24資源GETを完了。Tは全4費用の全70合計で黒字だが、追加16のC5D0は赤字、R追加25玉の実現差は全4費用で負で、採用はない。未知期間の安定性は未確認である。[EMAの傾きと価格位置の重複](../technical-analysis/組み合わせ/同じEMAの傾きと価格位置の重複.md)も結果後の共通知見として整理した。

判定はSource出生ごとに凍結する。同じ配送済みFrameは次の公表/resetまで複数出生から参照でき、1公表1取得へ制限した比較ではない。

以下は実行前の設計の履歴であり、案の本文を保持する。[113](../../study/00113_起動前の支持否定と利益保護の切替/README.md)では、起動額H50と起動前の固定支持失効＋MACDを追加しても純利益を改善できなかった。そこで[114](../../study/00114_順行と反転の取得確認を分ける/README.md)では、出口のP100・数量・元Sourceを共通にし、新規要求時の複合確認だけを比較することにした。

## 背景の一致と、回復した出来事を分ける

保有方向をs（買＋1、売−1）、配送済みの最新確定3分足をt、連続する前足をpとする。

| 役割 | 判定案 |
| --- | --- |
| T：順行確認 | s×(EMA8−EMA21)>0、s×ΔEMA8>0、s×ΔEMA21>0、s×(Close−EMA8)>0、s×Hist>0 |
| R：逆配置からの回復確認 | s×(EMA8−EMA21)<0、s×ΔEMA8>0、s×(Close_p−EMA8_p)≤0からs×(Close_t−EMA8_t)>0へ移る、s×ΔHist>0 |

Tは現在の配置・傾き・価格位置・勢いの水準が揃う状態。Rは平均配置がまだ逆でも、価格のfast線奪還イベントに平均自身とMACD増分の回復が重なる状態。Rへslowの正傾きやHistの正水準は要求しない。既にfast線の順側にいた状態を、新しい奪還として繰り返し数えない。G=0は既知中立、Hist増分=0は改善成立としない。

TのHist正はMACDがsignalの保有方向側にあるという追加確認で、MACD本体のゼロでもトレンドそのものでもない。一定速度の順行でHistが0となればTは不成立になる。人工の加速例でTが通ったことを、すべての順行を検出できる証拠にはしない。

A0は元の入口、TはTだけ、TRはT又はRを通す。反転側の注文を新しく発生させる条件ではなく、元Sourceが要求した方向を同じ出生で通すかどうかの判定である。Sourceのownerから順行/反転の意図を推定して除外しない。

## 入口と約定の時計

元Sourceの新規要求原行で、その原行までに実際に配送済みの現在/前Frameを使って一度だけ判断する。要求と同秒でも後の物理行で公表された足は使用しない。約定時に未来のFrameで再判定もしない。保護の確認・注文・約定は、引き続き逐次原行で行う。

当場coldのHist等が未準備ならUnknownを残す。AND/ORは三値で計算し、判定Unknownと入力欠落件数を別記する。待機・不成立・容量制約・取消・実取得は別の段階である。数値準備による待機を、新しく設定した開始静観と混同しない。

## 評価するものと残る問い

mini片道38.5円、片側上限10枚、追加滑り0/5pt・追加価格時計遅延0/1秒の全12条件で、費用後純額、利益/損失総額、利益後赤字、DD、回数・枚数・期間/ownerを残す。元54と追加16を分け、A0は旧113P100の4費用へ金融同体を確認する。全Source新規要求を分母にし、未知や不成立を消さない。未参加・退出後の仮想利益、機会損失は評価しない。

この比較は、113で見つかった「逐次BBOは抵抗を超えたが確定終値はまだ」という退出時計の問題を直接直すものではない。取得後の状態遷移による退出、BBOによる失効、構造距離に対する数量は別の因子として検証する。[外部確認と心理の仮説](外部再調査/順行の水準と反転の回復イベントを分ける.md)も、NKで改善を実証した事実とは区別する。
