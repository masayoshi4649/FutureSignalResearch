# 既知回復の公表時計と実取得の壁を分ける

2026-11-12。[試行137](../../study/00137_市場終端後の既知回復を公表時点で確認する/README.md)で確認した事実と、まだ検証していない解釈を区別する。

市場で新5分足が終わった時刻と、その足をプログラムが知った時刻は別である。市場End後の回復1分が既に正常閉鎖確認済みなら、新5分の実配送時点に両方を使える。ただし過去の回復終値で取得できたことにはならない。現在Lastを確認し、その後の現在Ask/Bidでcap/riskを再確認する。[136](../../study/00136_押戻し後の回復入口を加えて頻度と先着を比較する/README.md)の公表後から丸1分を待つ条件は変更せず、別試行137でこの時計を比較した。

30分の方向、15分の押戻し、5分のEMA帯接触・MACD改善・RSI/ATR、1分の拒否・回復構造と量を順番に確認する心理仮説は、押戻し中の売り買いが失速し、元方向の注文が再び価格を支えるというもの。これは参加者の内心を観測した事実ではない。

今回の事実は出生9・取得2だった。出生Lastでは9件とも適格でも、同時BBOは8、最初の評価Lastは5、評価BBOは2。取得しなかった7件はcap超過3、K維持喪失4に分かれた。Last同値でも取得側BBOが10pt不利化し、構造確認の価格と注文価格が離れる例があった。K喪失4件は出生時の余裕5ptに対し、その後Lastが逆方向へ10/20pt動いた。これを「構造が成立しなかった」「数量が足りなかった」と一括りにしない。

旧79取得は保持され、主A0だけ新2件を追加した。新2件は順行先着1・未到達1、C5利益11,923円/損失5,077円・差引+6,846円。全81取得/73場は40順18逆17未到達6不足、到達済み先着率68.97%=40/58、平均0.11236件/時だった。全場min1は満たしたが、70%と平均概ね1件/時は未達。全取引勝率や未知期の有効性と呼ばない。[分母の整理](先着率と参加率と決済損益の分母を分ける.md)、[頻度の定義](先着率を保ちながら時間あたりの取得数を増やす方針.md)。

この2件の改善から、cap/期限の緩和や同じ手法の拡張が有効とは分からない。出生時BBO確認の効果、他の技術familyを含む全成立streamによる頻度拡大を次の問いに残す。最初1補完の選別と、全成立した取得候補を評価する研究は分ける。137の条件へ後付けせず、全場min1・同幅到達済み率・時間加重頻度・費用後利益/損失/未知を新試行でも別に記録する。
