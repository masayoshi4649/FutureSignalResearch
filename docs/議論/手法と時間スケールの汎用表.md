収録範囲は本リポジトリの教科書、組み合わせ、価格・数量・板・関連系列と研究で使うモデル・評価・保護である。世界中の技法を網羅する表ではなく、追加時はカタログへ新IDを登録する。

時間尺度は**計算に用いる足**。EMA20の20本や過去12本窓は計算期間であり時間足とは分ける。セッション足はデイまたはナイトを1本にした足。VWAPの起算点とは区別する。30分間引きは30分足の使用を意味しない。

## 追加入力・定義の確認欄

次はカタログ上の必要条件。データの有無は試行ごとに確認し、未使用をデータ不存在へ読み替えない。

| 手法ID | 必要な入力・確認 |
| --- | --- |
| I12 | 採用価格・数量・起算点。観測差分量を使う場合は完全な全約定VWAPと区別 |
| V01 | 区間数量と利用可能時計。現在は価格時計で利用可能な観測累積差分量 |
| V02 | 整合する価格足・区間数量。観測量を採用する場合は数量品質の仮定を明示 |
| V03 | 高安終値・整合する区間数量 |
| V04 | 価格変化と区間数量。式と同値の配分方式を固定 |
| V05 | 対象限月・公表頻度・利用可能時刻付きのOI系列。出来高や板から復元しない |
| B02 | 対象商品の価格別数量。現キャッシュのvalidだけでは多段数量を復元できない |
| B03 | 更新順・受信時計等の監査。板増減と成立済みの攻撃側約定量を区別 |
