# 保有区間OHLCで分けた利益後赤字の原因

確認日: 2026-11-10。[集計方針](保有区間OHLCと損失を検査する方針.md)に従い、固定112の24政策・費用条件×70場を原板へ接合した。詳細と原行の根拠は[調査](../../study/00113_起動前の支持否定と利益保護の切替/根拠/112保有区間OHLC/調査.md)、全件は[CSVの見方](../../outputs/01a1889f-f2af-7943-a047-543275ee9ed2/112保有区間OHLC/README.md)に残す。新113の金融条件を実行した結果ではない。

この診断を受けた変更は、その後の[113の固定比較](低い利益起動と支持失効だけでは改善しなかった比較.md)で検証した。H50は損失総額を減らしたが純利益は悪化し、支持否定＋MACDによる起動前撤退も改善しなかった。以下の損失額を、そのまま回避可能額や改善額とは扱わない。

## 観測した事実

対象は延べ13,332建玉・14,908返済片。実取得から実返済までのLast・Bid・AskのOHLCと、H/Lの初回・最後の到達日時と原行を求めた。部分返済は残枚数と実現額を更新し、初期枚数を最後まで維持した仮の評価にしない。原板のセッション累積高安は使わない。

主P100（片道38.5円、追加滑り0pt・追加価格時計遅延0秒、次の正常な後原行で約定）は558玉、費用後純額＋1,126,987円。正益後赤字178玉のうち、176玉・−3,692,102円は追加追尾の起動前に完結し、起動後赤字は2玉・−154円だった。保存済み評価額と原板から復元した最大・最小値は一致し、この損失の中心を集計バグでは説明できなかった。

112P100は現在公表の動的PriorPivotとMACDで狭幅を確認し、適格な取得後pivotによる構造床も使う。113Eで計画する取得時固定支持の失効判定とは別条件である。

未起動の正益後赤字176玉を、実初期1枚当たりの最大費用後評価で分けると、5,000～10,000円未満が55玉、それ未満が121玉だった。H100からH50への変更は前者へ作用し得るが、後者ではその起動額にも届いていない。この実損失を、変更後に全額回避できる損失と解釈しない。

元S0とP100の主条件には、正常な返済側BBOでは一度も費用後正益にならず、Lastだけで見ると正益となる玉が各12玉あった。その実現損失は各−171,309円。Lastのチャートだけで「利益を放置した」と分類すると、この群を誤る。

主P100で、当該返済枚数が要求行の正常BBOでは費用後正益だったが、実約定で赤字になった返済片は1片・−77円。追加片道5pt・追加1価格秒では9片・−1,078円だった。既に要求済みの気配悪化と、要求を出さず保有を続けた損失は分ける。

## 保護が働いた例と残った問題

11/06デイ11:30:49の57,980pt・4枚買いは、元S0では最大費用後評価＋79,692円を観測した後、12:11:00に−76,308円で完結した。同じ入口のP100は11:37:15に必須保護が起動し、11:39:15に＋3,692円で返済した。利益後に原手法の返済を待ち続ける問題へ、追加保護が実際に作用した例である。

一方、11/06デイ13:52:13の57,420pt・7枚売りは、返済側Askが57,400ptまで進んで最大費用後評価＋13,461円を観測したが、H50にも届かず、14:02:49に−133,539円で完結した。ここは起動後の幅変更だけでは扱えない。

元S0の主純額＋2,146,987円に対してP100は＋1,126,987円であり、全体の実現収支は悪化している。保護が働いた例と、手法全体の優位性は別に評価する。

## 次に判別したいこと

仮説は、入口の判定と保有継続の判定を分けること。小さい順行後の通常の押戻しと、取得時に根拠とした支持・抵抗の失効を区別する。方向の整合だけで保有を続けず、取得後に公開された確定足の構造とMACD等の勢いを組み合わせる。MA収束やBB縮小は警戒材料として扱い、単独で反転確定とはしない。

心理の仮説として、取得方向へ一度動いた事実は、その後も同じ参加者の注文が続く証拠にはならない。支持・抵抗の失効と勢いの逆転が重なるなら、当初の継続を期待する根拠が弱まった可能性がある。これは注文主体の心理を実測した結論ではなく、[外部確認](../../study/00113_起動前の支持否定と利益保護の切替/根拠/順行と反転の外部確認.md)と今回の実経路から立てる検証仮説である。

113では、低い必須起動額、取得時の支持・抵抗の失効＋MACD失速、両者の組合せを分けて検証した。一定利益での必須追尾・最低床・非緩和を保ち、起動前の失効を別の撤退理由として記録したが、採用できる改善は得られなかった。取得時から逆向きの状態と、取得後に根拠が崩れた状態、逐次価格と確定足の時計差を次の問いとして残した。

## 再利用する診断上の注意

- 初回正益後の初赤字が、最高益の後とは限らない。微益と赤字を何度も往復した後に最大益へ達する例がある。
- 同秒の原行を一つへ丸めない。時刻の根拠はCurrentPriceTimeであり、実受信時刻はこの原板から確認できない。
- 起動水準への到達、実起動、返済要求、予約、実約定を分ける。逆指値・追尾床で要求しても、その価格での約定保証にはならない。
- 極値は事後の記録。当時の情報で判別できた根拠を示すまで、「無意味だから全額回避できる損失」とは結論しない。
- ラージの板によるmini約定代理、既使用70場、Sourceへの保護約定非返送という比較モデルの限界を残す。11/09は未読。退出後の仮想利益・機会損失・最高点利確の仮損益は評価しない。
