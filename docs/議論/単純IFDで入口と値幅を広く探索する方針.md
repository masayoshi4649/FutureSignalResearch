# 単純IFDで入口と値幅を広く探索する方針

2026-11-14のユーザー追補。161の三方式の比較や過去案の再現で研究を終了しない。過去案は対照とし、新しい複合テクニカル条件を多数考え、結果の原因調査から次の仮説を実験する。候補作成・評価・再観測の再用ツールを優先し、文書作成だけで探索を止めない。

出口はまず単純IFDで比較するが、±125ptや±250ptへ固定しない。125ptを超える複数の幅を扱い、頻度を維持しながら方向優位と費用後利益・損失を改善できる組合せを探す。幅を広げたために未到達が増えて先着率だけが良くなる場合は、全取得分母、未到達、観測不足、保有時間、期限決済を併記する。

162は既存観測が持つ125/200pt×H30/H60で新規972規則を広く探索する第一段階。静的な共通条件だけでなく、背景混在・短期再加速・失速後回復・BB位置・値幅・量等を組み合わせる。163へ向け、別の488履歴規則と任意幅のRaw価格索引を準備する。200ptを最終固定とする方針ではない。

有望な条件を得るまでPDCAを続ける。全期の最良率を保証や採用済み成績とせず、複数幅や近傍条件での安定性、三帯・前後、実際の取得頻度、費用後収支、必要なら数量制約下の実行可能性を確認する。仮説や主要条件を追加する場合は新試行として固定する。
