## 長い高安窓に使える足はどれだけあるか

全73場・43,124配送bar・全40,544q0（適格35,339q0）を残した。同Raw全配送後の最新bar ID/直近4slot/配送refsと、End/AvailableAt/Stampの時刻・index・物理行が当時履歴に一致した。窓端Eは最新slot.Endで、通常窓は厳密な[E−15/30/60分,E)。rを含み、r突破用の先行窓やq0からの直近窓とは異なる。

適格q0を分母とする可用性は次のとおり。価格可用は区間全slotのclosed/price_known/非Missing、共同可用はそれにvolume_knownを加えたもの。

|窓|高安の価格可用|価格・量の共同可用|
|---|---:|---:|
|15分|26,350 / 35,339（74.56%）|26,309 / 35,339（74.45%）|
|30分|22,342 / 35,339（63.22%）|22,304 / 35,339（63.11%）|
|60分|17,451 / 35,339（49.38%）|17,418 / 35,339（49.29%）|

全q0の価格可用率は15/30/60分で71.00%/60.60%/48.31%。適格以外を勝手に除外した分母と混ぜない。未知slotを飛ばして古い足で本数を補わず、最新未知から古いknownへfallbackしない。

## 当場Start固定VWAP近似は別の欠測問題を持つ

足HLC3×既知量のStart固定近似が計算可能なのは、適格q0で7,946/35,339（22.49%）、全q0で9,213/40,544（22.72%）。最初のslotは73場ともclosed/price_knownだが、量未知は47/73場（64.38%）だった。Start固定の量prefixは一度未知になると後続足だけでは回復しない。一度以上可用なのは26場、全q0で常に可用なのは21場だった。

rolling窓は欠測が窓外へ出れば回復できる。一方、固定prefixは未知を残す。これを混ぜてStart+60へずらす、正常区間へ再anchorする、未知量を0にする救済は採用していない。既知量0×価格未知は加重寄与0になり得るのでstrict jointとcontribution-knownを別maskにしたが、今回の自然barに既知量0はなく件数差は出なかった。

## 時計と測定の限界

CSVの市場Start/End、モデル公表End+60、実配送Stampを分ける。q0はCurrentPriceTimeによる価格時計で、実受信時刻を復元したものではない。既知・closedの足が揃っても、取引所/WSの全約定網羅や真の全セッション高安を認定しない。観測高安と真値を分け、EOF未配送足を過去q0へ足さない。

HLC3×Vは足代表価格の近似で、約定ごとの真VWAP・提供VWAP・市場全員の建値とは異なる。支持抵抗や平均回帰への役割は仮説であり、今回の可用性から損益・125pt持続・頻度・70%の優位は確認していない。次に条件を加えるなら未知を残した別仕様で評価する。
