# 価格失敗へ量比の方向変化を加えた比較

確認日：2026-11-05。[試行36](../../study/00036_価格失敗と量比の方向変化/README.md)の共通知見。[実行前計画](../../study/00036_価格失敗と量比の方向変化/計画.md)、[設定と結果](../../study/00036_価格失敗と量比の方向変化/設定と結果.md)、[対応診断](../../study/00036_価格失敗と量比の方向変化/対応診断.json)を正本とする。全66場は既使用の追加開発。

## 価格・勢い・量の役割を分けた

[35](CCI突破の到達と回復を別々に評価する.md)では、後で回復する群の選別と、待ってから入る価格/時計の代償を分けた。36は後続確認を延ばさず、[29](極値更新とOBV非追随の反転を比較する.md)の価格P＋中心化MACD差の同時点に量を加える比較とした。

価格Pは3分の過去20公開足の安値/高値を更新し、終値が旧BB20±2σのstrict内。MACD12/26/9のヒスト一足差を反転方向へ要求する。旧29のATR/数量/同OBV区間等のMも保持し、OBV非追随の値条件は足さない。**旧高安の内側へ終値が帰還したことや、ヒゲの旧BB外到達は要求していない。** 「失敗」「内復帰」という略称から、その確認を補わない。

新しい[ボリュームレシオ教材](../technical-analysis/指標/ボリュームレシオ.md)でVR1/VR2を区別した。VR2を中心化したB20=(上昇量−下落量)/総量と、その現前差を使う。低いBでも改善し始める反転候補を許し、Bの水準・過熱・RVOLの追加閾値を重ねない。価格構造、勢い、量の配分、ATRの保護幅という役割であり、独立した四票ではない。

|入口|追加条件|比較するもの|
|---|---|---|
|V0|旧29R0と同じ全308登録|元の数量Mを持つ基準。量なし対照ではない|
|V1|V0＋現前B20の有効準備|数量の連続性・総量正という準備の影響|
|V2|V1＋side×ΔB>0|量配分が反転方向へ改善する値選別|

現前20変化には22終値と21量が必要。最古基準終値の数量を余分に要求せず、数量欠測でも有効終値は次足分類の基準へ残す。価格欠枠/非公開/不正では価格基準も切る。完全0量は入力可、総量0はB未準備。qのfloatを有理数へ厳密化し、差分子で採否を決め、表示floatへ戻さない。売買反射でU/Dが交換しB/ΔBの符号が反転する。

V0→V1の準備で除外したのは学習・選択各1登録で、両方とも仮250は0/1。小さい準備差をVR値の効果としない。V1→V2では学習の保持群16/85＝18.82%に対し、除外群は21/55＝38.18%。選択も保持15/68＝22.06%に対し除外13/57＝22.81%だった。三案とも入口支持は満たしたが、支持付き70%に届かず、量比の改善条件を足す根拠は得られなかった。

同じ原登録の純新規key/価格・先着は全て同値なので、ここは待機価格の代償ではなく事例の選別差である。全仮約定を分母にし、期限未達/観測不足を残す。原要求での30分間引き、実参加の保有抑止、実現損益と混同しない。

## 窓落ちと当足の方向は同じではない

V2採用でも、当足の終値方向が反転注文と反対だった登録は学習9・選択10件（仮250は3/9・4/10）あった。ΔB改善は当足の方向だけを表さず、古い方向別量が窓から落ちる影響も含む。V2の窓落ち分類が実方向負だった登録は61/48件。ただし当足の変化と重なる分類であり、この件数を窓落ちだけの因果寄与とはしない。

今回のV1/V2には当足q0、窓落ちq0、現20量が全て同じ正量、両窓和集合21量が全て同じ正量の群はなかった。21量同正は両窓が方向回数式になることを保証する十分条件であり、必要条件ではない。不均一量でも偶然同じ比になる場合はある。「量が同じなら価格方向回数へ退化する」という例を、このデータで実際に起きたと記さない。同正量の群がなかったこともMACD等との情報重複不存在の証明にはならない。

この機序は採否へ新しい閾値を戻すための事後最適化ではない。保存panelだけで当足/退出足と先着を分けた診断であり、少数9/10件の高率を新しい利益条件として採用しない。

## 次の判別へ持ち越すこと

今回は、量比の改善を価格失敗へAND追加しても予測と回収の改善を裏付けられなかった。だからといってΔB不成立群を逆注文にするのではなく、まず**旧高安の内側へ本当に終値が戻った反転と、旧BB内でも旧高安の外に残る突破継続を、勢い方向と合わせて分けられるか**を次の仮説とする。現Pは両者を定義上区別していない。この違いが今回の損失原因だったと確認したわけではない。

[24](終値内復帰と外回復を上位状態で選別する.md)のf/g等との重複・時計・窓・価格を先に比較し、既存手法の微調整を新知見と数えない。真の構造帰還/外側残留、反転方向の勢い/継続方向の勢い/不一致を別の発動として設計し、支持・費用・品質と除去した成功も測る。具体的な次試行の条件・効果は未検証。
