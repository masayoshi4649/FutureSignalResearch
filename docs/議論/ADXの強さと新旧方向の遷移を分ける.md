# ADXの増減と新旧方向を分けて確認する

確認日：2026-11-12。145の自然funnel・金融を読む前の外部調査であり、次の問いだけを残す。145の条件・コード・正式文書は変更しない。Raw・価格CSV・追加2場も未読。

## 一般説明と数式から分かること

ADXは方向を持たない強さで、方向は+DIと−DIで別に読む。StockChartsは、強い上昇から強い下降へ移った際にADXが高水準を保った例と、平滑による遅れを説明する。反転には必ずADX低下が挟まる、とはいえない。[StockCharts公式・ADX](https://chartschool.stockcharts.com/table-of-contents/technical-indicators-and-overlays/technical-indicators/average-directional-index-adx)

CQGもADXを方向から分離し、旧トレンドから新トレンドへの急変をこの指標だけでは拾えないと注意する。Fidelityも方向にはDIを組み合わせる。これらは一般解説であり、NK225の15分足における有効条件の実証ではない。[CQG公式・ADX](https://help.cqg.com/cqgic/25/Documents/averagedirectionalmovementindexadx.htm)、[Fidelity公式・ADX](https://www.fidelity.com/viewpoints/active-investor/average-directional-index-ADX)

Wilder型の初期化後、期間をn、DIの和を正とすると、次式になる。これはStockChartsの計算式を整理したもの。未知・初回seed・0除算の処理は別である。

ここでP_tはPlusDI（+DI）、M_tはMinusDI（−DI）という、どちらも非負の系列名である。MinusDIを負の数と解釈しない。

```text
DX_t = 100 * abs(P_t - M_t) / (P_t + M_t)
ADX_t = ((n-1)*ADX_(t-1) + DX_t) / n
ΔADX_t = (DX_t - ADX_(t-1)) / n
```

したがって、ΔADX<0は「今のDXが平滑済み前ADXより低い」であり、「今のDI差が前足から縮んだ」と同義ではない。DXが前足より増えていても、まだ前ADXより低ければADXは下がる。逆にDIの優勢が反対へ移り、その偏りが前ADXを上回ればADXは上がり得る。DIを左右入れ替えてもDXは同じなので、ADXの上昇だけでは旧方向の再開と新方向の強まりを判別できない。これは式からの推論である。

## 145の固定条件に対する論理的な含意

採用原文は[145条件](../../study/00145_押戻し完了と失敗突破を別の構造イベントで評価する/条件.md)へ収録した。原文のSHAは `38d1cc08e15438af669d318a9abd43814c590c48eadc1c8bb7ea0c255158f6b3` で、収録先の条件.md自体のSHAとは区別する。Aは現在のMA30方向・DI15方向の一致とΔADX15>=0を維持する。Bはarmの旧MA方向dを保存し、狙いs=-dとするが、confirm/pendingでもΔADX15<0を維持する。Bの現在DI方向は閾値ではない。

このため、価格構造・Hist5・同足量が新方向sを支持しても、DI15がs側優勢となってADX15が再上昇すれば、Bは現在背景で取消し得る。**これは固定仕様が選ぶ範囲の限界であり、実装不具合や145失敗の実測原因を意味しない。** ADXが等値になった場合もBは不成立である。再上昇しても、MA30がまだ旧dなら、Aは新s方向の入口を代わりに出すとは限らない。

旧d基準の `D=d*(PlusDI15-MinusDI15)` と強さ変化を分けると、次の観察区分を作れる。これは診断の候補であり、新たな売買規則ではない。

| 現在のDI優勢 | ΔADX15<0 | ΔADX15>=0 |
| --- | --- | --- |
| D>0：旧d側 | 旧方向優勢だが現在DXは平滑平均との差で低い。旧方向終了とは未確定 | 旧方向の偏りを保持/強化している候補。価格構造による再開確認は別 |
| D<0：新s側 | 新方向優勢でも平滑値は低下中。Bの強さ条件に適合し得る | 新方向優勢で平滑値は横ばい/上昇。Bは取消し得る移行区分 |
| D=0 / 未知 | 同値と未知を分ける。反転完成や弱い状態へ補完しない | 同左 |

この表で「強化」はADXだけから価格の加速や継続を保証する意味ではない。現在MA30も旧d/新s/符号不一致/0/未知へ分ければ、方向の移行と強さの移行を混同せず記録できる。ADXの高さ・増分は円建て値幅や取得位置を表さず、±125の余地・Iまでの距離・当時ATRは別に必要である。
