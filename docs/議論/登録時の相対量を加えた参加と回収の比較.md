# 登録時の相対量を加えた参加と回収の比較

確認日：2026-11-06。[試行64](../../study/00064_再試験の量と価格進行を別々に確認/README.md)では、価格のみの同構造対照へ量価格情報を追加すると、条件選択期間の参加が増えたが、費用後損益は改善しなかった。**実際に分岐へ選ばれた追加列は登録足の相対量だけであり、再試験時の量や価格進行の有効性を否定した実験ではない。** 支持付き先着70%・待ち50%以下・費用後利益の同時目標は未達。

数量は固定済み配信累積差分からの観測量で、完全な約定契約数や売買主導側ではない。同Day/Night・同限月・同3分indexについて、当場開始前に終了した直近10場を先に選び、完全量5場以上・正平均を条件に通常比を作った。休日差は未調整。全12,952足中、公開完全量12,798足、通常比既知10,828足。評価でb/rが存在する場合の量価格ペアはすべて有効で、追加の準備不足による評価対象除外はない。段階なしと量基準不足は別に保存している。

## 追加列がどこで参加へつながったか

20場・30場時点のB/Qは追加列を使わず、純候補・実完結集合が同じだった。40場時点のQでは**登録bの同時刻相対量F55**が2節点に選ばれた。再試験rの量、b/rの一足進行、2有効旗は未選択。量を加えた木を作ったことと、すべての量価格仮説を試したことを混同しない。

選択期間の一方の量節点は784方向が通過し、162方向が最高側になったが純採用0。もう一方は411方向→最高側360→純採用25だった。その25は次の**組み合わせ全体**を満たす葉24に属した。

- 候補方向の15分DI優勢差が正。
- 開始帯幅／現在3分ATRが4.0519208908より大きい。
- 候補方向の現在3分実体／ATRが−0.4172712862より大きい。
- 対応する登録足の同時刻相対量が2.9242255688より大きい。

この葉の過去支持は65方向、先着得点22/65＝33.85%であり、目標70%ではない。過去の主費用回収は平均−105.08円。Q0の参加下限1/3は通るが、Q1の回収正条件は通らず、25件すべてが待ちになった。後続の追加6純候補も同じ理由でQ1では不参加。**B1とQ1は、集計値だけでなく全期の純候補・実完結集合まで同じ**だった。

量追加Q0の選択25純候補は全順行で、排他的な現在状態はb出生段階で有効12、r段階で有効2、k有効6、k取消3、b出生段階で取消2だった。これはbが過去に形成された総数とは別である。形成IDは11、最大4枠で反復しており、25個の独立した形成ではない。実完結は24、残り1は保有中で新規に建てなかった。この状態内訳の分母は純候補25で、24完結の状態別内訳ではない。

量追加で共通候補の退出が改善したのではなく、B0にない24完結を増やして主損益が−3,528円変わった。後続は6純追加・4完結・新規取消2、追加完結の主損益は−788円。共通の完結は識別子以外の全属性が一致した。

旧J→Bでは、時系列の純候補が大きく入れ替わり、J0/B0の共通は13枠のみ。選択ではB0が8純候補・7完結を増やし、追加完結−4,054円。これをQによる量の効果へ混ぜない。DI根だけの経路が複数技法不足で除かれる場合もあり、固定根の変更は単なる節点名の変更ではない。

利益旗の起動は現在の粗益−122円strict正で、最低床は名目新規価格。費用後同値を保証する床ではない。後行約定と返済待ちがあるため、床が非緩和でも不利返済は起こり得る。この内訳だけから「利確が遅いことだけが原因」とも「入口だけが原因」とも断定しない。出口は今回変更していない。

## 次に判別すること

今回追加された葉は、過去の突破時に量が多いことと、現在の実体が大きく逆行していないことを確認したにとどまる。現在も防衛線が有効で、調整が終わり、注文方向へ進み直したことを全件へ要求してはいない。登録の活動量を、そのまま現在の継続需要と読むには条件が足りない、というのが次に検証する仮説である。今回の損益からその心理を実証したという意味ではない。

次候補では、**登録時の活動→現在の位置と失効→その後の価格応答**を分ける。同じ高量登録でも、線を保持して別足で再開する場合、元方向が失敗して反対側へ進む場合、確認前・取消・期限切れを区別する。元仮説の失敗だけで逆向きに入らず、反対方向自身の価格確認を必要とする。全件k待ちの強制は既に支持不足・取得遅れの論点があるため、自動的な採用案にはしない。段階条件、量と進行の相互作用、形成反復を分けた支持を、別試行で事前固定して比較する。

これは未固定・未実行の次候補である。特定の量閾値を成功例へ合わせて選び直したり、少数のk有効だけを分母にして目標達成としたりしない。比較した浅い木でr量が選ばれなかったことは、量と再試験の組み合わせ全般を否定しない。

外部の[再試験と量価格の調査](外部再調査/再試験の量と価格進行を段階で分ける.md)と[市場心理の識別](外部再調査/量の不釣り合いと市場心理の識別.md)も並行して進めた。吸収・枯渇・仲介往復は心理仮説で、無方向の観測量から主体・新規返済・指値補充を同定した事実ではない。テクニカルな場所・順序・反証で候補を作り、原典の説明を収益保証へ置き換えない。
