# 日経の判断をTOPIXの板から作り直した場合と日経から受け取る場合

2026-11-19。日経で成立した入口が他の指数に移るかを調べる際、①移植先の価格と出来高から判断を作る、②移植元が選んだ時刻・方向を両商品の板で測る、③移植元の取得通知で移植先の独立した口座を動かす、という三つの問いを区別すると、差の所在を絞れる。[試行213の条件と数値](../../study/00213_日経デイ199の入口をTOPIXへ固定移植する/README.md)

日経199_02をTOPIX自身で判断させ、入口・出口の呼値数をそろえた旧42デイの収支は−129,786円。費用前も−51,000円で、全42日参加した。日経で黒字だった、15分MACDの増分がまだなく短期の方向・勢い・回復で入る条件は、TOPIXでは25件中、順先着5・逆先着10・未到達10だった。日経での同条件は23件中13・3・7だった。現物休場日を含む09:00前とこの条件は多くが重なり、時間帯と技術条件の寄与は独立に加算できない。

日経由来の同じ取得時計・方向・ティック数・期限で両指数の値動きを測ると、TOPIXにも平均で設定幅の＋0.105相当の費用後利益が残った（両側確定157件）。TOPIX自身が選んだ取得時計・方向では−0.049幅（同130件）。価格が連動することと、各々の指標が有利な場面で発火することは別々に検証できる。ここでの幅単位の損益は事後の経路診断で、実際の一枠口座の累計には加えない。

日経の取得を通知してTOPIX側を一枠で動かした対照は40/42場・127取引、既知＋282,466.4円、未知1件。移植先の判断が振るわなかった場合も、判断元を保つ使い方が研究候補になる。この結果には価格比による換算、通知遅延・約定代用の仮定が含まれ、発見に使った同じ42日の結果である。日経・TOPIXで発火した違いを指数構成の効果とするには、別期間と別の識別根拠が必要になる。[候補別CSV](../../outputs/00213_日経199のTOPIXデイ移植比較/README.md)
