# 参加率と一定利益後の可変追尾

更新日：2026-11-09。根拠は本研究へのユーザー指示。新しい候補へ適用し、試行100・101等の固定済み条件を変更しない。

## 判断の機会を確保する

判断は5分または15分ごとに行う。各セッション開始30分を見送り、末尾30分も除外できる。その他の除外を必要とする場合は、その理由と影響を明示する。米国開始30分の旧見送りも、適用する候補と時間を記す。

2026-11-09の追加指示により、30分見送りが問題になる場合は20分への短縮も比較できる。変更する開始区分（デイ・ナイト・米国）、新規可能な最初の時刻、主・副の判断枠数を新試行で先に固定する。試行107の実行中の30分条件は維持し、20分の成績や増える判断枠を混ぜない。

参加率は「新規または保有の枠数 ÷ 対象判断枠数」。買い・売りを同時に保有しても1枠とし、保有継続は待ちに含めない。目標は50%以上、最低条件は25%以上とする。注文の受理と実際の新規約定は別記し、未約定注文だけを保有として数えない。欠測・判定不能も分母に残し、待機と区別する。5分と15分、全期間と日中・夜間を別に報告する。

売買しなかった枠の仮想利益は算出しない。参加率は運用条件であり、機会損失の推計とは区別する。

## 利益保護の起動と幅を分ける

費用後含み益が初めて正になった瞬間の起動に限定しない。一定利益に達したら必ず追尾を起動する。起動水準は事前に固定し、価格の呼値・手数料・想定滑り・ATR等の通常変動を区別する。実際の返済側価格を使い、残枚数の利益を評価する。

起動後は最低でも新規価格を保護し、保護価格を不利に緩めない。トレンドが継続する間の通常幅と、収束・失速時の狭い幅を比較する。例えば、ATRで通常幅を決め、移動平均間の収束にMACD増分の鈍化や価格構造の否定を重ねて幅を狭める。低ボラティリティや平均の収束だけを反転と断定しない。

新規は定時、保護は定時外も連続で判定する。起動前にも損失上限と技法否定による退出を置く。売り・買いは符号反転した同じ式とし、片側上限10枚を維持する。逆指値の発動価格と実約定価格は別であり、建値の保護を費用後黒字の保証としない。

これらは検証方針であり、新しい幅や起動水準の有効性は未検証である。実現損益、DD、利益後赤字の件数・金額、取引数、参加率を同時に比較する。参加率だけを稼ぐ短期往復や、保有時間を延ばすための損切り先送りを採用しない。

## 旧候補の位置付け

試行100のE3S＋P0は少数の入口へ絞った対照であり、参加率条件を満たす最良候補とは扱わない。旧損益は保持し、判断枠を使った参加率を追記して比較資料を訂正する。試行101も同じ入口を使う固定対照として保存し、新条件の合格例へ読み替えない。

再集計した主C0/D0は、開始30分・末尾30分を除く5,832枠中、新規24・保有13・待機5,775・判定不能20。参加37枠、**0.6344%で最低25%未達**だった。新規の受理28要求56枚と実新規約定28回56枚は別に確認し、この集計では実新規約定のある枠も24で一致した。米国開始後の旧静観時間も主分母には含めた。元S0の同時計保有率は未集計であり、全54場で取引があることを参加率100%とは呼ばない。[結果](旧100の参加率_結果.json)と[コード・指紋](旧100の参加率_参照.json)を参照する。

同じ5分運転を15分の時刻だけで観測すると1,944枠中10枠、0.5144%。これは入口を15分へ移して再運転した成績ではない。米国開始30分を分母からも除いた副表でも5分0.6526%で、除外の選び方で未達は解消しない。

[試行102](../../study/00102_定時チャートと一定利益後の可変追尾/README.md)は、各枠の独立した複合チャート判断と一定利益後の通常幅／可変幅を比較した。全24設定の参加率54.66〜66.91%は目標50%を満たす一方、全案赤字。同実入口内の退出改善と、その後の実参加の損失を分けて保存した。

[試行103](../../study/00103_元の多玉と数量を保つ一定利益後の追尾/README.md)では元の多玉・数量・返済を保ち、追加追尾の起動だけを変更した。ATR1倍起動は全4感度で黒字、全体参加27.63〜28.27%で最低25%以上。ただし夜間単独は約18.4%、全体50%も満たさない。共通の[起動時機と建玉構造の整理](利益追尾の起動時機と元の建玉構造を分ける.md)へ結果と未解決事項を反映した。可変幅の次の比較は、この一定利益起動と分けて固定する。
