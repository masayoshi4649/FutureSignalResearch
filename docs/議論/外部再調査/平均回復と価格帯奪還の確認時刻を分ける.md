# 平均回復と価格帯奪還の確認時刻を分ける

確認日：2026-11-08。[91の比較](../利確後の新しい再開で変わった損益.md)後に作成した事前設計。一般的な説明、独自の価格定義と仮説を分ける。現在は[92の検証結果](../価格帯奪還の確認で変わった参加と回収.md)も保存し、本書の事前説明と実績を区別する。

## 外部資料から確認したこと

CMEは、以前の高安や移動平均等を支持・抵抗の候補とし、突破後に支持と抵抗の役割が交代し得ること、厳密な一点より帯として理解することを説明している。[CME：支持と抵抗](https://www.cmegroup.com/education/courses/technical-analysis/support-and-resistance)

反転の教材は、形の出現と確認を分け、例えば途中の安値・高値を抜けることを確認材料に挙げる。量の増加も補強材料とするが、必ずその方向へ進む規則とはしていない。[CME：反転パターン](https://www.cmegroup.com/education/courses/technical-analysis/technical-patterns-reversals)

継続の教材は、調整や持ち合いからの突破を他の証拠と合わせて読む。ここでの独自のClose順序を、教材のフラッグやペナントの検出と同一視しない。[CME：トレンドと継続](https://www.cmegroup.com/education/courses/technical-analysis/trend-and-continuation-patterns)

Lo・Mamaysky・Wangの研究は、米国株の日次パターンに追加情報が含まれる場合を示している。NK225の3分足・費用後利益や、高い勝率を保証する結果ではない。本研究でも図形を再現可能な式へ落とすことと、運用で利益を得ることを別に検証する。[NBER：テクニカル分析の自動認識と統計的評価](https://www.nber.org/papers/w7613)

以下のCloseだけの式、足数、900秒の寿命は本研究の独自条件である。実高安・完成スイング・教材の図形検出を再現したとは呼ばない。

## 複数技法の役割

| 役割 | 候補で確認するもの |
| --- | --- |
| 背景 | 15分EMAの元方向。ただし平均が残っていることと現在の価格構造の維持は別 |
| 価格構造 | 以前の推進Close基準を奪還し、その上で押し、突破段のCloseを越えて再開したか |
| 勢い | 新しい価格確認時にもMACD histogramとRSIの増分が同方向か |
| 値幅・位置 | ATRと取得側気配、同時スパイク警戒。確認を待つ間の追い掛けや取得遅れも数える |
| 量 | 元FARの価格・量条件を持つSource運転と、現在のOFI/表示数量/価格応答を区別。現在量支持を追加判定したことにはしない |

MACDとRSIは同じ価格系列から計算されるので、独立した二市場の投票のように成功確率を足さない。価格がどの基準を回復した時の勢いなのかを確かめる。

## Close基準と、突破後の最高Closeを分ける

売買方向を`s=+1（買い）/−1（売り）`、方向座標を`X=s×Close3`とする。元の推進開始iと最新押しpから、`H=max(X[i以上・p未満])`、`L=X[p]`を固定する。同窓・同epochの連続した公開足が必要で、Hは押し前の方向側最大終値である。

買いの説明用にH=95、L=90という架空の価格列を考える。これは市場データの成績ではない。

| 時点 | Close | 読む構造 |
| --- | ---: | --- |
| b | 100 | Hを初めて奪還 |
| P | 110 | 突破後にさらに進んだ最高Close |
| h | 105 | Hより上で、Pからの調整 |
| v | 111 | 調整後にPを越えた新しい進行 |

調整を「最初のbの価格より下」と定義すると、この105の押しを取りこぼす。またvを「hより上」だけにすると、106でも成立し、110を回復したとは言えない。そこで修正版は、b後・h前の方向側最大Close Pを因果的に更新し、`H<X_h<P`の調整、その後の別足`X_v>P`を再開と定義する案である。

bは最初の越過、Pはhが出る前だけ更新する。h中の方向側最小Closeも記録し、H以下に戻ればb/P/hを破棄する。同値を越過へ変換せず、将来成功した足へbやPを付け替えない。新しいpや窓・背景の変更も別の失効理由として扱う。

これは最高終値と調整終値の関係であり、ヒゲが支持抵抗に触れたことを示すものではない。

## 市場心理としての仮説

買いの例では、旧抵抗Hを越えた直後には新規買いと売り方の買戻しが混在し得る。続伸後の調整でもH上を維持し、再び調整前の最高終値Pを越えるなら、最初の突破だけよりも売りを受け止めた価格経路を確認できる、という仮説である。売りは符号を反転して同じ説明にする。

ただし、板と終値から個々の参加者の動機は観測できない。H維持も「全員が支持として認識した」という証明ではない。確認を増やすほど取得が遅れ、ATR内の取得位置や次の15分判断までの維持条件を失う場合もある。この利点と遅れの両方を数える。

## 量による別の確認へ再用できるもの

2026-11-08にCQGとIBKRの公式説明も再確認した。CQGは先物VWAPの出来高加重式と日/セッション等の開始点を、IBKRは売買価格の執行比較基準としての用途を説明する。これらはVWAP付近の反発利益や、全参加者の平均建値を保証しない。[CQG：先物VWAP](https://help.cqg.com/cqgic/25/Documents/volumeweightedaveragepricevwap.htm) / [IBKR：VWAP](https://www.interactivebrokers.com/campus/glossary-terms/volume-weighted-average-price-vwap/)

本repoには[17の配信元VWAP・売買代金の入力監査](../../../study/00017_配信元VWAPと売買代金の入力監査/README.md)と[出来高の入力制約](../../データと閲覧形式.md)がある。今後、価格帯の奪還・維持に出来高や数量加重基準が伴うかを調べる場合に再用する。提供累積の起点と当該セッションの差分、欠測・重複・リセットを先に区別し、板表示量やFAR現在保有量を約定出来高に置き換えない。

これは次の検証候補の役割整理であり、固定92へVWAP/出来高の新gateを追加したものではない。現在基準から離れた順行と、基準への回帰を別の仮説とし、結果を見た後に都合のよい起点へ変えない。

## 二つの確認時計を混ぜない

旧E1は平均回復後の勢い確認kから900秒で失効する。さらに別足の突破・調整・再開を待つと、新しい価格確認ができる前、又は次の15分判断までに、旧kの期限が切れる可能性がある。

| 比較候補 | 入口の意味 | 証明すること |
| --- | --- | --- |
| A | 旧E1に価格順序を追加 | 旧kの寿命を維持し、その範囲に価格確認が収まるか |
| B | 現在のE0複合資格と独立した価格trigger | 旧kでi/pを復活させず、新trackerが因果的に保持。新vを起点に固定寿命を定義 |

BをE1の単純な追加ANDとは呼ばない。旧kが期限切れとなった事実は原値のまま残し、独立episodeと現在資格を別に証明する。どちらも新規判断は初回を除く15分、損益保護は原行ごとを維持する。

まず既存Recordの公開価格と定時だけから、価格完成数・定時までの失効・現在資格・Source候補の有無を数える。損益や勝敗を読まず、定義と時計が機械的に両立するかを検査する。原案と修正版の仕様を保持し、可用性の群を新しい運用損益とはしない。

旧i/p文脈での前検査では、時計許可2,376枠×2方向のうち、旧E1は168方向。修正版の価格完成を保持してE0/E1も満たすのは3方向、非closingの同方向Sourceもあるのは2方向だった。完成後最初の定時までに旧k期限でi/pが消えた例も15件あった。これは独立finderの成績ではなく、旧kへ確認を積み増す場合の時計上の制約である。そこで次候補は旧kから独立したi/pとv期限を持つ別モデルとして定義し、先に可用性を測る。元データと検査の証拠は`work/92設計/可用性前検査の停止.json`へ保存した。

## 反転と待機を分ける

Hを奪還しないからといって反対へ入る条件にはしない。将来の反転候補ではL否定、戻りの失敗、逆方向の価格進行と勢い、値幅・量の役割を別に確認する。元Sourceの方向と実売買方向、元Source返済通知の意味も分けた契約が必要である。今回の設計段階では反転売買の利益をまだ検証していない。
