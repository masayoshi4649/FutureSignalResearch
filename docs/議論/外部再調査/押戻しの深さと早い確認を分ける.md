# 押戻しの深さと早い確認を分ける

確認日：2026-11-06。77の公開計画・条件設計より後に読んだ資料であり、77の事前根拠へ遡及しない。77へ追加gateは0。押戻しの背景と価格確認を分ける概念は既存知見と重なり、新発見や新しい実績とはしない。

Rayner Teo本人の公式教材、[#17: Do You Make These Pullback Trading Mistakes?](https://www.tradingwithrayner.com/course/17-do-you-make-these-pullback-trading-mistakes/)を、Lesson17導入からRecap・末尾までのHTML書き起こしで実読した。公開日表示なし。動画は未視聴、図中の数値は再測定していない。FX、金、米10年債先物の例を含み、日足と2/4時間足の組合せが示される。3分/15分の検査ではない。

本文は、固定した支持抵抗までの戻りだけを待って浅い調整を逃すことと、最初の小反応を調整終了と見て早く入り過ぎることを両方扱う。強い・中程度・弱い流れでは戻りの深さが違うと説明し、当時の場所での価格拒否や下位構造の変化を参加の手掛かりとする。支持を一度割って終値で戻る偽突破も例示する。20/50/200MA等は説明上の設定であり、本研究への追加条件ではない。

商用教育の本人解説で、全件、費用後、外標本の成績は示されない。「買い手/売り手が支配する」は価格反応の解釈で、主体の在庫・意図や注文フローの実測ではない。深い調整を自動的に反転、浅い調整を必ず継続とは判定できない。

次の問いは、背景の方向・強さ、押戻しの深さ、現在の価格応答を別の役割として記述し、継続途中の調整と構造が崩れた場面をどう分けるかである。確認を早めるだけでは小さな戻りを誤認して早期取消が増え得る。一方、高い確認端を待つ間に波が終わる場合もある。いずれも、後から都合のよい底や戻り高値へ起点を替えず、当時の公開出典と最初の確認・否定を残す必要がある。

原典の次足始値参加と、15分定時のBBO要求・遅延後約定は別である。3分の確認が早くなっても、定時にも有効か、現在資格を満たすかによって、純判断も実取得も変わらない場合がある。取得価格、費用・保護、250/125先着と実回収を別に評価する。本文は70%、活動、利益や最適な確認幅を保証しない。新しい閾値候補の固定・次試行採番・市場読取・再生・fitは、この整理では行っていない。
