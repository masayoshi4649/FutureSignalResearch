# 内包足の偽突破と価格帯への受容

確認日：2026-11-06。73完了後の追加調査。[詳細メモ](../../../work/74設計/外部の順序条件.md)に版・実読範囲・未読部分・原記事の指紋を保存した。

## 原典と確認できたこと

Dan Chesler『Trading False Moves with the Hikkake Pattern』、Active Trader 2004年4月、印刷42〜46頁を、[Peter Brandt本人サイトの公開原記事](https://www.peterlbrandt.com/wp-content/uploads/2016/06/Hikkake-Dan-Chesler.pdf)から読んだ。全5頁の本文と図キャプションを抽出して確認し、図の価格プロット全体を画像で検証したとはしない。著者自身の配布URLは取得できなかった。URLにある2016年は記事の発表年ではない。

基本形は、直前足の高安にstrictで内包する足I、その次に高安の両方が一方へ移る足B、続く3本以内のI反対端への価格突破という順序である。実体の色を条件にせず、継続・反転の両方に現れる。日足の先物・株式の図例には、確認の不成立と確認後の損失もある。事前に選ばれた図例の説明で、全件の勝率や費用後成績ではない。modified版には別条件があり、基本形と混ぜない。

Jim Dalton本人の[Top Ten Resolutions for Traders](https://jimdaltontrading.com/top-ten-resolutions-traders/)は項目1〜10を実読した。前pitセッションの範囲内で始まる場合の時間による情報追加、既存の参照と当日発達する参照、複数時間軸の場所を区別している。機械的な受容秒数・本数、NK225の売買条件や成績は示していない。

## 心理の仮説と計測の違い

最初の方向へ追随した参加者の期待が崩れ、返済や反対側の参加につながるという説明は仮説である。高安・終値から、追随注文、損切り連鎖、注文主体を測れたとはしない。内包足の偽突破がそのまま継続する場合や、反対端を確認した後に戻る場合も残す。

価格が帯の外で終わる、複数足にわたり維持する、内側へ戻るという観測は受容・拒否の代理になり得る。ただしDaltonの「時間」を任意の滞在本数へ置き換えるなら、それは独自の検証条件である。事後的なtrend day分類を朝の入力へ戻さない。

## 74への適応で変えるもの

[試行74の事前計画](../../../study/00074_内包足の偽突破確認と局面切替/検証計画.md)では、原典の価格crossを、公開された3分足終値による確認へ適応する。15分DI、ADX変化、3分FastKを組み合わせ、上位方向への順行と上位に逆らう反転の条件を変える。原典の規則をそのまま再現した比較ではない。

| 比較する問い | 残す反例と測定 |
| --- | --- |
| 終値で確認すれば判断が変わるか | 足内の突破後に戻る試行を除く一方、確認を待つ取得遅れがある |
| 同じ形を定時で何度も使わないか | 形成ID、最初の確認、使用窓、確認後の否定、同形の反復数を残す |
| 上位に沿う再開か、逆向きの反転か | DIによる役割と、局所パターンの反転を別の意味として記録する |
| 次の価格突破を待つか、定時に要求するか | 同じ純候補で注文方式を比較し、新規時刻・価格・参加差を測る |

新パターンがない場合の従来候補へのfallbackも独自条件である。原典にない閾値や寿命を収益の保証とせず、先着250/125、支持、費用後回収、品質、全予定枠での活動を実データで確認する。
