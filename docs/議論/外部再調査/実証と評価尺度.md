# テクニカルの実証と、今回求める先着率を分ける

一次資料確認日：2026-11-06。先物の学術実証、著者の研究報告、確率の教科書を読んだ調査である。新しい市場データの取得・指標計算・先着計算・運用再生・算法実装は行っていない。既存試行と目標を変更しない。

**次の設計では、指標値を足す前に、どの時間帯・価格構造・参加者行動を想定し、どの観測がその説明を否定するかを固定する必要がある。** 以下の実証は、テクニカルが一律に有効又は無効という結論を支えない。市場、時代、時間幅、費用、出口と検証方法によって結果が違う。今回の「+250ptが−125ptより先」の70%を示した資料は、この確認範囲では見つかっていない。目標を下げる提案ではなく、その目標への根拠を取り直すための整理である。

### 新しい日経先物研究が示す時間帯の文脈

Iwanaga（2026、Finance Research Open）は2001–2024の日経先物日中1分、5,716日を使う。前日のS&P500の方向に対し、寄付後30分は逆方向、引け前30分は同方向という関係を報告する。費用後の寄付反転例は年率3.59%・勝率49.65%、引け順行例は年率−0.40%。ただしauctionのスプレッド0、連続取引の有効スプレッド0.25tick等を仮定する。心理機序は直接検定していないと著者も限定する。今回は出版社の検索本文からデータ節・4.5/4.6を確認した範囲で、直接本文/PDFの再取得、時点整合や未見外標本の再現確認は未完了である。+250/−125、現在BBO、利益追尾の証拠には置き換えない。[出版社論文・DOI](https://doi.org/10.1016/j.finr.2026.100108)

**ここからの研究上の推論**：同じ「順行」「反転」でも、寄付の情報調整、日中の往復、引けの売買需要を混ぜれば条件の意味は変わる。次は心理説明を、当時既知の市場状態→固定端/発動→予想する価格経路→否定条件という形へ落とす。時間帯を結果後に切って良い帯だけ残すことや、この論文の符号をそのまま新gateへ足すことは、まだ行わない。

## +250/−125の先着率は、通常の売買勝率ではない

|尺度|数えていること|今回分ける理由|
|---|---|---|
|方向正解率|将来の特定時点の価格が基準より上か下か|途中の−125先着も、約定できたかも表さない|
|今回の主先着率|仮新規後、期限内に+250へ−125より先に到達した件数/全仮約定|期限未達・観測不足も分母に残る。未約定は別。利益追尾の実返済ではない|
|決着例だけの先着率|+250件数/(+250件数+−125件数)|期限・不足を外した別の条件付き比率で、主率の代用品にしない|
|費用後の実勝率・平均損益|実一建玉の実返済と手数料/追加費用|早い追尾返済により、仮250でも実収益は小さい又は赤字になり得る。成功率だけで期待損益は決まらない|

### 無方向・無費用・無期限の1/3は限定された比較式

公平な等幅ランダムウォークを考える。新規時の損益を0、飛越なし、スプレッド・手数料なし、期限も追尾もなく、+250又は−125のどちらかに必ず達するまで待つ。上端先着確率をpとすると、公平性から次を得る。

~~~text
0 = 250p − 125(1−p)
p = 125/(250+125) = 1/3
~~~

これは公平な賭けの破産確率のn/Tを、n=125、T=375へ写した導出である。「上がる/下がるの方向当てなら50%」を、2倍遠い利益端への先着率へそのまま当てはめない。[MIT教材・20.1節、定理20.1.1](https://ocw.mit.edu/courses/6-042j-mathematics-for-computer-science-spring-2015/mit6_042js15_textbook.pdf)

次はこの基準式からの**数理的な限定・推論**であり、実市場で検証した基準率ではない。

- 有限期限では未到達が残る。同じ基準過程なら「期限内に上端が先」の事象は無期限の上端先着の部分集合で、全仮約定を分母とする率は1/3より低くなり得る。決着例だけの率とは別。
- BBO新規直後は通常、返済側評価がスプレッド分不利になる。初期損益0の仮定が崩れる。手数料だけを後から引く場合は名目の先着事象を変えないが、費用後の期待損益は下がる。既にBBOへ入ったスプレッドを二重控除しない。
- ドリフト、価格飛越、時間変化する値幅、約定遅延、価格時計や観測欠落によっても単純式は変わる。公平性を実際のNKへ仮定して「観測値は正常」と弁護しない。
- 利益追尾を入れた実返済は、+250/−125の二値収益ではない。勝率p、平均利益G、平均損失L、費用cの期待値はpG−(1−p)L−cで評価する。実際のG/Lを固定端の250/125へ置き換えない。

参考として、全件が正確に+250/−125だけで決着し費用が一定c ptなら、損益分岐はp=(125+c)/375。c=12.2ptなら約36.6%だが、これは122円参照を入れた理想二値計算であり、現行追尾の採用基準ではない。70%なら費用前期待値は137.5pt/回で、強い条件付き優位性が必要となる。**この計算で70%目標を変更しない。** 20〜30%台だけで全テクニカルの誤りと断定せず、同時にその水準を収益性の証拠にもしない。

## 多数探索と未見不足を、次の設計でどう扱うか

Baileyらは、金融バックテストの単一hold-outだけでは試行数を扱えず、標本が短い場合や設計者が外標本を既に知る場合にも問題があると論じ、PBO/CSCVを提案している。これは補正方法の研究で、計算すれば利益を保証する手続ではない。ここでは著者版2015年改訂原稿の導入・hold-out論を読み、刊行年2017と区別した。[著者原稿](https://www.davidhbailey.com/dhbpapers/backtest-prob.pdf)、[刊行情報](https://escholarship.org/uc/item/4w1110bb)

以下は文献を踏まえた**未実行の研究設計案**である。

1. 心理・価格文脈を先に置く。背景、発動、無効化、期待する経路を明示し、同じ終値加工の複数表現を独立票と数えない。条件追加前に、その仮説がどんな観測で否定されるかを書く。
2. 見た期間と試した候補を研究全体で記録する。同じ66場で試行番号だけ変えても未見データにはならない。「学習/条件選択/後続」という名称より、結果を知った後に次案を作った履歴が重要になる。
3. 目標の先着率、実運用の費用後平均・総額、回収、取引機会/支持を別々に事前定義する。率が上がって平均が悪化する場合も採用へ結びつけない。多重比較を扱うときは候補単体でなく探索した集合を対象とし、試行履歴が無い部分の補正を厳密に済んだと称さない。
4. 次の未見評価へ進むなら、新案を止めてから時系列の未使用区間を一回評価する。重なる発動や同じ日の取引を独立標本と見なした狭い信頼区間だけに頼らず、日/場の依存、複数期の再現、費用・遅延を含める。少数の後続2場を最終実証にしない。
5. 未見結果を読んで条件を直したら、それは次の開発材料となる。既存の固定試行・不採用・品質注意を保存し、全体確定nullを観測損益で埋めない。新しい指標や時間帯の採用は、この外部調査だけでは決めない。

先物研究には肯定例も不成立例もある。今回の課題は既存の低率を正当化することではなく、心理・市場文脈の仮説と、求める価格経路・約定・回収・未見検証をつなぎ直すことである。
