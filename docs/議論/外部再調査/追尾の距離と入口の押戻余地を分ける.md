# 追尾の距離と入口の押戻余地を分ける

確認日：2026-11-06。外部の無料公開本文を読んだ調査であり、原板・新しい市場系列・教師・モデルを読まず、fit・運用再生・条件探索をしていない。固定54以前のコード・条件・結果は変更しない。

**ストップを通常変動と構造に合わせるという着想はある。しかし、現在費用後正で起動し、最低名目新規床を守る本研究では、追尾幅を広げるだけで起動後の押戻余地が増えるとは限らない。** 必須保護は維持し、その保護と両立する取得位置・価格経路を入口側で調べる。

## 既存調査と今回の追加

[市場心理と価格構造](市場心理と価格構造.md)は支持抵抗・注文集中と心理推測の限界、[定時観測と序盤レンジの隔たり](定時観測と序盤レンジの実装上の隔たり.md)はATR・端からの距離・確認遅延と取得位置、[実務の局面切替](実務の局面切替と定時判断.md)は初回押戻し等を整理済みである。本稿はそれを新発見としない。

今回の追加は、**初期ストップと構造上の否定点、起動後の名目床、返済要求後の執行**を分けること。下の著者記事・論文の出口条件は本研究と異なり、原典の成績を現在の運用へ移さない。

## 現規約を起動前・起動後・要求後に分ける

以下は外部資料の規則ではなく、[本研究の連続追尾条件](../15分判断と連続追尾の研究条件.md)と固定O49を読むための算術である。新規価格E、実方向s、現在正常返済BBOの価格mに対し、r=s(m−E)、保護用最高順行幅h=max(前h,0,r)、新規時固定Dとする。

```text
初期L = max(−125, −D)
更新L = max(前L, −125, h−D)
現在r×10−122 > 0 を観測したら arm=true、以後 L=max(L,0)
r≤L で返済要求 → 後行1価格時計秒以降の正常BBOで返済
```

Dは現方式で最新3分ATRの5pt切上げ・5〜125に制限。起動時刻・最低名目床・損失の連続追尾・非緩和は変更しない。250は固定利確ではない。

|段階|追尾幅Dが効く部分|入口との適合を調べる点|
|---|---|---|
|起動前|初期の−Dと、順行後のh−D。含み損側も新規直後から保護する|構造がまだ壊れていない通常の押戻しより、線が先に触れる配置か。なおh−D>=0なら、arm前でも名目同値以上の線が生じ得る。名目床と利益起動旗は別|
|起動後|Lは少なくとも0。h<Dならh−Dが負なので、名目床が支配しやすい。h>=Dなら利益側のh−Dも効く|起動後に必要な再テストがentry以下へ戻る設計なら、Dだけ広げてもその余地は作れない。過去のLも維持するため、途中で緩めて救済しない|
|返済要求後|保護用h/L/armを凍結し、注文の執行を待つ|後の反発・新しいATRで要求を取り消したことにしない。要求線、要求時BBO、実返済BBOと費用を別記。保護用hと返済待ちを含む実MFEの範囲も分ける|

**人工の算術例**。h=20ptで現在r=20ptなら、粗益200円−122円=78円で利益旗が立つ。D=40でも80でもh−D<0なので最低L=0となる。後にr=0へ戻れば返済要求し、名目同値で約定しても主費用後は−122円。+1秒後にr=−10で約定すれば−222円である。これは実相場の件数ではない。

逆にh=10、D=5ならh−D=5なので、現在r=10の正味益は−22円でarmが偽でもLは正になり得る。**「起動前なら元の広さが必ず残る」「起動後は常に0だけで決まる」の双方が誤り**で、どのmax項が保護線を決めたかを読む必要がある。

## 必須保護を維持した入口の研究案

ここからは未固定・未実行の独自案。まず共通の価格経路候補C0を固定し、Pとして押戻しと保護の適合を少数比較する。建値引上げを遅らせる、床を新規価格より下へ戻す、定時まで損失保護を止める案ではない。

**当時の値と未来の診断を分ける。** 新規判断時はまだ実約定Eを知らない。特徴へ使えるのは当時正常な新規側気配E*（買ask/売bid）、当時確定した構造否定点K、既知ATR等である。+1秒後の実E、起動h、将来のMFEや先着は後段の評価専用とし、入口へ戻さない。

KがLast価格の足から決まる場合、返済BBO線と同じ価格系列ではない。以下の距離は当時の配置の記述であり、両線への到達時計が一致する保証には使わない。

|記録する少数の軸|意味・研究上の問い|反証・限界|
|---|---|---|
|構造否定点までの符号付き距離 d*=s(E*−K) とD|E*を仮の新規価格とする初期線では、0<d*<=Dなら否定点より外側/同値、d*>Dなら構造否定前に触れ得る。d*<=0はKが逆行側に無い別状態|実約定Eによる初期配置は事後に照合する。仮の初期配置だけで、順行に伴う線の引上げ後まで生存を保証しない。Kは共通C0で事前定義し、結果後に近いpivotへ選び直さない|
|当時までに完結した調整幅/ATR、D/ATR、気配差/D|「小さな追尾幅」と「通常の往復に対して小さい保護余地」を分ける。ATR切上げ値が125を超えて上限に切られた旗も別記できる|ATRは通常押戻幅の上限ではない。直前低変動→急拡大もある。将来の終日値幅で分類せず、窓/価格経路の定義を先に一つ固定する|
|調整を消化した再開か、定時までに既に伸びた取得か|同じ方向背景でも、直前の否定点・再テスト帯からの現在距離と発動の古さが、名目床への戻りやすさを説明するか|確認を増やせば常に良いとは限らず、遅延と悪い取得原価で逆効果になり得る。過去の発動価格で約定したことにしない|

最初は上の意味による記述と、共通ready・同じ予定枠/教師を保った小さな比較に留める。採否化する場合も結果で閾値や窓を大量に選ばず、Pの定義を事前固定する。入口が静かな進行だけに偏れば、待ち率が増えて本要件を満たさない可能性も残す。保有継続は非待ちだが、待ち率のために保護違反で保有を延ばさない。

## 評価で混ぜない分母

- 全予定枠の共通準備→純入口→仮約定→実新規/完結を別に残す。保有・pendingの占有が違えば、純subsetでも実参加の包含は保証されない。
- 125/250は同時計・方向の仮先着。将来250へ届いた件数、実保有中MFE250、250判定前の実返済、実費用後損益を分ける。「退出後250だった」だけで、本来その全益を回収できたとはしない。
- 実保有の起動前退出、起動後の名目床による要求、正のh−Dによる要求、要求後の不利約定を分ける。同値費用負け、負の粗益、正の粗益だが費用負けも分ける。0/5/10ptは同じ約定への費用感応で、起動参照122円を感応ごとに変えない。
- 起動後床の影響は、そこまで生き残った事後群である。群の先着率を当初全件と直接比較して床の因果効果としない。品質注意/未解消時の全体確定nullを観測額で埋めない。

## 心理仮説と限界

「取得後もentry付近へ何度も戻るのは、反対注文をまだ消化していないから」「調整後の再開なら戻りが少ない」は、検証したい心理仮説である。価格列だけでは新規/返済、撤退、吸収、stop注文の所在を直接識別できない。ニュース・流動性低下・気配拡大でも同じ往復が起こる。

反証は、当時の構造/通常値幅で適合とした群でも起動後のentry回帰・費用負けが減らないこと、又は減っても未約定/待ちの増加や確認遅延で総合適格を失うこと。外部資料から今の保護規則の収益性を証明したとも、54の結果を見て追尾を緩和すべきと結論したとも扱わない。
