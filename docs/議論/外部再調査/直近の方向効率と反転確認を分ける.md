# 直近の方向効率と反転確認を分ける

確認日：2026-11-06。73の学習前の追加調査。3分5差分や閾値、NK225の先着・回収の有効性を確認した資料ではない。

Kaufman本人の[効率比の説明](https://kaufmansignals.com/matching-the-markets-to-the-strategy/)をPerformance節まで再確認した。`ER=|Σd|/Σ|d|`は、窓内の往復に対する端点変化の比で、変動幅の大小とは別。記事の120日トレンド・市場間比較には小標本と期間依存の留保がある。低ERの平均回帰については直接成績を示さず、トレンド成績から推論している。[既存教材](../../technical-analysis/指標/線形回帰と決定係数.md)の式を、新しい収益根拠として数え直さない。

同じ作者の[High Momentum or Mean Reversion?](https://kaufmansignals.com/high-momentum-or-mean-reversion/)は、株価指数の連続下落後の買いと、UVXYで次の価格条件を確認する売りの例を分ける。成績は非掲載。低効率や直近下落だけでは反転方向が決まらず、対象・背景・次の価格確認が必要という着想として扱う。両記事は日付表示なしの商用実務説明で、査読実証とは区別する。

Baltas・Kosowskiの[2011-12-10会議稿](https://www.efmaefm.org/0efmameetings/efma%20annual%20meetings/2012-Barcelona/papers/EFMA2012_0485_fullpaper.pdf)は12先物で価格経路を用いるトレンド信号と月・週・日尺度を比較する。日次では持続が弱く、短い形成・保有には反転の例がある。30分の原系列を用いていても、場内3分足のERや集中度を検定した研究ではない。第1・2節、信号・回転、第4.4節、結論を確認し、後年の別標本稿の成績を混ぜない。

| 今回の独自観測 | 区別できることと残る問い |
| --- | --- |
| `E=sΣd/TV`、`TV=Σabs(d)>0` | 方向付きの効率。`abs(E)=ER`であり、両者を独立票にしない |
| `C=max(abs(d))/TV` | 一足への集中。同符号ならER=1でもCは異なる |
| `J=s sign(max(d)+min(d))` | 最大絶対差分の向き。正負同値なら既知0 |
| 三列の組合せ | 値動きの順序は保持しない。急進が直近か、急進後に失速したかは価格経路で別に確認する |

高Cでも継続する、低Cでも往復する、低ERでも反転発動がない、という反例を残す。注意・追随・意見対立という市場心理は解釈であり、ニュース・裁定・流動性でも同じ価格列が生まれる。比率だけから心理を確定しない。

試行へ移す際は公開済み足だけを使い、欠足で窓を延長せず、ゼロ分母を0補完しない。新観測を準備できる集合を対照にも要求し、準備落ちによる損失減と観測追加効果を分ける。入口先着、実追尾回収、費用、待ち率を別々に評価する。[前回の連続性と集中](進行の連続性と一足への集中を分ける.md) / [今回の読取記録](../../../work/直近進行の集中と効率/追加外部調査.md)。
