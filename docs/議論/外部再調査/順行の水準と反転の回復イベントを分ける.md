# 順行の水準と反転の回復イベントを分ける

確認日：2026-11-10。[113の結果](../低い利益起動と支持失効だけでは改善しなかった比較.md)を受け、114の入口比較へ持ち帰る資料を確認した。以下の一般説明、心理の仮説、本研究の独自条件を区別する。市場での新しい成績ではない。

Woodらの研究から持ち帰るのは、転換を全履歴から後付けで区切らず、判断時までに観測した情報で扱うこと、速い切替を増やす際は費用も別に確認すること、という設計上の推論である。変化点モデル・LSTM・日次配分は114へ導入しない。論文の成績を114の見込み利益には使わない。

## 心理の仮説を、観測できる条件へ分ける

順行では、平均の配置・進行、価格位置、MACDとsignalの位置が同じ側にあることを、現在の方向が維持されている仮説の材料とする。反転では、遅い平均の配置がまだ逆でも、価格がfast線の逆側から順側へ移り、fast線自体の進行と勢いの増分が回復するイベントを候補にする。買いは下からの回復、売りは上からの失敗を同じ符号式で扱う。

この説明は、売買主体・買戻し・損切り・吸収を実測した結論ではない。MAとMACDは重なる価格履歴から作るため、二つの条件が揃っても独立した二票として確率を掛け合わせない。価格の奪還も、過去の支持抵抗全体の回復や持続的な転換完了とは呼ばない。

## 114で固定前に決めた役割

共通のP100保護・元Source数量・連続通知を保ち、A0は元出生をそのまま受け、Tは平均配置/二傾き/Close位置/Hist水準、TRはT又は逆配置からの価格奪還/fast傾き/Hist増分で選別する。TのHist水準を要求しない旧案は採用せず、実装前に変更した。数値を見て後から追加した条件ではない。

T/Rとも現在の値と前の値、公表時刻、実配送原行を保存する。履歴不足と既知の不成立を分け、Unknownを勝手に分母から落とさない。入口が通った後の約定までに新しい公表が来ても、当初の判断を未来値で置き換えない。追加保護をSourceへ返さない比較モデル、ラージBBOによるmini代理約定という限界を残す。
