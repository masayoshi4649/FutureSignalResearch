## これまで心理をどう扱い、何が足りなかったか

[試行52](../../../study/00052_定時判断へ価格履歴を追加/README.md)では、OR端への最大10本3分の内外切替を独自の履歴特徴として追加した。共通準備の対照を置いたが、追加列は分岐へ選ばれず成績は同値だった。[履歴追加の比較](../定時の価格履歴を追加しても分岐が変わらなかった比較.md)へ限定と次の問いを残す。原典の用語をそのまま機械条件の成功根拠にはしない。

[試行53](../../../study/00053_局所帯の反応で先に分岐/README.md)では、直前の帯と反応期間を分け、反応旗を最初の分岐へ固定した。分岐は変わったが先着・活動・費用は未達だった。[局所帯の比較](../局所帯の反応で分岐を固定した比較.md)では、異なる価格経路を一旗にまとめる限界、指標分類と情報の重複、学習後の技法資格による見送りを次の調査へ戻す。

[試行54](../../../study/00054_方向と局所帯を先に分岐/README.md)では、候補とDIの同向/逆向も必須の分岐へ置いた。反転を採用できる構造になったが、反転確認や利益の根拠とはならず、目標は未達だった。[方向と価格反応の比較](../方向と価格反応を先に分けた比較.md)で、逆向きの配置・価格の遷移・同一新規の先着と実回収を分け、次の価格経路の調査へ接続する。

既存の[市場心理の教材](../../technical-analysis/市場心理/README.md)には、参照価格、損失回避、追随、買い戻し等と出典がある。したがって、心理資料を一切見ていなかったわけではない。

一方、最近の検証は、指標と価格端を定義し、条件を追加・切替して全件照合する作業が中心になっていた。計算が定義どおりであることは検査できても、その定義が心理的な売買機会を適切に表現する保証にはならない。心理の説明が教材に存在することと、それが入口を選ぶ理由として検証されていることは別である。

今回の見直しは、既存文献を新発見として並べ直すことではない。本文まで戻り、どんな注文・参加者・価格反応が実際の根拠だったかを確認し、こちらのモデルが省略した文脈を洗い出す。

|何を成功と数えるか|方向、250先着、実際の利確を同じ勝率にする|同じ要求時計/執行/費用で、先着・実回収・品質・活動頻度を別に比べる|

「指標を使わない」という変更ではない。複数手法の使用は引き続き必須とする。まず仮説と場所を定め、指標をその背景・発動・反証・リスクのどの役割に使うかを説明する。

## 外部資料から得た優先候補

以下は未固定・未検証の調査候補であり、新しい成功手法ではない。旧試行の名前替えになっていないかも確認する。

### 1. 同じ既知帯で、突破の継続と失敗を区別する

優先する問いは、「元の方向が良い/悪い」より、到達先の帯で何が起きたかである。

- 順行仮説：帯外へ進んだ後も、再接近で元の帯へ押し戻されず、再開する。
- 反転仮説：帯外を試した後に内側へ戻され、再突破も失敗する。
- 待機：反応が不明、価格の往復が多い、対向帯や通常変動との関係から固定125/250の前提を説明できない。

価格反応を主条件にし、上位構造・勢い・変動幅・量で異なる問いを確認する。過去高安やラウンド価格に必ず注文があるとは仮定せず、先物での反応を検査する。心理は「誰かが狩った」と断言する材料にしない。

### 2. 単純な調整と、再開失敗を含む調整を分ける

最初の反対波だけでトレンド終了とせず、一回目の再開が失敗しても長めの構造が保たれている場合を区別する。逆に、長めの構造が破れた後の最初の調整は、元トレンド内の押し戻りと別の候補にする。確定を待つほど入口が遅れるので、心理的な物語だけで後続確認を増やさない。

### 3. 時間帯を単なる集計区分から、参加の文脈へ戻す

日中と夜間、寄付近辺、他市場の開始、引け近辺で同じ形の意味が違う可能性を調べる。研究で示された他市場・他時代の時刻を、そのままNK225の現在の時間割へ移さない。外部市場を参照するなら、その値の当時利用可能性と、追加データの必要性を先に決める。
