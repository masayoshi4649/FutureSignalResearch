# 利益保護と相場の持続性を分ける

確認日：2026-11-10。一次資料の再読と、次に検証する問いの整理である。115の金融条件・凍結コードは変更せず、金融Native・原板・市場CSV本文は読んでいない。下記の115集計はRootから共有された元54場の途中集計で、全70場の結論や個別退出の原因診断とは区別する。

**保護を付ければ期待利益とDDが両方改善する、とは限らない。** 逆行が続く場面から退出する効果、通常の押戻しで退出する効果、費用と執行の効果を分ける。必須の利益保護は維持し、その前提で入口と保有中の状態を組み合わせる。

## 既存調査との差

[狭い保護と再参加の費用](狭い保護と再参加の費用を分ける.md)はKaminski・Lo（2014）、Lo・Remorov（2017）、Fan・Zhang（2024）を確認済み。[追尾距離](追尾の距離と入口の押戻余地を分ける.md)はLeung・Zhangを、[候補の否定と反対方向の成立](候補の否定と反対方向の成立を分ける.md)はGlynn・Iglehartを既に読んでいる。これらを今回の新発見として数え直さない。

今回はKaminski・Lo刊行版を再取得し、既読版と同じSHA256であることを確認した。Glynn・Iglehartの画像PDFも該当頁を再読した。追加はLeung・Li（2015）の著者公開本文と、**収益の持続性／価格水準の平均回帰、価格の刻み／最初の到達、費用控除／費用を参照する退出**の区別である。

Kaminski・Loの退避は、損失の後にも同方向の収益が続く条件で役立ち得る。一方、利益追尾を細かくすれば、元方向が続く途中の押戻しでも終了し得る。**「持続性があるから狭い追尾が有利」「トレンドがあるから保護不要」のどちらも、この論文からは導けない。** MAの同方向配置も、論文の条件付き収益や自己相関を測った値とは異なる。

また、Kaminski・Loの「平均回帰」は**収益のAR(1)負自己相関**、Leung・Liは**価格水準のOU平均回帰**である。対象変数・入口・停止・再参加・目的関数が違う。平均回帰という名前だけで、反転戦略にはストップが必ず有害、と一般化しない。115のT/Rも独自の入口票であり、これらの確率過程を識別した分類ではない。

## 期待利益・保護線・DDは別の量

Kaminski・Loは期待収益が増減する条件と分散の変化を分けている。**変動性の低下は最大DDの低下と同義ではない。** 一玉の床が守る範囲、複数玉の実現収支、費用後資産曲線の山から谷へのDDを別記する。小損が続けば資産曲線のDDは蓄積する。正常気配の観測間、要求から約定までの値動きも、理想的な連続価格の線では抑えられない。

したがって次の比較では、成立した取引の純額・利益総額と損失総額・回数・利益経験後赤字率・起動後赤字・保存点の連結時価DDを併記する。未保存時点を含む連続DDを証明したとはしない。正益経験玉が少なくなっただけで赤字件数が減った場合と、正益経験玉を分母にした赤字率が改善した場合も区別する。未参加・退出後の仮想利益は評価しない。

## 費用と小さな境界差で退出が変わる仕組み

**一般仕様。** 日経225miniは5円刻み・1ptにつき1枚100円、分析用ラージは10円刻みである。価格系列の刻みも同一とは限らない。[JPX商品概要](https://www.jpx.co.jp/derivatives/products/domestic/225mini/)で確認した。[CME注文解説](https://www.cmegroup.com/education/courses/things-to-know-before-trading-cme-futures/futures-order-types)も発動条件と実行可能価格を分ける。CMEの注文方式をOSEの仕様や本研究の注文実装と同一視しない。

**本研究のコード上の算術。** P113/P100の純演算では、方向を揃えた返済側気配からの価格差をg、既返済分の純額をR、現在残枚数をnとすると、全玉費用後評価は次になる。

```text
W = R + n × (100 × g − K)
K = 77 + 200 × S 円／枚
S = 片道想定滑りpt（C0は0、C5は5）
```

費用は、同じ約定列から最後に引く場合と、Wを参照する起動・床・要求を変える場合がある。P100は後者も含む。C0→C5は同じR・n・気配でも未返済1枚の評価を1,000円変えるため、起動行や床の選択が変わり得る。部分返済後は実Rと現在nを使う。これは純演算の性質であり、115の特定の玉で起きた原因を確認したものではない。[純保護の定義・再現資料](../../../study/00113_起動前の支持否定と利益保護の切替/README.md)も参照する。

**人工例。** 通常幅の `5×ceil(max(200,2A)/5)` は、A=100で200、A=100.01で205になる。これは丸めの境界を示すだけで、新しいATR設定ではない。他の床が支配すれば退出は変わらない。一般の追尾でも、方向を揃えた価格差が0→20→15と進んだとき、最高値から5ptの線は15で到達、10ptの線はまだ未到達となる。後の価格や仮想損益を補わなくても、最初の到達行が違うことは分かる。

微小差が常に大差になるわけではない。しかし、切上げ・同値を含む比較・起動ラッチ・床の非緩和・予約と部分約定があるため、入力差と最終損益差が滑らかに比例するとは限らない。一般仕様と離散モデルを本実装へ接続した**設計上の推論**であり、論文が115の感度を実証したという意味ではない。

## 次の検証へ残す問い

1. **まず退出差の事実を分類する。** 同じ実入口を対応付け、起動／床更新／最初の要求／Source予約／実返済行と価格／配賦純額を照合する。建玉数・枚数の一致だけで同入口とはしない。異なる取得も別に残す。
2. **入口の持続性と出口の都合を分離する。** 三時間軸の背景・勢い・局所構造が、成立した取引の損益や利益後赤字にどう対応したかを調べる。勝った後に相場状態の名前を付け、その名前を当時判別できたと主張しない。
3. **感度を検証するなら別の事前固定比較にする。** 費用・1呼値・幅の切上げ境界に対して、売買の変更件数と支配項を記録する。今回の304,000円残差に合う幅を探索しない。再参加を変えるならSource据置の出口比較とは別試行にする。

この調査は新しい金融候補の採用、条件変更、市場再生を行っていない。115の固定条件・必須P100・連続判断時計を維持する。
