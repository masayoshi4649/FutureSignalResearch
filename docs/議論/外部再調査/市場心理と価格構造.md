# 市場心理と価格構造：注文の機序から検証する

一次資料確認日：2026-11-06。状態は外部再調査であり、新しい売買条件の固定・実装・市場計算ではない。48の結果・先着・実取引・損益は未閲覧、凍結コードは不変。新raw/cacheを開かず、未予約11/5Dayも未読のまま保持する。

## 今回変える視点

**指標がいくつ同方向かより先に、どの参加者の、どの制約・参照価格・注文行動が、その水準での反応を生むと考えるかを定める。** 次に、今の資料でその行動を直接観測できるのか、価格反応だけを代用するのかを分ける。最後に他系統の技術情報が反応の判別を改善するかを問う。心理を述べるだけで支持抵抗や勝率の根拠を得たことにはしない。

Osler、Loら、Odeanは新発見ではない。[既存の参考資料](../../参考資料.md)、[参照価格と損失回避](../../technical-analysis/市場心理/参照価格と損失回避.md)、[追随と買い戻し](../../technical-analysis/市場心理/追随と買い戻し.md)に既に収録していた。旧文書にも心理の推測と実測の区別はある。今回の不足は文献の有無ではなく、その区別を水準の選び方、候補の採否、比較・反証条件へ十分に結び付けられていたかである。本稿では原典本文の標本・版・識別の限界まで再点検する。

## 2. 支持抵抗とストップ連鎖：Osler本文の再点検

### 公表水準の反応を検定した研究

Osler（2000）は、事後のチャートから選んだ成功線ではなく、6社が日々配信した支持抵抗を検定した。任意水準より日中のトレンド中断を予測したが、効果は会社・通貨で異なり、配信者の「強い水準」という格付けも反応頻度に一貫対応しなかった。反応の情報と、強さの説明を分ける必要がある。[NYFed原文・冒頭と結論](https://www.newyorkfed.org/medialibrary/media/research/epr/00v06n2/0007osle.html)

本研究へ持ち込むべき点は、線の名称ではなく**水準を反応より前に定め、同じ状況にある対照水準と比較する手順**である。公表済み水準の検定を、任意の足の高安にもそのまま成り立つ証明へ広げない。

### 注文型によって反応の向きが変わる

SR125は、銀行の条件注文で利食いとストップの指定価格に異なる集中を見つけ、節目での反転と突破後の進行を説明する。公開PDFの注文期間は1999年9月1日〜2000年4月11日で、当該銀行・通貨の資料である。情報監視コストや制度的リスク管理も条件注文の利用理由として論じる。[NYFed SR125本文・データと第I節](https://www.newyorkfed.org/medialibrary/media/research/staff_reports/sr125.pdf)

重要なのは「丸い価格なら反転」という単一則ではない。同じ水準付近でも、逆方向の注文を出す利食い型の負フィードバックと、突破方向へ出すストップ型の正フィードバックが競合し得る。心理を強気/弱気の一語へまとめず、**接近時と突破後、注文型と執行方向を分ける**機序として読む。

### 価格カスケードは何を実証したか

SR150は、ストップが集中する型の水準を越えた後の進行が、利食い型の反応より大きく持続する証拠を示す。持続は主に時間単位で、日単位の普遍則ではない。著者自身が、統計から因果を証明できず、ストップを急変の唯一又は主たる原因とも主張しないと限定している。[NYFed SR150本文・冒頭、第I節、第IV節](https://www.newyorkfed.org/medialibrary/media/research/staff_reports/sr150.pdf)

**版と別標本の注意。** SR125のサイト掲載年月は2001年4月、PDF表紙は3月。SR150のサイトは2002年7月、PDF表紙は6月である。SR150の注文資料は1999年8月1日〜2000年4月11日の9,655件だが、価格検定は1996年1月〜1998年4月のReuters分次気配である。SR125の公開PDFとは期間表記も異なる。両者を「同じ9,655件の発動と同時価格を全件照合した実験」と合成しない。[SR125書誌](https://www.newyorkfed.org/research/staff_reports/sr125.html)、[SR150書誌](https://www.newyorkfed.org/research/staff_reports/sr150.html)

### 心理の読み過ぎを防ぐ

条件注文の利用には、損失への感情だけでなく、監視の委託、執行遅延、保有制限、リスク管理が関わる。SR125の注文分類も、既存建玉の実損益を必ず識別するものではない。したがって「ストップ狩りで恐怖が連鎖した」「全員が同値逃げした」という個別原因は、価格反応だけでは確定しない。ここでの心理仮説は、制度や執行規則を含む行動機序である。

## 3. 心理・統計・注文計測を混同しないための補助資料

### 形状に情報があることと、心理原因が分かること

Lo・Mamaysky・Wangは、カーネル回帰による形状認識を使い、複数形状に条件付けた米株日次リターンの分布に追加情報を検定する。機械的定義で主観性を抑える設計が参考になる。注文や投資家の心理を直接観測した研究ではない。[著者公開論文](https://www.mit.edu/~wangj/pap/LoMamayskyWang00.pdf)、[NBER書誌](https://www.nber.org/papers/w7613)

分布の差は、現在の125/250先着率、費用後収益、最良気配で実行可能な入口の差と別の命題である。形を検出した時点を未来の極値へ描き戻さず、心理の説明がなくても価格情報として検定できるものと、心理原因を識別したものを区別する。

### 利益を実現しやすい行動の実測

Odeanは、1万口座の取引記録で利益の実現が損失の実現より選ばれやすいことを報告し、複数の代替説明を点検した。これは口座の取得価格と売却選択を用いた行動の証拠である。[著者公開論文・要旨とデータ](https://faculty.haas.berkeley.edu/odean/papers%20current%20versions/areinvestorsreluctant.pdf)

NK225の価格帯・VWAPに再接近した人が誰で、まだ建玉を持つかは現在の8列では分からない。残存建玉の平均取得価格と、累積約定を加重したVWAPも同一ではない。この研究を背景に「戻り売り」を考えることと、その戻り売りを手元で実測したことを分ける。

### 継続から反転へ変わる機序のモデル

Hong・Steinは、情報を徐々に受け取る主体と、過去の価格へ追随する主体の相互作用から、初期の継続と後の過剰反応を説明する理論を示す。単純な追随では初期/後期を見分けにくい点が重要である。[著者ページと公開本文](https://stein.scholars.harvard.edu/publications/unified-theory-underreaction-momentum-trading-and-overreaction-asset-markets)

これは「強いMACDなら初期」「高RSIなら後期」と決める根拠ではない。同じ値を新情報への反応と追随の自己増幅が生む可能性がある。ニュース時刻、価格反応の起点、既に進んだ経路など、指標値と別の手掛かりを要するという研究上の問いへつなぐ。原論文が背景とする月〜年の現象を、日中数分へそのまま縮尺変換しない。

### 量から需給を読むなら、何を測るか

Contらは、最良気配の価格・数量の更新による注文フロー不均衡と短時間の価格変化を調べ、単なる約定量との関係より頑健な関係を報告する。著者稿の標本は2010年4月の米株50銘柄、主集計10秒である。[著者稿・書誌](https://arxiv.org/abs/1011.6402)、[本文第3節](https://arxiv.org/pdf/1011.6402)

現在の8列cacheには最良気配の数量更新列がないため、同じ指標は再現できない。終値差×量、CLV×量、上昇足/下落足の量は異なる要約で、注文追加・取消や攻撃側売買を識別したとは呼ばない。また、同一区間の価格変化を説明する関係は、そのまま次区間の予測精度ではない。原payloadに必要項目があるかは別の入力監査の問いであり、今回は新rawを開いていない。

## 4. 任意のForce足高安と、共有され得る水準の違い

|水準|当時分かること|心理・注文集中について残る不明点|
|---|---|---|
|条件注文の指定価格分布|当該注文を保有する資料なら、どの注文型がどこに置かれたか|その銀行以外の注文、取消後の残存、同じ注文と価格反応の因果|
|事前公表の支持抵抗、明瞭な過去pivot、高安、丸い価格|反応より前に定義でき、他の参加者も参照し得る|実際に何人が参照し、どの注文が残るか。共有の程度自体が仮説|
|研究者が選んだ窓の最大最小|その窓内の極値という価格上の事実|窓や足幅を他の参加者も選んだか|
|Force交差足の高安、任意の指標発動足の端|当該仮説の失効・確認を定義する内部のリスク水準|市場の注文集中水準である根拠は別に必要|

47/48の足端には、仮説の失効/確認線として明確な機械上の意味がある。そのことだけでOslerの注文集中水準と同じ意味を持つわけではない。他方、24/26の高位高安や45の確認pivotにも既存の構造定義があるので、構造を今回初めて導入したとも呼ばない。次に測る差は、**どの水準を、いつ、なぜ市場参加者の参照候補としたか**である。

CMEの教育資料は過去高安・節目等を支持抵抗として説明する。Grimes本人は、単純/複雑な押し戻り、既存pivotのfailure test、方向転換のshock後の初回押し戻りを構造として区別する。これらは実務の着想・用語として有用だが、ここで確認したページにNK225の外標本損益や注文集中の直接検定は無い。[CME公式教育](https://www.cmegroup.com/education/courses/technical-analysis/support-and-resistance)、[Grimes本人の解説](https://www.adamhgrimes.com/fundamental-trading-patterns/)

## 5. 先に立てる観測と反証の問い

以下は新算法の条件表ではない。価格水準・時間幅・測定区間を事前固定する前に、何を確認すれば心理の説明を一段進められるかを整理したもの。

|心理/注文の仮説|観測候補|反証又は識別不能となる条件|
|---|---|---|
|参照候補の水準へ逆方向の注文が集まり、接近を止める|事前固定水準の初接近後の拒絶、足内/足後の価格進行、反対側への回復。可能なら数量更新・取消も別測定|同じ時刻帯/直前値幅/接近距離の対照水準と反応差がない。線を事後選択したときだけ差が出る|
|水準突破に正フィードバックが加わり、進行が続く|水準前後の移動速度・値幅・その後の保持/再テストを、通常水準と比較|一時突出しかなく追随可能な進行がない。価格反応はあっても遅延/スプレッド/費用後の利益がない|
|新しい方向への初期反応と、進行後の遅い追随は異なる|当時確定した構造変化/急変の起点、初回押し戻りと後続試行、その前に既に進んだ経路|起点を後知恵で置き直す必要がある。同条件の初回/後続で差が再現しない。ニュースや流動性で区別できない|

「出来高が大きく進まないから吸収」「突破で急進したからストップ連鎖」は、いずれも代替説明を持つ。ニュース、新しい裁定/ヘッジ、気配の取消、低流動性でも似た価格列になる。価格・観測量だけの段階では、拒絶/進行という**価格反応の型**を記述し、真の吸収・買戻し・新規参入を実測した呼称へ昇格させない。

対照には、事前に定めたずらした水準や、時間帯・直前変動幅等をそろえた到達事例を検討する。全く到達しない水準を対照へ大量に入れるなど、到達頻度の差を反応の優位と取り違えない。成功した線・shock・本数を結果後に選ばない。指標の確認を加えるなら、同じ水準/イベント上で追加情報を測り、共有され得る水準そのものの効果と混ぜない。

拒絶/定着を後の価格で確認してから入る場合は、その確認時計後の新約定から評価する。接触時の事後反応を、接触時点に既知だった入口条件へ戻さない。pivotも中心足でなく確認時点から利用する。同一水準・同日の繰返し接近を独立標本として過大計上せず、日/場/水準単位の依存と支持を点検する。

## 6. 既存の説明から、検証設計へ変える点

|これまでの説明が留まり得た段階|次に必要な変更|
|---|---|
|「価格が戻るので買い戻しが起きた可能性」|新規/返済を観測できるか明示する。無ければ回復という価格事実にとどめる|
|「Force/CMF/RSIが改善したので心理が改善」|計算で確定する内容と、注文・感情についての推測を別列にする|
|「高安を越えたのでストップが集中」|水準を反応前に選ぶ理由、集中の直接根拠、対照水準を置く|
|「確認条件が多いほど強い」|同じ価格由来の重複を数えず、何を新たに識別するかを一つずつ問う|
|「全状態監査が一致したので仮説も正しい」|監査は実装/時点/価格/会計の一致を保証する。心理の因果や収益の有効性は別に検定する|

既存の市場心理教材を否定して書き直す作業ではない。その注意を、新候補の出発点と母集団の選択に反映する。特に、指標発動後に心理の物語を添える順序から、行動機序→参照水準→価格反応→他情報の判別、へ変える。

## 7. 次の判断に残す条件

- 先に「水準の意味」「反応の開始時計」「直接観測と代理」「競合する原因」を短い仮説カードへまとめる。新しい指標数や有名な名称から算法を決めない。
- 原データの受信時刻/共通序列、数量の整合、追加の気配数量/約定分類が必要なら、予約と入力監査を別途先行する。現在の価格時計を実受信・実注文の時計へ読み替えない。
- 売買は符号対称に定義する。丸い価格格子を用いる場合、価格反射の軸と格子の関係まで確認し、片側だけ都合のよい節目を選ばない。
- 仮先着と実回収、心理/価格反応の検定と経済性を分ける。現在のXFは手数料・想定滑り控除後の現在含み益がstrict正（現前提122円控除）で起動し、最低名目entry床・非緩和を維持する。ストップ連鎖を説明に使いながら、自分だけ無遅延・無滑り約定と仮定しない。
- 全66場は既使用の開発集合で、再調査によって未見へ戻らない。支持基準・費用・品質・未解消の扱いを後から緩めず、未予約11/5Dayをこの文献選択へ使用しない。

今回の成果は、既存文献の概要再掲ではなく、注文の実測と心理の推測、別標本の価格検定、実務パターン、手元の観測可能性を接続し直した点にある。新条件・試行番号・入力取得・相場計算には進めていない。

損益、費用、外標本、多数探索と先着尺度の外部実証は、同時調査の[実証と評価尺度](実証と評価尺度.md)へ接続する。価格反応の情報、心理機序、費用後に採用できる運用は、それぞれ別の問いとして評価する。
