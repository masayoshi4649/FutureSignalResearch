# 押戻しの深さと先行波の文脈を分ける

確認日：2026-11-06。59と並行し、既読のGrimes本人の手法説明を具体的な先物図例で深掘りした。新しい独立研究が二つ一致したという意味ではない。

## 本人資料で確認したこと

[Context in Pullbacks: What Should Happen?](https://www.adamhgrimes.com/context-in-pullbacks-what-should-happen/)（2023-11-29）は、押戻しの大きさ・速さとともに、その前の進行を評価する。強い進行でも伸び切りなら注意し、上位足の調整や既に大きく進んだ波との関係を見る。浅い・遅いという一条件だけの優位性を示す説明ではない。

[Selective Intraday Trades](https://www.adamhgrimes.com/selective-intraday-trades-a-deep-dive-into-the-snap-pullback/)（2023-10-06）は、旧方向の不調、強い逆方向の進行、弱い戻り、その後の価格発動という順序を説明する。逆方向の鋭い進行は、単に悪い押戻しではなく転換を疑う文脈にもなる。

どちらもS&P先物の本人図例を伴う実務説明である。全件母数・費用後の未見成績や、NK225の250/125先着を検証した資料ではない。参加者が退出するという説明は心理の推論であり、注文動機の直接測定ではない。

## 機械へ移す問い

| 比較する差 | 観測候補 | 混同しないもの |
| --- | --- | --- |
| 同じ上位方向でも押戻し方が違う | 登録以後の深さ、現在までの戻り、平均進行、保持端からの距離 | 一足の減速と登録以後全体の平均、確認後だけの進行 |
| 強い先行進行と伸び切り | 先行波の幅・速度・上位足との関係 | 大きい指標値だけで継続や反転を断定しない |
| 旧方向の調整か反対側への転換か | 否定点の破断・再取得と、その後の逆方向進行・戻り・再開 | 旧方向が弱まったことと反対方向の入口成立 |
| 形を確認しても値幅が残るか | 当時の判断価格と既知の価格構造、遅延後の実取得価格 | 過去の極値を約定価格として使わない |

表は独自の検証候補で、資料の条件を完全再現したものではない。方向・勢い・値幅・価格構造を組み合わせ、先着・実回収・待ちを別に評価する。数量補助や上位足との整合まで一度に変更すると差の理由を分けにくいため、比較ごとに変更点を固定する。

[59の計画](../../../study/00059_保持水準への深さと速度/検証計画.md)では、旧30特徴へ登録後の4値をT/R別に追加する。同じ登録bから判断までの平均速度であって、先行波全体や押戻し区間だけの速度を測るものではない。今回の情報追加で全ての文脈を表したとはしない。支持・出口・費用は旧58のまま、未登録・取消・反応なしも分母へ残す。
