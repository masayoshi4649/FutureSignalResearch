# 未発動と参加後の不進行を分ける

確認日：2026-11-06。**構想が外れたこと、価格発動がなかったこと、参加後に進まなかったことは別である。** 確認を増やすほど有利とも、値幅を使ったら必ず反転するとも結論しない。固定した[試行62の計画](../../../study/00062_方向に対応する再開確認を先に分ける/検証計画.md)は変更せず、次候補への未検証の論点として整理する。

## 将来の局面と心理を入力へ混ぜない

Daniel / Moskowitzは将来の市場感応度を用いた補正が実装不能なバイアスとなる点も指摘する。後から分かった反発局面、最終極値、損失期間を、過去の入口を分類する正解入力へ変えない。当時までの下落や変動幅を候補にすることと、未来の「反発局面」を既知として学習へ渡すことは異なる。原典の条件を移植する提案も今回は採用していない。

「先行参加者の利確で止まる」「反対建玉が踏まれて再開する」「強い背景へ逆らう参加者が不利になる」は心理仮説である。価格図やリターンだけでは、新規・返済・注文集中・参加者の確信を直接特定できない。ニュース、流動性、リスク負担の変化も競合説明として残す。

次に調べるなら、未発動／発動後も有効／否定／期限失効と、発動から現在までの遅れ・値幅を分ける。売買反射、15分判断、現在費用122円strict正での利益起動・連続追尾、支持と全予定枠の分母を維持する。悪い結果だけを事後に「遅い」「伸び切り」「局面不適合」と命名せず、既使用66場を未見と呼ばない。新しい閾値、NKの先着70%、費用後利益の根拠は、この調査だけでは得られていない。
