# 短い保有で価格と注文フローの失効を確認する

確認日：2026-11-08、追加確認2026-11-09。一次資料から、短い保有中の価格・数量・勢いの更新を考える研究知見である。一般説明、他市場の実証、心理仮説、独自の未採用案を分ける。本記事の調査・整理では具体閾値の固定、新方式の実行、正式試行の追加は行っていない。

関連する実現成績は[試行100の結果正本](../../../study/00100_費用後利益化の前後で保護を分ける/成果物/結果.json)を参照する。別の保有時計の補助診断は、P0のViewer実約定と結果の保有枠だけから保有時間を調べたもので、個別Nativeを読まず、Source・返済理由・利益起動時刻は全玉未知とした。本記事はその中央値を新たな数値根拠として転載せず、特定玉の退出原因や改善効果も推定しない。以下の差分は、分足が更新しない保有中に、何を背景として固定し、何を価格・板の更新トリガーにするかである。

## 未検証の退出候補は二つだけ

**案A：価格線の喪失＋反対の量と短秒進行。** 入口前までに公開され、選択規則を固定した線Lを使う。買い/売りをs=+1/−1で同式にし、Lの保有方向側から逆側へ現在価格が移り、現在の符号付き量支持が反対、短秒価格変化も反対になったときだけ追加退出を検討する。片側のスプレッド拡大だけを構造否定にしない観測方法が必要。Lの種類、気配のどちらを判定に使うか、等号、量/進行の窓、品質と持続条件は未固定。RSI水準やEMA一本だけで返済しない。

**案B：喪失後の回復失敗＋反対量の再確認。** 同じLについて、喪失t1→回復を試したt2→回復を維持できず逆進行したt3を、実保有中の公開観測だけで順に確認する。t3で反対量も既知なら追加退出を検討する。未来の高安/pivotをt1へ遡って置かず、二つの時点が同じ古いOFIを参照するだけなら再確認に数えない。案Aより確認が遅れるため、通常の押しと否定を区別できても実損失やDDが増える反証がある。追加退出より既存の床/Source返済が先なら予約を優先し、二重返済しない。

**心理仮説：** 価格線を割るだけなら提示の一時的な変化かもしれないが、回復が維持されず反対量と逆進行が重なれば、元方向へ価格を維持する働きが弱まった可能性がある。ただし同じ観測は補充・取消・通常の調整でも生じ、投資家の意図を観測した説明ではない。退出は新しい逆方向エントリーの成立を意味せず、Source Sideや返済通知を反転して流用しない。

## 現在の保存欄からできること／できないこと

[固定Tapeの公開型](../../../scripts/固定通知と価格行の再生/tape.go)のScalar11には当原行の価格時計・BBO・公開ATR5があるが、各原行のOFI/E08・短秒特徴・数量内訳はない。5分gridのCurrentを次の5分まで据え置いて「現在」として連続退出に使えない。したがって現Tapeだけでできるのは、既存5分枠での低頻度な追加退出案又は価格のみの経路観測までであり、**秒内の複合退出を検証済みとはできない**。

案A/Bを連続で比較するなら、将来は当原行の価格/量/短秒のKnown、Time/Received、物理行、特徴連番、線Lの値/出典/出生時刻と各遷移を専用sidecarへ保存し、元Sourceへ返さない入力拡張が必要になる。数量更新がない時間とデータ不良を分け、Quote連番とFeatures連番を同一と仮定しない。未知なら追加退出の根拠は不足とし、元の義務の床とSource返済を継続する。

次の問いは、固定した共通入口・量・費用・遅延の下で、各方式の実現正額/負額/純額、u正益前後の最終赤字、DD、回数を改善できるか。上位背景が同じでも、価格喪失と反対量の交差が区別に使えないなら仮説を棄却する。保有終了後の値動き、未参加の仮想利益、回収率は採点しない。この外部調査と正式整理では、新しい日・原板・Native本文の読取、市場再生・パラメータ探索はすべて0である。

## 指数先物の追加資料と、背景・発動の区別

同日追加確認：[Hu・ZhangのCSI300指数先物の著者プレプリント](https://arxiv.org/html/2505.17388v1)（2025-05-23、§2.1.1・3.1・4〜6）。500msスナップショットを使い、OFIへ組み合わせる指標の効果が予測地平によって異なり、指標の記憶も月ごとに変わると報告する。§3.1のPnLは、予測符号で分けた将来Mid変化の仮想合計であり、NK225の費用後約定収支の証拠には使わない。板深さ・分散等の検証も残されている。

ここからの推論は、短秒の失速を長い確定足の反対化と同一視せず、窓と組合せを別に検証すること。5秒・15秒が最適、量の符号だけで退出すべき、という根拠にはならない。[CMEの取引計画教材](https://www.cmegroup.com/education/courses/building-a-trade-plan/trading-strategies-in-your-trade-plan)も、取引する背景条件と具体的な発動点、保有管理・退出を分けて記述している。

ローカルの[5分退出の補助診断](../5分の退出条件と短い保有の時間を分ける.md)を受け、確定足を背景、当時の短秒進行と現在量を発動候補へ分ける別案を準備する。これらの外部資料を、その別案の収益改善や事前に判別できるレジーム切替の実証とは扱わない。

## 量の偏りと価格の応答を区別する追加資料

2026-11-09確認：[Gould・Bonartの著者稿](https://arxiv.org/abs/1512.03492)（2015年、§4・6–8）は、Nasdaqの10銘柄で最良Bid/Askの表示数量比と次のMid変化の方向を調べる。標本外分類の改善は呼値・スプレッドの構造で異なる。静的な数量比はOFI30やE08四量差とは別であり、次の一変化の分類を5秒/15秒の費用後退出成績へ置き換えない。

[Lillo・Farmerの著者稿v2](https://arxiv.org/abs/cond-mat/0311053v2)（2004年、§III・VI）は、LSEの注文符号に持続性があっても、取引数量と流動性の変動が価格への作用を相殺する関係を報告する。取引費用の詳細推定や退出戦略の実証ではなく、数量と流動性のどちらが主因かも確定していない。

ここからの研究上の問いは、**量が同方向なのに価格が進まない状態**と、**量も価格も反対になった状態**を区別できるか、である。前者を特定主体の「吸収」や反転確定と呼ばず、後者も実際の返済要求・約定・費用後損益で検証する。両論文は株式市場の資料であり、NK225への移植やS5Q/S515Qの窓・閾値を直接支持しない。市場心理は流動性供給と即時執行の相互作用を考える仮説とし、参加者の意図を断定しない。
