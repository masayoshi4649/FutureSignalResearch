# 実務の局面切替と定時判断

確認日：2026-11-06。[再調査の目次](README.md) / [15分判断と連続追尾の研究条件](../15分判断と連続追尾の研究条件.md)。実務家本人の無料公開資料から、順行・反転・待機を切り替える根拠と限界を調べた。販売教材の購入、転載書籍の取得、新しい算法の採用・実装・市場計算は行っていない。48以前の正式条件・結果・報告は変更しない。

**使える着想は、同じ価格の動きでも「どこで、何を期待した後に、何が失敗したか」で扱いを変えること。ただし、裁量的な実例を15分定時・一建玉・固定125/250・連続追尾へ移すと、別の方針になる。今回確認した資料は、その方針の収益や待ち率50%以下を実証していない。**

## 既存のGrimes/Brooks調査に付け加わる点

[既存の実務家調査](実務家の局面認識と心理仮説.md)は、Grimesの単純/複雑押し戻り・突破失敗・転換後の初押し戻りを区別した。Raschkeの失敗後の見方変更とHougaardの反対価格端の確認は、**撤退の判断、元方向を休止する判断、逆方向へ新規する判断を分ける**材料になる。逆行したから反転、損切りしたから即ドテン、という一段の規則にはならない。

待機の対照として、Brooks本人は狭いレンジでは多くの取引者が見送り、広いレンジでも中央を避けると説明する。[本人の公開解説、2020-10-25](https://www.brookstradingcourse.com/how-to-trade-manual/trading-ranges/)。「常に方向の見方がある」ことと「常に建玉を持つ」ことは同じでない。このページの失敗率等を、NKの逆行125前の順行250率へ移さない。

## 15分定時へ移すときに変わるもの

以下は資料から得た**設計上の推論**であり、採用済み算法ではない。

|新研究の条件|利用できる構造|移植前に決めること・反証|
|---|---|---|
|初回を除き15分ごとに新規判断|定時ごとに背景、既知帯、接近/突破/復帰の履歴、元仮説の維持/失敗を更新できる|1/5分で出た初押し・突破失敗は次定時までに終わり得る。同じ15分内で帯外→帯内→帯外となった経路を終値一つで復元しない。過去の発動価格へ遡って約定させない|
|持越し無し|前日高安や過去の分析履歴は当時既知の参照として利用し得る|Raschkeの複数日・複数時間幅の例を日中完結へ縮めると別物。前日帯までの距離、残時間、引け返済で狙った動きが収まるかは未検証|
|利益/損失を定時外も追尾|新規判断と、保有中の前提無効化・防御線の更新を別に管理できる|原典の裁量利確/スキャル退出・停止位置/建て増しを混ぜない。連続の非緩和追尾・現在費用後正での最低名目床は本研究側の制約で、原典より有利とは言えない|
|全予定枠の待ち率≤50%、保有継続は非待ち|保有を維持する判断も方向と保護状態を持つ観測として残せる|本人資料はこの活動率を要求していない。見送りが多ければ外部着想と活動条件が両立しない可能性がある。待ち率のための保有延長・無条件の新規を足さない|
|売買は符号鏡像|高値試し失敗の売りと安値試し失敗の買いを、同じ時計・幅・費用で対にする|原資料の買いの例を売りへ写した部分は本研究の一般化。上下の結果が対称になる保証や、指数の方向分布の対称性を仮定しない|

定時の記録では、少なくとも「背景と場所」「現在の価格反応」「元仮説の反証」「買い/売り/待ち/保有継続/撤退/処理中/判定不能」「その判断に使えた公開時計」を別欄にする。前提が失敗しても逆側の価格確認がなければ、撤退・待機と反転新規を混ぜない。これは判定項目の整理で、まだ閾値や執行順を固定していない。

## 心理の仮説を反証できる形へ狭める

|心理の物語|価格から確認できる候補|その物語だけでは説明できない例|
|---|---|---|
|突破参加者が取り残され、撤退が逆行を促す|事前に既知の帯の外を試す→復帰→外側の再開失敗/逆側への進行|帯内復帰後すぐ再突破する。帯の反対側まで届かない。同じ経路でも注文動機は不明|
|強い方向の参加者が調整を利用する|先行する方向的な波、反対波の相対的な深さ/時間、その後の再開|調整が二波へ伸びても元構造は維持される。初回再開失敗を直ちに大局反転とすると分類を誤る|
|収縮後に均衡が崩れ、追随が重なる|過去に比べた狭さ、帯外の値幅と進行、戻りの成否|拡大がすぐ往復へ変わる。寄付ギャップの向きとその後の方向が異なる。終日を見てから日型を付けた場合は先読み|

「強い・速い・弱い・深い・重要・初めて・失敗」は、そのままコードへ移せない。帯の生成時刻、確定の遅れ、値幅/時間の比較対象、許容帯、同足内の順序、失効と再試行の扱いを、結果を見る前に限定する必要がある。未定量語を後から都合よく読み替えた成績は、本人手法の検証にも、新しい心理仮説の実証にもならない。

## 検証前に残す反証と比較

1. **文脈があることの効果を分ける。** 同じ時刻・売買・残時間の基準に対し、既知帯の近傍/中央、順行波/調整/失敗後の構成を比べる。成功した図から帯を選び直さない。
2. **見送りと反転を同義にしない。** 元仮説失敗、逆向き確認、時刻までに未確定を別件数にする。保有の有無で次の判断も変わるため、純判断集合と実参加を別に示す。
3. **定時化で失う機会を隠さない。** 当時の定時価格で評価し、枠間で完了した形を昔の価格へ戻さない。形が残っても取得悪化で250余地や費用後収益を失う可能性を残す。
4. **出口で同じ仮説を別物にしない。** 構造的な停止と本研究の連続追尾が衝突する位置を記録し、方向、125/250先着、実回収、費用後額、待ち率をそれぞれ検査する。

特定の実務家の利益実績や言葉の確率を根拠に、70%目標・支持・費用条件を満たしたとしない。現段階の結論は、失敗後に見方を更新する具体例と、定時化・追尾・活動率が原典と異なることを確認した範囲に留まる。新49算法は未採用のままである。
