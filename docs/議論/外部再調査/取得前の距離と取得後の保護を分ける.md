# 取得前の距離と取得後の保護を分ける

確認日：2026-11-06。71の学習・運用結果を見る前の追加調査。[前巡の価格応答](期待した進行の不発と取得保護の距離を分ける.md)と[方向・取得位置](継続の方向と取得位置と短期保護を分ける.md)を起点に、以下の本人・運営組織の本文2件を実読した。動画の全視聴や図の数値再測定はしていない。

## 原典から読めること

Alphatrends、[2 Important Questions to Answer Before Entry](https://alphatrends.net/archives/2-important-questions-to-answer-before-entry/)、2024-11-18。Brian Shannonの運営組織の教育本文である。直前の急進を追う取得と押戻し後の取得を分け、前方の供給候補に対する余地を考える。到達目標は理論値で、実際の管理は保護を中心に行うと説明する。高確率という表現に全件・費用後・未見の検定は付かず、NK225の数値的根拠にはならない。旧Guide PDFの直接取得は404だったため、検索断片を原本実読の代わりにしない。

Adam Grimes、[What to do with missed profit targets?](https://www.adamhgrimes.com/missed-profit-targets/)、2017-03-14。目標直前から赤字へ戻った株式の読者事例を扱う。入口日の急な往復と、その後に長く進まない状況を区別し、早い利確にも待つ場合にも事前の規則を求める。一つの痛い失敗でルールを変えることや、損失直後の感情的な再参加を戒める実務説明であり、最適な利確幅・追尾幅の検定ではない。

二資料とも既読概念を具体化する商用教育資料で、独立した先物の統計的実証ではない。焦りや利益消失への恐怖という心理説明は、原板から参加者の動機を同定した結果ではない。

## 再利用する問い

| 局面 | 当時に記録する候補 | 区別すること |
| --- | --- | --- |
| 取得前 | 方向・先行進行・上位端・新規側気配・通常幅 | 方向が合うことと、その価格から参加できること |
| 取得時 | 設定から発動までの進行、実約定の気配と遅延 | 当時の予定価格と、後で決まる実取得価格 |
| 取得後 | 早期の往復、後続の不進行、保護起動と実返済 | 同じ赤字でも、未起動の失敗と利益後の消失 |
| 次の判断 | 旧前提の否定、新しい形成、反対方向の確認 | 退出の理由と、新規・反転へ参加する理由 |

価格の強い進行を追う注文、押戻しでの再参加、利益を失った参加者の退出という説明は心理の仮説である。同じ価格変化は量・流動性・時刻などでも生じる。方向・勢い・量・価格構造を併用しても、同じ価格の加工を独立票として数えない。

## 71へ入れる独自の特徴と、入れない条件

71の候補は `g=s×(M−E*)/D`。Mは当時公開済み15分足の方向端、E*は当時正常な新規側気配、Dは既存の追尾幅である。Mを実証された支持抵抗、正のgを残り利益、負のgを過熱・反転と断定しない。gは構造の否定点までの後方距離でもない。

入力接続では、全2,046準備済み枠で上位終値と現在3分終値が同じだった。幅と終値位置は旧特徴に含まれるため、gの一部は既存情報の組合せで、新しい部分は当時気配との差やDへの尺度変換となる。独立した技法を新設せず、既存の価格構造P01へ置く。この入力事実は成績を示さない。

旧60列対照と61列追加側を同じ条件入口教師・容量で学習し、両側へ同じ約定支持の統合を適用する。入口・利益旗・損失側も含む非緩和の追尾は変更しない。将来の実約定や最大順行を入力へ戻さず、未発動も残す。

別候補の「事前否定線Bから取得気配までの距離」は今回追加しない。先にBの確定・公開時刻と失効を定める必要がある。原典の部分返済・数量調整・複数日保有を移植せず、70%・最適距離・未見利益を外部説明から主張しない。
