# 再試験の量と価格進行を段階で分ける

確認日：2026-11-06。**再試験中の量縮小、価格が進まないこと、後続の価格再開は別の観測である。** 低量だから再試験成功、高量だから反転、と直結しない。[出来高と価格進行の調査](出来高と価格進行を文脈で組み合わせる.md)から、具体的な再試験の順序と参加時計へ進める。

## 既存研究との差

[14](../../../study/00014_反転入口と観測差分量/計画.md)は発動足RVOL、[36](../../../study/00036_価格失敗と量比の方向変化/計画.md)は終値方向別量の比と変化、[42](../../../study/00042_突破再テストと数量加重終値位置/計画.md)と[43](../../../study/00043_再テスト時のCMF変化方向/計画.md)は同じ再テスト時点のCMF水準／差を扱った。[47](../../../study/00047_上位方向とForce波からの価格発動/計画.md)と[48](../../../study/00048_Force失敗後の価格確認と上位禁止/計画.md)は終値差×量の平滑波と後続価格確認を組み合わせた。新発見として再掲せず、各段階で**量と価格の結果を別々に保持する点**を今回の比較軸にする。

原典の蓄積・再蓄積帯は、短いrolling帯や任意の登録足の高安と自動的に等しくない。原典にはTestを必須にしない反例があり、独自のb/f/r/kを全件へ要求するなら、確認待ち・取得悪化・未参加を研究側の規約として残す。原典のTest価格へ、15分定時の新規価格を戻してはならない。

## 段階と量を組み合わせる際の留保

- 順行側では、突破b、その後の調整r、防衛線の保持、別足kでの価格再開を分ける。r中の低量や不進行だけを先に「成功」と呼ばず、kなし・取消・失効も残す。
- 反転側では、元方向の失敗f、旧方向への再試験r、その後の反対向き価格確認を分ける。高量不進行も、再突破・継続へ戻る場合があり、自動的な反対注文にしない。
- 買いの安値保持／後続高値越えは、売りで高値保持／後続安値割れへ同じ符号反射で写す。量と時間帯基準は無方向。価格T/Rの仮説名と、現在DIによる実運用役割も別にする。
- 量比は比較する足幅・段階・基準を先に固定する。長いepisodeほど合計量が増える時間曝露、同じ形成を定時に何度も見る反復、足の高安幅と終値純進行を区別する。CMF・VR・Force・量比を独立票として重ねない。
- 基準量0なら比は未知で、完全な当足量0とは別。未知を弱い相場へ置換しない。過去同時刻基準は判断前に完了した場のみから作り、未来の選択場を分母へ混ぜない。

別足と公開keyの順序だけでは、rの全高安が前段公開後に形成された保証にはならない。足開始と前段confirmの関係を別に固定し、足内の到達順をOHLCから補わない。数量も当時利用可能な時計・完全性・リセット・次足量混入を別監査し、後日の確定量で過去の公開足を補完しない。Schroederのtick volumeを契約数や気配更新回数と同一視しない。

「供給が尽きた」「大口が吸収した」「取り残された側が返済した」は心理仮説である。総量から主体・新規／返済・意図を直接識別した事実ではない。ニュースや流動性でも同じ形になり得る。

原典の停止位置やP&F目標、管理助言を現行出口へ移植せず、固定の現在費用122円strict正の利益起動・連続保護と先着／実回収の分離を維持する。既使用66場、支持付き先着70%、全予定待ち50%以下、費用後利益を満たす原典実証は確認していない。今回の調査は条件設計の参考で、仕様の採否と保存結果の評価は別に行う。
