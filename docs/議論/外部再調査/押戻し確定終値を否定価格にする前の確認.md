# 押戻し確定終値を否定価格にする前の確認

確認日：2026-11-08。[90の事前計画](../../../study/00090_押戻し確定終値の固定床と初期損失/検証計画.md)に対する外部資料と研究仮説の区別。

## 外部資料で確認した一般論

CMEは、損切り位置を売買の方向判断が誤っていたと分かる論理的な位置とし、通常の値動きだけで容易に触れる位置を避けるよう説明している。位置までの距離と許容損失から数量を考える説明であり、特定の終値や10ptの余白が有効だと検証した資料ではない。[CME：Proper Position Size](https://www.cmegroup.com/education/courses/trade-and-risk-management/proper-position-size)

CMEの支持・抵抗の教材は、移動平均、過去の高安、重要な価格、トレンド線を代表的な候補として挙げる。これらは方向が変わる、または進行が弱まる可能性のある水準という説明で、到達すれば必ず反転するという保証ではない。[CME：Support and Resistance](https://www.cmegroup.com/education/courses/technical-analysis/support-and-resistance)

JPXの商品概要で日経225ラージ先物の呼値は10円と確認した。[JPX：日経225先物の商品概要](https://www.jpx.co.jp/derivatives/products/domestic/225futures/index.html)

## 今回独自に試すこと

15分背景、確定3分価格、MACD/RSIの勢い、ATRと取得位置、急変警戒、元FARの価格構造・量条件を維持する。その複合入口で参照した最新押戻し足の確定終値を固定し、買いなら10pt下、売りなら10pt上を追加の否定価格にする。

これは安値・高値による一般的なスイング否定を再現するものではない。保存されている確定終値から、未保存の高安を推測しない。10ptは入力ラージの一呼値を使う固定の研究条件であり、mini/microの刻みや最適な余白とは呼ばない。

心理の仮説は、押戻しから平均の方向へ回復した後に、その押戻し終値を再び超えて逆行すれば、再開を支える価格の受容が弱まった可能性があるというもの。ただし終値は取引の一時点であり、支持・抵抗の厚さや参加者の意図を直接表すわけではない。通常の揺れを切りすぎる可能性もある。

## 結果で分ける問い

- 利益が出る前の損失を小さくしたか。元のATR床が既に近い場合は追加線の効果としない。
- 同じ入口で勝ちを失ったか。早い返済による後続の参加変更は出口差と分ける。
- 入口時に既に線を割っていなかったか。今回は追加の入口条件を設けず、その副作用を記録する。
- 利益後赤字の件数が減っても、利益を観測した玉そのものが減っただけではないか。

外部資料は設計理由を与える。今回の費用後損益や安定性を裏付ける実証結果には代用しない。
