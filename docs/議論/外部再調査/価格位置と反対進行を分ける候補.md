# 価格位置と反対進行を分ける候補

確認日：2026-11-08。[試行85の全玉比較](../../../study/00085_保持帯の返済側固定否定/出口差診断.md)を踏まえ、[86の計画](../../../study/00086_保持帯喪失と短秒反対の複合退出/検証計画.md)の固定前に仮説を整理した。後に計測した[86の比較結果](../保持帯喪失と反対進行を重ねた比較.md)は悪化であり、教材の一般説明を収益性の証拠へ読み替えない。

## 資料で述べられていること

[CME：Support and Resistance](https://www.cmegroup.com/education/courses/technical-analysis/support-and-resistance) は、支持抵抗を価格一点より帯として扱い、他の判断情報と合わせる説明である。[CME：Oscillators](https://www.cmegroup.com/education/courses/technical-analysis/oscillators-macd-rsi-stochastics) は、勢いを見る指標の役割と、強いトレンド中に過熱表示が続くこと、価格に遅れることを説明する。位置への接触だけで反転を断定する根拠にはしない。

これは5秒・15秒の速度や今回の1tickという閾値の有効性を実証する資料ではない。NK225の現在の費用後収益へ一般化せず、教材の一般論と本研究の独自条件を区別する。

## 心理の仮説を観測へ置き換える

順行を期待した帯へ価格が戻っても、利益確定や流動性の一時的後退を消化した後に元の方向へ再開する場合がある。一方、帯の両気配が逆側へ進み、短期の価格変化も反対向きに続けば、元の追随が失速したという説明を検討できる。ただし、同じ見かけでもV字回復する反例がある。売買動機や参加人数は板価格から直接分からない。

86では、凍結した価格帯を「どこで売買仮説を見直すか」、5/15秒の中央値速度を「今どちらへ進んでいるか」に使う。複数分足EMA・MACD・RSI・ATRと現在帯維持・反対圧力解消の入口背景は固定する。価格位置と速度は役割が違っても、ともに同じ価格系列から計算される。独立票の数として強さを主張しない。

反対進行を確認できない場合は否定未確認、速度の入力が欠ける場合は判定不能である。通常押戻しと確定したわけではなく、旧ATR・125保護・確定足失敗・正益後の最低建値/G1追尾を続ける。反対方向へ新規を建てる条件は別に必要とする。

## 反証と次の比較

確認を待つ間に損失が拡大する、V字の底で同じ勝ちを切る、短秒の未知が多く追加条件が働かない、主約定だけ良く1秒遅延で悪化する、という反証を先に置く。利益旗後赤字が減っても、正益前に切ったため分母が減っただけなら保全達成とはしない。全実新規の対応を残し、救った損失・失った勝ち・損失拡大・変化なしを費用後金額で比較する。

速度は実経過秒・正常な過去端・異常累計から再構成し、保存されたKnownだけで検証済みとはしない。資料の心理説明、実装の入力整合、費用後の有効性は、それぞれ別の証拠を必要とする。
