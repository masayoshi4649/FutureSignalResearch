# 推進と調整の区間と確認遅れを分ける

確認日：2026-11-06。59で登録後平均を追加した結果を受け、同じ著者の別本文2件を実読した。独立した二つの統計実証という意味ではない。

[Grimes、Flags: Not Just for Patriots](https://www.adamhgrimes.com/content/files/2025/08/grimes0803.pdf)はSFOの2003年8/9月記事で、本人サイトに許諾掲載された5ページのPDFである。推進部・調整部・再開を分け、長引く調整にも注意し、再開を確認してから入ることで取得位置が悪くなる代償を説明する。したがって、低速の理由を小さい変位と長い時間へ分ける問いが生まれる。URLの2025/08は記事の発表年ではない。

同記事の集計には完全な売買規則がなく、目標より大きい初期stopの選択も論じる。掲載された高い勝率をNK225の+250/−125先着率へ読み替えない。20本への言及も、本研究の3分×20本＝60分TTLを正当化するものではない。

[Grimes、One, two, three steps to shorting stocks](https://www.adamhgrimes.com/one-two-three-steps-to-shorting-stocks/)（2015-09-02）は、S&P500先物の日足例で、新しい下向き勢い、戻り、再び下へ向く確認を区別する。MACDの新安値とfast lineの折返しは異なる役割を持つ。この記事にも全件表・完全な規則・費用後の外標本成績はなく、逆方向への急伸も認めている。MACDの線を本研究のFastKやDIと同一視しない。

## 検証へ移す問い

| 比較する違い | 当時保存する候補 | 限定 |
| --- | --- | --- |
| 登録へ向かう進行と、その後の調整 | 起点・終点・純変位・足数・方向別効率 | 固定10差分は実際の推進波全体ではない |
| ヒゲの水準接触と、終値の押戻し | 再試験以前の有利な終値とr終値 | rへの平均進行は正値にもなり得る |
| 調整と再開 | r以前とr以後を別に測る | r直後は再開確認kの前を含む |
| 確認済みの形と実際の取得 | r→k、k→定時、定時→約定の時計と価格 | 過去のk価格で新規した仮定を使わない |

これは独自の機械化候補であり、資料に最適な速度比・閾値が載っているわけではない。[60の計画](../../../study/00060_先行進行と再試験の区間分離/検証計画.md)では旧38特徴へ区間別8値を追加し、上位方向・短期勢い・ATR・価格構造と組み合わせる。支持・費用・連続追尾は保持する。心理の説明は注文動機の直接測定ではなく、NK225の70%達成を示すものでもない。
