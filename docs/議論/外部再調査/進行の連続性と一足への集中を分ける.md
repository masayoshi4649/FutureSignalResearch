# 進行の連続性と一足への集中を分ける

確認日：2026-11-06。72固定後の追加調査であり、72の条件・学習には投入していない。急進と持続の着想は既出で、以下は新たに本文を確認した2原典から、観測の違いを整理したもの。

Da・Gurun・Warachkaの2014年論文は、米株の日次収益の正負割合と過去の累積収益を組み合わせ、月次形成・後続6か月等を比較する。情報への注意不足は心理仮説であり、価格から注意そのものを直接測っていない。本文は、全て同符号なら変化の大きさが偏っていても同じIDになる反例を挙げる。[著者公開PDF](https://academicweb.nd.edu/~zda/Frog.pdf)の第1・2節、特にPDF7〜9頁の定義と反例、12〜17頁の評価説明を実読。RFS先行公開2014-02-05。

Shephard・Yangの著者投稿は、CMEの金利・為替先物2契約×2日の価格を、一過性成分と持続成分を含むモデルで記述する。主な尺度は0.1〜60秒で、取引価格と直ちに取得できるbid/askの違いも留保する。個々の急進を当時に分類する売買検定ではない。[2015-01-05版本文](https://arxiv.org/html/1410.7317v2)の第1・5節・付録Cを実読。初稿2014-10-27。

| 再利用する区別 | 当時の観測と反証 |
| --- | --- |
| 同符号でも大きさの集中は違う | 正負の割合と最大絶対差分の比を分ける。原典IDの知見を独自集中度Cの有効性としない |
| 低集中でも往復なら方向性はない | 純変位と絶対変化合計を別に見る。低Cを順行資格にするのは未検証 |
| Lastの急進とBBO取得は別 | 過去取引価格の跳ねを、その価格で新規取得できる証拠にしない。追随費用と保護距離は別評価 |
| 一足集中と急進後の保持は別 | 高Cでもそのまま進む反例を残す。前提否定だけで反対方向成立とも呼ばない |

表の機械化は独自・未検証。`C=max(|d_i|)/Σ|d_i|`、窓n=5や閾値はまだ候補で、原典の公式ではない。n=5差分なら6個の連続公開終値が必要。分母0・欠足を補完せず、判断時点までの公開足だけを使う。将来の戻りや事後推定した持続成分を入力にしない。売買は価格反射と方向符号反転の同じ規則にする。

米株の日次・月次結果も、先物の短い4データのモデル適合も、NK短期の70%先着や費用後回収を保証しない。注意不足・流動性・追随という心理説明は代替仮説である。72結果を根拠にした条件変更、市場計算、追加fitは行っていない。
