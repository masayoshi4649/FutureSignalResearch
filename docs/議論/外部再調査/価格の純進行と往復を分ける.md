## 提供元資料の説明

[StockChartsのKAMA仕様](https://chartschool.stockcharts.com/table-of-contents/technical-indicators-and-overlays/technical-overlays/kaufmans-adaptive-moving-average-kama)は、効率比ERを終値の純変化の絶対値と、各足の終値変化の絶対値の合計との比で説明する。KAMAはERを平滑係数へ写す適応移動平均である。同資料も単純な平均クロスの往復損失に注意している。指標提供元の仕様説明であり、NK225の将来利益を確認した研究ではない。

```text
純進行 = abs(Close[t] − Close[t−n])
総往復 = sum(abs(Close[j] − Close[j−1]), j=t−n+1..t)
ER = 純進行 / 総往復
```

説明用の4変化では、100→110→120→130→140は純進行40・総往復40でER=1。100→130→110→150→140は同じ純進行40でも総往復100でER=0.4となる。実データの結果や採用期間を示す例ではない。

[thinkorswim自身の仕様](https://toslc.thinkorswim.com/center/reference/Tech-Indicators/studies-library/M-N/MovAvgAdaptive)もKAMA方式のERを純変化/終値変化の総和として説明する。一方、平滑の速い/遅い側の説明にはStockChartsの掲載式とそのまま合わせられない箇所がある。説明文を継ぎ合わせず、将来実装する場合は計算式・初期化・分母0・欠足・公開時刻を一つの版として固定し、既知の手計算例で確認する。今回はKAMA数値器を実装していない。

[FidelityのADX解説](https://www.fidelity.com/viewpoints/active-investor/average-directional-index-ADX)は、トレンドの強さをADX、方向をDIで分ける。ERも絶対値なので方向を持たない。ER・ADX・ATRを、売り/買いの方向そのものと取り違えない。

## 市場心理として考える仮説

同じ純進行でも往復が多ければ、順方向注文と反対注文が交互に優勢になり、単純な平均回復が何度も失敗する可能性がある。一方向の連続進行は継続注文の優勢という説明に対応する。ただし価格経路から動機を直接観測したものではなく、材料発表後の一度の大幅移動も高いERを作り得る。

ERの高さが現在の有利な取得位置を保証するわけでもない。既に進んだ後の追い掛けを避けるには、押戻しの価格構造、ATRで測る現在取得位置、勢いの回復を別の役割として残す。

## 次の切替へ使うなら何を区別するか

| 観測 | 分けたい場面 | 別に必要な確認 |
| --- | --- | --- |
| 上位の純進行と総往復 | 進行のある背景／往復の多い背景 | EMA又はDIによる方向、確定足の既知性 |
| i/p/r/kの価格関係 | 前の進行を取り戻す再開／平均だけの再クロス | MACD増分、押しの否定、現在の取得ATR位置 |
| 反対進行と量の応答 | 一時的利確／継続根拠の否定 | 既知OFI又は価格帯応答。表示量を約定量と同一視しない |
| 価格の内復帰・反対構造の形成 | 反転狙いへ切り替え得る場面／待機 | 反対側の価格確認と勢い。低ERだけで逆張りしない |
