# 判断時刻と条件注文の発動を分ける

確認日：2026-11-06。[試行66](../../../study/00066_複数手法の適格方向から優先側を選ぶ/README.md)の結果後に追加調査した。**15分ごとの分析で売買候補を決めることと、その場で新規注文を出すことは別の設計である。** 外部資料を根拠に、定時に条件を固定し、後続価格で発動する比較を検討する。次試行は未採番・未固定・未実行であり、優位性を確認したものではない。

## 心理の説明を観測へ変える

以下は本研究の仮説で、注文動機を観測した事実ではない。

| 段階 | 心理の説明候補 | 価格で確かめること | 反証になる動き |
| --- | --- | --- | --- |
| 背景と候補 | 上位方向・値幅・位置が、その方向の参加を許す | DMI等の方向、ADXやBB幅、ATR、価格帯、短期勢い・量の役割を分ける | 背景が整っていても価格が動かない |
| 順行の発動 | 調整後に再び同方向へ参加する人が優勢になる | 当時決めた局所高安への、その後の到達 | 届かず失効、又は先に調整を否定する側へ進む |
| 反転の発動 | 元の方向の見込み違いによる撤退が、反対方向の参加と重なる | 失敗した帯への復帰と、反対方向への進行を別段階で確認 | 元方向へ再拡大する、復帰後に進まない |
| 発動後の持続 | 一時的な注文集中を超えて価格が進む | 発動後の順行・逆行・継続時間と実回収 | 発動直後に戻る、追随費用に見合う幅が残らない |

出来高が増えた事実だけで、新規・返済、情報による注文・機械的発動を識別しない。「買われた理由」を確定する代わりに、同じ背景でも発動した場合・しなかった場合・発動後に否定された場合を記録する。

## 次の比較へ移す独自案

同じ15分時点、同じ複数技法の候補、同じ方向、同じ費用・利益/損失追尾を使い、**即時要求と、将来の価格発動を待つ要求だけを比較する**。売買は符号反転した同一条件にする。現在の形を追加の資格にする変更とは同時に行わない。

1. 定時に、方向・参照足・発動線・否定線の有無・満了時刻・追尾幅を決める。例えば最新の公開済み3分足高安を参照する案があるが、まだ採用していない。
2. 次の定時までは固定条件への価格到達だけを監視する。途中の新しい指標で方向や線を選び直さない。保有後の連続追尾は別に動かす。
3. 発動を観測した後の価格で注文を評価する。線を飛び越えたのに線価格で約定した扱いにしない。同秒原行順・要求後の遅延・約定期限を固定する。
4. 満了・否定・発動・約定待ちが競合する処理を決める。定時に既に線を越えた場合、次定時に発動済み未約定も取消すか等を、成績を見る前に決める。
5. 全予定枠、純候補、監視開始、発動、失効、要求、実新規・完結を分ける。未発動の監視を保有継続と呼ばず、待ち相当を含めた活動率を確認する。

この解釈は[ユーザーの15分判断指定](../15分判断と連続追尾の研究条件.md)を、定時に条件を決める時計として使う研究案である。定時成行までをユーザーの指定とはしない。一方、既存O49は判断から30秒以内の要求を想定しているため、単なる時刻差替えで同一仕様として扱えない。
