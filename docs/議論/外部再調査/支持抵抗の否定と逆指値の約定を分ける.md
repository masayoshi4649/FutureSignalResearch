# 支持抵抗の否定と逆指値の約定を分ける

確認日：2026-11-08。85の条件固定後の補足調査。金融条件は変更していない。

## 一般的な説明と資料の範囲

- [CME：Support and Resistance](https://www.cmegroup.com/education/courses/technical-analysis/support-and-resistance) は、過去高安・移動平均などを支持抵抗の手掛かりとし、突破後の役割交代を説明する。価格一点ではなく帯として扱い、判断材料の一つとする説明である。
- [CME：Proper Position Size](https://www.cmegroup.com/education/courses/trade-and-risk-management/proper-position-size) は、売買方向の判断が誤りと分かる論理的な位置に損切りを置き、その距離と許容リスクから数量を決める考え方を説明する。通常変動だけで発動する位置も避けるとしている。
- [Fett・McPhail：Stop Orders in Select Futures Markets](https://www.cftc.gov/sites/default/files/Stoploss_final_ada.pdf) はCFTC職員の2017年研究。米国3先物の2014～2016年の注文・約定を対象とし、急変時にはストップ発動後の利用可能価格で約定して損失が想定を超え得ると説明する。著者の分析でありCFTCの公式見解ではない。NK225の現行制度の説明ではない。

## 市場心理としての仮説

ある帯で反発を期待する参加者と、その帯の突破後に撤退する参加者がいるなら、帯の維持と否定は継続・退出を分ける材料になり得る。ただし、過去価格への注目や注文集中は心理の仮説であり、本リポジトリの板から参加者の意図や隠れた逆指値は直接観測できない。

入口では複数時間軸の方向、勢い、値幅、現在の価格応答を合わせる。出口ではその入口根拠が保たれているかを問い直す。「支持があるから買う」と「支持を割ったからすぐ売る」を単独で有効と決めつけず、費用と往復の振られ損を含めて比較する。

## 85で検証する範囲

[85の検証計画](../../../study/00085_保持帯の返済側固定否定/検証計画.md) は、固定84C0の複合入口を保ち、要求時のfreshな保持帯を返済側1tick超えで否定する出口だけを追加する。これは帯という一般概念を検証可能な単線へ離散化した仮説であり、資料が1tick・60秒・32更新という閾値やNK225の収益性を保証しているわけではない。

利益保護は費用後正益が観測された時点で連続起動する。発動・返済要求・約定・全玉純損益を別々に記録し、価格飛びや約定遅延による赤字と、正益を観測したまま注文しなかった事例を区別する。数量調整は今回の比較に混ぜず、損切り距離が違う取引の安定性を問う次の候補として残す。
