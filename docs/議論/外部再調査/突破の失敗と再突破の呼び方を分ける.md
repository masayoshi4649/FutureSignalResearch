# 突破の失敗と再突破の呼び方を分ける

一次資料確認日：2026-11-06（日本時間）。本人の別記事・書籍公開部分の2件を確認した。市場入力、教師、モデル、現在又は今後の実結果は開かず、計算・実装を行っていない。

**最初の突破、逆行、元方向への再開は別の段階である。ただし、著者がいう「失敗」を、OR端への終値内復帰と同義にしてはいけない。** [価格の履歴と一時点の指標](価格の履歴と一時点の指標を区別する.md)で扱った情報圧縮の一般論を、ここでは用語と機械条件の違いへ絞る。

## 原典で読めたこと

### Brooks：逆行が続かない場合を、初突破と分ける

Al Brooks『Trading Price Action Trading Ranges』第5章、掲載書誌は2012年1月。[正規配信の公開プレビュー](https://www.oreilly.com/library/view/trading-price-action/9781118172339/OEBPS/9781118172339_epub_c_05.htm)の導入2段落だけを読んだ。**本章全文・続く図例は未読**である。

突破後の押し戻りから、反対方向への転換が続く場合と、短い逆行で終わり元の突破方向が再開する場合を分ける。本人は押し戻りの開始から広くfailureと呼ぶ。したがって、元の線の内側へ終値が戻ることや、同じ線の再突破が必須という定義を、この公開部分から導けない。

ここで得られるのは、初突破と、反対進行の不成立後の再開を別の状態として考える着想である。再開確認まで待てば有利という統計や、具体的なOR終値売買の規則は、この読取範囲にはない。

### Grimes：水準割れ後の再取得にも代償がある

Adam Grimes『Traders get an edge by thinking in categories』、2015-05-08。[本人記事](https://www.adamhgrimes.com/technical-analysis-thinking-in-categories/)の支持抵抗保持・破断の節を中心に本文を確認した。

支持は常にきれいに保たれるとは限らず、一時的に割れてから回復する場合を区別する。割れで退出して再び保たれたときに取り直す選択には、小損を繰り返す交換条件があると述べる。突破時の薄さ・滑りも注意点である。振り落とされた買い手が再配置するという説明は本人の心理解釈で、この記事による注文実測ではない。

記事の高確率という表現を、監査済みの母数・費用後勝率として採用しない。水準の保持と突破を分類する説明であり、最初より二度目が必ず優れるという実証ではない。

## 52の順序特徴への接続は独自規約

52で検討するのは、当時確定したOR上端・下端に対し、最大10本の公開済み3分足の窓で、内外±5の状態の**外切替→内切替→再外切替**という順序・回数を既存15特徴へ加える案である。

これは作者ルールの再現ではない。ORの選択、3分終値、±5、最大10本、状態の等号・中間帯・窓先頭の扱いは、原典から一意に定まらない研究側の定義である。「再突破」はその規約内での再外切替を指し、著者のfailed failure全般や、全場での二回目の突破と同じ意味にはしない。

この特徴は、現在が外側にあるという値へ、そこまでの順序を追加する。ただし、回数が多いほど強い又は弱いとは先に決められない。連続した外側の足数と、内外を往復した回数も異なる。上端と下端、買いと売りの説明は対応する鏡像として扱い、一方だけの心理説明で採否を変えない。

## 心理仮説・反証・確認の遅れ

以下は本研究の仮説であり、2資料で注文動機を直接測定した結果ではない。

|仮説として考えられること|当時の価格で区別すること|反証・別解釈|
|---|---|---|
|初突破への参加が継続する|外側へ移った後、内復帰せず進む|外側にいても進行せず、取得可能な利幅が残らない|
|内復帰で元方向の参加が減り、その後に再び元方向への参加が生じる|同じ既知の線への内復帰と再外切替の順序|再外切替後にまた内復帰する。単なる往復で、撤退・新規注文の内訳は不明|
|再突破の反復が線の状態変化を表す|回数と、最後にどちら側へいるかを別に記述する|時間帯・直前値幅をそろえると差がない。細かな往復を数えただけである|

15分定時の判断では、再開した3分足の価格へ戻って新規できない。定時までに再失敗が済む例、再突破を待つ間に値幅を使い切る例、再突破を一度も伴わず初突破から進む例がある。追加確認は、待ち増加、支持不足、取得悪化も伴い得る。OHLC内の高安の順序や、未公開足での回復を補わない。

両資料から、NKの日中・固定2R先着率70%・費用後損益・全予定枠の待ち率50%以下を満たす証明は得られない。履歴の有効性と活動への影響は未実証として残す。指標は背景・勢い・値幅を、価格の順序は既知の線への反応履歴を担当するという役割分担の着想に限り、目標を下げる材料にはしない。
