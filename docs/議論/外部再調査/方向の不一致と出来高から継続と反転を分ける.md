# 方向の不一致と出来高から継続と反転を分ける

確認日：2026-11-06。試行71後の追加調査。原著論文・取引所教材・商用教材の本文6件と、別論文の公開本文抜粋1件を確認した。**次の仮説に使うのは、指標の一致数ではなく、不一致が生じた場所と、その後に何が成立・否定されたかである。** 新しい売買条件や収益はまだ検証していない。

## 順行・反転・待機をどう切り替えるか

以下は資料から考えた**独自の未検証候補**。上位が上昇している例で説明するが、実装では価格の上下と売買側を反転した同じ条件を使う。原典の「下落後の反発が強い」といった非対称性は持ち込まない。

| 観測する場面 | 順行へ進む確認 | 反転へ進む確認 | まだ決めない場合 |
| --- | --- | --- | --- |
| 上位は上向き、下位だけ下向き | 既知の支持構造を保ち、下位の売り方向の進行が鈍った後、戻りの高値を回復する | 支持構造を失い、回復を試しても戻せず、反対方向の安値更新が続く | 下位が下向きになっただけ。上位の傾きが遅れて残っているのか、調整なのか未確認 |
| 上位・下位とも同方向 | 勢いが複数足に広がり、調整後も価格が進む。量は時刻と局面に対して比較する | 同方向だけでは逆売買しない。既知端の突破失敗と内復帰、回復失敗を別に確認する | 一足だけの急伸、前方の既知端が近い、量増に価格進行が伴わない |
| 帯が狭まり方向が揃わない | 先行方向を背景に、帯外の価格発動と保持を確認する | 外へ出た試行が失敗し、帯内へ戻った後に反対側の進行が成立する | 収縮しか観測できない。出来高の大小だけでは退出方向を決めない |

ここでいう支持・抵抗は、当時に固定できる価格構造の候補である。他の参加者が実際に同じ線を参照しているとは確認していない。突破、保持、否定、次の発動を別々に記録し、**元の仮説が崩れたことを、そのまま逆方向の新規理由にしない**。

心理の仮説は、調整では一時的な利食い等があっても元方向の参加が再開し、反転では元方向への試行が続かなくなる、というもの。OHLCと総量で参加者や動機は同定できない。したがって検証する対象は「利食いした人」ではなく、既知水準への復帰・再取得・更新、その順序である。

## 指標の役割と、追加するなら何を測るか

| 役割 | 手法・尺度の候補 | 誤って重ねない判断 |
| --- | --- | --- |
| 背景の方向 | I08 DMI、又はI01移動平均の傾きを上位・下位で比較 | 遅速リターンの論文をDI対オシレーターの実証とは呼ばない。同じ価格加工の一致を独立票にしない |
| 勢いの持続・失速 | I07ストキャスティクスの推移、I03 MACD、P05終値差の分布 | 水準の高さと、今の増分・持続を分ける。単なる過熱だけで逆売買しない |
| 通常の値幅 | I09 ATR、I05 BB幅の変化 | 小さい幅を継続方向の証拠にしない。125/250と残り時間に対して測る |
| 参加状況 | V01同時刻相対出来高と、その区間の値幅・純進行 | 量だけで新規買い・返済売りを識別しない。量の不足と低量を区別する |
| 発動・否定 | P01足の終値位置、P02高安構造、既知の帯 | 後から確定する高安や将来の実約定価格を判断時点へ戻さない |

これは[汎用表・版5](../手法と時間スケールの汎用表_版5.md)の候補整理であり、全手法を同時にAND条件へ加える指示ではない。現61特徴のF01は**15分DI**、下位の勢いは3分FastKとその変化である。移動平均の傾き・MACDは現61列に入っておらず、上表の追加候補と区別する。

新しい観測候補を一つ具体化すると、**直近の進行が一足に集中しているか**がある。当時までに完全公開された3分足の終値差を `d₁…dₙ` とし、次を別々に記録する。

- 集中度 `C=max(|dᵢ|)/Σ|dᵢ|`。分母0は未定義。大きいほど絶対変化が一足に偏る。
- 方向効率 `E=s×Σdᵢ/Σ|dᵢ|`。sは買い+1・売り−1。分母0はC・Eとも未定義。集中度が高くても、最大変化が逆方向なら順行スパイクと呼ばない。
- C・Eだけでは最大変化の方向を復元できない。元の差分列と各終値の公開keyを残し、最大絶対差分の符号も確認する。同じ最大値に正負両方があれば混在として扱い、都合のよい側だけを選ばない。
- 同じ区間の相対量、上位方向、既知水準の保持・否定を併記する。CとEは同じ価格由来で、独立した二手法とは数えない。

これは原典の公式ではなく独自案。n=5なら連続する6個の公開終値から15分間の5差分を作るが、窓・閾値・欠枠規則は採用前に固定する。強い初動が一足に集中してそのまま進む反例も必ず残す。単にCの高い例を全除外して的中率だけ上げるのではなく、失った250成功・待ち率・実回収まで比較する。

## 既存検証との違いを先に確認する

[試行71の知見](../取得位置の追加が支持統合で判断に残らなかった比較.md)では、取得位置gを加えても3,404組の判断は同じだった。gが入った元分岐には約定111枠しかなく、両子各60枠の支持を保てず統合された。配下の先着scoreも基準未達で、支持不足だけが原因ではない。**文献を増やしたことと、実際の判断に差が生じたことを分ける。**

既存61列は、水準の突破・再試験・再開・否定、深さ、区間平均進行、量価格ペアを既に含む。ただし、有効旗は形成の出生時にも立ち、再開完成と同義ではない。過去の形成時点を起点にした平均進行と、現在直近窓の一足への集中度も同じではない。新指標名を増やす前に、この違いを入力仕様で確かめる。

15分定時に条件を作り、その後の固定線突破で発動する骨格は67〜71で検証済みである。今回新しく検討するのは、どの背景・時系列状態を入口資格にするか。条件発動そのものを新発見として再試行しない。

利益保護も独立した問題として残る。71の選択期間では、利益旗98件中74件が費用後赤字で、内訳は名目同値39・有利価格だが費用負け31・不利価格4件。現在費用控除後の含み益が正で起動しても、最低保護線が名目新規価格なら費用後黒字は保証されない。入口と追尾の変更を同時に行い、この原因を混ぜない。

## 次の比較と達成判定

1. まず既存特徴と支持条件の対応を確認する。分割を選ぶ時点で約定支持を要求する比較案は、この観測を残すための方法上の候補であり、それだけでテクニカルの優位を示すものではない。
2. 技法側の追加候補は、方向不一致の解消、既知構造の否定、一足への集中をそれぞれ分ける。既出の再試験規則の名前替えになっていないか確認し、一度の比較で変更軸を混ぜない。
3. 売買は鏡像、15分判断、全枠待ち50%以下（保有継続は非待ち）、費用後正益での追尾起動と最低同値床、場内完結を維持する。資料に合わせてこれらを緩めない。
4. +250/−125先着、費用後の実勝率・平均損益、未発動、品質不足、活動頻度を別に記録する。先着25〜30%は方向予測の的中率ではなく、成功とみなす説明にもならない。[尺度の整理](実証と評価尺度.md)に従い70%目標は維持する。
5. 既使用66場で作った追加案は探索。試行番号や学習窓を変えても未見データには戻らない。将来の確認期間に条件を合わせ直さない。
