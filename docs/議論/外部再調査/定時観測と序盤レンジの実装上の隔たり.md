# 定時観測と序盤レンジの実装上の隔たり

確認日：2026-11-06。[日中パターンの追加調査](日中の価格パターンと条件付き優位性.md)と[実務の局面切替](実務の局面切替と定時判断.md)で本文を精査していなかった一次資料を、今回は**2件**に絞って確認した。第三の引用を埋めるための資料追加はしない。新しい市場入力・キャッシュ・損益は読まず、計算・算法実装・旧固定成果物の編集も行っていない。

**当場序盤30分の既知高安を、15分定時の離脱・内復帰へ使う着想はある。しかし、そのまま売買対称・複数手法・連続追尾・125/250先着70%・待ち率50%以下を支える実証は、この2資料では未達である。** 原典の滞在時間や5分発動と、こちらの定時状態分類を同一手法と呼ばない。

## 今回精査した2資料

### 1. Fisher（2002）：価格到達と、その外側での滞在は別

[Wileyの書誌](https://www.wiley.com/en-us/-p-9780471215516)と[出版社公開の第1章](https://catalogimages.wiley.com/images/db/pdf/E0471215511.01.pdf)を確認。印刷10–19・24–32頁の定義・失敗例を読んだ。序盤レンジは商品や保有時間に応じ5〜30分を先に固定。A/Cはレンジ端そのものではなく外側の価格基準で、原則レンジ時間の半分の滞在を要求する。触れて直ちに戻る失敗と、成立後の反対側への転換を分ける。想定時間内に進まない退出も説明する。

これは作者の規則・実例であり、公開章に未見の取引母数、費用後成績、NKでの勝率検定はない。「序盤に日中高安が出やすい」という作者の比率と無方向モデルとの比較も、本調査で検証済みの統計根拠には使わない。

**実装への隔たり（独自の推論）**：30分レンジなら、その半分は15分になるが、「次の15分終値が外側」と「その間ずっと指定価格以上で取引」は違う。レンジ内終値への復帰だけでFisherの失敗条件を再現したとも言えない。候補で使うのが終値分類なら、滞在条件を借りたと称さず、その別定義を固定する。

### 2. Chuk（2026年10月、第2版）：30分帯でも、発動・出口・検証は別

[著者の原稿](https://justinchukmarkets.com/papers/orb_paper.pdf)の方法・Tables 1/2/7・外標本/限界節を確認。NQの2010〜2026年7月の1分資料を使い、09:30–10:00 ETの高安、最初の5分終値が上端超→次足始値の買い、下端ストップ・1:1目標・13:55足終値（14時境界、次の14:00足は見ない）退出。原版は往復2.50ドル＋入口1tick/ストップ追加2tick、別micro版は費用等が異なる。前者の2020年以降は勝率54.5%と報告する。

査読済み・独立再現済みとは扱わない。著者自身が、全パラメータ選択に関してin-sample、未見記録なし、族内Holmでは全144探索の自由度を十分処理できない、別実装の出口/約定差が未解消と明記する。価格機序も未検定。5分確認の買いのみ・1:1の結果を15分・売買鏡像・2Rへ移さない。

**実装への隔たり（独自の推論）**：この例の「突破後に買う」と、定時に現在の外側残留を買うことは違う。初回5分確認を過ぎてからの15分判断では、すでに戻った例・再突破例・さらに進んだ例が混在する。過去の端や次足始値へ価格を戻して比較しない。原稿の押し戻り/再獲得の比較も、新しい確認を重ねれば優位になるという根拠にはならない。

## 30分レンジを「当時既知」にするための区別

以下は原典の実証結果ではなく、新研究の固定前に決める事項である。

|固定するもの|区別する理由|
|---|---|
|序盤30分の開始・終了、日中/夜間の起点|現行OSEの08:45開始と東証09:00開始は別。前者の30分は09:15、後者は09:30に終わる。どちらが優れるかは本調査では判断せず、結果前に一つを定義する。公式時刻は[日本先物の時間帯](日本先物の時間帯と参加構造.md)を参照|
|価格の終了時計と、足の公開/利用可能時計|09:15に範囲が終了しても、構成する最後の足が判断時点に未公開なら、その完全な範囲を既知としない。許容する猶予・不準備の扱いを先に決める|
|端の確定後の固定と、範囲の更新|後続の高安で序盤範囲を広げれば、固定帯への反応という問いが変わる。後から見やすい幅へ更新しない|
|端と等号、外側残留、内復帰|端上の同値を、strict外側又はstrict内側へ都合よく混ぜない。今の終値位置だけと、以前の離脱を伴う復帰を分ける|
|同一帯の再試行・失効・場替|何回目の外側試行か、反対端到達後も元仮説を続けるかが結果を変える。初回だけ等の条件を結果後に選ばない|

## 15分判断だから、15分終値しか使えないわけではない

新規注文を許す時計と、そこまでの観測履歴の粒度は別である。[新研究条件](../15分判断と連続追尾の研究条件.md)は新規判断を15分ごとにする。定時までに公開された3分足等で枠間の経路を記録する余地はある。ただし、記録できた過去の突破をその時点で取引したことにせず、定時の現在価格から別途評価する。観測粒度が細かくても、原入力に受信時計がない限界は消えない。

**人工の情報欠落例**。上端110、下端100の既知レンジに対し、次の二経路を考える。

|枠内の価格順|枠のOHLC|分かること|
|---|---|---|
|109→108→112→111|O109/H112/L108/C111|初離脱前に安値があり、その後上へ離脱|
|109→112→108→111|O109/H112/L108/C111|上へ離脱→内へ復帰→再離脱|

終値もOHLCも同じだが、「初突破後の失敗」は違う。OHLCだけから高値・安値の順を補ってはいけない。細かい足でも同じ足内に両方あれば未解決として残す。

定時の終値が前回も今回も外側なら、分かるのは**二つの定時に外側だったこと**であり、間に内復帰しなかったことではない。前回内・今回内でも、枠間の外側試しがなかったとは言えない。終値だけを使う場合は「定時外→次定時内」等の状態遷移に限定し、初離脱・連続滞在・物理最初の復帰と区別する。

## 複数手法と心理仮説を、観測できる役割へ分ける

|材料の役割|検証できる説明候補|この材料だけでは言えないこと|
|---|---|---|
|固定した序盤帯と定時の位置|序盤に取引された価格帯から離れた評価が維持されたか、元の帯へ戻されたか|全参加者がこの30分帯を共有している、端に損切り注文がある、という注文実測|
|離脱/内復帰の時系列|一度外を試した後の復帰が、未離脱の中央滞在と違う経路を持つか|内復帰した全件が反対端まで進む、撤退注文がその原因であるという断定|
|当時既知の方向背景と勢い|背景と離脱方向が一致した群と、相反した群で、その後の持続/復帰が違うか|背景指標の傾きが買い圧力そのもの、勢い低下が必ず反転という解釈|
|ATRと端からの距離・残時間|通常値幅に対してどの位置で取得し、125/250へ届く時間が残るかを記述|ATRが方向や成功を保証する、比の良い区間が事前に分かったという主張|

これらは**心理を反証可能な価格仮説へ狭める案**で、まだ採用閾値ではない。継続を予想したのに内復帰し、再開もしない例、内復帰後すぐ再離脱する例、混在して進まない例を残す。成功図だけから帯の重要性や勢いの閾値を決めない。

## 固定前に残す結論

- 初期レンジ30分の具体性は得られたが、**固定帯への15分定時の離脱/復帰＋方向/勢い/ATR**という候補全体の費用後優位は未確認。原典を合わせて一つの検証済みシステムにしない。
- 直接観測する位置、当時までの履歴から復元できる遷移、粒度のため不明な順序を別記する。離脱を確認する遅れと、その後の取得原価・残余値幅は両方残す。
- 全予定枠の待ち率≤50%は、論文の取引日率や発動率とは違う。保有継続を非待ちとする一方、活動条件のための保有延長や枠の事後削除をしない。
- 原典の時間退出や固定1:1返済を、現在費用後正の起動・最低名目床・定時外の非緩和追尾へ変えれば別検証である。入口の125/250、実回収、費用、品質、活動率を分け、目標は変更しない。
