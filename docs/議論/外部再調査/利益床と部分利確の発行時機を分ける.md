# 利益床と部分利確の発行時機を分ける

確認日：2026-11-08。外部説明、心理仮説、未検証の研究案を分ける。新しい市場条件の実行結果ではない。

## 一次資料の説明

[CME Directの追尾注文](https://www.cmegroup.com/tools-information/webhelp/cme-direct/cme-direct-trader-broker/Content/Trailing-Stop-Orders.html)は、有利な価格進行に追随してstopを移し、逆行時には緩めない注文として説明する。保護を動かしながら、残る建玉で順行を取りに行く考え方である。CMEのLast基準と、本研究の返済側気配は同一実装ではない。

[Leung・Zhangの原論文・2019版](https://arxiv.org/html/1701.03960v2)の要旨・導入では、線形拡散モデルの下で追尾stopを制約に置き、それより先に自発的に利確する時機も扱う。保護と利確の併用を考える材料になるが、NK225の板・費用・部分約定での実証ではない。モデルの最適価格や比率を直接移植しない。

[CMEのオシレーター解説](https://www.cmegroup.com/education/courses/technical-analysis/oscillators-macd-rsi-stochastics)では、強いトレンド中の過熱表示の持続や指標の遅れを扱う。RSIが高いというだけで全利確せず、価格構造と勢いの変化を区別する材料とする。[継続パターン](https://www.cmegroup.com/education/courses/technical-analysis/trend-and-continuation-patterns)の説明も、すべての押戻しを保有すべきだという主張ではない。

## 研究で分かったこと

[87](../../../study/00087_FAR参照玉と可変数量の比較/README.md)のG1は、費用後現在単価益が正になれば最低建値床を起動し、実確定益で残玉予算を作る部分収穫を行う。初回収穫はS主146玉中144玉が+20pt、数量割合の中央値は約76.9%だった。これは実観測で、固定100枚の割合ではない。

[83](../../../study/00083_構造否定と利益配分/README.md)のG2も、正益後最低建値床とATR追尾を備えていた。部分収穫を行わず残量で順行を追う比較であり、利益を放置する方式ではない。入口・100枚固定・Source退出の有無が異なるため、その金額を現在の可変数量方式へ比例移植しない。

心理の仮説としては、小さな利益を早く確定したい判断と、一時的な押戻しを許して伸ばす判断が競合する。人間の心理を直接測定した結果ではなく、機械側では「保護床の更新」と「何枚をいつ確定するか」を別の制御に分けるための説明である。

## 次の固定比較候補

まず同じ15分入口・元参照量・Source返済・費用・遅延で、G1と可変Source向けの保護付きG2相当を比較する。strict正益時の最低建値床は両方に残す。未約定の利確予定を保護予算に入れない。

その後、継続の肯定がある時だけ初回収穫を保留し、失速時に発行する案を考える。役割は次のように分ける。

| 役割 | 当時観測できる材料 | 注意 |
| --- | --- | --- |
| 継続の背景 | 上位EMA、価格が支持側を維持するか | 配列・傾き・収束を混同しない |
| 進行の失速 | 新高安を伸ばせない価格構造、MACDhist増分 | 1回の減速を反転確定としない |
| 反対側の補強 | 既知の反対OFI、価格帯への内復帰等 | 板OFIを真の出来高や建玉と呼ばず、未知を0支持としない |
| 値幅と保護 | ATRと非緩和床、最低建値床 | ATRは方向を示さない |

既存の全量返済条件と同じ「EMA反対側＋MACD反対」を部分利確へ重ねるだけでは、先行の全返済が優先し、新しい判別にならない。全否定より前の失速を別に定義する必要がある。ここで閾値や最適な割合を決定したわけではない。

保護付き全量追尾も、建値での約定なら費用赤字になり、要求後の急変では床より悪い価格になり得る。収穫を遅らせれば必ず改善するとは仮定せず、同実入口の出口差・参加変更・平均勝敗額・正益前後・費用と要求後悪化を分けて評価する。
