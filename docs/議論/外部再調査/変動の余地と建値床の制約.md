# 変動の余地と建値床の制約

2026-11-07本文確認。83の実装と並行して、ATR追尾の設計と早い返済・継続の違いを一次資料で確認した。今回の数値設定を利益確認済みとする資料ではない。

## 資料で確認したこと

[StockChartsのChandelier Exit公式説明](https://chartschool.stockcharts.com/table-of-contents/technical-indicators-and-overlays/technical-overlays/chandelier-exit)は、期間の高安とATRの倍率から停止線を作り、トレンドの途中で早く退出し過ぎることを避ける目的を説明する。掲載既定例は22期間・ATR3倍で、変動が大きい銘柄では通常の押戻りで停止する反例も示す。これらは説明とチャート例で、NK225・15分新規・費用後損益を検証した成績ではない。

83は新規時3分ATR14の幅を固定し、最高方向値差からの床を下げず、最低建値・固定EMA線等を重ねる独自仕様である。資料のローリング高安・更新ATRによるChandelierと同値再現ではない。今回中に倍率や尺度を追加探索しない。

[CMEの決済教材](https://www.cmegroup.com/education/courses/things-to-know-before-trading-cme-futures/closing-your-position)は、事前の利益目標で早く出る場合と、継続を見ていて反転前の出口を失う場合を説明する。損切りでも、早く切ってから回復する例と、待ち過ぎて予定を超えて失う例を両記する。手動監視が機械的な出口より有利という検証ではない。

## 本研究の式から分かる制約

正益旗が立った後、G2の床は概略`max(前床,0,最高方向幅−D,有効な構造床)`である。最高方向幅がD以下ならATR項は非正で、最低建値0が支配する。したがってDを広げても、初回の小さな利益の後に建値へ戻れば撤退する点は変わらない。建値床を下げずに変動の余地を増やしたいなら、取得位置・初期逆行・回復確認の時点も含めて問う必要がある。

G1の部分確定は小さな進行から利益を残せる一方、残量が減るため、その後の大きな進行で得る額も変わる。G2は大きな進行を全量で取れる可能性と、建値返済で費用負けへ戻る可能性を両方持つ。どちらが総損益に有利かは、同じ実入口とその後の参加を分けて比較しないと分からない。

## 心理の仮説と次の観測

継続する流れの中でも利確や反対参加による往復があり得る。往復を許すことと、入口根拠が崩れたことを区別する仮説として、変動幅・価格構造・現在の勢いを別の役割にする。参加主体や注文目的は直接観測していない。
