# 上位方向との逆向きと反転確認を分ける

確認日：2026-11-06（日本時間）。公式教材と著者本人の記事を再確認した。DMI/ADXとGrimesの分類は既に収録済みであり、新発見ではない。今回は、**上位DIに逆らう候補を作ることと、価格の反転を確認することの違い**へ絞る。新しい市場入力・教師・54の実モデルを読まず、fit・市場再生は行っていない。

## DIの逆側を選んだだけでは、遷移を観測していない

以下は本研究の算術整理である。候補方向をs、現在の上位方向をd=sign(DI+−DI−)とすると、s×d<0は「候補が現在のDI優勢と逆」という関係を表す。過去の方向、交差、価格の防衛線破断を含まないため、それだけでは「今、上位トレンドが反転し始めた」という時系列の証拠にならない。DI同値は逆向きとは別である。

DXは100×|DI+−DI−|/(DI+＋DI−)を平滑化前の材料とする。分母が正のとき、両DIを交換してもDX、同じ履歴を交換したADXは変わらない。ADXが高いから買い、低下したから売り、という方向は導けない。DIとADXは同じ高安系列から作る指標体系であり、独立した二票でもない。[公式計算説明](https://chartschool.stockcharts.com/table-of-contents/technical-indicators-and-overlays/technical-indicators/average-directional-index-adx)

区別する対象は次の通りである。

|観測|分かること|まだ分からないこと|
|---|---|---|
|上位DIと候補方向の逆向き|上位の平滑方向に対して逆を選ぶ配置|押し戻り、往復、反転開始のどれか|
|局所帯の反対端から内復帰|固定した下位の帯に対する保存済み価格経路|上位方向が変化したこと、逆方向に十分な利幅が残ること|
|別途固定した価格の失敗・再開確認|その具体的な価格規約が成立したこと|将来のトレンド転換や利益の保証|

逆に、下位価格が先に変化して上位DIの平滑方向が残る可能性もある。したがって逆向きを一律に禁じる根拠にも、必ず反転として買う根拠にもならない。Grimesの「終了しても反対トレンドになるとは限らない」という区別は、この名称の過大解釈を避ける参考になる。[本人記事](https://www.adamhgrimes.com/technical-analysis-thinking-in-categories/)

## 53の構造問題と54の独自比較

[53の共通知見](../局所帯の反応で分岐を固定した比較.md)で確認した制約は、**F0_F40という保存木に限定した事実**である。採用資格を満たす葉10/22/23は全てF01=s×(DI+−DI−)/100の正閾値を要求し、DI逆側が到達できなかった。W30では逆側採用もあり、「53全体が逆側を禁止した」とはしない。局所帯Zに逆端復帰を含めても、実際のDI反転役割を確保するとは限らなかった。

54のD0は、価格ZとDIに対する候補の関係を二つの固定段にして、その4群内を17列の深さ2木で学習する独自案である。実際のDI分岐はfloat32化後のF01≤0と>0で、左にはDI同値やfloat32で零になった値も含むため、左枝を厳密なDI逆向きと同一視しない。最終の背景DI同値は役割未確定WAITとする。54の正本は[検証計画](../../../study/00054_方向と局所帯を先に分岐/検証計画.md)と[条件](../../../study/00054_方向と局所帯を先に分岐/条件.json)へ置く。原典の売買法や、反転確認の再現とは呼ばない。逆向きの群を別に置くことは、その群に十分な支持や利益が生じる保証ではない。

Zは自端継続又は逆端復帰のORであり、DIに対する同向・逆向とは別軸である。二段の固定分岐も、この二つを同じ心理へまとめる操作ではない。また、固定Z段をprice、固定DI段をtrendとしてpathのfamilyへ数える場合、異種family条件はその二段だけで充足する。同じ資格式を使っても53と同じ制約の強さとは限らず、子木が追加の異種技法を選んだ証拠とはしない。

公開済み上位足の時点、下位反応の固定帯と5本窓、DI同値、欠測、売買鏡像は研究側の規約である。DIがまだ優勢であることから未来の転換を補わず、下位の価格反応から上位の未公開状態も推測しない。ADXや新しい反転閾値を、この調査から54へ追加しない。

両資料は、NKの固定250/125先着70%、支持、費用後正、全定時枠の待ち50%以下、連続保護の達成を証明していない。分類を分けたこと、学習木が逆向きへ分岐できること、fit外の実績が改善したことを別々に確認するための参考である。
