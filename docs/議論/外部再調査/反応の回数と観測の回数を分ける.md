# 反応の回数と観測の回数を分ける

確認日：2026-11-06。[58の計画](../../../study/00058_同じ水準を追う再試験/検証計画.md)と並行した原研究の確認。既存の[水準を発見する窓と反応を追う寿命](水準を発見する窓と反応を追う寿命.md)を補う。

## 原研究で測っているもの

Garzarelli他の2014年刊行版は、2002年のロンドン証券取引所9銘柄を調べる。反発は帯へ入り、反対側へ貫通せず退出する一つの出来事である。観測尺度を変えると、細かな揺れを別の反発に数えるかも変わる。帯内にいる間の複数観測を、そのまま独立した反発回数へ置き換える定義ではない。[原論文、Methods](https://pmc.ncbi.nlm.nih.gov/articles/PMC3967202/)

同論文は費用・発注から執行までの遅れ・流動性を含む収益化を今後の課題とする。尺度として扱う秒数を、水準の有効期限と読み替えない。価格系列の記憶という解釈は、参加者の心理や注文動機の直接測定ではない。[原論文、Discussion](https://pmc.ncbi.nlm.nih.gov/articles/PMC3967202/)

Chung・Bellottiの2021年原稿では、水準の発見窓を変える比較と、前回反発からの経過を調べる比較を分けている。時間経過の関係は商品・条件で一様ではない。発見窓60分と、登録後60分で監視を打ち切るTTLは異なる設定である。[原稿、§4](https://arxiv.org/pdf/2101.07410)

## 本研究の分母を分ける

例えば同じbから生じたkが09:15、09:30、09:45で見えているとき、これは3判断枠、1つの形成である。各枠で別に新規/返済すれば取引数は増えるが、それも新しい価格形成が3回起きた証明ではない。

| 識別するもの | 記録する意味 |
| --- | --- |
| 固定水準と参照出典 | 何を同じ水準として追ったか |
| bの形成ID | どの突破試行から追跡を始めたか |
| r/kの足番号・公開key | 再試験と再開をいつ確認できたか |
| 定時の枠ID | 同じ形成を何回判断に使ったか |
| 実新規ID | 保有・返済後に何回参加したか |

58では、既存の枠支持を同条件比較のために維持し、形成IDのunique数・最大反復も表示する。形成数を使った新gateや再参加禁止は別の条件変更なので、今回の保持期間変更へ混ぜない。期限切れ、価格否定、未完成、形成なしも分ける。

長く追えば記録は増える。しかし学習材料の独立性や費用後の優位性が同じだけ増えたとはいえない。新しい機会を見つけたのか、同じ機会を繰り返し見ているのかを先に区別する。
