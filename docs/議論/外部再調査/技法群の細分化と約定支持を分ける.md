# 技法群の細分化と約定支持を分ける

確認日：2026-11-06。試行70の事前調査。相場の説明を増やす前に、複数技法をどこまで細かく分けて評価できるかを点検する。

## 追加で確認した一次資料

scikit-learn開発者の[Decision Trees公式説明](https://scikit-learn.org/stable/modules/tree.html)を、取得時の1.9.1版で確認した。冒頭の長短、標本数と深さ、回帰、最小費用複雑度剪定の節が対象。細かすぎる木の過適合と不安定性、葉の標本数制約を説明している。公式の剪定は不純度と葉数の罰則を扱う。本研究の約定支持による統合は別の規約であり、公式の `ccp_alpha` 最適化を再現したものではない。

これは統計手法の実装者による解説であり、NK225の利益・取得価格・相場心理の実証資料ではない。資料が挙げる原著そのものは今回実読していない。既読の[局所と広い構造](局所の否定と広い構造の継続を分ける.md)で扱った、定義の細かさと対象の広さの交換条件とも重なる。

## 研究への接続

以下は本研究側の推論である。無取引0を含む回帰標本が多数あっても、その技法群で約定し、先着率を確かめられる例が多いとは限らない。指標条件を増やして見た目の説明が細かくなることと、判断を裏付ける約定例が残ることを区別する。

広い親群へまとめると、同じDI方向・価格経路でも、勢い・量・取得位置が異なる局面が混ざり得る。支持が増えても先着率や費用後平均が改善する保証はない。親の統計は所属全体の値を使い、子の平均の単純平均では作らない。まとめたから参加者の心理が同じになったとも解釈しない。

[試行70の計画](../../../study/00070_約定支持を保つ粒度で技法を組み合わせる/検証計画.md)は、学習時の約定60枠・6日・10場を保てない分割を両側まとめる。scoreや利益を見て統合場所を選ばず、固定した方向・価格経路の大枠を残す。支持を満たしても、複数技法資格・先着score・回収条件は別に検査する。新fitは行わない。

次の[取得位置の仮説](継続の方向と取得位置と短期保護を分ける.md)も、この粒度と別の比較軸である。強い方向と伸びた価格での参加を区別する心理仮説は保つが、70で新価格特徴を同時追加しない。全予定の活動、先着250/125、実追尾損益、費用と品質を別々に確認する。全66場は既使用で、支持付き70%と未知期間の利益は未証明である。
