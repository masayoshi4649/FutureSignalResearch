# 正益起動と価格同値床の意味

確認日：2026-11-10。これは既存P100コードの確認と、新しい保護を考えるための手製算術である。117は未採番・条件未固定・市場未実行。正益直後起動の収益改善や約定保証を示した資料ではない。

## 起動・価格床・費用後目標を分ける

miniは100円/pt、片道税込38.5円とする。片道滑り想定をS pt、取得価格E、返済側気配m、買いs=+1・売りs=−1、実残数量n、初期実数量q0、同じ実Positionの部分返済純額Rと置く。買いのmはBid、売りはAskであり、Lastだけの含み益と区別する。

```text
g = s(m−E)                         符号付き順行幅pt
K = 77 + 200S                     往復費用 円/枚
κ = K/100                         往復費用pt
u = 100g−K                        残1枚の費用後評価円
W = R+n u                         同じ実建玉全体の費用後評価円
ceil5(x) = 5 ceil(x/5)             mini価格床の5pt丸め
```

Rは実際に部分返済された配賦の純額だけを使う。別の玉の利益やSource仮想残量を持ち込まない。nは部分返済後の現在数量であり、初期枚数を最後まで仮想保有しない。

旧P100は`W >= q0×10,000円`で起動する。次に比較する厳密な`W>0`は、閾値の数字を0へ変えた`W>=0`とは別定義になる。実保有n>0と既知の正常返済BBOを前提とし、n=0では新起動・床更新をしない。最低価格床をEに置くことと、費用後全玉ゼロを約束することも異なる。

|費用|K円/枚|残1枚の費用後ゼロ床 `ceil5(κ)`|現P100の余白付き最低床 `ceil5(κ+5)`|
|---|---:|---:|---:|
|C0：片道滑り0pt|77|Eから順側5pt|Eから順側10pt|
|C5：片道滑り5pt|1,077|Eから順側15pt|Eから順側20pt|

現P100の10/20pt床では、残1枚あたり923円の費用後余白になる。式中の5pt余白と、5pt刻みへの丸めを混同しない。ラージ板の10pt刻みを丸め式へ入れているわけでもない。停止済みP100の実API4鏡像でこの差を確認した。実使用コードの所在は[正式115コード索引](../../../study/00115_三時間軸の方向性と局所構造で入口を分ける/再現資料/コード所在索引.json)、確認の履歴は[設計確認](枚数と短期保護の整理資料/正益床の設計確認.json)に残す。

## E床へ変えるには全玉目標の初期値も変わる

全玉目標をL円とした価格床は、次式で表せる。

```text
F_W(L,R,n) = ceil5((nK+L−R)/(100n)), n>0
床fが含意する全玉額 I(f,R,n) = R+n(100f−K)
```

最低価格床だけ0へ変えても、旧TargetのL=0を残すと`F_W(0,0,n)=ceil5(κ)`が働く。このため、価格同値床Eから始める手製案では、起動前のLを未設定にし、最初の厳密W>0観測で一度だけ`L_init=R−nK`を代入する。この初期値なら`F_W=0`となる。`max(旧0,R−nK)`では価格同値床の案にならない。

初期化後の床fとLは不利に緩めない。通常追尾や有効な構造床がEより有利なら、最初からその床が優先する。「最低床E」は、実際に採用される床が常にEという意味ではない。

```text
f := max(0, 前回f, F_W(L,R,n), ceil5(Peak−Width), 有効な構造床)
L := max(L, I(f,R,n))
```

この案の初期Lは負になり得る。R=0ならEで返しても費用分は赤字になる。既に部分返済で価格損失を出したR<0なら、その損失も残るため「赤字は費用だけ」とは言えない。逆にR>0なら、残玉がE以下でも全玉W>0となる境界があり、起動時点で既にE床hitとなり得る。

新しい有利な峰が生じ、候補床を現在gainより1mini呼値以上後ろに置ける場合だけ、費用後全玉ゼロや余白目標へ段階的に引き上げる手製案も確認した。この5ptの余地は未検証の設計条件であり、最適閾値ではない。部分返済益により既存床の含意額が上がる更新と、新しい目標を追加採用する更新を分ける。

## 即起動は即約定ではない

R=0の手製mini5pt格子では、C0の最初の正益gainは5pt、C5は15ptになる。その場で厳格な費用回収床を置くと等号hitとなる。価格E床はこの例ではhitしない。一方、最初の正益が大きく跳んで観測される場合まで、必ず即返済になるとは言えない。これは観測格子の反例であり、実Rawの最初性や刻みを検証したものではない。

`Active`、床hit、返済要求、実約定、最終純額を別に記録する。現Actorの自己返済要求はafter_sourceで未予約量n−rへ出し、D0でも同Indexでは約定しない。D1はさらに価格時計1秒以上を待つ。次の正常返済BBOで約定するため、E床で要求しても実返済価格がEになる保証はない。Activeは内部保護状態で、取引所に非常用逆指値が登録された証拠ではない。

たとえば2枚をEで返せれば費用による赤字はC0で154円、C5で2,154円。要求後の正常気配がgain−5なら、それぞれ1,154円、3,154円の赤字になる。後者の追加1,000円は価格逆行であり、費用赤字と分ける。この例は手製の執行反例で、退出後の取り逃がしを算出していない。
