## 心理を仮説へ翻訳する

ここからは研究側の推論であり、注文動機を測定した事実ではない。例えば上への突破が押し戻されれば、買い手の利確・損切りや新規売りが重なる可能性がある。しかし売りが持続するか、買い直されるかは別の問いとなる。元の買いの理由がなくなっただけで、新規売りの理由が完成したと扱うと、この区別を失う。

反対に、以前の失敗を記録することには価値があるが、その記憶を現在も有効な仕掛けとして扱うべきとは限らない。現在の水準・価格進行・上位方向・短期の勢いを合わせ、何がまだ成立しているかを判断する必要がある。

## 再利用する判断の分離

| 層 | 当時の情報で答える問い | 記録するもの |
| --- | --- | --- |
| 仮説の登録 | どの水準をどちら向きに突破したか | 元方向・固定水準・登録時刻・形成ID |
| 現在の有効性 | 否定・期限・品質問題が既に生じたか | 現在有効旗と理由。未登録と取消を区別 |
| 構造の進行 | 再試験・再開など何を確認したか | 達成段階と各公開時刻。未形成も残す |
| 複合判断 | 上位方向・勢い・値幅と整合するか | 使った技法・時間軸・閾値。相関する二つの価格旗を独立した二票としない |
| 発注と退出 | 今の価格で入れるか、保有をどう守るか | 新規判断と保有退出を分け、遅延・費用・連続追尾を適用 |

売り買いは符号反転した同じ条件にする。成功した後続足を見て過去のsignal足を選ばず、完成足の公開時点に限定する。15分判断では当時の価格へ発注し、過去の確認価格へ約定を戻さない。

## 試行61への接続と限界

既存のT/R episode有効を先頭に使い、四群へ分ける。0/0は未登録・取消・失効などを含み、1/0・0/1・1/1も登録が残っているという意味にとどまる。有効1には再試験rや再開kの未形成が含まれる。T/Rは別の登録水準・元方向を持ち、最終のDI順行/反転という役割とも別である。

旧60と同じ46特徴を使うため、これは新情報の追加ではなく、分割順と学習容量配分の比較になる。price二根に変えると、旧Z→DI二根では構造上満たしていた複数技法資格が自動では満たされない。子のtrend/osc使用、支持不足、先着score不足を分けて追う。旗だけによるエントリー成立や、改善を事前に断定しない。
