# 板数量と将来の方向予測を分ける

2026-11-07。[84の候補](../チャート方向に現在の価格応答を重ねる候補.md)作成後の追加確認。今回の閾値・入口・利益保護はこの再読で変更しない。

Cont・Kukanov・Stoikovの[原論文](https://arxiv.org/abs/1011.6402)と[公開本文v3](https://arxiv.org/pdf/1011.6402)の概要、1.1、表4の説明を確認した。NYSE50株の最良気配で、注文追加・成行・取消を含む需給差OFIと、短時間の価格変化との関係を検討している。売り成行と買い取消が同じ気配数量減を生む場合もある。表4のOFIと価格変化は同期間の量であり、その説明力を次期間の方向正解率へ読み替えない。

## 本研究で区別するもの

| 観測 | 84での役割 | そこから直接は言えないこと |
| --- | --- | --- |
| 3／15分EMA・MACD・RSI・ATR | 背景、現在の勢い、急変警戒、取得位置 | 今後も同方向へ進む確率 |
| FARの両気配帯の維持 | 判断時にも過去の進行が維持されているか | 取引所全イベントを観測したこと |
| 同価格表示数量の回復 | 定義した回復点が当時有効か | 約定出来高、参加者の意図、将来の支持 |
| 既存OFI30補助 | 既知反対拒否・失速時確認 | 論文と同じデータ品質・尺度・収益性 |

心理の仮説は、背景方向に沿う追随と反対圧力の応答が続く局面を分けること。買戻し、新規買い、取消、差替えの内訳を本データで直接識別したわけではない。数量回復という名前から参加者の確信を作らない。

本研究の価格時計・物理行・源Features番号・価格更新番号は、受信時計や取引所の全注文イベント番号とは異なる。保存時点で使える範囲の複合条件を再生し、費用・次板約定・未観測と、NK225で実際に得た成績を別に記録する。論文の関係を根拠に70%や黒字を前提とせず、C0へQを加えるC1が勝ちを落とす反証も残す。
