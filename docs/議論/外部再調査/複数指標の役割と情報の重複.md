# 複数指標の役割と情報の重複

確認日：2026-11-08。複数手法は、何を確認する条件なのかを分けて組み合わせる。同じ価格履歴を加工した指標が三つ一致しても、独立した証拠が三つ得られたとは数えない。

## 再確認した説明

[IBKR Campus掲載のMarketLife教材「Using Indicators」](https://www.interactivebrokers.com/campus/trading-lessons/using-indicators/)の本文「Guidelines for Using Indicators」「Different Ways to Measure」を確認した。計算の意味と指標間の重複を理解するよう説明し、範囲に収まるRSI等と、固定範囲を持たないMACD等を区別している。IBKR自身の実証論文ではなく、教材提供者の解説である。

[CME「Oscillators: MACD, RSI, Stochastics」](https://www.cmegroup.com/education/courses/technical-analysis/oscillators-macd-rsi-stochastics)の本文は、強いトレンド中に過熱表示が長く続き得ることと、他の情報と併用することを説明する。一方、冒頭の固定範囲という総論をMACDにまで適用せず、計算式を優先する。MACDが正というだけで買われ過ぎ・逆売りとは定義しない。数量についても、教材の出来高を保存板の表示待機量へ置き換えない。

どちらもNK225の5分新規、特定の組合せ、70%の勝率、費用後利益を実証する資料ではない。

## この研究への適用案

以下は資料を踏まえた独自の設計整理であり、有効性の検証結果ではない。

|役割|答えたい問い|候補|混同しないこと|
|---|---|---|---|
|背景の方向|どちらを順行側として調べるか|複数確定足のEMA配置・傾き、価格構造|平均が上向きでも、現在の上昇が再開したとは限らない|
|現在の勢い|背景側の押す力が改善しているか|MACD差の増減、ROC、確定足の進行|MACD水準と増分は別。勢いの改善だけで構造突破を認定しない|
|急変の警戒|通常の継続と一時的急伸を分けられるか|RSI変化、足値幅とATRの比|高いRSIが継続した状態と、単発急変を分ける|
|価格上の成立・否定|どこを維持・奪還・喪失したら判断を変えるか|当時既知の高安、押戻し、支持抵抗|未来の山谷を当時の線へ戻さない|
|量の同意|定義した量が価格方向を補強するか|表示量、数量変化、OFI、約定出来高を別々に扱う|静的板とフロー、注文取消と成行消化を同一視しない|
|値幅と退出|通常変動と許容する否定幅はどれくらいか|ATR、実建値からの連続追尾|ATRは売買方向を選ぶ指標ではない|

背景・成立・警戒・退出へ同じ役割の条件を重ねるときは、追加条件が何を変えたかを別の比較にする。全指標の全条件を一度に必須にすることも、例示した二指標だけに限定することも避け、各試行の汎用表へ採用・未使用・未知を明示する。

市場心理としては、背景に残る追随、押戻しでの利食い、再開時の新規参加、支持否定時の手仕舞い等が候補になる。ただし表示板・価格だけから主体の意図は確定できない。心理の説明を、確定足・公開済みの価格反応・量の窓端という観測へ翻訳してから比較する。
