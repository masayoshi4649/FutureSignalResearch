# 幅と保有時間と数量枠を一緒に比較する

2026-11-15。[168](../../study/00168_固定複合入口を片側十枚の数量枠で再生する/README.md)と[169](../../study/00169_数量枠の下で技術近傍と任意幅を再探索する/README.md)の診断を、次の[170](../../study/00170_ATRと三時間帯の幅で複合入口を数量枠に適合させる/README.md)へつなぐ。170の優位を事前に断定しない。

## 独立入口と数量枠

入口を一件ずつ独立mini一枚で集計した成績は、同時に買い十枚・売り十枚以内で実行した口座収支とは異なる。保有時間が長い入口が集中すると、次の要求時点で枠が埋まる。枠を守ると取得集合が変わり、先着率も利益・損失も変わる。独立一枚の利益を十倍して、片側十枚の収支としない。

数量枠はq0時点の保有と未決注文の予約から判断する。未約定要求も枠を使い、取消・失効・観測済み決済でのみ解放する。数値表に同秒決済の原行順が無い場合は、その秒を保有継続として保守的に扱う。金融未知の建玉を0円で決済して枠を空けない。場末返済価格が不明なら全件収支を未知とし、既知分の合算を別記する。

168の主案は旧73場で672取得・195順86逆・69.395%、追加七場で123取得・40順18逆・68.966%となった。全場参加と平均概ね一回/時を維持し、買売各十枚を守れたが、数量枠込みで70%には届かなかった。これを枚数を増やす根拠にはしない。

## 幅を変える意味

同じ技術式でも、幅を変えると先着の意味と保有時間が変わる。その結果、枠が解放される時計、後続の要求の採否も変わる。固定済み取得の損益だけを別の幅で再計算する比較と、各幅で数量枠から再生する比較を分ける。

169は30幅対・四期限・技術近傍を各々cap10で再生した。全期の発見支持は106政策あったが、前48場だけの固定選択A/Bはともに不適格だった。前半70%以上の四政策はすべて金融未知10%を超えた。率以外の支持を満たす808政策の最高は142順63逆・69.268%だった。後の成績を使ってA/Bを入れ替えず、全期発見と過去だけの選択を区別する。

## 次のATR仮説

[FidelityのATR説明](https://www.fidelity.com/learning-center/trading-investing/technical-analysis/technical-indicator-guide/atr)（確認日2026-11-15）は、価格の変動幅に応じてストップ距離を考える用途を説明する。ATRは方向予測の代用ではない。170では方向・勢い・量・価格位置の複合入口を維持し、主枝の対称IFD幅だけを当時の5分ATRに比例させる。

共通倍率と、米国前を狭く・以後を広くする三帯倍率を比較する。ATR自体で時間帯差を吸収できるなら追加倍率は不要かもしれない。いずれも検証前の仮説であり、先着率改善の事実ではない。幅はq0で決め、取得後に有利な幅へ付け替えない。未知ATRは主新規不成立とし、技術初参加補完の既定幅と区別する。

評価は成立した取引の実現損益、先着・未到達・観測不足、頻度・参加・枠利用を使う。数量棄却の件数は運用条件として記録するが、棄却後の仮想利益を機会損失として最適化しない。
