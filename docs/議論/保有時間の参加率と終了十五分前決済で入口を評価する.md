# 保有時間の参加率と終了15分前決済で入口を評価する

2026-11-22の更新。下記の開始待機は11月16日時点の指定。現在の日経デイは開始20分・30分待機を比較し、終了前のノーポジションは引き続き適用する。[両端の時間条件](セッションのノーポジションと建玉保有時間を区別する.md)

2026-11-16、178報告後のユーザー指定。参加率は「対象時間のうち1枚以上を保有している時間」で測り、20%以上を目指す。ユーザー回答により、開始の一律待機は設けない。

- 対象時間はデイ08:45〜15:30、ナイト17:00〜翌05:45。場終了15分前には全決済する。米国前後の境界はNY09:30を夏冬自動変換する。
- 分子は実取得代用から決済代用までの保有区間の合併長。注文待ち・未取得・同一秒の重複を含めない。米国前から後にまたがる保有は時間帯ごとに分割する。
- 主は全対象時間による加重参加率。デイ・ナイト別と米国前後、セッション別の分布、20%に達した場数も示す。場別20%を新しい必須条件にせず、偏りを隠さない。
- 欠測を分母から落とさず、決済不明時の保有は確定下限と可能上限を分ける。不明な保有を満額加算して20%達成としない。
- 買売合計で保有・予約1件、追加建て禁止、費用後の建玉別・セッション別両中央値黒字は継続する。先着70%は硬い足切りにせず、頻度・量・損益の広がりも比較する。
- 利益集中は全場を残した中央値、黒字場数、上位1/3/5場への利益集中と除外後収支、累計DD、前後期間で点検する。利益のある場を事後に除外して採用損益を作らない。

終了時計の変更は既存取引の出口だけを差し替える処理では足りない。枠の解放と後続入口まで口座全体を再生し、既存174/177/178の新時計対照も同じ条件で比較する。旧試行の固定結果は変更しない。

[179](../../study/00179_保有時間参加率と終了前決済で入口を広げる/README.md)で適用済み。締切1分前から新規・予約を止めて全決済を要求し、1秒以上後かつ締切内の最初の正常BBOで決済代用する。最後の正常価格を事後に選ばず、欠測で締切内決済を確認できない場合は未知を残す。執行用の1分は分母に含める。

全期主J035は、保有率下限がデイ51.88%・ナイト28.94%。場別20%達成を確定できるのは39/40デイ・26/40ナイトで、全場達成ではない。デイの取得数は161→153へ減ったが、黒字場は27→31、上位3正純益場を除く診断収支も170,758円→666,682円へ改善した。長く保有する政策では、回数と時間参加率は逆方向に動き得る。

改善したデイの追加枝は、長期MACD Hist増分が未公表の時に使う局所的な複合入口である。これはデータ可用性による分岐であり、長期方向の一致を確認できた意味ではない。選ばれた枝は追加出来高条件なし（V0）。量を加える候補も試したが、今回の利益改善を量の有効性の証明とはしない。複合入口単体の独立取引合算と、1件枠の再生による政策全体の成績も区別する。

ナイト入口は旧178のままで、追加4ナイトは既知収支−126,924円。全80の金融未知は5件あり、前48場選択の後25場悪化も残る。デイ改善を有望な結論として新探索を一旦止めるが、将来の安定再現を確認したとはしない。[候補別CSV](../../outputs/00179_保有時間参加と終了前決済/README.md)。
