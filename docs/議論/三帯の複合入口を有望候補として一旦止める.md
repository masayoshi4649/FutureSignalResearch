# 三帯の複合入口を有望候補として一旦止める

2026-11-15。[171の固定主案](../../study/00171_三時間帯で順行と回復失敗の確認を切り替える/README.md)を研究上の有望候補として残し、新しい条件探索を一旦止める。250ptへ固定せず、技術条件・幅・期限・数量枠を分けた結果である。153の当時の一旦達成判断は変更しない。

## 固定した判断

| 判断q0の帯 | 入口の組み合わせ |
|---|---|
| デイ | MACD・RSI・ADX・相対量の複合順行MP0057と、BB端・ヒゲ・動力・量の弱い回復へ逆らうEX0076を合成 |
| ナイト・NY09:30前 | デイと同じ複合条件を維持 |
| ナイト・NY09:30以後 | MACD・RSI・ADX・相対量がそろう複合順行MP0057を使い、EXの即時反対売買は行わない |

`MOMENTUM_ONLY`は単一のモメンタム指標を意味しない。複数技術の順行条件へ限定する識別名である。NYの夏冬時間は自動変換し、帯境界の強制返済は加えない。指標は当時の公表済み値だけを使う。

主枝は順行200pt・回復失敗400pt、技術初参加補完200ptの対称IFD、期限H60。各要求mini一枚、買売各十枚に未決予約を含める。初参加補完は166の長中短8票と、長期未公表時の局所6票を維持する。5分・15分の定時新規には戻していない。

## どこが改善し、何が残ったか

同じ644取得を全枝±125ptで再観測した出口診断も残した。両方の損益が既知の609件では、主案の利益7,760,355円・損失3,438,248円に対し、125ptは利益4,156,972円・損失3,184,865円、差引はそれぞれ4,322,107円と972,107円だった。共通既知分の差は3,350,000円である。125ptだけ損益既知の22件を加えた差額と混同しない。この診断は同じ取得集合に対する出口比較であり、125ptで数量枠から再生した別の運用収支ではない。

168の同じ固定二枝を全帯で使うcap10主案は旧73場69.395%だった。171はNY以後の技術判定を切り替え、旧73場の同帯既知差引が−800,091円から+204,379円へ変わった。枠解放後の後続取得も変わるため、単に既存取引の負けだけを取り除いた比較ではない。条件束の変更と数量枠を含む再生の結果であり、個々の指標単独の効果とはしない。

すべての帯・期間が70%という結果ではない。旧前48場は67.442%、後25場79.699%。旧73場の米国前は48.936%・既知差引−47,396円、追加7場の同帯も到達5件・20%・−68,694円だった。全体はデイの寄与が大きい。

前48場だけから選ぶA/Bはともに支持不適格で`null`のまま保持した。固定主案を全期最高額へ入れ替えていない。旧73場は条件設計で既使用、追加7場も先行基準案の確認後に再利用しており、新規独立未見とは呼ばない。将来の70%再現や実mini板での注文成立を保証するものではない。

## 再利用と次の問い

幅・期限・順逆の観測は共用価格索引、当時特徴からの純出生、数量予約の再生、三帯の技術ルートを分けて再利用する。大きな原板や全統計のMD転記を試行ごとに増やさない。[先着時計](任意幅IFDの先着確定と未到達を分ける.md)、[幅と数量枠](幅と保有時間と数量枠を一緒に比較する.md)、[171の閲覧資料](../../study/00171_三時間帯で順行と回復失敗の確認を切り替える/閲覧資料.md)を参照する。

今後再開する場合は、米国前の弱い群、前半と後半の差、未到達後の利益保護、金融未知35件、数量の確信度への配分を別々の問いにする。現在の単純IFD入口比較へ後付けで追尾を混ぜず、利益保護は新しい出口比較として扱う。
