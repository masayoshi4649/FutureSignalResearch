# 高安帰還と外側継続の同時点判別

確認日：2026-11-05。[試行37](../../study/00037_高安帰還と外側継続の判別/README.md)の共通知見。条件・数値の正本は[事前計画](../../study/00037_高安帰還と外側継続の判別/計画.md)、[設定と結果](../../study/00037_高安帰還と外側継続の判別/設定と結果.md)、[対応診断](../../study/00037_高安帰還と外側継続の判別/対応診断.json)。全66場が既使用の追加開発であり、未見検証ではない。

## 高安値とBBの内側は異なる

[36の量比比較](価格失敗へ量比の方向変化を加えた比較.md)で残った問いは、同じ「BB内終値」でも、過去の高安へ戻った反転と、その高安を越えたままの継続を分けられるかだった。旧29の価格Pは、3分の過去20公開足の安値/高値を当足で更新し、終値が旧BB20±2σのstrict内というもの。旧高安の内側への終値帰還や、ヒゲの旧BB外到達は要求していなかった。

過去高安を支持・抵抗として扱い、突破後の役割転換を考える一般的な説明は[CMEの教材](https://www.cmegroup.com/education/courses/technical-analysis/support-and-resistance)にある。ただし、本試行の20足・strict境界・MACD差の組合せやNK225の成功率を裏付ける説明ではない。支持・抵抗は実際には帯として考えられるが、今回は比較可能な点の条件を先に固定した。

心理の仮説は、安値を更新しても旧範囲へ戻れば下への追随が続かなかった可能性、安値の外に終値が残り下向きの勢いも続けば売りの継続可能性がある、というもの。高値側は符号を反転する。参加者の注文や意図を直接観測した事実ではない。単に旧範囲へ戻っただけで上昇継続が保証されるわけでもない。

## 位置と勢いで反転・順行・待機を分けた

過去20足の安値をL、高値をH、当足終値をCとする。元Pの反転方向をs（安値更新なら+1、高値更新なら−1）、元境界をK（安値側L/高値側H）とし、中心化MACD12/26/9ヒストグラムの現前差をΔhとした。MACDのトレンド・勢いという一般用法は[Fidelityの教材](https://www.fidelity.com/learning-center/trading-investing/technical-analysis/technical-indicator-guide/macd)を参照。差分の符号を本試行で使うことは研究仮説である。

|入口|価格・勢いの条件|実際の注文方向と役割|
|---|---|---|
|B0|旧29R0と同じ価格P、共通M、時間条件、s×Δh>0|s方向・反転。完全な基準|
|R1|B0かつL<C<H|s方向・反転。旧範囲の全体へ帰還|
|T1|旧価格P、元Pの共通M、時間条件、s×(C−K)<0、(−s)×Δh>0|−s方向・順行。元境界の外側で勢い継続|
|S1|R1/T1の技術候補を同時点で分類して併用|新規約定時に反転/順行を固定|

共通Mの元P数量準備、同OBV区間、ATR等は保持し、OBV非追随・VR・新しい数量値閾値は追加していない。元Pを全件から調べ、Tを旧R0不採用の補数にしたり、反転の先着ラベルを逆に読んだりしていない。Tの新方向BBOから先着を新計算した。

新R/T/Sの位置・勢い判別では、境界の等号や価格と勢いの不一致は待機。B0は旧29を完全維持するため、この位置の待機規約を足していない。同時計・原板行に複数候補があれば、同方向でも全て見送る。Sは保有中の役割変更や自動ドテンを行わない。Tの「極値更新」と「終値が旧境界外」は有効OHLCの下で重複するので、独立した二つの根拠とは数えない。

R1には元境界への帰還だけでなく、**L<C<Hの全範囲内**を要求した。反対端を突き抜けた終値まで帰還扱いすると、一つの大きな足を安値側の反転買い・高値側の順行買いの両方として数え得るためである。[24のf/g](終値内復帰と外回復を上位状態で選別する.md)は30分6足の固定範囲、突破の先行登録と後続の内復帰/外回復を使う。37は3分20足の当時範囲、旧BB、同一足の位置/勢いを使い、後続監視を足していない。

四入口とも事前の件数・日数・場数の支持条件を満たしたが、主率/間引き率の70%条件は未達。R1で除いたB0の群は学習11/32＝34.38%、選択10/33＝30.30%で、残した群を上回った。「範囲へ帰還した方がよい」という説明だけで採用できない。除外群の逆方向が有利とも、この表だけでは言えない。

Tはこの比較でB0/R1より主率が高かったが、元P・方向・事例集合が異なる。RからTへの同一事例での処置効果ではない。全仮約定を分母にし、観測不足と期限未達を残す。混合S全体の支持・率を各役割の成績へ代用しない。

Sの純反転/純順行集合は各単独R1/T1と全期間で一致した。一方、実一建玉では保有・返済待ちが後続を抑止する。単独二案の取引と利益を足した数値は、Sで同時に実行できる成績ではない。

B0→R1は純集合のsubsetでも、実新規では学習・選択それぞれ3件の追加があった。先の登録を見送ると後の候補へ参加できるためで、同時点の価格選別と一建玉全体の参加差は分けて測る。

## 次に分ける問い

構造と勢いで順行/反転/待機を機械的に分けることはできたが、その分類だけでは70%と安定収益を達成しなかった。Tの高い相対先着率だけで順行を採用せず、Rの不調だけで反対注文を採用しない。

次は、**発動時点の上位方向が、短期の外側残留を継続と見てよい局面と、長期方向へ戻る途中の一時的な突出とを区別するか**を候補にする。既存28の一目、22のADX/幅、24の上位選別の結果を先に照らし、同じ条件の焼き直しや閾値総当たりを避ける。上位情報をただAND追加しても成功を除く場合があったため、準備だけの除外・値による選別・役割別支持・同じ新規の出口・実参加を再び分ける。具体条件と効果は未検証。

回収では、仮250成功でも早く退出した事例と、正益前に125へ向かう事例を分離して扱う。将来の峰を用いた利確や、最低同値追尾を外す比較を実行成績へ混ぜない。新しい入口仮説の70%評価と、費用床や技術的な退出の改善は別の検証として残す。
