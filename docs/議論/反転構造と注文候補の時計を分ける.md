# 反転構造と注文候補の時計を分ける

確認日：2026-11-08。固定96の公開型・技法B・5分出生処理から確認できる範囲を整理する。新しい売買条件や採用判断ではない。

## 固定Bが確認していること

[固定96の技法B](../../scripts/FAR5分枠の順行反転と数量/technical_gate.go)は、**Source出生方向を維持したまま**、上位15分EMAの配置に逆らう候補を判定する。最新の連続3分足a/b/cに対し、`L=a時点のEMA8_3`を固定し、a終値は候補方向の反対側又は同値、b終値は奪還、c終値は同じLを維持し価格・RSIが再進行することを要求する。共通の勢い・取得位置・数量・品質条件も別にある。

[固定96の結果正本](../../study/00096_5分枠の順行反転と現在数量/成果物/結果.json)ではB成立0・取得0だった。ただし必要条件の交差がどこで全て落ちたかの詳細は、本稿では未確定とする。市場に反転がなかったことや、出生時計が原因だったことを示す結果ではない。既存Sourceの方向を反転して注文する方式でもない。

## 価格位置を確認できても、反転の全過程とは限らない

|公開済みの材料|確認できること|その材料だけでは証明できないこと|
|---|---|---|
|3分Close、EMA、直前足、Recent3|固定Lのどちら側で確定したか、別の後足で維持・再進行したか|Lが以前支持として機能したこと、実際にLを再試験して失敗したこと。公開SnapshotにはOHLCやヒゲがない|
|3/15分EMA、MACDヒストグラムと増分、RSI、ATR/TR|平均配置・相対的な勢い・値幅と急変を別の役割で確認|主体の売買意図や、EMAの逆配置だけから反転が確定したこと|
|枠時点のBBO、CurrentのOFI/E08等|当時の価格位置と、定義した窓での量・既知性|枠間の量の全推移。板減少だけから成行消化と取消の区別。帯Active=falseだけから支持価格の突破|

型の正本は[チャートSnapshot](../../scripts/複数尺度チャートの助走/bank.go)と[技法入力](../../scripts/FAR5分枠の順行反転と数量/technical_gate.go)。Recent3は[当場で公開済みの直近3足](../../scripts/FAR5分枠の順行反転と数量/chart_context.go)であり、保持→喪失→回復試行→反対進行の全履歴を記憶する状態ではない。AvailableAtと、公開をdrainした上限のObservedClock、特徴器と全受理NKの連番を混同しない。

「支持喪失→回復失敗→反対進行」を明示的に観測する将来案には、事前に固定した線の由来・方向・scene/限月・公開時計/原行と、各公開点・失効理由を追う別の観測状態が必要になる。終値で回復未達だった形と、線を実際に試して拒まれた形は分ける。未知を突破や不成立へ補完しない。

## 観測成立と、注文候補があることは別

[5分出生処理](../../scripts/FAR5分枠の順行反転と数量/entry_grid.go)は、一出生を `300×(floor(birthAt/300)+1)` の最初の次枠へ一度だけ割り当てる。quiet、取消、未取得、Source返済予約、空き不足、未知や技法拒否で消費した機会は、後枠へ復活しない。元の方向・親段階・出生量を維持し、取得済みSourceの現在残量と片側余力にも従う。[技法callback](../../scripts/FAR5分枠の順行反転と数量/entry_gate.go)は、その金融上の適格性を通った候補の採否だけを返す。

**旧Bには「3足ともSource出生後」という条件はない。** 既に公開された出生前の足も使える。一方、将来「出生後に3足を新たに確認し始める」案なら、a→cの足終端差だけで360秒必要で、最初の次枠まで最大300秒の時計では完結しない。この制約を旧B成立0の原因には使わない。

[Runtime](../../scripts/FAR5分枠の順行反転と数量/replay.go)は出生のない枠にもChartGridを保存する。従って構造の観測可用性と、同方向の有効Source出生があるかは別に扱える。反対進行が見えても対応する出生がなければ、現方式では観測/待機のまま。将来候補を更新するなら、期限・重複消費・親履歴・数量・返済所有を含む別契約とし、Source Sideだけを反転して元の返済通知を流用しない。

## 一般説明と心理の仮説

CMEの[支持抵抗教材](https://www.cmegroup.com/education/courses/technical-analysis/support-and-resistance)は、移動平均や過去価格帯、突破後の役割交代、支持抵抗を帯として扱う考え方を説明している（2026-11-08、該当本文を確認）。これは一般教材であり、固定Bの条件やNK225の反転確率・収益の実証ではない。

「取り戻せない価格帯から反対へ進むなら、平均に残る背景と現在の受容価格が食い違う可能性がある」は心理の仮説である。価格図形から投げ・吸収・主体交代を断定しない。関連する概念整理は[平均方向と現在の勢い・板の食い違い](平均方向と現在の勢いと板が食い違うとき.md)、参照版と確認範囲は[参照JSON](反転構造と注文候補の時計_参照.json)に残した。新市場・原板・新日・売買再生・金融変更は0。
