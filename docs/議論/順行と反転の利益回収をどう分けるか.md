# 順行と反転の利益回収をどう分けるか

## 1. 入口・通常出口・利益保護を別の問いにする

順行型は「上位の方向が続く間の一時的な押し戻りから再開するか」、反転型は「既知の端を越えた動きが失敗し、以前の範囲へ戻るか」を問う。上位方向へ乗ることと、行き過ぎから戻ることを、同じRSIの数値で説明しない。

| 役割 | 順行型で知りたいこと | 反転型で知りたいこと |
| --- | --- | --- |
| 入口 | 方向に沿う再開を、追い掛け過ぎず確認できるか | 端の突破が失敗したことを、価格の復帰で確認できるか |
| 通常出口 | 再開の前提が崩れたか、勢いが失われたか | あらかじめ定めた中心・対向水準へ戻ったか |
| 利益保護 | 調整を許しながら、既得の順行をどこまで返すか | 回帰途中の利益が消える前に、どの幅で退くか |
| 非常時の保護 | 通常出口を待てない逆行、観測空白、期限 | 同左。中心へ戻るという期待で保護を緩めない |

買いのRSIが70以上、または価格が上側BBへ触れたという理由だけで売る条件は採らない。Fidelityは強いトレンド中のRSI極値持続を説明し、Bollinger本人は帯接触だけを売買信号にせず、帯外終値が継続を示す場合を説明している。[RSI公式説明](https://www.fidelity.com/learning-center/trading-investing/technical-analysis/technical-indicator-guide/RSI)、[Bollinger本人の規則](https://www.bollingerbands.com/bollinger-band-rules)

## 2. 資料から何を引き継げるか

FidelityのEMA教材は、上向きEMAへの押しを買い候補とする考え方と、平均線の遅れ・短期変動への敏感さを説明する。したがって、EMA付近で指値約定したと仮定せず、**一度下へ戻った後の確定終値による復帰**へ置き換える。[EMA公式説明](https://www.fidelity.com/learning-center/trading-investing/technical-analysis/technical-indicator-guide/ema)

CMEは、以前の高安、移動平均線、突破後の支持・抵抗の役割変化を説明する。一方で支持抵抗は一点の保証ではなく帯として扱う。ここから「突破済みの水準を先に固定し、その後の再接近を確認する」候補を作れるが、下記の6本・3本・1ティックをCMEの実証済み手法とは呼ばない。[CME・支持抵抗](https://www.cmegroup.com/education/courses/technical-analysis/support-and-resistance)

Chandelier Exitの公式ツール説明は、高安からATR幅を離した撤退線と、入口を別の指標で決める役割分担を示す。代表例は**日足22本・ATR22の3倍**で、計算線はATRや窓内高安の変化により上下する。本研究の「建玉後だけの最高気配」「ATR14を入口時に固定」「単調に引き上げる2倍幅」は、原典を場内用に変更した別仕様である。[StockCharts・Chandelier Exit](https://chartschool.stockcharts.com/table-of-contents/technical-indicators-and-overlays/technical-overlays/chandelier-exit)

ATRは方向の指標ではない。Fidelityの説明でも、拡大は上下どちらにも生じ、低ATRの後は継続と反転の両方を取り得る。低ボラほど良い、2ATRを置けば安全、という入口の前提は置かない。[ATR公式説明](https://www.fidelity.com/learning-center/trading-investing/technical-analysis/technical-indicator-guide/atr)

## 3. 次回の少数候補：4入口×2足×3出口＝24

以下は、すべて買いの定義。売りは価格の上下・不等号・高安を対称化する。`C/H/L`は確定足のLastによる終値・高値・安値、`E`はEMA20、`A`はWilder ATR14、`M`は終値20本SMA、BBは母標準偏差20本・2倍とする。`t`は3分または5分の発動足。平均線・ATRの初期化と欠枠処理は既存仕様を継承し、変更する場合は明示する。

15分上向きは、利用可能な最後の確定15分足で `C15 > E15 > 前E15`。同じ15分足が継続して参照される場合も、未来の15分終値を埋めない。反転型の環境候補は `ADX14 < 20` とし、資料の普遍的な境界ではなく、今回の固定された役割条件として扱う。

各足幅内の4入口は、EMA20・ATR14・ADX14・BB20と、その場で1本以上確定した準備済み15分EMA20を利用できる共通時点で比べる。追加条件の効果と準備による開始時刻の差を混ぜない。3分と5分の発動機会数は同じではないため、件数・場・開始日と残り時間も別記する。

足はセッション起点の半開区間から作り、足終了後にそれを確認できた原行で判断する。15分足も足終了時刻と確認時計・原行の両方が判断時点以下のものだけを使う。現時点の比較案は、残り60分以上、正常板で要求+1価格時計秒以上・30秒以内の新規、追跡期限15:35／翌05:50を引き継ぐ。価格時計は受信時計ではなく、1秒は実通信遅延の測定値ではない。最終の新規停止・期限優先・EOF・300秒超正常板空白の扱いは試行条件へ記録する。

| 入口ID | 意図 | 発動時までに観測する条件 | 主な反例 |
| --- | --- | --- | --- |
| T1 押し目再開 | 上位方向に沿って下位足が復帰 | 前・現発動時点とも15分上向き。`前C ≤ 前E`、`今C > 今E > 前E`、`今C > 前C` | 転換直前の遅い復帰、EMA付近の往復 |
| T2 突破後再テスト | 上抜け後、以前の抵抗を保持 | 前1〜3足のうち最新の突破足jで、その足を除く直前6本最高値Rを固定。`Cj > R`。以後の確定終値がR以下になれば候補失効。今足は `R−1ティック ≤ L ≤ R＋1ティック`、`C > R＋1ティック`。15分上向き | 深い再テストを除外する機会損失、支持失敗直前の反発 |
| R1 端の失敗突破 | 直前範囲の下抜けが続かない | 今足を除く直前6本の安値Q・高値Rを先に計算。`L < Q < C ≤ R`、`C > 前C`、ADX14<20 | 安値更新の途中の一時回復、低ADXからの新トレンド |
| R2 BB内復帰 | 帯外で終わった後に価格が改善 | `前C < 前下帯`、`今下帯 ≤ 今C < 今M`、`今C > 前C`、ADX14<20 | バンドウォークの途中、帯の移動だけによる復帰 |

T2は、現在足自身の突破を再テストとして数えず、R・登録足・失効・満了を状態として持つ。待機3本の満了を含む。複数の登録がある場合は最新だけとし、同じ登録で一度発動したら再使用しない。窓は同場の連続有効足のみ。T1も交差一回を一イベントとする。

R1/R2の中心目標案は、判断時の `M_t` を固定する。共通入口の準備として `M_t > C_t` を要求する。実約定が中心を越えた場合も、その場で目標を遠ざけず、目標出口を採る運用では約定後の最初の評価から返済条件成立として扱う。この状態と件数を記録する。中心までの距離、250ptに対する比、残り時間は診断へ残し、結果から良い層だけを抜き出して次の合格率にしない。

| 出口案 | T1/T2の順行運用 | R1/R2の反転運用 | 比較で答えること |
| --- | --- | --- | --- |
| X0 固定幅対照 | 利確+250pt、初期保護−125pt、期限 | 同左 | 従来の運用尺度との対照 |
| X1 通常のチャート出口 | 確定発動足の `C ≤ EMA20` で返済要求。−125pt・期限も維持 | 入口判断時に固定したSMA20へ返済側気配が到達したら返済要求。−125pt・期限も維持 | テクニカルな前提崩れ／回帰完了で回収できるか |
| X2 通常出口＋利益保護 | X1に加え、建玉後最高返済気配から `2A_e` 下の線を単調更新 | X1に加え、返済気配の含み益が `A_e` 以上で、最低 `0.5A_e` の順行を残す保護線を有効化 | 利益消失の減少と、早期退出・大幅利益取り逃しの差 |

`A_e` は入口を決めた確定足のATR14を保存した定数で、将来のATRに差し替えない。全案で−125ptの非常保護を維持し、X1/X2には+250ptの固定利確を重ねない案とする。**その代わり、入口の125/250pt先着ラベルは全案共通で別保存する。** 通常出口が中心到達の+40ptで勝ちでも、+250pt先着の成功とは数えない。

この24案は、出口・保護を同時に何通りも最適化する格子を避けるための上限案である。入口4×足2をまず比較し、同じ入口にX0/X1/X2を対応させる。RSI閾値、ATR倍数、目標の手前幅、15分足の追加条件を結果後に増やさない。もっと少数で始めるならT1とR1に限って12案とし、残りは未検証候補へ置く。

## 4. 保護線は、観測できた後から有効にする

買いの返済側はBid、売りの返済側はAsk。買いの新規価格をP、建玉後に観測した最高BidをBmaxとすると、X2順行案の提案線は `max(旧保護線, P−125, Bmax−2A_e)`。売りは建玉後最低Askと `min` を使う。価格刻みへの丸めは発注可能な方向と方法を試行条件へ固定する。

反転の利益保護も、買いなら `max(旧線, P＋0.5A_e)`、売りなら対称とする。活性化は実際に返済側気配で1ATR_e順行を観測した後である。これは現金利益の保証ではない。新規・返済スプレッド、手数料、待機後の価格変化、空白中の経路により、実現利益が保護幅を下回る場合がある。

新しい線を計算した同じ原行へ過去に遡って適用しない。原板逐次でBmaxを更新するなら、その更新要求・有効化時刻／原行を持つ。確定足で更新するなら、その足の高値を足頭から利用しない。約定前に付けた高安も建玉後高安へ含めない。新規・返済・保護取消／変更の待機と期限優先を、既存の注文状態モデルに合わせて固定する。[既存の追尾決済教材](../technical-analysis/組み合わせ/ATRと追尾決済.md)

「勢い失効」も独立候補にはできる。例は、買い保有で確定足の `C < 前C` かつ `RSI14 < 50`、または15分方向が買いでなくなった時である。ただし、この24案に追加して探索数を曖昧にしない。EMA出口と重なる情報が多いため、まず不一致事例の診断に残す。RSIが70を超えたこと自体を勢い失効としない。

## 5. 中心線とVWAPへの復帰は、目標の仮説である

SMA20は過去20終値の平均で、反転時に必ず戻る価格ではない。入口後も更新すると、価格が戻らず平均線が下がったことで目標へ触れる場合がある。まず入口時点で固定した中心を使い、動的中心の追随は別の候補にする。入口から中心までの幅が125ptしかなければ、250ptを狙う入口とは異なる取引目的になる。

VWAPも回帰を強制する力ではない。IBKRの定義は約定金額／約定量という執行価格の比較基準であり、TradingViewの足版は各足の代表価格×数量の累積による近似で、起算と計算足が設定に含まれる。これらを、すべての参加者の平均建値やmini/microの平均建値とは呼ばない。[IBKR・VWAPの定義](https://www.interactivebrokers.com/campus/glossary-terms/volume-weighted-average-price-vwap/)、[TradingView・VWAPの計算と起算](https://www.tradingview.com/support/solutions/43000502018-volume-weighted-average-price-vwap/)

本データの数量は価格時計で採用した観測累積差分量で、全約定の価格・数量対応ではない。VWAP版を追加するには、その入力監査と分母0・欠量・場起算・ナイト午前0時を跨ぐ仕様を先に定義する。現時点の24案へVWAPを代理名で混ぜず、**数量監査後の未検証候補**として残す。[入力と数量の監査](入力と数量の監査.md)、[VWAPの教科書](../technical-analysis/指標/VWAP.md)

Katoの研究は、出来高過程を入れた最適執行モデルの下でVWAP執行を扱う。価格がVWAPへ戻るという方向予測や、BB復帰からの利確優位を実証した論文ではない。[原著の著者要旨](https://arxiv.org/abs/1408.6118v4)

## 6. 心理の説明候補と反例

| 観測パターン | 説明し得る心理・注文の仮説 | 観測だけでは分からないこと |
| --- | --- | --- |
| 上位方向内で押して復帰 | 一時的な利確後、追随注文が再び優勢になる | EMAの近くに参加者の注文が集まったか、誰が買ったか |
| 突破水準の再保持 | 突破を逃した新規と、逆側建玉の返済が支える | 新規／返済の区別、支持帯の普遍的な効力 |
| 安値を割って範囲へ復帰 | 下抜けに追随した売りが続かず買い戻される | 誰かが意図的にストップを狩ったか |
| BBから中心へ接近 | 偏った短期変動が落ち着き、以前の価格帯へ戻る | 真の均衡価格、将来の平均回帰の保証 |
| 含み益後に価格が戻る | 利確・逆側注文・流動性変化などが考えられる | 「利益があったから売りたい」という自分の希望と、市場の次の方向 |

利益保護を狭くすれば、含み益後の負けを減らす可能性がある一方、通常の押しでも退出し、費用と再参加を増やし、大きな順行の取り分を失う可能性がある。利益消失だけが減ったことを改善とはしない。

Kaminski・Loの原著の大学リポジトリ要旨は、指数先物の日次データを使うポートフォリオのストップ政策について、評価頻度によって期待収益・変動性への効果が変わる研究を紹介する。確認できたのは書誌と要旨であり、今回は本文を取得できていない。場内3/5分の単一建玉や、この利益保護幅の有効性へ外挿しない。[MIT・原著書誌と要旨](https://dspace.mit.edu/entities/publication/bb69ca4b-0cdc-487f-831d-63b2e84fafee)

## 7. 改善と呼ぶ前に比べるもの

入口目標は従来通り、逆行125pt以上より前の順行250pt以上。期限未達・観測不足も全約定分母に残し、未約定と分ける。返済側気配で判定し、順行確定後の逆行を入口失敗へ変更しない。運用の小利確による勝率と並記し、両者を混ぜない。

出口だけの効果を読むため、同じ保存入口からX0/X1/X2を独立に追う診断を残す。その診断では仮想保有が重なる。実運用は単一建玉のため、早く返済した案だけ次の入口へ参加できる。後者を前者と同じ取引集合の対応差と呼ばず、入口抑止・待機・取消・活動場・無取引場も記録する。

含み益消失は少なくとも、返済までのMFE、実現値幅、`MFE−実現値幅`、1ATR_e以上の順行を観測した後の赤字化件数、費用後損益、最大損失、期間別・売買別・場集中で比べる。MFEは実約定後から実返済までの返済気配で測り、異なる保有長のMFEを同じ将来経路として扱わない。捕捉率を出すならMFE>0だけとし、分母0や欠測を0%へ置かない。

既に開いた旧64場と11/4デイは、次回にはすべて使用済みの探索である。探索内の期間分割は時系列の再利用比較として記録し、新しい未見データが増えたとは呼ばない。候補と評価順を固定し、支持件数・日数・場数、30分間引き、費用感度、品質を併記する。条件未達なら未達を保存し、次の問いを変えた新試行へ進む。
