# 先着率と参加率と決済損益の分母を分ける

2026-11-12確認。以下は[135の固定対照C0](../../study/00135_公表差で不安定な方向上書きを抑える/結果と限界.md)の実BBO・取得後60分・同幅±125ptを例とする。[全セッションCSV](../../outputs/01a1889f-f2af-7943-a047-543275ee9ed2/135公表差CSV/全セッション.csv)と[正本集計](../../study/00135_公表差で不安定な方向上書きを抑える/成果物/集計.json)を照合した。新しい金融計算・原板走査は行っていない。

## 39順・18逆は57場だけ参加したという意味ではない

全73セッションで取得があり、取得数は合計79件。1取得の場が68、2取得が4、3取得が1で、0取得の場はない。最低1・最大3取得だった。候補や注文要求の件数ではなく、取得代用が成立した件数で数える。

|数えるもの|分母と分子|この例の値|
|---|---|---:|
|全場参加|1回以上取得した場 / 全対象場|73/73＝100%|
|全取得の方向分類|順39＋逆18＋未到達16＋観測不足6|79件|
|到達済み同幅先着率|H完了で順行側先着 / H完了でどちらか先着|39/(39+18)＝68.42%|
|未到達込みのH完了内順行割合|順39 / H完了73件|39/73＝53.42%|
|全取得に対する上記順行分類の割合|H完了で順行先着の39件 / 全取得79件|39/79＝49.37%|
|IFD代用の金額判明|金額既知 / 全取得|76/79、未知3件|

39・18は**入口の件数**であり、セッション数でも、全79件の決済勝敗でもない。未到達16件も取得済みで、所定の観測規則でH60完了となったが±125ptのどちらにも届かなかったもの。IFD代用では期限時点の実側BBOによる清算対象であり、待機や不参加ではない。期限清算の損益は別途確認する。

観測不足6件は、全H完了を求める上記の方向分類では率の分母から分ける。ただし不足する前に利確・損切り側へ到達し、IFDの決済金額が分かる場合がある。このため**Hの観測不足6件とIFD金額未知3件は別の分類**である。未知を0円や負けへ置き換えない。

## 決済損益と現在の目標

このC0のC5代用損益は、金額既知76件で利益506,304円・損失313,156円・差引+193,148円、未知3件は未算入。mini1枚独立・往復手数料77円と追加費用1,000円の条件であり、全取得の実運用口座収支や利益追尾の実績ではない。順行先着率、費用後の黒字取引率、利益額/損失額の比率を混同しない。

現在の目標は、**到達済み同幅先着率70%以上**と**全対象セッション最低1取得**の両方。この例は参加条件を満たすが、68.42%なので率の条件は未達である。39/79の49.37%も補助情報として示すが、目標を勝手に「全79件中70%以上」へ変更しない。

報告では「勝率68.4%」だけと呼ばず、例えば「全73場79取得、H60±125ptは39順18逆・未到達16・不足6、到達済み先着率68.42%、IFD金額既知76/未知3」と記す。先着の幅・時計・全件数・未到達・不足・費用と、場の参加状況を一緒に残す。
