# VWAP復帰と通常出口を対応させる

確認日：2026-11-04。一般的な説明、心理の仮説、この研究の観測を分ける。

## 発動と利益の出口は別の問い

VWAPの下から上への復帰と、その傾きを組み合わせた入口例は[Schwabの解説](https://www.schwab.com/learn/story/how-to-use-volume-weighted-indicators-trading)にある。これは平均を取り戻す動きへの着目であり、将来の250pt順行を保証しない。同記事の帯は標準偏差で、本研究の1ATR乖離帯とは異なる。

[ATRの公式教材](https://www.fidelity.com/learning-center/trading-investing/technical-analysis/technical-indicator-guide/atr)は値幅を測る用途を説明する。方向は示さないため、ATRだけで順行/反転を決めない。1ATRを越えた後に内側へ戻る条件は、本研究がVWAPとATRを組み合わせた仮説である。

心理の仮説として、平均の再獲得は以前の逆方向の参加が弱まった可能性、乖離からの復帰は行き過ぎの調整を表す可能性がある。ただし、保有者の建値・注文動機・含み損益は板とVWAPだけでは観測できない。配信VWAPは夜間から日中へ継続する場合があり、当場平均への回帰と同じ意味にはしない。

## 00019で確認したこと

[00019](../../study/00019_VWAP復帰の入口と通常出口/README.md)は、再獲得Q1/乖離内復帰Q2×1/3/5分×15分方向追加有無の12入口、固定幅/入口固定VWAP/公開足更新VWAPの36運用を比較した。全65場は既使用。支持付き70%は0入口、費用資格は0運用だった。5分Q1方向追加なしの固定幅は片道追加5ptでも学習+10,430円・選択+3,374円だったが、これだけで安定収益としない。

通常VWAPへ早く返すと改善する、という説明も全体には成立しなかった。例えば3分Q1方向追加なしの固定幅→更新VWAPは、共通実新規で学習−13,300円・選択−3,900円、そのほか増えた取引も−674円・−2,874円。早期返済で空いた建玉枠の効果と、同じ入口の出口差を分けている。

同じ例で、固定幅側の保有中に100pt以上進んだ共通新規は学習24・選択19件。最終純赤字は固定幅7/6件に対し更新VWAP16/14件だった。これは事後対応診断であり、未来の100pt到達を入口フィルターにしていない。

反転の通常目標までの距離も注意点となった。3分Q2方向追加なし・入口固定VWAPの実新規から目標への方向距離中央値は学習31.60pt/選択39.06pt。実新規が既に目標を越えた例は15/130・6/103件あった。判断時点の価格でなく実新規後の余地を記録する必要がある。

詳細と全対照は[対応診断](../../study/00019_VWAP復帰の入口と通常出口/対応診断.json)、条件と全額は各試行の正本にある。通常出口だけを利益保護の代用にせず、次巡では複合判別と同値以上の利益追尾を別々に持たせる。

## 次に判別する違い

平均近辺の再獲得が、大きい流れに沿った押し戻りか、方向のない往復かを多時間EMAとADX/DMIで分ける。RSIの高い状態が持続しているか、直近の急変だけかも分ける。反転では低ADXだけを使わず、平均の収束とRSIの戻り、実際の価格復帰を組み合わせる。[次の複合判別](複数手法で局面を判別し利益を追尾する.md)へ進む。
