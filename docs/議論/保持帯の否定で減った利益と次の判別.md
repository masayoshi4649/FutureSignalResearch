# 保持帯の否定で減った利益と次の判別

2026-11-08。[試行85](../../study/00085_保持帯の返済側固定否定/README.md)で、固定84C0の複合入口に保持帯の返済側1tick否定を加えた。**早い否定線の追加は費用後損益を悪化させた。** 全66場は既使用であり、新期間の成績ではない。

## 固定したものと変えたもの

入口は3/15分EMA、3分MACDの現在増分、RSIと値幅の同時急変警戒、ATR取得位置に、freshな同方向帯維持と反対圧力解消を重ねるC0を固定した。既知短秒・OFI反対拒否も維持する。売買は符号反転の同条件で、Day09:15・Night17:30から15分ごとに新規判断する。利益保護は全原行で連続する。

H0は旧G1保護だけ、H1は要求時の同方向保持帯から返済側1tickの固定線を作り、旧床を緩めず追加する。取得後の新しい帯へ線を動かさない。費用後現在単価益が正なら最低建値床と部分利確を即起動する条件は両案同じ。100micro固定、往復費用122円/枚、次正常ラージBBOを代理約定とし、追加価格時計1秒を別に再生した。

## 次の判別仮説

支持・抵抗に参加者が反応するという[外部の説明](外部再調査/支持抵抗の否定と逆指値の約定を分ける.md)から、帯を試す動きには、押し戻された後の再開と、元の方向の根拠喪失の両方が考えられる。単線到達だけでは、この二つを区別できない。参加者の意図自体を観測したとは扱わない。

次は、帯を割った時点の価格応答と勢いを組み合わせ、通常の押戻しと否定を分ける候補を先に固定する。具体候補は「要求時の帯から両気配が1tick逆側へ進み、当原行の既知5秒・15秒速度も両方反対」を同時に求める追加退出である。未採用・未実装・成績未計測であり、当原行での入力可用性も先に調べる。二つの速度は同じ価格系列に由来するため独立した二票と数えない。未知時は旧保護を維持し、情報がないことを逆方向の証拠にしない。

帯の位置を売買仮説、速度を反対進行の確認、確定足の複合テクニカルを背景として役割を分け、未来の反発を判定に使わない。線の到達を一律に反対売買へ変換せず、退出・継続・反対方向への新規成立を別々に扱う。

利益配分や数量は同時に変更しない。新しい判別を加えるなら別試行とし、救った損失だけでなく、失った勝ち、損失拡大、変化なしの全実入口を残す。利益が出るまで同じデータで閾値を選ぶことと、未使用期間で安定性を確認することも区別する。
