# 短秒の逆行確認と一定利益後の保護を分ける

更新日：2026-11-09。[試行101](../../study/00101_短秒の失速と現在量で利益を守る/README.md)は金融・独立・保存・Viewer照合まで完了した固定対照。[試行102](../../study/00102_定時チャートと一定利益後の可変追尾/README.md)も金融・保存検算を完了した。[同実入口の改善と再参加の分解](利益保護の改善と退出後の再参加を分ける.md)へ結果を追記し、101と102の条件差を分ける。

## 確認した結果

101は同じ実入口28玉・56枚を使い、P0の利益追尾へ短秒の反対進行と現在量による返済を追加した。全12の比較で取得変更・片側だけの参加は0であり、同じ実入口の退出差として比較できる。費用後実現純額は次の通り。

| 保護 | 追加滑り0・通常 | 追加滑り0・1価格秒 | 仮定片道5pt・通常 | 仮定片道5pt・1価格秒 |
| --- | ---: | ---: | ---: | ---: |
| P0 | 27,688円 | 58,688円 | 51,688円 | 73,688円 |
| 5秒逆行＋現在量 | 15,688円 | 43,688円 | −10,312円 | 13,688円 |
| 上記＋15秒逆行 | 13,688円 | 39,688円 | −28,312円 | −14,312円 |

主条件の正益後最終赤字はP0の23/28玉から両短秒案の18/28玉へ減ったが、純額も減った。件数の削減と費用後利益の改善は同じではない。15秒を重ねる案も、この比較では5秒案を上回らなかった。[正本](../../study/00101_短秒の失速と現在量で利益を守る/成果物/結果.json)と[検証後の要約](../../study/00101_短秒の失速と現在量で利益を守る/検証後の要約.md)を参照する。

入口は依然として少ない。旧100P0の主条件を開始・末尾30分除外の全5分枠で数えると37/5,832、0.6344%で、新しい最低25%に未達だった。少数取引の総黒字を、十分に参加して安定利益を出す達成例とはしない。

## 次の判別に使う考え方

短い逆行と板数量の反対は、上位方向そのものの消滅とは限らない。注文の取消・補充や短い押し戻りでも起こり得るという心理・構造上の仮説であり、当事者の動機を直接確認した事実ではない。反対の秒数だけを増やすことより、平均の方向、勢いの変化、価格の保持と通常変動を別の役割として扱う。

102では、全5分枠の複合チャート判断で入口を作る。利益保護は一定の費用後利益で必ず起動し、通常変動を許す幅と、平均線間隔／ATRの収束にMACD鈍化を重ねた狭い幅を比較する。価格が平均の逆側へ出てMACD増分も反対なら、収束とは別の失速として扱う。単なるATR低下やRSIの高さだけで反転を決めない。

この設計は既存結果が原因を証明したという意味ではない。入口の変更と出口の変更を区別し、A0とA1の共通実入口、取得変更、双方の実参加額、参加率、実現損失を検証する。未参加や決済後の仮想利益は評価しない。

## 一般論の根拠と適用範囲

以下は2026-11-09に外部再調査で確認した一次教材。NK225の具体的な起動水準・幅係数・5分時計の収益性を証明する資料ではない。

- [FidelityのATR解説](https://www.fidelity.com/learning-center/trading-investing/technical-analysis/technical-indicator-guide/atr)：ATRは方向ではなく値動きの幅を見る。幅を方向判定と混同しない。
- [TradingView公式MACD解説](https://www.tradingview.com/support/solutions/43000502344-moving-average-convergence-divergence-macd-indicator/)：ヒストグラムの水準と変化を分ける根拠。縮小を直ちに価格反転とはみなさない。
- [John Bollinger本人の規則](https://www.bollingerbands.com/bollinger-band-rules)：帯や収縮だけで売買を決めず、異なる役割の確認を重ねる一般的な考え方。102にBBを実装したという意味ではない。
- [CMEの支持抵抗教材](https://www.cmegroup.com/education/courses/technical-analysis/support-and-resistance)：価格帯の保持・突破後の役割の一般説明。自分の建値や平均線が実際の支持になる保証ではない。

BB・ADXは今回の保存Technicalに含まれず、102では未使用。使っていない指標の効果を複合成績へ帰属しない。
