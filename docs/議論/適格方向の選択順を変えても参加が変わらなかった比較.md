## 何が分かり、何が分からないか

保存診断で準備済みの両側資格を排他的に分けると、次のとおりだった。未知・raw同点は準備済み枠内で全期0。未準備127・104・3枠を下表の分母へ含めず、全予定枠の活動集計には残す。

| 候補・期間 | 両適格 | 最高側のみ適格 | 低側のみ適格 | 両不適格 |
| --- | --- | --- | --- | --- |
| E0 時系列 | 7 | 161 | 0 | 445 |
| E0 選択 | 21 | 228 | 0 | 535 |
| E0 後続 | 1 | 15 | 0 | 55 |
| E1 時系列 | 0 | 0 | 0 | 613 |
| E1 選択 | 0 | 48 | 0 | 736 |
| E1 後続 | 0 | 7 | 0 | 64 |

E0の最高側不適格445／535／55枠は、高低両側とも理由がscore1/3未満だけだった。E1の最高側不適格613／736／64枠では、低側も全件で過去回収が非正。そのうちscoreも不足するのが606／723／64枠、回収非正だけが7／13／0枠である。この低側集合に技法・葉・回収支持の不足はない。E1選択では、高側もscoreと回収の両方が不足535、高側は回収だけ不足だが低側は両方不足188、両側とも回収だけ不足13だった。

今回の変更が作用するのは、raw同点・未知ではなく、最高側が失格で他側が全資格適格な枠だけである。その純追加は0だった。したがって、**この保存木・資格・標本では、最高側から検査する順序が参加を減らす原因になっていなかった**。他の木や別の資格でも順序変更が無効という結論ではない。作用する場面のない比較から、低い得点側の収益性を評価することもできない。

葉のpathに異種の技法が含まれること、過去の支持があること、現在の価格setupと発動が成立していることは異なる。[65の現在状態の診断](現在の有効状態を量価格の前に分けた比較.md)では、選択期間の順行152純候補は特定のT経路が未登録又は取消済みで、反転の現在有効65純候補のうち60は再試験rがまだなかった。今回の順序変更は、その資格の意味自体を変えていない。

外部の[候補成立と優先順位の調査](外部再調査/候補の成立と方向の優先順位を分ける.md)は、相場環境、setup、trigger、管理を分ける設計参考である。順序変更が有利という外部実証や、取消済みの特定経路があらゆる手法を無効にするという説明ではない。参加者の防衛・撤退という心理は観測の解釈であり、無方向の量と価格だけで意図を特定したものでもない。

次は、順序をさらに変えるよりも、**当時の複数時間軸の背景と、現在の形・価格応答をどの条件で結び、どの否定で待機又は別候補へ移るか**を検討する。既存のk必須や有効旗分岐との重複、確認待ちによる取得の遅れ、待ち率、O49との適合を点検してから一つの変更を固定する。現在有効だけ、反対側が失格だけを発注理由にしない。次の方式は本書時点で未固定・未実行である。
