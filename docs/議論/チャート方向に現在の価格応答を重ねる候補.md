# チャート方向に現在の価格応答を重ねる候補

2026-11-07。未検証の次候補。83の出口結果を読む前に、固定82の保存判断とFAR由来のコードから整理した。[83の知見](固定否定線と利益配分を分けた知見.md)を受けて次に固定する候補であり、新損益・未使用期の確認はまだ行っていない。

## 背景と現在の応答を分ける

82B1は、3／15分EMAの並び、3分MACDの現在増分、終値のEMA8回復、0..1ATR取得位置、RSIとTRの同時急変警戒を組み合わせる。既知の短秒・OFI反対を拒否し、失速時には追加支持を求める。しかし順行枝は現在のFAR価格帯維持を常時必要とせず、転換初動枝だけが帯・数量支持・反対圧力解消を必要としている。

次は、この背景に現在の両気配の進行後維持を重ねる。「平均線が同方向」という過去の要約から、取得時点でもその帯が支えられているかへ問いを進める。心理の仮説は追随と反対圧力の応答が続くかであり、参加者の意図を直接観測した事実とはしない。

## 比較する二案

`D`を固定82B1の同じ方向別許可、`K/B/Q/A`を同じ判定器が保存する構造既知・fresh価格帯維持・fresh同価格数量支持・反対圧力解消とする。仮IDは次試行の正式設定IDとは別である。

| 仮ID | 条件 | 追加の問い |
| --- | --- | --- |
| C0 | `D && K && B && A` | 順行でも現在の価格応答と障害の解消を必要とする |
| C1 | `C0 && Q` | 同じ構造へ表示数量の回復も必要とする |

`B`は既知のE08同方向holdがactive・未pressured、60秒／32価格更新以内で、BidとAskが共に帯の方向側へ残ること。源の帯は8価格更新窓の両気配20pt進行・方向比0.625以上の候補を2更新維持して確認する。鮮度を結果に合わせて延長しない。

`Q`は当時の同価格表示数量回復点が既知かつ60秒／32更新以内。`A`は既存の障害回復点がfreshなら返済側BBOで10pt通過し、freshな反対数量支持が残らないこと。障害の鮮度切れを「市場に反対注文がない」と解釈しない。

実装では[82のentry.go](../../scripts/チャートの現在性と補助確認/entry.go)の`structureState`と保存した方向別チェックへ結ぶ。新たな近似式に置換しない。源は`SessionTradeExecuter/internal/strategy/selected_night_state.go`と`selected_night_features.go`で、固定80の入力台帳に純戦略のSHAを保持している。

同じ入力の純判断では`C1⊆C0⊆82B1`、元の初動枝は両案へ全保持される。81B0はOFI等の支持既知性と現在チャートの要件が異なるため、81B0へ戻る比較ではない。実参加は占有で変わり得るので、純判断の包含と実新規の包含を混同しない。

## 先に残す反証と再現条件

- 帯確認を待って進行を使い切り、取得後の追随が続かない。
- 60秒／32更新の状態と15分定時が合わず、良い流れも見送る。少数黒字でも安定性の証明は弱い。
- 数量回復は取消・差替えを含む表示値であり、C1でC0の勝ちを失う。
- 正益前損失が減っても、同実新規の利益回収が改善するとは限らない。
- 建値床・部分返済で大きな順行を失い、入口を絞っても費用後利益が残らない。

時計・売買鏡像・数量・費用・遅延・正益strict正の即時保護を揃え、まず入口の追加だけを比較する。再テストは元原行だけのパルスなので、定時まで保持する記憶と失効規則を決めずに混ぜない。未使用期間は候補固定後の確認まで保留する。見送った保存玉の損益を足して新戦略の成績とはしない。

## 一次資料と本仮説の距離

2026-11-07本文再確認。CMEの[支持と抵抗](https://www.cmegroup.com/education/courses/technical-analysis/support-and-resistance)は、高安・平均・役割転換と価格帯の考え方を説明する。今回のE08や鮮度の優位性を示す資料ではない。

CMEの[流動性評価](https://www.cmegroup.com/education/articles-and-reports/assessing-liquidity)は、表示板厚だけでなく補充・速度・価格影響を合わせて見る。2020年のESの検討であり、NK225の収益予測へ転用しない。[適切な建玉量](https://www.cmegroup.com/education/courses/trade-and-risk-management/proper-position-size)は、方向仮説を否定する論理的な停止水準と通常変動による発動を区別する。特定のEMAや帯が正しい停止線であるとの証明ではない。
