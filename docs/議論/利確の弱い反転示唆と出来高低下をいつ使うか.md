# 利確の弱い反転示唆と出来高低下をいつ使うか

2026-11-22。日経199_02デイの既使用45日で、追加の利確を早めるかは「反対方向の兆候の強さ」「既に得た値幅」「そこで注文するか、追尾に切り替えるか」の組で決まった。基準のRC20は元の指値・逆指値を維持しつつ、反対シグナル2回でも追尾する。追加条件は同じ133件の取得、費用・再開制限で比較した。[試行227の条件と結果](../../study/00227_弱い反転示唆と出来高低下を利確に使う/README.md)

- 単発の反対主シグナルで即時返済すると、総損失は92,231円減ったが、総利益が390,231円減った。1分の失速が同時にあり、即時返済を0.15R幅の追尾に替えたW08では、元の固定利確はすべて維持し8,000円増益。収支が変わったのは2日で、期間を広げた再現は未確認。
- W12では0.80R以上先に進み、元の幅の0.60R以上が残り、完成5分足の方向が転じた瞬間に1分足でも逆向きなら追尾を狭める。元の損切りの1件を黒字で返し、総損失16,077円減・収支8,000円増。ただし後半21日で27,000円減益した。損失抑制を優先する追加日向けの比較対象とする。[成績を変えた6件](../../study/00227_弱い反転示唆と出来高低下を利確に使う/弱い反転/決済の内訳.md)
- 出来高が落ちた足では、保有方向へ進める注文も、それに反対する注文も減りうる。出来高だけで一律に返すと、元の指値に届く値動きを何度も途中で手放した。薄商いの後の出来高回復と逆向きの値抜けを要求したD09でも、早期返済11件のうち10件はRC20で固定利確した。この結果には、既に大きく順行した建玉を母集団にした影響が含まれる。[出来高可用率・価格だけとの対照](../../study/00227_弱い反転示唆と出来高低下を利確に使う/出来高低下/README.md)
