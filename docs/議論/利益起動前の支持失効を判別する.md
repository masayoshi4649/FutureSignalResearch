# 利益起動前の支持失効を判別する

2026-11-10。以下は[113](../../study/00113_起動前の支持否定と利益保護の切替/README.md)の実行前に整理した仮説。実行後は[低い利益起動と支持失効だけでは改善しなかった比較](低い利益起動と支持失効だけでは改善しなかった比較.md)を参照する。全70場・24条件を独立検算し、起動早期化・失効撤退の追加は対照の純額を改善しなかった。以下の設計理由を、改善が確認された事実として読まない。

112の主P100では、負け259玉のうち未起動257玉・約539万円、起動後2玉・154円だった。未起動の176玉・約369万円は一度費用後正益を観測していた。[既成立取引の診断](../../study/00113_起動前の支持否定と利益保護の切替/根拠/112入口枝診断/結果.json)で、未起動と正益未経験を分けた。利益後の赤字がすべて起動後のトレール幅の問題とはいえない。

そこで、必須起動を100から50pt相当へ下げる変更と、起動前でも取得時支持が失効した場合に撤退する変更を分ける。起動を下げると通常の押戻しでの退出も増え得るため、失効撤退なし/ありの双方で実再生する。これらの金額を新規則の利益へ足し戻すことはしない。

取得時支持は、その実取得行で既知の方向対応pivotを固定し、取得価格が支持の有利側にある時だけ使う。取得後に終わった確定足がその支持を逆抜けし、保有方向のMACDヒストグラム増分も負なら、保有根拠の失効として記憶する。現在損益が正であることは条件にしない。支持未知・不適格なら基礎ルールを続ける。これは起動後の動的pivotによる幅縮小とは異なる。

心理仮説では、支持が残る調整と、取得時の支えが崩れ勢いも落ちる局面を区別する。MACD鈍化だけを反転成立とは扱わない。[一次資料の確認](../../study/00113_起動前の支持否定と利益保護の切替/根拠/順行と反転の外部確認.md)は、方向と強さ・RSI過熱の持続・BB幅と方向・価格水準の失敗を分ける。取得時pivot、3分足、H50、失効条件は研究独自であり、教材がNK225での最適性を証明したものではない。

日中addon等の純額差も見つかったが、成績だけで枝を除外しない。保存タグではaddon内の突破型/往復型が分からず、未来価格や親番号から補わない。今回の比較は入口を維持し、通常支持の有無と起動前後で撤退を切り替える検証とする。元の順行・反転の入口確認や、実返済をSourceへ返す統合変更は別条件で扱う。

売買対称・費用後の必須起動・最低価格床・非緩和・セッション完結を維持する。未参加や決済後の仮想利益・機会損失は評価しない。11/09は未読のまま、採用と未知期間の安定性は未確認である。
