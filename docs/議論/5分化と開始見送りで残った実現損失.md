# 5分化と開始見送りで残った実現損失

確認日：2026-11-08。[試行95](../../study/00095_5分判断と開始30分見送り/README.md)の固定済み条件による、既使用54セッションの比較。未参加や決済後の仮想利益は評価しない。[実現損益を中心に評価する方針](実現損益を中心に評価する方針.md)に従う。

## 何を変えて比較したか

元FARの出生・売買方向・可変数量を維持し、新規注文の時計だけを比較した。Nは元の連続判断、B5は出生後の最初の次5分枠で一回判定、B5Qはさらにデイ・ナイト・米国開始後30分の新規を見送る。見送りやSource未取得を後続枠で復活させない。元Sourceがその枠で保有を維持し、返済予約がなく、実口座に余力があることも必要とする。

全案で、残玉の費用後現在益が正になった時点から最低名目建値・2ATRの連続追尾を行う。買い・売りの各上限10枚、mini片道税込38.5円、セッション内完結は共通。今回新しい「枠時点の複合チャート条件」は追加していない。時計変更とテクニカル強化の効果を混同しない。

追加価格時計1秒のC0D1では、N/B5/B5Qの純額は−111,135 / −260,281 / −242,818円となり、Nと5分案の順位が変わる。仮定の追加滑り5pt片道を入れて動的に再生したC5を含め、全12案が赤字だった。「5分にすれば改善する」「開始30分を避ければ有利」と一般化しない。

## 次に判別する対象

今回のB5Qでは、正益を観測しない49玉の損失が赤字総額の大半を占める。次は**新規枠の時点で、元の出生根拠が現在も有効か**を複数テクニカルで判定する。方向・押戻しからの回復・勢い・値幅・数量の役割を分ける。上位方向が同じでも単足の異常な突出なら同じ採否にせず、上位に逆らう局所反転も価格回復の順序と勢いで別に判別する。

この説明は次の仮説であり、95の黒字群を事後抽出した新戦略成績ではない。15分EMA21などは当場30分では準備できないため、同限月の過去セッションから指標の数値履歴だけを因果的に助走させ、公開済み確定足で判定する必要がある。建玉を持ち越すこととは区別する。利益前の否定線・損失上限も今後の別条件として固定して比較する。

## 検証範囲と留保

金融全54場、独立原板648会計、N216会計の旧94との全文比較は成功した。原板の時刻は価格項目の時計であり、独立受信時計ではない。同時刻の市場間順序は再生規則で、真の到着順を証明するものではない。実mini板の流動性、実受信遅延、未知期間の収益安定性は未確認。追加5pt滑りも実測値ではなく費用感度の仮定である。

保存集計にあったEOF時計と同秒予約の二つの検査誤りは、元の金融条件・約定を変えずに訂正した。[EOF訂正](../../study/00095_5分判断と開始30分見送り/集計時計の訂正.json)、[同秒予約訂正](../../study/00095_5分判断と開始30分見送り/同時計予約の訂正.json)に出典と範囲を残す。
