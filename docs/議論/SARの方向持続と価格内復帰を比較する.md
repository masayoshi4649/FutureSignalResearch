# SARの方向持続と価格内復帰を比較する

確認日：2026-11-05。[00025](../../study/00025_価格イベントとSAR方向持続/README.md)で、固定24と同じ価格イベントに、MACDヒストグラムの一足の変化又はSAR二本の方向持続を組み合わせた。既使用65場の追加開発であり、支持付き125/250pt先着70%・費用資格は両案未達。SARを加えるだけで反転と順行の両方が改善するとは結論しない。

## 役割を置き換え、準備を揃えた

[FidelityのSAR教材](https://www.fidelity.com/learning-center/trading-investing/technical-analysis/technical-indicator-guide/PSAR)は極値と加速因数による追随、時間経過による線の移動、横ばいでの往復を説明する。[TradingViewのSAR教材](https://www.tradingview.com/support/solutions/43000502597-parabolic-sar-sar/)は更新・反転・二本高安の制約と初期規約を示す。URL確認日：2026-11-05。今回の二足持続やNK225分足での有効性は、本研究の仮説である。

心理の仮説は、内復帰した一足の反応だけでなく、それ以前から同じ側へ極値を更新しやすかった状態を確認すること。ただしSARも価格由来であり、注文動機や独立した参加者の観測ではない。

| 案 | 価格構造 | 指標の役割 |
| --- | --- | --- |
| Q0 | 固定30分6本範囲への最初の内復帰f/外回復g | 実side×ΔH>0。H=MACD−Signal |
| Q1 | 同じf/g | 同場隣接公開3分の前/現SAR方向がともに実side |

両案の共通M25は、旧M24に前/現SARの数値準備を加えたもの。Q1にMACDの符号や上位ADX/DI/BB幅の値選別をさらにANDしない。価格構造と別の指標を両案で組み合わせ、SARを単独注文や出口には使わなかった。15分ペアは旧M24の数値準備に残すが、今回はその方向値で切り替えない。数量は診断のみ。

最初のf/gは指標不成立でも消費し、後の好都合な足へ取り直さない。MACDやSARの不準備で価格登録/監視を取消さず、建玉と独立に進めた。売り買いは符号反転した同条件。詳細は[計画](../../study/00025_価格イベントとSAR方向持続/計画.md)と[設定表](../../study/00025_価格イベントとSAR方向持続/設定と結果.md)を正本とする。

## SARの表示時点を分ける

AFは初期0.02・増分0.02・上限0.2。初期終値差が同値なら方向未確定とし、特定方向へ優先しない。当足の前から有効な線へのstrict貫通を先に判定し、反転しなければ前二足高安で表示線を制約、その後に極値/AFと次線を更新する。等号では反転しない。初期/反転時の線を含め本研究の規約を固定し、他の全SAR実装との完全同値は主張しない。

当足前の線、当足高安を知った後の反転表示、次足用の線を別列に保存する。後から反転した表示点を過去の注文値へ返さない。完全幅未公開末尾足は数値銀行だけに反映して場間carryし、公開二本条件には使わない。不正OHLC・欠枠・尾部欠枠・限月替わりのresetも独立確認した。

全12,694足中、数値準備12,584、初期化79、反転1,114、clear91。実データには完全幅末尾NPの数値更新は0件で、その分岐は人工検証で確認した。この値計算の一致を、収益上の有効性や独立した標本数へ読み替えない。

## 準備落ちで成績が変わったわけではない

SAR準備を加えても、旧M24が通った足数は学習5,478・選択3,945・最終129の全てで変わらなかった。旧24E0からQ0へ落ちた価格イベントは0件。全220原価格イベントの価格・時点・固定出典・原先着は24と同値だった。

Q0の実新規も旧24E0と学習74・選択54・最終5件全て同じで、出口と純額差0円。参照案の再生差をSARの効果に混ぜていない。

| 期間 | Q0反転/順行の原採用 | Q1反転/順行の原採用 |
| --- | --- | --- |
| 学習40場 | 70 / 15 | 0 / 20 |
| 条件選択24場 | 46 / 14 | 3 / 14 |
| 既使用最終1場 | 3 / 2 | 0 / 2 |

Q1は初内復帰の反転を大半除き、元方向へ外回復する順行を多く残した。同じ二本持続を両役割へ当てても、同じ機能を果たすとは限らない。「傾向が既に続く」と「新しい反転が始まる」は、知れる時点が異なる可能性がある。

順行の率は両期間で記述的に上昇したが、少数で70%に達しておらず、将来への有効性を確認した結果ではない。順行のQ0だけの原採用は学習2件（250先着0・125先着2）、選択5件（1・4）。Q1だけは学習7件（2・3・期限1・未約定1）、選択5件（2・3）だった。Q1はQ0の部分集合ではない。

## 出口を改善した差ではない

共通実新規は学習8・選択7件で、出口純額差0円。Q1−Q0の観測総額差＋7,832/＋10,614円は、Q0のみ66/47件の−7,252/−10,434円と、Q1のみ10/10件の＋580/＋180円から生じた。見送りで後の順行へ参加できた差も含む。

順行だけの実参加はQ0学習10/選択8件、Q1 18/14件。追加5pt平均はQ0−112.00/−259.50円、Q1−77.56/−179.14円だった。全体の改善には反転除去が大きく影響するが、順行の参加集合にも改善が見える。いずれも赤字・少数で、共通新規の利確改善とは異なる。

出口は共通のhard125/TP250・強制返済・必須A5追尾を維持した。起動後の設定床は最低新規価格、D=max(5,ceil(実新規ATR/5)×5)、線は不利へ緩めず、返済待機中は更新しない。SARの反転表示でドテンや通常返済を追加しなかった。

Q1の起動後純赤字は学習12/18、選択8/15。以下は追尾起動後の取引に限る。同値未満約定3/1件、最終設定不足合計50/10pt。赤字の全てを滑りで説明できず、同値約定でも費用が残る。仮250先着の順行4/6件のうち実運用の純赤字は2/3件で、全て250利確前に返済していた。実際に250pt含み益を得てから失った件数ではない。

## 価格余地だけを増やしても識別は増えにくい

診断として公開終値から、反転が向かう固定範囲の反対端までの距離、元境界までの無効化距離を測った。注文gateには使っていない。Q0反転で「反対端まで250pt以上かつ無効化距離125pt以内」は学習68/70、選択46/46が既に該当した。この終値条件だけなら選択の反転群は減らない。

余地があることと、その方向へ到達しやすいことは異なる。実約定価格・費用による距離差も別に必要だが、余地条件を足せば今回の逆行群を広く分けられるとの期待は、この診断からは持てない。

次は、反転と順行に同じ持続を要求する方式から、役割ごとに知りたい現象と発動時計を分ける案を考える。初内復帰fを反転の登録として保持し、その後に新しい方向転換が確定した時点の新価格で評価する等である。旧fを取り直すのではなく別イベントの仮説とし、待機で進む価格・失う250候補・活動不足も一緒に確認する。まだ検証済み条件ではない。
