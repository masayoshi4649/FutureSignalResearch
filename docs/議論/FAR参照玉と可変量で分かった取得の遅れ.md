# FAR参照玉と可変量で分かった取得の遅れ

2026-11-08。[試行87](../../study/00087_FAR参照玉と可変数量の比較/README.md)は、元FARの三手法を全原行で仮想運転し、15分定時で生存している参照玉の現在量を取得するSと、それへ複数テクニカルのC0最終許可を追加するSCを比較した。時計・売買対称・連続G1保護・費用は共通。旧70%・125/250先着・待ち率を合格判定に使わない。

## 費用後の結果

| 案 | 主損益 | 追加1秒損益 | 完結玉 主/1秒 | 全玉正益後赤字 主/1秒 |
| --- | ---: | ---: | ---: | ---: |
| S：元参照玉＋G1 | −1,352,810円 | −1,450,048円 | 245 / 244 | 29/145 / 47/155 |
| SC：同じ参照玉＋C0＋G1 | −9,292円 | −9,692円 | 7 / 7 | 0/5 / 1/5 |

全66場は既使用。SCは主で5勝2敗だが、正益観測5玉の合計＋2,260円に対し、正益未観測2玉が−11,552円となり、黒字ではない。7玉・86microの往復費用は10,492円。粗損益＋1,200円でも費用後赤字で、同じ約定の滑り0pt参考でも手数料込み−692円だった。勝率だけで安定収益を判断できない例である。

Sは粗損益も−705,600円、往復費用647,210円であり、赤字を費用だけの問題にできない。元D164/P164/U165の主損益もそれぞれ−1,022,110/−73,040/−257,660円。可変量へ戻すだけでは、現在価格での新規の優位性を確立できなかった。

## 同じ参照玉と、同じ実入口は違う

SCの7玉は、場と参照IDではすべてSと共通していた。しかしSCの要求はSより900〜15,300秒遅い。要求時計・方向・実取得時計・価格・量まで一致する入口は0だった。

[全玉診断](../../study/00087_FAR参照玉と可変数量の比較/出口差診断.md)では、SCの元参照取得から要求まで1,897〜15,547秒、実建値は元参照建値より方向付きで＋40〜＋740ptだった。最新Source snapshotの鮮度と、元の参照が生まれてからの経過を分ける必要がある。これだけを根拠に年齢や価格差の新しい閾値を決めたわけではない。

| 対応群 | 主 | 追加1秒 |
| --- | ---: | ---: |
| 同参照ID・取得変更7玉のS損益 | −4,414円 | ＋6,386円 |
| 同じ7参照を後に取得したSC損益 | −9,292円 | −9,692円 |
| Sだけの参照の損益 | 238玉・−1,348,396円 | 237玉・−1,456,434円 |
| SCだけの参照ID | 0 | 0 |

総額差の大部分はS側だけの参加が消えたことで、同じ7参照の後続取得は両遅延とも悪化した。同じ入口の出口改善とは説明できない。C0をSの実入口に後から掛けて損失行を削るだけでも、SCの実運用にならない。待機中に参照状態・残量・価格・seen・占有が変わるためである。

最初の集計では要求時計も集合のキーにしたため、遅い共通参照を片側参加へ分けていた。対応分類だけを訂正した。金融再生・全経済値・その他269成果物は不変で、Viewer原APIの取得時SHAを残した同値証拠を[Viewer監査](../../study/00087_FAR参照玉と可変数量の比較/Viewer監査.json)へ内包した。元結果の比較欄を差し戻すと元JSON bytesを復元できる。

## 保護の履行と、最終黒字を分ける

原板から現在益・所有・非緩和床・予約を再構成した検査では、必要な床返済の不足は0だった。それでもSの全玉正益後赤字は主29/145、追加1秒47/155である。保護起動と注文要求を行うこと、次板で約定して費用後黒字となることは同じではない。

Source部分返済が既に予約されている場合、G1収穫を二重予約せず建値床を先に維持する。予約が解けるまでに現在単価益が非正へ戻る場合もある。人工ではこの境界を確認したが、市場の全原行で何回あったかを保存されていない値から推定しない。部分利確の予定額を残玉保護の確定益へ足すことも禁止する。

Sの正益未観測損益は主−1,478,430円で、正益観測玉全体は＋125,620円だった。残る問いは、利益後だけの退出調整に加え、正益へ一度も届かない現在の取得をどの複数テクニカルで判別するかである。利益旗の残玉単価と全玉合計も別の分母として残す。

具体例では10/15NightのSC−7,220円と9/28Dayの−4,332円はG1起動前で、返済要求後の悪化は0だった。10/19Dayの追加1秒SC−528円はG1後で、要求後悪化1,800円を記録した。後者も保護を放置した取引と同じ分類にはしない。出口差診断へ要求・約定・費用の根拠を保存した。

## 次へ再利用する問い

[外部調査](外部再調査/参照数量と実損益を分ける.md)のsetup・trigger・数量・保有管理を、元参照の生存と現在取得の資格へ分けて使う。生存は「今も追随が強い」の直接証拠ではない。既に順行して残量が小さくなった玉、通常押戻し中の玉、進行が失速して滞留する玉は競合する説明である。

次の最小比較では、3/15分の方向、現在MACDと価格回復、RSI/TRの一時的スパイク、ATRに対する取得位置、現在帯・反対圧力を役割別に見る。C0の全条件未成立を、そのまま元背景の否定へ読み替えない。通常押戻しと強い背景否定を当時点で区別する条件を先に定義し、再評価により同参照へ後から入る価格と量まで再生する。固定S標本の事後群集計は候補作りにとどめ、新戦略の損益と呼ばない。

原板G1は486,342、Source通知は9,849、保存判断は4,442,461、Viewerは18,520項目で差0。Source650通知を264会計へ結び、元Sourceの全Step/Force/定時Frameを固定80と比較した。これは実装・会計の検査であり、安定利益の達成やFAR戦略の独立再実装の証明ではない。
