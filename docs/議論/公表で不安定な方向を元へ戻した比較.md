# 公表で不安定な方向を元へ戻した比較

2026-11-12記録。[135](../../study/00135_公表差で不安定な方向上書きを抑える/README.md)では、旧79出生と全73場取得を固定し、CSV・Raw即時・Raw遅延の選択方向が一致する時だけ固定T8を使い、他はSource元方向へ戻した。E0は元方向保護。三公表は同じ価格の異なる形成であり、三つの独立テクニカル票ではない。

主U0は33順23逆未17不足6、58.93%で70%未達。IFD既知76/未知3、C5利益450,612円・損失373,464円・既知差引+77,148円。旧T8のC0は39順18逆未16不足6、68.42%、利益506,304円・損失313,156円・差引+193,148円。主は116,000円悪化し不採用とした。[結果](../../study/00135_公表差で不安定な方向上書きを抑える/結果と限界.md)、[全場CSV](../../outputs/01a1889f-f2af-7943-a047-543275ee9ed2/135公表差CSV/README.md)。

## 不一致は元方向が正しいという証拠ではなかった

全79出生で三方向が計算でき、49件の一致・9件のE0保護・21件の公表不一致があった。最終U0が旧C0と違った13件はすべてSource復帰だった。その変更群は、C0の8順4逆1未・C5+28,999円から、U0の2順9逆2未・−87,001円へ変わり、全13件既知のペア差は−116,000円だった。

『入力形成に敏感な反転をやめれば元の複合判断が優る』という仮説はこの群で支持されない。不一致は入力・既知性への感度を表すが、元判断と反転判断のどちらが正しいかを直接は教えない。結果を見て元へ戻す群を再選別する場合は、新仮説と別試行にする。

## 当該OHLCが同じでも指標状態が違う

同じ出生でRaw遅延方向が変わった5件は、採用5/15/30分のEndとOHLC、実体比/B0が同体だった。5件すべて30分EMA21増分がCSV既知からRaw未知へ変わり、T8の追加反転が止まった。3件は5分Hist/ATRも未知になった。当該足の形の違いではなく、指標の状態差が直接の分岐である。

reset・carry・warmupのどれが未知化を起こしたかは、この保存237行だけでは未証明。価格未知を通信欠測と決めつけず、履歴本数や最後のreset/seed由来を追う必要がある。[非金融診断と事後原因](../../study/00135_公表差で不安定な方向上書きを抑える/根拠/同じ79出生の公表差.md)。135のN0/D0は固定79出生の方向だけの比較であり、134の78取得へ直接対応させない。

次は、方向上書きの多数決だけで改善を狙う前に、当時の指標状態と利用可能性を揃え、背景→押戻し/失速→構造回復→取得維持の順序を検証する。既存119/120/129も順次確認を持つため、単なる別名再試行を避け、差分を固定する。[外部調査の参考](../../study/00135_公表差で不安定な方向上書きを抑える/根拠/次入口の因果順序.md)は未採用・未検証の案で、135の条件を後付け変更しない。
