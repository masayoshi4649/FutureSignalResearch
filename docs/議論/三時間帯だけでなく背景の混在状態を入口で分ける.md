# 三時間帯だけでなく背景の混在状態を入口で分ける

2026-11-14。[161](../../study/00161_三時間帯の入口を共通属性分割で比較する/README.md)で、デイ・ナイトNY09:30前・以後を入口の採否へ組み込んだ。共通100特徴、三帯属性入り103特徴、帯別100特徴を同じ過去20場・成熟時計・学習支持・IFD±125で比較した。時間帯はq0で決め、取得後のq1分類と区別した。

旧151の全q0確率と65モデル、旧151/152/153の主要8政策は保存正本と同体だった。これは再現性の確認であり、未見の将来性能を確認したものではない。共通新枝は旧152A0そのもので、Fの参加補完を新しい技術エッジへ帰属しない。旧153 U15の入口目標一旦達成も変更しない。

## 背景が混在するところに設計上の穴があった

旧補正は「30分EMA21の傾きと30/15分DIがすべて元方向と逆、15分ADX>25」の強反対背景G内だけで短期回復Rを必須にする。Gが偽なら元の予測方向を維持する。

旧14件は30分EMAが上向き、30分DIが反対、15分DIが元方向、ADX23.09と食い違っていた。このためG外となり、5分Hist/RSIの失速や1分構造回復の未知・不成立を注文拒否へ使わなかった。取得はEMA8より−1.30～+0.20ATRで、単純な追い高値上限でも拒否できない群だった。

この実例から、**強反対ではないことを、そのまま順行可能の根拠にする設計**を見直す。時刻区分を残したうえで、背景同方向・反対・混在を技術で定義し、混在時の短期再加速・構造回復・量の確認を分けて検証する。

## 心理面の解釈は仮説として残す

平均線の上向きは過去の買い優勢を反映しても、現在の追加需要を直接示さない。上位の買い方向が残ったまま、短期の新規買いが弱まり、利食いや戻り売りが相対的に強くなる遷移を考えられる。Hist/RSIの増分、実体回復、相対量、BB余地、ATR比値幅やヒゲは別の役割を持つ。

これはデータと整合する心理仮説であり、売買主体の意思を観測した事実ではない。過熱や大商いだけで反転せず、反対側の構造回復と勢い・量を確認する。相対量の未知を0へ変えて弱い需要と解釈しない。

4. 同一構造の近接入口を、押戻し・失敗突破・回復の状態変化で再武装すると、連続損失を減らせるか。
