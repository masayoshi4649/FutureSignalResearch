# 事前帯の外保持と内回帰を分けた比較

確認日：2026-11-06。[試行75](../../study/00075_事前帯の外保持と内回帰を判別/README.md)の保存結果から得た知見。全66場は既使用で、以下の時系列検査20場は結果JSONの「学習」に対応する評価期間である。初20場の学習専用区間を含めた成績ではない。新しい学習・独立測定は行わず、3政策を各46場で一枚運用した。

事前帯と現在の反応を組み合わせると順行・反転の候補は生まれたが、先着70%・費用・活動を同時に満たす政策はなかった。前帯への変更で総損失は縮小したものの、準備集合と参加集合も変わっている。前提線までの距離とRの中央余地を制限すると損失取引と250先着の両方が減り、活動はほぼ失われた。

## 場所・価格の形・技法資格を分ける

[本人・取引所資料の整理](外部再調査/事前帯の外保持と内回帰を判別する.md)を踏まえ、帯外への進行が続く形Tと、外試行から帯内へ戻って別足で再開する形Rを直接条件にした。観測帯は正常BBOと正有限Lastの高安であり、公式の全約定高安、価値領域、参加者のinventoryを測ったものではない。

当場の外終値5pt以上が完全隣接2本続けばT。Rは同じ外試行の最終外足後1〜3本の内復帰f、その後1〜3本の別足でfの反対端を実方向へ終値突破するkを要する。前提を失えば取消し、同じ原因から復活させない。有効な形は次の15分判断でも残り得る。

全候補に方向付きFastK中央差0以上・変化strict正、現在終値変化strict正を求める。Tは15分DI同方向、既知ADXが20以上かつ非減速。RもDI同方向なら順行で、逆方向の場合はADX減速と方向付き15分終値位置の正を必要とする。さらに当時Lastと新規側BBOの両方が前提線の実方向側にあることを求めた。T/Rは価格の形成種別であり、順行/反転というDIとの役割とは異なる。売買は同じ式の符号反転である。

## 前提に近い取得は、多くの成功も除外した

P1は実sideをs、当時新規側気配をE*として、前提線までの距離 `0<s(E*−line)<=D` を求める。Rには `s(帯の算術中央−E*)>=250` も加える。E*は判断時気配であり、1秒後以降の実取得を保証しない。算術中央までの名目余地も、実追尾で回収できる値幅ではない。

P0/P1の準備集合は同じだった。選択期の基本適格な形成観測98件中93件が位置条件で除外され、距離超過93件、R中央余地不足32件を記録した。理由は重複し、この32を93へ加算しない。ここで98件は形成ごとの観測であり、一般には定時枠数と同じではない。今回はP0純98枠とも一致した。

[保存ラベルの補足比較](../../work/75完了整理/共通知見の補足集計.json)では、残った計8候補は同元枠・同方向で、先着の非説明項目が同値、形成T/Rの入替えも0だった。実完結も同じ8件で、共通出口差0円。これは今回の保存結果であり、一般に位置条件後の同側T/R選択が変わらないという規則ではない。

取り逃がした250先着は利益取引の取り逃がしと同義ではない。除外した実完結の主額は赤字であり、P1の総損失は縮小した。しかしP1も時系列・選択は赤字で、後続の＋1,278円は1件だけである。選択期のR3件＋234円も、片道滑り10ptでは−66円へ変わる。少数の黒字を安定した優位性とは認めない。

## 有効な形の反復と、その場で取得する資格

P0の選択期は3,377形観測に対して171形成ID、active観測404、採用98枠に対して採用ID32だった。同じ採用形の最大反復は10枠。採用kから判断までの経過は中央値4,161.5秒、最大21,246秒である。古い形が生きていることと、現在がよい取得位置であることは別の問いとなった。P1では採用ID5、最大反復1、k経過中央値162秒へ変わったが、時間条件で選んだ結果ではなく位置条件を通った集合の記述である。

P0のactiveでも複合条件に届かない観測には、FastK進行が非正234件、終値変化が非正219件、FastK中央差が逆向き125件、TのADX減速81件、ADX20未満35件などがあった。これらも重複理由であり、個別技法の効果や排他的な待機内訳を表さない。帯外/帯内の位置だけで、現在の勢いまで認定したわけではない。

## 保護・費用・活動を通した結論

利益旗は現在の正常返済BBOによる主費用後益がstrict正になった時に起動する。以後の最低名目新規床、損失線の非緩和、返済要求後の保護凍結と次BBO約定は維持した。先着250を待つラベルと、この連続退出の回収は別である。

選択期O0は利益旗76件中56件が主費用後赤字で、同値30・有利だが費用負け19・不利7。P0は70件中50件が赤字で、同値24・有利費用負け17・不利9だった。P0の250先着27候補に対し、実完結のうち26件は対応する250到達より前に退出している。名目新規床は手数料・滑り・約定遅延を含む損失0円の保証ではない。

今回、全政策・全期で実運用の品質注意場は空、未解消0で、全体確定0/5/10円はnullではなかった。一方、独立先着の「不足」や前帯の準備不足は存在し、それを実運用の品質注意なしで消してはいない。O0/P0は全期とも滑り0ptでも赤字。P1も時系列・選択では0/5/10全て赤字だった。

選択期の主待ち率/保守上限はO0が73.20%/84.91%、P0が71.73%/88.74%、P1が82.32%/99.32%。全予定888枠が分母で保有継続は非待ち、判定不能を加えた保守上限で活動50%以下を判定する。新3政策はいずれも三期全て活動未達で、P1の損失縮小をそのまま採用とはできない。O0の時系列・選択、P0の選択は入口支持を満たすが70%未達、P1は全期支持不足である。

次の問いは[広い帯の内側と局所の波](外部再調査/広い帯の内側と局所の波を分ける.md)を分けることになる。前帯の外試行が無い帯内でも、当場prefixの局所進行→起点を失わない押戻し→別足の再開を価格構造として定義できるか。逆方向は取消だけで注文せず、前提喪失後の別足反対確認と上位の減速・短期応答を組み合わせる。広い帯端は場所、局所端は前提線として区別し、E*からの距離と確認後の取得遅れを記録する。

この案は結果を見て生まれた未固定・未実行の探索仮説である。窓・寿命・閾値、条件切替やhybridの額はまだ算出していない。費用・利益保護・支持・活動の条件を下げず、初動に第2波が来ない反例、確認で追随取得になる反例も残す。価格や指標から注文主体・心理を直接観測したとはしない。
