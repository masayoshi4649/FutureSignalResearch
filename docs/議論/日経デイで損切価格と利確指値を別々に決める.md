# 初期の損切価格と利益の守り方を別々に比べる

2026-11-22。日経199_02デイの研究では、同じ損切で利確方法だけを変える対照が必要だった。元の固定利確かトレールかという二択だけでは、「午後だけ目標を縮めること」と「期限前の利益に追尾を置くこと」の寄与が重なる。[試行220の全条件](../../study/00220_日経199デイの損切位置と利益の確定方法を比較する/README.md)

|問い|同じにするもの|45デイで分かったこと|
|---|---|---|
|狭い損切は赤字を減らすか|元181件の取得と元利確|0.75Rに逆行した55件のうち14件は最終黒字。一律0.75R損切では総損失が228,078円増えた|
|どの注文が利益を守ったか|初期損切と、午前・午後ごとの利確指値|期限前を含む可変追尾を加えた増分は収支＋8,000円、総損失10,231円減。9/29の売りを救ったのは午後の指値、11/20の売りを救ったのは追尾だった|
