# mini片側10枚と5分判断への研究更新

更新日：2026-11-08。ユーザーの最新指定を反映する。固定済みの試行80〜92は当時の条件のまま残す。ここに記す新条件の成績はまだ未検証である。

## 数量と費用

日経225miniを、買い最大10枚・売り最大10枚、両建て時の合計最大20枚とする。毎回10枚ではなく、複合的な技法の支持に応じて数量を変える。未約定の新規予約も各方向の上限に含める。元手法の支持スコアを校正済みの勝率と呼ばない。

手数料の正本は本会話でユーザーから提示された画像で、miniは約定1枚あたり片道税込38.5円、往復77円である。証券会社やプランは画像から推測しない。小数0.5円を途中で整数へ丸めず、税を再加算しない。新規と返済の各約定枚数で費用を計上する。

| 費用項目 | mini1枚の往復 | 10枚の往復 |
| --- | ---: | ---: |
| 手数料 | 77円 | 770円 |
| 片道5ptの仮定滑り | 1,000円 | 10,000円 |
| 合計 | 1,077円＝10.77pt | 10,770円 |

miniの倍率は100円/pt、呼値は5円である。[JPXの商品仕様](https://www.jpx.co.jp/derivatives/products/domestic/225mini/01.html)（確認2026-11-08）。滑り5ptは従来研究からの比較仮定で、mini実測値ではない。ラージ気配を代理約定に使う研究では、ラージとminiの気配差・miniの板厚・実際の部分約定は未測定である。手数料だけの場合と滑りを追加した場合を分ける。

片道5ptは「注文ごとに価格5円、miniの1呼値分、不利になる」という仮定である。次正常板の買いAsk・売りBidによる約定には、すでに気配差と要求後の板変化が含まれる。本再現では約定値をさらにずらさず、追加滑りを費用として別計上する。指定手数料だけの収支を必ず併記し、追加滑りを実測費用や証券会社の請求額と扱わない。

## 比較の順序

1. 元の連続判断と整数配分を再現し、旧100microの粗収支照合と、新mini10枚上限での実枚数・指定手数料・仮定滑りを確認する。元の判断は変更しない対照で、利益保護の完成版ではない。
2. 同じ元入口を基準に、費用後の現在含み益が正になった時点で連続追尾を必ず起動する方式を比較する。建値床と費用回収価格の床、失った大きい利益、約定後の赤字化を分ける。
3. 入口を15分・5分へ制限した影響を比較する。過去の参照残玉を無期限に新規信号へ置換せず、元通知の出生・保持期限・当時の再確認・失効を明示する。
4. 複数の技法で現在の継続・反転・待機を分け、入口と数量を改善する。背景、価格構造、勢い、値幅、量の役割を分け、元入口だけ／保護追加／技法追加を識別する。

条件を一度に全部置き換えると、黒字を失った原因も改善した原因も分からなくなるため、この順に基準を作る。新旧の市場再生は既使用データから行い、未使用日の本文を探索に開かない。

## 次に比較する時計

ユーザー提案に従い、5分刻みの新規判断と、デイ・ナイト・米国株通常取引開始後30分の新規見送りを候補に加える。デイの初回は09:15、ナイトは17:30、米国後はニューヨーク09:30の30分後である。米国開始は夏時間の日本22:30、標準時間の23:30で、固定した日本時刻にしない。

元手法の米国前後15分静観と、新しい開始後30分見送りは別の変更である。米国前の返済時刻、夜間手法の開始・準備状態、最後の新規枠、場末強制返済を各試行で固定する。方向判定に使う足の時間幅と、注文を判断する5分時計を混同しない。損益の保護は新規判断の時刻に関係なく全原行で行う。

## 利益になった玉を損失へ戻さないために

各玉の実建値と現在の返済側気配から、手数料と想定滑りを控除して利益化を判定する。正になれば追尾を起動し、保護線を後退させない。両建ての反対玉の利益で個別玉の保護未実施を隠さない。部分返済の実確定益と、未約定の予定益も分ける。

建値の床では往復費用が残る。片道5pt滑りの場合、価格差10ptでもmini1枚は費用後−77円、15ptなら＋423円である。費用回収価格を5pt刻みで安全側へ丸めた床も比較する。これは費用の算術で、次の板がその価格で約定する保証ではない。追尾の設定遅れ、発動前の反落、発動後の価格飛び・遅延、部分返済後の予算不足を別々に記録する。

利益率・損失率は、勝敗件数だけでなく、費用後総損益、総利益/総損失、平均利益/平均損失、最大ドローダウン、赤字場数、利益化後赤字化の頻度・金額、売買別・時間窓別の偏りで評価する。
