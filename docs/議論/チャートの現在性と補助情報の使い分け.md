# チャートの現在性と補助情報の使い分け

2026-11-07。[81の結果](現在の新規根拠と部分利益保護を分けた比較.md)から作る次の候補。**未固定・未実装・未再生**であり、安定利益を確認した条件ではない。初回除く15分新規と連続保護、売買の符号対称を維持する。

## 背景の方向と現在の進行を分ける

81の順行枝は3／15分EMAの並びを必要としたが、転換枝に使った現在MACD増分と終値のEMA8位置は順行へ必須化していなかった。平均の方向が残る一方、現在は失速・押戻り中という入口が混在し得る。これは実装条件の差であり、条件を追加すれば黒字になる証明ではない。

売り買いを`s=+1/−1`で反転する。確定公開済み3分足の終値C、EMA8 A、MACD(12,26,9)ヒストグラムH、ATR14 V、RSI14 R、直前確定足を添字−1、新規側BBOをEとする。

| 役割 | 共通候補条件 | 解釈と反例 |
| --- | --- | --- |
| 現在の進行 | `s×(H−H−1)>0` | 平均差の勢いが改善。価格が既に反転したという単独証明にはしない |
| 回復の実現 | `s×(C−A)>0` | 終値が短期平均の方向側。確認を待つほど取得が遅れる反例も測る |
| 取得位置 | V>0かつ`0<=s×(E−A)/V<=1` | 新規価格が平均から遠すぎないか。1ATRは81継承の仮置き |
| 急変警戒 | TR3>前ATR×2かつRSI差絶対値>15を拒否 | 同時急変は81継承。高RSIの持続そのものを拒否しない |

これらを同じ価格の独立した賛成票に数えず、背景・現在・位置の異なる問いとして組み合わせる。

## 順行と転換初動

- **順行**：共通条件と、3／15分の`s×(EMA8−EMA21)>0`が共に成立する。
- **転換初動**：順行ではなく、共通条件、方向別RSI増分>0、直前足の`s×(C−1−A−1)<=0`から現在の平均回復、当時の同方向E08帯・数量支持・反対圧力消失を合わせる。RSI50交差と上位方向一致を全て待たない。
- **待機／判定不能**：既知の不成立と、必要なチャート・転換構造の未知を区別する。補助の短秒情報が未知という理由だけでチャート既知の順行枠を消さない。

帯は81の60秒／32価格更新と同価格数量の鮮度を継承する。新鮮な反対供給帯は返済側BBOで10pt通過、新鮮な反対量支持は残らないことを転換に要求する。表示数量を実出来高と呼ばない。

## 補助情報の使い方を2案で比較する

自己短秒は元の`Selected.DayShort`を抽出し、v5／v15を方向別の`Move/Elapsed`、単位pt/秒で保存する。81の`Support.Own5/Own15`は窓別換算bp幅であり、この速度へ代用しない。各窓の既知性・元時計・異常理由を保存する。

| 候補 | 共通のチャート条件に追加する内容 |
| --- | --- |
| A：既知の反対だけ拒否 | 既知v5<0、既知v15<0、既知の方向別OFI30<0のいずれかがあれば見送る。未知を0・反対・支持へ置換しない |
| B：既知の失速だけ支持を確認 | Aに加え、両速度既知・v15>0・v5<=0.5×v15の時だけ、既知OFI正又は新鮮なE08帯・数量支持を必要とする。速度未知を失速扱いしない |

0は中立、未知は未観測として別記する。Bの失速時に補助が両方未知なら、追加確認は判定不能とする。元M/Tは未校正で未知補完を含むため、新規確率に読み替えない。相手120秒や自己120／300秒も当時値と既知maskを診断保存するが、この比較で硬い必須条件へ増やさない。

## 利益保護と正益前の否定

入口比較では81のG1を固定継承する候補とする。費用後現在益が正になった時点で部分利確要求・最低建値追尾を起動し、約定済み利益だけから残玉予算を計算する。要求の取消・延期をしない。部分利確後も赤字は起こり得るため、要求前と要求後の悪化を別記する。

81の正益未観測損失は短時間に生じており、3分確定足の技法否定より先に大きく逆行する場合がある。次の別仮説は、入口時に既知だった押戻り起点や帯の喪失を否定線にすること。入口変更と同時に都合のよい幅へ最適化せず、まず同じ出口で入口差を比較し、次に構造否定を分けて検証する。将来完成した高安や未確定足の終値を使わない。

## 心理の説明候補と資料の範囲

[外部資料6本の詳細と反例](外部再調査/失速と再開を分ける一次資料.md)も参照する。

平均線は過去価格の方向、MACDは勢いの変化を捉える。強いトレンドでオシレーターが高止まりすることと、反転形状に価格確認が必要なことは別の説明である。[CME・移動平均](https://www.cmegroup.com/education/courses/technical-analysis/understanding-moving-averages)、[CME・オシレーター](https://www.cmegroup.com/education/courses/technical-analysis/oscillators-macd-rsi-stochastics)、[CME・反転形状](https://www.cmegroup.com/education/courses/technical-analysis/technical-patterns-reversals)（2026-11-07本文確認）。

本研究の心理仮説は、平均の方向が残っていても新しい追随が弱まる場合、価格回復に追随注文と反対側の返済が重なる場合、帯の供給が残って再開が不発になる場合を分けること。参加者の実際の目的・新規／返済内訳は観測しておらず、因果関係を確認した説明ではない。

OFIと短区間の価格変化の関係を報告する[Cont・Kukanov・Stoikovの原論文](https://arxiv.org/html/1011.6402)は米国株の研究である（2026-11-07本文確認）。NK225、FAR正規化OFI30、15分定時の将来費用後利益を実証したものではない。

## 次の検証で固定するもの

同一の確定3分足同士で直前Close／EMA8／MACD／RSIを結び、連続180秒と終端時刻を検査する。3／15分の現在足は判断時刻以前で、未知・NaN・未来・セッション空白を区別する。100micro固定、同時一建玉、主費用と追加1秒、全66場の既使用性を維持する。

候補・実参加・保有・判定不能、順行／初動、補助の未知／反対／中立／支持を保存する。同実入口の出口差、入口時点と後続参加、正益前損失、正益後保護、昼夜・日別・費用感応を分ける。結果後に選んだ少数黒字群の合計を運用成績とせず、新試行の固定前提として検証する。
