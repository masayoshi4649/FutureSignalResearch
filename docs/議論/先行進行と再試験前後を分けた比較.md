# 先行進行と再試験前後を分けた比較

## 平均する区間を分けた

59は登録bから現在までを一つの平均で表した。60は旧38特徴へ、登録へ至る10終値差分の平均進行と効率、再試験rへ至る終値進行、r以後の平均進行をT/R各4列として加えた。全46特徴を、従来の上位DMI・短期ストキャス・ATR・価格構造と組み合わせる。同教師・同回収目的・同支持・同出口の比較である。

登録10差分は先行波全体の検出ではなく、bを含む固定区間である。正常なbの成立条件により、その進行と効率の符号はTで正・Rで負となる。符号を独立した方向確認と扱わない。rへの接触はヒゲでも起きるため、終値の押戻しを保証せず、rへの平均進行は正値も許した。未rの適用外0とr当足の既知0も区別した。

## 次に区別するもの

今回の新分岐は、既存の保持水準が有効か、取消済みかを入口条件にしていない。旧段階・有効旗は入力にあるが、入力しただけで木が必要な順序や意味を使うとは限らない。次の比較では、現在有効な形成と、否定された形成を明示的に分け、後者で反対方向や再取得の入口が成立したかを別に判定する。今回の70候補をただ全て消すだけでは、S1は無取引となり活動条件を満たさない。
