# 安定性を累計経路と取引の広がりで評価する

2026-11-16。ユーザーは、173前48J026の「先に累計損失を膨らませて後から回収する経路」と、174全期J002の「米後の取得が少なすぎること」を問題とした。**期間合計と中央値だけから173を「最も安定」とした評価を撤回し、174米後も安定採用候補には置かない。** 173/174の固定条件・当時選択・正本の数値は保持する。

## 173前48J026の累計損失

デイは金融未知0件、40場・67取得。終点は黒字でも、最初の12場中10場で場末累計がマイナスだった。

|項目|確認結果|
|---|---|
|開始からの累計の底|2026-10-05、−42,924円（11場目）|
|最大DD|9/29の＋5,461円から10/05の−42,924円まで、48,385円|
|ピーク回復|10/07。ピークの6場後、8暦日後|
|最後のゼロ回復|10/07（13場目）。以後の場末累計はゼロ割れなし|
|前半・後半・追加の合計/中央値|それぞれ黒字。ただし、上記の途中経路を否定しない|

DDは場末の実現収支ベースで、既知建玉の決済順でも同値だった。建玉保有中の時価DDを算出したものではない。最初12場の主2取得は＋19,846円、初参加補完12取得は−19,924円。主と補完を分け、参加確保の補完が累計を傷めていないかを入口から検証する必要がある。

米前はさらに開始3ナイトで−123,231円。ここは未知がなく確定した損失で、9/30（8場目）にゼロへ回復した。全期の米前には金融未知6件があるため、その後の既知分累計から全件のDD・回復を確定しない。

## 174全期J002の米後の支持不足

全40ナイトの米後は16取得、取得したのは9場、金融未知2件。主技術の成立自体は8場だけだった。先着10F/0Aという比率や赤字確定場0だけでは、安定した成績とは評価しない。既知決済には損失取引もあり、全勝ではない。

- 旧36Night：主42要求、18受理、15取得・3失効。保有による棄却24は全て米後自身の建玉で、米前保有による主要求の棄却は0。
- 追加4Night：1,111q0中、主成立0。必要条件が片側以上すべて既知だったq0はRG0034で947、NR0009で805。
- 両主入口は低ADX向け。RG0034は15分ADX<=15、NR0009は<=20を要求する。追加4NightのADXは全q0で既知かつ20超だったため、この条件だけで全て遮断された。

米前保有が一般に米後を抑制し得ることと、今回の希少性の主因を混同しない。今回は主入口の局面範囲が狭いことが中心だった。10Fは7場に分布するが、利益上位3場が既知利益の59.51%を占め、支持の広がりも十分ではない。

## 今後の評価と技術仮説

採否は総利益や両中央値だけで決めず、次を併記する。現時点で新しい数値の合格閾値を設定したわけではない。

1. 累計の初期損失、ピークからの最大DD、底と回復の時計、未回復期間。場末実現収支と建玉中の時価を区別する。
2. 連続する5場・10場の収支と中央値、赤字区間の長さ・位置。重なる窓を独立試行とは数えない。
3. 実取得数、取得した異なる場数・期間、特定場への集中。無取引が多いために平らな曲線を安定と呼ばない。
4. 取得0の原因を、指標未公表、技術条件不成立、保有/未決による棄却、取得代用の失効へ分ける。
5. 金融未知を0円に置かず、既知寄与の曲線を全件確定曲線と呼ばない。両中央値・費用・追加禁止・全場参加という既存条件も保持する。

次の入口仮説は、低ADXの帯端回復に加え、高ADX側で5/15/30分のEMA・DI方向と押戻し回復、MACD/RSIの持続とスパイク、実体・量を組み合わせ、順行・失速反転・待機を判別する枝を持たせること。ADXだけで方向を決めたり、閾値を外すだけで件数を増やしたりしない。これは原因から立てた未検証仮説であり、売買条件を変更する場合は175以降の別試行へ置く。
