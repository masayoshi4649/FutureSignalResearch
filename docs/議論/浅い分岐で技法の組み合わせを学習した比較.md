# 浅い分岐で技法の組み合わせを学習した比較

確認日：2026-11-06。[試行51](../../study/00051_技法特徴の浅い分岐学習/README.md)は、当時のDMI、FastK、ATR、開始帯と足形を浅い決定木で組み合わせた。深さ4のQ1は条件選択24場で活動条件を満たしたが、仮250先着率29.05%、費用後−85,454円で、先着70%と収益には届かなかった。深さ2のQ0も含め、両期間同時適格は0/2である。

本稿は[結果JSON](../../study/00051_技法特徴の浅い分岐学習/結果.json)、6モデル、正式帳票、保存物確認の読取である。詳細圧縮ファイル、原板、キャッシュを開かず、市場再生・特徴再計算・モデル再fitを行っていない。全66場は研究に既使用で、今回のfit外評価を研究全体の未見検証とは呼ばない。全条件・全葉・手法表は[設定と結果](../../study/00051_技法特徴の浅い分岐学習/設定と結果.md)へ残す。

## 何を変え、どの期間で比べたか

[50の追加診断](局所再開の発動と定時までの失効.md)では、調整の登録終値まで回復した群が両期間で一貫して優位とはならず、OR外・同方向DIという背景も全枠の約48%だった。そこで51は、OR外や同方向DIを入口の必須ANDにせず、その価格位置や方向を特徴として渡した。旧P0の採否・役割・保有、将来の先着は特徴選択へ使わない。

特徴は3分FastK14の水準・変化、3分ATR、OR幅と中央からの距離、現前3分の価格変化・足形、15分DI差・足形の15列。価格由来の加工が多く、独立した注文・心理の15票ではない。量、MACD、RSI、注文集中の実測は今回未使用である。共通木を両方向へ適用し、最高得点の一方向だけに、score1/3以上、葉の異なる枠60・6日・10場以上、経路の異なるfamily2種類以上かつtrend又はoscを要求する。同点や最高側不適格は待ちで、次点へ救済しない。

教師は固定49の同時計B±先着で、250を1、125と観測された期限未達を0にした。未約定・不足が片側でもあれば同枠の両方向をfitから除き、除外を現在の特徴準備へ戻さない。各方向の重みは1/2だが、同枠二方向や重なる将来経路が独立標本になったとは扱わない。各木の教師終了は評価開始よりstrict過去で、評価中は再fitしない。

初期20場はfit専用。最初の20場で作った木を次の10場へ、最初の30場で作った木を次の10場へ適用する。以下の「時系列検査20場」は、その二つを合わせた評価であり、40場への当てはめ率ではない。条件選択24場と既使用後続2場は40場fitの木を固定して使う。深さ2/4それぞれ3木、計6木で、評価の予定枠は740/888/74となる。

## Q0の0取引は、入力がなかったという意味ではない

時系列検査のQ0は純採用も実完結も0だった。保存判断理由の740枠は、複数技法不足173、score下限未達と複数技法不足の重複217、同点238、特徴判定不能112に分かれる。保有による抑止だけで0になったのではない。

[Q0_W20](../../study/00051_技法特徴の浅い分岐学習/models/Q0_W20.json)の分岐はF06（OR中央からの実方向距離/ATR）とF05（OR幅/ATR）だけで、price以外のfamilyを使っていない。[Q0_W30](../../study/00051_技法特徴の浅い分岐学習/models/Q0_W30.json)はF06とF04（ATR/125）を使ったが、必須としたtrend又はoscを含まない。W30の葉率も全て1/3未満である。したがって「深さ2では技術的な局面が存在しなかった」とは言えず、この学習と採用資格の組合せで採用が残らなかった、と読む。

40場fitの[Q0_F40](../../study/00051_技法特徴の浅い分岐学習/models/Q0_F40.json)ではF01（実方向DI差/100）が分岐に入り、条件選択で329純候補が残った。これは同じ条件で学習材料が増えた後の別の固定木であり、評価結果を見て資格を緩めたものではない。採用葉6の学習率37.52%に対し、条件選択の選ばれた入口は76/316＝24.05%。その経路は実方向DI優勢を要求するため、実際のQ0採用は順行だけだった。

## 学習葉の率と、その後に選ばれた入口を分ける

6木とも最初の分岐にF06を選び、後の分岐にはDI差、FastK変化、ATR、OR幅等が使われた。これは固定した特徴とgini分割で選ばれた関連であり、OR中央に注文が集中することや、その特徴単独の利益を実測した結果ではない。例えばF14（15分幅/3分ATR）はQ1_W30で使われたが、Q1_F40には残らなかった。FastK水準F02や多くの足形列が分岐に選ばれなかったことも、単独効果を否定する検定ではない。

とくに[Q1_F40](../../study/00051_技法特徴の浅い分岐学習/models/Q1_F40.json)の葉18は、学習率71.11%、90ユニーク枠・10日・12場で、price/trend/volの経路だった。表示を短縮すると、F06>−8.476、F01>0.104853、F05≤5.351、F04≤0.429333である。実際の採否はモデルJSONの全桁閾値とfloat32特徴で行い、この表示値を新条件にしない。

その葉へ条件選択で採用された入口は8/26＝30.77%、実完結24件・−3,428円。後続2場の採用は0だった。**学習で70%の葉が得られたことは、後続の70%達成ではない。** ただし学習率はその葉に入った全方向行の比率、後続率は両方向の最高側比較と採用資格を通った入口の比率なので、同じ母集団の校正検査や同群の崩壊とは断定しない。

早い期間も一様ではない。Q1_W20の採用葉7は学習40.23%に対し次期間6/28＝21.43%。Q1_W30の葉10は学習34.29%に対し32/85＝37.65%、葉12は46.36%に対し14/35＝40.00%だった。これらは各10場の葉別集計で、単独では学習側の日数6等の支持条件を満たさず、葉を選べば一般化したという根拠にはしない。

葉別の非重複間引きは各葉の部分集合内で再集計されるため、葉間の件数を足して候補全体の非重複239件にはできない。表の実完結・観測円は実際の混合運用から入口葉へ帰属させた値で、葉だけを単独再運用した成績ではない。葉別評価も全方向scoreの確率校正とは区別する。

## 順行と反転の両方を増やしても、回収は別だった

役割は当時の上位DI差と選択sideが同方向なら順行、逆なら反転、DI同値は役割未確定WAITとした説明ラベルである。明示的な突破失敗や心理的方向転換を正解教師にしたわけではない。

Q1の時系列検査は順行41/103＝39.81%、反転11/45＝24.44%。混合入口の支持は充足するが、各役割は日数又は件数の支持不足だった。条件選択は順行79/280＝28.21%、反転59/195＝30.26%で各役割の入口支持を満たしたが、どちらも70%未達。実完結は順行270件・−54,440円、反転187件・−31,014円だった。反転群の率が順行群よりわずかに高くても、同時計・同母集団の切替効果や利益と同義ではない。

既使用後続2場のQ1は20/56＝35.71%、56完結・−12,732円、保守待ち21.62%。活動は満たしても支持不足であり、将来成績を裏付ける未見標本ではない。

運用は49のままで、利益前も連続追尾、現在の正常返済BBO粗益−122円がstrict正なら利益旗、最低名目entry床・非緩和を維持した。固定250利確はない。Q1の利益起動は時系列検査102件・条件選択311件で、そのうち最終追加5pt費用後赤字は同順77件・226件。実MFE250は5件・8件で、仮250先着の52件・138件とは母集団も経路も異なる。名目同値床は費用後同値を保証せず、起動後赤字を全て粗損への転落と決めつけない。

全候補・全期間で損益品質注意と未解消は0なので、表の観測額と全体確定額は一致する。これは特徴判定不能112/82枠がなかったという意味ではない。追加0ptでもQ1は時系列検査−4,646円・条件選択−39,754円であり、追加5ptだけを赤字の原因とする説明も成立しない。

## 次に残る問い

ここからは未採用の研究上の問いであり、51の結果や条件を変更するものではない。

1. **広い波の履歴を何で表すか。** 今回の15特徴は主に現在・前足・開始帯の位置で、調整内の戻り高安、元トレンド極値、防衛線、回復後の再失敗という履歴を明示的に区別していない。[外部調査](外部再調査/調整の起点回復と失敗の見分け方.md)と[50の起点回復診断](../../work/局所再開/00050/起点回復の診断.json)を踏まえ、当時既知のどの構造を表現するかが残る。単純にb終値回復をANDして改善したとは扱わない。
2. **方向葉の安定性をどう確かめるか。** Q0は早い二つの木で採用0、40場木では順行のみ。Q1は採用を両役割へ広げたが、高い学習葉率や分岐構成は後続の成功を保証しなかった。特徴追加や良い葉の事後選別の前に、固定した条件が次の期間でどの葉へ入り、どの方向・支持で残るかを確認する必要がある。
3. **先着と回収をどう接続するか。** 活動を満たす頻度が得られても、先着率と費用後回収は未達だった。広い波での取得位置、保護による早い返済、名目床と費用の差は別々の仮説であり、本結果から最適な追尾幅・新しい出口・閾値を決めない。

[価格履歴の原論文調査](外部再調査/価格の履歴と一時点の指標を区別する.md)では、順序付き極値を定義しても、極値の発生日・認識日・評価開始日を分ける必要があった。指標自身も履歴の要約であり、追加履歴が今回の不足を解消すると確認したものではない。

[実証と評価尺度](外部再調査/実証と評価尺度.md)で整理した反復探索と未見不足も残る。手動ANDから木へ移って探索を透明にしたことは、心理の直接測定や、既使用期間を未見に変えることではない。先着70%、活動50%以下、費用後正の目標を下げる根拠にもしていない。
