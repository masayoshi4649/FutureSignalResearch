# 元Sourceの売買対称性と重複条件

2026-11-09。外側のE3S・S5Q・S515Q・会計の人工鏡像と、元Sourceが自然入力から同じ条件で買売を生成することを区別する。試行100/101が参照する純戦略43は現物指紋と一致したが、全Sourceの売買対称を無条件に確認済みとはできない。[確認範囲と指紋](元Sourceの売買対称性_参照.json)を参照する。

## 確認した例外

[判断式](../../../SessionTradeExecuter/internal/rules/addon_specs.go)の`addon.entry.range_side`は、方向効率が0.3以下のとき、先に`mid <= low + 0.1R`なら買い、そうでなければ`mid >= high - 0.1R`なら売りを選ぶ。[実行側](../../../SessionTradeExecuter/internal/strategy/active143.go)にも同じ順序がある。

高安幅Wが`W <= 0.2R`なら二つの領域が重なるため、両条件が真の場合も買いを返す。Rは[特徴生成](../../../SessionTradeExecuter/internal/strategy/features143.go)の`max(ATR, 0.5W, 8tick)`であり、領域が重ならないことを保証していない。三Sourceから到達し得る共通入口の静的な方向裁定である。

説明用の数値例として、low=70,000、high=70,010、R=80、mid=70,005、方向効率0.2なら、買い境界70,008と売り境界70,002の両条件を満たす。現在の順序は買いを選ぶ。この例は原板で観測した事例ではなく、分岐の重複を示すための例である。

## 確認範囲を混ぜない

- 数量・容量・保護やD/P/U固有の多くの判断は、同じ方向付き関数・閾値・整数換算を共用している。昼夜や担当別の差を買売の差と誤読しない。
- bp率等は同じ閾値でも、任意の算術的な価格反射で特徴まで厳密に符号反転するとは限らない。これは側別係数差や、上の買い優先分岐とは別の性質である。
- 既存93の手製通知による鏡像は、所有・約定・費用等の接続検査である。自然Source生成全体の成功へ読み替えない。

自然データで重複域が発生したか、最終通知まで進んだか、損益へ影響したかは未確認。現在の結果の良否をこの分岐へ帰属しない。旧43・Source通知・固定試行100/101は変更しない。

## 次の検証で扱うこと

新しいSource候補では、両条件成立を明示的に検出し、待機等の方向対称な裁定を別条件で検証する必要がある。上位方向・勢い・量で方向を選ぶ案は、単純な重複待機とは別の技法変更として扱う。

その後、[104](../../study/00104_重複時の方向裁定と元Sourceの再形成/README.md)として重複時だけ待機にする一式を採番し、完全Observationから全54場を再形成した。3生成口の全通知記録が同一で、同じB5Q/LD10を適用した新旧216Book対も全JSON同体だった。[結果と限界](重複方向の修正後も維持されたLD10の成績.md)を参照。修正の標本内利益改善は0。L/Hの内部実評価回数は未計測なので、重複域の不発生や自然Source全体の完全鏡像を証明したとは言わない。

入口時計の再判断と、この方向裁定の修正を一度に混ぜて効果を判断しない。新条件を実行前に固定し、実発動数・売買方向・実現収支・利益後赤字を記録する。機会損失を理由に重複域の参加を増やすことは目的にしない。
