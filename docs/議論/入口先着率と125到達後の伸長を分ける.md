# 入口先着率と125到達後の伸長を分ける

2026-11-12。[157の固定入口比較](../../study/00157_固定入口の到達距離と追尾退出を比較する/README.md)で得た共通知見。

±125ptの入口先着率は、初動の方向判別を評価する。+125へ到達した後も同じ方向へさらに125進む優位とは別である。高い入口先着率だけで利確を250へ延ばさない。

125→250の確率には、保有期限と下側条件が必要である。初期−125を維持する場合、+125から許す下落は250pt。建値0なら125pt、峰から100の追尾なら高値の更新に合わせて許容価格が動く。各条件の確率を同列に扱わない。

全起点数、目標先着、下側先着、期限未到達、観測不足を残す。先着が判明した例だけの率は、全起点数での率より高く見えることがある。無保護の将来到達と、政策が途中退出せず保持できた到達を区別する。

追尾起動を早くするだけで、利益後赤字や損失総額を減らせるとは限らない。小幅利益で建値床を置くと、通常の揺れで費用負けの決済を増やし、利益総額を大きく減らすこともある。これは今回確認した結果であり、全市場・全入口への一般法則ではない。

市場心理の仮説として、取得後に支持が形成されるまでの揺れと、支持が否定された失速は別の状態と考えられる。次の技術保護では、価格構造、ATR/BBによる通常値幅、勢い/量の継続を当時情報だけで組み合わせて区別する。過熱単独・MA単独で退出を決める仮説へ戻さない。現157はその可変幅の有効性をまだ検証していない。

出口の比較は同じ入口・期限・費用・約定遅延の単純IFD±125を対照とする。未知数が違う場合には同取得で双方既知の対応差分も必要。利益総額・損失総額・差引・利益後赤字・場ごとの安定性を併記し、損失総額が減っただけで改善としない。

標本数も取得件数だけでは測れない。152 U0は153 U15より多数だが、上位5場への集中が大きかった。場単位の再標本化と前後区間を確認し、場内の連続取引や共通取得を独立標本へ水増ししない。既使用データでの参考区間は、未知データの運用再現性を保証しない。
