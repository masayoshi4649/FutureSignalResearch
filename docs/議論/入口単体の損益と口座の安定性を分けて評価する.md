# 入口単体の損益と口座の安定性を分けて評価する

確認日：2026-11-17。根拠は[183](../../study/00183_単純IFDで両指数の入口と損失安定性を検証する/README.md)と[184](../../study/00184_TOPIXの足の形成時計と入口の反転を検証する/README.md)。対象はNK225とTOPIX、出口は単純IFD。今回の数値を一般的なテクニカルの有効性や将来利益の保証にしない。

## 新入口を追加した口座が改善しても、その入口が良いとは限らない

単一保有では、新入口の取得が次の予約・保有・返済時刻を変え、後続の既存入口も入れ替わる。183のNK04では全デイ収支と赤字場数が改善したが、新しい押戻し入口36取得自体は−45,772円だった。

今後は必ず、基準口座と新口座の全体比較に加え、残った既存入口、新構造、既存入口の方向切替、補完入口を分ける。同じ取得の利益を複数の指標の効果へ重複帰属しない。差し替わった取引の診断は実現損益を説明するために使い、未参加の仮想利益を機会損失として最適化しない。

## 損失総額・赤字場・連鎖・DDを交換しない

全BO確認待ち01は損失総額を減らしたが、赤字デイは10→14場、連続赤字も増えた。一方、押戻し追加04は赤字場10→9、DD低下でも損失総額と直近追加期を悪化させた。よって「改善」はどの軸かを必ず指定し、全面的な安定化と部分改善を分ける。

適格性は全場取得・保有下限20%・両中央値黒字・未知非増加。順位では損失の発生頻度、深さ、連続性を利益額より先に置く。前半選択と全期発見を保存し、後半・追加期・最終場を分ける。既知寄与のDDを、未知取引を含めた真のDDと呼ばない。

## 低ADXだけではレンジを確定できない

184のTOPIXでは低ADX反転R0の実側反転で、デイの損失・赤字場・連続赤字が減った。元方向の逆張りが弱かった可能性を示すが、ADXは方向の指標ではなく、遅行や足の形成状態によっても低くなる。心理仮説としては、方向が形成され始めた段階を「往復が続く場」と誤認した可能性がある。

この仮説を確認するなら、ADXの水準だけでなく傾き、DIの優位の持続、MAの収束後の拡大、価格帯内への復帰/外側の受容、相対量を組み合わせる。これは次回の仮説であり、この組み合わせの改善損益はまだ計算していない。反転の率を1−pとせず、実側BBO・保有枠・期限で再計算する。

## 足の不成立と市場の不適合を分ける

TOPIX初期2場の未参加は、1分足の確認遅延を長い足にも波及させたことで、15分足の履歴が足りなくなった影響があった。原板から長い足を直接形成すると初日の判断が生じるが、参加改善だけでは損失改善を保証しなかった。同じ反転条件でも足形成変更で赤字に戻ったため、支持された値が足形成に依存していないかを確認する。

取引のない足を架空の0出来高足で埋めたり、存在しない受信時計を作ったりしない。CurrentPriceTimeによる観測、板時刻不明、累積量の可視時刻を区別する。市場心理の説明より先に、何がその時点で分かっていたかを固定する。

## 板情報を次に使う場合

注文フロー不均衡・キュー不均衡・注文履歴に関する一次研究は、短期価格形成を考える根拠になる。ただし株式や次の1ティックの結果を、そのまま日経/TOPIXの幅広いIFDへ当てはめない。スナップショット数量から完全な約定フローや吸収を観測したとも言わない。[一次資料と適用限界](../../study/00183_単純IFDで両指数の入口と損失安定性を検証する/NK225/外部一次資料.md)。
