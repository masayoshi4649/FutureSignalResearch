# 重複方向の修正後も維持されたLD10の成績

確認日：2026-11-09。[試行104](../../study/00104_重複時の方向裁定と元Sourceの再形成/README.md)の既使用54セッションに基づく。数値の正本は[主B結果](../../study/00104_重複時の方向裁定と元Sourceの再形成/成果物_主B/結果.json)と[保存検算](../../study/00104_重複時の方向裁定と元Sourceの再形成/成果物_主B/保存会計の確認.json)。未見期間の安定収益を証明した結果ではない。

## 変更を分けて比較した

元Sourceの共有D07で、低方向効率の範囲逆張りの買い・売り条件が両方成立したとき、買い優先から待機へ変更した。他の技法・数量・返済を変えず、元の完全Observationから全54セッションを再生成した。旧生成口と既定全式を渡す生成口の108ケース・324Source会計は、旧93と全JSON構造が一致した。

さらに、旧／修正Sourceのそれぞれへ、103と同じ5分判断・一定利益後のLD10追尾を適用した。主Bは432会計、旧側216会計は103の全Bookと一致。新旧同費用の216対も全Book JSON・除外0で一致した。全時点を別engineで再計算した独立金融検査とは区別する。

通常条件の費用後正益を一度でも観測した253玉のうち最終赤字112玉、赤字額−1,383,939円。一方、LD起動129玉のうち最終赤字21玉、赤字額−3,079円。小利益から起動前に赤字化する経路は残っている。起動後の小さな赤字額だけを、全ての利益後赤字を解消した結果としない。[103の比較と限界](利益追尾の起動時機と元の建玉構造を分ける.md)を維持する。

## 今回の修正から言えること

全54場で、3つの生成口の全Step/Force記録の圧縮SHAと結果本文SHAがそれぞれ一致した。[記録](../../study/00104_重複時の方向裁定と元Sourceの再形成/検査/Source全54場/三方式の保存同体.json)に基づき、**今回の方向裁定修正による公開通知・損益への影響は観測されなかった**。

ただし、内部で範囲方向式を評価した回数やL/H両条件の同時成立数は記録していない。重複領域が一度も発生しなかったとも、全ての自然Sourceが任意の価格反射に対して完全鏡像になったとも言えない。確認した買い優先例外を、以後の候補では残さず、標本内の改善額を0として記録する。

旧93のJSON構造同値と、今回A出力のbytes同体も異なる。新Aの3mode間ではbytes指紋が同じでも、旧93の保存JSONとは整形・エンコード等のbytesが異なる。過去の元SHAを新結果へ付け替えない。

## 次に確認すること

1. 条件を変えず、使用歴を調べた11月5～6日の4場で追加確認する。限定した記録では実入力採用の証拠がない候補だが、完全な未見を証明したものではない。原板を開く前に新しい試行・アルゴリズム・入力・時計を固定する。
2. その後、同じSource版の中で[収束・勢い・価格構造による可変幅](収束と失速を分ける可変追尾の候補.md)を別比較する。新Sourceと幅変更を同時に導入して効果を混ぜない。
3. 正額・負額・DD・利益後赤字・参加率を同時に見る。未参加や退出後の仮想利益は評価しない。既使用54場の反復改善を、未知期間の安定性と呼ばない。
