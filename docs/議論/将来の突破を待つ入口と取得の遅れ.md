# 将来の突破を待つ入口と取得の遅れ

確認日：2026-11-06。[試行67](../../study/00067_定時候補を将来価格の突破で発動/README.md)では、複数技法が選んだ方向を維持し、将来の価格突破で発動する入口を比較した。**条件選択期間では損失総額は縮小したが、先着率は低下し、共通する元候補の回収も悪化した。確認を待つだけでは入口の改善にならなかった。**

## 何を固定して変えたか

旧66の全60特徴、3木、過去回収、売買方向・順行反転の区別、定時ATR/Dを保存参照した。DMI/ADX、ストキャスティクス、ATR、BB幅、価格構造、段階別の相対量等を組み合わせる判断は変えていない。新fit・新特徴計算・新予測は0。全66場は既使用で、新候補G0/G1を評価対象46場ずつ計92運用した。

E0→G0は基本候補、E1→G1は旧即時入口での過去回収正も必要とする候補。Gは最新公開完全3分足の高安を定時に凍結し、買いLast>高値、売りLast<安値で新規要求する。設定時既超過は見送り、次定時で未発動と新規約定待ちを取消す。発動後1価格秒以後の正常BBOで取得し、線価格へ約定を戻さない。今回は発動前の反対端否定を加えていない。

保有後は旧O49の連続追尾を維持。現在の手数料・滑り控除後含み益strict正で最低名目新規床を起動し、損失側も非緩和。主費用はmicro代理1枚10円/pt、片道手数料11円＋滑り5pt、往復122円。利確250固定ではなく、250/125先着と実追尾回収を別に評価した。

## 確認が除く損失と、確認で失う取得位置

条件選択の両仮約定147候補では、G0は平均198.66秒遅れ、方向に43.47pt進んだ価格で取得した。中央値は81秒・40pt。旧250成功55件のうち、新入口でも250成功は37件、125先着15件、期限3件だった。一方、旧125先着の59件は新条件では未発動となった。成功した発動だけを見ても、未発動の損失回避だけを見ても比較は完結しない。

## 利益保護と次の判別

G0選択の利益旗95件のうち費用後赤字は71件（74.74%）。内訳は名目同値40、不利価格6、正の粗益だが費用赤字25。旧E0の119/160＝74.38%とほぼ同程度で、件数減少を利益保護の改善とみなせない。最低名目床と、約定遅延・費用込みの黒字は別である。

次の問いは「どれだけ待つか」だけでなく、**発動までに局所前提を否定した往復と、前提を保持した進行を当時の価格順序で区別できるか**である。[並行外部調査](外部再調査/突破の確認と取得位置と前提否定を分ける.md)の取消案へ接続する。ただし取消追加は活動を減らし得る。上位背景・量・値幅と組み合わせた事前判別と、否定後の別候補を調べる必要があり、自動反転や追加ANDでの件数削減を解決としない。
