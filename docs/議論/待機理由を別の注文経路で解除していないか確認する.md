# 待機理由を別の注文経路で解除していないか確認する

2026-11-18。[194の追加2場](../../study/00194_追加二場へ両指数の固定候補を適用する/README.md)、[195の補完注文比較](../../study/00195_保留中の補完入口を技術根拠で判別する/README.md)から得た問い。注文経路ごとの実装差と、テクニカルによる局面変化を分けて扱う。

## 確認した事実

日経では、元の方向への圧力が強いときに旧反転注文を保留し、価格の受容と勢いの変化を待つ仕組みを加えた。しかし、その待機は別の入口にも同じように作用していなかった。

- 195では、保留中の補完Tを制限すると過去80場のデイ損失を減らせた。ただし193対照からの収支改善64,000円は10/09デイ一場の取引の入替えであり、新しいT確認の取得は0だった。独立した新入口の優位とはいえない。
- 194の11/17デイでは、旧条件の11:16:04の買い（+16,923円）を見送り、11:31:02の別の旧売り（−24,077円）を取得した。口座の差は−41,000円。後者は新しい反転・順行確認を通った注文ではなく、リスク条件の非該当によって待機状態を取り消した旧幹だった。
- 短中期MAの非拡大を確認する193、Tだけを制限する195のどちらも、この旧幹の取消経路には作用しなかった。全取引が同じ約定・単一枠条件であることは194の独立監査で確認した。

利益だった旧注文を後から残すことが対策ではない。見送った時点の理由と、後続注文を許可した時点の根拠が整合しているかを調べる。

## 次に比べる仮説

市場心理の仮説として、強い圧力を警戒して待った後は、「元の警戒条件から外れた」だけでは別方向の需要が続く証拠にならない。移動平均・DIは方向の残存を表していても、MACD/RSIや短期の価格構造は直近の反発を示すことがある。同時点の方向票と、その後に価格が支持された経過を区別する。

199では、保留中の旧注文も元の二方向確認へ通す案、逆方向の旧注文だけを通す案、元の待機理由を捨てる代わりに新方向の固定水準・量・価格受容を取り直す案を比べる。**これらは検証する仮説であり、改善確認済みの結論ではない。**

待機を長くすれば自動的に良くなるとも仮定しない。旧条件の方が良かった取得、後続枠の変化、未参加の場、保有時間、新しい確認枝自身の成績を分ける。未参加や決済後の仮想利益は機会損失として最適化しない。

## 再利用する診断項目

|問い|記録するもの|
|なぜ待ったか|当時の方向、リスク判別、固定価格水準、固定ATR、期限、必要指標の可用性|
|何が待機を終わらせたか|確認成立、正常化、別の旧注文、補完、期限切れ、データ境界を別記|
|次の注文に新しい根拠があるか|現在のMA/DI、MACD/RSI増分、1分構造、量、固定水準が維持された時間|
|利益の差は何に由来するか|両案共通の実取得、旧だけの実取得、新だけの実取得、新確認枝と旧枝の区別|
|同じ失敗を繰り返していないか|前後期間、追加場、最悪場、連続損失、取得場数、保有時間率|

旧81場は探索に既使用。追加2場も194を読んだ以降は既使用である。199の追加2場への適用を、新たな未見検証とは呼ばない。
