# 利益ゼロの日を入口と出口に分けて調べる

日経199_02デイのRC20で、黒字決済が一度もなかった日は既使用45日中5日。6建玉はすべて一時は費用後に黒字だった。10月8日の朝の買いは追尾を始めるだけの順行幅が足りず、昼の買いは幅が足りても反対シグナルが連続せず、場末まで持った。両方が赤字となった理由が違うため、日時ごとに当時の入口根拠、清算側の最大含み益、注文可否、保護の条件成立を順に確かめた。[10月8日の原板と取引](../../study/00228_日別の損益偏りと十月八日の入口出口を検証する/十月八日/README.md)

相場の形は方向、日中値幅、始点と終点の隔たり、途中の押し戻しに分ける。今回は上昇・下落、往復・片道ともに全体は黒字だった。10月8日のような下落片道で赤字だったのは9日中1日。その一方で利益ゼロの5日はすべて、値幅が最小の15日に含まれた。後から決まる日中の高低差を使って損失を避けられたと数えることはできない。実際に注文前の20分が小幅と分かった12日のうち、引けまで小幅だった日は4日だった。[日別の形](../../study/00228_日別の損益偏りと十月八日の入口出口を検証する/日別の形/README.md)

入口を変えると、その後に空く枠で入る注文まで変わる。10月8日の損益が正に転じても、他44日、赤字日数、総損失の改善が続くかを照合する。出口を変える場合は同じ取得を対応させ、救った赤字と、元の固定利確に到達していた黒字の減少を分ける。ピークの含み益をそのまま実現利益とする計算は使わない。

今回は反対向きの背景で取った建玉を早く追尾し、取得前の値幅が小さい時だけ利確を近づけるX2を、開始20分待機に限って次の比較に固定した。総損失が両期間で減った一方、後21日の収支は元のRC20に及ばず、改善は値幅の小さい日に偏った。次の追加日では入口と執行仮定をそろえ、各建玉の実現損益と日単位の差を記録する。[試行228の判断](../../study/00228_日別の損益偏りと十月八日の入口出口を検証する/README.md)・[全45日のCSV](../../outputs/00228_日別の損益偏りと入口出口の比較/README.md)
