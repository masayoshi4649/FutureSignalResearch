確認日：2026-11-08。固定三手法と既存研究器のコードを調べた記録。次の新規条件の設計資料であり、5分運用の成績ではない。[判断時計の方針](mini片側10枚と5分判断への研究更新.md)と、[ATR追尾の役割](外部再調査/ATR追尾と建値床の役割を分ける.md)を併せて使う。

## 現在値の取得範囲

5分ごとに判断することと、5分足で指標を計算することは別である。特に、元三手法のEMA15/60は**1分足の15本/60本**であり、15分足と60分足の平均ではない。

| 役割 | 取得できるもの | 追加が必要なもの・留保 |
| --- | --- | --- |
| 背景の方向 | 元ObservationのEMA15/60、方向、公開/名目時計 | 複数時間軸の傾きは別に計算する。元方向の生存だけで現在成立としない |
| 複数足の平均 | 既存TechnicalBankの3分/15分EMA8/21と足終端 | 94には未接続。傾き、個別の既知性、更新時刻を保存する |
| 勢い・急変 | 同Bankの3分MACDヒストグラムと前値、RSI14と前値 | MACD線/シグナルそのものや5分/15分RSIは追加計算。ヒストグラム増分と0交差は別 |
| 変動幅 | 元の5分ATR12と公開時計、研究器の3分ATR14 | 方式・初期値・公開時計が違う。低ATRだけで継続方向を決めない |
| 価格構造 | 元の帯、夜間の支持/障壁、既存ChartBankの前3分終値/平均 | 元Band20/40は1分端点mid標本の帯で、約定OHLC極値ではない。押し→回復の順序は別状態で追う |

| VWAP・約定量 | 現NativeのBoard/Observation/TechnicalViewには公開fieldなし | 配信値や約定量/代金の入力接続、起算・差分・reset・欠測の検査が必要。板Qtyで代用しない |

元コードは `../SessionTradeExecuter/internal/e01/features.go`、`internal/strategy/features.go`、`types.go`、`selected_types.go`。研究器は [FAR後期15分移植](../../scripts/FAR後期15分移植/README.md) の `technical.go/types.go` と、[チャートの現在性と補助確認](../../scripts/チャートの現在性と補助確認/README.md) の `chart.go` にある。現在値を持つことと、次の実行器へ接続済みであることも分ける。

## 次に分ける二つの成立

順行は、背景方向に対して価格の支持/回復と勢いの再開がそろうかを確認する。買いAsk・売りBidまでの距離をATRで測り、局所反発と進み過ぎた取得を区別する。量は個別の既知性を残し、一度に全指標を必須へ増やさない。

反転は、元方向の構造を失い、戻しで回復できず、反対側の勢いが続くという順序を確認する。RSIの高値一回や平均の遅れだけで反転としない。元方向を見送ることと、逆方向へ実際に新規することは別の売買条件である。[CMEの勢い指標](https://www.cmegroup.com/education/courses/technical-analysis/oscillators-macd-rsi-stochastics)、[支持抵抗の教材](https://www.cmegroup.com/education/courses/technical-analysis/support-and-resistance)を一般的な根拠とし、具体的な順序・距離閾値は独自仮説として事前固定する。

心理面では、順行は利益確定の押しを支持側が吸収する仮説、反転は支持を失った保有者の解消と反対参加が戻しを抑える仮説として考える。参加者の意図を直接観測した事実ではない。必須値の未知は判定不能として残し、未来の足や相手市場の後原行で補完しない。
