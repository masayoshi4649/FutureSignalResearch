# セッション両端のノーポジションと建玉の保有時間

2026-11-22。ユーザーが指定したのは、開始直後と終了前に建玉を持たず、各セッション内で全決済すること。建ててから60分という制限は研究側が設けた。以後の日経199_02デイの基準は、元の片幅Rによる利確・損切と、15:30までの全決済。保有中に60分が経過しても、注文・建玉はそのまま継続する。

|時計|今回の扱い|
|---|---|
|セッション開始からの経過|デイ08:45を起点に20分と30分を主比較。09:05または09:15から新規要求可。待機中も指標は更新できる。待機中のシグナルを予約して後から建てることはしない。15分は参考、0分は旧試行との照合用。|
|セッション終了までの残り時間|デイ15:30・ナイト翌05:45までに全決済。既存モデルは締切1分前から新規を止め、返済を要求する。取得と返済の実行可能時刻、気配欠測による不明を検査する。今回検証するデータは日経のデイ。|
