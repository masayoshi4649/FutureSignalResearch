# 全場参加と入口精度を分けた複合入口の結果

2026-11-11。[123](../../study/00123_複合入口で全セッション最低1回を検証する/README.md)の既使用全73場で、複数テクニカルを組み合わせた補完により最低1取得は全場で達成した。一方、主P3・60分±125ptは26順31逆未到達16、到達済み45.61%・全完了35.62%で70%未達。両立条件を満たさず不採用とする。全場参加自体が不可能という反証ではない。

## 何を変え、何を保持したか

122のE0全9件を保持し、まだ取得がない場で方向T（5/15/30分のEMA/DI）、勢いM（5分RSI/Histの水準/増分）、価格位置P（5分足形/現在位置）、量u、値幅gを合成した。通常は強い順行又は5分の失敗突破/回復を確認し、開始3時間後も未取得なら通常閾値を外してSの符号で方向を決めた。2/4時間期限も比較し、どちらも全場取得・精度未達だった。

長期成熟値と1分連続性を補完の必須条件から外し、元の未知maskを残した点で参加可能な情報集合は広がった。[当時利用可能性監査](../../study/00123_複合入口で全セッション最低1回を検証する/根拠/当時利用可能性/README.md)と全73場取得の実績は、このデータ範囲で全場参加の経路があったことを示す。期限が来れば必ず非対称に買う設計ではなく、完全同率は未解決として保持した。

## 再利用する知見

全場取得を達成する入力・時計の設計と、有利な方向/取得位置を選ぶ設計は別に検証する必要がある。今回のSは方向・勢い・足形の既知符号を合成したもので、値0.5等を成功確率とみなせない。相関する価格由来指標を組み合わせた票数は独立な根拠の数ではない。

時間が経過しても新たな優位性は生じない。現在の合成と、期限だけを理由に通常の強確認を外す方式には70%のエッジを示す結果がなかった。通常順行も未達のため、期限枝だけを悪者にして既存入口を完成扱いしない。保持したE0の少数高率を、追加した大きい母集団へそのまま拡張することもできなかった。

心理の解釈として、方向や勢いの整合だけでは、既に進んだ値動きへの追随と取得直後の逆行の少なさを十分に区別できていない可能性がある。MAが揃うこと等の単独因果を主張しない。実装のspike g/TRは確定5分TR/前ATRであり、現在Rawからの未確定急変の除外を証明していない。Last−Cも符号だけで距離・飛び乗りを判定していない。この不足を今回の負けの原因として実証したとも言わない。

次の問いは、時刻だけで確認を外さず、領域接触→構造回復/再テスト→勢い/量の継続で取得時点を選ぶこと、当時までの未確定値幅/距離を加えて背景の整合と取得位置を分けることである。今回の勝敗から閾値を後付けし直した新政策は、この試行へ混ぜない。

参加分母は73場、先着分母は完了した独立候補。未取得・観測不足・未到達を混ぜない。期限評価の平均が正であっても、先着70%達成やIFD実約定利益とは別である。全73場は既使用で、主125ptの選択も既知122結果を踏まえた研究内比較。未知期間の安定性・利益追尾・片側10枚口座収益は未確立である。
