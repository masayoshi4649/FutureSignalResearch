# 複合切替の学習改善が時系列後半に残るか

2026-11-11。[試行126](../../study/00126_複合切替を時系列に分けて学習評価する/README.md)で、[125](実体の進行後に入った群を条件付きで反転する.md)の方向をB0として、複数テクニカルの追加切替を前48場だけで選び、固定後に後25場へ適用した。

主の後25場は12順8逆未4、到達済み60%で70%未達。B0と率は同じだった。mini1枚・追加滑り込みC5の既知清算では利益147,922円は不変、損失が134,847円から130,847円へ減り、差引は+13,075円から+17,075円へ4,000円改善した。率の改善と金額差を混同しない。

## 組み合わせから確認したこと

MA/DI方向・位置、RSI/MACD勢い、TR/ATR値幅、RVOL量の4役割・45固定境界を探索した。root/childは異役割、深さ2、主の両末端にH完了8件以上を要求し、複雑さを罰した。最終木はB0向きの30分EMA21増分>=0かつ5分Hist/ATR>=0.1でB0を反転するものだった。非該当・未知ではB0を維持する。

学習前48場53取得では22順15逆のB0が27順10逆へ変わり、到達済み72.97%となった。後25場26取得で切り替えた4件のうち、完了した3件は逆→順1件、順→逆1件、未→未1件で、率の改善は相殺された。残1件はH不足かつIFD未知。複数指標を組み合わせ、複雑さを抑えても、学習の改善が後半に残るとは限らなかった。

全73場の参考では39順18逆未16・68.42%、C5既知利益506,304円/損失313,156円、差引+193,148円、PF1.6168だった。学習を含む復元内の数値であり、主の後半評価へ置き換えない。元の全79時刻・全73場を保持したうえでの方向選択で、独立した新しい出生の成績ではない。

## 心理の仮説と限界

MA方向とHistがB0を支持する時の逆向き切替が学習内で改善したことは、既に進んだ所で追随していた例を含む可能性と整合する。ただしこの木は、失速、拒否足、水準回復、現在の構造維持を確認していない。強いトレンドを見たら一般に逆張りすべきという説明ではない。注文者の意図も直接観測していない。

RSIとMACDは同じ勢い役割、EMA配置・傾き・距離は同じ方向・位置役割にまとめた。役割が違っても、価格から派生する値の相関や[EMAの冗長性](../technical-analysis/組み合わせ/同じEMAの傾きと価格位置の重複.md)は残る。指標を増やした数を独立した根拠の強さと数えない。

## 再利用する研究手順と次の問い

場単位で入力を物理分割し、学習は前側だけを読む。木をSHA固定してから後側を一度評価し、未達後に境界や主を変更しない。126ではこの手順と全79/73保持・未知処理・240比較・CSV全セルを確認した。ただしB0自体は全73場を見て選んでいるので、完全な未知期間の独立検証になったとは扱わない。後25場の95%参考区間もC5平均・B0差とも0を含んだ。

次は独立出生127で、過去の取得時刻に向きを当て直す方法から、技術領域への接触、突破/回復、取得位置cap、当時Lastによる構造維持を用いて候補を生む方法へ進める。元の79時刻だけの未達を、テクニカル一般又は全場参加の不可能性に広げない。利益追尾と実IFD注文は、入口評価と分けた次段階に残す。
