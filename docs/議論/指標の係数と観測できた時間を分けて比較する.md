# 指標の係数と観測できた時間を分けて比較する

2026-11-17。[187共通価格比較](../../study/00187_両指数を同じ価格特徴とIFDで比較する/README.md)と[188数量比較](../../study/00188_両指数の共通入口に数量の持続を重ねる/README.md)から得た知見。いずれも安定採用の結論ではなく、NK225/TOPIXの入口探索を継続するための原因整理。

## 同じEMAでも同じ時間を記憶しているとは限らない

187は両商品で足形成、EMA/DI/RSI/MACD/ATR/BBの式・係数、IFDを揃えた。それでも不良足を飛ばして有効足だけ更新するため、近傍15分21本の取引時間跨度中央値はNK21,600秒、TOPIX19,800秒だった。名目21×15分の18,900秒に対し、それぞれ1.143倍・1.048倍である。セッション間の閉場時間を足した値ではない。

同じ期間数の指標でも、相場が動いてから何分遅れて反応するかは異なり得る。これは市場の需給差だけでは説明できない。今後は式だけでなく、公表、欠足、実時間跨度、初期準備を記録する。欠測を黙って埋めたり、使えない時間を参加率分母から落としたりしない。

全対象2,832,300秒のうち、187のq0を利用できる窓はNK約51.0%、TOPIX約63.1%、両方の共通窓は1,287,272秒（45.45%）だった。全時間での比較と、双方観測できた共通時間の診断を分ける。共通時計だけで得た結果を全セッションの達成率としない。

## 出来高の効果と、観測可用性の効果を分ける

188では量なしQ0に対し、QKを「量と直前20分の平均が既知」とだけ定義した。相対量の水準を問わなくても損益が改善する例が出た。NK Night M×2.5では、既知収支が+224,801円から+282,112円へ増えた一方、取得98→51、参加37→28場、保有下限17.73→9.02%となった。

この結果は、十分な量が続くことの有効性を証明していない。場開始の準備不足や量時計の欠測を含む時間選択と、後続の建玉枠が変わる影響がある。量多寡を論じる際は、QKに加えて水準/持続を課した差を評価する。未知を0量にして「薄商いだった」と説明しない。

観測量自体にも幅がある。188の量は、価格時計で見えていた累積量の端点差であり、端点は分境界から最大30秒ずれる。原板に独立した受信時計がないため、真の全約定量や攻撃側注文量とは呼ばない。

## 広い幅の少数先着を入口の高精度としない

187のT×ATR15の4倍では、同幅先着がNK4順0逆、TOPIX3順0逆でも、H60未到達がそれぞれ99件・120件、金融未知が8件・7件だった。広い幅へ届いた少数だけの割合は、全建玉が有利になる確率ではない。取得、順/逆先着、未到達、観測不足、期限収支を併記する。

幅を広げると損切りに接触しにくくなる反面、時限返済の割合と保有時間が変わる。率・参加・収支・両中央値を同時に調べ、いずれか一つの改善を全体達成としない。

## 次の検証への適用

商品差の説明は、観測条件を揃えた上で残る差を対象にする。未知のデータを都合よく除外するのではなく、観測可能な技術を使った別の入口を事前に定義し、全場の分母で比較する。方向は価格構造・勢い・量の関係から仮説化し、費用や約定品質による参加可否と分けて調べる。

共通条件の失敗だけで商品別探索を打ち切らない。187/188の固定対照を保持し、商品別の受容・混在局面・再開条件へ進む。全81場は既使用であり、同じ過去に繰り返し適合させた成績を未見実証と呼ばない。
