# 含み益が出た建玉をいつ守るか

2026-11-22。日経199_02のデイでは、181建玉のうち165件が一度は往復費用以上に順行し、そのうち55件が赤字で決済された。一方、費用分を超えた瞬間に全建玉へ狭い保護を置くと、試行219では取得が377件に増え、既知収支が−504,952円に下がった（1件不明）。失われた含み益の大きさを、そのまま新しい出口で回収できる利益と見積もると、元々伸びた建玉の途中決済や再予約による損失を見落とす。[元181建玉の経路](../../study/00219_日経199デイの利益保護と出口条件を比較する/経路診断/README.md)

|確かめたいこと|比較方法|今回の観察|
|---|---|---|
|利確が遠すぎたのか、保護の起動が早すぎたのか|元IFD、静的な利確幅だけの変更、同じ利確幅に追尾を足した口座を比較する|午後0.90R利確のみのM04は後半の総損失が元と同額。期限別の起動・残り10分の保護を加えたM34では元より10,154円減った|
|保護を注文したことが実際の返済を変えたか|起動件数、発動件数、最終決済の原行、起動後赤字を区別する|M28と期限前だけ保護するM27は起動件数が違っても全決済が同じ。W31の起動は72件、実際の追尾返済は4件|
|新しい出口そのものが効いたか|元の全取得に固定して再決済し、さらに1枚の予約・保有枠を時系列で再計算する|W31は元181件固定で＋56,000円。口座で＋146,154円となり、後続取引の入れ替わりも寄与した|
|日中の損失減少が大きな一敗への耐性を伴うか|赤字日数、日末下落、1件当たり最悪、時期・方向別寄与を併記する|W31の45日の日末最大下落額は72,077円減ったが、最大1件損失は4,000円増えた。M34の収支増は売りが担い、買いは8,077円低下した|

ここでいうRは各新規の元IFD片幅。W31とM34は同じ45日を見ながら探索した。新たなデイでは両候補と元IFDを並行して再生し、どちらが勝った日だけを抜き出すことを避ける。新しい条件を試すときは、その時点で既に見た場を明記する。[試行219](../../study/00219_日経199デイの利益保護と出口条件を比較する/README.md) ・ [固定条件](../../study/00219_日経199デイの利益保護と出口条件を比較する/次の追加デイの固定条件.json)
