# 登録後の深さと速度を複合判断へ加えた比較

更新日：2026-11-06。[試行59](../../study/00059_保持水準への深さと速度/README.md)の知見。条件と全結果は[設定と結果](../../study/00059_保持水準への深さと速度/設定と結果.md)、定義は[特徴仕様](../../scripts/価格経路の深さと速度/特徴仕様.md)を正本とする。

## 何を変えたか

58は同じ水準を保持することで完成経路の観測が増えたが、追加列は分岐に使われなかった。59では、その水準を登録した後の深さ・平均速度・現在位置を加えた。上位DMI、短期ストキャス、ATR、序盤帯・局所帯と合わせた旧30特徴へ8列を追加し、同じ教師・回収目的・分岐深さ・支持条件で比較した。売買対称、15分判断、損失側も連続追尾し、費用後の現在含み益が正なら最低名目新規価格を保護する出口は変更していない。

登録足bから現在公開足jまでの終値に対し、売買方向をそろえて次の4値を、突破再開T・失敗後逆向き再開Rの各経路に持たせた。

| 追加情報 | 測っているもの | 測っていないもの |
| --- | --- | --- |
| 最大逆行のATR比 | b終値からの最大逆行 | 実際の新規価格からのMAE、足内最悪値 |
| 最大進行からの戻りのATR比 | b以後の最良終値から現在までの戻り | 押戻し区間の長さ、参加者の退出動機 |
| 一足平均純進行 | bからjまでの純変化÷現在ATR÷経過足数 | 瞬間速度、押戻し区間だけの速度、b前の先行波 |
| 保持水準からの現在位置 | 現在終値と登録水準Kの距離÷現在追尾幅D | 現在BBO、後行約定価格、将来の残り値幅 |

未登録の追加値0は適用外を表し、既存の段階列と一緒に読む。登録足で経過足数0の場合の平均進行0は既知値である。取消後の情報も期限又は置換まで残すが、有効な形成へ戻したことにはしない。これらは同じ価格の加工であり、独立した心理・注文・数量の票を増やすものではない。

## 新しい列はどこで使われたか

新3木では、W20は追加列0、W30は1箇所、F40は2箇所を選んだ。旧58の保持経路12列は今回も選ばれず、新8列のうち現在位置と平均進行が選ばれた。最大逆行と最大進行からの戻りは選ばれていない。

W30のF34とF40のF33は、旧局所帯の固定Zが高く、DIが売買方向と一致し、局所帯内の終値位置F17も高い経路で使われた。F40のF37は固定Zが高く、DIが売買方向に逆行する経路で使われた。T/Rは価格経路の名前で、上位DIに対する採用役割の順行・反転とは区別する。

「速いほど良い」という単調な結論にはならない。T平均進行の高い群は学習内の先着率・回収とも改善したが、R平均進行の高い群は先着率が高い一方で回収は悪化した。全6群が学習先着1/3未満かつ平均回収負だった。V0は先着閾値を通過せず、V1は追加の平均回収正という条件も満たさない。負の平均回収はV0の不採用原因ではない。1/3は候補を作る旧来の学習閾値であり、最終目標70%を引き下げたものではない。

## 採点と最終判断を分ける

V0と旧E0の評価46場について、保存済み予測を比較した。V1を加えて同じ枠を二重計数していない。

| 適用木 | 全判断枠 | 準備済み枠 | 採点が変わった枠 | 最高側が変わった枠 | 最終方向が変わった枠 |
| --- | ---: | ---: | ---: | ---: | ---: |
| W20 | 370 | 308 | 0 | 0 | 0 |
| W30 | 370 | 305 | 72 | 26 | 0 |
| F40 | 962 | 855 | 328 | 68 | 0 |
| 合計 | 1,702 | 1,468 | 400 | 94 | 0 |

新列を経由した400方向観測はすべて入口の先着閾値を通過せず、採用方向0だった。最高側が変わることと、取引資格を満たすことは別である。最終理由も全枠同値で、二政策合算の全3,404判断・実完結580件は旧58と一致した。共通完結の追加0・除外0、識別ID以外の全属性も同値だった。580は政策間重複を含む件数であり、独立580機会ではない。400も方向観測数であり、独立した400形成を意味しない。

今回の知見は、追加列が無視されたというものではない。学習内の損失差を分け、採点や最高側を変えたが、取引を認める群へ変わらなかった。支持不足だけで説明することもできない。条件選択24場のV0は先着62/235＝26.38%、費用後−47,838円、主待ち59.57%。V1は26/93＝27.96%、−15,424円、主待ち76.69%で、目標は未達である。micro1枚、主往復費用122円の仮定による結果である。

新12回帰fit・3木・92運用、人工36件と独立人工2,738項目、保存物142,540項目の照合が成功した。Viewer184資源と新2候補代表を確認した。全66場は既使用で、未見成績ではない。
