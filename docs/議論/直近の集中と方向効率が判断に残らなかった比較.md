# 直近の集中と方向効率が判断に残らなかった比較

確認日：2026-11-06。[試行73](../../study/00073_直近の集中と方向効率を組み合わせる/README.md)の結果後の知見。全66場は既使用である。

## 分かったこと

現在直近の「一足への集中」「方向効率」「最大一足の向き」を既存の複数技法へ加えても、今回の学習方法では新しい分岐に選ばれなかった。判断・参加・利益回収は対照と同じだった。追加観測の計算不能で対象が減った結果でも、採用した新分岐が後から消えた結果でもない。

一方、この結果だけで集中や効率が常に無意味とは言えない。固定した上位DIと保持経路の分類、回収誤差を使う分割、支持条件、深さ、現在の発動・追尾の組み合わせの中で、既存列を上回る境界を選べなかったという結果である。

## 何を組み合わせたか

15分DI/ADXを方向と強弱、3分の勢い・値幅を短期状態、保持水準と再試験を価格経路、相対量を量の補助、取得位置を価格余地として使う旧61列が対照B。追加Qは次の3列を加えた64列である。売り買いは方向の符号だけを反転する。

| 追加観測 | 当時までの連続3分終値6個・5差分から計算 | 区別できないこと |
| --- | --- | --- |
| 一足集中C | 最大絶対差分÷絶対差分合計TV | 急進の原因や発生順序 |
| 方向効率E | 売買方向に符号を合わせた純変位÷TV | 高効率の後も継続するか |
| 最大一足の向きJ | 最大絶対差分の方向。正負同値は0 | その一足が窓の最初か最後か |

3列は同じ価格変化から作るP05の補助で、独立した3系統の確認ではない。欠足・未公開・TV=0は未知としてB/Qとも外し、旧未準備も保持した。全予定2,442枠中、旧準備済み2,046枠と共通準備2,046枠が一致し、追加除外0。過去の可知教師もW20/W30/F40の537/809/1,097枠で共通だった。

旧72Sは保存参考として再集計。S→Bの準備と再実装の比較、B→Qの観測追加を分けた。定時、条件発動、約定遅延、費用、追尾は同じである。詳細は[事前計画](../../study/00073_直近の集中と方向効率を組み合わせる/検証計画.md)と[設定と結果](../../study/00073_直近の集中と方向効率を組み合わせる/設定と結果.md)に残す。

## 計算できたことと、判断に使われたこと

Qの元木・支持統合後の木は各期とも7・11・17nodeで、新3列による分割は元/派生とも0。W20は旧列も新列も、候補の両側に約定支持を確保できる境界がなかった。W30/F40は、Q全体の支持適格候補がBより64/301件増えたが、選ばれた分割は旧列のままだった。件数は複数nodeで調べた境界数で、独立した売買機会ではない。

S→B、B→Qとも、各政策1,702定時枠の予測全文・純判断が同値。0政策は純候補705、実新規・完結233、追加・除外0で、政策IDを正規化した注文・価格・保護・現金も同値だった。1政策は過去主回収strict正を追加したものだが全0。取引をしないための損失0を改善とはしない。
