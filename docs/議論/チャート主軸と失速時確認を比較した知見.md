# チャート主軸と失速時確認を比較した知見

2026-11-07。[試行82](../../study/00082_チャートの現在性と補助確認/README.md)は、[81](現在の新規根拠と部分利益保護を分けた比較.md)からチャートの現在の進行と取得位置を強化し、短秒・OFIの欠測で一律拒否しない案を比較した。初回を除く15分新規、売買対称、連続保護を維持した。旧合格判定は使わず、費用後損益と利益保全を見る。

## 今回の結果

66場は全て既使用。新規100micro固定、同時一建玉、往復費用122円/枚、ラージ正常BBOを価格代理とする。同じ固定81G1の部分利確・確定益予算・最低建値追尾を使った。元FAR三手法と同じ売買列の再現ではない。

| 入口 | 主費用後損益 | 価格時計1秒追加 | 主実新規 |
| --- | ---: | ---: | ---: |
| B0：チャート主軸＋個別既知の反対拒否 | −4,078,900円 | −4,145,600円 | 142玉 |
| B1：B0＋既知失速時の追加支持 | −3,907,300円 | −3,984,000円 | 139玉 |

共通の139実入口は時刻・方向・価格・数量が同じで、同じG1による出口差も0だった。差はB0だけの3玉で、主−171,600円／1秒−161,600円。失速時確認でその3玉を見送れたが、残る139玉の赤字は大きい。「保護が改善した」「安定黒字化した」とはしない。

全定時の共有入力、B1のB0への包含、許可時の独立数式等は保存判断監査306,512照合、原板の所有・次正常BBO・追尾要求・確定予算等は581,738照合で不一致0だった。元の指標系列自体や初動の全構造生成を独立再実装した検査ではない。

## 正益前と回収額の問題

B0主では正益未観測68玉が計−4,699,600円だった。保有秒中央値117.5秒、入口ATR追尾幅の中央値55ptで、次の3分確定による技法否定より先に損失が進む例がある。これは全玉の平均時間ではなく、残玉単価の正益を一度も観測しなかった群の診断である。

費用後の平均勝ちは約9,971円、平均負けは約−61,390円、実現黒字率は45.8%だった。この観測平均を固定した算術上の均衡率は86.0%となるが、将来必要な勝率の推定ではない。部分保護を維持した今回の損益配分では、入口の黒字率だけを小幅に上げても大きな損失を覆いにくい。[損益構造の診断](../../study/00082_チャートの現在性と補助確認/損益構造の診断.md)

G1を固定した試行なので、平均利益が小さい原因を部分利確だけの単独効果とは断定できない。早く確定して守る量と、技法の継続を取る量、正益前の否定を分けて比較する必要がある。

## 未知の扱いと、測れている支持

B0主のOFI未知107玉は−3,840,500円、OFI支持35玉も−238,400円だった。5秒速度支持36玉も−513,100円。未知を0や反対にしないという入力上の原則と、未知の時でも同じ入口で参加してよいという売買上の仮説は別である。今回のチャート条件だけでは、未知を埋めずに参加できても利益は改善しなかった。

順行137玉は主−4,087,900円、転換初動5玉は＋9,000円／1秒＋4,000円。ただし初動は5玉だけで、転換優位や順行全廃の根拠にはしない。支持群にも1秒で利益が消える小群がある。[全群の事後診断](../../study/00082_チャートの現在性と補助確認/入口補助の事後診断.md)へ、0件の周辺群と全観測組合せを保存した。群の合計を、条件を選び直した運用戦略の成績にはしない。

5秒速度・15秒速度・OFIの全てが支持だった群も17玉・12日15場と小さく、主は14勝3敗でも−52,400円、追加価格時計1秒は＋57,600円だった。[三補助支持群の診断](../../study/00082_チャートの現在性と補助確認/三補助支持群の診断.md)。観測黒字率の高さだけで、利益配分や約定耐性を満たしたとは言えない。結果を見てこの群へ絞る判断自体も事後探索である。

その主最大損失−82,200円は、最高順行10ptで費用12.2ptを覆えず正益旗が立たなかった例だった。ATR床到達時の要求と次原行の約定は同価格で、要求後悪化0。利益が出た後に放置した損失とは分ける。追加価格時計1秒では14秒後の適格板で10pt有利に売れたため保護が起動し、最終＋300円となった。追加1秒は常に実時間1秒後の約定を意味しない。[最大損失例](../../study/00082_チャートの現在性と補助確認/最大損失例の診断.md)

## 次に分ける問い

- **入口の裏付け**：背景と現在のチャートに、短期の同方向進行とOFIが共に観測できる場合を分ける。未知は悪材料と決め付けず、必要な確認ができない状態として見送る案を新固定する余地がある。結果後の群選択であり、既使用での再生と後続期間の確認が必要。
- **正益前の構造否定**：入口時に既知だった平均回復点・押戻り起点・帯の喪失を連続BBOで監視し、確定3分足を待つ方式と比較する。通常の往復で勝ちを失う反例、未知時のATR対照、既存125pt保護を維持する。
- **回収配分**：利益正益時の追尾開始と最低建値床は維持し、部分確定量と残量の配分を別比較する。未約定益を予算に入れず、返済要求を取消・延期しない。黒字保証に読み替えない。

背景EMA、現在MACD増分、終値回復、ATR取得位置が揃っても、進行が持続する根拠とは限らない。追随参加の勢いと、反対側の供給・返済の応答を別に問うのが心理の仮説である。実際の参加主体や新規／返済内訳は直接観測していない。[失速と再開の一次資料](外部再調査/失速と再開を分ける一次資料.md)、[追尾の発動と約定の区別](外部再調査/追尾の発動と返済約定を分ける.md)の一般説明を、今回の利益の証明に使わない。
