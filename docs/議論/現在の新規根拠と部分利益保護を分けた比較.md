# 現在の新規根拠と部分利益保護を分けた比較

2026-11-07。[試行81](../../study/00081_定時の現在根拠と部分利益保護/README.md)では、FAR後期D164_15／P164_06／U165_03の特徴部品を使い、15分時点の新規条件を直接計算した。元手法の保有玉を定時へ写した[80](FAR後期三手法の15分移植と利益保護の比較.md)とは別の複合仮説である。従来の70%・125/250先着・待ち50%による合格判定は外し、費用後利益と利益保全を見る。

## 条件と結果

初回09:00／17:15を飛ばし、デイ09:15・ナイト17:30から15分ごとに新規判断。保護・返済は全原行で行う。既使用66場、同時一建玉、新規100micro固定、1枚10円/pt、往復手数料・想定滑り122円。ラージBBOは約定価格の代理であり、microの実約定を保証しない。80は数量可変のため総額の差を改善効果とはしない。

| 入口・保護 | 主費用後損益 | 価格時計1秒追加 | 主完結玉数 |
| --- | ---: | ---: | ---: |
| B0G0：複数時間軸方向／中心線回復＋全量保護 | −787,600円 | −607,600円 | 58 |
| B0G1：同入口＋部分利確・確定益による残玉保護 | −602,600円 | −527,600円 | 58 |
| B1G0：取得位置・転換初動＋全量保護 | −352,800円 | −222,800円 | 24 |
| B1G1：同入口＋部分利確・確定益による残玉保護 | −345,300円 | −260,300円 | 24 |

同じ入口内のG0/G1は、全て方向・時刻・価格・数量が同じ実新規だった。B0の部分保護は主で185,000円、1秒で80,000円改善。一方B1は主で7,500円改善しても、1秒では37,500円悪化した。部分利確を常に優位とはしない。B1の総損失が小さいことにも、58玉から24玉へ参加が減った影響がある。

## 利益を放置しない仕組みと残るリスク

全案で利益前からATR損失追尾を行い、3分終値とMACD増分が共に反対なら技法失敗として返済する。費用後の現在含み益が正になった原行で保護を起動する。

G1はまず部分利確を要求し、残玉の床を最低建値とする。部分注文の約定完了後にだけ、確定した利益から残玉の往復費用と想定10pt悪化を賄う予算床を計算する。未約定益を予算へ入れず、床を下げず、返済要求を取り消さない。具体式・数量・実装は[検証計画](../../study/00081_定時の現在根拠と部分利益保護/検証計画.md)を正本とする。

返済要求後の次板悪化は残る。建値床があっても費用後黒字とは限らず、10ptの余裕を超える価格差もあり得る。原板監査では即時要求・次正常原行・所有数量・確定予算を検査し、残玉単価の正益と、部分確定を含む全玉正益を別記した。放置の防止と黒字保証を混同しない。

## 次の問題は正益前と入力の役割

B0では全玉正益を一度も観測しなかった15玉が計−1,073,000円、B1では7玉が−475,400円だった。この損失は各Gで同じ。正益後の改善だけでは総赤字を解消できなかった。

全2,442定時枠のうち、自己・相手・OFIの必要値が全て既知だったのは628枠。OFI30秒窓の異常／空白が1,608枠にあった。理由は重複するため合計しない。未知を反対・ゼロとして埋めるのではなく、測定できるチャートによる方向・現在の勢い・取得位置を主軸とし、板支持は既知の時に役割を持たせる次仮説を考える。

原板の価格時計は板の受信時計と同じではない。短秒速度やOFIの硬い必須条件が、3／15分チャートを使える場面まで除いている可能性がある。ただし条件を外せば利益が増えるとは未検証である。

## 再利用する判断の分け方

| 役割 | 判断する内容 | 次の仮説・反例 |
| --- | --- | --- |
| 背景 | 複数時間軸EMAの方向 | 平均の向きだけが残り、現在の推進が失速している場合を別にする |
| 現在の進行 | 終値のEMA位置、MACDヒストグラム増分、短期速度 | RSI水準の高さだけを追随理由にも逆張り理由にもしない。回復確認が遅く取得価格が悪くなる反例も測る |
| 位置・値幅 | EMAからの距離をATRで測る、既知の価格帯 | 方向が正しくても伸び切った所へ入る可能性を分ける |
| 順行／転換 | 同方向の再開か、反対圧力後退と価格回復か | 上位方向が未一致という理由だけで転換を消さず、実際の回復構造を必要とする |
| 数量・相手市場 | 既知のOFI、数量支持、相手の応答 | 未知は未知のまま。独立の情報でも必ず利益を増やすわけではない |
| 撤退・保護 | 入口理由の否定、確定利益で守れる残量 | 正益前の否定と正益後の確定・継続を別にする |

心理の説明候補は、平均価格の方向が残っていても新しい追随注文の勢いが弱まり得ること、調整後の価格回復に新規追随と反対側の返済が重なり得ること、抵抗帯の供給が残れば再開が不発になり得ることである。参加者の目的や新規／返済内訳は本データで直接観測できず、実証済み因果関係ではない。同じ価格を加工したEMA・RSI・MACDを独立した賛成票として数えない。
