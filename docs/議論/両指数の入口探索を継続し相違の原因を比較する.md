# 両指数の入口探索を継続し相違の原因を比較する

2026-11-17、183/184報告後のユーザー指定。有望な入口の発見まで、原因診断・仮説・検証を継続する。今後はNK225とTOPIXの両方を対象にする。同じアルゴリズムである必要はないが、異なる条件が必要になった理由も検証対象にする。

[単純IFD・損失安定性の優先](単純IFDで損失の出にくい入口を優先する.md)を維持する。保有・未決予約合計1件、開始一律待機なし、終了15分前までの返済、保有時間率20%程度と可能な全場取得、費用後の建玉・全セッション収支中央値黒字を評価する。未知を0円にせず、各商品・時間帯の損失を他の利益で隠さない。

## 今回の出発点

[183/184](../../study/00183_単純IFDで両指数の入口と損失安定性を検証する/README.md)は固定対照として保持する。NKの新EM群自体は赤字で、口座の増益には後続の既存取引が入れ替わった効果がある。TOPIXの低ADX反転を実側反転するとデイ損失が減ったが、足の形成を変えると崩れた。いずれも安定採用とはしていない。

次は、価格が回復した一時点と、回復した価格側で売買が続く状態を分ける。固定した水準、経過時間、途中の逆側への戻り、方向・動力・量の持続を当時情報で記録する。元方向の危険を見つけただけで、反対側に優位があるとは判断しない。

185はNKの受容と圧力持続、186はTOPIXの同役割の新入口、187は両商品の共通対照として準備する。条件や主要仮説を変えた次の反復は新番号にし、旧数値を上書きしない。

## 条件が乖離する理由の切り分け

|調べる違い|固定又は対照にするもの|結果から言える範囲|
|---|---|---|
|価格単位・典型値幅|価格差を当時ATR等で正規化、時間尺度と保有期限を合わせる|pt幅の桁違いを入口の性質と混同しない|
|手数料・滑り・スプレッド|同じ取得台帳で費用前、商品別費用後を併記。BBOと追加滑りを分ける|費用で黒赤が変わることと方向精度が違うことを分ける|
|足形成・公表・欠測|同じ形成方式を両商品で使用し、旧方式・直接形成を別比較|不足足や観測頻度による選別を市場特性と呼ばない|
|約定代用|同じ利確指値・逆指値の接触、遅延、TTL、終了処理|NKとTOPIXで違っていた金融モデルの寄与を分離する|
|条件成立の分布|各商品の全場と、同じ場・利用可能時刻での比較を両方残す|共通時計に揃えた際に除いた区間も隠さない|
|トレンド・往復・変動性|MA/DIの方向と持続、ADXの水準と変化、価格効率、ATR比などの共通定義|同じ局面でも成績が違うのか、局面の出現割合が違うのかを分ける|
|指数構成・参加者の仮説|指数算出方法等の一次資料と観測結果を別記|構成が違うという事実だけで売買優位の原因を確定しない|

商品別に独立探索した最良額を並べるだけでは、乖離の原因は分からない。共通の複合条件を両方へ適用し、その後に商品固有の差分を加えた比較を残す。比較対象の期間・足・IFD・費用・数量枠が異なる場合は、まずその相違を明記する。

## 探索と採用の区別

新金融前に候補・Source・判定順序を固定する。全80場での発見と前48場での選択、その後25・追加7・最終デイを区別する。既使用81場を何度比較しても未見期間には戻らない。将来の欠測や損益で当時の入口を除外しない。

十分な参加と黒字を保ちながら、損失の発生頻度・深さ・連続性と期間差の改善を探す。総損失が減っても取引や参加を大幅に失った場合、又は赤字場や最大損失が増えた場合は、改善した範囲と悪化した範囲を明示する。新入口自体の実現損益と、後続取引が変わった口座全体の損益を分ける。

根拠は試行正本へ、共通知見はdocsへ、閲覧結果は候補別CSVへ保存する。探索が未達なら、どの観測・仮説が失敗したかを調べて次へ進み、候補数だけを増やすことを進捗としない。

## 2026-11-18の到達点

185以降の比較は[試行一覧](../../study/README.md)に保存した。[187/188](指標の係数と観測できた時間を分けて比較する.md)では、同じ指標係数でも欠足により記憶の実時間が違い、両商品の共通観測窓は45.45%にとどまった。量が既知の時点だけを選ぶ効果もあり、最良条件の差を指数固有の心理だけで説明できない。

[194](../../study/00194_追加二場へ両指数の固定候補を適用する/README.md)で、候補選択に未使用だった11/16ナイト・11/17デイを固定適用した。日経は追加デイで旧条件より悪化、TOPIX旧対照は両場黒字。結果から候補を交換せず、以後はこの2場も含む全83場を既使用扱いにする。旧81内の前48/後25/追加7/最終1と、新2の区分は残す。

日経は[待機を別注文が取り消す経路](待機理由を別の注文経路で解除していないか確認する.md)、TOPIXは足形成・量補完による判断時点の追加と売買方向の変更を分けて検証している。現在も単純IFD・参加・両中央値・損失安定性を維持し、有望な入口の発見まで継続する。

[206](../../study/00206_指数間の相対変化を複合入口へ加える/README.md)の相手指数追加85口座は一律支持による安定化にならず、可用性と時計感度を残した。[207](../../study/00207_VWAPと固定価格の時間順入口を量支持で比較する/README.md)では短期端失敗の反転Rと、戻り試行拒否の元方向Fに差が出た。[208](../../study/00208_TOPIXの浅い押戻し逆張りを控え損失を比較する/README.md)のTOPIXナイト主3は損失/DD軽減の部分的候補として保持するが、支持5取得・後続枠寄与・赤字場/連敗不変・追加に成立なしという限界がある。TOPIXデイと、参照価格を変えたF型の入口を別試行で継続する。

[現物制度属性による既存取得の分布](../データ監査/現物制度属性と入口の分布/README.md)も診断した。日経には通常現物寄付前の10取得、TOPIX D4には0取得で、母体が参加した場面の構成が異なる。現物休場の5デイも通常日の寄付/昼休みと区別した。既存取得の群別損益であり、時刻除外後の口座収支ではない。

同日の[212接続比較](../../study/00212_デイとナイトの見送りとnative入口を同じ口座で比較する/README.md)で損失とDDを軽減する閲覧主6を得たため、[到達点と固定候補](両指数の有望入口を固定して追加検証へ渡す.md)へ引き継ぎ、新しい条件探索を一旦区切る。日経195/199とともに追加データへ固定適用する。80/83参加・未知7・新枝5支持・選択nullという限界を消して全面合格とはしない。
