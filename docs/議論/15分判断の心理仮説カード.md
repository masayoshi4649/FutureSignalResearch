# 15分判断へ落とす心理仮説カード

作成日：2026-11-06。作成時点の**未固定の設計カード**。[外部再調査](外部再調査/README.md)と[新しい時間・追尾・待ち率の条件](15分判断と連続追尾の研究条件.md)をつなぐ。旧49の作成途中案は採用せず、その後[試行49](../../study/00049_15分定時の序盤帯反応/README.md)で序盤30分高安・FastK・ATR・上位DMIを具体化した。以下の候補全てを検証済みとはしない。

## 優先する一つの問い

**反応前に既知の価格帯へ到達した後、帯外への進行が保たれる場合と、帯内へ戻される場合を、価格構造・勢い・変動幅等で区別できるか。これを定時に判定し、待ち率・125/250先着・連続追尾の収益を同時に満たせるか。**

心理の仮説は、新規追随・反対建玉の撤退・利確・反対側の流動性供給の競合である。誰の注文だったかを価格列から確定するという仮説ではない。指標足の高安を、自動的に共有された注文集中帯へ昇格させない。

## 機械化する前に固定する観測

|項目|必要な定義|現段階の候補・注意|
|---|---|---|
|参照帯|判断より前に生成できる水準と帯幅|前セッション高安、当場序盤の既知高安、確認済み構造等。どれが効いたかを見てから帯を選ばない|
|到達前の背景|長めの高安構造・平均・方向優勢等|MAの向きだけを持続可能性とせず、価格構造との整合を見る|
|帯への接近|接近方向、直前に進んだ距離、初接近/再接近|接近後の成功を使って起点を描き直さない|
|帯での反応|外への進行・内への復帰・再接近/再開の順序|定時までに観測できたことだけを使う。足内順序をOHLCから推測しない|
|定時の発動|09:15以降等の当時可視の状態|境界後に届いた確定値の扱いを決め、過去の接触価格で新規しない|
|無効化|当初の方向を否定する価格/勢い|新しい注文判断と、常時有効な保護線を区別|

序盤高安を選ぶ場合、デイ08:45から09:15までが30分であることはユーザーの判断時刻から生じる事実であり、30分レンジが最適又は参加者共通という実証ではない。参照帯の種類・数・期間・帯幅は外部根拠と観測可能性を踏まえて次計画で固定する。

## 同じ帯で順行・反転・待機を分ける

|分類|価格構造の問い|他系統の確認の問い|否定又は待機|
|---|---|---|---|
|順行|帯外への進行後、再接近でも元の帯へ戻されず再開したか|長めの方向優勢、短期の勢いが一足だけに集中していないか、通常変動と余地が整合するか|帯内復帰、元方向の再開失敗、確認までに狙う値幅が消費された|
|反転|帯外の試行が内側へ戻され、再突破も失敗したか|逆方向の勢いがあるか、長めの構造は継続/転換/往復のどれか|外側への再定着、単なる高RSI/低RSIしか根拠がない|
|往復内の反転候補|事前に定義した往復帯の端で更新に失敗したか|方向優勢が弱いという背景と、端からの勢いの変化が整合するか|帯中央、片側へ持続離脱、反対端までの距離が目標と合わない|
|待機|有効な情報があっても、上の区別が当時できないか|相反する根拠と、必要情報不足・価格不正を区別。後者は「判定不能」へ別分類する|定義を結果後に緩めて埋めない|

これは構造の質問表であり、発注可能な閾値表ではない。既存の再テスト、多段監視、確定pivotを再び名前だけ変えて試さず、共有され得る帯の定義、15分時点の比較、時刻の妥当性という差を明示する。

## 複数手法の役割

|役割|検討する手法の候補|避ける重複|
|---|---|---|
|位置と構造|既知高安・支持抵抗・価格の再試行|終値突破と高安更新という同じ事実を別票にしない|
|方向/往復の背景|高安の推移、MA、DMI/ADX|上向きと強さを同一視せず、複数平均を独立票にしない|
|勢いの持続/変化|RSI、ストキャス、MACD等|高低だけで反転せず、価格位置と別の問いを持たせる|
|値幅・損失許容|ATR、実現値幅、帯と対向帯の距離|小さい変動を無条件に継続優位としない|
|量・需給の補助|RVOL等の観測量、入力監査後の板更新|観測差分量を真の買売別量へ読み替えない|

全候補を一度にANDへ足さない。既存の55手法一覧から役割を選び、共通の価格構造・値幅に対して、追加の背景/勢いが何を区別したかを最小比較で測る。具体的な選択・閾値・時間幅・比較数は未決定である。

「その日が結局トレンドだった」「終日の値幅が大きかった」という事後分類と、09:15等の判断時に推測できる状態は別にする。終日高安・終日リターン・将来の実現変動を当時のgateへ使わない。良い局面が事後に見つかっただけで、その局面を当時選べたとは評価しない。

## 先に確認する機会の被覆

- 全予定15分枠に、買い・売り・待ち・保有継続・撤退・処理中・判定不能の状態を残す。保有中も分母に含み、保有継続は非待ちとする。
- まれな形状だけを選んで待ち率が高くなる場合は、どの文脈が未分類かを調べる。待ち率の達成を装うための保有延長や、結果を知った後の発注追加はしない。
- 心理の仮説を満たす機会がどれだけあるかと、そこから250へ届くかを別に調べる。成功例だけの図解で活動条件を満たしたとはしない。
- 新規後は定時外も損失/利益の追尾を行う。入口先着70%、実回収、費用後収益、待ち率50%以下を一つの数値へまとめない。
