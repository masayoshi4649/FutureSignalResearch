# E0保護の方向同体と期限補完に残る逆行

2026-11-11。[132](../../study/00132_E0の構造回復を保護して他入口へT8を使う/README.md)は「E0だけO0方向を保護し、それ以外は固定T8」とする主P0を、金融計算より先に方向だけ照合した。E0全9票でT8は既にO0と同じだったため、P0=T8が全79票/73場で一致し、方向変更は0。新しい金融集計・300比較・3CSVは重複生成しなかった。132に金融前F1はなく、後から作らない。

これはE0保護が新しく70%を達成したという結果ではない。既報のT8は39順18逆未到達16/観測不足6、到達済み68.42%で未達。取得と方向が同じなら、その不足を解消する変更にはならない。候補の名前や分類を変えることと、新しい売買判断が生まれることを分ける。

[旧固定政策の入口型追補](../../study/00132_E0の構造回復を保護して他入口へT8を使う/根拠/入口型の追補/結果と型の由来.md)では、T8で残った18逆行のうち期限補完deadlineが11、通常trendが6、E0が1だった。deadlineは38取得で15順11逆未到達11/不足1、57.69%。一方、E0は7場9件の小標本で7順1逆未到達1、通常trendは31件で16順6逆未到達4/不足5だった。これらは全て既使用の保存票から分けた旧T8の診断で、132の新しい金融成績や未知期の成功ではない。

E0は1分の構造回復・15分BB端/RSI極端・30分ADX既知低下・TR/取得距離の複合入口で、量を必須にしていない。B0が参照した5分実体と、E0の出生1分実体は異なる。既存T8がE0を一律に壊しているという懸念は、この79票では当たらなかった。悪化が残る型と、その型を当時認識できた理由を確認してから次の条件を作る。

次133では、開始3時間で強い条件の探索を終えて弱い期限補完へ切り替える方式を見直し、強い構造回復や継続候補を長く探す方針を準備している。まだ結果はない。deadline群を丸ごと反対売買する、又は低成績の場を削除するという結論にはしない。全対象場最低1取得を保持する必要と、遅い取得がH60観測不足へ偏る可能性を分け、全件数・未到達・不足・費用後利益/損失も評価する。

心理の仮説は「時刻の経過だけでは、買い/売りの参加や価格構造の確認は追加されない。回復・突破・失速を待てる場面では、時刻だけで確認を弱めない」。参加者の意思や因果を実証した主張ではなく、強い候補を長く探せば70%に届くという保証でもない。133の主条件と結果は別試行で固定する。
