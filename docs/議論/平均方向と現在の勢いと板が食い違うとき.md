# 平均方向と現在の勢い・板が食い違うとき

確認日：2026-11-08。既存の[MACD教科書](../../docs/technical-analysis/指標/MACD.md)、[DMI/ADX教科書](../../docs/technical-analysis/指標/DMIとADX.md)、[ADXの水準と変化](../../docs/議論/外部再調査/ADXの水準と変化を入口で分ける.md)、[板数量と将来方向](../../docs/議論/外部再調査/板数量と将来の方向予測を分ける.md)を先に確認した。以下は概念の補強と未検証の観測案であり、本稿作成時点では97全54場のH結果を未読。新市場データ読取・条件追加・実装・売買再生は0。

**EMAの方向配置が揃い、ヒストグラム増分と短期の板が逆向きでも、直ちに逆方向が成立したとは言えない。** 平均に残る背景と、直近の相対的な勢い・需給が食い違っている。順行再開か、調整か、局所反転かは、当時に固定した価格帯への実際の反応を分けて観測する必要がある。

## 水準・増分・時間尺度を混ぜない

買い方向を例にする。売りは価格方向の符号を反転し、ADXの強弱自体は反転しない。

|観測|式・値から言えること|まだ言えないこと|
|---|---|---|
|短期EMAが長期EMAより上|指定した平滑価格の順序が上向き|現在も同じ速度で上がっている、支持が有効|
|`M>0` / `h>0` / `Δh<0`|順に短長平均差が正、MがSignalより上、その差が前足より縮んだ|同じ意味の3票ではない。`h:+2→+1`は正の差の縮小で、逆側への交差ではない|
|`h:−2→−1`|差は改善したがMはまだSignalより下|上昇トレンド確定。Δhは価格の加速度そのものでもない|
|高いADXが低下／低いADXが上昇|過去の方向性が弱まる／偏りが増す可能性を別に観測|ADX低下＝下落、ADX上昇＝買い。高いADXにも過去の値が残る|
|表示板量の片側偏り|その時点の表示待機量の非対称|約定量、買い手/売り手の人数、注文主体の意図。数量減だけから成行消化と取消も区別できない|
|短秒OFIの逆符号|定義した直近窓の気配数量・価格変更の流れが逆向き|次の5分も継続すること。論文の同時価格説明力を将来方向の正解率へ読み替えない|

**OFIの有効時間を論文から一律10秒にはできない。** 著者は10秒集計で自己相関が小さく速やかに消えることも報告するが、NK225の保存snapshot・更新頻度・ラージからminiへの適用は別条件である。判定時の窓端・最終更新時計・欠落・既知性を残し、古い逆符号を5分間の反対圧力として持ち越さない。静的板量、E08の数量変化、最良気配OFIはそれぞれ定義を分ける。

## 切替のために観測する順序（独自案・未検証）

|モード候補|価格構造を主軸に分ける観測|勢い・量・値幅の役割|
|---|---|---|
|順行継続・再開|既知の支持側を保ち、押しの後に直近の戻りの端を取り戻す|hの縮小後の改善を確認。短秒の逆圧力が解消したかと、解消前でも価格が支持を保ったかを区別。ATRは取得距離と否定までの余地を測る|
|減速・調整／待機|旧構造は保つが、再開する価格の進行もまだない|h減速・逆板だけでは逆売買しない。ADX低下はこの状況と整合し得るが、それだけで反転にしない|
|局所反転の成立候補|既知構造を失い、取り戻す試行が失敗し、反対側への新しい進行が成立する|元方向の減速だけでなく反対方向の勢いを別確認。量は価格反応への補助、ATRは新しい否定位置との距離。上位EMAが遅れて残ることと矛盾しない|

例えば同じ「EMA上向き・Δh<0・逆方向の短秒フロー」でも、支持保持なら調整候補、支持喪失→回復失敗なら局所反転候補になる。この**価格反応との組合せ**を観測するのであり、逆OFIや負のΔhだけで反転注文へ切り替える案ではない。局所反転は上位トレンド全体の終焉とも同義ではない。

利食い・一時的ヘッジ・追随注文の弱まり等は心理の仮説である。主体在庫や新規/返済を測っていないため原因を断定しない。逆フローがあっても価格が崩れない場合も、直ちに「吸収」と命名して成功扱いせず、保持とその後の公開済み価格進行を分けて残す。

次の記録は背景、M/h/Δh、ADX/ΔADX/DI方向、固定構造の保持/否定/回復試行、ATR取得距離、量の定義と窓端を同じ判断時刻へ結ぶ程度に留める。確定足と公開時刻を守り、未来の山谷を使わない。未知は既知の否定と分ける。ADX等の追加入力が必要なら、未計算の96Tape欄を値の代用にしない。元Sourceの方向と実売買方向・返済通知の対応も別仕様であり、この調査で反転や再参加を金融へ加えない。
