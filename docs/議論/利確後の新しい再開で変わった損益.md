# 利確後の新しい再開で変わった損益

2026-11-08。[試行91](../../study/00091_利確完了後の新しい再開へ再参加/README.md)の既使用66場比較。[計画](../../study/00091_利確完了後の新しい再開へ再参加/検証計画.md)・[設定](../../study/00091_利確完了後の新しい再開へ再参加/設定と結果.md)・[結果正本](../../study/00091_利確完了後の新しい再開へ再参加/成果物/結果.json)・[機会差の診断](../../study/00091_利確完了後の新しい再開へ再参加/再参加と初参加の機会差.md)を参照する。

## 機会と方向判断を分けた

前回の利益を保護して返済すると、元FAR参照が残っていても恒久seenで再参加できなかった。今回はR0を旧89 E1/G1に固定し、R1だけ、直近実参加の費用後全利確完了後に公開された新p/r/k・別eventへ一度ずつ入れるようにした。初回除く15分新規、連続利益保護、売買対称、G1部分収穫と実確定益予算は共通である。

現在のE1も再検査した。15分EMA背景、3分平均回復、MACD/RSI増分、ATR取得位置、急変警戒、i→p→r→kの順序を組み合わせ、元FAR後期三手法の価格・量条件も維持した。過去に利確したという事実だけで現在の方向を決めず、前回の利益も新玉のG1予算へ持ち越さなかった。

[外部の継続パターンの説明](外部再調査/利益保護後の新しい押戻しを別機会とする.md)を心理の仮説へ使ったが、今回の履歴資格・機会ID・優先順位は独自条件である。90のp終値固定床やER選別は同時に加えていない。

両遅延とも、初参加33玉/577枚は要求・方向・実取得時刻/価格・量まで一致し、その損益も全て同じ。同実入口の出口差0、参照ID自体の片側参加0で、全差は追加再参加だけだった。再参加保有によるfresh初参加の見送り候補は今回0件だが、将来も発生しないと示したものではない。

主条件は2勝2敗、追加1秒は3勝0敗。追加1秒は主条件と同じ4玉に滑りを足した比較ではなく、前回の実利確資格と受理時の状態が変わり、参加集合自体も異なる。少数3勝を安定性の証明としない。全案費用後赤字で、安定利益は未確認である。

## 利益保全の分母

| 条件 | R0 全玉正益後赤字/正益玉 | R1 同左 |
| --- | ---: | ---: |
| 主 | 1/16 | 2/19 |
| 追加1秒 | 6/17 | 6/20 |

分母は「実確定額＋残玉の費用後現在額」がstrict正を観測した実玉数、分子はそのうち最終総額が負の実玉数である。残玉単価の正益による床起動とは別の全玉観測である。

主では追加再参加の正益3玉のうち1玉が最終赤字となった。追加1秒は新たな正益3玉が分母へ加わったため比率が下がるが、既存初参加の6玉を救ったわけではない。初参加・再参加、正益未観測・正益後赤字を分けて保全を評価する。

## 次に判別すること

今回、保護して退出した後に別の新しい機会へ入る機構は成立した。一方で、既存初参加の約18万円の赤字は残り、再参加の少数利益で解決できたとは確認できなかった。次は機会を増やすことに加え、**現在の複合条件がどの価格局面を表しているか**を中心に調べる。

- 15分EMAの背景が残る間の3分平均回復が、元方向への再開か、逆向きの波の中の局所的な戻りかを区別する。
- MACD/RSIの同方向増分を、価格の高安更新・支持抵抗の回復・取得余地と照合する。同方向のオシレーターを独立した成功確率として足し合わせない。
- 順行根拠が弱まったことと、逆方向の売買が成立したことを別に確認する。反転には逆側の価格構造と勢いの確認、値幅・量の役割を明示する。
- 前回の実利確・Source現在量・元Sourceの古さと、現在の需給支持を混同しない。量や価格応答を追加する場合も、未知を不支持や支持へ補完しない。

これらは次候補であり、新規則の収益をまだ検証していない。全66場は既使用で、未使用期間の安定利益を示していない。
