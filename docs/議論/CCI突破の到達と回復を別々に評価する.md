# CCI突破の到達と回復を別々に評価する

確認日：2026-11-05。[試行35](../../study/00035_CCI突破の到達後回復/README.md)の共通知見。[実行前計画](../../study/00035_CCI突破の到達後回復/計画.md)、[設定と結果](../../study/00035_CCI突破の到達後回復/設定と結果.md)を正本とする。全66場は既使用で、未使用性能の確認ではない。

## 到達は回復と異なる

[34](CCI突破の即時と固定高安指値を比較する.md)は、価格構造＋CCIの同じ突破登録で、旧高安の30秒指値を比べた。取得価格を改善しても、買いaskが旧抵抗R以下へ戻るだけでは、買い直しや支持の維持を確認していない。

35ではE1=旧30秒指値、E2=同じ指値を180秒まで延長、E3=180秒以内の初到達後、strict後keyで初めて買bid>Rへ回復した時に市場新規要求、と分けた。売りは初bid≥旧L、後ask<Lの鏡像。価格構造は位置、登録時の現前CCI20実方向100超は平均からの偏り、ATRは取得後の保護幅を担う。CCIが回復時にも持続していると確認した条件ではない。

[CMEの支持抵抗](https://www.cmegroup.com/education/courses/technical-analysis/support-and-resistance)は過去高安と突破後の役割変化、価格帯として捉える考え方を説明する。[FidelityのCCI](https://www.fidelity.com/learning-center/trading-investing/technical-analysis/technical-indicator-guide/cci)は偏りと方向用途、価格分析等との併用を説明する。ここから「旧境界へ押し戻った後、外へ戻る反応は継続候補となる」という心理仮説を立てた。吸収注文・参加人数を観測した事実ではなく、180秒や単発BBO回復の有効性を資料が実証したわけでもない。

## 何が増え、何が改善したか

主率は250pt順行が125pt逆行より先に到達した割合で、全仮約定を分母にする。各案の新規価格・時計から新計算し、到達/回復前の値動きを成功へ足さない。

|案|学習・仮約定/全登録|学習・250先着率|選択・仮約定/全登録|選択・250先着率|選択・30分間引き率|
|---|---|---|---|---|---|
|E1 30秒指値|97/457|26.80%|70/301|28.57%|21.43%|
|E2 180秒指値|236/457|23.73%|154/301|32.47%|28.57%|
|E3 到達後回復|122/457|23.77%|86/301|36.05%|26.83%|

E1の仮約定はE2へ全て同key・同価格で残る。延長で増えた139/84件の質は、既存30秒群と分けて読む。E3はE2仮約定の一部だが、回復を待つ選別に加え、市場新規の価格と時点が変わる。E3の選択主率がE2より高くても、学習の主率はほぼ同じで、選択の間引き率は下がった。三案とも入口支持は満たしたが、支持付き70%の目標は未達。

保存結果を対応させると、次の違いが見える。B/Cは回復したという未来を知った後の比較群であり、E2の登録時点で選べた群ではない。

回復する群には高率側の選別がある一方、同じ最終群のC→Dでは250先着が4/6件減った。E2からE3の新規は、価格時計差の中央値29/25.5秒、実方向価格差の中央値+20/+20pt（買いの追い高・売りの追い安）。確認時点まで待つ費用を含む差で、価格だけの因果効果ではない。回復技術発動130/88→時間可129/88→仮約定122/86も分け、未発注と発注後未約定を混ぜない。

実E3は監視受理369/234→初回復111/69→実新規注文110/69→完結103/67。監視中の後続抑止48/39件もあった。E1→E2の同実新規key/価格/ATR/D群78/57件は出口全属性差0だが、E2→E3にその厳密共通群は0件。同じ入口からの出口効果があったと主張せず、別価格・別時計の入口方針として読む。[対応診断](../../study/00035_CCI突破の到達後回復/対応診断.json)は保存物36,092項目を差0で照合した。

既使用後続2場のE3先着6/11=54.55%も、実9取引の追加5pt後は−3,398円。薄い既使用2場を、両期間の支持や新しい未見確認の代用にしない。

## 再利用する記録と次の判別

- 原登録b、初到達、初回復、回復時の時間可否、市場要求b′、仮約定、実参加を分ける。30分間引きはb。b′がNoneなら未発注で、bへ置き換えない。
- E3は回復要求+1秒以降の現在BBOで取得する。絶対期限はb+180のままで、b′+180へ延命しない。b+180での回復は最短有効化が期限外なので未発注。
- 同秒後行の回復は許すが、実時間で反発が何秒続いたかは分からない。[価格時計と受信時計](価格時計と受信時計を分ける.md)の違いを残す。
- 到達/回復の技術的な仮観測は全登録独立。実監視は一件で、後続登録の抑止・監視満了・実注文取消を別計数する。未来snapshotをliveの純15列へ混ぜない。
- 全E2→回復した群のE2→E3仮約定群のE2→同群E3を比較し、機会の選別と、価格/時計を含む取得変更を区別する。共通原登録と、同実新規key/価格/ATR/Dの厳密共通出口も別に読む。
- 利益追尾は現在返済BBOの手数料・参照滑り控除後益がstrict正（122円控除、12.2pt超）で起動する。最低床は名目新規価格であり、費用後同値や遅延後の同価格約定を保証しない。

今回の単発回復を支持維持の判定として採用できる根拠は得られなかった。次は古い登録CCIを待機後の勢いへ読み替えず、**価格失敗の発動時点に、勢いと数量の変化をどう組み合わせて反転/待機を判別するか**を別仮説にする。35の未回復群や損失群を、そのまま逆方向エントリーへ変換しない。新しい閾値や切替条件は未設定・未検証である。
