# 方向切替と待機の効果を分けて評価する

2026-11-12。[152の固定結果と原因診断](../../study/00152_強い反対背景を複合回復で切り替える/README.md)から整理する。全73場は既使用で、独立未知期の成績ではない。

## 全体が改善しても方向切替が成功したとは限らない

152主U1は697取得・到達済み62.63%、C5既知利益4,724,429円/損失3,374,174円/差引+1,350,255円、未知12件だった。固定対照U65の55.41%・既知+473,678円から改善したが、70%未達で、後25場は49.13%・既知−240,706円だった。

その改善を「反対側へ売買を切り替えたため」と解釈すると誤る。P65からA0への共通748件は同側730件と実切替18件だった。同じ取得時計の18件では、元の方向が10順8逆・既知+8,614円、切替後が7順11逆・既知−71,386円。実側BBOによる差は−80,000円で、今回の切替は改善要因ではなかった。新しいcaseや別の取得時点が混ざった差でもない。

一方、強い反対背景の入口をそのまま多数維持しなくした点は、152で変わった成立集合の一部である。非成立にした仮想入口の将来利益を機会損失として最適化せず、固定対照と新政策で実際に成立した取引の条件・数・費用後収支を比較する。

## 取得位置の制限も、率・回数・収支を別に見る

A0の748件から位置制限後のB0は同じ側の614件になり、到達済み率は60.45%から61.82%へ上がった。ただしA0だけで成立した134件の既知小計は+7,682円であり、位置制限を加えたことで全期の利益が増えたという結果ではない。これはA/Bという固定政策の実現収支の比較であり、Bの未参加を取り逃がした利益として採点したものではない。

主U1は旧C1を含み平均0.9668回/時。場別の回数差は許容するが、全対象時間を分母とする頻度と、先着率、利益/損失を同じ数字にまとめない。

## 残った取引の失敗は、追加した分岐の外にもある

後25場の新B0全151件は、強い反対背景Gに入らず元P65を維持した枝だった。保存されたR(s)が不成立の145件は69順76逆・既知−249,165円。一方、前48場の同じR不成立429件は244順110逆・既知+1,417,660円だった。

したがって「Rが不成立なら悪い」「全ての入口にRを追加すれば解決」とは確認できない。G外のB0でR成立は全期6件しかなく、同じ予測方向に条件を重ねるだけでは候補数を大きく縮める問題もある。候補を生む時点・方向そのものを、複数のテクニカルから独立に組み立てる比較と分ける必要がある。

## 次の比較で記録すること

- 固定対照と新政策の共通case、同方向、実方向変更、追加case、非共通caseを分ける。
- 方向変更は同じ取得時点の実反対BBOで再評価し、1−pで代用しない。
- 順行/逆行/未到達/観測不足と、IFD既知/未知を別に保持する。
- 価格位置の制限、方向の判別、出生候補の変更を同じ効果として説明しない。
- 全73場参加・平均頻度・全体と前後期間を残し、後の良い期間や分岐へ主を交換しない。

金額は独立mini1枚、1pt=100円、往復手数料77円と追加往復滑り1,000円を控除したIFD代用の既知小計。近接する観測窓は重複しており、実口座・可変枚数・利益追尾の成績ではない。構造回復・勢い・量の併用が将来の優位を保証する、という因果の証明も行っていない。
