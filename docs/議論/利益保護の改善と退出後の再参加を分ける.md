# 利益保護の改善と退出後の再参加を分ける

2026-11-09。[試行102](../../study/00102_定時チャートと一定利益後の可変追尾/README.md)の既使用54場・24設定を金融再生し、保存約定の会計と限定因果を検算した。[正本](../../study/00102_定時チャートと一定利益後の可変追尾/成果物_版2/結果.json)に基づく。原板全経路を別の金融engineで再計算した検証ではない。

## 参加率と黒字化を分ける

5分ごとに3/15分の方向、MACD、RSI、価格構造、ATR、当時量を組み合わせた。開始30分・末尾30分を新規から除外した5,832枠で、全24設定の新規＋保有は54.66〜66.91%。最低25%・目標50%を満たしたが、**全設定が赤字**だった。

主条件S4・追加滑り0・通常後続行では、即時起動P0が−17,511,816円、一定利益起動A0が−10,723,920円、複合可変幅A1が−10,948,700円。いずれも手数料控除後。A0は方式全体では損失を減らしたが、保有期間と後続の実入口集合も変わるため、起動だけの効果とは断定しない。

元S0の複数建玉・元数量・Source返済を、102では単一建玉・支持数による2/4/6枚へ置き換えた。元S0との大差を、追尾や支持票だけへ帰属しない。支持数は相関した価格指標を含み、独立した証拠の数や校正済み勝率ではない。

## 可変幅の同実入口には改善があった

A0とA1は起動水準・費用回収床・初期損失上限が共通で、複合収束／失速時の幅だけが異なる。要求時計・原行・取得価格・数量・取得ATRまで一致した実入口に限定すると、全8比較で退出差が改善した。

これは両運転で実際に成立した取引の加法分解であり、未参加の仮想利益や機会損失ではない。「狭い追尾が無効だった」とまとめると、同実入口の改善を見落とす。一方、同実入口だけの改善をもって運用全体の黒字化とも言えない。

## 起動前の小幅正益にも損失が残る

A0の主条件は、u正益観測1,026玉のうち最終赤字704玉・−12,964,764円。保護起動813玉のうち最終赤字492玉・−410,520円とは別の分母である。一定利益を待つ区間の小幅正益後の逆行も大きく、起動後だけを評価して保全成功とはしない。逆指値の床と後続行の実約定も同一ではない。

## 次の仮説

背景の方向支持と、新たな発注の引き金を分ける。102は退出後も各5分枠で新規を許すため、同じ方向支持が残るだけで再参加できる。保有期間の差が後続参加を変えたことは確認済みだが、43件すべての損失原因を「古い背景での再参加」と特定したわけではない。

次は定時判断を維持し、元Sourceの複数建玉・可変数量・返済構造を残した基礎へ戻す。一定利益の起動と幅を比較し、保護後の再参加は新しい押し戻り・奪還等のsetupとtriggerで区別する。生存する参照玉を常時再発注する案とは分ける。参加最低25%を維持できるかも実測し、未達を隠すために保有を延ばさない。

元SourceのD07重複時の買い優先は別の既知課題。修正するなら別条件のSource再生が必要で、旧通知の読み替えだけで売買対称を主張しない。現時点で安定利益を達成した新候補はない。
