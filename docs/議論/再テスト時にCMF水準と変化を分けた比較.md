# 再テスト時にCMF水準と変化を分けた比較

確認日2026-11-05。[試行43](../../study/00043_再テスト時のCMF変化方向/README.md)・[設定と結果](../../study/00043_再テスト時のCMF変化方向/設定と結果.md)・[保存診断](../../study/00043_再テスト時のCMF変化方向/対応診断.json)に基づく。全66場は既使用の開発であり、未使用期間の実証ではない。条件の正本は試行へ置く。

## 何を維持し、何を比較したか

[試行42の価格分岐](突破の再テストを数量加重終値位置で判別する.md)を維持した。最初の3分終値突破bで旧20本の高安と境界を固定し、最初の対象再テストjが外側を維持したTなら元方向、旧範囲へstrict帰還したRなら逆方向を候補とする。境界等号等はWAIT、反対端の終値到達は先取消。実方向のMACDヒスト一足差が正という複合条件も残す。CMFだけから方向を決めず、逆符号や不採用を自動反転へ置き換えない。

|案|固定した追加条件|比較の意味|
|---|---|---|
|D0|固定42A0の純入口245件を識別子以外そのまま使用|全66場の入口・先着・実運用・追尾が同じ完全対照|
|D1|D0かつ同場の隣接した現前CMF21が共に準備済み|和集合22本、数量・価格・公開時点の準備による除外|
|D2|D1かつ実side×(CMF現−CMF前)>0 strict|同じ準備での変化方向の選別|

3案とも売買対称、出口は固定XF。現在水準の正、当足寄与Iの正、零線交差、後足待ちは追加しなかった。D1の要求数は学習106、選択95、後続9。42A1は現在21本だけの準備で、選択96件だった。したがって旧42A2と新D2の全件差を、水準対変化だけの効果と解釈しない。

## 「改善」が当足から来るとは限らない

[CMF変化の補足教材](../technical-analysis/指標/CMFの変化と窓の入替え.md)に一般式と人工例を分離して残した。FをCMF、mを足内終値位置、qを観測差分量、oを脱落足とすると、

```text
ΔF = I+O
I = q_t*(m_t−F_prev)/Q_t
O = −q_o*(m_o−F_prev)/Q_t
```

Iは前平均に対する当足の位置・重みの効果、Oは古い足の脱落の効果である。新しい買い注文量や売り手の退出を測った式ではない。現在q=0でも古い低い位置が抜ければΔFは正になり得る、という人工反例と、実際の出現を区別する。

今回のD1要求では「I=0で脱落だけが実方向へ改善」は全期0件だった。一方、実方向Iが負・Oが正だった要求は学習9、選択2件あり、そのうちΔFが実方向へ正となりD2へ残ったのは5、1件だった。**I=0の例がないことは、脱落寄与がないことを意味しない。** この診断から新しいI>0条件や別運用を補算していない。

全22本は同場の連続公開完全足、全幅正、全q基準完全・有限非負、現前それぞれの総q正を必要とする。完全0量は有効で、共通20本の総量0も両窓が定義できれば許す。欠測を飛ばす圧縮や古い正常値への代替はしない。分数の差と交差積の符号を厳密に照合し、表示丸めで採否を変えない。

## 同じ準備でも、水準と変化は異なる対象を残す

D1内で現在水準と変化の実方向符号を対応させた要求数。これは保存済み入口の診断であり、4群の独立運用ではない。

|期間|両方正|水準だけ正|変化だけ正|双方非正|合計|
|---|---:|---:|---:|---:|---:|
|学習|31|6|50|19|106|
|選択|29|10|37|19|95|
|既使用後続|6|0|3|0|9|

例えば変化だけ正の仮約定先着は学習17/45、選択6/36、両方正は7/28、12/27で、関係は期間で揃わない。この結果を見て有利な群だけを採用するなら新しい仮説であり、同じデータ内の事後選別になる。今回のD2の結果へ置き換えない。

心理の仮説は、明示的な価格の維持/帰還に、数量で重み付けした終値位置の改善が伴うか、というものだった。しかし価格加工同士の重複、窓脱落、観測量の不完全さが残る。市場参加者の意図や今後の継続確率を確認したとはしない。

## 仮250と実際の利益保護は別に見る

利益追尾は、現在正常返済BBOの実side×(mark−entry)×10−122円>0 strictで一度起動する。122円は往復手数料22円と参照追加5pt/片。新規要求j時点のATRによる固定D、MFE−D、最低名目entry床、非緩和、pending凍結を維持した。費用感応0/5/10でも起動参照は同じ5pt。名目entry床は費用後同値や遅延後の同値約定を保証しない。

D2選択では対応仮250成功18件のうち17件を仮到達より前に実返済し、実保有MFE250は1件だった。追尾起動51件中、基準費用で赤字25件は名目同値20件と不利返済5件。学習も対応仮250成功23件全てが実返済後の到達で、実保有MFE250は0件だった。仮入口の良否と、実際に確保できる額の両方が必要である。追尾を外せば同じ参加で仮成功を全回収できる、とはしない。
