# 三時間軸の選別と正益後赤字を分けて読む（115）

確認日2026-11-10。Rootが成功を解禁した115独立全70場840会計の集計に基づく。22対照・8,037対応の診断と独立加算も完了した。閾値を結果へ合わせて変えない。

## 一般説明と心理の仮説

30分EMAの長い終値配置、15分DMIの高安拡大、5分の前3本高安突破は役割が違うが、同じ価格履歴から作るため独立票ではない。ADXは向きのある指標ではなく、DIの偏りの強さを平滑した尺度である。強い方向の中でRSI等が過熱表示を続けることも、価格幅が収縮しても方向が未定であることも、単独の反転指示にはならない。[事前の一次資料調査](外部再調査/三時間軸で配置と高安拡大と突破を分ける.md)に出典URL/確認日2026-11-10を残した。一般教材の説明をこの複合条件の優位の証明へ広げない。

心理の仮説は、長い方向配置と中期の高安更新が同じ向きで局所抵抗を越えて保持するなら複数の時間幅の判断が重なる可能性、逆配置の中で中期方向が回復するなら旧方向の手仕舞い/新方向の参加が始まる可能性である。新規/返済・主体・吸収量は価格指標から確定しない。DI順側という状態は押戻し→復帰という過程そのものではない。

## 今回確認した事実

A0は元Source入口＋P100共通保護、T/TRは同保護の入口選別である。C0D0ではA0+1,126,987円/558玉/1,169枚、T+386,917円/28玉/79枚、TR+407,916円/34玉/92枚。T/TRは保存点DDも利益総額・損失総額も減った。取得数が大きく違うため、そのまま保護技法の改善や単位リスク当たりの改善とは言えない。

Tは558出生中28票（5.02%）、TRは34票（6.09%）を通した。選択未知7と入力不足診断79は別に残した。C5ではT/TRがD0/D1とも赤字で、黒字だったC0だけを採用根拠にしない。共通28玉は全返済・保存保護も同体で、R追加6玉13枚の純額は4費用で＋20,999／＋13,999／＋8,999／＋2,999円だった。主条件は追加16場の1玉の影響が大きく、一般化はできない。

全玉W>0経験玉を分母にしたC0D0最終赤字率はA0の178/477=37.32%に対し、Tは11/25=44.00%、TRは14/31=45.16%。全4費用でもT/TRの同率はA0より高かった。起動後赤字0と、起動前も含む正益経験後赤字は別の観測である。どの玉を取得したかと、取得後の保護の違いを切り分ける必要がある。

11/06DayはT/TRともC0D0で−92,616円、2玉8枚。2玉とも全玉正益経験あり、追尾起動なしで最終赤字だった。Nightは0取引。新条件にも小正益から赤字となる実玉があり、0取引日の0円でその問題が解決したと扱わない。

## 次に判別したい問い

条件が厳しく成立数が少なかった事実で終了せず、長い配置・中期の高安方向・短い突破のどこが成立窓を制限したかを、当時公表済み値とSource枝の役割別に調べる。未知/古い公表と、既知の方向不一致、構造がまだ突破していない状態は分ける。順行待ちと反転待ちのどちらへ切り替えるかを先に状態で定義し、結果のよかった出生だけを後から拾わない。

Rの中期DI回復が一時的な買戻し/売戻しか持続的な転換か、Tの突破が通常の再開か既に拡大し切った追随かは、価格・高安方向・値幅の当時の遷移として問う。未来の回復や決済後価格を発注条件にしない。現行のADX20/前3本/TR2倍をこの70場の損益へ合わせて変更する検証は行っていない。

全70は既使用、11/09未読。未知期間の安定性、実mini板約定は未確認。採用false・研究目標達成false。[費用別・期間別の結果](../../study/00115_三時間軸の方向性と局所構造で入口を分ける/README.md)と[独立した実現差のレビュー](../../study/00115_三時間軸の方向性と局所構造で入口を分ける/診断/実現差のレビュー.md)を参照する。


## 費用は実退出も変えた

TのC0D0/C5D0は全28玉79枚が同実入口で、実返済の違いは5玉。純額差43.6万円の内訳は、追加滑り7.9万円と実粗利益の減少35.7万円だった。最大差の10/15Dayは、通常幅の縮小ではなく、費用を含む最低床が10ptから20ptへ変わった実退出差である。別の10/29Dayでは起動の有無が変わった。

したがって、小さい入力差に損益差が比例すると仮定せず、起動・支配した床・要求・実約定を別に保存する。今回は起動後赤字0でも起動前の損失が残り、費用を置くと総額は赤字となった。利益保護と入口の持続性を分ける理由は[外部の一次資料再調査](外部再調査/利益保護と相場の持続性を分ける.md)にも整理した。いずれも最低床を不利に緩める根拠や、現在の70場に合う最適幅の主張ではない。

11/06Dayの[2玉のOHLC](../../study/00115_三時間軸の方向性と局所構造で入口を分ける/診断/11月06日の2玉と保有区間OHLC.md)も既存112集計へ接合した。売7枚の全玉W最大は＋27,461円、売1枚は＋7,923円で、必須起動水準70,000円／10,000円には届かなかった。追尾起動後の幅だけでは扱えない群が今回も残った。最大値は事後の観測であり、起動額を下げれば純収支が改善するという結果ではない。
