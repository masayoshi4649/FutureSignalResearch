# 先着率を保ちながら時間あたりの取得数を増やす

2026-11-12。ユーザーの追加指定を記録する。先着率の見通しが立った後は、平均して概ね1時間に1回の取得を目指し、同程度の先着率を維持できる複合テクニカル条件を探す。

頻度は全対象セッションを通した時間加重平均で評価する。条件が繰り返し成立するセッションでは高頻度、機会が少ないセッションは1回でもよい。各場に同じ回数・毎時定時の新規・一律の回数上限を課さない。全対象場最低1取得は下限として維持する。

## 数える単位と分母

- 1回は、独立した技術的な入口条件が成立し、注文適格性を通過して取得代用が成立した1エントリー。候補出生だけ、未取得、注文再送、部分約定、同じ入口の枚数分割を別の回数へ水増ししない。
- 同じ状態の連打と、状態が解除された後に新しく成立した入口を区別する。episode識別、再準備条件、cooldownを金融前に固定する。cooldownを全手法共通の恒久的な上限とは扱わない。
- 主の頻度は `全取得回数÷全対象セッションのザラバ時間合計`。日数ごとの回数平均や、場ごとの回/時の単純平均へ置換しない。場別・デイ/ナイト別の分布も併記する。
- 60分先着の観測を場内へ残すため新規末尾を除く場合は、ザラバ全時間を主の分母へ残し、新規可能時間での頻度を副として記す。欠測・指標不明の時間を都合よく除かない。
