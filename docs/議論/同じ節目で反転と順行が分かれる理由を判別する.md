# 同じ節目で反転と順行が分かれる理由を判別する

2026-11-12確認。外部研究の事実、市場心理の仮説、本研究への適用案を分ける。以下はNK225の先着率70%を示す資料ではなく、複数手法で局面を切り替える設計の根拠である。

## 外部の実証と解説

Oslerの研究は、銀行の為替注文を調べ、利食い注文と損切り注文では集中する価格と値動きへの作用が異なり、節目での反転と突破後の加速を説明できると論じる。単に「同じ価格に注文が多い」だけでは、その後の方向を決められない。[NY連銀 Staff Report 125](https://www.newyorkfed.org/research/staff_reports/sr125.html)。

別の研究では、業者が事前配信した支持抵抗と為替の分足を比較し、反転・中断の予測力を確認した一方、通貨と業者で差があった。評価は水準接触後の時刻判定を含み、当リポジトリの同幅先着・費用後収益とは異なる。[Osler 2000 原論文](https://www.newyorkfed.org/medialibrary/media/research/epr/00v06n2/0007osle.pdf)。

CMEの教材も、価格形状は継続・反転の手掛かりであり、完成した構造や他の情報との確認を求める。形の名前だけから次の方向を確定しない。[継続形](https://www.cmegroup.com/education/courses/technical-analysis/trend-and-continuation-patterns)、[反転形](https://www.cmegroup.com/education/courses/technical-analysis/technical-patterns-reversals)。

為替の銀行注文という実測を、日本の先物板に同じ注文主体がいる証拠へ置き換えない。本原板からは注文が利食いか損切りかを直接分類できないため、以下の心理は推論である。

損切り注文の連鎖を調べた別の研究は、為替では特定水準を通過した動きが自己増幅する証拠を報告している。[NY連銀 Staff Report 150](https://www.newyorkfed.org/research/staff_reports/sr150.html)。したがって本研究では、急な値幅・RSI上昇を一律に反転の根拠とはせず、「突破側を維持する加速」と「旧域へ戻る失敗」を価格構造・勢いの持続・量で分ける仮説を置く。これはNK225で確認済みの結果ではない。

## 技術的に確認する違い

|局面の仮説|価格構造|背景・勢い|量・値幅の役割|判断候補|
|---|---|---|---|---|
|節目で反対側の圧力が価格を戻す|接触後に旧レンジへ戻り、戻った水準を維持|旧方向の勢い縮小を確認。ADX低下だけでは反転としない|回復足自身の量で裏付け、ATRで無効化距離を測る|構造回復を伴う反転|
|節目を越えた方向の圧力が続く|突破側へ終値が出て、その後も水準を保持|長中期のMA配置/傾き・DIと短期の勢いが整合|突破/回復を含む足の量。異常幅の一発だけを別扱い|押戻し・再試験後の順行|
|突破が持続せず、追随側が不利な状態になる|一時突破の後に旧レンジへ復帰|元方向の加速か失速かを区別し、失敗構造を確認|大量だけで吸収と断定せず、価格の復帰と同時の量を見る|失敗突破の反対側|
|判断できる証拠が足りない|水準が未確定、又は現在Lastが確認側を維持しない|背景の未知・指標の助走不足|未知量を0や支持へ変えない|新規待機・既存保護は別管理|

MA・MACD・RSIを独立した票として足すのではなく、背景・位相・構造を別の役割へ置く。ATRは方向を決めず価格距離の尺度、量は参加の裏付けとして使う。方向を正にそろえた同じ式を売買へ適用する。

## 全成立ケースへ広げるときの検証

旧137の固定81取得を対照とし、追加候補の出生時点で利用可能だった情報だけを持つ。節目は事前の確定高安などから固定し、後の山谷で描き直さない。公表時刻と市場時刻を区別し、入口で知り得た状態へ正逆両方の実BBO先着を結合する。

反転過多の群が見つかっても、直ちに全件を反転する規則へしない。その群を当時の背景・勢い・価格位置・量で判別できるか、区分を事前固定して実側気配で再評価する。取引数、全場参加、先着の3分母、未到達・不足、費用後利益・損失を同時に残す。

本資料から新しい閾値や売買規則はまだ採用していない。既存候補の全取得を集めた入力と、出生時の特徴を固定する次段階の検証案である。

## 採用を保留する外部数値

2026-11-12に[ICT/AMDをNQ先物で検証したプレプリント](https://arxiv.org/abs/2610.35887)の本文も確認した。報告された地合い別の方向判定は「日中終値と事前レンジ中心の関係」であり、同幅先着ではない。日足EMAによる地合い分類も、当日終値をいつ利用するかの因果関係を本文だけでは確定できず、コード未照合である。率の移植や70%達成の根拠には使わない。取得時に既知だった背景だけで、同じ反転形の成功と失敗を分けるという検証課題として留める。
