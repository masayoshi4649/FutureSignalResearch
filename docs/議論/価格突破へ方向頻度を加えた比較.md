# 価格突破へ方向頻度を加えた比較

確認日：2026-11-05。[試行00030](../../study/00030_価格突破とBB幅と方向頻度/README.md)の全66場・二案に基づく。**入口支持は両案で充足したが、70%と費用資格は0/2。** PSY方向差の追加で平均損失は小さくなったものの、先着率の改善は両期間で揃わず、赤字を解消していない。

## 価格・幅・回数を同じ時点で比較した

3分の現在終値が、同場直前20本の高値/安値をstrictに突破した足を原Pとする。P0はBB20・2σの絶対幅4σが拡大したもの。P1はさらに、現前それぞれ12終値変化の上昇数U−下落数Dが実方向に正であることを要求した。売りは買いの鏡像。

同値Fは中立。上昇率は100U/12、下落率は100D/12で別に計算し、売りを100−上昇率で作らない。U>DはU>6という過半数条件ではなく、値幅・順番・参加者の人数も測らない。通常の[PSY教材](../technical-analysis/指標/サイコロジカルライン.md)と、この符号付き頻度差の使い方を区別する。

BBの前窓は前20終値、現窓は古い1本を外して現終値を入れた20本。数学上同幅なのにfloatで微差が出る人工例を確認したため、幅の増加と同値な母分散の現前差をFractionで厳密比較した。表示の幅と、採否の厳密符号・分散差分子/分母を別に保存する。期間・閾値・費用を結果後に選び直していない。

## 現前PSYは独立した二票ではなかった

価格原Pでは、現在の終値変化が必ず突破の実方向になる。実sideをs、回数差をSとすると、`sS_t=sS_(t−1)+1−s×窓から落ちる旧変化の符号≥sS_(t−1)`。従って前Sが実方向なら、現Sも自動的に実方向になる。

これは結果開示前に計画へ記録した。全原P1,309件で確認し、前が実方向正・現が非正は0件。両条件は規定どおり維持するが、主に測ったのは「突破前から方向回数差が正だったか」の追加価値である。指標の条件数を、独立した証拠数とは扱わない。

## 観測品質と参加減少を分ける

学習の品質注意はP0が2場、P1が1場で、両案とも学習期間の全体確定額はnull。観測総額の縮小を確定収益の改善とはしない。

- 9/22Night：両案で注意取引1件、場全体の最長正常価格時計間隔583秒。注意取引の保有中は430/528/494秒の間隔があり、観測純額は+178円。
- 10/9Night：P0で注意取引1件、場全体の最長正常価格時計間隔399秒。注意取引の保有中は399/359/306秒の間隔があり、観測純額は−322円。

P1が一方の注意取引へ参加しなかったことを、将来の観測空白を検知した能力とは扱わない。結果後の参考として注意場の和集合二場を両案から同じく外した38学習場でも、追加5pt平均はP0−269.35円・P1−254.03円と赤字だった。この除外は事前見送り規則に採用しておらず、正式なnullや費用資格を置き換えない。

条件選択24場は両案とも品質注意0。実完結330→259件、追加5pt総額−78,960→−61,498円で、平均の改善は小さい。学習の観測総額は−130,272→−96,372円だが、476→376取引への参加減少と品質の構成差も含む。

同じ実新規の対応は学習372件・選択256件で、返済時計・原行・価格・純損益差は全費用で0だった。学習のP0のみ104取引は基準−25,288円、P1のみ4取引は−1,388円。選択は74取引−11,428円と3取引−1,066円。純入口部分集合でも一建玉の実新規は単純な部分集合にはならない。

## 値幅の一発への集中をどう選んだか

先着・損益を開く前に、PSYと同じ直近12変化について、最大一足の絶対変化/全絶対変化和と、現一足/同和の診断を予定した。中央値の分母は未約定も含むP0純入口の保持/除外群。

| 指標の中央値 | 学習保持/除外 | 条件選択保持/除外 |
| --- | ---: | ---: |
| 最大一足の比率 | 20.83% / 23.33% | 20.55% / 23.81% |
| 現一足の比率 | 12.12% / 16.36% | 11.65% / 17.65% |
| 現一足の実方向変化 | 50 / 60pt | 50 / 70pt |

今回のPSY条件は、一足の値幅寄与がやや小さい構成を残した。しかし一発変動の完全な除去ではなく、その違いが両期間の先着率を一貫して改善したわけでもない。前PSYの全整数値でも記述集計を保存したが、結果のよい小区分を後から現P1の条件に足していない。

## 250先着と利益回収

P0の実取引に対応する仮250先着は学習134件・選択90件。そのうち134件・89件が250判定より前に返済し、実保有で250に達したのは0件・1件。P1の学習も仮250先着103件は全て判定前に返済した。これを「得ていた250ptを失った」と表現しない。

有利5ptで起動するA5/X0を両案で共通にした比較である。P0の起動後赤字は学習211件のうち同値返済・費用によるもの167件、不利返済44件。選択148件は126件と22件だった。P1は学習165件が128件と37件、選択118件が101件と17件だった。起動後の最終設定線が守る名目利益は全件0pt以上（買いは新規価格以上、売りは新規価格以下）だが、それが実際の返済価格や費用後の同値を保証するわけではない。

価格時計での待機を実microの注文遅延と同一視せず、最低同値の設定線・返済価格・費用を分けて検算する。指定二場の少数原行標本では、同じ価格時計のまま気配が変わり、受信時計は見つからなかった。[時計の共通知見](価格時計と受信時計を分ける.md)に範囲と限界を残す。次の利益回収変更も、入口選別と再参加を分けた別試行にする。

## 証拠と次の問い

人工18件と、非PnLの独立準備3,240,275項目の一致後、121ファイルを固定。全先着・Decimal会計・CSV・Viewerは313,230項目、状態は3,698,293項目、追尾は620,044項目、対応は18,815項目、保存物の追加独立読取は8,676項目で差0。ATRのみ既定の微小許容とD整数厳密照合を使い、精密分散・PSY・価格・時点・全採否は厳密に照合した。

順行・反転とも、単なる指標追加と活動減少を精度改善としない。残る問いは、どの既知の価格状態でどちらの発動を選ぶか、利益保護と実行時計の前提が回収へどれだけ影響するかである。今回の不採用群を自動で反対注文に変換せず、切替にも独自の実行可能な価格条件を要求する。
