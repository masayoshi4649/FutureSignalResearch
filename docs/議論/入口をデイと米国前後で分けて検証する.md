# 入口をデイと米国前後で分けて検証する

2026-11-13のユーザー提案。出口探索の結果を受け、入口のデイ・ナイト米国前・ナイト米国後を明示した比較へ戻る。[160の固定診断](../../study/00160_入口を三時間帯で診断する/README.md)で、全期の先着率やPFに時間帯差が隠れていたことを確認した。

153 U15の旧厳密H60/±125ptの到達済み率は、デイ79.41%・米国前50%・米国後100%（9取得のみ）。152 U0は65.50%・46.27%・52.82%。153を一旦達成とした以前の判断は変更せず、全時間帯で同じ方向精度だと一般化しない。未到達・不足・全取得分母率は[正本](../../study/00160_入口を三時間帯で診断する/成果物/型付き三表.json)へ残す。

## 入口へ戻る理由

152の後25場では、入口先着そのものがデイ53.13%、米国前10%、米国後45.71%へ落ちた。初期方向が崩れた群は、125到達後の追尾幅だけでは改善できない。

一方、米国前の追加14逆行は10月23日ナイトの買い1場へ集中していた。時間帯の一般的性質と、同じ場・近接経路で弱い条件を繰り返す問題を分ける。三帯分割だけで安定性が戻るとはしない。

時間帯によって現物市場との結び付き、参加者、量・値幅・価格受容が違い、同じMA・勢い・構造回復の意味が変わる可能性は心理・市場構造の仮説である。2014年データを用いた[JPXの日中/夜間の研究](https://www.jpx.co.jp/english/corporate/research-study/working-paper/b5b4pj000000i468-att/E_Summary_JPX_working_paper_No14.pdf)も注文行動と板の差を分析するが、2026年の三帯別テクニカルの優位を証明しない（2026-11-13確認）。

## 次の入口比較

共通条件、時間帯属性を持つ共通条件、三帯別条件を分けて比較する。5/15/30分の方向/収束、構造回復/突破失敗、勢いの持続/spike、ATR/BBに対する値幅、量を複数役割で使う。時計だけで買い・売り・反転を固定しない。量や値幅を帯別基準化する場合も、当時までの履歴だけを使う。

旧C1全87は固定対照に残す。旧87を必ず保持する追加入口案と、旧信号を当時情報で再判定・置換する案は分ける。153の米国前は旧C1だけでも50%であり、追加だけではこの群の方向・取得位置を直せない。対応q0が結べない旧信号へ、後のq1価格や足から特徴を捏造しない。

全73場で最低1取得という下限は継続し、各小時間帯最低1へは拡張しない。新案の未取得場を未来の最良候補で埋めず、当時の時刻と状態で作動する補完規則を事前固定する。通常/補完の回数・率・損益を両方残す。

## 時計と評価

米国前後は夜間開始日の[NYSE通常開始NY09:30](https://www.nyse.com/trade/hours-calendars)をIANA timezoneで変換する。2026年は[11月1日に夏時間終了](https://www.nist.gov/pml/time-and-frequency-division/popular-links/daylight-saving-time-dst)のため、日本22:30/23:30を切り替える（両資料2026-11-13確認）。これは米国株の通常開始であり、米国先物の取引開始ではない。

160は実取得q1の事後分類。新しい入口の採否では判断q0で帯を決める。旧FARの開始前後15分静観、内部準備、境界返済を三帯ラベルと同時に新導入しない。入口の旧厳密H60と、金融の場末短縮H60/D1返済も区別する。

三帯で別々に最良条件を探すと探索自由度が増える。同じ辞書や候補数だけで公平とせず、探索数・支持場数・成熟時計・過去場適用・前後・場集中を記録する。主出口はまずIFD±125へ固定し、入口改善を確認してから必須利益保護を再比較する。

[具体設計と共有入力](../../study/00160_入口を三時間帯で診断する/次の入口探索の設計.md)を参照。160で実行したのは固定入口の診断までであり、新しい時間帯別入口の成績はまだ出していない。

## 2026-11-14の実行結果

上記の未実行表記は160時点の記録である。その後[161](../../study/00161_三時間帯の入口を共通属性分割で比較する/README.md)で、三帯属性入り・完全分割と共通条件を全73場で実検証した。主Fの先着率は共通60.68%・属性56.64%・帯別51.62%で、今回の二案は改善しなかった。旧151/152/153の指定範囲は同体再現できた。[背景の混在状態と短期再加速](三時間帯だけでなく背景の混在状態を入口で分ける.md)を次の未検証仮説へ残す。160の固定診断値・旧試行・153の一旦達成は変更していない。
