## 何を変え、何が分かったか

[52](定時の価格履歴を追加しても分岐が変わらなかった比較.md)では、追加した価格履歴が学習木に使われなかった。53では参照線を直前の局所帯へ変え、履歴を最初の分岐へ固定した。今回は分岐・採用・成績が変わったが、先着率70%・活動・費用後収益の同時達成にはつながらなかった。

外部調査から、帯の表示期間と反応を判定する期間を分ける必要を確認した。[StockChartsとTA-Libの公式説明の整理](外部再調査/直前の価格帯と反応期間を分ける.md)を踏まえ、前10本の3分足で帯を固定し、その後5本の終値反応を観察した。固定帯・窓長・±5・強制分岐は本研究の独自規約である。

|候補|入力・構造|比較の意味|
|---|---|---|
|H0|旧52の25特徴・深さ4、同46場の保存対照|前回との接続。再fit・市場再生なし|
|B0|旧15特徴＋局所帯幅/ATR・方向別の帯中央距離/ATR、自由な深さ4|価格位置の追加、準備変更、再fitを含む|
|F0|B0と同じ準備/教師、反応旗Zで根を固定し、各子は17列・深さ3|局面を先に分ける構造全体の比較|

Zは、端から±5ptの状態判定で「自方向端への突破が維持されている」又は「反対端から帯内へ復帰した」のORである。中間の価格では直前stateを保持する。両方成立しても1、Z=0も正常な局面として扱う。順行/反転という役割は15分DIとの同方向/逆方向で決まり、Zの名前とは別である。

条件選択では準備済み784枠のうち417枠で少なくとも片方向Z1だった。それでもF0の純採用は201枠にとどまった。局面旗が発生することと、その方向が最高得点になり、支持・技法条件を満たして採用されることは別である。52の「窓内切替あり」と53のZでは定義・参照帯が異なるので、発生割合の単純な改善比較はしない。

F0の選択期間では、純判断で同点98、最高側の技法不足のみ203、得点不足のみ173、両方不足109、採用201だった。基礎・局所帯の未準備は104枠。保有継続による実際の待ちとの違いは運用集計に残す。

**複数手法を採用資格で要求しても、学習した分岐がその資格を満たすとは限らない。** 現方式はまずginiで子木を作り、その後にtrend又はoscを含む複数familyの経路だけを採用する。この順序により、学習で選ばれたprice/vol中心の経路を運用で見送る場合がある。F0で待ちが増えた一因として技法不足を実際に観測したが、資格を外せば改善するという意味ではない。複数手法を必須とする条件は維持する。

## 次に検証する違い

1. **価格経路をまとめる粒度**：自端継続と逆端復帰を別に記述し、上位DIとの関係を含め、どの経路が順行/反転候補になったかを確認する。Z1を一律に有利とせず、Z0を一律に除外もしない。
2. **複数技法の役割を分岐の作り方へ入れる**：学習後に技法不足で落とすだけでなく、背景の方向・短期の勢い・価格反応を使う候補構造を先に定める。具体案は、DI同向/逆向と価格反応を先に分け、それぞれの中で短期の勢い・値幅等を評価する構造である。同じ教師・深さ上限の対照を置き、役割別の適格経路の有無も検査する。採否の閾値を緩めたり、深くして学習率だけを上げたりする対処とは分ける。
3. **新規を選ぶ方向と否定点**：突破維持ならどの戻りで継続を否定するか、反対端復帰なら再び外へ戻ったとき何が失敗したかを、当時の価格で定義する。15分の判定時点で既にその動きが終わっていないかも調べる。
4. **仮250と回収の接続**：実際の同一新規を対応させ、費用後正益から赤字へ戻る経路、追尾幅・床・返済遅延を分ける。将来の峰を知って利確した計算にはしない。

以上は次の仮説であり、切替に成功した規則の発見ではない。新しい条件を試す場合は別試行で固定し、53の学習・モデル・損益を後から変更しない。
