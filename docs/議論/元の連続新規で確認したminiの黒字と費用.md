# 元の連続新規で確認したminiの黒字と費用

2026-11-08。[試行93](../../study/00093_元三手法のmini連続再現と費用/README.md)は、元の三手法の新規通知を連続で約定する基礎比較を行った。mini買売各10枚上限・数量可変、2026-09-21〜10-27の既使用54セッションで、指定手数料後＋2,839,865円、さらに仮定片道5pt滑りを控除して＋2,084,865円だった。359建玉・新規755枚で、未知期間の成績ではない。

以前の黒字を裏付ける記録があり、現在のmini模型でも黒字を確認できた。80の参照保有抽出や87以降のSource生存玉を使う15分移植は元の参照残玉を後から新規取得する構造で、元の初回と取得価格・数量・返済までの距離が違う。今回との差を「15分だから負ける」という一因子だけの結果にせず、元通知、取得、数量、保有上限、保護、期間をそろえて次を比較する。

## 費用の意味

ユーザー指定はmini1枚片道税込38.5円、往復77円。片道5ptの追加滑りはmini1呼値＝価格5円の不利約定を仮定する別感度で、実測値ではない。次正常ラージBBOには気配差と次原行の価格変化が既に含まれ、追加滑りは費用として一度だけ引いた。mini1枚の往復では77円と1,000円、計1,077円になる。

この比較は元の費用0判断が共通なので、同じ約定に費用を分けて控除できる。今後の費用後利益追尾では、費用仮定が起動時刻を変え得る。費用だけの後引き感度と、追尾の実行経路を変えた検証を分ける。

## 原行の順番が成績を変える

元100microの対照にはD−300円・P＋5,000円・U0円の差があった。今回の境界timer→最初の正常原行fillと、元FARの原行内Observeで締切要求→次正常原行fillの違いを調べた。23境界返済の同量で後者の価格差を計算すると、D＋300円・P−5,000円・U0円となり、残った差を説明できた。[価格差診断](../../study/00093_元三手法のmini連続再現と費用/境界1行差の診断.md)

全23件は価格時計が同じで物理行だけが後だった。Uの総額一致も、異なる2価格差の相殺を含む。時刻や総額の一致だけを、注文・約定原行の一致とはしない。保存したNative価格と元gross一致=falseを保持し、完全な代替運転や元全Signal同値の成功を主張しない。
