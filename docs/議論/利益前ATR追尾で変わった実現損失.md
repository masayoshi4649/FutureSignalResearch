# 利益前ATR追尾で変わった実現損失

2026-11-08。[試行98](../../study/00098_実建値からの利益前ATR追尾/README.md)は、同じ入口・数量・利益後H0を維持し、利益前だけ実取得時ATRの固定幅で追尾した。金融・全経路独立照合・保存会計は54既使用場、24口座で完了。Viewer1296資源・98,505照合も差0で、最終報告を保存した。

## 確認したこと

主条件はmini100円/pt、片道税込38.5円、追加滑りなしC0・strict後続正常原行D0。各側10枚上限の可変数量、5分新規と開始30分見送り、場内完結。H0は費用後の残玉単価uがstrict正になったとき、未予約残への返済を要求する。利益前幅はATR0.5/1倍を20〜125ptへ制限し、未知125を永久固定した。

G0/AB、追加滑り0/5pt片道、追加価格時計遅延0/1秒の全16比較で、初期追尾追加後の純額が悪化した。各比較でSource出生・要求・取得時刻/Index/物理行/価格・初期量は全件同一で、取得変更や片側だけの参加は0。今回は実入口が同じ取引の退出差である。全ての個別取引が悪化したという意味ではない。

主G0では0.5倍により最終黒字から最終赤字へ変わった実取引が29玉、1倍では8玉。赤字から黒字は各0玉だった。これは同じ入口を持つ二つの戦略の再生で成立した最終額の比較であり、決済後に持っていれば得られた仮想利益を計算した値ではない。

主G0のu正益後赤字は追加なし45/253玉、0.5倍37/216玉、1倍44/244玉。正益を観測する前に退出すると分母自体が変わるため、赤字件数が減っただけでは利益後保護の改善と判定しない。u未観測の最終赤字は49→86→58玉となった。同じ49玉の損失がそのまま変わったという分解でもない。

場内DDが小さくなる条件があっても、純額と連結DDが同時に改善したとは限らない。ABも同じ6出生の反復であり、費用/遅延/幅の反復を独立標本に数えない。[全24成績](../../study/00098_実建値からの利益前ATR追尾/成果物/結果.md)と[実現比較の正本](../../study/00098_実建値からの利益前ATR追尾/成果物/結果.json)を参照する。

## 次の判断へどうつなぐか

[FidelityのATR教材](https://www.fidelity.com/learning-center/trading-investing/technical-analysis/technical-indicator-guide/atr)は値幅に合わせた停止幅の一般的な理由を示すが、方向や今回の倍率の有効性を保証しない。今回の結果から、ATR幅だけで継続可能な押戻しと失敗を判別できたとは言えない。

次は、背景のEMA配置と、現在のMACD改善・板数量の同意を分けて入口へ使う案を独立に調べる。平均に方向が残っていても、新規に入る時点では勢いが衰えている場合を区別したい。背景側への再参加、調整での利食い、逆側の手仕舞い等は心理の仮説であり、主体の意図を板から断定しない。

この入口候補はまだ市場損益を算出していない。旧保存候補の部分集合で正益を観測したことを新戦略の勝率とせず、現在候補・数量・容量を含めた全動的再生が必要である。今回の結果を見てATR幅を細かく探し直したり、入口条件を98へ追記したりしない。

支持の保持・否定・回復失敗による反転判別も、順行側の減速だけと混同せず別途扱う。[平均方向と勢い・板](平均方向と現在の勢いと板が食い違うとき.md)、[複数指標の役割](外部再調査/複数指標の役割と情報の重複.md)、[実現損益中心の評価](実現損益を中心に評価する方針.md)を参照する。未参加や退出後の仮想利益・回収率は評価しない。安定収益は未確認で研究を継続する。
