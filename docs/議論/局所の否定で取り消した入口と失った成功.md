# 局所の否定で取り消した入口と失った成功

確認日：2026-11-06。[試行68](../../study/00068_発動前の反対端否定で条件を取り消す/README.md)の結果後の知見。条件の正本は[設定と結果](../../study/00068_発動前の反対端否定で条件を取り消す/設定と結果.md)、数値の正本は[結果JSON](../../study/00068_発動前の反対端否定で条件を取り消す/結果.json)。全66場は既使用で、新たな未見成績ではない。

**単一3分足の反対端を否定線として加えても、支持付き先着70%・費用後収益・待ち50%以下の目標は達成しなかった。** 主候補N0の条件選択では逆行候補を除外したが、成功候補も失い、残った入口の先着率と平均損益は改善しなかった。価格による取消という操作の正しさと、その線が適切な前提を表すことを分ける。

## 何を同じにして比べたか

旧67のG0/G1と新N0/N1は、複数技法の60特徴、旧65三木・回収集計、純方向・役割・ATR・追尾幅を共用する。新しい学習・特徴算術・予測はない。定時に凍結する最新公開3分足の高安、将来Lastのstrict突破、次定時までの寿命、取得遅延と費用、利益・損失の連続追尾も同じ。

新しく加えたのは、買いLast<=安値／売りLast>=高値による発動前取消だけ。設定時なら未登録の待ち、監視中なら登録取消とし、その枠で復活・反対新規はしない。約定待ちへ発動した後と保有中の処理は変えない。正常BBO・有限正Lastで観測し、観測不足の扱いは取消と区別する。N1は旧G1と同じく過去の回収平均正を加えた参考条件であり、条件入口を新たに学習した候補ではない。

micro1枚の代理評価、往復手数料22円と片道滑り5pt、合計122円を控除した値。場内完結・返済待機を含む一建玉の結果で、今回の新候補に品質注意はない。

条件選択の総額差＋4,354円は、共通元定時80取引の−17,260円が新旧同じで、旧だけの62取引−4,764円がなくなり、新だけの5取引−410円が加わった結果。共通取引は識別子以外の全属性も一致した。新しい5取引は、前の取引を取り消して一建玉の占有が変わったことを含む。独立仮約定の包含関係を、実運用の包含へ置き換えない。

保有は非待ち。主待ちは全予定枠に対するWAIT、保守上限はWAIT・判定不能・登録後の実新規なしの合計。条件選択の主待ちは旧61.37%から新67.57%、保守は81.53%から89.64%に悪化した。未発動監視を建玉と同じ活動へ数えない。

## 含み益の赤字化は残った

N0条件選択の利益旗53件中38件＝71.70%が費用後赤字だった。内訳は新規と同値の価格で返済23、価格不利2、粗益は正だが費用を回収できず13。旧G0は95件中71件＝74.74%。時系列では旧46/61＝75.41%から新23/29＝79.31%へ悪化しており、一貫した保護率改善ではない。

共通元定時80取引の出口と回収は同じなので、取消による旗後赤字の件数減少を追尾自体の改善としない。現在費用後含み益が正になった瞬間から最低新規価格を守る規約は維持したが、名目の新規価格への返済では費用が残る。利益旗の起動、保護線、返済要求、その後のBBO約定を分けて読む。

## 心理の仮説と次に区別するもの

[並行した外部調査](外部再調査/局所の否定と広い構造の継続を分ける.md)では、局所の安値・高値を一度越えても広い構造では調整が続く説明を確認した。これは今回の成績を予言した資料ではなく、68の固定後に追加した次の問いである。実際の参加者の意図や建玉は今回の板・足から確定できない。

| 観測 | 心理の仮説 | 当時の判別に必要な比較 |
| --- | --- | --- |
| 3分足の反対端を越える | 短期の継続期待が崩れた | 上位の押し戻り構造も崩れたか、それとも局所の試しだけか |
| 局所の反対端を試し、再び元の方向へ進む | 逆側の進行が続かず、元方向への参加が再開した | 価格回復に勢いと量が伴うか。完成後の成功例だけを抜き出さない |
| 突破後も少しの利益から返される | 発動点で追随が尽きた、又は通常の押し戻りが追尾幅を超えた | 入口の価格段階と、同じ入口の保護・回収の差を別比較にする |

次は否定条件の追加だけを続けず、**上位の方向・構造、短期の再開、量と価格進行を役割別に組み合わせ、順行・反転・待機を当時判別する候補**へ戻す。狭い3分足の端を広い構造の否定と同一視しない。取消後の再参加は次の定時の新判断として扱う。将来の反転成功を見て取消を無効化しない。

また、旧木の教師は即時入口であり、遅延発動・取消後の入口への転用が適切かは別の問題である。新しい入口条件で学習する場合には、新しいラベルと時系列分割を事前固定する。旧採用488候補だけで教師を作ると旧選別へ偏るため、基礎準備済みの全定時枠・両方向から条件注文を独立定義する案を検討する。未発動という確定した無取引、観測不足、約定後の未確定を分け、無取引を125先着へ置き換えない。先着と回収の両方が評価開始より前に確定した教師だけを使い、可知集合が変わる場合は共通集合の対照も必要になる。これは次候補の設計上の論点で、まだ固定した学習方法ではない。

技法側は、上位DI・ADXによる方向と強弱、保持水準による場所、短期ストキャスティクス・終値進行による応答、調整段階の相対量と価格進行による裏付けを別役割として読む。教師の変更で、反転の資格や現在の形の成立まで自動的に回復したとは扱わない。過去の平均正だけで現在の条件入口の優位を保証しない。全予定分母の待ち率・取引数・支持・費用を同時に残し、入口の選別だけで目標へ近づいたことにしない。
