## 単足の強さや固定水準とは別の発動を作った

前足pの逆色実体を現在足jの実体が包んで終わった場面を、新しい価格Pにした。買いは前足陰線・現足陽線・O_j≤C_p・C_j>O_p、売りは完全鏡像。ヒゲ全体の包み、実体比、CLV、固定高安の突破は要求しない。[個別教科書](../technical-analysis/指標/二足の実体包み.md)に、一般的な包み足と研究上の等号・先行方向・長さ規約の違い、心理の仮説、研究要旨の適用範囲を整理した。

二足の形が分かるjの確定公開後にだけ要求する。p/jは同場の隣接した完全3分公開足・有効OHLC・missing0、p.key<j.key、p.end=j.start、両confirm≥end。45の水準crossに用いたj.end>p.confirmは持ち込まない。jの形成開始前からpを知っていたことを仮定せず、j判断時に両足が利用できる観測である。

P成立なら実方向の終値前足差は自動で正になるため、別の賛成票と数えない。MACDヒスト一足差は過去EMA状態を含み、P成立でも逆向きになる人工反例を確認した。この非自動条件を共通の勢いとして使った。両者も平均も同価格由来で、統計的に独立した票ではない。

|案|採用条件|集合の名称|純要求数・学習/選択/既使用後続|
|---|---|---|---:|
|B0|二実体P＋実方向MACDヒスト差strict正＋共通ATR/時間|反転|372 / 270 / 27|
|B1|B0＋現足を除く前二SMA20の共通準備だけ|反転|337 / 239 / 25|

平均はM_p=mean(C[j−20..j−1])、M_(p−1)=mean(C[j−21..j−2])。過去21終値がそろう最速j21、現在を含め22足で共通準備になる。進行dM=M_p−M_(p−1)、位置dP=C_j−M_pは元floatからのFractionで判定する。jを平均へ入れないが、位置には現在jの終値を使う。dM=(C_p−C[j−21])/20には古い足の脱落も含まれる。

実sideをsとし、s*dM>0かつs*dP>0ならT順行、両方<0ならR反転、他はWAIT。実sideを変更しない。B0/B1の反転は直前実体との関係、B2の反転は平均背景との関係であり、同じ意味ではない。実評価する群はB0反転・B1反転・B2順行・B2反転の4群で、空のB0/B1順行を実評価に数えない。

## 正益化と、250ptの回収は別問題

現行XFは、現在正常返済BBOによる粗含み益円−122円>0で起動する。現jの入口ATRから固定したDでMFE−Dを追い、最低名目entry床・非緩和・pending後凍結・最初適格気配への要求遅延を維持する。名目床は費用後同値でも、同値価格での約定保証でもない。

## 再利用する知見と次の問い

二足の反対実体の包含、勢い変化、平均位置/進行には再現可能な定義を付けられるが、その分類が有利な入口の識別に成功するとは限らない。今回のT/R/WAITは、先着率を両期で改善しなかった。価格の拒絶・反転や押し戻りの再開があったという心理の説明も仮説に留め、注文の意図や追加参加余力を測った事実とはしない。

計算では全12,952足の27列・全1,068価格P・三採否・1,745新caseを別実装で確認した。生ATR200足・中心化ヒスト47足の表現差はいずれも最大2.842170943040401e−14。数値だけのabs1e−10/rel0許容と、SMA全分数・時点・H差符号・準備・全採否の厳密差0、検算済み旧29正本値による全内容SHA一致を分ける。新しい数値blobや旧入口/label/controlの複製は作っていない。

次は同時点で形状・勢い・平均をそろえる条件だけでなく、上位の背景を先に知る→下位の逆行波→回復→後続価格での再開/明示的失敗、という時間順序を持つ複合条件を事前に検討する。既存23等の再テスト機械との重複、数量指標を足す場合の価格変化との冗長性・観測数量の品質も先に確認する。46の除外群や損失をそのまま反転発動へ変えず、具体条件・効果は未検証として次試行へ分ける。
