# 逆行200ptより先に順行400ptへ届く入口

作成・資料確認日：2026-11-01。状態：[試行00004](../../study/00004_逆行200ptと順行400ptの入口分析/README.md)で探索・独立照合を実施。以下は設計と解釈の整理、条件・全結果の正本は試行に置く。

まずNK225だけを対象に、**入口から200pt以上逆行する前に、400pt以上順行したか**を調べる。ptは先物価格の差であり、円損益やティック数ではない。TOPIXへ同じ200/400を移用することは今回の前提にしない。

[議論の目次](README.md) / [入力と数量の監査](入力と数量の監査.md) / [前回の複合判断](複合判断の候補と検証方針.md)

## 1. 問いを入口だけに絞る

今回は、同じ入口に対して固定200/400ptの先着ラベルを作り、チャート条件で選んだ入口にどのような違いがあるかを見る。通常のMA決済、ATR利確、追尾決済を同時に変える比較にはしない。

「後から400pt動いた場面」の始点を目視で選ぶのではなく、実際にその時点までに利用できた確定足から候補を出す。旧60セッションは、前の試行で追加確認に使った三場も含めて**全て再利用探索**とする。今回の結果に対する新しい未使用評価期間とは呼ばない。

同じ5分時点・同じ売買方向に対してラベルは一度だけ生成する。六つの候補群は、その共通イベントを採用するかどうかの旗を持ち、候補ごとに別の将来経路や約定価格を与えない。

## 2. 共通の判断時点と準備

5分足の確定を確認できる最初の観測を判断時点とし、買い・売り双方の仮想入口を用意する。5分足の終値と、新規を仮定する気配価格は別である。判断から新規までの待機・失効・正常板条件は試行の条件ファイルで固定し、結果を見て変更しない。

全候補群を次の同じ準備範囲で比較する。

- 5・15・30分の確定足からEMA20、5分足からワイルダー型ATR14等を準備する。方向の傾きには前のEMAも必要となる。
- 15・30分足は、当セッションでそれぞれ一つ以上の完全足が確定していることを要求する。前セッションの最終上位足を、当セッションの方向確認の代わりにしない。
- 直前6本の高安は同じセッションの確定5分足から作り、今足を含めない。欠枠を前値の架空足で補わない。
- 前足時点の正規化ATRと、その時点より前60本の比較値まで準備する。初期化・欠損・限月変更・履歴継続は全群で同じ規則にする。
- 押し戻りの「前5分時点」は同場の直前足のスナップショットを参照する。当時有効だった上位足だけを保存し、後に確定した15・30分足を埋め戻さない。

たとえば09:10の判断に、09:15までの15分足の最終高安・終値を使ってはならない。EMAの履歴を継続することと、未確定・古い上位足を現在の確定情報とすることを区別する。[上位足と下位足](../technical-analysis/組み合わせ/上位足と下位足.md)

## 3. 固定する六つの候補群

各足幅の「上方向」は、終値がEMA20より上、かつEMA20がその足幅の前値より上であること。「下方向」は両方の不等号を反対にしたものとする。等号や位置と傾きの不一致は方向なしとする。

| 群 | 買いの入口条件 | どの追加情報を見るか |
| --- | --- | --- |
| ① 無条件・両方向 | 共通準備と執行条件だけで買い・売り双方を評価 | 他の群の対照。チャートによる方向選別をしない |
| ② 5分方向 | 確定5分足が上方向 | 直近の方向だけで絞った効果 |
| ③ 5・15・30分方向整合 | 三つの足幅が全て上方向 | 上位足方向の追加。三つの独立した市場の確認とは考えない |
| ④ 整合＋直前6本突破 | ③に加え、今足終値が直前6本の最高値を厳密に上回る | 方向が揃う状態から価格帯を離れる発動 |
| ⑤ 押し戻り後の復帰 | 15・30分が前5分時点と現在の両方で上方向。前5分終値≤前EMA20から、今5分終値>今EMA20へ復帰 | 上位方向の中で一度逆行した後の再開。5分EMAの上向き自体は追加要求しない |
| ⑥ 整合＋収縮拡大突破 | ③と直前6本突破に加え、前足の正規化ATRが当時の過去中央値以下、今足TRが前ATRより大きい | 過去の比較的静かな状態と、その後の値幅拡大を時点で分ける |

②〜⑥の売りは方向と価格の不等号を反対にする。⑤では前5分終値≥前EMA20から今終値<今EMA20への復帰を使う。⑥の値幅条件自体は上下に共通であり、売りだから小さいTRを要求することはしない。

①②③を対照として残すことで、方向を絞っただけの違いと、突破・復帰・収縮拡大を追加した違いを区別する。六群の結果を見て、RSIや出来高の条件をさらに追加することは今回の固定比較に含めない。

⑥の計算時点を、5分足の添字 `t`、ATR14を `A_t`、終値を `C_t` として明示すると次のとおり。

```text
q_t = A_t / C_t

収縮側の条件:
q_(t−1) ≤ median(q_(t−61), …, q_(t−2))

拡大側の条件:
TR_t > A_(t−1)
```

過去中央値は前足時点で利用可能な60本から作る。今足の変化を含む中央値で、過去の収縮を判定し直さない。この条件は前足の値幅水準を使う簡易版であり、「長期間スクイーズが続いた」ことまで要求する定義ではない。現在のATR比が低いことだけを要求した前回のB因子とも異なる。

## 4. 200/400ptの先着ラベル

新規のモデル価格を `E` とする。買いはAskで入り、以後のBidで返済可能な価格差を観測する。売りはBidで入り、以後のAskで観測する。

```text
買いの価格差: Bid − E
売りの価格差: E − Ask
```

新規以降の正常板を観測順に追い、次のいずれかでラベルを確定する。現在値Lastだけの順行・逆行や、足の高安だけで到達の前後を決めない。

| ラベル | 判定 |
| --- | --- |
| 順行先着 | 価格差が＋400pt以上へ、−200pt以下より先に到達 |
| 逆行先着 | 価格差が−200pt以下へ、＋400pt以上より先に到達 |
| 期限未達 | 必要な観測を確認でき、期限までにどちらへも到達しない |
| 不明 | 判定前の観測不足によって、到達順を確定できない |
| 未約定 | 共通の執行条件内で新規価格を与えられない。約定済み入口の分母へ混ぜない |

期限はデイ15:35、ナイト翌05:50とし、**期限ちょうどの観測も含める**。順行先着を確認した後に200pt以上逆行しても、その入口の成功判定は取り消さない。成功前の順序を問う分析であり、セッション全体の最大逆行を後から条件にする分析ではない。

判定前に正常板の観測が300秒を超えて空いた場合、その空白中に反対側の水準へ先に到達した可能性を除けない。空白後に見えた到達で成功・失敗を確定せず、不明にする。既に空白前に確定したラベルは維持する。期限までの入力を確認する前にEOFとなる観測不足も、不明として期限未達と区別する。

この300秒は今回の観測モデルで固定する基準であり、300秒以下なら通信欠落がないという証明ではない。価格時計と物理行順も、受信時計や取引所の全約定順を完全に復元するものではない。[時計と入力の限界](入力と数量の監査.md)

## 5. 成功率と、入口で見える尺度

順行先着を `S`、逆行先着を `F`、期限未達を `T`、不明を `U` とする。未約定は別に件数を残し、約定した仮想入口について二つの率を併記する。

```text
成功 / 全約定        = S / (S + F + T + U)
成功 / 判定可能入口  = S / (S + F + T)
```

一つ目は不明を成功に数えない観測モデル内の下限であり、統計的な信頼下限ではない。二つ目は不明を除くため、不明率と一緒に読む。`S/(S+F)` だけでは、＋400先着を確認できなかった期限未達・観測不足の候補も分母から落としてしまうので、それだけで判断しない。分母ゼロは率を計算不能として表示する。

入口時点で既知の値を固定した層で診断する。境界は実行前に条件へ記録し、結果を見て有利な区間だけを入口条件へ変更しない。

| 診断する値 | 読みたいことと限界 |
| --- | --- |
| 期限までの残り分 | 同じ400ptでも観測できる時間が異なる。終了後の価格を持ち込まない |
| `400/A_t`、`200/A_t` | 最近の5分値幅に対して目標・逆行幅がどれだけ大きいか。何本で届くかを示す式ではない |
| `TR_t/A_(t−1)` | 発動足が過去の平均的な値幅に対してどれだけ動いたか。発動前と発動時を混同しない |
| RSI・観測数量 | 勢いの配分や活動量で結果が違うかを見る補助診断。今回は許可条件へ追加しない |

ATRが小さいと200pt逆行を避けやすい可能性があっても、400pt到達までの余地が不足する可能性もある。高ATRも方向を保証しない。ATR倍率、RSI、数量、残り時間の層別から得た特徴を、そのまま最適な入口として採用しない。計算不能や数量品質の限界も欠測として区別する。

## 6. 根拠・心理の仮説・反例を分ける

資料は分析の考え方を支える。EMA20、足幅、6本、60本、固定200/400ptの収益性や到達率を実証するものではない。⑥はATRで具体化した本研究の設計であり、原典のBBスクイーズをそのまま再現した手法ではない。

| 候補 | 心理・注文の説明候補 | 同じ形でも失敗する説明 |
| --- | --- | --- |
| 方向整合・突破 | 方向への追随や、反対建玉の返済が続く可能性 | 入口の確認が遅れた後の反転、価格帯を出てすぐ戻る動き |
| 押し戻り復帰 | 長めの方向が続く中で、短期の利益確定後に取引が再開する可能性 | 復帰に見えた動きが転換途中の戻りである、復帰前に大きく順行済み |
| 収縮から拡大 | 狭い価格帯を離れた追随や、気配の薄さで動きが広がる可能性 | 方向のない往復、ニュースによる飛越え、拡大後すぐ反転する偽突破 |

これらの参加者の動機を、OHLCやATRだけから実測したとは言わない。低ボラはエネルギーの蓄積を証明せず、出来高増も取引人数や買い意欲だけを測らない。[市場心理の教科書](../technical-analysis/市場心理/README.md)

## 7. 入口イベントと実運用の違い

今回は各仮想入口を、別の入口の建玉制約から切り離して評価する。同じセッションの近接時点、買いと売り、六群の間で経路が重なり、仮想保有も重複する。計算上は別イベントでも、統計的に独立した多数の取引ではない。

件数だけでなく、セッション別の結果と候補が出ない場も残す。成功が一部の大きく動いた場へ集中していないか、残り時間や値幅尺度の違いによる見かけの差でないかを確認する。候補数・層別数・定義変更も記録する。

成功率やイベントの価格差を合算した値は、同時建玉数、次の入口への制約、費用、注文受付・滑り・部分約定等を持つ実運用の損益ではない。ラージBBOによる観測を、micro・miniの約定実績とも呼ばない。今回の目的は、次に詳しく検証すべき入口の状態と反例を見つけることである。

## 8. 初回の入口分析で得た問い

NK225の旧60場を[00004](../../study/00004_逆行200ptと順行400ptの入口分析/README.md)で分析し、共通準備が揃った50場から10,588候補を生成した。押し戻り復帰の順行先着は54/192約定候補＝28.125%で、逆行先着95・期限未達23・観測不足20も残った。確実に200pt逆行を避けられる条件とはいえない。

同じ時刻に買売半々を選んだ対照は22.65625%で、選択方向との差は全体で＋5.46875ポイント。ただし前半＋9.65、後半＋0.83、既使用末尾3場−5.56ポイントへ縮小・反転した。これは独立した対照による因果効果ではなく、次の未見期間で確認する候補にとどめる。

固定した残り時間層では、復帰の180分以上が51/141、60〜180分未満が3/42、60分未満が0/9だった。400pt動く時間余地を入口から分けて考える必要があるが、この層を見て新しい時間制限を採用・再評価した意味ではない。[固定層別](../../study/00004_逆行200ptと順行400ptの入口分析/固定層別.csv)

研究の次の問いは、上位方向だけで入るより、短期の戻りを待つことに追加価値があるか、200ptの中に価格構造の否定点が収まるか、400pt先の価格帯と時間余地をどう定義するか。後二つの価格構造条件は今回の六群では未検証である。成功した場所を後から入口に選び直さず、変更時は別試行と新しい評価期間へ送る。
