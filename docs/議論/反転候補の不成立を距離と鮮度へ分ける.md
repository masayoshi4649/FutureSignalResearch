# 反転候補の不成立を距離と鮮度へ分ける

確認日：2026-11-08。[反転構造と注文候補の時計](反転構造と注文候補の時計を分ける.md)で未確定とした条件交差を、既存の固定標本について補足する。旧記事・技法・金融条件は変更していない。

対象は固定97の主口座 `H0_B5Q_P0_C0_D0` で実取得した302候補の**要求時入力**。固定96の公開関数へ本名Bで渡し、既存のAB20checkと保存査定にも照合した。損益・u群・退出値は読取型から除外し、新取引や閾値緩和の収支は計算していない。

## 構造・数量が成立しても、取得位置は別の条件

固定3足形状・上位15分EMAの逆背景・現在量支持が全て成立する2候補は、以下の理由でB全体が成立しなかった。ここでいう形状成立は、反転の成功や利益を意味しない。

|要求枠（JST）|方向|既知不成立|必要未知|最終判断|
|---|---|---|---|---|
|2026-10-14 Day 14:55|売|取得位置1.275179ATR|なし|既知不成立|
|2026-10-22 Night 23:10|売|取得位置1.146613ATR|現在価格時計：16秒|既知不成立|

固定条件の距離は、候補方向を `s=±1`、買いAsk/売りBidを `e` として `d=s(e−現在EMA8_3)/ATR3`。`0<=d<=1` を要求し、**0と1の同値を許す**。これは距離checkの境界であり、B全条件の同値を一律に許す意味ではない。Bの固定線 `L=a時点EMA8_3` と、取得位置で使う現在のEMA8も別である。

両件はEMAの逆側にいたのではなく、候補方向側へ現在EMA8から1ATRを超えて離れていた。DayはBid68,210・EMA8約68,297.134・ATR約68.330、NightはBid63,300・EMA8約63,398.298・ATR約85.729だった。形状・勢い・数量の条件を通っても、距離条件との交差で拒否されることを示す。

## 鮮度の未知と、既知の否定を混ぜない

Dayの参照価格は要求枠の5秒前で、価格時計checkは成立。Nightは16秒前であり、固定の15秒以内を満たす既知性がなく `Known=false` となった。これは保存された市場価格時計と判断枠の差であって、**実受信の通信劣化・ネットワーク遅延を測定した証拠ではない**。気配を判断枠の時刻へ付け替えてもいない。

NightでもBBOとE08数量支持自体は既知だった。全17checkのうち、Dayは16成立・1既知不成立、Nightは15成立・1既知不成立・1未知。固定ANDは既知不成立を優先するため、Nightも最終判断は既知不成立となる。未知の値を0や反対支持へ補完した結果ではない。

この2件ではMACD増分、終値とEMA8、スパイク警戒、現在量、上位逆背景と固定3足条件は成立している。しかし「距離条件を外せば有効な反転手法になる」とは分からない。2候補の損益・勝敗は調べておらず、閾値の有効性や主体の投げ・吸収・意図を価格図形から断定しない。

## 保存した根拠と限界

54正式gzipと既存Native本文の指紋、302実入口とSourceの一意性、AB20check、保存査定2,416件の一致を確認した。費用・遅延の同じ査定を独立した市場事例へ水増ししない。全B checkの `Known/Passed/Reason` と当時入力は[結果](検討資料/反転Bの2候補/結果.json)、事前固定した範囲は[計画](検討資料/反転Bの2候補/計画.json)、前後指紋は[確認](検討資料/反転Bの2候補/確認.json)に本文同体で保存した。全302のContext・check本文は複製せず、再現に必要なID/時刻・20文字の状態・入力指紋だけを[小型索引](検討資料/反転Bの2候補/再現用入口索引.json)へ保存した。

この補足は固定標本の条件交差の説明であり、市場全体の反転可用性や因果効果ではない。[旧記事](反転構造と注文候補の時計を分ける.md)のとおり、Bには「3足ともSource出生後」という条件はない。将来全て出生後に確認する案の360秒対300秒という時計制約を、今回の拒否原因へ置き換えない。
