# 突破の再テストを数量加重終値位置で判別する

確認日2026-11-05。[試行42](../../study/00042_突破再テストと数量加重終値位置/README.md)・[設定と結果](../../study/00042_突破再テストと数量加重終値位置/設定と結果.md)・[保存診断](../../study/00042_突破再テストと数量加重終値位置/対応診断.json)に基づく。全66場は既使用の追加開発であり、未使用期間の実証ではない。条件の正本は試行へ置く。

## どういう情報で切り替えたか

最初の3分終値突破bで、直前20本の高安R/Lと境界Bを固定する。まだ注文せず、後続の最初の**対象足**再テストjで価格と当時のMACDの勢いを合わせる。継続が不成立だから反転する、という補集合の売買にはしない。

|構造|jで初めて分かる価格条件|実方向と扱い|
|---|---|---|
|T|元side×(C_j−B)>0|突破側の外側を維持、元方向の順行候補|
|R|L<C_j<R strict|旧範囲への明示的帰還、逆方向の反転候補|
|WAIT|B等号等|一回消費して待機|
|先取消|反対端へ終値が到達・飛越|反転へ補完せず親を終了|

T/Rとも実side×jのMACDヒスト一足差>0を要求するA0を基準に、CMF21準備A1、実side×CMF21>0のA2を追加した。集合名は「切替」、実建玉の役割は順行/反転。売買は符号反転した同じ条件、出口は全3XFである。旧41の登録へANDを追加した比較ではなく、新母集団・新要求時刻で全先着を計算した。

[CMF](../technical-analysis/指標/CMF.md)は、複数足のCLVを観測数量で加重した平均である。現在の水準が実方向に正かを使い、上昇/低下、クロス待ち、次の都合のよい再テストへの取り直しは加えない。準備には当足含む同場21連続公開完全足、全q基準完全/有限非負、全幅正、総q正を要求する。0量は有効、零幅/総q0は未定義。数量不完全はCMF窓だけを切り、価格の親監視を取り消さない。

## 時計と一回消費を先に固定する

ヒゲを使うjは `start_j>b.confirm` かつ公開keyがbより後であることを要求した。通常b+1は公開前から形成されていたので対象外だが、6足寿命の年齢1には数える。最短b+2から6足までの、最初の対象足touchだけを消費する。「物理的な最初の戻り」を必ず捉える規約ではない。

全体一監視・同場used(s,B)で再登録を抑止し、親の消費/取消/満了同足には新登録しない。実建玉とは独立に純監視を進め、保有中に抑止された新規を空き時刻へ延期しない。jで役割が変わっても保有中の自動ドテンは行わない。

Rのb→jは学習中央値364秒、選択362秒。元突破方向の終値差は両期中央値−70ptだった。これはbとjの確定終値の差で、BBOで取得した改善額や、新規後の利益ではない。Tの同差中央値は両期0ptで、外側維持という分類はb終値からの上昇を意味しない。未発動親の先着は補算せず、待機中の値幅をj新規後のMFEへ加えない。主の30分間引き時計はj、bは対応診断だけに使った。

## CMFは独立した数量の票か

同じ21足で単位量にしたCLV平均との実方向符号は、A1要求の学習24/106、選択15/96、後続1/9件で異なった。今回、数量加重が符号を変える例はあったが、それが収益を改善したという比較ではない。単位量による別運用は実行していない。

全21量が同じ正量ならCMFはCLV平均に一致するが、今回その十分条件を満たしたA1要求は0件だった。等量でなくても符号は一致し得るため、0件を「全て独立した数量情報」と解釈しない。CMFは観測差分量で加重した足内位置であり、真の資金流入や積極売買の観測ではない。

## 利益保護後の赤字と仮250は分ける

固定XFは、現在正常返済BBOでの実side×(mark−entry)×10−122円>0strictで一度起動する。参照は手数料22円と想定追加5pt/片、新規要求j時点のATR固定D、MFE−D、最低名目entry床、非緩和、pending凍結を維持した。費用感応0/5/10で起動参照を変えない。名目床は費用後同値や遅延後の同値約定を保証しない。

A2選択の対応仮250成功12件は全て仮判定より前に実返済し、実保有MFE250は0だった。起動28件中、基準費用で赤字だった9件は名目同値7件と不利返済2件。仮の大目標到達と実回収は別で、追尾を外せば同じ参加で12成功になるとはしない。後続の2件は実保有MFE250へ届いているが、この少数を一般化しない。

## 再現の責任と次の問い

全12,952足の原8列価格/Q/ATR/中心化MACD、別手順の登録区間走査、全CMF精密値・全採否を照合した。独立ATR200足/ヒスト47足の最大2.842170943040401e−14の表現差は許容するが、差符号/採否のstrict不一致は0。最終人工21/21、独立準備2,702,516、状態3,349,842、追尾405,121、会計106,119、保存診断65,809項目は全て差0だった。538新case、198場候補、482完結、3,798追尾ログ、Viewer198資源と3代表へ接続した。検査件数は収益の標本数ではない。

最終足に登録して即場末取消となる境界も、登録actionへ出典を一回保存し、正式5gzipから全親を復元できる。旧422固定と旧カタログは保持し、CMF専用V06を加えた[版4](手法と時間スケールの汎用表_版4.md)を新規保存した。ラージBBO・価格時計+1秒代理は実microの数量/キュー/受信遅延を保証しない。

次の問いは、CMFの「現在の水準」と「今の足による変化」が継続/反転でどう違うかである。比の変化には当足だけでなく古い足の脱落も入るので、共通現前準備と当足寄与/脱落寄与を先に定義して比較する候補を検討する。今回の損失原因がCMFの遅れだったとは未確認。逆CMFから自動反転せず、明示的なT/R価格発動と待機を維持し、条件・効果を未検証として次試行へ分ける。
