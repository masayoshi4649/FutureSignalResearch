# 中期MACDの同調を固定入口へ移した結果

全場最低1取得は固定Source上で満たしたが、主副とも70%未達。既知IFD76/未知3、金額は独立mini1枚・往復77円と追加1,000円のC5代用であり、全79件の口座収支ではない。H0は前48場64.86%・後25場55%と、両方でT8を下回った。全期間は既使用で、未知期の再現を示さない。

確認された事実は「この取得集合へこの符号条件を加えても改善しなかった」。129の別出生集合で見た15分Histの関連を旧79取得へそのまま移せなかった。方向と勢いを別に記録する必要は残る一方、価格から派生するMAとMACDの同調を独立の賛成票や継続の保証にしない。条件を多く揃えること自体はエッジの証明ではない。

心理の仮説は、上位方向への参加者が残り、中期の勢いも回復すれば継続しやすい、というものだった。しかし同調は進行済みの伸びや反転前の強い動きとも両立し得る。今回の成績だけでそのどちらが原因かは実証していない。個別の方向・位置・spread・時計・品質の診断と、次の切替条件は新試行へ分ける。

今回の切替は同一時刻の保存実正逆BBOによる方向診断で、逆を1−pとせず、主副の式・時計・全場を金融前に固定した。自然出生の生成、逆注文のcap/I/TTL、実mini、追尾を再構築していない。[結果と限界](../../study/00131_中期MACDの位相で複合入口の方向を切り替える/結果と限界.md)、[CSV](../../outputs/01a1889f-f2af-7943-a047-543275ee9ed2/131既存入口CSV/README.md)、[独立検算](../../study/00131_中期MACDの位相で複合入口の方向を切り替える/検査/独立数値検算.md)から母集団と分母を確認できる。

一般的な説明と今回の成績は区別する。[StockCharts Moving Momentum](https://chartschool.stockcharts.com/table-of-contents/trading-strategies-and-models/trading-strategies/moving-momentum)は方向・押戻し・回復確認を段階化する教材であり、本案の70%を根拠付けない。[MACD-Histogram](https://chartschool.stockcharts.com/table-of-contents/technical-indicators-and-overlays/technical-indicators/macd-histogram)の符号と拡大/収縮も別の状態である（確認日2026-11-11、金融前に調査済み）。今回の案は不採用として固定し、より良い条件へ結果後に書き換えない。
