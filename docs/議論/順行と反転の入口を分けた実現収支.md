# 順行と反転の入口を分けた比較で確認したこと

2026-11-10。[試行114](../../study/00114_順行と反転の取得確認を分ける/README.md)の全70場/840会計・同入口12対照を独立照合し、正式保存・CSV再読・Viewerの840一覧ID/11月06日夜24資源のHTTP照合まで完了した。全840資源のHTTP取得や描画確認ではない。

## 一般説明と心理の仮説

Tは3分EMA8/21の配置・両傾き・Close対fast・MACD-Histの順方向水準が揃う状態。Rは逆配置が残る中で、Closeがfastを奪還し、fast傾きとHist増分が改善する出来事である。Histの正水準と増分は別で、どちらもMACD本体のゼロや価格転換の確定ではない。[市場前の一次資料確認](外部再調査/順行の水準と反転の回復イベントを分ける.md)を参照する。

配置が揃えば順方向の参加者が優勢、奪還なら逆側の圧力が弱まった、という説明は心理の仮説である。参加者の意図や吸収を実測していない。MAとMACDは価格履歴が重なるため独立な確率証拠へ数えず、Rの奪還だけで持続的反転が完成したとも扱わない。

## 本研究で確認した事実

共通P100保護のまま元Source入口A0、順行T、T又はRのTRを比較した。主C0D0の純額はA0＋1,126,987円、T＋437,127円、TR＋269,739円。Tは全4費用の全70で黒字となったが、追加16のC5D0は−43,856円。未知期間の安定性や採用は未確認である。

| 主C0D0 | 利益総額（円） | 損失総額（円） | 利益後赤字玉 | 起動後赤字玉 |
| --- | ---: | ---: | ---: | ---: |
| A0 | 6,514,793 | -5,387,806 | 178 | 2 |
| T | 1,933,292 | -1,496,165 | 44 | 0 |
| TR | 2,007,906 | -1,738,167 | 53 | 0 |

T/TRは実取引数と利益後赤字件数・損失総額を減らしたが、利益総額も減った。Tは558出生中129、TRは154を許可。選別結果の未知は41/42、入力不足診断はどちらも120。分母はいずれも558要求だが、測る事象が異なる。既知の否定票があれば、一部入力に不足があってもANDの結果は偽となる。Tが全機会の良し悪しを識別できたという結論にはしない。

一度でも全玉費用後評価Wが正だった玉を分母にすると、最終赤字はA0が178/477＝37.3%、Tが44/112＝39.3%、TRが53/132＝40.2%だった。件数は減ったが、この条件付き赤字率は改善していない。Tの起動後赤字0も、起動前の正益後赤字44玉が解消されたことを意味しない。利益保護を評価する際は、取引数の減少と保有中の赤字化を分けて記録する。

全12の同入口対照で共通玉の実取得・初期P100・全返済と保存保護が同体、取得変更群は0だった。T→TRの共通129玉は全4費用で実現差0。R真の25玉44枚を加えた側の実現は−167,388/−150,388/−211,388/−193,388円で、元54も追加16も主R群は赤字だった。これはこの固定Source・保護で実際に加わった群の差で、反転一般が無効という証明ではない。

RはHist正水準やslow正傾きを要求せず早い回復を拾う設計だが、条件から『失敗反転だった』と結果を逆算しない。主R群の粗損益も負で、44枚分の手数料3,388円とC5滑り44,000円だけでは説明できない。主A0で双方偽362玉＋660,490円、TR未知42玉＋196,758円だったことも、追加条件を満たさない＝不採算ではなかった事実として残す。T129玉は127公表、R25玉は23公表に対応し、出生/公表を独立サンプルとして水増ししない。

[Rの当時値の記述診断](../../study/00114_順行と反転の取得確認を分ける/診断/要求時技法の文脈/Rの当時値の記述診断.md)では、Hist水準が順方向の9玉も、slow傾きが順方向の14玉も主純額の合計は負だった。既公表の反対側pivotを確定Closeで突破した例は1玉で、強化条件の有効性を判定できる数ではない。一項目を足すだけで良否を識別できたとは扱わない。

また、同じ確定終値で更新したEMAの1本傾きと、そのEMAに対する終値位置は数学上同じ符号になる。[教科書補足](../technical-analysis/組み合わせ/同じEMAの傾きと価格位置の重複.md)のとおり、114のa8=(2/7)x8、a21=(x8+G)/10で、G/x8正は二傾き正も含意する。保存値のfast550件/slow498件でも符号差0だった。次は5分・15分・30分の背景や、方向の強さ・価格構造・観測数量の役割を区別する。固定114の条件は書き換えず、新しい効果は別試行で検証する。
