# 元のIFDを活かす出口の調べ方

本稿の60分期限は研究側が置いた過去の対照条件。ユーザー指定の時計と現行の比較は[セッション両端のノーポジションと建玉の保有時間](セッションのノーポジションと建玉保有時間を区別する.md)を参照。

2026-11-22。日経199_02のデイで、利確・損切・時間切れを分けて調べた。各取引がどの理由で終わったかを数えると、改善を狙う場所が見える。注文が実際に果たした役割は、その注文一つを変え、同じ板を順に再生して調べる。[試行221](../../study/00221_日経199デイの元IFDの利点を残して利益を守る/README.md)

- **元の入口・方向に合わせて利確を置く。** 元利確65件は費用後総利益の73.4%を生んだ。指値を外すと元の181件では収支が増えたが、65件中13件が赤字に転じ、1枚口座では保有が長くなり次の取引が変わった。同じ日時の買いと売りを実際のBid／Askで逆にした対照、同週の別日の同時刻の対照も残すと、入口が選んだ局面の役割を評価できる。
- **保護する利益の種類を決める。** 元利確に届かず60分で返していた建玉と、利確直前の小さな振れを経て目標に届く建玉では、早い追尾の作用が異なる。F01は入口で分かる350pt幅・60分期限だけに追尾を付け、元利確65件を保った。同じ181建玉の総損失は36,308円減った。診断に使う「将来、元IFDなら時間切れに終わる」は発注条件に使えない。
- **時間切れと価格による損切を別に試す。** 元の価格注文を両方残し60分だけ延長すると、元の時間切れ78件の29件が利確、14件が損切、35件が場末に到達した。追加保有の代償もあり、黒字から赤字に転じた9件があった。延長と追尾を組み合わせる評価には、延長だけ、追尾だけ、延長＋追尾の三つの対照が要る。
- **1枚口座と同じ建玉の損失を両方測る。** T04は口座で元より総損失143,617円減だったが、元181件を固定すると68,076円増えた。売買した件数や保有時間が変わるため、口座総損失の減少は各建玉の損失軽減と一致しない。含み益後赤字の件数と確定損失、赤字日、日末DDもそれぞれ記録すると違いが分かる。

この結果は2026年9月21日〜11月20日の既使用45デイ。方向ごとの結果も異なり、延長による収支改善は売りに偏った。固定した候補の評価は同じ追加日・費用・執行条件で続ける。[期限と保護の比較](../../study/00221_日経199デイの元IFDの利点を残して利益を守る/元IFDの寄与/期限と保護の照合表.md)
