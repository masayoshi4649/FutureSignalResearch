# 反転入口を失速と量で切り替えた結果

2026-11-10。[118](../../study/00118_指値待機と複数技法の取得確認で入口を比較する/README.md)から[121](../../study/00121_失速と量で反転の入口を切り替える/README.md)まで、入口の同一幅先着を優先して比較した。200pt指値待機を改善の主軸にせず、複数技法から独立に候補を作る方針へ移した。

**失速と量を使って反転候補を選別する手掛かりは得たが、安定した70%以上は未確立。** 既使用70セッションの探索であり、未知検証・IFD注文の実約定損益・片側10枚の運用口座は未検証。少数例の高率を達成扱いしない。

## 入口をどう変えたか

119では、30分背景・15分位置・5分回復の複合確認でも70%へ届かなかった。順行の確認は接触から中央値715.5秒、Lastが中央値100pt進んでいた。条件の数を増やすことと、よい位置で入ることは同じではない。

120では、5/15/30分は背景に使い、確定1分で小構造を回復した時点へ入口を早めた。取得が高過ぎる場合、構造が崩れる価格まで遠い場合、現在Rawで回復水準を再び割った場合は新規を拒否した。主評価60分±100ptでは、押戻し追随は34順/43逆、収縮放れは14順/25逆、失敗突破からの反転は10順/7逆だった。

その反転の当時情報を分解し、121で次を固定して再生した。買いなら逆側のBB/RSI領域、直前5本1分安値の一時突破後にレンジ内へ5pt以上回復、反転実体・終値位置、ATRによるスパイク/距離制限、現時点での回復維持を使う。売りは高安・符号を反転した同条件。

率は順÷(順+逆)。この主評価では全完了例が±100ptへ到達したため、未到達を含む全完了分母の率とも一致する。B1の観測不足5例は率や金額に0として混ぜない。各幅の未到達と両分母の率は[幅別CSVの案内](../../outputs/01a1889f-f2af-7943-a047-543275ee9ed2/121入口比較CSV/README.md)へ。

## どう判別し、何がまだ分からないか

低いADXには、元の方向が衰えている場合と、強さが立ち上がり始めている場合が含まれる。今回の仮説では絶対値だけでなく変化を使う。ただしADX低下は反転方向を示さないため、方向は価格帯と1分の回復・現在の維持で定める。相対出来高も参加量を示すだけで売買方向を示さない。これらは技術を組み合わせる心理の説明仮説であり、参加者の意図を板から実測したという意味ではない。[公式根拠](../../study/00121_失速と量で反転の入口を切り替える/根拠/外部一次調査/公式根拠と局面分類.md)を参照する。

E0/V0は既知の結果から見つけた条件で、再生して同じ成績が出ても独立の検証成功ではない。E0は元54場が6順0逆、追加16場が0順1逆。V0は3順0逆と2順1逆。B1も6順2逆から4順5逆へ低下した。条件を広げれば70%を保って件数を増やせる、という結果にはなっていない。

E0の買いは2順0逆、売りは4順1逆。EVは売り2例だけで買いの成立がない。両側・異なる期間で十分な件数があるとは言えず、2例100%を最良の完成手法としない。技術指標は同じ価格に由来する部分があり、組み合わせの数を独立した証拠数とみなさない。

## 比較を成立させるための確認

C0の22出生・17取得は旧120P2と、当時票・要求・拒否・取得価格・期限観測まで全件同体だった。E0/V0/EVはC0と同原行の出生から派生させ、B0はB1と同原行から派生させた。基礎候補だけが300秒の冷却を消費するため、条件を満たさない別時刻へ黙って入口を移していない。

同じ出生の派生が成立すれば取得価格・観測結果も同一になる。その組の平均差0を改善失敗と捉えるのではなく、ここで測っているのは当時情報による母集団選別である。B1とC0は出生領域が異なるため、全件の平均差をBBだけの因果効果とは呼ばない。

全70場の原板SHA・公表配送・採用数を検査し、保存結果の別実装検算とCSV全セル再読を行った。原板の別走査による先着初回性、mini板の注文待ち行列・実受信遅延を独立証明したわけではない。1秒遅延・ラージBBOのmini代用、往復77円/C5追加往復1000円はモデル条件。重複する独立mini1枚の試験を口座収支へ合算しない。

## 次へ残すもの

有望な切替仮説は「位置と回復構造に、強さの低下又は量を加える」。固定条件と反証を保存し、ユーザー指定の「良い結論が出たら一旦停止」に沿って、121の資料を確定して区切る。安定70%の達成や実運用採用を宣言するものではない。

再開する場合は、条件を先に固定した未使用期間でE0/V0の件数と先着を確認し、その後にIFDの利確・逆指値・期限退出・必須利益追尾の実約定代用と費用を再生する。60分の期限清算評価を、±100ptで利確損切りしたIFD実績へ読み替えない。

追記：全セッション検証の指定を受け、[122の全73場検証](E0固定条件の全73セッション検証.md)で条件を固定したまま新3場を追加した。主±100ptは6順3逆66.7%、事前副評価±125ptは7順1逆・未到達1で87.5%（全9件中77.8%）。121の85.7%は旧70場での数値達成として保持し、追加後の結果と区別する。
