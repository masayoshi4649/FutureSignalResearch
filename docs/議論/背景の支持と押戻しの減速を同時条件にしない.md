# 背景の支持と押戻しの減速を同時条件にしない

[129](../../study/00129_背景方向と短期構造回復で取得を早める/README.md)は、5/15/30分の複合背景と1分拒否・Raw維持を組み合わせても、主F0が23/73場・6順13逆=31.58%だった。既知IFD代用のC5利益95,384円/損失211,155円・差引−115,771円。実逆も50%・既知−33,694円で、単純反転では救えていない。全73場の取得と70%を両方未達として固定保存した。

出生不足を金融なしで切り分けると、C1接触444→setup216→出生80、C2接触179→setup30→出生9、C3弱い反対足55→次足回復2→出生2。全91出生/38場から実取得42候補/23場へ減った。条件を多く重ねたことと、入口に優位があることは別である。

初日Dayには価格既知1分220本と共通背景37snapshotがあった一方、15分ADXが全場未知だった。30分未知を15分cohortへ分けても、その15分ADXを必須にしたため背景が成立しなかった。長期数値の未成熟と、短期ATR/価格構造の不足を別に扱う。未知を支持や低ADXへ置き換えない。

上位方向＋共通条件が揃った公表snapshotのHist同向率は45.6%、さらに公表Closeが現在EMA帯内の場合は30.1%。押戻しは短期の減速を伴い得るため、背景支持とHist絶対符号を接触時から同時に求めると候補を減らす可能性がある。ただしこれは公表値の記述で、全Raw接触時のHistでも、Hist条件を外せば利益が出る証拠でもない。

10pt格子に対して高安±5の回復水準と最大20pt capは狭い。実出生では有効価格が1点のもの5、2点86。ATR<20では格子上成立しないが、今回の公表にその実例はなかった。量の「拒否量不足」も複数gateの合算なので、capや量を単独の原因と断定しない。次案ではK未回復/cap超過/risk/量既知/量比/拒否形を分けて保存する。

次の自然出生案は、成熟MA又は既知3本の15/30分高安構造を背景cohortとして、背景→押戻し→減速鈍化→1分二段回復→Raw維持を別状態にする。現在価格のEMA/ATR距離とレンジ位置を背景の向きから分け、拒否足の薄さと回復足の量の増加も役割を分ける。勝敗を見て後からcohortを選ばない。採番前の可用性点検では、固定128公表のザラバ終了7分前まで・ATR5既知の公表機会に限り、MA30成立58場、30分未成熟時のMA15成立62場、30分の三本構造成立73場だった。これは背景を観測できるという記述で、接触・出生・取得・入口優位の証明ではない。初日Dayでは15分ADXだけでなく15分Histも全機会で未知なので、新しい共通必須条件へ移して同じ欠落を再発させない。

## 外部説明と次の検証で分けること

2026-11-11確認。[StockChartsのMoving Momentum](https://chartschool.stockcharts.com/table-of-contents/trading-strategies-and-models/trading-strategies/moving-momentum)は、大きな方向、押戻し、回復確認を順に扱う構成を説明する。日足株式の例であり、その期間・閾値をNK225分足の成績へ転用した根拠ではない。[MACD-Histogramの解説](https://chartschool.stockcharts.com/table-of-contents/technical-indicators-and-overlays/technical-indicators/macd-histogram)で扱われるHistはMACDとシグナルの差なので、価格の上下そのものや、Histの増減と同義ではない。MA方向、Histの符号、Histの増減、価格構造の回復を別項目に保存する。

[CMEの反転解説](https://www.cmegroup.com/education/courses/technical-analysis/technical-patterns-reversals)では、形の完成と価格水準の突破による確認、確認中の出来高を組み合わせている。量の増加を無条件に継続支持とせず、どちらの価格構造が回復・破綻した場面の量かを区別する。

心理の仮説は「背景方向への参加者が残っていても、押戻し中は短期の勢いが一時的に逆を向く。価格の回復と参加量が戻る段階を待つ」。一方で中期の勢い自体が逆向きなら、同じ短期回復を戻り売り・押目買いの終了と誤認する可能性がある。これらは今後の検証仮説であり、参加者の意思を板から実証した主張ではない。

129では同じ執行区間限定器を元出生にも適用し、技術変更とphase修正を分離した。元F0は68場・46.81%・既知−161,005円。元R1の旧128からの金額変化は非ザラバ観測の排除と未知増加による部分を含み、回避利益とは呼ばない。価格時計だけで真の受信/mini約定phaseを復元したとはしない。

詳細は[出生不足の診断](../../study/00129_背景方向と短期構造回復で取得を早める/根拠/出生不足の診断.md)、[結果と限界](../../study/00129_背景方向と短期構造回復で取得を早める/結果と限界.md)、[CSV三表](../../outputs/01a1889f-f2af-7943-a047-543275ee9ed2/129短期回復CSV/README.md)。一般的な心理仮説と、出生段階の実測、金融上の成績を混同しない。

## 153で再確認した同時条件の絞り込み

2026-11-12。[153](../../study/00153_長い先行域から順行と反転を独立出生する/README.md)は旧予測の入口資格を外し、全35,339判断から、短期回復・背景・量・価格構造を直接組み合わせた。129のHist絶対符号の話とは異なり、今回は1分の実体回復と5分Hist/RSI増分に、5/15/30分のEMA増分・DIの同時整合を重ねた。

短期回復と共通品質を満たす1,494出生側のうち、背景まで成立したのは78。背景不成立1,214、未知202を分けて記録した。背景の6方向条件だけなら198、ADX水準まで129、ADX増分まで78だった。個別の不成立は重複し、5分EMA増分882、DI5は1,009側で逆向き又はゼロだった。この観測は短期回復と5分方向の位相差を示す材料で、5分条件を外した場合の利益を示すものではない。

78から、平均線を同じ1分実体で跨ぐ形と距離を要求した押戻しは4出生/3取得、先行15分高安の突破は4出生/3取得。反転は0取得となった。新入口6取得は4順/0逆/1未到達/1不足にすぎず、旧C1を含む93取得・先着率71.88%を、新条件だけの十分な優位とは呼ばない。全時間平均は0.1290回/時で、頻度不足だった。

一方、背景と追加構造を課さない共通回復R0は1,375取得・512順/623逆/126未到達/114不足、先着率45.11%、C5既知利益6,805,646円/損失9,725,134円、未知31件だった。したがって「条件を減らせば解決」とも結論できない。背景を保つ段階、調整の段階、新しく回復した段階を分ける案は[129後の知見](#外部説明と次の検証で分けること)と[145の構造イベント比較](方向の静的整合と構造変化を分ける次仮説.md)に既にあり、再提案するときは入力・構造幅・確認時計のどこを変えるかを明示する。

同じR0取得時計の実反対BBOも、514順/618逆/129未到達/114不足・45.41%、C5既知利益6,779,415円/損失9,786,057円、未知29件だった。原623逆行のうち反対側が順行したのは514で、70は反対側でも逆行、39は未到達。1−45.11%を反転の成績へ代用できない。別算術で全/前48/後25の144値を独立照合し、単純な全売買反転も改善策としなかった。

Moving Momentumの一次資料は同日に再確認した。大きな方向・調整・回復確認を分担させる一般説明は参照できるが、同時ANDを時系列へ変えるだけでNK225の同幅125pt先着70%や毎時頻度が得られるという証拠ではない。上記は既使用73場の探索結果で、独立未知期の成績でも、可変枚数・追尾を含む口座収支でもない。153の固定条件は変更していない。
