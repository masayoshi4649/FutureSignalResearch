# 板の短期符号と押戻しの位相を分ける

2026-11-18。[201の板追加比較](../../study/00201_板数量の更新尺度を複合入口へ加える/README.md)と[203の独立した時系列](../../study/00203_TOPIXの長期支持と中期転換を独立に確認する/README.md)から得た問い。原板の情報を増やしても、異なる役割を単純に同方向の票へ変えると入口を損なう場合がある。

## 観測したこと

201では両指数166商品場・2,674万行から板数量の純特徴を作り、5つの既存複合入口に5条件を重ねた。強い反対板を除くと日経の損失とDDを減らす部分効果はあったが、赤字場や利益との交換が残った。TOPIXでは同じ追加で損失/DDが悪化した。同方向支持必須は参加と両中央値を失い、両指数の共通解にはならなかった。

[取得q0の尺度診断](../../study/00201_板数量の更新尺度を複合入口へ加える/板数量の観測尺度.md)は、損益を使わず実取得点の純特徴だけを集計した。BASE5母体の重複除去784点で、16回/64回更新・4完了現値時計ブロックの幅中央値は0〜39秒だった。これは受信時計で測った実時間ではない。同じ現値時計のまま板が更新されるため、0秒差を同時発生や高速性の証拠にしない。

TOPIXデイでは、実売買側と反対のOFI64が125/195点、完了4ブロックが139/201点あった。これは損失率ではない。既存入口が価格の短期逆行を使う押戻しを含む以上、反対量を全て危険として除くと、狙っていた位相自体を変え得る。ただし反対量を押戻しの証明とすることもできない。

201は板条件を共通にしたが、元の価格入口は商品ごとに異なる。今回の差だけで指数固有の注文心理を原因と確定しない。同じ価格入口・利用可能時点を揃えた[187/188の共通対照](指標の係数と観測できた時間を分けて比較する.md)と組み合わせ、入口の位相・足の履歴・数量の更新尺度の寄与を切り分ける必要がある。

203では短期RSI/MACDの同時ANDを外し、長期支持→中期押戻し→短期回復、長期失速→次の中期足の回復を順序付きで独立に調べた。転換47取得の45件で旧30分EMA方向が残り、44件で15分EMA並びも旧側だった。失速とEMA8回復だけでは、新方向の持続を十分に識別できなかった。新15分DI/傾きが新側の11件も既知赤字であり、指標の追加一致だけを次の解決策にはしない。

## 次の仮説に残す役割

|役割|当時に観測すること|混同しないもの|
|---|---|---|
|長期の背景|方向、並び、傾き、支持が残る価格位置|勢いの弱まりと方向転換|
|中期の位相|背景への押戻し、新方向の回復、固定した水準の維持|線を一度越えたことと持続する支持|
|短期の応答|反対圧力が縮小したか、元方向が再加速したか|一時点の短期逆流と悪い入口|
|板の確認|表示数量の変化と、その前後に価格が進む/止まる順序|表示量、約定量、注文者の意図、吸収の確定|
|運用の結果|共通/旧のみ/新のみの実取得、参加、両中央値、損失の連鎖|入口枝単体の利益と後続枠の入替え|

205では逆行過多群を同時点の反対側BBOで診断し、旧長期支持が残る押戻しと、新方向が成立した場面を分ける。204ではVWAPの起算・量/代金の入力を再確認し、移動平均とは異なる参照価格と固定構造の余地を調べる。いずれも新しい仮説であり、201/203の条件を結果から書き換えない。

全83場は既使用。小さな成功群だけを採用したり、逆方向の確率を単純な1−pから作ったりせず、単純IFD・同じ費用と約定代用・一枠・終了15分前・全場分母を維持して再生する。
