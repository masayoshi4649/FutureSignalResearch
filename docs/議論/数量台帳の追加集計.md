# 現在のNK225全65場の数量台帳集計

確認日2026-11-04。[既存の入力と数量の監査](入力と数量の監査.md)を補足する。00008に保存された数量監査を再集計したもので、原板の新しい独立再監査ではない。全65場は既使用。

場内の単調な価格時計で数量監査へ採った2,379,517状態は、数量時計と価格時計が一致していた。保存監査の数量欠測/不正、数量時計欠測、先行/遅延、採用累積減少・採用数量時計後退はいずれも0。原行全体や場外・時計欠測まで完全だったという意味ではない。

基準不完全85足は初回または欠足後の再基準化を含み、欠けた5分枠21個と区別する。この入力では観測差分量による補助を検討できるが、数量条件を付ける候補だけ開始を遅くせず、対照も同じ数量助走を要求する。現在足をRVOLの直前20足平均へ入れない。1/3分で比較する場合は、その足幅の集約と準備の検査を追加する。

価格は最終観測価格、数量は累積値の変化であり、差分量すべてがその最終価格で約定したとは分からない。全約定VWAPや参加者の建値として使わず、約定側別の買い/売り圧力とも呼ばない。出来高補助の費用後優位性は別の試行で検証する。
