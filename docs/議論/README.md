# 研究の問いと検証方針

同じ短期突破へ四つの追加条件を付け外しする16候補を00002で探索した。結果を踏まえ、M・V・Bの入口を固定して決済方法三つを00003で比較した。旧57場の探索では、両試行の全候補が両指数とも費用後で赤字だった。追随押し目・収縮突破・レンジ回帰は設計上の候補に含めたが、00002・00003でこれらを検証したとは扱わない。

00002では全対象の損失が小さかったM・Bでも、期間や文脈によって結果は変わる。特にTOPIXのM追加効果は探索前半と後半で反転した。00003の1ATR利確も、NK225では悪化しTOPIXでは改善した。条件を重ねることや早く利確することを、一般的な改善策とは結論しない。

既に閲覧した57セッションは再利用する探索資料である。00001で「未使用評価」とした期間も、次の改良に対しては未使用ではない。もとは未見だった追加3セッションも、条件・コード・テストの固定後に三候補を一度だけ予備評価した。追加確認の1ATR利確は、両指数とも既存EMA決済を下回った。三場という短さも踏まえ、採用見送りを維持した。追加確認を見て出口は選び直していない。

00003終了時点の次の問いは、突破直後を追う代わりに押し戻りを待つこと、現在の低ATRと「過去の収縮から発動時の拡大」を分けること、RSIの非過熱と回復・勢い持続を分けることだった。入口の復帰・収縮拡大はその後00004で比較したが、有効性を確定していない。既に評価した追加3場も、次の条件変更に対しては未使用と呼ばない。

各試行の設定と成績は、汎用表をコピーした `設定と結果.md` から参照する。00005は探索・後続検査済みで、固定一候補の後続は6/15＝40.0%、30分間引き1/8＝12.5%となり70%未達だった。後続の成功は1日に集中し、件数の支持条件も満たさない。表には実行済みの範囲だけを記し、未使用・未検証・データ不足・対象外を分ける。

00006では外部資料を着想に、開始幅突破・失敗復帰・狭幅突破・高安端復帰・BB内復帰・EMA復帰を1・3・5分で比較した。147候補に探索70条件の達成はなく、固定一候補の後続も5/12＝41.67%、30分間引き4/8＝50.00%で支持不足だった。補助条件の改善は期間・設定によって変わり、指標単独の有効性とはしない。

00007は同じ固定入口を一建玉で運用し、費用と返済待機を加えた別の評価である。旧60場の基準観測純損益＋23,628円には保有空白注意2場を含み、全体の確定収益とは呼ばない。条件選択期間は追加費用で赤字へ変わり、新4場の利益も00006と共通の後続に基づく。入口70%未達は変わらず、追加評価で条件を変更せず、採用確定には至っていない。
