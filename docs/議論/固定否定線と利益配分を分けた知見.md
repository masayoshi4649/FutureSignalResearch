# 固定否定線と利益配分を分けた知見

2026-11-07。[試行83](../../study/00083_構造否定と利益配分/README.md)では、初回除く15分の新規判断と82B1の複合チャート入口を固定し、当時のEMA価格線を失った時の撤退と、正益後の部分返済／全量追尾を2×2で比較した。全66場は既使用。全案で費用後損益は赤字であり、安定収益を確認した手法は得られていない。

## 比較できた範囲

S0は既存のATR・125pt保護・確定足の技法失敗。S1はこれに、新規要求時の3分EMA8を固定した否定線を重ねる。G1は部分利確と実確定益による残玉予算、G2は部分返済なしの全量追尾。両方とも費用後現在益がstrict正になった原行で最低建値床を起動し、15分を待たず保護する。取得後にEMA線を動かさず、受理返済は延期しない。

各案は100micro固定、1枚10円/pt、片道手数料11円・想定滑り5pt、往復122円/枚。主は次の正常ラージBBO、追加価格時計1秒は別の約定系列である。両条件とも、全4案の139実新規が時計・価格・方向・数量まで一致した。取得変更・片側のみの後続参加は0で、今回の差は同実新規の出口差として分解できた。他の入口や将来期間へ一般化しない。

## 早い否定は、損失と一緒に回復の機会も切った

G1へ構造否定を追加した主の改善は82,500円だった。内訳は、両赤字40玉の損失縮小＋910,000円に対し、黒字から赤字へ変わった14玉の−677,500円、両赤字4玉の悪化−150,000円。赤字から黒字へ変わった玉は0だった。追加1秒では改善が7,500円へ縮んだ。

従って「損切りが遅いから固定平均線で早く切ればよい」という一律の説明では不足する。平均回復の喪失は失敗の代理にはなるが、正常な押し戻りから回復する玉も切る。S1を全面採用しただけでは安定性を得ていない。全139玉で構造線が既知だったため、今回の結果を未知時の代替処理の優劣とも解釈しない。

## 全量を残すと右裾を取れたが、利益の赤字化は増えた

S0でG1からG2へ変えた主の差は＋441,500円。両黒字14玉の利益増＋908,900円、赤字から黒字3玉の＋260,000円に対し、黒字から赤字47玉の−665,000円などがあった。S1でも総差は＋429,000円だが、黒字から赤字35玉が生じた。

全玉正益旗後の最終赤字は、S0で9玉・−27,400円から53玉・−606,600円へ、S1で6玉・−20,800円から40玉・−458,000円へ増えた。全量追尾は少数の伸びを残せた一方、ユーザーの「利益が出た後の赤字化を避ける」意図への適合が悪くなった。総額が相対的に良いという理由だけでG2を採用しない。

建値床は費用後黒字を保証しない。床0ptで返せても往復費用が残り、返済要求から次適格板までの悪化もある。G1も実約定した部分益だけを残玉予算へ使うため、部分返済の悪化で予算を得られない場合がある。追尾起動・要求の非延期と、黒字で返済できたかは別検査である。[変動の余地と建値床の制約](外部再調査/変動の余地と建値床の制約.md)も参照する。

[正益後赤字の追加診断](../../study/00083_構造否定と利益配分/正益後赤字の診断.md)では、G1の全42会計玉を20原板・75物理行へ結んだ。全件で初回正益の同原行に部分返済要求が出ており、実部分約定の悪化で確定益予算が不足した。主S0/S1の計15会計玉では、残量の返済要求後に追加悪化した例は0だった。S0/S1・遅延条件で同じ場面を重複して数えるため、42件の独立事象とはしない。

例えば75枚を20ptで利確する計画の＋5,850円は、10pt不利な実約定で−1,650円となる。残25枚を10ptで返しても−550円、全玉−2,200円。実約定後に予算床を30ptへ上げても現在10ptなら即返済になるだけで、初回部分返済の損失は取り消せない。残量保護だけでなく最初の利益回収自体の約定リスクを別に扱う必要がある。初回全量回収や技法による配分切替は次の別固定仮説であり、今回有効性を確認したものではない。

## 出口変更だけで残った問題

主の正益未観測群は、S0が−4,525,200円、S1が−4,392,600円だった。G1/G2でこの群は同じであり、正益後の配分だけでは消えない。S0G1の約定価格差損益も−2,211,500円で、費用だけを原因にした説明も成立しない。S1G2は総額が最も良くても33日中29日が赤字である。

次は、平均線の方向・MACD増分・RSI急変警戒・ATR取得位置という背景に、FARが観測した現在の価格応答を加える。既存順行枝では硬必須でなかった、freshな両気配の進行後維持と反対圧力の解消をまず必要とし、その上の同価格数量回復を別比較にする[候補](チャート方向に現在の価格応答を重ねる候補.md)を、83結果を読む前に整理した。まだ正式採番・新損益再生・利益確認はしていない。

心理の仮説は、平均線が示す過去の流れと、取得時点にその帯を維持する応答を分けること。数量回復は表示板の代理であり、参加者の意図・新規／返済・実約定出来高を直接測るものではない。少数候補、確認待ちの遅れ、強い流れの見逃し、数量追加で失う勝ちも反証に残す。見送った保存玉の損益を足し算して新戦略の利益とはしない。
