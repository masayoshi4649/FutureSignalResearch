# 先着率の小幅低下を許容して取得頻度を優先する

2026-11-16、178の報告後のユーザー指定。参加が少なく、多少成績が悪化しても、より多く取得している候補を重視する。今回は固定済み結果の読み直しと評価方針の更新であり、新しい入口条件の検証結果ではない。

## 次の比較で優先すること

- 先着率70%を維持するために取得数の多い候補を一律に落とさない。率の小幅低下と取得数・時間当たり頻度の増加を同じ表へ並べ、少数高率だけを選ばない。「多少」の許容幅に新しい数値を独断で設定しない。
- 全Day/Nightで最低1取得を目指す条件と、頻度の不足を別々に評価する。従来の平均概ね1回/時を比較目安に残す。今回の指定は5分・15分の定時注文への変更ではない。
- 建玉保有・予約中の新規禁止、費用後の建玉別・全セッション別収支中央値が黒字という条件は継続する。0取得場を落とさず、未知を0円扱いしない。
- 回数が増え、異なる日・局面でも成績が保たれれば、少数の成功だけに依存しない根拠が増える。同じ値動きの短時間反復を独立標本とみなさず、日別支持、前半・後半・追加期、損益経路も示す。場別の回数を均等にするための間引きはしない。
- 取得が少ない原因を、技術条件不成立、必要指標の未公表、保有・予約による棄却、取得代用失効に分ける。条件緩和だけでなく、異なる局面の複合入口や幅・期限が枠を占有する時間も検証対象にする。変更した後続要求は口座全体で再生する。

178の固定主・前半選択・CSVは変更しない。新しい閾値や選択順位で探索する場合は次番号の試行とする。178の「一旦停止」は当時判断として残し、以後の候補評価には今回の頻度優先を適用する。

## 現行178は何を使って入口を判断しているか

価格・観測量から計算した指標を組み合わせる数値ルールである。次表は現行主案に残っている役割であり、全取引が全条件の同時一致を要求するという意味ではない。時間帯と局面により入口規則が異なる。

|知りたいこと|使用する情報|判断での役割|
|---|---|---|
|向き・背景|EMA8/EMA21、EMA傾き、DI差|平均線への復帰、複数足が注文方向を支持するか|
|トレンドの強さ|主に15分ADX|低ADXの帯端回復と、高ADXの継続・突破等を分ける|
|勢い・その変化|5分/15分MACDヒストグラム、RSIと増分|動力の向き、再加速、急激なRSIスパイク等を確認する|
|値幅と価格の位置|ATR、ボリンジャーバンド、平均線との距離|伸び切り、帯端、目標側の余地を数値化する|
|価格構造|直前高安、ローソク足実体、平均線・価格帯の回復履歴|突破、押戻しからの復帰、帯端の回復を識別する|
|量|当該1分の観測量÷直前3本の平均|直近の量に対して弱すぎる動き等を除く。元の新枝では相対量0.5以上を許容するため、出来高急増を必須としてはいない|
|取得の適格性|Bid/Ask、スプレッド、価格の鮮度、取得位置、保有・予約状態|技術条件成立後、取得代用として扱えるかを確認する|

デイの既存入口は、15分ADX25以上に5分の動力・RSI改善、15分MACDヒストグラムの順方向、量を組み合わせる勢い型、および直前3分端からの突出・5分実体・動力・量を組み合わせた入口で構成する。勢い型の15分MACDには、増分改善までは要求していない。後者は、現在の固定主では元シグナルと反対向きへ取得する。

ナイトの既存入口は、複数足のEMA/DIと平均線回復、又は低ADXとBB端の回復・動力・量等を組み合わせる。177で高ADX用の押戻し・突破・混在局面の枝を加え、178ではその新枝だけに次を追加した。

- 米国前：15分EMA21傾き、30分EMA21傾き、15分DI差、30分DI差の4項目中、実際の注文方向に正の項目が2つ以上。4項目とも当時既知であることが必要。
- 米国後：上記に加え、5分MACDヒストグラム増分と5分RSI増分が、ともに実際の注文方向に正。

複数足の指標は同じ価格から導くため、4項目を独立した確率として扱わない。旧主入口→追加した新入口→初参加用の技術補完という順で判断し、保有・予約中は追加しない。補完も技術条件付きであり、時刻だけで無条件に注文するものではない。

新規の判断点は、148の母集団にある最新1分足が既知・確定・鮮度条件を満たした公表時点q0。5分/15分/30分足はその時点までに利用可能になった値を参照する。取得代用q1は別の原行かつ1秒以上後とし、実際の受信時計を完全復元したものではない。指標の足幅を5分・15分の定時新規時計と混同しない。

現行には、元の突破・回復条件と反対方向へ取得する規則もある。旧BO0065/NR0050では、方向反転とは別の「突破失敗」「回復失敗」を確認していない。178の追加確認は新枝限定なので、この旧入口へも適用済みと説明してはいけない。相場心理は条件を考える仮説であり、実参加者の心理を直接観測したものではない。

条件の詳細：[174の条件と市場心理](../../study/00174_共同条件を残して単一建玉の入口を広げる/条件と市場心理.md)、[178の設定と結果](../../study/00178_新枝の実方向と複数足の背景を確認する/設定と結果.md)。今回の説明・方針更新では、新しい損益計算やCSVの置き換えは実行していない。
