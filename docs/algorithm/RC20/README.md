# RC20　日経225miniのデイ売買

RC20は、**日経225ラージの値動きと出来高で入口を決め、日経225miniを1枚だけ建てる**手法である。取引開始は09:05。日経199_02の入口に利点があった値幅を保ち、利益が乗ってから値動きが反転したときの損失を抑える。手仕舞い後にすぐ建て直すと取得する取引自体が変わるため、追尾で先に決済した場合は、元の価格目標か損切価格に届くまで新規を休む。[試行224の固定仕様と単純IFD対照](../../../study/00224_利益保護後の再エントリーをシグナルで待つ/README.md)

## 1日の流れ

1. **08:45から指標を更新する。** 過去の同一限月のデイとナイトで数値を初期化し、当日の確定足が公表されるたびに使える指標を更新する。開始20分間はポジションを持たない。
2. **09:05以降、確定1分足の情報が新しく使える原板で候補を判断する。** 主入口を優先し、当日未参加なら09:30以降に補完も使う。正常な気配で取得できた時に1枚を建てる。入口一件ごとに片幅 `R` が決まる。標準の4通りは150・200・350・400ポイント。新規判断・取得の有効範囲は14:40未満まで。
3. **保有中は原板ごとに返済側の気配をみる。** 当初の利確と損切は建値から順逆に各1R。0.95R順行すると広い追尾を始める。逆向きの主通知が2回続き、最大順行・現在の順行が条件を満たせば狭い追尾を使う。時刻・約定遅れ・優先順位があるため、同じ分足の高安から結果を決めることはできない。
4. **15:29に場末返済を要求し、15:30までに全決済する。** 始めてから一律60分で返済する規則はない。早い保護返済後に元価格を待つ間は0枚で、その時間・仮想の値動きは保有率・損益に加えない。

**名前の対応。** 入口は `199_02`、利益保護は試行224の `R02`、再開方式は `C`、開始待機は20分。これを組み合わせた同じ基準が、試行224の `224_RC20_R02元価格まで待つ`、試行228の `228_E0RC20_元の入口と出口`、運転器の日中手法 `NK225_RC20` に対応する。比較する `I20` は単純IFD、`RA20` は保護後すぐに再開、`RC30` は開始30分待機、`X2C20` は追加の出口を持つ候補で、それぞれ別の仕様である。[候補別の比較](../../../outputs/00224_利益保護後の再エントリー/README.md)・[追加出口X2の固定条件](../../../study/00228_日別の損益偏りと十月八日の入口出口を検証する/追加日/README.md)

2026年9月21日〜11月20日の45デイで133建玉、費用後の利益2,067,993円・損失1,061,234円・収支＋1,006,759円を再現した。これはラージ気配でminiを代用した、既使用期間の検証値である。運転器は日経mini自身の気配・約定を扱い、利確・損切と追尾の条件が成立した際に所有建玉の成行返済を要求する。通信中断や板飛びでは保護価格での約定や15:30の全決済を保証できない。[日別損益](../../../outputs/00228_日別の損益偏りと入口出口の比較/228_E0RC20_元の入口と出口/デイ.csv)・[運転器の設定](../../../../SessionTradeExecuter/docs/RC20.md)
