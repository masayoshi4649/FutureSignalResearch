# 指標の計算と観測時計

[入口条件](入口と指標.md)で同じ数値を再現するための計算定義。JSTの日経ラージ1限月を扱い、価格の単位は指数ポイントとする。売買側を `s`（買い＋1、売り−1）、現在値を `P`、その側で新規を建てる気配を `E`（買いAsk、売りBid）と書く。正常な最良気配は有限の `0 < Bid < Ask`。価格時計は板の現在値の時刻、原行は同時刻の先後も保存する。

## 1　どの時点で何が使えるか

|入力|公表して判定に使う条件|
|---|---|
|過去場|対象デイの開始までに完結した同じラージ限月のデイ・ナイトから、確定5分足を時間順に読む。過去場内では、5分の終了＋60秒がその場の終了以下の格子まで更新する。別限月の数値を引き継がない。|
|当場の足|1分・5分は公式の確定OHLCと出来高・量完結フラグを使う。15分・30分は立会開始（通常08:45）を起点に連続する5分足から作る。高値は最大、安値は最小、始値は先頭、終値は末尾、量は各子足の合計。量にはすべての子足が完結、有限、0以上であることを要求する。価格と量の既知性は分ける。|
|原板での配送|当場の有効な現在値と価格時計を持ち、足終了＋60秒に達した最初の原行で足を公表する。最良気配が異常でも価格時計は進む。実配信では、その原行を受信した時点で利用できた確定足だけを使う。研究の過去再生は利用可能時刻を足終了＋60秒とする。足を後で受信しても、過去の判断を巻き戻さない。|
|1分足での判断|新たに1分格子が成熟した原行で1回評価する。無配信で複数の分が同じ原行に届いたら最後の分で1回。直近1分足が価格既知・確定で、`q0 < その足終了＋120秒`、かつ `q0 < セッション終了−3900秒` が必要。この条件を満たすと、最良気配が異常でもq0として評価し、スプレッドや取得気配に依存する特徴だけを未知とする。たとえば各手法の前回方向は中立に戻り得る。新規取得に使うq1には正常気配が必要。判断に使う直近3本とは、この直近足を除いた、一つ前から三つ前の**連続する**1分足を指す。|
|5・15・30分の背景|その場で既に公表され、受信順・原行順ともにq0以前の最新の各尺度を使う。足幅をW秒として `q0 < 足終了＋W＋60秒` の間だけ有効。過去場は数値を初期化するために使い、当日最初の公表までは当日背景を未知とする。|
|異常・欠測|当場外・逆行時刻・非正価格は採用しない。同秒の異なる原行は保持する。時刻格子に欠けた価格足は未知となり、その尺度の数値指標とDMIを初期化する。必要な値、正の分母、連続足が欠けた派生値は未知とする。同一確定足の再配信は最初の知得時刻を維持し、値・量・量完結に矛盾があれば実行器は異常として扱う。|

例えば08:45～08:50の5分足は、通常08:51以降の板から初めて使える。08:45～09:00の15分足は09:01以降、08:45～09:15の30分足は09:16以降が最初の公表機会になる。RC20の取引開始は09:05なので、開始直後に当日最初の30分足を要求する枝はまだ成立しない。[研究の当時特徴と100列辞書](../../../inputs/00148_全1分入口母集団/README.md)・[足・原板の逐次処理](../../../../SessionTradeExecuter/internal/rcsignal/engine.go)・[当日背景の有効期限](../../../../SessionTradeExecuter/internal/rcsignal/background/bank.go)

## 2　各尺度で持ち回る数値

5分、15分、30分のそれぞれに独立した計算器を持つ。前値はその尺度の直前の公表値。同じ限月では前場終値と当場の最初の足との変化も指標に含める。単に表示中のデイ足だけで初期化すると、同じ設定期間でもEMA、ADXや最初に使える時刻がずれる。

|指標|定義と初期値|
|---|---|
|EMA、EMA差|終値EMA8・21・12・26を計算する。各EMAは最初のN本の単純平均で開始し、以後 `前EMA＋2/(N＋1)×(終値−前EMA)`。EMA差は `EMA8−EMA21`、EMA21増分は `今回−直前`。|
|MACD|MACDは `EMA12−EMA26`。両方が既知になってからMACDのEMA9を同じ初期化手順で作る。ヒストグラムは `MACD−EMA9(MACD)`、増分は直前ヒストグラムとの差。|
|TR、ATR|前終値があれば `TR=max(高値−安値, abs(高値−前終値), abs(安値−前終値))`、ない最初は高値−安値。ATRはTRのWilder平均14。最初の14個の単純平均で開始し、以後 `(13×前値＋今回)/14`。現在のATRと前足のATRを使い分ける。|
|RSI|連続する終値差の上昇分と下落分の絶対量を別々にWilder平均14とし、`RSI=100−100/(1＋平均上昇/平均下落)`。平均下落0かつ上昇ありなら100、両方0なら50。中心差は `RSI−50`。|
|DI、ADX|前足との差から `up=高値−前高値`、`down=前安値−安値`。upが正でdownより大なら＋DM=up、downが正でupより大なら−DM=down、それ以外の成分は0。同値は両方0。前足のある時点からTR・±DMをWilder平均14にする。3平均が既知で、平均TRが正、かつ平均＋DMと平均−DMの和が正なら、`±DI=100×平均±DM/平均TR` と `DX=100×abs(平均＋DM−平均−DM)/(平均＋DM＋平均−DM)` を公表する。それ以外では両DIとDXをすべて未知にする。ADXは有効なDXのWilder平均14。DXが定義できない時はADXの初期化から再開する。DI差は＋DI−(−DI)、ADX増分は現ADX−前ADX。|
|15分ボリンジャーバンド|当該公表を含む直近20本の15分終値平均を中心、母標準偏差（分母20）をσ、バンドを中心±2σとする。同限月の過去場から窓を引き継ぐ。価格未知を含む20本はバンド未知。σ=0ではσ当たり位置も未知。|

指標の途中平均を既知として公表しない。TR/ATRなどの「比」と指数ポイントで測る「増分」を区別する。[EMA・MACD・RSI・ATRの数値処理](../../../../SessionTradeExecuter/internal/rcsignal/numeric.go)・[DMIとADX](../../../../SessionTradeExecuter/internal/rcsignal/dmi.go)・[BBの窓](../../../../SessionTradeExecuter/internal/rcsignal/background/bank.go)

## 3　入口条件の列を組み立てる

`t` はその尺度の直近公表足、`t−1` は直前の足。`A` は最新の当場5分ATR。変化・方向の列は下表のとおり側別に計算する。ADX、TR、ATR、スプレッドと出来高には売買の符号を掛けない。

|入口で使う量|算出式、単位|
|---|---|
|側別ヒストグラム・増分、側別RSI中心差・増分、側別EMA21増分・EMA差・DI差|各表現に `s` を掛ける。例は `s×(Hist[t]−Hist[t−1])`、`s×(RSI[t]−50)`、`s×(EMA8[t]−EMA21[t])`。ヒストグラム÷ATRを指示した条件だけ当該尺度のATRで割る。|
|側別実体比・終値位置|実体比は `s×(C−O)/(H−L)`。終値位置は買い `(C−L)/(H−L)`、売り `(H−C)/(H−L)`。1分と5分で対応する足を使う。ゼロ値幅は未知。|
|ズレ・取得位置|ズレは `s×(P−1分C[t])/A`。取得位置は `s×(E−5分EMA8)/A`。VLCのクロス判定だけは取得位置のEを現在値Pに替えた `s×(P−5分EMA8)/A` を追う。|
|1分終値増分、1分実体回復|前者は `s×(1分C[t]−1分C[t−1])/A`、後者は `s×(1分C[t]−1分O[t−1])/A`。元の実装はこの実体回復とズレを別々に計算し、その和の正負を比較する。|
|3本の側別端の突破|買いの端は前3本の最高値、売りの端は前3本の最安値。`s×(P−端)/A`。3本と直近足が60秒格子で実際に隣接していることを確かめる。|
|相対量|直近1分の量÷前3本の1分の量の単純平均。4本とも完結し、量既知で正の分母を要求する。個別足の出来高0は既知の0として扱える。板数量や5分出来高とは別の量。|
|正規化値幅|1分TR÷5分ATRの分子は直前の実隣接1分終値を使う。5分TRの比は条件の指定により現在5分ATRまたは前5分ATRで割る。|
|BBの価格位置・余地|`s×(P−中心)/σ` と `s×(E−中心)/σ` を区別する。前者は補完の現在値票、後者は保留開始時の固定価格を決める。順行側の上・下バンドをBとすると、補完の元列は `s×(B−E)/125`。実際の片幅200ptに換算して0.5以上、すなわち100pt以上の余地を要求する。|

数字の境界を照合するときは倍精度で計算し、中間の丸めを入れない。原仕様は100列全体の名前・正規化・単位を記録している。RC20が使う部分は上の表と主・補完の条件で特定できる。[固定100列辞書](../../../inputs/00148_全1分入口母集団/100特徴の列定義.json)・[短期特徴の計算](../../../../SessionTradeExecuter/internal/rcsignal/features/compute.go)・[背景特徴の計算](../../../../SessionTradeExecuter/internal/rcsignal/features/legacy74.go)
