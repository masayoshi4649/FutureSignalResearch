# 日経199_02のTOPIX移植に使った固定入力

[試行213](../../study/00213_日経デイ199の入口をTOPIXへ固定移植する/README.md)の生成入力。2026-09-21デイから11-18デイまでの85セッションを古い順に読み、各デイの判断時点までに公表された100特徴を作った。ナイトは後続デイの指標履歴に含める。最初の場は履歴なしから開始した。

- [原板・1分足・5分足の入力指紋](原板と分足の指紋.json)は `../JP_OSE_Data` からの相対位置、各ファイルの長さ、SHA256を記録する。85場の原板、各85本のCSVを対象とした。
- [共通時計と固定入口](全純入口.npz)は額面・呼値換算の2種類について、旧179幹と199_02（195_05）を一度ずつ計算した。[候補と保存列の対応](候補列.json)で共通列を使い回す。全85場で当時特徴が使える43,627判断がある。原板・特徴全体・仮想約定配列の複製は当フォルダに含めていない。
- 呼値換算ではLast・Bid・Ask、1/5分足OHLCを20倍した表記で共通部品を動かし、日経の固定価格条件を同じ刻み数に揃える。時刻、原行の順番、数量の単位を保持した。q0・q1・失効時計8列は額面版と全行で一致した。決済には元のTOPIX価格を使う。
- [各場の保留件数](保留の発生.json)は注文・建玉になる前のイベント数。[保存索引](保存索引.json)には対象ファイルと[再現用ソース](再現Source.zip)内の依存115ファイルの指紋を記録した。
- 価格3列と分足OHLCが全て20倍になり、時刻・行番号・正常性・数量・確定状態が保存されたことを、別の読込で85場の原行13,065,529件、1分足49,096行、5分足10,074行に照合した。[全行照合](単位換算の全行照合.json) / [確認コード](単位換算を照合.py)

## 再現

試行時はWindows、Go 1.24.2、Python 3.14.3・NumPy 2.5.4。新しいチェックアウトを使う場合、以下のコマンドはリポジトリのルートから順に実行する。元原板と分足は隣の `JP_OSE_Data` に配置する。同一名の固定資源がある環境では指紋を照合してから使う。PythonはNumPyを導入した環境を使う。

```powershell
$src213 = (Resolve-Path 'inputs/00213_日経型TOPIXの純入口').Path
Expand-Archive -LiteralPath (Join-Path $src213 '再現Source.zip') -DestinationPath .
Push-Location 'work/166可変場の観測'
go build -o 可変場観測.exe .
Pop-Location
Push-Location 'work/未見入口の同体接続'
go build -o 入口同体接続.exe ./cmd/run
Pop-Location
$env:PYTHONUTF8 = '1'
python 'work/今回移植/母集団.py'
python 'work/今回移植/呼値を揃える.py'
python 'work/今回移植/純入口を作る.py'
python 'work/今回移植/純入口を作る.py' --folder 'work/今回移植/呼値換算'
python (Join-Path $src213 '純入力を展開.py') --output 'work/今回移植'
```

最後のコマンドは、4つの固定入口の既存配列を恒久保存物と全列で照合する。空のフォルダを指定した場合は、同じ4つの入力を直接展開する。金融再生には別途、元価格の48バイト索引を使用する。旧42デイと新しい11月18日を分けた損益は試行の正本を参照する。

保存アーカイブだけを使って2つのGo実行ファイルを別フォルダにビルドし、生成済みのGo母集団を入力に、額面・呼値の純入口計算をそこで再実行した。双方の179/199入力4ファイル、保留の発生診断2ファイルは元の計算とバイト単位で一致した。[隔離再計算の記録](隔離再計算.json)
