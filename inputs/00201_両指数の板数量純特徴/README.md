原板166ファイルの現在の物理容量は計3,311,688,626byte（156 gzip・10 plain）。`抽出前固定.json.gz`はその物理SHA/mtime/byteと、過去の固定入力票から取得した展開後SHAを保持する。抽出で全行の展開後SHA、物理SHA、前後statを確認した。

## 正本と利用

- [抽出前固定.json.gz](抽出前固定.json.gz)：純q0の全識別子、参照資源、原板SHA、金融前Source/仕様/人工確認。
- [完了.json](完了.json)：全166商品場の出力SHAと品質件数。`scope=全83`、`financial_labels_used=false`。
- `NK225/{場}.json.gz`、`TOPIX/{場}.json.gz`：場別の純特徴。トップレベルdictの`rows`を読む。
- 各`{場}.検査.json`：原板・出力の指紋と既知/未知理由件数。
- [追加2の確認.json](追加2の確認.json)：同一Sourceで先に確認した追加2場。全83へ含まれるため件数を二重計上しない。
- [独立純特徴監査.json](独立純特徴監査.json)：特徴核・抽出器を呼ばず、原板prefixから全q0を直接検算した結果。

レコードキーは`symbol/session/line`。`time`は現値時計、`line`は1始まりの物理原行。`features`の7キーは`QI1/QI3/QI10/OFI16/OFI64/BLOCK4_OFI/BLOCK4_MID_CHANGE`。値と`known/reason/start_line/end_line/available_line/events/clock_span/max_clock_gap`を一緒に扱う。未知はnullであり、零支持ではない。

NKは181/194の既存全1分q0。TOPIXは183旧形成/184直接形成と194追加2の和集合で、同じ原行は統合し、元集合を`members`へ残す。TOPIXの足`close`を原行Lastとせず、既存の純8列索引の同原行Last/Bid/Askで原板と照合している。原行を超えた同時計の更新は取り込まない。

値は市場の買い方向が正。候補の実売買方向を掛けるのは利用側。4完了ブロックは、各ブロック平均の平均ではなく、4ブロック内全L1変化の正規化差分平均である。現在の未完了ブロックを未来まで見て閉じない。
