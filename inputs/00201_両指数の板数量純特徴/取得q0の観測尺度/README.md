# 実取得q0の板観測尺度

2026-11-18の事後診断。純特徴の生成・金融前封印とは別の資料で、純値を変更しない。201の25口座から実取得の識別子だけを投影し、損益列を計算に使用せず、数量のLast時計上の観測尺度を集計した。

- [取得識別子.json.gz](取得識別子.json.gz)：全25口座7,209取得のcandidate、symbol、session、q0物理line/time、実側、帯、origin、取得line/time。損益・先着ラベル・決済価格を含まない。元台帳の由来SHAを記録する。
- [観測尺度.json](観測尺度.json)：候補25×帯別のOFI16/64・BLOCK4_OFIの既知/未知、clock_span/max_clock_gapの分位・固定参考軸、実側同方向/反対の件数。BASE5母体の1,582行を商品/場/q0原行で重複除去した784点の分布も別保存する。
- [説明](../../../study/00201_板数量の更新尺度を複合入口へ加える/板数量の観測尺度.md)：短期量と5/15/30分背景の尺度差、零秒の意味、未判別の位相と次仮説。

q0は実際の取得時刻より前又は同時である。NK台帳のside 0/1を買い+1/売り−1へ対応し、TOPIXは保存された+1/−1を使う。帯は固定台帳のq0区分DAY/PRE/POSTを継承する。TOPIXのrequest_line、NKのleg/eventから得た純q0を使い、実取得lineへ差し替えない。

`clock_span=0`は同じ現値時計内の更新を含むことを示し、実受信時間0秒ではない。既知率の差を市場流動性の差と即断しない。分位は`floor((n−1)p)`の経験分位。5/15/30分・H60/H120は固定の参考尺度で、損益を見て選んだ閾値ではない。

[診断Source](../../../scripts/板数量の観測尺度201/診断201.py)は、恒久化した取得識別子があればそれと201純板キャッシュだけから再集計できる。最初の投影元はrootが管理する201金融正本で、元台帳を再利用する際はこの取得識別子内のSHAと照合する。金融成績の再計算はしない。
