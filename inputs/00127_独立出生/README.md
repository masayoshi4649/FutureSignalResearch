最短再現はInputを`work/127独立出生の評価/入力.json`へ戻す。源schemaからInputを再生成するときは、schemaを`work/126独立出生の事前案/出生イベント_v4.json`へ、[旧場metadata](../00124_同入口正逆の共用入力/入力.json.gz)を`work/124入口の原因分析/入力.json`へ戻す。旧metadataから取得entriesを捨て、場・Raw参照・品質だけを再用する。元取得時刻を独立出生に混ぜない。

公表出生そのものを再生成する場合、177,709,174B・SHA256 `6a6cd13dfd00c9669b522e3c3c8e06a4066766f6075786f64d8c0feeb45513ec`のInputを[122再現手順](../../study/00122_E0固定条件を全セッションで検証する/再現資料/再現手順.md)から復元する。旧118入力と新3公表を共用し、ここへ177MBを複製しない。

[127再現手順](../../study/00127_独立出生を最初の実取得で評価する/再現資料/再現手順.md)に、F1実行コードとF1外の公表出生v4コード、旧118Bank/124stats依存、固定原文の扱いを分けた。v3対照は金融ラベルではない。全て既知期間の研究用入力であり、未知期の成功・実約定を示さない。
