この保存は非金融の測定入力。154の自然売買/容量/金融は未実行で、手法の有効性や70%先着を意味しない。

正本は[先行回帰の入力.json.gz](先行回帰の入力.json.gz)、6,379,417 bytes。物理SHA256 `f0eef157e0559827e5d7d2f2d614b8ab4d3a98c27b8d463b02c2eec5e9325e98`、解凍55,041,534 bytes/SHA256 `7b05fa49f502ff8b25e7be11ffacde1898b3ca38bcb9d58835d8dc5f9d6e2387`。元work gzipを再圧縮せず一度同体保存し、全CRC/解凍SHAと元の前後stat/SHAを照合した。

[153の先行高安入力](../00153_先行高安の独立出生/README.md)を共有し、最新1分rを除く実時間15/30/60分の先行終値を測定する。範囲は `[r.Start−W,r.Start)` で、15/30/60分足そのものではない。欠測を詰めず、前場で不足を埋めない。参照市場時刻/配送順はq0以前に限定する。

OLSは切片と実1分格子を使い、傾きpt/分、R²、平均終値、母標準偏差(ddof0)、残差RMSE(sqrt(SSE/W))、両端の当てはめ値を保存する。定数系列のR²は未定義で、0補完しない。高いR²は標本内の直線性で、将来収益・方向の正解確率ではない。

全40,544q0・適格35,339・73場を保持。known72,809窓の509,663数値は、別NumPy2.5.4のlstsq標準式と独立に一致した。許容差は傾き/R²/std/RMSE 3e-11、価格水準3e-8で、閾値の売買判定を丸めて合わせた検査ではない。

[最小再現ZIP](先行回帰の再現資料.zip)と[索引](先行回帰の再現資料_索引.json)は元相対work pathを保つ。生成4源、準備票、私有660人工/Source、自然生成票、自然全件独立票/Sourceを格納し、旧途中票や巨大入力・100X・原板・観測は複写していない。再生成は同指紋の共有153入力と停止Sourceを隔離workへ復元して未作成出力先へ行う。既存正本は上書きしない。
