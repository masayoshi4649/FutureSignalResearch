# 両指数の固定端点相対変化・206純入力

2026-11-18生成。金融・先着・入口採否を使わず、全83場のNK225 40,314 q0、TOPIX 35,361 q0を保持した。既存8列166ファイル、24,210,481バイトから生成し、出力NPZ166ファイルは29,501,251バイト。原板は再抽出・複製していない。

判断q0の時計を`t`とし、自己・相手とも終点`t−d`と始点`t−d−h`へ過去方向に結合した。遅延`d=[1,5,30,60]`秒、窓`h=[60,300,900,1800]`秒。各固定端点から採用価格時計までの追加停滞は60秒以下。主値は原順の既到達時計を後退しない、同じ価格秒の最初の有効Lastである。

**価格時計の公表遅延を仮定する感度であり、実際の受信遅延や真の先行性を測定した特徴ではない。** 相手商品の原行番号は追跡用で、自己の原行との大小で先後を決めない。主は1秒のまま維持し、可用性や後の成績を見て主遅延を交換しない。

商品ごとに元のq0母集団・時間分布が異なる。この表の差だけで市場の流動性や優位性を断定しない。遅延を変えると検索境界が移るため、既知件数は単調には変化しない。全対象場・全q0を分母へ残し、未知を0リターンにしない。

NPZは`{商品}/{YYYY-MM-DD_Day又はNight}.npz`。q0は`q0_line`と`q0_time`で結合する。`log_return`と`quality_known`の軸は`(q0,遅延4,窓4,自己/相手2)`、差の軸は`(q0,遅延4,窓4)`。価格単位差は自然対数比で除き、ATR・全期の標準化・市場beta推定は加えていない。
