X0は42A0の純13列・同時計11先着・全66ledger/traceとID以外を直接照合する。43D0＝42A0は旧成功proofへ推移接続する。旧43の入口/対照/指標参照JSONは同byteで再用し、42全5明細と29数値を共有する。旧NKの価格一監視/数量/CMFを44で再構築したとは記述しない。

TOPIX同場u.end＝NKj.endかつu.confirm<NKj要求秒strictを要求する。異商品ファイルの原行番号は大小比較しない。同秒/後公開/未収録なら当時は補助参照None＋「TOPIX同終了strict事前公開参照なし」一理由を保持し、未来足追加で当時のNone・採否・理由が変わらないことを人工確認する。古い正常足/別endへのfallbackや新h待機は行わない。

NK確認遅延0は、TOPIX確認>=同endとstrict事前公開を同時に満たせず構造上X1不可である。全保存TOPIXから同秒/後公開/未収録/NP等を分ける表は**事後時計診断専用**で、live理由や未知の当時数値へ戻さない。strict価格時計先行は実受信先行を証明しない。

TOPIXの当足を含む同場連続公開20終値にx=0..19・切片付きOLSを適用し、元各float終値からFractionで傾きを計算する。MACD12/26/9はTOPIX同限月の中心化銀行を使い、当場隣接現前ヒストの差を取る。傾き0/ヒスト差0は準備可でX2は不成立。X2は同じ終値由来の方向・勢いの複合条件で、単独効果や独立二票ではない。

X01は関連指数の方向・勢い整合という具体設定で、相関係数/NT倍率/相対リターンを測った意味ではない。I14/I03はTOPIX3分補助、NKのMACD/ATR/P07/P10は別の役割である。R²・CMF・量・TOPIX ATR・上位一目/多時間軸を条件へ追加しない。TOPIXをNKの呼値へ丸めず、商品間pt/損益を合算しない。

新大明細はTOPIX全指標/発動判定/入口事例/全運用詳細/追尾の5gzip。TOPIX全足は一系列へ一回だけ保存し、OLS全panelは準備hash/count、NKj判定には当時参照した限定出典を保存する。旧母監視・NK全指標・全TOPIX窓を各caseや帳票へ複製しない。新caseは旧11先着との同値と、全実sideのNK原BBO直接独立監査を分ける。

非損益準備には別の小型`TOPIX数値定義.jsonl.gz`で場/index/Hだけを保全する。独立生数値の非H/原点出典は厳密、H現前/差はabs1e−10/rel0・符号/準備/全採否strict、正本H定義を使った17列/panel/decisionの全内容hashは厳密と分ける。独立生H差足数/最大差/生hash差は参考で、正本定義一致を独立生float SHA同一と呼ばない。初回生SHA差の記録を残し、I/J/O・条件・入口閾値を変えず先着/PnL前に主/独立準備を再bindした。正式新5系列の追加や新ゲートではない。

[正式保全のTOPIX数値定義](../../study/00044_TOPIX方向とNK再テスト/TOPIX数値定義.jsonl.gz)はwork正本と同byteである。workの定義が無ければ所定`work/TOPIX補助/00044/TOPIX数値定義.jsonl.gz`へ復元し、主準備の圧縮/展開内容SHAを照合する。場/index/macd_histの3列だけで、全17列/原板を複製する資料ではない。

TOPIX入力参照は入力台帳/入力監査/入力予約の各パス・SHAを持ち、主/独立準備・状態・追尾・会計へ参照自身を含む四SHAを結合する。台帳/予約/入力監査が未完・不一致なら実行を停止する。全NK66は既使用の追加開発で、初TOPIX結合を未知データ実証と呼ばない。11/5Dayは両商品とも除外・内容未読を維持する。

[TOPIX入力記録.zip](../../study/00044_TOPIX方向とNK再テスト/TOPIX入力記録.zip)はGit管理外の必須3JSON（入力台帳/入力監査/入力予約）だけを同byte保全し、原板/cacheを含まない。work消去時は3JSONを`work/TOPIX補助/00044/`へ復元し、TOPIX入力参照の各SHAと照合する。モデルが指す所定work・同SHAは変えず、zipを新たな採否ゲートや別入力版にしない。入力監査の照合成功と、時計後退/LastとBBOの不一致等の品質注意は別に記録する。
