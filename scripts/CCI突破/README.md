# CCI持続と上位BB幅の検証

[試行00031](../../study/00031_CCI持続と上位BB幅/README.md)用。3分の前20高安への終値突破とCCI20の現前の実方向偏りをC0とし、公開15分BB20の絶対幅拡大を加えたC1と比較する。全入口は順行、売りは買いの符号反転条件。

## 計算・公開の境界

CCIは元H/L/C各値をFractionへ変換してからHLC3、同じ現在20本の平均、平均絶対偏差MD、係数3/200を計算する。表示floatと、採否用の厳密分数・±100境界を分ける。MD=0は無効。3分の価格・CCI窓は当場の連続公開足に限る。

15分BBは価格で割らない絶対幅4σを使う。数値銀行の同限月carryと、判断時点で使える当場の隣接公開二足を分ける。現前の幅増加は元終値のFractionから母分散差を厳密比較し、差0を拡大にしない。分数は幅差ではなく分散差である。最新公開が不準備なら、古い正常値へ戻らない。

全案で数値準備・時点・ATR・執行・保護を共通にする。上位幅の値で不採用になった群を、自動的な反転注文へ変えない。現在終値突破と前CCIの方向だけで現CCIの閾値が自動成立するわけでもなく、現前の両値を保存する。
