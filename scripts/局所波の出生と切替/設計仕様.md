# 局所波の出生と同原因切替の入力仕様

作成日：2026-11-06。[試行76の計画](../../study/00076_局所波の押戻しと起点喪失を分ける/検証計画.md)を正本とする。本体と人工だけを作成した段階で、出生ATRの本物再構成、新価格計算、先着、損益、運用、fitは未実行である。3足、1ATR、9本、R確認3本、直接技法条件は独自規約であり、原典の実証値ではない。

## APIと責任の範囲

`extract(old_slot, history_sources, birth_atr_rows, decision_quote, prior_band) -> dict` は政策共有観測を返す。`choose(old_slot, observation, policy) -> dict` はL0又はL1の純判断だけを射影する。`self_test() -> dict` は架空の価格・ATR・保存指標・気配だけを使い、成功、テスト件数、照合項目数、不一致数を返す。

- `old_slot`：旧73保存Q0のsession、純10項目、feature。純10はscheduled/time/line/side/role/atr/D/reason/ready/slot_id。時計・現在ATR/D・featureを検査するが、旧side/role/reason/predictionは採否に使わない。
- `history_sources`：当場index0からの全3分SOURCE13配列。後続未来suffixを含めてもよい。SOURCE13はsession/index/minutes/start/end/confirm/confirm_line/publish/missing/open/high/low/close。
- `birth_atr_rows`：[出生ATR.py](出生ATR.py)の`visible_rows`が返す可視行配列。価格順に全可視行との一対一照合を要求する。packageそのものではない。
- `decision_quote`：旧55保存のnow/line/valid/bid/ask/last。旧未準備時はNoneのまま。未来約定・先着・回収は受け取らない。
- `prior_band`：75と同じdecorate済み前収録帯又はNone。使用するのは当時場所の診断だけであり、局所の準備や資格を増減しない。

固定75の[入力.py](../事前帯と現在の反応/入力.py)をSHA `2ef17219cb82b9ca45e106ba9abf84837c1649e73c60519030a2bdd33aba6f2a`で確認し、純粋な時計、公開prefix、保存値、quote、帯snapshot等の補助だけを再用する。旧Endpoint/extract/chooseは正式経路で呼ばない。旧globalsを変更しない。出生ATRの銀行計算や現ATR/D照合は外層の責任で、本体は銀行を動かさない。

## 可視性、照合、追加準備

旧feature.readyと旧純readyのbool完全一致を要求する。旧ready=Falseは、line=Noneを許す旧契約の小型未知観測を返す。他の入力を読んで復活させない。後のready=True枠では全prefixから再構成するため、前の定時枠が未準備でも検出時計が失われない。

公開処理はend<=scheduledを価格検査より先に適用し、次に公開key `(confirm, confirm_line)<= (time,line)` を適用する。future suffixのOHLCを検査・転記しない。end/keyが不正で未来か判定できなければschema例外。publish=Falseでも可視時計が確定していれば不完全足としてresetする。NPの非有限公開時計を補完して可視とみなさない。可視のindex/key重複・後退、prefix先頭がindex0でない、末尾と旧feature.base.base.sources.currentのSOURCE13全文差は停止する。

可視prefixのSHAはsort_keys、compact separators、ensure_ascii=False、allow_nan=TrueのJSONとする。既知の不良価格も指紋には残すが、観測のresetには足番号・公開key・end・理由だけを保存し、非有限価格を出力へ転記しない。出生ATRの全行SHAは同じ固定JSONだがallow_nan=False。

出生ATR行はSOURCE13全文SHAと、session/index/minutes/start/end/confirm/confirm_line/publish/missingをJSON型を含めて照合する。valid/readyはbool、numeric_countは非負int、reset_reasonsは文字列配列、atrは有限値又はNone。readyはvalidかつ有限正ATRと一致させる。valid=FalseでATR値がある場合も停止する。Noneの種不足と既知0を区別し、ともに検出準備不足として扱う。

不完全・不正OHLC、番号/end不連続、出生ATR未知で親とbufferをclearする。品質resetは期限より優先する。不連続が価格不良と同時なら不連続理由を保存する。reset足を新aへも使わず、その後の価格・ATRが準備済みの完全隣接3足で機械を再準備する。初期と品質/ATR reset後は3足未満をready=False「出生準備待ち」とする。3足が揃えば出生条件falseでも既知WAIT。正常な親の期限・取消終端ではprepared=Trueを保ち、新a/m/b待ちの0〜2足を新たな未知にしない。

## 一親の状態遷移

親IDは`session|W|方向符号付き|b.index|float(b.confirm).hex()|b.confirm_line`。T/R形成IDは親IDに`|T`又は`|R`を付ける。方向は出生時に固定し、Tは親方向、Rはその反対方向。同時に親一件、同時active形成は高々一件である。

出生は直近完全隣接a/m/bの終値差2つが同符号strict正、かつ方向付きCa→Cb進行がATR_b以上の場合。比較は`Fraction(str(value))`で行う。originは上昇親a.low/下降親a.high。bの公開がb.end+1620より後なら親を作らず、`history.rejected_births`と当該最新足の理由へ「出生公開が寿命後」を記録する。

親がある間は新しい出生を探さない。親終端/reset足は次のa/m/bへ兼用せず、次のa/m/bは終端後の3足から取る。最初r待ち、T確認待ち、T有効、T取消後の親起点喪失待ち、R確認待ち、R有効、親終了を分ける。

| 段階 | 優先規約と動作 |
| --- | --- |
| Tのr前 | 最初origin終値喪失をfへ。なければ最初の逆向きstrict終値差をrに固定。終値差0はrでない |
| Tのk前 | origin維持の間、別足で最初r実方向端strict終値突破をkへ。r反対端の一時喪失だけでは取消しない |
| Tのk後 | 買max(origin,r.low)/売min(origin,r.high)のstrict側を終値で保つ。等号否定でT永久取消。originが残れば親はR待ち |
| origin喪失f | r/k処理より優先。最初のfを固定しT終了、同じ親のR確認待ちへ。fをkへ兼用しない |
| Rのk前 | 元origin再獲得を確認より先に終了。f後1〜3の別足で最初のf実R方向端strict終値突破をkへ。3本目は時計が期限内なら確認を先に許す |
| Rのk後 | 買max(origin,f.low)/売min(origin,f.high)のstrict側を終値で保つ。等号否定で親終了。同fの再確認なし |

T/Rともtrigger_lineとpremise_lineを別に保存する。k後にtriggerへ戻っただけでは取消しない。Tのrは取り直さず、Rのf/kも取り直さない。T戦術線否定だけでは反対候補を作らない。R確認前のorigin回復、R確認後のpremise否定は親終端である。

親期限はb.end+1620、未確認R期限はmin(f.end+540,親期限)。可視足のend又はconfirmが期限をstrict超なら、価格段階の確認より先に期限終了。等号を許す。R確認後はf期限を使わず親期限だけを使う。最後にactual slot.timeでも期限を検査する。予定時計のみへ置換しない。late_f.remaining_barsはmin(3,親期限までの残り完全3分本数)。残り1本/0本を理由で区別し、0本のfでは同足にR確認余地なしで親を終了する。

独立900秒gateはない。k.end<=scheduledと公開key<=実判断、親寿命を満たす同一kの次枠再参加を許す。k最速はb+2なので、同じ有効kが通常最大2つの900秒予定へ入る境界を人工検査する。これは独立episode支持ではない。

## 観測の保存schema

topは`base_ready/ready/reason/source_count/source_sha256/atr_source_sha256/history/parents/formations/candidates/qualifications/selected_by_policy/band/location/side/role/selected`。topのside/role/selected/reasonはL1の共通選択を表示する。L0/L1の別はselected_by_policyに保存し、観測そのものを作り直さない。

- history：current SOURCE13、resets、birth_bufferの出典、preparation `{ready,count,required:3,reason}`、rejected_births。
- parents：id/direction、a/m/b、atr_b/birth_atr_source、origin/deadline、最初r/f、T/R辞書とT_id/R_id、birth_tip/tip_before_r/current_tip、active/status/terminal/late_f/trace。
- formations：id/parent_id/kind/side/b/r/f/k/trigger_line/premise_line/deadline/active/status/cancel。親内T/Rと同じ内容を一覧化する。
- candidates：現在active形成の複写。k_age_seconds=`actual-k.confirm`、k_end_age_seconds=`scheduled-k.end`、tip_distanceを追加する。tipは診断でありgateではない。
- qualifications：形成IDからqualified/role/reasons/values/priceへ。priceはLast、E*、premise、両方向距離。
- selected_by_policy：L0/L1それぞれside/role/reason/selected。選択なしのside0/role待機、Rだけ有効時のL0は「R形成はL0で採用対象外」。

tipは終値ではなく方向high/lowの極値で、同値は先頭出典。birth_tipはa..b、tip_before_rはr前の既知足までで固定、current_tipは親の期限内処理足まで更新し、価格による取消判定足も含む。期限を超えた足は遷移前に終了するため含めない。r足のヒゲが逆行の前か後かは推測せず、後からbirth_tipやtip_before_rを有利な過去形へ書き直さない。

traceは親に一元化し、形成の最初cancelは別に保存する。公開足参照は`{index,key:[confirm,line],clock:公開足,end}`、判断timerは`{index:None,key:[slot.time,slot.line],clock:判断時刻,end:None}`。traceはこれにaction/status/activeを加える。terminal/cancelはreasonを加える。毎足のtrace全件複製ではなく遷移時だけを残す。

## 資格、場所、純判断

旧float64値を再用しfloat32へ変換しない。F01/F02/F03/F07/F15は方向鏡像、F47/F48/F51/F52は方向不変として旧helperが検査する。現在ATR/Dも旧保存値と一致させ、出生ATRへ置換しない。

全候補はF02>=0、F03>0、F07>0、F01/rawDI非零。TはF01>0、F51=F52=1、F47>=.20、F48>=0。F47はADX/100なので100倍後の比較を追加しない。RのF01>0は順行、F01<0ならF52=1、F48<0、F15>0で反転。T/R名をDI roleへ流用しない。

正常BBO bid<askと正有限Lastを要し、Last及び実方向E*（買ask/売bid）がpremise strict側であることを求める。quote不良は現在ready=False、機械の過去形成を取消しない。後の正常枠で過去全prefixから同じ形成が再現される。現在quote不適格と公開終値による永久取消を分離する。

bandは旧75の未公開maskを通した小型snapshot。locationはready/reason/by_sideで、各実方向のE*、上外/下外/上端/下端/帯内/未知、H/M/Lの方向距離、strict前方参照線を保存する。前方線がなければ空配列、帯やquoteが未知ならNoneで、無限余地とはしない。距離<=D、R中央250余地、新量gateはない。

chooseは純10とsession/policy/origin/pattern_id/parent_id/formation/premise_line/trigger_line/birth_atr/band_idだけを返す。feature/旧予測/損益は転記しない。originは「局所波継続」「同原因起点喪失反対」「局所波待機」。L0のT純判断があるときL1も同じT・純10、L0なしでL1があればRだけ。実一建玉の参加包含は保証しない。

## 人工と実行の境界

人工は出生strict/ATR等号、複数足押戻しと最初r、T取消後の親保持、同原因f/R、R3本目と4本目、確認端戻り、origin再獲得、全売買鏡像、DI/ADX/FastK/CLV、現在Last/E*、前帯不明、ATR未知/0と3足再準備、価格不良/不連続、future不正suffix、旧採否/予測改変不変、公開/end/actual期限等号、late f、終端足再使用禁止、r前tip、同秒公開key、SOURCE/ATR欠落・偽指紋等の拒否を含む。

実行例は `C:/Python314/python.exe -B -X utf8 scripts/局所波の出生と切替/入力.py`。このCLIは人工のみで、本物出生ATRや価格銀行を動かさない。正式接続、同準備数、出生頻度、先着、回収、活動、費用の結果はまだない。正式実行はrootの固定後指示に従う。
