Python3.14.3・NumPy2.5.3、キャッシュ復元は既存orjson3.13.0。追加の学習ライブラリやGPUは使っていない。原板は複製せず、4種類の詳細gzipは`work/数量反転/00014/`へ保存する。圧縮内容のSHAではなく、展開内容SHA256を正本とする。

```powershell
python -X utf8 scripts/数量反転/合成検証.py
python -X utf8 scripts/数量反転/数量事前照合.py
python -X utf8 scripts/数量反転/数量独立確認.py --実行許可
python -X utf8 scripts/数量反転/独立監査.py --api-base http://127.0.0.1:8092
python -X utf8 scripts/数量反転/補助対応診断.py
python -X utf8 scripts/数量反転/注意経路診断.py
python -X utf8 scripts/数量反転/レポート.py
```

数量独立確認を先に保存し、主監査が正式結果へ取り込む。`--実行許可`は正式数値再生後に独立確認を実行する順序のフラグで、ユーザーへの追加承認要求ではない。API照合にはViewerを同じ市場root・本repoのresource_rootで起動しておく。`--api-base`を省略するとAPI以外のローカル監査を行う。

数値再現は別の空試行先へ正式`計画.md`と`条件.json`をコピーして行う。

```powershell
python -X utf8 scripts/数量反転/検証.py --study work/数量反転/再現00014 --work work/数量反転/再現00014詳細
```

正式結果上書き・固定後の条件/コード/入力変更は拒否する。先着分母に期限未達・観測不足を残し、未約定を別記する。数量基準完全は全約定収録の完全性ではなく、CurrentPriceTimeは受信時計ではない。量の増加を方向別フローや参加者の建玉へ読み替えない。注意部分の事後除外は実行可能な回避規則でも全体成績の代用でもなく、注意を含む全体の確定額は未確定を維持する。
