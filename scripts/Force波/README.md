上位は当場可視の最新15分uと隣接前足を、end≤下位endかつ公開key≤下位要求keyで参照する。新中心化MACD12/26/9の一足差Dを使い、水準signは使わない。最新不良を古正常へfallbackせず、同じ上位uをp/bで二度見ても独立二確認ではない。上位数値は同契約carry、完全NP内部更新、公開参照は当場限定である。

Force素X=(C現−C前)×q現、初2有効Xmeanを種に以後F2=(2X+前F2)/3。元C/qのFractionで値と符号を分ける。完全非負0q/0Fは有効、欠測を0へ補完しない。q不完全ならForceを解除しても正常Cを次足価格基準に保持でき、前価格足qは不要。NP/欠枠/不正/局所不連続は価格/Forceを解除する。観測差分量は全約定量や真の売買側フローではなく、0qでも過去Fの1/3が残る。

p/bで同じ非0背景sを知り、sF前≥0からsFb<0のcrossをb候補として記録する。b受理はdeadline前だけで、ATR/cutoff/残60分/遅延30秒を先に課さない。全体一監視、監視中の別波を置換せず、終了同足の再登録なし。元bから6足の寿命をjでresetしない。Force/最新上位pair未準備・価格不正・期限等を先取消、D0/逆だけなら監視維持する。

回復前の元逆端strict終値失敗を先WAIT。後続対象足の最初sF>0でD=sならjを固定し、D不一致はmonitorWAITで終える。j後の最初終値端だけをrawにし、元買ならC>HjがT/C<LbがR、売りは鏡像。端等号未到達、高安touch順序を推定せず、技術/時間不成立でも後端へ取り直さない。対象はend>親confirmとkey>親key、start>親confirmは要求しない。

Tは実side=s・順行、Rは実side=−s・反転。最初端で現在D/Fが実方向へ一致し、終端k/fのATR/時間/遅延が有効な時だけ採用する。ATR未準備は最初端でWAIT消費し、b/jATRへ取り替えない。回復前WAITは価格rawや新先着caseへ増やさない。RはTの将来損失/不採用補集合ではない。
