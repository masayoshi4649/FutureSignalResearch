# FAR背景維持と押戻し再開

[試行88](../../study/00088_背景維持と押戻し再開の時系列比較/README.md)のオフライン検証コード。元FAR後期三手法と固定87金融を参照し、S・現在資格E0・時系列資格E1を二遅延で比較する。実発注機能はない。

## 判定と責務

- `entry.go`：15分時点の複合資格、Source供給ID部分列、元順位と供給順位の分離。
- `event.go`：独立eventBankの確定3分足による進行・押し戻し・回復・勢い確認、失効と期限。
- `replay.go`：旧時計と追加3分時計、元Source、6金融会計、注文結合、診断専用初回利益観測。
- `source_equivalence.go`：元Sourceの全Step/Force/Gridと固定旧Referenceの同値照合。
- `input.go`・`batch.go`・`cmd/batch/`：固定入力、種の引継ぎ、並列処理、新規保存。
- `集計.py`：396会計、費用、対応分解、圧縮共有記録、Viewer約定と一覧。
- `基準と保存判断の照合.py`・`イベント保存照合.py`：旧S/C0同値と保存入力からの順序・資格・供給・注文結合の再構成。
- `原板監査.py`：原板1走査で所有・価格・G1義務・初回利益contextを照合。
- `Source通知監査.py`・`イベント原板結合.py`：別の原板1走査でSource通知・取消・丸め・足のClose/TR・失効・利益原行出典を照合。
- `表示監査.py`・`図示.py`：Viewer APIの396資源照合と損益比較図。
- `入口と利益の診断.py`：既存4正本から取得と利益初回の記述統計。新しい出口の反実仮想損益は生成しない。

金融とSourceの本体は固定87をimportする。旧ファイルを編集せず、外政策S/E0/E1と金融内部S0G1を区別する。費用後現在単価がstrict正になれば最低建値床を起動し、G1の実確定部分益だけを残玉保護予算に使う。入口時計・費用・遅延・利益保護は[検証計画](../../study/00088_背景維持と押戻し再開の時系列比較/検証計画.md)に記す。

## 検査と実行

Go 1.24.2 windows/amd64、CGO=0、Python 3.14.3。Go依存は相対`replace`で固定80〜87と隣接する`SessionTradeExecuter`を参照する。純戦略43ファイル、入力66場396ファイル、固定コードは試行の条件と台帳のSHA256で確認する。

```powershell
Push-Location 'scripts/FAR背景維持と押戻し再開'
go test -count=1 ./...
go vet ./...
go build -trimpath -o '../../work/再現88.exe' ./cmd/batch
Pop-Location
```

明示export3本は通常skipし、環境変数による専用出力先の指定で合成入力を新規出力する。各契約は`export_test.go`を参照する。自然Sourceの合成3場、実指標＋手製Sourceの売買2場、手製APIの検査範囲を混ぜない。

全66場の固定exe実行は次を使う。作業先は未使用の`work/`子領域を指定する。条件のexe指紋に合わない新buildは、正式結果へ紛れ込ませない。

```powershell
& 'scripts/FAR背景維持と押戻し再開/ネイティブ実行.ps1' -OutputRoot 'work/88再現' -ValidateOnly
& 'scripts/FAR背景維持と押戻し再開/ネイティブ実行.ps1' -OutputRoot 'work/88再現'
```

集計以降は各Pythonの`--help`と[再現補足](../../study/00088_背景維持と押戻し再開の時系列比較/再現補足.md)を参照する。既存出力は上書きせず、原板・正式旧試行・台帳を変更しない。

## 証明の範囲

eventBankと旧actualの数値同値は共通数値器の時計差を検査するもので、数値器の独立再実装ではない。種の前史も固定依存とする。NK原板監査ではTOPIX終端を別走査せず、TOPIX由来の終端は固定入力指紋と元ドライバ/旧S/C0同値へ依存する。ラージ気配でmicro約定を代理し、板深さ・順番・実通信・証拠金は未実証である。
