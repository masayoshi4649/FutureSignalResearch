## 数値境界と解釈

BB幅は価格で割らない4σ。同じ20本の現前比較なので、幅の増加は母分散の増加と同値である。採否は原終値のFractionによる母分散差の厳密符号を用い、等号の浮動微差を拡大としない。分数の分子/分母は幅差ではなく分散差として保存し、表示の幅はfloatと分ける。

PSYは現前それぞれ12比較のU/D/Fを保存する。同値Fは中立、売りは100−上昇率で作らず、整数U−Dの符号で決める。現前で14終値が必要。U>Dは上昇回数が12回の過半数という意味ではなく、連勝順序や投資家の人数も分からない。

価格突破では現在の終値変化が必ず実方向なので、前の方向差が実方向なら現も自動的に同方向となる。予定の両条件は維持し、二つの独立票とは扱わない。主題は突破前からの回数偏りの追加価値である。ATR以外の局所窓は同場・公開有効足だけを使う。
