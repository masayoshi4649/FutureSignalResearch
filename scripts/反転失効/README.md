# 反転不成立からの継続の検証

[試行00016](../../study/00016_反転不成立からの継続/README.md)の固定12案を再現する。固定00015の反転乖離を準備とし、単純逆向き/価格失効待ち、1/3/5分、実際の入口側と15分方向の一致有無を比較する。全65場は既使用。

価格失効は準備の次足から6本以内。最新一件の監視を、原順序で登録・置換・発動・消費・満了する。消費した最初の失効を後の条件成立まで再利用しない。準備の属性と実際の発動時属性を分けて保存する。条件と版の正本は試行の計画/固定/設定と結果。

Python3.14.3、NumPy2.5.3を使用。合成と保存結果の再表示は次のとおり。

```powershell
python -X utf8 scripts/反転失効/合成検証.py
python -X utf8 scripts/反転失効/レポート.py
```

正式保存先の上書きを拒否する。別再現先には計画/条件だけをコピーし、旧core・旧cache・元の00015条件を参照する。原板は複製しない。

```powershell
New-Item -ItemType Directory -Path work/失効再現/試行
Copy-Item -LiteralPath study/00016_反転不成立からの継続/計画.md,study/00016_反転不成立からの継続/条件.json -Destination work/失効再現/試行
python -X utf8 scripts/反転失効/検証.py --study work/失効再現/試行 --work work/失効再現/明細
```

`状態独立確認.py --実行許可`は原価格から全準備・監視・発動を再構成し、別先には`--study/--work`を指定できる。`独立監査.py`・`補助対応診断.py`・`レポート.py`の既定対象は正式00016であり、別再現先の検査と混同しない。Viewer照合付き主監査は`独立監査.py --api-base http://127.0.0.1:8092`。

先着率の高低と売買の反転は補数にならない。費用・空白・支持不足を残し、検査の一致を安定収益の立証とはしない。
