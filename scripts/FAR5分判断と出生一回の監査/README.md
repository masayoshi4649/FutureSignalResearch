# 5分判断・出生一回の独立監査

[試行95](../../study/00095_5分判断と開始30分見送り/README.md)の新しい入口時計と、継承した金融を分けて検査する。金融コード群から独立したread-onlyの監査群であり、新規条件や売買量へ出力を戻さない。

`出生と5分境界の照合.py`は、固定94の[原板/保護部品](../FAR個別利益追尾の監査/原板と保護の照合.py)をSHA256 `1437804124be71ba5254b57b583c8cc4db247f3bbb8749f89a6ac07c55caf5a6` でimportする。旧金融/全正常原行MTMの式を再用し、出生・strict次slot・quiet・Source当時残/予約・一回消費・grid行動を別状態で再構築する。

両市場のLast0を含む受理board時計から観測済みgrid列を復元する。Actorの最新QuoteはLast正のNKのままとし、古い正常行への巻戻しやQuote再時刻化を受理しない。未観測EOF後のgrid/新規は作らず、元Force通知だけを維持する。正常BBOの最初の適格Fill、Sourceclose比例/全取消、独立5分ATR・非緩和床・u/W・口座DDも照合する。

N4口座は固定94の保存Nativeへ、新しい5項目だけを除いて全既存fieldを比較する。保存Sourceの通知を使う監査であり、元戦略の全判断再生成や実mini固有板の約定保証とは分ける。

```powershell
& work/venvs/technical-tree/Scripts/python.exe -B -X utf8 scripts/FAR5分判断と出生一回の監査/出生と5分境界の照合.py `
  --run --input work/95実行/正式54場 `

```

`--fixture`は明示Go型人工、`--self-test`は基礎slot算術。実入力は`--run`を要する。先頭2場接続は`--limit 2`を明示し、54場全体の成功へ読み替えない。出力は新規先だけに保存する。Python 3.14.3・標準ライブラリ。評価は実現損益・費用・利益後赤字額・DD・回数を中心とし、機会損失は採点しない。

`集計.py`は保存95口座の金融算術・半円費用・配賦・u/W保存点を固定94の表記訂正後コードから再用する。95の出生とOpportunity/grid受理を別に結び、出生時刻を書換えたり架空受付イベントへ変換しない。Source比例作用・予約込みcap・実所有0・N対94全文を検査し、648Viewer資源と圧縮Nativeを作る。

保存だけの集計ではgridが全予定の連続prefixであることと、同Replay全12口座の時計列一致を検査する。EOF価格時計までの取り落としは原板側の検査であり、84/156の全予定枠を観測済みと仮定しない。

連続Nの同秒原行と枠前の予約は、価格時計だけで結合しない。Force→grid→同時計の後原行の順序を用い、B系の当枠受理だけを枠終了の予約へ加える。二つの保存検査の訂正範囲は試行95の記録を参照する。金融コード・固定条件・約定は変更していない。
