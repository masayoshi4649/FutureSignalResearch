幅は価格中心で割る公式BandWidthと別で、価格反射を維持する。追加8列は買売両vectorで同値、8つの独立票ではない。同限月carryで得た現値と、当場の完全隣接公開ペアから得る差は準備が異なる。最新の上位sourceは旧upperと一致させ、非可視前足を出典へ残さない。[特徴仕様](特徴仕様.md)を正本とする。

根は62と同じfloat32 F01<=0。非正側はRのk有効F27（index26）、正側はTのk有効F21（index20）を各0.5で分ける。D0_K0/D0_K1/D1_K0/D1_K1の子は、DIと対応旗だけを除く52列・深さ2、全深さ4。非正側はindex0/26、正側はindex0/20を除き、対象外経路の旗も子に残る。k0は未登録・未確認・取消・失効等の混合で、捨てずに学習へ残す。DI非正には同値/float32零化もあり、最終DI同値WAITは維持する。

J0は障壁score最高側についてscore>=1/3・葉支持・複数技法資格・過去回収60枠6日10場を要求し、J1は同じ木で過去pnl5合計strict正も要求する。回帰平均で方向を順位付けせず、次点救済もしない。固定根のtrend+priceで従来技法gateは構造的に充足するが、式の緩和や独立情報の追加と呼ばない。空葉のscore・平均はnullを保持する。

小型の結果・保存監査・新3木/3回収集計・旧62保存モデルから二MDを生成する。全54特徴、55手法×9尺度、全node/葉・枝別投影・子trend/osc、状態四群、全定時の価格経路・追加数値の局面分布・葉別episode反復を表示する。局面分布は旧ready枠が分母、状態四群は使用教師方向行が分母で、純採用・実完結とは別。unique枠や形成IDは重複するため群/葉間で加算しない。
