# 同じ方向・再開確認の分岐へADXと絶対BB幅を追加する

作成日：2026-11-06。63の純学習仕様。本物入力・教師・保存実モデル・本物fitは扱わず、固定62のコードと人工行だけで実装・検査した。

## 比較と範囲

[旧62学習](../方向と再開確認/学習.py)をLEGACYとして使用する。全46特徴、教師pair、pnl5回帰目的、固定DI→対応k、子深さ2/全体4、min_samples_leaf60、方向重み0.5、seed51、障壁score順位、葉支持、複数技法gate、回収追加条件を保つ。

旧46列の後へADX/BB値4列と有効mask4列を追加し、全54列とする。追加指標が未準備でも旧readyと教師集合は変えない。未知値0と既知0をmaskで区別し、全準備枠を同じ教師pairで比較する。未知maskを根拠にpairを追加除外しない。

fit/modelのpolicyはJ0。J1は同じJ0木へ従来の回収支持とstrict正額条件を後段で加える。旧K0/K1は保存対照で、本コードは再学習しない。

|ID|内容|method|family|scale|数値検査|
|---|---|---|---|---|---|

|F48|15分ADX同場現前差/100|I08|trend|m15|−1以上1以下|
|F49|15分絶対BB幅4σ20/現在3分ATR|I05|vol|m15|0以上|

metadataは旧46列を旧62へ渡して検査し、追加id順・method/family/scale・空でないnameを検査する。表の短名と完全同じ文字列であることは要求しない。

追加値はboolを除く有限実数。四つのmaskはboolを除く数値の0/1とし、mask0なら対応するF47..50が厳密0であることを要求する。F52=1ならF51=1、F54=1ならF53=1も必要。差が未知なら差0/mask0、現在値が未知なら現在0/mask0とする。現在と差の両maskが1でも値0は有効な同値/零幅である。

検査はraw値の領域と整合を先に確認し、float32化後の有限性も確認する。新しいepsilon、丸め救済、欠測を別値へ補間する処理は作らない。旧46列は旧62.float32へそのまま渡し、段階・旗・適用外値の旧検査を保持する。

学習器はADX/BBや時点の計算を担当しない。15分現在sourceの旧参照一致、同場隣接前値、49銀行と同じcarry/reset、BB母分散/絶対幅、売買反射の不変性は特徴側の責任である。F49は公式の4σ/SMA20と式が異なり、F50は各時点のATR比の差ではない。

## 教師pairと指紋

1. 全入力の54値とmaskを検査する。
2. features先頭46列を旧62.prepare_rowsへ渡す。
3. 旧62が全pairの障壁/回収既知・未来境界を検査し、使用ID集合を確定する。
4. 元入力順の54canonicalを作り、同じID集合だけをusedへ戻す。

片側だけの追加、未知pairの一側救済、枝内のpair成立要求は行わない。使用教師数・row_idsの順・target・期間は旧62と同じで、各方向の重みは0.5。

training.base46_fingerprintsは旧62全46教師の六値を保存する。

```text
input_rows_sha256 / used_rows_sha256 / row_ids_sha256
target_rows_sha256 / period_sha256 / used_barrier_rows_sha256
```

base18_fingerprints/base30_fingerprints/base38_fingerprintsも継承する。新54canonicalのinput_rows_sha256/used_rows_sha256/used_barrier_rows_sha256は追加8列を含むので旧46の値とは別である。row_ids_sha256/target_rows_sha256/period_sha256は変えない。

feature_missing_handlingは `旧62全46準備の同じ教師pair。追加8指標は未知0＋有効mask、追加除外なし`。障壁教師は250が1、125/期限が0。回収教師pnl0/5/10の既知とstrict過去終了境界も旧62と同じ。教師不足を現在のreadyへ逆流させない。

## 固定三node・四群・枝別52列

|node|feature|左|右|
|---|---|---|---|
|0|F01 index0、threshold0|D0、node1|D1、node2|
|1|F27 index26、threshold0.5|D0_K0|D0_K1|

比較は旧62同様float32、左は<=、右は>。DI非正側はR k、正側はT kを参照する。微小正DIのfloat32零化でD0へ入る場合があり、厳密DI/実運用roleと完全同値とはしない。厳密DI同値の最終WAITは主処理で保持する。

四群を全て残し、k0を即時WAITや教師除外へ変更しない。空群でも固定三nodeは常設し、子は未知leafのscore=None/data_absent=Trueとする。どちらかの方向が未知leafへ到達すれば両方向WAITで、score0補完しない。

低側D0の子はglobal index0/26を除く52列、高側D1は0/20を除く52列。追加F47..54は全て両枝の候補となる。子のlocal feature indexは合成時に元54列のglobal indexへ戻す。

子はDecisionTreeRegressor、criterion=squared_error、splitter=best、max_depth=2、min_samples_leaf=60、sample_weight0.5、random_state51、max_features=None、ccp_alpha0等を旧62から再用する。固定段を含めmax_depth4。固定段はMSE最適分岐ではない。保存合成モデルは三phaseで3本、回帰器fitは非空群だけで最大12回、分類器fitは0。

## 予測と資格

54列用のJSON walk/predictを新ファイルへ実装し、旧62の46列globalや政策名を書き換えて呼ばない。入力をfloat32化し、保存thresholdで木を走査する。循環・子ID・feature index不正・保存path不一致を拒否する。joblibは使わない。

両方向は同じ木を使用する。回収meanでなく障壁scoreのstrict最高側だけにscore>=1/3、unique枠>=60・6日・10場、複数family条件を課す。同点、片側未知、最高側不適格はWAIT。下位側が高回収でも救済しない。

固定trend+priceが全有効pathへ入るので従来技法gateは構造的に満たすが、資格関数は変更しない。ADXとDI、BB幅と価格特徴は同じ価格由来であり、独立した票や原因とはしない。追加maskも対応するI08/I05へ属し、独立した新技法familyを増やさない。

J1は同じ最高側へ従来の回収支持/strict正額条件を追加する。予定枠分母、保有非待ち、正常BBO、+1秒/TTL、連続損失追尾、現在純益122円strict起動・最低名目新規床、費用、強制返済は固定O49のままで、本学習器は変更しない。
