# 局面強弱の追加特徴

確認日2026-11-06。[62の全46特徴](../方向と再開確認/特徴仕様.md)を保持し、15分の方向性の強弱と変動幅を8列追加する。売買方向で追加8列の符号は変えない。方向票ではなく、既存の価格段階・短期ストキャス・ATR等と組み合わせる文脈である。

| 列 | 式・意味 | 手法/系統 |
| --- | --- | --- |
| F47 | 現ADX14/100 | I08/trend |
| F48 | (現ADX14−前ADX14)/100 | I08/trend |
| F49 | 現15分BB価格幅/現在3分ATR14 | I05/vol |
| F50 | (現15分BB価格幅−前15分BB価格幅)/現在3分ATR14 | I05/vol |
| F51〜54 | 順にF47〜50の有効旗0/1 | 対応する数値と同じ手法/系統 |

全列の時間スケールはm15。F49/50の正規化には既存の現在3分ATRを使う。現前のBB幅を同じ現在ATRで割るため、F50の符号はBB価格幅の差の符号であり、ATRの変化による比率差ではない。

追加数値が未知なら対応値0・有効旗0とし、既知の数値0・有効旗1と区別する。追加欠測で旧readyや教師pairを落とさない。これは欠測を低ADX・収縮と解釈する規則ではない。学習木へ値と旗をともに渡すため、実際にどちらが使われたかを結果に残す。

ADXは固定49のSOURCEから数値銀行を再構成した値とする。Wilder14の種・更新・同限月carry・欠枠/無効/場末不足/限月変更のresetを維持し、現DIが固定50slotの保存DIと一致することも確認する。BBはこの銀行のnumeric_count/resetに同期し、直近20有効終値の母分散から4σを求める。分散まではFraction、平方根はfloat。正規のセッション境界で同限月の数値助走はcarryできるが、現前差は当場の隣接足に限る。

現在の15分足は旧upper.sourceとSOURCE13が完全一致し、予定時刻以前に終了、実判断の価格時計と原行までに公開されたもの。前足は同場index−1の完全隣接かつ当時公開足で、現在へ数値種が連続している必要がある。非公開・未来の前候補は診断列もNoneへ消し、より古い足へ代替しない。

公式のBandWidth `(上帯−下帯)/中心線` と違い、ここでは価格幅を使う。価格を定数−価格へ反射すると中心線は変わるが、価格幅・ATR・ADXは不変になるためである。20本窓から古い値が抜けても幅は変わる。幅拡大を新規参加や注文流入の実測とはしない。

APIは `build_context(sessions)`、`extend(slot, old_feature, rows)`、`control_projection(feature)`。最初は固定49inputs形式のSOURCE、二番目は固定50slotと固定62の46特徴を受け取る。返り値に全54vector、旧46vector、局面数値・有効旗・現前SOURCE・BB窓の識別指紋を持たせる。旧射影は追加前dictと完全一致させる。原板や全窓OHLCの複製を作らず、入力台帳とSOURCE銀行へ結ぶ。
