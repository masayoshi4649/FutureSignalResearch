# 高位高安の突破と再テスト再開

[試行00023](../../study/00023_上位高安の再テストと順行再開/README.md)の再現用コード。3分の二運用B0/C0、15分S2、公開30分6本の固定高安を扱う。計画・数値条件・固定SHAは試行側を正本とする。

## 実行と保存

リポジトリルートでPython 3.14.3、NumPy 2.5.3を使用する。市場入力・大きな作業明細は既存の台帳参照と `work/高安再開/00023/` を使い、原板をコピーしない。

```powershell
C:/Python314/python.exe -X utf8 scripts/高安再開/検証.py --prepare
C:/Python314/python.exe -X utf8 scripts/高安再開/状態独立確認.py --prepare
```

上記は登録・再テスト・再開と準備の件数だけを点検する。先着ラベルと損益は計算しない。人工足の最終合成成功・編集終了、コード/条件/計画/入力の固定確認を経て正式再生する。

```powershell
C:/Python314/python.exe -X utf8 scripts/高安再開/検証.py
C:/Python314/python.exe -X utf8 scripts/高安再開/状態独立確認.py --実行許可
C:/Python314/python.exe -X utf8 scripts/高安再開/追尾独立確認.py --実行許可
C:/Python314/python.exe -X utf8 scripts/高安再開/独立監査.py --api-base http://127.0.0.1:8092
C:/Python314/python.exe -X utf8 scripts/高安再開/対応診断.py
```

正式再生は既存結果の上書きを拒否する。完了済み試行をもう一度正式実行するコマンドではない。別の条件を比較する場合は新しい試行とコード版を作る。独立監査・対応診断は保存結果の検算で、売買条件を再選択しない。

## 各コードの役割

| ファイル | 役割 |
| --- | --- |
| [指標.py](指標.py) | 固定21の価格指標を読み、30分の公開六本窓を別に保持する |
| [入口.py](入口.py) | 固定22のS2/R1と、新しい価格設定・監視・消費を管理する |
| [運用.py](運用.py) | 固定21の125/250pt・必須A5追尾を読み取り再利用する |
| [検証.py](検証.py) | 入力指紋、準備/正式の分離、固定、先着、二つの一建玉会計とViewer資源を保存する |
| [合成検証.py](合成検証.py) | 人工足で公開時点・寿命・買売対称・競合確定・量不関与・固定依存を確認する |
| [状態独立確認.py](状態独立確認.py) | 原価格から窓・設定単位の別区間走査で全監視/発動を再構成する |
| [追尾独立確認.py](追尾独立確認.py) | 全実保有区間の最初の要求・起動・設定線・待機中停止を検算する |
| [独立監査.py](独立監査.py) | 先着/対象外・Decimal会計・単一建玉・帰属・CSV・Viewerを検算する |
| [対応診断.py](対応診断.py) | 待機で失った機会、同episodeの別入口、同じ実新規の出口、利益回収を分ける |

同じepisodeのB0/C0は入口時点・価格・ATRが変わる。同じ実新規の出口比較と混同しない。時間条件外で消費した再開価格イベントは先着評価の対象外とし、未約定候補へ混ぜない。数量は観測差分量の診断だけで、採否や共通準備へ使わない。
