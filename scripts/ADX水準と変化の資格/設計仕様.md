## 変更範囲

[固定77入力](../押戻し再開の確認幅/入力.py)のSHA256は `cc2f9814847c29c68ce57cd79065c6af2124b65fa133eb4224169363986bcbcf`。固有名import前に確認する。旧globals・Machine・関数・ソースへ代入変更や文字列置換を行わず、旧RULESは深い写しを新moduleへ持つ。

`extract`は固定77の純出力をdeepcopyする。親、出生、r/f/k、期限、取消、再出生、形成、現在候補、SOURCEとATR指紋、history、ready、前帯と場所診断はそのまま保持する。T確認は77と同じ実方向終値反応で、`trigger_line`、固定premise、確認3項目の意味も変えない。

正常な現在気配の下で既に評価されたTについてだけ、保存された同じ9値と当時quoteから資格を明示再計算する。元の理由文字列を削る方法や、未知の資格を新たに既知として評価する方法は使わない。Rの資格辞書は元純出力の深い写しを保持し、再定義しない。

| 観測 | Tの条件 |
| --- | --- |
| 短期の位置・進行 | F02>=0、F03>0、F07>0 |
| 方向 | F01非零・raw DI非同値、さらにF01>0 |
| ADX既知性 | F51=F52=1 |
| ADX水準 | F47>=0.20（保存値はADX/100） |

旧条件もF48=0を許すため、変更は「上昇必須」の解除でなく「非減速必須」の解除である。変化mask F52は残す。未知0と既知の0／負を混同せず、ADX差を売買鏡像で符号反転しない。水準0.20の等号は許し、直下は拒否する。

Rは元と同じ。DI同方向のRは順行、DI逆向きRはF52=1・F48<0・F15>0を維持し、共通のFastK・価格条件・現在取得条件も残す。ADX低下だけで反対注文を作らない。

- F48負／零／正で、負だけが追加になり、零／正の元資格と純採用を保つことを確認する。
