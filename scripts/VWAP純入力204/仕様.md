# 204 配信VWAPの原行純入力

2026-11-18。入口候補の採否・金融を参照しない。対象は201が固定した83場のq0。同じ原行のnative VWAP、TradingValue、TradingVolume、数量時計、始値、限月・市場を追加する。原板を複製せず、q0以外の状態は保存しない。

現在はTOPIXの棚卸し。大ラージの係数はTOPIX10,000/NK2251,000。内部比率は代金÷累積数量÷係数、許容0.00010001pt。これは同じ配信内の内部整合であり、全約定から独立再計算した真の取引VWAPを認定しない。HLC3×観測数量も生成しない。

価格時計はCurrentPriceTime、数量時計はTradingVolumeTime。VWAP/代金の独自時計と受信時計はない。全原行を原順に監視し、価格時計後退、数量時計未来、累積値不正は当該状態で利用不可。q0のraw値を残し、古い正常値へfallbackしない。数量時計が場内か、起算識別が既知か、内部比率が整合かは別欄。

旧17の当場基準条件を継承する。Day当日06:00、Night当日15:45以後で開始前の両時計がある、同じ識別属性の整合累積又は直接ゼロだけを既知基準にする。始値時計が開始付近だからという理由で初期累積をゼロと推定しない。開始秒ちょうどの直接ゼロは別途許す。数量/代金減少、数量時計後退、既知限月/市場/始値変更で基準を破棄。恒等的に同じ値へ復帰しても旧基準を復活させない。

epochは観測できた累積区間変更。continuityは途中の時計・識別・累積・比率不明区間の開始/復帰も区別する。これは後の傾きや区間差分で未知を跨いだか識別するための純品質で、未知時の売買行動を定めたものではない。未観測のリセットは否定できない。

native既知は場内価格/数量時計・後退なし・内部整合・正Last・起算識別既知の交差。当場差分はそれに有効基準、同じ識別、正の数量/代金差分を要求する。nativeを当場VWAPと呼ばない。全q0・全場は残す。

各q0の値はsnapshot時にコピーし、後続同秒原行・場末診断で遡及変更しない。原板の全展開SHA、物理SHA、前後statとq0のLast/Bid/Ask/時計を201へ照合する。場全体の変更数や最終観測は事後の入力監査であり、当時入口に使う特徴ではない。
