# 配信元VWAP・売買代金の入力監査

[試行00017](../../study/00017_配信元VWAPと売買代金の入力監査/計画.md)の入力研究。固定00008のNK225全65場から必要な列だけを抽出し、配信値の内部整合・時計・累積区間・既知基準からの差分比率を確認する。入口・損益・架空のViewer取引は生成しない。

旧8列cache、旧研究core、原板を変更しない。原板のstat・展開SHA・物理行/復号行数が一致した後に小列NPZを公開する。欠測はNaN、正式JSONはnull/件数。価格時計や原行の後退、未来数量時計を採用しない。VWAP/売買代金の固有時計と受信時計は補わない。

Python3.14.3、NumPy2.5.3、orjson3.13.0を使用。orjsonがない環境では標準jsonへ切り替える。境界合成は実市場を読まず実行できる。

```powershell
python -X utf8 scripts/VWAP入力/合成検証.py
```

全量抽出は合成成功と対象コード/条件の一致を検査し、実行前に計画・コード・入力指紋を固定する。正式結果は上書きしない。`--実行許可`は、静読と合成後に全量を開始するための操作フラグである。

```powershell
python -X utf8 scripts/VWAP入力/抽出監査.py --実行許可
```

再現は新しいGit外保存先へ計画/条件/入力台帳をコピーし、入力台帳の相対参照が元00008を指すように設定して`--study`と`--work`を指定する。参照は指紋と解決先を検査する。別版の作業cacheの混在や、既存補助NPZの上書きは拒否する。

内部整合は`配信VWAP`と`売買代金÷数量÷1000`の差を0.00010001pt以内で確認する。全約定履歴を別取得して再計算した値とは区別する。開始前の整合した既知基準がなければゼロを補わない。始値属性の一時欠測行は差分参照を止め、同一確認後の行だけ再開する。既知不一致や累積減少で破棄した基準は復活させない。

`独立確認.py`は主抽出を数値計算へ読み込まず、補助NPZ全件の式/時計/基準を別計算する。原板との直接対応は選んだ標本を読む限定監査であり、全原行変換の独立証明ではない。検査の範囲・件数と再現用指紋は正式試行へ保存する。

```powershell
python -X utf8 scripts/VWAP入力/独立確認.py --実行許可
python -X utf8 scripts/VWAP入力/追加合成検証.py
python -X utf8 scripts/VWAP入力/レポート.py
```

追加合成は固定後の小型自作入力2件で、実行前の固定36件には加算しない。保存済み結果だけを再表示するのはレポート処理。次の売買研究の結合案は[設計メモ](../../docs/議論/VWAP補助列を確定足へ結合する.md)を参照する。
