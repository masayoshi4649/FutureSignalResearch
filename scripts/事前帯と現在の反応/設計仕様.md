# 75の固定帯反応・直接資格の入力仕様

2026-11-06。[75事前計画](../../study/00075_事前帯の外保持と内回帰を判別/検証計画.md)を実装する純入力。新しい市場データ、価格集約、教師、先着、損益、学習を扱わない。参考の[58保持機械](../水準を保持する再試験/特徴仕様.md)とは別実装で、同じ外試行からT取消とR成立を因果接続する。

## APIと入力

```python
extract(old_slot: dict, history_sources: list[dict], band: dict,
        decision_quote: dict | None, policy: str) -> dict
choose(old_slot: dict, observation: dict, policy: str) -> dict
self_test() -> dict
```

policyはO0/P0/P1だけ。`old_slot`は73保存Q0の純10項目・session・featureを持つ。旧予測、labels、operationを読み出さない。旧featureは64列、raw背景、ATR/Dと`base.base.sources.current`のSOURCE13だけを利用し、指標を再計算しない。old_slotとfeatureのready/ATR/D不整合は例外。

SOURCE13は`session,index,minutes,start,end,confirm,confirm_line,publish,missing,open,high,low,close`。publishはbool、公開keyは`(confirm,confirm_line)`。価格時計や原行を受信時計と呼ばない。old_slotの旧readyFalseではline=Noneを許し、他の3入力を見ずに旧未準備を返す。

`history_sources`は全当場のSOURCE13配列。可視足だけへ先に射影し、index0から旧currentまでを要求する。index/end不連続を表すことはできるが、最新15本等の部分prefixで初期状態を作り直してはならない。末尾は旧currentの全13項目と型を含むJSON表現が一致し、正常完全足でなければ停止する。

帯は外層が選んだ当場30分帯一つ又は前収録帯一つだけ。今後の当場全区間高安をP候補へ渡さない。帯の集約・被覆・限月・前収録選択は[参照帯モジュール](参照帯.py)と外層の責任である。

外層metadataは`id,session,current_session,reference_type,prior_gap_seconds,reference_available,reaction_start`。基礎帯は`begin,end,publication,published,publication_key,ready,reason,open,high,low,close,mid,sources,coverage,quality`。本入力は公開/準備済み帯のhigh/low/midを使い、sourcesやcoverageから高安を再集約しない。

- `reference_available=False`は前収録なし等の明示sentinel。published/ready=Falseを要求し、価格・begin/endを見る前に未準備を返す。架空の境界を作らない。観測のbegin/end/high/low/mid/publication_keyは全てNone。
- 通常帯は`reference_available=True`。row公開は`{time,line}`、timer公開は`{time:end,line:None}`。rowは判断key以下、timerは判断time以下だけ利用する。
- 未公開の価格・coverage・qualityを検査/転記しない。raw帯が将来のmarkerまで既に集約されていても、観測のpublication_keyはNoneへ隠す。固定id/既知区間等だけを残す。
- 公開後にreadyFalseなら帯理由を引き継ぎ未準備。readyTrueかつH=Lは既知の平坦帯であり、readyTrue/side0の対象外WAIT。
- 当場反応開始はO0でband.end、P0/P1で当場index0.start。外層reaction_startが付けばこの値との一致を要求する。

decision_quoteは旧55の`now,line,last,bid,ask,valid`全6項目又はNone。時計は元判断と一致が必要。正常はvalid=True、正の有限bid<ask、正の有限Last。非正常/Noneは観測不足の未準備。schema欠落や別時計は入力矛盾として停止する。

## 可視性とreset

1. 場と有限endで未来を判別する。end>scheduledは他の価格・confirm等を見る前に除外する。
2. 終了済み足は有限confirmと非負整数confirm_lineを要求し、公開keyが実判断keyより後なら価格検査前に除外する。未来か判断できないschemaは例外。
3. 可視SOURCEは全13項目、3分、有限start、bool publish、非負整数missingを要求。番号重複/後退・公開key同値/後退は例外とし、並べ替えで救済しない。
4. 可視の非公開、不完全180秒、missing>0、confirm<end、不正OHLCはその観測時に両端reset。番号飛び/end-start不連続もresetし、現足が正常なら新しい1本目として使う。reset理由と出典は保存する。
5. O0はstart<band.endの足を反応に使わない。形成帯と反応を同じ足へ兼用しない。

prefix指紋は未来除外後のSOURCE13配列を`sort_keys=True,separators=(',',':'),ensure_ascii=False,allow_nan=True`のJSONにしてUTF-8のSHA256を取る。既知NaN等は指紋で識別するが機械の比較へ入れずresetする。reset履歴はindex/key/reasonだけで、非有限価格を観測JSONへ直接転記しない。

## 外試行、T、R

上端d=+1/K=H、下端d=−1/K=Lで両端を独立に観測する。ただし各端のT/Rは**同一外試行ID**へ結合する。`q=d*(close−K)`は保存十進表現のFractionで比較し、epsilonを入れない。

外試行IDは`session|band_id|d符号|外試行|最初外足index|confirm.hex()|line`。最初のq>=5足がfirst_outside、以後の外足がlast_outside。T/R形成は同じ書式の種類部をT/Rとし、Tではrun先頭、Rではfの出典を使う。T形成のbはその連続run先頭、R形成のbは外試行のfirst_outsideである。

|処理|規約|
|---|---|
|外試行期限|足冒頭で、未消費試行のindex−last_outside.index>3なら消費を先行する。外0→中立1/2/3→外4は旧ID消費後、外4から新ID。3本目fは許可、4本目fは不可|
|T|q>=5の最初をb、完全隣接2本目を最初kとしてactive。以後q>=5で継続。q<5で取消。次のrunは新しいT形成だが、同じ未消費外試行へ属する場合がある|
|Rのf|未消費試行の最後外足後1..3本で、最初のq<=−5をfとして固定し、その時点で外試行を消費する。新外足が出るまで次のfを作れない|
|Rのk|f後1..3本の別足でq<=−5、実side s=−dの` s*(close−line)>0 `を最初に満たす足。lineは買いf.high/売りf.low。f自身をkへしない|
|R終了|f後q>−5なら取消。3本目までkなしなら確認期限切れ。k後もq<=−5かつlineのstrict外が必要で、どちらかを失えば取消。最初のf/最初のkは替えず、同じ試行を復活させない|
|新外足|消費済み試行の後にq>=5足が来たら、新外試行と新しいT runを作る。中立足だけでは再登録しない|
|品質reset|現T/Rの最初終了理由とtrial消費を記録し、現在ポインタを消す。過去形成の有効旗を再点火しない|

activeなT/Rのkに900秒TTLは付けない。有効なら複数定時から観測し、kは最初の確認足へ固定する。`k_age_seconds=slot.time−k.confirm`を候補に保存する。反復観測件数と形成uniqueを分ける。

## 指標資格と位置条件

保存float64のF01/F02/F03/F07/F15/F47/F48/F51/F52とraw背景を使う。方向値5列の売買符号反対、ADX4列の両側同値、mask二値、非零F01とraw背景の整合を検査する。未知を0補完せず、mask0の既存値を既知ADXとして用いない。float32化しない。

全候補はraw背景非同値、F01非零、F02>=0、F03>0、F07>0が必要。TはF01>0、F51=F52=1、F47>=0.20、F48>=0。**F47は旧ADX/100なので0.20へ直接比較**する。計画の実ADX20という意図を保存単位へ直した固定前裁定であり、100倍の追加丸めをしない。

RでF01>0は順行で、TのADX条件を追加しない。RでF01<0はF52=1/F48<0/F15>0を要し反転とする。T/Rという価格形成と、rawDIとの運用roleは同義ではない。

全候補でLastとE*（買ask/売bid）の両方に` s*(価格−premise_line)>0 `を要求。P1だけ、位置前の基本適格集合へ`0<s*(E*−line)<=D`を加え、Rにはさらに` s*(M−E*)>=250 `を加える。Tの中央余地はNoneで、十分/無限に置き換えない。位置は各候補へ適用してから選択し、P0の最新候補が位置落ちでも、別の同方向T/Rが残れば選べる。

資格集合からk公開key最新を選び、同keyならT優先。同じ種類・同方向の重複は入力矛盾。F03/F07の売買鏡像から反対方向同時資格は成立しないため、その矛盾も停止する。位置条件前の選択と最終選択を両方保存する。P1のsideはP0と同方向又は待機だが、実一枚の約定包含を保証しない。

## 返却schema

extractトップは`ready/reason/policy/source_count/source_sha256/reaction_count/reaction_start/band/history/trials/formations/candidates/qualifications/selected_before_position/selected/side/role`。

- historyは`current/resets`。currentは旧出典に一致する最新SOURCE13。旧未準備ではNone。
- trialsは`id/direction/level/first_outside/last_outside/consumed/consumed_at/consume_reason/T_ids/R_id`。
- formationsは全形成。`id/episode_id/kind/side/break_direction/level/premise_line/b/last_outside/f/k/active/status/cancel/trace`。b/last_outside/f/kは正常SOURCE13全文又はNone。statusは確認待ち/有効/取消/確認期限切れ/品質reset。cancelは最初のindex/key/reasonで固定する。
- traceはindex/key/action/status/active。通常の継続足全文を追記しない。candidatesはactive形成だけの複写にk_age_secondsを加える。
- qualificationsは形成ID→`basic_qualified/position_qualified/qualified/role/reasons/basic_reasons/position_reasons/values/price`。priceはlast/entry_proxy/premise_line/last_distance/entry_distance/mid_room/D。未準備やquote不正では資格辞書は空。
- selected_before_positionは基本資格での最新候補、selectedは政策の最終候補。どちらも無しはNone。

chooseはO49純10項目`scheduled/time/line/side/role/atr/D/reason/ready/slot_id`に`session/policy/origin/pattern_id/formation/premise_line/band_id`だけを加える。lineは元判断原行なので、前提価格と衝突させない。originはO30外保持/O30内回帰/前帯外保持/前帯内回帰、待機時はO30待機/前帯待機。旧feature・予測・結果は転記せず、旧Q0へのfallbackはない。

旧未準備/帯未公開/帯被覆不足/現在quote不正はreadyFalse。平坦帯/有効形なし/技法不適格/位置不適格はreadyTrue/side0。保有/注文との調整や活動集計は運用側で行う。

## 人工と責任範囲

`self_test()`は人工SOURCEと旧64値だけで、Tの5pt等号/2本、Rの両3本境界・f固定・取消後同原因復活なし・新外足再登録、k持越し、共有ID、最新k/T tie、P1位置前後R→同側T、Dと中央250等号、DI/ADX/Fast/CLVの資格、公開不正suffix、未来帯markerのmask、OR形成足除外、平坦帯、前参照なし、quote不足、reset、schema/鏡像矛盾、元引数不変を検査する。人工の値は成績による閾値調整に使わない。

本物の帯集約・全SOURCE接続・旧quoteの両方向同値・当場台帳・実運用・先着再用はrootと独立監査の責任。本ファイルは結果/labels/測定損益を入力せず、旧58/74の実装を期待値として呼ばない。数量gate、追尾幅、費用、利益旗、返済pending等も変更しない。
