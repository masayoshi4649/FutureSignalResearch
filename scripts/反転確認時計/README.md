# 反転のSAR確認時刻と順行持続

[試行00026](../../study/00026_反転のSAR確認時刻と順行持続/README.md)の再現コード。価格/SAR銀行とf/gの母集団は固定25を読み取り再用し、N0/N1の同f値条件とN2の後続SAR確認hを分ける。順行gのSAR二本持続とA5出口は全案共通。計画・条件・固定SHAは試行側を正本とする。

## 実行手順

Python 3.14.3、NumPy 2.5.3、リポジトリルートから実行する。共通台帳の既使用65場だけを使い、予約した新11/4Nightを列挙して追加しない。

```powershell
C:/Python314/python.exe -X utf8 scripts/反転確認時計/検証.py --prepare
C:/Python314/python.exe -X utf8 scripts/反転確認時計/状態独立確認.py --prepare
```

準備は先着/P&Lを読まず計算しない。全数値/状態・合成/編集終了・入力とコードの指紋を確認して固定した後だけ正式再生する。

```powershell
C:/Python314/python.exe -X utf8 scripts/反転確認時計/検証.py
C:/Python314/python.exe -X utf8 scripts/反転確認時計/状態独立確認.py --実行許可
C:/Python314/python.exe -X utf8 scripts/反転確認時計/追尾独立確認.py --実行許可
C:/Python314/python.exe -X utf8 scripts/反転確認時計/独立監査.py --api-base http://127.0.0.1:8092
C:/Python314/python.exe -X utf8 scripts/反転確認時計/対応診断.py
```

正式再生は結果上書きを拒否する。別条件は新試行へ分ける。独立監査と対応診断は保存結果の検算であり、新しい売買条件の再選択ではない。

準備の厳密canonicalではATR浮動値をε/Dの呼値整数へ投影する。ATR実値は全3分足と全参照pathで既定の絶対許容1e-10・相対0を使い別照合し、ε/D整数と他の投影値は厳密比較する。正式raw/監視のATR実値や売買式は丸め直さず、全floatのバイト完全同値とはしない。
