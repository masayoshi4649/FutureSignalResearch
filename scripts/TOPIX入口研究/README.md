# TOPIX固定純入口の再現

192・196・197・200・202・203・205・208・210の恒久純入口とSourceから、金融と保有枠を新しい`work/再現_TOPIX...`へ再生する。既存の作業成果は変更しない。原板は`inputs/`へのディレクトリ接続で共有し、複製しない。205からは共通金融CLIを呼び、試行番号別の実行器を複製しない。210は封印時点の全83場を固定対象とし、`--監査`では別段階表の純出生確認も金融前に実行する。

```powershell
$env:PYTHONUTF8='1'
& work/複合テクニカル学習環境/Scripts/python.exe scripts/TOPIX入口研究/固定純入口を再生.py 197
```

既定では金融正本の集計SHAが一致することまで確認する。`--監査`を付けると別BBO算術と集計検査も再実行する。Python3.14.3、NumPy2.5.4、tzdata2026.6を用いた。各試行の入力/Source指紋と当時の選択を維持し、追加データを自動混入しない。

固定条件で宣言されたSourceが当該試行のZIPにない場合は、過去の正式`Source.zip`から同一SHAのmemberだけを新作業rootへ補完する。元のworkを無確認にコピーせず、補完元を再現票へ記録する。205では184の直接形成Source一件をこの方法で復元し、全17金融の集計SHAが一致した。

作業領域内の`inputs`は元入力へ接続している。ツール自身はこの領域を削除しない。純出生の再計算条件は各研究READMEを参照する。

## 新しい固定入口の金融実行

[共通金融.py](共通金融.py)は候補名・候補数・IDテンプレート・純出生を引数として受け取り、既存のH60単純IFD、費用、予約/保有1枠、終了15分前を再生する。試行番号の文字列置換が年や期間境界へ作用する事故を防ぐため、入力81/83場、前48・後25・追加7・最終1・追加2を独立に検査する。

```powershell
python -X utf8 scripts/TOPIX入口研究/共通金融.py --condition 固定条件.json --births 固定純入口.json.gz --output 新規出力先 --id-template 'TOPIX205_{name}_DayA25_H60'
```

条件の`候補/規模/Source/純入口SHA`と、純出生の`session/time/line/signals/widths/origins`を使う。`--extra`は固定追加2場を含める際に明示する。入力の途中場・末尾だけを自動追加する機能ではない。既存出力へ上書きしない。Source、動的到達木、原順NPZすべての指紋を開始票へ残す。

任意の`--expected-dir`で全金融pack、`--expected-metrics`で全群・全期間の成績を固定結果へ照合できる。[203の同体確認](共通金融の同体確認203.json)では28口座・7,647取得の全台帳と全集計が既存実行器と一致した。これは同じIFDの共通化検査で、独立した原BBO監査は各試行の独立確認を参照する。
