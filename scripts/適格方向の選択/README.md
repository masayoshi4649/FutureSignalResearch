# 適格な方向集合の中から優先側を表示する

[試行66の計画](../../study/00066_複数手法の適格方向から優先側を選ぶ/検証計画.md)に対応する保存表示器。旧65U0/U1各46場を保存対照、新E0/E1各46場を表示する。新運用92、Viewerは旧92＋新92＝184資源。

全60特徴・教師・旧65U0三木と三回収集計・閾値・支持・出口は同じ。新fit0・新保存木0・新独立計測0。モデルmetadataのpath/policyは旧65のU0のままで、新E0/E1木をコピー保存しない。参照木の全閾値・葉支持・score・平均・MSEは表示するが、66で学習・回収集計した結果とは呼ばない。

| 段階 | 旧U0/U1 | 新E0/E1 |
| --- | --- | --- |
| 同点・片側未知 | 両側WAIT | 同じWAITを先に保持 |
| 両側既知・得点差あり | 全方向score最高側を先に選ぶ | 各側のscore>=1/3・葉支持・技法・回収支持を先に確認 |
| 方向決定 | 最高側が不適格ならWAIT、次点救済なし | 適格集合の中で障壁score最高側 |
| 正回収の条件 | U1は最高側の主合計strict正も要求 | E1は各側の主合計strict正も資格へ含む |

回収平均の高い側へ順位を変えない。E1では適格集合が狭くなっても、E0で買い・E1で売りになることがあり、同方向の部分集合を断定しない。旧Uから対応Eへの純候補比較と、E0/E1同士の逆方向比較、建玉占有に左右される実参加は別に表示する。

「適格」は保存葉pathの技法分類や過去支持・平均を指す。現在の価格setupや別足triggerの成立の直接検査ではない。旧DI→対応episode有効根のtrend＋priceによる資格、V1出生≠r/k、V0の未登録・取消・TTL/reset等の混合も維持する。選択順を変えただけで、取消履歴が現在の発動条件になった問題まで解決したとは呼ばない。

全60特徴と55手法×9尺度、旧参照三木・三回収の全node/閾値、旧証明の教師・状態・数量・経路被覆、旧新の入口先着・実回収・DI役割、保存理由・救済比較と方向差を表示する。旧教師一致・base60と既存18/30/38/46/54等は旧65証明を継承した参照で、66の新実施検査とは分ける。

```powershell

C:/Python314/python.exe -X utf8 scripts/適格方向の選択/レポート.py
```

`self_test()`は正式入力なしの成功・テスト件数を返す。正式生成は主・保存監査成功通知後だけ。`--check`は二MDの同byte・全60・55×9・内部リンクを確認する。fit・予測walk・原板読取・教師再生成・独立測定・市場再生は行わない。

固定49Oの15分25/49全予定枠、保有非待ち、判定不能込み保守待ち50%以下、現在費用122円strict正起動・損失側も連続保護・pending保護凍結を維持する。先着250は固定TPでも実利益でもない。品質注意の全体確定null、独立回収の重複建玉合計と一戦略利益の違いも残す。全66場既使用、初20場学習専用・後20時系列・選択24・既使用後続2を区別する。
