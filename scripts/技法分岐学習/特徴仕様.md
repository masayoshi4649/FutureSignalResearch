# 51の当時技法特徴

50保存P0slotの出典だけから15特徴を作る。教師、先着、約定、保有、損益を読まず、特徴を使った効果もまだ確認していない。市場再生やfitはこのモジュールの責務に含まない。

## APIと責任

- [特徴.py](特徴.py) の FEATURES は順序固定の15辞書で、id/name/method/family/scale を持つ。
- extract(slot: dict) は ready/reason/vectors/atr/D/background_direction/sources/diagnostic を持つdictを返す。
- vectors のキーは文字列 "1" と "-1"。準備可なら各15個の有限float、判定不能なら両方とも空配列。欠測を0で補完しない。
- background_direction は上位DI差のstrict符号−1/0/1。売買選択・T/R判定・木の学習は行わない。
- 元入力は変更しない。固定49入口を固有名でimportし、有限性・SOURCE・価格完全性・隣接・ATR距離の純補助だけを使う。銀行構築や市場ファイル読取は呼ばない。

旧P0の ready/side/role や旧Rの ready/side/role/structure を準備・特徴へ流用しない。旧Rの10本窓を新しい共通準備へ持ち込まない。初期15特徴は価格・方向・勢い・値幅の保存値を材料にする比較であり、新しい回復構造や追加指標を計算したとは扱わない。

## 共通準備

1. 場名、予定秒、実判断秒、整数原行がある。実判断は予定以後30秒以内で、reason が「判断BBO不正」ではない。最初の正常BBOという入力の作成責任は主側にあり、extractは原列を走査しない。
2. current/previous は当場3分SOURCE。公開、missing0、完全180秒幅、有効な正値OHLC、確認時計が終了以後である。番号・終了開始・公開keyが完全隣接する。
3. 両足の終了は予定以前、公開keyは実判断key以前。最新足の古さは予定秒−終了秒が180秒以下。最新不正を古い足へ代替しない。
4. OR.ready が真で、高安とindex0..9の10本SOURCEがある。全10本が当時公開済みの完全有効足で隣接し、保存高安が10本の最安・最高と一致する。中央は保存表示値からではなく高安の精密平均から作る。零幅ORは有効値である。
5. upper.ready が真。当場15分SOURCEが完全900秒、公開・有効で、終了が予定以前、公開keyが実判断key以前、古さ900秒以下。DI正負両値が有限。準備可のDI同値0は欠測と区別する。
6. slotの現ATRが有限正値。Dは固定49 distance(ATR)、すなわち保存ATRを精密化して5pt上方呼値へ丸め、5〜125へ制限する。slotの旧Dは使わない。
7. diagnostic.old_R.current と current の場＋SOURCE12が全項目で一致する。旧Rの fast_k/fast_change は有効なexact辞書で、整数分子・正整数分母・有限表示値が整合する。

出典は session/index/minutes/start/end/confirm/confirm_line/publish/missing/open/high/low/close の13項目。可視性は endがscheduled以下、かつ(confirm, confirm_line)が(time, line)以下。同秒後行の公開や予定後終了足を混ぜない。存在しない字段、未来、不完全、数値欠測は理由を残して判定不能とし、待機という教師には変えない。

## 15特徴

sは候補実方向で買+1・売−1、Aは現3分ATR、Kは保存FastK14、ΔKはその保存現前差、MはOR高安中央。各価格・ATR・DIの元floatを個別にFraction化し、演算後にfloatへ一度写す。extractでfloat32化・表示桁丸めは行わない。

|ID|特徴|技法|役割・時間幅|
|---|---|---|---|
|F01|s×(DI+−DI−)/100|I08|trend・m15|
|F02|s×(K−50)/50|I07|osc・m03|
|F03|s×ΔK/100|I07|osc・m03|
|F04|A/125|I09|vol・m03|
|F05|(OR高−OR低)/A|P03|price・m30|
|F06|s×(C−M)/A|P06|price・m03+m30|
|F07|s×(C−前C)/A|P05|price・m03|
|F08|s×(C−O)/A|P01|price・m03|
|F09|(H−L)/A|P01|price・m03|
|F10|s×(2C−H−L)/(H−L)、零幅は0|P01|price・m03|
|F11|買は(H−前H)/A、売は−(L−前L)/A|P02|price・m03|
|F12|買は(L−前L)/A、売は−(H−前H)/A|P02|price・m03|
|F13|s×(上位C−上位O)/A|P01|price・m15|
|F14|(上位H−上位L)/A|P01|price・m15|
|F15|s×上位(2C−H−L)/(H−L)、零幅は0|P01|price・m15|

F13/F14の分母も現3分ATRであり、15分ATRを新計算しない。F10/F15の零幅0は有効足の明示定義で、欠測の0補完ではない。F11/F12は売で高安を交換するので、買ベクトルの該当列を単に負にした値とは限らない。

sources は現前3分と上位15分のSOURCE13、およびOR高安・0..9番号・最遅公開keyを返す。OR全10本は入力で検査し、特徴側へ全件再転記しない。Fastの当時値・出典は固定保存物へ接続し、14足窓を再構築する責務とは区別する。保存slotに含まれない別の最新足の有無や、実判断が最初の正常BBOかは、この入力だけでは再検算しない。これらの選択証明は固定49/50の出典・監査へ接続する。

## 人工確認と限界

[特徴の人工検査.py](特徴の人工検査.py) は、手計算15値、売方向端交換、全列鏡像、一定価格移動、零幅、180/900秒等号、予定時刻と公開原行、欠枠・部分足・NP、OR10本、Fast出典・精密値整合、ATR呼値、旧採否・教師・保有への非依存、入力非改変と抽出時I/O禁止を確認する。実データや教師は使わない。

鏡映MをO/C→定数−O/C、H/L交換、DI正負交換、K→100−K、ΔK→−ΔKとすると、z(Mx,−s)=z(x,s)。この特徴対称性と、学習後の同一木・同じ売買選択規約による対称性は別に検査する。木の深さ・閾値・葉支持・学習範囲・活動・先着・費用後の採用条件をこの特徴モジュールで決めない。
