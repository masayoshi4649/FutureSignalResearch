# 5分・15分・30分の名目可用性

固定70場の5分CSVと保存Headerから、完全な子足による合成・名目公開時計・同限月carry・欠足reset後の履歴本数を計数する。足終+60秒のモデルであり、実際の配送時計、EMA等の値、技法成立率、参加率、損益は計算しない。

```powershell
python -B -X utf8 scripts/三時間軸の可用性/調べる.py
```

Python 3.14.3の標準ライブラリのみ。入力台帳・時計台帳・保存完了・140CSV・70Header等、214参照を前後のSHAへ結ぶ。詳細は `work/三尺度可用性の正式参照/5分15分30分の可用性.json` に生成する。正式資料は[方針と限界](../../docs/議論/5分15分30分で入口の環境と確認を分ける.md)と[小集計](../../docs/議論/資料/三時間軸/名目可用性.json)。個別全件表を正式資料に重複させない。
