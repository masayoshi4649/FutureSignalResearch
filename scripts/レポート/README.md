# 手法・時間スケールと試行結果のMarkdown生成

[現行の汎用表・版7](../../docs/議論/手法と時間スケールの汎用表_版7.md)と各試行の `設定と結果.md` を、同じカタログの行・列から生成する。汎用表は未記入、試行のコピーは未使用セルも保持して設定・閾値・複合結果を記入する。[記録方針](../../docs/議論/手法と時間スケールの記録方針.md)を参照。旧版専用の生成処理は履歴であり、固定試行の再生成に使わない。

```powershell
python -X utf8 scripts/レポート/カタログ版7.py
python -X utf8 scripts/レポート/カタログ版7.py --check
```

Python標準ライブラリだけを使用。バックテスト・学習・候補の再選択を実行せず、保存済みの条件と結果をMarkdownへ写す。

- `手法カタログ.json`：手法ID・尺度ID・分類・教科書参照。初版は51手法×9尺度。追加は新IDで行う。
- `既存試行設定.json`：00001〜00004のコード・条件を照合した設定と候補別のCSV参照条件。準備・診断だけの設定も区別。
- `設定結果レポート.py`：汎用表、00001〜00005のコピー、00005全4,605候補の全閾値・結果を生成。00005の表示用設定はnew_settingsに明示し、数値結果は正式CSV/JSONから読む。

各レポートはカタログ・設定・結果正本のSHA256を残す。Sは設定、Rは複合評価。複合成績を指標単独の効果に置き換えない。00005のモデル入力を全て固定一候補の入口条件とみなさず、固定候補の使用範囲を本文に記す。

新規試行ではまず汎用表を `設定と結果.md` へコピーして記入できる。自動生成へ追加する場合は、試行専用の設定マッピングと結果読取を追加し、過去試行の数値・条件を変えない。カタログを拡張した際は版を更新する。過去文書を再生成すると表の収録範囲も変わるため、記録日・版と変更理由を明記する。
