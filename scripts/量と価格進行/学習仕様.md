作成日：2026-11-06。64の純学習仕様。固定コードと手作り教師だけを使い、本物入力・数量load・実教師・保存実モデル・本物fitは扱わない。

|---|---|---|---|
|B0|旧63の54列|DIだけを根に固定、両子53列/深さ3|B0は従来資格、B1は同じ木へ過去回収strict正も要求|

同じ教師pair・方向重み0.5・seed51・min_samples_leaf60・pnl5回帰目的・障壁score方向順位・従来支持/複数技法gateを保持する。数量欠測で旧ready/教師を落とさない。

## APIと入力次元

```python
fit(rows, feature_meta, policy, model_id, evaluation_start) -> dict
prepare_rows(rows, evaluation_start, feature_count=60) -> (used, training)
float32(values, feature_count=60) -> list[float]
walk(model, values) -> (leaf, path)
predict(model, vectors) -> dict
```

fit/modelのpolicyはB0/Q0だけ。B1/Q1の別fitを許可しない。fitとwalk/predictはpolicyから54/60を選ぶ。prepare_rows/float32は既定60なので、Bの54列を単独で呼ぶ場合はfeature_count=54を明示する。

metadataの先頭54列は[旧63学習](../局面強弱の複合確認/学習.py)の検査を直接再用する。F55..60は次の順を検査し、全てscale=m03、nameは空でない文字列とする。

|ID|内容|method|family|
|---|---|---|---|
|F55|登録bの同時刻RVOL|V01|volume|
|F56|bの実方向終値差/現在3分ATR|P05|price|
|F57|再試験rの同時刻RVOL|V01|volume|
|F58|rの実方向終値差/現在3分ATR|P05|price|
|F59|bの量・価格ペア共同有効mask|V01|volume|
|F60|rの量・価格ペア共同有効mask|V01|volume|

量のfamily文字列volumeは旧ATR等のvolと区別する。量・価格の式、b/r投影、同時刻基準、公開時計とsourceは[特徴仕様](特徴仕様.md)の責任で、本学習器は数量読取や価格経路の再構成をしない。

## 数値・共同mask

旧54列は旧63.float32をそのまま再用する。新6列はboolを除く有限実数で、RVOL2列は0以上、価格進行2列は正負を許可する。共同maskはboolを除く0/1とする。

- F59=0ならF55/F56の両方が厳密0。
- F60=0ならF57/F58の両方が厳密0。
- 量0・価格差0がともに既知ならmask1でよい。
- bとrの共同maskは独立。bの量基準が不足でも、後のrの量基準だけ有効な場合を新たな矛盾として落とさない。

raw値の領域と共同maskを検査し、float32化後の有限性も確認する。新しいepsilon、未知の正量への補間、片方だけを残す救済はない。未知0と既知0はmaskで判別する。価格差はイベント当時の終値差で、ATRだけは現在判断の尺度である。実取得や実MAEに読み替えない。

## 旧54への射影と教師指紋

全pairの検査は方向枝へ分ける前に行う。

1. 政策の54/60特徴と共同maskを検査する。
2. features[:54]を旧63.prepare_rowsへ渡す。
3. 旧63の障壁/回収既知・strict過去終了境界・未知pair全体除外をそのまま適用する。
4. Bでは返された54canonicalをそのまま使い、Qでは同じ使用ID集合を元入力順の60canonicalへ写す。

片方向だけの救済や、枝内で両方向が揃うことは要求しない。同じpairの方向行が別DI枝へ入ってよい。新しい数量準備による教師除外、重み変更、別教師は追加しない。

両政策のtraining.base54_fingerprintsに旧63全54教師の次の六値を保存する。

```text
input_rows_sha256 / used_rows_sha256 / row_ids_sha256
target_rows_sha256 / period_sha256 / used_barrier_rows_sha256
```

base18/base30/base38/base46の指紋もそのまま継承する。Bの現input/used/used_barrierは旧63の54canonicalと同じ。Qの現3指紋は新6列を含む60canonicalなので別である。row_ids/target/periodは両方とも旧63と同じ。新しい特徴の内容指紋が異なることと、教師集合が変わることを混同しない。

feature_missing_handlingは政策別に次の文字列を保存する。

```text
B: 旧63全54準備の同じ教師pair。基礎54の再fit、追加情報・追加除外なし
Q: 旧63全54準備の同じ教師pair。追加6列は未知0＋共同有効mask、追加除外なし
```

## DI一段根と二つの子

固定nodeはid0/F01 index0/threshold0だけ。float32 F01<=0を左D0、>0を右D1へ分ける。D0の対象価格経路はR、D1はTだが、微小正値のfloat32零化では厳密DIによる実roleとの一致を保証しない。厳密DI同値の最終WAITは主処理で保持する。

両子からindex0だけを除き、元列順の `[1..feature_count−1]` を使う。Bでは53列、Qでは59列。k有効旗index20/26や旧Z等も子へ戻り、k0群を事前除外しない。

各非空子はDecisionTreeRegressor、criterion=squared_error、splitter=best、max_depth3、min_samples_leaf60、sample_weight0.5、random_state51、max_features=None、ccp_alpha0等の旧パラメータを使う。固定根を含む最大深さ4。固定根はMSE最適化で選んだ分割ではない。

空方向枝は未知leafを残し、data_absent=True、score/regression_value/impurity等をNone、方向行0とする。固定根は必ず存在し、空側をscore0へ置き換えない。3窓×2政策の保存合成モデルは6本、回帰器fitは非空子だけで最大12回、分類器fitは0。

## 保存schema

structure.kindはfixed_direction_only、fixed_nodesはid0だけ、child_depth3、max_depth4、child_features53又は59、feature_count54又は60、child_feature_indicesは実列順list、excluded_feature_indicesは[0]、fixed_mse_optimized=False、child_estimator=DecisionTreeRegressor、target=pnl5。

training.partitionはD0/D1。各値は次の項目を持つ。

```text
d / route / policy
excluded_feature_indices / child_feature_indices
direction_rows / pair_unique / days / sessions / row_ids_sha256
fit_performed / root / node_count / fit_parameters
```

routeはD0でR、D1でT。pair_uniqueは枝に含まれるunique枠数で、両方向が同じ枝に揃ったpair数ではない。子のlocal indexは保存時に元54/60列のglobal indexへ戻す。

固定根を含む全node所属・方向行・0.5重み・障壁score・unique枠/日/場・methods/families・pnl0/5/10のDecimal合計/平均・MSE/barrier_giniを使用canonicalから再計数する。元sklearn子の全node所属・件数・重み・回帰値・MSE・全方向葉ID/予測を合成JSONへ照合する。

生回帰mean/MSEとDecimal算術の照合だけは旧数値許容を使い、score・支持・strict正額・閾値にepsilonを加えない。回帰MSEと障壁giniは別物である。

## 方向順位・技法資格・maskだけの経由

walk/predictは新ファイルの政策別54/60JSON走査を使い、旧globalを書き換えない。同じ木を両方向へ適用し、障壁250成功率scoreがstrict高い側だけに従来資格を課す。回帰meanで方向を変えない。同点・片側未知・最高側不適格はWAITで、低い側の救済はしない。

score>=1/3、unique枠>=60・6日・10場、pathに異種family2以上かつtrend又はoscを要求する。**固定根はtrend一つなので、子が分岐しない葉は技法資格不足になり得る。** 旧62/63の固定trend＋priceによる構造的充足とは異なる。

新maskF59/F60はV01/volumeに属するため、DI根と量maskだけを使ったpathも、同じ従来family条件では通り得る。これを実数量水準や価格反応を確認した効果とは呼ばない。診断では新6列のpath利用を次に分けられる。

- 量実数を使用：F55又はF57。
- 価格進行を使用：F56又はF58。
- 共同maskを使用：F59又はF60。
- 新6列のうちmaskだけを使用：新使用列集合が空でなく、F59/F60だけの部分集合。

最後の分類でも旧54の価格/勢い等を使っている場合があるので、全pathがmaskだけという意味ではない。診断分類のために新しい採用gateは作らない。数量を新規買い圧力・攻撃側フロー・参加者心理の直接観測としない。

B1/Q1は同じ最高側へ従来の回収支持と過去主回収strict正額を追加する。一建玉、全予定分母、保有非待ち、正常BBO、+1秒/TTL、損失連続追尾、現在利益122円strict起動・最低名目新規床、費用・強制返済は固定O49のまま。
