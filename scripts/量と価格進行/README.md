固定根はfloat32 F01(index0)<=0の一段。D0/D1の子はDI以外の53/59列、深さ3、全深さ4。minleaf60・重み0.5・seed51・pnl5回帰MSE。方向の順位は障壁score最高側のままで、円予測による順位変更も次点救済もしない。固定根はtrendだけなので複数技法資格は自動充足しない。新maskはvolume familyなのでmaskのみのpathも従来式で資格を満たし得るが、実量や価格再開を確認した意味ではない。

旧J→Bはk固定解除・子の容量変更・技法資格の自動充足消失を含む。B→Qが同構造・同教師・同出口の情報追加比較であり、J→Qの差を量単独の効果としない。状態四群は旧DI→対象kの診断分類で、新木のpartitionは二群である。

候補側float32 F01>0ならT、それ以外はRの既知b/rへ対応させる。実運用roleは旧raw DI規約で別に付く。イベント足の一足終値差は現在ATRで正規化し、b→rの区間進行ではない。共同mask0なら対応2数値は両0、完全q0と正基準ならRVOL0・mask1。追加欠測で旧54のreadyや教師pairを減らさない。[特徴仕様](特徴仕様.md)を正本とする。
