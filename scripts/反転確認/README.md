# BB反転の確認と構造リスクを比べるコード

確認日2026-11-04。[試行00012](../../study/00012_BB反転の確認と構造リスク/README.md)の4純入口・8運用。旧00011のR2と固定X0を読取継承し、即時/次足確認と固定/構造保護の効果を分ける。

| ファイル | 役割 |
| --- | --- |
| [入口.py](入口.py) | 即時R2と次の連続一足の価格確認。設定足中心・構造と確認足ATRを分ける |
| [運用.py](運用.py) | 固定250/125、要求時既知BBOでの送信前構造審査、実約定後の構造保護 |
| [検証.py](検証.py) | コード・条件・入力を固定し、全65場を同じ指標履歴で再生する |
| [合成検証.py](合成検証.py) | 24境界確認。既知時計/原行、鮮度30秒、送信後実約定と往復費用、固定同値など |
| [独立監査.py](独立監査.py) | 全保存入口先着、BBO/会計/費用/DD/MFE/MAE、旧00011即時固定同値、Viewerの直接照合 |
| [構造独立確認.py](構造独立確認.py) | 全構造注文の送信前審査と最初の保護要求・返済を、売買処理をimportせず直接照合 |
| [レポート.py](レポート.py) | 数値正本からREADME・全候補結果・51×9設定表を生成する |

Python3.14.3・NumPy2.5.3。キャッシュ復元には既存orjson3.13.0。新しい機械学習ライブラリ・GPUは使っていない。大きな詳細はGit外の`work/反転確認/00012/`へ置き、原板は複製しない。

```powershell
python -X utf8 scripts/反転確認/合成検証.py
python -X utf8 scripts/反転確認/構造独立確認.py --実行許可
python -X utf8 scripts/反転確認/独立監査.py --api-base http://127.0.0.1:8092
python -X utf8 scripts/反転確認/レポート.py
```

独立監査は既存のViewerが同じ市場root・本repoのresource_rootで起動している場合にAPIも照合する。`--api-base`省略ならローカル記録の監査のみ。構造の直接確認は先に単独実行し、主監査がそのGit外の保存結果を正式試行へ取り込む。`--実行許可`は数値再生完了後の作業順を明示するフラグで、別途のユーザー承認を必要としない。

数値再現は別の空試行先へ正式な`計画.md`と`条件.json`をコピーし、次を使う。

```powershell
python -X utf8 scripts/反転確認/検証.py --study work/反転確認/再現00012 --work work/反転確認/再現00012詳細
```

正式結果の上書き、固定後の条件・コード・入力変更は拒否する。新しい条件は別の試行へ分ける。全65場は既使用で、再実行は未見性を増やさない。構造取消を入口先着率から除外せず、小さい損失と失った大きな利益を同じ資料で読む。
