# 実現利益の開始日集中を確認する

`旧100の集中を確認する.py` は試行100の完成済み結果JSONだけを対象とするCLI。P0四感度・54セッション・27開始日を明示検証する。Native・原板・Tape・Source・金融再運転を使わない。作業版と同じbytesを正式配置した。

```powershell
& 'work/venvs/technical-tree/Scripts/python.exe' -B -X utf8 `
  'scripts/実現利益の集中/旧100の集中を確認する.py' `
  --input 'study/00100_費用後利益化の前後で保護を分ける/成果物/結果.json' `
  --input-sha '47a46a85bc30cf138effceba9cc899e33968430735c04e2aa271cc1561c839ba' `
  --out 'work/利益集中の新規出力先'
```

出力先は未使用とする。入力とコードのSHA、日別合計と元集約の一致を確認し、円・半円を丸めない。コードSHA256は `5494518595c62e02c8567eeaeb2745d891c2ab8657bab1df7f9b1f8494414671`。Python 3.14.3、標準ライブラリのみで実行した。

再利用可能な純関数 `concentration(daily)` は開始日・実現純額の列を受け、最良日除外額、各1日除外の範囲、正負ゼロ日数、分母を明示した利益寄与を返す。CLIの試行100専用schemaを新101へそのまま流用しない。新試行への接続は完成結果の型と分母を確認して行う。

新しい合格条件・日付除外ルール・ブートストラップ・未知期間の安定性・機会損失を扱わない。[知見と数値](../../docs/議論/実現利益の集中と日別の安定性.md)を参照する。
