# 61の特徴は60の全46列と同じ

確認日：2026-11-06。[特徴.py](特徴.py)は[固定60の特徴](../波の区間分離/特徴.py)のmetadata・規約・抽出結果をそのまま複写する。同じ当時入力から得る全46列と付随するhistory/paths/geometry/segmentsは不変である。詳細な式・出典・未適用値は[60の特徴仕様](../波の区間分離/特徴仕様.md)を正本とする。

61で変えるのは[学習仕様](学習仕様.md)の固定二段と子への投影である。F20のT有効、F26のR有効を先頭に使い、残る44列を子候補へ渡す。新しい特徴列・定義・除外条件を追加するものではない。

主処理は固定60の教師接続を再用し、旧60の評価全3,404記録（2候補各1,702枠で、同じ予定枠の重複を含む）の46列辞書と付随状態が完全一致することを確認する。監査も固定60の独立再構成を再用し、新特徴shimを期待値として呼ばない。20/30/40場の使用986/1,482/2,014方向行、各六指紋、既存18/30/38射影の保持を検査する。

この文書は実行後に表示器の仕様リンク先として追加した同一入力の説明で、固定済みの計算・条件・結果を変更しない。固定前の規約は[検証計画](../../study/00061_現在有効な経路を先に分ける/検証計画.md)・条件JSONと旧60の固定出典から確認できる。
