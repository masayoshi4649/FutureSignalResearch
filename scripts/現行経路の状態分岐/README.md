# 現在有効な経路を先に分ける

[試行61の検証計画](../../study/00061_現在有効な経路を先に分ける/検証計画.md)に対応する保存結果の表示器。旧60のS0/S1各46場を保存対照とし、新A0/A1各46場を表示する。fit・予測walk・単独計測・市場運用は再実行しない。

全候補の入力は同じ46特徴。現在T有効F20（index19）→現在R有効F26（index25）を各0.5で固定分岐し、子は両列を除く44列・深さ2を使う。F18とDIは子へ移る。T0_R0等の四群名は旗の組であり、継続・反転の成立を意味しない。有効1はb登録から始まりr/k形成を保証せず、有効0には未登録・取消・期限失効等が混在する。

A0は障壁score最高側についてscore>=1/3・葉支持・複数技法資格・過去回収60枠6日10場を要求し、A1は同じ木で過去pnl5合計strict正も要求する。回収平均の高い側へ順位を変えず、最高側の資格不足を次点で救済しない。固定根2つはpriceなので、子にtrend/oscがない葉はpriceやvolが選ばれても技法資格を満たさない。

表示は小型の結果JSON・正式監査・新3木・3回収集計と旧60の保存モデルへ接続する。全46特徴、版5の55手法×9尺度、全node/葉と子のtrend/osc選択、状態別の方向行・非重複枠・日/場、形成ID・episode反復を省略しない。IDの葉間重複は加算せず、状態分布は採用群ではなく使用教師方向行が分母である。

`base46_fingerprints`六キーは旧60全46列へ厳密に照合し、既存のbase18/30/38射影も保持する。55の独立一枠回収は再測定しない。その重複保有を含む合計を単一戦略の利益として扱わず、先着率・回帰予測・過去平均・実運用利益を分ける。

```powershell
C:/Python314/python.exe -X utf8 scripts/現行経路の状態分岐/レポート.py --self-test
C:/Python314/python.exe -X utf8 scripts/現行経路の状態分岐/レポート.py
C:/Python314/python.exe -X utf8 scripts/現行経路の状態分岐/レポート.py --check
```

`--self-test`は人工schemaのみ。正式生成は主実行・保存監査成功後に行い、`--check`は同byte・全46特徴・55×9・内部リンクを照合する。旧60当初表示器の純補助を基礎にし、60の表示訂正ラッパは呼ばない。登録へ至る十差分はbを含み、純粋な推進波全体を自動認定した値ではない。

固定49Oの15分判断・連続保護・現在費用後122円strict正の利益起動・pending中の保護凍結を維持する。全66場は既使用で、時系列検査20場・条件選択24場・既使用後続2場を未使用外標本とは呼ばない。

外部根拠は[形の否定と新しい入口の再調査](../../docs/議論/外部再調査/否定された形と新しい入口を分ける.md)。2026-11-06にBrooksの[公式用語集](https://www.brookstradingcourse.com/price-action-trading-terms-glossary/)（個別著者・公開日不明）とGrimes本人の[Did you miss a trade?](https://www.adamhgrimes.com/did-you-miss-a-trade/)（2021-08-25）の本文を確認した。元形の否定・反対新規・再取得を別の観測として扱う参考であり、既読説明の深掘りである。教育説明と単一例はNK225の先着70%・費用後利益の実証でも心理の直接測定でもなく、四群の固定分岐は本研究の規約である。
