# 現在有効なT/R経路を先に分ける回収学習

作成日：2026-11-06。61の純学習仕様。市場入力・本物教師・保存済み実モデル・本物fitは扱わず、固定60のコードと人工行だけで実装した。

## 比較で変えること

[旧60学習](../波の区間分離/学習.py)をLEGACYとして読み、全46特徴・同じ教師pair・pnl5回帰目的・深さ・支持・費用・方向順位を保持する。固定二段を旧F18→F01から、**F20のT episode_valid→F26のR episode_valid**へ変更する。

子には旧固定段のF18とF01を戻し、新固定段のindex19/25だけを除く44列を使う。したがって分割順と子の容量配分を変える比較であり、有効旗1列の単独効果や単純な取消群除外の検証ではない。

価格経路T/Rは実sideに対応した別々の元突破方向・K・b・期限を持つ。現在DIとの同向/逆向から付ける運用roleとは別である。Rのepisode_validは出生bからTrueになり、f/r/kや反転成立を意味しない。Falseには未登録・取消・期限・resetが混在する。その違いは同じ46列の旧stage/k等や保存出典で判別する。

## APIと教師の完全再用

```python
fit(rows, feature_meta, policy, model_id, evaluation_start) -> dict
prepare_rows(rows, evaluation_start, feature_count=46) -> (used, training)
predict(model, vectors) -> dict
walk(model, values) -> (leaf, path)
```

fit/modelのpolicyはA0のみ。A1は同じA0木へ、後段の固定回収集計で過去回収正額条件を加える。別木を学習しない。

metadataは旧60.feature_metadata(feature_meta,'S0')、float32は旧60.float32をそのまま再用する。列数・順・型・段階・旗・適用外0・効率領域等の旧検査を変えない。旧moduleのglobalには代入しない。

prepare_rowsは旧60の全pair検査、両方向の既知障壁/回収、strict過去境界、未知pair丸ごと除外を**四群へ分ける前に**直接呼ぶ。返されたusedのcanonical行・順番・使用IDを変えない。枝内で両方向が揃うことは要求せず、同じpairの方向行が別群へ入ってよい。各方向の重みは従来の0.5である。

trainingには旧18/30/38指紋をそのまま残し、旧60の次の六値をbase46_fingerprintsへ追加保存する。

```text
input_rows_sha256 / used_rows_sha256 / row_ids_sha256
target_rows_sha256 / period_sha256 / used_barrier_rows_sha256
```

同名の現canonical指紋六値も旧60と同じである。新しい特徴・教師・目標値・除外を追加したわけではない。feature_missing_handlingは `旧60全46特徴・同じ教師pair。追加情報・追加除外なし` とする。使用教師row_idsも同じ順序で残す。

## 固定三nodeと四群

float32化した値で比較する。旧領域検査が二値の有効旗を要求するので、0.5は旗そのものの許容値ではない。

|node|feature|左|右|
|---|---|---|---|
|0|F20 index19、threshold0.5|T0、node1|T1、node2|
|1|F26 index25、threshold0.5|T0_R0|T0_R1|
|2|F26 index25、threshold0.5|T1_R0|T1_R1|

左は<=、右は>。全群を残し、False群を自動WAITや教師除外にしない。固定三nodeはデータがなくても常設する。

各子の入力indexは `[i for i in range(46) if i not in (19,25)]` の44列。F18(index17)、DIのF01(index0)を再選択できる。子のlocal特徴indexは保存時に元46列のglobal indexへ戻す。

各群でDecisionTreeRegressorを使い、criterion=squared_error、splitter=best、max_depth=2、min_samples_leaf=60、random_state=51、max_features=None、ccp_alpha=0等の旧引数を維持する。class_weightを回帰器へ渡さない。固定二段を含む最大深さは4。固定分岐はMSE最適化で選ばれたものではない。

空群は未知leafを置き、score/regression_value/impurity等をNone、data_absent=True、方向行0とする。空T側のF26内部nodeも消さない。非空少数群はfitできるが、最終の葉支持は従来条件で判定する。三phaseの保存合成モデルは3本、分類器fitは0、回帰器fitは非空群だけなので最大12回である。

## 保存nodeとpartition

全nodeのid/left/right/feature/threshold/path、方向行/0.5重み/先着成功率score、unique枠・日・場、methods/families、回収pnl0/5/10合計・平均・Decimal正本、MSE、barrier_gini等は旧60同schema。

固定nodeを含む全所属と統計を使用方向行から再計数する。元sklearn子の全node所属・件数・重み・回帰値・impurityと、合成JSON全方向予測/葉IDを照合する。生回帰mean/MSE対Decimal算術だけは旧数値許容を用い、score、支持、正額、閾値へepsilonを加えない。

training.partitionはT0_R0/T0_R1/T1_R0/T1_R1で、各値は次の項目を持つ。

```text
t / r / policy
direction_rows / pair_unique / days / sessions / row_ids_sha256
fit_performed / root / node_count / fit_parameters
```

旧z/aをt/rへ変更する。pair_uniqueはその枝に含まれる枠数で、両方向が同じ枝にあるpair数ではない。

structure.kindはfixed_current_routes、fixed_nodesは上記三node、child_depth=2、child_features=44、child_feature_indicesは上記投影、feature_count=46、max_depth=4、fixed_mse_optimized=False、child_estimator=DecisionTreeRegressor、target=pnl5。

## 方向順位と資格

walk/predictは新モデルのpolicyだけを局所的にS0へ射影して、固定60の汎用JSON走査・予測純関数へ渡す。元modelの辞書や旧globalを書き換えない。新固定nodeのfeature/threshold/pathをそのまま走査する。

方向順位は回帰平均ではなく障壁250成功率scoreの最高側である。同点はWAIT、どちらか未知葉へ到達すれば両方向WAIT。最高側だけにscore>=1/3、unique枠>=60・6日・10場、複数family条件を課し、最高側不適格時に低い側を救済しない。

**新固定二段は両方priceなので、従来の複数技法gateを自動では満たさない。** 採用葉の実通過pathに二つ以上のfamilyがあり、trend又はoscを含むことが引き続き必要。子がpriceだけを使った葉は支持や回帰平均が良くても不適格となる。二つのprice旗を二つの技法familyとは数えない。

A1の回収支持とstrict正額条件は後段で同じ最高側へ追加する。DI0WAIT、一建玉、連続損失追尾、現在純益起動・名目床、費用、定時判断は本コードの外の固定処理で維持する。
