確認日2026-11-04。[試行00013](../../study/00013_収縮後の突破と失敗反転/README.md)の8入口・8固定X0運用。全65場は既使用。

| コード | 役割 |
| --- | --- |
| [入口.py](入口.py) | 同場20足の帯幅最小・6足固定高安・次6足までの拡大突破・次3足までの失敗復帰 |
| [検証.py](検証.py) | 3/5分×追随/失敗反転×方向補助2種。固定指紋、先着、一建玉、Viewer資源を保存 |
| [合成検証.py](合成検証.py) | 25境界確認。最小/高安への当足包含、6/3端点、同足不可、飛越、全リセット、補助独立、実依存固定 |
| [独立監査.py](独立監査.py) | 8×65会計・BBO・費用・DD・全先着・全X0返済初着・CSV/JSONL・Viewerを直接照合 |

| [レポート.py](レポート.py) | 固定JSONからREADME・全候補結果・51×9設定表を生成 |

運用は旧[00011の固定X0](../テクニカル循環/運用.py)を読取呼出し、変更しない。Python3.14.3・NumPy2.5.3、キャッシュ復元は既存orjson3.13.0。新しい学習ライブラリ・GPUは使用していない。原板を複製せず、大きな詳細は`work/収縮反転/00013/`。

```powershell
python -X utf8 scripts/収縮反転/合成検証.py
python -X utf8 scripts/収縮反転/状態独立確認.py
python -X utf8 scripts/収縮反転/独立監査.py --api-base http://127.0.0.1:8092
python -X utf8 scripts/収縮反転/補助対応診断.py
python -X utf8 scripts/収縮反転/レポート.py
```

状態独立確認を先にGit外へ保存し、主監査が正式試行へ取り込む。状態確認が未保存の主監査は途中結果をGit外へ保存し、総合監査を完了としない。`--api-base`省略ならAPIを使わないローカル確認。APIを使う場合はViewerを同じ市場root・本repoのresource_rootで起動しておく。

数値再現は別の空試行先へ正式`計画.md`と`条件.json`をコピーし、次を使う。

```powershell
python -X utf8 scripts/収縮反転/検証.py --study work/収縮反転/再現00013 --work work/収縮反転/再現00013詳細
```

正式結果の上書き、固定後の条件・コード・入力変更は拒否する。補助対応の共通仮約定を別の市場標本として加算しない。品質空白を含む全体の確定額は未確定のまま保持する。原著の125本低帯幅・連続帯外終値の再現ではなく、20/6/6/3は本研究独自の条件である。
