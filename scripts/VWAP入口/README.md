# VWAPを価格入口へ加える検証

[試行00018](../../study/00018_VWAPの位置と傾きで順行反転を比較/README.md)の36案。旧00011のT1押し目再開/R2BB内復帰を価格Pとして1/3/5分で使い、VWAPの共通助走・位置・傾き・起算を分ける。入口の125/250先着と単一建玉X0運用を別に評価する。全65場は既使用。

`参照.py`が固定00017の補助NPZを公開判断原行までに原順で結合し、`入口.py`が旧PへN/Dの条件を加える。`検証.py`は出典と固定指紋を検査し、全36入口/運用を一度再生する。旧code/cache・原板・既存結果は変更しない。

Python3.14.3、NumPy2.5.3を使用。00017を読取再利用するため、同抽出時に使ったorjson3.13.0があれば使用し、なければ標準jsonが読み込まれる。今回の再生自体は固定NPZが入力で、原板JSONを全量再抽出しない。

```powershell
python -X utf8 scripts/VWAP入口/合成検証.py --final
python -X utf8 scripts/VWAP入口/検証.py
```

合成の途中実行は`--final`を付けず途中proofへ保存し、編集終了した最終合成だけが`合成編集終了:true`を持つ。主再生は対象5ファイルのSHAと成功flagを検査してから実行前固定を作る。正式結果の上書き・固定後変更は拒否する。固定後に検査を追加する場合は追補を別ファイルにする。

数値再現は`--study`と`--work`へ新しいGit外の先を指定する。計画/条件を新試行先へコピーし、補助入力台帳の`参照`を固定00017結果へ、`作業台帳参照`を00017抽出台帳へ解決できるよう設定する。両SHAは元ファイルと同じ値にする。価格入力台帳は固定00008への参照として主処理が検査/作成する。原板やNPZの複製は不要。

```powershell
python -X utf8 scripts/VWAP入口/状態独立確認.py --実行許可
python -X utf8 scripts/VWAP入口/独立監査.py --api-base http://127.0.0.1:8092
python -X utf8 scripts/VWAP入口/補助対応診断.py
python -X utf8 scripts/VWAP入口/準備診断.py
python -X utf8 scripts/VWAP入口/レポート.py
```

状態側は全価格足・補助as-of・基準/epoch・四点準備・旧P・全36発動を別再構成する。会計側は保存先着を正常気配から直接追跡し、約定/注文/費用/MFE・MAE/DDを検算する。補助対応は同じ価格イベントと実新規を揃え、固定X0の共通出口差と、左右だけの参加集合の純額差を分ける。数値独立監査と保存明細の対応診断を同じ検査とは呼ばない。

会計監査/補助対応の既定対象は正式00018。別の再現先には状態側の`--study/--work`を指定し、正式結果の検査と混同しない。

準備診断は現在の配信値の問題と確認遅延/履歴助走を区別し、元価格PからN_A/D_Aへの除外を数える。保存結果のレポート再表示は市場・損益を再計算しない。

大きい全足参照/価格P/入口/運用明細はworkのgzip、正式には指紋と全36成績を残す。Viewerは実行前指定の3分T1/R2×六設定12運用を保存する。1/5分を表示代表へ選ばなかったことを、未検証と取り違えない。
