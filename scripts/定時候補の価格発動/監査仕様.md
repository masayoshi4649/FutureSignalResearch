## 独立先着の公開API

```python
prepare_events(events) -> dict
label(events_or_index, slot, condition, force, end) -> dict
entry_stats(rows, target_period, period_function) -> dict
```

場ごとに元6列を一度だけ索引化できる。入力は価格時計が有限・非後退、原行がstrict昇順である。正常BBOは元valid旗＋有限正bid<ask、発動監視は加えて有限正Lastを要求する。数量正常旗や受信時計を推定し直さない。

設定行のLast不正は登録せず「観測不足」。実判断は判定不能にし、watch未開始なので監視不足qualityへ加えない。設定時に買Last>high又は売Last<lowなら「既超過」、等号は未突破として登録可能。設定keyよりstrict後の最初の正常監視行が外側なら発動する。同価格秒の後行も対象だが、設定行自身は発動させない。

watchの最終正常監視時計は設定timeを初期値とする。以後の**全原行**で、最終正常＋300秒をstrict超す最初の到着を突破より先に観測不足取消へする。不正Last/BBO行でも取消時計の出典になるが、監視時計は更新しない。該当到着がなければ満了timerで最終観測との差を検査する。300秒等号は可。後続gap取消は期間の損益quality注意に接続する。

発動行を新しいrequest_time/lineとし、+1価格秒以後かつ後原行の最初正常BBOで買ask／売bidへ仮約定する。Lastは発動までに使い、発動後のfillにLast正常を追加しない。新規TTL30秒等号は可だが、次定時・force・endは未満だけ。価格飛越でも線価格へ戻して約定しない。同枠の取り直しはない。

返り値は元BINDING5/policy/side/roleを保持し、origin_slot、condition全文、trigger(time/line/last)、request_time/line、condition_outcome/reason、watch_started/qualityを持つ。元time/lineをtriggerへ上書きしない。

非fillのcondition_outcome/outcomeは、未発動／既超過／観測不足／発動未約定を分ける。fill後はcondition_outcome=約定、outcome=250／125／期限／不足とし、entry_time/line/price・mfe/maeを保存する。先着は新規fillから正常返済側BBOで測り、gap>300を障壁より優先する。forceは**最初の同秒正常行までを含む**固定49補足の規約、endは半開である。未発動や未約定を確定0利益と呼ばない。

非重複先着は実entry_time/line/slot_id順へ並べた後、前先着終点keyよりstrict後だけを採る。旧の予定枠順を当然の約定順としない。支持60枠・6日・10場・非重複20（時系列）／20枠・3日・5場・非重複10（その他）、主と非重複70%目標は維持する。
