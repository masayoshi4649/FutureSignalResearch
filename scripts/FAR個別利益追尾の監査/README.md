# 個別利益追尾の独立監査

[試行94](../../study/00094_連続出生を固定した個別利益追尾/README.md)の保存口座を、金融Goとは別の状態と算術で検査する。原板は共用入力を参照し、複製しない。

`原板と保護の照合.py`は保存Nativeの新規・取消・返済通知を全原行へ結び、Actualの受理・予約・取消・最初の適格正常行での約定を再構成する。正常原行ごとの約定前・後で、残玉単価の費用後利益u、全建玉清算額W、正益後の赤字化、ATR幅の固定、非緩和床、保護要求、口座合算の時価DDを検査する。保存された極値点だけの検算とは区別する。

ATRは凍結5分足から独立計算する。足の利用可能時刻を守り、未来の足で過去の床を補わない。元戦略のSource通知は再生成せず保存Nativeを使うため、元FAR全面同値や実mini板での約定可能性の証明ではない。原板の欠測中の価格も推定しない。

固定93の[原板照合部品](../FAR元連続再現の監査/原板照合.py)はSHA256 `49825ac408513e9cea8e9f8d852360a00436546fb9e99ec0b5edf2f86cafb62b`で照合する。Python 3.14.3、標準ライブラリのみ。出力は未作成ファイルへ保存する。

```powershell
& work/venvs/technical-tree/Scripts/python.exe -B -X utf8 scripts/FAR個別利益追尾の監査/原板と保護の照合.py `
  --run --input work/94実行/正式54場 `
  --manifest study/00080_FAR後期三手法の15分移植と利益保護/入力台帳.json `
  --out work/94Raw検査/全54場.json --workers 8
```

`--limit 2`は先頭2場の接続確認専用であり、54場全体の成功へ読み替えない。コードの人工確認、接続確認、全54場の実行証拠は試行94に分けて記録する。

`表示監査.py`は12口座×54場の648資源を、固定93/80の表示比較部品で既存Viewerと照合する。新規・部分返済の所有ID、枚数、半円費用、純額、終了所有0、応答本文SHAを検査する。これは保存会計の表示一致であり、実mini執行やSource生成同値を保証するものではない。サーバーの起動・停止・設定変更は行わない。

`診断.py`は独立集計に通過した保存54場を、正負額・PF・u/Wの利益後赤字・元手法/段階・開始日へ分解する。未参加や決済後の仮想利益を機会損失として採点しない。入口の閾値選定や原板再生を行わず、初正益時の予約状態を赤字化の原因と単独では断定しない。

```powershell
& work/venvs/technical-tree/Scripts/python.exe -B -X utf8 scripts/FAR個別利益追尾の監査/表示監査.py `
  --run --catalog study/00094_連続出生を固定した個別利益追尾/成果物/一覧.resources.json `
  --result study/00094_連続出生を固定した個別利益追尾/成果物/結果.json `
  --out work/94表示監査/全54場.json --url http://127.0.0.1:8092 --workers 8
```
