bは当場前20公開連続有効3分足の旧R/Lを現在Cがstrict突破した登録で、注文ではない。元方向sと固定Bを登録時に使用済みにし、一監視中の別突破・同水準再登録・消費/取消同足の登録を抑止する。bの次1〜6足を寿命へ数えるが、高安を使うのはstart_j>b.confirmかつ公開key後strictの対象足だけ。通常b+1は対象外でも寿命に数え、最短b+2〜6の最初の対象足再テストを一回消費する。

反対端終値取消を先に、買Low<=B/売High>=Bの最初の再テストjで、外側終値Tは実side=s/順行、旧L<C<R strictはRとして実side=−s/反転、元端等号はWAIT。勢い/数量/時間不成立でも後足へ取り直さない。集合/sourceの役割文字列は「切替」、pure/建玉は実「順行」「反転」を保持する。純価格監視は実一pending/一建玉と独立であり、保有中役割変更で自動ドテンしない。

A0はT/R構造と実方向MACDヒスト一足差>0、現jATR14有限正/当場隣接ヒスト等の共通準備。A1でCMF21準備だけ、A2で実side×CMF>0strictを追加する。CLV=(2C−H−L)/(H−L)、CMF=ΣCLV*q/Σq。元floatH/L/C/q各Fractionの加重和/総量/比を精密保存し、採否epsilonを使わない。全21qの完全有限非負・各幅正・総q正が必要で、q0有効、H=Lはq0でも未定義、総q0も未定義で補完しない。数量理由だけで価格監視を取消さず、CMF窓と価格窓を分ける。

CMFは観測量で重み付けした足内終値位置であり、真の積極買い/売り量・機関注文・資金流入ではない。同じ21窓の単位量CLV平均との符号比較は保存読取診断だけで、単位量運用や新gateを追加しない。全21qが同じ正量なら同じ平均になる十分条件で、必要条件ではない。旧33単足CLVと情報が重なり、独立した確認票へ換算しない。

正式大明細は登録監視/発動判定/入口事例/全運用詳細/追尾の5gzip。親bは登録actionのfull登録参照から復元でき、最終足b→場末取消でも出典を失わない。全CMFpanelと登録配列は準備hash/countで接続し、正式数値出典はjへ限定する。固定29のOHLC/ATR/中心化MACD/Qを参照共有し、旧contextや全CMFを複製しない。
