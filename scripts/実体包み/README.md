s=買+1/売−1とし、`s(Cp−Op)<0`、`s(Cj−Oj)>0`、`s(Oj−Cp)<=0`、`s(Cj−Op)>0`。始値側の等号だけを許し、終値側strict、零実体/ヒゲ包み/実体比/CLV/20高安条件は追加しない。Pならs(Cj−Cp)>0は自動で、独立した勢い票ではない。現前中心化MACD12/26/9のsδH>0を共通に組み合わせる。

p/jは同場連続完全公開3分・index隣接・p.end=j.start・両confirm>=end・p.key<j.key。j確定時の二足観測なので、45のj.end>p.confirmは持ち込まない。公開key同値/後退と重複indexは拒否する。欠枠/NP/不正/不連続で二足/SMA局所窓を解除し、missing>0当足は投入しない。固定29から価格/ATR/macd_hist正本15列だけをstrictコピーし、数値銀行を無断変更しない。

`Mp=mean(C[j−20..j−1])`、`Mpp=mean(C[j−21..j−2])`、`dM=Mp−Mpp`、`dP=Cj−Mp`。当足を平均へ入れず、共通準備は現在含22足/j21が最速。元floatをFractionに写して全平均/差/符号をstrict計算し、0は準備可・B2ではWAIT。両s差正をT、両負をR、残りWAIT、実sideは保持する。dMには古い終値の窓落ちが入り、注文圧力とは言えない。平均の価格差は割合乖離率ではない。

実4役割はB0反転/B1反転/B2順行/B2反転、会計人工は買売×4の8経路。B2はB1の部分集合でも実役割が変わるため、role込みの全case正規化同値を要求しない。同経済的新規は場/side/新規key/価格/入口ATR/Dを対応し、同役割と役割だけ差を別記する。同じXFの共通出口と、純除外/実一建玉抑止・再参加の差を分ける。
