# 保存済み損益のCSV出力

## 現行：一CSVに一候補だけ保存

2026-11-16以降は、別手法・別条件IDを同じCSVへ混在させない。[候補別に出力する.mjs](候補別に出力する.mjs)は、型付きJSONの4表から候補ごとに `集計.csv`、`デイ.csv`、`ナイト_米前.csv`、`ナイト_米後.csv` を作る。元の全セル・候補内の行順・空欄を保持し、数値を再計算しない。既存候補フォルダを上書きしない。

依存はNode24.22.1とCodex提供のartifact-tool2.8.157。`--dependencies`へ付属`node_modules`を指定し、依存一式をリポジトリへ複製しない。

```powershell
node scripts/損益CSV/候補別に出力する.mjs --input 型付き入力.json --output 新しい出力先 --proof 新しい確認票の保存先 --dependencies "$env:USERPROFILE/.cache/codex-runtimes/codex-primary-runtime/dependencies/node/node_modules"
```

174の表示移行は[174の閲覧形式を更新する.py](174の閲覧形式を更新する.py)。分割32CSVを元4CSVの全セルと照合した後、旧4CSVを履歴ZIPへ元byte保存して現行表示から外した。新規試行の採番や売買研究の再実行は行わない。[正式の変更記録](../../study/00174_共同条件を残して単一建玉の入口を広げる/再現資料/候補別CSV索引.json)。

## 旧107・108形式の出力履歴

金融を再実行せず、検算済みの試行107・108形式の `成果物/結果.json` から、候補別集計と全セッションを出力する。無取引のセッションも残す。正本JSONのSHA256を必須とし、出力先は新規フォルダに限る。

依存：Node.js 24.22.1、`@oai/artifact-tool`（Codex付属依存）。スクリプトを `work/損益CSVの出力/` へコピーし、同フォルダの `node_modules` を付属依存の `dependencies/node/node_modules` へジャンクションで結ぶ。リポジトリへ依存一式を複製しない。

```powershell
node work/損益CSVの出力/出力する.mjs 入力の結果.json 入力のSHA256 新しい出力フォルダ
python -B -X utf8 scripts/損益CSV/再読で照合する.py 入力の結果.json 入力のSHA256 出力フォルダ
```

`全セッション.csv` は条件IDごとにセッション開始日の順で並び、ナイトは開始日に属する。累計は条件ごとに0円から計算する。`候補別集計.csv` は各条件の全70場の合計。参加率は0〜100の百分率であり、行の単純平均ではなく参加枠合計÷判断枠合計で求める。金額は円で、丸め・桁区切り・通貨記号を付けない。文字コードはUTF-8 BOM付き、改行はCRLF。

片道追加滑り0ptは、観測BBOと手数料を含む基準。5ptはその上に片道5ptを加える仮定である。仮定遅延1秒は価格時計上の仮定で、実測通信遅延ではない。mini片道手数料は1枚税込38.5円。保存点連結時価DDは保存済み観測点に基づく値で、全ティックの最大DDとはしない。

全行の純損益、候補別合計、建玉・注文の残存0、主参加枠の内訳、表計算上の純損益・累計・参加率、入力の前後不変を検算し、`CSVの確認.json` を保存する。CSVを再読して件数・重複・無取引行の保持も確認する。
