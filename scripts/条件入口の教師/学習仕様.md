確認日：2026-11-06。[69の検証計画](../../study/00069_条件入口に合わせて技法群の教師を作る/検証計画.md)に対応する。学習器の所有は本書・`学習.py`・`学習の人工検査.py`だけ。旧65以下を変更せず、本物測定・学習・運用は親担当だけが固定後に実施する。

## 比較の境界

I0は即時入口、C0は68条件入口の独立先着と回収を使う。両者とも同じ共通可知pair、同60特徴、同じ学習演算を使い、運用では68の発動・否定・寿命・費用・連続保護を維持する。I1/C1は対応する同じ木へ過去主回収strict正を追加する運用であり、別fitではない。

[旧65の学習仕様](../現在状態と量価格/学習仕様.md)のDI→対応episode四群・子58列深さ2・全深さ4・seed51・squared_error・min_samples_leaf60・方向重み0.5を保持する。固定段はMSE最適化の対象ではない。新指標、特徴閾値の総当たり、原板の追加、新しい教師以外の情報はない。

rootが全定時の基礎ready両方向から、即時と条件の両契約とも可知なpairを用意する。旧採用候補だけを測定しない。未知が一側でもあればそのpairを両対照から除く。条件入口は同高安から一側が発動して反対側が否定され得るため、両側約定を要求しない。旧65のprepareや旧55のaggregateを直接呼ばない。

## 公開API

```python
prepare_rows(rows, evaluation_start, feature_count=60) -> (used, training)
fit(rows, feature_meta, policy, model_id, evaluation_start) -> model
walk(model, values) -> (leaf, path)
predict(model, vectors) -> prior
```

`policy`はI0/C0だけ。metadataは旧65の60列を固有importして検査する。float32・共同mask・Decimal money・数値照合許容・木の展開も旧純関数を読み、大域値を変更しない。新prepareは旧prepareを呼ばず、次のcanonical11項目を独自に検査する。

| 項目 | 型・意味 |
| --- | --- |
| session / slot_id | 空でないstr。pairは両者の組で識別 |
| side | boolを含まないint、+1/-1。同枠の両側が必須、重複拒否 |
| features | 60個の旧規約の有限数値。保存はfloat64表示、走査は旧float32 |
| filled | 厳密bool |
| outcome | 約定時は250/125/期限。確定無取引は無取引 |
| end_time | 条件又は障壁の既知終了。有限非負、評価開始秒よりstrict前 |
| recovery_end_time | 回収既知終了。有限非負、評価開始秒よりstrict前 |
| pnl0 / pnl5 / pnl10 | 有限Decimalへ正規化する回収。無取引は3値とも厳密0 |

None・不足・未知回収を0へ補完しない。既知終了が評価開始と同秒なら拒否する。canonicalに元判断time/lineやentry keyは含まれないため、原判断以後の終了、SOURCE、元原行との厳密結合、共通集合を作る時点での品質はmainと独立監査の責務である。学習器へ未知を隠して入力しない。

入力順を保ち、元辞書へ代入しない。`training.evaluation_start`と`training.period.evaluation_start`は同じ評価開始秒。`training.row_ids`はsession/slot_id/side、`input_rows_sha256`と`used_rows_sha256`は新canonical全文、`target_rows_sha256`はidentity+pnl5、`used_barrier_rows_sha256`は回収3値と回収終了を除いた新列、`period_sha256`は場順・最大既知終了・評価開始を結ぶ。旧即時canonicalの指紋と同値と称さない。学習器内では追加除外0、共通集合と特徴の出典指紋はrootが別途保存する。I/Cの終了時計が違えばperiod指紋も違い得る。

## 回帰と先着を分けるnode

| 項目 | 分母・意味 |
| --- | --- |
| direction_rows / weighted_rows / total_weight | 全可知方向行とその0.5重み。sklearn所属と一致 |
| filled_direction_rows / unfilled_direction_rows | 当nodeの約定既知／確定無取引方向数 |
| barrier_total_weight / success_weight | 約定既知数×0.5／250件数×0.5 |
| score | 250件数÷約定既知数。無取引を125失敗へ混ぜない |
| fill_rate | 約定既知方向数÷全可知方向数。採点順位へ掛けない |
| unique_slots / days / sessions | 約定既知だけの枠・日・場数。`filled_`の同名項目も同値 |
| all_unique_slots / all_days / all_sessions | 無取引も含む全可知群の枠・日・場。先着支持へ転用しない |
| data_absent | 回帰行そのものが0 |
| barrier_data_absent | 約定既知行が0。回帰行があって平均0でもscoreはNoneになり得る |
| recovery | 無取引0を含む全可知行の費用別回収統計 |
| recovery_filled | 約定既知だけの同じ形式の回収統計 |
| recovery_mse_decimal | 全可知pnl5のDecimal正本MSE |
| regression_value / impurity | 子木はsklearnの生float平均/MSE、固定段はDecimal統計のfloat |

`recovery`と`recovery_filled`はともに次の形式である。

```python
{
    'pnl0': {'sum': 'Decimal合計文字列', 'mean': float_or_None,
             'mean_decimal': 'Decimal平均文字列又はNone'},
    'pnl5': {...},
    'pnl10': {...},
}
```

合計は方向行の単純和であり、0.5重みを掛けた合計損益ではない。全行が同じ重みなので平均・MSEは単純平均と同じ。合計を必要精度で正確に作り、平均・MSEの最後の除算だけ80桁ROUND_HALF_EVEN。旧65と同じ生float照合許容を使い、生値の0補正はしない。

無取引回収が0なので両統計のsumは同値になる。`recovery_positive`は全可知pnl5のDecimal合計strict正。全無取引ならFalse、回帰行なしはNone。全可知平均と約定当たり平均の大きさは異なるため、説明で取り替えない。

rootの新calibrationは`mean_yen[f] = node.recovery_filled['pnl'+f]['mean']`、`mean_all_yen[f]`は`recovery`のmean、`sum_yen[f]`は同じsum文字列、supportはnode.leaf_support、positiveはnode.recovery_positiveを使う。空葉のpositiveは表示・選択形式へ必要ならFalseとして扱うが、元nodeの未知値は残す。旧55aggregateで無取引のclosedを取り出してはならない。

## 構造と予測

固定node0はF01/index0<=0、node1はDI非正側のF26/index25<=0.5、node2はDI正側のF20/index19<=0.5。いずれも空群でも保持する。四partitionはD0_V0/D0_V1/D1_V0/D1_V1。子列は各方向のDIと対応episode旗だけを除く58列で、相手経路の旗は残す。全pair検査後に方向行を分割し、枝内でpairが揃うことは要求しない。

V1は出生bから有効でありr/k完成ではない。V0も学習へ残す。固定trend＋priceによる従来技法資格は構造上維持されるが、心理的独立二票でも、現在setupや反転の成立の証明でもない。float32DIの零化枝と実DIroleが異なり得る既存限定を保ち、実DI0WAITは呼出側で維持する。

葉の支持60枠・6日・10場は約定既知に要求する。回帰木のmin_samples_leaf60は全可知方向行であり、これを満たしても先着支持が立つとは限らない。両方向が同じ葉に来ても同じ枠をunique支持へ二重加算しない。重複枠・反復episodeは独立標本と称さない。

priorは旧と同じ`{scores,leafs,side,winner_side,reason,eligibility}`。eligibilityはscore>=1/3、約定支持、異種family2以上かつtrend又はosc。両空は特徴未準備、片側でもscore未知なら未学習枝WAIT、raw同点は同点WAIT。ここでの「未学習枝WAIT」は、空回帰葉に加え、学習行はあるが約定先着標本がない葉も含む。nodeの二つの旗で区別できる。既知の反対側だけでこの先行WAITを解除しない。

prior自体は最高側への旧資格判定を返す。固定66selectorに新learnerを渡し、運用政策をE0/E1へ局所写像すれば、両側適格集合での最終選択・正回収条件・救済をそのまま使える。新学習器は回帰平均で方向順位を変更せず、取得価格へ未来の発動成功を埋め戻さない。
