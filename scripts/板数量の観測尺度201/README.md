# 201実取得q0の観測尺度診断

[診断201.py](診断201.py)は、201の25口座の取得識別子を純板特徴へ結合し、観測幅と実側に対する符号だけを集計する。金融の損益列、先着率、候補順位は集計へ入力しない。新入口や閾値を探索しない。

出力は[恒久入力](../../inputs/00201_両指数の板数量純特徴/取得q0の観測尺度/README.md)、説明は[201の尺度診断](../../study/00201_板数量の更新尺度を複合入口へ加える/板数量の観測尺度.md)。

```powershell
& 'work/複合テクニカル学習環境/Scripts/python.exe' -X utf8 'scripts/板数量の観測尺度201/診断201.py'
```

標準ライブラリだけを使う。既存の`取得識別子.json.gz`があれば、金融元台帳を再読せず、その投影と恒久純特徴から同体再集計する。未知は零にせず、候補別の分母を保持する。全25の単純合算を市場サンプル数とせず、本文用のBASE5母体はq0で重複除去する。
