# 固定26の新Night一場確認

[試行00027](../../study/00027_試行00026の新Night固定後確認/README.md)用。固定26のN0/N1/N2とX0を変更せず、旧65場を指標の助走だけに使い、新11/4Night一場だけを採点する。旧65場の損益を合算せず、新1場で支持や将来安定性を代用しない。

## 開封前と開封後を分ける

Python 3.14.3、NumPy 2.5.3で、リポジトリルートから実行する。

```powershell
C:/Python314/python.exe -X utf8 scripts/固定後確認/確認.py --warmup
C:/Python314/python.exe -X utf8 scripts/固定後確認/状態独立確認.py --warmup
```

助走は固定旧65場の技術系列だけを検算する。新原板/CSV/cacheを開かず、先着と運用を計算しない。主の七技術系列と品質は固定26へ厳密照合、別実装の数値/時点は独立助走で確認する。ATRの数値許容と呼値整数の厳密範囲も26を維持する。

人工検証の最終成功・編集終了、主/独立助走と全コードの指紋一致を確認してから開封前固定する。

```powershell
C:/Python314/python.exe -X utf8 scripts/固定後確認/確認.py --freeze
```

固定は新原板の名前/サイズ/更新時刻だけを確認し、内容ハッシュを先に読まない。開封承認を経た最初の一回だけ次へ進む。

```powershell
C:/Python314/python.exe -X utf8 scripts/固定後確認/確認.py --開封実行
C:/Python314/python.exe -X utf8 scripts/固定後確認/状態独立確認.py --実行許可
C:/Python314/python.exe -X utf8 scripts/固定後確認/追尾独立確認.py --実行許可
C:/Python314/python.exe -X utf8 scripts/固定後確認/独立監査.py --api-base http://127.0.0.1:8092
```

完了済み試行を再び未見として開封するコマンドではない。既存結果・開封journal/cache・予約stat変更・固定版変更を拒否する。途中失敗も最初の開封記録に残し、削除して初回状態へ戻さない。保存済み結果の閲覧と独立検算を、条件の再選択に使わない。
