## 会計と時計

- 実新規は25／49の15分枠。現在原行を入れる前の情報で判断し、約定は次正常原行。追加1秒は別に再生する。
- Source・参照・実所有を分け、参照ID単位の実新規は一度だけ。部分返済は未通知残量・未予約実残量で比例配分する。
- 主費用はmicro1枚片道11円と想定滑り5pt。ラージBBOを価格代理にする費用付き模型であり、micro板の約定実績ではない。
- 主保護は費用後正益で起動し、20pt以上の利益床と入口ATR幅で連続追尾。受理した返済は取消・延期しない。次板の悪化は残る。
- 技法Lastの可用性と約定BBOの可用性を分離する。時計欠損・逆行・不良Lastを数え、未知を0の観測値にしない。
- 場末は10分前に返済要求。末尾に正常な原行がなければ未解決として保存し、最終値で架空清算しない。

原板・中間JSON・実行ファイルは`work/`で扱う。正式成果物は小型の比較JSON、Markdown、圧縮した玉別診断、Viewer一覧と約定に絞る。
