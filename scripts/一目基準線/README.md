Python 3.14.3・NumPy 2.5.3。プロジェクトルートから、先着と損益を計算しない準備を先に行う。

```powershell
C:/Python314/python.exe -X utf8 scripts/一目基準線/検証.py --prepare
C:/Python314/python.exe -X utf8 scripts/一目基準線/状態独立確認.py --prepare
C:/Python314/python.exe -X utf8 scripts/一目基準線/合成検証.py --final
```

主準備・別実装の準備・人工検証の一致と、現コード/条件/入力の指紋を確認してから正式再生する。正式コマンドは実行前固定を行い、既存結果や正式中間物の上書きを拒否する。

```powershell
C:/Python314/python.exe -X utf8 scripts/一目基準線/検証.py
```

正式再生後は、全保存状態・追尾・会計・対応を順に確認する。


これは66場を使う既使用データ内の比較であり、新しい未見確認ではない。原板を新規抽出・複製せず、台帳の既存cacheを参照する。主準備の大きな全足証拠と六つの圧縮明細はGit外の `work/一目基準線/00028/` に保存する。正式MDに全行を転記しない。

## 各ファイル

| ファイル | 役割 |
