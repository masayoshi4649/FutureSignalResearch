# 入口条件の探索コード

作成日：2026-11-01。NK225の固定入口フレームについて、逆行125pt以上より先に順行250pt以上を観測する条件を探す。計画・条件・成績の正本は[試行00005](../../study/00005_順行250ptと逆行125ptで勝率70を探索/README.md)、[計画](../../study/00005_順行250ptと逆行125ptで勝率70を探索/計画.md)、[条件JSON](../../study/00005_順行250ptと逆行125ptで勝率70を探索/条件.json)に置く。

対象の旧60場はすべて既使用である。時系列の後続検査も、新しい未見相場の評価とは呼ばない。先着の確認率は運用損益の勝率ではなく、未校正のモデルスコア0.7も実際の確認率70%を意味しない。

## 分割・探索・支持基準

開始日で学習20日40場、条件選択5日10場、後続5日10場へ分け、同じ開始日のデイ・ナイトを同じ分割へ置く。境界は2026-10-19と2026-10-26。各ラベルの観測期限はセッション内なので、前の分割のラベルが次の分割の価格を使うことはない。過去の確定足による指標履歴は継続できる。

モデルへ許可する84列と監査専用29列は`特徴定義.json`に分ける。未来ラベル、新規・判定価格、MFE/MAE、所要分、日付・イベントIDはモデルへ渡さない。欠測補完の中央値、モデルのfit、日付ごとの重み、スコア分位点は学習約定行だけから作る。欠測補完後の学習を使う決定木と、欠測を扱う勾配木を区別する。

固定条件4,326通り、深さ2/3/4/5×最小葉40/80/160の決定木12モデルの葉・スコア閾値、勾配木4モデルの固定閾値・学習分位点を比較する。スコアは分類器の未校正出力であり、日別重みも入る。スコアの値ではなく、選択候補の実際の件数から確認率を測る。

確認率は`順行先着 /（順行先着＋逆行先着＋期限未達＋観測不足）`。未約定は別記する。

| 分割 | 最低約定候補数 | 最低開始日数 | 最低場数 | 70%判定に必要な30分間引き後件数 |
| --- | ---: | ---: | ---: | ---: |
| 学習 | 60 | 6 | 10 | 20 |
| 条件選択 | 20 | 3 | 5 | 10 |
| 後続検査 | 20 | 3 | 5 | 10 |

間引きは選択された**全候補**を要求時計順に並べ、同じ場・方向で採用要求から1,800秒以上離れた最初の要求を残す。未約定も起点に含め、新規時計・判定時計・成否を使って候補を選び直さない。70%候補には支持基準と、学習・条件選択双方の通常率・間引き率70%以上を要求する。

一候補の選択順は、探索70条件、学習・条件選択の低い確認率、低い間引き率、条件選択件数、簡潔さ、固定生成順。70%候補がなくても診断用の一候補を固定するが、達成とは扱わない。`選択固定.json`へコード・条件・入力・選択モデルのSHA256を残し、後続ではその一候補だけを評価する。再学習・全候補の再順位付け・閾値変更はしない。

Wilson95%区間は独立二項を仮定した参考値。日別bootstrapは選択候補がある開始日をまとめて再標本化し、成功数と全約定数から率を作り直す。日内比率の単純平均ではない。後続5日では日クラスタも最大5つであり、両区間とも将来70%以上の保証や多重探索の補正にはならない。

## 再現する順序

以下は新規の計算先で行う順序例。既存の正式試行へ一括して再実行する手順ではない。再現を別の作業先へ行う場合も、同じ計画・条件と、元台帳へ正しく解決する入力参照を用意する。既存の選択固定・後続結果を上書きして探索し直さない。

まずキャッシュを復元し、データを使わない検証を行う。

```powershell
python -X utf8 "scripts/複合検証/キャッシュ復元.py" --manifest "study/00005_順行250ptと逆行125ptで勝率70を探索/入力台帳.json"
python -X utf8 "scripts/入口分析/検証.py"
python -X utf8 "scripts/入口探索/ラベル準備.py" --self-test
python -X utf8 "scripts/入口探索/独立照合.py" --self-test
python -X utf8 "scripts/入口探索/特徴生成.py" --schema-only
python -X utf8 "scripts/入口探索/評価検証.py"
```

ラベルの合成7ケース、独立判定16ケース、特徴の合成7項目、評価の15テストを確認する。`--schema-only`は定義と合成結果を作業先へ書く。次に、同じ10,588候補を再ラベル化し、特徴だけを生成して照合する。

```powershell
python -X utf8 "scripts/入口探索/ラベル準備.py" --adverse 125 --favorable 250
python -X utf8 "scripts/入口探索/特徴生成.py"
python -X utf8 "scripts/入口探索/独立照合.py"
```

この準備では全60場のラベル生成・品質照合は行うが、後続の成績を探索の選択へ使わない。独立ラベル照合は入口時点の特徴や候補の完全列挙まで再現する監査ではない。特徴の旧ID・旧属性一致と、それぞれの合成検証も併せて確認する。

準備・照合が通ってから探索する。`$入口試行`は計算先を指す。

```powershell
$入口試行 = "study/00005_順行250ptと逆行125ptで勝率70を探索"
python -X utf8 "scripts/入口探索/探索.py" --study $入口試行 --phase 探索
```

後続を開くのは、一候補と最終コードの固定・レビューを終えた後だけである。次のコマンドは、その段階で別に実行する。

```powershell
python -X utf8 "scripts/入口探索/探索.py" --study $入口試行 --phase 後続
```

後続で不達・件数不足となっても、この試行内で別候補へ変更しない。仮説や主要条件の変更は別番号と新たな評価期間へ送る。

## 記録の読み方

4,605候補中、支持条件を満たす候補400、探索70候補0。診断用に固定した規則01319だけの後続検査を実施し、6/15＝40.0%、30分間引きは1/8＝12.5%だった。最低20約定に未達で、成功6件は1開始日に集中した。探索・後続の70条件は未達。選択固定JSON内の「未評価」は固定時点の状態として保持し、実行済みの数値は正式試行のREADME・後続結果JSONを参照する。後続後の再探索・後続結果の上書きはガードで拒否する。

入口時点で分かる情報を限定しても、同じ市場経路を共有する近接候補、既使用データへの仮説選択、多数候補からの選択偏りは残る。参考資料は[漏洩防止](https://scikit-learn.org/stable/common_pitfalls.html)、[確率校正](https://scikit-learn.org/stable/modules/calibration.html)、[Wilson法](https://www.itl.nist.gov/div898/handbook/prc/section2/prc241.htm)（確認日2026-11-01）。本125/250条件の70%を実証した文献ではない。
