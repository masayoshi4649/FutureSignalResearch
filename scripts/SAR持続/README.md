# 価格イベントとSAR方向持続

[試行00025](../../study/00025_価格イベントとSAR方向持続/README.md)の再現用コード。固定24の全価格登録/内復帰/外回復を読み取り再用し、共通のSAR数値準備上で、Q0のMACDヒストグラム現前差とQ1のSAR二本方向持続を比較する。数値条件・計画・固定SHAは試行側を正本とする。

## 実行

リポジトリルートでPython 3.14.3、NumPy 2.5.3を使い、共通入力台帳とcacheを参照する。原板をコピーしない。まず次の二つでラベル/損益を計算しない準備を照合する。

```powershell
C:/Python314/python.exe -X utf8 scripts/SAR持続/検証.py --prepare
C:/Python314/python.exe -X utf8 scripts/SAR持続/状態独立確認.py --prepare
```

最終合成・編集終了と全指紋の一致を確認して固定後に、正式再生と検算を行う。

```powershell
C:/Python314/python.exe -X utf8 scripts/SAR持続/検証.py
C:/Python314/python.exe -X utf8 scripts/SAR持続/状態独立確認.py --実行許可
C:/Python314/python.exe -X utf8 scripts/SAR持続/追尾独立確認.py --実行許可
C:/Python314/python.exe -X utf8 scripts/SAR持続/独立監査.py --api-base http://127.0.0.1:8092
C:/Python314/python.exe -X utf8 scripts/SAR持続/対応診断.py
```

正式再生は既存結果の上書きを拒否する。完了済み試行を再実行する手順ではない。別条件は新試行へ分け、保存した正本の検算と売買条件の再選択を混ぜない。

## コードの役割

| ファイル | 用途 |
| --- | --- |
| [指標.py](指標.py) | 固定24の銀行/窓と、新しいSAR銀行を分けて管理する |
| [入口.py](入口.py) | 固定24の全価格状態を純変換し、新M25とQ0/Q1の採否を決める |
| [運用.py](運用.py) | 固定24の125/250pt・必須A5追尾を読み取り再用する |
| [検証.py](検証.py) | 準備/正式を分け、全入力指紋、二運用、10圧縮明細、Viewer資源を保存する |
| [合成検証.py](合成検証.py) | 人工OHLCでSAR数式/初期同値/鏡像/公開/欠枠/二本持続を検査する |
| [状態独立確認.py](状態独立確認.py) | 原OHLC区間の別走査でSAR全値、全監視、全Q採否を再構成する |
| [追尾独立確認.py](追尾独立確認.py) | 全実保有区間の起動・非緩和・最初の返済要求を検算する |
| [独立監査.py](独立監査.py) | 全先着/対象外・Decimal会計・建玉帰属・CSV・Viewerと別証明を結合する |
| [対応診断.py](対応診断.py) | 旧24との不変価格/先着、準備差、手法差、実参加・共通出口・回収を分ける |
| [レポート.py](レポート.py) | 保存結果と証明から二文書・51手法×9尺度表を再表示する |

SARの方向未確定、現在だけの方向一致、前現在の二本持続は別の状態。反転判定前の線、確定後表示線、次足線を分け、後の表示を過去の注文値へ使わない。完全幅未公開の末尾足は銀行だけを更新し、局所前/現在の公開二本へは使わない。SARを出口・自動ドテンには使わず、最低同値以上のA5追尾を共通維持する。
