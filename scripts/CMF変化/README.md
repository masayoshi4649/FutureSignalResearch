D0は固定42A0の純13列/同時計11先着/全66ledger・traceをID以外変えずに保持する。旧全424jと採用245は別分母で、CMFが良くても旧不採用/WAITを救済しない。新しいh待機、現水準正、当足寄与I正、当足CLV正などのANDは加えない。

D1は現窓j−20..jと前窓j−21..j−1の和集合22公開完全連続足・全22q完全有限非負・各幅正・現前両総q正を要求する。完全0qは有効だが、零幅/総q0/未準備を0へ補完しない。前は当場隣接足の公開時点以下だけとし、古い正常値や前場へfallbackしない。量不完全で旧42の価格親を取消さない。共通20足総量0でも、両21総量正なら現前比を定義できる。

元H/L/C/q各floatをFraction化して、m=(2C−H−L)/(H−L)、N=Σmq、Q=Σq、F=N/Qを計算する。D2は実side×ΔF>0strict、ΔF=F現−F前。直接差と交差積N現Q前−N前Q現の符号を照合し、表示float/epsilonを採否に使わない。

```text
I= q現(m現−F前)/Q現
O=−q落(m落−F前)/Q現
ΔF=I+O
```

I/Oは前値から見た相対CLV・観測量・分母希釈の代数分解である。I正でも当足mは0となり得て、当足q0でOだけ改善する場合もある。Iを新買い圧力、Oを売り手退出人数と呼ばない。水準×差3×3とI/Oは同じD1準備の保存診断だけ。旧42A2全体は前準備の分母が違い、損益差を水準対変化の純効果としない。水準/I/O別運用は実行していない。
