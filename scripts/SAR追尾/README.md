# 最低同値床と公開SAR追尾

[試行00032](../../study/00032_最低同値床と公開SAR追尾/README.md)用。固定31のC0/C1両入口を保ち、X0の入口ATR幅追尾とXSの公開SAR追尾を比較する。入口評価は二案、運用は四案。SARの準備を入口条件へ追加しない。

## 共有するものと新規計算

[入口参照](../../study/00032_最低同値床と公開SAR追尾/入口参照.json)が固定31の条件・結果・証明・六圧縮明細を指す。旧CCI/BB/context/先着全件を32へ複製しない。運用へ渡す信号は固定31の純再構成から明示whitelistで写し、ラベル・仮新規価格・将来MFE等を渡さない。

新しく保存する大明細は `SAR全足.jsonl.gz`、`全運用詳細.jsonl.gz`、`追尾.jsonl.gz`。Git外の `work/SAR追尾/00032/` に置き、小型の参照・条件・固定・結果・証明・Viewerはstudyへ保存する。

SARは固定25で選んだ初期化・strict反転・表示clamp・次足候補の順序を、元OHLCのFractionとAF整数2/100〜20/100で計算する。特定ライブラリの出力と完全同一とはしない。長い精密分数は符号付き16進分子/正分母へ保存し、表示floatを反転判定や呼値丸めへ戻さない。

## XSの時点・保護

正常返済BBOのMFEが5pt以上になれば、SARの不準備・逆方向でも名目同値床を起動する。当場最新公開SARの方向が保有方向と同じ、かつ元の精密次足候補の名目利益がstrict正の場合だけ、買いceil/売りfloorで5pt呼値へ丸めて非緩和に締める。

公開足tの次足候補は、公開keyより後の正常BBOからだけ使う。同keyの過去気配や、bar処理時の古い最終気配で要求しない。入口前に当場公開済みの値も使えるが、最新無効から古い正常値へ戻らない。既設の保護線は維持する。注文待機中は建玉の線と適用出典を凍結し、SARのグローバル参照更新と分ける。

期限・既存待機約定・hard125・TP250が先行する。SAR線を越えていても、その線の価格で約定したとはせず、返済要求後に価格時計で最低1秒待った正常BBOで代理評価する。名目同値床と費用後同値、価格時計と実受信時計を区別する。
