## 数値と品質を分ける

前20価格足は同場の連続した有効公開足。数量は固定14の観測累積差分を使い、完全0量を有効とし、RVOLや正の平均量は要求しない。OBVは同場・同有効区間内だけを比較し、比較元kより前の量欠測を余分に要求しない。missing足は価格窓とOBVへ投入せず、価格MACD/ATRの銀行とは解除の範囲を分ける。

MACDは数値reset後の最初の有効終値を原点にした `C−原点` で同じ12/26/9のEMAを計算する。定数移動に対する理論上の不変性を使い、絶対価格の大きなEMA同士を差し引く丸めを抑える。原点・出典を保存し、数量欠測だけでは価格数値を解除しない。
