# 同じ局所帯の再試験と、再開後の終値進行

作成日：2026-11-06。新57の事前仕様。市場入力・本物教師・本物モデル・56結果は読まず、固定53のコード/出典schemaと人工材料だけで作成した。原典の売買規則そのものではなく、研究側で定めた価格経路の規約である。

## 準備とAPI

[固定53の特徴](../局所帯分岐/特徴.py)と[仕様](../局所帯分岐/特徴仕様.md)を変更せず、固有module名で読み取る。旧globalへ代入しない。

```python
extract(slot: dict, frames3: list[dict]) -> dict
```

返り値はready/reason/base/control_vectors/vectors/atr/D/background_direction/paths。`base`は固定53の返り値全文、`control_vectors`はその18列vectorsの深い複写、`vectors`は同じ18列の後ろへ12列を加えた30列である。旧18列の値・順・符号・metadataを変えない。atr/D/background_directionも旧値を使う。

旧53が未準備ならcontrol_vectors/vectorsとも両方向空list、pathsのT/RはNone。旧準備が成立した場合、価格イベントの不成立・途中・取消を理由にreadyを落とさない。これらは既知の状態であり、欠測ではない。新しい数値が表示範囲を超えた場合は例外とし、0補完や無言の準備選別をしない。

full SOURCEはbase.historyの参照10本・反応5本へ一回だけ置き、pathsの段階出典は足番号indexと公開keyの参照にする。原板、数量、教師、損益、保有の状態は読み込まない。

## 窓・原点・方向

判断に用いる旧53の最新3分足をjとする。参照はj−14..j−5の10本、反応はj−4..jの5本。参照10本の高安から上端U/下端Lを作り、5本の反応を通じて同じ価格に固定する。反応足の高安を帯へ加えない。

各定時にこの新しい窓から初期化する。前回のepisodeを更新された帯へ接ぎ替えず、前回の取消/消費状態を持ち越さない。同じ5本窓に、元突破方向d=+1と−1を別々に扱う。

- d=+1ではK=U、d=−1ではK=L。
- 価格の原点を `q(price)=d×(price−K)` とし、q_close=d×(C−K)、q_min=min(q(H),q(L))、q_max=max(q(H),q(L))。
- Tは元突破方向への再開で、実side s=d。
- Rは元突破の失敗から反対へ再開する経路で、実side s=−d。

返り値paths[実side]には、Tを元d=実sideから、Rを元d=−実sideから対応させる。価格T/Rは経路の名称であり、主処理が上位DIとの同向/逆向で付ける運用の順行/反転roleを置き換えない。上位DI同値WAIT等も変更しない。

## b/f/r/kの順序

最初の前足終値には参照末足j−5の終値を使い、その後は直前反応足の終値を使う。初回bは**buffer線5のcross**で、前q_close<5かつ現q_close>=5を要求する。これは前終値がK自体以下である条件と同じではない。境界にepsilonを加えない。

|経路|順序|条件|
|---|---|---|
|共通b|最初の外終値cross|前q_close<5、現q_close>=5。最初の一つだけを登録|
|Tのr|bより後の別足|q_min<=0、q_close>=5。同端へ高安が再接近し、終値は外側を保つ最初の足|
|Tのk|rより後の別足|q_close>q_max(r)。rの方向端を終値でstrict突破。追加bufferなし|
|Rのf|bより後の別足|q_close<=−5。最初の内復帰|
|Rのr|fより後の別足|q_max>=0、q_close<=−5。同端へ再試験し、終値は元外側を再取得しない最初の足|
|Rのk|rより後の別足|q_close<q_min(r)。rの反対端を終値でstrict突破。追加bufferなし|

全段階は別足にする。例えば、b足のヒゲがKへ触れていてもbとrへ二重使用しない。f足がrの高安条件も満たしていても、fを記録するだけにする。rを記録したその足でkを作らない。kは足中の高安更新だけでは成立しない。

最初のb/f/r/kとその出典を固定する。より後のrへ置き換えたり、取消後の再crossで新しいepisodeを始めたりしない。最初のr端を使い続けるため、より浅い又は深い後続足を後から選べない。

## 取消の優先と最大到達stage

各反応足は、まず既存episodeの取消を判定し、有効な場合にだけ次の一段を検査する。まだbがない場合だけ初回bを検査する。取消足や新段階を作った足を、別の段階へ再使用しない。

|経路・段階|優先取消|
|---|---|
|Tのb後、k前後とも|q_close<=−5でT帯内失敗|
|Rのb→f待ち|外側に残ることだけでは取消しない|
|Rのf後、k前後とも|q_close>=5で元外側再取得|
|T/Rのk形成後|上記帯取消に続き、s×(C−line)<=0で確認kの突破線否定。等号も取消|

lineは、kが突破した**r端**である。Tは元方向端、Rは元の反対端。実sideで表せば、買いはr高値、売りはr安値となる。k自身の高安やk終値へ途中で線を取り替えない。

同じ終値で帯取消と確認否定の両方が成立すれば、reasonsは帯取消を先にして両理由を残す。最初の取消だけを保存し、episode_valid/k_validをFalseにする。それ以後は新しい段階を作らず、再点火しない。

stageは最大到達段階であり、取消時に0へ戻さない。

|値|T|R|
|---|---|---|
|0|bなし|bなし|
|1|bまで|bまで|
|2|rまで|fまで|
|3|kまで|rまで|
|4|対象外|kまで|

episode_validはb形成後から最初の取消までTrue、k_validはk形成後から最初の取消までTrue。最大stageとの意味重複はあるが、未形成/未完成/途中取消/k形成後取消を区別するmaskとして保持し、独立した技法の証拠とは数えない。

## 確認後の既知終値進行

判断時刻にはslot.time、尺度Aにはその判断の旧ATRを使う。k形成済みなら、取消後も判断時点までに既知の反応終値を記述する。取消したepisodeの有効旗を復活させる処理ではない。

```text
age = (slot.time − key(k)[0]) / 900
x_i = s × (C_i − C_k) / A        （iはkを含む、以後現在までの既知反応足）
x = x_現在
h_close = max(0, max(x_i))
戻り = h_close − x
```

key(k)は(confirm,confirm_line)。SOURCEのpublishはboolであり、時刻として使わない。予定scheduledより後にkが公開されても、判断time/keyまでに可視ならageは非負になる。同秒でも原行前後があり得るので、age=0は「出典keyも同じ」を意味しない。

kを含む終値から始めるため、kだけなら進行と戻りは0。k足の高安を使って、公開前の足中経路を確認後の最大進行へ加えることはしない。k未形成だけage=−1、進行/戻り=0とする。0は欠測補完ではなく、段階と旗によって適用外を識別できる既定値である。

これは価格終値差のATR正規化で、費用控除後利益や実約定からのMFEではない。C_kは要求又は新規価格ではない。連続O49のh、利益起動、保護線、実MFEとも混同しない。x/h_close/戻りは従属した表現で、独立な三つの証拠ではない。

五本窓の制約から、最短Tでもk後に最大2本、最短Rでは最大1本の終値しか観測できない。進行値の乏しさや確認の稀少さは標本の制約であり、その結果を見て寿命・buffer・参照期間を変えない。

## pathsの保存schema

paths['1'/'-1']['T'/'R']は各episodeの診断で、次を返す。

- role、side、break_direction、level：価格経路の種類、実side、元突破方向、固定帯端。
- stage、episode_valid、k_valid：最大到達と現在の有効旗。
- b/f/r/k：未形成None又は{index,key}。TのfはNone。
- line：k形成時に固定したr端。未形成None。
- cancel：未取消None又は{index,key,reasons}。最初の取消を保持。
- trace：反応5本ごとの{index,key,action,stage,episode_valid,k_valid}。値は処理後で、直前状態は前行又は初期0/Falseから復元できる。
- age/progress/max_close_progress/pullback：上記の終値統計。最大値は説明用で、追加vectorには直接入れない。

反応足の高安順や、足が先行確認の後に形成開始したことまでは主張しない。固定53が保証するのは必要SOURCE・公開key・連続性と判断時点の利用可能性である。足中に理想の価格で新規したことにもせず、最終判断は15分枠の当時情報とする。
