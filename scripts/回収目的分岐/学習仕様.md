# 回収目的の固定分岐学習

作成日・確認日：2026-11-06。対象は新56の純学習部分。市場入力・本物教師の読取、本物のfitはrootが担当する。本ファイル群の人工は生成した数値だけを使う。

[旧54の学習](../方向局面分岐/学習.py)と[仕様](../方向局面分岐/学習仕様.md)を固定のまま参照する。旧globalを書き換えず、旧54→旧53の純関数を固有のmodule名で読み込む。

## 変更するものと維持するもの

旧54と同じ18特徴を用いる。F18（Z）を根、float32化後のF01符号を次段へ事前固定し、四つの群の17列子木を学習する。今回変えるのは、子木の目的を障壁分類のginiから、**独立O49測定のpnl5の二乗誤差**へ移す点である。

|項目|規約|
|---|---|
|保存モデル政策|G0だけ。G1は同じG0木を使い、別の木をfitしない|
|固定node|0=F18<=0.5、1=Z0のF01<=0、2=Z1のF01<=0。三つとも空群があっても保持|
|群|Z0_a0/Z0_a1/Z1_a0/Z1_a1。a0はfloat32 F01<=0、a1は>0|
|子入力|F01..17。F18は子へ入れず、F01の強さは子でも分岐可能|
|子学習器|DecisionTreeRegressor、criterion=squared_error、splitter=best、max_depth=2|
|全体深さ|固定二段を含め最大4。固定段はMSE最適分割でない|
|支持パラメータ|min_samples_leaf=60方向行、min_samples_split=2、min_weight_fraction_leaf=0|
|その他|random_state=51、max_features=None、max_leaf_nodes=None、min_impurity_decrease=0、ccp_alpha=0、monotonic_cst=None。回帰木にはclass_weight引数がないため渡さない|
|重み|各方向行0.5。両方向を持つ一枠の重みは計1。枝へ分かれた後にpair揃いを再要求しない|
|依存版|scikit-learn 1.9.1。fit時に版を検査。Python/NumPy/SciPy実版もmodelへ保存|

公式[DecisionTreeRegressorの仕様](https://scikit-learn.org/stable/modules/generated/sklearn.tree.DecisionTreeRegressor.html)を参照する（2026-11-06確認）。squared_errorは平均による回帰と分散減少の目的であり、正益か否かの分類器ではない。全てのpnl5が負でも、負額の大きさが異なれば分岐し得る。

## API

```python
fit(rows, feature_meta, policy, model_id, evaluation_start) -> dict
prepare_rows(rows, evaluation_start, feature_count=18) -> (used_rows, training)
walk(model, values) -> (leaf_id, path)
predict(model, vectors) -> dict
```

`feature_meta`は旧54と同じF01..18順のid/name/method/family/scale。familyは旧15列の順を保ち、F16..18はprice、F18のmethodはP10。列の追加、並べ替え、欠測補完はしない。

`fit`のpolicyはG0のみ。model_idは非空文字列、evaluation_startは次の評価開始価格秒。`prepare_rows`の返り値は旧54と同じく**二要素**である。

## 教師と除外の順序

入力行は旧54の教師に、pnl0/pnl5/pnl10/recovery_end_timeを付けたものとする。

|列|型・用途|
|---|---|
|slot_id/session|非空str。sessionとslot_idの組でpairを識別|
|scheduled/time/end_time|有限実数の価格秒。旧障壁終了は評価開始よりstrict前|
|line/end_line|0以上のint。bool不可|
|side|intの+1又は−1|
|features|18有限実数。float32化後も有限、Zは元値で0/1のみ|
|outcome/filled|250/125/期限/未約定/不足とbool。250だけを障壁成功1、125と期限は0とする|
|entry_time/entry_line|使用できる障壁教師には有限時刻/int原行が必要。未約定・不足はNone可|
|pnl0/pnl5/pnl10|int/float/Decimal又は数値文字列。None又は列欠けは回収未知。bool/NaN/Inf/不正文字列とfloat64の桁あふれ・非零の桁落ちは拒否|
|recovery_end_time|独立回収の終了価格秒。None又は列欠けは未知。提供済みなら判断以後かつ新規時刻以後、評価開始よりstrict前。評価開始と同秒は全原行を拒否|

1. **旧障壁検査を最初に全入力へ実施する。** 両方向が同枠・同場・同scheduled/time/lineであること、重複/片側/未来・逆順・feature不正等を旧54と同じ規約で検査する。未約定/不足を含むpairは双方を除く。除外候補でも旧障壁終了の未来を隠さない。
2. 全入力行の回収値を検査する。Noneは未知として残すが、提供済みの未来回収終了や不正な数値は例外にする。除外による未来情報の救済はしない。
3. 障壁側で使用可能なpairについて、両方向の三費用回収額と回収終了が全て既知であることを要求する。片側一項目でも未知ならpair全体を除く。障壁除外と回収除外はstageを分け、方向別の欠測列・outcome/filledを残す。
4. 最後に使用方向行を元入力順で保持して、Z×float32 DIへ分ける。群内片側だけでも非空ならfitする。全体で使用pairが0ならfitできないとして拒否する。

回収値の追加状態列は純学習では使わない。回収額が確定完結から来たこと、旧障壁の新規と同じ新規であることは、上流の固定55測定・集計・監査の責任とする。正の損益か否かを教師の採否へ足すことはしない。

## canonical行と指紋

旧障壁canonicalは、必須11列とentry2列の計13列である。新canonicalはそれにpnl3列とrecovery_end_timeを加えた**17列**。featuresは旧と同じfloat列、pnl3列は丸めないDecimal文字列に正規化する。entry列と欠測の回収列はNoneを明示する。ID/配列順を変えず、全JSON指紋は有限値だけで作る。

`training`は次を保持する。

- 新input_rows_sha256/used_rows_sha256：回収値を含む全入力/使用canonicalの指紋。
- row_ids/row_ids_sha256：最終使用教師のsession/slot_id/sideを入力順で保存。方向行の合算とunique枠は別。
- target_rows_sha256：同じ順のsession/slot_id/side/pnl5。pnl5はDecimal文字列。
- barrier_fingerprints：旧54検査が返すinput_rows_sha256/used_rows_sha256/row_ids_sha256/period_sha256の四つをそのまま保持。回収追加前の検査との照合用。
- used_barrier_rows_sha256：回収除外後の使用行を旧13列へ射影した指紋。回収欠測があれば、旧検査直後のused指紋とは異なる。
- input_pairs/used_pairs/direction_rows、weight_per_direction=0.5/total_weight、障壁/回収別の除外数、全除外pairと理由・方向別欠測項目。
- barrier_period：旧検査の期間情報。新periodには使用回収のmax_recovery_end_timeと全入力の既知回収のmax_input_recovery_end_timeも含む。障壁・回収とも終了秒<evaluation_start。
- partition：四群全てのz/a/policy/direction_rows/pair_unique/days/sessions/row_ids_sha256/fit_performed/root/node_count/fit_parameters。

上流が同じ教師集合の比較を要求する場合は、旧使用ID、新使用ID、固定55回収集計IDの一致を別途確認する。欠測を埋めて一致させない。

## 保存nodeと統計の尺度

全nodeは旧54のflat配列形式とid/feature/feature_id/family/threshold/left/right/pathを保持する。全使用方向行を合成JSONへ通して、固定段を含む各nodeの所属・支持・ID指紋を再計数する。

|field|意味|
|---|---|
|direction_rows/weighted_rows/total_weight|所属方向行数と0.5重み。方向行数とunique枠は別|
|success_weight/score|旧障壁250の成功重み/成功率。回帰値でも回収黒字率でもない|
|barrier_gini|2×score×(1−score)。障壁分類の診断値で、今回の子木分割目的ではない|
|unique_slots/days/sessions|session+slot_idのunique数、session先頭10文字の日数、場数|
|methods/families/leaf_support/method_support|全pathによる手法・familyと旧54の支持。固定price+trendもpathへ数える|
|training_ids_sha256|所属方向行のsession/slot_id/sideを入力順に並べた指紋|
|recovery.pnl0/5/10.sum|所属方向行の**単純合計**のDecimal文字列。0.5を掛けない。重複して実行できるstrategy損益ではない|
|recovery.pnl0/5/10.mean|所属方向行の平均の表示float。同じ0.5重みなので加重平均と同値|
|recovery.pnl0/5/10.mean_decimal|合計/方向行数を精度80・ROUND_HALF_EVENで除算した文字列|
|recovery_positive|Decimalのpnl5合計>0のbool。合計0はFalse。epsilonを加えない|
|recovery_mse_decimal|pnl5の母分散。n×Σy²−(Σy)²を十分な桁で計算し、n²による最後の除算を精度80・ROUND_HALF_EVENで保存|
|regression_value|子nodeはsklearnの生回帰平均、固定nodeは同所属のDecimal平均をfloat化したもの|
|impurity/impurity_kind|impurity_kind=squared_error。子nodeはsklearnの生MSE、固定nodeは同所属のDecimal MSEをfloat化したもの|
|data_absent|所属0方向行の未知node。score/平均/MSE/回収正はNone。sumは空和として文字列0|

空のZ群でもDI固定内部nodeを残し、各空terminal群に未知leafを一つ保存する。未知のscoreを0へ補完しない。非空少数群はfitできても通常の葉支持で除外する。

## 数値照合

子木は特徴float32、目的pnl5はfloat64でsklearnへ渡す。全node所属、件数、0.5重み、局所IDから全体IDへの変換と全方向のapply/predictを照合する。保存する子nodeのregression_value/impurityは生学習器値なので、JSONへの同値転記は厳密である。

独立Decimal算術との演算順の表現差だけ、次を許容する。

- 平均：絶対1e−10又は相対1e−12のmath.isclose。
- MSE：絶対1e−8＋1e−10×max(1,E[pnl5²])。

MSEは二乗値の差から計算されるため、極小の残差や微小な負数が生じ得る。生値を0へ丸めたり、giniへ置き換えたりしない。Decimal正本のMSEと区別する。合計・回収正の旗、障壁率・支持、float32分岐、予測のscore差/下限にはこの許容を使わない。

## 予測とG0/G1

`walk`と`predict`は、元modelのpolicyだけをD0へ射影した辞書を固定54の純関数へ渡す。元model・旧globalは変更しない。予測にscikit-learnやjoblibは不要。

返り値は旧54と同型のscores/leafs/side/winner_side/reason/eligibility。両方向を同じ木で採点し、**障壁scoreがstrict高い側だけ**を候補にする。同点はWAIT。最高側のscore>=1/3、葉unique枠>=60・日>=6・場>=10、pathの異種family>=2かつtrend又はoscを含む条件を維持する。最高側不適格でも低い側を復活させない。

一方でも到達葉が未知なら、他方にscoreがあっても未学習枝WAIT。両vectorsが空なら特徴未準備WAIT、片側だけ空は拒否する。実方向DI0のWAIT等、上流の運用規約は純学習が変更しない。

G0予測の後に、上流が固定55回収集計を使って回収支持及びG1の回収正条件を判定する。nodeのrecovery_positiveを使って回帰平均の大きい方向へ選び直さない。学習葉の率・平均は評価期間の将来値ではなく、学習済み統計であり、将来確率や利益の保証ではない。

人工は旧54の小型factoryから生成した400枠/800方向行だけを使う。四群の別回帰器との全node/全方向照合、固定三node/深さ/投影、障壁giniとMSE、全負回収でも分岐、pair先除外、回収指紋、未来/不正拒否、空Z/少数枝、float32境界、鏡像・同点・最高側のみ、零近傍のDecimal回収正、旧予測との完全一致を確認する。本物教師・市場・保存モデルを読まず、学習成果物も保存しない。

この人工は回帰器の最適化アルゴリズムの正しさや市場での利益を証明しない。固定構造・入力/出力の接続と境界を確認するものであり、本物の時系列fitと保存物の独立監査は別に行う。
