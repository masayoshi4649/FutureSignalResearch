# 方向に対応する再開確認を先に分ける

[試行62の検証計画](../../study/00062_方向に対応する再開確認を先に分ける/検証計画.md)に対応する表示器。旧61A0/A1各46場を保存対照とし、新K0/K1各46場を表示する。fit・予測walk・独立一枠計測・市場運用は再実行しない。

入力は全候補で同じ46特徴。根はfloat32 F01（候補方向のDI優勢差）<=0。非正側は価格Rの現在k有効F27（index26）、正側は価格Tの現在k有効F21（index20）を各0.5で分ける。四群はD0_K0/D0_K1/D1_K0/D1_K1。子は各枝のDIと対応k旗だけを除く44列・深さ2、全深さ4を維持する。非正側ではindex0/26、正側ではindex0/20を除外し、F18や対象外経路の旗は子に残る。

DI非正には同値・float32零化も含み、左枝を全件「反転進行中」とは呼ばない。最終の背景DI同値WAITは不変。k有効1は対応経路の価格確認が済み現在有効、0は未登録・未確認・取消・期限失効等の混合であり、0も学習に残す。61のepisode有効はbから始まり、今回のk有効と異なる。どちらも価格T/Rの名前と、現在DIによる実運用の順行/反転は別である。

K0は障壁score最高側についてscore>=1/3・葉支持・従来の複数技法資格・過去回収60枠6日10場を要求する。K1は同じ木で過去pnl5合計strict正も要求。回収平均で方向順位を変えず次点救済もしない。今回は固定根にtrendとpriceがあるため従来技法gateが構造的に充足するが、式を緩和したり独立票を追加したりはしない。空葉のscoreや回収平均は未知のnullを保持し、支持・平均条件も別途確認する。

小型の結果・正式保存監査・新3木/3回収集計・旧61の保存モデルを読む。全46特徴、55手法×9尺度、全node/葉・枝別投影・子trend/oscの選択、状態四群、全定時の価格経路・各葉episode反復を表示する。状態分布は使用教師方向行が分母で、純採用・実完結と分離する。unique枠や形成IDは群/葉をまたぐ重複があるため加算しない。

`base46_fingerprints`六キーを旧61全46列へ厳密照合し、既存base18/30/38射影も保持する。新特徴・新教師・新独立測定を追加する比較ではない。旧55の一枠両方向回収は再測定せず、その重複保有合計を同時実行戦略の利益として扱わない。先着率、回帰円予測、過去平均と実運用利益を区別する。

外部根拠は[局面と価格確認を分けた再調査](../../docs/議論/外部再調査/局面と価格確認を別の条件として組み合わせる.md)。2026-11-06にBollinger本人公式の2021年[Method IV](https://www.bollingerbands.com/_files/ugd/58be43_d09c50b6e8ea4afd9af0523ef94de876.pdf)と[Method II](https://www.bollingerbands.com/_files/ugd/58be43_b120ddf0184540608baf19e2c0ae2019.pdf)の本文を確認した。前提・価格確認・役割を分ける参考であり、既読説明の具体化である。ADX強弱やMFIをDI方向/k確認と同一視せず、原典にない15分・枝順・寿命やNK先着70%の根拠を作らない。教育的な実装説明は心理の直接測定や費用後未見成績の実証ではない。
