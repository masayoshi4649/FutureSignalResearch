# DI方向と対応経路の再開確認を先に分ける回収学習

作成日：2026-11-06。62の純学習仕様。実装・人工には固定コードと手作り教師だけを使い、本物入力・保存実モデル・本物fitを扱わない。

## 比較で保持することと変更すること

[旧61学習](../現行経路の状態分岐/学習.py)をLEGACYとして読み、旧46特徴・同じ教師pair・pnl5回帰目的・深さ4・支持・方向順位・費用・出口を保つ。旧61のT/R episode_valid固定二段を、**実方向DIのF01と、その枝に対応する経路の現在k_valid**へ変更する。

float32 F01が非正ならRのF27、正ならTのF21を第二段に使う。k0群も残し、自動的なWAITや教師除外にしない。出生bから立つepisode_validと、形成されたkが現在も有効であることを区別する。ただしk0には未形成・失効/取消・未登録等が含まれ、k1だけを心理や将来利益の証明としない。

同じ深さでも固定段と枝別の子候補列が変わる。分割順・44列投影・学習容量配分の比較であり、k旗だけの単独効果ではない。k成立方向が少なければ、その群の回帰木は十分に細分化できず、葉支持でも不適格となり得る。少数性を理由に既定のmin_samples_leafや資格を変更しない。

## APIと教師の完全再用

```python
fit(rows, feature_meta, policy, model_id, evaluation_start) -> dict
prepare_rows(rows, evaluation_start, feature_count=46) -> (used, training)
predict(model, vectors) -> dict
walk(model, values) -> (leaf, path)
```

fit/modelのpolicyはK0のみ。K1は同じK0木へ、後段の固定回収集計で回収支持とstrict正額条件を追加する。K1用の別木を学習しない。

metadataは旧61.feature_metadata(feature_meta,'A0')、float32・教師検査は旧61の純関数を直接再用する。新しい特徴、教師、目標値、欠測代用や除外を追加しない。旧moduleのglobalへ代入せず、入力辞書を変更しない。

prepare_rowsは両方向の既知障壁/回収・strict過去境界・未知pair丸ごと除外を四群へ分ける前に行う。片方向だけを教師へ追加せず、枝へ分けた後には両方向が揃うことを要求しない。同じpairの方向行が別枝に入ってよい。各方向のsample_weightは従来の0.5。

旧18/30/38/46の指紋とrow_idsをそのまま保持する。次のcanonical六値は旧61と完全同じで、既存base46_fingerprintsとも一致することを検査する。

```text
input_rows_sha256 / used_rows_sha256 / row_ids_sha256
target_rows_sha256 / period_sha256 / used_barrier_rows_sha256
```

feature_missing_handlingは `旧61全46特徴・同じ教師pair。追加情報・追加除外なし`。旧障壁教師の125/期限は0、250は1で、方向順位にはこの先着scoreを使う。回収meanが高い方向へ順位を変えない。

## 固定三nodeと四群

|node|feature|左|右|
|---|---|---|---|
|0|F01 index0、threshold0|D0、node1|D1、node2|
|1|F27 index26、threshold0.5|D0_K0|D0_K1|
|2|F21 index20、threshold0.5|D1_K0|D1_K1|

左は<=、右は>。D0はfloat32 DI非正、対象経路R。D1はfloat32 DI正、対象経路T。対応旗は二値を要求する既存領域検査を通し、0.5自体を旗値として許可しない。固定三nodeはデータが空でも残す。

**固定根は学習と予測で同じfloat32値を比較する。** 微小な正のF01がfloat32で0になればD0へ入る。D0を厳密DIによる反転role、D1を順行roleと完全に同一視しない。厳密な上位DI同値の最終WAITは従来どおり主処理で保持する。本学習器はそこへ新しいepsilonを加えない。

子は各枝で次の44列を使う。

|方向枝|対象k|除くglobal index|子に残る例|
|---|---|---|---|
|D0|R k_valid|0,26|F18、T k_valid index20、他44列内の全候補|
|D1|T k_valid|0,20|F18、R k_valid index26、他44列内の全候補|

各列の順は元46列の昇順。子のlocal feature indexは合成時に元46列のglobal indexへ戻す。DIのF01は両枝の子から除くため、DIの強さによる追加分岐は本構成ではできない。対応しない側のk旗と両episode有効旗は子に残る。

DecisionTreeRegressorのcriterion=squared_error、splitter=best、子max_depth=2、min_samples_leaf=60、random_state=51、max_features=None、ccp_alpha=0等は旧61と同じ。固定二段を含む全体max_depth=4。固定段はMSE最適分岐として選んだものではない。三phaseの保存合成モデルは3本、非空子の回帰器fitは最大12回、分類器fitは0回。

## 保存schema

全nodeは旧61同型のid/left/right/feature/feature_id/threshold/path、direction_rows/0.5重み、障壁score/barrier_gini、unique枠・日・場、methods/families、pnl0/5/10のDecimal合計/平均、regression_value、impurity、recovery_mse_decimal等を持つ。

固定nodeを含む全所属と統計は同じ使用方向行から再計数する。元sklearn子の全node所属・件数・重み・回帰値・impurityと、合成JSON全方向の葉ID/予測値を照合する。生回帰mean/MSEとDecimalの照合だけは旧数値許容を用い、score・支持・正額・予測閾値はepsilonなし。

training.partitionはD0_K0/D0_K1/D1_K0/D1_K1。

```text
d / k / route / policy
excluded_feature_indices / child_feature_indices
direction_rows / pair_unique / days / sessions / row_ids_sha256
fit_performed / root / node_count / fit_parameters
```

routeはD0でR、D1でT。pair_uniqueはその枝に含まれるunique枠であり、両方向が同じ枝で揃ったpair数ではない。空群は未知leafを置き、data_absent=True、score/regression_value/impurityはNone、方向行0とする。空側の固定内部nodeも削らない。

structure.kindはfixed_direction_confirmation。fixed_nodesは上表、child_depth=2、child_features=44、feature_count=46、max_depth=4、fixed_mse_optimized=False、child_estimator=DecisionTreeRegressor、target=pnl5。child_feature_indicesは `{'D0':低側44indices,'D1':高側44indices}`、excluded_feature_indicesは `{'D0':[0,26],'D1':[0,20]}`。各partitionにもその枝の投影を保存する。

## 方向順位・資格・連続保護

walk/predictはpolicyだけを局所的にA0へ射影し、旧61の汎用JSON走査・予測純関数を呼ぶ。旧globalや元modelの辞書を書き換えない。

両方向で同じ木を使用し、障壁scoreがstrict高い側だけにscore>=1/3、unique枠>=60・6日・10場、複数family条件を課す。同点又は片側でも未知leafなら両方向WAIT。最高側が不適格なら、低い側のscoreや回収がよくても救済しない。

**固定根のtrendと対応kのpriceが全ての有効pathへ入るため、従来の複数技法条件は構造的に満たされる。** 条件を取り除いたのではなく、同じ資格関数を使う。二つの指標を独立な証拠や利益原因として数えない。

K1の過去回収支持/strict正額は同じ最高側へ後段で追加する。固定O49の一建玉、予定枠分母、保有非待ち、正常BBO、+1秒約定、損失連続追尾、現在純益strict起動・最低名目新規床、費用、強制返済は本コードの外で変えない。
