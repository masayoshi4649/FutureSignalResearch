# 短秒の進行と現在量で保有の失効を判断する仕様（未採用）

2026-11-08。既使用54場のX5査定を見て立てた探索案。市場入力・損益を見る前にこの別仕様を固定する。旧X5・100は変更しない。機会損失は対象外とする。

| 政策 | 必要条件 |
| --- | --- |
| S5Q | 正常で15秒以内のCurrent、保有方向付き5秒窓速度がstrict負、現在量がstrict負 |
| S515Q | S5Qに加えて、保有方向付き15秒窓速度もstrict負 |

方向sは実保有の買い+1・売り−1。等号0は既知不成立、未知は0へ置換しない。既知の否定を優先する三値ANDを用いる。5/15秒窓は気配中央の元pt/秒であり、両端・実経過・遅れを保存する。元Knownがtrueなのに単位/両端の整合が崩れていれば入力破損として拒否する。未知窓は正当な未知として扱う。

両窓のKnown=trueには、Short.Time=Current.Time、Short.Mid=Bid+(Ask-Bid)/2、Elapsed>=公称秒、Elapsed=Time-Endpoint、Endpoint<=Time-公称秒、Delay=Elapsed-公称秒、0<=Delay<=15、Speed=Move/Elapsed（相対許容1e-12）が必要。未使用の15秒窓もKnown=trueの破損は拒否するが、正常なKnown=falseはS5Qの必要条件にしない。

量は旧X5公開APIの同Current出典を再用する。Dayはsideに対応するOFIKnown/OwnAtとOFI30、NightはAvailable/E08/QuantityKnown/同Time/FeaturesIndexの四量差。保有方向付きQを用い、約定出来高・CVDとは称さない。

確定3/15分の反対化は追加退出の条件にしない。新規E3Sの背景・勢い・現在量と、共通P0のATR追尾は金融側で維持する。純式では全公開Inputの有限性・未来・出典を旧X5で検査し、現在量と出典だけを再用する。旧X5の判断/P/Mの採否をS政策へ流用しない。金融のQuoteOK・最新原行・場/限月・実保有方向・利益起動・freeは外部の別責務であり、架空EntryCandidateやAvailable数量を作らない。

金融接続の案は、旧OnNativeStepの処理完了後（旧P0保護とSource通知処理後）に、当原行contextで既利益起動・未予約残だけを判定する形。同じ原行へ即約定せずstrict後続正常原行、D1は追加1価格秒を維持する。5分新規・開始30分quiet・片側10枚・旧Source返済・連続P0起動/最低建値/2ATR・費用条件は変更しない。追加退出の予約を新規余力へ即時解放しない。

この純式だけでは保護・約定・改善を証明しない。人工→共有sidecarの旧入力一致→金融/独立検査→別の市場前固定計画の順で進める。同54場の結果は探索であり、未知期間の安定性確認にはならない。
