## 保持機械と計算対象

K、b、登録前10本、T/R段階、公開順、取消、置換、60分TTL、欠測reset、last_expiredは旧58だけが定義する。新59はこれらを選び直さない。Tは元突破方向と実sideが同じ、Rは逆である。ここでのT/Rは価格経路の種類で、上位DIとの同向/逆向による運用roleとは別である。

旧58で照合済みの最新完全3分足をjとし、現episodeのbを含む番号b.index..j.indexの全終値を対象にする。元SOURCE銀行から当時可視な足だけを読み、次をassertする。

- bの番号・公開keyが旧pathと一致する。
- 最新SOURCE全文が旧jと一致する。
- 対象番号が全件揃い、全足が公開・完全幅・欠枠なし・有効OHLCである。
- 全隣接足が同じ場・連番・終了/開始隣接・strict公開key順である。

不整合時は例外とし、短い別spanや有利な底へ起点を取り直さない。未来足の除外とprefix指紋の保証は旧58のvisible_sources/historyをそのまま再利用する。新しい原板やBBOを読まない。

## 四つの式

実sideをs、b終値をC_b、i足終値をC_i、現在判断ATRをA、現在判断DをDとする。

```text
u_i = s × (C_i-C_b)              i=b..j
n = j.index-b.index

1. b基準最大逆行 = -min(0,min_i u_i) / A
2. 既知ピークからの戻り = (max(0,max_i u_i)-u_j) / A
3. 一足当たり平均純進行 = u_j/(A*n)  if n>0, else 0
4. 保持端からの終値位置 = s×(C_j-K) / D
```

元のint/floatをFractionへ変換して途中計算し、保存値だけをfloatにする。epsilon、clip、追加の丸め、欠測の0補完を用いない。表示範囲を超えた非有限値は例外とする。

b自身を含めるのでu_b=0が既知であり、u_min<=0、u_max>=0となる。min/maxの同値を再訪した場合、出典には最初の公開足を採用する。未来に確定する峰や底は使わない。

第三値は一つの完全3分足当たりの平均**純進行**であり、瞬間速度や総移動距離ではない。公開秒差が0でも別足・後行keyならnで区別でき、秒割りの不定値を生じない。n=0なら現在足はbそのものなので純進行0は既知の値である。

第四値は現在の**終値**と固定Kの位置関係である。判断気配E*、注文価格、未来の実約定を使わない。Dは旧判断ATRから5〜125へ制限された追尾距離なので、ATRと同じ分母とは限らない。Kも必ずしも実際の取消線・保護線ではない。従って実取得位置、損失余地、実約定MAEとは呼ばない。

## 未形成・取消・期限・置換

|状態|値の扱い|
|---|---|
|旧ready=False|両方向vectors空、geometryの各T/RはNone|
|readyだがIDなし|四値0。n/u系/b/KはNone、observations0。現在jだけは診断へ残す|
|b成立・k未形成|b..jの四値を通常計算。k成立を準備条件にしない|
|取消済み|旧IDが残るTTL/置換/resetまで既知終値統計を更新。有効旗を復活させない|
|新bへ置換|新C_b/K/spanで計算し、旧episodeの極値を引き継がない|
|期限又はresetでclear|旧58が現IDを消すため、追加四値も未IDの0へ戻る|

深さ0は「b未発生」の場合と「b以後の終値が一度も逆行しなかった」場合がある。旧stage/episode_valid/k_validとgeometry.episode_id/nで区別する。未IDの4zeroは既知の適用外表現であり、特徴未知の代用ではない。

取消後に四値が改善しても、元episodeの有効性が戻ったことにはならない。価格構造の有効旗と履歴の記述を分けたまま学習へ渡す。

## geometryの小型schema

geometry['1'/'-1']['T'/'R']はNone又は次の辞書である。pathsへ同じ値を追加転記しない。

```text
episode_id: str | None
b: {index,key} | None
current: {index,key}
n: int>=0 | None
observations: int>=0
b_close: 数値 | None
current_close: 数値
level: 数値 | None
u_current / u_min / u_max: float | None
u_min_source / u_max_source: {index,key} | None
values: [最大逆行, 戻り, 一足当たり平均純進行, 終値位置]
```

IDなしではb/level/n/u系/極値出典がNone、observations=0、values=[0,0,0,0]。currentとcurrent_closeは旧58の最新jを保持する。IDありではobservations=n+1であり、全spanのSOURCEや終値listを再転記しない。出典は旧historyの可視prefix指紋と元SOURCE参照へ結び付ける。

## 旧特徴との重複と限界

旧F07は現在一足の変化で、第三値はbからの平均である。一足の変化が0でも、bからの純進行は非0になり得る。ただし第三値は端点差を足数で割った量であり、内部のジグザグや加速度を完全には表さない。

旧k後progress/戻りと新四値は起点が違う。新列はk前の逆行・ピークも含み、k未形成でも存在する。一方、最大終値進行が全てk以後に生じた場合、新しい戻りと旧k後戻りが同じになる場合もある。追加しただけで独立情報・独立した三票を得たとはしない。

高安ではなく公開終値列なので、足中に発生した最大逆行・最大利益を測定していない。また、後続足の形成開始がb公開後だったことまで保証せず、旧58の公開endpoint順の記述を守る。実約定からのMFE/MAE、250/125先着、追尾回収と別の量である。

同じepisodeを複数定時で観測する点も旧58と同じ。反復枠数を独立機会数へ読み替えず、episode支持は主処理の別診断へ残す。教師pair、学習重み、固定分岐、支持gate、最高側採否、DI0WAIT、O49の費用・利益床・損失追尾を変更しない。
