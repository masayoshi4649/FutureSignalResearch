# 独立一枠の追尾回収計測

作成・人工確認：2026-11-06。本担当は人工入力だけを使用する。実市場の測定はrootが固定後に一回行う。旧コード・固定出典・結果を変更せず、[固定O49](../定時帯反応/運用.py)の運用機械をそのまま呼ぶ。原板・共有キャッシュ・教師・fitを本計測コードから読み込まない。

## 測っているもの

一つの定時slotがflat状態から単独で新規・連続追尾した場合の約定と回収である。同じ場の別slotや反対方向が同時に存在しない世界を、それぞれ独立に測る。**独立測定の全損益を足しても、同時実行可能な一建玉戦略の損益にはならない。** 実際の候補運用は、保有・pendingによる後続抑止を別に評価する必要がある。

元の125/250先着教師と、このO49独立回収は別の量。固定250利確を追加せず、当時のATRから決まったDと現在益起動・最低名目entry床を維持する。後から実entry・将来MFE・先着結果をslotの判断条件へ渡さない。

## API

```python
bank = MeasurementBank(events, session, bounds=None)
result = bank.measure(pure_slot, candidate_id="独立測定", background_direction=None)

# 単発用。多数枠の場合は上のbankを場ごとに一つ再利用する。
result = measure(events, pure_slot, session, candidate_id="独立測定",
                 bounds=None, background_direction=None)

# 同じcandidate_idを使った全期間O49 singletonとの比較用。
expected = O49.replay(events, [pure_slot], session, candidate_id, bounds)
assert comparison_view(result) == comparison_view(expected)
```

`background_direction`は説明用のkeywordで、運用規則を変えない。0なら測定用roleは順行とし、measurementに「DI同値・測定用順行仮置」と明記する。pure slotのroleだけからDI同値を推測しない。後段候補のDI0WAITはrootが従来どおり保持する。

### 入力

- `events:list[dict]`はC49.events_forの返り値に相当する場内6列`now,line,last,bid,ask,valid`だけ。時計は有限非後退、原行lineは正の整数・strict昇順、`start<=now<end`。不正時計・後退時計・場外は事前処理側で除外し、計測部はこの契約違反を拒否する。
- validは元のBBO/数量正常flagで、時計の可否ではない。正常BBOは固定O49の`valid is True`かつ有限正`bid<ask`。見た目の価格が正常でもvalid=Falseをfill/保護へ使わない。
- 純slotはO49.SLOT_FIELDSの`scheduled,time,line,side,role,atr,D,reason,ready,slot_id`。将来ラベル・特徴辞書等の余分なキーを拒否する。DI同値測定以外の役割も引数どおりである。
- 実lineのslotは予定以後最初の有限非後退価格原行へ対応し、0〜30秒の時計と原行が一致することを要求する。その行がinvalidでも後の正常行へ待ち直さない。欠測placeholderは`time=scheduled,line=None,ready=False`で、固定O49の独立timerを使う。
- Dは実新規時に固定する有限5〜125。現在の根本値はrootが定時最新3分ATRから作り、計測側は再計算しない。boundsは人工用の任意引数で、正式では場名から固定O49の開始・強制・終了を使う。

元events/slotは変更しない。銀行は6値の不変tupleとして入力を保持し、元dictが後から変更されても、構築時の測定材料を変えない。非正常BBOの価格欠測は許容するが、受ける値は不変な数値・文字列・Noneに限定する。正常な約定価格へ欠測補完は行わない。

## prefixを一回だけ作る

銀行構築時に一度だけ全イベントを走査し、各原行のstrict前について以下を索引化する。

|状態|保持方法・意味|
|---|---|
|last_time / last_line|その前までの最終場内価格イベント。非正常BBO行も含む|
|raw_line|最後に処理した原行。切出最初の行でstrict昇順判定を維持|
|last_quote_time|その前までの最終正常BBO。非正常価格行で上書きしない|
|非正常BBO行数 / 空き時間長気配間隔数|slot以前は単独運用がflatなので、正常気配間隔>300秒はflat診断に数える|

前正常行の位置・累積カウンタには小型の配列を使い、全行ごとに状態辞書や全tick追尾を作らない。各測定は二分探索で判断原行又は欠測予定時計の開始位置を求める。prefix全体を測定ごとに再走査しない。

実slot以前の原行は全て予定よりstrict前、placeholder以前も予定より前である。slotのscheduledはforceより前なので、このprefixには他の注文・建玉・発注counter・消費済みforce timerが無い。初期Engine([slot])のlast_time/last_line/raw_line/last_quote_timeとflat品質だけを正確にseedし、その他の初期状態はO49のまま使う。

銀行の全期間索引作成は入力検査も兼ねるが、あるslotのseedへ使うのはそのslotより前のprefix値だけ。将来の正常気配をlast_quote_timeへ入れず、未来価格を見て切出位置や打切を選ばない。

## 切出しと停止

判断原行から原行順にgeneratorを供給する。各yieldをO49が処理し終えた後で、初回closed、又は判断済みでposition/pendingが無くなったことを確認して打ち切る。後者は新規取消、invalid・side0等の無新規判断を含む。

未決着の建玉/返済pendingは途中で切らず、元の場内イベント末尾まで供給する。最後は常に**固定O49.run自身のdrain_timers(end, final=True)とfinalize**へ任せる。新規TTLがイベント間で切れる場合、forceで新規を取消す場合、EOF後にforce返済要求が残る場合も独自の埋合せをしない。

|境界|固定O49から維持するもの|
|---|---|
|新規|要求+1価格時計秒かつ後原行の最初の正常BBO、TTL30秒等号可。forceは同秒新規fillより先に取消す|
|連続保護|同じ新規fill行から返済側BBOで保護。現在粗益×10−122>0 strictでarm、最低名目entry床・非緩和。固定250TP無し|
|返済pending|保護用h/L/armは凍結、実MFE/MAEは正常気配で更新。返済も要求+1秒以降後行正常BBO|
|force|15:35/05:50の独立timerで要求し、その時点の最後既知原行を出典にする。force+1以後正常BBOで約定可能|
|終了|15:40/05:55はhalf-open。現在の入力契約はその時計以降の原行を含めない。最後値で架空返済しない|
|長gap|保有又は返済pendingをまたぐ正常気配間隔>300秒は損益品質注意。300秒等号、flat、新規pendingは別診断|

## 返り値と一致範囲

返り値はO49標準の`decisions,trades,fills,closed,trail,orders,quality,metrics,final_state,session,candidate_id,bounds`を保持し、`measurement`を追加する。closedは0又は1件。entry/exit時計・原行・価格、ATR/D、h/L/arm、実MFE/MAE、pnl0/5/10等は固定O49からそのまま返す。

手数料11円/片道、micro10円/pt、同じ実約定に追加片道0/5/10ptの費用を計上する。Viewerのfee_yen=61は参照5pt込み。滑りを価格へ加算せず二重計上しない。未解消なら新規片道費用を台帳へ残し、全体確定対象額はnull。単体の`quality['損益確定可能']`・未解消・0/5/10確定nullは全期間singletonと同じでなければならない。

`comparison_view`は次を深い複写で返す公開の比較項目である。

- closed/trades/orders/decisionsは全辞書・全属性を比較する。
- active_trailはposition/pendingのある行と、定時判断・返済約定・新規取消。flat後のforceだけのログを含めない。
- qualityは保有中長気配間隔数、判定不能枠数、損益注意理由、損益確定可能、未解消建玉/注文数、活動評価適格、全枠判定可能。
- metricsとfinal_stateは全体を比較する。metricsの活動分母はこの単独slotの**1枠**であり、全予定枠の待ち率資格に代用しない。

初回完結・取消の後を省くため、**その後のflat強制ログ、非正常行数、flat長gap、新規取消後の残存gap旗による新規待機gap等の件数は全期間singletonと違い得る**。これらを全期間品質の同値と称さない。O49標準形の全出力が全byte同じだとは主張しない。保有中の注意と損益確定可否は省略で変えてはならない。

measurementには独立一枠測定・全体売買ではないこと、活動分母1/活動評価に使用不可、入力/prefix/供給件数、切出開始key・走査最終key・打切理由、seed、説明用DI方向、固定O49SHAを残す。打切後に走査していない時計出典を後から埋めない。

## 人工と正式の責任分界

[計測の人工検査.py](計測の人工検査.py)では、同じcandidate_idの`O49.replay(events,[slot])`を期待値として全期間実行し、公開射影を比較する。買売反射、12.2pt等号/12.3pt、名目床、pending保護凍結と実MFE、valid=False、TTL等号と超過、force同秒優先と+1秒、未解消の−11/−61/−111円とnull、保有gap300/300超、prefix時計/正常気配/flat品質、取消後省略、placeholder/無新規、銀行の反復独立、DI0説明、入力汚染拒否を含む。

```powershell
C:/Python314/python.exe -X utf8 scripts/独立追尾回収/計測の人工検査.py
```

本物はrootが固定後に一回だけ測定する。正式では各場最初の特徴ready枠の両方向について全期間singletonとの標本比較を行う予定。既存D0の実新規と独立新規が同じslot/sideで対応する場合、entry/exit/arm/L/h/D/pnl等の一致も別に確認する。後者はIDや全体の建玉占有を同一にする意味ではなく、独立回収を全戦略収益と呼ぶ根拠にもならない。
