# 独立追尾回収

[試行55の検証計画](../../study/00055_先着候補へ独立追尾回収を加える/検証計画.md)を正本とする。固定54D0の3分類木を再fitせず、同じ18特徴・先着最高側・現在費用後正起動の固定49Oを使う。

- D0：同46場の固定54保存対照。再運用しない。
- C0：旧D0の採用側の葉に、過去の確定回収60unique枠・6日・10場以上を追加。
- R0：C0へ、葉内の主費用後平均がstrict正という条件を追加。十進合計の符号で判定する。

独立測定は全2442枠×両側の4884記録で、技法準備済みの枠だけを別々の一建玉として測る。未準備・未約定・品質注意・未解消を損益0へ補完しない。同時に持てない重複建玉を含むため、その純額合算を戦略利益とはしない。

回収集計は各旧木のtraining.row_idsと両方向回収確定pairの共通部分だけを使う。障壁終点・回収終点は評価開始よりstrict過去。初期20場は過去集計専用、後半20場が時系列検査、選択24/既使用後続2場で再fitしない。旧66場は全て既使用である。

## コードと実行

- [検証.py](検証.py)：入力と版を固定し、独立測定・過去集計・新92混合運用を一度実行する。
- [計測.py](計測.py)：O49の一枠単独取引を保存する。状態・保護・約定・品質と走査範囲を残す。
- [回収集計.py](回収集計.py)：旧分類木の全葉へ過去回収を結合する。空葉の平均はnull。
- [保存物確認.py](保存物確認.py)：保存物の結合・所属・予測・会計・保護を確認する。
- [レポート.py](レポート.py)：正式な小型結果・監査・3回収集計・旧3木だけを読んでREADMEと設定と結果を表示する。圧縮詳細・原板を開かず、特徴・計測・fit・運用を再実行しない。

市場実行前の人工検査は次の通り。rendererの人工schema検査は正式結果を開かず、正式MDも作成しない。

~~~powershell
work/venvs/technical-tree/Scripts/python.exe -X utf8 scripts/独立追尾回収/レポート.py --self-test
~~~

固定と本物計測はroot担当の一回だけで行い、開始済みを再起動しない。実行環境・版は試行の固定.jsonを参照する。旧D0の分類器を学習し直すコマンドは設けない。

~~~powershell
work/venvs/technical-tree/Scripts/python.exe -X utf8 scripts/独立追尾回収/検証.py --freeze
work/venvs/technical-tree/Scripts/python.exe -X utf8 scripts/独立追尾回収/検証.py --run
~~~

結果・保存監査・Viewer一覧の完成後だけ、以下で二つの正式MDを生成する。--checkは同じ保存物から作ったUTF-8バイト列と保存MDの一致、全18特徴・版5の55×9・内部リンクを確認し、書き込まない。

~~~powershell
C:/Python314/python.exe -X utf8 scripts/独立追尾回収/レポート.py
C:/Python314/python.exe -X utf8 scripts/独立追尾回収/レポート.py --check
~~~

先着250/125は実運用の黒字率と別、名目新規床は費用後同値の保証と別である。回収支持と正額条件を追加した成績も、指標単独の効果や将来利益の校正とはしない。[外部の問い](../../docs/議論/次の比較を価格経路と回収から設計する.md)へ接続する。
