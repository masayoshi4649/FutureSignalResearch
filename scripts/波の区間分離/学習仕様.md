# 46列の同教師回収分岐

[試行60の計画](../../study/00060_先行進行と再試験の区間分離/検証計画.md)を正本とする。旧59の38列を維持し、登録へ至る進行・効率・再試験前後の速度8列を加える。

prepare_rowsは38列へ射影して固定59の全pair・回収既知・未来境界を検査し、同じ使用IDだけを46列canonicalへ戻す。旧18/30指紋を維持し、旧38六指紋をbase38_fingerprintsへ保存する。回収目的・教師集合・採用支持を追加列で変えない。

S0はF18→F01の固定二段と、F18を除く45列の子深さ2。全深さ4・minleaf60・重み0.5・seed51・pnl5二乗誤差を保持する。S1は同じ木へ過去回収正額を追加。順位は障壁率の最高側で、回帰平均による方向変更や次点救済はしない。

全46列をfloat32へ写す。旧38は固定59の領域検査を再用し、新8列は有限性・float32範囲・効率−1..1を検査する。段階0なら新4値0、r未形成なら後2値0を要求する。rへの進行は正負を許し、正値を誤って欠測又は逆行へ補正しない。

四群別の形成・r有無・分布は診断でありgate/重みには使わない。未ID、未r、真のゼロ、r当足を区別する。区間長・純変位は小型診断へ保存するが、今回の新学習列は4式だけである。同じ形成の反復を独立標本とみなさず、学習内の差と後続実績を分ける。
