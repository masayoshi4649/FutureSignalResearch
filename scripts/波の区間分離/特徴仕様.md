# 登録へ至る波と、r前後の終値進行を分ける

作成日：2026-11-06。新60の事前仕様。固定59の全38列と価格機械を保持し、T/R各四列を加える。相場入力・教師・本物モデル・損益を読まず、固定コードと手作りSOURCEだけで作成した。

## APIと旧出力

```python
extract(slot: dict, frames3: list[dict]) -> dict
control_projection(feature: dict) -> dict
```

[固定59特徴](../価格経路の深さと速度/特徴.py)と[仕様](../価格経路の深さと速度/特徴仕様.md)を固有module名で読み取る。旧globalや固定ファイルは変更しない。F59.extractの返り値を深い複写で保持し、次だけを加える。

- control_vectors38：旧59のvectors全38列の深い複写。
- segments：実side別のT/Rそれぞれに、追加四値と小型出典を置く。
- vectors：旧38列＋T四列＋R四列の46列。

旧ready/reason/baseF53/control_vectors18/control_vectors30/geometry/paths/history/atr/D/background_directionは変更しない。control_projectionは旧59全keysだけを深く複写し、vectorsをcontrol_vectors38へ置き換える。新keysを旧対照へ混ぜず、旧59返り値全文との厳密一致を検査できる。

旧ready=Falseなら両vectorsとcontrol_vectors38は空list、segments['1'/'-1']['T'/'R']は全てNone。旧準備成立後に新たなready除外を加えない。入力矛盾や出典不足は例外とし、0補完や短い別区間への差し替えで救済しない。

## 方向と共通出典

実sideをs（買+1/売−1）、現在判断ATRをA、保持episodeの登録足をb、現在までの最新完全3分足をjとする。Tは元突破方向と実sideが同じ、Rは逆である。これは価格経路の名称で、上位DIとの関係から付ける運用roleと同一ではない。

K、b/f/r/k、登録前10本、取消、置換、60分TTL、欠測reset、公開keyと可視範囲は旧58/59の機械をそのまま使う。元SOURCE銀行からend<=scheduledかつ公開key<=(time,line)だけを選ぶ。新しい原板・BBO、未来の実新規価格、教師、損益を入力しない。

source_spanは指定された両端番号を全件要求し、公開・完全幅・有効OHLC・欠枠なしと、同場/連番/終了開始隣接/strict公開key順を確認する。終値の発生時点と公開された時点は区別し、足中高安の順序や、足の形成開始が前の公開より後だったことまでは推測しない。

## ① 登録へ至る10終値差分の平均

登録前10本の番号はb−10..b−1。その後にbを加えた**11終値、10差分**を用いる。path.reference_indicesがこの範囲に厳密一致し、reference_keysが元SOURCEと一致することも確認する。

```text
N = s × (C_b-C_(b-10))
V1 = N / (10A)
```

「b以前だけの平均」ではなく、bへ到達した最後の差分も含む。登録終値がいつ分かったかはbの公開keyであり、その前から突破を知っていたことにはしない。尺度は現在判断のATRで、登録時ATRへ固定しない。

## ② 同区間の符号付き効率

```text
W = Σ_(i=b-9..b) |C_i-C_(i-1)|
V2 = N/W    W>0
V2 = 0      W=0
```

netの絶対値でなく、**実sideを掛けた符号付きnet**を使う。分母は隣接差分絶対値の和で、終値の高安幅や高安の足中変動ではない。効率は−1..1で、ATRには依存しない。追加のepsilonやclipは使わない。

有効なbは登録前10本の高安Kを元方向へbuffer5突破する。その10本にC_(b−10)も含むため、正常なbではNはTで必ず正、Rで必ず負、Wも正となる。従って①②の符号を、新しい独立の方向確認とは呼ばない。W=0の分岐は定義として保持し、純算術の人工例で確認するが、有効bで実観測したケースと主張しない。

## ③ rへ至る区間の平均終値進行

旧経路にrが形成された時だけ計算する。Tではa=b、Rではa=fとし、Rのrにfを必須とする。a/rは別足でなければならない。

```text
p = [a,r−1]でs×Cが最大となる最初の足
V3 = s × (C_r-C_p) / (A × (r.index-p.index))
```

実side買いなら区間の最高終値、売りなら最低終値を選ぶ。高値/安値ではない。r自身をp候補へ含めない。同値では最初の公開足を選び、pをr形成時点の区間へ固定する。後の峰・底が現れてもpを更新しない。毎回再構成する実装でも、選ぶ範囲は常に同じ[a,r−1]である。

rはヒゲでKへ再接近していても終値がpを実方向へ越える場合があるので、V3は正値も許可する。「rへの進行」を機械的に負の押戻しへ変換しない。rがなければ0で、segments.masks.approach=Falseと旧段階で適用外を識別する。

## ④ rから現在までの平均純進行

```text
V4 = s × (C_j-C_r) / (A × (j.index-r.index))    j>r
V4 = 0                                       j=r又はrなし
```

r当足は値0が既知で、since_r_steps=0、masks.since_r=True。rなしはsteps/netがNone、mask=Falseなので、適用済みの0と区別する。以後は現在jまでのnetを足数で割る。瞬間速度、総移動距離、公開秒当たりの速度ではない。

## 未ID・取消・期限・置換

|状態|追加四値・診断|
|---|---|
|旧ready=False|vectors空、segmentsの各T/RはNone|
|readyで現IDなし|四値0、区間mask全False、registration_steps0、他の区間値/足数はNone。currentは保持|
|bあり・rなし|登録二値を計算。r前後二値は0、両maskFalse。Tのa=b、Rのaはfがあればその出典を保持|
|r形成済み|四値を計算。r前後maskTrue。取消済みでもmaskは計算適用を示すだけ|
|取消後|TTL/置換/resetまで記述を継続。旧episode_valid/k_validは復活させない|
|置換又はclear|旧機械に従って新bへ替えるか、現IDなしへ戻す。古い区間やlast_expiredから復活しない|

maskは取引の採用許可ではない。取消後でも計算対象があればTrueとなる。新しい採用gate・支持gate・重み・再参加制限は導入しない。

## segmentsの小型schema

segments['1'/'-1']['T'/'R']はNone又は次の辞書。出典参照は全て{index,key}で、全SOURCEや終値配列は重複保存しない。

```text
episode_id: str | None
b / a / p / r: {index,key} | None
current: {index,key}
registration_start: {index,key} | None
registration_steps: 10（IDあり）又は0（IDなし）
registration_net / registration_total_abs: float | None
approach_steps / since_r_steps: int | None
approach_net / since_r_net: float | None
masks: {registration: bool, approach: bool, since_r: bool}
values: [登録平均, 登録効率, rへの進行, r後の進行]
```

IDなしではb/a/p/r/registration_startと区間net/総変動/approach_steps/since_r_stepsはNone。currentは旧59で検証済みの最新jの出典を残す。aはTでb、Rで既知のfがあればf、なければNone。pはrができるまでNone。r当足のsince_r_steps=0は欠測ではない。

登録参照やb/a/r/currentが元SOURCEと矛盾すれば例外とする。旧paths/history/geometryの出典・指紋は変更せず、新segmentsの参照も同じ元銀行へ結び付ける。

## 解釈上の限界

旧59のb..j平均は全区間のnetであり、新③はrへ向かうp..r、新④はr..jである。旧F07一足変化・k後進行とは異なる区間だが、端点や足数が一致すれば同値化する。①②も同じnetを共有するため、独立した技法票として数えない。

今回のpはr形成時までに知れる区間内終値の極値であり、後に確定する先行波全体の始点・終点ではない。新①はbへの10差分で、その区間が裁量上の「先行波」と一致する保証もない。先行波全体や調整内部の全速度を完全に表したとはしない。

いずれも終値列の幾何であり、実約定からのMAE/MFE、250/125先着、費用後損益ではない。現在ATRでの正規化は過去のその時点に同じATRが分かっていたという意味ではなく、現在の説明尺度である。同じepisodeの反復観測を独立機会数へ数え替えず、旧支持と別に記録する。
