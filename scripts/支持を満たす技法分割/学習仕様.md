## 候補列挙と厳密な改善

各子nodeについて、候補列をglobal feature index昇順に処理する。各列のfloat32値を昇順に並べ、隣接する**異なる値**の中点をfloat64閾値とする。完全同値の値を行番号で分割しない。左は `x<=threshold`、右は `x>threshold`。同じ列の閾値は昇順となる。

全行minleaf60を満たす境界を数え、S0だけはさらに両子のfilled unique枠・日・場を調べる。unique枠は `(session,slot_id)` で数える。同じ枠の複数方向行を別枠にせず、日・場も集合で数える。C0も診断用に支持適格数を保存するが、候補除外には使わない。親のunique数から分割可能性を先に近似せず、各境界の左右集合で判定する。

金額は `Decimal` の符号・係数・指数から共通の10進整数単位へ丸めず変換する。使用行のpnl5を `y_i=t_i/q` とし、所属全行n、左行l、右行r、全整数和T、左整数和Lとすると、親MSEから行数加重子MSEを引いた改善は次の厳密値になる。

~~~text
gain = (n*L - l*T)^2 / (n^2*l*r*q^2)
~~~

重み0.5は全行一定なので、このMSE比較から相殺される。候補間は整数分子分母の交差積で比較し、最後に既約Fractionを保存する。Decimalの既定精度、floatの微小許容、sklearnのMSE丸め、評価score・回収正負を選択へ使わない。gainがstrict正の候補だけ採用する。同改善なら先に処理した特徴index・閾値を保持する。全候補が0改善なら分割しない。

全nodeの回収統計は旧69系のDecimal合計・最後80桁除算を再用する。`regression_value`と`impurity`はそのmean/MSEのfloat表示であり、今回はsklearnの生値ではない。先着score、回収符号、支持、採否は既定どおりstrictに扱う。

## 探索記録schema

固定三nodeは `split_search=None`。それ以外の学習node・停止葉は次のdictを持つ。

~~~text
split_search = {
  candidate_count, row_eligible_count, support_eligible_count, selectable_count,
  support_required, stop_reason, selected
}
selected = None または {
  feature, feature_id, threshold,
  gain: {numerator: 整数文字列, denominator: 正整数文字列},
  left: {direction_rows, unique_slots, days, sessions, supported},
  right: 同じ項目
}
~~~

- candidate_count：全59列の全異値境界。別の特徴が同じ所属を作っても別候補。
- row_eligible_count：左右の全方向行が各60以上の境界数。
- support_eligible_count：全行条件に加え、両子の約定60枠6日10場を満たす境界数。
- selectable_count：C0ではrow_eligible_count、S0ではsupport_eligible_count。0改善もこの件数には含む。
- selected：その集合中の最良strict正改善の候補だけ。候補全件は転記しない。

早期停止の優先順は「空」→「最大深さ」（子深さ2）→「全行例数不足」（n<120）→「目的純粋」（全pnl5整数同値）。この場合、全候補件数は0でselected=None。列挙後の停止順は「全行適格候補なし」→S0だけ「支持適格候補なし」→「正改善なし」。採用時は「分割採用」。これらは後から損益を見た説明ではなく、実行した探索手順の記録である。

topのparameters/subtree_parametersは旧容量のパラメータへalgorithm/support_required/threshold_rule/tie_rule/gain_ruleを追加した保存用dictであり、sklearnへ渡さない。random_stateはNoneへ上書きし、legacy_random_state=51とrandomness_used=Falseを別項目に残す。RULESの同名三項目も同じ値にし、子学習器は独自列挙名とする。criterion・depth・全行minleaf等は独自列挙の実制約と対応する。structureは旧kind・固定3node・59投影・全61を保ち、child_estimatorに独自列挙名を記す。versionsはPython、学習器、整数/既約有理数、sklearn.fit0。共有コード指紋は71の共有出典列に71学習を足した順で保存する。
