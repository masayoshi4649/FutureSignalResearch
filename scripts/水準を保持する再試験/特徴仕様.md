# 登録水準を保持する再試験と再開後の終値進行

作成日：2026-11-06。新58の事前仕様。市場入力、本物教師、本物モデル、損益は読まず、固定53/57のコードと人工SOURCEだけで作成した。60分TTL、buffer5、最初の段階だけを使う順序は研究側の独自規約である。[水準の発見窓と反応寿命の資料整理](../../docs/議論/外部再調査/水準を発見する窓と反応を追う寿命.md)は着想と限界の参考であり、原著の売買規則や収益を再現したものではない。

## APIと旧準備

```python
extract(slot: dict, frames3: list[dict]) -> dict
```

[固定53特徴](../局所帯分岐/特徴.py)を固有module名で読み、旧global・旧ファイルを変更しない。返り値はready/reason/base/control_vectors/vectors/atr/D/background_direction/paths/history。baseは固定53の返り値全文、control_vectorsは旧18列vectorsの深い複写で、vectorsはその18列＋保持経路12列の30列である。

旧53が未準備なら、control_vectors/vectorsとも両方向空list、pathsのT/RはNone、historyはNone。旧準備が成立した場合、episodeの未登録・未完成・取消・期限切れを理由に追加のready除外をしない。これらは既知の価格状態であり、特徴欠測ではない。旧53の準備は直近15完全足等を含むため、保持機械の直前10本の最低準備も満たす。

毎回当時可視の価格prefixを最初から再構成する。以前の定時がready=Falseだったことや、呼出しの有無、保有状態は機械を止める条件にしない。未準備時にpathsを返さなくても、後の準備済み判断では、そこで初めて見つかった過去bを含めて同じ公開履歴から復元する。

旧F16/F17/F18は旧53が各定時に作る局所帯の幅・中央距離・反応旗のまま保持する。新episodeのKはb時点に固定する別の水準であり、旧F18を新Kの反応旗と読み替えない。上位DI、Fast、旧ATR/D、教師、O49出口、支持gate、重みを変更しない。

## 当時可視なSOURCEとリセット

SOURCE13はsessionと固定49のSOURCE12列。公開keyは(confirm,confirm_line)で、publishはboolであり時刻ではない。

1. 当場の足について、有限なendがscheduledより後なら、confirmや価格の検査より先に除外する。
2. end<=scheduledの足は有限confirm・非負整数confirm_lineを要求し、key<=(slot.time,slot.line)だけを選ぶ。同秒後行も未来として除外する。
3. 可視足の番号重複、公開key同値・後退は入力不正として拒否する。入力を並べ替えて救済しない。
4. 可視足のNP、欠枠、不完全幅、不正OHLC等は局所状態をclearする。番号・終了時刻の不連続もclearし、その現足が正常なら再準備の1本目にする。

リセットは当時知り得る範囲だけに適用する。未来のNP/欠枠/不正価格を配列へ追加しても、現在のvectors、paths、historyの指紋は変わらない。未来足か判定できない場/endの欠落や、既に終了した足の不正な公開時計は入力例外であり、未知を正常と仮定しない。

局所resetでは四機械の現episode、段階、固定K、k統計と直前10本の履歴を消す。以後10本は参照用の蓄積で、11本目からb登録が可能。H=L自体は旧有効OHLCに従い、不正とはしない。

**不良又はgapの観測足はTTLよりresetを優先する。** 同時に期限へ到達していても、新しいlast_expiredは作らず品質resetとして記録する。既に作られていたlast_expiredは診断履歴として保持する。連続有効足の処理順は後述のTTL→取消→段階→取消済み新bである。この優先は数値stage0が同じ場合にも、理由の違いを明示するための規約である。

足の形成開始が先行足の公開より後だったとまでは主張しない。使うのは別足、完全隣接、公開endpointの順序であり、足内の高安順を推測しない。

## 登録時のKと四つの独立機械

元突破方向d=+1/−1と価格経路T/Rを組み合わせ、四機械を独立に再構成する。Tの実sideはd、Rの実sideは−d。paths[実side]にはTを元d=実sideから、Rを元d=−実sideから置く。価格経路T/Rは、主処理が上位DIとの関係で付ける運用の順行/反転roleとは別である。

未登録又は以前の足で取消済みの場合に、当足を除く直前10完全隣接3分足から新Kを作る。

```text
d=+1: K = 直前10足の最高値
d=-1: K = 直前10足の最安値
q(price) = d × (price-K)
q_min = min(q(H),q(L)), q_max = max(q(H),q(L))
b = q(前C)<5 かつ q(現C)>=5
```

前終値と現終値は**同じ新K**で比較する。前Cは参照10本の高安内なので、q(前C)<=0、従って前条件q(前C)<5は自動成立する。前足時点に計算した別Kとのcrossではない。b足の高安をKへ混ぜない。価格は元のint/floatをFraction化して比較し、epsilonや追加の丸めを使わない。

bの受理時にKと参照10本の番号/keyを固定する。有効中は、新しい高安や別crossが現れても置換しない。T/Rは取消・置換・期限を別々に持つため、元方向が同じでもb/K/IDが異なる場合がある。

episode_idの書式は次の通りで、同じbを複数定時で同じIDとして識別する。

```text
session|T又はR|元方向を符号付き整数表示|b.index|float(b.confirm).hex()|b.confirm_line
```

## 段階と取消・置換

各有効足は、最初に期限、次に有効episodeの取消、その後に次の一段だけを処理する。

|経路|段階|条件|
|---|---|---|
|共通|b|同じ新Kで前q_close<5、現q_close>=5|
|T|r|b後の別足でq_min<=0かつq_close>=5。最初のrを固定|
|T|k|r後の別足でq_close>q_max(r)。追加bufferなし|
|R|f|b後の別足でq_close<=−5。最初のfを固定|
|R|r|f後の別足でq_max>=0かつq_close<=−5。最初のrを固定|
|R|k|r後の別足でq_close<q_min(r)。追加bufferなし|

b/f/r/kは全て別足。同じ足を二つの段階へ使わない。後の有利なrへ替えない。kの高安到達だけでは成立せず、終値strict突破を要求する。

|取消|条件|
|---|---|
|Tのb後|q_close<=−5|
|Rのf前|外側残留だけでは取消しない|
|Rのf後|q_close>=5|
|k後の共通否定|実side×(C−line)<=0。等号も取消|

lineはkが突破したr端で、実side買いならr高値、売りならr安値。k自身の高安や終値へ線を替えない。帯取消とk否定が同時なら、帯取消を先に両理由を保存する。

最初の取消後は、最大stageを保持しepisode_valid/k_validをFalseにする。その取消足では新bを作らない。次足以降、新しく計算した直前10本のKでcrossがあれば、その機械だけを新bへ置換する。新crossがなければ取消履歴とk統計を期限まで保持する。置換で旧k統計は消え、旧episodeが再点火したことにはしない。

stageはTが0なし/1b/2r/3k、Rが0なし/1b/2f/3r/4k。取消だけでは最大stageを消さず、TTL又は局所resetで0へ戻す。

## 60分TTLと判断時だけの失効

```text
expiry = b.confirm + 3600
公開足処理の冒頭: row.confirm >= expiry なら失効
全可視足を処理した後: slot.time >= expiry なら失効
```

60分は15分の4間隔に相当する独自設計であり、「最大4定時観測」を保証する条件ではない。公開遅延と判断遅延があるため、観測枠数とは区別する。

最初の期限越え公開足ではclearだけを行い、その足をbへ使わない。その次の足から探索する。新bが受理されるまでは現episode_id/expiry/level等はNone、stage0、旗0、age−1、進行/戻り0となる。

公開足の到着がなくても、判断timeの等号で失効を反映する。この判断で架空の新足は作らない。次回も全prefixを再構成するため、先に定時で失効を観測したかに依らず、最初の期限越え足は同じく登録不可となる。

last_expiredは直近の失効ID/期限/理由を保持し、再登録や品質reset後も履歴として残せる。同じ失効が複数sampleへ残るため、非None件数は「失効観測」であり、独立した失効episode件数ではない。途中のresetがTTLより先なら、その時点で現episodeは消える。

## k後の終値統計と30列

旧57と同じ数式である。判断時の旧ATRをA、k終値をC_k、実sideをsとする。

```text
age = (slot.time-k.confirm)/900
x_i = s×(C_i-C_k)/A                 i=kを含む以後の既知終値
x = 最新の既知終値のx_i
h_close = max(0,max(x_i))
戻り = h_close-x
```

k形成後は、取消後も置換/期限/resetまで既知終値を記述する。有効性の復活ではない。内部では価格単位の現在進行・最大進行を保持し、各判断の同じATRで割る。k足の高安や未公開の足、当時気配、未来の実新規価格はこの統計へ使わない。k未形成はage−1、進行/戻り0。maskにより適用外と真の0を区別する。

これはk終値からの価格進行であり、費用後利益、実約定MFE、O49のhや保護線ではない。進行/最大進行/戻りは従属表現で、独立した技法票には数えない。

## 小型出典とpaths

paths['1'/'-1']['T'/'R']は次のschemaを持つ。

- role/side/break_direction、episode_id/expiry/level。
- stage/episode_valid/k_valid。
- b/f/r/kはNone又は{index,key}。lineはNone又は固定r端の価格。
- reference_indices/reference_keysはb登録時の10本。未登録は空list。
- cancelはNone又は{index,key,reasons}。現episodeの最初の取消だけ。
- traceは現episodeのb/f/r/k/取消という状態遷移だけ。各行は{index,key,action,stage,episode_valid,k_valid}で処理後の値。待機足やSOURCE全文は反復転記しない。
- age/progress/max_close_progress/pullback。
- last_expiredはNone又は{episode_id,expiry,reason,stage,b,k,observed_at}。observed_atは{kind:'公開足'又は'判断時刻',time,line,index}で、判断だけならindex=None。

期限clear後は現ID/level/段階出典/参照10本/traceが空になり、last_expiredだけが直近の期限記憶を残す。取消後の新b置換では現traceも新episodeだけになる。過去全episodeの台帳を各sampleへ複製しない。

historyは、source_prefix_sha256/source_prefix_count/source_fields/source_hash_encoding/first_source/last_source/reference_ready_count/reset_count/last_reset。元SOURCE銀行を別途保存参照する前提で、当時可視な13列射影だけを指紋化する。JSONはensure_ascii=False、sort_keys=True、separators=(',',':')、allow_nan=True。最後の指定は不正価格のNaN等もhash入力で識別するためで、返り値JSONへ非有限値を転記するためではない。正本全銀行の指紋とは区別し、未来足はこのprefix hashに含めない。

baseの旧出典は旧仕様のまま残す。新paths/historyには、それより古い登録10本やr/kも番号/keyで参照できるようにし、SOURCE全文を定時ごとに追加複製しない。

## 集計の責任と限界

主処理は全準備方向又は採用方向について、T/Rごとにepisode IDのunique数、同ID最大反復枠数、現IDなし件数、k形成・k有効のunique ID等を別に集計できる。葉ごとのunique枠60等は同じepisodeの反復を含み得るため、独立した価格機会60件とは呼ばない。追加のepisode支持gate、消費制限、重み変更は今回入れない。

保持により確認機会が増えるか、学習がその列を使うか、同時刻教師や連続追尾回収が改善するかは未検証。履歴の存在を直接の採用条件とせず、固定した比較へ特徴を渡す。旧57の固定5本窓とは新仕様の比較であり、旧固定出力や閾値を更新しない。
