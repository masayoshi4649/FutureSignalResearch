# 終値の内復帰と外回復による順行反転

[試行00024](../../study/00024_終値の内復帰と外回復による順行反転/README.md)の再現用コード。公開30分6本の固定高安、3分の最初の内復帰/外回復とMACD、15分ADX/DMI・BB幅を組み合わせる。計画・条件・固定SHAは試行側を正本とする。

## 実行手順

リポジトリルートでPython 3.14.3、NumPy 2.5.3を使う。入力台帳と `work/複合検証/キャッシュ/` を参照し、原板をコピーしない。

```powershell
C:/Python314/python.exe -X utf8 scripts/終値切替/検証.py --prepare
C:/Python314/python.exe -X utf8 scripts/終値切替/状態独立確認.py --prepare
```

準備モードはラベルと損益を計算しない。最終合成成功・編集終了、コード/計画/条件/入力の固定確認後だけ正式再生する。

```powershell
C:/Python314/python.exe -X utf8 scripts/終値切替/検証.py
C:/Python314/python.exe -X utf8 scripts/終値切替/状態独立確認.py --実行許可
C:/Python314/python.exe -X utf8 scripts/終値切替/追尾独立確認.py --実行許可
C:/Python314/python.exe -X utf8 scripts/終値切替/独立監査.py --api-base http://127.0.0.1:8092
C:/Python314/python.exe -X utf8 scripts/終値切替/対応診断.py
```

正式再生は完了済み結果の上書きを拒否する。別条件は新試行で固定する。独立監査・対応診断は保存した売買の検算であり、売買条件を再選択しない。Viewerは共通の原板ルートと本リポジトリを資料ルートにした既存設定を使う。

## ファイルと責務

| ファイル | 用途 |
| --- | --- |
| [指標.py](指標.py) | 固定23の価格指標と公開30分窓を読み取り再利用する |
| [入口.py](入口.py) | 登録、内復帰、外回復、消費とE0/E1の採否を管理する |
| [運用.py](運用.py) | 固定23経由で125/250ptとA5必須追尾の運用を再利用する |
| [検証.py](検証.py) | 指紋、固定、先着、二案の一建玉再生、圧縮明細とViewer資源を保存する |
| [合成検証.py](合成検証.py) | 人工足で時間、等号、寿命、鏡像、初回消費、数値準備と量不関与を検証する |
| [状態独立確認.py](状態独立確認.py) | 原価格と別の区間走査から全価格監視・二案採否・上位状態を再構成する |
| [追尾独立確認.py](追尾独立確認.py) | 全実保有区間で最初の要求、起動、設定線、待機中停止を検算する |
| [独立監査.py](独立監査.py) | 先着/対象外、Decimal会計、単一建玉、帰属、CSVとViewerを検算する |
| [対応診断.py](対応診断.py) | 上位選別で失う勝ち/避ける負け、役割構成、実参加と共通出口差を分ける |
| [レポート.py](レポート.py) | 保存した条件・結果・証明から二文書と51手法×9尺度表を再表示する |

価格状態は指標や建玉と独立に進み、失格でも最初のf/gを消費する。数量は診断だけ。原E1がE0の部分集合であっても、先行保有の抑止が変わるため、実参加のE1はE0の部分集合とは限らない。
