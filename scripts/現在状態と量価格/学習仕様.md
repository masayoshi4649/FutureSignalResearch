作成日：2026-11-06。65の純学習仕様。実装・人工では固定コードと手作り教師だけを使い、本物入力・保存実モデル・本物fitは扱わない。本物実行はrootだけが行う。

## 保持と変更

[旧64学習](../量と価格進行/学習.py)をLEGACYとして、旧64Q0の全60特徴・同じ教師pair・順序・回収pnl5目的・最大深さ4・支持・費用・方向順位を保持する。追加の量、状態、教師、除外条件は作らない。

旧64はDIだけを固定根にし、子59列・深さ3だった。65は**DIの非正側でR、正側でTの現在episode有効**を第二段に固定し、枝ごとの子58列・深さ2へ容量を配る。kが未形成・取消・未登録の群も残し、kを全件に要求しない。

現在episode有効は出生bから真である。特にR有効を失敗f／再試験r／確認kの成立と呼ばない。V0は未登録、取消、TTL後等を含み、V1も出生・途中・確認済みを含む。既存のstage、f/r/k、有効k、古さ、進行、量価格6列は、除外する対応有効旗以外を子へ残す。

固定price段の追加で従来技法gateが構造的に充足し、子の深さ・候補列・所属も変わる。固定順・58列投影・容量配分・技法資格を含む構造比較であり、flagだけ、量だけの単独効果ではない。登録bの量と判断時の現在状態を分け、参加者や注文意図を総量から同定しない。

## APIと完全再用

```python
fit(rows, feature_meta, policy, model_id, evaluation_start) -> dict
prepare_rows(rows, evaluation_start, feature_count=60) -> (used, training)
float32(values, feature_count=60) -> list[float]
walk(model, values) -> (leaf, path)
predict(model, vectors) -> dict
```

学習モデルpolicyはU0のみ、予定保存IDはU0_W20／U0_W30／U0_F40。U1は同じU0木へ従来の回収支持と過去主回収strict正額を後段で要求する候補で、別fitをしない。feature_countは60以外を拒否する。metadataは旧64の `feature_metadata(meta,'Q0')` で検査し深く複写する。旧globalや引数の辞書へ代入しない。

float32は旧64へ60を明示して直接再用する。旧54の領域、ADX/BB値とmask、量価格6列の非負RVOL・有限進行・二値共同maskを保持する。mask0なら対応する量と進行は両方0。既知の数量0と未知0をmaskで分け、b未知・r既知も新たに禁止しない。

prepare_rowsは旧64へ60を明示して直接再用する。障壁／回収の既知、同slot両方向の整合、strict過去終了境界、未知pair丸ごと除外を**四群分割より先に**行う。片側の未知や未約定・不足を片側だけ救済せず、提供済み未来の終了時計を除外で隠さない。枝へ分けた後には両方向が揃うことを要求しない。両方向は各sample_weight=0.5であり、同pairが別DI枝へ入ってよい。

旧64と同じ全60canonical・順序から、次の六指紋を `base60_fingerprints` へ保存する。

```text
input_rows_sha256 / used_rows_sha256 / row_ids_sha256
target_rows_sha256 / period_sha256 / used_barrier_rows_sha256
```

trainingの同名六項目も旧64と同値で、base18／30／38／46／54_fingerprints、使用row_ids・除外分類／ID・最大終了時計等も継承する。feature_missing_handlingは `旧64全60特徴・同じ教師pair。追加情報・追加除外なし`。量の未知で旧ready・教師を追加除外しない。

## 固定三nodeと四群

|node|feature・閾値|左（<=）|右（>）|
|---|---|---|---|
|0|F01、index0、0.0|D0、node1|D1、node2|
|1|R episode有効F26、index25、0.5|D0_V0|D0_V1|
|2|T episode有効F20、index19、0.5|D1_V0|D1_V1|

固定三nodeはデータが空でも全て残し、四つの子群も空なら未知leafを置く。旗値そのものは0／1を検査するため、0.5を入力値として許可しない。固定段はMSE最適分割として選んだものではない。

学習・予測ともF01をfloat32化した値で比較する。微小正が0へ丸まればD0となる。これはraw DIの厳密な符号や実運用roleと必ず一致するわけではない。厳密DI同値の最終WAITは従来どおり主処理の責務で、本学習器はepsilonや新しい役割変更を加えない。同じ木を両方向へ適用し、方向交換で同じ規則を使う。

|方向枝|対応旗|子から除くglobal index|子候補|
|---|---|---|---|
|D0|R現在有効|0,25|元60列から2列だけを除く58列|
|D1|T現在有効|0,19|元60列から2列だけを除く58列|

子列の順は元global indexの昇順。反対側の現在有効旗、両k旗、量価格6列等は残る。DIの強さを子で再分岐することはできない。子のlocal indexは合成時に元60列のglobal indexへ戻す。

DecisionTreeRegressorはcriterion=squared_error、splitter=best、子max_depth=2、min_samples_leaf=60、random_state=51、max_features=None、ccp_alpha=0等を保持する。固定二段込みの全体上限は4。3phaseの保存合成モデルは3本、非空子の回帰器fitだけを数えるため最大12fit、分類器fitは0。

## 保存JSON

全nodeは従来互換のid／left／right／feature／feature_id／threshold／path、所属方向行・0.5重み、unique枠／日／場、methods／families、障壁score／barrier_gini、回収pnl0／5／10のDecimal合計・平均、regression_value／impurity／recovery_mse_decimal等を保持する。

固定nodeを含む全nodeの所属・障壁・回収統計を、同じ使用方向行から再計数する。scoreは250先着率で、回帰平均やMSEではない。回収合計は方向行の単純和、平均とMSEは同じ0.5重みなので等重みの平均になる。合計を同時実行可能な戦略損益へ読み替えない。

元sklearn子の全node所属・件数・重み・生回帰値・MSEと、合成JSON全方向の到達葉／予測値を照合する。Decimal平均・MSEとの生float照合だけは旧数値許容を用い、障壁score・支持・正額・分岐閾値にepsilonを加えない。固定nodeのimpurityは同じ所属行のMSEであり、その固定分割がgreedy最適だったことを表さない。

空群はdata_absent=True、方向行0、score／regression_value／impurity／回収平均等はNone。空側の固定内部nodeも残す。未知をscore0へ補完しない。

training.partitionのkeyはD0_V0／D0_V1／D1_V0／D1_V1。

```text
d / v / route / policy
excluded_feature_indices / child_feature_indices
direction_rows / pair_unique / days / sessions / row_ids_sha256
fit_performed / root / node_count / fit_parameters
```

routeはD0でR、D1でT。pair_uniqueは群内のunique枠であって、両方向が同じ枝に揃ったpair数ではない。全所属はpair除外後の方向行から作る。

structureは次のliteralを持つ。

```text
kind = fixed_direction_current_episode
fixed_nodes = 上表の常設3node
child_depth = 2 / child_features = 58 / feature_count = 60 / max_depth = 4
child_feature_indices = {'D0':低側58indices,'D1':高側58indices}
excluded_feature_indices = {'D0':[0,25],'D1':[0,19]}
fixed_mse_optimized = False
child_estimator = DecisionTreeRegressor / target = pnl5
```

## 方向順位・技法資格・運用

walk／predictはmodelのpolicyだけを局所的にQ0へ射影し、旧64の60列JSON走査／予測純関数を呼ぶ。元modelと旧moduleのglobalは変更しない。

障壁scoreがstrict高い側を先に決め、その側だけへscore>=1/3、unique枠>=60・6日・10場、異種family2以上かつtrend又はoscを要求する。同点・片側未知は両方向WAIT、最高側不適格でも下位側へ救済しない。回収平均が高い側への方向変更は本巡に含めない。

**固定DI根のtrendと対応episode旗のpriceが全有効pathへ入るため、技法条件は構造的に充足する。** 64でtrend単独だったpathとの違いであり、従来条件自体は残す。固定段と学習子のfamily、量実数／価格進行／mask経由を区別して報告し、二つの独立証拠や量だけの効果とは呼ばない。

U1の回収支持・過去平均strict正は同じ最高側へ後段で追加する。学習目的は回収MSEでも、順位は障壁scoreのままである。先着率と実回収の目的差、独立一建玉と実運用の保有占有差を維持する。

旧O49の一建玉、全定時枠分母、保有継続非待ち、正常BBO、+1価格秒／TTL、損失連続追尾、現在費用後122円strict正での起動・最低名目新規床、0／5／10pt費用、強制返済等は本コードの外で変更しない。
