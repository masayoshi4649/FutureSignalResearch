L0は新P＋実side×OLS傾き>0＋実side×現前MACDヒスト差>0。L1はR²定義可能を追加するが、非零傾きなら全平方和が正なので数学的に冗長である。L2はR²≥1/2を追加し、半分等号を採用する。R²は当該20点の直線性で、未来の勝率・有意水準・独立した予測票ではない。現在を前20高安へ含めず、回帰20終値へは含める。

元float終値を各々Fraction化し、x=0..19、切片付きOLSのDxx=13300とDxy/Dyyから分子・分母を保存する。全同値は傾き0を定義できてもR²未定義とし、0/1補完や採否epsilonを加えない。同場21連続公開有効足の局所窓と、固定29のATR/MACD数値銀行の同限月carryを分ける。旧BB/k数量M/上位/CLV/TR上限は使わない。

独立は全12,952足のOHLC/ATR14/中心化ヒストを元入力から別算し、中心偏差と残差二乗和の別式でOLSを検算する。精密OLS/価格/時点/全採否は厳密、ATR/ヒスト/現前ヒスト差の表現だけabs1e−10/rel0を許容し、ATR正有効/D整数/ヒスト差符号/全採否はstrict一致を要求する。保存正本SHAと独立再算の生float SHAを混同しない。

同じ新PのL0/L1/L2は同時計・同価格の直接先着を対応させる。旧case/旧label/旧全運用対照は流用しない。同一試行内のL0/L1は識別子だけを正規化した全運用・追尾も照合する。新大明細は回帰判定/入口事例/全運用詳細/追尾の4gzip。固定29の全指標一明細から必要な3分15列だけを読み、旧contextや原板を複製しない。
