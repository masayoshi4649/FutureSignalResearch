# 96・チャート数値の独立原板監査

固定80の数値器を呼ばず、Pythonで3/15分半開足、初期SMA後のEMA8/21/12/26、MACDのEMA9、WilderのRSI/ATR14を実装した。固定82の前3分公開関係、96Bankのtimer→grid→raw、同限月の数値種だけの継承、EOFで未完足を締めない契約も別式で確認する。新規注文・Source・金融を再生しない。

## 実行と読取範囲

```powershell
work/venvs/technical-tree/Scripts/python.exe -B -X utf8 work/96チャート原板監査案/人工を照合する.py --out work/96チャート原板監査案/人工_再現用新規フォルダ

```

出力は既存上書禁止。市場CLIは9/21 Day/Nightの2場だけを許可する。54場への拡大はRootの完了通知・追加指示を待つ。実2場Nativeは`chart_grids`の識別/時計/Chart/Recent3と`chart_end`だけを参照し、Current・Actors・Source・損益へアクセスしない。JSONの解析後に対象fieldだけを抽出するためファイル全体のbytes指紋は保存するが、損益値は比較・表示・判断に用いない。

原板は台帳にある9/21 Day/NightのNK225/TOPIX計4gzipのみ。CSV、他の場、96結果集計、未読日を読まない。初回と停止版で**同じ4原板を再照合**した。新規の市場価格範囲は追加していない。

## 時計・品質・種

- readerはSHA固定95→94→93から`parse_clock/number/session_clock`だけを再用。旧`walk_raw`はLast0を省くため使わず、同じ採用規則でLast0を含む新iteratorを作る。20段の原板field型を確認し、価格時計不明・場外・後退を除く。
- TOPIX先行、同市場は物理順のstable merge。TOPIXは時計だけを進め、LastをNKの足へ入れない。全受理NK原行に0始まりのIndexを付ける。FeaturesのLast正行連番とは別で、Currentの数量監査へ流用しない。
- gridまでに公開できる3分timerを先に進め、同時計原行は次の足へ入る。ObservedClockはdrainを許した原行の上限、AvailableAtは論理公開時計で、別物として一致確認する。先の原行価格を過去足へ入れない。
- 不良Lastで数値履歴を即座に未知化し、その形成足も不良とする。BBOだけが不良ならLastはチャートへ採用する。欠足を横ばい価格で埋めない。
- Seedはdeepcopyした数値系列だけ。同限月で前場の確定前終値・平均種を保つが、形成足・公開mask・前3分追跡は新場で初期化する。限月交代では数値種も初期化する。SealでAdvanceを呼ばない。
- EMAは各期間の初期SMAから更新する。RSI14は14価格差、ATR14は14TR、MACDはEMA12/26の既知後にsignal EMA9を助走する。数値器が持つ個別の助走状態を独立に追跡し、公開総合Knownだけから未公開の個別既知性を推測しない。

## 数値誤差と成立境界

既知数値の比較は`abs_tol=1e-8, rel_tol=1e-12`。時計、原行、field集合、順序、Known/reset、公開出典は厳密比較。個別に未助走の数値は有限表現だけを確認してskip数へ分け、未知の0を指標値の正しさの根拠にしない。

EMA方向、MACD増分、CloseとEMA8/前Close、同時TR/RSIスパイク、Bのa時点固定Lに対するa/b/cの位置とcの価格/RSI再進行は、許容誤差を使わず符号・等号の成立を比較する。現在取得側BBOによるATR位置と量支持、最終GateDecisionは数量/金融/保存の別監査へ分担する。許容差内でもstrict符号を変えたMACD・固定Lの人工を拒否した。
