# 試行00020：複数手法で順行・反転・待機を切り替え、利益を追尾する

計画更新：2026-11-04。未固定・未実行。ユーザーの追加条件に合わせ、未実行だった15分局面だけの案を置き換える。先行00019の固定済み条件と結果は変更しない。

## 問いと入力

当時の複数時間軸EMA、ADX/DMI、RSIの持続/急変、ATR、VWAP復帰を組み合わせ、順行Q1・反転Q2・待機を選ぶ。その状況を事前に区別する条件と、切替で避けた逆行・逃した順行の両方を検証する。売買は同じ閾値の符号対称。方向側RSIは買いRSI、売り100−RSIとする。

入力は固定00008価格台帳と00017補助台帳のNK225全65場。学習40・条件選択24・既使用最終1、125pt逆行前の250pt順行、支持付き70%、30分間引き、費用・品質・一建玉・持越し禁止・遅延条件を維持する。全場は既使用で、新しい未見検証ではない。ラージBBOをmicro1枚へ代用し、倍率10円/pt、片道手数料11円、追加費用0/5/10ptを使用する。

入口尺度は1/3/5分。中期15分・長期60分の最新公開足を、入口足の公開キー以下かつ足終了以下で結合する。指標計算の同限月場間持続/欠測リセットは既存定義を使う。未確定上位足で分類しない。

全戦略共通の準備Mは、15分の終値/EMA20/前EMA20/ADX14/±DI14が有限、入口・15・60分のEMA10/EMA20/前EMA20/ATR14が有限でATR>0、入口尺度の同場連続公開RSIが過去4本と現在の計5本有限であること。欠枠/非公開/番号飛越でRSI履歴を切り、欠測を0にしない。対照側も同じ助走を待つ。

## 手法の役割と固定条件

| 手法 | 役割 | この試行の条件 |
| --- | --- | --- |
| 三時間軸EMA10/20 | 傾きの一致・平均の収束 | 各尺度s=(EMA20−前EMA20)/その尺度ATR。順行は三尺度全てside×s>=0.02、かつ入口side×(C−EMA20)>0 |
| EMA間隔とATR | 値幅に対する収束 | abs(EMA10−EMA20)/ATR<=0.25かつabs(s)<=0.10を収束とし、反転は三尺度中二尺度以上を要求 |
| 15分ADX14・±DI14 | 強さと方向の補強 | ADXの20/25境界とEMA/DI方向一致をS1/S2で使用 |
| 入口RSI14の持続 | 水準が続いているか | 順行は直近3本の方向側RSIが全て50以上。高いという理由だけで除外しない |
| 入口RSI14の急変 | 現在までの急伸への警戒 | 現RSI側>=70、前足差>=12、過去4本で65以上が1本以下の全成立で「急変警戒」。複合候補の新規を見送る |
| 入口RSI14の戻り | 反転方向へ勢いが戻ったか | 前RSI側<=40、30<=現RSI側<=60、現>前を反転に要求 |
| 配信VWAP・ATR | 平均付近の再獲得/乖離からの戻りという発動 | 固定00019の追加方向なしQ1/Q2を使用。N四点・起算・遅延等の準備も維持 |

0.02/0.10/0.25/RSI本数・急変幅は本研究の仮説であり、有効と実証された推奨値ではない。急変警戒を、将来の反落まで確認したスパイクとは呼ばない。各尺度の傾きはその尺度の一足差を自身のATRで正規化し、異なる分足の速度を直接比較しない。EMA・ADX・RSIは同じ価格の派生で、独立した票とは数えない。

## 局面と五戦略

15分の`C>EMA20>前EMA20`と`+DI>−DI`がともに成立なら方向1、鏡像なら−1、他は0。S1はADX<=20でレンジ、ADX>=25かつ方向±1でトレンド、それ以外は待機。

S2は初期待機。ADX<=20でレンジ。レンジはADX<25で維持する。トレンドはADX>20かつ方向が従前と同じなら維持する。その他はADX>=25かつ方向±1でそのトレンド、残りは待機。場開始/欠枠/非公開/未準備で記憶を初期化し、新しい15分公開足ごとに一回だけ更新する。

| 戦略 | M準備後の新規 | 位置付け |
| --- | --- | --- |
| B1 | Q1だけ | VWAP+ATRの順行固定対照。採用候補ではない |
| B2 | Q2だけ | VWAP+ATRの反転固定対照。採用候補ではない |
| S0 | Q1/Q2両方 | 同じ助走・保護を使う常時混合対照。採用候補ではない |
| S1 | 即時局面と下記複合条件を満たすQだけ | 複合候補 |
| S2 | 履歴保持局面と下記複合条件を満たすQだけ | 複合候補 |

S1/S2の順行は、トレンド局面かつ実売買側と一致、三尺度EMA方向一致、RSI持続、急変警戒なしを全て要求。反転はレンジ局面、二尺度以上のEMA収束、RSI戻り、急変警戒なしを全て要求する。条件不成立は待機で、反対側へ自動的に入らない。収束だけを逆張りの根拠にしない。

3尺度×五戦略=15入口集合。Q1/Q2共通の一建玉・一注文状態とする。同一判断の両方向競合、同方向二信号の曖昧な重複は見送る。入口役割は実新規時に建玉へ固定。保有中も局面を観測するが、局面変化だけで役割変更/ドテン/強制返済をしない。

## 必須の利益追尾と三出口

全45運用に同じ利益追尾を必須とする。起動幅A=5pt（正常返済BBOで初めて1呼値の正益を観測）、入口ATRをA0に固定し、追尾幅D=max(5,ceil(A0/5)×5)。実新規後の正常返済BBOだけで最大順行MFEを更新する。未固定段階の0.5ATR起動案は、起動前の正益が無保護になるため、この1呼値起動へ変更した。実結果を読む前の変更である。

MFE>=Aで起動し、保護する方向側利益をmax(0,MFE−D)とする。価格へ変換後、買いは5pt刻みの上方・売りは下方へ丸め、前回の保護線より緩めない。起動後の設定は最低でも新規価格。入口前の峰・将来高安・未確定ATRは使わない。

X0は125pt非常保護・250pt利確＋必須追尾。X1はこれに入口判断VWAPの役割別通常出口、X2は公開足で更新するVWAP通常出口を加える。全て追尾を使い、追尾なしの運用を新候補にしない。優先順は期限/既存待機約定、125保護、250利確、追尾、VWAP通常出口。同じ原行は正常板→公開足→入口。

逆指値設定が同値でも、要求から1価格時計秒後のBBO約定、跳躍、費用で実損は起こり得る。起動済み取引の純赤字、保護設定と実返済との差、費用後純額を別に記録する。

追尾起動済みは、返済要求がまだない正常BBOで実際に追尾を有効化した取引とする。先に期限/利確/通常出口等が返済を要求していたら、待機中はその要求を維持し、追尾状態も更新しない。返済待機中や約定時までの最終MFEが5pt以上でも、その値だけで過去の追尾起動を補わない。
