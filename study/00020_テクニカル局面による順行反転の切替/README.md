## 全45で必須の利益追尾

実新規後・返済要求前の正常返済BBOでMFE>=5ptを初観測したら起動。D=max(5,ceil(入口ATR/5)×5)を固定し、side方向の保護利益=max(0,MFE−D)。価格変換後は買ceil/売floorの5pt丸め、起動後は最低新規同値・前設定より緩めない。

順序は期限/既存待機約定→hard125→TP250→追尾→通常線、同原行はquote→bar→signal。返済pending中は追尾の起動/線更新も止め要求を上書きしない。TP等が先に要求された取引は後のMFEが5を越えても起動漏れとはしない。全要求後1価格時計秒以上の最初正常BBOで約定し、同値設定でもgap/待機/費用で赤字を残す。

## 条件と解釈の限界

ラージBBOでmicro1枚代理、倍率10円/pt・片道11円・呼値5pt、新規有効30秒・停止前・期限残60分。新規買Ask/売Bid・返済買Bid/売Ask。追加片道5/10ptは同じ完結往復から100/200円を控除する感度で、価格を滑らせた再参加の再生ではない。正常BBO空白300秒超/EOF/未解消がある全体の確定対象額はnullのまま。

本試行と00019の直接金額差には共通M・追尾追加も含まれ、局面分類だけの効果とはしない。本命/対照は同じM・追尾で比較し、見送りで失った順行と避けた逆行、共通実新規の出口差と片側だけ参加を分ける。件数消失を高勝率達成と呼ばず、同じ市場観測からの派生を独立標本へ加算しない。EMA/ADX/RSIは価格由来の関連特徴で独立した票ではない。

MFE後赤字は事後の観測峰と最終純額の関係で、その峰で実際に回収できた証明ではない。通常出口で保有期間が短くなる効果も含む。配信VWAP/代金固有時計・正確な受信時計は未収録で、repeat全長はオフライン出典metadataとして保存するだけ。心理/需給の説明を観測済み事実としない。全65既使用の追加開発であり、採用には将来の別確認が必要。
