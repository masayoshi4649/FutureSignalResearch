## 極値中心と知れる時点

価格極値の中心iと、極値と知れるi+2の公開時計・原行を区別する。中心足自身の公開キーは保存資料の『中心足公開時計秒/原行』、右2足後のキーは『極値確認時計秒/原行』。要求は後者で、中心の安値/高値へ約定を描き戻さない。RSIは両中心に対応する値を比較し、判断時のRSI準備とは別に保存する。

左2本はstrict、右2本はinclusiveの価格極値。同値の並びでは先頭側を選ぶ。同側の隣接極値だけを比較し、RSI未準備・中心間隔外・時間外・発動不成立でも必ず更新する。欠枠・index飛越・非公開足で窓と前極値をリセットする。3〜20は中心間隔の足本数で、1/3/5分の尺度と混同しない。

現判断足のRSI14有限・ATR14有限正と当場15分EMA20/前値の準備を要求する。下位EMA20・ADX・BB・数量は入口gateへ使わない。共通コードが計算していても、この試行での使用を意味しない。反転乖離は上位方向不問、押し戻り継続だけ方向一致。ネックは両中心を除く間の高安に対する現終値のstrictな位置選別で、交差検出や後続突破待ちではない。

価格更新とRSI非更新を勢いの変化、価格を維持したRSI調整を押し戻りと読むのは仮説で、利確・手仕舞い・追随注文の主体を測った結果ではない。RSIは終値の加工であり価格と独立のフロー情報ではない。[資料と心理仮説](../../docs/議論/RSIと価格の山谷を時点どおりに比較する.md)の一般説明と、この固定定義の研究結果を区別する。

ラージBBOでmicro1枚を代理し倍率10円/pt・片道11円を仮定。追加片道5/10ptは同じ完結往復から100/200円控除する感度で、滑りによる発動・再参加の再計算ではない。価格時計は受信時計ではなく1秒待機は通信遅延の実測ではない。正常板空白・EOF・未解消を含む全体を確定利益へ置き換えない。運用確定対象欄の『未算出』は品質上の未確定（正本null）を表し、無取引の平均・率とは理由が異なる。
