# 00068：発動前の反対端否定で条件を取り消す

作成日2026-11-06。本物評価前に固定する計画。全66場は既使用、初20場は既存木の学習専用、後20場・条件選択24場・後続2場を評価する。11月5日Dayと未確認TOPIXを追加で開かない。前巡67は市場・保存監査・文書を完了し、133対象の指紋一致を再確認したため、前巡は進展と分類する。

## 問いと維持する条件

[67](../00067_定時候補を将来価格の突破で発動/README.md)では、突破を待つことで大きな損失群を外す一方、共通元候補の取得が遅れて回収が悪化した。今回は、発動前に元の反対端を先に否定した往復と、否定せずに発動した候補を分ける。

旧G0/G1の全60特徴・旧65三木・回収・純方向・役割・ATR/D・定時・条件4項目を保存参照し、新N0/N1だけを92運用する。新fit、木、教師、特徴算術、予測は0。旧67のG92運用と488入口は再実行しない。DMI/ADX、ストキャスティクス、ATR、BB幅、価格構造、段階量等を使う複合判断を維持し、価格一つだけの売買候補には替えない。

## 追加する否定規約

条件は旧67と同じ `{high,low,source,expires}`。最新公開完全3分足、足end≤予定T、公開key≤実判断key、当場と銀行13項目同値。買いLast>high／売りLast<lowの発動と、次定時T+900の満了は変更しない。

| 場面 | 追加条件と処理 |
| --- | --- |
| 設定時 | 旧BBO・保有・pending・準備・既超過の優先を維持。その後、買いLast≤low／売りLast≥highなら待ち・未登録、結果は設定否定 |
| 設定後の監視 | 設定keystrict後だけ。正常観測間隔>300秒なら従来の観測不足を優先。正常BBOかつ有限正Lastの行で同じ反対端否定を満たせば前提否定で取消 |
| 等号 | 反対端への到達を否定に含む。high=lowで設定Lastが等号なら設定否定。発動端の等号は従来どおり未発動 |
| 否定後 | 同枠の再登録・復活・自動反対新規なし。次定時に同じ複合判断を行う |
| 発動済み | 新規pending・保有へこの否定条件を追加しない。旧要求+1秒・後行正常BBO・TTL30と、次定時取消を維持 |

設定否定の理由は「設定時に反対端を否定」、監視否定は「発動前に反対端を否定」。監視否定は最後の正常監視時計を更新し、条件取消のkeyを残す。価格による否定を観測不足や損益品質注意にしない。満了timerは境界同秒の価格より先。足OHLCから先後を推測しない。

主待ちはWAIT/全予定枠。保守は（WAIT＋判定不能＋登録後に実新規なし）/全予定枠で50%以下。設定否定はWAIT、登録後の前提否定は登録未約定。保有は非待ち。取消だけで活動目標が改善するとは仮定しない。
