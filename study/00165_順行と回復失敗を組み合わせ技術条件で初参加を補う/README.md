## 入力・費用と分母

全73場・35,339q0・31,642物理caseの既存母集団を維持。共有148の当時100Xと163の実両側・任意幅IFD表を用いる。技術出生へ教師・q1・金融を渡さず、出生固定後に実取得対応を結ぶ。5/15/30分の足幅と新規判断の時計を混同せず、連続したq0を使う。DAY/夜間NY09:30前/以後は夏冬変換、q0出生帯とq1取得帯を区別する。各帯強制参加はしない。

先着は164のIFD_FIRST：打切り前の最初の既知touchでF/A、touchなし期限完了でN、他C。F/(F+A)は到達済み先着率で、N/Cを含む全取得成功率や費用後実現勝率とは異なる。金融未知は0円実績にせず別計数。

各入口を独立mini1枚、100円/pt、税込片道38.5円（往復77円）と追加往復滑り1,000円を控除。実BBOでBUY Ask/SELL Bid取得、反対側BBO清算する。順逆同じ幅を枝ごとq0で固定し、touch又は完了期限BBOで決済する。利益は費用後正の合計、損失は費用後負の絶対値合計、PF=利益/損失。既知差引は未知を解決した全損益ではない。

頻度は全対象ザラバ720時間55分を分母とする。同じ入口の重複分割を回数へ水増ししない。独立入口は保有が重なり得るため、片側10枚上限を満たす実口座収支とは称さない。mini固有板・遅延・待ち行列も未再現。新7場は本試行の条件探索・成績へ使用しない。
