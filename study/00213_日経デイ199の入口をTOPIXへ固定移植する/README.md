## 差が生じた場面

**価格の単位をそろえる必要があった。** 額面をそのまま渡した01は、決済が判明した85件すべてが幅の内側で期限を迎えた。02では出口幅を1/20にして実際に利確・損切が起きたが、入口には日経のポイント建て制限が残った。03はTOPIXの現値・気配・1分/5分足のOHLCも20倍して日経と同じ特徴生成器へ渡し、元の板価格で決済した。42日の14,534判断で主入口の発生時計が02と03で49箇所変わり、既知収支も116,250.8円変わった。03の費用は135件計78,786円。追加滑りと手数料を全額戻しても費用前は赤字である。費用前の値には売買気配の差が入っている。[価格単位の照合・入力仕様](../../inputs/00213_日経型TOPIXの純入口/README.md)

**特に差が出たのは、当日序盤の局所的な回復を拾う入口だった。** 179で追加したLCは、その場で15分MACDの増分がまだ一度も公表されていないとき、短い足の方向・勢い・価格回復・値幅・スプレッドの条件で入る。旧42日で日経は23件、順13・逆3・未到達7、＋440,229円。TOPIXでは25件、順5・逆10・未到達10、−102,090円だった。その他の通常入口も日経129件＋588,067円に対し、TOPIX99件−54,776.4円。初回参加を補う入口は日経10件＋29,230円、TOPIX11件＋27,080.4円だった。[元のLCの条件](../00179_保有時間参加率と終了前決済で入口を広げる/README.md)

すべての取引日で08:45以上09:00未満だけを抜き出すと、日経は11件11勝・＋416,153円、TOPIXは15件4勝・−135,254円。09:00以後の取得による既知収支は日経＋641,373円、TOPIX＋5,468円。時計による集計には現物休場日を含む。LCとこの時間帯は日経10件、TOPIX14件が重なる。これらは同じ取引の分類であり、その時間を禁止した口座損益は再計算していない。

**日経の確認待ちにはTOPIXでも効果が残った。** 03は保留導入前の04に比べ、損失を86,168.8円、赤字日を25→23日、場末DDを53,077.2円減らし、収支を70,336円改善した。保留期間中に別注文が先に建つことを防ぐと、その後の一枠で取得できる注文も変わる。この差は一連の変更による口座全体の効果である。従来のTOPIX専用入口に保留条件だけを足した診断では、5分DIの必要符号が両立せず、対象2,450判断（旧D4）・2,383判断（210主3）の発動はともに0件だった。[保留条件の必要符号](既存TOPIX入口の保留診断/README.md)

## 同じ時刻・同じ方向で両指数を測る

上の口座で差が生じた理由を絞るため、各指数が実際に建てた時計と方向を固定し、その1秒後から両方の板で同じ呼値数・元の期限の値動きを測った。どちらかの取得・決済が不明ならペアから除き、分母を残した。表の数値は「各取引の費用後損益÷その取引の設定幅の円相当額」の平均。1.00は設定幅ひとつ分の利益に当たる。個別観測は時間が重なり得るため、この診断には口座収支を付けない。

|時計・方向を決めた指数|通知|両指数で観測完了|日経の平均損益／幅|TOPIXの平均損益／幅|
|---|---:|---:|---:|---:|
|日経199_02|162|157|＋0.224|**＋0.105**|
|TOPIX 03|135|130|−0.001|**−0.049**|

取引商品をTOPIXに固定しても、日経が選んだ時計と方向では平均が正、TOPIX自身が選ぶと負になった。同じ日経由来の判断でもTOPIXでの値動きは日経より弱かった。この期間の差には、①どの場面でどちらへ入ったか、②その後に各指数が設定幅に対しどれだけ動いたか、の両方が表れている。指数構成や注文フローが差を生んだという因果までは今回の観測から特定できない。[同時計の集計](同期照合の集計.json)

日経の実取得通知でTOPIX側の独立した一枠口座を動かす別対照も実施した。建玉ごとの事前価格比で幅を換算し、従来のTOPIXの指値・遅延ルールを使用。162通知から127取得、40/42場、未知1件。費用後の既知利益768,813.6円、損失486,347.2円、収支＋282,466.4円だった。この口座には送受信時刻の実測値がなく、日経の判断と各商品固有の値幅・執行代用を含む。固定候補として追加期間で検証する価値がある。[通知対照の条件・限界](日経取得通知の対照/README.md)
