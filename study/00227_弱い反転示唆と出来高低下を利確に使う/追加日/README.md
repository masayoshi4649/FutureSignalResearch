# 追加デイでRCとW12を固定比較する

日経199_02のデイに、既存のRCと「元の利確まで80%順行した後の5分足反転で、狭い利益追尾を加えるW12」を適用する。開始待機は20分と30分の両方、場末は15:29に返済を要求して15:30までに全決済する。買い売り合計1枚、ラージの清算側気配でmini1枚を代用し、往復1,077円を控除する。新しい日の収支に応じた閾値や候補の選び直しは行わない。研究上の比較候補で、実運用への採用は保留する。[W12の条件](../弱い反転/確定足の転換を待つ条件.md)・[RCの定義](../../00224_利益保護後の再エントリーをシグナルで待つ/README.md)

## 入力と実行

[試行216の手順](../../00216_十一月二十日の固定入口と寄り前の反例を検証する/日経/README.md)で新しいデイの母集団、199_02の純入口NPZ、正常気配の原板索引を用意する。旧形式の純入口ZIPにも対応し、その場合は `--圧縮内` に対象NPZの末尾名を添える。依存する既存研究部品と入力の復元は[224の手順](../../00224_利益保護後の再エントリーをシグナルで待つ/追加日への適用.md)のとおり。

次は既使用の11月18〜20日の照合例。新しいデイを調べるときは、各入力と場名を差し替え、`--既使用照合` を外す。未公表の未来のデイを補う処理は行わない。リポジトリ直下で実行する。

```powershell
$py = 'work/複合テクニカル学習環境/Scripts/python.exe'
$run = (Get-Item 'study/00227*/追加日/固定した出口を比較する.py').FullName
$dest = Join-Path work ('227追加日_' + (Get-Date -Format 'yyyyMMdd_HHmmss_fff'))
& $py -X utf8 $run --母集団 'work/216日経/母集団' --純入口 'work/216日経/純入口.npz' --板索引 'work/216日経/前史十場と追加二場の索引参照.json' --場 '2026-11-18_Day' '2026-11-19_Day' '2026-11-20_Day' --既使用照合 --出力 $dest
```

`RC20_デイ.csv`、`W12C20_デイ.csv`、`RC30_デイ.csv`、`W12C30_デイ.csv` はそれぞれ1候補。出来高を使わないW12のために出来高入力は追加せず、実際の候補定義をそのまま実行する。0取引日も利益・損失・収支0円の行を残す。未決済が1件以上ある日の確定収支、その日以後の確定累計は空欄とし、既知金額・未知件数を別欄に残す。保有率には実際に観測できた保有秒だけを使う。元帳には新規と決済の日時・価格に加え、入力指紋・既使用照合の区別を記録する。[固定条件と各日の照合指紋](固定条件.json)

## 動作照合

2026年11月22日、追加日用の経路に既使用5入力群（37・3・1・1・3日）をそれぞれ渡し、全45日の4口座・延べ532建玉の全項目指紋、および各候補の45日次行の利益・損失・収支・回数を確認した。

|候補|45日建玉|総利益|総損失|費用後収支|
|---|---:|---:|---:|---:|
|RC20|133|2,067,993円|1,061,234円|1,006,759円|
|W12C20|133|2,059,916円|1,045,157円|1,014,759円|
|RC30|133|2,043,070円|1,087,311円|955,759円|
|W12C30|133|2,034,993円|1,071,234円|963,759円|

W12が早く返した10月7日の日計はRC20＋13,769円、W12C20＋36,769円。11月20日はRC20＋31,769円、W12C20＋12,769円で、W12の日計が19,000円少なかった。30分待機にも同じ2日で同じ差が残った。実データの決済未知は0件。未知1件に続き0取引日がある小規模な集計照合では、未知の日の確定収支は空欄、続く0取引日の確定収支は0円、両日の確定累計は空欄となった。
