# 日経199_02デイで、弱い反転や出来高の低下を利確に使えるか

**一部の大きな含み益を保護する使い方に限って、追加検証する価値があった。** 既存のRC20は反対の主入口2回で追尾を狭める。今回はその手前で利確指示を出す仮説を30条件、20分・30分待機の両方で試した。入口・利確指値・初期逆指値・保護後の新規再開規則を固定し、同じ日に同じ方向・価格で取った133件ずつを比較した。額は全て日経225mini 1枚換算の費用後。既使用45デイの結果である。[全条件](全条件の比較.md)・[設定と結果](設定と結果.md)

## 取引時間とRC20の日別損益

09:05から新規判断を許可する。新規判断と取得は15:29:00未満。15:29に残った建玉の返済を要求し、1秒以上経過した最初の正常な清算側気配を用いて15:30までに決済する。15:45終了のデイの最後15分は無保有。今回のRC20で場末まで残った18件は15:29:01〜15:29:22に返済した。開始待機中・終了前の無保有と、建玉を何分持つかは別で、保有時間の上限は設けていない。[全45デイの日別表](../../outputs/00224_利益保護後の再エントリー/224_RC20_R02元価格まで待つ/全セッションの損益.md)・[全90場のCSV（デイ45、対象外のナイト45）](../../outputs/00224_利益保護後の再エントリー/224_RC20_R02元価格まで待つ/全セッション.csv)・[JPXの立会時間、2026-11-22確認](https://www.jpx.co.jp/derivatives/rules/trading-hours/index.html)

**反転をどの段階で受け取るか。** W01は元の固定利確に達した17件を早く返し、それだけで433,000円を手放した。W08は単発の反対シグナルと完成1分足の失速を同時に要求し、そこからの最大順行を0.15Rの幅で追った。元の固定利確・損切はすべて維持したが、収支が動いたのは2日、後21日の差はゼロだった。[弱い反転の条件・建玉別寄与](弱い反転/README.md)

**一段進んでから、方向転換を確認するW12。** 元の利確幅を1Rとして、5分足の確定前に0.80R以上順行し、確定後も0.60R以上残っていることを求める。直前の5分足の終値変化は保有方向、今確定した5分足の変化は逆方向で、1分終値がEMA8の逆側、直近3分の値動きも逆向きに偏るときに0.15R幅で追う。買いと売りは対称。10月7日の売りではRC20の−16,077円を＋6,923円に変えた。総損失減16,077円を支えたのはこの1件で、別の3件の元利確に対して計48,000円の減益があった。前24日ではRC20比＋35,000円、後21日では−27,000円。赤字日数と日末最大下落63,154円はRC20と同じ。RCと追加返済の執行をともに3秒・5秒に遅らせても、同遅延のRCに対する収支差＋8,000円・損失差−16,077円が残った。[追試の条件](弱い反転/確定足の転換を待つ条件.md)・[金額が変わった建玉](弱い反転/決済の内訳.md)

**出来高が落ちると何が分かるか。** 取引の減少だけでは、買い手と売り手のどちらが引いたかは判別できない。D01は黒字になった後の損失を減らしたが、元の固定利確58件も途中で返した。同時刻の平常の出来高を参照し、逆方向の足・その後の出来高回復まで要求したD09では、先に返した11件のうち10件がRC20なら元の利確を達成した。11月11日の買いが一例で、12:30:01の早期返済は＋23,923円、元の指値は7秒後の12:30:08に＋33,923円。もともと大きく順行していた建玉なので、10/11を新しい順行予測の確率として使わない。[出来高を使った10条件](出来高低下/README.md)

薄商いを識別する基準には、直前3本の平均比と、同限月の過去10デイの同じ時分に対する比率を設けた。日経225miniの2012〜13年の公開研究でも取引量は時間帯で変化した。ここで用いた60%閾値および利確の判断は今回の検証仮説である。[原著、2026-11-22確認](https://www.econstor.eu/bitstream/10419/103805/1/790394936.pdf)

**利確直前の停滞。** 0.75R順行後に有利な極値を5分更新せず、まだ0.50Rの含み益方向にあり、1分足の失速で追尾するZ04は123,000円減益。残り30分に限って即時返済するZ05は4件が変わって7,000円増益、総損失は同額だった。一日を通して「動かなくなった」ことを利確理由にする案は元の大きな利確を繰り返し手放した。[停滞の条件](利確手前の停滞/比較条件.md)

## 入力・費用・検算

次の追加デイに固定した比較対象はRC20・RC30とW12の20分・30分待機。追加日用の経路でも、既使用45日×4口座・延べ532建玉の取得・決済・損益が元帳と一致した。新しい日の結果は今後の観測対象。[追加日の固定条件と実行手順](追加日/README.md)

固定入口は[日経199_02](../00224_利益保護後の再エントリーをシグナルで待つ/README.md)。ラージの正常なBid・Askでmini 1枚を代用し、1pt=100円、往復手数料77円と追加滑り仮定の往復10pt・1,000円を控除した。即時返済要求にも1秒以上の遅延を置く。未知を都合のよい価格で埋めない。全実験で追加返済後は元の±1Rのどちらかへの到達または場末まで新規を休止し、待機は実保有率に含めない。20分と30分は大半の取得が重なる。より早く得た利益は、旧取引の実際の返済と比較したもので、決済後の仮想収益は足していない。[原行照合](原行照合/README.md)・[再現手順](再現手順.md)・[代表候補別CSV](../../outputs/00227_日経デイのテクニカル利確/README.md)
