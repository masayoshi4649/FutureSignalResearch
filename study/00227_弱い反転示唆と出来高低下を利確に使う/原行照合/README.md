## W08・W12の追加判断

両待機で重なる同一判断をまとめた。W08の追加判断は4件（買い2、売り2）で全件が早く返済された。W12は8件（買い3、売り5）で、返済を変えたのは6件（買い2、売り4）。判断が出た全12例について、当時までの正常な中値から完成1分終値を作り、EMA・経路効率・値幅収縮と5分終値の変化を該当条件ごとに再計算した。W08は199_02がその原行までに公表した最新の有効主入口の方向と90秒以内の鮮度、W12は0.80R到達が5分足境界の直前までに確認できたこと、確定後1分以内の順行0.60Rを確認した。早まった返済では0.15Rの追尾床への最初の接触行も原行順に照合した。
