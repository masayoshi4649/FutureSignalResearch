# 出来高が落ちたら利確するか

日経199_02デイのRC20では、**直前3分平均の60%以下に出来高が落ちた時点で利確すると、総損失は196,770円減ったが、収支は817,000円減った。** RC20と同じ133建玉で83件の返済が早まり、そのうち58件はRC20では後に元の指値で利確できていた。この58件だけで実現利益が1,080,000円減った。一方、元の損切33件のうち5件で150,000円、元の場末・追尾返済で計113,000円改善した。[全条件の約定数・総利益・総損失](全条件の効果.md)

**出来高を弱い逆足の確認に加える用途には違いがあった。** 同じ時刻の基準を利用できる完成足で、陰線かつ前終値割れ（売りは逆）だけを使うD06の収支は177,759円。直前3分と過去10デイの同じ時分の両方で出来高が落ちた場合に限定するD04では605,759円、同じ条件で即時利確を幅0.15Rの追尾に替えたD05では645,759円だった。D05でも元の固定利確75件のうち23件を早く手放し、RC20の1,006,759円を361,000円下回った。開始30分待機のD05もRC30より328,000円少なかった。[初回6条件](比較方針.md)

## 薄商いの後に商いが戻った場合

次に、元の片幅の半分まで順行し、今も0.25R以上の順行がある時だけを対象にした。買いは完成1分足が陰線で前足の安値を割れ、売りは陽線で前足の高値を超えた時に判断する。価格条件だけのD07は48件の早期決済、RC20との収支差−468,000円。先行1〜3本以内の薄商いを待つD08は23件・−280,000円、さらに確認足の量回復を待つD09は11件・−173,000円だった。3条件を同時に増減させず、各段階でどの元利確・損失を避けられたかを数えた。[事前に定めた4対照](量回復の追試条件.md)

量回復まで待ったD09の11件中10件は元の利確に届き、残る1件もRC20では場末で黒字。9日で悪化して改善日はなく、総損失はRC20と同額だった。D10は同じ合図で狭く追い、10件の返済を早めて収支差−179,000円。半Rまで順行し、0.25R以上の順行と二つの出来高基準を同時に観察できた79建玉のうち65件は、既にRC20で元の利確に届いている。元から利確しやすい取得・局面に対する比較で、D09の10/11を未取得の建玉に一般化できない。

|RC20と同じ入口|追加利確の結果|RC20での結果|
|---|---|---|
|10月13日11:41:03の売り|D01は11:49:20に＋7,923円|14:09:07の損切で−41,077円|
|10月1日11:40:28の買い|D01は12:14:17に＋5,923円|14:04:16に元の指値で＋38,923円|
|11月11日10:57:02の買い|D09は12:30:01に＋23,923円|その7秒後、12:30:08に元の指値で＋33,923円|

11月11日の例では、12:25開始足は6枚で、直前3本平均13.67枚・過去同時分の中央値24枚の双方を下回った。12:28開始足は149枚（過去同時分中央値34枚）で直前安値を割る陰線だった。確定情報を最初に利用できた原行は12:30:00。この1秒後に利確しても、その直後に元の利確指値へ届いた。出来高増加と陰線の組み合わせから、その後も売りが続くと判断する難しさが実際の約定時刻に表れている。

## 入力と再現

日付は2026年9月21日〜11月20日の既使用45デイ、時刻は日本時間。ラージの約定数量と正常な気配を使い、日経225mini換算1枚、往復1,077円を控除した。20分待機の17,325分中、直近・同時分の両基準を公表済み足で確認できたのは12,960分。このうち1,387分が両基準で60%以下。未公表、欠測、過去同時分の観測日数不足は追加条件の見送りとして元のRCを継続した。追加利確が約定した後は元の±1Rに届くまで同口座での新規を待ち、結果に仮想の損益を含めない。
