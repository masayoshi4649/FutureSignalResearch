日経199_02デイの開始20分待機・45日・同じ133取得を比較した。**反対方向の主シグナルが一度出たら即利確するW01は、RC20より総損失が92,231円減ったものの、総利益が390,231円減り、収支は298,000円下がった。** 元の静的利確が早まった17件で計433,000円を手放した。買いを早く返して40,000円改善した10月8日の例と、売りの利幅を34,000円削った9月22日の例がともにある。[条件](比較条件.md)・[代表日時と決済内訳](決済の内訳.md)

1分終値とEMA8、3分の経路効率、完成した5分足の値幅が反対方向で揃ったら即利確するW05も、赤字7件を非負にできた一方、元の静的利確41件を早め、収支806,000円減となった。単発の反対主シグナルと完成1分の失速・収縮が同時に出て初めて0.15Rの追尾に切り替えるW08は収支8,000円増、総損失は同額だった。早い返済4件のうち日計が増えたのは10月2日の17,000円、減ったのは9月21日の9,000円。後半21日の収支差は0円だった。

## 利確の近くで新しく5分足が転じたとき

過去に十分な含み益が乗ってから、保有方向だった完成5分足が初めて逆向きとなった時点へ限定した。W12は5分足の確定前に元の利確幅の80%以上に到達し、確定後も60%以上の順行が残り、完成1分足の終値・経路効率が不利になったときだけ狭く追尾する。20分待機では8取得で成立し、元のRC20より早く返済した6件すべてで実際に費用後利益が残った。[追加条件](確定足の転換を待つ条件.md)

W12が軽減した損失16,077円は**10月7日の売り1件**だった。この売りの返済額は−16,077円から＋6,923円へ変わった。そのほか、元の追尾で返す2件の利益は計33,000円増え、元の利確に届くはずだった3件は計48,000円の減益。11月20日の売りではRC20の＋33,923円を約19分早く＋14,923円で返している。両待機とも6件の変化と金額差は同じで、2回の独立した再現には当たらない。W13・14のように転換と単発主シグナルの同時成立まで求めると、45デイでは一度も追加条件を満たさなかった。

弱い示唆をどの段階で使うかに依存し、今回の比較ではW12の減損は1件、W08の増益も1日で生じている。元の利確の前に起きる押し・戻りと、相場が転じて損失まで戻すケースの識別が追加日でも働くかを評価する。
