# 再現手順

[224の入力準備と口座再生](../00224_利益保護後の再エントリーをシグナルで待つ/README.md)に従って基準RC・元IFDと価格索引を用意する。出来高の10条件は共用原板の `../JP_OSE_Data/future/NK225/<デイ>/candle_1min.csv` と固定特徴の公表時点記録も読む。PythonとNumPyは試行222・224と同じ環境。旧試行の結果は固定対照として残す。

```powershell
$py = 'work/複合テクニカル学習環境/Scripts/python.exe'
$study = (Get-Item 'study/00227*').FullName
$run = Join-Path $study '候補を再生する.py'
$groups = [ordered]@{
    '227弱反転' = '弱い反転/出口条件.py'
    '227確定足転換' = '弱い反転/確定足の転換.py'
    '227出来高' = '出来高低下/出口条件.py'
    '227量回復' = '出来高低下/量回復の出口.py'
    '227停滞' = '利確手前の停滞/出口条件.py'
}
foreach ($g in $groups.GetEnumerator()) {
    & $py -X utf8 $run --定義 (Join-Path $study $g.Value) --出力 (Join-Path work $g.Key)
    if ($LASTEXITCODE) { throw $g.Key }
}
& $py -X utf8 (Join-Path $study '集計する.py')
if ($LASTEXITCODE) { throw '集計失敗' }
& $py -X utf8 (Join-Path $study '原行照合/全候補の決済を検算する.py')
```

W12の感度は `--定義` に `弱い反転/確定足の転換.py`、`--候補 W12 --執行秒 3` または `--執行秒 5`、`--出力` に別の保存先を渡す。RCの既存の追尾と新しい追加返済は同じ遅延で処理する。対応する基準元帳は[223の遅延再生](../00223_保有期限なしの利益保護を順行幅と値動きで比較する/再現手順.md)の `work/223反対追試/比較元帳.json` にある。

候補別の閲覧CSVを再生成するには、新しい作業先を指定する。デフォルトは7条件×2待機の代表口座。`集計する.py --全候補CSV` の場合は30条件すべてから作る。全条件の金額と前後期間はどちらでも同じ。

```powershell
$deps = Join-Path $env:USERPROFILE '.cache/codex-runtimes/codex-primary-runtime/dependencies/node'
& (Join-Path $deps 'bin/node.exe') scripts/損益CSV/候補別に出力する.mjs --input work/227集計/閲覧入力.json --output work/227再生成/CSV --proof work/227再生成/照合 --dependencies $deps
if ($LASTEXITCODE) { throw '候補別CSV出力失敗' }
& $py -X utf8 (Join-Path $study '集計する.py') --照合 work/227再生成/CSV
```

RC20の全90場一覧は `全場の台帳を照合する.py` の実行で `work/227全場/閲覧入力.json` を得て、同じCSV出力器で作成する。正式な224の45日次・133取引から、利益・損失・収支・累計と枚数を再計算する。対象外のナイトに損益値を入れず、足・原板・巨大な中間元帳を重複して保存しない。
