# 保存保護点から見た失速判別の課題

確認日：2026-11-09。対象は解禁済みの既使用70場、E0/L0のG0対G3/G4、C0D0だけ。110の金融条件・算法・閾値は変更していない。

## 確認した事実

G3/G4をそれぞれ同入口のG0へ結び、932玉分の保存保護点と実返済を検査した。各政策466玉・979枚で、純額はG0 2,173,617円、G3 983,617円、G4 1,378,617円。これは成立した両実戦略の費用後純額比較で、未参加・退出後の仮想利益を計算した値ではない。

|保存実績|G3|G4|
|---|---:|---:|
|起動玉|202|177|
|初床hitのある玉|145|128|
|起動後の最終実現赤字|2|1|
|両方で勝ち、後の実現額が小さい玉|45|33|
|この減益群の実現差合計|−2,050,000円|−1,468,000円|
|減益群のうち警戒狭幅が一度もない玉|31|18|
|初hit床が保存最終床更新の峰−幅に由来する玉|100|110|

警戒はM AND(C OR P)で、保存M/C/Pの三値を独立に結び直した。起動後の初狭幅点は、警戒が幅へ初めて作用した点である。未起動中に最初に警戒が成立した時刻は保存されておらず、復元していない。

減益を警戒狭幅だけへ帰属できない。通常幅も現在Vに追随するので、警戒が偽でも幅や床が変わりうる。G3の初hitで現Vが新規V未満の群は81玉でG0比−834,000円、G4は81玉で−501,000円だった。ただし「V縮小だけが原因」とする証拠ではなく、保存された起動・最終床更新・初hitに基づく条件付き関連である。

床の由来は、初hit以前の同じ床が初回起動又は保存最終床更新にあれば識別した。最低床・峰−幅・構造床は同率も分ける。現hit点で等しい候補があるだけでは、過去に床を作った原因と断定しない。今回の初hit床の識別では構造床の支配を確認していない。全tickの構造床利用がなかったと一般化しない。

## 起動後赤字の二つの機序

2026-09-24ナイトのU165_03、1枚はG3/G4とも最終−77円。起動時の方向幅80pt、最低床10ptに対し、初hitの保存方向幅は0ptで、既に費用後−77円だった。自己要求から次原行の実fillまでの方向価格差は0pt、経過秒数も0秒。追加遅延によって正益から悪化した例とは言えず、観測された初hit時点で床を下回っていた。

2026-11-02ナイトのU165_03、2枚は、Source部分返済の1枚−9,077円が先行した。G3の残1枚の起動時には単位含み益uが＋8,923円でも、返済済み分を含む全玉清算Wは−154円だった。最低床10ptで残1枚を＋923円で決済し、全体は−8,154円。同入口のG0は＋24,846円で完結している。このG3の起動後赤字は、残玉の実fillが最低床を割った結果ではなく、先行した部分返済の損失を残玉単位の床が補償していない結果である。

この二例を同じ「トレーリングの滑り」として数えない。実約定のgap、要求後の価格差、部分返済込みWと残玉uの違いを分けて次案へ繋げる。

## 次に固定して比較する仮説

以下は未検証の切替候補で、110の実証結果ではない。

1. **起動と保護の会計単位を揃える。** 一定利益の判定を残玉uに置く対照へ、部分返済込みWが一定利益に達した場合に起動する候補を加える。起動後の最低床も、既実現額・残枚数・残費用を含めて全玉のどの値を保護するか定義する。赤字Wに対して市場価格を上回る架空の床を発注したことにしない。
2. **通常の値幅収縮と方向失速を分ける。** 現Vの低下だけで通常幅が縮む現行を対照とし、起動時の幅を維持しながら峰の更新には追随し、M AND(C OR P)等の複合失速が確認された場合に幅縮小を許す候補を比較する。最低保護は必須のまま、床を不利に緩めない。同じ幅縮小を「一時調整」と「失速」で切り替えられるかを実約定で検証する。
3. **広い背景を出口にも保存する。** 次試行で必要なら、5/15/30分の確定方向・価格構造と3分の収束/勢いを同じ公表時計へ結び、上位方向が継続している時のV収縮と、支持破壊を伴う失速を事前ルールで分ける。今回保存されていない出口時の15/30分を後付け補完しない。

心理的な説明として、値幅が小さくなる局面には継続途中の調整と方向転換前の失速が混在する可能性がある。しかしこの診断はその心理や予測能力を証明していない。どの観測組合せで切り替えるかを次試行で固定し、同一入力・実費用・実予約・実fillで比較する。
