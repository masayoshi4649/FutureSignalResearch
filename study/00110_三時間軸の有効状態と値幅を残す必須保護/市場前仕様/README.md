## 仮説

109の三時間軸入口は、新しい確認イベントと元Sourceの出生時計が重なることを要求し、70場で3件となった。30分の背景・15分の押戻し・5分の状態を維持しながら、過去の確認が現在も有効かを判別する。移動平均だけにせず、RSI/MACDの維持と増分、ATRで測る距離、既知の支持抵抗を役割別に組み合わせる。順行と反転は別の条件とし、売買は符号反転で対称にする。

109の一定利益後保護は、起動H中央値20ptに対して最低床10ptとなり、初回自己保護要求まで中央値21〜25秒だった。同入口で利益後の赤字が減った一方、実現総額は悪化した。必須保護を維持し、起動時の利益と床との間に通常の戻り幅を残せる水準を、新規時ATRと足内値幅から定義する。
