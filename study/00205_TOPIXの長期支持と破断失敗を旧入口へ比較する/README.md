## 追加による利益と損失を分ける

旧形成F/W15の増分6は旧172→187取得、37→38場、保有29.56→31.74%、両中央値正を保ち収支+243,452円。しかし損失540,353.6→596,355.2円、DD40,681.6→45,516円と悪化。新枝自身21取得は利益104,996.8/損失84,252.4/収支+20,744.4円であり、利益が出ても損失安定性の強化にはならなかった。

直接F/W15の増分14は204取得/39場・保有35.35%まで増えたが、未知11・損失665,442円・両中央値赤字。新枝自身51件で−55,345.6円、旧入口153件で+184,710.8円。新枝追加後に枠が変わるため、独立入口だけの集計を口座と同一視しない。[原因診断](原因診断.json)では共通実取得、基準だけの実取得、補完口座だけの旧入口実取得、新枝を分けている。

直接R/W15全置換9は36取得/28場・保有6.11%・未知1、6F/2A/27N/1C、既知+36,074円。到達75%は8件のみ、場中央値0。前48+1,995.2/後25+44,829.6/追加7−10,750.8円で採用しない。A25の11では収支−22,259.6円。W15増分10も189取得/38場へ増える一方、損失600,938.8円・場中央値0となる。

## 元方向と実際の方向、長中期の支持

旧N01の元順行48件は利益299,326.4/損失190,339.2/収支+108,987.2円、17F/6A/25N・未知0。実反転124件は利益463,733.2/損失350,014.4/収支+113,718.8円、14F/8A/95N/7C。200と保有枠が異なるため、200の枝寄与をこの口座へそのまま転記しない。

実反転の多くで30分背景は履歴又は鮮度不足だった。欠測を混在相場・閑散相場と呼ばず、実際に公表された指標の方向不一致と分離する。30/15のEMA並び・傾きがともに源元側のまま反転した35件は−25,258.8円・1F/2A/30N/2C。ただし元順行で30/15とも実側支持の29件も−1,424.4円・6F/5A/18Nだった。長中期の同方向だけを入口の十分条件とはしない。

直接独立Fは96件中82件が15分も源側支持なのに、その82件は−157,353.6円。源価格が15EMA8の実側54件で−153,763.6円、逆側42件で−39,093.2円。源→確認は中央値4.43分・0.654ATR5進んでおり、取得位置と方向を分けて次仮説を作る。今回の三足端回復は有効な押し目・戻りを十分に区別できなかった。

[反対側診断](反対側診断.json)では直接Fの同96実取得q0を反対BBOで個別再評価すると、費用前+42,500円でも費用後−8,856.8円、12F/12A/64N/8C。旧形成とA25も反対側は費用後赤字。1−pによる反転推定ではなく、実際の反対気配と遅延を再計算しており、個別反転の合算を単一枠口座と呼ばない。
