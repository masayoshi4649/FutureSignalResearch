# 00088：背景維持と押戻し再開の時系列比較

2026-11-08。Source現在玉・現在量、初回除く15分新規、共通G1を固定したS/E0/E1の比較。未使用期間の安定利益は未確認。

Sは旧87のSをそのまま使用する。E0は15分EMA背景と3分の価格・MACD増分・RSI増分・急変警戒・取得0..1ATRの現在資格。E1はE0と同じ現在資格に、背景内の推進i→押しp→価格回復r→最初の勢い確認kという順序を追加する。i<p<r<=kを必要とし、r=kも許す。

背景支持下で一時的な押しを経て価格と勢いが戻る、という市場心理の仮説を調べる。EMA/MACD/RSIは同じ価格由来であり独立三票ではない。足の形から参加者の意図を直接観測したとはしない。

| 外政策 | 取得の資格 |
| --- | --- |
| S | 当時のSource生存参照玉を元At/ID順に供給 |
| E0 | S候補に共通現在資格を追加 |
| E1 | E0かつ同窓の未否定再開履歴が一枠内で有効 |

再開はat−900<k.BarEnd<=atかつk.PublishedAt<=at。900秒ちょうど前は失効し、保有・品質・Source不在で次枠へ延期しない。kを後続足で若返らせず、再押しで旧eventを消す。event_seenは追加せず、Source seenは旧87と同じく要求受理後永久消費。同時一建玉・一枠一参照IDで、保有中実追加/同ID再参加はない。

旧actual bankと金融/Sourceの呼出時点は87のまま。同じ種の別eventBankだけを3分公開で進める。全旧呼出後Technicalは既知/未知含む同値を確認し、旧C0は旧bankから診断保存する。E0/E1へC0最終許可、freshHold、短秒、OFIを隠れたANDとして追加していない。

実fill→Source連続通知→旧技法/G1の順。Source部分通知はBefore比率を未約定新規/未予約残量へ整数floorし、0作用・無所有・取消も保存する。現在単価益10×方向幅−122円がstrict正になれば最低建値床を起動。予約がなく現在単価益も正ならG1収穫し、実約定した確定益だけを残玉予算へ使う。受理済返済は取消/延期しない。
