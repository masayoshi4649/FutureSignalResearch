## 限界と知見の扱い

価格突破は既知水準の通過、CCIは同窓平均からの偏り、上位BBは方向を持たない変動背景として役割を分けた。追随参加や利確心理は仮説であり、人数・注文量を直接観測したものではない。高CCIが続く可能性はあるが継続を保証せず、CCI/BB/価格は同じ価格系列の加工で独立票ではない。

この二案で直接比べるのは上位BB幅値の追加。CCIなしの同条件対照を置いておらず、CCI単独の増分効果は未測定。PSY/量/OBV/MACD/一目/RSI/ADX等と他尺度は未使用、ATR準備/保護だけを複数入口分析と数えない。純集合包含と一建玉の実参加包含は別であり、共通出口差と片側参加を対応させる。未来先着・事後MFE・仮新規価格を当時の採否へ戻さず、主要条件変更は別試行にする。既使用2場で不足支持を代用しない。
