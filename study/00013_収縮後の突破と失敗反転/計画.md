# 試行00013：収縮後の突破と失敗反転

## 仮説と固定8案

短期の収縮から拡大する文脈では、単なる帯内復帰とは異なる入口が得られるか。初回突破の追随と、突破後に固定範囲へ戻った反転を別入口にする。3分/5分×突破追随/突破失敗反転×補助なし/15分方向一致＝8。出口は全て固定TP250/SL125・期限。今回に利益床・新しい通常出口を加えない。

## 状態と参照値

1. BB20・母標準偏差2倍の帯幅を`4×標準偏差÷SMA20`とする。SMA20>0、帯幅>0のみ有効。同場の連続した公開済み20足（当足を含む）で、当足の帯幅が最小値以下なら収縮設定。等値の最小は認める。最小参照窓は同場のみで、場をまたがない。
2. その設定足を含む直近6足の高安を固定範囲とし、設定番号・時計・原行・中心・帯幅・高安を保存する。設定足自身を突破足にしない。未突破の間に新しい収縮設定が成立したら、現在足の処理後に最新へ置き換える。
3. 設定の次の1〜6連続足だけで、終値が固定高値より上/固定安値より下、かつ当帯幅>設定帯幅なら最初の突破を登録し、その方向へ一度だけ追随入口を作る。帯幅が増えず終値だけが範囲外へ出た場合は設定を失効し、突破後状態も作らない。6足を過ぎた設定は満了。境界と同値の終値は突破ではない。
4. 突破を登録した後の次の1〜3連続足だけで、固定安値<終値<固定高値に戻った最初の足を突破失敗とし、元突破と反対方向へ一度だけ反転入口を作る。同じ突破足で反転しない。終値の範囲端ちょうどは復帰としない。3足を過ぎた突破は満了。復帰前の反対側への飛び越し（買突破後C≤固定安値、売突破後C≥固定高値）は失効し、遅れた範囲内復帰を拾わない。
5. 突破後状態が残る間は新しい収縮設定を登録しない。復帰・失効・満了した足は、その処理後に新しい収縮設定として登録できる。欠枠・非公開足で20足窓・設定・突破後状態を全てリセットする。20足すべてで帯幅が有限・正、SMA20が正であることを要求し、帯幅未定義/非有限/非正またはSMA20非正でも窓・設定・突破後状態を全リセットする。

準備条件は00011に揃え、判断足EMA20/ATR14>0/ADX14/BB20と、同場で当時利用可能な準備済み15分EMA20を必要とする。収縮設定と突破後状態の登録は、価格・帯幅・連続窓だけで行う。EMA/ATR/ADX/上位の準備不足だけでは帯幅窓・設定・突破後状態を切らず、発動を抑止する。発動には準備と時間条件を要求する。補助なしも上位指標の準備は要求し、方向を制約しない。補助ありは確定15分のC>EMA20>前EMA20なら買い方向、逆なら売り方向として入口の方向一致を要求する。状態遷移と消費は補助の可否や建玉の有無で変更しない。上位足の公開キーは判断足以下、足終了時刻も判断足以下とする。
