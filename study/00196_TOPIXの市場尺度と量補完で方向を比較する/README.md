## 原因を分ける

[原因診断](原因診断.json)では、旧優先ATR比0.35の213取得のうち、5分量補完63件は既知−37,930.8円・未知10。旧対照と同じ要求で実方向が逆になった38取得は既知−104,593.2円。新候補だけの取得77件は既知−123,434円・未知12。同じ要求同側98件は+148,641.6円だった。形成・方向・量・枠の変更が交絡しており、ATRの心理仮説だけが失敗したとは結論しない。

同案の未知17件は返済時計不足13・正常板300秒超空白4。直接ATR比0.35も未知16件のうち返済時計不足15。量可用性や原価格時計の不足を「市場が閑散だった」と呼ばない。未来の欠測を知って入口を除くこともしない。

次の197は旧価格条件をそのまま残し、q0の範囲・量補完・方向尺度の一因子対照を行う。旧費用境界と価格ATR比0.0010/11/12の近傍を比較し、最良1点の選択で結論しない。
