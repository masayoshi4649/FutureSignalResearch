# 前週までの実績から選ぶと、翌週の損失は減るか

日経199_02の出口9種類を、各週の始めに完結済みの週だけで選んだ。**過去に「総損失減と収支増」の両方を満たした出口を使っても、次の週に両方を再現したのは1週だけだった。** 全履歴を参照する選び方では6選抜週中1週、直近3週では5選抜週中1週。直近3週の残る1週は該当なしで単純IFDを使った。[週ごとの選択と反例](週ごとの選択.md)

全週参照で収支が44,615円増え、赤字日が2日減った。一方、含み益から赤字になった建玉は29件から30件、そこでの損失は729,233円から733,310円へ増えた。10月21日に反対主シグナルを2回待つR02は単純IFDより総損失を10,000円減らし、10月26日には同じR02で総損失が14,000円増えた。この2日だけで全週参照の費用後収支差の44,692円を占め、残り28日は計−77円。今回の週替わり選抜は、損失の大きさと集中を抑える運用としては保留する。開始30分待機も単純IFDに対する金額差が同額だった。[両待機の利益・損失・取引数](期間別成績.md)

## 入力と条件

2026年9月21日〜11月20日の45デイ。固定入口の日経199_02と各出口はこの期間を使って発案した。週初の計算ではその週以後を外し、未来の週を除いた状態でも同一の選択になることを照合した。9候補・評価窓・順位の決め方は週別成績の計算前に記録した。未使用の日を集めた将来検証はまだない。二つの待機口座も同じ日を使っており、成績が一致した箇所を別標本としては数えない。[選抜条件](選抜条件.md)・[手法と尺度別の設定](設定と結果.md)

09:05／09:15まで新規を待つ。日経225mini換算1枚。ラージの正常な最良気配を用い、手数料片道38.5円、想定滑り片道5pt、往復計1,077円を控除。売買を合算して予約・保有は最大1枚。各入口が定めた値幅を1Rとして±1Rの両注文を維持し、15:30までに返済。建玉単位での保有時間の一律上限は設けない。日ごとに場末で建玉を閉じるため、実際に選ばれた出口の当日口座を連結した。損失欄は費用後赤字の絶対額を合計する。
