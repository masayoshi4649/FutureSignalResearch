# 00082：チャートの現在性と補助確認

2026-11-07。主費用で黒字の案はなかった。 全66既使用場で、チャートの現在の勢い・価格回復・取得位置を主軸に二入口を比較した。出口は81G1を固定し、主と追加価格時計1秒の4会計を別にする。旧70%・125/250先着・待ち50%で棄却しない。

D164_15/P164_06/U165_03は元FAR後期の特徴部品と時計窓の出典であり、元三手法の同値売買列ではない。SourcePortfolio保有を入口に写さず、元FARや80の利益を合算しない。81とも入口の式が異なり、総額差を単一指標の因果効果としない。

## 仮説と固定条件

[81の知見](../00081_定時の現在根拠と部分利益保護/README.md)では部分保護だけで総赤字を解消できず、正益前損失と板の必須既知性が次の問いになった。[事前候補](../../docs/議論/チャートの現在性と補助情報の使い分け.md)を新試行として固定した。

新規は初回を除くDay09:15..15:15、Night17:30..翌05:30の15分枠。NY09:30の前後15分は静観し前窓で返済、場末15:35/05:50に返済要求する。保護は全原行で連続、売り買いは方向符号だけを反転して同条件。

100micro固定・片側100・同時一建玉。保有、未約定新規、返済待ちは占有を保つ。推奨枚数ではなく研究尺度。1枚10円/pt、片道手数料11円＋想定滑り5pt=61円、往復122円。主は判断より後の最初の正常ラージBBO、追加価格時計1秒は別約定列。同約定0/10ptの計算は費用感応に限る。

現在と直前の確定3分足は連続180秒と同一前hist/RSIへの結合を確認する。3/15分の終端は当時以前180/900秒以内。現在Last/BBOは同物理行・自己時計15秒鮮度。未確定足、未来の極値、未知の0埋めは使わない。EMA・RSI・MACDを独立した賛成票へ数えない。

利益保護は両入口で81G1を固定。正益前は入口ATRをceil5・15..125ptへ固定したDで追尾し、3分終値がEMA8反対かつhist増分も反対なら技法失敗返済する。費用後単価益がstrict正なら部分利確を要求し、残玉を最低建値の床で保護する。部分利確が全量約定した後だけ、確定純額Rと残量nから予算床を計算する。未約定益を予算にせず、返済要求を取消・延期しない。

利確量はceil((222Q+1−R)/(u+222))を1..Qへ制限し、完了後の予算床はceil5(max(0,(222+(1−R)/n)/10))。222円は往復122円＋10pt悪化余裕100円で、余裕を費用へ二重加算しない。次板悪化で赤字になる可能性は残る。詳細は[検証計画](検証計画.md)と[全設定・版5の55×9表](設定と結果.md)。
