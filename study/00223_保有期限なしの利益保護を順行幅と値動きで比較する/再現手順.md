# 45デイの元帳と出口比較を再生成する

[222の再現手順](../00222_セッション両端の建玉制限と期限なしIFDを照合する/README.md)で、固定199_02の全要求・板索引・費用後元帳を用意する。環境はリポジトリのPython・NumPyと共通CSV出力器を使用。実出来高は共用原板の各デイの `candle_1min.csv` を参照する。条件やCSV名を変更せず照合する場合は以下をリポジトリ直下で実行する。

```powershell
$trial = (Get-Item 'study/00223*').FullName
$py = 'work/複合テクニカル学習環境/Scripts/python.exe'
$runner = Join-Path $trial '出口を比較する.py'
$groups = [ordered]@{
    '223値幅' = '値幅による保護/出口条件.py'
    '223値幅追試' = '値幅による保護/失速の追試.py'
    '223値幅感度' = '値幅による保護/遅延感度.py'
    '223構造' = '価格構造で保護/出口条件.py'
    '223構造追試' = '価格構造で保護/再度の押し戻し.py'
    '223建値構造' = '価格構造で保護/建値付近で確認する.py'
    '223構造遅延' = '価格構造で保護/広幅追尾の遅延.py'
    '223残存' = '残り時間と値幅/出口条件.py'
    '223反対' = '反対の入口シグナル/出口条件.py'
    '223反対追試' = '反対の入口シグナル/近傍と遅延.py'
}
foreach ($pair in $groups.GetEnumerator()) {
    & $py -X utf8 $runner --定義 (Join-Path $trial $pair.Value) --出力 (Join-Path work $pair.Key)
    if ($LASTEXITCODE -ne 0) { throw $pair.Key }
}
$vol = Join-Path $trial '量を通じた利益保護/出口条件.py'
& $py -X utf8 $runner --定義 $vol --出力 work/223量 --候補 Q00 Q01 Q02 Q03 Q04 Q05 Q06 Q07 Q08
if ($LASTEXITCODE -ne 0) { throw '出来高群の再生失敗' }
& $py -X utf8 $runner --定義 $vol --出力 work/223量追試 --候補 Q09 Q10 Q11 Q12 Q13
if ($LASTEXITCODE -ne 0) { throw '出来高追試の再生失敗' }
$names = @($groups.Keys) + @('223量','223量追試')
$ledgers = $names | ForEach-Object { Join-Path work "$_/比較元帳.json" }
& $py -X utf8 (Join-Path $trial '比較結果をまとめる.py') @ledgers --閲覧 (Join-Path $trial '閲覧候補.json')
if ($LASTEXITCODE -ne 0) { throw '集計失敗' }
& $py -X utf8 (Join-Path $trial '反対の入口シグナル/反対二回を原行順に照合する.py')
```

閲覧用CSVは別の出力先へ再生成できる。日次・期間・建玉の3表を条件ごとに分けて出力する。

```powershell
$deps = Join-Path $env:USERPROFILE '.cache/codex-runtimes/codex-primary-runtime/dependencies/node'
& (Join-Path $deps 'bin/node.exe') 'scripts/損益CSV/候補別に出力する.mjs' --input 'work/223集計/閲覧入力.json' --output 'work/223再生成/CSV' --proof 'work/223再生成/照合' --dependencies $deps
```
