# 利益が乗った後の赤字は、どこで生じたか

2026-11-22。日経199_02の単純IFDで、09:05から入るI20は133件中124件が費用後の含み益を経験し、36件が最終赤字となった。合計損失は907,772円。**その36件の含み益ピークの中央値は6,923円だった。** 0.75Rの大きな順行を待って追尾すると、36件のうち起動しうるのは2件、確定損失38,154円だった。[水準別の件数・方向・日時](診断結果.md)

- **小さな含み益から追尾すると、元の利確にも頻繁に触れる。** I20で0.25R順行した後、費用後同値まで戻した80件のうち52件は、その後、元の利確に達した。0.50R順行後に同じ床を試すと32件中17件、0.75R後でも10件中7件が元利確に戻った。I30の0.50Rの対応は33件中17件。これらは価格経路の件数で、床で約定していた場合の損益とは区別している。
- **初動が速いときは順行が続く例が多かった。** I20で5分以内に0.50Rへ達した19件中17件が元の固定利確で完了。15分を超えて到達した45件には31利確・14場末があり、6件が最終赤字だった。速さと幅、場内の残り時間が異なるので、この件数だけで時間条件を選ぶことはできない。
- **最大の戻しは10月14日の買い。** R400、11:26:06に68,390で取得し、13:30:53に費用後＋16,923円、14:58:20に元損切の−41,077円で確定し、ピークから58,000円低下した。10月26日の買いは元R350に残り10ptまで迫ったものの、10:56:21の＋32,923円から場末の−22,077円へ戻した。前者の観測最大順行は0.45R、後者は約0.97Rであり、同じ起動条件がどちらにも効くとは限らない。
- **損失の集中は幅と期間でも変わる。** I20のR350の73件のうち23件に利益後赤字があり、損失636,771円。I30では同じ幅で24件、672,848円だった。I20全体では前24デイで13件344,001円、後21デイで23件563,771円。二つの開始条件には同じ建玉が多数あり、二つの独立した検証期間としては数えない。

金額はラージの正常気配で日経225mini 1枚を代用し、各取引で往復1,077円を控除。ここでの「同値」は費用込みの建値に当たる買いのBid／売りのAskを指す。取引を終えた後の値動きは含めていない。対象は既使用の2026-09-21〜11-20の45デイで、調査時の `../JP_OSE_Data/future/NK225/` のデイは同じ45日だった。
