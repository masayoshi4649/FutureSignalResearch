## 反対方向の主シグナルを使う

初期の利確と損切は元の±1R。清算側で0.95R順行したら、最大順行から0.80R下、かつ建値より利益側20ptを下限とする保護を必ず起動する。買いと売りは鏡像。さらに保有中に0.25R以上順行し、今も20pt以上の順行があり、最後の有効な主シグナルが2回続けて反対方向なら、そこからの最高順行を0.25Rの幅で追う。2回のうち最新は90秒以内、一つ前は180秒以内。注文価格を不利に緩めない。元の指値・逆指値が先に執行されればその価格注文を優先する。[定義](反対の入口シグナル/仮説.md)・[近傍と遅延](反対の入口シグナル/追試条件.md)

- **10月14日の買い。** 11:26:06に68,390で取得し、ピーク時は費用後＋16,923円。単純IFDは14:58:20に−41,077円で損切りした。R02は14:19:14に＋1,923円で返済し、43,000円改善した。反対に9月28日の売りでは、元の＋38,923円が＋3,923円となり35,000円を手放した。
- **元と同じ133件。** 取り逃した元利確は1件、元の利確群の差は−35,000円。元損切群は＋43,000円、場末群は＋30,000円。総損失は96,231円減、総利益は58,231円減で、収支は38,000円増えた。
- **1枠の口座全体。** 元と同じ133件に8件が加わり、その8件の総利益92,692円、総損失78,308円、収支＋14,384円。後21日の口座全体では総損失が単純IFDより14,077円増えた。30分待機の口座も141件、総利益2,135,762円・総損失1,165,619円・収支970,143円。
- **頑健性。** 2回の反対方向の判定に使う180秒を120秒へ変えると、20分待機の収支差が＋52,384円から−9,385円へ変わった。執行遅延を3・5秒に変えた場合の差はともに＋48,384円。45日間に限った閾値依存がある。
