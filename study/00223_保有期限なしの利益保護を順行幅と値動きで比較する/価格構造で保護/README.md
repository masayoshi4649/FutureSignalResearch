# 押し戻しを見分けるための価格構造と、広い利益保護の比較

20分待機で元利確に到達した76件のうち、確定足の崩れで早く利益床を詰めるS03は18件で先に返済し、元利確の収支を406,000円失った。元損切の3件で79,000円、元場末の10件で67,000円改善したが、元の133取得では差し引き260,000円減った。元取得の総損失は147,462円減った一方、単一口座では取得が133件から158件に増え、総損失が68,000円増えた。元の1Rまで継続する前の安値割れを含むため、今回の1分・5分条件だけでは保護の対象を選び切れなかった。[初回7条件](仮説と条件.md)

短期の安値割れと上位足の下向きだけを使うS01も、局所高値の再試行失敗だけのS02も元取得では減益。順行0.70R、押し0.20R以下、0.35Rまでの再回復を待つS13では、判別を遅くして元利確の収支減を147,000円に縮めた。それでも20分待機の固定取得は102,000円減益。利益が建値付近に消えるところまで待つS22では、元利確15件から457,000円を失った。含み益が一度消えても、実際には元の利確に再到達した建玉がある。[押し・再回復の10条件](再度の押し戻しを待つ条件.md)・[建値での逆行確認7条件](建値へ戻ったときの条件.md)

## 0.90Rから広く守った場合

S00は初期損切・利確を元の±1Rに置き、実返済側で0.90R順行すると必ず追尾を起動する。保護床は建値より利益側20ptと最大順行−0.80Rの有利な方。時間を測った手仕舞いはない。20分の単純IFD133件への適用で返済が変わったのは次の4件だけで、30分待機でも同じ4件が変化した。

|元の取得日|元の理由|単純IFD|S00|費用後差|
|---|---|---:|---:|---:|
|10月2日|場末|＋19,923円|＋4,923円|−15,000円|
|10月7日|損切|−16,077円|＋1,923円|＋18,000円|
|10月26日|場末|−22,077円|＋5,923円|＋28,000円|
|11月5日|利確|＋13,923円|＋923円|−13,000円|

固定取得の総損失は38,154円減、収支は18,000円増えた。単一口座では20・30分待機とも元より4件増の137件となり、総損失は2,077円減、収支は60,692円増、赤字日は1日減。収支改善が生じたのは上記と同じ4日で、改善幅の大きい3日を除くと差は＋923円。追尾により元の取得だけでは収支が減った10月2日と11月5日も、1枚口座では後続の建玉が変わり日計はプラス方向に変わった。

起動水準を0.85Rにすると固定取得は元比−61,000円、0.95Rなら＋13,000円だが1枚口座で総損失が14,000円増えた。元幅350pt以上では0.95R、狭い幅では0.85RのS19は、両待機の口座収支が48,692円増えたものの、改善上位3日を除くと11,077円減。S00の実行遅延を1秒から3秒・5秒に変えると、どちらでも口座改善額は59,692円、総損失減は2,077円、固定取得の収支差は＋17,000円。遅延への感応は小さいが、有効な取引日数は少ない。[両待機の24条件・遅延別成績](全成績.md)

## 再現

試行222の基準口座とその原板入力を準備する。リポジトリ直下のPowerShellで次を実行する。価格・極値・1秒後の動的返済原行は複数モード・条件の重複を含む延べ13,543建玉で検算した。金額はラージBBO、mini1枚の往復1,077円控除後。過去45日はいずれも入口・出口の研究に既使用。

```powershell
$trial = (Get-Item 'study/00223*').FullName
$group = Join-Path $trial '価格構造で保護'
$py = 'work/複合テクニカル学習環境/Scripts/python.exe'
$jobs = [ordered]@{'223構造'='出口条件.py';'223構造追試'='再度の押し戻し.py';'223建値構造'='建値付近で確認する.py';'223構造遅延'='広幅追尾の遅延.py'}
foreach ($item in $jobs.GetEnumerator()) {
    & $py -X utf8 (Join-Path $trial '出口を比較する.py') --定義 (Join-Path $group $item.Value) --出力 (Join-Path work $item.Key)
    if ($LASTEXITCODE -ne 0) { throw $item.Key }
}
& $py -X utf8 (Join-Path $group '構造判断の効果を集計する.py')
& $py -X utf8 (Get-Item 'study/00219*/経路診断/出口の原行を照合する.py').FullName '223構造/全案' '223構造追試/全案' '223建値構造/全案' --出力 'work/223構造/全体原行照合.json'
```
