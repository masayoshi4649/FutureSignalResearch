# 大きな出来高を伴う反転で、含み益を守れるか

2026-11-22。開始20分待機で、下落足だけで早く保護するQ01の収支は162,446円、同じ足に相対出来高1.5倍を要求したQ02は580,371円だった。出来高を伴う場合に絞ると余計な決済が減った。それでも、通常の追尾だけのQ00は1,029,451円、元の単純IFDは968,759円。Q02を同一133建玉で試すと、元なら76件が利確するところ、同じ原行まで残せたのは46件で、元損切から黒字に移せたのは3件だった。[条件](条件.md)・[待機別の全成績と代表日時](全条件の結果.md)

**価格が崩れる足と、その後にもう一度売られる足の両方で出来高を要求すると、20分待機のQ13は142件で利益2,122,454円、損失1,138,388円、収支984,066円。** 元IFDと比べて損失が19,077円減り、赤字日が14日から13日となった。ただし、元と同じ建玉では収支34,000円減、元IFDとの差は前24日で＋30,538円、後21日で−15,231円。全45日でも改善上位3日を外すと差は−74,385円で、日末最大下落は74,693円から78,385円へ拡大した。30分では収支933,066円、元IFDとの差・同一建玉差はいずれも20分と同額。二つの待機には同じ建玉が多い。

**価格と出来高で個々の大きな損失を見抜く例はあった。** 20分待機のQ10は、10月14日11:26の買いで元の−41,077円を＋923円に止めた。同じ条件が10月1日11:40の買いにも作動し、元の＋38,923円を＋923円で返した。Q10の元利確群の損益差は−380,000円で、元損切群の＋103,000円と元場末群の＋102,000円を合わせても補えなかった。総出来高が高いと買い手も売り手も活発で、押し目で買い直す動きにも同じ形が出うる。前後者の識別に約定主導側の内訳は用いていない。

ここでの出来高は `../JP_OSE_Data/future/NK225/<場>/candle_1min.csv` の完備した当分の約定数量。元の当時判断記録で実際に参照できた完成足のうち、前3本も連続・数量有効で公表後の正常板を確認できたのは20分待機で13,851／17,325分、30分で13,403／16,875分だった。売買は鏡像、元の利確・損切幅は固定し、入口ごとの保有期限は設けず15:30までに返済する。45日は既使用期間で、ここで選んだ二段確認の利益保護を新しい日の有力設定とする根拠は得ていない。

## 再現

試行222の元帳と原板索引を用意する。リポジトリ直下のPowerShellから実行する。Q00と同じ設定のS00は[価格構造群](../価格構造で保護/README.md)の手順で作る。Q00の両待機・両モードの取得・返済原行と費用後損益はS00と全件照合する。

```powershell
$python = 'work/複合テクニカル学習環境/Scripts/python.exe'
$study = (Get-Item 'study/00223*').FullName
$policy = Join-Path $study '量を通じた利益保護/出口条件.py'
& $python -X utf8 (Join-Path $study '出口を比較する.py') --定義 $policy --出力 'work/223量' --候補 Q00 Q01 Q02 Q03 Q04 Q05 Q06 Q07 Q08
& $python -X utf8 (Join-Path $study '出口を比較する.py') --定義 $policy --出力 'work/223量追試' --候補 Q09 Q10 Q11 Q12 Q13
& $python -X utf8 (Join-Path $study '量を通じた利益保護/当時の出来高を照合する.py')
& $python -X utf8 (Join-Path $study '量を通じた利益保護/結果を集計する.py')
```
