# 順行のどこで利益を保護するか

日経199_02のデイでは、含み益が費用を超えた瞬間に建値で追尾するP01は、20分待機の単純IFDで利確した76建玉のうち、同じ利確を残したのが3件だった。早い決済で新規枠が何度も空き、133建玉・費用後＋968,759円だった口座が335建玉・−622,795円になった。利益側20ptを床にするP02でも353建玉・−512,181円。床は発注条件であり、その金額での約定を保証しない。[初回12案の条件](条件.md)・[全結果](値幅ごとの結果.md)

0.95R順行まで待つP20では元利確を20分待機で76/76件、30分で75/75件維持した。単純IFDと同じ133取得では総損失が22,077円減り、収支が13,000円増えた。変わったのは10月2日（元の＋19,923円が＋4,923円）と10月26日（−22,077円が＋5,923円）の2件。口座がすぐ次の新規を許すと136取得となり、収支は26,769円増えた一方、総損失は14,000円増えた。保護後の再開方法による違いは[試行224](../../00224_利益保護後の再エントリーをシグナルで待つ/README.md)で比較している。

0.85Rで始めるP06は20分待機の口座で総損失を8,000円減らして収支を21,615円増やしたが、同じ取得だけでは収支が61,000円減り、改善上位3日を除く口座の収支差は−38,154円だった。完成足の失速・収縮・価格構造割れや再試行を追加して0.60〜0.75Rから早める追試でも、元利確を守りながら安定して損失を減らす条件は見つからなかった。[追試の各条件](追試条件.md)・[比較結果](失速の追試結果.md)

追尾発動から返済までの最短遅延を標準1秒から3・5秒に変更しても、P20は全取引収支が同じで、P06の20分待機の対照差は＋22,615円と＋20,615円。初回・追試の標準遅延は入口固定と実口座の両方を合わせて延べ13,030建玉（うち保護返済3,362件）を原行照合した。全て同じ既使用45デイでの比較。日経mini1枚換算、片道38.5円・片道5pt、ラージの正常な最良気配からの約定代用。[遅延感度](返済遅延の結果.md)

再現は試行223の共通再生器へこのフォルダの `出口条件.py`、`失速の追試.py`、`遅延感度.py` を順に渡し、元帳をそれぞれ `work/223値幅`、`work/223値幅追試`、`work/223値幅感度` に出す。各結果は `差を調べる.py --入力 <元帳JSON> --出力名 <値幅ごとの結果／失速の追試結果／返済遅延の結果>` で再計算できる。
