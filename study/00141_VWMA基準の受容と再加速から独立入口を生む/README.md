## 出生に至らなかった理由

[保存Sourceの非金融診断](根拠/原因と次の問い.md)は、受容a1=689→a2=550→再接近j=207→再加速b=7→最初の維持1→出生/取得0を確認した。全689episodeは取消と一対一。V0がないことはVWMAの優位がないという実証ではなく、今回の複合生成/確認/取得条件から評価可能な新取得を作れなかった結果である。

回復bの7件は全て、確定終値自体が固定capを約1.081〜35.746pt超えていた。End+60公表・追加配送遅れだけが原因ではない。6件は最初正常BBOでcap拒否、唯一維持へ入った1件も同秒の次原行で実側気配がcapを超え、1秒維持前に取消された。Lastがcap内でも実Bidが5pt外になる例を分け、同秒原行を1秒に水増ししていない。

確認を待つことで、固定Kから最大20ptの取得上限と再加速済みの現在位置が衝突した可能性がある。ただしcap拡大だけで勝つとは分からず、riskにも落ちる例がある。保存b7件が全て取得できたとしても旧81込み最大88件・約0.122件/時という算術上限で、頻度目標には足りない。これは別の早期取得規則を自然再生した結果でも、将来の全方式の上限でもない。

次の問いは受容a2時点・j後の現在K回復・確定b後を別streamとして比較すること。必要な構造/量の確認も変わるので、単なる公表秒数の調整と呼ばない。本試行のcap・TTL・母集団を後から変えず、次試行へ分ける。Rootが準備する固定T8全成立対照も別試行で、ここへ未実施結果を混ぜない。

## 仮説と旧試行との差

直近20分の量加重基準より上/下を別の2本の終値で受け入れ、その固定帯への再接近を止め、次の1分で再加速する局面を独立に生む。30分EMAの向き、15分DI/ADX、5分MACD位相/増分と値幅、同じ回復足の実体/終値位置/量、現在の実BBO取得位置を組み合わせる。

心理は「量が伴った直近価格帯の外で終値を維持し、戻り試験後も同じ向きへ進むなら、その側の価格受容が続くかもしれない」という仮説。全参加者の平均建値や機関の防衛を観測した意味ではない。VWMAは有限窓の足HLC3×量であり、全約定の真VWAP・セッションVWAPと区別する。量加重・同足量・価格構造を独立した票として掛け合わせない。

[140](../00140_出生時の失敗突破と同足の勢いと量で方向を切り替える/README.md)の固定752への狭い反転補正から、新しい出生と取得を生む独立streamへ研究対象を移す。旧P0全752はunionへ加えず、旧137 A0全81を固定対照C0とする。120/128/129の構造回復や137の知得後維持は参考にするが、VWMA・受容2本・再接近・次足再加速を固定した別仮説である。
