## 選ばれた複合条件

主T8は末端のH完了例数8以上、比較T6は6以上で別々に学習し、同じ木になった。主を結果後に選び直していない。

1. B0向きの30分EMA21増分が0以上。
2. かつB0向きの5分MACDヒストグラム/ATRが0.1以上。
3. 両方ならB0の逆向きへ切り替える。非該当又は必要値未知はB0を維持する。

MAの方向と短期の勢いという2役割を通る。ただしRSI/MACD等の価格由来の指標を独立証拠の票数と数えていない。この木が逆向きを選んだことを、一般的な強いトレンドの反転確認と同一視しない。

事前45条件・4役割から、深さ最大2、異役割のroot/child、`gain−分岐数−反転末端数`で選んだ。body・ヒゲ・終値位置、出生後のspread/遅延、時刻・strategy・日夜・売買別を追加候補にしなかった。[固定仕様](根拠/条件.md)と[候補一覧](根拠/探索範囲.json)へ有限閾値と未知処理を残す。
