## 価格失敗・勢い・数量の役割

価格Pは買い現在L<前20最安Lかつ旧20終値BB20・2σ内のstrict終値、売りは高値更新の鏡像。ヒゲBB外や前C帯外を追加しない。MACDはreset初C原点のC−oへ12/26/9の算術seedEMA、隣接ヒスト差の実方向正を要求する。価格/ATR/MACDは固定29規約をread再用する。

V0は旧R0の数量準備も含む。完全非負当足qとt/k同OBV区間（kは前20極値の最新同値足）を保ち、OBV比較差の値は使わない。V0を量なし基準とせず、V0→V1で固定窓の準備、V1→V2で同じ準備のもと値選別を測る。全原Pは旧時点の採否を準備正本から共有し、大きい旧contextを複製しない。

B20=(U−D)/(U+D+F)は終値上昇/下落/同値へ分類した観測差分量の比。現20変化t−19..tと前t−20..t−1には当場連続22終値/21完全qが必要で、最古終値のqは不要。数量不完全は量窓を切り、有効公開closeは次の比較元へ保持する。完全0量は有効、全0分母は欠測、片側0は±1、同値量だけならB0。価格欠/NP/欠枠/不正と量の解除を分ける。

V2はside×(B現−B前)>0strictだけを追加し、元qのFractionによる分数差分子を使う。0等号不成立、表示floatや任意εを使わず、B優勢/過熱/MFI/OBV値を重ねない。反射でU/D交換・F不変、BとΔBの符号反転を守る。期間20は旧価格/BB尺度との事前仮説で、期間探索の最良値ではない。

ΔBは現在量だけでなく古い方向量の窓落ちや分母変化でも動く。方向比改善を当足量増勢、積極買売、新しい参加人数、純資金流入の実測と呼ばない。価格失敗に逆側の量配分変化が伴えば反転候補となるという心理は仮説で、支持維持や将来継続を直接見たものではない。

## 同時計の取得・費用起動・場内完結

V1/V2は旧Pの同じ公開keyで選別し、次足/指値/35の到達後回復を待たない。純13列と保存label11列は別で、liveへ未来先着や量比パネルを混ぜない。同元イベントの共通仮新規は同時計/同価格/同入口ATR・全先着同値で、保持群の率変化は採用構成の差。30分間引き・期間分割は原要求時計。

取得は旧市場要求+1価格秒以降・有効30秒内の最初正常BBO、買ask/売bid。実は一注文/一建玉で、後続抑止を空き時刻へ延期しない。旧X0は名目5pt起動、XFは現在正常返済BBOのs×(mark−entry)×10−122>0strict（往復fee22＋想定片道5pt往復100）で一度起動する。名目境界12.2pt超、過去MFEだけでは起動しない。

起動後は入口D=max(5,ceil(ATR/5)*5)、max(0,MFE−D)、買ceil/売floor、最低名目新規床・非緩和、返済pending中更新停止。hard125/TP250/期限を継承する。最低名目床は費用後同値や遅延後同値約定を保証しない。

ラージBBOによるmicro1枚代理、倍率10円/pt・呼値5pt・片道11円、返済要求+1秒以降の正常返済BBO。追加0/5/10ptは同約定に対する費用負荷で、起動参照5ptを感度ごとに変えない。デイ入力08:45〜15:40/停止15:25/強制15:35、ナイト17:00〜05:55/停止05:40/強制05:50。正常板300秒超空白等は品質へ残す。

## 限界と再利用

三比較は旧A5→現在起動、準備追加、値追加の順。同じ純入口でも出口変更で実再参加が変わり、準備/値の純subsetでも実追加参加がある。総損失縮小だけを一取引平均や共通出口の改善へ読み替えず、共通出口差＋右のみ額−左のみ額を全費用で分解する。

三入口/四運用は同じ原Pに依存し、標本を合算しない。未準備/値不採用を逆向きに売買した成績ではない。既使用の高率小群や計算一致は未使用確認・将来利益の証明ではなく、閾値や主要条件を変えるなら新試行で固定する。数量基準完全は真の全約定量を保証せず、板数量・建玉残高・資金入出金とも違う。価格時計は受信時計ではなく、実キュー/部分約定/実microの成立は別に確認が必要。
