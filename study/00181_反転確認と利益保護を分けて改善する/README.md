## 仮説・入力・条件

BO反転は即時注文を15/30実分のセットアップ記憶へ変え、実方向の勢い・価格構造・観測出来高・取得位置が回復したq0で発火。MP順行は厳格確認と、EMA乖離・明確な直近価格崩れ・値幅と量/RSI変化の同時スパイクを除く緩やかな確認を比較した。第一版8案は金融未読の純成立点検で厳し過ぎると分かり、元8案を保持して8案を追加し、その16案を封印後に金融を計算した。

出口は費用後50/100/150pt相当で起動し、固定幅50/100/125pt、ATR連動、BB収束とMA/MACDによる複合縮小を比較。元利確指値の維持/撤廃は別ID。起動後は費用後同値以上の床を不利に緩めず、接触後1秒以降の実BBOで返済する。床価格での理想約定ではない。
