# 168 固定複合入口の数量枠による再生

2026-11-15。片側10枚にすると、PRIMARYの到達済み先着率は旧73場69.40%、追加7場68.97%となり、無制限入口の70%超を維持しなかった。一方、全対象場最低1取得と既知差引黒字は維持した。FRONT48は追加7場cap10で既知差引−93,239円。固定幅・入口をこの場で交換せず、[次の数量枠探索](../00169_数量枠の下で技術近傍と任意幅を再探索する/README.md)へ原因と仮説を分ける。

## 仮説・入力・条件

独立入口合算のPRIMARYは旧73で買17/売21、FRONT48は買19/売29の予約ピークがあり、片側10枚の運用とは異なっていた。保有と未決注文を片側枠へ計上し、実際に受けられる取得集合でも方向優位・利益損失・頻度が維持できるかを検証した。

[条件](条件.json)SHA `b8acd5daf5050b16a0d36c74d207db8e60d77a817b6fb62964f08b416c8b1f89`。PRIMARYは166事前主案、FRONT48は166前48場固定選択。主方向・旧T・局所補完と枝幅は変更しない。PRIMARYは順行±200/失速±400/補完±200・H60、FRONT48は±250/±400/±150・H120。各要求mini1枚、買10枚/売10枚を別枠とし、両側同時保有はあり得る。

旧73場は既使用。当時35,339q0・31,642物理caseの固定母集団を使う。追加7場は167の固定入力を共用し、3,608q0・3,250物理case。q0と取得q1を区別し、候補成立や注文要求だけでは取得へ加算しない。

## 費用・先着・未知

mini100円/pt、税込片道38.5円、往復77円＋追加滑り往復1,000円（C5）。実BBOスプレッドも価格へ含む。BUY Ask/SELL Bidで取得し、反対実側BBOで清算する。数量棄却した要求へ手数料は計上しない。取得した各1枚の金額であり、全損益を10倍しない。

IFD_FIRSTは打切り前の最初の既知touchでF/A、両未到達で期限完了ならN、他C。F/(F+A)はN/Cを分母に含めない先着率で、費用後決済勝率とは別物。Nは期限BBOの費用後損益へ算入する。Cは損益0で決済したことにせず、全件収支はnull、既知分の利益・損失と差引だけを示す。金融未知の数量はその場末まで保守的に保持し、価格0の決済を生成しない。

## 検査・限界・再現

純engineの独立人工は固定境界9例、乱数14,400q0・鏡像14,400q0と未来損益毒を確認。自然独立確認は旧73/追加7×二候補×無制限/cap10の8再生、全3,878要求・3,445取得、全11,232統計指標を一致確認した。167の固定出生545,258セル、全26幅対照13,520指標も同じ独立票に含む。168固有の数量確認と167の確認範囲を混同しない。

これは原板を第二parserで全再走査した検証ではなく、固定特徴・生金融NPZからの再計算。実mini板、待ち行列、通信遅延、複数実注文のマッチングは未再現。無制限・cap10・前半選択を同じ「最良」へ混ぜない。幅・保有時間と数量枠の相互作用は別試行へ分ける。
