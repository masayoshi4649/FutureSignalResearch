# 201 板数量の更新尺度を複合入口へ加える

2026-11-18。**板数量の同方向支持を一律に必須とする案は採用しない。** 強い反対板を避ける案には日経で損失軽減の部分効果があるが、赤字場や利益との交換があり、TOPIXへ共通の改善にはならなかった。日経195/199の有望範囲を対照に残し、TOPIXの価格構造と板応答の役割を検証する。

## 仮説と固定した25口座

複数時間軸の価格方向・構造・勢いから生まれる既存入口へ、表示量の支持を重ねる。NK199の00/02/05とTOPIX200のI00/I10へ、追加なし・必要板既知のみ・強い反対板を除外・同方向支持必須・完了4ブロックも逆の場合に除外、の5条件を適用。[金融前カタログ](金融前カタログ.json)と[条件](条件.json)を新しい板条件の金融開封前に固定した。

QI3は上位3段数量不均衡、OFI16/64はL1変化回数尺度、BLOCK4は直前4完了現値時計ブロック内の差分平均。買い正の純値へ実側を掛ける。未知のVETOは元要求を保持し、SUPPORTは不成立。coreを棄却した同q0で別名Tを発火させない。単独の板注文や新たな方向反転は追加していない。

全83場は既使用。単純IFD・幅・期限・費用は親のまま、買売合計保有/予約1、開始待機なし、15:30/05:45まで。mini1枚・NK往復1,077円/TOPIX583.6円（手数料と仮定滑り）。未知は0円とせず枠を場末まで保持する。ラージBBO代用で、miniの実約定を観測した結果ではない。

日経旧基準へVETOを加えると、デイ損失1,236,467→1,190,313円、赤字取引71→69、場末DD111,001→65,231円。全42場取得・保有51.33%・両中央値正を保つが、赤字場11→12。主要な改善は9/29と11/16の取得入替えで、新たな入口単体の利益とはいえない。

199_05へVETOを重ねると損失1,074,543→1,053,466円、収支1,030,988→1,002,219円。利益も減り赤字場が増える。支持必須では日経デイは78〜84取得、夜間78取得・保有15.90%へ減り、夜間の両中央値を満たさない。

TOPIX旧母体のVETOはデイ損失830,610.8→836,110.8円・DD103,204.8→114,621.2円、夜間損失555,020.8→560,520.8円・未知7→8と悪化。SUPPORTはデイ損失を505,266.8円へ減らすが38/42場・両中央値不適合。I10 SUPPORTも夜間損失203,006.4円/DD18,167.2円まで減る一方、29/41場・保有8.52%・両中央値不適合。取引を減らした低損失を目標達成としない。

全25口座の同期間の利益・損失・前48/後25/追加7/最終1/追加2は[安定性正本](全25口座安定性.json.gz)。[全候補CSV](../../outputs/00201_板数量追加の比較/README.md)は125ファイル、各候補の全場を残す。純数量が既知の時点だけ選ぶ効果と数量の符号の効果をKNOWNで区別する。次は押戻しと転換、板尺度と価格背景尺度の違いを調べる。固定条件は結果から変更していない。

板条件は共通でも、元の価格入口は商品間で異なる。この差を指数固有の市場特性へ直結させず、187/188の共通価格入口・同時可用性の対照と合わせて解釈する。[観測尺度](板数量の観測尺度.md)も受信時間や予測可能期間の測定ではない。
