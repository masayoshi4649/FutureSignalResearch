# 212 組合せの効果と限界

[共通・旧のみ・新のみ実取得](実取得差分.json.gz) / [F枝の実取得支持](F枝支持.json.gz) / [親14帯同体](親帯同体確認.json)。実現した取引間の差であり、未参加の仮想利益を機会損失にしていない。

Day/Nightは持ち越さず、限界帯の金融は親と同じになる。一方で累計口座経路は両帯の順序で変わる。7は損失最少でも全口座DD107,342.4円、6は100,426円で、この2案を単一の「最良」へまとめない。

全4主比較の最大DD区間は10/23Nightの頂点→10/29Dayの谷。6と7のこの区間の違いはAにより10/26Nightの旧売り＋6,916.4円がなくなる1件で、新たなF損失が発生した差ではない。7は全期間の損失をより削る一方、この窓では利益取引の見送りが谷を深める。

初期最小−28,501.6円（9/23Night）、最長水面下14場、最大DDからの回復11/4Dayは共通。両帯で別々にDDが減ることから、合算口座の連続損失まで改善したと推定しない。DDは場末既知実現寄与で、未知全件の確定経路や保有中時価DDではない。

A+Fの新F5取得はFのみと同体。NightでF→AFは共通171取得・既知298,789.6円、Fだけ6取得−20,501.6円、AFだけ2取得−12,667.2円となり口座差＋7,834.4円。旧要求の棄却だけでなく枠解放後の取得を含む。AF固有の新F優位を主張しない。

前48/後25のNight F効果−5,000/＋46,416.4円は保守的A対照へ追加しても同じ。全口座の前半改善はDay見送りとの組合せで、F単体の安定性が増した根拠ではない。追加7・本日1・追加2の金融同体は効果を新データで再現した事例に数えない。
