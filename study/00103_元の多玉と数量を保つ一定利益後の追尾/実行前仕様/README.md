# 00103：元の多玉と数量を保つ一定利益後の追尾

2026-11-09採番。**実装・人工確認中、市場損益は未検証。** [102](../00102_定時チャートと一定利益後の可変追尾/README.md)では参加条件を満たしたが全24条件が赤字だった。今回は元Sourceの複数建玉・可変数量・比例返済・出生の履歴を保持し、追加する全玉保護の起動時機だけを比較する。

## 仮説と変更する範囲

元の入口はEMA、ATR、価格帯と再試験、短秒進行、板・二市場支持等の複合状態を持つ。これを支持票の多数決や単一建玉へ置き換えない。旧B5Qの5分受付を保ち、追加全玉保護の起動を小幅正益直後から通常値幅に応じた一定利益へ遅らせると、早すぎる建値往復を減らし、元の収益構造を残せる可能性がある。

| 区分 | 起動条件・管理 | 用途 |
| --- | --- | --- |
| P0 | 現在残玉1枚の費用後益uが正なら起動。最低名目建値＋取得時固定2ATR幅の非緩和追尾 | 旧B5Qと同じ対照 |
| LD05 | uが `100円/pt × max(10pt, 0.5×ATRLock.Value)` 以上なら起動 | 主比較 |
| LD10 | uが `100円/pt × max(10pt, ATRLock.Value)` 以上なら起動 | 主比較 |
| S0・追加全玉保護なし | 元Sourceの返済と元来の部分保護等だけを使う | 時計だけで元利益が残るかの診断。全玉保護義務を満たす候補とは扱わない |

LDの起動後の床・幅はP0と同じ。`ATRLock.Value`は元の公開native ATR12の未丸め値で、102の3分ATR14を持ち込まない。既存の幅は `5×ceil(2×Value/5)` であり、幅の半分をATRの代用品にしない。未知ATRではLDの起動を保留し、後から既知になった最初の適格ATRを既存規則で固定する。初回u正益の観測と保護の起動は別に記録する。

入口の新gate、初参加拒否後の再判定、保護後の同出生再参加、可変幅、手数料回収床の追加を重ねない。これらは次の別因子とする。初期損失側は元Sourceの損失退出・Forceを継承し、新しい損切り幅を加えない。買い・売りの追加保護は同じ方向付き式を使う。

## 固定する時計と参加率

新規は元出生後の最初のstrict次5分枠に一度だけ査定するB5Q。デイ09:15・ナイト17:30以降、セッション開始30分と米国開始30分は新規を見送る。損益保護と元Source返済は定時外も連続して処理する。

主分母は `[Session.Start+1800, Session.ForceClose)` の全予定5分枠。デイ09:15〜15:30の76枠、ナイト17:30〜翌05:45の148枠、54場で**6,048枠**。元のForceは15:35／翌05:50で、この時刻以降の新規不可・持越し防止を維持する。今回は末尾30分の新規除外へ時計を変えない。個別P手法の米国前締切、米国quiet162枠、欠測を全体分母から除かない。

比較用に、開始・末尾30分を除いた通常の**5,832枠**も副表として観測する。これは末尾30分の注文を止める別運転ではない。

主参加の分子は、当枠で受理した新規が同じ`[t,t+300)`で実約定した枠と、grid時点で実保有している枠の和集合。同枠多玉・両建てでも1とする。受理だけの新規、後枠まで遅れた約定を元枠へ戻した新規、実Fill時刻のbucketも別列に残す。Force→grid→同秒rawの位相を守り、未来の約定をgrid直前の保有へ戻さない。最低25%・目標50%は主参加で評価する。

旧B5Qには102の15秒age gateや60秒TTLがない。今回は起動時機を隔離するため移植しない。その代わり要求時気配age・要求から実Fillまでの時間・同枠外Fillを明示し、未約定だけを参加としない。

## 既知の限界と評価

**固定SourceのD07には重複領域で買いを優先する既知の例外が残る。** 本試行はそのSourceを固定した保護の実験であり、自然Source全体が厳密に売買対称な新候補を実現したとは扱わない。方向裁定を直すには別条件でSourceを再実行する必要があり、旧通知の削除やSide反転で新Sourceを作らない。

費用後実現損益、正負額・PF、DD、u正益後／保護起動後の最終赤字と分母、日別・日夜・売買別、参加、約定遅延、枚数を比較する。同じSource出生と同じ実入口の退出差、取得変更、片側実参加額を分ける。未参加や決済後の仮想利益、機会損失、MFE回収率、資本金不明ROIは計算しない。

既使用期間の探索で、未知期間の安定利益は未確認。参加不足でも損切りを遅らせて率を作らない。Sourceの例外、品質、費用、約定、参加、保護義務を満たさずに総黒字だけで達成としない。
