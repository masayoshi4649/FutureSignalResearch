## 何を変え、何が分かったか

旧171デイの好成績には同側保有中の追加302/341件が含まれていた。171入口をglobal1で初めから再生すると、旧37DayのT付きは75取得、先着71.43%、建玉中央値＋6,923円でも場中央値−1,231円で新条件に不適合。旧数量の独立1枚損益を単に足して今回の口座収支にはしない。

旧1460・172新768・新LOCAL152の計442,368設定、三帯1,327,104行を予備評価。新LOCALは長期指標が一度も公表されていない場で、5分のEMA/DI/MACD/RSI・実体・量を使う。独立一枚の予備表から全期と前48を別選択し、単独182・異技術OR等193・Night接合224・三帯接合96政策をglobal1で再生した。

参考の前48J026は全80Dayの主34件が24F/5A/5N・先着82.76%・既知＋455,382円に対し、初参加補完33件は12F/12A/9N・50%・−54,541円。主だけは17/40Day、補完が全場参加に寄与する。高率主と低率補完を混ぜた率低下を、主入口の無効性と同一視しない。Nightは85件すべて主で40/40場。

段階選択の診断では、全期Night接合に両中央値正＋70%以上の8案があるのに次段短表へ残らなかった。4観点の順位を個別に上げても共同条件が保持されるとは限らない。Dayの再生済み単独/ORには共同適合がなかった。[174](../00174_共同条件を残して単一建玉の入口を広げる/README.md)で候補の広さと共同条件の留保を別に改善する。
