## 改善が続かなかった理由

152のA11は、157対照に対して全期で200件の利益伸長（+834,000円）と106件の利益縮小（−766,000円）となった。後25場だけでは伸長13件/+68,000円に対し縮小39件/−275,000円、対応差−207,000円。後半の既知差引はA11−314,786円、157対照−99,863円。**伸ばす価値がある状態と、125/250で確保すべき状態の判別が必要**だった。

早期失効を強くしたA04（SAR/勢い/DI等）は152で522取得に技術退出要求を出した。157対照で非赤字だった260件を赤字へ変え、差分−3,690,000円。一方174件の赤字額軽減は+1,442,000円で、救済だけでは利益破壊を埋められず、全期対応差−2,635,000円。SAR単独の効果ではなく、当該複合政策と早期退出機能の失敗である。

3票以上の持続失効A14も、損失を減らす枝と、本来利益になった玉を早く切る枝が混在した。複数の価格変換指標を集めた票は独立な証拠数ではない。通常押戻しを失効へ誤分類した可能性を、根拠の心理仮説として残す。

厳格なMTF/量/効率によるA15延伸許可は153で実床変更2件、152で28件に限定され、IFD対応差−17,000/−20,000円。『背景が全部そろったら延伸』という一つの人手条件も最適とは言えなかった。159では既定文法内の異役割2条件を過去だけで探索する。
