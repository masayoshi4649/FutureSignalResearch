## 何が作用したか

Aは純67要求/8場→固定監視29→確認7。基準の実取得では10件/6場（1F/5A/4N、−50,086円）で、追加7以後は該当0。主3で変わった取得は基準だけ12件−63,753.2円と、見送り後の別の旧要求7件−40,085.2円。共通202件は同体。口座改善+23,668円には後続枠の変化が含まれ、A群の損益を除外後利益と同一視しない。[原因診断](原因診断.json)に全個票を保存した。

A2の反対側確認は実取得1件−9,083.6円。弱い方向を見送ることと、反対側を取引すれば優位という主張は分ける。30分逆側という背景だけで反対売買を一般化できない。

BはAを除いた純247要求/36場→93監視→別5分冷却38→固定線破断13→確認6。冷却時に源EMA8の同側だった20件は後の跨ぎを待ち、単なる同側滞在を回復と数えない。冷却前期限36、冷却後期限22、欠測17などを[純成立診断](純成立診断.json)へ残す。B成熟確認の実取得は1件+15,666.4円だけで、5の利益増を新枝の一般的優位としない。5は損失をさらに減らすが、主3より赤字場18・取引連敗10・DD102,444.4円が悪く、主を交換しない。

M2は全加速源988→監視272→冷却132（既に線の同側78）→確認25、実取得4件+36,415.6円。口座全体は40/42場に減り、追加Day−19,834.4円。M1の単純MACD減速ANDは建玉中央値−83.6円・場中央値0で不適格。旧の良い押戻しまで一律ANDで削ることは安定改善と同義でない。
