## 時計・実前足・正本

固定122背景5/15/30を118Bankへ配送し、146と同じ1分CSVモデルを使う。1分はEnd+60以後の最初採用Rawで知り、当場・確定・価格既知・closed・隣接p/rだけを使う。初配送time/indexの両方がstrict増加した場合だけ成立。同Raw catch-upを過去準備済みにせず、全背景/利用可能1分を配送してから最新rを一回だけ判定する。p初Context未知を後で補完しない。

BB15は現公表を含む20終値のSMA20±母σ×2。同場欠分で窓を切り、同限月場間は継承/異限月resetする既存定義を保持する。20元公表refsとBB値は公表ID別canonical正本へ一度保存し、ContextはそのIDを参照できる。現在背景freshと、pに固定した歴史の参照を混同しない。

## 構造・取得・再準備

K=p.Open、I=買min(p.Low,r.Low)−10/売max(p.High,r.High)+10をr知得時に初固定する。完成前の仮I監視や持続armは置かない。W=s(K−I)は0<W<=125。p初知ATR5をAとして、cap=min(A,125−W,s(F−K)−125)を固定し、cap<0は不適格とする。

現在Lastと実Pのそれぞれで0<=s(価格−K)<=cap、s(価格−M)>=0、s(F−価格)>=125を要求し、実PからIまで125以内を確認する。p高安突破を待つ方式とは異なる早期の実体回復で、順側バンドは目標到達の保証でも必ず反転する抵抗でもない。r.Closeへ取得を遡らせない。短期TRはp.Closeから直接求めて2*A以内、現在5分TRは実前ATR5の2倍以内とする二尺度の急変ガードも保持する。

出生別Raw+1秒以降の最初正常BBOを買Ask/売Bidで検査し、不適合を後の好位置まで待ち直さない。TTL=min(birth+30,L)、L=min(force_close,End−3900)で等号拒否。pending中も現在背景/実増分/急変ガードと最新1分のknown/closed/fresh、固定Last位置を監視し、古い既知足へfallbackしない。

Raw開始時pendingがあれば、同Rawで取得/取消/失効しても届いた新rは全て抑止・消費する。次のさらに後の新rから再開し、同r再発注をしない。回数cap/毎時強制は置かず、保有や旧C1の未来取得予定をSourceへ渡さない。
