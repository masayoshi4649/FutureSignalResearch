# 試行00002：複数時間足と四系統の要因比較

計画固定日：2026-10-31。損益の計算前に比較条件を固定する。

## 仮説と比較

5分足の方向に沿った短期価格帯突破に、上位足の方向一致（M）、RSI非過熱（R）、観測数量増加（V）、低ボラティリティ（B）を加えると、費用後のセッション損益が改善するか。

四因子のオン・オフ全16通りを比較し、一因子だけ異なる8組ずつの対応差も残す。主評価は銘柄別・同一場の純損益差と無取引を含む場平均。8組は独立した実験8回ではなく、他因子の組み合わせが異なる8文脈である。すべての候補を保存し、最良だけ報告しない。

根拠と心理の説明候補は[議論](../../docs/議論/複合判断の候補と検証方針.md)。非過熱・数量増加・低ボラが利益や継続を保証するとは仮定しない。

## データと評価範囲

- 入力は原板から作る価格時計順の5分足。同時計の原行順を維持する。キャッシュの入力パス、サイズ、展開内容SHA256を `入力台帳.json` へ凍結する。原板とキャッシュの作成コードは共通参照とし、原板を複製しない。
- 探索対象は両指数の2026-09-21_Day〜2026-10-29_Day、各57場。以前に損益を見たため、全期間を再利用した探索と呼ぶ。10/19以降の17場も未使用評価とは呼ばない。前半40場・後半17場の内訳を残す。
- 追加の2026-10-29_Night、10-30_Day、10-30_Nightは、入力監査だけ許可する。この試行の探索中は損益を計算しない。次の少数候補と選択理由を固定した後、一度だけ追加確認に使う。3場という少なさから優位性の確証にはしない。

## 共通の価格条件

- 5分区間はセッション開始08:45/17:00起点の半開区間。次区間の最初の観測で前足の確定を確認する。
- 15分・30分は完全な5分足3本・6本だけを集約する。セッション末の部分足は使わない。同時に閉じる上位足を更新してから5分足の判断を行う。
- EMA20は最初の20本のSMAで初期化。RSI14・ATR14はWilder平滑。RSIの上昇幅・下落幅がともに0なら50とする。
- 同じ限月の過去セッションのEMA・RSI・ATR・正規化ATR履歴を継続する。突破範囲・数量参照・上位足の部分集約は場ごとに初期化。欠けた5分区間・限月変更では全指標を再初期化し、未約定新規を取消す。欠足から遅れて確定した古い足は判断に使わない。保護・期限返済は継続する。
- 共通入口：買いは5分終値が直前6本（今足除外）の最高値を上回り、終値>5分EMA20かつEMA20>前値。売りは反対。足確定の確認が足終了から30価格時計秒を超えた場合、新規発動しない。

## 四つの入口因子

| 因子 | オンの場合に追加する条件 |
| --- | --- |
| M：上位足整合 | 15分・30分の両方で、買いは終値>EMA20かつEMA20>前値。売りは反対。5分条件は全候補に共通 |
| R：非過熱 | 買いは5分・15分のRSI14がともに70未満。売りはともに30超。50基準やRSIの方向条件は加えない |
| V：観測数量増加 | 当足観測数量÷同セッション直前20足の平均観測数量が1.2以上。分母へ今足を含めない |
| B：低ボラ | 当足のATR14/終値が、その前の有効5分足60個の各ATR14/各終値の中央値以下。今足を中央値へ含めない |

16候補すべてに、5/15/30分の必要指標、直前6本の価格範囲、数量20足、正規化ATR60個が揃った共通機会を使う。因子をオフにした候補だけ準備を早めない。数量の制約で各セッション最初の約105分以上は共通入口の対象外となる。

数量は `TradingVolumeTime <= CurrentPriceTime` の非負累積だけを受け入れ、差分を受け入れた価格時計の5分区間へ計上する。未来の数量時計はその行では未使用。初回・累積減少・数量時計後退は基準を更新し、当足は数量基準無効。欠足後も基準を再取得する。当足内の数量時計を一度も観測できない足も無効とし、数量参照履歴を再初期化する。この量は**観測差分量という代理尺度**であり、全約定の厳密な足別出来高ではない。数量基準有効も、通信欠落がない保証ではない。CSVは主計算に使わない。

## 共通の出口・執行・費用

- 通常出口：買い保有中に5分終値<EMA20、売りは反対。突破の有無や入口の共通有効性にかかわらず、EMA値が利用可能なら毎確定5分足で判定する。
- 非常用保護：新規の実際のモデル約定価格から不利側へ2×シグナル足ATR14。実行商品の呼値へ外側に丸め、固定する。買いはBid、売りはAskが保護線へ達した観測で返済要求する。
- 1枚・最大1建玉、追加・両建て・同5分区間の返済後再新規なし。反対の新規発動では旧未約定新規を取消す。
- 約定：ラージのBuy1をBid、Sell1をAskとし、正価格・Bid<Ask・両数量1以上。要求の価格時計から1秒以上後の最初の正常板で、買いAsk・売りBid。これは価格時計を用いた代理モデルであり、受信遅延やmini/microの実板での成立の再現ではない。
- 新規要求の有効30秒。新規停止はデイ15:25/ナイト翌05:40、全返済要求は15:35/翌05:50。15:40/翌05:55以降に架空約定を作らない。期限→保護→通常返済→新規を優先。終了未解消は失敗として記録し、完結した損益へ混ぜない。
- 商品・費用は初回と同じ固定仮定：NK225micro1枚、倍率10円、刻み5、片道11円。TOPIXmini1枚、倍率1000円、刻み0.25、片道41円（公開税込41.8円を1注文1枚で円未満切捨て）。スプレッドは気配価格に含まれるため重複控除しない。
- 費用増ケースは同じ取引経路を固定し、手数料2倍＋片道1実行商品ティックの費用を追加する。違う価格経路で保護を再判定した結果ではない。
- 費用根拠は2026-10-31確認：[eスマート証券](https://kabu.com/item/fop/f_detail.html)、[TOPIX補足](https://kabu.com/item/fop/f_detail/topix.html)。過去の実料金を復元した意味ではない。

## 結果から次へ進む条件

各指数の全候補純損益、費用前、費用増、取引数、勝率、PF、含み込みDD、前後半、時間帯、売買方向、発動許可率を確認する。追加因子で取引経路が変わるため、約定の単純な部分集合とはみなさない。

この探索で最も良かったものを直ちに採用しない。次の試行では、ここで見つかった損失要因または組み合わせの差に対し、少数の改善案と変更理由を新番号で固定して比較する。追加3場はその固定後にのみ開く。全期間で利益が出ても、短期間・多数比較・代理執行の限界があるため実運用へ移さない。
