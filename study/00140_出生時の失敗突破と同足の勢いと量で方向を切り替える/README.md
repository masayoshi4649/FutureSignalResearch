## 規模と原因を分けた結論

既存326順297逆・到達済み623件から70%へ進むには、全て有利な逆→順の変更でも**最低111件**が必要。110件なら436/623=69.984%、111件で437/623=70.144%。未到達を含む分母変化を許す抽象上界でも111件が下限。変更6件の理想上界は332/623=53.29%であり、今回の条件の適用規模では全体70%へ届かない。これは個別結果を順位付けせず、旧総数だけから求めた[算術](検査/独立/方向変更数の上限確認.json)。実際は6件全部が悪化しており、規模不足と判別精度の問題が同時にある。

[当時証拠の作者診断](根拠/反転6件の原因.md)では、6件は4場・5種類の足、全6件でHistのnative符号が維持され、3件は出生時にnativeへ再加速していた。逆側の参考Kに4件未到達、到達した2件も対向端までの参考余地は20/100pt。小さい逆足の減速を元方向全体の反転と扱った可能性がある。旧Rを実再生した因果比較や、これを追加すれば成功するという検証ではない。条件を後から変更しない。

次は低率の752取得を全て残した微修正だけに依存せず、旧81を固定対照にして、独立した技術入口streamを出生から検証する。VWAPや価格帯の受容/拒否は予備調査中で、次試行の条件・採番・自然結果はまだない。全場min1・同幅到達済み70%・平均概ね1件/時を維持し、結果後の除外や目標縮小はしない。
