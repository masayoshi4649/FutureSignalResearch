```powershell
python -X utf8 'study/00167_固定した複合入口を追加七場へ適用する/再現資料/正式入力から再現する.py' --verify-only
python -X utf8 'study/00167_固定した複合入口を追加七場へ適用する/再現資料/正式入力から再現する.py' --destination 'work/167任意の再現先' --replay
```

## 原板からの再生成

重い原板再解析は通常の閲覧・政策再集計に不要。実行する場合は、固定された [空取得入力](../../inputs/00167_追加七場の入口と共用価格索引/索引前の空取得入力.json) のRaw path/SHA/statと、母集団接続計画のCSV/前史を先に検査する。追加7場の入力選択はgzip優先・無い場のみ生JSONLで、初回二形式停止と訂正も恒久入力へ保持した。

旧73前史は122計画のCSVを予定Endまで正規に再生し、BB/RVOLは当時実公表を別再生する。私有Seedを保存SeedInfoから作らない。旧122の177MB派生公表を新たに複製せず、必要なら [122の復元](../00122_E0固定条件を全セッションで検証する/再現資料/再現手順.md) に従う。

順序は、空取得のRaw索引→停止済bridgeでq0/100X/q1→非金融出生の封印→同じ索引で純観測→数値adapter。各CLIへ固定SHAと未作成先を渡す。元の全件成功後のファイルへ再実行せず、CRC/SHA/前後statとSource不変を確認する。q1は原行の実Bid/Askへ全数値照合する。受理数・品質の事前期待は未指定だったため、実測を「事前期待照合済み」と呼ばない。
