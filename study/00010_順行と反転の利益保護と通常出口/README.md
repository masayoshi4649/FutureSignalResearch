## この比較で確認したこと

R01の20→10pt床は条件選択で黒字38/54=70.37%だったが、基準純損益は-4,788円、追加5pt後は-10,188円。黒字取引率70%超は入口の125/250pt先着率70%ではなく、利益の大きさと損失・費用を無視した採用根拠にしない。

同じR01_X00との共通実新規39件では、赤字→黒字を14件救い、黒字→赤字が2件あった。一方、元が黒字だった共通新規の純額は合計-34,900円変化し、共通新規全体の純額差は-12,000円だった。元のみ1件・変更のみ15件も生じ、全体差-13,108円のうち集合差の純額は-1,108円。救済件数が増えても、元の大きな黒字の取り分と追加参加の結果を合わせると純損益が悪化した、というこの条件の観測である。

同床の未起動10件は純額-13,020円、起動済44件は8,232円だった。床を起動する前の損失は、起動後の小幅利益だけでは埋まらなかった。未起動損益は初期SLだけの内訳ではない。また追加費用は取引数に比例するため、同じ入口でも早期返済による再参加増加を含めて確認する。
