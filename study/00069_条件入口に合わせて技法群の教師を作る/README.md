## 固定した判断・条件発動・利益保護

デイ09:15〜15:15の25枠、ナイト17:30〜05:30の49枠。定時の60特徴から両方向を同じ関数で評価し、同点・片側score未知はWAIT。両側のscore>=1/3・filled支持・複数技法・回収支持を先に評価し適格内最高側。I1/C1だけ主回収strict正も要求するため、0と1を同方向の部分集合とは断定しない。raw DI0は最終WAIT。

最新公開完全3分足high/lowを定時凍結。買Last>high／売Last<lowで要求し、設定既超過は拒否。買Last<=low／売Last>=highは発動前否定。設定否定は未登録WAIT、監視後前提否定は登録未約定で、否定自体は品質注意でない。normal BBO＋有限正Lastで監視、gap>300秒の観測不足を優先。否定後の同枠復活・自動逆注文はなく、発動後pendingや保有へこの否定を追加しない。

次定時T+900 timerでwatchと新規pendingを取消。発動後1価格時計秒・後行正常BBO・TTL30秒も次定時未満。Lastや過去線価格へ約定を戻さず、足内順をOHLCから補わない。途中の新指標で候補やDを更新しない。

主待ち=WAIT/全予定、保守=(WAIT＋判定不能＋条件登録後entryなし)/全予定で50%以下。保有は非待ち。候補・登録・発動・仮約定・実新規・完結は別分母。micro10円/pt、片道11円＋滑り5ptの往復122円。現在正常返済BBOの粗益−122円strict正で利益旗と最低名目新規床。Dは定時ATRの5pt切上げを5..125へ制限し、損失側も連続非緩和。返済pendingでh/L/arm凍結。強制15:35/05:50、終了15:40/05:55、残60停止なし・固定250TPなし。費用0/10感応は同約定・利益旗122円不変。名目保護線は実損や費用後同値の保証でない。
