# 117：入口方向と利益消失を分けた追加診断

2026-11-10。ユーザーの二つの問いに対する説明を追補した。新しい売買条件の探索や金融再実行は行わず、研究の一旦停止は維持する。元の117条件・結果・停止記録は変更していない。

## 入口はどちらに動いたか

[入口診断](入口診断.md)に全14幅の先着表と3種類の基準を記した。元S0・C0D0の既使用70場558実新規が対象。実建値EからLastが順逆同幅へ先に到達した件数は、50ptで順218・逆273、75ptで順223・逆206、125ptで順189・逆96、250ptで順117・逆12だった。調べた幅では50pt以下で逆行先着が多く、75pt以上で順行先着が多かった。

「一度でも同幅まで動いたか」も分ける。両方向へ到達した玉は両欄に入るため、これは先着や勝敗とは異なる。

方向が全面的に逆だったとは言えない一方、小幅な値動きに対する実取得位置には不利があった。取得時Lastを基準にした10pt先着は順321・逆234であるのに対し、実建値基準では順65・逆491だった。符号付きの建値と取得時Lastの差は中央値10pt、383件が10pt不利だった。Lastと気配の差を単独の予測失敗や、約定後の滑りと同一視しない。正常返済BBO基準では75ptが順201・逆246、100ptが順200・逆182で、実際の返済側でも短い幅は不利だった。

観測は新規原行の次から元S0の最終決済Rawまでで、全玉に同じ保有時間を課した検証ではない。大幅の逆行へ届く前に損切りされる玉があり、大幅側ほど右打切りの影響を受ける。125ptでは273件、250ptでは429件が両方未到達。到達者だけの66.3%・90.7%を全558件の勝率や独立した入口予測力へ読み替えない。決済後の価格や仮想利益は使っていない。

全70原板のSHA、限月、全採用数、新規・最終返済原行を照合し、保存された23,436先着符号と19,713到達点を別集計で確認した。[独立集計](入口の独立集計.json)と[入力来歴](入力来歴の追補.json)を参照する。

## 保有中利益を最も失った玉

[利益消失の詳細](利益消失.md)。片道手数料38.5円・片道追加滑り5pt・追加遅延0秒の標準条件で、元S0/W100/P100の最大減少は11/06 09:45:36の売り7枚。10:25:07の費用後最大評価益552,461円から、10:34:54の最終実現13,461円へ、539,000円減った。全20費用・遅延条件を含めると、同出生の遅延1秒条件で最大546,000円。

P100は起動済みだったが、固定5分ATR12=514.156347ptから通常追尾幅が1,030ptとなっていた。最大順行800ptでも峰−幅が最低床20ptを上回らず、複合狭幅も未成立だった。最終の発注後にはむしろ7,000円有利に約定しており、大きな減少は要求前の値戻りが主因。内側Sourceの元返済理由は保存時に正規化されているため、どの内側分岐が最後の返済を出したかまでは未同定。

費用後正益から最終赤字へ変わった最大例は、11/04 10:25:25の買い9枚。標準C5D0では10:26:04の8,307円から10:30:06の−333,693円へ342,000円減った。旧H100の起動基準はこの9枚で90,000円だったため未起動。この例と、起動済みでも幅が広かった11/06例は別の問題である。

同11/06出生の新H0E/H0Mは、実保有中の最大13,461円から09:45:47に−539円で閉じており、減少14,000円。保有していなかった後の10:25価格は新H0の極値に加えない。早期保護が全体の収益を改善したとは結論しない。

新H0M自体の標準C5D0での最大減少は別の玉だった。10/09 09:39:27の売り6枚@68680で、3枚を部分返済後、10:11:32の全玉W146,538円から10:27:18の最終80,538円へ66,000円減った。通常幅425ptに対し残玉の最大順行は300ptで、通常追尾の峰差床はまだ最低床より下だった。短期複合条件で幅50ptへ縮めた時点では、残3枚の順行が既に90ptまで戻っていた。ピークから要求まで210pt×3枚×100円＝63,000円、次原行でさらに10pt逆行して3,000円、計66,000円の減少。後から算出した保護価格68430で過去に約定したことにはせず、実Ask68600で決済した。幅縮小が発生しても、その判定以前の戻りは保全できなかった例である。

最大評価は、その瞬間の全額決済を保証する額ではない。今回の金額は、実保有中に保存した全玉の費用後評価W（部分返済Rを含む）と最終実現額との差である。原板から最大Wを第二の実装で再計算した検査ではない。
