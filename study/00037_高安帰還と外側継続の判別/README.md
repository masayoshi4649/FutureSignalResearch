全入口は同じ旧Pに依存し、同元P/同新規を独立標本として重複加算しない。少数の高率や計算一致、既使用66場の差は未使用確認や将来利益の証明ではない。事後の位置/勢い/抑止/利益保護群を新しい採否へ戻さず、主要条件や閾値を変えるなら別試行で固定する。
