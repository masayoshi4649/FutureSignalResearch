# 157：固定入口の到達距離と追尾退出を比較する

2026-11-12。全73場・153 U15全93件/152 U0全831件の固定入口で、到達距離と12出口を比較した。**153は±125ptの単純IFD対照を安定して上回る出口が見つからず、152は「+125で幅100追尾＋TP250」が次の比較候補となった。** 初期からの125幅追尾と、一律の費用後正益即建値保護は、今回の両入口でIFD対応差分が悪化した。

## 仮説

±125ptの先着率だけでは、250ptまで保持する出口や追尾の良否は決まらない。+125到達後に建値や逐次峰から100pt戻る前に250ptへ進む頻度を調べれば、固定利確と追尾の使い分けを検討できる。最初から125pt幅の追尾と、125pt順行後に100pt幅で起動する追尾は、起動前の損失も含めて比較する必要がある。

## 固定条件

[実行条件](実行条件.md)を結果を見る前に固定した。153 U15の93件、152 U0の831件、全73場をそのまま使う。共通87を含む837物理caseを共有し、政策への所属は924。入口や方向を出口成績で入れ替えない。

H60とセッション末までの2期限、12出口政策、即時約定の理想化D0と1秒以上後の後原行約定D1を比較する。主費用C5はmini1枚あたり往復1,077円（手数料77円＋追加滑り1,000円）、C0は77円。ラージ板のBBOを約定代用に用いるためminiの流動性を直接実証するものではない。

## 125ptから250ptへ、どの程度進んだか

下表の起点は、取得から−125へ達する前に清算側BBOで+125へ達した例。H60は取得後60分（場末の既定清算時刻が先ならそこで終了）。起点から60分延長していない。先着数/起点全数で示し、期限まで両方へ未到達・観測不足も分母へ残す。

|入口・期限|125起点数|−125へ戻る前に250|建値0へ戻る前に250|峰−100へ戻る前に250|
|---|---:|---:|---:|---:|
|153 U15・H60|48|18/48＝37.50%|15/48＝31.25%|13/48＝27.08%|
|152 U0・H60|453|246/453＝54.30%|227/453＝50.11%|148/453＝32.67%|

H60の峰−100について、153は13目標先着・30追尾先着・5期限未到達・0不足、152は148目標先着・293追尾先着・8期限未到達・4不足。先着が決まった例だけを分母にすると30.23%/33.56%になるが、これを起点全数の確率と取り違えない。

下側を初期−125にすると、+125から見た許容下落は250pt、上昇目標まで125ptとなる。建値0、峰−100とは別のリスク条件である。「125を超えれば250へ届く」を一つの率で表すのは不適切だった。

無保護経路ではH60中に250ptへ届いたのは153が22/93、152が291/831。これは途中の損切りや追尾を無視した価格診断であり、そのまま利益にできる率ではない。25〜500ptの12幅、125起点2種・目標250/300/375/500・下側3種はCSVへ全件を残した。

## 利益保護と損切りの判断

**一律に早く狭くすれば改善する、という結果ではなかった。** H60/D1で初期SLを125から75/100へ狭めたIFD対応差分は、153が−181,000/−68,000円、152が−1,778,000/−1,307,000円。初期から幅125追尾も悪化した。通常の押戻しを途中退出させる影響がある、という市場心理上の仮説は整合するが、原因をその仮説だけへ断定しない。

費用後W>0で建値床0を置くE0W125は、H60/D1で153が利益60,922円/損失179,467円/差引−118,545円、152が1,172,145円/2,381,592円/−1,209,447円。損失総額は減るが、利益の減少がそれを上回った。正益後の赤字件数も、微小益から費用負けで閉じる例を含むので、件数だけを改善指標にしない。

+125で幅100追尾を起動すると、初回線は最低でも粗益+25ptとなる。理想的に同線で閉じればC5後+1,423円だが、価格飛越や遅延で同価格は保証されない。今回H60/D1では、この2政策の**125到達後の費用後赤字は両入口とも0件**。ただし125到達前の小幅正益から失敗した赤字は、153が23件、152が182件残る。起動後の幅だけを調整しても、その群の損失は減らない。

損切りも250へ広げる固定対照F250S250は、152のH60/D1既知差引3,490,554円と大きかったが、125到達後赤字93件が残り、後25場は−409,863円、金額未知33。利益保護を伴わない固定対照を、そのまま実運用候補へ昇格しない。

## 標本数と安定性

153は93取得・先着確定64、152は831取得・先着確定722。少数の153にまぐれの懸念が残ること、152には多数を検査できる価値があることの両方を認める。ただし152は上位5場に401/831＝48.26%が集中し、153は13/93＝13.98%。共通87取得を持つため、両入口を独立な比較標本とも扱わない。

旧H60/±125先着率を73場単位で再標本化した95%参考区間は、153が60.94〜82.26%、152が50.17〜71.51%。152の名目件数が約9倍でも、場内相関を考慮すると推定の幅は単純には9倍分だけ縮まらない。一場除外時の率は153が70.97〜73.02%、152が56.84〜63.94%。153の高さが特定一場だけで生じたわけではないが、既使用データへの多数回の探索による選択バイアスはこの検査で解決しない。

152のTP250付き追尾はH60/D1のIFD対応差分が前48場+195,000円、後25場+254,000円だった。しかし後25場の既知差引は−99,863円（IFD−341,940円）、場末では−135,940円（IFD−383,017円）で赤字が残る。対応既知788件/未知43件について場単位再標本化した差分の95%参考区間も−177,000〜+1,104,000円で0をまたぐ。**改善候補は得たが、安定黒字・有意改善の確定とはしない。**

## 次の仮説

153の入口優位を、そのまま250pt以上の継続優位と見なさない。152はTP250付き100幅追尾を固定対照にし、125到達前に根拠が失効する群と、通常の押戻しを区別する技術管理を次試行で比較する。価格構造の再割れ、ATR/BBに対する通常揺れ、勢い/量の失速などを当時情報で組み合わせ、一定利益後の必須保護と線の非緩和を維持する。結果を見た後の分類を現157へ遡及適用しない。

## 読み方と限界

まず全窓の到達距離、次に125到達後の条件付き先着、最後に同じ入口へ出口を適用した費用後の利益総額・損失総額・差引を見る。無保護の価格経路と実退出までの保有経路を分け、退出後の順行を実利益や機会損失へ算入しない。

独立mini1枚ずつの比較であり、重複保有を含む合算は片側10枚上限の実口座成績ではない。前48場/後25場はいずれも既知データであり、未使用データによる運用確認ではない。観測不足と未約定を0円へ変えない。長期保有ほど欠測の影響を受け、全窓不足はH60の153＝7/152＝31に対し、場末では22/114。既知の早期決済は、その後の欠測で未知へ戻さない。

到達距離のMFE/MAE/OHLCは取得より後・正常BBOがある原行・期限未満だけで、MAEは0基準かつ取得spreadを除く。出口結果のMAEは取得spreadを含み、Last OHLCは取得行Openから不正常BBO行のLastも含む実保有区間。両方に到達原行/時刻を保存するが、異なる範囲の高安を同じ指標として比較しない。
