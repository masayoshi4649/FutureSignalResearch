# 00119：技術領域の出生と確認後再試験で入口を比較する

2026-11-10。118の次の仮説変更として新規採番。条件・コードを事前固定して既使用70場を実行し、345領域出生・1,035役割別候補を比較した。実行前原文は[README](実行前原文/README.md)と[設定表](実行前原文/設定と結果.md)へ同bytesで保持する。

## 得られた結果

6候補×30/60分×5幅の60条件すべてで、同幅先着70%へ届かなかった。順行の確認後成行は60分C5平均＋1,244.43円だったが、±100ptは順9/逆19（32.14%）、中央値−3,577円、完了28例。同じ出生のzone役と双方完了した22組では、確認後の平均評価が8,727.27円悪かった。平均が一部黒字でも入口精度を達成したとは言えず、119は未採用。

確認イベントまでの時間は順行中央値715.5秒・反転1,215秒。接触時から確認時までのLast順行幅は両方中央値100ptだった。5分足の奪還確認で既に動いていたことを記録したが、確認を早めれば改善するという因果効果までは未証明。[結果と限界](結果と限界.md)に全12条件・同出生比較と分母を記す。

## 変えるものと比較

118では200pt指値の約定後も逆行が多く、テクニカルの確認成立とSource価格からの50pt有利条件も噛み合わなかった。119は元Sourceの通知時刻・方向・価格から独立して候補を生む。同じ技術領域への接触を出生とし、次の6政策を比べる。これは固定5分の新規強制や、Source全558への後付け選別ではない。

|政策|出生と新規|
|---|---|
|Ttrend_zone|順行背景の押戻し帯へ初接触後の現在価格|
|Ttrend_confirm|同接触後、構造・勢い・量の確認後の現在価格|
|Ttrend_retest|同じ確認で使った5分高安の再試験指値|
|Treversal_zone|弱い/失速背景の過熱帯へ初接触後の現在価格|
|Treversal_confirm|同接触後、構造奪還・勢い回復・量の確認後の現在価格|
|Treversal_retest|同じ確認で使った5分高安の再試験指値|

売買は符号反転した同条件。1つの領域接触に3候補を対応させる。確認成立群だけと全領域群を無条件に比べず、同じ出生で両方成立し評価が完了した組の対照を別に残す。再試験が来ない場合に仮の利益を与えない。

入口精度の改善を優先し、固定30/60分の同一幅±25/50/100/125/200pt先着で順行70%以上を目指す。幅ごとに解決済み先着率（順行÷順逆合計）と全評価完了中の順行率を併記し、未到達・観測不足も示す。少数例・既知70場の成績は未知場の再現性を証明しない。IFD型の利確・損切りで継続利益を目指す次段階へつなぐが、119は先着診断であり、その注文再生は未実行。費用77/1077円もあるため、70%だけで利益を証明しない。

## 技術・候補寿命

30分EMA配置と傾き、15分DI/ADX、5分EMA21とATR帯を順行側へ使う。反転側は30分ADX≤25又は低下、15分BB20±2母σとRSI過熱を使う。接触後の5分高安strict奪還、MACD/RSI、TR/前ATR、相対出来高による確認は118純条件を同bytes再用する。前史数値だけを同限月carryし、当場最新・fresh・公表配送済みを要求する。

各枝×買売の4状態で原行監視する。背景と領域が真の初回接触で出生、30分未満に確認する。背景が既知偽なら未約定を取消し、未知なら保留する。領域内が続く間は再出生せず、領域を離れた新5分公表を確認後、次の原行から再接触を受け付ける。失効/確認原行で同じ波を即座に作り直さない。

発生器はSource.force_close以後の領域イベントも保存し、同出生3役の記録を作るが注文しない。全出生数と、出生時点で新規可能な数（各候補のExpires>Born.Time）を分ける。先着率の分母は約定後の観測完了群とし、全出生・新規可能・約定・観測不足の件数も併記する。

領域時の成行代用は出生から30秒未満。確認成行は接触から30分・確認から30秒の早い方まで。再試験指値は接触から30分・確認から5分の早い方まで。いずれも要求より後Rawかつ価格時計1秒以上、正常BBOだけを使う。指値は買いを確認5分高値の5pt切下げ、売りを5分安値の5pt切上げへ固定し、反対側BBOが10pt通過した場合に指値価格で約定代用する。原Source価格から50/200pt有利というcapは追加しない。

未約定注文は確認後も背景の既知否定で取消し、未知なら執行保留。再試験中に高安突破そのものまで再要求すると戻りを受けられないため、価格確認イベントと背景の維持を分ける。既約定の評価を旧損切り時刻で打ち切らない。

## 評価と限界

新規単独の1mini試験、30/60分、順逆25/50/100/125/200ptの先着と期限清算評価を別にする。正常返済BBO、往復手数料77円、往復滑りストレス0/10ptを費用化。1枚100円/pt。Raw又は正常BBOが300秒超空いた場合、場末、期限後30秒以内の正常気配なしは観測不足。未約定や打切りを0円へ置かない。

期限に達した最初の正常Rawが評価終端で、同じ価格時計秒でも後の原行は含めない。endpointが期限後に遅れた場合、先着は元期限まで、清算評価は保存した実endpointを使う。重複する独立試験を片側10枚の運用口座収支として合計しない。運用では可変枚数・利益追尾・実約定返送を別に検証する。

入力は既使用70場の同じ原板・115確定公表で、118入力の価格/公表/場metadataだけを再用する。入力にあるSource signals/cancellationsは119の出生へ使用しない。11/09の価格・損益・入力指紋は未読を維持する。未知テストではなく、118結果を踏まえた探索である。
