## 仮説と根拠

132の関連診断では、既存T8に残った18逆行のうち期限補完deadlineに11が集中していた。E0は7順1逆で到達済み87.5%だが9取得中の到達済み8だけ、通常trendは16順6逆で72.7%、deadlineは15順11逆で57.7%だった。これは既使用の旧取得集合から分けた小標本で、133の新成績や未知期の成功ではない。[型別の根拠](../00132_E0の構造回復を保護して他入口へT8を使う/根拠/入口型の追補/結果と型の由来.md)、[次の問い](../../docs/議論/E0保護の方向同体と期限補完に残る逆行.md)。

仮説は「時刻の経過だけを理由に確認を弱めず、失敗突破の回復や継続の確認を待てば、期限補完より良い入口が見つかる場がある」。心理的には、価格が旧領域を回復した、又は複数時間軸の方向に勢い/量が伴ったという確認と、単に開始から3時間経ったことは異なる。参加者の意思を観測した証拠や、長く待てば70%になる保証ではない。全場参加のための期限補完を残し、遅い取得の観測不足も明示する。

## 継承する複合テクニカル

E0は121C0由来の1分失敗突破回復に、15分BB端/RSI極端と30分ADXの既知低下を重ねる。1分の形状・TR、自然否定距離、cap→hold→riskを維持し、量を新しく必須にしない。詳しくは[122固定E0の実行前仕様](../00122_E0固定条件を全セッションで検証する/実行前原文/README.md)を参照する。

通常順行は5分のMA並び/両傾き/DIが既知同向、既知15/30分方向が反対でないこと、RSI側中心0〜20、HistとM/Pの同向、絶対score≥0.5、TR≤2前ATR、既知RVOL≥1を要求する。通常反転は5分の直前連続3本領域の失敗突破→内側5pt回復とLast維持、前RSIの側中心≤−15、RSI/Hist増分正、ADX5既知低下、同じTR/量を要求する。1分E0と5分反転を混同しない。

要求後の別原行・価格時計1秒以上後・30秒TTL未満・共通取得限界未満の最初の正常BBOを取得代用とする。要求時の型・方向・当時票を固定し、fill後の価格や将来結果で方向を選ばない。旧公表時計を維持し、後から確定した足を前倒ししない。
