# 試行00004：逆行200ptと順行400ptの入口分析

計画固定日：2026-11-01。到達ラベルを計算する前に固定する。ユーザー指定に従いNK225のみを対象とし、ptは指数価格1円を指す。

## 何を評価するか

入口後、**逆行200pt以上が観測されるより先に、順行400pt以上へ到達するか**を調べる。成功条件は到達までの最大逆行が200pt未満であること。＋400へ到達した後の逆行は成功を取り消さない。200/400を最適化せず固定する。

本試行は入口の経路分析であり、通常決済や追尾の損益を最適化しない。各時点・売買方向の候補を仮想的に独立評価するため、同じ時間の保有が重なる。件数を独立な取引回数や実運用のPF・資金効率へ読み替えない。

## 入力と探索の境界

対象は2026-09-21_Day〜2026-10-30_Night、NK225の60場。全て前試行で既に使用した再利用探索であり、未見の評価期間はない。前半40場・後半17場・既使用末尾3場を別表示し、結果の変動を記述する。

00002の固定入力台帳をSHA256付きで参照する。元原板サイズ・更新日時、キャッシュSHAを検査し、キャッシュの原行順を維持。同価格時計の異なる状態を省略しない。原板の複製は行わない。

## エントリー候補と共通準備

5分足は場の開始08:45/17:00を起点とする半開区間。次区間の最初の観測で確定を確認する。完全な5分足3本・6本だけで15分・30分を作り、同時確定の上位足を更新してから入口を考える。前試行のEMA20、Wilder RSI14・ATR14を同じ初期化で継承する。

同限月の指標履歴とATR比履歴は場をまたぐ。場内の直前6本・上位足部分集約・前5分の条件比較・数量参照は場ごとに消去する。15分・30分は当セッションに完全足が一つ以上確定し、前5分時点でも当場の上位足を利用できることを全群の共通準備にする。欠5分枠または限月変更で全指標を再初期化し、古い足を遅れて新規発動に使わない。

共通準備は直前6本の同場足、5/15/30分EMAの現値と前値、RSI、ATR、当足と前足時点でそれ以前60足のATR/close中央値が計算できること。数量の直前20本は共通準備にせず、数量が十分にない場面も価格だけの比較へ残す。数量比・RSIは今回許可条件に加えず、診断用に固定して記録する。

以下6群を事前に固定する。同じ買い・売りイベントのラベルは一度だけ生成し、適合した群で共用する。

| 群 | 入口条件 |
| --- | --- |
| 無条件両方向 | 共通準備済みの各5分確定時点に、買いと売りを別々に評価する対照 |
| 5分方向 | 買いは5分終値>EMA20かつEMA20>前値。売りは反対 |
| 複数足整合 | 5・15・30分全てで上記の方向が一致 |
| 整合突破 | 複数足整合に加え、買いは当足を除く直前6本の最高値を終値で厳密に突破。売りは最安値を厳密に突破 |
| 押し戻り復帰 | 15・30分の方向が前5分時点・現時点とも買い側で維持され、前5分終値<=前EMA20から今終値>今EMA20へ復帰。売りは反対。未来の押し安値や山谷を使わない |
| 収縮拡大突破 | 整合突破に加え、前足のATR14/closeが前足時点でそれ以前60足の同率中央値以下、当足TRが前足ATR14より大きい。現在の低ATRと区別する |

候補を足終了時点の価格で都合よく約定させない。確認が足終了から30価格時計秒を超えた候補は未約定として別出しする。新規要求から1価格時計秒以上後の最初の正常なラージBBOで、買いAsk・売りBidを仮新規価格とする。有効期限は要求から30秒、新規は15:25/翌05:40未満のみ。数量1以上・正価格・Bid<Askを要求する。

## 到達順の判定

評価期限はデイ15:35、ナイト翌05:50。持越しはしない。期限ちょうどの正常板は含め、期限より後の価格は到達判定に使わない。

- **順行先着**：買いはBid>=新規Ask+400、売りはAsk<=新規Bid−400が逆行線より先。
- **逆行先着**：買いはBid<=新規Ask−200、売りはAsk>=新規Bid+200が順行線より先。
- **期限未達**：期限まで上のどちらも観測されず、観測範囲が期限を覆い、正常板の300秒超空白もない。
- **観測不足**：未確定の経路を追っている間に正常板価格時計が300秒超空いた、または入力が期限前に終わった。次の板が閾値へ飛び越えていても空白を優先して不明とする。期限後に次の板があっても、期限までに直前板から300秒超となる場合は不明。
- **未約定**：確認遅延、30秒以内の正常板不足、新規停止時刻等で仮新規が成立しない。約定後の期限未達と混ぜない。

新規したその板も距離観測へ含める。スプレッドだけで200pt以上不利なら即逆行先着。等号は200・400とも到達とし、同時計では原板物理行順を使う。確定した先着ラベルは将来変更しない。

「観測不足」は通信断の証明ではなく、独立した受信時計がない価格時計モデルでの品質打切りである。閾値に達しない小さな観測間隔にも未観測の値動きはあり得るため、保存BBOでの先着であって全約定経路の保証ではない。

## 集計と診断

主に件数、順行先着/全約定候補（観測不足も分母に含む確認割合）、順行先着/判定可能候補（順行＋逆行＋期限）を併記する。順行/(順行＋逆行)は参考にとどめる。期限や不明を落として良い入口と結論しない。売買別・場別・前後期間と発生場数を残す。

事前固定の層別は、残り時間<60/60〜180/180分以上、400/ATR<=2/2〜4/4〜8/8超、方向側RSI（売りは100−RSI）<50/50〜70/70以上、数量比不足/1未満/1〜1.2/1.2以上、デイ/ナイト。この結果を見て条件や閾値を同試行で作り直さない。

方向選択の参考として、各候補と**同じ時刻の反対方向イベント**も対応させる。自分の順行先着確認割合と、同時刻に買売を半々で選んだ場合の確認割合（双方の成功0/1を平均）を併記する。これは時間余地や相場が違う入口同士の比較を避ける記述であり、無作為化実験や運用利益の証明ではない。未約定・不明の内訳は維持し、同じ時刻の近接候補を独立標本としない。

全イベントのMAE/MFEは新規から先着・打切りまでだけを測る。代表成功・失敗はViewer向けに独立単一シナリオとして保存し、閾値到達と1秒待機後の返済約定を分ける。全候補の仮想保有を合算した約定ファイルは作らない。

区間木での先着検索を素朴な順走査と合成例で照合し、実イベントも別コードで再検証する。候補比較は記述的な探索であり、多数の近接候補から一般的な成功確率や再現性を断定しない。
