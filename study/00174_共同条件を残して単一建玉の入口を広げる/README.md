## 173の問題をどう変えて再実験したか

[173](../00173_追加建てを禁止し両中央値で入口を再探索する/README.md)では、全場参加と両中央値は得たが、共同条件に適合するNight8案が段階短表で全滅した。Dayの短表31にも共同適合はなかった。この原因を調べた上で、本試行では以下を別条件として固定した。

- Dayは旧31を包含し、Source×技術群×売買向き×発火方式の支持付き88層から各route240候補へ拡張。各routeOLD149/NEW66/LOCAL25。Wilson先着/参加/既知差引を巡回し、同論理入口の幅・期限だけで埋めない。
- global1の各段は共同条件4枠を先に留保し、先着支持/両中央値/参加/疎補完を各3枠、最大16へ。個別順位が高いだけの候補で共同適合を全て落とさない。
- 旧複合初参加Tの技術と200/H60は維持し、Dayだけ45/90/120/180経過分からの技術成立を比較。無条件の定刻新規は行わない。主J002は45分、前48J000は90分が選ばれた。待機の延長が一律に改善したという結論ではない。

単独600、異技術OR＋DayT869、Night接合648、三帯接合416の計2,533政策を再生。全期選択範囲では共同支持56政策、前48選択範囲では91政策が成立し、各routeから主と近傍を追加7の当該政策結果を読む前に固定した。
