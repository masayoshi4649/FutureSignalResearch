# 192 TOPIX：価格構造・方向混在・数量尺度

2026-11-18。[190](../00190_TOPIXの足形成差と夜間の入口確認を分解する/README.md)で見つけた費用/ATRによる方向切替の脆さを受け、方向を価格構造・多足・勢いから選ぶ72案と旧190固定対照を比較した。**新案の共同適合は0。厳しい旧P0はDayの損失とDDを減らす部分があるが37/41場に減少し、新T/R/Xは条件を同時に求めすぎて希少化した。原因を分解して196へ進む。**

## 仮説・入力・条件

P0順行/P0実側反転は診断対照。新しいTは三足方向と持続、Rは観測20分レンジの端へ触れた後の回復、Xは時間軸混在からの構造転換、MはT/R/X統合。6家族×緩/厳×旧/直接形成×量3尺度＝72案と、旧190D4/N01の1対照を、同じq0和集合34,424件で比較した。

数量は旧1分相対量、原累積量の5分端点差（現在5分÷前4窓平均）、1分不明時だけ5分へ補完の3通り。量時刻が価格時計以前で、6端点とも境界30秒以内に見えていること、窓中の累積減少・時計後退・90秒空白がないことを要求。未知を0量へ置換しない。

価格構造はq0直前1分を除いた20分の原順観測高低。ERは同じ窓の21固定1分端点から計算する。端点30秒以内・原価格空白90秒以内であり、完全な全約定経路や真の受信時計とは異なる。量5分は28,625q0、価格構造は23,812q0で計算できた。

対象は固定された2026-09-21〜11-16Dayの81場。11/16Night・11/17Dayの追加2場は本探索へ含めず、選択を先に封印した。81場は既使用であり、未見実証ではない。[条件](条件.json)・[567セル表](設定と結果.md)。

Dayは各形成のq0公表済みATR5×2.5（5〜25pt、0.25pt切上げ）、Nightは±15pt、H60の単純IFD。miniTOPIX1枚、片道41.8円＋0.25pt。保有/未決予約合計1、開始一律待機なし、Day15:30/Night05:45までに返済。未知の建玉は場末まで枠を保持。旧190対照の幅・方向は当時のまま保持した。新案の費用比は可否にだけ用い、方向を変えない。

## 新しい複合条件が希少化した理由

T緩・5分量の段階診断では、三足/ER/取得位置まで通るNight候補が、最後の「1分順行と5分MACD・RSI増分の同時回復」で大きく減った。旧形成の米前250→21、米後715→72、直接形成は米前395→41、米後984→98。複数技法を使うことと、異なる時間尺度で全て同時に改善することを要求する設計は同一ではない。

Rのレンジ端回復はDay4取得程度、XもNight2取得程度の候補があり、黒字率が高くても採用理由にしない。全量・品質・背景を通した上で狭い端接触まで必要としたため、対象が非常に小さくなった。[段階診断](原因診断.json)。

## Nightの方向と期限損益

旧形成P0緩・1分量の米後では、元方向は18順/14逆と先着だけなら良く見えるが、期限返済71件（未知3）の費用前寄与が−52,000円だった。実反転は期限返済の費用前が+25,000円となる一方、先着が11順/21逆となり損切りが増える。単純反転で同じ建玉の利益が反対になるわけではなく、返済時計・保有枠・後続取得も変わる。

旧190の方向切替は、価格とATRを完全に固定したまま片道手数料を41.8→0円へ替えると、旧形成の米後P0成立1,023要求中108、直接の1,147中127で方向が変わった。これは方向ロジックの料金定義への依存を示す診断で、新しい損益の再生ではない。ATRが市場局面の代理だった可能性もあるため、次はATR比・過去ATR・価格効率と、数量/形成を追加する効果を分ける。
