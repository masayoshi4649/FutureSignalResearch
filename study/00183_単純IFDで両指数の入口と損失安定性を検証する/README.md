# 00183 単純IFDで両指数の入口と損失安定性を検証する

2026-11-17検証。**新しい入口を加えれば安定する、という結論には至らなかった。** NK225の28候補とTOPIXの39候補を81セッションで比較し、失敗原因を分けてTOPIXは[184の117新比較](../00184_TOPIXの足の形成時計と入口の反転を検証する/README.md)まで進めた。出口は単純IFDで、追尾を加えて入口の悪さを隠さない。

閲覧は[候補別CSV一覧](../../outputs/00183_単純IFDの入口比較/README.md)。設定の一覧は[設定と結果](設定と結果.md)、詳細・指紋・再現手順は[NK225](NK225/README.md)と[TOPIX](TOPIX/README.md)。損失が減った部分と悪化した部分を残し、今回は安定採用を見送る。

## 仮説と比較方針

移動平均とDIによる背景、MACD/RSIの変化、ATR/BBによる位置と値幅、相対量、固定した価格水準への回復を組み合わせ、順行・反転・待機を分ける。RSIの高低だけを反転根拠にしない。NK225は旧4対照＋価格構造6群×統合4方式、TOPIXは順行・反転・局面切替13群×対称幅5/10/15ptを比較した。細かな時刻区分は追加せず、デイ/NY09:30前/以後と当時の価格背景を使った。

出口は固定利確・固定損切りと期限・終了前全決済のみ。買売合計の保有・予約1件、開始一律待機なし、デイ15:30/ナイト05:45までの返済を継承する。手法ごとの実取得・全対象場・保有時間率を残す。未知を0円とせず、両中央値黒字・全場取得・保有下限20%・未知非増加を候補の適格性として確認する。

順位は、適格性→赤字場率→最悪5場の損失→最大場損失→連続赤字→赤字取引率→損失/取得→DD→参加の順。全期利益最大を採用条件にしない。未知を含む既知寄与の順位は、真の損失上限の証明にはならない。

新金融前に候補・Source・純入口・順位を固定。全80場での発見と前48場での選択を区別し、その後25・追加7・11月16日デイを分けて確認する。全80場にはデイ40場、前48場にはデイ24場が含まれる。全81場は既使用であり、未見検証とは呼ばない。

## 入力と費用

- 利用可能な完了フォルダは両指数とも2026-11-16デイまで。原板は `../JP_OSE_Data/future/` を共用し、試行ごとの複製を作らない。
- NK225は既存の旧73・追加7・11月16日デイ1の81場と公表済み100特徴、終了前決済済みのIFD数値表を再用。mini1枚、1pt100円、片道税込38.5円、追加滑り片道5pt、実BBOを継承。新しい入口間では元の幅・期限を固定する。
- TOPIXはminiTOPIX1枚、1pt1,000円、片道手数料41.8円、追加滑り0.25pt/片道。NK225の乗数・滑りを流用しない。仕様の出典と確認日は[TOPIX正本](TOPIX/README.md)に記載した。

## TOPIXで分かったことと次の実験

183の39組では共同条件に適合する候補がなかった。原因の一つは、1分足の確認が30秒を超えると長い足の形成からもその分を捨てるため、最初の2場で15分足の履歴が不足したこと。市場の不向きとデータ処理上の未参加を区別し、[184](../00184_TOPIXの足の形成時計と入口の反転を検証する/README.md)で原板からの5/15/30分足直接形成と、実BBO側を変えた売買反転を分離して比較した。

低ADX反転R0・幅15の実側反転C1は、全41デイで損失484,099.6→312,676.8円、赤字28→13場、連続赤字6→2、DD240,440.4→73,427.6円へ改善した。収支は−240,440.4→+50,143.2円、金融未知0。これは**次の仮説を作るための有望な差**である。ただし35/41場しか取得せず、最大場損失が悪化し、直接形成に替えた同じ実反転C3では赤字に戻る。足形成に対して頑健な入口としては採用しない。

## 検証と限界

NK純入口の人工92,438項目、全28候補の独立集計117,936属性を照合。TOPIX183実装修正1は17,015取得、184の全156組は70,447取得を、到達探索木を使わないBBO直接走査でも照合した。184は金融915,811・集計502,632属性が一致。CSV54件も再読し152,760セルを照合した。[閲覧資料の再現と検査](閲覧資料/README.md)。

TOPIX183の決済窓と取得行に関する実装修正は、修正前Source/結果の指紋を保持して全39組を再計算した。修正と新しい仮説変更184を混同しない。

価格時計は記録にあるCurrentPriceTimeを用いる。原データに独立した板時刻・受信時刻がないため、真の受信時点と約定成立は保証できない。出来高は可視時刻を確認した累積差分であり、完全な約定フローやminiの数量ではない。保有・決済未知は0損益化せず、全件確定値を空欄に保つ。株式の板研究や心理仮説を先物の大幅IFD利益の証明にしない。[外部一次資料](NK225/外部一次資料.md)。

次に確認する論点は、押戻し入口を全帯に足すことではなく、米前の連続性と実方向の受容を何で識別するか、またTOPIXの低ADXをレンジと誤認していないかである。新しい条件は別試行で固定する。今回の候補を安定採用へ昇格させず、183/184の条件と数値を保持する。
