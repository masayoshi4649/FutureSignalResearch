# 候補別CSVの保存・照合・再現

[CSV一覧](../../../outputs/00183_単純IFDの入口比較/README.md)はNK225の4候補・TOPIXの5候補、それぞれ6表、合計54CSV。全81場（デイ41/ナイト40）と取引明細を残した。候補は混在させず、未知の値は空欄にする。金融条件や採否を閲覧処理で変更しない。

[保存索引](保存索引.json)は5Source・9正式金融正本・54CSV・確認票のサイズとSHA256を持つ。型付きJSON2件は金融正本の転記となるため、指紋だけを保存する。PNGとxlsxは正式保存しない。

## 確認済みの範囲

|確認|NK225|TOPIX|合計|
|---|---:|---:|---:|
|候補|4|5|9|
|CSV|24|30|54|
|型付きデータセル（見出しを除く）|63,563|87,355|150,918|

見出しを含む**152,760セル**を、生成後のCSVから再読して元の型付き値と照合した。UTF-8 BOM、未知空欄と数値0の区別、候補分離、全場残存も確認した。[CSV再読確認](CSV再読確認.json)に54ファイルの個別SHAと件数がある。

- [NK入力照合](NK入力照合.json)・[TOPIX入力照合](TOPIX入力照合.json)：金融正本から型付き表への利益/損失/累計/未知/保有時間の照合。
- [NK作成確認](NK作成確認.json)・[TOPIX作成確認](TOPIX作成確認.json)：共通出力器によるセル照合とCSV生成の記録。
- [別root再現確認](別root再現確認.json)：旧workの中間資料を読まず、正式9packから型付きJSON2件と入力照合票2件を再生成し、4件すべて元byteのSHAに一致。

型付き変換・別root再現はPython 3.14.3の標準ライブラリだけで実行した。CSV本体の既存作成記録はNode v24.22.1。共通CSV出力器は `@oai/artifact-tool` を使用するが、今回の別root確認ではCSVの再生成・markerの作成を実行していない。

## workを参照しない型付きJSONの再現

必要なのは、このフォルダ、[NK225新規Source](../Source/NK225/新規Source.zip)、[NK225保存4候補](../NK225/選択4候補/)、[TOPIX183保存3候補](../TOPIX/金融正本/)、[TOPIX184保存2候補](../../00184_TOPIXの足の形成時計と入口の反転を検証する/金融正本/)である。大きな原板、価格索引、旧work、CSVの生成環境は不要。

リポジトリルートから、未作成または空の別ディレクトリを指定する。既存ファイルを削除・上書きしないため、再実行では新しい名前を使う。

```powershell
python -X utf8 study/00183_単純IFDで両指数の入口と損失安定性を検証する/閲覧資料/再現する.py --root work/183閲覧の別root再現
```

`--proof 保存先.json` を任意で付けると、標準出力と同じ確認票を新規保存する。既定では正式資料を変更しない。再現Sourceは次を順に行う。

1. [Source.zip](Source.zip)内の5Sourceを元の相対パスで新しいrootへ展開する。
2. 安定性集計Source1件をNK225の封印ZIPから取り出し、同じ新rootへ配置する。
3. 保存索引に従い、正式9packを新rootの元work相対パスへ配置する。元データと正式保存のSHAが同じことを確認する。
4. `python -I -X utf8` でNK/TOPIXの型付き生成Sourceを実行する。Sourceは新rootを基準に動き、旧workへ接続しない。
5. 新root内の `work/183閲覧資料/` に生成された型付きJSON2件と入力照合票2件を、保存索引の元サイズ/SHAへ照合する。

実走では `work/183閲覧のみ再現_20261117_A` を空rootとして使用し、4件とも同体だった。これは閲覧表の再現であり、元の金融損益計算・原板約定の再検証ではない。

## CSV出力器の保存

Source.zipには `NKの型付き入力を作る.py`、`TOPIXの型付き入力を作る.py`、`CSVを再読して確認する.py`、NKが継承する182の型付き変換Source、`scripts/損益CSV/候補別に出力する.mjs` を元の相対パスで保存した。共通出力器のCLIは `--input 型付きJSON --output 候補CSVの親フォルダ --proof 確認資料フォルダ --dependencies artifact-toolを解決できるフォルダ`。出力先候補フォルダは新規を要求する。

CSV再読Sourceは型付き2JSONと対応54CSVを読み、全セルを照合する。今回の保存ではCSV本体を作り直さず、既存54CSVの指紋を保持した。生成JSONや各表の原行情報から金融正本へ遡れる。
