# 00081：定時の現在根拠と部分利益保護

2026-11-07。主費用で黒字の案はなかった。 全66既使用場で、FAR後期の現在支持・価格帯の部品から15分定時の新規を直接判定し、B0/B1とG0/G1の4組×2遅延を比較した。旧70%・125/250先着・待ち50%で棄却しない。

D164_15/P164_06/U165_03は時計窓と特徴部品の出典タグであり、元三手法の同値再現又は各元手法単独の成績ではない。80から100枚固定へも変更したため、80との総額差を入口だけ・出口だけの因果効果としない。

80の参照保有抽出は用いず、元SourcePortfolioの運転・源返済の写しも行わない。元FAR及び80と同じ売買列ではなく、両者の利益を加算しない。

## 条件と技法

新規は初回を除くDay09:15..15:15、Night17:30..翌05:30の15分枠。NY09:30の前後15分は静観し前窓で返済、場末は15:35/05:50に要求する。保護は全原行で連続、売り買いは符号反転で同条件。

1候補100micro固定・片側100・同時一建玉。保有、未約定新規、返済待ちは占有を保つ。推奨数量ではなく固定尺度の研究対照。1枚10円/pt、片道手数料11円＋滑り5pt=61円、往復122円を主費用とする。次正常ラージ板BBOを価格代理とし、追加価格時計1秒は別約定列、同約定0/10ptは費用感応に限る。

| 政策 | 新規の複合根拠 |
| --- | --- |
| B0 | 自己5/15秒・相手120秒・OFI30秒の現在支持、M/T、確定3/15分EMA方向又はRSI50回復・MACDhist改善・EMA回復 |
| B1 | 同じ現在支持と新規側BBOのEMA8から1ATR以内の位置。順行又は、50交差を待たない勢い改善＋新鮮なE08帯・同価格量支持・反対圧力の解消 |

3分TRが前ATRの2倍超かつRSI差絶対15超の同時急変を見送る。必要未知を0の観測へ置かず、元1/5分の準備計算と追加3/15分の値選別を分ける。自己と相手の原価格時計、物理行、源Indexを保存する。表示量は攻撃側約定量ではなく、M/Tも校正確率ではない。

両Gは正益前から新規時3分ATR14をceil5・15..125ptへ固定したDで損失を追尾し、未知は125。3分EMA8反対側かつMACDhist差反対の新確定足では技法失敗返済する。G0は残玉単価純益がstrict正から20pt床で全残を保護する。G1は部分利確を要求し、最低建値とATRで残玉を保護、部分注文全約定後にだけ確定純益Rと残量nで全玉予算床を計算する。未約定の益を予算へ入れず、受理返済を取消・延期しない。

G1の要求量はceil((222Q+1−R)/(u+222))を1..Qへ制限する。222円は往復主費用122円と追加悪化余裕10pt=100円で、余裕は費用へ二重加算しない。完了後の床はceil5(max(0,(222+(1−R)/n)/10))を前床・建値・ATR床へ重ねる。これは次板悪化を防ぐ保証ではない。詳細は[検証計画](検証計画.md)、[全設定IDと版5の55×9表](設定と結果.md)。
