## 原板なしで復元する

リポジトリルートから、新規のwork先を指定する。

```powershell
python -X utf8 "study/00131_中期MACDの位相で複合入口の方向を切り替える/再現資料/保存資料を復元する.py" --destination work/131再現
```

コードZIPのCRC/各源SHA、共有gzipの解凍SHA、方向票SHAを照合してから展開する。方向準備と人工検査のJSONも正式検査票から復元し、F1全21源を追跡できる。旧正本の作業用解凍はwork内だけへ置き、恒久資源は変更しない。展開先の正式MDは実行前版なので、閲覧には元リポジトリの現行正式資料を使う。

展開先を作業ルートにして、`work/T8の15分位相による切替案/人工検査.py`と`work/131既存入口の位相切替評価/人工検査.py`を実行できる。どちらも自然outcomesを読まない人工8検査である。主副・未知/0・符号鏡像・IFD既知/未知・全場/空場・phase停止を検査する。

## 固定評価を再計算する

正本集計を置かない別の未作成先へ復元する。

```powershell
python -X utf8 "study/00131_中期MACDの位相で複合入口の方向を切り替える/再現資料/保存資料を復元する.py" --destination work/131再計算 --inputs-only
```

以降は`work/131再計算`を作業ルートにする。方向票を変更せず、RootのF1・choicesを指定して評価する。

```powershell
python -X utf8 work/131既存入口の位相切替評価/評価する.py --f1 work/131既存入口の位相切替評価/F1.json --f1-sha256 8694a553430b66032dd733c06fa166803d470d488a8810fbe6a29310e3f66882 --evaluate-fixed-choices cdf1f0c6248d76222d49c7d872094cce20edecb7f52aa9e725d1040aa51f17c3 --output-dir work/131既存入口の位相切替評価
```

全79取得/73場と主H0・副H1を保持し、Source/choices/コードの指紋と全政策のentry/touch/endpointがScene.End−300未満かを検査する。違反時は保存前停止し、取得・未知を後から除外しない。旧O0/B0/T8の全180条件へ一致することをassertする。全体/前48場/後25場の各100条件、計300行を保存する。前後は既使用期間の参考分解であり、未知期ではない。

出力は`集計.json`、`CSV用の表.json`、`評価完了.json`。表SHAは`96af73095d0485f97b03962816ca58b576987868582829fad2a033e55787a96d`。固定票による評価にモデルの再学習は不要。方向票自体の準備を再現する場合は125/126の準備資源も各正式手順から復元し、既存choicesへ上書きしない。

## 独立検算とCSV

再計算後に`work/131独立検算/検算する.py`を実行すると、評価器/124算術をimportせずFractionで方向・全300条件・全16,574表セルを含む32,067値を再構成する。[保存短報](../検査/独立数値検算.md)。bootstrap区間の独立再実装や原板の最初touch再走査は対象外である。独立準備の[短報](../検査/独立準備確認.md)は金融前に行った395方向・232参照・人工4,096組の確認で、後段の金融検算と分ける。

CSV出力器は`work/131既存入口CSV出力/出力する.mjs`、再読は同フォルダの`CSVを独立再読する.py`。同版Artifactの既存runtimeへ`node_modules`を接続し、依存を複写しない。適用するCSV作成手順の操作開始markerを作成3点/CSVで一度実行し、新規出力先へ保存する。

```powershell
node work/131既存入口CSV出力/出力する.mjs --input work/131既存入口の位相切替評価/CSV用の表.json --sha256 96af73095d0485f97b03962816ca58b576987868582829fad2a033e55787a96d --output work/131再現CSV
python -X utf8 work/131既存入口CSV出力/CSVを独立再読する.py --input work/131既存入口の位相切替評価/CSV用の表.json --sha256 96af73095d0485f97b03962816ca58b576987868582829fad2a033e55787a96d --folder work/131再現CSV --output work/131CSV再読.json
```

[正式CSV案内](../../../outputs/01a1889f-f2af-7943-a047-543275ee9ed2/131既存入口CSV/README.md)。300×26/79×51/73×65、全16,574セル・12,011数値を独立再読し、Rootが3プレビューを確認した。xlsxは生成していない。独立mini1枚IFD代用であり、実IFD・利益追尾・10枚口座収支に読み替えない。

保存資源の確認コードは[保管を確認する.py](保管を確認する.py)。公式復元先と元repoを指定し、`--output`へ未作成のwork証跡先を渡すと、原板/金融再計算なしに全F1源・MD・504セル・ZIP・CSV bytes・リンクを照合できる。正式保存の確認票は`検査/保管復元の確認.json`に置く。
