仮説は「長期MAと短期Histが強くても、中期の勢いまで同調した継続と、背景MAだけが残った反転局面は違う」。129の別の出生集合では、5分Histが全て同向でも15分Hist負の群で逆行が多かった。これは小標本・既使用・結果後の診断であり、その率を今回の成績へ移さない。130の出来高案は主68.42%のままで悪化したが、131の数式は130の個別損益を開かない担当が129診断と当時特徴から提案した。既使用データへの選択偏りは残る。

買1/売−1。全ての符号特徴をB0へ揃える。T8がB0を反転し、B0向き15分Gap>0、EMA21増分>0が既知なら中期方向の支持とする。主H0はさらに既知の15分Hist>0ならB0に戻し、他はT8。副H1はその条件に既知の15分Hist増分>0を追加する。0と未知は支持票にせずT8維持。RVOL5は診断記録だけで閾値にしない。全79時計・全73場最低1取得を維持し、良い副案へ主を結果後に交換しない。

入力は124の同一取得の実正逆BBO結果、当時特徴、125のB0、126の固定T8モデル。方向変更時の逆注文I/cap/TTL適格性は再構築していない。通常取引区間の終端以前か、全政策・両時間・全幅の利用票で検査する。境界違反時は保存前停止し、除外や0円化をしない。

主評価は全体H0・実側BBO・取得後60分・同幅±125pt、Hを全観測できた事例の順/(順+逆)。未到達込み率、観測不足、IFD既知/未知を分ける。前48場53票/後25場26票は参考で、既使用であり独立未知期でない。副評価はH30/60、±25/50/100/125/200、Last方向参考。固定O0/B0/T8の180条件が旧126へ一致するか確認する。

費用はmini1枚100円/pt、往復77円。C5は追加往復10pt相当1,000円の感度仮定で、BBO内包スプレッドを再控除しない。IFD代用は既知の最初のtouch清算BBO、未到達でH完了時だけ期限BBO、他は金額未知。Last金額はnull。利益/損失/差引を併記し、実約定又は10枚の口座収支へ換算しない。
