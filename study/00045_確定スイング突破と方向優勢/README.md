## 価格機械・複合条件と時点

左右2の中心を右2公開で確定し、左strict/右同値可。jはpまでに確定した最新R/LだけでCp<=R<Cj（売鏡像）を判定する。j.end>p.confirm/keystrict、lateはP/消費なし・履歴j投入。j右2確認の新pivotはj判断後に登録し、生誕同足へ戻さない。初(side,pivotID)crossは構造/指標/時間/保有都合で不採用でもconsume、再crossを後で救済しない。
