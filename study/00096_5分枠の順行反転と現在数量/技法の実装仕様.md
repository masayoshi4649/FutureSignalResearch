# 96・現在の複合テクニカル採否

## 範囲と公開API

`AssessTechnicalGate(input TechnicalGateInput, candidate EntryCandidate, policy string) (TechnicalAssessment, error)`は、金融の既存適格性と枚数計算の後に呼ぶ純関数。政策は`A/B/AB`、場区分`Kind`は`Day/Night`。SourceのSide・量・段階、注文、保護、費用、Nativeには書き戻さない。原板・損益・決済後価格を読まない。次枠への候補復活や状態保持も行わない。

| 型 | exact JSONメンバー |
| --- | --- |
| `TechnicalGateInput` | `snapshot_id, at, kind, chart, recent3, current` |
| `TechnicalAssessment` | `decision, checks` |
| `TechnicalGateCheck` | `id, known, passed, reason` |
| `GateDecision`（金融定義） | `policy, snapshot_id, known, allowed, role, reason` |

`chart`は`chartwarmup96.Snapshot`、`recent3`は同型の最新3公開足以下を古い順に持つslice、`current`は固定82の`CurrentEvidence`。`Input.At=Chart.At=candidate.At=判断grid`、`Decision.SnapshotID=Input.SnapshotID`。外側の固定`ChartView`の大文字メンバー名、内部既存JSONタグを変更しない。

`EntryCandidate`は金融定義の`ordinal/at/side/source/quote/available/quantity`。量や金融の資格を再計算しない。取得側気配`e`は買Ask・売Bid、方向`s`は買+1・売−1とする。各式はこの符号だけで対称。

## 出典品質と必要未知

先に全数値の有限性、判断時計、政策、場、候補の正Last・正常BBO、出典を検査する。Currentと候補QuoteはTime/Last/Bid/Ask/SourceLine/FeaturesのSourceIndexが完全一致。Current.Received及び支持窓/夜間帯/短秒の源時計が判断又はCurrentより未来ならerror。既知指標の非正価格、負ATR/TR、RSI範囲外、夜間数量変化の負値もerror。未知の0を既知にはしない。

チャートの`ObservedClock`は当該公開をdrainした入力時計上限なのでgridより未来でもよい。利用時刻は`BarEvidence.AvailableAt<=Snapshot.At<=grid`で検査する。足出典のBarEndとTechnicalの終端を結び、最終原行は当半開足内に置く。Scene、原行順、公開の前後を破った値はerror。**これは保存された公開値の整合性検査であり、指標や源数量の独立再計算ではない。**

`Chart.LastInput.Index`はNK受理全行の連番、`Current.SourceIndex=candidate.Quote.Index`はLast正のFeatures連番で、両者を同値にしない。助走不足、空足、不良Last後の数値未知化、必要窓不足・古さは通常の未知。Last0後に過去のRecent3が残っても現Technicalが未知なら反転成立へ復活させない。

固定TechnicalViewにはEMA15単独Knownがない。EMA背景は`TrendKnown`（3分8/21及び15分8/21の全既知）を使う。MACD増分/EMA8は`ExitKnown`、同時スパイクは`SpikeKnown`、ATRは`ATRKnown && ATR3>0`。反転aのEMA8は`TrendKnown || ExitKnown || ReversalKnown`、b/cのRSIは`SpikeKnown || ReversalKnown`という、固定APIが保証する範囲だけで既知とする。正の数値だけによる助走完了の推測はしない。

## 共通9条件

| Check ID（`共通.`以下） | 条件 |
| --- | --- |
| 現在価格時計 | 価格時計がgridから15秒以内（等号可） |
| 確定3分 | DataKnown、BarEnd以下、足齢180秒未満 |
| 確定15分 | DataKnown、BarEnd以下、足齢900秒未満 |
| EMA背景既知 | 上記両足及び固定TrendKnown |
| MACD増分 | `s*(Histogram3-PreviousHistogram3)>0` |
| 終値とEMA8 | `s*(Close3-EMA8_3)>0` |
| 取得位置ATR | `0<=s*(e-EMA8_3)<=ATR3`（両等号可） |
| 同時スパイク警戒 | `TR3>2*PreviousATR3 AND abs(RSI3-PreviousRSI3)>15`なら拒否 |
| 現在量支持 | 下記の当時既知な量支持がstrict正 |

Dayは候補方向のBuy/Sell supportの`OFIKnown && OwnAt==Current.Time`を必須とし、符号未反転の`OFI30`に`s`を掛けてstrict正。Nightは`Night.Available && Window==E08 && Band.QuantityKnown`、`Band.Time==Current.Time && Band.Index==Current.SourceIndex`を必須とし、`s*(BidRefill+AskDeplete-AskRefill-BidDeplete)>0`。4成分等の数量変化は有限・非負。未対応窓・未知・別時計は未知、中立/反対は既知不成立。

これらは板由来の量変化であり、生の約定出来高ではない。M/Tを純量へ変換せず、この採否には代用しない。RSI70超という水準単独や持続高値だけで拒否しない。

## 役割と論理

**A（順行）**は共通に加え、`s*(EMA8_3-EMA21_3)>0`、`s*(EMA8_15-EMA21_15)>0`、連続する前確定3分足から` s*(Close3-PreviousClose3)>0`を要求する。Check IDは`A.3分EMA方向/A.15分EMA方向/A.確定終値進行`。

**B（反転）**は共通に加え、15分EMA差が`s`のstrict逆。最新同Sceneの連続3本a/b/c（終端差各180秒、DataKnown、必要指標既知、cは現在確定3分）だけを使う。`L=a.EMA8_3`を固定し、次を全て要求する。

- `s*(a.Close-L)<=0`（同値可）。
- `s*(b.Close-L)>0`及び` s*(c.Close-L)>0`。
- `s*(c.Close-b.Close)>0`及び` s*(c.RSI3-b.RSI3)>0`。
- 現在の取得側気配も` s*(e-L)>0`。

Check IDは`B.15分EMA逆背景/B.固定3足窓/B.a足は固定線反対側/B.b足で固定線奪還/B.c足で固定線維持/B.c足で価格再進行/B.c足でRSI再進行/B.現在取得側も固定線方向`。固定Lをb/cのEMAへ替えない。公開OHLCがないため、足内安値/高値での維持確認とは呼ばない。過去に成立した3本窓を次枠で復活させず、Source Sideも反転しない。

ANDは一つでも既知不成立なら既知拒否、既知不成立がなく必要未知があれば未知。ABのORは一方が既知成立なら成立、双方が既知不成立なら既知拒否、それ以外は未知。全Checksは未知を含め保存し、未知CheckのPassedは偽。成立RoleはA=`順行`、B=`反転`、既知拒否=`待機`、必要未知=`判定不能`。A/Bの背景符号は排他的であり、ABは共通9件を重複保存しない。

## 人工と限界

`go test -run '^TestTechnical96' -count=1 ./...`で、売買鏡像・A/B分離・三値OR/AND、高RSI持続とstrictスパイク境界、Day/Night量の支持/中立/反対/未知/別時計/未対応、価格15秒と足齢の等号、ATR位置の両端、固定L、最新3足不足/空足/欠足、Last0後の未知化、未来公開/源時計/連番/非有限/別場/原行取り違え、入力map/slice不変を確認する。Root接続を含む通常`go test ./...`と`go vet ./...`も実行する。

人工の技法値は手製のAPI境界値で、実指標の市場効果や源生成成功を主張しない。閾値はRootの事前契約に従い、実原板・95/96の損益を参照して選んでいない。A/Bは未検証の研究仮説であり、成立から将来利益や反転成功を保証しない。旧金融・Source・正式95・盲検設計2923…は変更しない。
