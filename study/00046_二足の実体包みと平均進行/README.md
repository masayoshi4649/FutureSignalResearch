## 複合条件・公開時点と心理の仮説

s=買+1/売−1に対しs(Cp−Op)<0、s(Cj−Oj)>0、s(Oj−Cp)<=0、s(Cj−Op)>0。始値側等号だけを許し、終値側strict。前足反対実体の打ち返しを反転と呼ぶが、長期トレンド終結の観測ではない。ヒゲ包み/実体比/CLV/20高安条件は加えない。Pならs(Cj−Cp)>0は自動で独立の勢い票ではなく、現前中心化H差sδH>0を組み合わせる。

p/jは同場・連続完全公開3分、p.end=j.start、index隣接、両confirm>=end、p.key<j.key。j確定時に二足を観測し、45のj.end>p.confirmを加えない。欠枠/不正/NP/局所不連続で二足/SMAを解除、完全公開窓へmissing>0を投入しない。公開key同値/後退と重複indexは拒否する。

Mp=mean(C[j−20..j−1])、Mpp=mean(C[j−21..j−2])、dM=Mp−Mpp、dP=Cj−Mp。元floatをFraction化し当足を除外、共通準備最速j21/現在含22足。両s差正ならT順行、両負ならR反転、0/不一致WAIT、未準備は別記。B0へ平均準備を先に課さずB1は準備だけ。実sideは保持する。dM=(Cp−C[j−21])/20には窓落ちが入り、新注文圧力とは言えない。dPは価格差でI02の割合乖離ではない。

Tは背景進行側の打ち返し、Rは背景と逆向きでまだ平均の反対側という心理仮説。投資家の新規/返済を直接観測せず、ローソク/MACD/SMAは同価格由来で独立三票ではない。重なる二足と共通21終値の依存を日場・30分間引きと分ける。
