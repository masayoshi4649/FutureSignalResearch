## 固定した判断と取得の単位

[148](../00148_全1分知得から入口品質の母集団を固定する/README.md)で広く記録した適格q0全35,339件を、当時の買売100特徴だけで先に判断した。q1/取得できた事実/先着ラベルを選択器へ渡さず、必要値nullは待機。同側の複数成立は1候補にまとめ、OR8同時両方向23件を競合待機とした。後段で未取得も含む取得対応を結び、同q1は1物理取得、旧C1と重なる16件は旧C1の方向を優先した。旧87を成績で選別せず全件保持する。

8局面は、方向・強さ・勢い・価格位置/構造・値幅・量の役割を分ける。全技法を同方向へそろえる単一AND、一定時刻の強制新規、場ごとの均等化、回数上限での切捨ては採用しない。[条件](条件.md)と[513セルの設定表](設定と結果.md)がF0固定の閾値を保持している。

主U0は旧C1 87＋OR8 4,085−同q1重複16＝4,156件。OR8単独は68場で5場未取得、旧C1を統合して全73場min1を満たした。全場平均は全ザラバ720時間55分が分母で、1時間ごとの強制割当ではない。場別1〜151件の偏りをそのまま残す。
