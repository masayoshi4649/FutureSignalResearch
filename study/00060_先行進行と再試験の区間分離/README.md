## 価格順序・判断・執行の限定

Tはb→r→k最低3本、Rはb→f→r→k最低4本の順序を保ち、反応を5本へ切らずb.confirm+3600まで追う。60分は定時4枠の上限ではなく、出生の位相や公開/欠測により観測枠数が変わる。取消・未登録・段階未完了を消さず、完成したkだけを母集団にしない。経路T/Rは仮説の名前であり、採用役割の順行/反転は現在DIで付く。k有効を全新規の追加ANDとして強制した実験ではなく、木は未完了・取消も特徴として受け取る。

当時既知の同じ帯端Kに対して最初のb/f/rを固定し、取消を次段成立より優先する。別の足と公開key順序を確認し、同足高安の到達順を作らない。r足の高安が前段の公開後に形成されたと保証する条件は追加していない。終値の観測順と足内形成順は別。有効中は新しい水準へ置換しない。取消した足を新bへ使わず、次足からのみ新登録を検討する。判断time又は処理足の公開時刻がb.confirm+3600へ達した同秒を含め失効し、最初の期限越え足は新bへ再使用しない。k後の既知統計は取消後もTTL又は置換まで継続する。

判断はデイ09:15〜15:15の25枠/ナイト17:30〜05:30の49枠。保有継続は非待ち、全予定枠で判定不能込み保守上限50%以下を要求する。定時より前のk価格へ約定を戻さず、現在正常BBOから後行1価格時計秒、新規TTL30秒。新規残り60分条件なし、強制15:35/05:50・終了15:40/05:55。

固定49O・micro1枚10円/pt、片道11円＋想定片道5pt。新規時の現ATRを5pt切上げD5..125へ制限し保有中固定。損失側も連続追尾、現在返済気配の粗益−122円strict正で利益旗・最低名目新規床・非緩和、返済pendingは保護凍結。固定250TPなし。0/10ptは同約定の費用感応で起動122円は不変、名目床は費用後同値の保証ではない。

先着率・回帰予測・過去平均・実運用利益は別。旧55単独測定は重複保有を含み合計はstrategy利益でない。新価格列は同じOHLCの加工であり、独立した注文票・心理の直測・量情報の追加ではない。価格の不進行だけから吸収や反転成立を断定しない。ラージBBO代理で、micro実板・受信時計の測定ではない。
