## 仮説

突破水準の近くへ価格が戻っただけでは、押戻しと失敗を区別できない。取得時または取得後に、固定水準の順側・MACD Histの順側・15分DIの順側が同時に確認できた状態をarmedとして保存し、その後に価格構造とHistの順側水準が一緒に失われた場合を追加撤退の候補とする。

これは心理の仮説であり、突破後の支持への注文が残る通常の再テストと、局所水準を保てずMACDとsignalの相対関係も逆転した状態を分ける試みである。注文主体や吸収量、反転の因果を価格指標だけから断定しない。Histの符号はMACD本体の0交差や価格反転そのものではない。

旧113は取得時pivotの否定と3分Hist増分低下で早期撤退し、全体の純利益を下げた。初めから背景が逆の玉と、取得後に根拠が崩れた玉が混ざり、Histがまだ順側の例もあった。116では出生時の実突破境界、5分Hist水準、armedからの遷移、現在返済BBOと確定Last Closeの違いを明示する。同じ案の改名とは扱わない。

後のarmedは、取得後に終了・配送された5分足を参照し、5Closeと正常返済BBOが境界の順側strict>0、方向付きHist5>0・DI15>0を同時に満たす場合とする。使用5/15/30足が当場freshであることも必要。取得後30EMA配置の符号が変わることだけを新たな方向gateにはしない。

armed後、取得後の新5分公表でHist5の方向付き水準が<=0となり、XCは同じ公表Closeが固定境界の逆側strict<0、XQはその公表がfreshの間の正常Raw返済BBOが逆側strict<0で失効を完成する。買いはBid、売りはAsk。XQは公表配送行だけに限定しない。価格等号は退出偽、Hist等号は順側水準消失とする。これは独自の研究定義で、普遍的な最適閾値ではない。

Hist警戒がHist回復で解除された段階と、完成した失効ラッチを分ける。価格条件は当時値から毎回評価し、価格だけが順側へ戻ってもHist警戒が消えたとは数えない。未知・欠足・古さは使用値だけでarmed鎖を切り、正常化後に再確認する。BBO異常だけは鎖を切らず、XQ判定と発注を待つ。XCは気配異常中でも確定公表で完成した失効を保存し、正常気配を待って発注する。未使用ADX/RSI/BB/出来高の未知を理由に監視を無効化しない。

元予約とP100を先行し、未ラッチでP100が起動した玉には新しい追加失効を出さない。既に完成したラッチや注文は後のP100起動で取り消さない。未予約の実残だけを要求し、既存の後原行正常BBO約定と遅延、費用、部分返済配賦、残玉0の検査を維持する。
