## 原因から得た知見

1. **足準備不足と市場条件不成立は別。** 183初日Day/Nightは15分の累計2/4本でq0が0。直接形成では初日Day12:50から43q0、Night17:15:06から217q0へ増えた。直接M4のDay全41取得も、これで改善した。参加だけでは両中央値や未知の悪化を相殺しない。
2. **低ADXと短期反発は、元方向の終了確認に足りなかった。** R0はADX<25、BB反対側、1分陽転、RSI/MACD差分の回復を使う。その逆側が良かったため、「方向性が弱い市場」ではなく「既存方向の途中の短い戻り」も含んでいた可能性がある。ADXの遅行・短い利益確定/逆張りの反発という心理仮説であり、参加者の意図を観測した事実ではない。
3. **そのまま反転させるだけでも安定解ではない。** 直接足C3 R0では両中央値が正でも合計赤字へ変わった。足形成・履歴不足・欠測選別で背景が変わる感応が大きい。損失の深さ、負けの集中、追加期の建玉中央値を次の判別材料に残す。

C1 R0で未取得だったDayは9/21・9/22・9/23・10/12・10/15・11/4。いずれも純条件の成立0であり、約定失効のためではない。9/21は全q0不足、他は利用可能特徴とR0条件をさらに分けて診断すべき対象として残す。機会損失額は評価していない。
