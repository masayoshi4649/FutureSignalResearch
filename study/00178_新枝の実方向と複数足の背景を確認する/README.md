## 仮説と177からの変更

[177](../00177_固定幹を保ち高ADXの入口を増分比較する/README.md)は高ADXの複合枝で取得の広がりを改善したが、追加期の方向悪化と全80Night場中央値の保留が残った。元Sourceが回復を示した側と、REVERSEで実際に取得する側が異なる場合もある。178では**正逆変換を終えた実注文側**に背景の整合と動力があるかを、新枝だけへ追加する。

旧174の幹・初参加T・デイ・新枝の幅/期限・数量時計を変更しない。177固定4親から生まれた7つの異なる新枝実方向へ12ゲートを適用して84純方向を封印した。元ALL/EDGE後の非0方向を通すか0にするだけで、後でゲートが回復してもEDGEを作り直さない。

市場心理の仮説は、短期回復だけでは参加者の方向が揃わず、15/30分の平均線傾き・DIに実注文側の支持があり、5分MACDとRSIもその側へ改善している時は、一時的な反発と継続的な進行を区別しやすい可能性があるというもの。逆側HMが選ばれたことから「戻り売りが実際に吸収した」と後付け実証はしない。価格由来の相関した票を独立確率として掛け合わせない。
