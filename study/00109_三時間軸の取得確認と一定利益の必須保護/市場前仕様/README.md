## 仮説

[108](../00108_開始静観20分と30分の比較/README.md)は20分静観で費用後純額が改善したが、夜間参加と利益後赤字は未解決だった。[11/06の実取引](../../docs/議論/11月06日の赤字を入口と利益保護から診断する.md)では、取得時の大きいATRに比例する保護が起動しない、又は起動後も床が建値に留まる問題を確認した。

次の二つを因子として比較する。

- 入口：元Sourceの出生時だけでなく、実際の取得枠で5分・15分・30分の方向、傾き、勢い、確定価格構造を確認する。順行と局所反転を別の経路で認識する。
- 保護：一定の費用後利益へ達した時は技術的警戒の有無によらず保護を起動する。その後、足内値幅の中央値、収束、勢いの鈍化、既知の支持抵抗の否定で保護を強める。

入口条件を増やすだけで参加が少なくなる反例も検証する。全判断枠の技術的成立、Source出生との同時性、金融適格性、実取得、保有を分け、待機が増えた具体的理由を残す。未参加・退出後の仮想利益は計算しない。

## 保護案の式

呼値q＝5pt、片道追加滑りS、費用の価格換算K＝0.77＋2S。V_entryは新規時点で公開済みの連続3分足5本のHigh−Low中央値。中央値はATRではない。

```text
H = ceil5(max(20, 2K, 0.25V_entry))  # 費用後利益ptで表した必須起動水準
V_entry不明なら H = ceil5(max(20,2K))、後から引き上げない
最低の粗価格差床 = ceil5(K+5)
```

最低水準はC0で費用後2,000円/枚、C5で2,500円/枚。最低床はそれぞれ粗10pt/20pt。これは最適値が実証された設定ではなく、利益化瞬間からの細かすぎる起動と、約1ATRまでの遅い起動の間を比較する独自仮説である。V不明時の最低保護は、入口不明を成立に置き換える処理ではない。

G2はVで幅を制限し、警戒 `MACD失速 AND (平均間隔収束 OR prior構造否定)` で狭める。狭幅は継続し、以前の床を不利に緩めない。構造床の追加はその時点の警戒が真で、中心足が新規後、実確認・公表済みの支持抵抗だけに限る。買いはpriorLow−5pt、売りはpriorHigh＋5ptを使い、最低粗床を超えた場合だけ採用する。部分返済・全予約・Source返済との競合・同原行約定禁止・費用配賦を維持する。床価格での約定や費用後赤字0を保証せず、実際の約定結果を記録する。
