# 同入口で保護方法を変えた実現額の比較

既使用70場の109金融Nativeを全70本SHA認証し、入口E0/E1・追加滑り0/5pt・遅延0/1秒を合わせて、G0/G1/G2の3組を比較した。24比較×70場でSource全文、新規要求時刻/気配、実entry時刻/全気配/価格/枚数、SourceHoldが全て一致した。取得変更・片側だけの参加は0。したがって以下は、同入口の両実戦略の実現差として読める。機会損失や退出後の仮想利益を計算していない。

## 黒字から赤字になった内訳

入口E0、追加滑り0、遅延0では全466玉・979枚の入口が同体だった。

| 比較 | G0実現円 | 新保護実現円 | 実現差円 | 勝玉 |
| --- | ---: | ---: | ---: | ---: |
| G0とG1 | 2,173,617 | −346,383 | −2,520,000 | 203→334 |
| G0とG2 | 2,173,617 | −327,383 | −2,501,000 | 203→334 |

G1では、G0で負だった131玉が勝へ変わり、両実現額の差は **＋1,863,000円**。一方、両方で勝った203玉の実現益は **6,283,041円から1,900,041円へ減り、差は−4,383,000円**。両方で負だった132玉の実現額は−2,518,637円で同じだった。3群の加法で−2,520,000円になる。G2も同じ131玉の負→勝で＋1,867,000円、勝→勝群の差は−4,368,000円、負→負は同額だった。

勝率は約43.6%から約71.7%へ上がったが、実現額の収支は悪化した。負→勝を増やした効果と、同入口の勝→勝群で実現益が小さくなった効果を区別する必要がある。G1/G2の起動後赤字0は改善として残し、総利益の改善とは分けて扱う。

## 保存点から分かる初期の床

E0 C0D0のG1/G2は共に328玉が起動し、起動床は全て10pt。G1は全328玉で費用床が単独支配、G2は327玉で単独支配・1玉で峰−幅と同率だった。Hの全玉中央値は20pt、起動時方向幅の中央値は30ptだった。

| 保存診断 | G1 | G2 |
| --- | ---: | ---: |
| 起動幅の中央値 | 235pt | 150pt |
| 保存点で峰−幅が最低床を上回った玉 | 16/328 | 46/328 |
| 最終床が最低10ptだった玉 | 312/328 | 282/328 |
| 自己保護を要求した玉 | 277 | 290 |
| 初回自己要求の床が最低10ptだった玉 | 267/277 | 259/290 |
| 起動から初回自己要求までの中央値 | 21秒 | 25秒 |
| 狭幅になった玉 | 0 | 47 |

大半は起動時の`峰−幅`が10ptを下回り、最低費用床10ptが先に効いた。幅を広く持っていても、低い水準で起動した後に10ptへ戻れば返済を要求する。保存点と実現差を合わせると、損失へ戻る取引を減らす一方、同入口G0で大きく勝った群も早い小額の実現へ変わったことが総額悪化の中心と考えられる。これは現在の保存値に基づく説明で、起動水準や床を変えた新案の検証結果ではない。

日夜ともG1のG0比は悪化し、デイ−1,676,000円、ナイト−844,000円。ISO週別は7週中6週で悪化し、改善はW44の＋123,000円だけだった。特定の11月06日だけで全体の符号が変わったものではない。全費用/遅延とE1の比較はCSV・JSONに分けて保存し、感度設定を独立標本として数えない。

E0 C0D0はデイがG0 −100,388円、G1 −71,388円、G2 −45,388円。ナイトはG0 −42,232円からG1/G2 ＋37,768円へ改善した。デイは依然赤字。

09:50の売り7枚は、同じ57,350円の入口でG0 −7,539円、G1/G2 ＋13,461円。G0は10:24:57に方向幅500pt・当時の実玉含み＋349,461円で保護起動し、最終実現は赤字だった。G1/G2は09:56:36に方向幅80pt、H70pt、初床10ptで起動し、10:00に全決済した。起動時幅はG1 985pt、G2 480ptで、両方とも初床は最低費用床が支配した。

一方、09:20売り1枚−20,077円、12:30売り7枚−42,539円、13:55売り7枚−119,539円など、G1で起動せず同じ損失が残る玉もあった。14:45売り3枚は両方とも黒字だったが、G0 ＋99,769円、G1 ＋21,769円という実現差が出た。改善する玉と悪化する玉が同日に混在するため、同入口群と保存保護点を対応させて次の仮説を立てる。
