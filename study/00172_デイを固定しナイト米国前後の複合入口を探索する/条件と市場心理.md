# 172の固定三組を条件と心理仮説から読む

確認日：2026-11-15。172の固定条件の説明。条件は162の純辞書と列定義から照合した。この作業では先着ラベル、数量再生の成績、追加7の自然値を読み込んでいない。心理は価格・指標から考えた説明仮説であり、注文目的や参加者の感情を観測した事実ではない。

## 固定政策の対応

| 組 | q0帯 | 規則と実方向 | IFD対称幅 | 最大期限 |
| --- | --- | --- | ---: | --- |

| 主案B05_01 | POST | HP0050の元成立方向 | 400pt | H30 |

| 前半選択B06_18 | POST | EX0086の元成立方向 | 300pt | H60 |

五規則とも発火方式は**ALL**。条件が成立する各q0の方向列であり、初回交差だけに限るEDGE方式ではない。同じ物理取得の重複排除と未決予約込みの数量制約は、後段の取得・口座再生で行う。SESSIONは当該セッション内の期限であり、持越しを許す意味ではない。PRE/POSTは判断q0のNY09:30厳密前/等号以後で分類し、保有中のNY境界を理由に強制返済しない。デイは171の固定条件を保持する。

以下の「買いの説明」は**辞書が元買い方向を成立させる場合**を示す。売りは価格・指標の方向を対称に反転する。EX0064だけは、その判定後に実方向を反転させる。

## 全五規則に共通する価格品質と量の意味

| 全条件の列名 | 正確な閾値 | 説明 |
| --- | --- | --- |
| `q0_spread_points` | `>0`、かつ各規則の上限以下 | EX0064・HP0050・TP0050・EX0086は20pt、CP0031は10pt |
| `abs_q0_close_gap` | `<=1` | 判断q0のLastと当時1分終値の距離絶対値がATR5の1倍以下 |

`m1_volume_relative_prior3`は、当時の直近1分の観測量を、それに実隣接する前3本の量平均で割った比。全規則が量の既知性を必要とするが、0.5以上や0.75以上は「平均より量が増えた」という条件ではない。CP0031の1.25以上だけは、この短い比較窓に対して25%以上多い量を要求する。これはセッション全体の活況、攻撃側売買量、純資金流入を表さない。

必要な価格、指標、前値、量が未知なら、その側の成立は認めない。両側が同時成立した場合は競合待機となる。足幅やATRなどのゼロ分母を有効信号へ読み替えない。

## PREのEX0064反転：局所的な回復条件の反対側へ立つ

共通品質の3比較に加え、辞書の全条件は次の7比較である。

| 条件の列名 | 閾値 | 元買いの場合の観測 |
| --- | --- | --- |
| `bb15_position_sigma_to_side` | `<=-1.5` | q0のLastが当時BB15中心より1.5σ以上下 |
| `m5_opposite_wick_ratio` | `>=0.6` | 当時公表済み5分足の下ヒゲが足幅の60%以上 |
| `m5_rsi_center_to_side` | `<=5` | 5分RSIが55以下 |
| `m5_rsi_delta_to_side` | `>0` | 5分RSI増分が正 |
| `m5_hist_delta_to_side` | `>0` | 5分MACDヒストグラム増分が正 |
| `m5_body_ratio_to_side` | `>=0` | 5分実体が非負。陽線又は始値と終値が等しい足 |
| `m1_volume_relative_prior3` | `>=0.5` | 直近1分の観測量が前3本平均の半分以上 |

**実売りの例**では、この元買い条件が成立した同じq0で売る。下側の価格位置、長い下ヒゲ、RSI/Histの上向きという局所的な回復を観測し、その回復と反対側へ立つ。実買いは鏡像で、上側1.5σ以上・長い上ヒゲ・非正の実体・RSI55の鏡像である45以上からの低下・Hist増分低下という元売り条件を見て買う。

心理の仮説は「一時的な買い戻し・押し戻しがあっても、元の価格偏りに沿う売買が再び優勢になるかもしれない」というもの。ただし、この規則に上位方向の整合、BB内への帰還、戻りの高安割れ、**回復失敗を後続足で確認する条件はない**。したがって「回復失敗を確認してからの順行」「失敗突破を確認した反転」という名称にはしない。観測した回復がそのまま伸びれば、反転した実方向に不利となる。帯接触だけで反転を決めず、帯沿いの継続もあり得るという一般論は、この両方の経路を考える根拠にとどまる。[ボリンジャー本人の使用規則6〜8](https://www.bollingerbands.com/bollinger-band-rules)（確認日：2026-11-15）。

## POSTのHP0050：短期Hist増分の非負状態を時間窓で確認する

共通品質の3比較に加え、全条件は次の6比較である。

| 条件の列名 | 閾値 | 元買いの場合の観測 |
| --- | --- | --- |
| `h_histdelta_min_20` | `>=0` | 現在を含む直近20実分のq0観測で、5分Hist増分が全て非負 |
| `h_rsi_absdelta_max_20` | `<=12` | 同じ20実分で、5分RSI増分の絶対値が全て12以下 |
| `m5_hist_atr_to_side` | `>=0.05` | 現在の5分HistがATR5の0.05倍以上正側 |
| `long_up_votes` | `>=2` | 15/30分のEMA21傾きとDI方向、計4項のうち正側が2項以上 |
| `m15_adx_delta` | `>=0` | 15分ADX増分が非負 |
| `m1_volume_relative_prior3` | `>=0.75` | 直近1分の観測量が前3本平均の75%以上 |

履歴窓は実時間で、少なくとも16分の被覆、10以上の異なるq0価格時刻、窓内必要値の全既知を要求する。同じ5分公表値が複数q0に現れることがあるため、「20本の異なる5分足が連続上昇」とは書かない。Hist増分は非負なので横ばいも許す。RSI条件は急変の上限であり、RSI水準の高さ又はRSI増分の正符号を要求していない。

心理の仮説は、短期の価格差の改善がすぐに崩れず、背景の一部も同方向なら、継続的な追随や反対建玉の返済が価格を支えるかもしれない、というもの。HistはMACDとシグナルの距離であり、参加者数や注文動機を測らない。[StockCharts公式・MACDヒストグラム](https://chartschool.stockcharts.com/table-of-contents/technical-indicators-and-overlays/technical-indicators/macd-histogram)（確認日：2026-11-15）。ADX増分が非負でも、それだけで買い方向が強まったとは言えず、方向は別のDI/EMA条件から読む。[Fidelity公式・ADXとDMI](https://www.fidelity.com/viewpoints/active-investor/average-directional-index-ADX)（確認日：2026-11-15）。

400pt/H30は大きい到達幅と短い最大期限の組み合わせである。HPの「100%」は**Fが少なくNが多い到達済み先着率**であり、全取得の勝率や30分以内の400pt到達確率ではない。全80では34F/0A/154N/17C、到達4Night・最大場集中79.41%。前半支持不足を含む数値の正本は[README](README.md)を参照する。

## 安定性対照のPOST・CP0031：低い相対BB幅と現在の推進を組み合わせる

共通品質の3比較に加え、全条件は次の8比較である。

| 条件の列名 | 閾値 | 元買いの場合の観測 |
| --- | --- | --- |
| `bb15_width_atr_ratio` | `<=4` | 当時のBB15幅がATR15の4倍以下 |
| `bb15_position_sigma_to_side` | `>=0`、`<=1.5` | q0のLastがBB15中心以上、上側1.5σ以下 |
| `long_up_votes` | `>=3` | 15/30分のEMA21傾きとDI方向の4項中3項以上が正側 |
| `m5_body_ratio_to_side` | `>=0.6` | 公表済み5分足の正の実体が足幅の60%以上 |
| `m5_hist_delta_to_side` | `>0` | 5分Hist増分が正 |
| `m5_rsi_delta_to_side` | `>0` | 5分RSI増分が正 |
| `m1_volume_relative_prior3` | `>=1.25` | 直近1分観測量が前3本平均の1.25倍以上 |

心理の仮説は、相対的に狭い価格帯から、背景に沿う大きめの実体と短期量を伴う動きが現れたとき、追随や反対建玉の返済が加わるかもしれない、というもの。比較に使うBB幅は**BB幅/ATR15**であり、作者の中心価格で割るBandWidthとは異なる。過去の収縮、幅の再拡大、固定した高値突破を条件にしていないため、「スクイーズ後の突破を検出」とは書かない。一般的なBandWidth・収縮の考え方と、この一時点の独自近似を分ける。[ボリンジャー本人の使用規則18〜19](https://www.bollingerbands.com/bollinger-band-rules)（確認日：2026-11-15）。

150pt/H30は主案POSTの400pt/H30と出口幅が違う。安定性の解釈は、同じ入口の優劣と決めつけず、条件集合・到達幅・枠解放・後続要求が一緒に変わる比較としてRootの再生結果と結び付ける。

## 前半選択のPRE・TP0050：複数足幅の現在の方向整合

共通品質の3比較に加え、全条件は次の8比較である。

| 条件の列名 | 閾値 | 元買いの場合の観測 |
| --- | --- | --- |
| `ema_up_count` | `>=2` | 5/15/30分のEMA21傾きが正の足幅を2つ以上 |
| `di_up_count` | `>=2` | 5/15/30分で+DI優勢の足幅を2つ以上 |
| `momentum_up_count` | `>=2` | 5/15分のHist増分とRSI増分、計4項中2項以上が正 |
| `m5_hist_delta_to_side` | `>0` | 5分Hist増分が正 |
| `m5_rsi_delta_to_side` | `>0` | 5分RSI増分が正 |
| `q0_entry_minus_ema8_atr5_to_side` | `>=-0.5`、`<=1` | q0の買いAskがEMA8−0.5ATR5以上、EMA8＋1ATR5以下 |
| `m1_volume_relative_prior3` | `>=0.5` | 直近1分観測量が前3本平均の半分以上 |

EMA票とDI票は別に数えるため、**同じ2足幅で両方一致することは要求しない**。また5分Hist増分と5分RSI増分を共に正とするだけで勢い2票が成立する。したがって`momentum_up_count>=2`を「15分の勢いも回復した追加確認」と説明しない。ただし、この派生の既知性は5/15分の4列全てを必要とするため、15分値が未知なら不成立になる。

心理の仮説は、いくつかの時間幅で方向が揃い、現在の短期勢いも正で、取得側価格が短期EMAから過度に遠くない場面に参加するというもの。辞書名は「押戻し順行」だが、以前の下落・押し目・回復の交差履歴は条件にない。「押戻し完了を観測した」とは書かない。高値追随が続く経路にも、背景の遅れで転換直後を捉える経路にもなり得る。[既存教材・MAとMACDとRSI](../../docs/technical-analysis/組み合わせ/移動平均線とMACDとRSI.md)、[上位足と下位足](../../docs/technical-analysis/組み合わせ/上位足と下位足.md)（文書確認日：2026-11-15）。

こちらは元成立方向のまま売買する。心理の仮説は、相対的に外側の価格位置で、売り一巡や返済買いなどにより現在の短期回復が出た場面を捉えるというもの。45はこの研究独自の閾値で、一般的なRSI30の境界と同一視しない。BB内帰還、背景レンジ、後続高値突破を要求していないため、強い下落の途中の小反発も含み得る。RSIは強い方向相場で極端な領域に長く留まることがある。[Fidelity公式・RSI](https://www.fidelity.com/learning-center/trading-investing/technical-analysis/technical-indicator-guide/rsi)（確認日：2026-11-15）。

EX0064反転とEX0086正方向は、同じBB端・ヒゲ・勢いの技術群でも閾値と実方向が異なる。結果を見て一方を「正しい順行」、他方を「正しい反転」と一般化せず、それぞれの固定条件と入口時点の実BBO側で比較する。

## 一般論・心理仮説・研究結果をつなぐ際の注意

BB・MACD・RSI・EMA・DMIは共通の価格履歴から作られ、独立した複数の市場を観測しているわけではない。特に同じEMAの傾きと同更新終値の位置には符号の重複があり得る。[既存教材・EMAの傾きと価格位置の重複](../../docs/technical-analysis/組み合わせ/同じEMAの傾きと価格位置の重複.md)（文書確認日：2026-11-15）。

追随・返済注文の説明は、[外部一次調査](外部調査と候補.md)と[追随と買い戻しの教材](../../docs/technical-analysis/市場心理/追随と買い戻し.md)に対応する仮説として置く。これらの資料はNK225ナイトの特定条件・閾値・到達確率を実証していない。長いヒゲから「大口が買い支えた」、量比から「新資金が流入した」と断定しない。

本試行の[README](README.md)と[閲覧資料](閲覧資料.md)で、主案・安定性対照・前半選択の役割、主と初参加補完、F/A/N/C、既知利益損失、Night支持場数、前後半、買売、頻度、未知を併記した。HPの少数到達・多い未到達・前半支持不足を、条件の心理説明で覆わない。全期発見と過去だけの選択、追加7が既使用参考である点も保持する。
