**研究上は入口を維持し、出口だけを変えたX2を次の追加日の比較に残す。** 元のRC20は2026年9月21日〜11月20日の45デイで34日黒字・11日赤字。総損失1,061,234円のうち811,541円は、一度は費用後に黒字になった33建玉が最終的に失った額だった。X2は同じ133建玉を取り、そのうち5件を赤字から黒字に変えた。日経225mini 1枚換算で総損失は92,385円減り、収支は53,000円増えた。一方、後21日の収支は14,000円減った。45日はすべて探索に使っており、運用基準の交代は保留する。[比較方針](比較方針.md)・[全45日の候補別CSV](../../outputs/00228_日別の損益偏りと入口出口の比較/README.md)

## 10月8日に利益を確定できなかった二つの理由

09:05〜15:29の気配中値は69,815から69,335へ480pt下落した。RC20は売りを一度も取らず、買い2件でこの期間最大の日次損失63,154円を出した。どちらも直近3分の安値を割ったところを買う、従来の逆張り入口だった。MACD・RSIと出来高が下抜けを裏付けた一方、方向性指数の差はまだ買い優勢で、元の安全条件は反発確認を要求しなかった。11:01には5・15・30分のEMA21がすべて低下していた。

### X2が変更する条件とその代償

1. 取った方向に対して、直前の完成1分終値が当日寄りの逆側、かつ完成5分・15分終値の変化がともに逆向きなら、反発が失速する場合に備える。元の利確幅を1Rとして0.25R以上順行した後、現在も20pt以上順行し、反対の主シグナルが1回出たら0.15R幅で追尾する。この変更で8建玉を早く返済し、元の赤字3件を黒字に変えた。
2. 取得前の完成20分の高安幅が0.50R以下なら、0.50R順行で返済を要求する。実際に9建玉を早く返済し、元の赤字2件を黒字に変えた。10月8日を救ったのは1の追尾であり、この小幅利確は同日に発動しなかった。

いずれも元の利確・損切・RC保護と同時に監視し、先に成立した決済だけを採る。買売は対称。X2は取得・価格がRC20と全133件一致し、早期返済は17件、実現損益が変わったのは16件。建玉・日次の収支中央値は＋13,923円・＋24,846円でRC20と同額、実保有率は58.57%から50.89%になった。利益ゼロの日は5日から2日（9月23日・10月28日）。[反対示唆の条件](出口/条件.md)・[小幅利確の条件](出口/小値幅の追試条件.md)

期間を分けると、X2は前24日で収支＋67,000円・損失54,231円減、後21日で収支−14,000円・損失38,154円減。日次が改善したのは7日、悪化も7日で、改善額上位3日を除くと差は−50,000円。事後に小値幅だった15日では＋105,000円、中・大では−36,000円・−16,000円。11月18日は元々の固定利確に届いた買いを早く返し、＋33,923円が＋11,923円になり、X2の最大赤字日−55,308円となった。値幅判定の閾値を0.40・0.50・0.60Rと変えた小幅利確単独の収支差も−1,000円・＋25,000円・−94,000円と敏感だった。30分待機では、対RC30の収支差＋53,000円でも日末DDは87,693円から113,001円へ悪化した。採否の主対象は開始20分のX2とし、30分も待機時間の感度対照として記録する。[日と建玉の寄与](出口/日と建玉の寄与.md)・[開始待機・執行遅延の感度](全条件の比較.md)
