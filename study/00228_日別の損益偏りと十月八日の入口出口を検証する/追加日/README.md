# 追加デイで日経199_02のRCとX2を固定比較する

次のデータには同じ入口・同じ1枚枠でRCとX2を適用する。主比較は開始20分、30分は感度比較。元の価格注文、15:30までの全決済、元の価格到達までの再開待機、mini1枚の手数料と滑り計1,077円を両者で揃える。X2は取得時に直前20分の値幅が元の片幅の半分以下なら、0.50R順行で利益を確定する。もう一つの出口は、寄りから逆向きで直近の確定5分・15分も逆向きの場合に、0.25R順行後の反対通知で狭い追尾を起動する。元のRCを含め、最初に約定する返済を用いる。いずれも公開済みの板・当時の通知で判断する。[出口の定義](../出口/併用条件.py)・[条件・コードと既使用45日の照合指紋](固定条件.json)

## 入力からの実行

下記は11月20日の既使用照合。リポジトリ直下で実行する。Python・NumPy、[既存の入口生成器と原板索引器](../../00216_十一月二十日の固定入口と寄り前の反例を検証する/日経/README.md)、[共用の口座部品](../../00224_利益保護後の再エントリーをシグナルで待つ/追加日への適用.md)を使う。

```powershell
$py = 'work/複合テクニカル学習環境/Scripts/python.exe'
$section = (Get-Item 'study/00228_*/追加日').FullName
$tag = Get-Date -Format 'yyyyMMdd_HHmmss_fff'
$src = Join-Path work ('228日経入力_' + $tag)
$dest = Join-Path work ('228日経日次_' + $tag)
$date = '2026-11-20'
& $py -X utf8 "$section/追加日の入力を作る.py" --最終デイ $date --出力 $src
& $py -X utf8 "$section/二つの固定出口を比較する.py" --母集団 "$src/母集団" --純入口 "$src/純入口.npz" --板索引 "$src/前史十場と追加二場の索引参照.json" --場 ($date + '_Day') --既使用照合 --出力 $dest
```

新しいデイが揃ったら `$date` をその日へ変え、比較時の `--既使用照合` を外す。事前に同名の既使用日へ書き戻さず、実行ごとに新しい保存先を用いる。準備時は試行194の11月17日デイまでの前史に続け、同日ナイトから指定日までの保存済みデイ・ナイトを順に読み、途中の夜間の移動平均などを引き継ぐ。存在するディレクトリの原板・1分・5分の不足はエラーにする。データ提供元にフォルダそのものが欠落した場の有無は営業日程と照合する必要がある。生成した `生成入力.json` の通過順と母集団計画で元データの来歴を確認できる。既存の199_02純入口と索引があれば比較コマンドだけでもよい。従来形式のZIPは `--圧縮内` でメンバーの末尾名を指定する。

出力の `RC20_デイ.csv` と `X2C20_デイ.csv` が主比較。30分の2候補は別ファイル。日別の費用後利益・損失・収支・累計・建玉回数・実保有時間を記録する。0取引は0円。欠測で決済が確定しない場合は、未知件数、既知金額、空欄の確定収支を区別する。出力フォルダの `再生元帳.json` に入力指紋、対象日の限月・元板・板索引の由来、建玉の全項目を残す。板索引の内容と指紋、純入口側と索引側の原板指紋を照合する。原板の取得価格にはラージ最良気配を用いる。
