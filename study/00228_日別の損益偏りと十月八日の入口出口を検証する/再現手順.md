# 試行228の再現手順

2026-11-23。検証対象の日付は224の固定元帳の45デイ。原板は `../JP_OSE_Data/future/NK225/`、比較の取得要求・特徴・価格索引は前試行の再現済み入力を使う。必要な過去の作業元帳は[224](../00224_利益保護後の再エントリーをシグナルで待つ/README.md)・[227](../00227_弱い反転示唆と出来高低下を利確に使う/再現手順.md)から再生成できる。追加日の入力と実験時に用いた履歴は別保管とする。Python・NumPyは前試行と同じ作業用環境。日時は日本時間。

## 元の入口、入口変更、出口変更の再生

以下をリポジトリ直下のPowerShellで順に実行する。1秒が主比較。遅延感度は3・5秒で、基準RC側の遅延もそろえる。入口だけの変更では出口判定が見る主シグナルを元の時系列で保持する。

```powershell
$py = 'work/複合テクニカル学習環境/Scripts/python.exe'
$study = (Get-Item 'study/00228_*').FullName
$run = (Get-Item 'study/00227_*/候補を再生する.py').FullName
foreach ($file in @('順行入口を再生する.py','入れ替わりを集計する.py','旧BOの回復を待つ.py','回復確認を集計する.py')) {
    & $py -X utf8 (Join-Path $study "入口/$file")
    if ($LASTEXITCODE) { throw $file }
}
$groups = [ordered]@{
    '228出口' = '出口条件.py'
    '228小値幅' = '小値幅で確認する.py'
    '228併用1' = '併用条件.py'
}
foreach ($g in $groups.GetEnumerator()) {
    & $py -X utf8 $run --定義 (Join-Path $study "出口/$($g.Value)") --出力 (Join-Path work $g.Key)
    if ($LASTEXITCODE) { throw $g.Key }
}
foreach ($delay in @(3,5)) {
    & $py -X utf8 $run --定義 (Join-Path $study '出口/併用条件.py') --候補 X2 --執行秒 $delay --出力 "work/228併用$delay"
    if ($LASTEXITCODE) { throw "遅延 $delay 秒" }
}
foreach ($file in @('両方を再生する.py','原行を照合する.py','集計する.py')) {
    & $py -X utf8 (Join-Path $study $file)
    if ($LASTEXITCODE) { throw $file }
}
```

## CSVと日形・原行の照合

公式CSVは条件・待機時間ごとに分けてあり、総利益、総損失、収支、累計、建玉回数を日別明細からたどれる。公開した20口座60CSVの77,287セルが元帳から作った表と一致した。他の候補も必要な場合には `集計する.py --全候補CSV` で入力を生成し、別の作業先へ出力できる。

```powershell
$deps = Join-Path $env:USERPROFILE '.cache/codex-runtimes/codex-primary-runtime/dependencies/node'
& (Join-Path $deps 'bin/node.exe') scripts/損益CSV/候補別に出力する.mjs --input work/228集計/閲覧入力.json --output work/228再生成/CSV --proof work/228再生成/照合 --dependencies $deps
if ($LASTEXITCODE) { throw 'CSV書出し' }
& $py -X utf8 (Join-Path $study '集計する.py') --照合 work/228再生成/CSV
if ($LASTEXITCODE) { throw '全セル照合' }
```

日ごとの形は[形と収支の照合](日別の形/README.md)、10月8日の当時情報・取引時刻と画像は[二建玉の診断](十月八日/README.md)の手順で再生成する。以下は日形CSVと小値幅・併用の元帳に依存する最終照合。固定した次のデイの入力準備と比較方法は[追加日](追加日/README.md)にまとめた。
