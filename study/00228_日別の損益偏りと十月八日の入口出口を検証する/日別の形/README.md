# RC20の損益は、どんな一日に偏ったか

2026-11-23。RC20は日経225mini 1枚相当、全45デイ・133建玉で、**上昇日も下落日も黒字だった。最も明らかな弱点は値幅の小さい日**で、利益が1円もなかった5日は全て値幅の小さい15日に含まれていた。一日の片道比や中心へ戻った割合だけでは赤字日を判別しにくい。[日別の価格・買いと売りの利益と損失CSV](../../../outputs/00228_日別の損益偏りと入口出口の比較/228_RC20_日別の形/日別の形と損益.csv)・[各区分の集計CSV](../../../outputs/00228_日別の損益偏りと入口出口の比較/228_RC20_日別の形/集計.csv)

下落日は日数・売り件数ともに多く、そこでの売りが総収支への最大の寄与だった。最大の黒字日を各方向から1日ずつ除いても上昇日の計＋316,996円・下落日の計＋480,533円。前24日／後21日のどちらでも両方向の合計は黒字だが、**全方向の買いだけを分解すると前24日＋276,152円、後21日−20,079円**で、売りは＋243,690円・＋506,996円だった。この内訳は同じ口座から抽出した実績で、片側専用に変更した場合の口座収支とは区別する。

時間の定義も変えて、確定した08:45の1分足始値と15:39の1分足終値を比べると、上昇19日で＋354,765円、下落26日で＋651,994円だった。デイのザラバ全体とRC20の売買窓の違いで6日の方向分類が変わっても、双方で収益を得たという結論は続いた。[時間窓・欠測の感度](検算と別の窓.md)

各尺度は同じ45日の切り口なので縦に合算しない。値幅％は窓内の高安幅÷始値。各15日の値幅はそれぞれ0.593〜1.255%、1.261〜1.750%、1.766〜4.879%。**小・中・大で1建玉当たりの収支は約＋2,030円、＋11,555円、＋7,624円**となった。大きく動いた日の収支の増加には、実際に多く建てたことも寄与する。建玉ごとの当初の注文片幅がその日の高安幅に占める割合の中央値は46.2%、37.2%、15.3%。値幅の小さい日は目標に必要な移動が相対的に大きく、上位3黒字日を除いた残り12日の収支が−74,463円だった。利益ゼロは9月23日、10月5日・8日・12日・28日。取引前に最終値幅は分からない。

片道日と往復日の双方に黒字日があった。途中の推移まで含む別の定義でも、始終差の絶対値÷5分終値間の道のりの上位15日は14黒字・＋550,996円、中位15日は8黒字・＋226,304円、下位15日は12黒字・＋229,459円だった。一方で、**黒字日34日と赤字日11日を直接分けると日別片道比の中央値は0.460と0.456、値幅％の中央値は1.491%と1.064%**。12:15の前後で向きが反転し、前後とも日中値幅の1/4以上動いた切り返しは、上昇後下落2日で1黒字・−36,308円、下落後上昇7日で5黒字・＋168,383円。2日・7日で切り返しの上下差を一般化するのは難しい。

中心回帰は、直前30分の平均から離れた時点でその平均を固定し、15分後に同じ価格へ近づいた割合を測った。60%以上の4日は10月9日・20日・11月6日・11日。最大黒字日10月20日を除いた3日も計＋155,999円だった。中心回帰が少ない20日でも16日が黒字で、RC20が平均回帰日だけで利益を出したという結果ではない。中心まで完全に戻った頻度や、逆張り戦略で費用後に利益が残る頻度とは異なる。[分類式と採取間隔](分類条件.md)

日別収支とのSpearman順位相関は、始終変化率−0.125、始終差の絶対値＋0.364、値幅％＋0.417、片道比＋0.219、5分効率＋0.292、中心回帰率＋0.260（有効41日）。日中値幅は同日の収支と関連したが、その大小によって明日の収支を予測した結果ではない。2026年9月21日〜11月20日を探索に使っており、相場区分の強度や多数の区分間差を独立な将来検証とはみなさない。

事後の値幅が小さかった15日のうち、取得時の完成20分の値幅が元のIFD片幅の半分以下だった日は4日。10月8日の2件はいずれも該当しなかった。期間ごとの赤字日・利益ゼロ日・売買内訳と、事前に得られる情報の限界も照合した。[小値幅を取引中に判別できたか](小値幅を取引中に判別できたか.md)

## 再現

ラージの正常な最良買気配・売気配の中値から形を求め、RC20の建玉は清算側の気配とmini換算100円/pt、往復手数料77円、片道5ptずつの追加滑り想定で検算した。日次・建玉の両方で全45日・133件が正式CSVと一致した。価格の形に用いる正常気配があったのは各日384分中320〜384分。終値が欠けた分は観測不足とし、中心回帰の統計に補間値を使わない。窓の最初の正常原行は全日09:05:00〜09:05:20、最後は15:28:13〜15:28:59。

```powershell
$py = 'work/複合テクニカル学習環境/Scripts/python.exe'
$group = (Get-Item 'study/00228*/日別の形').FullName
& $py -X utf8 (Join-Path $group '形と収支を照合する.py')
& $py -X utf8 (Join-Path $group '窓と欠測を入れ替える.py')
$deps = Join-Path $env:USERPROFILE '.cache/codex-runtimes/codex-primary-runtime/dependencies/node'
& (Join-Path $deps 'bin/node.exe') scripts/損益CSV/候補別に出力する.mjs --input work/228日別の形/CSV入力.json --output work/228形再生成/CSV --proof work/228形再生成/照合 --dependencies $deps
```
