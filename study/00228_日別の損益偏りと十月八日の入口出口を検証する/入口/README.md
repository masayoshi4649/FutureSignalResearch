# 10月8日を説明できる見送りが、他の日の損失も防ぐか

元の日経199_02の入口を維持する。10月8日の2件は下抜けを逆張りした旧BO0065の買いで、確定5分の価格・モメンタムが買いに逆らっていた。15分EMAとDIも買いに逆らった2件目だけを見送るE2では、最初の買いは同じ−36,077円。次の買いを見送ると、空いた枠で11:36・13:56に売りを取得し、＋33,923円・＋30,923円になった。当日は−63,154円から＋28,769円に変わるが、残り44日の収支差は−40,077円、総損失は45日で8,077円増えた。

より広い対象を反転したE4は当日2件の売りで＋56,846円。しかし20分待機で実際に反転した全9件は合計−25,693円。実側を反転してよかったのは当日の2件に偏る。全45日のRC20では、E3の条件に直接該当した9件は全て旧BOだった。旧BOだけに限定したK1は両出口・両待機ともE3と全建玉が一致した。

旧BOを一度見送り、直近3分の高安幅の中央を取り戻し、確定1分足の実体と終値の変化が建てる側に一致するまで待つK2も試した。開始20分のRCで、この遅い確認から実現した14件は13日にまたがり、8勝6敗、計＋1,922円。新しい元要求だけを待つK3より口座収支が109,461円上がったが、元のRC20比では総損失が201,385円減る一方で総利益も307,461円減少した。赤字日は11→14、利益の出ない赤字日は5→7、日末最大ドローダウンは63,154→112,385円。10月8日は短期回復を待った2件で収益を得られず、別の10:03の売り1件で−21,077円だった。開始30分でも悪化し、待機を入口に導入する根拠は得られなかった。
