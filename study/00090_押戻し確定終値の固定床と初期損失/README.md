# 00090：押戻し確定終値の固定床と初期損失

2026-11-08。89のE1入口・G1配分・Source現在量・15分時計を固定し、保存p確定3分Closeの逆側10pt価格床off/onを比較した。全66場は既使用で安定利益は未確認。

P0は旧89 E1G1のATR/最低建値/cash床/既存退出。P1は買いp.Close−10・売りp.Close＋10を要求時に凍結し、実建値から換算して旧床へmax合成する。pは最新押し足の終値であり、高安や初回押し足ではない。判定は各原行の返済側BBOで、確定足まで返済を待たない。

売買は符号反転の同じ条件。費用後現在単価益strict正で最低新規価格床を起動し、G1部分収穫・実確定益cash床・ATR/125pt/3分失敗/Sourceを維持する。片道手数料11円＋滑り5pt、往復122円/実枚。D0は次正常行、D1は追加価格時計1秒の次適格行。ラージ板のmicro代理約定。

公開pは生存eventの出典で、EMA180秒鮮度を流用しない。新しい入口gate/格子丸め/再参加は加えていない。取得時既否定を記録し、同原行から保護する。後続pやevent失効で線を動かさず、同値床は旧G1理由を優先する。床の起動と次板の費用後黒字約定は別である。
