### 損失減少がどこから生じたか

- L00〜07では8案とも総損失は減ったが、利確幅を延ばす前から発動する追尾で従来の黒字も縮小した。L00の元181件では固定取引だけで収支が431,000円下がった。目標を変えずに起動を0.95Rに遅らせるL09では、元IFDと全取引・収支が一致した。
- L10では口座全体の既知収支が86,077円増加、既知損失が51,308円減少。利益後赤字55→52件、その確定損失891,235→853,004円、赤字日12→11日、日末最大DD147,463円は同じ。保有50.37%、日次・建玉中央値下限は22,692円・11,923円。自身の利益上位3日を除く収支は＋645,680円で、元の＋668,526円を下回った。
- **L10の同じ取得だけを比べたときは、出口を変えただけで収支は向上しなかった。** 固定した元181件は元より2,000円少ない。口座再生の共通172件の確定収支は両方＋1,054,756円。元だけに残った9件は−34,693円、新たに取得した9件は既知＋51,384円・不明1件で、この入れ替わりが全86,077円差を説明する。後者の10月6日の70,460円での売りは通常期限の返済気配が不足し、損益を確定できなかった。元と新の確定額比較に使っていない。同じ日付で両方の確定値がある範囲では、日計で改善10日、悪化12日。
- L11は目標を近くすると増益が4,000円まで薄れ、前24日の収支は元より悪化する。L12〜14の遅い起動では全額確定のまま収支が3,000〜15,000円伸びたが、総損失は元と同額で、後21日の収支は元より少ない。参加の入れ替わり・不明決済と閾値感応を含めて、L10は固定追試用の比較候補。全15案の前後・集中度・損益は[二群の比較.json](二群の比較.json)に収録した。

### 再現

[共通の元帳・索引と約定規則](../口座再生の仕様.md)を準備し、リポジトリ直下で実行する。各群の元帳は `work/219延長` と `work/219遅延長` に分ける。一つの口座の中の予約・建玉は合わせて1枚まで。

```powershell
$trial = (Get-ChildItem study -Directory -Filter '00219_*').FullName
python -X utf8 (Join-Path $trial '口座再生.py') --出口定義 (Join-Path $trial '利幅延長/出口定義.py') --出力 'work/219延長'
python -X utf8 (Join-Path $trial '口座再生.py') --出口定義 (Join-Path $trial '利幅延長/遅い起動の出口.py') --出力 'work/219遅延長'
python -X utf8 (Join-Path $trial '利幅延長/成績を比較する.py')
```
