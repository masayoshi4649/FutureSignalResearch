# 出口の変更で収支差が最も開いた2日

SessionTradeViewerで [一覧.resources.json](一覧.resources.json) を開き、同じ日の「元IFD」「W31」「W36」を切り替える。45デイでW31と元IFDの差が最大となった改善日・悪化日を各1日選んだ。日経225ラージの板の履歴を使い、日経225mini 1枚の建玉と返済を表示する。各片の費用538.5円は手数料38.5円と想定滑り5pt分500円を合わせた値である。

|デイ|元IFD|W31|W36|口座ごとの建玉回数|
|---|---:|---:|---:|---:|
|10月7日|＋38,615円|＋19,615円|＋19,615円|各5回|
|11月17日|−58,462円|−9,462円|−58,462円|各6回|

**10月7日は、利益を確保した直後の売り直しで悪化した。** 共通の11:05:03の売り（70,350）を元IFDは12:05:13に70,390で返して−5,077円。両追尾案は11:34:40に70,310で利益を保護し＋2,923円だった。この1件では8,000円改善した。しかし空いた枠で11:35:08に新たに売って−16,077円となり、元口座が12:26:17に建てて＋10,923円だった売りと入れ替わった。当日差−19,000円は、共通売りの差＋8,000円と後続売りの差−27,000円で説明できる。

**11月17日は、午後の買いの損切りを少し遠くしたことが改善の起点だった。** 共通の12:42:03の買い（59,150）を元IFDとW36は13:05:23に58,800で返して−36,077円。W31は保有を続け、13:42:18の期限に59,110で返して−5,077円だった。W31の次の売りは14:21:02に建って＋8,923円。元IFDとW36の13:26:01の売りは−9,077円だった。当日差＋49,000円のうち31,000円は共通買いの損失縮小、18,000円は後続売りの入れ替わりである。
