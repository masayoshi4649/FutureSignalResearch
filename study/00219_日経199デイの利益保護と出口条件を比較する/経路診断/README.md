# 元IFDの含み益は、どの建玉で赤字に変わったか

**165件に一度は費用後含み益があり、そのうち55件は赤字で決済した。** この55件の確定損失は891,235円で、元口座全体の損失1,342,467円の66.4%だった。残る16件の赤字は、保有中に費用後黒字を観測できなかった建玉で計451,232円だった。

到達群は入れ子である。5,000円を越えた142件のうち108件は最終的にも黒字だった。低い水準で保護を始めるほど救える赤字の候補が増えると同時に、後で大きな利益を得た建玉にも働く。表は各建玉が観測した極値の事後集計で、ピーク決済や上記の確定損失全額を回収できることを意味しない。

10月14日の買いは元幅400ptに対して180pt順行した後、400pt逆行して損切りに達した。9月29日の売りは元幅350ptに対して330pt順行し、利確水準まで20ptを残して反転した。固定幅に近い売りの戻しを抑える方法と、幅の半分にも届かない買いを保護する方法では、起動が必要な水準が異なる。

早期の損切りにも代償がある。取得後5分時点で保有継続かつ、それまで一度も費用後黒字を観測しなかった41件は、5分時点の最後の正常気配で計−321,157円、元決済では−84,157円だった。15分まで同じ状態だった18件では、それぞれ−248,386円と−294,386円。この時点比較には、新しい決済注文の遅延・後続予約は入っていない。[新旧の出口を実際に再生する条件](../閾値.md)

## 観測と再現

元口座の181件は全件決済済み。元の価格索引に対して、新規・決済の時刻と原行、実側気配による取得価格・返済価格・費用後収支を照合した。新規原行の返済側気配を含む。正常でなかった1,542観測行は損益算出から外し、間を補間しない。建玉内の隣接する正常気配の最大間隔は225秒で、元の300秒の欠測打切りを超えた例はなかった。同一極値に複数回達した場合は最初の原行と時刻を記録する。観測行間の値動き、ラージ板を代用したmini実約定の成立は検証外。

## 提案した出口の独立照合
