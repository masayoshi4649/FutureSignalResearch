# 129の再現手順

Go1.24.2 windows/amd64、Python標準ライブラリ。CSVはNode24.22.1・Artifact2.8.129を使用した。保存正本の照合では原板を読まない。金融ラベルを再生成する場合だけ、元入力に記録された共有原板の参照先を必要とする。

- [追補コード](検算と保管の追補コード.zip)：結果後の独立検算器、固定124のFraction算術、保管/復元補助。[索引](追補コード索引.json)。研究条件のF0/F1固定源とは区別する。

## 1. 原板なしで保存資料を復元する

リポジトリルートで以下を実行する。出力先は未作成が必須。ZIP全源のSHA/CRC、各gzip解凍SHAを確認し、小型コードと入力2・結果2・集計2を復元する。全73場の0出生も保持する。

```powershell
python "study/00129_背景方向と短期構造回復で取得を早める/再現資料/保存資料を復元する.py" --destination work/129再現
```

展開先のMDは実行前版を含む。正式な結果の閲覧はこの試行の現行文書を用い、原文は固定条件の追跡に使う。別作業先では旧絶対パス入りのF0/F1 runnerをそのまま上書き固定せず、以下の直接CLIと保存指紋を使う。

人工テストは展開先の`work/129短期回復の出生`、`work/129執行区間を限定する評価器`の各フォルダで`go test -count=1 ./...`。保存コードを別の作業先から復元して、両モジュールの人工テストが成功することも確認した。

独立検算器は`work/129独立検算/独立集計する.py`。`--series new`又は`baseline`と、`--result-sha256`、`--input-sha256`、`--aggregate-sha256`、未作成の`--output`を指定する。集計SHAは各保存集計のbytesから計算する。Root集計関数をimportせず新120/対照140・計6,440値を確認した[証跡](../検査/独立検算の短報.md)がある。

## 2. 原板から同じ固定入口を金融再生する場合

別の未作成先へ`--inputs-only`を付けて復元すると、保存結果/集計を置かずコードと固定入力2だけを用意する。共有原板は入力に記録された参照先へ配置し、bytes/SHA/11品質を維持する。

```powershell
python "study/00129_背景方向と短期構造回復で取得を早める/再現資料/保存資料を復元する.py" --destination work/129再計算 --inputs-only
```

以降は`work/129再計算`を再現ルートとして、`work/129執行区間を限定する評価器`で`go test -count=1 ./...`と`go build -o 独立出生の再生.exe ./cmd/run`を行う。再現ルートへ戻り、以下を実行する。

```powershell
work/129執行区間を限定する評価器/独立出生の再生.exe --input work/129短期回復の評価/入力.json --sha256 96382d12330a49fc5237e78bf3d888c4be52ade98ed6ff6017057aee5f4f7d56 --output work/129短期回復の評価/新入口結果.json --workers 4
work/129執行区間を限定する評価器/独立出生の再生.exe --input work/128Raw時計の評価/gap300入力.json --sha256 474455be28a60248c7418fd69e123297738f6f782648b9c52aab076384e3c384 --output work/129短期回復の評価/元出生結果.json --workers 4
```

新旧とも同じ区間限定器。q.Time≥End−300を執行/観測へ使わず、新規はmin旧force,終了−120。価格時計は受信/実約定時計ではない。結果には原板mtime等の監査情報も入るので、別環境で保存SHAが変われば監査差とラベル/金額差を分けて記録し、元の指紋を書き換えない。

## 3. 集計とCSVを再作成する

結果SHAを求め、新入口は`work/129区間限定の短期回復集計/集計する.py`、対照は`work/129元出生の区間対照集計/集計する.py`へ、`--result`、`--sha256`、`--input`、`--input-sha256`、`--output-dir`を渡す。出力先はそれぞれ`work/129短期回復の評価/新入口集計`、`元出生集計`。旧124の固定算術コードもZIPに含む。H30/60×5幅×BBO/Last・新6/対照7政策を保存する。

各集計の`CSV用の表.json`のSHAを渡して次を実行する。

```powershell
python work/129閲覧表をまとめる.py --primary-sha256 新入口表のSHA --base-sha256 元出生表のSHA
```

同じラベル/入力なら閲覧三表JSONのSHAは`7bdc36ce3311571eaaed7fb95df09e8d8003b8692799105e2b6b2273e53336f2`。列名の和集合へ元セルを転記し、政策対象外だけnullにする。`node_modules`は同版Artifactの既存runtimeを参照し、ZIPへ大量の依存を複写しない。元PCのNode/module参照先は[生成確認](../検査/CSVの生成確認.json)に記録している。

```powershell
node work/129短期回復CSV出力/出力する.mjs --input work/129短期回復の評価/CSV用の閲覧表.json --sha256 7bdc36ce3311571eaaed7fb95df09e8d8003b8692799105e2b6b2273e53336f2 --output work/129再現CSV
python work/129短期回復CSV出力/CSVを独立再読する.py --input work/129短期回復の評価/CSV用の閲覧表.json --sha256 7bdc36ce3311571eaaed7fb95df09e8d8003b8692799105e2b6b2273e53336f2 --folder work/129再現CSV --output work/129再読.json
```

正式CSVは[案内](../../../outputs/01a1889f-f2af-7943-a047-543275ee9ed2/129短期回復CSV/README.md)。全26,990データcell/15,563数値を独立再読し、Rootが3プレビューを視認済み。xlsxは生成しない。CSVを正式フォルダへ重複保存しない。

## 4. 自然出生から作り直す場合

背景の固定128即時gap300公表（保存SHA`e382858a62865b321449279d9653f5b1c644c97f6c4254cbae8dd9d3ea065e62`）を[128再現手順](../../00128_Raw価格時計で構造回復の出生を比較する/再現資料/再現手順.md)から復元する。CSV値を時刻前倒しして代用しない。出生器をbuild後、`--execute-all`、`--background`、`--sha256`、未作成`--output`を指定する。正確なCLIはZIP内の出生器READMEにある。

全73場を一Raw走査ずつ因果再生し、旧129の自然出生SHAは`d67b0787f2e34c2a63bec4b7f5c6d02a74c4362c2b6b1d3da1b5efb723a62d6a`、91出生/38場。転記は`work/129出生を入力へ渡す.py --sha256 出生SHA`で、取得入力SHA96382d…へ接続する。生成された大きな公表は作業領域に置き、再度恒久複製しない。出生の場別Statsは[圧縮保存](../成果物/出生段階Stats.json.gz)、金融なしの診断は[出生不足](../根拠/出生不足の診断.md)。

120の三関数/128decoderの出自照合まで再実行する場合は、旧120/128の正式コードも元のwork位置へ復元する。通常のGo人工検査と固定入力の金融再生は129コードZIPで自己完結する。Rootの固定器は当時の全56源/F0・入力/F1の順序証拠として保管し、結果後の検算器/閲覧器と区別する。
