**実行済み・主U1は未達。** 到達済み先着率62.63%（372順/222逆）、697取得・全73場、全時間平均0.9668回/時。C5既知利益4,724,429円/損失3,374,174円/差引+1,350,255円、IFD未知12件。後25場は49.13%・既知差引−240,706円で、70%と後期の安定性を確認できなかった。比較U0/U65へ主を交換しない。

## 何を比較したか

固定151 P65の非ゼロ方向を、30分EMA21・30/15分DI・15分ADXによる強い反対背景Gで分類した。G内は1分実体・q0Lastで残る前実体回復・5分Hist/RSI増分・同足相対量を各方向で確認し、片側だけが成立すれば維持/切替、未知や両側不成立なら待機するAを比較した。主BはAの最終注文側に5分EMA8から順向き1ATR以内の上限を追加した。G外のAは元P65を維持する。

旧C1全87を保護したU1=B＋C1を主、U0=A＋C1を比較、U65=P65＋C1を固定対照とした。新学習・再推論・新特徴・Raw走査は行っていない。買売は同じ条件を各実側Ask0/Bid0配列に適用し、全q0判断後にだけq1を結合した。[実行前条件](条件.md)と[設定済み513セル](設定と結果.md)はF0原文を保持している。そこに残る「未実行」はF0時点の記録で、現在の実行状態は本READMEと末尾結果節に示す。

## 件数の変化と解釈

P65は1,126出生/1,118取得、Aは755/748、Bは620/614。Bのうち旧C1と同q1の4件は保護され、U1は697取得となった。P65→A→Bでは方向維持/切替/待機があるため、異なる政策の金額差を同じ取引の改善と即断しない。U65からU1で全体率・既知差引は改善したが、70%と後期安定は未達で、Bの追加によるU0との差引改善も全体では確認できない。

一般説明は方向をDI/MA、強さをADX、勢いをHist/RSI、構造を実体/現在Last、量を同r相対量、位置を最終側EMA8距離と分けるもの。心理は「背景へ逆らう場合も背景へ戻す場合も回復・動力・量の確認を要求する」という仮説であり、参加者の意思や反転完了の証明ではない。事後の枝別診断は[根拠](根拠/固定P65から複合回復へ変えた結果.md)へ分離し、新閾値を採用していない。

事後の同case照合では18件の方向変更が、旧P65の10順8逆から新A0の7順11逆へ悪化した。一方、強反対背景で新たに待機した旧成立集合370件は旧記録で逆行が多かった。全体の改善を切替成功と同一視しない。後25のA0全193件/B0全151件はG外維持で、今回のG内回復枝が後期の不調を直したわけではない。G外へRを一律追加する新規則もここでは採用していない。
