## 固定した比較

同じ足IDを重ねて数えない直近3つの確定5分足から、EMA8/21方向・DI・方向の持続を計算。EMA差の収束/拡散、MACD/RSI変化、固定価格水準の翌1分での受容、相対量を合わせた。ここでいう圧力は技術指標による代理であり、板フローや吸収の直接観測ではない。

受容は前q0で越えた高安/EMA8を固定し、30〜90秒後の連続1分でも同側にいること。厳条件は足内逆端も水準を割らず、緩条件は0.1ATR以内の一時戻りを許す。時計空白と途中戻りを区別する。

IFDは固定±10/15TOPIXpt、又は**q0以前に公表された**5分ATR×1.5/2.5を5〜25ptへ制限し0.25pt切上げ。取得後は幅を変えない。H60、保有/予約1枚、終了15分前決済、開始待機なし、miniTOPIX片道41.8円＋0.25ptを維持。形成別・同幅規則のT0を未知非増加対照とした。[条件封印](条件.json)・[金融封印](金融開始前固定.json)。
