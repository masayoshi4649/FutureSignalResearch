## 読み方と限界

- 主率は仮250/全仮約定。125・期限・不足も仮約定分母へ含め、未約定は別。実黒字率や固定250利確率ではない。非重複間引きは30分間引きではない。
- 保有継続は非待ち。判定不能を全て待ちとする保守上限=(待ち+判定不能)/全予定枠が50%以下で活動適格。評価の全枠は740/888/74で、初期20場を加えたり欠測を除いたりしない。
- 葉率は0.5重みの学習標本内比率で、将来確率ではない。葉別評価は選ばれた入口だけであり、全方向scoreの校正ではない。基礎・価格履歴を独立した心理の票と数えない。
- H0→B0は準備/入力と再fitを含む方針差。B0→F0は同ready/同教師pairに対してZの固定根と子探索を変える比較で、Z単独の因果効果ではない。F18固定rootはgini最適分岐でなく、空枝はscore未定。片側でも未知leaf到達なら両方向WAITで、0点補完や救済をしない。
- 共通木の最高score側だけに1/3以上、枠60/6日/10場、path異種family2以上かつtrend又はoscを要求する。同点/最高側不適格はWAITで、次点へ救済しない。
- 運用は固定49。定時最新3分ATRからDを固定し、現在正常返済BBOの粗益−122円>0strictで利益旗、最低名目entry床。損失側も定時外に追尾し、返済pending中の保護は凍結する。0/5/10ptは同じ実約定の費用感応。品質注意時の確定nullを観測額で埋めない。
- 木の探索・期間設計まで含めて既使用66場の開発。未予約11/5Day両商品は使わず、未見利益や心理的因果の実証とはしない。貪欲最適分岐の別算法再学習や全tick戦略の独立実装まで監査したとは述べない。
