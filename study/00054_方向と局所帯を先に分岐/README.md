## 読み方と限界

- 仮250/全仮約定は入口経路の率で、125・期限・不足を含み未約定は別。実黒字率や固定250利確ではない。群内非重複間引きは30分間引きではない。
- 全予定枠は740/888/74。保有非待ち、判定不能も含む保守待ち上限=(待ち+判定不能)/全枠<=50%。欠測枠や初期warmupを分母から除かない。
- 学習葉率は重み0.5の標本内率で未来確率ではない。葉評価は採用入口だけ、全score校正ではない。葉/局面の間引きは非加算、実額は元運用の帰属で限定再運用ではない。
- 固定ZとDI符号はgini最適分割ではない。固定price+trendで技法条件が構造上充足するため、複数心理の独立二票や学習発見の証拠とはしない。D0は群分けと子の探索深さを変える総合比較。
- 未知leafのscore=nullは0%ではない。一方向でも未知なら両方向WAIT。既知側へ救済せず、双方既知でも最高側だけにscore>=1/3・unique枠60/6日/10場・family条件を課し、不適格なら待つ。
- 運用は固定49。定時最新3分ATRでD固定、現在正常返済BBO粗益−122円>0strictで利益旗・最低名目entry床。損失/利益追尾は定時外も行い、返済pending中保護は凍結。費用0/5/10は同約定、品質nullと観測額を混同しない。
- 全66場は開発既使用、未予約11/5Day両商品は不使用。未見利益・市場心理の因果実証、別算法による最適分岐の独立再学習まで保証しない。
