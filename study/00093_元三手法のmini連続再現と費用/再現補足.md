# 再現手順と検査の範囲

Go1.24.2/windows-amd64/CGO=0、Python3.14.3標準ライブラリを使用した。兄弟SessionTradeExecuterは条件JSONの43指紋、過去データは固定80台帳の指紋を必要とする。新しい未使用日の本文は使わない。

次の例はリポジトリのルートから実行する。保存先は未作成の例示名で、既存結果を削除・上書きしない。Pythonは同版の別実行ファイルへ置き換えられる。

```powershell
New-Item -ItemType Directory -Path work/93再現例
$env:CGO_ENABLED = '0'
go -C scripts/FAR元三手法のmini連続再現 test ./...
go -C scripts/FAR元三手法のmini連続再現 vet ./...
go -C scripts/FAR元三手法のmini連続再現 build -o ../../work/93再現例/93.exe ./cmd/batch
& work/venvs/technical-tree/Scripts/python.exe -B -X utf8 scripts/FAR元三手法のmini連続再現/固定入力監査.py --out work/93再現例/入力前_正式54場.json
& work/93再現例/93.exe --manifest study/00080_FAR後期三手法の15分移植と利益保護/入力台帳.json --out work/93再現例/全54場
& work/venvs/technical-tree/Scripts/python.exe -B -X utf8 scripts/FAR元三手法のmini連続再現/固定入力監査.py --before work/93再現例/入力前_正式54場.json --out work/93再現例/入力後_正式54場.json
& work/venvs/technical-tree/Scripts/python.exe -B -X utf8 scripts/FAR元三手法のmini連続再現/集計と閲覧形式.py --run work/93再現例/全54場 --out work/93再現例/集計
```

**最後の集計は終了1を返す。** 独立会計検算と成果物保存後、固定した元micro粗額にD−300/P＋5,000/U0の差があることを検出するためである。期待値を変えたり、保存結果のflagをtrueへ変えたりしない。過去の集計形式誤読は[訂正](集計形式訂正.json)で扱い、売買Goは変更していない。

この暫定状態を明示したうえで、報告とViewerだけの検算を続ける。

```powershell
& work/venvs/technical-tree/Scripts/python.exe -B -X utf8 scripts/FAR元連続再現の監査/原板照合.py --results work/93再現例/全54場 --out work/93再現例/原板照合.json --workers 4
& work/venvs/technical-tree/Scripts/python.exe -B -X utf8 scripts/FAR元連続再現の監査/報告.py --summary work/93再現例/集計/結果.json --native work/93再現例/集計 --settings study/00093_元三手法のmini連続再現と費用/設定と結果.md --out work/93再現例/報告 --allow-reference-mismatch
& work/venvs/technical-tree/Scripts/python.exe -B -X utf8 scripts/FAR元連続再現の監査/報告.py --summary work/93再現例/集計/結果.json --native work/93再現例/集計 --settings study/00093_元三手法のmini連続再現と費用/設定と結果.md --out work/93再現例/報告 --allow-reference-mismatch --check
& work/venvs/technical-tree/Scripts/python.exe -B -X utf8 scripts/FAR元連続再現の監査/境界1行差を診断する.py --work work/93再現例 --out work/93再現例/境界診断
```

報告の設定欄は結果markerを除くと、条件固定時のSHA256 `bd2d6ec8258dce5b24fe1bbd1242b766d25973e8835e2abc2dc536baec6eec4d` に復元できる。計画時の「未実行」はその当時の状態であり、現在の結果はmarkerと結果.mdを読む。

Viewerが既に8092で稼働し、resource_rootが本リポジトリ、data_rootが過去データを指す場合だけ、次の数値検算を行える。サーバーの停止・再起動・設定変更はしない。

```powershell
& work/venvs/technical-tree/Scripts/python.exe -B -X utf8 scripts/FAR元連続再現の監査/表示監査.py --run --catalog work/93再現例/集計/一覧.resources.json --result work/93再現例/集計/結果.json --out work/93再現例/Viewer照合.json --workers 8 --allow-reference-mismatch
```

Nativeの指紋、原板物理行、次正常行、独立した所有と費用、Viewerの一致は別の検査である。元粗額不一致のままでも、明示オプション付きの報告・Viewer検査は自身の範囲で成功し得る。これを元手法全面同値の成功へ読み替えない。

本試行の主と仮定滑りの2列は、費用0の元判断から得た同じ約定へ費用を分けて引いたものである。次に費用後正益を起点とする追尾を実装する際は、費用仮定が起動・退出時刻も変える。費用を変えた出口は実行経路ごとに再検証し、単なる後引き感度と混同しない。
