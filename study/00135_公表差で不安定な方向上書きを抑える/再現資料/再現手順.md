[保管索引](../保管索引.json)にサイズ・SHA・復元先を残した。固定コードは[追加7源ZIP](135追加固定コード.zip)と、131の[共有コードZIP](../../00131_中期MACDの位相で複合入口の方向を切り替える/再現資料/131コード.zip)の算術/評価2源。方向chooser、135評価器・正式MD生成原文を保つ。結果後の独立検算・CSV・保管・非金融診断コードは[後発ZIP](検算と保管の追補コード.zip)へ分けた。

[新入力](../../../inputs/00135_公表差一致の固定方向/README.md)はchoicesと公表再生の2gzip計365,595 bytes。choices解凍SHA`4855a482f85a5dac40611e961e7a9d03efd9e4c79311cad1021e3bc9f80cd9d1`、79出生×三公表の非金融JSONは`1c034b7b55e9d5e10ed2ca9f25d4ffd5c17d5b187667dd46b69a845e6d4e7b81`。旧124観測/特徴・126集計・metadataは既存資源を参照し、Raw・巨大入力・全件中間表を重複保存しない。

## 保存観測からの再集計

Python標準ライブラリだけで実行する。リポジトリルートから未作成workへ復元し、別名のパス台帳で照合する。

```powershell
python -X utf8 "study/00135_公表差で不安定な方向上書きを抑える/再現資料/保存資料を復元する.py" --destination work/135再現
python -X utf8 "study/00135_公表差で不安定な方向上書きを抑える/再現資料/保存観測から再集計する.py" --restored work/135再現 --proof work/135再現の照合.json
python -X utf8 "study/00135_公表差で不安定な方向上書きを抑える/再現資料/保管を確認する.py" --restored work/135再現 --output work/135保管の確認.json
```

F1全15源を元SHAへ復元し、履歴F1を同体保存する。`再現用パス台帳.json`は元F1の各SHAを保ち、repo内相対位置だけを新workへ写す。作成UTC・元F1 SHAと「金融前固定ではない」を明示し、新しい事前F1と扱わない。

原文のCLIは履歴F1の絶対パスを検査するため、そのまま別rootへ実行しない。再集計helperは原文評価器をimportし、`evaluate(再現用パス台帳)`を呼ぶ。評価器・方向票・算術・条件は変更しない。履歴F1原文が作業先にもあるため、出力のF1_SHA256は元の監査参照である。新しい評価の事前固定を主張しない。

実再現では集計JSONは元F1参照を含む全bytes同体、三表JSONも全bytes同体となった。[再現確認](../検査/保存観測からの再現確認.json)。保存済み旧正逆Quoteだけの再集計で、Raw/巨大Source入力/新出生を読まず、元正本を上書きせず、CSVは生成していない。

## 非金融の公表再生からたどる場合

[公表差診断](../根拠/同じ79出生の公表差.md)と[その非金融F0](../根拠/公表差診断のF0.json)は135の金融前F1とは別段階の履歴である。出生を再生成せず、固定79出生のRaw indexまで公表を配送してdirection133を再計算する。元CSVの全fields/refs/方向と一致を要求する。

診断コード`work/同じ79出生における公表差の診断/診断する.py`・Go overlay・元条件は後発ZIPへ同体保存した。再現に必要なSource133/118/121は[134の復元手順](../../00134_Raw公表時計で複合入口を再生成する/再現資料/再現手順.md)の共有コードを使う。Go1.24.2と相対モジュールを保ち、`診断する.py --人工`→`診断する.py --実行`。`go test -overlay=...`で指定人工/再生だけを呼ぶ。未作成の出力先を使い、元F0や停止結果を置き換えない。

Source入力は旧122の177,709,174 bytes（SHA`6a6cd13dfd00c9669b522e3c3c8e06a4066766f6075786f64d8c0feeb45513ec`）、134のRaw即時83,614,403/遅延84,670,954 bytes。これらは複製せず、122/128/134の正式生成元とSHAを共用する。134と同じ旧133Source出生も既存gzipから参照する。必要な外部データがなければ保存237行からの再集計までが可能な範囲であり、巨大入力を保管したことにしない。

非金融結果から方向票を再生成する場合、未作成先で保存評価器の`--mode 固定`を使う。元scriptは固定配置の定数を持つため、同体入力/元MD原文が全て揃う作業先で実行し、新しいF1が履歴と同じ時点のものとは主張しない。成功した方向票は元choicesと比較する。金融結果は原15源を固定してから旧観測からのみ評価する。
