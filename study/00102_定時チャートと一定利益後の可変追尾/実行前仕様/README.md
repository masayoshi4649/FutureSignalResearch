# 00102：定時チャートと一定利益後の可変追尾

2026-11-09採番。**実装中・市場損益未検証。** [最新方針](../../docs/議論/参加率と一定利益後の可変追尾.md)を適用する。旧100・101の少数入口を合格候補として扱わず、新規＋保有の参加率を最低25%、目標50%以上として報告する。

## 仮説

元Sourceの出生を一回だけ審査する入口では、後から技法が整っても新規判断が行われなかった。新候補は全5分枠で、複数時間軸の方向、勢い、価格構造、通常値幅、当時の板数量を役割別に組み合わせ、順行・反転・待機を再判断する。元FARの順行／往復という考え方を参照するが、元Sourceの売買通知を再現したアルゴリズムとは呼ばない。

一定利益を待ってから保護を起動すれば、微小な正益直後の建値往復を減らせる可能性がある。通常幅と、価格・勢いの失速や収束に合わせて狭くする幅を比較し、実現損益と損失を検証する。利益後の損失をゼロにできるという仮定は置かない。

## 入力と条件

- NK225のみ。既使用の2026-09-21〜10-27、27日・54セッション。試行101で照合済みの連続入力Headerと正常／不正気配の原行Scalarを再用する。新しい原板取得・Source再形成はしない。
- 5分判断は各セッションの開始30分後以上・終了30分前未満。デイ09:15〜15:10、ナイト17:30〜翌05:25。各72／144枠、合計5,832枠。米国開始後の追加除外は設けない。欠測は分母に残す。
- 保有中は新規を追加しない単一建玉。枚数は確信度に応じ2／4／6枚、片側上限10枚。両建ては必須ではなく、この候補では行わない。買い・売りは符号反転した同じ条件とする。
- 判断枠の保存値に加え、公表を観測した時計を発注可能時刻の下限とする。その時刻で観測した原行自身では約定せず、厳密に後続する正常原行で買いAsk／売りBidを使う。新規の締切は「論理判断時刻＋60秒」と「終了30分前」の早い方で、等号以上は要求しない／取消。実要求時の正常気配も15秒以内を必要とする。遅い公表を後の枠へ持ち越さず、欠測・失効の枠は分母に残す。
- 旧入力と同じ強制返済時計（デイ15:35、ナイト翌05:50）で新規を取り消して返済要求し、後続正常原行で返す。場末までに完結しない会計を成功としない。
- 日経mini、100円/pt、税込片道38.5円/枚。追加滑り0／仮定片道5pt、最低追加価格秒0／1を比較する。ラージBBOで希望全枚数が約定する仮定であり、mini板の実測約定や流動性を証明しない。

## 比較する少数条件

入口S3／S4は8つの支持点のうち3点／4点を必要とする。方向条件と勢い条件、反転の価格経路は別途必要とし、票数だけで売買しない。未知の支持点は上下限で扱い、反対方向との優劣が確定しなければ判定不能とする。具体式と既知性は市場を見る前の設定へ残す。

| 保護 | 起動と幅 |
| --- | --- |
| P0・新会計対照 | 費用後残玉単価益が正なら起動。最低名目建値、取得時2ATRの固定幅。旧100の同名口座と同じ実入口・会計であるとは主張しない |
| A0・一定利益 | 費用後単価益が `max(10pt, 取得時ATR×0.5)` 以上なら起動。最低床は呼値5ptに切り上げた往復費用回収価格。通常幅 `max(10pt, 現在ATR×1.5)` |
| A1・可変幅 | A0と同じ起動・床。複合収束または複合失速を既知確認したら `max(10pt, 現在ATR×0.75)` へ狭める |

全保護で、起動前は取得時 `max(20pt, 2ATR)` の損失上限を置く。起動後の停止価格を不利に緩めない。5分ごとに保護の技法状態とATRを更新し、保護の発動・利益起動・追尾更新は正常気配ごとに行う。既知の逆方向判断と保有側の複合失効がそろう場合の定時返済も共通とする。

新規の対象時間外も、保存入力に存在する5分枠は保有中の技法更新へ使う。末尾30分に新規を止めても、保護の状態更新や返済を止めない。ATRは5分判断枠へ供給された公開3分ATRで、毎原行の最新ATRやATR5ではない。技法が未知の枠は最後の既知の幅状態を保持し、その幅で正常気配ごとの価格追尾を続ける。未知を新しい反対確認や継続確認に置き換えない。

2入口×3保護×4費用／遅延＝24会計を同じ54場へ適用する。多くの閾値の総当たりで採用値を選ばない。技法成立枠の事前確認と実約定後の参加率を区別する。

## 評価と限界

費用後実現損益、利益・損失合計、DD、取引数・枚数、正益観測後／保護起動後の最終赤字の件数・金額、日別・日中夜間・売買別、参加率を報告する。旧S0の実現額は参考対照とし、時計・入口・退出が異なる総差を保護単独の効果としない。

新規枠は、その枠で判断した注文が締切内の後続正常原行で実約定した場合だけ数える。保有枠は論理判断時刻の実保有で数え、同枠を二重計数しない。これは注文した枠の実約定による事後分類であり、論理枠ちょうどの保有率とは区別する。受理数・実約定数も別記し、後の損益を採否や分類へ戻さない。

未参加の仮想利益、退出後価格、機会損失や理想ピーク回収率は計算しない。同じ既使用期間での探索であり、未使用期間の安定利益は未確認。参加率だけのための損切り先送りは行わない。コード・入力指紋、実行前条件、約定・会計検査と再現手順を保存する。
