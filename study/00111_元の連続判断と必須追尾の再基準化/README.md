## どう判別して切り替えるか

W100に対するT100の主純差−492,000円は、初狭幅時点P真の2玉+33,000円、P偽の71玉−525,000円、狭幅なし485玉0円に分解できた。B100の主差−574,000円もP偽74玉が−607,000円を占めた。Pはその時点の既知pivotに対する支持否定であり、事後のトレンド判定ではない。

P偽でも増益玉は多く、一律に不適切とはしない。ただし少数の大きな実現減が多数の小さな改善を上回っていた。次の実装候補は、**一定利益後の通常追尾を続け、勢いが鈍っても支持否定がない間は通常幅を保ち、支持否定とMACD失速が重なった時に狭める**規則である。P真は2玉、P未知は0玉なので、優位性や未知時の効果はまだ未検証。今回の分類差額を足し戻して、新手法の仮の利益を作らない。

全70同入口比較は36対照・2,520対照場別を照合。H100のW→T/Bは全費用で厳密同実入口だった。B50のD1には空き枠による別の新規受理もあるため、全政策が常に同じ実入口とは仮定しない。未参加・決済後の仮想利益や機会損失は評価しない。

「建玉全体」は、一つの実Positionの先行部分返済と残量の合計を指す。別の新規建玉や反対方向の損益とは相殺しない。初期枚数は途中で減らさない。費用後100pt相当はmini1枚なら10,000円、50pt相当なら5,000円である。

通常幅は取得時に分かったATRの2倍と200ptの大きい方を5ptへ切り上げて固定する。ATR未知でも200ptで必須保護を開始し、後で尺度を付け替えない。T100/B100/B50は複合警戒で狭幅へ移り、以後の保護価格を不利に緩めない。起動前の最高値で遡及起動はしない。

追加チャートは当場の確定3分足を使用する。MAはEMA8/21の間隔が3公表連続で縮むか、BBは終値20本のSMA±2母標準偏差の幅が3公表連続で縮むかを測る。収束は値動きの拡大が止まった状態を示す候補であり、反転の確定とはしない。保有方向のMACDの失速を別に確認し、通常の押戻しだけで狭めすぎる事例と区別して検証する。これらの本数や閾値が最適という意味ではない。
