# 利益保護後、いつから次の新規を許すか

**損失を抑える観点で次に固定したいのは、開始20分待機のRC20。** 日経199_02の元の利確・損切を残し、保有中に反対側の主シグナルが続いたら利益保護を強める。保護が実際に約定したら建玉はなくなる。そこから元の建値の±1Rのどちらかへ清算側の気配が達するまで、同じ口座での新規を待つ。先に場末が来れば、その日は終了する。建玉ごとの保有時間上限は設けていない。

## 何が変わったか

2026年9月21日〜11月20日の既使用45デイ。日経225mini 1枚換算、片道38.5円の手数料と片道5ptの想定滑りを含む。元の入口が指定した片幅Rは150・200・350・400ptのいずれか。ラージの正常な最良気配で売買を代用する。開始20分は09:05、30分は09:15から新規を受け付け、15:29に場末の返済を要求、15:30までに全て決済する。

|20分・R02保護・即再開|141|2,160,685円|1,139,542円|1,021,143円|12|63,154円|63.94%|
|20分・R02保護・元価格まで待つ（RC20）|133|2,067,993円|1,061,234円|1,006,759円|11|63,154円|58.57%|
|30分・単純IFD|133|2,101,301円|1,183,542円|917,759円|16|87,693円|66.08%|
|30分・R02保護・即再開|141|2,135,762円|1,165,619円|970,143円|14|87,693円|65.15%|

RC20と単純IFDでは、全133件の取得が日付・時刻・方向・価格まで同じだった。RC20は7日に1件ずつ決済が変わった。元の損切だった10月14日の買いが−41,077円から＋1,923円に、場末で赤字だった10月21日と26日の買いも黒字になった。11月19日の売りは−15,077円から−77円。一方、9月28日の売りでは元の利確＋38,923円を＋3,923円で終えた。ほかに9月24日と10月2日でそれぞれ17,000円と15,000円の利益減がある。[日別CSV](../../outputs/00224_利益保護後の再エントリー/224_RC20_R02元価格まで待つ/デイ.csv)・[建玉・起動・決済の日時](../../outputs/00224_利益保護後の再エントリー/224_RC20_R02元価格まで待つ/建玉明細.csv)

9月28日の売りの早い利確と10月14日の買いの赤字回避は、同一の原板チャートと売買マーカーでも比較できる。[2日の建玉をViewerで比較](Viewer/README.md)

RC20で一度でも費用後含み益が出てから赤字決済した取引は36件から33件、損失合計は907,772円から811,541円。建玉中央値は＋13,923円のまま、日収支中央値は31,769円から24,846円に下がった。総損失は前24日で59,154円、後21日で37,077円減少。収支差は前24日が−5,000円、後21日が＋43,000円で、改善上位3日を除くと−52,000円になる。45日すべてに参加し最終確認不能は0件。保護の改善は限られた7日の観測で、追加日への固定適用で確かめる余地がある。

## 値幅だけで保護する場合

最初にP20（0.95R順行で起動）とS00（0.90R）で、保護後すぐ入る、反対シグナルを待つ、一度中立になるまで待つ、元価格を待つ、反対か元価格を待つ、の5通りを各待機で比較した。元価格を待つとS00は総損失38,154円減・収支18,000円増、P20は総損失22,077円減・収支13,000円増で、元の133取得と同じ。中立を1度待つ方法は、今回の全取得・決済が即再開と一致した。「反対の主シグナルを待つ」は即再開比でP/Sとも赤字日が1日増えた。初回を終えてから、保有中にも反対の入口を観察するR02を別の追試にした。[初回の比較方針](比較方針.md)・[追試の条件](反対信号保護の追試方針.md)・[条件ごとの結果](全条件の比較.md)・[63手法の設定表](設定と結果.md)

## 買いと売りで利益保護はどう働いたか

20分待機では同じ買い51件・売り82件を、取得日・取得原行ごとに単純IFDと対応させた。両方向に同じ条件を使った結果、総損失は買いで81,231円、売りで15,000円減った。売りは元なら取れた利益も67,000円手放し、収支は52,000円減った。30分待機は買い50件・売り83件で、損益が変わった7件と金額差は同じだった。

|20分待機|決済が変わった件数|総利益（IFD → RC20）|総損失（IFD → RC20）|収支差|
|---|---:|---:|---:|---:|
|買い|3/51|743,690 → 752,459円|577,617 → 496,386円|＋90,000円|
|売り|4/82|1,382,534 → 1,315,534円|579,848 → 564,848円|−52,000円|

同じ建玉について得た差であり、買い専用・売り専用の別条件は選んでいない。追加日でも両方向を同じ条件で集計する。[RC20の日時・方向・決済明細](../../outputs/00224_利益保護後の再エントリー/224_RC20_R02元価格まで待つ/建玉明細.csv)

## 再現

条件を固定し、[返済を3・5秒遅らせた場合](執行遅延/結果.md)と[週を一つずつ外したときの差](期間別のばらつき.md)も照合した。新しい日付の比較には[追加デイへ適用する手順](追加日への適用.md)を使う。

[試行221の入力再現](../00221_日経199デイの元IFDの利点を残して利益を守る/再現手順.md)に従い、45場の原板索引と固定199_02の当時のシグナルを用意する。[222](../00222_セッション両端の建玉制限と期限なしIFDを照合する/README.md)の口座元帳と223のP20・S00・R02の口座／入口固定元帳を先に生成する。PythonとNumPyは同じ環境を使う。リポジトリ直下で実行する。

```powershell
$study = (Get-Item 'study/00224*').FullName
$py = 'work/複合テクニカル学習環境/Scripts/python.exe'
& $py -X utf8 (Join-Path $study '再エントリーを再生する.py')
& $py -X utf8 (Join-Path $study '再エントリーを再生する.py') --反対信号追試
& $py -X utf8 (Join-Path $study '集計と閲覧入力を作る.py') --照合 'outputs/00224_利益保護後の再エントリー'
```

各場で保護返済の実約定後に再開ルールを適用し、全要求を予約込み1枠で再生する。Cの判定に元の価格到達を追う間は建玉0枚で、実保有時間・損益・費用には一切加算しない。Aは試行223の実口座と全項目で一致、Cは元の入口固定元帳の全133件の主要原行・時刻・損益と一致した。日別CSV・建玉明細・期間集計は候補別に保存し、54ファイル・67,374セルを読み戻して照合した。[候補別CSV](../../outputs/00224_利益保護後の再エントリー/README.md)

公開CSVを新しい作業先へ再生成するには、上記で作った閲覧入力を既存の[候補別出力器](../../scripts/損益CSV/候補別に出力する.mjs)に渡す。出力器は既存の候補フォルダを上書きしない。

```powershell
$deps = Join-Path $env:USERPROFILE '.cache/codex-runtimes/codex-primary-runtime/dependencies/node'
& (Join-Path $deps 'bin/node.exe') 'scripts/損益CSV/候補別に出力する.mjs' --input 'work/224再開/閲覧入力.json' --output 'work/224再生成/CSV' --proof 'work/224再生成/照合' --dependencies $deps
```
