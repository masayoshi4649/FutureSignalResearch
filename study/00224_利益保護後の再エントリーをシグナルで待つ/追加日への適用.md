# 追加デイに同じ条件を適用する

2026年11月22日に、単純IFDのI、反対シグナル2回による保護の即再開RAと元の価格まで待つRC、広い追尾で同様に待つPC・SCを固定した。各案は開始20分と30分の2通り。RC20とI20が主比較、他は開始条件や再エントリーの影響を確認する対照。元入口、±1Rの価格注文、15:30までの全決済、費用はいずれも[試行224](README.md)と同じ。追加日の結果で候補を選び直さず、赤字日・総損失・利益後の赤字・日末DDと収支の両方を記録する。[条件・コード・照合用の指紋](追加日の固定条件.json)

新しい日の[入口・特徴と板索引を準備](../00216_十一月二十日の固定入口と寄り前の反例を検証する/日経/README.md)し、[試行222](../00222_セッション両端の建玉制限と期限なしIFDを照合する/追加デイの手順.md)と同じ入力を渡す。新しい日の場合は `--既使用照合` を外して場名を差し替える。複数日でも日付順に評価し、取引の無い日も各候補のCSVに残す。未決済・欠測がある日の確定収支は空欄とする。手仕舞い後の待機は保有率に含まない。

```powershell
$py = 'work/複合テクニカル学習環境/Scripts/python.exe'
$run = (Get-Item 'study/00224*/追加日に固定適用する.py').FullName
$dest = Join-Path work ('224日経_' + (Get-Date -Format 'yyyyMMdd_HHmmss_fff'))
& $py -X utf8 $run --母集団 'work/216日経/母集団' --純入口 'work/216日経/純入口.npz' --板索引 'work/216日経/前史十場と追加二場の索引参照.json' --場 '2026-11-18_Day' '2026-11-19_Day' '2026-11-20_Day' --既使用照合 --出力 $dest
```

旧形式の純入口ZIPも `--圧縮内 旧73_新入口.npz` を添えて照合できる。10月14日と11月18〜20日の計4デイ、10口座の全取引・順序・約定と保護時刻を45日版の同じ日の元帳に照合した。追加日の入力が到着してから初めて検証対象日が増える。既使用4日の再生は実装の検査に使った。
