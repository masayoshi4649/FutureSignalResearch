金額はmini1枚、費用後の円。元口座の内訳では日次収支ゼロの日も分母に残す。各内訳のDDは、その側の寄与だけを日末ごとに累計した曲線の最大下落額。売り限定の10月6日12:32:15の売り（70,460円、幅350pt、期限60分）は、通常期限の返済に使える正常な最良気配が不足した。保有は13:32:01まで観測でき、口座枠は15:30まで占有扱い。未確定の損益は既知利益・損失の双方から外した。

## 片側にすると何が変わるか

- 買い限定では元の買いと同一原行の65件の損益は＋247,995円で一致した。元にだけ残る11件が＋22,153円、限定で新たに建った43件が−318,311円。新たな43件は主入口33件が−191,541円、初参加補完10件が−126,770円で、両方が赤字だった。前24日は＋182,919円、後21日は−253,235円。10月20日の元の買い寄与は＋33,923円、買い限定では−2,154円。
- 売り限定では同一原行102件（＋753,146円）の損益が一致し、元だけ3件が−3,231円、限定で新たに建った29件が既知＋41,844円（不明1）だった。前24日は既知＋190,842円、後21日は＋604,148円。自身の利益上位3日を除くと既知＋477,376円、10月20日を除くと既知＋654,298円。売り限定の既知日末DDは元の両側より小さい一方、元口座で成立した売りだけを集計する場合より大きい。
- 取引のなかった日は、買い限定が10月7日・22日、売り限定が10月1日。この3日は許可方向の有効な主入口・初参加補完とも0件。元口座では反対方向の建玉があった。片側限定の結果には、保有・予約の競合と初参加補完の資格が変わった影響も含まれる。

## 再現

1. [217の日経の再現条件](../../00217_デイの利益集中と入口条件を比較する/日経/README.md#再現とデータ条件)で、当時情報による固定入口と原板の価格索引を準備する。Python 3.14.3・NumPy 2.5.4を使用した。
2. リポジトリ直下で下記を実行する。3口座の全建玉を `work/218片側/比較元帳.json`、照合・期間別集計を[片側口座の比較.json](片側口座の比較.json)に保存する。

```powershell
python -X utf8 (Get-ChildItem 'study/00218*/片側対照/片側を再生する.py').FullName
```

元の判断を両側で計算した後、有効な主入口の方向を先に確定する。その側を禁止する口座では同一原行の要求全体を見送る。元から有効な主入口が無い場合は、許可側の既定補完要求だけを残し、当該口座で同日未取得かつ開始45分以後のときに補完できる。予約・保有中、取得失効、幅・期限・損切り・終了15分前までの決済は従来どおり各口座の時計で処理する。ラージの最良気配でminiの売買を代用し、1pt＝100円、往復1,077円（片道手数料38.5円、片道追加滑り5pt）。両側口座の全181件は、試行216の日経正本と日付・方向・新規と決済の時刻・原行・価格・収支・先着・保有確認期限の11項目が一致した。[片側を再生する.py](片側を再生する.py)
