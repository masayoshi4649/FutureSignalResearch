## 人工検査と市場再生

以下は再現用コマンドで、この保管作業で金融を再実行したものではない。当時Rootは全体の`go test -count=1 ./...`とbuildを成功させた。10主人工テストはスコア4・継承入口4・補完2。現在の正式結果を上書きしない新規先を使う。

```powershell
Set-Location work/123全場参加の入口比較
go test -count=1 ./...
go build -o 入口比較.exe ./cmd/run
.\入口比較.exe --input <復元122入力JSON絶対path> --sha256 6a6cd13dfd00c9669b522e3c3c8e06a4066766f6075786f64d8c0feeb45513ec --output <未作成123結果JSON絶対path> --workers 8
```

当時exe SHA256は`e6b213ec3ea6cd365174fe5235a9ee0e5cf777d9f697827240a301230c311973`。再buildが違うSHAなら新しい環境・実行物として記録し、当時の実行物と同一と呼ばない。入力JSONの原板絶対pathとSHAを保つ。別環境のpath変更で入力bytesが変わる場合は新入力版として記録する。

元の`固定して実行する.py`はF1時の絶対pathと3文書を前後照合する。結果追記後のREADMEをそのまま使えば原文一致しない。新しい再現ツリーで原文・コードを復元して内容SHAを照合し、旧F1を上書きせず、新環境の指紋記録を別に作る。直接CLIの場合も同じ検査範囲を自動で満たしたとは扱わない。
