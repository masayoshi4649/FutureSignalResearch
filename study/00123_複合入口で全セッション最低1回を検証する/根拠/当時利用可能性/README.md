## 期限とfallbackの入力要件

開始3hの時計では、5分EMA8/21・両傾き・DI・ATR/前ATR・TR・RSI/前RSI・Hist/前Hist・RVOLは73/73場でknown/freshだった。P3の短期複合スコアに必要な値の入力基盤は全場にある。一方、同じ3hでE0必要指標は54場だけ。15/30成熟値は利用できた範囲をmaskで示し、未知を支持票にしない設計が必要である。

開始を早める案では、直近3本の連続確定5分価格からの短い平均、前2本高安/実体・終値位置、観測量変化という複数技法が使える。この履歴は73/73で開始17分37秒までに揃い、20/30/60/120/180分の各時計でも全73で利用可だった。平均線・構造・量の役割を分ける案であり、単独の1指標で埋める案ではない。完全EMA5を必須にすると初日は10:31まで必要で、3本平均の短履歴案と区別する。

「入力が利用可能」と「方向が非0」「次の正常BBOで取得できる」は別である。完全対称な価格列では、符号鏡像を保ちながら必ず片側を選ぶことはできない。価格clockの1秒条件と30秒TTL、Source新規期限までの正常BBOも必要となる。全場1取得は実再生で検証し、方向未解決や正常気配/時間不足を分母から落とさない。初日以外72Rawは今回再読しておらず、その全ての締切後BBO存在まで保証していない。

初日の正常BBOは08:45:01〜15:39:59、15:35新規期限前の最終は15:34:57。初日を丸ごと「データなし」として落とす状況ではない。Source CurrentPriceTimeのgapであり、WebSocket受信が同秒数途絶えたとの解釈はしない。
