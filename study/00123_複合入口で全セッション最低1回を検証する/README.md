## 複合スコアと通常入口

`sgn`は既知の正/負/0を1/−1/0へ写し、未知は平均の分母から除く。各成分のKnownと分母を保存する。

- 方向`Tf`は5/15/30分それぞれの`sgn(Gap),sgn(EMA8Δ),sgn(EMA21Δ),sgn(DI差)`の既知平均。`T`は既知Tfの平均で、5分を必須、15/30分未知はmask付きで除く。
- 勢い`M`は5分の`sgn(RSI−50),sgn(Hist),sgn(RSIΔ),sgn(HistΔ)`の既知平均。少なくとも1項既知を必須とする。
- 価格構造`P`は確定5分OHLCと現在Lastによる`平均[sgn(C−O),sgn(2C−H−L),sgn(Last−C)]`。価格は既知を必須とする。
- ATR5/前ATR5は既知正、TR5は既知非負を必須にし、`v=TR5/前ATR5`、`g=min(1,2/v)`（TR=0は1）。`u=clip(RVOL5,0,1)`は量既知時、未知は追加支持なしの0として元maskを残す。
- `S=[T+g{M+(1+u)P}]/[1+g(2+u)]`。方向・勢い・価格・量・値幅の研究独自の合成で、独立票の成功確率ではない。

通常順行は5分Gap/EMA両傾き/DI差が全て既知同方向、既知15/30分Tfが反対でないこと、側RSI中心0〜20・側Hist正、M/P同方向正、`|S|≥0.5`、TR≤2前ATR、既知RVOL≥1を要求する。

通常反転は、確定5分が当場の連続直前3本の逆側高安領域を一時突破し、終値が境界から内側5pt以上かつ旧領域内へ回復、現在Lastも維持することを要求する。前RSI5側中心≤−15、RSIΔ/HistΔが既知側正、ADX5/前値が既知低下、TR≤2前ATR、RVOL≥1を合わせる。E0の1分構造とは別の5分構造であり、ADX低下だけから方向を決めない。

## 期限・未知・取得の扱い

期限以降は、通常の強い確認閾値を外し、T5/M/P/値幅の必須既知条件と`sgn(S)`で方向を決める。Sが厳密0のときだけ直近連続確定5分の終値差を使い、それも0/未知なら発信せず後のRawで再検査する。補完に15/30分成熟・BB15・連続1分足は必須にせず、E0のそれらの条件は変えない。非対称な固定買いで穴埋めしないため、完全対称や取得可能Raw不足では全場目標に届かない可能性も残す。

同RawのE0発生は補完待機を取り消し、E0待機中は補完要求を作らない。E0又は補完の取得が一つでも成立したら補完を終了し、後のE0全候補は保持する。補完待機は一つまでで、TTL切れ後も未取得なら再要求する。要求方向・当時票を固定し、fill時の情報で方向を変更しない。

E0のcap→hold→riskは122と同じ。補完は別のmini1枚成行要求で、**E0専用のcap・1分自然否定境界・同リスク幅は課さない**。要求後の採用Index/物理行、価格時計1秒以上後・30秒未満・ForceClose未満の最初の正常BBOで買Ask/売Bidを取得代用する。E0優先取消・取得済取消を同Rawの補完fillより先に適用する。これはE0の改善効果ではなく、全場参加の別入口である。

## 参加と先着を別々に判定する

全対象73場を分母とし、各場の取得代用が1回以上なら参加条件を満たす。候補成立や注文要求だけでは満たさない。取得0の場も全場CSVへ残し、理由・品質とともに参加条件不合格として記録する。欠測・未知・注文拒否を理由に場を分母から除外しない。

入口の主数値条件はP3の60分±125pt、順/(順+逆)≥70%。未到達を含む順/全観測完了も別の70%判定として併記する。分母0はnull/評価不能。参加分母73と先着分母を混同しない。全場1取得と主数値条件の両方を判定し、参加増加だけ又は率だけで全体達成とは呼ばない。

副評価は30/60分×±25/50/100/125/200ptを全て保持する。100ptを含む全5幅を同じ比較表で併記し、125ptだけを取り上げて良化を主張したり、実行後に良かった幅やP2/P4を主へ交換したりしない。少数でも数値70%を超えた事実は示し、将来安定性や相関の課題を別記する。場末等の観測不足は取得済みの参加と分ける。
