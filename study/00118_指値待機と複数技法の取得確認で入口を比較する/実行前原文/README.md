# 00118：指値待機と複数技法の取得確認で入口を比較する

2026-11-10。入口改善を主課題として新しく採番した。117の結果と固定条件は変更しない。現在は条件固定・実装中で、118の市場結果は未算出。旧「一定以上の逆行をする前に広幅順行」や、旧手法の返済時刻での観測打切りから入口優位を判断しない。

## 仮説

元Sourceの新規提案は候補時刻・方向として残すが、現在価格での新規を前提としない。有利な価格を待つだけで改善するのか、押戻しと反転の確認が必要かを分ける。200pt下の買い指値／200pt上の売り指値は比較対象であり、唯一の解・有効な価格とは未確認。

|ID|入口候補|役割|
|---|---|---|
|M0|新規通知後、1秒以上後の正常BBOで取得|新評価時計での元方向の対照|
|L50|候補側気配から50pt有利な指値待ち|価格位置のみの対照|
|L100|同100pt|価格位置のみの対照|
|L200|同200pt|ユーザーが指摘した待ち指値の基準|
|Ttrend|30分方向・15分DI/ADX、5分EMA帯への押戻し後、構造・勢い・量を確認|順行の取得確認|
|Treversal|30分の強さ低下、15分BB/RSIの過熱帯、5分構造奪還・勢い回復・量を確認|反転の取得確認|
|Thybrid|順行・反転を役割別に判定したOR|状態を分けた複合入口|

複合候補は確認時にも候補側気配より50pt以上有利な価格を要求する。確認後の指値と、無条件の待ち指値は別候補。売買は符号対称。

## 評価を固定する

母集団は、未約定・取消を含む全Source NK225mini新規通知。旧S0で受理された558実新規との対応も保持するが、それだけへ母集団を限定しない。各候補を独立したmini1枚の入口試験として扱い、重複する試験金額を片側10枚の運用口座収支として合計しない。

新規を仮定した後の30分・60分を同じ時計で観測し、順逆25/50/100/125/200ptの先着を正常返済BBOで集計する。先着は決済を意味しない。期限到達後30秒以内の最初の正常BBOによる清算評価も別計算する。費用後清算評価は1枚100円/pt、往復手数料77円、追加滑りストレス0/10pt往復の二条件。これは入口単独の評価で、利益追尾を省略した運用戦略として採用するものではない。

Source旧返済時刻では打ち切らない。場末、300秒超の観測空白、期限後30秒以内に正常気配なしは観測不足として残す。未約定に仮の損益0円を埋めない。約定者同士の率だけでなく全出生分母・未約定・取消・未知を併記し、同出生で両案が成立した組の比較も残す。非約定や退出後の仮想利益を機会損失として採点しない。

## 注文・待機

基準価格P0はSource新規通知原行の買いAsk／売りBidで固定し、後の元実約定価格を使わない。待機期限は出生から15分未満、Source新規取消が届けば未約定だけを取消す。旧Source仮想返済では取消さず、独立した新入口候補の期限とする。場末以降の新規はしない。新規通知・確認・指値約定にはそれぞれ後続Raw・1秒以上の条件を課す。

指値は、買いAskが指値より10pt以上下／売りBidが10pt以上上を主模型とし、指値価格で記帳する。Lastや同側気配の接触だけでは約定させない。テクニカル確認後の注文は出生から15分と確認から30秒の早い方で失効。ラージ板によるmini指値約定の代用であり、miniの優先順位・約定数量は証明しない。滑りストレスは価格上限を破る架空約定ではなく別費用として計上する。

## 技術条件

5/15/30分の115確定公表を当時の配送Indexまで参照し、同限月の前史数値だけを継承する。未知を支持へ置き換えない。当場の3足が既知・freshであることを要求する。VWAPは今回使用しない。

順行は30分EMA8/21の配置と両傾きが順側、15分DI差が順側かつADX≥20。5分EMA21から符号付き−1〜＋0.25ATR内への押戻しを記録する。その後のRawで、押戻し後に形成・公表された5分高安を順側strict突破、Histが順側、符号付きRSI−50が0〜20、足TR≤前ATR×2、相対出来高≥0.8を要求する。

反転は30分ADX≤25または低下中、15分BB20±2母標準偏差の逆側外と符号付きRSI−50≤−15を待機帯とする。その後の5分高安奪還、HistとRSIの順側改善、TR≤前ATR×2、相対出来高≥1を要求する。BBは公表済み終値20本、相対出来高は当5分量÷直前20本平均。前史数値は同限月だけ継承し、欠測の数値を0として補完しない。各閾値は研究仮説であり、文献上のNK225最適値ではない。
