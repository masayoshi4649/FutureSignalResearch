## 評価と独立検算

下記は新規再現用ツリーで実行する。評価器は元のBBO/Last正逆ペアを選び、集計とCSV用表を未作成先へ生成する。評価後は集計SHAを上記へ、表JSON SHA256を`b7df2aaedc8aaf06dbc16f38555778a538b6f23acced7a0a7123c98907b7074a`へ照合する。

```powershell
python -X utf8 work/125足の実体と反転切替/評価する.py --evaluate-fixed-choices 16577b438f2de650c4398b313c2212fa124e812aea278e4dc00c529ffcb4c0a3
```

Root固定器の`--mode 固定/評価`は入力/5コード/3原文の前後一致も検査する。当時F2は絶対pathを含む。現在のREADME等は結果更新後なので、そのままF2原文一致とはならない。新環境では保存原文を検査し、旧F2を上書きせず別の固定記録を作る。直接評価CLIだけでは全F2検査を自動で満たしたとはしない。

独立検算用には、F2を`work/125足の実体と反転切替/F2.json`へ、[124集計gzip](../../00124_逆行の原因と売買反転を同じ入口で検証する/成果物/集計.json.gz)を`work/124入口の原因分析/集計.json`へ戻す（解凍SHA256 `1ca939bd2c619f6d2a3926999cb1b8e57726d48f2584b798cc6688e42ece49f8`）。125集計・表・選択票とコードを揃え、未作成の独立proof先で実行する。

```powershell

```

[独立proof](../検査/独立検算.json)はSHA256 `5e82485f15e490b25309541f07e958f63f9bb8570b4b2bcfc0a8490d08be27b8`。80組1920値、316選択、全73/79、反転20/9/8、未知3全keep同体を確認した。全CSVセル・bootstrap再実装・Raw先着最初性はこのcheckerの範囲外。[レビュー](../検査/独立レビュー.md)へ範囲を残す。
