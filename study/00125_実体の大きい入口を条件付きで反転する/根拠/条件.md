# 125：元向き5分実体比による正逆切替の探索内比較

## 固定する問い

124で事前に区分した「元向き5分実体比 `[0.5,0.75)`」について、Rootから原向き4順行/17到達済み、実逆向き12順行/17到達済みという探索内の所見を受けた。これは同じ79件から見つけた事後仮説である。本試行では、その群を実際に逆向きへ切り替え、群の外は元向きを保持したときの全79件を比較する。群内の70.59%を全79件又は未知期間へ一般化しない。多重比較未補正であり、独立検証ではない。

## 母集団と入力

- 母集団：123主政策P3で取得した全79件・全73セッション。除外、追加、時刻変更、再取得、枚数変更をしない。
- 元の入口はMA・傾き・RSI・MACD・ATR・価格構造・量等を組み合わせて生まれた固定母集団である。実体比単独の入口又は独立効果として扱わない。
- 当時特徴：`work/124当時特徴の診断/全79例の当時特徴.json`、SHA256 `e4f0bf25156c1fe732b186c5c5d90b6e9f95718985a440d8eb7005588f734774`。
- 同時点実BBO正逆ペア：`work/124入口の正逆比較/全73場の正逆結果.json`、SHA256 `25517066b291a0434211190299b9f0195e67f9a7d2e89c801d5b9e6b4b51c3a1`。
- 選択票生成は特徴ファイルだけを読む。124正逆結果、Raw、CSV、後続足、勝敗、損益を読まない。評価はRootの125固定後の指示を待つ。

## 条件と4政策

`s`を元の買い`+1`・売り`-1`、`O/H/L/C`を出生時に配送済みの最新確定5分足とする。

`b = s × (C−O) / (H−L)` は元向き符号付き実体比である。絶対実体比ではない。特徴キーは `candle5_body_signed_ratio`。`H=L`等で特徴が未知なら該当しない。数値0と未知を分ける。下端を含み、上端を含まない。

| 政策 | 反転する条件 | それ以外 |
| --- | --- | --- |
| O0・固定対照 | 反転しない | 元向き |
| T1・主 | 既知の `0.5 <= b < 0.75` | 元向き |
| T2・比較 | T1条件、かつ元 `strategy == "trend"` | 元向き |
| T3・比較 | T1条件、かつ既知の `1 <= rvol5 < 2` | 元向き |

RVOLは既存特徴の `rvol5` をそのまま使う。元E0と補完入口での由来は特徴の `rvol_source` に残す。未知を支持とせず保持する。T2とT3をANDした第5政策は設けない。買売の同時反転と価格鏡像変換ではbが変わらないため、条件は買売対称である。新T1/T2/T3を旧124の同名政策から区別する。

反転では同じRawの逆方向Ask/Bidを使用し、単純に勝率を`1−p`にしない。時刻、経過時計、観測不足、spread等は固定済みペアを再用する。新しい成行時刻、TTL、追加注文を作らない。

## 固定する評価

- 主：T1・BBO・60分・同幅±125pt。主を結果後に変更しない。
- 比較：4政策×BBO/Last×30/60分×25/50/100/125/200pt＝80条件。
- 固定H先着率は全H完了を母集団とし、到達済み順行率と全完了順行率を併記する。未到達、観測不足を勝ちにしない。
- IFD代用は先着Rawの清算側BBOを使用。到達済みなら後のH観測不足にかかわらず既知。未到達かつH完了のみ期限清算。その他は未知で金額nullとする。
- mini1枚・価格1ptあたり100円、C0は往復手数料77円、C5はそれに往復想定滑り10pt＝1,000円を加えた1,077円。既存費用条件を変更しない。
- Lastは約定不能の純価格方向診断であり、金額欄は全てnull。独立例のIFD代用は口座収支、資金曲線、実IFD約定ではない。
- 集計は124固定モジュール `work/124入口の原因分析/集計する.py`（SHA256 `8479ca348231ffd77a637360797750833c9e6617c7fc4a6502e015c7a1d9f04a`）の `stats` / `ifd` / `bootstrap` 等を原文不変で再用する。新しい深い複製上の `choices.T1/T2/T3` だけを置換する。実行時の `POLICIES` は `O0,T1,T2,T3` とする。
- bootstrapは全73場を保持し、場単位5,000回、seed124を継承する。未知清算を0円観測にしない。既知IFDの件数加重平均とO0との両側既知差の探索内参考区間であり、有意性の確定ではない。

Rootによる125固定後に限って評価し、`集計.json` と `CSV用の表.json` を出す。3表は比較80行、入口全79行、全73セッションを保持する。CSV出力は同じ3表から生成する。固定仕様・入力・コード・選択票の指紋は保存し、既存124資料は変更しない。
