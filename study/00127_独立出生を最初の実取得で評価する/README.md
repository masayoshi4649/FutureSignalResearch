## 実取得をどう判定するか

確認公表のdeliveryStampを出生時点とし、そのRawのtime/index/物理行を全て結合する。確定5分Closeは当RawLastや約定価格ではない。出生RawのLastで回復K維持・capを満たしたものだけ要求し、**1秒後以降・後続原行・30秒TTL内の最初の正常BBO**で買Ask/売Bid取得を評価する。最初の正常評価でcap/hold/riskが不成立なら取消し、後から都合の良い気配を選ばない。

entry_cap=K+s×0.5ATR5、hold_boundary=K/hold_minimum=0（Kに既に±5を含む）。Iは拒否/押戻し等の逆極値±5。実BBOのI距離は**10以上、min(125,1.5ATR5)以下**。出生段階の1.5ATR制限に125上限を追加するため、650のうちmetadata両立は599件/全73場、51件は追加上限で両立しない。51も母集団から落とさず未請求/取消へ記録する。599/73も実Rawの取得保証ではない。

1分ATR連続履歴は要求せず、5分の確定OHLC構造とATRを使う。15/30成熟指標の未知は別maskで、未知を同向へ補わない。足幅5/15/30と取得時計を区別し、固定5分/15分の新規枠や開始3hの弱条件fallbackを設けない。

## 主F0と診断対照

全650候補を固定した同じ条件で独立に取得評価したうえで、実取得Rawの時系列から各場のF0を選ぶ。先着方向や損益の良し悪しで選ばない。同一Rawでは次の規則を固定する。

1. Mode優先R→T→S→Q。
2. 同mode内では実取得BBOからIまでのrisk最小。
3. 同riskで両方向が残れば、そのRawは方向未解決として見送り、次の取得候補へ進む。日付/買売側を優先しない。
4. 同方向・同riskだけならID順（価格/観測結果は同一）。

F0は最大1件/場。FRは同じF0の同Rawで実逆側だけを選ぶ対照で、逆向きのcap/risk条件を再適用しない。A0全取得、各modeの先頭は診断対照とし、疎なmodeだけで全場参加や主合格としない。A0は独立候補の集合で同時保有を管理した口座戦略ではない。未請求・未取得・取消・方向未解決・観測不足・0取得場を残し、全73場を分母から落とさない。

主はF0/BBO/H60±125ptの順/(順+逆)≥70%。未到達込みの順/全H完了も別に示す。H30/H60×同幅25/50/100/125/200ptを全保存し、結果後に主幅/政策を良いものへ差し替えない。先着は取得から固定時間の全H完了分母で、未到達と観測不足を分ける。場末の時間不足を勝ち/負け又は0円へ置換しない。
