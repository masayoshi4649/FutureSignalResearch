## 反省から変更したこと

[180の診断](../../docs/議論/十一月十六日の最大損失と反転確認の不足.md)では、旧BO入口が元方向の勢いを確認した後、反転する実方向の回復を必須にせず注文していた。利益になった後の赤字だけでなく、利益化しなかった赤字も多かった。このため入口確認と利益保護を分けて実装した。

[181](../00181_反転確認と利益保護を分けて改善する/README.md)では16入口×11出口＝176組を比較した。一律の確認と小さい追尾幅は損失を減らす一方、従来の大きな利益も削った。182では4入口×7出口＝28組を追加し、確認する局面と保護値幅を分けた。合計204組の比較には固定対照の再比較を含み、204個の独立仮説という意味ではない。

| 軸 | 今回比較した内容 |
|---|---|
| 入口 | 元入口、全BOを15実分以内の複合回復まで待つ、強い逆向き背景のBOだけ待つ、背景又は突破スパイクのBOだけ待つ |
| 背景 | 5・15・30分のEMA21傾きとDI方向。追加案はADXの強さ・増分、価格端突破・値幅・相対出来高も使用 |
| 回復確認 | 実方向の1分実体・価格進行・直近構造、元方向のMACD/RSI圧力の改善、複数足の背景・量・取得位置を組み合わせる |
| 出口 | 固定IFD、181の150pt起動/125pt追尾、元IFD幅の50%又は75%を基準とする起動、固定幅・ATR幅・BBとMA/MACD収束による縮小 |

出来高はラージの観測累積差分からの相対量である。miniの実約定量や、買い手・売り手の注文動機を直接観測したものではない。未知の背景を安全確認とは扱わず、旧入口を保持する既定行動として別記した。

## 損失軽減候補04の仕組み

04は `E182_01__A075_ATR2_TP`。デイのBOをすべて早期複合回復確認へ替え、MP・LC・夜間の入口定義は保持する。「15実分」は反転候補を記憶する期限であり、15分ごとの定時注文ではない。売買は符号反転した同じ条件。

元のIFD幅をWとすると、費用後含み益が `max(150, 0.75×W)` pt相当になった時点で必ず追尾を起動する。追尾幅は5分ATRの2倍を、下限 `min(75, 0.5×W)`、上限 `0.5×W` へ制限する。ATRが古い・不明なら0.5Wへ戻すが、既に設けた保護価格は不利に緩めない。元の利確指値・初期損切り・保有期限は維持する。

例えばBOのW=350なら費用後262.5pt相当で起動し、幅は75〜175pt。MPのW=150では費用後150pt起動より先に元利確指値へ届くため、小幅の取引へ過度に早い追尾を足さない。起動後の最低床は往復費用10.77ptをmini刻みへ切り上げた15pt。接触から1秒以降の正常BBOで返済するため、実約定代用が床を下回る場合も残す。

BB収束を追加した03なども比較したが、04はATR幅までの案である。複合指標を増やせば必ず改善するとの結論にはしない。

## 03の好成績をそのまま採用しない理由

03は、5/15/30分のEMA傾き・DI差がすべて実方向に逆のBOだけ確認を待ち、ATRに加えてBB収束とMA/MACDで幅を縮める。全81場の既知収支は1,711,440円と基準を29,769円上回るが、**デイの未知が0→1件に増え、全体は未知6件**。既知分だけで改善確定とは判定できない。

新しい未知は10月6日デイの売り。先行する取引の返済時刻が変わって枠が空き、新しい取得が通常期限付近の価格欠測に重なった。起動前の取引であり、追尾価格を0円補完すれば済む問題ではない。全80場に限ると03の既知収支は1,770,902円で基準1,775,210円を4,308円下回る。03は事前の未知非増加条件を満たさない参考案として保存する。

## 選択・入力・費用・限界

順位は旧全80場と前48場で別々に算出し、今日1場と全81場は診断に使った。全80デイの事前順位先頭は基準IFD、前48デイの先頭はE182_03＋IFD。夜間は基準IFDが先頭だった。04は損失軽減という軸で残した比較候補であり、事前順位1位へ交換していない。元候補の全期選択と今日の反省が設計に入っているため、過去だけで順位付けしても未見検証にはならない。

入力は163/167/180の恒久保存入力を共用した旧73＋追加7＋本日デイ1の81場。全期間が既使用。ラージ正常BBOでmini1枚の取得・返済を代用し、1pt100円、片道税込38.5円、追加滑り片道5pt。往復費用は1,077円で、実BBO差も別途価格に含まれる。mini自身の約定可能量や待ち行列は実証していない。

買売合計の保有・未決予約は1。一律開始待機なし、公表済みq0で判断。デイ15:29・ナイト05:44に全返済要求と新規停止を行い、1秒以降の正常BBOで15:30・05:45までに返済する。全対象時間はデイ405分・ナイト765分、保有率は実保有時間の合計÷対象時間合計。0取引場を残し、未知保有で率を水増ししない。米国前後はNY09:30を夏冬変換し、新規q0で損益を分類、保有時間は実際の境界で分割する。

早期決済が入る先着F/A/N/Cは返済時点で観測が切れる場合がある。固定IFDの入口精度と同じ率だと解釈せず、未到達・観測不足・決済勝率を分ける。利益の取り逃がしは最適化していない。今回の含み益診断も取得から実返済までに限る。
