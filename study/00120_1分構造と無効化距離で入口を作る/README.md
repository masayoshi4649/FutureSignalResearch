# 00120：1分構造と無効化距離で入口を作る

2026-11-10。119の結果を受けた新しい仮説。事前F1を固定し、既使用70場・301候補を実行した。条件の[実行前原文](実行前原文/README.md)と[設定表原文](実行前原文/設定と結果.md)は同bytesで保持する。

## 結果の要点

主評価60分・±100ptはP1が順34/逆43、P1plusが5/5、P2が10/7、P2plusが2/0、P3が14/25、P3plusが0/4。P2plusの2例は両方順先だったが、70%の再現性や安定利益の確立とは判定しない。P2本体は17例の58.82%、C5期限評価平均−4,724.06円。構造回復と追随上限を加えても、順行と収束放れを含め全体の入口課題は残った。

[結果と限界](結果と限界.md)に30/60分の全12条件、幅別の未到達・少数例、取得前取消と同分対応群を記す。次はP2の順先/逆先の当時情報の違いを診断し、P1/P3で待機や反転へ切り替えられる条件も検討する。診断で得た条件を120へ後付けして成績を変えない。

同一幅の利確側先着70%以上を目指し、入口精度を先に改善する。200pt有利な指値へずらすことを目的にしない。119では確認を増やしても同幅先着の改善にならず、順行確認後の60分±100ptは順9・逆19だった。5分構造の確認より早い1分構造と、実取得から構造の無効化価格までの距離を組み合わせる。

## 仮説と条件

全政策で、30/15/5分の確定・配送済み情報と、当Rawまでから形成した1分OHLCを使う。1分足は次の分に入った最初のRawで確定し、未確定足の完成形は使わない。空足を補間せず、欠けた場合は連続履歴を作り直す。5分は指標の尺度であり、固定時刻の強制新規ではない。売買は符号反転した同条件。

隣接する分でも採用Rawの価格時計が60秒超空いた場合は、1分履歴と形成中足を破棄し、現在Rawから再開する。空足resetと別に件数を残す。保存済み5/15/30分の公表窓の扱いや、取得後評価の300秒打切り条件は変えない。

全政策に1分の実体方向・終値位置70%以上を要求する。直前14本のTR単純平均をATR1とし、当1分のTRがその2倍を超えるスパイクを拒否する。ATR1に判定中の足自身は入れない。ATR1や必要公表が未知なら新規候補を作らない。

買いの無効化価格は判定1分安値−5pt、売りは高値＋5pt。当Lastからの距離が正かつ `min(100pt, 0.5×ATR5)` 以下の場合だけ候補化する。取得上限は買いが1分終値＋`min(10pt, 0.15×ATR5)`、売りは鏡像。実際の取得側BBOがこの上限より不利なら注文代用を取消し、価格が戻るまで指値で待たない。実取得時にも無効化までの距離を再確認する。同政策・同側の候補間隔は300秒以上で固定する。

閉鎖1分足で回復していても、現在のRawで水準を割っていれば成立としない。出生時と取得評価時のLastが、P1は前1分順側高安をstrictに維持、P2は前5本逆側境界から順側5pt以上を維持、P3は前5本順側境界をstrictに維持することを要求する。最初の正常BBO評価でcap、構造維持、距離を順に判定し、不適なら即取消す。市場結果を読む前の独立レビューで加えた、回復条件の現時点維持である。

P3の狭い帯は直前5本1分高安幅≤0.75×ATR5。BB幅収縮は同セッションの直前既知15分BB公表との比較で、未知を前値0へ置かない。P1の帯は1分逆側極値が5分EMA21に対して−1〜＋0.25ATR5、P2のBBは15分20終値±2母標準偏差を用いる。詳細数値と全56手法×9尺度は[設定と結果](設定と結果.md)へ保存する。

## 執行と入口評価

1イベントを独立したmini1枚として評価する。要求より後のRawかつ1秒以上後、30秒未満、正常BBOの最初の行で成行代用・取得上限・構造距離を判定する。Sourceの通知・旧決済は使わず、Source.force_close以降は新規不可、既取得の観測はSession.Endまで。将来気配で候補を選ばない。

取得後30/60分、±25/50/100/125/200ptの同一幅先着を記録する。到達済み分母の順行率と、未到達を含む全観測完了分母の順行率、出生・要求・約定代用・観測不足を併記する。正常BBO又はRawの300秒超欠測、場末、期限後30秒の気配不足を0円にしない。期限に達した最初の正常Rawで評価を止め、同秒後続行を混ぜない。

本試行の主評価は60分・±100ptの順行先着率とする。他の幅・30分は副評価として全件を保存し、結果が良い幅だけに差し替えて主目標を達成したとはしない。買売・元54場/追加16場・セッション別の件数と偏りも確認する。

往復手数料77円、追加往復10pt（1,000円）の感度を示す。ラージBBOをminiの約定代用に使う。指標や構造だけで70%を保証せず、先着診断とIFD注文の実約定損益を区別する。実運用の必須利益追尾は次段階で保持し、固定期限評価を追尾廃止の提案にはしない。

既使用70セッション（2026-09-21 Day〜11-06 Night）の探索。11/09の価格・損益・入力指紋は未読を維持する。重複する独立試験を片側上限10枚の口座損益へ合算しない。1分候補も同場で依存するため、二項区間だけで再現性を認定しない。

## 市場心理と由来

仮説は「上位方向が同じ」だけで早く買うことや、5分の回復を待って遠くで買うことから、近い構造の回復と無効化距離を判定することへの変更である。押戻しの売りが続く局面と、小構造を取り返して売りが維持できなくなる局面を区別する。反転は過熱そのものではなく、突破失敗・回復を確認する。収束は放れ方向の確定まで待つ。これらの心理は説明仮説であり、売買主体の行動を実測した事実ではない。

一般的な根拠はCMEの支持抵抗・役割転換、Fidelityの突破失敗・BB、価格水準付近の注文集中を扱う研究等。[外部事前案と出典](根拠/外部一次調査/小構造と無効化距離から入口を作る.md)、[119](../00119_技術領域の出生と確認後再試験で入口を比較する/README.md)、[入口の評価方針](../../docs/議論/入口の評価時計と候補の出生を分ける.md)を踏まえる。外部事前案の数値は参考であり、本試行の固定数値は上記を正本とする。外部資料はNK225の70%を証明しない。
