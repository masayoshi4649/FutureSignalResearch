## 独自の一監視・最初の対象再テスト

当場の前20公開連続有効3分の旧R/Lを現Cがstrict突破したbでR/L/B/元sを固定。一監視でused(s,B)を登録時消費し、監視中の別bと同水準を抑止、消費/取消同足の登録はしない。登録は注文でなく、数量/MACD/ATR値で登録を間引かない。新しいBの別登録は可能で、同じトレンドの参加を全て一回に制限した意味ではない。

寿命はb次1..6足。start_j>b.confirmかつ公開key後strictの対象足だけ高安を使う。通常b+1は対象外でも寿命に数え、最短b+2〜6の『最初の対象足再テスト』である。反対端終値取消を先に、買Low<=B/売High>=Bを初touchとする。外側終値Tは実side=s/順行、旧L<C<R strictならRは実side=−s/反転、元端等号WAIT。指標/時間が悪くても一回消費して後足へ取り直さず、自動ドテンしない。

不正/公開不備/欠枠/期限→寿命超過→対象時点→反対端終値→初touch→技術/時間採否の順。ヒゲだけの反対端到達を取消へ加えず、足中高安の順序を推定しない。登録snapshotは登録actionへ一回保存し、最終足登録から即場末取消でも正式親出典を保持する。

## CMF準備と値を分ける

CLV_i=(2C−H−L)/(H−L)、CMF21=Σ(CLV_i*q_i)/Σq_i。元floatH/L/C/qを各々Fraction化し、加重和/総量/CMFの精密分子分母で符号を判定する。全21足の同場連続公開完全足・各幅正・全q基準完全/有限非負・総q正がA1準備。完全0qは有効だが総q0は未定義、H=Lはq0でもCLV未定義で0補完しない。数量不完全や零幅はCMF窓だけを切り、価格監視を数量理由だけで取消しない。
