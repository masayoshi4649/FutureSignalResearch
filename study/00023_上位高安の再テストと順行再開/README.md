# 試行00023：上位高安の再テストと順行再開

NK225の3分B0/C0＝二入口・共通A5/X0の二運用。30分高安を価格構造、15分S2を局面、3分を発動時計へ分担した。数量は診断のみでC1未実行。全65場（学習40/条件選択24/既使用11/4デイ1）は全て既使用の追加開発で、内部の後続確認も未見ではない。

[計画.md](計画.md) / [条件.json](条件.json) / [固定.json](固定.json) / [結果.json](結果.json) / [設定と結果.md](設定と結果.md)

**支持付き入口70目標は0/2、費用資格は0/2。** 先着率は運用勝率ではなく、候補数・活動・品質と費用後額を分けて読む。

## 準備と各時間足の役割

固定22の下位三公開足BB/H/K/ATR・同場15分現前ペア・現在確認遅延<=30に、前公開3分足pまでの30分6本窓を加える。R1も両案でこのM23へ揃え、30分準備で失う元R1を別記録。数値Mと新規停止/残60分の時間条件は分ける。下位EMA/RSI/nativeVWAP/数量を新しいgateへ足さない。

30分は完全公開6本のR=max高値/L=min安値、R>L。各出典end<=p.endかつ公開(clock,line)<=p判断key。突破足bと同時に知る30分足を先取りしない。同限月carry可、完全幅NP/欠枠/尾部完全欠枠/限月変更で内部窓clear、末尾partialは含めない。非公開markerは過去public snapshotを改訂せず、次の公開足から窓を再構成する。

15分S2はd!=0,a>0,(A>=25 OR Δw>0)ならd方向T、A<=20,a<=0,Δw<=0ならR、他WAIT。A=ADX/a=現前差/w=4母σ/SMA20/d=DI方向。DX−A=13aは同じ14平滑の恒等式で独立二票ではない。公開現前の準備・as-ofと指標bankは固定21/22同値。

売りは鏡像。再テストzone端は等号可、回復/再開終値はstrict。開始<=公開の足はヒゲや再開を使わず寿命だけ進め、後の最初eligible超えを使う。帯割れ高安の判定もstart>setup.confirmに限定し、再開待ちでも基準はsetup.confirm。

監視は全体一件、旧監視→新設定の順。公開/数値/連続性不正・返済期限→age>6/3満了→eligible帯失敗→同方向S2T消失→対象足/再開を優先する。取消/満了/消費同足のT再登録は禁止、used(side,境界)は取消後も当場保持し場頭reset。既存監視の初価格再開は有限H差非正や時間不可でも消費するが、数値/公開不正は先に取消。新設定は時間不可で登録しない。建玉中だから価格監視を延命しない。

時間外に消費したshadowは先着APIへ渡さず、評価対象false・ラベル対象外・要求時間条件外・通常数値9個None。未約定や通常五分類の先着率分母へ混ぜない。時間内で勢い条件だけ不成立のshadowは通常の事後先着診断が可能。量の欠測・RVOL値はM/状態/採否を変えない。

## 出口・費用は変更しない

固定21/22のnative不使用A5エンジンを読取再用。hard125/TP250/期限、5pt正益の実観測で追尾起動、D=max(5,ceil(入口ATR/5)*5)、最低新規同値・買ceil/売floor・ratchetのみ。C0の入口ATRはkの値で、bのATRを追尾へ流用しない。pending中追尾更新停止、役割は実fillで固定し保有中の局面だけでドテンしない。

ラージBBOをmicro1枚代理、倍率10円/pt・呼値5pt・片道11円。要求+1価格時計秒以上の最初正常BBO、新規TTL30、買Ask/売Bid新規・返済側BBO。価格時計は受信時計ではない。追加片道5/10ptは同じ完結往復から100/200円控除する費用感度で、参加経路を再生し直した結果ではない。同値設定は実約定同値や費用後黒字の保証でない。
