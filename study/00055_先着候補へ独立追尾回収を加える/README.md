## 判断・執行と限界

デイ09:15〜15:15の25枠、ナイト17:30〜05:30の49枠、初回を除く15分判断。保有継続は非待ち、判定不能を含む保守上限も全予定枠で50%以下を要求する。新規の残り60分条件は追加しない。新規/返済は後行1価格時計秒、正常BBO、新規TTL30秒。強制15:35/05:50、連続終了15:40/05:55。

固定49Oで利益前も損失を連続追尾する。Dは新規時3分ATRの5pt切上げを5〜125へ制限し、建玉中は固定。現在正常返済BBOの粗含み益−122円がstrict正なら利益旗、最低名目新規価格床、非緩和、返済pending後の保護凍結を維持する。固定250TPはなく、仮125/250先着は別評価。名目同値床は費用後同値の保証ではない。

micro1枚・10円/pt・片道11円＋想定片道5ptで主往復122円。0/10ptは同約定への費用感応で、起動費用122円は変えない。ラージBBOの代理であり、microの実板や受信遅延を測った利益ではない。

独立測定は全定時の両方向を別々の一建玉として測る。その重複する純額合計・葉平均は、単一建玉の戦略損益ではない。評価時の未来回収は採否へ渡さず、過去の旧training.row_idsと両側回収確定pairの共通部分だけを使う。回収平均は未来確率の校正ではなく、1/3という先着得点閾値を円平均へ流用しない。

量・注文フロー・新しい価格発動は追加していない。DI逆向きは転換の時系列確認ではなく、心理も直測していない。C0/R0純入口の包含と実参加の包含は別で、群内の非重複集計も加算できない。
