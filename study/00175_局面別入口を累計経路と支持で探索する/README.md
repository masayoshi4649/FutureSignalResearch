## 仮説と技術の役割

173前48J026の初期赤字と174米後の希少高率を踏まえ、低ADX回復だけを広げず、高ADX押戻しHT・高ADX突破HB・高ADX失速反転HR・背景混在整理HM・長期未公表LC・低ADX帯端RLを別の複合技術として生んだ。ADXは強弱、EMA/DIは方向、MACD/RSIは動力、BBと価格端は構造、実体と観測量は現在の確認、ATRは取得位置とスパイク警戒に分担する。

市場心理の仮説は、順行枝では背景の参加が押戻し後にも残ること、反転枝では元方向の圧力が弱まった後に反対側が価格帯を取り戻すこと。過熱だけでは反転しない。これらは売買主体の心理の直接観測ではなく、固定した組合せを検証するための説明である。
