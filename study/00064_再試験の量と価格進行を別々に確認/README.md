## 価格段階・公開時計・連続保護

量は方向票ではない。既存価格機械が保存したb/rへ、当時利用可能な観測qと直前隣接公開終値差を対応させる。過去同時刻基準は当場開始前に完了した同Day/Night・同限月の直近10場を先に選び、同indexの完全qが5場以上・平均正のときだけ算術する。q0は基準へ含め、欠測で11場目以前まで延長しない。祝日層化は未実施。価格側ATRだけは現在判断値である。

Tはb→r→k、Rはb→f→r→kを別足・公開順で追い、未登録・未確認・取消も入力へ残す。最初のb/rを固定し、有効中に水準を置き換えない。寿命はb.confirm+3600で同秒を含め失効。取消足や最初の期限越え足を新bへ再使用せず、次足から検討する。k形成後は取消後もTTL又は置換まで既知現在の統計を更新し、有効旗を復活させない。終値観測順は足内高安の形成順を保証しない。

判断はデイ09:15〜15:15の25枠、ナイト17:30〜05:30の49枠。保有継続は非待ち、全予定枠分母で待ち＋判定不能の保守上限50%以下。現在正常BBOから1価格時計秒後の最初の正常気配へ新規要求し、TTL30秒。過去b/r/k価格に約定を戻さない。残り60分の新規停止は使わない。強制15:35/05:50・終了15:40/05:55。

固定49O、micro1枚10円/pt、片道11円＋想定片道5ptで往復122円。新規時ATRの5pt切上げをD5..125へ制限し保有中固定。損失側も連続追尾し、現在返済気配の粗益−122円strict正で利益旗と最低名目新規床を起動する。非緩和、返済pending中のh/L/arm保護は凍結。固定250TPはない。費用0/10pt感応も同じ約定・起動122円を保持し、名目床を費用後同値と呼ばない。

仮125/250先着率、回帰円予測、過去回収平均、混合一建玉の実損益は別である。旧55一枠測定の重複建玉合計は同時実行できるstrategy利益ではない。品質注意時は期間全体の確定額nullを保ち、観測額・役割別額を保証へ変えない。ラージBBO代理でmicro実板や受信時計を測定したものではない。
