# 試行00018：VWAPの位置と傾きで順行反転を比較

計画日2026-11-04。未実行。00017で監査した配信VWAP・累積売買代金を初めて売買条件へ使う。全65場は既使用であり、学習40・条件選択24・既使用11/4デイ1場の区分を維持する。独立な新標本の確認とは呼ばない。

## 問いと技術的な着想

既存の価格発動に、量で加重された基準の位置と傾きを追加すると、順行/反転の125/250先着と費用後損益は改善するか。00011の価格発動を対照へ残し、価格パターン・助走・線の起算・出口を一度に変更しない。[基礎と入力監査](../../docs/議論/配信元VWAPとセッション起算を確認する.md)、[結合設計](../../docs/議論/VWAP補助列を確定足へ結合する.md)、[00017](../00017_配信元VWAPと売買代金の入力監査/README.md)を参照する。

順行では押し目からの再開が配信基準より先にあるか、反転ではBB内復帰後も配信基準への回帰余地があるかを測る。基準の上昇中に一時的に下へ離れた買い反転など、線の傾きが実入口側へ向く選別を追加対照とする。市場心理の説明は、参照価格付近での参加/返済という仮説で、参加者の建値や注文目的の観測ではない。VWAPの位置と傾きは同じ価格/量の加工であり、独立な二票とは数えない。

## 価格発動Pと時間尺度

時間足は1/3/5分。価格発動Pは固定00011のT1「押し目再開」とR2「BB内復帰」をそのまま読取利用する。同generateへ渡す価格条件は00011と同じで、時間足許可を1/3/5分へ広げる。1分はこのPの追加尺度で、3/5分は元の価格発動との同値も確認する。T2/R1は今回使わない。下位EMA20・ATR14・ADX14・BB20/2σ・直前6本・当場公開15分EMA20方向の共通準備と、T1/R2固有条件を黙って削除しない。数量RVOL、RSIの新閾値は追加しない。

価格指標は既存価格cacheから従来と同じ方法で計算し、同限月の場間履歴・限月/欠枠/尾部リセットを維持する。VWAP手法の履歴は当場だけで、価格EMAの場間履歴と混ぜない。

## 判断時点の補助値

価格足の公開キー`(confirm,confirm_line)`で、その原行までに存在した補助値を原順に結合する。採用するのは**公開判断時点**の観測値で、前足終端VWAPとは呼ばない。確認行の更新を含み、同時計の次原行は含めない。旧cacheと補助cacheで省略する列が異なるため、原行の完全一致は要求しない。repeatは物理的に同じ状態が続く件数で、約定数量ではない。

00017と同じく接頭/終端を含む原順の最大価格時計キーから後退した補助行は除外し、時計で並べ替えて救わない。旧価格driverとの採否差、補助の最大キーが判断キーより先にある場合は参照不可として理由を記録する。現在の最後の状態が欠測・不整合・先行数量時計なら古い正常値を黙って検索し直さない。数量時計は場内かつ価格時計以下、Last/native/数量は有限正、代金は有限非負、配信比率の差は00017固定の0.00010001pt以内とする。さらに限月・市場・始値価格/時計の識別が既知で、始値時計が当時より未来でないことを必要とする。

価格時計欠測/後退の補助raw行は、基準・採用累積・epochを更新しない。ただし、それが判断原行までの最後のraw状態なら当判断は参照不可とする。00017の集計で行を除くことと、00018の結合で昔の正常値を現値として据え置くことを区別した保守条件である。識別属性が欠測中は既知identityを保持し、その属性を更新しない。有効な累積数量/代金は00017正本同様に採用してpreviousを進めるが、現在の識別確認が不十分なので売買参照は不可とする。

VWAP/売買代金固有時計・受信時計は存在しない。数量時計の条件は必要条件にすぎず、同時生成/実測受信遅延の保証とはしない。実際の約定モデルは旧価格/BBOを使い、VWAP価格で約定したと仮定しない。

## 起算、基準、履歴

配信値nativeと既知開始前基準からの差分値を別名で保持する。差分基準の作成/破棄は00017固定と同じ規則とする。Day当日06:00以後・Night当日15:45以後で場開始前の既知整合接頭、または開始秒ちょうどの直接零だけを基準にし、不明な初期累積を0で補わない。数量/代金減少、数量時計後退、既知identity不一致で永久破棄する。一時identity欠測は不変候補を保持するがその行は参照不可、後の同一確認行からだけ再開し、過去を補完しない。

nativeの区間番号epochは、上記の既知累積/識別変更で更新する。新起算値を読むことと旧区間の傾き履歴を橋渡しすることを分ける。各公開足の最新補助が不可、確認遅延30秒超、欠枠/index飛越、非公開、場/限月/epoch変更ではVWAP手法の連続履歴を切る。差分基準保持と手法履歴保持は別であり、一時未確認でも4点履歴の助走はやり直す。

native不可/非公開/確認遅延超過の足は参照記録を残すが、有効4点の履歴へ加えない。以後4つの正常な連続足で再び準備する。差分だけが不可ならnative履歴は維持し、Dの直近4点が全て有効になるまで待つ。

## 六設定と36入口

同じ尺度の現在足と直前3足、計4点の連続公開判断値を使う。Nマスクは4点全てのnative参照が有効かつ同epoch。DマスクはNに加えて4点全ての正の差分加重価格が有効かつ同じ基準/epochであること。価格Pの共通準備と時間条件も必要とする。

| 設定 | 共通助走 | Pへ追加する条件 |
| --- | --- | --- |
| N_A | N | なし：価格だけの対照 |
| N_B | N | nativeとの位置 |
| N_C | N | nativeとの位置、かつ`side×(native現在−native3足前)>0` |
| D_A | D | なし：差分比較用の価格対照 |
| D_B | D | nativeとの位置 |
| D_D | D | 差分加重価格との位置 |

sideは買い1・売り−1。位置は順行T1なら`side×(確定終値−線)>0`、反転R2なら`side×(線−確定終値)>0`。全て厳密不等号で、等号は見送る。N_Cの傾きも3足前との差が0なら見送る。N_A/N_BもCと同じ4点助走を要求し、Cだけ長く待つ比較を避ける。

2役割×3尺度×6設定＝36入口を全65場で評価する。Dは23Dayという一覧フラグで許可せず、各判断時点までの基準/履歴の可否から生成する。全65のN_A/B/Cと、D共通マスク内のD_A/B/D_Dを別の比較層にする。NとDの全運用額を引いて起算の効果としない。同じ価格P・同じ時点での包含関係と、実建玉抑止/再参加による参加集合の変化も保存する。

## 先着と運用

入口目標は逆行125pt以上より前の順行250pt以上。初期条件・支持数・30分間引き・費用資格は00016と同じものを固定して使い、目標を変更しない。全仮約定を分母とし、期限未達・観測不足を落とさず、未約定を分ける。既使用最終1場は旧二期間の支持判定へ加えない。

今回の出口は既存X0だけ。初期125pt保護・250pt利確・強制期限返済、単一建玉、要求後1価格時計秒以上の最初の正常BBO、新規有効30秒、確認遅延上限30秒、残り60分を維持する。micro1枚・ラージBBO代理・倍率10円/pt・呼値5pt・片道11円は比較用仮定。片道追加5/10ptは同じ保存約定への費用感度で、滑った価格から注文を再実行した結果ではない。

正常BBO空白300秒超等の品質注意を残し、全体の確定対象額をnullとする従来規則を維持する。利益が出ていた取引の20/50/100pt到達後赤字、活動頻度、場内時価/DDも記録する。VWAPへの通常回帰出口は今回未使用。80pt回帰の利確を250pt先着成功へ読み替えず、通常出口は入口を固定した次段階で比較する。
