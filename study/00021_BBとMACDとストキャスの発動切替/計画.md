# 試行00021：BB・MACDの継続とストキャスの反転を切り替える

計画日：2026-11-04。実行前の計画。旧00020の条件・結果・コードは変更しない。未実行/合成/準備点検/本再生/独立確認の状態はREADMEに記録する。

## 問いと以前との違い

00020はVWAP発動に三時間軸EMA/RSI等を重ね、成功例も除いて少数へ縮小した。今回は発動自体を二種類に作り、当時の局面で使い分ける。BBの相対位置・値幅変化とMACDの平均差の変化から継続T1、BBの価格文脈とストキャスの領域復帰から反転R1を定義する。移動平均線とRSIの例示に限定しない複合判断の一試行である。

00001のMACD/Signal交差、00011〜14の帯外→内や厳密な端越え、00013の最小帯幅から固定高安突破、00015/16の右足で確定するRSI極値とは発動時計が異なる。旧Q/P候補の名称変更や追加フィルターだけの試行にはしない。支持抵抗を先に登録する別案、数量、SAR、一目等はこの試行へ追加しない。

## 入力・執行・評価

固定00008の価格台帳を共有し、NK225全65場（学習40・条件選択24・既使用最終1）を使用する。全場は既使用で、11/4デイを未見確認とは呼ばない。配信VWAP補助列を入力にせず、原板を複製しない。入力の指紋/限月/時計/足形成は従来と照合する。

ラージ正常BBOをmicro1枚へ代用し、倍率10円/pt、5pt呼値、片道11円を仮定する。追加滑り0/5/10ptは同じ約定への費用感度で、再約定ではない。新規/返済は要求から1価格時計秒後以降の正常BBO、新規有効30秒、単一建玉/一注文、同判断の複数信号は同方向も見送る。デイ15:25/ナイト05:40新規停止、15:35/05:50期限返済を維持する。入口には残り60分以上を要求し、持ち越さない。

目標は逆行125pt前の順行250ptの支持付き確認率70%。全約定を分母とし、期限未達/観測不足を成功率から除かない。未約定は別記する。学習60約定・6開始日・10場、条件選択20約定・3日・5場以上を維持。30分間引きも学習20/選択10約定以上かつ双方70%以上を要求する。運用は費用/品質/両方向/活動支持を従来と同じにし、利益追尾による小さい黒字率をこの入口目標と混同しない。

## 指標計算と公開時点

入口足は1/3/5分、局面は15分。半開足の価格観測と、次の足に進んだことを知る価格時計/原板行を使う。15分参照は公開キーが下位以下、かつ足終了が下位終了以下の最新足。未確定足・後から分かる極値・将来の成績を使わない。

| 指標 | 固定する式と準備 |
| --- | --- |
| BB | 終値20本の算術平均Mと母標準偏差σ、帯はM±2σ、幅比w=4σ/M。M>0かつσ>0 |
| MACD | EMA12−EMA26、Signal=MACDのEMA9、H=MACD−Signal。各EMAは最初の期間本数の算術平均をseedにし、その後2/(n+1)で更新 |
| H変化 | ΔH現=H現−H前、ΔH前=H前−H二足前。MACD最速26本目、Signal/H34本目、この二変化の比較は最速36本目 |
| ストキャス | rawK=100×(C−直近14本安値)/(直近14本高値−安値)、当足を含む。SlowK=SMA3(rawK)、SlowD=SMA3(K)。Dは診断のみ、Dの準備/交差は必須にしない |
| 定幅時 | 14本高安差0ならrawK未定義、K/D平滑化窓を初期化。OHLC14窓は保持し、3連続有効rawKでKを再準備。0で補完しない |
| ATR/ADX/DMI | 共有Wilder14の定義/seed/欠測を維持。ATRは入口の値幅と追尾距離、15分ADX/±DIは局面判別へ使用 |

数値銀行は同限月の場間で持続し、欠枠では当足更新前、限月変更/前場の尾部欠枠では次の更新前に初期化する。完全幅の終端非公開足の数値銀行更新は既存Wと同じにするが、同場の入口や比較履歴へ入れない。その値が次場の銀行へ残る場合も、前場終了後に既知となる値であり、前場へ発動を遡及しない。

局所の比較窓は場ごとに空から始める。欠枠/非公開/足番号飛越/必要な単点値の未準備で初期化し、欠枠の当足は更新後に新しい窓の1本目とする。H/Kは有限であれば符号制限なし（負/ゼロのH、ゼロのKも許可）。BB中心/σとATRだけ正を要求する。D未準備は窓を切らない。

全四戦略共通の準備Mは、同場連続公開3本の必要単点値が有効で、現在の公開遅延<=30秒、15分ADX/±DIが公開済み有限であること。上位未準備や現在の遅延は発動抑止だけで、局所窓を切らない。過去2本の公開遅延gateを追加しない。全対照が同じ助走を待ち、未準備と準備済み待機を分ける。60分EMA・RSI・VWAP/N四点・数量は必須にしない。

## 発動T1/R1と売買対称

買いside=1、売りside=−1。価格差とH変化へsideを掛ける。Kは買いK/売り100−Kへ変換する。

| 系統 | 発動条件（同時に全成立） | 解釈と反例 |
| --- | --- | --- |
| T1・継続 | side×(C−M)>0、w現>w前、side×ΔH前<=0、side×ΔH現>0 | BBの方向側/値幅拡大で平均差の変化が再び方向側へ移る仮説。Hの0交差ではない。窓から大きい足が落ちたことでも指標は変わり、将来の加速を保証しない |
| R1・反転 | side×(C−M)<0、方向側K前<=20、方向側K現>20 | 中心の反対側で終値の相対高安位置が低位から戻る仮説。売りの生Kは前>=80かつ現<80。帯外→内、支持抵抗突破/失敗、K/D交差は要求しない |

等号は表のとおり。BB中心上ちょうど/下ちょうど以外はT/Rの価格文脈を混ぜない。T/Rが同じ判断で競合した場合の全記録はshadowへ残し、選択戦略内の複数信号は見送る。指標は同じ価格の派生であり独立した票として数えない。

## 四戦略と局面切替

15分ADX<=20ならレンジ。ADX>=25かつ+DI≠−DIならトレンド、方向は+DI>−DIで買い、鏡像で売り。他は待機。EMA方向条件/履歴保持は追加しない。分類は15分公開足ごとに一回だけ行い、同じ足を参照する下位足で更新回数を増やさない。

| 戦略 | 準備M後の許可 |
| --- | --- |
| T0 | T1だけ |
| R0 | R1だけ |
| A0 | T1/R1の両方 |
| S1 | トレンドでDI方向と一致するT1、レンジでR1、待機では新規なし |

3尺度×4戦略×共通出口X0一種=12運用。固定T/R、常時混合も複数手法を使う候補として全成績/支持/費用資格を記録する。切替の効果は同じ準備のA0等を対照にする。T/R別々の建玉の合算ではなく、一つの注文/建玉状態を共有する。役割は実新規時に固定し、保有中の局面だけで役割変更/ドテンをしない。

## 必須利益追尾と出口優先

全12運用で固定125pt非常保護/250pt利確/期限返済に利益追尾を併用する。正常返済BBOでMFE>=5ptを初めて観測したら起動する。入口ATRからD=max(5,ceil(ATR/5)×5)を固定し、保護する方向側利益=max(0,MFE−D)。価格へ換算後、買いは5pt上方、売りは下方へ丸め、既存線より緩めない。起動後の設定下限は新規価格。

正常板→確定足→信号の原行順を維持し、期限/既存待機約定→hard125→TP250→追尾の優先とする。既に返済要求があればその待機中は追尾状態を更新せず、最終MFEから起動を補わない。通常VWAP出口を使わず、初期化にもnative準備を要求しない。設定同値でも跳躍/待機/費用で実損は起こり得るため、起動後純赤字、設定と実返済の差を記録する。
