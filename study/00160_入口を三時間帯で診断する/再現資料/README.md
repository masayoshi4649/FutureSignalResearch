## 時計と範囲

主分類は実取得時刻の事後区分。デイはDay、ナイトは場開始日のニューヨーク09:30より前／等号以後で分ける。`America/New_York`の夏冬を自動変換し、2026-11-01以降を固定22:30で扱わない。旧FARの前後15分は別の補助分類であり、移行帯を除外しない。夜間前半の取得を米国開始時刻で強制返済する変更も加えていない。

入口のF/A/Nは旧取得後60分の観測が`complete`の例だけを125pt先着方向で分類し、他はCとする。記録touchがあっても全窓不完了ならCという旧契約を保持する。到達済み率F/(F+A)、H完了率F/(F+A+N)、全取得率F/全取得は別である。

金融H60はmin(取得+3600秒, デイ15:35/ナイト05:50)で、旧厳密H60へ置き換えない。D1は要求より後かつ1秒以上後・30秒以内の正常ラージBBO返済代用。C5はmini独立1枚、100円/pt、往復手数料77円＋追加滑り1,000円。mini固有の板深さや市場インパクト、片側上限10枚の口座は評価していない。利益・損失は判明分、未知は0円へ置換しない。

全73場を保持し、各セッション最低1取得を各小時間帯の強制1取得へ変更しない。前48/後25とも既使用で、時間帯別の新入口を選別・再学習した研究ではない。将来の入口選択では判断q0の時刻を使う必要があり、今回のq1取得区分を過去へ遡及して新条件と称さない。未見11/10ナイト・11/11デイ、旧156には触れていない。

- Python 3.14.3、tzdata 2026.6。診断と標準CSV再読は標準ライブラリを使用する。入力の場所と指紋はSource定数で固定する。
- CSVは提供環境のNode v24.22.1、`@oai/artifact-tool` 2.8.157。旧159のSDK 2.8.129と混同しない。SDK・skia-canvas・`@oai/walnut`・node_modulesは複写しない。新しい環境でimportできる依存を用意する。
- ZIPを別checkoutのrepoルートへ相対pathを保持して復元する。Root診断は同梱の逐次読取だけに依存し、旧workの計算器をimportしない。汎用Readerは旧159の停止源を同体再用したもので、独立数値検算は別の計算器で行う。

人工だけを確認する場合、repoルートで以下を実行する。自然再集計は呼ばない。

```powershell

```

全入力から本当に再生成する場合、**repo内の未作成の絶対出力path**を指定する。相対output-dirは固定Sourceの完了票で`relative_to(ROOT)`例外となるため使わない。
