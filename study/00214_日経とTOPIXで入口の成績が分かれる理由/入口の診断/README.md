# 同じ入口が二つの指数で別の時刻を選んだ理由

2026-11-19。試行213の既使用42デイで日経199_02と、同じ特徴・ルール・呼値数を使ったTOPIX03を比較した。**TOPIXが朝の短期回復を拾ったとき、日経ではすでに値が走り、同じルールが「買い上がり・売り下がり過ぎ」と判断する場面があった。** 一方、日経が朝に入った時間のTOPIXでは、短期の勢いや価格回復の根拠が不足することが多かった。

## 同じルールでも発火した足が違う

片方だけ判断できない場面を把握するため、各場・各指数の直近の確定1分足の終了時刻を照合した。同じ足でも、原板の公表を観測できた時刻は数秒ずれる場合がある。以下は両方の足がそろった後の比較。主入口は売買の純粋な成立数で、保有・予約の棄却より前に数えた。初参加用の補完Tは含めていない。

|同一分足の判断|両指数で比較可|日経だけ主入口成立|TOPIXだけ主入口成立|双方同方向|双方逆方向|双方とも無信号|
|---|---:|---:|---:|---:|---:|---:|
|全42デイ|14,284|507|448|69|19|13,241|
|予定公表が09:00未満|538|12|18|2|1|505|

朝に対応する当時特徴が片方だけの足は日経2、TOPIX1だった。比較可能な33足でどちらかが主入口を出し、同時に同方向は2足。片方だけに観測機会があったことでは、朝の発火の大半の違いを説明できない。朝の技術条件の構成を比べる際は、指標単位の履歴不足を別に扱った。

## 朝の補完入口で、どの確認が食い違ったか

LCは同じセッションで15分MACDヒストグラムの増分が未公表の間、5分方向・5分の勢い・短期の価格回復を組み合わせて判断する。ほかに取得位置や値幅の上限があり、条件が成立し始める場面だけを発火させる。出来高の足切りは使っていない。朝は取得時刻08:45以上09:00未満で、祝日の先物取引も含む。

|自指数の朝LC実取得|件数|同じ足で相手も同じ方向のLC全条件を満たす|取得側の5分DI差が注文方向|取得側の5分MACD増分・RSI増分がともに注文方向|
|---|---:|---:|---:|---:|
|日経|10|2|7|6|
|TOPIX|14|2|13|2|

- **TOPIXの取得位置。** TOPIXの朝LC14件中6件で、日経はすでに注文方向へ5分EMA8から1.88～3.17 ATR進み、同じ位置上限1.5 ATRを超えていた。TOPIXで取引したこの6件は1勝5敗、−83,501.6円。日経199が実際に同時にこの6件を見送った原因には、ほかの条件の不成立も重なる。日経の判断を厳密に発注時計より過去90秒以内に限定しても、4件で上限を超えた。これは価格の位置関係であり、二市場の配信順や注文フローが実際に日経からTOPIXへ先行していた証拠にはならない。
- **日経の取得時の勢い。** 日経の朝LC10件に対応するTOPIXで、同方向のMACD増分・RSI増分が両方とも正とならず、少なくとも片方を必要とする動力条件まで不成立だったものが5件（別に1件は既知不足）。構造の回復が成立しなかったものが3件。位置が範囲外だったものは1件で、注文方向と逆へ−2.71 ATRだった。条件間の件数には重複がある。
- **同じ「勢いあり」の中身。** TOPIXの朝LC14件中9件は、MACD増分が注文方向だがRSI増分は横ばいか逆向きの片側だけで通った。2勝7敗、−105,252.4円。日経では同じ状態は3件で全勝。TOPIXで両増分とも注文方向だった2件も2敗だった。RSI一致を追加すれば改善するとの判断はできない。
- **値幅と買い・売り。** 朝LCの設定幅÷取得時5分ATRの中央値は日経4.48、TOPIX5.22。呼値数を合わせても難易度はそろわなかった。日経では買い2件・売り8件がすべて黒字。TOPIXは買い7件すべて赤字（−133,085.2円）、売りは7件中4件黒字（＋15,914.8円）。左右対称の条件を変えず、期間に現れた売買の構成と結果を数えた。5分DIが既存方向を強く示していても、その後の継続は保証されなかった。

TOPIXの旧LC25取得を、発注時計より厳密に前・90秒以内の日経の取得側気配とEMA8の位置で事後分類した。金額はminiTOPIX1枚の費用後。範囲内は−2～＋1.5 ATR、下限割れは全件0。朝の上限超過と、日経で位置を算出できなかった時の損失は別々に発生していた。

|日経の位置（過去90秒）|朝14件の勝敗と収支|09:00以後11件の勝敗と収支|
|---|---:|---:|
|＋1.5 ATR超過|1勝3敗・−42,334.4円|1勝0敗・＋1,916.4円|
|範囲内|3勝3敗・−3,501.6円|5勝4敗・＋8,247.6円|
|日経の判断はあるが位置が算出不能|0勝4敗・−71,334.4円|0件|
|90秒以内の日経の判断がない|0件|1勝0敗・＋4,916.4円|

朝に直前の日経の位置が算出できなかった4件は、いずれも日経の売り気配が買い気配を上回っていた。日経の当時特徴を原行で見ると、9月25日・11月9日の08:50台には当場最初の5分足が未公表だった。10月1日・10月21日の08:58台には5分足の価格が公表され、ATRとDIは未算出だった。この4件は値幅で正規化した位置を判定できない。

事後に同じ完了足を使う場合、朝の超過は1勝5敗・−83,501.6円、範囲内3勝3敗・−3,501.6円、算出不能0勝2敗・−30,167.2円だった。09:00以後は超過0件、範囲内6勝3敗・＋20,747.6円、同じ完了足なし1勝1敗・−5,667.2円。超過時に注文を取り消すと後続の建玉も変わるので、これらの収支をそのまま回避可能な損失には計上しない。

双方が同じ足で同じ方向の朝LCを発火させ、実際に同方向を取得したのは下記の2日。いずれも両指数の発注判断は08:56:00だった。2026年11月2日はTOPIXで先に逆行し、日経ではその後に順行幅へ届いた。
