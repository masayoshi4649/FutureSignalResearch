# 方向の値動きと売買気配・費用の内訳

試行213の既使用42デイについて、日経199_02の162取引と、TOPIX自身で呼値換算して判断した135取引の取得・決済原行を調べた。同じ原行の仲値で評価すると、方向に沿って動いた分は日経で＋1,426,000円、TOPIXで＋29,500円だった。TOPIXはこの29,500円を往復の売買気配差80,500円だけで使い切った。日経に比べ、TOPIXの判断後の値動きが売買負担に対して小さかった。[比較条件](比較条件.md)

|mini 1枚・旧42デイ|日経199_02|TOPIX移植03|
|---|---:|---:|
|同じ取得・決済時刻の仲値差による損益|＋1,426,000円|＋29,500円|
|取得時の半スプレッド負担|97,500円|39,500円|
|決済時の半スプレッド負担|96,500円|41,000円|
|実際に代用した売買気配での損益|＋1,232,000円|−51,000円|
|往復手数料|12,474円|11,286円|
|往復の想定追加滑り|162,000円|67,500円|
|**最終収支**|**＋1,057,526円**|**−129,786円**|

1取引の設定幅を1とし、取引ごとに換算して平均すると、仲値差は日経＋0.3119幅、TOPIX＋0.0334幅。往復気配差はそれぞれ0.0436幅・0.0406幅、手数料と想定滑りは0.0390幅・0.0402幅で、合計負担は0.0826幅・0.0808幅と近い。いずれも実際のIFD出口の時刻を維持した分解である。仲値だけで発注・決済できる戦略の成績としては使えない。

朝のTOPIXはスプレッドと費用をすべて外しても、その売買方向への仲値変化がマイナスだった。09:00以後は仲値変化がプラスだが、気配差68,750円と手数料・想定滑り70,032円を引くと残りが小さい。LCと09:00前は日経10件・TOPIX14件が重複する。時間帯別の損益は当日の元の取得集合を分類した値である。

## 表示されていた板と約定量

売り注文には買い最良気配、買い注文には売り最良気配の表示枚数を対応させた。取得時の中央値はラージで日経8枚、TOPIX9枚。取得側の表示が1枚だったのは日経20/162、TOPIX4/135件で、両商品とも数量不明・ゼロは0件。返済側の中央値は日経6枚、TOPIX12枚だった。取得時スプレッドの中央値は両方とも各miniの2ティック。この観測に、TOPIXが一貫して薄かったという特徴は現れていない。表示枚数の取引単位は商品ごとに異なる。miniの実板と引き受け可能枚数は未観測である。

取得時点で公表済みの直近完全1分のラージ出来高中央値は日経58枚、TOPIX96枚。各商品の同一場の直前20分平均で割った相対量の中央値は日経1.153（143件）、TOPIX1.019（112件）。20分の準備不足・欠測があるため相対量不明は19件・23件で、09:00前は両商品とも全件が不明。全日中央値の差を朝の原因に転用できない。原板表示・出来高の集計は取得した局面に条件づけた記述であり、数量条件の売買成績は検証していない。

## 再現

Python 3.14.3の標準ライブラリを使用した。リポジトリ直下で `python study/00214_日経とTOPIXで入口の成績が分かれる理由/板と費用/同じ原行で分解する.py` を実行すると、旧199と213の固定台帳・84商品場のラージ原板・1分CSVから[結果](結果.json)を再生成する。11月6日の日経は199の価格索引が参照した `inputs/105生成原板` 内の同じ圧縮原板を使用した。原板の指紋を元帳の出典台帳と照合し、相異なる1,571原行で最良気配・数量・現値時計を抽出した。確定取引の取得・決済時刻/価格と費用後損益をすべて元帳へ照合した。
