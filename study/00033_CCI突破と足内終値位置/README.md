## 複合条件と同時点選別の意味

T0は固定31C0を識別子だけT0へ写した完全対照。3分の当場連続公開前20高安へのstrict終値突破、現前CCI20の実方向100超、ATR14正、当場最新15分BB現前公開ペア準備と時間/遅延を保持する。CCIは元OHLC FractionのTP・各20窓の同じ平均/MD・係数3/200、MD0無効、現前には21公開。BB数値は同限月carryし、当場隣接u/u−1のend/key asofを要する。上位BB幅拡大の値条件、SAR、量/OBV/PSY/ADX/一目を追加していない。

T1は当時の突破足のH>Lかつs×CLV>0（s=買+1/売−1）だけを追加し、CLV=(2C−H−L)/(H−L)を元H/L/C Fractionで求める。H=Lは未定義、実方向0もstrict不成立。幅0をT0共通Mへ加えず、表示float/任意εで採否を変えない。上下反射でCLV符号とsideがともに反転し、同じ実方向条件になる。CLV不成立を逆張り注文へ変えない。

価格突破は過去高安を越えた位置、CCIは同窓平均からの乖離、CLVは当該足高安内の終値位置を表す。同じOHLC由来で独立した票ではない。方向側で終えた足は押し戻しが比較的小さいという解釈を仮説とするが、参加者心理/需給の実測や継続の保証ではない。後足確認を待たず同じ公開keyで候補を選別する。

liveは固定31の純再構成から明示whitelistの当時情報だけを新辞書へ写す。旧C0 case・先着ラベルは正式集計だけに共有し、仮新規/判定/未来MFE等を運用へ渡さない。T0_X0と旧C0_X0の全fill/order/取引/入口取扱/追尾は識別文字列_T0→_C0だけの正規化で一致を検査し、数値や属性を除外しない。前ATR/前20高安幅による距離は記述専用で、欠測も採否へ混ぜない。

## 利益保護・執行・費用・場内完結

X0は固定31旧A5の完全対照でMFE>=5pt起動。現方針XFは現在正常返済BBOのs×(mark−新規)×10−122>0strictで起動する。122円は往復手数料22円＋想定片道追加5ptの往復100円で、MFEが過去に伸びただけでは起動しない。起動モデルの参照滑りは5pt固定、0/5/10の損益感度ごとに別の起動条件を再生していない。

起動後は両出口とも入口ATRからD=max(5,ceil(実入口ATR/5)*5)、保護利益max(0,MFE−D)、買ceil/売floor・非緩和・最低名目新規同値を維持する。起動条件が費用後正でも設定床は名目entryで、手数料込み黒字を保証する床ではない。hard125/TP250/期限と返済pending中追尾停止を維持し、CLVによる通常出口/SARは足さない。設定線は実同値約定や費用後非赤字を保証しない。

ラージBBOでmicro1枚代理、10円/pt・呼値5pt・片道11円。買Ask/売Bid新規・返済側BBO、要求+1価格秒以降の最初正常板、新規TTL30秒。同原行は気配→公開足→signal。片道追加5/10ptは同じ完結往復へ100/200円を控除する費用感度で、異なる発注経路の再生ではない。全順行、一建玉、自動ドテンなし。

デイ入力08:45〜15:40/停止15:25/強制15:35、ナイト17:00〜05:55/停止05:40/強制05:50を継承。正常板空白300秒超、未解消/EOF不足を品質として残す。価格時計は実受信時計ではなく、待機1価格秒は実注文遅延や実micro約定の実測ではない。

## 限界と次の問い

T0_X0→T0_XFは追尾起動定義だけを変え、T0_XF→T1_XFは同じ費用起動にCLV選別を加える二段比較。T1_X0は実行しておらず、2×2の全交互作用を識別しない。旧A5参考は現在方針採用候補へ数えない。T1純入口はT0の部分集合だが、出口や一建玉の占有時間が後続参加を変える。保持/除外の仮先着、同一実新規の出口差、片側参加差を分け、除外の仮250を実現可能な利益へ置き換えない。共通実新規/仮250対応/CLV符号群は結果後の集計で、良い群だけを当時の別フィルターへ戻さない。
