# 両指数を同じ価格特徴と単純IFDで比較する

18口座の共通対照を検証した。**この条件群は採用しない。18組とも建玉ごと・全セッションの中央値下限黒字を同時に満たさない。** TOPIXのT×4だけ既知合計が黒字だが、安定した入口の達成ではない。旧183/184の指数間成績差は、元の足・特徴・約定代用の違いを含むため市場固有の差と断定しない。本試行も、同じ式でなお残る観測可用性・指標の実時間記憶・費用/Rを可視化する対照である。

## 仮説と固定仕様

2026-11-17。81場（Day41/Night40、全て既使用）。Tは三足EMA/DI整合とMA近傍の動力再開、Rは低ADX・BB反対側位置・RSI/MACD増分・1分構造回復、MはADX15の25を境にT/Rを切り替える。買売は符号鏡像。Tは固定水準で押戻しを持続受容する状態機械ではない。条件を増やす前に、同じ無次元複合条件のどの部分が指数間で異なるのかを検証する心理仮説であり、利益を保証する説明ではない。

原観測から1/5/15/30分OHLCを直接形成。足始め・終端公表30秒、内部観測gap300秒以内の有効足を採用する。1分足が公表された原行で判断し、量を出生条件にしない。EMA等は有効足順で更新するため、欠測を飛ばした後の記憶時間は伸びる。同限月では完成指標を継承し、未完成足/1分直前3本は場越ししない。初期履歴不足や途中不足の場も分母へ残す。受信時計は存在せず、CurrentPriceTimeと原行順のモデルである。

IFD幅はq0時ATR15×1.5/2.5/4をmini呼値へ切上げ。H60、買売合計1保有・予約中も追加禁止。q0+1秒以降30秒内の最初正常ラージBBOで買Ask/売Bid。TPは返済側接触時の事前指値価格、SL/期限は+1秒以後30秒内の反対BBO。取得行のspread損切接触も含む。正常BBO300秒超空白や返済TTL不足は金融未知として場末まで枠を空けない。将来欠測を入口選択へ戻さない。

Day15:29/Night05:44に全決済を要求し、遅くとも15:30/05:45までを分母とする。開始一律待機はない。今回は追尾や技術による途中返済を足していない。

BBO差は取得/返済価格に入り、表の追加滑りはそれと別の費用仮定。ラージBBOをminiへ代用しており、mini自身の板流動性や実注文の待ち行列は再現していない。商品間の金額の大小で優劣を付けない。

## 差の所在

- 共通の対象時間2,832,300秒に対して、純q0公開後の判断分内可用区間はNK1,443,912秒（50.98%）、TOPIX1,787,804秒（63.12%）、両指数共通1,287,272秒（45.45%）。共通区間の割合はDay73.15%、PRE23.20%、POST36.35%。これは連続市場の観測可能時間全体ではなく、公開済みq0から次の分枠末までの保守的な区間である。共通区間で原口座を選別して成績を作り直していない。
- 近傍15分21有効足の取引時間跨度中央値はNK21,600秒/名目18,900秒＝1.143倍、TOPIX19,800秒＝1.048倍。5分35本/30分21本も診断に保存。EMAの全記憶がこの本数で切れるという意味ではない。同じ係数でも実時間記憶と局面出現数が異なり得る。
- T×1.5のIFD幅中央値はNK270pt/TOPIX11.25pt。往復費用/R中央値はNK0.03989/TOPIX0.05188、取得spread/R中央値はNK0.03922/TOPIX0.04762。取引価格へのspreadと追加費用を別記した。
- 同じ帯・ADX階級・実方向三足整合へ取得済み既知取引を分けると、T×1.5の平均net_R差（NK−TOPIX）は−0.02449。その算術分解は同局面内−0.07110、群構成差+0.04661で相殺される。この分解は各群の既知取引に条件付けた記述であり、未取得・未知を補完した市場固有の因果差ではない。全群の支持件数と共通支持率を正本へ保存した。

数量/出来高/相対量は今回未使用。欠測を量0としたわけでもない。価格だけのT/R/Mが両指数で安定しないという結果から、同じ価格母集団へ量観測可用性と量の水準条件を別々に重ねる[188](../00188_両指数の共通入口に数量の持続を重ねる/README.md)へ進む。187の金融後に量条件を追記しない。
