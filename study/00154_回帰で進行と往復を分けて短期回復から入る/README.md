# 154 回帰で進行と往復を分けて短期回復から入る

**実行済み・主U30は率と頻度の共同目標未達。** 213取得/全73場、81順89逆30未到達13不足、到達済み47.65%、平均0.2955回/時。C5既知利益1,072,300円/損失1,402,470円/差引−330,170円、未知3。新N30は126取得・35.45%で、旧C1を含めた主より低かった。結果の良い60分窓や旧対照へ主を交換していない。

## 検証した仮説と役割

153と同体の短期回復R0に対し、最新1分rを除く先行終値OLSの直線性と方向で進行/往復を分類した。TはR²≥.5・同向傾き・q0実側EMA8距離[-1,1]ATR。VはR²<.5・先行域端近傍からのClose/現在Last回復と、q0実側が端から内半分という取得位置を組み合わせた。R0の1分形状/現在回復、5分Hist/RSI増分、同足量は別役割で、5/15/30のMA・DI全方向/ADX ANDを追加していない。

窓は**r除外1分足×実時間15/30/60分**で、15/30/60分足ではない。30を主に固定し、15/60は比較。R²は標本内の直線性で将来勝率ではなく、境界.5/.25/[-1,1]/内半分は事前研究仮定だった。旧41の当足包含3分20点/終値突破への追加とは異なる仮説である。

全35,339q0を100特徴・先行域・OLSだけから先に保存し、その後取得対応と旧152/153対照を結合した。q1・教師・予測・旧選択を新資格へ使っていない。心理は「整った進行で同方向回復、往復では端近傍と内側位置」という仮説で、注文圧力や真の支持抵抗を観測したものではない。

[実行前条件](条件.md)と[設定済み513セル](設定と結果.md)はF0全文prefixを保持した。残る未実行表記はF0当時の記録で、現在の状態はこのREADMEと末尾結果で区別する。

## どの条件で残り、実逆ではどうだったか

R0出生1,494側のうち30分窓known1,163、進行R²≥.5は355。同側傾きで124へ減り、EMA8下限による追加減少はなかった。往復R²<.5は808側だが端接触16、実P内半分で8。T124出生→118取得、V8→8だった。未知331側を低R²へ補わず、低R²だけをレンジの確証としない。

同q1実逆ではT30は55順49逆7未7不足・52.88%/C5−56,086円、N30も52.68%/−64,702円で、方向を反転しても目標へ届かなかった。進行がR0と反対だった別事後群は231出生→226取得、元99順100逆11未16不足/−216,171円、実逆80順115逆15未16不足/−740,094円。原/逆のどちらも新規則の採用根拠にしない。

[停止原因短報](根拠/回帰環境の分類で残った制限.md)は全/前48/後25・出生/取得・原/実逆を分け、主要270正本値へ一致した。過去30分の直線性と短期回復が同じ向きでも、現在からの125pt先着を支えるとは確認できなかった、という固定群の関連であり、OLS単独の因果効果や最終的な敗因を断定しない。153の新6取得から126へ増えたことも、70%/1hの共同達成ではない。

さらに[現在価格と回復足の独立診断](根拠/現在価格と回復足の維持を分ける.md)では、元向きにr始値を維持したR0の1,147件も45.97%/C5−2,174,163円だった。始値より逆側の108件を実逆にしても51.09%/−77,239円、逆端を破った79件の実逆も44.78%/−147,006円。始値は負・逆端非破りの29件だけは実逆68%/+69,767円だが、前48は50%赤字・後25は80%黒字という事後小群で未採用。単純な現在足始値の維持/喪失だけでは、固定R0を70%へ改善できる結果ではなかった。原因の証明や新政策の採用とは区別する。
