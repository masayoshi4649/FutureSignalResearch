## 不調の原因と次の技術仮説

10/23ナイト米国前の旧14逆行を同じq0から追跡した。共通は14買いを維持し14逆行。属性入りは5待機・9買いで9逆行。帯別は5待機・9売りで9順行、局所既知+108,307円となった。反転率を1−pで計算せず、反対側の実Ask/Bidで確認した。ただし帯別Nのそのナイト全体は155取得・32順56逆55未12不足・既知−656,242円。局所9勝を場全体の安定化とはしない。

旧14件はMA・DIの向きが混在し、5分Hist/RSIが買いを支持しない一方、強反対背景Gが成立しないため短期回復Rを必須にせず買いを通していた。後25場のCOMMON新193件もすべてG外維持で46.11%。主な改善候補は、強い反対だけを検出する二分岐から、背景同方向・反対・混在を分け、混在時に構造回復・短期再加速・量を組み合わせる部分である。BB余地・ATR比・ヒゲで推進と終端を区別し、近接した同一構造を新しい独立エッジとして数え過ぎない仮説も残した。[原因と次の仮説](原因と次の仮説.md)。ここで新閾値を後付け採用していない。

## 支持・探索自由度・限界

共通/属性は65モデルずつ、帯別はデイ29・米国前28・米国後28の85モデル。過去20暦場・1000物理pair・8寄与場・3クラスを固定し、場開始時だけ学習した。帯不足7,122q0のうち3,799は当場COMMONへ、3,323は共通も未準備で待機した。時間属性は複数技術役割へ数えていない。

SPLIT主Fの2908取得を分解すると、真の帯別モデル2747件は50.40%・既知−2,717,126円、COMMON戻し119件は71.11%・+366,145円、初C1補完42件は77.42%・+181,843円。したがって支持不足だけで不調を説明できず、共通戻しの4場の高率を帯別モデルへ帰属できない。[分解の正本](検査/帯別学習と共通戻しの事後分解.json)。純Nの帯別由来2749件との差2件はFの旧優先統合による。

3方式×3閾値と、P65だけのA補正で12信号、N/U/Fの36政策、旧5対照の計41政策を事前固定した。各帯の最高条件を後から結合していない。それでも既知の160診断を踏まえた設計で、前48/後25とも既使用。未見11/10ナイト・11/11デイ、未実行の旧156は読まず保持した。近接入口は1時間の観測が重なり独立ではない。全場を除外せず、未取得・未到達・不足・金融未知を残した。未参加の仮想利益を機会損失として最適化していない。
