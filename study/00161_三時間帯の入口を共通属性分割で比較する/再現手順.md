## 学習と旧再現確認

Python3.14.3、NumPy2.5.4、CatBoost1.2.10、CPU1thread。時帯変換はzoneinfo+tzdata、独立金融監査はijson3.6.0。正確な版は保存索引へ記録する。元の自然実行はSHA固定した旧151の後発cache4本を使った。cacheは正式151後発生成物で、自然実行のF0より前から存在したことと、正式151初回F1より前に存在したことを混同しない。

cacheが無い別checkoutでは、Source.zipを元の相対位置へ展開し、学習と採否.zipから場別監査を取り出して次を実行できる。

```powershell
python -X utf8 work/161三時間帯入口/正式入力から学習を再現する.py work/161隔離再現 展開先/場別モデルと教師.json.gz
```

正式148の共有gzipから旧151のSHA固定Sourceで再射影し、同じ過去成熟選択・三方式を学習する。学習配列/木構造/教師のSHAを自然結果へ比較する。NPZやモデルJSONの時刻metadataによる物理byte同体は要求しない。この正式入力直結の追加CLI自体は今回全学習を重複実行していない。自然cache入力検査と、215モデルの保存JSON全再推論・独立教師再構築は実施済みである。

元cacheを持つ別checkoutでは`学習する.py`、`取得を結ぶ.py`、金融`outcomes161.py`のrunner、`集計する.py`の順に実行する。各Sourceの保存pathと固定出力先を確認し、未作成の作業先を使う。`correct`/`connect`は純関数として再用できる。ラベルを受けない出生判断を先に確定し、取得、金融を後段で結合する。

旧151正式ZIPと152/153正式選択は直接SHA/CRC確認して照合する。証拠は[旧151学習同体](検査/旧151学習の同体確認.json)・[8政策同体](検査/過去8政策の同体確認.json)。旧153と152は再探索せず保存政策を固定対照として継承した。旧156と未見2場は未使用。

## 金融・表の再現

`work/161三時間帯入口の金融/outcomes161.py`の`read_outcomes`は入口採否を受け取らず、正式148観測全73場を読了しCRC/解凍SHAを確認後に小表を確定する。strictH60 completeのF/A/NとCを区別する。IFDは最初touchの実BBO、なければcomplete endpoint、他は金融未知。Cでも早期touchがあれば金融既知。`net5`をtouch損益へ転用しない。

四表は型付きJSONを`CSVへ出力する.mjs`でartifact-toolに読み込み、全セル照合・再計算・inspect・表示確認を行ってUTF-8 BOM付きCSVへ出す。xlsxを生成しない。`CSVを独立再読する.py`でPython標準csv全セル再読。CSVが見られれば、表示確認画像やNode環境は閲覧に不要。

```powershell
node work/161三時間帯入口/CSVへ出力する.mjs study/00161_三時間帯の入口を共通属性分割で比較する/成果物/型付き四表.json outputs/隔離再現161
```

独立監査はSource.zip内の`work/161独立確認/`を参照。金融独立監査は作者と別のijsonで元全観測を読み直す。入口の3方式・閾値・A補正・N/U/Fを変えた場合は161を上書きせず新試行とする。
