## 共有入口と出口の役割

C0は当場3分前20高安へのstrict終値突破＋現前CCI20実方向100超、C1はさらに当場公開15分BB20絶対幅拡大。CCIは元H/L/C FractionのTP・同じ各20窓平均/MD・係数3/200、MD0無効/±100等号不可。15分BB数値carryと当場公開pair/end-key asof、ATR正を31と同じ準備にする。今回SARを入口gateへ追加していない。

旧case・旧labelは共有参照だがliveの出所にしない。固定31を純再構成し、場/ID/方向/要求key/当時low-high-ATR/bb_meanだけを明示whitelistで新辞書へ写す。仮新規・判定・未来MFE等は運用へ渡さない。入口評価は二案で不変、SARは出口の追加材料である。X0は旧関数へ直渡しし、全fill/order/取引/入口取扱/追尾属性を除外なしで旧31と一致確認した。

精密SARは固定25の選定規約を元OHLCのFraction・AF整数/100で新実装した。初期は隣接終値のstrict差・同値保留、初期表示は買min(前L,現L)/売max(前H,現H)、EP現高安・AF2。成熟時は前次足線へのstrict貫通を先に反転判定し、非反転時だけ前2足clamp、その後EPstrict更新でAFを2増/上限20、表示+AF×(EP−表示)で無clamp次足線を作る。反転は旧EPと現在高安から表示/EPを再設定しAF2へ戻す。旧floatやTA-Lib/TradingViewとの完全同値、唯一の標準SARとは呼ばない。

SAR銀行は同限月carry、欠枠/番号欠/不正/尾部/限月で解除。有効欠枠当足は数値の種、全幅NPは内部更新だけ、partialは不投入。場初の公開参照は空で、当場最新だけを使う。長い精密値はhex正規分子/正分母へ保存し、float表示を方向・反転・利益・呼値判定へ戻さない。

## 同値床・SAR・BBO・注文の時点

両出口とも建玉あり・pendingなしの正常返済BBOでMFE>=5ptなら必須起動。XSはSAR不準備/逆向きでも名目同値床を作り、入口時ATR距離による上締上げを行わない。X0はD=max(5,ceil(入口ATR/5)*5)、利益幅max(0,MFE−D)を継承する。

XSは公開足tの確定方向と精密次足線を、公開keyよりstrict後の正常BBOから使う。同keyはBBO→bar→signalで、bar時lastBBOで線更新や即時要求をしない。BBO間に溜まった公開は最新一つだけ、最新不良から古い正常SARへ戻らない。入口前の当場最新公開も利用可。方向=sかつ元精密線のs×(S−新規)>0のみを5pt買ceil/売floorし、買max/売minで旧線非緩和。逆向き/不正/非正益では旧床を維持する。

初回床BBOで既知SARを締めることもできる。候補が気配を既に越えていても現在気配へclampせず、そのBBOで初着要求、要求+1価格秒以降の最初正常BBOで代理約定する。SAR線そのもので約定した扱いにしない。返済pending中は建玉の起動/設定線/適用出典を凍結し、global数値/公開源と実返済までのMFE/MAEは進める。pending後にMFEだけ伸びても過去の起動を補完しない。

期限/既pending約定→hard125→TP250→必須追尾の優先を保持し、通常出口/自動ドテンは足さない。新規TTL30秒、ラージBBOのmicro1枚代理・10円/pt・呼値5pt・片道11円。買Ask/売Bid新規・返済側BBO、追加5/10pt片道費用は同じ完結往復への感度である。同値床は同値約定や費用後非赤字を保証しない。

デイ入力08:45〜15:40/停止15:25/強制15:35、ナイト17:00〜05:55/停止05:40/強制05:50を継承。正常板空白300秒超/未解消/EOF不足を残す。価格時計は受信時計ではなく、1価格秒待機は実発注遅延の実測でも実micro約定再現でもない。

## 限界と知見の扱い

SARは極値・AF・時間から追随線を作るが、参加者の注文・心理を直接測らない。進まない建玉から退出しやすくなる仮説と、押し戻りで早く退出する可能性を両方持つ。今回XSはATR距離を外し、足公開単位のSARへ替えたため、値と更新頻度を含む方針全体の比較である。

SAR締上げ済/床のみ、共通実新規、仮250対応は結果後の群。良い群だけを当時の入口や動的切替へ戻さない。床のみの独立対照は実行しておらず、全期のSAR追加だけの純増分を識別する比較ではない。未起動の事後MFEもpending中の伸び等を含み、床省略の証明ではない。共有入口・X0同値でもXSの保有長が後続参加を変えるため、同じ取引の出口差と参加差を分ける。主要条件を変える場合は別試行として事前固定する。
