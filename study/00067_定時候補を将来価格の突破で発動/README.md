## 固定した条件発動と保護

デイ09:15〜15:15の25枠、ナイト17:30〜05:30の49枠で候補を決める。定時に最新公開・完全な3分足の方向端high/lowを凍結し、将来Lastのstrict突破を待つ。設定時の既超過は拒否。normal BBOかつ有限正Lastで監視する。設定時のLast／BBO不正は判定不能とし、監視開始後のgap>300秒は観測不足取消・品質注意とする。途中の新指標で方向・線・ATR/Dを更新しない。

T+900の次定時で未発動watchも発動済entrypendingも取消。発動後1価格時計秒かつ後行の最初の正常BBOへ新規、TTL30秒でも次定時未満に限る。Lastは発動条件で、線価格やLast自体へ約定を戻さない。同秒原行順を保持し、過去の足高安から足内順を推測しない。

主待ち=WAIT／全予定枠。保守上限=(WAIT＋判定不能＋条件登録してentryなし)／全予定枠で50%以下、保有継続は非待ち。登録指示だけを実参加と数えない。候補・監視・発動・要求・仮約定・実新規・完結は別分母であり、条件待ちの事後結果を当時の採否へ戻さない。
