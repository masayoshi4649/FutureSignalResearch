# 67：定時候補を将来価格の突破で発動する

計画作成日：2026-11-06。固定前の計画。市場実行後の正本は結果.jsonと設定と結果.mdへ保存する。入力は全66場既使用、今回の評価46場も探索である。未読11月5日Dayは開かない。

## 仮説と比較

同じ複数技法で方向候補を決めても、現在の価格がその方向へ再開しているとは限らない。定時後に局所高安の突破を確認すれば、動かない候補への参加を避けられるかもしれない。一方、取得位置の悪化・利益の取り逃がし・待ちの増加があり得る。この両方を測る。

[外部調査](../../docs/議論/外部再調査/判断時刻と条件注文の発動を分ける.md)の候補・発動・約定の分離を設計参考とする。3分足・15分寿命・Last strict突破は独自の機械化で、原典の完全な再現でも、心理の直接測定でもない。[試行66](../00066_複数手法の適格方向から優先側を選ぶ/README.md)の選択順変更は全判断同値だったため、ここでは純方向を固定し、実際に要求を出す価格条件へ進む。

| 候補 | 定時の分析 | 実新規の要求 |
| --- | --- | --- |
| E0/E1保存対照 | 66の保存された全60特徴・3木・技法/支持/回収資格 | 定時に即時要求。保存結果を参照し再生しない |
| G0/G1 | E0/E1と同じside・役割・ATR/D・予測全辞書を直接保存参照 | 定時に最新公開3分足の方向端を固定し、将来のstrict突破で要求 |

方向決定はDMI/ADX、ストキャスティクス、ATR、BB幅、開始帯・局所帯・段階別価格経路・量の既存複合構成。高値突破だけで方向を決めない。新fit、新予測、新保存木、新特徴算術、新教師作成、新独立追尾回収は0。新しい入口からの先着評価は行う。旧55回収は即時入口の過去情報であり、新しい発動入口の期待回収を学習済みとは呼ばない。

## 判断と条件の時刻

- Day09:15〜15:15の25枠、Night17:30〜翌05:30の49枠、各900秒。元の全予定枠を保持する。
- 実判断は予定から30秒以内の元原行。保有・返済待ち中は新規監視を登録しない。退出後も次の定時まで同枠再登録なし。
- 元純候補の最新3分SOURCEを旧28銀行と照合する。足end≤予定T、公開key≤実判断key、当場、公開完全、有限正OHLC。将来の足で線を更新しない。
- 買いは同足high、売りはlowを発動線Kとする。買いLast>K、売りLast<Kをstrict発動。bufferを追加せず、等号は未発動。high=lowも許す。
- 設定行が正常BBOかつ有限正Lastで、既にstrict外側なら登録しない。同時刻以前の突破へ遡らない。Last不正なら判定不能で未登録。
- 設定keyよりstrict後の原行だけを監視する。同価格秒の後行は対象だが、設定行自体は発動しない。新しい指標・方向・ATR/Dへの更新は行わない。
- 否定価格線は今回は追加しない。監視からの自動反対注文・再発動も行わない。

## 寿命・約定・観測不足

発動前の監視はwatch、発動後の約定待ちはentry pendingとして別に持つ。一つのwatch、一つのpending、一枚の建玉を上限とし、重複新規を作らない。

1. watchは次の予定T+900で満了する。最終枠もDay15:30/Night05:45で満了する。
2. 次定時では未発動watchと、その出自の未約定entry pendingをともに取消す。境界等号は約定より取消優先。返済pendingは取り消さない。
3. 発動後は要求+1価格時計秒以降、後原行の最初の正常BBOで買いask/売りbidを使う。TTL30秒等号を許すが、次定時・強制・終了未満に限る。飛越した線価格で約定しない。
4. watch用の正常観測は正常BBOと有限正Lastの両方。設定行timeを起点とし、この観測間隔が300秒を超えたら突破判定より先に観測不足取消。300秒等号は許す。満了まで観測がない場合も、最後の観測との差を検査する。
5. watch中の不足は未発動確定と分け、当場の品質注意とする。期間全体の確定損益はnullへ倒し、観測現金を別に残す。登録前のLast不正は判定不能で、watch不足として二重計上しない。

この要求方式は旧O49の定時要求契約を変更する。新エンジンを別ファイルへ置き、旧実装は変更しない。CMEの取引所native stopやOSEの実発注を再現したとは呼ばない。受信時計・板待ち順位・部分約定は未観測である。

## 保有後の保護と費用

元定時ATRからD=clip(ceil(ATR3/5)×5,5,125)を固定。新規後h=max(0,過去h,現在方向差)、L=max(過去L,−125,h−D)。現在正常返済BBO粗益−122円がstrict正になれば利益旗を立て、最低L≥0。r≤Lで返済要求し、返済pending中はh/L/利益旗を凍結、実MFE/MAEは別に更新する。

O49と同じ連続追尾・返済後行遅延・強制15:35/05:50・終了15:40/05:55半開を保つ。固定250利確は追加しない。ラージBBOをmicro1枚代理、10円/pt、片道手数料11円・想定滑り5pt。往復122円。0/10ptは同約定の費用感応であり、別約定の再生ではない。最低名目同値は費用後黒字を保証しない。

## 評価と分母

| 評価 | 定義 |
| --- | --- |
| 純候補 | 旧E0/E1と同じ枠・方向。488方向予定。建玉占有に関係なく条件入口を一回評価 |
| 新先着 | 新trigger後の仮約定を起点に、返済側BBOの+250より前に−125へ達しないか。旧即時ラベルは転用しない |
| 未発動・未約定 | 既超過、設定観測不足、watch観測不足、正常未発動、発動未約定を分ける。成功約定だけの分母を全候補と呼ばない |
| 非重複 | 仮entryの時刻・原行順で並べ、同場の前label終点よりstrict後だけ採る。force同秒は最初の正常原行まで |
| 実運用 | 一枚の占有を考慮する92運用。新旧の実参加集合が同じとは仮定しない |
| 主待ち | 当時のactionが待ちの数/全予定枠。条件登録指示、保有継続、処理中を別に表示 |
| 保守待ち | （待ち＋判定不能＋条件登録したが最終的に新規約定なし）/全予定枠。未発動監視を非待ち成功に数えない |

先着支持・主/非重複率70%、主/保守待ち50%以下、旧費用支持・品質を満たす費用後正額を同時に要求する。時系列20場と条件選択24場を主判定、既使用後続2場を別表示。後続少数の黒字だけで採用しない。

同じ純候補に対する新旧結果対、両約定での方向付き価格差・取得遅延、順行/反転、買い/売り、利益旗後赤字を保存する。新規数減少による赤字減を、入口先着率の改善と取り違えない。
