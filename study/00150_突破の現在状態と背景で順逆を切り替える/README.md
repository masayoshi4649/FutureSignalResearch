## 一般論・心理仮説・研究事実を分ける

一般教材では、突破した抵抗が支持へ変わる場合と水準を帯として見る考え方が説明される。端への再接近と、その後の支持・拒否の成立は別である。[CME](https://www.cmegroup.com/education/courses/technical-analysis/support-and-resistance)、[StockCharts・Rectangle](https://chartschool.stockcharts.com/table-of-contents/chart-analysis/chart-patterns/rectangle)

ADXは方向と独立した強さであり平滑遅れもある。高ADX・ADX低下のどちらも、継続や反転を単独で確定しない。BBへの接触単独も売買信号ではなく、帯沿いの継続がある。[StockCharts・ADX](https://chartschool.stockcharts.com/table-of-contents/technical-indicators-and-overlays/technical-indicators/average-directional-index-adx)、[Bollinger公式ルール](https://www.bollingerbands.com/bollinger-band-rules)

「端を維持できず突破参加者の返済が増える」「強い背景では押し目買い・戻り売りが支える」「低い方向性の下で帯端の偏りが修正される」は本試行の心理仮説である。主体や注文理由を観測していない。**終値突破→現在端以内という状態を、反転完成やリテスト成功とは呼ばない。** RTも次の再突破や成功したリテストを確認した手法ではない。直前3本端は、複数回試された支持抵抗と自動的に同一ではない。[Wyckoff教材](https://chartschool.stockcharts.com/table-of-contents/market-analysis/wyckoff-analysis-articles/wyckoff-market-analysis)

149の事後小群では、T4の端復帰26件が実逆16順4逆だった一方、R3の現在Lastが前足始値回復を失った25件は元向き14順6逆だった。この違いを背景と構造の役割で区別できるかが新しい問いである。全期既使用の事後群から着想しており、150の検証済み優位や未知期成功ではない。[149結果](../00149_継続と反転を可読8局面で判定する/README.md)、[共通知見](../../docs/議論/構造の成立水準と無効水準を局面別に分ける.md)

**FA/FD/RTの量は終値突破足rの量であり、その後に端へ戻った動きの量ではない。** OHLCVの総量は買い成行・売り成行の内訳でもない。未確認の反対構造、後続の回復足、将来pivotを当時の証拠へ足さない。資料確認日：2026-11-12。上記教材は日中NK225の±125pt先着70%や、本試行のADX等の最適閾値を裏付ける実証ではない。

## 入力・判断・評価

148の当時特徴・取得対応・入口参照の保存gzipと100列定義を共用する。BUY/SELLは同q0のAsk/Bidを使って別計算済みの100値であり、単なる符号反転ではない。全q0の判断を先に生成してから取得対応と結合する。q1価格・取得有無・将来ラベル・損益は条件の入力へ渡さない。

同q1 caseの新候補は最初のq0を代表にし、旧C1との重複は旧87を優先する。未知を既知0へ補完せず、反対方向の競合・未取得・品質取消・期限切れも記録する。固定73場は全て既使用。追加2場の価格は未読のままとし、独立未知期の検証とはしない。広い容量調査は非金融の成立余地を調べた参考資料で、150の自然選択・運用頻度・成功率の結果ではない。

主評価は実BBO・取得後60分・同幅±125ptの到達済み利確側先着率70%以上。順行・逆行・未到達・観測不足と全取得数を分け、全73場min1と、全720時間55分を分母にした平均概ね1回/時も別及び共同で判定する。場ごとの一律頻度や強制時刻は課さない。途中の条件成立数や枚数分割を取得回数へ代用しない。逆向きは保存した実BBO側を用い、1−pで推定しない。

mini1枚換算で1pt=100円、往復税込手数料77円。費用C0は手数料のみ、C5は片道5ptずつの追加滑り計10pt=1,000円を加える。期限清算や実逆も同条件で比較し、IFD金額の既知・未知を分ける。Lastはチャート側の先着診断とし実約定金額へ置換しない。全件の重複保有を許す独立ケースのIFD代用合算であり、片側10枚・両建て口座の収支や実注文、利益追尾の有効性を検証したものではない。
