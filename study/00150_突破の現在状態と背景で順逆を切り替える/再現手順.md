# 150の保存資料からの再現

条件・選択・金融を分ける。正式結果は[README](README.md)、全保存実体・由来SHAは[保管索引](保管索引.json)、固定票は[入口前F0](検査/F0入口選択前.json)・[入口固定後F1](検査/F1入口選択後.json)・[金融前F2](検査/F2金融集計前.json)を参照する。

## 入力とコードを復元する

条件JSONは[inputs正本](../../inputs/00150_構造状態の可読選択/条件.json)、Sourceは[scripts正本](../../scripts/入口研究/固定特徴から可読条件を選択する.py)。F0/F1の正式3MD原文は検査の文書snapshot gzipに保存した。現在の結果追記済み文書を実行前SHAの照合へ直接使わない。

F0/F1/F2の小型源は再現資料の各固定ZIP又は既存恒久正本へ分類し、保管索引の復元先・ZIP内path・保存SHA・解凍SHAに従って復元する。[保管・再集計コードの後発ZIP](再現資料/150保管と表示の後発資料.zip)は事前F0へ追加したものではなく、保存・閲覧・再現の後発資料である。既に存在するworkのコードは指紋照合し、無条件に上書きしない。

148の100列定義・当時特徴・取得対応・入口参照のgzip、大観測gzip、旧145の87対照の保存観測と集計は共有依存である。150の恒久保存先へ大入力を重ねていない。150で新たに生成した[判断・取得結合・確認の3gzip](../../inputs/00150_構造状態の可読選択/)は各一度保存し、元24,094,970bytesを1,140,691bytesへ圧縮した。物理gzipのSHAと解凍JSONのSHAを区別する。

## 保存観測から金融を再集計する

後発ZIPの元相対pathどおりに小型コードを復元し、リポジトリルートで次を実行する。既存の正本や作業先は上書きせず、destinationは未作成のwork内パスを指定する。

```powershell
python -X utf8 work/150正式保存/保存観測から再集計する.py --destination work/150再現_任意の未作成名
```

再現器は恒久ZIPから停止済み集計器・依存源を復元し、148の4入力gzipと大観測gzipを直接読む。旧145圧縮観測は隔離workへhardlinkで参照し、原板走査・出生生成・入口選び直しを行わない。842MBの観測plainを新たに保存する必要はない。旧固定票の絶対pathは再現先専用票へ写すが、全数値・セルは変更しない。

保存実体だけを使った再実行で720比較・参加・頻度・場別累計・連結群の全dict、および三表JSONのbytesが一致した。[保存再現の検査票](検査/保存観測からの再現確認.json)が証跡である。独立した金融算術は[Root別算術票](検査/金融独立検算.json)に分離し、保存再現を新しい独立算術検査とは呼ばない。

作者集計JSONのキー名`F2_SHA256`には、CLIに渡した入口固定F1のSHA `d19e311a…`が入っている。金融前F2は別原本の `222b3572…`である。再現先票のpathに伴う同キーのSHA差だけを正規化して比較し、作者原本・数値を修正しない。今後の集計器共通化時に直す課題として残す。

## 選択を別途再確認する場合

共通SourceのCLIで固定条件JSON・148の3gzipに通知済み物理SHAを渡し、未作成の別output-dirへ出力する。全q0の判断を先に生成し、その後に取得対応・metadataを読み、q1や将来ラベルをXへ渡さない。条件bookとSourceの指紋はF0で固定済みである。新しい選択を正本へ置換せず、保存された3JSONと比較する。

取得前の[独立全件監査の保存先](保管索引.json)は全35,339q0・全政策参照・FA除外・C1優先を別実装で確認した。監査票は金融前F2の固定ZIP、監査コードは後発ZIPへ分けて保管した。入力の品質・真の受信時計・実発注約定・枚数口座・未知期の成立を追加で証明したものではない。[CSVの閲覧](閲覧資料.md)と未知の扱いも維持する。

[事後原因短報](根拠/広げた構造候補が弱まった理由.md)は旧T4当時26/旧R3全59と追加領域を分ける。旧小群の良さを残しつつ、広い追加域へ一般化しなかった事実であり、良い群を選び直した採用成績ではない。詳細は[一度gzip](根拠/原因診断.json.gz)へ保存した。
