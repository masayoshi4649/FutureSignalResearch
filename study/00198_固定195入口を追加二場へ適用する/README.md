## 何が変わったか

11/17の11:16:01、旧買い要求810は5/15/30分の売り背景が揃うriskとして保留された。旧基準はこの買いを取得し+16,923円。その15分後11:31:01に旧売り825が出た時、買い圧力のriskが非該当なため保留setupを取消し、旧売りをそのまま取得した。その収支が−24,077円で、差−41,000円となった。他5Day取引とNight2取引は同じ。

825の売りMA差・DIは正で拡大していたが、売りMACD増分−0.314・RSI増分−2.970は短期の反発を示していた。この取得は新しい反転/順行確認を通らず、193のMA非拡大も195のT判別も対象外だった。リスクが非該当になっただけで、新方向の取得根拠が揃ったとは限らない。[当時の特徴と固定水準](監査/旧幹による確認取消の診断198.json)は事後診断として保存。次199では保留中の旧幹による確認取消を別条件として比較する。
