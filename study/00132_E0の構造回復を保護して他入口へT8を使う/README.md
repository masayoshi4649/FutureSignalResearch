## E0の元条件と市場心理

E0は[121のC0/E0仕様](../00121_失速と量で反転の入口を切り替える/実行前原文/README.md)、[122の固定E0](../00122_E0固定条件を全セッションで検証する/実行前原文/README.md)、[123の共通入口仕様](../00123_複合入口で全セッション最低1回を検証する/根拠/入口仕様.md)を継承する。今回はこれらの条件を再選別せず、保存された9票の元方向をそのまま使う。

買いは当1分Lowが15分BB20の下端（±2母標準偏差）以下、RSI15≤35。直前5本1分の最安値を当1分が厳密に割り、終値がその境界から内側5pt以上かつ旧5本レンジ内へ回復する。売りは高安・上下・RSI50からの符号を反転した同一条件。側実体正、側終値位置≥0.7、当TR≤2×当足を除く直前14本TR平均を保持する。

E0は政策C0に、ADX30と前値がともに既知で当ADX<前ADXを要求する。ADXの低下だけで買い/売り方向を決めない。RVOLは記録するがE0の必須条件ではなく、量の未知を低量又は支持へ置換しない。上位MAの同向をE0へ新しく加えない。

自然否定は当1分逆側極値の外5pt、出生Last/実取得までの正距離≤min(100pt,0.5ATR5)、取得capは終値から側min(10pt,0.15ATR5)。出生/取得Lastで前5本の逆側境界から内側5pt以上の回復を維持する。要求より後の原行かつ価格時計1秒以上後・30秒未満の最初の正常BBOでcap→hold→riskを評価する元仕様を確認した。132でこの注文を再生し直すわけではない。

心理の仮説は「過熱領域で元方向の突破が失敗し、価格が旧領域へ戻れば、突破追随者の撤退と反対側の参加が生じ得る。長めのADX低下は元の圧力の弱まりを示す補助になり得る」。注文者の意思を観測した証拠や、反転が必ず続く保証ではない。今回は、こうして構造から作られた方向を他の型と区別することに予測力があるかを検証する。
