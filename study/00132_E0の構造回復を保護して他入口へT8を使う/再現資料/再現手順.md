132は金融前の方向同体検査である。金融前F1、新しい入口先着率・損益集計、300比較、3CSVを作成していない。後から金融前F1を再構成しない。[主条件と結果](../README.md)、[設定表](../設定と結果.md)。

- [旧T8の入口型追補](../根拠/入口型の追補/結果と型の由来.md)：追加区分の事前MD・固定票・型由来・保存79票/73場の診断。これは旧O0/B0/T8の既知結果の分解であり、132の新しい金融実行ではない。

## 未作成workへ復元して実行する

リポジトリルートから実行する。保存ZIPのCRC/各源SHAと、共有gzip・純chooserの指紋を確認し、新規先の中だけへ展開する。

```powershell
python -X utf8 "study/00132_E0の構造回復を保護して他入口へT8を使う/再現資料/保存資料を復元する.py" --destination work/132再現
python -X utf8 "work/132再現/work/E0の構造回復を保護する切替案/方向同体を確認する.py"
```

実行コードSHAは`ef2329a93e46b901dabe9a75f4f61ec5ece4d8a1ebcc1b78a0059732682e6a0b`。E0保護、その他の型、R0、売買鏡像、不正型の拒否の人工8検査を行い、入力3源の固定SHAを実行前後で照合する。79取得/73場と元の出生・取得時計、T8から変更0、E0保護適用9を確認する。新しい損益は計算しない。

出力は展開先の`work/E0の構造回復を保護する切替案/方向の同体検査.json`一つだけ。新規先へ実行し、元の停止済みproofへ上書きしない。出力の解凍前JSONのSHAが上記の正式proofと一致することを確認できる。

旧T8の68.42%は[131](../../00131_中期MACDの位相で複合入口の方向を切り替える/README.md)の既報を参照する。方向が同じという検査から、未知期の成功や自然新入口の参加を主張しない。R0は反対方向という定義だけで、132で金融評価していない。逆の率を1−pで作らない。

保存時の照合は、入力3源・Root正本・コード・504セル不変・リンク・公式復元先での同体proof再現を確認する。金融前F1が存在しないことと、132の金融/CSVが未実行であることを確認票へ明記する。
