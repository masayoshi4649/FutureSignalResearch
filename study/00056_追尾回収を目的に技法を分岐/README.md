## 判断・執行と限界

固定49Oを変更せず、利益前も損失側を連続追尾する。現ATRの5pt切上げを5..125に制限したDを新規時固定。現在正常返済BBOの粗含み益−122円がstrict正なら利益旗・最低名目新規床・非緩和、返済pending中は保護を凍結する。micro1枚10円/pt、片道11円＋想定片道5pt。0/10ptは同約定への費用感応、起動122円不変。固定250TPなし、名目同値床は費用後同値の保証ではない。
