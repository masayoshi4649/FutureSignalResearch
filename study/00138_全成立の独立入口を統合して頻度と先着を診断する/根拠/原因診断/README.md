## 複数技法を重ねるだけで十分だったか

特徴は各originの出生時点までのCSV122公表を再生したもの。Raw公表を使った128/129の原生背景と同一ではない。新たな売買候補を作らず、取引別結果を読む前に固定した記述区分へ追加671を分けた。

- 5/15/30分のMA並び・EMA8増分・EMA21増分の9値が全同向：98件、45/33＝57.69%、差引＋16,762円。
- MA9値全同向＋ADX15≧20＋Hist5正＋RSI5中心≧0＋RVOL5≧0.5＋TR/前ATR5≦2：46件、23/19＝54.76%、差引＋458円。前48場62.50%に対し後25場44.44%だった。
- ADX背景の弱化＋5分実体順行＋Hist増分正＋RSI増分正＋RVOL5≧1＋TR/前ATR5≦2：38件、19/14＝57.58%、差引＋32,151円。前48場61.11%、後25場53.33%。凍結した価格構造Kの回復まで確認した群ではない。

RVOLの既知4帯も47.96～53.40%にとどまった。静的な背景整合や量を加えるだけでは70%を説明できず、押戻し・失速・構造回復の順序や取得位置を分ける必要が残る。「MAが同方向だから直ちに乗る」の十分性は確認できなかった。

Hist5増分未知は32.14%、BB15位置未知は32.08%で、実逆がそれぞれ60.71%・58.82%へ上がった。ただし未知は市場心理の反転シグナルではない。助走・carry・公表モデルの品質差を含むため、未知だけを根拠に逆売買する条件へ変換しない。どの技法の役割が既知だったかは、[原因診断.json](原因診断.json.gz)へ全区分を残した。

## 出生後の待機で背景が古くなったのか

752取得の出生→取得は中央値3秒、95%点22秒、最大105秒。FARの420 originでは、出生時に参照した5分足が取得前にfresh期限を跨いだものは6件だった。出生後の長い待機が追加群全体の弱さを説明する証拠は薄い。

これは「取得時点の最新背景が未知だった」という判定ではない。途中で新公表を受け取ったかはこの診断で再生していない。またSourceのdelayed_initialには出生前の待機があるため、出生→取得の数秒からその待機を評価できない。短時間の価格先行やスプレッドの影響も否定できない。全originの時計と参照足は[出生待機と参照時計.json](出生待機と参照時計.json.gz)に保存した。
