# 全成立の独立入口を統合して頻度と先着を診断する

試行00138。2026-11-12、金融・独立算術照合・CSV確認・保存観測の再現まで完了。**主P0は752取得/全73場min1、平均1.04312件/時を達成した一方、H60±125ptのH完了到達済み先着率52.33%で70%未達。C5利益4,217,125円/損失4,631,489円・既知差引−414,364円だった。**

## 仮説と事前固定

最初1補完の選別を外し、成立済みの複数技術familyの全取得を使ったとき、全場平均概ね1回/時と同幅先着70%を両立できるかを問う。旧137A0の81取得を固定C0として保持し、FAR初期系456、Raw即時v4 Q/R/S/Tの264、129新C系列42を素材にした。Source追加102通知・CSV127/Raw遅延の別公表モデル・129旧重複対照は足していない。

各familyはMA/ADXの方向と強弱、MACD/RSIの勢い、ATR/BBの値幅と位置、量、拒否/回復/放れの価格構造を役割別に組み合わせる。元FAR通知は元保有状態に依存し、M0へ今回の追加技術選別はない。方向のある押戻し・弱い域端回復・収縮放れを並べることは、局面を正しく切り替えた証明ではない。

phase除外72、同方向等の追加origin統合17、反対side競合の待機2originを経て752取得へ固定した。時計・向き・重複/除外理由・全originの出生を[条件](条件.md)とmanifestに残す。主P0は保存されたnative方向、対照C0は旧137A0、R0はP0と同じ取得原行の実BBO逆向き。新特徴で方向を上書きせず、結果で主を交換していない。[全504セル](設定と結果.md)は金融前のまま、結果だけを末尾へ追記した。

## 入口の診断と次の問い

今回の結果は、既存の全成立を同方向のまま集めれば、取得頻度は増えても70%の精度を保てるとは限らないことを示した。全反転も改善しない。次は当時の価格構造・方向/強弱・勢い・値幅・量を使い、familyと局面が合う入口、反転すべき入口、待つ入口を区別する問いへ進む。金融後の閾値学習や選別は次試行とし、138の752取得/方向を改変しない。

全出生の74列特徴はCSV122の公表を各origin出生へ重ねた診断overlayとして一度保存した。Raw即時で成立した元Q/R/S/Tや129の指標背景と同一ではない。複数originを単一の代表出生へ丸めず、未来公表・未知の0埋め・Entry/ラベルを特徴に渡していない。特徴値は今回P0の方向・取得・familyの選択に使っていない。[停止済みの原因短報](根拠/原因診断/README.md)では、追加671は286順279逆・50.62%/−614,358円。D164追加208は45.18%/−424,939円、短期C1追加31は29.63%/−169,387円で、その実逆も55.56%/＋2,613円に留まった。familyは重複origin群なので行の合計を全体にしない。MA9値全同向98件は57.69%、別役割も加えた順行複合46件は54.76%で、後半は44.44%へ下がった。出生→取得中央値3秒/p95 22秒・当初5分参照の期限跨ぎ6/420であり、待機だけが主因という支持も薄い。これらは事後診断で、138の方向を変更していない。

[特徴の非金融独立確認](根拠/特徴の独立確認/README.md)は769照会/74列、2,289足refs/fresh、850origin対応と、旧79の5,846特徴値・旧124の3,792生指標を照合した。Raw原生背景のknownへ外挿せず、未知を反転シグナルにしない。

ラージ板からmini独立1枚100円/ptへ射影、片道税込38.5円・往復77円。費用C5はBBOに追加して片道5ptずつ・往復1,000円。実IFD、利益追尾、mini実板、保有重複/片側10枚上限・資金制約を含む口座収支は未検証。取得後の固定H先着診断と戦略の実際の決済を分ける。価格更新時計は真の受信時刻ではない。全期既使用・多数仮説の探索内評価で、多重比較を補正した未知期の有効性ではない。追加2場は価格未読のまま残した。
