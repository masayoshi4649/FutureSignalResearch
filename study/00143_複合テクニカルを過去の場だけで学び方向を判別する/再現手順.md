## 計算環境

本実行はWindows11、Python3.14.3、CatBoost1.2.10、CPU/thread_count=1。固定ZIPの `work/複合テクニカルの逐次学習案/導入版.txt` が全導入packageの版、Sourceの `依存版.json` がPython/主要binary指紋、`計算環境の確認.json` が自然データを使わないCPU/GPU人工動作確認である。GPUの人工動作確認を行ったことと、143の主学習でCPUを使うことを区別する。

必要なら復元先のrequirementsを使い、新しい作業用venvを作る。以下の宛先は例であり、既存環境を上書きしない。

```powershell
python -m venv "work/143任意の計算環境"
& "work/143任意の計算環境/Scripts/python.exe" -m pip install "pip==25.3"
& "work/143任意の計算環境/Scripts/python.exe" -m pip install -r "work/143任意の入力復元先/work/複合テクニカルの逐次学習案/導入版.txt"
```

venv・DLL・pyd・wheelはGitへ保存していない。版を揃える手順と実行binaryの指紋を残す方式であり、将来の配布可用性や環境全体のbit同体を保証するものではない。モデルJSONにはGUID/時計を含み得るため、保存モデルの再推論と、再学習したモデルのSHA同体・数値同体は区別する。保存済み64モデルを正本として参照し、結果後に深さ・seed・閾値やモデルを交換していない。
