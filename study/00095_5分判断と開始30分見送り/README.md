## 一出生一枠とSource資格

B系は `slot=300*(floor(birthAt/300)+1)`。09:15:00原行での出生は09:20の機会となる。quiet・未知・未取得・closing・容量0・完結で採用できなくても、その出生は一枠で消費し、後の枠へ復活させない。SourceHold IDは元fillが届くまで作らない。

slot時に実在する取得済SourceHoldの残>0・予約0だけを許し、要求量は `min(出生mini量,Source現在取得残量,Actual片側余力)`。一部でも源close予約があればclosingとして失効する。元source_addをActualが初めて取得することは許し、元Kindと実初参加を別に残す。Source所有残量を現在出来高とは呼ばない。

同slotの出生は登録順（元Time/Index/Line/batch/Signal内順）で安定処理し、予約による余力変化を反映する。元のSourceSignal/数量を外から書き換えず、元受付自体を落とす方法は使わない。
