## 固定条件と限界

旧73・追加7・11/16Dayの3期間。全81は既使用。条件変更前にSource/閾値/人工検査/純出生を封印し、前48と全80の同じ損失優先順位を別計算。元基準も既使用全期由来なので前48選択を未見検証とは呼ばない。

複数技法による順行・反転・待機を比較。単純IFD、元幅/期限種、保有・未決予約合計1、開始待機なし、終了15分前までの返済。mini1枚、1pt=100円、片道38.5円と追加滑り5pt、往復1,077円。ラージBBOの即時約定代用でありminiの実約定ではない。未知を0損益にせず、枠も空けない。
