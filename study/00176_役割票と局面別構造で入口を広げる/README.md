## 仮説と技術の役割

175の全ANDが狭すぎたため、同じHT/HB/HR/HM/LC/RL六群を方向・動力・構造の役割票へ変更した。HT/HBでは5/15/30分EMA傾きとDI差の6票中2又は3票、かつ長期票1以上。他群は5分EMA傾き・DI差・gapの3票中1又は2票。動力は5分MACD増分・RSI増分の2票中1又は2票。構造は各枝の履歴イベント、実体回復、現在の価格進行という3パターン中1以上を求める。

ADX水準/傾き、長期の混在/反対方向、BB位置、相対量、スパイクと追いかけのATR制約は票の外の必須として保持した。HRはADX低下と元方向失速後の回復を使い、過熱だけで反転しない。必要列が一つでも未知なら役割全体をNaNとするため、未公表を0票に変えない。MA/MACD/RSIの票を独立した確率として掛け合わせない。

心理仮説は175の役割分担を継承するが、回復の兆候の全一致を待つと取得位置が遅れる可能性を考え、異なる価格回復パターンを代替とした。一方、代替によって小さな一時回復を反転完了と誤る可能性も結果で確かめる。
