# 175/176の固定再現

175/176は未採用の研究である。175追加7は未実行のまま、175旧固定二案と176旧73/追加7固定四案を同体再現する。全探索の再実行や独立未見性能の確認とは区別する。

Sourceと小正本は、この試行の[Source.zip](再現資料/Source.zip)、[出生と比較正本.zip](再現資料/出生と比較正本.zip)、[保存索引.json](再現資料/保存索引.json)を175と共有する。175側の参照票も同じ保存先を指す。

## 必要な共有入力と環境

- `inputs/00148_全1分入口母集団/`：正式な当時特徴・固定取得・取得対応。固定151/161 Sourceで射影する。
- `inputs/00163_任意幅の共用価格索引/数値表/`：旧73の共用金融配列。
- `inputs/00167_追加七場の入口と共用価格索引/`：追加7の純特徴・取得対応・共用金融配列。
- 共有 `study/` の固定条件・共用入力指紋。読み取り専用で参照する。
- Python 3.14.3、NumPy 2.5.4、tzdata 2026.6。tzdataは米国夏冬時間の再構成に使う。

原板と作業feature cacheは使わない。大容量共有入力をSource/小正本ZIPへ複製しない。各ファイル・各memberの指紋は保存索引に記録する。

## ZIP復元後の実行

Source.zipをリポジトリ相当の空ディレクトリへrepo相対パスのまま復元する。小正本の `work/` memberも同じ相対パスへ復元し、共有 `inputs/` と `study/` を参照可能にする。ZIPの内容を現行workの同名Sourceへ差し替えない。

```powershell
python 'work/176正式保存/正式入力で再現する.py' --archive 'study/00176_役割票と局面別構造で入口を広げる/再現資料/出生と比較正本.zip' --output 'work/正式runner確認'
```

出力先は新規フォルダにする。元byteの純出生と合成配列、全取得・予約保有engine・台帳・金融・完全経路を照合し、176全80は再生成した対象場/時間と実台帳から再計算する。金融未知None・0取引場・主案nullを保持する。

## 監査付きの隔離実行

復元したSourceを含む通常repoで、以下を実行すると、新しい隔離repoへSource/小入力をZIPから復元する。必要なNumPy/tzdataを新規venvへ用意し、共有入力への書込、元work・原板・feature cacheの読込を監査で拒否する。

```powershell
python 'work/176正式保存/隔離を準備する.py' --bundle 'study/00176_役割票と局面別構造で入口を広げる/再現資料'
```

`work/176隔離再現/` が既存なら新規実行を止める。成功票は `repo/work/正式runner確認/再現確認.json`、監査票は `repo/work/監査結果.json`。保存前の隔離確認では、175旧2＋176旧追加各4の計10候補期間が一致し、禁止参照0だった。正式ZIP内にもこの確認票を収録する。

Source/小正本の正式保存自体はRoot最終GO後に `work/176正式保存/保存175_176.py --execute --go` で行う。175側へ同じZIPをもう一組作らない。
