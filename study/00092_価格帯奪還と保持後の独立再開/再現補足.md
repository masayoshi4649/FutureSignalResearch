# 再現補足

本書は92の保存生成と後段診断の再現を扱う。条件・入力参照・全66場の実行と、会計/保存/原板/Source/Viewerの各完了証拠を先に揃える。既存Viewerの8092を使い、起動・停止・再起動・設定変更を行わない。

`記録反映.py` は次の12ファイルを必須入力とする。売買・原板・Viewer APIの再実行は行わない。図は全66場・ゼロ起点・赤字表示・検査scope脚注と入力結果SHAを含む。

```powershell
$trialPath = (Resolve-Path 'study/00092_価格帯奪還と保持後の独立再開').Path
$reportPath = 'scripts/FAR価格帯奪還と保持後再開/記録反映.py'
$reportArguments = @(
    '--result', "$trialPath/成果物/結果.json",
    '--cash', "$trialPath/成果物/約定会計照合.json",
    '--raw', "$trialPath/原板監査.json",
    '--source', "$trialPath/Source通知監査.json",
    '--saved', "$trialPath/基準と保存判断の照合.json",
    '--viewer', "$trialPath/Viewer監査.json",
    '--condition', "$trialPath/条件.json",
    '--input-ref', "$trialPath/入力参照.json",
    '--plan', "$trialPath/検証計画.md",
    '--settings-before', "$trialPath/設定と結果.md",
    '--figure', "$trialPath/損益比較.svg",
    '--availability', "$trialPath/可用性前検査.json"
)
& 'work/venvs/technical-tree/Scripts/python.exe' -B -X utf8 $reportPath @reportArguments --run
if ($LASTEXITCODE -ne 0) { throw '帳票生成が未完了です' }
& 'work/venvs/technical-tree/Scripts/python.exe' -B -X utf8 $reportPath @reportArguments --check
if ($LASTEXITCODE -ne 0) { throw '生成物が一致しません' }
```

`--settings-before` は初回の事前表でも、生成後の正式`設定と結果.md`でもよい。結果マーカー内を未実行文へ復元すると同じ事前SHA `bb02c16b685161896674a16b5a751b7ea3cf2695b4787727b9d24fad0c7199fc` になることを検査する。44設定・55×9の閾値と事前本文は不変。事前表を正式へ二重保存する必要はない。

生成時はタイトル直後へ「事前設定内の未実行は作成時点、現在結果は末尾」と固定注記を1件追加する。再照合ではその決まった位置の注記だけを除去してから事前SHAへ復元する。注記の重複・移動や、閾値/事前本文の変更は認めない。

生成証拠の`settings_before`入力指紋は、この復元済み事前本文のSHAである。出力欄には結果を含む正式設定のbyte SHAを記録する。残り11入力はbyte指紋を前後確認するため、初回生成と最終ファイルからの再生成で同じ証拠を得られる。

出力はREADME・設定結果マーカー内・生成証拠だけ。結果JSON全件、全玉診断、原板をREADMEへ転記しない。H0は旧E1、H1は現在E0＋独立価格triggerで、複合成績を個々の指標の効果とはしない。人工の部分scope、元数値器・前史・Source生成に依存する範囲と、正式全場検査を区別する。

小型診断は[入口と回収の診断.py](../../scripts/FAR価格帯奪還と保持後再開/入口と回収の診断.py)で再生成できる。`--result`へ`成果物/結果.json`、`--trades`へ`成果物/取引診断.jsonl.gz`、`--grids`へ`成果物/定時判断.jsonl.gz`の3正本を渡し、`--out-json`と`--out-md`には新規の保存先を指定する。すべて必須。市場再生・原板・APIを使わず、公開時点の根拠と取得後の実績を別に出す。入力パスもJSONへ記録するため、異なる入力パスでの再生成は経済値が同じでもbyte指紋は異なる。
