2026-11-14。同じ出生・取得・幅・期限・金融を使い、最初の既知IFD到達で先着を確定するIFD_FIRSTへ分けた。NORMAL/REVERSEの840,960政策から報告支持186を得た。頻度順先頭は **EX0076 / ALL / REVERSE / ±400 / H60 / U：534取得、95順40逆、70.37%、既知利益5,650,364円・損失3,774,710円**。前後既知差引はともに黒字だが、0.741回/時で希望0.8へ届かず、新採用せず次の入口仮説へ継続する。

## 仮説と条件

後で観測が切れた取引でも、打切り前に既にIFD利確/損切りへ届いていればその時点の先着を数える。逆行過多条件については同じq0出生の向きを定数−1で反転し、実反対側BBOで再評価すれば有意な候補を分けられると仮説を立てた。利確側先着率を1−pで反転しない。

[条件.json](条件.json)のSHA256は `e415f92ee290b8adad74e378255432e384114d67abe16082505af06a10b65f5d`。163の12幅・4期限・1,460規則の固定出生を継承し、向き2通りを追加した。ATR適応480政策は164で再探索していない。[設定と結果](設定と結果.md)に全V8表と支持閾値を記した。

IFD_FIRSTは、実touchありかつ金融knownなら期限未完了でもF/A、touchなし期限完了ならN、それ以外C。F/Aの成熟はtouch原行時計、Nは期限又は場境界のknown_at。全NORMALについて163と分類関連7指標以外の金融・取得指標が同体であることを全数assertした。旧STRICT_H値は書き換えない。反転するのは新規出生のみで、U/Fの旧参照は元側に保持する。

## 入力・取得・費用

旧全73場、31,642物理case両実側、35,339判断q0を維持し、正式148の100特徴を用いた。5/15/30分の背景・勢いと、BB/ATR・実体ヒゲ・相対観測量・短期価格端を組み合わせる。初版10群972と履歴6群488、合計1,460規則。買売は実側で符号を正規化した同条件。入口の向きを探す関数へ教師・q1・金融は渡さない。デイ/夜間NY09:30前/以後は夏冬時刻でq0を区分し、今回の固定規則は共通条件、各帯の強制参加はしない。

ALLと状態遷移だけのEDGEを分け、同物理q1は最初の成立q0で一意化する。Nは純新規、Uは旧87全取得の保持統合、Fは各場の旧初回出生時まで実取得0ならその旧信号を因果的に予約する補完。U/Fで全73場参加でも純新規が全場参加したとは呼ばない。

各取得を独立mini1枚として、同幅の利確・損切りIFDを比較。取得はBUY Ask/SELL Bid、清算はBUY Bid/SELL Ask。利益・損失は費用後正負の別集計、PF=利益/損失。100円/pt、税込片道38.5円（往復77円）、追加往復滑り1,000円（合計10pt相当）を控除する。実BBOのスプレッドも含む。未到達は完了期限BBOで清算、観測不足でも打切り前touchが確定していれば金融既知、それ以外は未知であり0円実績にしない。既知差引は未知を解決した全損益ではない。

F=順側先着、A=逆側先着、N=両側未到達で期限完了、C=分類観測不足。到達済み先着率F/(F+A)と、全取得に対するF比率、費用後の実現勝率は別物。頻度の分母は全73場の対象ザラバ時間であり、候補成立時間だけではない。利益・損失は重複しうる独立入口の合算で、片側上限10枚を守る実口座収支ではない。
