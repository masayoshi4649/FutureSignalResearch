一方、直接形成のA25（21）の反対側は費用前+11,250円でも費用後−16,179.2円。旧形成8/9も反対側は赤字。逆行が多い入口を逆にすれば常に優位になるとは言えない。旧30分方向が残る群と、元方向へ実際に回復し始めた群を別の新仮説で比較する。

長期支持が残る45件だけの反対側収支は+23,821.6円、価格が旧側30EMA21にある40件では+45,739.6円。これらは同じデータの事後分解であり、群の最良値だけを採用しない。新15分DI/傾きが反転側へ整合していた11件も、元の反転入口は全て赤字だった。指標の同時一致を増やせば解決するという説明は支持されない。
