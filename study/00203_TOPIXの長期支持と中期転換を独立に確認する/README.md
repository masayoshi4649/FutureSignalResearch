## 失速と転換の違い

[原因診断](原因診断.json)では、転換47取得の45件で旧30分EMA方向が残り、40件で価格が旧側30EMA21を保持、44件で15分EMA並びが旧側だった。MACD増分の反転は長期の勢いの弱まりを示しても、新方向の持続を証明しない。新15DI/傾きが新側の11件も全て既知赤字なので、そこへANDを追加すれば解決するという根拠もない。

直接順行は448源→210保持確認→79純発火、直接転換は356源→84中期確認→54純発火。量2/3継続も改善しなかった。要求成立と保有枠内の取得は別に集計する。次は逆行の多い転換を同時点の反対BBOで診断し、旧長期支持が残る押戻しと新方向成立の区別を新仮説へする。反対確率を1−pから推定しない。
