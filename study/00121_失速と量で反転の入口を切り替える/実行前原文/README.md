# 00121：失速と量で反転の入口を切り替える

2026-11-10。120のP2固定結果を診断して立てた新仮説。現在は実行前の条件で、市場結果は未算出。既使用70場に対する探索であり、未見データへ事前登録した仮説とは呼ばない。主評価は取得後60分・同幅±100ptの順行先着70%以上を目指すが、少数の高率を完成・採用とは判定しない。

## 診断から検証へ移す問い

120の突破失敗反転P2は22出生・17約定・60分±100ptで10順/7逆。一方、出生時のADX30が前公表より低下した7完了例は6順/1逆、RVOL5≥1の6完了例は5順/1逆だった。この違いを当時に判定可能な失速・量の候補として次試行へ移す。

ただし期間の偏りがある。ADX低下は元54場で6順/0逆、追加16場で0順/1逆。RVOL≥1は元54場で3順/0逆、追加16場で2順/1逆。両方を満たした2例は2順/0逆に縮み、120P2plusの2例と重なる。**7例の85.7%、6例の83.3%、2例の100%を将来の再現性や完成手法の証明にしない。** 未約定も条件別に保持し、約定後だけ都合よく分類し直さない。[事前診断の要約と正本](根拠/P2の事前診断/README.md)を参照する。

仮説は、反転候補で長期MAの同方向を必須にするのでなく、元方向の強さが低下したか、量が伴うかを分けること。極端なBB/RSI領域へ限定した旧P2と、もう少し広い逆側の領域も別母集団で比べる。既定の増分0・相対量1等を分解した後付け仮説であり、幅広い閾値探索で勝った境界を採用したわけではないが、結果を見て生んだ仮説という限界は残る。

## 六つの政策

|政策|領域・構造|出生時に追加する条件|基礎cohort|
|---|---|---|---|
|C0|120P2を固定対照として再現|旧P2のADX30≤25又は低下、15分逆側BB外/RSI過熱、1分失敗突破・回復|C0自身|
|E0|C0と同じ|ADX30・前値がともに既知で、当ADX<前ADX|同じC0出生|
|V0|C0と同じ|RVOL5が既知で≥1|同じC0出生|
|EV|C0と同じ|E0の失速とV0の量の両方|同じC0出生|
|B0|広い逆側のBB/RSI帯と失敗突破回復|ADX30低下、RVOL5≥1、5分Hist/RSIの側増分がともに>0|同じB1出生|
|B1|B0と同じ広い領域・構造|ADX30低下、RVOL5≥1。B0の5分勢い追加だけを外す|B1自身|

広い帯は買いが当1分Low≤BB15中心かつRSI15≤50、売りがHigh≥BB15中心かつRSI15≥50。B0/B1はADXの絶対水準を制限せず、既知の前公表からの低下を要求する。上位MA向きは六政策とも新しい選別条件にしない。複数技法の役割は、ADXが背景の強さ変化、BB/RSIが位置、1分構造が回復、ATRが値幅・距離、量が参加の大きさ、B0のHist/RSIが勢いの変化である。ADX低下だけで反転方向を決めない。

政策IDのC0と、手数料だけを控除する費用条件C0は別の名称である。結果では「政策C0」「費用C0/C5」を明記する。

## 母集団と判断時計を揃える

C0条件とC0用300秒cooldownを通過した原行で基礎出生を一度作り、その同原行の当時情報でE0/V0/EVを派生させる。三派生に独立cooldownを持たせない。B1条件とB1用cooldownから別の基礎出生を作り、同原行で勢い改善も真ならB0を派生させる。cooldownはC0/B1×売買側だけで、Session開始時にresetする。

Eventの文字列`cohort_id`はC0とその派生、B1とその派生で共通とする。出生・要求・取得時計の対応を保ち、取得成功や将来損益を見た後で派生を作らない。派生がない場合も基礎出生の当時の既知/未知/否定条件を残す。取得前cap等で取消された基礎候補の派生も同じ母集団として保持する。異なる領域を持つC0群とB1群を、同母集団の単独効果として無条件に差し引かない。

再生後は政策C0と120P2の22出生・17約定が一致することを確認する。件数だけでなく、対応する出生時刻・方向・1分構造・要求/取得/拒否・観測結果も、政策IDや新しい診断項目を分けて照合する。対照が再現できなければ、新仮説の優位を評価する前に不整合を解消する。

## 120から固定して再用する構造・執行

買いでは当1分安値が直前5本1分の最安値をstrictに割り、当1分終値がその境界+5pt以上かつ旧5本レンジ内へ戻る。売りは高安・上下の鏡像。全政策で実体が新規方向、終値位置≥0.7、当TR≤2×直前14本の既知TR単純平均を要求する。ATR1へ当足を混ぜない。

1分は採用Rawの価格時計からUTC60秒床で因果形成し、次分の最初のRawで前足を閉じる。閉鎖Endから30秒超は信号を出さず、空足やRaw時計差60秒超では1分形成・履歴を作り直す。5/15/30分は当原行までに配送された当場freshな確定公表を使い、同限月の数値窓だけを継承する。未知を支持や0へ置換しない。

無効化価格は当1分の逆側極値の外5pt。出生Lastと実取得からの正距離が`min(100pt, 0.5×ATR5)`以内、取得capは当1分終値から順側`min(10pt, 0.15×ATR5)`。出生時と取得評価時のLastが、買いなら前5本Low+5pt以上、売りならHigh−5pt以下を維持する。後続Rawかつ1秒以上後、30秒未満の最初の正常BBOでcap→hold→riskを検査し、不適なら即取消して後の有利化を待たない。

新規はSource.force_close未満、取得済みの評価はSession.Endまで。元Source通知・旧決済・固定5分新規時計や開始静観は候補出生へ使わない。1分構造が成立しない時は待機であり、毎分の強制注文ではない。

## 評価と再現性の限界

独立mini1枚・100円/pt。主は60分±100pt、副は30/60分×±25/50/100/125/200ptを全保存する。順/(順+逆)と順/全観測完了を併記し、出生・派生条件・要求・約定・未到達・観測不足を分ける。同cohortの基礎と派生が双方完了した組、各政策の全完了群、買売、元54/追加16、全70場を別集計する。

費用は往復税込手数料77円、追加往復10pt分1,000円のC5ストレス。Raw又は正常BBO差300秒超、場末、期限後30秒以内の正常気配不足は観測打切り。期限に達した最初の正常原行で終わり、同秒後続原行は混ぜない。未約定・不足を0円にせず、未参加や決済後の仮想利益を取り逃しとして採点しない。

既使用70場（2026-09-21 Day〜11-06 Night）の探索で、11/09価格・損益・入力指紋は未読。ラージBBOによるminiの約定代理で、miniキューや実受信遅延は未証明。重複候補を片側10枚の口座収支へ合計せず、IFD実決済・利益追尾・可変数量・実約定返送を含む安定利益は別検証とする。固定期限診断は実運用の必須利益保護を省く提案ではない。

## 市場心理の仮説

反転の向きは失敗突破と回復から定める。ADX低下は元の動きの強さが鈍るかを見る背景であり、買い/売りの優位を直接表さない。平均より大きい量は、その回復に参加が増えた可能性を見るが、売買のどちらが攻撃的かはRVOLだけでは分からない。B0は勢いの回復も要求し、B1との同cohort比較で追加の絞込みを評価する。

一般的な支持抵抗・突破失敗の説明と、注文が集中する心理の着想は[120の外部一次調査](../00120_1分構造と無効化距離で入口を作る/根拠/外部一次調査/小構造と無効化距離から入口を作る.md)を参照する。これは参加者の注文目的を実測した事実や、NK225の70%を証明する根拠ではない。資料の一般論・心理仮説・120診断で確認した記述・未実行121の成績を区別する。
