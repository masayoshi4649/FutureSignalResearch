実fill→現在Source返済通知→旧テクニカル/G1の順で連続保護する。未約定新規は通知比率で取消し、実未予約量にはQuantity/Beforeを掛けて整数切捨て。0丸め/実所有なしも記録し、末尾全通知は残全量を要求する。timerはLastやfillを進めず、要求時計を古い気配時刻へ巻き戻さない。受理済返済を取消/延期しない。
