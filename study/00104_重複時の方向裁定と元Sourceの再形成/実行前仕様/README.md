# 00104：重複時の方向裁定と元Sourceの再形成

2026-11-09採番。市場実行前の仮説。新しいSource・損益・参加率は未検証。[103](../00103_元の多玉と数量を保つ一定利益後の追尾/README.md)の黒字を新条件の成績として転記しない。

## 仮説と単一変更

元三手法D164_15/P164_06/U165_03には、EMA・ATR・価格帯・短秒進行・二市場と板数量の支持・初回/追加/親の履歴がある。これを維持し、共有D07の範囲逆張り方向式で買い・売り両方が成立したときだけ待機にする。狭い帯の両端条件が同時成立しても、買いを先に評価したという理由で方向を選ばない。

`efficiency <= 0.3` の領域で、買い候補Lは `mid <= low + 0.1*risk`、売り候補Hは `mid >= high - 0.1*risk`。従来はLなら買い、そうでなければHなら売り。新式はLとHが等しければ0（両方真/両方偽）、Lだけ真なら+1、Hだけ真なら−1。方向効率・境界係数・risk尺度・準備/解除/返済等の他式は変えない。

両側に同じ価格条件が成立する領域は、方向を選ぶ情報が不足しているという解釈を置く。これは設計上の仮説であり、実参加者の心理を観測した証明ではない。上位トレンドや勢いで重複時に方向を選ぶ案は別仮説とし、今回へ追加しない。任意の価格反射でbp率等まで完全鏡像になるという主張とも区別する。

## 段階A：自然Sourceを再形成する

既使用2026-09-21〜10-27の54セッション、固定80の二市場原板と確定1/5分足6入力を共用参照する。旧Scalarから欠けた特徴を補わず、元93の入力検査→実Features→完全Observation→実Sourceを通す。原板を正式試行へ複製しない。

1. legacy：元93生成口をそのまま使用。
2. default：新しい全式override生成口へ既定の完全mapを渡す。旧93との生成口の同値確認。
3. symmetric：完全mapの `addon.entry.range_side` 一式だけを上記へ変更。

legacy/defaultは固定旧93の場別JSONを全構造で比較する。全Ledger/数量/費用/予約/配列nil空/品質/SourceRowsを落とさず、除外0を条件とする。先頭2場で自然な新規・Fillの非0を確認し、同じ条件・コード・実行物で全54場へ進む。差が出たら新成績を採用へ進めず、差の発生点を確認する。元資料は書き換えない。

miniとmicroの両方を元の商品条件のまま動かすが、microは元規格の照合対照であり、ユーザーの新しい運用候補はmini。Aのminiは元MiniConfigの片道5pt仮定費用を含む連続Source会計である。Aの粗額/純額を、Bの5分判断・LD10適用後の成績と混ぜない。

各Step/Forceの公開Deltaを空通知も含め逐次保存し、Targets/Closes.Before/所有ID/配賦を失わない。完全Observationそのものを全件複製せず、fresh Scalar11と全ObservationのSHAを記録する。同時計TOPIX/NK、公開足、Force、P終了後U開始の元の順を維持する。価格時計と受信時計は区別する。

## 段階B：同じ一定利益後保護へ接続する

Aの結果を見て閾値を選び直さず、legacyとsymmetric各々へ103と同じB5Q＋LD10を適用する。defaultは生成口同値の照合用で、同値成立後の金融結果を重複採用しない。Source変更の全体効果には新規・数量・返済の自然な変化も含む。同実入口の退出差と片側だけに成立した実取引は別記する。

新しいTapeは、Aで再生成したminiの全Deltaを、元TapeのQuote Scalar11全値・FeaturesIndex・物理行・active method順へ厳密に結ぶ。Forceは元の時計と各method直前SourceLine、gridは既存の全board由来の列を維持する。時刻Atだけで結合しない。元Sourceを形成しない旧Scalarを完全Observationと偽らない。legacy/defaultは変換後Tapeと旧Tapeの通知・順序、103金融の全時点/最終会計の同値を確認してから新Sourceの経済効果を判定する。

結合器・B金融実行物は別途コード/入力を実行前に固定する。現在は未完成・未実行であり、A成功をB成功としない。結合不能・通知欠落・別位相なら補完せず停止し、保存データで原因を調べる。
