### 独自SAR数値規約

AF初期0.02・増分0.02・上限0.2。連続二本close差strict正/負で方向をseedし、同値なら未確定で次の隣接対を待つ。seed表示は買min(前low,現low)/売max(前high,現high)、EPは現high/low、AF初期。これはTA-Lib等と同一の初期値/等号規約だとはしない。

当足の事前線は前足next。買low<事前線/売high>事前線のstrict貫通で先に反転し、等号は非反転。非反転の表示線だけ前二本low以下/high以上へclampし、当足EPをstrict更新した時だけAFを増やす。反転表示は新買min(旧EP,現low)/新売max(旧EP,現high)、EP現・AF初期。次線は表示+AF×(EP−表示)で、next自体はclampしない。

事前線・足確定後表示・次足線/EP/AFと出典を別保存する。当足高安の確定後方向を当足開始時から使わない。欠枠/不正/尾部完全欠枠/限月変更でreset、同限月場間carry。末尾完全幅未公開足NPも内部数値は更新/carryするが公開現前pairへ不使用。OHLC非有限の原入力は不正clear/非投入で、保存出典の非有限だけNone正規化し時計/keyを補正しない。原OHLCの別手順と全足canonical SHAを照合する。

## 限界と次の問い

全65場（学習40/条件選択24/既使用11/4デイ1）は全て既使用の追加開発。SARの二本持続は独自仮説で、Fidelity/TradingViewの一般解説がNK225の125/250先着70%や利益を実証したものではない。出典URL・確認日2026-11-05は計画と共通議論へ残す。SARは極値と経過で動き、時間だけで線が近づくため、売買圧力の急増を直接測ったとはしない。心理は『単発の反応より元から続く方向へ参加が続くか』という仮説で注文動機の観測ではない。

MACDとSARを総当たりの票へ加算せず、同じ価格event・同じM25で勢いと持続の役割を対照した。数値準備除外、役割構成比、役割内成績、純発動と実参加を区別する。SARのseed/strict貫通/clamp順は固定した独自仕様で最適化した標準値ではない。RSI・移動平均線の例へ限定せず、次候補も手法一覧から役割を考えるが未実行を実績へ加えない。

仮先着は実返済後の経路も含み、実保有中MFEは事後の峰で全額回収可能とはしない。同episodeのR/Tや二案共通の成功を独立二票へ数えない。最大場内DDは期間累積DDと別。終値の価格余地は当時診断で、実約定/費用余裕や先着予測力を示していない。未来ラベルを当時条件へ戻さず、主条件変更は新試行へ分ける。固定後の未使用場による別確認まで将来の安定収益達成とはしない。
