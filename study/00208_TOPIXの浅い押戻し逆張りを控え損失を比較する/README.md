## 仮説と入力

[205](../00205_TOPIXの長期支持と破断失敗を旧入口へ比較する/README.md)は独立新枝を加えて参加を増やせたが損失を増した。今回は既存の要求を基本的に残し、当時の技術的な役割と旧実方向が矛盾する部分だけを控える/切り替える。[外部研究と独自仮説](../../docs/technical-analysis/市場心理/日中の順行と反転を時間順序と需要で分ける.md)が述べる需要の継続、失速と転換の違いを参照するが、今回のRSI/BB等の閾値を外部研究が実証したわけではない。

当初81場（2026-09-21Day〜11-16Day）で9条件を固定。全80発見と前48選択/後25/追加7を分けるが全て既使用。その後、同じ9条件を11-16Night/11-17Dayへ再選択せず適用した。追加2も既使用対照である。[条件](条件.json)・[設定と結果](設定と結果.md)。

Aは長中期支持下で過熱していない浅い押戻しを、旧判断が反対側へ売買しようとする場面。旧維持/見送り/源方向へ切替。Bは過熱＋MACD失速＋量がある場面の旧順行要求。旧維持/見送り/固定3足端の反対側破断と後足保持を待つ、の3行動。A/Bは旧実方向との関係で排他、3×3=9。価格構造前のB即時反転は候補にしない。

miniTOPIX1枚、1pt=1,000円、片道41.8円+0.25pt。旧DayA25/NightW15/H60、単純IFD、ラージBBO代用、遅延1秒/取得TTL30秒、保有予約合計1。開始待機なし、15:30/05:45までに決済。金融未知は0円や既知利益に置換せず、場末まで枠を保持する。

## 改善した項目と変わらない項目

旧81の主3は損失額・DD・最悪場（−19,752.4→−19,001.6円）・最悪5場の既知寄与（−27,172→−14,926円）を改善した。一方、既知赤字取引数は76→75でも分母が172→168へ減るため赤字率下限は44.19→44.64%へわずかに上がる。赤字場10/40、取引連敗6、場連敗2〜3、初期損失−11,088.4円は変わらない。未知7があるため、経路は既知寄与と完全確定部分を分ける。

[原因診断](原因診断.json)では、A純要求157件/27場に対し、基準の実取得でAに該当したのは5件/5場のみ。全て±15pt未到達Nで、利益9,249.2/損失14,167.2/収支−4,918円だった。これを源方向へ反転した6の同5件も−5,918円なので、見送ることと反対売買の優位は同義ではない。

主3の実取得差は、基準だけ6件−20,501.6円と比較口座だけ2件−12,667.2円。Aで取り除いた5件のほか、後続の通常旧入口が1件変わった。口座の+7,834.4円改善をA五件の単独効果とは呼ばない。個票は当時の指標・q0・源方向・実方向とともに原因正本へ保存した。

Bは純要求37件/14場→固定源21→構造発火14だが、基準の実取得では1件だけ。2026-11-06 03:11の通常旧順行は+5,416.4円、構造確認で03:12へ遅らせ反対売買した2では−15,083.6円。Bの一般的な有効/無効を1件から断定しない。未知と未成立、保有/予約棄却、即時要求優先で使わなかった確認を分けている。
