# 20分待機と30分待機で建玉が入れ替わった2日

SessionTradeViewerで[一覧.resources.json](一覧.resources.json)を開く。同じ日付の「開始20分待機」と「開始30分待機」にその日すべての新規と返済を収録した。固定IFDを使用し、保有時間に個別上限はない。価格の単位はpt、時刻は日本時間。日経225mini 1枚換算、往復1,077円控除後。

**11月16日。** 20分口座では09:11:02に61,060で買い、09:39:07に60,710で損切した（−36,077円）。30分口座では09:11は待機中。取引がまだなかったので初参加用補完入口が利用可能で、09:31:01に60,900で売り、09:39:19に60,700で利確した（＋18,923円）。その後09:58と11:51の売りは両口座で同じ建玉だった。日次差の55,000円は最初の1件の入れ替わりで説明できる。

**11月17日。** 20分口座の09:06と09:08の売りの合計は−2,154円。両方とも返済済みだったが、取得済みのため09:38に初参加用の補完売りは出ない。09:41:01に主入口で59,180を売り、13:05:07に58,830で利確した（＋33,923円）。30分口座は09:38:02に補完で59,070を売り、09:41:21に59,270で損切した（−21,077円）。09:41:00の主入口の時点ではまだ保有中。10:14・11:31・12:42には順に＋33,923円、−36,077円、−36,077円となった。13:26の最後の売りは両口座共通。開始10分の違いが初参加用補完の資格、さらに午後までの1枚枠の使われ方に影響した。09:05〜09:15に取得した2件の合計損益は−2,154円にとどまる。
