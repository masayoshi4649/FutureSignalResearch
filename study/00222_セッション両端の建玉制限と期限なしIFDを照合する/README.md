## 何を修正して検証したか

以前の「元のIFD」は過去の検証用の出口で、元181件のうち157件に60分期限が設定されていた。今回は研究側の時間切れを外す。先着率を調べる観測時間や、ユーザー指定の「セッション内で完結する」条件は、それぞれ役割が違う。[過去の60分設定の由来](../../docs/議論/セッションのノーポジションと建玉保有時間を区別する.md)

- **新規可能時間**　08:45から20分待機なら09:05、30分待機なら09:15に新規を解禁。待機中の板は指標の計算に使い、その間に出た要求は予約ごと除外する。全要求から時系列で買売共用1枠を再生し、初参加補完の可否も判定し直した。既存の199_02入口・入口で決まる幅をそのまま使用。入口の再選択は行っていない。
- **手仕舞い**　片幅R（150・200・350・400pt）の利確と損切を維持する。残る建玉は15:29に場末返済を要求し、15:29:01から15:30までの最初の正常気配で決済する。15:29以降は新規・新規取得も停止。この45日で最も遅い返済は15:29:22。単純IFDの主2案では各133建玉のうち各63件を60分超保有し、最長はいずれも6時間14分1秒だった。
- **対象と費用**　2026-09-21〜11-20の日経225ラージの過去板を使用。日経225mini換算1枚、1pt＝100円。買い新規はAsk、売り新規はBid、返済はその反対側の気配。片道税込手数料38.5円と追加滑りの仮定5ptを合わせ往復1,077円控除。15分は短い参考条件、0分は試行221のD04・T02との照合用。指値の注文順位とmini実板での約定は未検証。日中立会のザラバは15:40まで、15:40からプレ・クロージング、15:45に板寄せ。2026-11-22確認。[JPX・立会時間](https://www.jpx.co.jp/derivatives/rules/trading-hours/)・[商品仕様](https://www.jpx.co.jp/derivatives/products/domestic/225mini/01.html)

### 開始10分の違いが後続取引に及んだ日

単純IFDの各133建玉のうち126件は両口座で同じ取引・同額だった。日次収支は40日で同額、5日で差が付いた。11月17日は20分待機が＋36,692円、30分待機が−54,385円で、1日の差が91,077円。この日を外すと30分待機の収支が40,077円多い。

- **11月16日は30分待機が55,000円有利。** 20分口座では09:11の買いが−36,077円。30分口座は朝の最初の取引が変わり、09:31の補完売りを＋18,923円で決済した。
- **11月17日は20分待機が91,077円有利。** 20分口座は09:41の主シグナルで売り建て、13:05に＋33,923円で決済。30分口座は09:38に建てた補完の売りを09:41:21まで保有していたため、その主シグナルでは建てられなかった。その後の取引も入れ替わった。朝の取引だけを古いCSVから削除すると、この違いを再現できない。[両日の取引をViewerで比較](Viewer/README.md)

### 追尾は損失を減らしたか

追尾付きは建玉時間を計らず、0.95R順行した時点か、場末返済要求まで残り10分で現在0.45R以上順行した時点で保護する。床は建値より利益側20ptと最大順行から0.80R戻した水準の有利な方。終盤に確定足の勢いが失速・収縮した場合は0.35R戻しまで縮める。元の利確・損切と同時に効いた場合は静的注文を優先し、動的返済は発動から最短1秒後の正常気配を使う。[詳細設定](設定と結果.md)

20分・30分のどちらでも、追尾を足すと**総利益33,769円増、総損失14,000円増、収支19,769円増**だった。日末最大下落は同じ。含み益を一度でも経験し最終赤字となった建玉の損失は、20分で907,772→921,772円、30分で986,003→1,000,003円に増えた。20分口座の収支増の内訳は共通133建玉で＋6,000円、追加3建玉で＋13,769円。追尾による改善額の最大日10月26日（＋25,846円）を外すと両待機で追尾側が6,077円下回った。今回の結果からは、損失軽減のためにこの追尾へ切り替える理由は弱い。
