# 112の実保有区間OHLCと損失診断

確認日: 2026-11-10。[調査と代表例](調査.md)、[CSV三点と列定義](../../../../outputs/01a1889f-f2af-7943-a047-543275ee9ed2/112保有区間OHLC/README.md)、[共通知見](../../../../docs/議論/保有区間OHLCで分けた利益後赤字の原因.md)。

固定112の全24条件×70場の成立取引を調べた。延べ13,332玉と14,908返済片について、実取得から返済までのLast/Bid/AskのOHLC・到達日時、実残枚数と実現損益による費用後評価を集計した。同じ入口を複数政策・費用で比較しており、延べ件数を独立サンプル数とはしない。113新金融の実行完了・採用・安定収益の立証ではない。

## 検査した範囲

- 全70場の原板11,431,748物理行を各一走査。価格区間1,952・実R/n一定状態片3,887・保存点原行witness7,521。新規/返済境界・保存原行はすべて一致した。
- 異常時計52,192行、場外773行を除外。採用11,378,783行のうち異常BBO19,172行はLastと区別した。これらは入力全体の品質数で、建玉の区間内件数とは別。
- 全84,720価格系列のOHLC境界、14,908返済片の費用とW保存、13,332親建玉の配賦、既存台帳39,996値を別処理で照合した。[全件表の検算](検査/追加/全件表の独立検算.json)。
- 事前指定した11/06デイ・ナイトを別Python実装・有理数算術で一走査ずつ照合。142価格区間、279状態片、1,080玉、新規/返済quote2,240件、保存marks11,508点が一致。[二場独立監査](検査/追加/二場独立監査.json)。phase・数量・R・u・Wを確認し、予約数は今回の独立原板監査の対象外。
- CSVの全6,175,316セルを別処理系で再読し、日時・数値・空欄・型と統合集計の一致を確認。[CSV独立再読](検査/追加/CSVの独立再読.json)。
- 保存時に70JSONの元bytesとSHA、小ZIPのCRC/集合/元SHA、全入力とコードの前後不変を確認。[正式保存の確認](検査/正式保存の確認.json)。

## 再現手順

Windows、Python 3.14.3標準ライブラリ、Go 1.24.2、Node 24.22.1、CSV出力に`@oai/artifact-tool` 2.8.129を使用。原板は[入力台帳](検査/入力台帳70場.json)の固定70場だけで、11/09は未読。元金融の正本は[112](../../../00112_支持否定の確認と通常追尾幅の比較/README.md)を参照する。

1. [コード所在索引](再現資料/コード所在索引.json)に従って新ZIPと既正式参照を復元し、元パスとSHAを照合する。固定要求は絶対パスを含む。同一環境なら元パスを使い、環境を移す場合は参照を付け替えた新要求とSHAを別に作る。
2. 台帳側の`台帳を作る.py --output <未作成先>`で、固定112Nativeから建玉・返済片・Reader入力を作る。保存コードに台帳がimportする入口結合コードも含めた。
3. 原板を再走査する場合は、Readerの`保有中OHLC.exe --fixed <固定要求> --fixed-sha <SHA> --out <未作成先> --workers 8`。価格集計だけを再利用する場合は、`Reader結果.tar.gz`を索引のSHAと照合して復元する。今回の実要求は[Reader固定要求](検査/Reader固定要求.json)。
4. `Raw結果を統合する.py --fixed <統合要求> --sha256 <SHA> --output <未作成先>`で実R/n曲線とCSV入力を作る。[実統合要求](検査/追加/統合のRoot要求.json)・[確認](検査/追加/統合の確認.json)を対照にする。任意の新出力先に変えた場合は、後続要求の参照も新たに固定する。
5. 独立監査は`独立走査を実行する.py --request <監査要求> --request-sha <SHA>`。[実監査要求](検査/追加/二場独立監査のRoot要求.json)は11/06二場に限定する。
6. CSV出力の`出力する.mjs <統合gz> <SHA> <未作成先>`と`CSVを独立再読する.py`、Rootの`統合表を検算する.py`で正本と全件照合する。新しい表の作成時はSpreadsheetsの作成手順に従う。今回の出力済みCSVを上書きしない。

Reader結果・CSVを作る際の金融戦略の再生は0。原板時計はCurrentPriceTimeであり実受信時刻は不明。同秒別原行と部分返済を保持する。ラージBBOをminiの約定代理に用いた比較で、実際のmini板・取引所逆指値の約定を立証していない。退出後の仮想利益・機会損失・最高点利確の仮損益は含めない。
