## テクニカルな判別で不足した点

主E100の失効16玉はaddon9/episode7、core0。3分EMA8/21の並びは取得→失効で逆→逆12、順→順3、順→逆1。Close対EMA21は逆→逆15、順→順1だった。失効時にEMAが逆方向という静的条件だけでは、取得後に新しく背景が崩れたことを示さない。ownerからaddon内部の突破/往復の型を推定して一律除外もしない。

MACDのMはヒストグラムの変化が保有方向に弱まる条件で、水準の方向逆転とは異なる。主16件中6件は失効時もHist水準が保有方向だった。平均線を背景、MACD差を勢いの変化、価格構造をセットアップの無効条件という役割に分け、取得時と失効時の関係を確認する必要がある。

11/06デイ13:52:13の7枚売り@57,420では、固定抵抗57,570、取得時ATR約176.93、距離150ptだった。13:54/13:57/14:00の確定Closeは57,450/57,440/57,510で、抵抗の上に出なかった。14:00のMは真。14:02:49の元返済時Askは57,610だが、最後の確定Closeは57,510のままで、追加失効は発生しない。未成立票は確定終値の支持否定であり、予約で失効を妨げた例ではない。原保存点だけでは保有中の最初のBBO抵抗越え時刻までは確定しない。

次は、取得/取得後に確認できた背景が後に崩れた状態遷移、終値による確認と逐次BBOによる失効の時計差、価格構造に対する数量リスクを別の要因として検討する。単に逆MAを追加する案や、起動額を下げ続ける案へ置き換えない。改善額は次の固定比較まで未確認。
