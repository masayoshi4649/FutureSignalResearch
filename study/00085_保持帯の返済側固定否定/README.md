# 00085：保持帯の返済側固定否定

2026-11-08。主費用で黒字の案はなかった。

固定84C0の複合チャート入口を同じにし、要求時のfreshな保持帯の返済側を1tick割る固定線を追加する出口だけを比較した。G1量計画・100micro・費用・初回除く15分時計を揃え、旧70%・125/250先着・待ち50%は合格判定から一旦外す。
[検証計画](検証計画.md)・[設定IDと版5の55×9表](設定と結果.md)・[固定84](../00084_現在の価格応答と数量確認/README.md)を参照する。元FAR後期三手法の売買列の同値再現ではない。

## 仮説と固定条件

| 設定 | 保持帯価格線 | 共通の出口 |
| --- | --- | --- |
| H0G1 | off。要求時HoldAnchorは保存し、床へ追加しない | ATR・125pt・確定足技法失敗とG1利益保護 |
| H1G1 | 買Hold.Bid−10／売Hold.Ask＋10。要求時に固定し既存床へmax追加 | H0と同じG1 |

入口C0は3/15分EMA方向、3分MACDhist増分・終値EMA回復、0..1ATR位置、RSI/TR同時急変警戒と、短秒/OFIの個別既知反対拒否・失速時支持を維持する。その上でfreshなE08帯の両気配維持と反対圧力解消を必要とする。C1の追加数量Qは採らず、元の転換初動・失速確認に含まれる数量の役割は残す。売買は符号反転の同条件。

新規はDay09:15..15:15/Night17:30..翌05:30の15分枠で初回09:00/17:15を除く。NY09:30前後15分は静観し前窓返済、場末15:35/05:50返済要求。損失・利益保護と確定3分技法失敗は全原行で連続する。100micro・片側100・同時一建玉は研究尺度で推奨数量ではない。1枚10円/pt、片道手数料11円＋想定滑り5pt、往復122円。
正益前から新規時ATR3のceil5を15..125ptへ固定し、未知125、非緩和ATRと125pt床を使う。現在単価純益10×方向幅−122円がstrict正になれば最低建値床とG1部分返済を即起動し、全量約定後の実確定益だけを残玉予算に使う。保持帯の負の床を理由に利益床を下げず、返済受理を取消・延期しない。

## 保持帯線の出典と意味

HoldAnchorはEMA用StructureAnchorと分離する。要求時の同方向holdの出生Bid/Askから買P=HB−10・売P=HA＋10を固定し、実取得Eへ方向床s×(P−E)を一度だけ写す。H1は返済側Mでs×(M−P)<=0を含む境界、同値床の返済理由は旧理由を優先する。Pは後のhold・鮮度失効・滑りで動かさない。δ=10ptは今回のラージ板と源特徴の研究刻みであり、mini/micro実板の呼値・約定を検証した意味ではない。
これは入口Bの両気配ORによる厳密否定や、源holdの両気配10pt超逆行による解除とは別。買いでAskだけ低下、売りでBidだけ上昇する場合を単線で必ず止める条件ではない。hold.Bid/Askは出生値、Time/Index/Eventは後続確認時の値なので、確認時BBOとの単純同値を要求しない。
候補ありの未知・別方向・別原行・未来・非有限・非格子・停止式不整合は入力errorにする。非候補は理由付きcanonical未知を保存。実fillが既に否定側でも新規を消さず、同正常原行で未予約全量を要求し、後の適格原行で返済する。線での架空約定・同原行相殺は作らない。初回hitと理由付き要求を分け、先行部分片へ後段のhitを遡及しない。

心理の仮説は、取得を認めた帯が返済側でも保たれる局面と、その水準を割り追随根拠が弱まる局面を分けること。参加者の意図を直接測った事実ではなく、損失縮小と回復する勝ちの取り逃しを両方反証に残す。
