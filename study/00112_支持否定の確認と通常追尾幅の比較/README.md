狭幅は最低10pt、取得時ATRと現在の3分足内値幅5本中央値Vから選び、通常幅以下。取得時ATRが未知なら通常200/400ptを固定し後で付け替えない。B100/P100/P400は起動後の初回警戒真で狭幅をラッチし、その後に警戒が偽・未知になっても解除しない。P100/P400はラッチ前にP偽・未知なら新たに狭めない。B100はPが真でなくても、Mが真かつC/BとのORが真なら警戒真になる。ラッチ後の幅は現在既知の尺度で再評価し、両尺度未知なら現幅保持、保護床は非緩和とする。P警戒のprior pivotと、中心足が取得以後という構造床の適格性は別条件である。
