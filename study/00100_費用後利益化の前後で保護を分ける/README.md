# 00100：費用後利益化の前後で保護を分ける

2026-11-08。条件固定・市場実行前の計画。[99](../../study/00099_背景と現在の勢いと数量で順行を選ぶ/README.md)では複合入口E3/E3Sが同じ28取引56枚、主C0/D0で＋38,688円となったが、仮定の追加5pt/片道では−4,312円だった。費用後正益未観測の1玉が−35,385円を占め、保有中に価格10ptの順行を観測しても、費用後の残玉単価は最大でも−77円だった。

今回は入口E3SとSource・数量・時計・費用を維持し、**利益化前の名目床を追加するHG、旧H0、利益後にATR追尾を継続する旧P0の実現収支**を比較する。E3とE3Sが今回同じだったことを一般的な同値とはしない。新しい入口や反転Source、枚数政策は加えない。
