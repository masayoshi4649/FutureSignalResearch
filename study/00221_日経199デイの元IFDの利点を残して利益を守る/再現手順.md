# 45デイの再生と次のデイへの適用

リポジトリ直下のPowerShellで実行する。原板は隣接する `../JP_OSE_Data/future/NK225/` の45デイ。元199_02の予約・価格索引・当時特徴と依存部品は[219の入力再現手順](../00219_日経199デイの利益保護と出口条件を比較する/再現手順.md)に従う。T01を既存S1P2と照合するため、[220の主比較](../00220_日経199デイの損切位置と利益の確定方法を比較する/再現手順.md)の元帳も先に作る。今回の実行環境はPython 3.14.3、NumPy 2.5.4、CSV出力はNode 24.22.1、@oai/artifact-tool 2.8.157。

## 条件と口座

最初に[比較方針](比較方針.md)の方向・時刻対照、元注文を外した診断、各出口定義の2通りの金融再生を行う。大きい元帳はworkに保存する。

```powershell
$trial = (Get-ChildItem -Directory 'study/00221*').FullName
$engine = (Get-Item 'study/00219*/口座再生.py').FullName
$py = 'work/複合テクニカル学習環境/Scripts/python.exe'
$sets = [ordered]@{
    '221元IFD' = '元IFDの寄与/出口定義.py'
    '221入口別' = '入口別の保護/出口条件.py'
    '221両注文' = '両注文を残す/出口条件.py'
    '221期限の追試' = '両注文を残す/期限の追試.py'
    '221延伸' = '利点を残して伸ばす/出口条件.py'
}
foreach ($item in $sets.GetEnumerator()) {
    & $py -X utf8 $engine --出口定義 (Join-Path $trial $item.Value) --出力 (Join-Path work $item.Key)
    if ($LASTEXITCODE -ne 0) { throw $item.Key }
}
& $py -X utf8 (Join-Path $trial '元IFDの寄与/分期限を延長する.py')
& $py -X utf8 (Join-Path $trial '元IFDの寄与/期限延長と追尾を組み合わせる.py')
& $py -X utf8 (Join-Path $trial '元IFDの寄与/60分境界の欠測を検査する.py')
& $py -X utf8 (Join-Path $trial '入口方向を照合する.py')
& $py -X utf8 (Join-Path $trial '出口の作用を集計する.py')
```

[元注文・期限延長](元IFDの寄与/README.md)、[両注文と追尾](両注文を残す/README.md)、[指値の延長](利点を残して伸ばす/README.md)、[F01の遅延と原行照合](入口別の保護/F01の返済遅延と具体例.md)に、それぞれの追加検算と生成コマンドがある。比較対象は入場をそろえた全181件と、各日ごとに全注文を先頭から処理した単一口座。価格・時計・費用・含み損益は板で照合した。[60分判定の原行監査](元IFDの寄与/60分判定の原行監査.md)

## 日別CSVとViewer

CSVを再生成する場合の例。出力器は候補ごとにフォルダを新規作成し、上書きをせず全セルを検算する。公開先を再現するには、毎回別の空き作業先を使う。実行時に対象のNode依存ディレクトリを指定する。

```powershell
$deps = 'C:/Users/masay/.cache/codex-runtimes/codex-primary-runtime/dependencies/node'
$dest = Join-Path work ('221出力再現_' + (Get-Date -Format 'yyyyMMdd_HHmmss_fff'))
& (Join-Path $deps 'bin/node.exe') 'scripts/損益CSV/候補別に出力する.mjs' --input 'work/221集計/閲覧入力.json' --output (Join-Path $dest 'CSV') --proof (Join-Path $dest '比較記録') --dependencies $deps
```

実際の公開は6候補×3表・18 CSV・27,438セル。元板を複製せず閲覧できる[Viewerの2日4表示](Viewer/README.md)は、このCSVと異なり、両戦略で共通取得だった建玉1件ずつを表示する。

## 条件を固定して追加デイを照合する

新しいデイの入力は[216の日経入力生成](../00216_十一月二十日の固定入口と寄り前の反例を検証する/日経/README.md)と同じ入口定義で準備する。基準45日のうち11月18〜20日の6口座は、別の適用経路でも各建玉の全項目・順序を両モードで照合した。下記はその照合コマンド。次回は新しい日付の母集団・純入口・索引と場名を指定し、`--既使用照合` を外す。固定候補は元IFD、F01、D04、T02、T03、T04。[ソースと既使用デイの指紋](追加デイの固定条件.json)

```powershell
$next = (Get-Item 'study/00221*/追加デイで照合する.py').FullName
$result = Join-Path work ('221追加照合_' + (Get-Date -Format 'yyyyMMdd_HHmmss_fff') + '.json')
& $py -X utf8 $next --母集団 'work/216日経/母集団' --純入口 'work/216日経/純入口.npz' --板索引 'work/216日経/前史十場と追加二場の索引参照.json' --場 '2026-11-18_Day' '2026-11-19_Day' '2026-11-20_Day' --既使用照合 --出力 $result
```
