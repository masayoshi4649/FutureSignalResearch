## 利益を取ったのは何か

元IFDの利確65建玉は全件黒字で、費用後利益1,732,995円。全利益2,362,530円の73.4%を占めた。損切30件の損失は902,310円。通常期限78件は41勝37敗で＋133,994円、場末8件は4勝4敗で＋55,384円だった。これは元の決済の内訳であり、各注文の効果は実際にその注文を外して測る。

- **固定利確の寄与。** 元181件を固定して利確だけ外すと収支は308,000円増えた。元の利確65件のうち36件はさらに伸び、29件は利益を返し、13件は赤字に反転した。1枚口座では保有率51.87%→64.69%、取得181→119件。共通の116建玉は116,000円改善した一方、消えた旧65建玉の収支は＋162,995円、新たな3建玉は＋31,769円。差し引きで口座収支は元より15,226円低かった。実現損失は379,540円少なく、赤字日は12→13日。従って、固定利確には取引を回転させる価値があり、到達後に延ばすには収益の戻しと保有枠の両方を考慮する必要がある。
- **固定損切の寄与。** 元の損切30件のうち、損切を外すと16件は戻り、4件は最終黒字になった。一方で残る14件の悪化402,000円が、回復した16件の改善281,000円を上回った。同じ181件では損切を残した側が121,000円有利だった。11月4日13:46:01に建てたR350の売りは、元では−36,077円。固定損切を外すと期限で−129,077円になった。口座全体の取引件数が減ると総損失だけは小さく見えるが、損失大5件計は195,385円→373,385円へ拡大した。
- **期限の寄与。** 元の±1Rは両方残し、通常の60分期限を場末の強制決済まで延ばした。元の通常期限78件中、45件が改善、31件が悪化、2件同額。赤字から黒字18件、黒字から赤字9件で、固定181件の収支が414,000円増えた。他の元決済理由では収支差0円。口座全体では138件・全45日参加、保有率63.14%、建玉中央値13,923円、日次中央値32,384円。元より収支287,311円増、総損失203,002円減となった。11月12日10:35:01の売りは60分期限の−25,077円から利確の＋33,923円に転じた。反対に10月8日11:01:02の買いは＋14,923円から場末の−27,077円に転じた。

D04の前24日収支は＋640,688円（元＋595,917円）、後21日は＋666,686円（元＋424,146円）。日次は21日改善・10日悪化・14日同額。改善幅の大きい3日を両口座から除くと収支差は＋21,080円まで縮小した。赤字日は12→13日。買い収支は元より46,229円低下し、売りが333,540円改善した。一度でも費用後黒字を経験して赤字で終わった建玉は55→36件だが、その損失総額は891,235円→889,772円である。建玉数が減った割にこの損失は残る。元の損切と利確を維持したまま、期限に届くまでの利益の戻しを保護する余地がある。

## 期限を延ばした玉に利益保護を重ねる

**60分で建値から0.25R以上大きく逆行していない玉を延ばし、そこから利益を守るT04**では、元の利確も損切も1Rで維持する。元の60分時点に達した65件のうち52件を延長し、延長後に0.45Rの順行で保護を起動したものが41件、実際に追尾で決済したものが24件だった。床は建値から＋20pt以上。延長後の最大順行から0.65R下、確定足で失速・収縮が現れたときは0.35R下まで上げる。売りには同じ条件を符号反転する。[各設定の条件](期限と保護の追加条件.md) ・ [前後・固定建玉・遅延の照合表](期限と保護の照合表.md)

- **実口座での違い。** 単一口座で元のIFD→T04は181→161件。利益2,362,530→2,421,453円、損失1,342,467→1,198,850円、収支1,020,063→1,222,603円、日末最大下落147,463→65,231円。一度でも費用後黒字だった玉が赤字で終わった回数は55→37件、その損失は891,235→847,849円。赤字日はどちらも12日。全45日参加し、買い収支は元より4,230円低く、売りが206,770円高い。収支差の大きい3日を除いた差は＋40,309円。
- **追尾自体の寄与。** 延長条件が同じT06の追尾なしと比べ、T04は口座収支が17,691円増え、総損失は18,077円減少、利益後赤字の損失は67,231円減少した。一方、元の181建玉を共通にすると、T04はT06に比べて損失を115,539円減らす代わりに利益を333,539円手放し、収支は218,000円減る。口座での改善には追尾後に別の入口を受けられた効果が含まれる。この固定181では、T04の損失1,410,543円は元IFDの1,342,467円より大きい。
- **収支を優先した場合。** 元の60分を全て場末まで延ばし、全保有期間に従来のS1P2確定足保護を適用するT02は、141件・利益2,480,608円・損失1,153,465円・収支1,327,143円。元のIFDより収支は307,080円増えたが、保護を追加する直前のD04と比べると増加は19,769円で、追尾返済6件、総損失は14,000円増えた。費用後の利益を経験して赤字だった玉の損失も元IFDより12,537円多い。増益の主な要因は期限延長だった。
- **執行待ち。** T04は追尾要求から1・3・5秒後の返済で収支1,222,603円・1,226,603円・1,223,603円となり、いずれも日末最大下落65,231円。延べ2,405建玉について1秒条件の新規・返済・価格極値を原行で照合した。さらに全3遅延・全案・両モードの延べ6,129件を読み、60分直前の板価格と確定12分効率による分岐1,701件、遅延を満たした最初の板での動的返済621件を独立に照合した。追加条件はD04の結果を知ってから同じ45日で立てた。次の追加デイでの再現性は未確認。
