## どこに損切・利確・追尾を置くか

元の入口が使う値幅を1Rとし、すべての案で最初に＋1Rの指値と−1Rの防御注文を置く。60分期限を持つ建玉と、もともと場末まで持つ建玉の期限も維持する。表示する順行幅は建値から返済側気配への値幅。売りでは符号を反転する。

- **A22** は0.95R順行で常に追尾を始め、最高順行から0.80Rの押しを許す。通常の60分期限の建玉は、残り10分に現在0.45R以上あれば追加で追尾を開始する。この10分で完成1分足から勢いの失速または値動きの収縮を確認したときだけ、許す押しを時間に応じて0.65Rから0.25Rへ縮める。場末期限の建玉は0.95Rの広い追尾のみ。起動後の床は最低で建値から順行側20ptとし、不利な方向へ戻さない。
- **A12** は60分期限の建玉を0.85R順行で保護するか、残り10分・現在0.45R以上で保護する。許す押しは通常0.80R。終盤の失速・収縮時はすぐ0.35Rまで縮める。場末期限はA22と同じ。元65件中3件の利確を先に手じまいして33,000円を失い、元の通常期限14件で48,000円改善した。元赤字5件が黒字化した。1枠口座では80,846円改善したが、同じ181件で説明できるのは15,000円。早く枠が空き、その後に取得できる建玉が変わった影響が大きい。
- 比較した初回13・追試8の**どの案も、元181建玉の1R損切30件の返済を変えなかった**。保護で減った赤字は主に、利益を一度得ながら期限まで戻された建玉から生じた。したがって、損切を変えず追尾だけを加える今回の案では、元の固定損切に直行する建玉は救えていない。

利確直前の反落だけで保護を強めたA06は、元の利確12件に割り込んで計172,000円を失い、固定取得の収支も144,000円悪化した。技術確認を足したA07でも元の利確8件を手放した。A01の広い追尾だけでは元の181件の返済を一度も変えなかった。保護幅・残り時間の対照と全21案の結果を掲載した。[初回の条件](条件.md)・[追試の条件](期限の追試条件.md)・[全条件の結果](全条件の結果.md)

## 選抜、費用、再現

初回の前24日基準ではA12が首位。追試の前24日首位A27は2分の停滞確認を加えたが、A12と同じ収支になった。A22は過去45日全体で元の65利確を残した点から選んだ比較例で、前24日の選抜外。前24日の収支は元より2,000円低く、赤字日は全期で1日多い。いずれも既に入口の探索に使った45日であり、改善は一部の日に集中する。値幅到達や床の価格は約定保証を意味しない。元のラージ板で新規・返済の対応する気配を確認し、動的保護は発動から1秒以上経過した最初の正常板で返済する。片道手数料38.5円・想定滑り5pt、往復費用1,077円。

[219の入力再現](../../00219_日経199デイの利益保護と出口条件を比較する/再現手順.md)に加え、220の主比較元帳を準備して実行する。初回A00は220のS1P2と両モードの全建玉を照合した。元IFDを含む両群の全8,356建玉記録（同じ対照の重複込み）について、建玉・決済の価格時刻、最良気配、極値、動的返済の発動と実際の板を照合した。

A22の追尾発動からの返済を3秒、5秒に遅らせると、口座収支は順に1,057,986円、1,054,986円。5秒でも元IFDより34,923円高く、元の固定取得65件の利確は全て維持した。元より赤字日が1日多い点は各遅延で共通だった。[遅延別の損益と原条件との照合](A22の返済遅延.md)
