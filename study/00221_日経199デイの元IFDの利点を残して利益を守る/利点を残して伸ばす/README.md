# 速く順行した建玉だけ利確指値を伸ばすとどうなるか

**最初の利確幅を超えて伸ばすとき、利益を守る追尾には効果があった。ただし、速く順行したという情報だけで元IFDより優れた1枚口座は作れなかった。** 2026年9月21日～11月20日の日経199_02・既使用45デイ。ラージ板の実側で約定を代用し、日経mini 1枚、往復1,077円を控除した。買いと売りの条件は鏡像、初期損切はすべて取得時の元1R。通常60分または元の場末期限を守り、最長15:30に決済した。

H02は最初に0.60R進むまで10分以内で、0.25R以上の逆行がなかった場合だけ、利確を1.0Rから1.5Rへ変更する。元の1.0Rに届いた時点で「0.90R、または最大順行−0.25Rの大きい方」まで利益を保護する。指値変更の適用も、床に触れてからの返済も最短1秒後。判断までに元の指値へ届いていれば元の利確を使う。日中の注文処理やmini実板での約定価格は測っていない。[全9案の設定](仮説と条件.md)

## 利益を守れた取引と、口座で失った利益

- 11月6日10:16:01、57,290で売り、1Rは350pt。10:22:41に延長が有効となった。元IFDなら10:24:01、56,940で＋33,923円。H02は追尾で10:25:44、56,910で＋36,923円を確保できた。同じ延長に追尾を足さないH08では、10:52:26、57,640で損切りとなり−36,077円だった。固定181取得全体でも、この追尾の有無だけで収支差が132,000円あった。
- 11月5日08:56:05の売りは62,910、1Rが400pt。09:00:06に指値を変更し、元の09:01:23、62,510の＋38,923円から、09:03:10、62,310の＋58,923円まで伸ばせた。H02で変更が間に合った固定22件のうち20件が元1Rに届いた。その20件でも元より増益は9件、減益は10件、同額は1件だった。元1Rまでの継続と、その先の伸びは分けて考える必要がある。
- H02を同じ181取得に当てれば＋41,000円。しかし1枚口座では、10月20日11:56:04の売り＋33,923円が保有中のため入れず、12:11:11の買い−36,077円に替わった。共通180取得で増えた41,000円から、この入替差70,000円を引くと元より29,000円減る。
- 反対群H04は口座で元より＋36,308円だが、元181取得固定では既存の損失額は変わらず、利益が18,000円増えた。口座で総損失が30,231円減った理由は、後続の損失建玉を取らなくなったことにある。日末最大下落は1,000円増加。元より改善幅の大きい3日を除くと差は−33,769円。前24日だけの規則で選ばれたH04でも、この45日間を使った選定の影響が残る。元IFDから利確指値を動かす根拠としては限定的である。

各案の費用後収支を前24日・後21日・末3日、元の利確に届いた件、口座の取得入替で分解した。全案で45日すべて取得あり、金融未知0件。固定181件のうち元IFDが利確しなかった116件は、全案で決済原行と収支が一致した。[固定と口座の全成績](固定と口座の全成績.md)

## 再現

リポジトリ直下のPowerShellから実行する。研究環境と原板索引は[219の口座再生仕様](../../00219_日経199デイの利益保護と出口条件を比較する/口座再生の仕様.md)に従う。

```powershell
$実行 = 'work/複合テクニカル学習環境/Scripts/python.exe'
$再生 = (Get-ChildItem 'study/00219*/口座再生.py').FullName
$枝 = (Get-ChildItem -Directory 'study/00221*/利点を残して伸ばす').FullName
& $実行 -X utf8 $再生 --出口定義 (Join-Path $枝 '出口条件.py') --出力 'work/221延伸'
& $実行 -X utf8 (Join-Path $枝 '延長の寄与を調べる.py')
$照合 = (Get-ChildItem 'study/00219*/経路診断/出口の原行を照合する.py').FullName
& $実行 -X utf8 $照合 '221延伸/全案' --出力 'work/221延伸/原行照合.json'
```

適用条件と執行の実装は[出口条件.py](出口条件.py)。[照合・集計コード](延長の寄与を調べる.py)が、延長が有効にならなかった建玉と元利確以外について、原行と収支の一致を検査する。別の原行照合でも、元IFDを含む全案の入口固定・1枠口座延べ3,604件を検算した。
