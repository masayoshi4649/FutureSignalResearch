## 元の利点はどこにあったか

1. **入口の日時と方向に意味があった。** 元181件の実際の買い・売りでは＋1,020,063円。同じ原行・同じ幅・同じ期限で売買を逆にし、新規と返済の板の側も入れ替えると−1,809,937円だった。同じ週の別デイに時刻・方向を移した4通りも、全対照が揃う153件でいずれも赤字（元は＋876,219円）。これらは選ばれた入口を個別に評価した診断で、取引可能な別口座や将来の期待収益を表す値ではない。[時刻・方向の対照](入口方向と時刻の対照.md)
2. **利確指値は総利益の73.4%を確定し、次の新規に枠を渡していた。** 元の利確65件で＋1,732,995円。利確指値を外すと65件中36件はさらに伸びたが、13件が最終赤字に転じた。元の181建玉に固定すると＋308,000円の改善、買売合計1枚で全注文を再生すると取得が181件から119件に減り、収支は15,226円下がった。損切だけを外すと最大の1件損失が41,077円から129,077円に広がった。[注文を一つずつ外した結果](元IFDの寄与/README.md)
3. **元の片幅に対して60分では足りない取引があった。** 元の60分期限で決済した78件のうち75件は片幅350pt。延長すると29件が元利確、14件が元損切、35件が場末返済。元期限からの追加保有は中央値64.9分。元期限で赤字から最終黒字へ18件、黒字から赤字へ9件。元の取得を固定すると＋414,000円で、うち売りが＋387,000円、買いは＋27,000円だった。期限判定に先立って売買で条件を分けていない。[期限後の到達先・所要時間](期限後の到達.md)

### 元の期限を残すF01

新規時の片幅Rは元から150・200・350・400ptのいずれか。全建玉で元の利確＋1R、初期損切−1Rを置く。**Rが350ptで元期限が60分の建玉だけ**、順行0.85Rで追尾を開始する。残り10分以内は現在0.45Rの順行でも開始。保護価格は建値より利益側20pt、または最大順行から0.80R戻した水準の有利な方。残り10分に確定1分足の失速・収縮が出れば、許す戻しを0.35Rに縮める。床を緩めず、売りは符号反転する。[適用先の比較](入口別の保護/条件.md)

元181建玉に固定すると65利確・30損切・8場末は全件同じ原行で、60分期限の13件だけが変わった。**同じ建玉で総利益4,692円増、総損失36,308円減、収支41,000円増**。1枚口座での改善72,923円のうち、残り31,923円は後続建玉の入れ替わり。例えば9月29日14:19の売りは−21,077円から＋3,923円。10月5日08:51の買いでは追尾後に再上昇し、＋25,923円が＋2,923円になった。追尾の執行を5秒に遅らせても65利確はすべて残り、口座収支は＋1,089,986円だった。狭い150・200ptにだけ同じ保護を足すF02では、元の利確3件から33,000円を手放した。[F01の執行遅延・日時と価格](入口別の保護/F01の返済遅延と具体例.md)・[全条件の比較](全条件の比較.md)

### 期限を変えるT04とT02

**T04**は両側の元注文を維持する。60分でどちらにも届かず、期限直前30秒内の最新正常気配で建値比−0.25R以上なら延長する。例えば60,000で買い、Rが350なら、初期損切59,650、利確60,350。期限直前の返済側気配が59,912.5以上なら延長対象。保護は延長中の順行が0.45Rに達したら起動し、以後の最大順行から0.65R戻し、完成足の失速・収縮時は0.35R戻しで追尾する。利益床は最低20pt。元から場末期限の建玉は元通り。価格差の小数は判定閾値で、板は実際に観測した気配で評価する。[追加条件](元IFDの寄与/期限と保護の追加条件.md)

T04の前24日＋710,918円、後21日＋511,685円、直近3日＋56,614円。改善上位3日を外しても元比＋40,309円。元との共通取得は＋213,000円、入替えが−10,460円で口座改善は＋202,540円。元買い口座に比べ買いは−4,230円、売りは＋206,770円。元181件固定では収支＋201,000円、**総損失は68,076円増**。また同じ延長条件で追尾だけ外すT06に対し、追尾の追加は固定181件で収支−218,000円、1枚口座では収支＋17,691円・総損失18,077円減となった。T04の良さには枠の再利用が含まれる。前24日だけの同群首位はT03で、T04は45日を見て選んだ比較候補。[期間別・執行遅延別の比較](元IFDの寄与/期限と保護の照合表.md)

**T02**は全建玉で元の両注文を場末まで待つ。0.95R順行、または場末の強制返済要求前10分以内に現在0.45R順行で保護を起動する。床は20ptと最大順行−0.80Rの有利な方で、終盤の失速・収縮時は−0.35Rへ縮める。元比収支＋307,080円のうち、追尾を付けないD04でも＋287,311円。追尾の追加だけでは収支＋19,769円、総損失14,000円増。元181件に固定した場合の追尾追加は収支＋3,000円。利益後の損失は元より12,537円増えた。6件の追尾返済が起きた今回の板で、収支増の主な理由は期限延長だった。
