## 保護と延伸を分けて得た結論

H60/D1/C5の上表6案は、153・152とも**125pt順行後に既知の赤字で終わった取得は0件**。IFDまたは125到達後の床引き上げは、このデータ内で利益保護に働いた。一方、125未到達の小幅な費用後正益から赤字になった取得は153で23件、152で182件残る。125起動が、あらゆる含み益を保護するという意味ではない。飛越・遅延・欠測時にも赤字を絶対に防げると推定しない。

本試行のGは全て、125到達前の負け経路をIFDと同じに保つ。このため損失総額がIFDと同じことは設計上の性質であり、技術選択が損失を減らした効果ではない。利確後の仮想利益を取り逃がしとして評価せず、実際に選択した決済経路の費用後差だけを比較した。

158の強い早期退出は、負けの軽減と同時に、本来勝つ取得を早く切って損益を悪化させた。159は125までは待つ設計に替えてその混同を除いたが、延伸判別の上乗せは確認できなかった。152の後25場のG01/G02では、延伸27件が7改善/20悪化でIFD比−67,000円。IFDを維持した76到達群のうち双方既知75件には、C1固定対照で+321,000円の改善が残っていた。単に延伸数が少ないのではなく、今回選んだ群と次の場で改善する群が逆転していた。

複数の指標が同じ価格変化を見ている点、支持場数と適用場の偏り、既定出口、全決済/全延伸の一度きりの選択を分けて次の問いとする。過去の最良一規則を選ぶことと、安定した群の識別は同じではない。[モデルの解釈](モデルの解釈.md)に実条件・発動・対照差の内訳を残す。

現在の比較対照は、153はIFD±125、152は125起動/100幅/TP250を維持する。これは既使用73場における研究上の基準であり、安定利益や実運用への合格を意味しない。152は後半赤字が残り、独立1枚を重ねた結果を片側上限10枚口座の損益へ単純に10倍しない。
