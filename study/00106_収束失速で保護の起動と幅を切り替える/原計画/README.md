# 00106：収束・失速で保護の起動と幅を切り替える

2026-11-09採番。**市場未実行・実採用なし。** [105](../00105_固定SourceとLD10の四場追加確認/README.md)で利益後赤字の多くがLD10未起動だったことを受け、固定した元Sourceの入口・多建玉・可変数量・費用・5分判断を維持し、保護の起動と幅を比較する。起動後の幅だけの差と、早期起動の差を混ぜない。

本計画を新しい市場再生前に保存する。入力参照・コード・実行物・段階の具体的な固定条件は、各口の準備後に別JSONへ固定する。未準備のSourceや公表値を仮定で埋めず、準備だけを市場成功としない。

## 共通する入口と管理

- 104/105と同じsymmetric Source。元EMA15/60、native ATR12、20/40分帯と再試験、5/15秒進行、板・数量・二市場支持、親/追加と比例返済を再用する。共有方向分岐の両側成立は待機、その他の元内式は変更しない。
- B5Qのstrict次5分一枠、一出生一回。デイ09:15、ナイト17:30以降、Actual米国開始から30分は新規静観。P締切US−15分/U開始US＋15分はSource側の別時刻。末尾30分は主表から追加除外しない。
- 主分母は日中35×76＋夜間35×148＝7,840、副表は7,560。保有＋同枠実取得で参加し、受理だけを約定と数えない。欠測・判定不能・US静観を勝手に分母から落とさない。全体最低25%、目標50%、日夜/場別も併記する。
- 売買は符号反転した同条件。手数料は1枚片道38.5円、C0/C5（追加滑り片道0/5pt）×D0/D1（追加価格時計0/1秒）の四感度をすべて評価する。BBO売買差は粗損益に含み、C5を二重計上しない。
- 元Sourceの返済予約を優先し、追加保護は未予約実残だけを要求する。同原行fill禁止、容量、部分返済、Force、終了時残/予約0を維持する。損益保護は定時外も逐次行う。

## 事前の五候補

uは現在残玉1枚の費用後円評価、Aは元の公開native ATR12を取得時又は初回既知に固定した未丸めValue。基本起動LD10は `u >= 100×max(10,A)`、早期の一定利益LD05水準は `u >= 100×max(10,0.5A)`。ATR未知では起動を保留する。

Cは新しい確定3分足3本で `abs(EMA8−EMA21)` が厳密に連続縮小、Mは保有方向sに対し `s×(Hist_t−Hist_(t−1))<0`。Pは当足より前に公表済みの最新局所安値/高値Lに対し `s×(Close_t−L)<0`。局所極値は左2本厳密・右2本同値許容で確認し、当足で新たに確認したLを当足Pへ使わない。欠測/未知を不成立や支持へ補完しない。

|W1|通常LD10|CかつMで約1ATRへ狭める|

幅は通常 `5×ceil(2A/5)`、狭幅 `max(5,5×ceil(A/5))`。狭めた状態はその玉終了まで保持し、床は最低名目建値・前床以上とする。起動前の最新公表も保存し、閾値到達時に使える。通常LD10と早期条件が同時成立した場合は通常LD10到達と記録し、早期だったと誤記しない。床と実約定は別で、費用後黒字を保証しない。

5候補×4費用×70場＝**1,400経済会計**。Wの内Keyは旧LD10、EはActivationPolicy/Key/理由をE1/E2と明示し、外namespaceでW0/W1/W2も区別する。MACDとEMAを独立した二票とは数えず、複合成績を指標単独の効果としない。

## 指標の履歴と因果順

SourceのCSV1/5分足・native ATRと、原行Lastから作る独立3/15分チャートを区別する。Scalar11や5分snapshotからEMA/OHLC/pivotを捏造しない。paired Bankは同じ原行Lastを旧・追加の両Bankへ供給して形成し、旧Snapshot全欄を照合する。

確認したdirectory範囲に先頭9/21より前の助走候補はないため、**9/21 Dayはcold開始**とする。以後、全70場を開始時刻順に通し、同限月の数値種だけを継承する。場頭で形成足・公表mask・C/M/P窓はresetし、限月変更はcoldへ戻す。保有の持越しはしない。計算対象の12場を助走専用へ除外しない。足りない履歴はunknownのまま記録する。

公表→Source Force時計→grid→rawを時刻と同秒優先順で配送し、全board制御、NK Last0、正NK Scalar、物理行/merge順、旧Tape ordinalを区別して結ぶ。EOF後へ公表・grid・価格・MTMを先締めしない。残Forceは別旗で扱う。新公表だけをC/M/Pへ送り、同じ公表の反復・reset後の同ID復活・未来・逆順を拒否する。
