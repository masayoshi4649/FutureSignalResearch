# 163 履歴と任意幅の入口探索

2026-11-14。**新規採用なし。** ±125/200ptに限定せず、履歴を含む複合入口1,460規則を12幅・4期限へ広げた。固定420,480政策とATR適応480政策を保存したが、SESSIONの高率に「後の期限完了で早期の既知先着まで除く」偏りを発見した。率をそのまま入口優位と解釈せず、[164](../00164_IFD最初到達の確定時計で入口と反転を比較する/README.md)で分類時計を別試行として再評価する。旧163正本は変更しない。

## 仮説と条件

持続するRSI/Hist、BB収縮後の再拡大、端からの回復、Impulse近似の禁止解除を、方向・構造・量と重ねれば、広い値幅でも高先着と頻度を両立できると仮説を立てた。全期探索であり、162で既使用のMP4候補も含む。過去だけの選択又は未見性能の証明ではない。

[条件.json](条件.json)のSHA256は `a4e5a3ad0417b5790a7f17e768327648e27790d25867092e5e60944ed2863b10`。[設定と結果](設定と結果.md)は汎用表版8を全セル複写している。

幅は125/150/175/200/225/250/300/350/400/500/750/1000pt、期限はstrictH30/H60/H120とSESSION。厳密期限が場末までに完了しなければC。SESSIONは境界観測とザラバ終端前の正常BBO鮮度30秒以内を要求し、境界原行をtouch/清算へ使わない。

ATR適応は既使用MP0057/58/81/82だけ。q0のATR5×2/3/4/6/8以上の最小gridを選び、上限1000、未知/非正ATRは待機、最初成立q0の幅を決済まで固定。旧参照の幅は200。

## 入力・取得・費用

旧全73場、31,642物理case両実側、35,339判断q0を維持し、正式148の100特徴を用いた。5/15/30分の背景・勢いと、BB/ATR・実体ヒゲ・相対観測量・短期価格端を組み合わせる。初版10群972と履歴6群488、合計1,460規則。買売は実側で符号を正規化した同条件。入口の向きを探す関数へ教師・q1・金融は渡さない。デイ/夜間NY09:30前/以後は夏冬時刻でq0を区分し、今回の固定規則は共通条件、各帯の強制参加はしない。

ALLと状態遷移だけのEDGEを分け、同物理q1は最初の成立q0で一意化する。Nは純新規、Uは旧87全取得の保持統合、Fは各場の旧初回出生時まで実取得0ならその旧信号を因果的に予約する補完。U/Fで全73場参加でも純新規が全場参加したとは呼ばない。

各取得を独立mini1枚として、同幅の利確・損切りIFDを比較。取得はBUY Ask/SELL Bid、清算はBUY Bid/SELL Ask。利益・損失は費用後正負の別集計、PF=利益/損失。100円/pt、税込片道38.5円（往復77円）、追加往復滑り1,000円（合計10pt相当）を控除する。実BBOのスプレッドも含む。未到達は完了期限BBOで清算、観測不足でも打切り前touchが確定していれば金融既知、それ以外は未知であり0円実績にしない。既知差引は未知を解決した全損益ではない。

F=順側先着、A=逆側先着、N=両側未到達で期限完了、C=分類観測不足。到達済み先着率F/(F+A)と、全取得に対するF比率、費用後の実現勝率は別物。頻度の分母は全73場の対象ザラバ時間であり、候補成立時間だけではない。利益・損失は重複しうる独立入口の合算で、片側上限10枚を守る実口座収支ではない。
