## 何を全場で検証するか

既知70場は121で既に全場を1走査し、E0は7候補・6セッション、6順/1逆、候補0は64場だった。デイ35場では5候補・4順/1逆、ナイト35場では2候補・2順/0逆。7件だけを抜き出して再生したものではない。C0基礎出生も0だった54場と、C0出生はあるがADX低下非支持/未知だった10場を分けて記録する。

122の「全場」は、現在棚卸した73場を全て走査する意味であり、全場で強制的に新規建てする意味ではない。条件不成立・指標/履歴不足・未約定・観測打切りを区別し、候補0を負けや先着率0%へ置換しない。どれも全セッション一覧へ残す。

棚卸では旧70のgzip/現plainの対応と、新規3場のplain原板（合計約942MB）がある。旧側は67場のgzip対応と、105で恒久保存した生成3gzipを扱い、同じセッションの複数形式を二重計上しない。73という場数・容量は棚卸由来で、未知本文を読んで勝敗を得た値ではない。

## 固定する入口

E0は121のC0（120P2固定対照）に、ADX30と前ADX30がともに既知で当値<前値を加えた候補である。単独のADXで向きを決めず、15分BB/RSIの逆側過熱領域、1分の失敗突破と回復、ATRによるスパイク/距離制限、取得capと回復維持を組み合わせる。

買いでは当1分LowがBB15下端以下、RSI15≤35。直前5本1分のLowを当1分Lowがstrictに割り、終値がその境界+5pt以上かつ旧5本レンジ内へ回復する。売りは高安・上下・RSI50からの符号を反転した同一条件。C0のADX≤25又は低下という背景も保持し、E0ではそのうち既知の低下を必須にする。上位MAの同方向や新しいRVOL条件を後から加えない。

全て121と同じ、側実体正・終値位置≥0.7、当TR≤2×当足を除く直前14本TR単純平均、無効化は当1分逆側極値の外5pt、出生Last/実取得までの正距離≤`min(100pt, 0.5ATR5)`、取得capは終値から側`min(10pt, 0.15ATR5)`。出生・取得Lastで前5本逆側境界から側5pt以上を維持する。

1分は当Rawまでから因果形成し、次分初Rawで閉鎖する。閉鎖Endから30秒超は発信しない。空足又は採用Raw価格時計差>60秒で1分形成/履歴をreset。公表済み当場freshな5/15/30分を用い、未知を支持や0へ置換しない。

C0基礎出生の300秒cooldownを消費した同原行でE0を派生させ、共通`cohort_id`を持つ。E0に独立cooldownを加えず、取得や将来勝敗を見た後に派生させない。要求後原行かつ1秒以上、30秒未満の最初の正常BBOでcap→hold→riskを判定し、不適なら即取消す。新規は固定Source.force_close未満、取得済み観測はSession.Endまで。固定5分/15分の強制新規や開始静観へは戻さない。

C0は出生anchorと旧版同体の内部対照として残す。V0/EV/B0/B1も121pureのコード同体を保つため出力へ残すが、今回の主評価・閲覧CSVの対象はE0。これらは「未使用/未実行」ではなく固定対照出力・主解析対象外と区別する。閾値・売買条件を新規3場の値動きへ合わせて変更しない。

## 原板の版と公表を揃える

Stage A後、旧70の対応gzipをストリーム復号し、現plainとSHA・byte数を全場照合する。旧生成3gzipも恒久保存先を正本として対応づける。原板本文を不要に複写せず、同一場は一度だけ使う。

旧版と同体なら、旧70の公表・原板・CSV前史の由来と起点を固定通り再用し、入力期間を過去へ伸ばさない。新規3場だけを115と同じ生成経路（candle300→公開器→原行配送、過去CSVの予定End seed）で生成する。5/15/30分のEnd/AvailableAt/DeliveryAtと実配送Indexを当時情報に揃え、前史に当場以後の値を混ぜない。CSV前史の参照範囲と指紋も記録する。

原板や参照入力に改訂差があれば、旧結果を消さず別入力版として全対象を再生成し、差の場・SHA・由来・処理を記録する。売買条件は変えない。旧70が同版の場合の同体照合と、改訂版との結果差を区別し、データ改訂を入口条件の変更で埋めない。どちらの分岐を使ったかをStage Bへ固定する。

## 主評価の数値判定

主はE0の取得後60分・正常返済BBOによる同幅±100pt先着。順/(順+逆)が70%以上かを従来通りの主数値条件とし、未到達を含む順/全観測完了も別の70%判定として併記する。副30/60分×±25/50/100/125/200ptも保持する。先着率の分母を、全セッション数や候補0の件数へ勝手に変えない。

率の分母が正なら、件数が少なくても計算された70%以上という数値達成の事実はそのまま示す。少数例・同場相関・期間偏り・未到達の多さは再現性の課題として別記し、それだけを理由に「数値条件未達」と言い換えない。分母0は評価不能/nullで、0%・未達・達成のどれにも補完しない。表示丸めだけで70%到達へ繰り上げない。

既知70/新規3/全73、日中/夜間の件数を残す。既知70の参照率85.71%は122の再実行前結果へ転記せず、実再生と版同体の検査後に評価する。新規3場は今回初めて読む追加期間だが、少数の短い追加期間だけで将来全般の安定性が証明されたとはしない。

観測はSource旧決済で打ち切らず、取得後の固定時計を使う。Raw又は正常BBO差300秒超・場末・期限後30秒以内のendpoint不足は打切り。最初の正常期限原行で終わり、同秒後続行を混ぜない。未約定・観測不足・未到達を分ける。
