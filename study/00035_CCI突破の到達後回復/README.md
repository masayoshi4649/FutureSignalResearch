## 共通の技術登録と三つの取得方法

元登録は当場3分前20高安strict終値突破＋現前CCI20実方向100超。元OHLC FractionのTP・各同窓20平均/MD・係数3/200、MD0無効/±100等号不可、当場21公開/ATR正、当場最新15分BB現前pair/end-key asofを保持する。CLVや上位BB幅値、SAR・量・別のANDは足さない。元R/Lと登録ATRは固定する。

E1は同IDで旧34の全case/detail/traceと全dict同値。E2は同じ+1秒有効化/正常BBO価格条件のまま30→180秒へ延長。E3は買ask<=R/売bid>=Lの初回到達後、strict後の原行keyで買bid>R/売ask<Lの初回回復を待つ。同秒後行も可、同key二遷移は不可。180秒は3分1本分の価格時計幅という事前仮説で、次の3分確定足を待つ条件ではない。

E3回復の残60分・新規停止前・回復+1<=元登録+180が可のとき市場要求。初回回復が時刻不可でも消費し、後を取り直さない。新規は要求+1秒以降の最初正常BBOで元期限内、期限等号可/停止等号不可。回復でTTLをリセットせず、新市場価格へ旧指値の上限を課さない。単発回復は支持持続や将来の継続を証明しない。

caseの要求時計/原行は元登録b、E3の新規要求b′と回復観測を別列へ分離する。無回復/時間不可の新規要求Noneをbへfallbackしない。間引き・分割はb、待機秒は元足の確認遅延と別である。仮監視は各登録独立、実運用は一予約/一注文/建玉。E3だけの監視記録はXF追尾とは別で、後続抑止の時計を空き時刻へ延期しない。未来観測/labelをlive純信号に混ぜない。

23は30分高安の突破→確定3分足の再テスト→その足高安の再突破とS2/MACDを待った。35は固定C0/旧水準へBBOで到達・回復する別の時計/価格で、6/3足寿命・同水準一回・失敗反転を継承しない。待機中の新しいCCIやATRで選び直さない。支持/抵抗を取り返す心理仮説は、吸収注文や参加者動機を直接観測した事実と区別する。

## 利益保護・費用・場内完結

全案XFは現在正常返済BBOのs×(mark−新規)×10−122>0strictで初回起動。往復手数料22円＋想定片道追加5pt往復100円、名目境界12.2pt超で、過去MFEだけでは起動しない。起動後は登録ATRのD=max(5,ceil(ATR/5)*5)、保護利益max(0,MFE−D)、買ceil/売floor・非緩和・最低名目entry床を維持する。hard125/TP250/期限、返済pending中更新停止を継承。名目床は同値約定や費用後黒字を保証しない。

ラージBBOでmicro1枚代理、倍率10円/pt・呼値5pt・片道11円。買ask/売bid新規・返済側BBO、返済要求+1価格秒以降の最初正常板。追加0/5/10ptは同約定の費用負荷で、起動や指値成立・新市場価格を感度ごとに取り直さない。実キュー/部分約定/mini-micro全量成立を再現したものではない。

デイ入力08:45〜15:40/停止15:25/強制15:35、ナイト17:00〜05:55/停止05:40/強制05:50を継承。正常板300秒超空白・未解消/EOF不足は品質へ残す。価格時計は受信時計ではなく、監視時間を実注文応答秒へ読み替えない。
