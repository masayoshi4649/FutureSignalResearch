## 仮説・条件・入力

[197](../00197_TOPIXの量と観測機会と方向尺度を分離する/README.md)では、量補完とq0追加による未知と損失を分離できた。200は過去の観測品質と、実側の構造変化が時間順に成立するかを分ける。Night母体2×品質3×時間順3=18、Dayは旧190D4固定。[条件](条件.json)・[設定と結果](設定と結果.md)。

同じLast価格時計を繰り返す行数は被覆の分母にしない。正常BBOを価格時計上で確認した後30秒までの区間を重複なく合算し、直前10/30分の90%以上を観測していたかを使う。最大空白90秒、開始端30秒内、場内窓を要求する。受信時計や真のBid/Ask更新時計がないため、取引可能性の代理に留まる。将来の欠測・決済可否を入口へ混ぜない。

時間順確認では源q0時点の前3本端（実反転）/EMA8（元順行）と10分期限を固定する。後続の突破、その次の連続1分q0の保持、MACD又はRSI増分、量を確認する。後から源や期限を更新しない。監視は注文pendingではなく、取得後の保有枠は従来どおり1。

原板・特徴は当初81場（2026-09-21Day〜11-16Day）と194の追加11/16Night・11/17Day。旧81も追加2も既使用。200は194結果受領後に設計され、追加2への適用は未見再現ではない。純条件・Source・出生を旧81金融前に固定し、その後追加全18を別封印して適用、最高候補への再選択なし。

単純IFD・DayA25/Night±15pt・H60、保有予約合計1、開始待機なし、15:30/05:45までに全決済。miniTOPIX1枚・1pt=1,000円、片道41.8円+0.25pt滑り。ラージBBO代用、遅延1秒/取得TTL30秒。未知は0円とせず場末まで枠保持、0取得場も分母に含む。
