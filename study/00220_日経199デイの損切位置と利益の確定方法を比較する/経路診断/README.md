# どこまで逆行から戻るか、順行をどこで守るか

2026-11-22。日経199_02のデイ45日、単純IFDで取得した181建玉（買い76・売り105）を調べた。買いは取得Askから後続Bid、売りは取得Bidから後続Askまでの符号付き値幅を見た。Rは元IFDの片側幅。mini 1枚、往復手数料と追加滑りで計1,077円を控除する。元の決済を境に打ち切るこの診断では、各取得で当時の情報で実施できた注文だけを評価した。後続取得の入れ替わりや、元の決済より長く保有する案は[独立した1枚口座の比較](境界の結果.md)で評価する。

## 損切りを早めると何を失うか

同じ取得で、逆行が各水準に**初めて**達した正常行を見つけ、それ以降に費用後含み益が再び現れたか、元のIFDでは最終的に黒字だったかを数えた。「早く切った場合の差」は、建てたときからその距離に静的な逆指値があったとして、最初に届いた実側気配で返済した場合の元181件との差。元IFDの利益2,362,530円、損失1,342,467円、収支＋1,020,063円。

|逆行幅|到達件数／181|その後に一度でも費用後黒字|元決済で黒字|元決済で赤字|早く切った場合の収支差|総損失の減少額|
|---|---:|---:|---:|---:|---:|---:|
|0.25R|124|88|55|69|−754,000円|＋251,765円|
|0.50R|84|44|28|56|−517,000円|−109,156円|

0.75Rでの一律損切りは元0.75R超の損を浅くする一方、この水準から戻って黒字になった14件を赤字に変えた。元181件の総損失は228,078円**増えた**。10月22日13:36:02の売りは63,370で取得し、13:59:29にAskが63,510（140pt逆行、元R＝150）まで上がった。0.90R損切りなら−15,077円。元の1R損切りのままでは14:22:48に63,220で利確し＋13,923円だった。逆に0.95Rでは元の勝ちを切った例がなかった。この水準は事後に見つかったため、幅を5pt内側へ丸めた感度と、後続の取得まで再予約した成績を追加した。[境界の追加検証](境界の結果.md)

条件付の余裕も少数取引で生じている。元181件の新規、利確、追尾を固定したW31とW36で、W31が損切幅を1.10Rへ広げたのは41件。そのうち決済が変わった8件は、元も新もすべて赤字で、3件が9,000・31,000・29,000円の損失縮小、5件は計18,000円の損失拡大。差引で51,000円改善した。W31で総合的な損失を減らした背景には「元の損切り銘柄が利益まで伸びる」以外に、**一時的な売り込み／買い戻しの後、損失が浅くなったところで期限決済できる**場合があった。

## 順行の後で利益を確保できたか

初回順行の後に元の固定利確・損切・期限を維持しながら、建値より順行側に20ptの保護床を追加した場合を測った。床はこの診断では固定し、到達した次の原行から監視する。床に触れたら1秒以上後の正常気配で返済。元IFDや期限の成立が同原行または先ならそちらが優先。「元黒字縮小」は元決済が黒字だった建玉で利益が減った件数で、黒から赤に転じた分を含む。凍結した181件における診断である。

|0.25R|135|108／27|65|95|23|68|−1,051,000円|
|0.50R|106|95／11|65|36|9|24|−399,000円|

たとえば0.90Rまで進んだ71件のうち、69件は元の出口でも黒字、65件は元の1R利確に到達した。0.90Rから20ptを確保するだけの床は、9月29日14:19の売りを元−21,077円から＋923円へ、10月7日11:05の売りを−5,077円から＋1,923円へ救った。その一方、10月6日08:56の買いは70,230で建て、10:11に360pt以上の順行に達し、10:27の押しで床返済すると＋923円。元IFDなら13:07に70,630で＋38,923円だった。0.90Rの20pt床で得た効果は買い合計−63,000円、売り＋16,000円、前24日−34,000円、後21日−13,000円で、両側を合わせた45日では赤字を2件減らす代償が大きかった。値上がりだけで即時に床を置く判断から、**固定利確を併設するか、いつ最大順行に追従して利益床を上げるか**を主比較で切り分けた。
