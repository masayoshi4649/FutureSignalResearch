# 同じ入口ならどこで切り、どこで利益を確定するか

日経199_02の既使用45デイをmini換算1枚で比較した。**W31の条件付き損切りを使う場合、午後の利確指値を置いたまま、期限前に限り可変追尾を強めるS3P3**は、元IFDに対して総損失を134,539円減らし、費用後収支を190,077円増やした。180件で全45日参加、決済不明0、保有時間率51.00%。日次・建玉の費用後中央値は27,615円・12,923円。改善幅が大きい3日を除いても元との収支差は＋51,000円だった。[条件と閾値](条件.md) ・ [全40案の実現損益](全組合せの結果.md)

### 初期の損切り

利確方法をP3で統一した比較。金額は円。費用は1往復1,077円。

|初期ライン|前24日損失|後21日損失|全45日収支|最も大きい1件損失|
|---|---:|---:|---:|---:|
|S0　全件0.75R|493,233|1,214,620|+645,677|33,077|
|S1　全件1R|432,694|869,388|+1,131,832|41,077|
|S2　全件1.10R|404,540|838,311|+1,130,371|46,077|
|S3　通常1R、11:30以降の往復時だけ1.10R|392,540|815,388|+1,210,140|45,077|

0.75Rでは一敗の深さは減った一方、後半の総損失が増えた。S3は事前に損切り幅を限定して広げているため、元IFDより1件の深い損失を許す。前24日の最大下落額はS3P3の69,231円が元の65,231円を上回った。前半24日だけで元より損失減・収支増・下落悪化なし等を求めたルールで選ばれたのはS1P3（旧M34）。

### 利確指値を置くか、追尾だけにするか

S3P3の例として、元の値幅Rが200pt、14時の買い、直前12分の効率の絶対値が0.35以下なら、損切りは建値の220pt下、利確は180pt上。60分期限なら現在の順行170ptで保護が必ず起動し、最後10分は現在90ptでも起動する。20ptまたは最大順行−160ptを床にし、期限前の失速や収縮があれば最大順行−70ptまで床を上げる。返済気配に触れた後の注文で実際の損益が決まる。15:30を越えて保有しない。

|同じS3での利確方法|総損失|費用後収支|日末最大下落額|赤字日／取得|
|---|---:|---:|---:|---:|
|P1　午前1R・午後0.90Rの指値だけ|1,218,159|+1,202,140|75,386|12／180|
|P3　P1の指値＋期限前の可変追尾|1,207,928|+1,210,140|70,386|12／180|
|P4　P3と同じ追尾だけ|1,140,389|+1,105,757|102,309|11／159|
|P5　追尾のみ、1Rに達したら0.80R以上を保護|1,213,774|+1,176,679|69,387|13／173|
|P6　P5に1.50Rの指値を追加|1,213,774|+1,217,679|69,231|13／173|

P3から利確指値だけを外したP4は、元181件の固定診断では損失同額・収支が15,000円多い。1枠を再生すると逆に収支が104,383円減った。共通153件の決済差−18,000円、P3だけの27件の収支＋155,921円、P4だけの6件＋69,538円で差を説明できた。保有率は51.00%から56.67%へ上昇しており、決済が遅いと枠を使い続ける。P4の日次赤字は11日と少ないが、日末最大下落はP3より31,923円大きい。

1Rに達してから利益を大きく戻したくない場合の比較がP5・P6。1R到達後の床を既存の床・0.80R・最大順行−0.30Rのうち最も高い位置にする。P6の1.50R指値は実口座の16件で成立し、P5と取得173件がすべて同じまま、損失同額・収支＋41,000円となった。ただしP6はP3よりも赤字日が1日増え、前24日収支＋629,379円はP3の＋697,071円より低い。P6の収支がP3を上回るのは後21日の寄与が大きい。

P3の可変追尾は、P1の静的利確と比べると全口座の改善は収支＋8,000円・総損失−10,231円。S3P3の元IFD比改善全体を追尾だけの効果にはできない。S3P3/P4/P6の追加返済遅延を5秒にすると、いずれも元IFDより損失減・収支増だったが、各口座で保護起動後に赤字になった建玉が1件生じた。
