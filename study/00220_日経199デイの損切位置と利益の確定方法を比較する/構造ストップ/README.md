# 直近の高安を損切りに使い、固定利確と追尾を入れ替えた結果

**初期損切りは元の1Rを主たる比較基準として残す。** 直近の12分安値・高値を使う候補S21は最大1件損失を41,077円から35,077円へ減らし、元IFDを上回った。一方、同じ利確ルールで損切りだけを1RからS21に替えた収支の上積みは4,846円で、後半21日は5,077円悪化した。構造水準を加工せずに採った9件だけの対照では、1Rから決済が変わった建玉は0件だった。[初回の条件](事前条件.md)・[結果を見た後の切り分け](上下限の寄与.md)

2026年9月21日〜11月20日の45デイを対象に、日経199_02の入口で、元181建玉への固定適用と、予約・保有を合計1枚に制限する口座再生を行った。全23案で全45日に参加し、費用後の損益不明は0件。買いの損切りは新規Askから下、売りは新規Bidから上。Rは元の利確・損切りの片幅。収支は日経225mini 1枚換算の円で、手数料と追加滑りを合わせて1往復1,077円を控除した。

買いの構造水準は完成済みの直近12本の1分足の安値から半ATR下、売りは同期間の高値から半ATR上。真の値幅は直前8本の平均。S21は構造水準までの距離が小さ過ぎれば0.85R、大き過ぎれば1.10Rに置く。S21を構成したのは下限138件・上限27件・履歴不足による元幅12件・範囲内の構造水準9件。採用した初期距離は127.5〜400pt、中央値297.5pt。観測は理論閾値を越えた最初の有効なラージ板によるため、返済代用価格と理論の逆指値価格は異なる場合がある。

- 10月16日12:26:02の65,620買いでは、S21の損切り幅297.5ptで65,320まで下がった際に返済し、−31,077円。元幅350ptのままのS01は期限返済で＋12,923円になった。
- 11月20日09:33:03の57,200売りでは、S21が165ptの余裕（1.10R）を持ったため57,050で利確し＋13,923円。S01は150pt逆行した時点で−16,077円の損切りだった。

S21はS01比で損失額36,692円減・収支4,846円増、日末最大下落額は6,000円増。利益後の赤字は51件から58件に増えた。改善の大きな3日を外した元IFDとの差は−35,308円、直近3日は−64,463円（元IFD−37,463円）。S21は前半の選択基準を通らず、初回20案で所定基準に適合したのはS01のみだった。S61の範囲内9件では決済原行・収支ともS01と全件一致し、追加3案の前半選択もS61。この成績から「真の高安に置いた損切りが効いた」とは判定できない。S21と3ATR対照S41の32,000円差は同じ取得の損切り8件から生じた。
