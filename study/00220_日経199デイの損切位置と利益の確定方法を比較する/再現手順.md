# 過去板から日次・注文水準を再現する

2026-11-22。Windows、Python 3.14.3、NumPy 2.5.4。元の板・当時の特徴・取得予約を[219の再現手順](../00219_日経199デイの利益保護と出口条件を比較する/再現手順.md)に従って用意する。リポジトリ直下で、元IFD・当該群の全設定について45デイの口座と元181取得固定での結果を再生する。システムのPythonにNumPyがないときは `work/複合テクニカル学習環境/Scripts/python.exe` を使用する。

```powershell
$trial = (Get-ChildItem study -Directory -Filter '00220_*').FullName
$engine = (Get-ChildItem 'study/00219*/口座再生.py').FullName
$modules = [ordered]@{
    '220主比較' = '主比較/出口条件.py'
    '220ポイント' = '絶対幅/出口条件.py'
    '220構造' = '構造ストップ/出口定義.py'
    '220構造追加' = '構造ストップ/構造の寄与を分ける.py'
    '220境界' = '経路診断/境界の出口.py'
    '220上限利確' = '利確の追試/出口条件.py'
}
foreach ($case in $modules.GetEnumerator()) {
    python -X utf8 $engine --出口定義 (Join-Path $trial $case.Value) --出力 (Join-Path work $case.Key)
    if ($LASTEXITCODE -ne 0) { throw $case.Key }
}
$books = $modules.Keys | ForEach-Object { Join-Path (Join-Path work $_) '比較元帳.json' }
python -X utf8 (Join-Path $trial '損切と利確を集計する.py') $books --閲覧 (Join-Path $trial '閲覧候補.json')
python -X utf8 (Join-Path $trial '利益保護の実例を描く.py')
```

候補別CSVは同じ表の出力器（Node.js、`@oai/artifact-tool`）に型付きの数値を渡す。次の例は、新しい作業フォルダを使って公開CSVを照合する。図にはMatplotlibを使用した。

```powershell
$deps = Join-Path $env:USERPROFILE '.cache/codex-runtimes/codex-primary-runtime/dependencies/node'
$dest = Join-Path work ('220照合_' + (Get-Date -Format 'yyyyMMdd_HHmmss_fff'))
& (Join-Path $deps 'bin/node.exe') scripts/損益CSV/候補別に出力する.mjs --input 'work/220出口集計/閲覧入力.json' --output (Join-Path $dest 'CSV') --proof (Join-Path $dest '照合') --dependencies $deps
$audit = (Get-ChildItem 'study/00219*/経路診断/出口の原行を照合する.py').FullName
python -X utf8 $audit '220ポイント/IFD' '220ポイント/B400P3' '220ポイント/B400P4' '220ポイント/B350P3' '220主比較/S3P3' '220上限利確/B400P1' '220上限利確/B400P6' --出力 (Join-Path $dest '原行照合.json')
```
