### 利確指値と追尾の役割

- B400P0から午後の指値だけを0.90RにしたB400P1で収支が69,846円増え、損失が21,077円減った。その上で、期限前の可変追尾を足したB400P3ではさらに収支が8,000円増え、損失が10,231円減った。B400P3の追尾は101件で起動し、実際に12件を決済した。
- B400P3の利確指値を外したB400P4は保有が長くなり、取得は21件減った。総損失はさらに67,539円少ないが、費用後収支も104,383円少なく、日末の最大下落は31,923円大きい。元181建玉を固定した診断だけなら、P4はP3より15,000円高く損失額は同じ。実口座との違いには後続取得の入れ替わりが含まれる。
- 利幅の延伸を狙う場合、B400P6では純追尾のB400P5と取得174件が全件一致した。1.50Rの指値を加えると損失同額・収支＋41,000円。B400P3と比較すると収支は7,539円高いが、総損失が5,846円増え、赤字日も1日増えた。直近3日の収支はP3が＋614円、P6が−2,386円。P6の増益は後21日に偏った。
- 0.85R到達で一律に少なくとも0.50R分を確保するG3は、P3と同じ181件を固定して調べると損失額は同額、収支は34,000円低かった。10月30日11:46:07の買いは＋923円から＋15,923円に改善したが、10月6日08:56:08の買いは＋38,923円から＋19,923円へ縮小。固定181件で影響を受けた建玉は増益5件、減益5件。純追尾の場合もG4はP4より固定収支が83,000円低く、増益15件・減益10件だった。守った件数だけで稼げる額は判断できない。

今回追加した7案だけで、前24日に[219の選抜規則](../../00219_日経199デイの利益保護と出口条件を比較する/閾値.md)を適用した順位はB400P2、P1、P7、P5、P6。B400P3は追加7案を計算する前から存在する対照。今後のデイへの適用は、既使用45日での後付け比較と分ける。

### 再現

[主比較の準備](../主比較/README.md)の後、リポジトリ直下で実行する。元対照のB400P0/P3/P4は前段の `work/220ポイント/比較元帳.json`、追加7案は `work/220上限利確/比較元帳.json` に出る。元と同じ181件での比較は「入口固定」、予約と保有の枠を再計算した結果は「口座再生」にある。

```powershell

```
