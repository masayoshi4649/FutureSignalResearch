# 10月5日と11月20日の板と約定を比べる

SessionTradeViewerで[一覧.resources.json](一覧.resources.json)を開く。各日に元IFD、B400P3（固定利確＋可変追尾）、B400P4（同じ条件の上限なし追尾）の3口座を収録した。日経225ラージの板の価格軸と、mini 1枚換算の建玉・損益を比較する。片道費用は手数料38.5円と追加滑り5pt＝500円。

|10月5日|4件・＋10,692円|4件・＋9,692円|4件・＋15,692円|
|11月20日|6件・＋51,538円|6件・＋61,538円|4件・＋98,692円|

10月5日08:51:03の69,790の買いは、B400P3・P4とも09:29:52に69,830で追尾返済、＋2,923円。元の60分期限まで保有した場合は09:51:04に70,060で＋25,923円だった。早く空いた枠で両候補は09:33:09に69,790でもう一度買った。2回目はP3が10:27:08に70,140の指値に届き＋33,923円、P4は10:33:22の期限に70,200で返済し＋39,923円となった。

11月20日09:00:01の57,720の売りでは、P3は09:28:23に57,320で1R利確して＋38,923円。P4は同じ入口から09:57:24に56,970で追尾返済し＋73,923円。P3が09:33の売りで−16,077円、09:35の売りで＋13,923円を計上した間、P4では最初の建玉が1枠を占有した。上限を外したときの当日差＋37,154円には、同じ売りを伸ばした＋35,000円と、後続2建玉の合計−2,154円が入れ替わった効果が含まれる。[候補ごとの全日・建玉CSV](../../../outputs/00220_日経199デイの損切と利確/README.md)

## 再現と検算

試行220のポイント上限群の元帳と公開CSVを生成してから、Viewerを起動して実行する。原板は共用フォルダのまま参照し、ディレクトリを移した場合は一覧を再生成する。照合は元帳の売買・数量・取得返済時刻・価格・費用、最後の確定残高と保有・含み損益、候補別CSVの日次収支を対象にする。[配布版の照合記録](Viewer照合.json)

```powershell
python -X utf8 (Get-Item 'study/00220*/Viewer/約定を出力する.py') --api http://127.0.0.1:8091 --csv
```
