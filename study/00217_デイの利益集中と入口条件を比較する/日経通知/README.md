# 日経の取得通知をTOPIX自身の値動きで選別する

2026-11-22。9月21日から11月20日までの45デイで、日経199_02が実際に建てた181通知を使った。**次の追加日で再確認したいのは通知03**。日経の通知と逆方向にTOPIXが既に一貫して進んでいるときだけ、新規を見送る。全45日の費用後の既知損失は565,516円から382,844円に減った。一方、収支の改善の約91%は空いた枠で後から建てた4件に依存した。

## 数値の読み方

## 判断方法と市場心理の仮説

1分足は両指数の正常な最良売買気配の中値から形成する。通知より過去の価格時計だけを使い、次の分の最初の正常板が通知より厳密に早いときに一つ前の終値を使う。値幅・経路・出来高に使う必要本数が連続しなければ、その見送り条件は成立しない。数量は、累積数量の時計が価格時計以下の行で受け取った増分。初回・逆行・飛んだ分の再基準化にかかる足は数量指標から外す。実受信刻の記録には限界がある。

- **通知03** は、直近12分の終値変化が注文と逆向きで、かつ「12分の始点と終点の価格差の絶対値 ÷ その間の1分ごとの終値変化の絶対値の合計」が0.35以上なら見送る。例えば買い通知でTOPIXが12分間に8ポイント下げ、その間の上下動の合計が20ポイントなら0.40で見送る。同じ下げでも上下動の合計が30ポイントなら0.27で通す。TOPIXにも継続的な反対売買があると、日経で反発を捉えてもTOPIXには波及しにくいという仮説を表す。
- **通知04** は、逆に、12分経路効率が0.25未満で直近3分が注文と逆なら見送る。往来の多い値動きの中で短期の逆行を避ける案。前24日（10月22日まで）のみで選ぶ場合は、両中央値下限が正、元の参加日数からの減少は1日以内、元の取引数の80%以上、保有率20%以上を満たした候補を、赤字日数、日末DD、損失額、候補IDの順に並べた。04が選ばれたが末尾3日で悪化した。通知03は前24日の取得が43件で、元の62件の80%に届かなかった。全期を見た後の有望候補としてのみ扱う。
- ほかに3分・12分の方向一致、逆方向への短期出来高増加、15分の数量加重気配中心と傾き、値幅端の過熱、日経・TOPIXの短期・中期変化の一致と乖離を比較した。例えば3分逆行＋数量増加の通知02は損失を減らしたものの、後21日の赤字日が7から9に増えた。全10案の閾値と結果は[期間別記録](期間と集中日の比較.json)にある。

## 何が損失を減らしたか

通知03で見送った元建玉45件は24勝21敗、合計−4,762.0円。新たに取れた4件は10月19日+21,416.4円、10月30日+8,916.4円、11月16日+22,166.4円、11月17日−6,083.6円で、合計+46,415.6円。共通95件は両口座で同じ経路をたどった。総収支改善+51,177.6円の大半を後続4件で説明できる。見送った元建玉には利益取引も多く、見送り条件単独の予測力と、単一枠の運用結果を分けて解釈する。
