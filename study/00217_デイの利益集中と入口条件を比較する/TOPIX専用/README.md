## どこで成績が変わったか

T26は旧条件が成立した時刻が09:00〜09:29なら、そのまま注文する。その他の時刻は、最新の公開済み1分終値を含む連続12本を取り、先頭から末尾までの実方向の変化を、11回の値動きの絶対値の合計で割る。値が0.25以上なら注文する。値動きが行き来して、進んだ距離が小さい場面では順方向の押し戻しシグナルを見送る。買い・売りは対称で、全45日で同じ式を使う。基準には5分・15分の方向持続、量、過熱・取得位置、30分との矛盾の検査がある。

全期間で同時刻・同方向だった建玉は92件で＋65,308.8円。旧だけに残る133件は合計−2,618.8円、新条件だけで取れた69件は＋81,481.6円。総収支の差＋84,100.4円の大半は、先の注文を見送った後で、旧口座で枠が埋まっていた別の受益機会を実際に取得したことによる。見送った建玉の段階で個別の大損を識別できたとは解釈できない。唯一の未参加は9月21日。旧側の要求は13:05、13:10、13:12の買い3回で、方向効率は順に−0.25、連続2本しかなく算出不可、連続4本しかなく算出不可だった。

T26の利益上位3日は11月20日＋47,998.4円、11月4日＋42,582円、11月16日＋28,082円。10月20日は＋7,999.2円。45日の最後の3日は計−11,004円。T26の純益は増えたが、初めの12日では−39,593.2円、次の12日では＋44,823.2円。期間の偏りは残る。費用後黒字建玉は92/161件（57.14%）、同幅先着は順32・逆24・未到達105件で到達済みを分母にすると57.14%。偶然同じ百分率だが、分母と数えている事象は異なる。

## 探索の経緯

- 一巡目の13口座では長短期の矛盾、RSIとMACDの同時悪化、出来高、ボリンジャーバンド、取引費用とATR、次足の回復や売買反転を検証。前24日選択T03は後21日で−31,529.6円。全45日で30分矛盾を除くT02は＋87,359.6円になったが、上位3日を外すと−103,884.8円だった。[条件と選択手順](候補と選択.md)・[13口座の結果](集計.json)
- 二巡目の9口座では源となった足の高安を終値で更新する確認を追加。全時間で確認を待つT14は−123,291.6円。9時台だけのT13は上位3日除外でも＋65,238.8円だが、前24日が−14,089.2円で、保有時間率12.10%。前24日選択T21の上位3日除外は−123,715.2円だった。方向効率を用いたT17の損失減少から三巡目へ進んだ。[二巡目の仮説](二巡目の仮説.md)・[9口座の結果](二巡目集計.json)
- 三巡目ではT17の近傍を一項目ずつ7通り調べた。12本を8本・16本に変更すると上位3日除外はそれぞれ−72,957.2円・−111,873.6円。方向効率の下限を0.15・0.35にすると−21,211.2円・−57,200円。9時台の例外の終点を09:30にしたT26は黒字、10:30にしたT27は−78,458円だった。前24日の全日参加を満たす候補がなく、この巡の前24日選択は空欄。特定の時刻・本数に感応する結果なので、今後は設定を固定して追加デイを評価する。[近傍の仮説](近傍の仮説.md)・[7口座の結果](三巡目集計.json)

## 価格と再現

建玉はミニTOPIX1枚相当。ラージの実側の最良気配で約定を代用し、手数料83.6円・想定追加滑り500円を往復ごとに控除する。単純IFDは源の5分ATR×2.5を5〜25ptに収め、0.25pt刻みに切り上げた上下同幅。60分以内に未到達なら時間決済、15:29に引け決済要求を出し15:30までに手仕舞う。予約・保有中の追加は禁止。保有時間率の分母は各日08:45〜15:30の合計。派生候補を含め各日を初めから再注文した。T00は既存225建玉の方向、注文・取得決済時刻、取得・決済価格、幅、先着、費用後収支、確認済み保有終点が一致した。

2026年11月22日確認。デイは9月21日〜11月20日の45日。既使用の全45日に対する探索であり、三巡・計29口座に多重探索の影響がある。前後区分の選択結果は各巡の条件が決まった後の擬似過去順評価に限る。

リポジトリ直下でPython 3.14、NumPy、tzdataを用いる。作業領域の旧ソース・原順入力が失われた場合も下記で再生成できる。1つ目のコマンドは16件を正式アーカイブのSHA256で照合し、欠けている部品だけを元の位置に展開する。2つ目のブロックは216の追加原順8列と特徴が不足するときだけ、共有原板から形成し直す。216の形成器は旧83場の時系列を使って指標履歴を引き継ぐ。金額を再度読むだけなら、各巡の結果と候補別CSVが利用できる。

```powershell

$tp='study/00217_デイの利益集中と入口条件を比較する/TOPIX専用'
$src='study/00216_十一月二十日の固定入口と寄り前の反例を検証する/TOPIX専用'
python "$tp/再現部品を準備する.py"
if (!(Test-Path 'work/216TOPIX専用/純特徴184直接.json.gz') -or
    (Get-ChildItem 'work/216TOPIX専用/原順8列' -Filter '*Day.npz' -ErrorAction SilentlyContinue).Count -ne 3 -or
    (Get-ChildItem 'work/216TOPIX専用/原順8列' -Filter '*Day.json' -ErrorAction SilentlyContinue).Count -ne 3) {
    python "$src/履歴を形成する.py"
}
python "$tp/デイを再生する.py"
python "$tp/回復確認を再生する.py"

```
