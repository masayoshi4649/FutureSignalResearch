- **10月20日 11:56～13:07**　元の日経は11:56:04の売りが+33,923円。NK10ではこの売りを見送った後、12:11:11の買いに回って−36,077円となった。他の4建玉は共通で、この入れ替わりが当日の差額−70,000円を説明する。
- **11月19日 11:56～14:17**　元の日経は11:56からの3建玉が+33,923円、−36,077円、−15,077円。NK10は同時間帯に12:08からの買いが+33,923円、12:49からの売りが+923円。ほかの4建玉は共通で、当日の差額は+52,077円。
- **11月16日 09:11～10:26**　元のTOPIX口座は09:11:03の買いを10:11:04まで保有して−7,583.6円。通知03は見送り、09:58:05に売りを建てて+22,166.4円になった。さらに12:58:07の+4,916.4円の売りも見送ったため、日全体の差額は+24,833.6円。

## 費用と照合

日経225miniの1ポイントを100円とし、新規・返済それぞれに手数料38.5円と想定滑り5ポイント相当500円を計上した。ミニTOPIX先物の1ポイントは1,000円、各片の手数料41.8円と想定滑り0.25ポイント相当250円を計上した。約定代用にはラージの買い・売り側の気配を使う。

試行215の変換器、216のAPI照合器を再利用した。候補別の日次CSV、元帳、配布版Viewer数値APIで6表示・計30建玉・60約定片を照合済み。全片の時刻、価格、数量、売買、手法ID、建玉ID、費用後の実現損益増減が一致した。すべての表示で引けの買い残、売り残、含み損益はゼロ。[配布版のSHA256と表示別の照合結果](Viewer照合.json)

## 再現

研究ルートで[日経の再生](../日経/README.md)と[通知の再生](../日経通知/README.md)を行い、[試行217の候補別CSV](../../../outputs/00217_デイ入口の利益集中と安定性/README.md)を作成してから実行する。既存の正式資料は `work/` の元帳を再形成せずに閲覧できる。配布版の既定ポートは8091で、起動中のViewerに合わせて変更できる。配布版に接続せず一覧と約定片だけを再生成する場合は `--api` を省略する。

```powershell
$env:PYTHONUTF8='1'
$exe='work/複合テクニカル学習環境/Scripts/python.exe'
$dir='study/00217_デイの利益集中と入口条件を比較する/Viewer'
& $exe "$dir/約定を出力する.py" --api http://127.0.0.1:8091
```
