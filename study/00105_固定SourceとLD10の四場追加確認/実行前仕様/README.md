## 新4場の時計とSource

完全Observationは既存の二市場原板と確定1/5分足から生成する。Source側のCSV1/5分足と、独立チャートの原行Last→3/15分足集約を混同しない。主運転はGateなしであり、今回新しい3/15分チャートの種やOHLC拡張を追加しない。

新しいSession/5分予定だけを持つClockCarrierを使い、既存continuous producerの全board時計（TOPIX/Last0を含む）で新Scalar11・Force・実観測gridを形成する。旧54Tapeの価格やgridを別日へ移さない。SourceRecordだけから全boardのgridを推測せず、時刻Atだけで結合しない。

新legacy基準Tapeをfresh Scalar/全board制御時計と新legacyのmini全公開Deltaから組み立て、Binderでlegacy/default/symmetricを順に照合する。FeaturesIndex・物理行・Scalar11全値・active method順・Force直前Line・空通知・Targets/Closes.Beforeを保つ。P終了後も空Stepを保ち、U切替と同秒Force→grid→rawを維持する。EOF以後へ未観測gridや気配を補わない。

legacy/defaultの新しい相互同値は、旧93市場golden同値や技法の有効性と別である。新4場には旧103金融goldenもなく、人工の互換成功を市場golden成功欄へ流用しない。Sourceの自然形成、時計/通知結合、主金融、保存検算の段階を分けて固定する。

## 売買・保護・費用は104と同じ

- 新規は元通知のstrict次5分一枠のB5Q。セッション開始30分は見送り、末尾30分を新たに除外しない。再参加や15秒age/60秒TTLを追加しない。
- デイ09:15〜15:30の76枠、ナイト17:30〜翌05:45の148枠、4場の主分母は448。元Forceは15:35/翌05:50。米国開始前後各15分の静観と個別P締切を分母へ残す。米国開始は既存の暦/夏時間による場時計を使い、旧9〜10月の時刻をコピーしない。
- 副表は開始/末尾30分を除く432枠。全予定grid480と主448/副432、実観測EOFの不足は区別する。未観測や判定不能を分母から勝手に落とさない。
- 参加分子は、同枠で受理して同じ[t,t+300)に実取得した枠と、grid時点で実保有する枠の和集合。同時多玉/両建てでも1枠。受理のみ・遅いFill・当時保有・欠測を分離する。全体最低25%、目標50%を維持し、日夜別も示す。
- LD10は現在残枚数1枚の費用後含み益u円が `100*max(10,ATRLock.Value)` 以上なら起動。元5分ATR12の未丸めValueを取得時または初回既知で一度固定し、未知ATRは保留。起動前も元Source損失管理/Forceを維持。
- 起動後は最低名目建値、固定幅 `5*ceil(2*Value/5)`、不利に緩めない。定時外も連続評価。保護発動価格での約定や費用後黒字を保証する条件ではない。
- 点価100円/pt、税込38.5円/枚片道。正常ラージBBOのstrict後行、D1は追加1価格秒。仮定滑りC5は片道5ptを費用として一度控除し、spreadを二重控除しない。mini固有板/実測滑りとは区別する。

## 評価と判定

費用後実現純額・全正負額・PF・保存点時価DD・取引枚数/回数、u正益後とLD起動後の最終赤字を別分母で報告する。セッション・開始日・日夜・売買方向を区分し、費用/遅延4設定を独立市場標本としない。未参加や退出後の仮想利益、機会損失、MFE回収率、元手未指定ROIは算出しない。

品質・先読み・所有・約定・費用・終了残予約0・入力前後不変を先に確認する。4感度の純額、全体最低25%/目標50%と日夜の参加をそのまま評価し、条件を緩めない。新4場は小標本であり、黒字でも未知期間の安定性を全面証明したとはしない。赤字/参加不足なら結果を残し、差を説明する技法条件を次の別試行で調べる。従来70%・125/250先着の合格判定は最新指示に従い一旦適用しない。
