# 米国開始付近の時計の誤記訂正

2026-11-09、入力固定後・Source先頭2場の再生中、主LD10金融の実行前にコードの静的確認で判明した。入力や損益に応じた条件変更ではない。実行前仕様の原本は書き換えず、本補足と現README・K05を主金融条件へ固定する。

実行前仕様の「米国開始前後各15分の静観」は、Sourceの運用時刻とActualの新規静観を混同した記載だった。今回の事前指定は**103/104のActorとB5Qを変更せず再用すること**であり、実コードの以下の時刻を維持する。

|対象|既存コードの規則|今回のNightでの日本時間|
|---|---|---|
|米国開始U|ニューヨーク現地当日09:30。既存タイムゾーン暦を使用|2026-11-05・06とも23:30|
|Actualの新規静観|`U <= grid < U+1800秒`|23:30以上、翌00:00未満|
|SourceのP強制終了|`U−900秒`|23:15|
|SourceのU口を開始|`U+900秒`|23:45|

Pの終了やU口の開始は、Actual静観時間を前後15分へ変更する規則ではない。保有を含む参加率の主分母448、副432、全予定grid480は変更しない。静観枠も分母へ残す。旧9〜10月の22:30を11月へコピーしない。

根拠は [Actual gridQuiet](../../work/103多玉の保護会計/entry_grid.go) の `inside := at >= b.result.Config.USOpen && at < b.result.Config.USOpen+1800`、同ファイルのP取得締切、[Source再生](../../work/104Source再生の接続準備/replay.go) のtimerとU口生成、[USOpen](../../scripts/FAR元三手法のmini連続再現/input.go) のNY09:30変換である。105時計口の `TestNovemberDSTClock` でも11月5・6日の各4冊・6境界枠を人工確認する。

原本に誤記があることを隠さず、コードと主金融前の訂正の両方を保存する。固定済み103/104の正式文書・結果・コードは本訂正に合わせて変更しない。
