## 寄り前の仮説と、利益が残らなかった建玉

11月20日に寄り前に入ったTOPIX移植03の注文は**売り**。08:58:00の判断直前、日経の取得側気配は5分EMA8から売り方向へ1.036 ATRで、前回定めた範囲内だった。08:58:09に3,745.0で売り、09:23:31には返済気配が3,764.0まで上昇。損切りまであと1ptから下げに転じ、09:40:11に3,725.0で利確した。11月19日の「買い・日経が1.5 ATR超」とは別の条件に属する。通常日の寄り前買いは引き続き1勝7敗。寄り前LCの直前の日経が範囲内だった群は3勝3敗から4勝3敗、上限超過群は2勝3敗のまま。日経自身の初回売りは09:00:00判断、09:00:01取得で、寄り前の件数には含めなかった。[日経の当時位置と全11建玉の原板照合](朝の診断/README.md)

日経の10:56の売りは、11:49:53に返済側気配で230pt順行し、当時の費用後評価は＋21,923円だった。固定IFDの期限決済は11:56:04で、10pt順行に縮み、往復費用1,077円を引くと−77円だった。TOPIX移植03の09:41の売りも最高評価＋1,416.4円から−8,083.6円で損切りとなった。ともに保有中の利益を失った実例。別の追尾で実現した利益としては加算していない。[原行別の最高・最低評価と到達時刻](朝の診断/建玉の照合.json)

同時刻・同方向・同一呼値数で両指数を観測した診断では、TOPIXでの日経由来6件が平均＋0.006幅、TOPIX自身由来5件が＋0.310幅。通知から実際にTOPIXを建てる口座は、価格比で幅を固定し、保有中の通知を棄却する別計算。日経からの6通知のうち4件を取得して＋44,165.6円だった。[固定通知と同期比較の明細](通知と同期の結果.json)
