2026年11月21日確認。11月20日デイの寄り前は、TOPIXの短期回復入口（LC）からの売り1件だった。3,745.0で売り、19pt逆行した後、3,725.0で利確。miniTOPIX 1枚で費用後＋19,416.4円。日経199_02も現物寄り付き直後に売って利確した。日経の判断は09:00:00、取得は09:00:01のため、寄り前には数えない。[取得・決済原行と価格](建玉の照合.json)

## 朝の判別条件との照合

TOPIXの08:58:00の売り判断より厳密に前の90秒で、最後に利用できた日経の判断は08:57:01だった。日経の取得側気配は5分足の8期間指数移動平均から売り方向へ1.036 ATR離れ、前回の許容範囲（−2～＋1.5）に収まっていた。TOPIXは08:58:09に売り建てた。09:23:31には返済に使う最良売り気配が3,764.0となり、20ptの損切りまで残り1pt。その後売り方向へ進み、09:40:11に利確した。これは全保有時間の正常な返済側気配で確認した最大逆行である。

この売りは直近日経の位置が範囲内だった寄り前LCの新しい1勝で、旧42日の3勝3敗から追加3日込みで4勝3敗になった。1.5 ATR超の群は11月19日を加えた2勝3敗、位置算出不能群は0勝4敗のまま。現物営業日の朝の買いも引き続き1勝7敗。11月20日はこれら3群への追加観測がない。[試行214の旧42日](../../00214_日経とTOPIXで入口の成績が分かれる理由/入口の診断/README.md)・[試行215の11月19日](../../00215_追加デイで日経とTOPIXの固定入口を再検証する/朝の診断/README.md)

## 利益が一度出て赤字で決済した建玉
