# 11月20日開始のデイ・ナイトをSessionTradeViewerで見る

SessionTradeViewerで[一覧.resources.json](一覧.resources.json)を開く。デイ4口座・ナイト2口座を選択できる。各建玉は実側気配で代用した取得・決済の2つの約定片で表示する。手数料と想定滑りは新規と返済の各片に日経538.5円、TOPIX291.8円を配分した。原板は `../JP_OSE_Data/future` の共用ラージ板を参照する。

|表示|建玉|費用後収支|
|---|---:|---:|
|デイ 日経199_02|6|＋51,538円|
|デイ TOPIX移植03|5|＋31,582円|
|デイ 日経通知でTOPIX|4|＋44,165.6円|
|デイ TOPIX専用212主6|6|＋56,998.4円|
|ナイト 日経199_02|6|−66,462円|
|ナイト TOPIX専用212主6|13|＋74,913.2円|

配布版Viewerの数値APIで6口座40建玉の全80約定片の時刻・売買・数量・価格・建玉と手法の識別子・費用後の損益増減を台帳と照合した。全表示で場末は売買残ゼロ・含み損益ゼロ。11月17日開始の日経ナイトの不明決済1件はこの11月20日専用表示の対象外。[照合結果](Viewer照合.json)

## 再現

Python 3.14.3を使用。リポジトリ直下でこのフォルダの[約定を出力する.py](約定を出力する.py)を実行する。絶対参照を更新するため、リポジトリや共有データの置き場所を移した場合も同じ方法で再生成する。APIの照合は、起動したViewerのポート番号に合わせて `--api http://127.0.0.1:8091` を追加する。使用した配布版実行ファイルは `../SessionTradeViewer/dist/windows-amd64/SessionTradeViewer/session-trade-viewer.exe`、SHA256は `0ed329e06293f55a99ab1dc503e32cc104285319316ef41b81b59470dce9d0e8`。
