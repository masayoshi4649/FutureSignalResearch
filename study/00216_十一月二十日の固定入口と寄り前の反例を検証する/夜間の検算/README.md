## 日経の返済価格が確定しなかった1件

11月17日ナイトの売りは翌18日02:39:12、58,690円で取得。順逆幅300円に届く前に120分の期限を迎えた。期限04:39:12から猶予末04:39:42まで、返済の最良売り気配を読める正常板は0件。最後は04:38:47、次は04:40:49で、期限後の最初の正常板は猶予に67秒遅れた。値動きと保有が確定した終点は04:38:47とし、収支は未知のまま保持した。同夜の−23,231円は他の3件の合計である。

## 11月20日ナイトの損失の集中

日経は米国寄り前が1勝1敗、＋7,846円。米国寄り後は4件とも売りで1勝3敗、−74,308円。特に翌21日02:53:03、03:31:01、03:46:01の3件はいずれも買い戻し時の最良売り気配が逆行幅（300、350、350円）に達し、3件で−103,231円だった。その後04:06:21の売りは、先に順行300円へ到達して＋28,923円を回収した。

3敗のうち、02:53の売りは一時100円順行し、往復費用控除後の最高評価は＋8,923円。03:46の売りも20円順行して＋923円まで達した。03:31の売りは最大10円順行で、最高評価でも−77円。損切りに至った売りの中に、わずかでも費用後の利益が出たものと、最後まで赤字だったものの両方がある。最高評価での決済・利益保護ルールの収益は算入していない。

## 再現

日経は215の原板独立検算の線形走査をナイトの時間へ合わせ、取得価格・物理行・時計・正常板条件を確認してから、各建玉の次の原行以降を返済側で走査する。TOPIX専用は両側数量1枚以上、正常板、価格時計の高水位を原板から抽出し、212保存版の独立線形核を使って通知の翌秒から取得を再計算した。TOPIXは利確の接触時は指値、損切りと期限は要求翌秒以降の実側気配を使用する。検算範囲は元帳に記録された取引で、各入口の発火・保有中予約の優先順位は元の固定再生が担当している。[検算コード](追加場の実側を検算する.py)・[212の独立確認](../../00212_デイとナイトの見送りとnative入口を同じ口座で比較する/独立確認の再現.md)
