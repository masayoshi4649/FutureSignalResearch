## 再現方法

[試行213の入力復元手順](../../../inputs/00213_日経型TOPIXの純入口/README.md)に従って旧85場の換算索引、Go生成器、Python部品を復元する。リポジトリ直下からNumPyを導入したPythonで次を実行する。試行時はPython 3.14.3・NumPy 2.5.4。元の原板・確定足は `../JP_OSE_Data/future/TOPIX` にある。

```powershell
$env:PYTHONUTF8='1'
python 'study/00215_追加デイで日経とTOPIXの固定入口を再検証する/TOPIX/固定入口を再生する.py'
```

旧85場に11月18日ナイト・11月19日デイを足した87場を同じ順で処理した。ナイトは確定足の履歴に使用。100特徴にはラージの元価格と分足OHLCを20倍した表記を使い、金融再生は元価格・決済幅0.05倍。1ptは1,000円。ラージの反対側気配で取引を代用した上でminiの手数料片道41.8円と追加滑り片道0.25ptを引く。実口座の約定ではない。

[再生コード](固定入口を再生する.py)は試行213の保存ソース115ファイルと金融再生部品の指紋を検査し、旧85場43,627判断の固定入口全16列が213の保存入力と一致することを確かめる。11月18日デイの5建玉（−23,418円）と予約・取引監査が213の金融正本と全属性で一致。追加2場の原板と1分・5分足、元値索引のサイズ・SHA256、取得に使った全原行番号は[固定照合](固定照合.json)に記録した。追加日の原板では時刻不正1,881行・場外6行を除外し、144,614行を取り込んだ。
