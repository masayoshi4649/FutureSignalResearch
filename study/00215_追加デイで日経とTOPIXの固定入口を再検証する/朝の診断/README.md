## 入力と再現

リポジトリ直下で、このフォルダの `原板で追加日を照合する.py --取引` をPythonで実行する。`--取引`を外すと両指数の原板だけで端点と相関を再生成する。入力は共用の`../JP_OSE_Data/future/{NK225,TOPIX}/2026-11-19_Day/book.jsonl`、215の日経・TOPIXの各固定結果、日経の再生で生成する`work/215日経/母集団/当時特徴.json.gz`。[照合コード](原板で追加日を照合する.py)

現物日報の照合は同じフォルダの `東証日報を照合する.py` をPyMuPDF 1.28.2で実行する。抽出には214と同じ午前欄の読取関数を用いる。[現物照合コード](東証日報を照合する.py)

5分窓は214と同じ価格時計を使う。開始だけは08:45以降最初、それ以外は境界より厳密に前の正常な最良売買気配を使い、端点の鮮度は30秒以内、正常気配の区間内の空白は300秒以下とした。取引は日経7件・TOPIX3件について、取引元帳の建値と物理行を出発点とし、同じ商品の元の原板を読み直した。買建玉は最良買い、売建玉は最良売り気配で、利確・損切りの先着、期限、終了前の決済を独立に走査した。10件すべてで取得・決済の物理行と価格、先着区分、費用後損益が一致した。原板はラージ商品であり、miniの約定は代用である。
