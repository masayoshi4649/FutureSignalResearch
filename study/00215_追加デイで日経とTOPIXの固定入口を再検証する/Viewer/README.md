# 11月19日デイをSessionTradeViewerで開く

SessionTradeViewerを起動し、画面の一覧ファイルの選択で[一覧.resources.json](一覧.resources.json)を開く。日経199_02、TOPIX移植03、日経通知でTOPIXの3口座を切り替えられる。各線の約定時刻・数量・建玉方向・原板行は、固定口座の約定に対応する。

日経は1ポイント100円、TOPIXは1ポイント1,000円。各取引1枚で、約定価格はラージの実側気配による代用価格を保存している。確定損益表示には各片で手数料と想定滑りを引いた。日経は片道38.5＋500＝538.5円、TOPIXは片道41.8＋250＝291.8円。配布版Viewerの数値APIで全30約定片を数え、各口座の最終確定損益、買残・売残・含みが元台帳と一致することを確認した。[照合結果](Viewer照合.json)

## 再現

一覧は原板とこのフォルダの絶対位置を保持する。リポジトリを移設したら、リポジトリ直下で次のコマンドを実行して参照を更新できる。[出力と照合のコード](約定を出力する.py)

```powershell
python 'study/00215_追加デイで日経とTOPIXの固定入口を再検証する/Viewer/約定を出力する.py'
```

Viewer起動後、同じコマンドに `--api http://127.0.0.1:8091` を付けると、実際の数値APIと照合して結果を保存する。ポートを変更している場合は起動先の番号を使う。今回の実行には `../SessionTradeViewer/dist/windows-amd64/SessionTradeViewer/session-trade-viewer.exe` のコピーを使用した。SHA256は `0ed329e06293f55a99ab1dc503e32cc104285319316ef41b81b59470dce9d0e8`。
