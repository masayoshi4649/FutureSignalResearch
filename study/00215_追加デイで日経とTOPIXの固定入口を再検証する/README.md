## 前回の朝の仮説はどうなったか

11月19日の08:59:02にTOPIXが買いを判断した。56秒前に利用できた日経の買い側気配は、5分足EMA8より上に**2.188 ATR**離れていた。214で調べた追いかけ過ぎの上限1.5を超える。TOPIXは08:59:05に3,812.5で買い、09:00:11には返済側の最良買い気配が3,797.5まで下がった。20ptの損切りまで残り5pt。09:15直前も建値を1pt下回っていたが、その後は持ち直し、13:01:40に3,832.5で利確した。4時間2分35秒の保有で＋19,416.4円だった。[限定時刻と原板による照合](朝の診断/README.md)

旧42デイで、現物営業日のTOPIXの寄り前買いは0勝7敗。11月18日は該当なし、19日を加えると**1勝7敗**となった。売買とも含め、寄り前の短期回復入口の直前90秒に日経が1.5 ATRを超えていた群は、旧1勝3敗から**2勝3敗**になった。この日、日経の位置を算出できなかった群には取引がなく、同群についての情報は増えていない。日経の上限超えだけで機械的に見送れば、今回の利益取引も棄却される。見送りを導入した口座では後続の注文も変わり得るため、当日の純損益への効果は未算出。[214の比較対象](../00214_日経とTOPIXで入口の成績が分かれる理由/入口の診断/README.md)

両指数とも08:45から09:00直前までは下落し、その後09:15直前までに日経は60円、TOPIXは3.25pt反発した。同期した5分騰落率の相関は日中0.902（79/81窓）。それでもTOPIXの朝の取得に日経の取得は伴わず、同方向へ動く市場でも手法が入る時刻は異なった。[原板の端点](朝の診断/価格.json)

東証日報でも前場始値から終値まで日経連動ETF（1321）は＋0.081%、TOPIX連動ETF（1306）は＋0.200%と、どちらもTOPIXの買いと同方向だった。アドバンテストは＋0.075%、東京エレクトロンは−0.374%で2社の方向は分かれた。日経の寄り前注文が0件だったため、214で観測した「日経が選んだ朝と半導体株の方向一致」はこの日に評価できない。日報確認日は11月20日。[日別の抽出値](朝の診断/東証の前場.json)・[東証11月19日日報](https://www.jpx.co.jp/automation/markets/statistics-equities/daily/files/202611/stq_20261119.pdf)

## 日経の判断をTOPIXへ移せば良かったか

213で作成した別口座では、日経の実取得7通知からTOPIXで5件を取得した。2通知は保有中だった。5件すべてで設定幅へ届かず、1勝4敗で−29,918円。11月18日も同じ手順で初めて通知口座を再生すると−30,334.4円で、追加2日はともに赤字だった。[通知ごとの採否と決済](通知と同期の結果.json)

同じ呼値数の価格経路でも確認した。通知の翌秒以降に両商品を同時照会し、元の期限まで確定した建玉の「費用後損益÷設定幅の円相当額」を平均した。日経が選んだ時刻・方向の7件は日経−0.103幅、TOPIX−0.339幅。TOPIXが選んだ3件は日経＋0.018幅、TOPIX＋0.092幅。追加日では両商品とも、どちらの指数が選んだ場面の成績が高いかが旧42日の順序と逆になった。これは7組・3組に限った個別観測で、同じ板を使う重複した損益を一つの口座には加えていない。

## 入力・費用・再現手順

- 共用原板は `../JP_OSE_Data/future/{NK225,TOPIX}`。基準通り11月18日ナイトを当時特徴の履歴へ加えた。原板と分足の指紋は各商品の固定結果に収録。11月19日ナイトはデイ入口の評価対象外。ラージ板の価格時計で約定を代用し、日経は片道手数料38.5円と5ptの追加滑り、TOPIXは41.8円と0.25ptの追加滑りを控除した。

- このフォルダの [通知・同期比較](通知と同期を比較する.py)と[日別集計](日別に集計する.py)を順に実行する。通知の採否と全約定は旧11月17日に照合し、追加日は線形走査と211の区間木で決済属性を照合した。実行環境はWindows、Python 3.14.3、NumPy 2.5.4。
- CSVは上で生成した `work/215閲覧/型付き入力.json` を[既存のCSV出力器](../../scripts/損益CSV/候補別に出力する.mjs)に `--input` で渡し、`--output` と `--proof` に新しい出力先、`--dependencies` にartifact-toolがあるNode依存ルートを指定する。各手法の全44日に0取引場も含め、旧結果の履歴も保持する。
