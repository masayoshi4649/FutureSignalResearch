## 足・量・継承

- 既採用Rawの物理順に観測し、価格時計が足終へ初めて進んだ原行で、現在行を次足へ入れる前に5分足を確定する。公表Stampはその原行で、名目足終へ配送を遡らせない。15/30分は既知の5分足を集約する。
- 主は観測価格時計gap300秒。空窓・品質不明は未知とし、EOFで時計を進めず形成中足を完成させない。gap60は品質可用性の対照で、勝敗によって主を選び直さない。
- 量は観測した累積数量の増分を現在行へ割り当てる代理値。最初の基準・減少・無効等は未知。取引所の真のバー数量や成行方向の約定量ではない。
- 初場cold。固定順序の直前場を完全走査し、SHA・stat・全品質照合が成功した同限月だけ数値/BB/RVOL窓を継承する。足形成・構造・公表・数量基準は場ごとにreset。週末等へ架空足を挿入せず、限月変更はcold。場間TR等は元数値式の通り。途中失敗時は停止する。
- 受信時刻・sequenceが無いため価格時計の因果モデルであり、実通信遅延の実測ではない。旧CSV由来とOHLC・量・助走も異なり、単なる60秒前倒しの比較とはしない。

同じgap300の確定値をEnd+60秒以降の最初の採用Rawまで保留する対照を事前に固定して実行した。値を未来から借りず、EOF未配送は未配送のまま。主は即時gap300で固定し、保留対照の成績で主を交換しない。
