# 試行00011：順行と反転のチャート構造と利益回収

計画日：2026-11-04。状態：実装・合成検証後、結果前に固定して実行する。[設計資料](../../docs/議論/順行と反転の利益回収をどう分けるか.md)の24案を固定し、00010の低幅利益床で黒字取引率が上がっても費用後損益が改善しなかった反例を踏まえ、入口構造と役割別の通常出口を比較する。新しい閾値を結果後に追加しない。

## 1. 範囲と分母

NK225の65場はすべて使用済み。学習40場・条件選択24場・既使用11/4デイ1場を別掲する。内部キーの「後続検査」は本試行では新しい未見確認を意味しない。原板・cacheは00008の入力台帳をSHA付きで参照し、原板を複製しない。

主目標は**逆行125pt以上より先の順行250pt以上**。入口は8種類であり、同一入口のX0/X1/X2へ同じ先着集約を表示しても24種類の独立した入口実験とは数えない。入口ラベルは一建玉の抑止や通常出口と独立した仮想入口で、保有の重複を許す。運用の小利確による黒字率70%を、入口先着率70%へ読み替えない。

## 2. 足と共通準備

3分・5分の発動足と確定15分足を使う。同じ足幅の4系統は、現在のEMA20・Wilder ATR14>0・Wilder ADX14・BB20の平均と母標準偏差、および同場で1本以上確定した準備済み15分EMA20とその前値を利用できる共通時点で比較する。全4系統に同場の直前6本連続足も要求する。3分と5分の発動数の違いと準備不足を記録する。

LastのOHLCをセッション起点の半開区間で作る。足終了後に確認できた原行で判断し、15分も足終了時刻・確認時計・原行が判断時点以下の最後の足だけを使う。15分未準備を中立へ置かない。EMAのSMA初期化、Wilder14、BB20母標準偏差、同限月履歴継続、欠枠・限月変更・前場尾部欠枠の初期化は00006/00008を引き継ぐ。価格窓と再テスト登録は場を跨がず、欠足でリセットする。

## 3. 4入口×2足幅

以下は買い。売りは価格の上下・高安・不等号を対称化する。C/H/Lは確定終値/高値/安値、EはEMA20、MはSMA20。上位買い方向は利用可能な確定15分で `C15 > E15 > 前E15`。売りは反対、それ以外は準備済み中立。

| 系統 | 買い発動 |
| --- | --- |
| T1 押し目再開 | 前・現の発動時点で上位買い方向を保持。`前C≤前E`、`今C>今E>前E`、`今C>前C` |
| T2 突破後再テスト | 前1〜3本内の最新の突破登録Rへ、今足安値が`R±5pt`内まで戻り、`今C>R+5pt`。現時点の上位方向が買い |
| R1 端の失敗突破 | 当足を除く直前6本の安値Q・高値Rに対し`L<Q<C≤R`、`今C>前C`、ADX14<20、`今M>今C` |
| R2 BB内復帰 | `前C<前下帯`、`今下帯≤今C<今M`、`今C>前C`、ADX14<20。BB20・母標準偏差2倍 |

入口IDは`3分_T1`等の8種類。RSI、BB2.5倍、数量、他の時間足、中心までの追加距離フィルタを足さない。中心距離、250ptのATR倍、残り時間は記述用で、結果の良い層を新しい条件にしない。

T2は各確定足jで、その足を除く直前6本最高値Rを先に固定し、`Cj>R`なら登録する。売りは直前6本最安値の下抜け。登録自体は共通指標準備前でも6本窓が揃えば保持するが、発動には共通準備と上位方向を要求する。既存登録に対して当足の満了（j+3を過ぎた）・終値失効（買C≤R）を先に判定し、j+1〜j+3の再テストを判定する。発動した登録は約定成否によらず消費し、再使用しない。最後に当足の新しい突破を登録し、この足自身の再テストに使わない。複数登録は最新だけを保持する。現在足で失効と発動が重なれば失効優先。

## 4. 3出口との運用比較

各入口にX0/X1/X2を付け24運用候補とする。ATR_eとSMA20中心は入口判断時の確定足から保存し、将来値へ差し替えない。

| 出口 | 順行T1/T2 | 反転R1/R2 |
| --- | --- | --- |
| X0 | TP250pt/SL125pt・期限 | 同左 |
| X1 | TP250なし。保有後に公開された同尺度確定終値がEMA20の反対側**または等号**で返済要求。SL125・期限 | TP250なし。入口判断時SMA20を固定目標とし返済側気配が到達したら返済要求。SL125・期限 |
| X2 | X1＋実新規以後の最高/最低返済側BBOから2ATR_eの単調追尾 | X1＋返済側1ATR_e順行を観測した後、0.5ATR_e順行の固定利益床 |

順行追尾は買いで `max(旧保護線, P−125, 建玉後最高Bid−2ATR_e)`、売りは最低Askとmin。反転の床も初期125pt保護より緩めず、買max/売minとする。5pt刻みへ買い保護線は下丸め、売りは上丸め。順行X2には追加の起動MFE条件を設けず、建玉後観測だけから更新する。

反転の実新規が固定中心へ到達または越えていれば、新規した原行の監視で返済要求し、その件数を記録する。入口をなかったことにせず、返済は1秒以上待つ。中心を遠ざけない。反転へ00010の構造失効線を追加せず、通常目標と非常保護・期限だけを使う。

通常出口は入口を作った足・未確定足・確認遅延30秒超の足を使わない。気配・確定足・新規合図は原行順と同一原行内の優先を保持する。期限、既存待機の約定、初期保護、追加出口の優先は運用コードで固定する。すでに出した成行返済要求を後の根拠で遅らせたり取り消したりしない。

## 5. 先着ラベルと執行

要求から1価格時計秒以上・30秒以内、新規停止15:25/翌05:40未満、判断時に期限まで60分以上、足確認遅延30秒以内を要求する。入口の新規は買Ask/売Bid、追跡は買Bid/売Ask。逆行125pt以下が先なら逆行先着、順行250pt以上が先なら順行先着。期限15:35/翌05:50の等号を含み、どちらもなければ期限未達。正常板300秒超の空白が先、または期限前EOF不足なら観測不足。成功後の逆行でラベルを書き換えない。

主率は順行先着/全約定。期限未達と観測不足も分母へ含み、未約定を別記する。同じ場・要求時計・方向の先着は一回計算して共有し、将来ラベルを運用のsignalsへ渡さない。約定独立の入口集合と、一建玉の新規抑止後の集合を混同しない。

NK225micro1枚をラージBBOで代理し、倍率10円/pt、呼値5pt。片道手数料11円は比較仮定。片道追加5/10ptは同じ完結往復から100/200円を控除する感度で、価格変更後の再参加再計算ではない。返済要求後1価格時計秒以上の最初の正常BBOを使う。CurrentPriceTimeは受信時計ではなく、1秒は実通信遅延の実測値ではない。追尾と床は逐次ソフト監視の模型であり、実際の逆指値訂正・受付の再現ではない。

## 6. 支持・評価・表示代表

入口支持と70%判定、30分間引き、費用支持の件数・日数・活動場・買売下限は00008を引き継ぎ条件JSONへ固定する。入口70%は8入口単位で数え、出口3案で水増ししない。費用資格は24運用それぞれ旧二期間で支持、品質注意0、追加5pt後純損益正を要求する。これは探索上の規則で、採用確定を意味しない。

運用純損益0/5/10pt、黒字取引数、活動/無取引、保有率、MFE20/50/100および1ATR到達後赤字化、床の起動前損益、期間内で最大の一場の含み込みDD、品質・EOF・未解消を記録する。異なる保有長のMFEを同じ将来窓とはしない。共通の実新規（イベントID/時計/原行/価格一致）の差と、元のみ/変更のみ新規の件数・純額も分ける。空白注意のある全体を確定収益としない。

正式約定の表示対象は各8入口のX0と、旧学習/条件選択の追加5pt後1取引平均の低い方が最大の一出口、同値ID順。11/4一場を順位に使わず、代表表示を採用と呼ばない。結果を見て候補を追加・閾値を調整する場合は別試行へ進む。
