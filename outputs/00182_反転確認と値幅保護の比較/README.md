## 数値の読み方

- 対象は全81場（デイ41・ナイト40）、2026-09-21〜11-16。全て既使用の診断結果です。0取引場も残しています。
- 金額は**mini1枚**、1pt100円、片道手数料38.5円＋追加滑り5pt、実BBO価格差を反映した費用後円。ラージ1枚・mini10枚の損益ではありません。買売合計保有・予約1件で追加禁止です。
- 利益は費用後黒字の合計、損失は費用後赤字の絶対額合計、収支は利益−損失です。`既知`は決済を評価できた分だけ。`全件確定`とその累計は未知を含む時点から空欄で、未知を0円にしたものではありません。
- 00/01/04/05はデイ未知0、ナイト未知5。02/03/06はデイ未知1、ナイト未知5。03の見かけの総収支増加を全件確定の改善と読まないでください。
- 保有率は**実保有時間÷対象時間**。開始待機なし、デイ15:30・ナイト05:45以後を除外し、1場405分/765分です。全体は時間加重集計。未知保有は下限・上限で表示します。04は全81場で取得、デイ43.91%・ナイト下限28.04%です。
- 米国前/後の損益は新規判断q0がNY09:30前/以後かで分類し、夏冬を自動変換。保有時間は境界をまたいで実際に分割するため、同じ行の損益区分と保有時間の区分は同一ではありません。
- `F/A/N/C`は順行先着/逆行先着/未到達/観測不足。早期決済の観測打切りもあるため、出口が違う案のこの率を、そのまま入口精度の比較にしません。
- 日付・時刻は日本時間。CSVはUTF-8 BOM付き。7案×6種の42本を全セル照合しました。

条件・全28組の比較・Source・監査と再現は[182正本](../../study/00182_反転の危険局面と値幅に応じた保護を組み合わせる/README.md)に集約しています。04は損失軽減軸の保存候補であり、事前に固定した総合順位の1位ではありません。
