# 121入口切替のCSV

[幅別先着率.csv](幅別先着率.csv)から読む。主60分・±100ptはC0が順10/逆7、E0が6/1、V0が5/1、EVが2/0、B0が3/2、B1が10/7。E0の85.71%は120診断の旧7例を同じ出生時計で再現した結果で、未知の成功や安定70%確立とはしない。

|CSV|行数×列数|用途|
|---|---:|---|
|[幅別先着率](幅別先着率.csv)|60×16|6政策×2期限×5幅。順/逆/未到達と二種類の分母率|
|[候補別集計](候補別集計.csv)|12×20|出生・要求・約定・完了/不足、費用後期限評価、同cohort対応|
|[全候補明細](全候補明細.csv)|162×26|81政策別候補×2期限。未約定/取消/観測打切りも保持|
|[全70場集計](全70場集計.csv)|840×13|全70場×6政策×2期限。0件場も保持|

率は0〜1で、0.7が70%。順/(順+逆)と順/全観測完了は別。例えばE0の60分±125ptは6順/0逆/1未で、前者100%・後者85.71%。EVの2/2を少数例からの完成・採用としない。参考二項区間も同場・同波の依存を考慮した将来保証ではない。

金額は独立mini1枚の固定期限清算評価で、IFD利確/損切りの実約定収益ではない。費用C0は往復税込77円、費用C5はさらに往復10pt分1,000円（片道5pt×2）を控除する。政策IDのC0と費用C0を区別する。重複候補を片側10枚の口座収支へ合計せず、未約定・不足の金額や未定義率は空欄のまま残す。

E0の主先着は元54場6/0・追加16場0/1へ偏る。V0は元54場3/0・追加16場2/1で、期限C5平均−15,410.33円だった。高い先着率と期限金額、未見の再現性を分ける。[結果と限界](../../../study/00121_失速と量で反転の入口を切り替える/結果と限界.md)、[条件表](../../../study/00121_失速と量で反転の入口を切り替える/設定と結果.md)を参照する。

UTF-8 BOM・CRLF。[生成確認](CSVの確認.json)と[独立再読](../../../study/00121_失速と量で反転の入口を切り替える/検査/CSVの独立再読.json)で16,332データセル・9,506数値セルを厳密一致させ、四表の小範囲プレビューもRootで視認した。CSV単体ではnullと空文字は区別不能。IDや日時は表計算ソフトへ文字列列として読み込む。

候補選別を再現できた段階で新規探索を一旦区切る。安定70%・IFD実約定利益・利益追尾を含む運用完成は未達、未採用である。
