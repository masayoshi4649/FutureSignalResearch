まず[全セッション.csv](全セッション.csv)の「入口構成」を新入口（主）で絞ると、全73場の出生・取得・主先着・既知代用収支を確認できる。元出生（同区間）も別73行として残し、計146行。新主F0は23/73場・31.58%、両条件未達。

- [正逆比較.csv](正逆比較.csv)：新入口120＋元出生対照140の計260行・29列。政策/価格軸/BBO・Last/評価時間/同幅を区別する。
- [入口別診断.csv](入口別診断.csv)：全実取得候補42＋264の計306行・44列。主に選ばれた候補だけへ絞っていない。
- [全セッション.csv](全セッション.csv)：新旧各73場の146行・41列。0出生・未取得・未知も保持する。

元の列名の和集合へ同体転記し、構成に存在しない政策列はnull（CSV空欄）。対象外nullを0取引へ変えない。費用はmini1枚換算・往復77円、C5は追加1,000円。金額は既知IFD代用で、口座収支・実IFD約定・利益追尾ではない。H完了とIFD既知は別分母で、未知を0円へ補わない。

自然CSVは全26,990データcell/15,563数値を標準csv/Decimalで厳密再読し、Rootが3プレビューを確認した。[生成確認](CSVの確認.json)。数値正本と条件/限界は[正式129](../../../study/00129_背景方向と短期構造回復で取得を早める/README.md)を参照。Node24.22.1・Artifact2.8.129でCSVだけを出力し、xlsxは生成していない。
