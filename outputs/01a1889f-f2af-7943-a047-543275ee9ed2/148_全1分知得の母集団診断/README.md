# 148：全1分知得の母集団診断

まず[全セッション.csv](全セッション.csv)で全73場を確認する。[入口別診断.csv](入口別診断.csv)は不適格/未取得も含む全40,544台帳、[正逆比較.csv](正逆比較.csv)は300条件を収録する。

**これは売買政策を選ぶ前の母集団診断であり、最終取引数・選択頻度・新政策合格はnull。** BUY/SELLの31,632物理q1を全て取引した運用成績ではない。旧87を保護した全観測caseは31,642で、未参照の旧C1も含むため母集団BUY/SELL集合と件数が異なる。

|政策|意味|
|---|---|
|C0|旧81固定対照|
|C1|旧145全87固定対照|
|RC1|C1同時点の実BBO逆方向|
|BUY/SELL|研究unique q1の同じ31,632件を実買/実売で別観測。未選別|

H60±125の到達済み先着率は、H完了内の順/(順＋逆)。BUY43.11%・SELL46.44%を全取引勝率と呼ばず、未到達・不足・IFD金額未知を分ける。C5は独立mini1枚・往復77円＋追加滑り往復1,000円、利益/損失/差引を別列に残す。追加滑り0の費用条件C0と、政策C0は別の意味である。Last金額はnull。重複保有IFD合算を10枚口座・実mini板・実IFDの収支へ読み替えない。

全データ2,123,963セル・数値800,382を独立再読し、Rootが3画像を確認した。空文字とnullはCSVでは共に空欄になるため、型付き正本は[CSV用の表.json.gz](../../../study/00148_全1分知得から入口品質の母集団を固定する/成果物/CSV用の表.json.gz)を参照する。
