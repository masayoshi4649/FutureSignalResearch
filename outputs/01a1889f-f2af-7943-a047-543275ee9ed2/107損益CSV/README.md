# 試行107の損益CSV

作成日：2026-11-09。xlsxの後継の閲覧資料。既使用の2026-09-21〜11-06、35日・70セッションを対象とし、実運用の成績や未使用期間の評価ではない。

まず [候補別集計.csv](候補別集計.csv) で条件ID末尾 `_C0_D0` を見る。[全セッション.csv](全セッション.csv) では候補・条件ID・開始日で絞り込める。全24設定×70場の1,680行を収録し、0取引の24行も含む。11/06ナイトは11/06の17:00から翌朝まで。

| 候補 | 入口の時計 | 利益保護 |
| --- | --- | --- |
| B0 | 従来の5分割当、開始・米国開始後30分静観 | 通常水準で起動、2ATR幅 |
| B1 | B0と同じ | 起動後、平均の収束とMACD失速で1ATRへ縮小 |
| BE | B0と同じ | 同じ収束・失速と低い利益水準で早期起動も許す |
| Q0 | 静観内の初回割当を一度だけ静観明けへ繰り越す | B0と同じ |
| Q1 | Q0と同じ | B1と同じ |
| QE | Q0と同じ | BEと同じ |

これらは共通Sourceの入口を使う保護・時計比較であり、マルチ時間軸の方向一致を新たに入口条件へ加えた比較ではない。詳細は [固定済み試行107](../../../study/00107_見送り明けの初回取得と利益保護/README.md) を参照する。

金額は円。純損益＝粗損益−手数料−追加滑り。累計は条件IDごとに全70場を時系列で加算する。参加率パーセント＝（実新規または保有の判断枠）÷判断枠×100。元手未指定のため収益率は算出しない。

`C0` は観測BBO＋片道税込38.5円/枚を含む。`C5` はさらに片道5pt追加滑りを課す仮定。`D0` は追加遅延なし、`D1` は価格時計上1秒の仮定。費用条件で約定経路も変わり得るため、C0の損益へ機械的に費用だけを加減しない。

正本は `study/00107_見送り明けの初回取得と利益保護/成果物/結果.json`、SHA256は `85e1d9f3de5e2e6ebec29b7e26fb152abf4ac530f46248d33e78f0f6f041bbb1`。出力方法は [損益CSV](../../../scripts/損益CSV/README.md)、照合結果は [CSVの確認.json](CSVの確認.json)。正本と既存xlsxは変更していない。
