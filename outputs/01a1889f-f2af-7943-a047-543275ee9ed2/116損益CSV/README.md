2026-11-10。まず[候補別集計.csv](候補別集計.csv)で36候補の利益総額・損失総額・PF・平均利益損失比を比較する。[全セッション.csv](全セッション.csv)は36候補×70場の2,520行を残し、0取引場も含む。CSVを正本とし、xlsxは生成しない。

## 比較する条件

入口はA0（元の入口）、T（順行確認）、TR（順行または反転確認）。共通P100保護に対して、X0は追加退出なし、XCは5分確定終値とMACD Histの根拠喪失、XQはHist警戒中の現在返済BBOによる根拠喪失である。X0も一定利益で必須追尾を付けた条件であり、保護変更前の原手法S0とは異なる。

日経miniは買い・売り各上限10枚の可変数量、100円/pt、片道税込38.5円/枚。C0/C5は追加片道滑り0/5pt、D0/D1は追加価格時計遅延0/1秒。どちらも要求より厳密に後の正常原行で約定する。5/15/30分は指標幅で、新規は元Sourceの連続判断を維持する。

## 利益と損失

## 検証と再現

CSVのRaw初回性列は独立保存時点の状態を固定している。その後、別の全70原行監査が成功した。対象は監視適格なXC/XQの保有窓・延べ808玉で、40失効要求と40実返済の初回性を照合した。2つの相場例が入口/費用条件へ重複するため、40件を40個の独立した有効例とは数えない。P100全床/幅のRaw再形成と新規fill最初性は監査対象外。
