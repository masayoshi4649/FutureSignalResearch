まず [候補別集計.csv](候補別集計.csv) の `Q0_C0_D0`、次に [全セッション.csv](全セッション.csv) の同条件を見る。全12設定×70場の840行で、0取引の12行を含む。候補はQ0＝通常起動と固定幅、Q1＝起動後の収束・失速で狭幅化、QE＝早期起動も使う。入口の技法を新しく変更した比較ではない。

20分はセッション開始・米国開始の静観長。初回新規割当が静観内の場合の一回繰越を使う。主参加分母は7,980枠。30分対照の7,840枠と混ぜず、率はそれぞれの分母で計算する。同じ30分以降だけでの参加比較も[試行108](../../../study/00108_開始静観20分と30分の比較/README.md)へ残す。

`C0` はラージBBOによる約定モデルとmini片道税込38.5円/枚、`C5` はさらに片道5pt追加滑りの仮定。`D0` は追加遅延なし、`D1` は価格時計上1秒の仮定。可変数量・買い売り各上限10枚。累計は条件IDごとに全70場を0円から加算する。金額は円、参加率は0〜100の百分率である。

主Q0は費用後+2,173,617円、参加2,219/7,980＝27.8070%。ただし全体最低25%未達7/12設定、夜間単独は全12設定が25%未達であり、採用・未使用期間での安定収益を証明したものではない。11/06デイはQ0 -100,388円、Q1 -123,388円、QE -87,388円で30分対照と同じ。静観短縮だけで当日の問題は解決していない。

30分の結果は [試行107のCSV](../107損益CSV/README.md)。同じQ0等の識別子でも、試行107は30分、108は20分である。今回の旧30分は保存済み対照を検算して参照したもので、新しく金融を計算した結果ではない。
