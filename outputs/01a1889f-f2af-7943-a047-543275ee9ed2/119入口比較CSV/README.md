# 119入口比較のCSV

入口精度を見るには[幅別先着率.csv](幅別先着率.csv)から読む。6候補×30/60分×同幅25/50/100/125/200ptの60行で、順先・逆先・未到達、二種類の率と70%判定を示す。今回の60条件は全て70%未達。

|CSV|行数×列数|用途|
|---|---:|---|
|[候補別集計](候補別集計.csv)|12×20|出生・要求・約定・観測完了、費用後の期限評価、同出生対照|
|[幅別先着率](幅別先着率.csv)|60×16|順逆の同幅先着率と分母・未到達・70%欄|
|[全候補明細](全候補明細.csv)|2,070×26|345出生×3役×2期限の注文状態と期限評価|
|[全70場集計](全70場集計.csv)|840×13|全70場×6候補×2期限。0件場も保持|

率は0〜1の数値で、0.7が70%。順/(順+逆)と順/全観測完了を区別する。先着は価格の到達順で、実決済の勝率ではない。参考二項95下限は同じ場・波の依存を考慮した将来保証ではない。

金額は独立mini1枚の期限清算評価。C0は往復税込手数料77円、C5はさらに往復10pt分1,000円（片道5pt×2）の滑りストレスを控除する。重複する候補を片側10枚の運用口座収支へ合計しない。未約定や観測不足の金額・率は空欄で、0へ補完しない。

順行confirmの60分C5平均＋1,244.43円は28完了例の平均で、±100pt先着は順9/逆19（32.14%）、中央値−3,577円。同出生zoneと双方完了した22組では平均差−8,727.27円だった。平均が黒字という理由だけで有効な入口とは判定していない。[結果と限界](../../../study/00119_技術領域の出生と確認後再試験で入口を比較する/結果と限界.md)と[設定表](../../../study/00119_技術領域の出生と確認後再試験で入口を比較する/設定と結果.md)を参照する。

UTF-8 BOM、CRLF。[生成確認](CSVの確認.json)と[独立再読](../../../study/00119_技術領域の出生と確認後再試験で入口を比較する/検査/CSVの独立再読.json)で65,940データセル・16,147数値セルの一致を確認した。型情報を持たないCSVではnullと空文字は区別不能。ID・日時等は表計算ソフトへ文字列列として読み込む。Rawの最初性や金融条件の再証明はCSV検査の対象外。
