A0は元の入口に共通P100利益保護を加えた基準で、元アルゴリズム無変更のS0とは異なる。Tは30分平均配置、15分DI/ADX、5分前3本の高安突破・ATR警戒・要求Lastの保持。TRは、長い逆配置でも中期方向と局所構造が回復したRをTへ加える。各候補は別の仮想口座なので合算しない。

費用はmini100円/pt、買売各上限10枚の可変数量、片道税込38.5円。C0/C5は追加片道滑り0/5pt、D0/D1は追加価格時計遅延0/1秒。D0も厳密な後の正常BBOで約定する。スプレッドは取得/返済の価格へ含み、追加滑りは別の費用。ラージ板のmini約定代理という模型である。

勝率は費用後正益の完結実玉/全完結実玉（同値も分母）。PFは利益総額/損失総額絶対値。玉数と枚数を分ける。DDは保存点の時価評価で、原板全更新点の独立極値走査ではない。累計は候補・費用内で独立に加算し、候補間で連結しない。

「費用後正益を経験した建玉数」は、保有中の正常な返済側BBOによる全玉Wが一度でも正だった玉。W=実既返済純額R＋実残枚数n×残1枚の費用後評価u。部分返済後に初期枚数を仮想維持しない。「正益経験建玉の最終赤字率パーセント」は、その分母に対する最終費用後赤字玉の割合で、全取引を分母にした勝率とは異なる。候補別率は全場の分子/分母を合算してから計算し、場別率の平均にしない。分母0は空欄で、0%と区別する。

「追尾起動後赤字」と「建玉全体の正益後赤字」は定義が異なり重複し得る。件数を足さない。入口を絞って赤字件数が減っても、正益経験玉を分母にした率が改善したとは限らない。

元新規要求、許可、採用モード票の真/偽/未知、入力不足、否定、容量を反映した受付、実取得を別に記録する。入力不足と否定と許可は重複し得る。連続Sourceの通過率であり、5分/15分固定枠の参加率ではない。5/15/30分は指標の足幅で、新規時計を変更していない。

UTF-8 BOM付き、日時・開始日はJST文字列。未定義比率は空欄。CSV全32,404数値・2,912未定義空欄を別処理で再読し、全場累計・分母・数量・費用と一致した。xlsxは作成していない。11/09は価格・損益・入力指紋とも未読。未参加・退出後の仮想利益・機会損失は含まない。
