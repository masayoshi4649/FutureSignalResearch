# 00128：Raw価格時計のCSV三表

最初は[全セッション.csv](全セッション.csv)の「公表モデル」を**即時（主）**に絞ると、全73場の主F0・日別差引・累計・未取得を確認できる。60秒保留（対照）と合わせて146行。欠測・未知は0円で埋めていない。

- [正逆比較.csv](正逆比較.csv)：280行×29列。2モデル×7政策×2価格軸×2期限×5幅。主は即時/F0/BBO/3600秒/125pt。
- [入口別診断.csv](入口別診断.csv)：432行×41列。即時264＋保留168の全実取得、出生・要求・取得時計/系列/費用と主選択。
- [全セッション.csv](全セッション.csv)：146行×41列。73場×2モデル。主F0を各場1件まで選び、0取得場も残す。

主即時は68/73場・46.81%、C5利益292,844円/損失453,849円・差引−161,005円。保留は62場・40.91%、247,306円/466,849円・−219,543円。IFD代用清算で、実mini口座収支ではない。

Source表の値と行順は変えず、先頭に公表モデル列のみ追加。31,818全セル・19,549数値の独立再読一致、Rootによる3プレビュー確認済み。[CSVの確認](CSVの確認.json)、[正式結果](../../../study/00128_Raw価格時計で構造回復の出生を比較する/結果と限界.md)、[再現手順](../../../study/00128_Raw価格時計で構造回復の出生を比較する/再現資料/再現手順.md)。プレビューはwork側の確認用で、恒久CSVへの装飾やxlsx生成は行っていない。

**終端気配の注意：**旧計算にはプレクロージング気配を即時清算可能と扱った疑いがある。数値は変更せず保存し、実現可能な口座損益とは呼ばない。[JPX根拠と診断](../../../study/00128_Raw価格時計で構造回復の出生を比較する/検査/終端気配と清算可能性.md)。
