# 134：公表時計を替えた複合入口のCSV

まず[全セッション.csv](全セッション.csv)で、全73場の政策別損益・参加・既知/未知・既知累計を見る。N0がRaw即時の主、D0がRaw60秒遅延、C0が従来CSV133L0、O0がN0の元方向、R0がN0の実逆。N0/D0/C0は独立に生成した取得集合であり、同じ取引のペア差として扱わない。

|ファイル|内容|データ行×列|
|---|---|---:|
|[全セッション.csv](全セッション.csv)|全73場を残す政策別C5の利益・損失・差引・参加・既知累計|73×69|
|[入口別診断.csv](入口別診断.csv)|三model合計235取得。出生/取得/方向、主・元・実逆の先着/IFD診断|235×55|
|[正逆比較.csv](正逆比較.csv)|全体/前48/後25×5政策×BBO/Last×H30/60×同幅25/50/75/100/125|300×29|

主は実BBO/H60/±125pt。N0は全73場78取得、24順32逆未15不足7、到達済み率42.86%で70%未達。C5利益337,382円・損失502,080円・既知差引−164,698円、IFD未知4。D0は53.57%/−10,775円、C0は68.42%/+193,148円。主を副や旧CSVへ交換しない。

金額はmini1枚独立100円/pt、往復77円にC5追加1,000円を控除したラージBBO代理。C0費用条件と政策名C0は別概念。未到達H完了の清算と、取得後のH不足/IFD未知を分ける。未知金額は空欄で、0円ではない。Last金額はnull。既知累計は未知部分を含む完全な口座収支ではなく、重複する政策を合算しない。10枚・両建て口座・実IFD・利益追尾の成績ではない。参加は各場の取得代用min1で、旧固定5分枠の参加率とは異なる。
