## 列の読み方

取引件数は実新規で作られた建玉単位で、部分返済片を別の勝負へ分けない。利益・損失は各建玉の全返済と往復費用を合算した最終純額である。損失総額・平均損失は負数、PFは利益総額÷損失総額の絶対値。勝率は正益建玉数÷全建玉数で同値も分母に含む。分母0の比率は空欄とし、実数0と区別する。

「建玉全体の正益後赤字」は、同じ建玉の部分返済込み費用後時価が正だった後に最終赤字となった数。「追尾起動後赤字」はさらに起動済みのもの。設定した床以上で実際に約定する保証ではなく、次正常原行のBBOで損益を記録する。S0の追加追尾起動0件は、その安全性を示す数字ではない。

DDは各場の保存時価極値・DDを連結した円額で、元手に対する割合ではない。保有時間秒は実約定間で少なくとも一枚を保有した時間の和、数量秒は枚数×時間。固定5分枠の参加率へ読み替えない。元54場と追加16場はすべて既使用データであり、未見検証とは呼ばない。

金融・独立会計・保存再読は全1,680口座で成功。CSVは別に35,952数値を独立再読し、全累計終端と正本に一致した。CSVはここを正本とし、試行側へ重複保存せずリンクする。原板・価格CSVの複製、xlsx生成・更新、未参加や決済後の仮想利益の計算は行っていない。
