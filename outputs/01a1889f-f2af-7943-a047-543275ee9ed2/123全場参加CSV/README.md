# 123：全場参加と入口先着のCSV

主P3は全73場で最低1取得を達成したが、主60分±125ptは26順31逆未到達16、到達済み45.61%・全完了35.62%で70%未達。今回の方式は採用不可。全場で取得したことと入口精度を両方確認するための三表である。

|読む順|CSV|データ行×列|用途|
|---:|---|---:|---|
|1|[候補別集計.csv](候補別集計.csv)|8×42|E0/P2/P3/P4×30/60分。取得0の場数、全5幅の両分母率、全場参加の判定|
|2|[全セッション.csv](全セッション.csv)|73×23|主P3の全73場、最低1取得の達否と初取得、主125pt結果。場を落とさない|
|3|[入口明細.csv](入口明細.csv)|534×28|全政策の候補×両期限。要求・未取得・取得・観測不足・先着・期限評価|

534行は534取引ではなく、267候補を30/60分の各行へ展開したもの。未取得候補も残す。P3の79取得も79場ではなく、全73場で最低1取得し、その後の既定E0も保持した結果である。P2/P4の全場内訳は正本集計から再生成でき、閲覧CSVへ292行の重複一覧は作っていない。

主政策/幅は実行前にP3・H60±125ptへ固定。125ptは122の既知副評価を踏まえた研究内選択で、未知期間の検証ではない。100ptを含む25/50/100/125/200ptを候補別表へ全て残した。主P3の100ptも36順31逆未到達6、53.73%/49.32%で未達。対照E0は9件の金融/event値を保持し、125pt率87.50%/77.78%を満たすが取得場は7/73である。

率は0〜1の数値で`0.7`が70%。到達済み分母は順+逆、全完了分母は順+逆+未到達。未取得・観測不足・未到達を別々に保持し、分母0は空欄・評価不能。取得0は参加条件不合格として残し、先着率0%や損益0円へ変換しない。

時刻はJST、価格差はNK225の指数pt、金額は独立mini1枚の固定期限清算評価円。C0は往復77円、C5は追加往復10pt相当1,000円を控除する。買Ask/売Bidのラージ気配による取得代用であり、mini実約定・IFD利確/損切り・利益追尾・片側10枚口座の実績ではない。独立候補を口座収支へ合算しない。全技術票は[圧縮正本](../../../study/00123_複合入口で全セッション最低1回を検証する/成果物/全73場の入口結果.json.gz)の候補IDから参照する。
