# 117：損益CSVの案内

2026-11-10。NK225mini、既使用70セッション（2026-09-21デイ〜11-06ナイト）。[試行の説明](../../../study/00117_正益起動と取得後1分波の失敗で利益を守る/README.md)と[結果・限界](../../../study/00117_正益起動と取得後1分波の失敗で利益を守る/結果と限界.md)を参照する。

- [候補別集計](候補別集計.csv)：5政策×4費用・遅延条件の20行。利益、損失、純損益、PF、回数、正益後赤字、保存点DD。
- [全セッション](全セッション.csv)：20条件×70場の1,400行。場別損益と候補ごとの累計収支。全場を残す。

S0は元Sourceの退出、W100は旧一定利益起動と通常幅、P100は旧3分の複合保護、H0Eは費用後正益で必須起動・最低取得価格床、H0MはH0Eに取得後1分波の構造・MACD・反対値幅による幅縮小を加えたもの。全条件とも元Sourceの連続新規時計と数量配分を維持し、研究側の5分/15分時計や開始静観を追加しない。

買い・売り各上限10枚の可変数量、100円/pt、片道税込38.5円/枚。C0/C5は片道追加滑り0/5pt、D0/D1は追加遅延0/1秒。D0も要求した原行では約定せず、後の正常気配を使う。ラージ板をminiの気配に代用し、miniの実約定を保証するものではない。

利益と損失は完結した実建玉の費用後正額・負額の合計で、損失は負符号。PFは利益合計÷損失合計絶対値。平均利益損失比は勝ち平均÷負け平均絶対値。正益後赤字率の分母は費用後正益を経験した建玉数で、場別率の平均ではない。0分母の比率は空欄。DDは保存点からの時価DDで、全Rawの最大DDとは呼ばない。未参加・決済後の仮想利益、機会損失、ROIは算出しない。

金融は元54場の117 Nativeを再用し追加16場を再生。独立会計は全70場・1,400条件を検算し、不一致0。CSV二点の53,900セルを別の読取器で再照合した。[独立再読](../../../study/00117_正益起動と取得後1分波の失敗で利益を守る/検査/CSVの独立再読.json)。固定枠の参加率は今回対象外。

H0MはH0Eより4費用条件とも小幅に改善したが、全H0は赤字。差のある元の出生機会は4件ですべて売り。既使用期間の探索結果であり、新期間の安定収益や買い側の効果は未証明。ユーザーの指示に従い、この限定知見を残して一旦停止する。CSV二点はこのフォルダを唯一の閲覧正本とし、xlsxは生成しない。
