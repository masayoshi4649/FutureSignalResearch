# 112の損益CSV

最初に[候補別集計.csv](候補別集計.csv)を開き、条件IDの`C0_D0`を比較する。各回の収支と累計は[全セッション.csv](全セッション.csv)で、候補・条件IDを絞り込んで読む。24条件×70セッション＝1,680行を保持した。対象は2026-09-21 Day〜2026-11-06 Nightの既使用期間。11/09は使っていない。

全条件は日経miniの買い・売り各上限10枚、可変数量、100円/pt、片道税込38.5円。ラージBBOを代理に、元手法本来の連続判断で計算した。研究側の5分/15分新規時計や開始静観は加えていない。主条件の全6候補は各558玉・1,169枚である。

| --- | --- | ---: | ---: |
| S0 | 元手法の入口・返済・内部保護 | +2,146,987 | +977,987 |
| W100 | 一定利益後の必須追尾、通常幅200pt/2ATR | +1,114,987 | −414,013 |

S0以外の必須起動は、先行部分返済込みの費用後利益Wが初期枚数×10,000円以上に達した時。W400/P400も起動水準は100pt相当のままで、400は通常幅の最低値を表す。取得時ATRが既知なら表の倍率と最低幅の大きい側を使い、未知なら最低幅に固定する。狭幅と適格構造床を加える案は、その組み合わせとして評価する。

主P100はW100より12,000円改善したが、元S0を下回り、費用条件すべてでの改善ではなかった。主P100は218玉で追加保護が起動し、そのうち最終赤字は2玉・計154円。起動後の価格床と実約定は区別する。通常幅を広げただけのW400は主W100より59,000円悪化した。

`C0/C5`はBBOスプレッドとは別の追加片道滑り0/5pt。C5の往復追加費用はmini1枚当たり1,000円。費用は保護の判断にも入るので、C0から一定額を引くだけの比較ではない。`D0/D1`は要求後の追加価格時計待ち0/1秒で、D0でも同じ原行では約定しない。4費用の全値は候補別CSVに残した。

純損益は粗損益から手数料・追加滑りを控除した値。利益総額は正、損失総額は負で、PFは利益総額/損失総額の絶対値。勝率は同値を含む全完結実玉が分母。比率の分母0は空欄で、数値0とは区別する。累計は各条件内の実現純損益の合計である。固定時計の参加率や、未参加・決済後の仮想利益は計算していない。

UTF-8 BOM付きCSV。独立正本の24集計・1,680場別と35,952数値、全条件の累計末尾を再読照合した。CSVはこのフォルダの2点が唯一の閲覧正本で、xlsxは作成していない。[設定・結果・再現資料](../../../study/00112_支持否定の確認と通常追尾幅の比較/README.md)を参照する。追加保護の実約定を元Sourceへ返す統合と、別期間の安定性は未確認。採用はない。
