# 118入口比較の見方

[候補別集計.csv](候補別集計.csv)から読む。7候補×30/60分の14行、37列。全出生・要求・約定・観測不足・同幅先着・費用後の期限評価を並べた。[全候補明細.csv](全候補明細.csv)は558出生×7候補×2期限の7,812行、28列で、未約定や観測不足も残す。

これは**独立mini1枚の入口試験**。重複する試験を片側10枚の運用口座収支へ合計しない。C0は往復手数料77円、C5はさらに往復滑り1,000円（片道5pt×2）を控除する。先着はその方向への到達順で、売買の勝敗・実際の決済ではない。全出生と観測完了、同出生で双方完了した比較の分母を区別する。

未約定や観測不足の金額は空欄で、0円ではない。技術3候補は約定0であり、平均金額も未計算。UTF-8 BOM、CRLF。表計算ソフトへはセッション・出生ID等を文字列として読み込む。

60分のM0は234順先/252逆先/10未到達、C5平均−538.69円。200pt待機は22順先/45逆先/1未到達、C5平均−3,974.06円で、待ち価格だけで有効な入口とは確認できなかった。[試行の結果と限界](../../../study/00118_指値待機と複数技法の取得確認で入口を比較する/結果と限界.md)、[条件・56×9表](../../../study/00118_指値待機と複数技法の取得確認で入口を比較する/設定と結果.md)を併せて読む。

[生成確認](CSVの確認.json)と[独立再読](../../../study/00118_指値待機と複数技法の取得確認で入口を比較する/検査/CSVの独立再読.json)で全セルの転記一致を確認した。金融計算やRaw最初性をCSV器が再証明したものではない。CSV SHA256は候補別 `a09b2e3ae34ade127ae924ca4f5ec45eec42995d0f6df38d2c38978c965c0728`、明細 `3f1ff32a8317ef9518f7d9d044a3b8d8908bd3b874ad6702f2f54d2581c1c55b`。
