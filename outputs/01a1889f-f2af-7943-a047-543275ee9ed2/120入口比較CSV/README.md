# 120入口比較のCSV

[幅別先着率.csv](幅別先着率.csv)から読む。主評価60分・±100ptではP1が順34/逆43、P1plus5/5、P2が10/7、P2plus2/0、P3が14/25、P3plus0/4。P2plusの2例を70%の再現性確立や合格とは判定していない。

|CSV|行数×列数|用途|
|---|---:|---|
|[幅別先着率](幅別先着率.csv)|60×16|6候補×30/60分×5幅。順/逆/未到達、二分母の率、記述上の70%欄|
|[候補別集計](候補別集計.csv)|12×20|全出生・要求・約定・完了/不足、C0/C5期限評価、同分構造の対照|
|[全候補明細](全候補明細.csv)|602×26|301独立候補×2期限。未約定・取消・観測不足も保持|
|[全70場集計](全70場集計.csv)|840×13|全70場×6候補×2期限。0件場も保持|

率は0〜1で0.7が70%。順/(順+逆)と順/全観測完了は別。P2plusの30分±100ptは1順/0逆/1未なので、前者100%でも後者50%。その60分±125/200ptも1順/0逆/1未に留まる。参考二項区間を、同場・同波の依存を考慮した将来勝率保証とはしない。

金額は独立mini1枚の固定期限清算評価で、実際の利確・損切り損益ではない。C0は往復税込手数料77円、C5はさらに往復10pt分1,000円（片道5pt×2）の滑りストレスを控除する。重複候補を片側10枚の口座収支へ合算しない。未約定や観測不足の金額・未定義率は空欄で、0へ補完しない。

[結果と限界](../../../study/00120_1分構造と無効化距離で入口を作る/結果と限界.md)と[設定表](../../../study/00120_1分構造と無効化距離で入口を作る/設定と結果.md)に全12条件と解釈を記す。UTF-8 BOM・CRLF。[生成確認](CSVの確認.json)と[独立再読](../../../study/00120_1分構造と無効化距離で入口を作る/検査/CSVの独立再読.json)で27,772データセル・11,301数値セルの一致を確認した。型を持たないCSVではnullと空文字は区別不能。IDや日時は表計算ソフトへ文字列列として読み込む。

支援PNGはA:Gの小さい範囲へ再描画して四点とも視認し、金融JSON・CSVはbytes不変だった。自然Rawの最初性や技術条件の再証明は、CSVの転記検査とは別である。
