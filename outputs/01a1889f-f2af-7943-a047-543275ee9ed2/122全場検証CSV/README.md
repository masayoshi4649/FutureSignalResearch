# 122：全73セッションとE0入口明細

最初に[全セッション.csv](全セッション.csv)を開くと、候補0の66場を含む全73場を確認できる。個々の取得と先着・期限清算評価は[E0入口明細.csv](E0入口明細.csv)。9候補を30/60分で各1行にした18行であり、18回の取引を意味しない。

|E0入口明細|18×31|`f3e689dd16f64a3aac5175cd6453cdcf01252db276db839e9708d0aa21e898dd`|

E0は基本反転C0＋既知ADX30低下。RVOL≥1は必須ではなく、量だけのV0・両方のEVは別の固定対照として結果JSONに残す。主60分±100ptは全9件で6順3逆、66.67%で未達。固定副60分±125ptは7順1逆未到達1、到達済み87.50%・全完了77.78%で両方の70%数値条件を達成した。副を主に差し替えない。

全場表の「基本反転複合条件不成立」55場はC0基礎出生0、「C0出生時ADX低下不成立/未知」11場はその次段階での分類。前者は各指標の既知偽/未知を完全分解した一意の根本原因ではない。共通品質の最初の拒否と重なり得る独立gateは別で、未知を性能0へ変換しない。全場走査は全場強制新規ではない。

率は0〜1の数値で、`0.7`は70%。分母0は空欄・評価不能、数値0は0のまま。未成立場を負け、未取得を損益0、未到達を観測不足へ置換しない。時刻はJST、価格差はNK225の指数pt、金額は独立mini1枚の円。費用C0は往復77円、C5は追加往復10pt相当1,000円を控除し、政策C0とは別である。

期限清算評価は取得後30/60分に正常返済BBOで清算した評価で、±100/125ptのIFD実決済や自然否定ストップ、利益追尾、片側10枚口座の実績ではない。独立ケースを口座損益へ合算しない。新11-09 Dayの後の売りは100pt逆行先着後に125pt順行先着したため、幅による結果差を確認できる。
