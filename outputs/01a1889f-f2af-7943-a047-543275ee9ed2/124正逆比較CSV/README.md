# 124：同じ入口の正逆比較CSV

2026-11-11。最初に[正逆比較.csv](正逆比較.csv)を価格軸BBO・評価60分・同幅125ptで確認する。主T1はO0と同体、45.61%で70%未達。次に[入口別診断.csv](入口別診断.csv)で個別の正逆・spread・当時指標を比較し、[全セッション.csv](全セッション.csv)で全73場の最低1取得と既知/未知を確認する。

|表|データ行×列|内容|
|---|---|---|
|正逆比較|160×24|8政策×BBO/Last×30/60分×25/50/100/125/200pt。先着率とIFD代用既知金額|
|入口別診断|79×29|同じ入口の正逆価格、25/125pt先着、当時特徴、T1/T2の理由。全特徴は圧縮正本参照|
|全セッション|73×19|主T1と元方向。全場保持、既知差引累計と未知件数累計を分離|

到達済み率=順/(順+逆)、全完了率=順/全H完了。H60は完了73件/不足6件、125ptのIFD代用は既知76/未知3で分母が違う。観測済み先着は後のendpoint不足でも既知清算とし、未到達は完了endpointでのみ清算する。空欄はnullで0と異なる。Lastは純方向の参考で、全金額が空欄。

金額は独立mini1枚=100円/pt。C0は往復77円、C5は追加往復10pt相当1,000円控除。実BBOにspreadを含む。既知代用利益/損失と累計はIFD実約定・同時保有・10枚口座の収支ではない。正逆反転は新規/清算価格側を変えて再生し、1−pではない。

UTF-8 BOM付きRFC4180 CSV。JSONのヘッダ・全値・型を転記し、標準csv/Decimalで7518データセル/4972数値が一致、3表のプレビューを確認した。CSVを再計算しておらず、元の金融条件は変更していない。[生成証跡](CSVの確認.json)、[独立再読](../../../study/00124_逆行の原因と売買反転を同じ入口で検証する/検査/CSV独立再読.json)、[正式報告](../../../study/00124_逆行の原因と売買反転を同じ入口で検証する/結果と限界.md)。
