主3は赤字場17→16、場連敗4→3、最悪場−57,585.2→−44,001.6円、初期最低−103,204.8→−79,536.8円を改善。一方、取引連敗は7→8へ悪化し、前48は−10,279.6円でまだ赤字。Aが作用した基準の実取得は10件/6場に限られ、後続旧要求の枠変更も収支改善へ寄与する。追加7以後はA該当がなく旧と同体で、新しい効果が再確認されたとはしない。

05は純益が高く損失額も少ないが、主3より赤字場18、取引連敗10、DD102,444.4円が悪い。成熟確認の実取得は1件+15,666.4円だけで、単独手法の優位を確定しない。全期最大利益ではなく損失安定性を優先し主3を保持した。

各候補のDay42行・Night41行を残した。Nightは全候補旧基準の176取得/38場、金融未知7で同体。Night208主3や209の新枝はこのCSVへ混ぜていない。保有率は全対象時間の率で、各場20%以上や毎時一定回数を意味しない。
