# 210:05_成熟待ち併用

主3の長期矛盾見送りに、BB外側の加速中は5分冷却→源EMA8の回復→保持を待つ処理を加えた比較。利益と損失額は改善するが、赤字場・連敗・DDが主3より悪く主を交換しない。

2026-09-21〜11-17の全83セッション。ミニTOPIX1枚、1pt=1,000円、片道41.8円+0.25pt、往復583.6円。ラージBBO代用、Day源A25/NightW15/H60単純IFD、保有予約合計1、開始待機なし、終了15分前決済。

[集計](集計.csv) / [デイ](デイ.csv) / [ナイト全体](ナイト全体.csv) / [ナイト米国前](ナイト_米前.csv) / [ナイト米国後](ナイト_米後.csv)。今回の変更はDayだけで、Nightは3案とも旧190N01。Night208主3を混合していない。

利益と損失は費用後の既知取引の金額。Day未知0、Night未知7。未知を含む場の確定収支と以後の確定累計は空欄で、別列の既知寄与を確定利益と扱わない。無取引場も残す。保有時間率は実際に確認できた区間の下限（0〜1）、終了前15分を分母から除く。予約・未確認保有で水増ししない。

損益は新規取得帯へ、保有は帯との実時間重複へ帰属。新規0でも保有率が正の帯がある。Night全体と米前・米後は別の集計なので重複加算しない。DDは場末実現寄与の経路で、保有中時価DDではない。
