旧基準と、確認待ちの注文経路を変えた二案を候補別CSVにした。全83場は探索に既使用。将来の安定性を確定する結果ではない。

「02_補完制限」は195_05、「05_旧幹確認」は199_05。02は赤字場を減らし、05は損失総額と赤字取引をさらに減らす交換がある。DDは場末の実現収支から計算し、建玉保有中の最大時価DDとは異なる。保有率は全デイ対象時間の合算であり、各場が一律20%以上という意味ではない。

## ナイトと追加期間の扱い

この3案のナイトは同体。41場・124取得、既知利益1,561,302円/損失759,465円/既知収支801,837円、未知5件、保有時間率下限28.81%。夜間の未確定損益はデイの利益で隠さない。ナイト全体と米国前後は同じ取引の別集計なので合算して重複計上しない。

11/17デイでは02が旧より悪化し、05は旧並みまで戻った。一方11/16では02より05が悪化する。総額だけで完全優位とせず、[個別原因・新枝の支持・旧80と追加区分](../../study/00199_保留中の旧幹を確認済みの根拠で切り替える/README.md)を併読する。旧幹の取引が入れ替わる効果を含み、新しい確認枝だけの利益ではない。

## CSVの列と再現

利益/損失は費用後の既知寄与。確定収支・確定累計の空欄は未知を意味する。既知寄与累計を口座全体の確定利益としない。各候補のデイ42行、ナイト41行を残し、候補を混在させない。
