## 列の意味

|列|意味|
|---|---|
|日付|セッション開始日。ナイトの翌朝分も前日のナイト開始日に帰属する。|
|利益（円）|費用控除後損益が正だった既知取引の利益合計。|
|損失（円）|費用控除後損益が負だった既知取引の損失絶対値合計。正の数で記録する。|
|収支（円）|既知分の利益−損失。観測不足がある行の全件収支は未確定。|
|建玉回数|追加建てを含む取得回数。各要求mini1枚で、注文要求数・最大保有枚数とは異なる。|
|主入口回数／補完入口回数|建玉回数の内訳。両者の和は建玉回数と一致する。|
|観測不足件数|決済損益を確定できなかった取得の数。|
|集計状態|「全件既知」「既知分のみ」「建玉なし」。不足のある取引を0円決済と認定しない。|

ナイトの米国前後は判断q0のNY09:30で夏冬時間を変換して区分。米国前に建てて米国後に決済した取引も、損益全額を米国前の行へ帰属させる。決済時刻で損益を分割した表ではない。

費用はmini1枚・1pt100円、片道税込38.5円、追加片道5ptの滑りを継承。実BBOのspreadも含む。数量は買売各10枚までの未決予約込み再生であり、全金額を固定10枚へ換算したものではない。
