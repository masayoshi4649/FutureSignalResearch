利益・損失は費用後の既知取引を分けた金額。未知を含む場の確定収支と、それ以後の確定累計は空欄。既知寄与を未知が解決した利益とはしない。未知7件はNight。無取引の場・帯も行を残す。累計は各候補・各帯ごとに0から始める。

保有時間率は対象実時間に占める確認済み保有の下限（0〜1）。末尾15分を分母から除き、予約と未確認保有で水増ししない。損益は新規取得帯、保有は実際の区間重複へ帰属するので、新規0回でも保有率が正の帯がある。ナイト全体と米国前後は同じ取引の別集計であり、足し合わせて重複計上しない。
