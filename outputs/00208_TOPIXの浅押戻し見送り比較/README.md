## CSVの定義と確認

各候補のデイ42行・Night41行を保持。確定収支/確定累計の空欄は未知で、0円ではない。利益−損失は「既知寄与」へ一致し、未知を含む口座全体の確定収支とは区別する。保有率は全時間の率であり、各場20%達成や毎時一定回数を意味しない。DDは場末の既知実現寄与で、建玉保有中の最大時価DDではない。
