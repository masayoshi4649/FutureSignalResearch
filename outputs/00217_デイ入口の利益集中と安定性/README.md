10月20日と11月19日の日経、11月16日のTOPIXには、旧入口と新入口の注文位置を比較できる[SessionTradeViewer用の約定](../../study/00217_デイの利益集中と入口条件を比較する/Viewer/README.md)もある。

対象は2026-09-21から11-20の45デイ。利益・損失はどちらも正額、収支は利益から損失を引いた円額。0件の日を含む。未知件数が正なら確定収支は空欄、以降の確定累計も空欄。既知累計は判明した建玉だけを足す。保有時間率は確認できた保有秒数を対象時間08:45〜15:30で割った値。各候補はmini1枚の独立した口座で、利確・損切り・期限を建てる段階で決める単純IFDを使う。
