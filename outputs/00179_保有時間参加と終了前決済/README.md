# 179：保有時間の参加率と終了前決済の比較

まず [主案・全期J035](179_全期_J035/README.md) の **デイ.csv** と **ナイト合計.csv** を見る。[旧178を同じ時計で再生した対照](179_旧178_新時計/README.md)と比較できる。

主案は全80場で取得があり、保有率の確定下限はデイ51.88%、ナイト28.94%。20%以上保有したことが確定した場はデイ39/40、ナイト26/40で、全場が20%以上ではない。デイの黒字確定場は旧178対照の27場から31場へ増え、上位3正純益場を除いた診断収支も170,758円から666,682円へ改善した。これは実現収支から有利な場を除いて採用したという意味ではない。

旧178を同じ締切で再生した対照も、保有率下限はデイ42.51%・ナイト28.94%で20%を超える。179の改善点は20%の初達成ではなく、デイの利益分布と保有時間の改善にある。

各候補を別フォルダとし、一つのCSVに異なる手法を混ぜない。各フォルダの集計は4行、デイ・ナイト合計・ナイト米前・米後は各40行。固定近傍2案と旧前半選択対照は研究正本へ残し、閲覧CSVの重複を抑えた。

- **対象と費用**：NK225ラージの実BBOをmini1枚の約定代用に使い、1pt＝100円。片道税込手数料38.5円、追加滑り片道5pt、往復固定費用1,077円。板のスプレッドも売買側価格へ反映する。買売合計で建玉・予約1件まで。
- **時間**：JST、セッション日は開始日。一律の開始待機なし。対象時間はデイ08:45〜15:30、ナイト17:00〜翌05:45。締切1分前に決済注文を出し、1秒以上後かつ締切内の最初の正常BBOで決済する。先にIFDや通常期限へ達した場合はそちらを使う。締切1分前から新規を停止し予約を取り消す。この執行用1分は参加率の分母に含める。
- **参加率**：実取得〜決済の保有時間を対象時間で割る。注文待ちは分子へ加えない。米国前後をまたぐ保有は実時間で分けるが、利益・損失は入口時点の帯へ帰属する。米前・米後の率は単純加算しない。CSVは小数比率で、0.20＝20%。
- **未知**：金融未知をゼロ利益とは扱わない。既知分収支と全件確定収支を分け、累計の全件確定は未知発生後に空欄にする。保有時間は確定下限と可能上限を記載する。終了前全決済が確認できない場も「未知」で残す。
- **先着**：Fは利確幅先着、Aは損切幅先着、Nは未到達の期限決済、Cは観測不足。先着率はF÷(F+A)で、全取引の勝率ではない。正負の決済損益と分けて読む。
- **安定性**：両中央値は建玉ごとと全Day/全Nightセッションごとの費用後中央値。米国前後は診断。上位3正純益場の除外後収支は集中の診断であり、残した件の利益を採用損益とはしない。

今回増えたのは保有時間で、デイの取得回数は161→153回へ減った。新しいデイ入口は長期MACD Hist増分がまだ公表されていない時の局所的な複合条件であり、選ばれた枝は追加出来高条件なし（V0）。量を使う候補も比較したが、今回の改善を出来高フィルターの効果とはしない。

ナイト入口は旧178のまま。主案の追加4ナイトは既知収支−126,924円で、全期間のナイト金融未知は5件ある。前48選択案も後25場で悪化した。全80場は既使用の研究データで、全期発見の将来再現は未確認。デイ改善を有望な結論として、新探索を一旦止めている。
