# どのCSVを見るか

**日経デイで利益保護後の再開を待つ場合は、RC20の「デイ.csv」** に9月21日〜11月20日の45日分の利益・損失・収支・累計・建玉回数・実保有率を載せた。約定日時・売買方向・元の利確損切・追尾時刻は「建玉明細.csv」、全期間・前24日・後21日・直近3日の集計は「集計.csv」。日経225mini 1枚、片道38.5円＋想定滑り5ptを含む。時間制限は開始待機と15:30までの全決済。実保有率の分母からこの両端を外し、決済後の新規待機は分子に入れない。

その他のフォルダは条件IDの2文字目で区別する。Bは反対の主シグナル、Nは中立か反対の主シグナル、Cは元の±1Rか場末、Dは反対シグナルと元価格の先に来た方を待つ。各条件のファイルに他の条件は含めていない。A（即再開）は223のP20・S00・R02の口座と全項目一致したため、223のCSVを参照する。[全条件の結果](../../study/00224_利益保護後の再エントリーをシグナルで待つ/全条件の比較.md)・[実験の読み方](../../study/00224_利益保護後の再エントリーをシグナルで待つ/README.md)
