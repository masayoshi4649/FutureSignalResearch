# 183・184 単純IFDの入口比較CSV

全81セッション（41デイ・40ナイト、2026-09-21～11-16）を残した候補別CSV。**損失安定性の全面改善として採用した候補はない。** 結論と原因は[183レポート](../../study/00183_単純IFDで両指数の入口と損失安定性を検証する/README.md)、TOPIXの再実験は[184レポート](../../study/00184_TOPIXの足の形成時計と入口の反転を検証する/README.md)。

まずNK225の「旧入口」と「EM追加」のデイを比較し、次にTOPIXの「R0旧足」と「C1R0反転」のデイを見ると違いが分かる。EMは移動平均への押戻し後に回復を確認する追加入口。R0は低ADX下の反転仮説、C1はその要求方向を実側で反転した対照である。

## 数字の読み方

- 一つのCSVに一つの候補だけ。全81場は既使用期間の診断であり、未見性能を示さない。選択区分の「全80」「前48」はデイ・ナイト合計の場数で、デイの評価対象は各40場・24場。期間別の選択と結果は各試行の正本へ保存した。
- NK225：1pt100円、往復手数料77円＋追加滑り1,000円。TOPIX：1pt1,000円、往復手数料83.6円＋追加滑り500円。いずれもラージBBOからの代理約定で、実際のmini約定ではない。
- 利益は正の費用後損益の合計、損失は負の費用後損益の絶対額。収支＝利益−損失。未知の決済は空欄で、既知収支と全件確定収支を区別する。累計全件確定は最初の未知以降空欄。
- 金融は新規要求時の帯で分類し、保有時間は帯に実配分する。米前・米後の利益・損失・既知収支・取得回数・保有秒は合算してナイト合計になる。中央値・DD・率は元台帳から再計算し、帯別の数値を足さない。ナイト合計を再び加算しない。
- 保有率＝1枚以上の実保有時間÷対象時間。未知区間は下限・上限を分ける。待機・予約で水増しせず、開始待機なし、デイ15:30/ナイト05:45以降を分母から除外。
- `F/A/N/C`は順行先着/逆行先着/未到達/観測不足。到達済み先着率と費用後決済勝率は別。通常期限・終了前決済があるため、単純IFDでも全取引が必ず幅いっぱいに届くわけではない。
- TOPIXの純成立・保有棄却・失効列は全セッション単位。米前/米後ファイルに併記したこの診断数は足し合わせない。保有や金融の数とは別。
