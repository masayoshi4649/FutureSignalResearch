# FutureSignalResearch：先物の自動売買研究

NK225先物とTOPIX先物のテクニカル分析を、再現可能な仮説と損益検証へつなげるリポジトリです。ラージの板を分析の基礎とし、mini・microで取引する場合は商品別の倍率・呼値・執行条件を分けて扱います。

目標は、サーバーからWebSocketを受信し、チャートを分析して注文・決済を自動化することです。デイ08:45〜15:45、ナイト17:00〜翌06:00の各セッション内で取引を完結させ、建玉を持ち越さない設計を研究します。
